Kapitel 80

CSS-referens för renderingstema

Ett renderingstema är CSS. Det formaterar förhandsvisning, HTML, PDF, bild och utskrift, samt de Word-format som listas i slutet av det här kapitlet. Ett renderingstema kan vara en enda .css-fil eller en del av ett ZIP-paket med lokala tillgångar. Syntaxprofiler definierar hur källtext blir dokumentet; renderingsteman formaterar bara resultatet. CSS formaterar aldrig programmet eller redigeraren; det görs av programtemat (Chapter 79).

Kaskaden#

Pilcrow tillämpar stilar i denna ordning:

  1. Pilcrows strukturella återställning;
  2. det valda temats CSS;
  3. engångs-CSS från exportpanelen (Avancerade alternativ ▸ Anpassad CSS);
  4. nödvändiga korrigeringar för utskrift och rendering.

Senare regler vinner enligt den vanliga CSS-kaskaden. Tema-JavaScript, fjärrresurser, file:-URL:er och @import stöds inte.

Resurser#

Pilcrow läser tema-CSS med en vanlig CSS-tokenizer, så escape-sekvenser avkodas innan något kontrolleras: u\72 l(…) är en url() och @im\70 ort är en @import. Varje ställe där en webbläsare skulle läsa in något kontrolleras: url(…), url("…"), src("…") och strängar inuti image-set(). Var och en måste vara något av följande:

  • en paketrelativ sökväg (fonts/Body.woff2, ./paper.png). En ?query eller #fragment är tillåten och ignoreras när filen slås upp;
  • en data:-URL av typen PNG, JPEG, GIF, WebP, SVG (image/svg+xml), TTF, OTF, WOFF eller WOFF2;
  • en fragmentreferens som url(#shadow), som anger ett element på sidan.

Allt med ett annat schema än data: (https:, file:, blob:) eller som börjar med // avvisas, liksom en sökväg som börjar med / eller innehåller ...

ZIP-paket#

Ett ZIP-paket kan innehålla renderingsteman (.css) och programteman (.json) tillsammans; vart och ett listas med sitt eget slag i Inställningar. Ett ZIP med högst en CSS-fil och högst ett programtema behöver ingen manifestfil. Allt utöver det kräver pilcrow-theme.json, som listar varje tema under variants[].file. Filens ändelse avgör dess slag:

{
  "id": "com.example.paper",
  "name": "Paper",
  "version": "1.0.0",
  "author": "Example Author",
  "license": "MIT",
  "cssAPIVersion": 1,
  "variants": [
    { "id": "app", "name": "Paper", "file": "Paper.json", "appearance": "automatic" },
    { "id": "light", "name": "Paper Light", "file": "Paper-Light.css", "appearance": "light" },
    { "id": "dark", "name": "Paper Dark", "file": "Paper-Dark.css", "appearance": "dark" }
  ]
}

Manifestet beskriver paketet och dess teman. Det innehåller aldrig stilvärden: dessa finns i CSS- och programtemafilerna.

  • Paketets id namnger installationsmappen. Det får inte börja med . eller ha inledande eller avslutande blanksteg. Att installera ett paket vars id redan är installerat ersätter det.
  • Ett ZIP som skapats med Finders Komprimera fungerar som det är. Pilcrow hoppar över __MACOSX/, ._*, .DS_Store och Thumbs.db, och när alla filer ligger i en enda toppmapp behandlas den mappen som paketets rot.
  • Att radera ett tema tar bort det från paketet och behåller de andra tillsammans med de delade tillgångarna. Att radera det sista temat tar bort paketet. Ett raderat tema som var valt återställer valet till sitt slags standard: Automatisk för programtemat, Ljus för renderingstemat.
  • CSS kan referera till paketerade PNG-, JPEG-, GIF-, WebP-, TTF-, OTF-, WOFF- och WOFF2-filer med relativa url(...)-sökvägar. Pilcrow verifierar deras signaturer och bäddar in refererade tillgångar som data-URL:er så att rendering och exporterad HTML förblir offline och fristående. ZIP-sökvägar får inte lämna paketet, kollidera på grund av versaler och gemener eller peka på länkar. Arkivets storlek, antal poster, enskild storlek och komprimeringsgrad är begränsade.

Word#

Word-export använder de ljusa (bas) :root-värdena och mappar dessa semantiska egenskaper till namngivna Word-format: --pt-foreground, --pt-background, --pt-accent, --pt-link-color, --pt-code-background, --pt-code-foreground, --pt-body-font-family, --pt-mono-font-family, --pt-base-font-size och --pt-line-height. Webbläsarselektorer och layoutregler har ingen allmän motsvarighet i Word. Förhandsvisning, HTML, PDF och bild använder hela formatmallen; Word använder denna delmängd och bevarar samtidigt dokumentstruktur, diagram, matematikbilder, länkar och media. Exportpanelen visar denna begränsning varje gång Word är valt.

Pilcrow innehåller två renderingsteman, Ljus och Mörk, som är fullständiga utgångspunkter.
