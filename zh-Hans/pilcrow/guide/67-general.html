通用

语言与窗口#

控件作用
语言选择 Pilcrow 的语言，与设备的语言无关。系统默认 跟随设备。使用 AI 翻译的语言会显示“机器翻译，可能包含错误。”更改会在你下次打开 Pilcrow 时生效，在 Mac 上有 立即退出 按钮。
启动 Pilcrow 时显示翻译提示在你选择了 不再显示 之后，重新开启“由 AI 翻译”的提示。
关闭最后一个窗口时退出 Pilcrow（Mac）在你关闭最后一个窗口时退出 App，而不是让它继续运行。

文件#

控件作用
启动时Pilcrow 启动时打开的内容：打开新文件、恢复上次关闭的文件夹、恢复上次关闭的文件和文件夹 或 打开自定文件夹（带有 选择… 按钮）。恢复会重新打开 App 上次退出时屏幕上的内容。之后已被移动或删除的文件会被跳过。
新文稿存储为新文档的文件类型，也就是语法配置：每个配置连同其扩展名，例如“CommonMark (.md)”。
自动保存更改在你工作时存储已有文件的文档。
关闭文件时不询问直接保存跳过“是否要存储？”的提问并直接存储。
保留的版本数Pilcrow 为“版本历史”保留每个文件多少个已存储的版本，从无到 500 个。默认为 50。“保留的版本数：无”会关闭历史记录。
记录最近使用的文件和文件夹让 Pilcrow 记住你打开过的内容，用于 最近打开 以及启动时的恢复。
显示隐藏的文件夹和文件在“文件”面板中显示名称以点开头的项目。
当有项目拖放到 App 上时当你把项目拖放到编辑器或侧栏上时的行为：对于 文件夹 或 Markdown 文件，为 在编辑器中打开 或 插入链接；对于 可导入的文件（主题、语法配置或宏集合），为 在编辑器中打开、插入链接 或 导入文件。

翻译#

翻译需要 macOS 15 或 iPadOS 18 或更高版本。

控件作用
翻译为你的默认目标语言。第一个选项是“系统语言”。
速度快速、最佳质量 或 AI 助手。快速适合长文档，速度可快约二十倍，但措辞较为平实；它需要 macOS 或 iPadOS 26.4。AI 助手 会把文本发送到你在 设置 ▸ 助手 中设置的连接；你的服务可能会对此收费，且文本会离开设备。
当文件使用其他语言时不执行任何操作、提示翻译 或 自动翻译。Pilcrow 会在你打开文件时判断其语言，此过程不会有任何内容离开设备。提示会显示一个栏，可选择翻译为你的默认语言。
对所有文件再次提示清除你设为 不再对此文件提示 的文件。
翻译后在新标签页中打开、在原文件旁保存副本（文件名为原文件名加上语言，例如 Notes_fr.md），或 替换文稿（可以撤销）。
此设备上的语言列出每种语言及其状态：在此设备上、下载 或 不可用。翻译使用保留在设备上的语言包。下载语言包时会向系统请求权限；若要移除，请在系统的语言设置中操作。

助手#

控件作用
启用 AI 助手将助手面板添加到侧栏。在你提问之前不会发送任何内容，并且只发送你选择分享的文本。
状态行就绪。，或未就绪的原因：“当前连接的地址不可用。”“当前连接需要 API 密钥。”或“请在下方添加连接。连接就绪后会出现助手窗格。”
连接连接列表，为空时显示“尚无连接。”每一项会显示其名称，正在使用的那个会显示 当前。每行提供 设为当前、编辑… 和 移除。
添加连接一个菜单：OpenAI、Anthropic、OpenRouter、Ollama（此电脑）、LM Studio（此电脑） 或 自定义…。
已排除的文件永不分享的文件的匹配模式。* 代表名称中的任意字符，** 代表任意文件夹，以 / 结尾的名称涵盖整个文件夹。默认包括 *.pem、.env*、*.key 和 secrets/。可以 添加 一个模式、移除 一个模式，或 还原默认设置。
已关闭的文件夹列出你已关闭助手的文件夹，每个都带有 开启。没有时显示“没有已关闭的文件夹。”
隐私一个用于阅读 Pilcrow 隐私政策的链接，以及 删除所有 AI 数据…，它会移除所有连接和已存储的密钥、对话以及你的隐私选择，并关闭助手。操作前会先询问。

你的 API 密钥只存储在此设备的钥匙串中。

连接表单#

添加连接 和 编辑… 会打开一个表单。

字段作用
名称连接的标签。
格式兼容 OpenAI 或 Anthropic。
地址服务的网址。请使用 https://，仅在连接本机或本地网络时才使用 http://。
允许在我的本地网络中使用未加密的连接允许在你的网络中使用 http:// 地址。这会以明文发送你的文本和密钥，因此只有在你信任该网络时才允许。
模型要使用的模型，可通过 选择… 从服务的列表中挑选。
需要 API 密钥 和 API 密钥服务是否需要密钥，以及密钥本身，存放在钥匙串中。编辑时留空则保留已存储的密钥。
测试连接检查地址、密钥和模型。先显示“正在测试…”，然后显示“已连接（N 毫秒）。”
取消、存储关闭或保留该连接。

诊断#

控件作用
记录诊断日志记录 Pilcrow 正在做什么，以便在出问题时发送给支持人员。在你分享之前，它会一直保留在设备上，并且设计为不包含你的文档文本和文件名。开启期间，状态栏中会显示红色的 正在记录日志 标记。
记录停止时间1 小时、24 小时 或 从不。
记录内容Pilcrow 每个部分的级别：文本编辑器、宏、主题、解析与描述文件、渲染与图表、导出与打印、文件与资源库 以及 App。每一项可设为 仅问题、常规、详细 或 全部。问题和错误始终会被保留。
重现问题将每个部分都设为“详细”并开始记录。让问题再次出现，然后完成报告。
添加日志报告错误时：每次询问、始终添加 或 从不添加 日志的最新条目到你的剪贴板，以便粘贴到表单中。
报告错误…与 帮助 ▸ 报告错误… 相同。
包含在报告中以下各项的开关：设备与系统信息、Pilcrow 设置、文档结构（仅计数）、速度与内存、近期操作轨迹 和 崩溃详情。文档结构是指文档有多少个标题、表格等，绝不包含其中的文字。此屏幕不会发送任何内容。
查看日志…打开日志查看器（见下文）。
清除日志…在询问后，从此设备永久删除已记录的日志。关闭记录会保留已记录的内容，直到你清除为止。

在你为错误报告记录日志时，重现中 — 完成报告（或“帮助”菜单中的 完成错误报告）会停止记录并完成报告。在这种情况下，记录会在 30 分钟后自动停止。

日志查看器#

诊断日志 会显示摘要（条目、会话、错误、警告、崩溃报告 以及日期范围），然后是条目列表（最新的在前），带有 搜索日志 字段以及 部分 和 级别 筛选。筛选只改变你看到的内容，不改变发送的内容。报告包含日志中的每个条目，加上你在“包含在报告中”下选择的内容。重新加载 会刷新。发送报告 提供：

项目作用
存储报告…保留一个文件，供你自行发送。
共享报告…打开共享面板（AirDrop、“文件”等）。
在 GitHub 上报告…打开一个带有简短摘要的新 issue。你可以选择 将日志添加到描述（最新的条目，最多 60,000 个字符，这是 GitHub 允许的上限，会拷贝到你的剪贴板以便粘贴）或 存储并附加文件（完整日志，放在一个由你自己添加的文件中）。在 GitHub 上的报告是公开的。

当你在没有任何记录的情况下开始报告时，Pilcrow 会询问 先记录问题吗？：先记录问题、立即报告 或 取消。当它打开表单时，会询问是否 添加日志并打开表单、始终添加日志，或 不带日志打开表单。

存储与隐私#

Pilcrow 在其沙盒内保存恢复副本、历史记录、访问授权和支持数据。每个类别都可以单独删除。这些控件绝不会删除你的文档。

部分控件
文稿查看恢复数据 和 查看版本历史。查看会列出受影响的项目及其大小，让你在删除任何内容之前就能看到占用的空间。勾选要删除的项目（全选 或 全不选），然后选择 删除所选。当文档有未存储的更改时，无法查看恢复数据：请先存储或关闭它。
文件访问清除最近文件的访问权限… 会移除最近文件列表、记住的“存储为”文件夹、会话书签以及每个文件的语法选择。
私有数据与支持数据删除 AI 数据和密钥…（连接、钥匙串密钥、当前对话和 AI 隐私选择）、删除诊断信息…（已记录的日志和已存储的崩溃诊断）以及 清除缓存…（可重新生成的缓存文件和网络响应）。

每次删除都会要求确认（“此操作无法撤销。你的文档不会被删除。”）。自定义的语法配置、主题、宏、风格指南和背景不会在此处移除；请在它们各自的“资源库”页面中查看和删除。
