编辑

显示与输入#

显示#

控件作用
显示行号在边栏中显示行号。与 视图 ▸ 行号 相同。
在当前行下方显示横线在光标所在行下方显示一条细线。
样式化源码用相应的字体样式绘制标题、粗体和斜体。
标题折叠在标题旁显示折叠箭头。
渲染块将表格、公式和图表绘制为图片，并带有编辑按钮。
自动展开章节当光标进入折叠的章节或图片块时将其展开，光标离开时再将其关闭。
隐藏标记隐藏除光标所在行以外每一行的标题、粗体和斜体标记。需要启用“样式化源码”。
长行自动换行关闭时，长行会横向滚动而不是换行。预览和导出始终会换行。20,000 个字符或更长的行，以及专注模式，始终会换行。
列模式中的短行当某行太短而无法到达所选列时，列模式的行为：使用行尾、跳过该行、用空格软补齐（添加空格，使键入的文本在屏幕上对齐）、用空格硬补齐（为每个缺少的字符补一个空格，使其按列号对齐）或 在该行处停止。删除操作绝不会从短行中移除字符。
显示状态栏开启或关闭底部的状态栏。
格式工具栏在文本下方显示可选的工具栏。

输入#

控件作用
自动配对括号和引号输入左括号或左引号时会自动添加右括号或右引号。
自动配对 Markdown ( \* \_ ` ~ ) | 对 Markdown 的标记执行同样的操作。
展开表情符号短代码（:smile:）在你输入时将短代码转换为表情符号。已经包含短代码的文件会按原样显示。
按回车键延续列表和引用按回车键开始下一项，在空项上按回车键结束列表，按 Tab 键缩进项目。
按回车键保持缩进新的一行以与上一行相同的前导空格或制表符开头。
按 Tab 键时插入空格Tab 键会插入与制表符宽度相同数量的空格，直到下一个制表位，而不是插入制表符字符。

智能标点、高亮、下标和上标位于 资源库 ▸ CommonMark 选项 中。

键入声音#

控件作用
输入时播放声音每个按键都会发出声音；空格、回车和删除的声音各不相同。粘贴和撤销时保持静音。在 iPad 上，静音开关会将其静音。
声音声音包：打字机、鸭子 或 小猫。
音量、预览设置音量并试听声音包。
自定声音为任意一类按键选择一段短音频；其他按键仍使用上面选定的声音。类别有 小写字母、大写字母、数字、符号和标点、空格、制表符、换行 和 删除。每一类都有 选择…（或 更改…）、播放 和 移除。音频片段最长 2 秒、最大 3 MB（WAV、AIFF、MP3、M4A 或 CAF），并存放在内存中，因此播放时没有延迟。

拼写与诊断#

键入时检查拼写 会在拼写错误处加下划线。显示解析警告 会标出那些很可能不是你本意的结构所在的行，例如未闭合的代码围栏或公式块、缺少右括号的链接，或与表头不匹配的表格行。提示显示在该行末尾。它只改变显示的内容，绝不改变文档的解析或导出方式。

图像#

这些设置决定了你插入图像（插入 ▸ 图像…，或通过拖放）时会发生什么。

控件作用
操作无特殊操作、将图像复制到当前文件夹 (./)、将图像复制到 ./assets 或 Copy image to ./\${filename}.assets。上传图像 显示为不可用：Pilcrow 没有图像托管服务，因此图像会按其原有位置插入。
应用于本地图像该操作是否适用于已在你设备上的图像。
应用于在线图像是否适用于指向网址的图像。
从互联网加载图像关闭时，指向网址的图片不会为预览、PDF 或图像导出而下载，因此托管它们的网站不会获知任何信息。开启时，它们会像在网页浏览器中一样被获取，该网站可以看到这次请求。
尽可能使用相对路径写入相对于文档的路径。
为相对路径添加 ./让相对路径以 ./ 开头。
插入时转义图像 URL转义地址中会破坏链接的字符。
