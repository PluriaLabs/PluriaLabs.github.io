Chapter 54

The Edit menu

The Edit menu holds the system's standard commands and many of Pilcrow's own. Menu items for selection, lines and carets work on the source, so they are greyed out in Preview.

Undo, clipboard and paste#

ItemShortcutWhat it does
Undo, Redo⌘Z, ⇧⌘ZSteps back and forward through your edits.
Cut, Copy, Paste, Delete, Select AllThe system's commands.
Copy as Markdown⇧⌘CCopies the selection as Markdown source.
Copy as Plain TextCopies the selection with structural markup removed where possible.
Copy as HTML CodeCopies the selection's rendered HTML as text.
Paste as Plain Text⇧⌘VPastes without any formatting from the clipboard.

Find#

Find is a submenu.

ItemShortcut
Find…⌘F
Replace…⌘R
Find Next⌘G
Find Previous⇧⌘G

Spelling and Grammar#

On iPad this submenu holds only Check Spelling While Typing, the same switch as in Settings. The other two items are Mac only, because an iPad text view has no spelling panel.

ItemShortcutWhat it does
Show Spelling and Grammar⌘:Opens the system spelling panel.
Check Document Now⌘;Checks the whole document.
Check Spelling While TypingUnderlines misspellings as you type. The same switch is in Settings.

Transformations and Speech#

ItemWhat it does
Make Upper Case, Make Lower Case, CapitalizeChanges the case of the selection, or of the word at the caret.
Start Speaking, Stop SpeakingReads the selection aloud, or the whole document when nothing is selected.

Selection#

A submenu of ways to select and move.

ItemShortcutWhat it does
Select Word⌘DSelects the word at the caret.
Select Line⌘LSelects the whole file line, not the wrapped screen line.
Select Paragraph⌥⌘PSelects the paragraph.
Jump to Top, Jump to Bottom⌘↑, ⌘↓Moves the caret to the start or end of the document.
Jump to Line Start, Jump to Line End⌃A, ⌃EMoves to either end of the line.
Add Caret Above, Add Caret Below⌃⇧↑, ⌃⇧↓Adds another caret on the line above or below (Chapter 7).
Select Next Occurrence⌃⌥DAdds the next match of the selected text.
Select All Occurrences⌃⌥⇧DSelects every match at once.
Next Field, Previous Field⌥Tab, ⌥⇧TabJumps between fill-in fields a macro left (Chapter 24). Settings has a choice of key pairs for this, called Super Tab keys.
Carets in a Column…⌃⇧GOpens a sheet to place carets down a column by number.

The shortcuts for carets, occurrences, fields and the command palette can be changed in Settings ▸ Keyboard.

Lines#

ItemWhat it does
Sort Lines Ascending, Sort Lines DescendingSorts the selected lines.
Reverse LinesReverses their order.
Remove Duplicate LinesKeeps the first of each repeated line.
Remove Blank LinesDeletes empty lines in the selection.
Trim Trailing WhitespaceRemoves spaces and tabs at the ends of lines.
Join LinesJoins the selected lines into one.

Delete Range#

ItemShortcut
Delete Word⇧⌘D
Delete Line⌥⇧⌘L
Delete Paragraph⌥⇧⌘P

Move, translate, navigate#

ItemShortcutWhat it does
Move Row Up, Move Row Down⌥⌘↑, ⌥⌘↓Moves the current line or selected lines up or down.
Translate ▸ Document, Translate ▸ SelectionOpens the translate sheet (Chapter 63).
Go to Line…⌃GJumps to a line number, or line and column.
Check Links…Checks the document's links and images (Chapter 19).
Command Palette…⌃⇧POpens the command palette (Chapter 62).
Go Back, Go Forward⌃⌘←, ⌃⌘→Retraces the places you jumped between.

At the bottom, the system adds Writing Tools, AutoFill, Start Dictation… and Emoji & Symbols.
