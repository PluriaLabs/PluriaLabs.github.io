रेंडर थीम CSS संदर्भ

रेंडर थीम CSS है। यह पूर्वावलोकन, HTML, PDF, चित्र और प्रिंट आउटपुट की शैली तय करती है, और इस अध्याय के अंत में सूचीबद्ध Word शैलियों की भी। रेंडर थीम एक अकेली .css फ़ाइल हो सकती है या स्थानीय एसेट वाले ZIP पैकेज का हिस्सा। सिंटैक्स प्रोफ़ाइल तय करती हैं कि स्रोत टेक्स्ट दस्तावेज़ कैसे बनता है; रेंडर थीम केवल परिणाम की शैली तय करती हैं। CSS कभी ऐप या एडिटर की शैली तय नहीं करती; वह एप्लिकेशन थीम का काम है (Chapter 79)।

कैस्केड#

Pilcrow शैलियाँ इस क्रम में लागू करता है:

  1. Pilcrow का संरचनात्मक रीसेट;
  2. चुनी गई थीम की CSS;
  3. निर्यात पैनल की एक बार की CSS (उन्नत विकल्प ▸ कस्टम CSS);
  4. आवश्यक प्रिंट और रेंडरिंग सुधार।

बाद के नियम सामान्य CSS कैस्केड के अनुसार जीतते हैं। थीम JavaScript, दूरस्थ संसाधन, file: URL और @import समर्थित नहीं हैं।

संसाधन#

Pilcrow थीम की CSS को मानक CSS टोकनाइज़र से पढ़ता है, इसलिए कुछ भी जाँचने से पहले एस्केप डिकोड कर लिए जाते हैं: u\72 l(…) एक url() है और @im\70 ort एक @import है। हर वह जगह जहाँ से ब्राउज़र लोड करता है, जाँची जाती है: url(…), url("…"), src("…"), और image-set() के भीतर की स्ट्रिंग। हर एक इनमें से कोई एक होना चाहिए:

  • पैकेज-सापेक्ष पथ (fonts/Body.woff2, ./paper.png)। ?query या #fragment की अनुमति है और फ़ाइल खोजते समय उसे अनदेखा किया जाता है;
  • PNG, JPEG, GIF, WebP, SVG (image/svg+xml), TTF, OTF, WOFF या WOFF2 प्रकार का data: URL;
  • url(#shadow) जैसा फ़्रैगमेंट संदर्भ, जो पेज के किसी एलिमेंट का नाम देता है।

data: के अलावा किसी भी स्कीम वाली (https:, file:, blob:) या // से शुरू होने वाली कोई भी चीज़ अस्वीकार कर दी जाती है, वैसे ही जैसे / से शुरू होने वाला या .. वाला पथ।

ZIP पैकेज#

ZIP पैकेज में रेंडर थीम (.css) और एप्लिकेशन थीम (.json) एक साथ हो सकती हैं; हर एक सेटिंग्ज़ में अपने प्रकार के साथ सूचीबद्ध होती है। जिस ZIP में अधिकतम एक CSS फ़ाइल और अधिकतम एक एप्लिकेशन थीम हो, उसे मैनिफ़ेस्ट नहीं चाहिए। उससे अधिक के लिए pilcrow-theme.json चाहिए, जो हर थीम को variants[].file के अंतर्गत सूचीबद्ध करता है। फ़ाइल का एक्सटेंशन उसका प्रकार तय करता है:

{
  "id": "com.example.paper",
  "name": "Paper",
  "version": "1.0.0",
  "author": "Example Author",
  "license": "MIT",
  "cssAPIVersion": 1,
  "variants": [
    { "id": "app", "name": "Paper", "file": "Paper.json", "appearance": "automatic" },
    { "id": "light", "name": "Paper Light", "file": "Paper-Light.css", "appearance": "light" },
    { "id": "dark", "name": "Paper Dark", "file": "Paper-Dark.css", "appearance": "dark" }
  ]
}

मैनिफ़ेस्ट पैकेज और उसकी थीम का वर्णन करता है। इसमें कभी शैली के मान नहीं होते: वे CSS और एप्लिकेशन थीम फ़ाइलों में होते हैं।

  • पैकेज की id इंस्टॉल फ़ोल्डर का नाम बनती है। यह . से शुरू नहीं हो सकती और इसके आगे या पीछे स्पेस नहीं हो सकते। जिस पैकेज की id पहले से इंस्टॉल है, उसे इंस्टॉल करने पर वह बदल जाता है।
  • Finder के Compress से बनी ZIP जैसी है वैसी ही काम करती है। Pilcrow __MACOSX/, ._*, .DS_Store और Thumbs.db को छोड़ देता है, और जब हर फ़ाइल किसी एक शीर्ष-स्तर के फ़ोल्डर के भीतर हो, तो वह फ़ोल्डर पैकेज का रूट माना जाता है।
  • एक थीम हटाने पर वह पैकेज से हट जाती है और बाकी थीम साझा एसेट के साथ बनी रहती हैं। आखिरी थीम हटाने पर पैकेज हट जाता है। चुनी हुई थीम हटाने पर वह चयन अपने प्रकार के डिफ़ॉल्ट पर लौट आता है: एप्लिकेशन थीम के लिए स्वचालित, रेंडर थीम के लिए हल्का।
  • CSS सापेक्ष url(...) पथों से पैकेज में रखी PNG, JPEG, GIF, WebP, TTF, OTF, WOFF और WOFF2 फ़ाइलों का संदर्भ दे सकती है। Pilcrow उनके हस्ताक्षर सत्यापित करता है और संदर्भित एसेट को data URL के रूप में एम्बेड करता है, ताकि रेंडरिंग और निर्यात की गई HTML ऑफ़लाइन और आत्मनिर्भर रहें। ZIP के पथ पैकेज से बाहर नहीं जा सकते, अक्षर-रूप के कारण टकरा नहीं सकते, या लिंक की ओर इशारा नहीं कर सकते। आर्काइव का आकार, एंट्री की संख्या, अलग-अलग आकार और संपीड़न अनुपात सीमित हैं।

Word#

Word निर्यात हल्के (आधार) :root मान उपयोग करता है और इन अर्थपरक प्रॉपर्टी को नामित Word शैलियों में मैप करता है: --pt-foreground, --pt-background, --pt-accent, --pt-link-color, --pt-code-background, --pt-code-foreground, --pt-body-font-family, --pt-mono-font-family, --pt-base-font-size और --pt-line-height। ब्राउज़र सेलेक्टर और लेआउट नियमों का Word में कोई सामान्य समतुल्य नहीं है। पूर्वावलोकन, HTML, PDF और चित्र आउटपुट पूरी स्टाइलशीट उपयोग करते हैं; Word इस उपसमूह का उपयोग करता है और दस्तावेज़ की संरचना, आरेख, गणित के चित्र, लिंक और मीडिया को बनाए रखता है। Word चुने जाने पर निर्यात पैनल यह सीमा दिखाता है।

Pilcrow में दो रेंडर थीम शामिल हैं, हल्का और गहरा, जो पूर्ण शुरुआती बिंदु हैं।
