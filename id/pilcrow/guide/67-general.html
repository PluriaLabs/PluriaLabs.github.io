Umum

Bahasa & Jendela#

KontrolFungsinya
BahasaMemilih bahasa Pilcrow, terpisah dari bahasa perangkat. Default sistem mengikuti perangkat. Bahasa yang diterjemahkan dengan AI menampilkan "Diterjemahkan mesin — mungkin mengandung kesalahan." Perubahan berlaku saat Anda membuka Pilcrow berikutnya, dengan tombol Keluar Sekarang di Mac.
Tampilkan pemberitahuan terjemahan saat Pilcrow dimulaiMengaktifkan kembali pemberitahuan "Diterjemahkan dengan AI" setelah Anda memilih Jangan tampilkan ini lagi.
Keluar dari Pilcrow saat jendela terakhir ditutup (Mac)Menutup app saat Anda menutup jendela terakhir, alih-alih membiarkannya tetap berjalan.

File#

KontrolFungsinya
Saat dimulaiApa yang dibuka Pilcrow saat peluncuran: Buka file baru, Pulihkan folder yang terakhir ditutup, Pulihkan file dan folder yang terakhir ditutup, atau Buka folder kustom (dengan tombol Pilih…). Pemulihan membuka kembali apa yang ada di layar saat app terakhir ditutup. File yang sejak itu dipindahkan atau dihapus dilewati.
Simpan dokumen baru sebagaiJenis file, dan dengan demikian profil sintaks, untuk dokumen baru: setiap profil beserta ekstensinya, misalnya "CommonMark (.md)".
Simpan perubahan secara otomatisMenyimpan dokumen yang sudah memiliki file saat Anda bekerja.
Simpan tanpa bertanya saat menutup fileMelewati pertanyaan "apakah Anda ingin menyimpan?" dan langsung menyimpan.
Versi yang disimpanBerapa banyak versi tersimpan dari setiap file yang disimpan Pilcrow untuk Riwayat Versi, dari nol sampai 500. Defaultnya 50. "Versi yang disimpan: tidak ada" mematikan riwayat.
Catat file dan folder terbaruMembiarkan Pilcrow mengingat apa yang Anda buka, untuk Buka Terbaru dan untuk pemulihan saat peluncuran.
Tampilkan folder dan file tersembunyiMenampilkan item yang namanya diawali titik di panel File.
Saat sesuatu dijatuhkan ke appApa yang terjadi saat Anda menjatuhkan sesuatu ke editor atau bar samping: untuk Folder atau File Markdown, Buka di editor atau Sisipkan tautan; untuk File yang dapat diimpor (tema, profil sintaks, atau koleksi makro), Buka di editor, Sisipkan tautan, atau Impor file.

Terjemahan#

Terjemahan memerlukan macOS 15 atau iPadOS 18 atau yang lebih baru.

KontrolFungsinya
Terjemahkan ke dalamBahasa target default Anda. Pilihan pertama adalah "Bahasa sistem".
KecepatanCepat, Kualitas terbaik, atau Asisten AI. Cepat cocok untuk dokumen panjang dan bisa sekitar dua puluh kali lebih cepat, dengan pilihan kata yang lebih sederhana; memerlukan macOS atau iPadOS 26.4. Asisten AI mengirim teks ke koneksi Anda dari Pengaturan ▸ Asisten; layanan Anda mungkin memungut biaya dan teks keluar dari perangkat.
Saat file berbahasa lainJangan lakukan apa pun, Tawarkan untuk menerjemahkan, atau Terjemahkan otomatis. Pilcrow menentukan bahasa file saat Anda membukanya, dan tidak ada yang keluar dari perangkat untuk itu. Tawaran tersebut menampilkan bilah dengan pilihan untuk menerjemahkan ke bahasa default Anda.
Tawarkan Lagi untuk Semua FileMenghapus file yang Anda atur ke Jangan untuk File Ini.
Setelah menerjemahkanBuka di tab baru, Simpan salinan di samping aslinya (dinamai seperti aslinya dengan tambahan bahasa, misalnya Notes_fr.md), atau Ganti dokumen (dapat dibatalkan).
Bahasa di Perangkat IniMencantumkan setiap bahasa dengan Di perangkat ini, Unduh, atau Tidak tersedia. Terjemahan menggunakan paket bahasa yang tetap berada di perangkat. Mengunduh satu paket meminta izin dari sistem; hapus paket di pengaturan bahasa sistem.

Asisten#

KontrolFungsinya
Aktifkan asisten AIMenambahkan panel Asisten ke bar samping. Tidak ada yang dikirim sampai Anda bertanya, dan hanya teks yang Anda pilih untuk dibagikan.
Baris statusSiap., atau alasan mengapa belum siap: "Alamat koneksi aktif tidak dapat digunakan.", "Koneksi aktif memerlukan kunci API.", atau "Tambahkan koneksi di bawah. Panel Asisten muncul setelah ada yang siap."
KoneksiDaftar koneksi, dengan "Belum ada koneksi." saat kosong. Masing-masing menampilkan namanya dan, untuk yang sedang dipakai, Aktif. Sebuah baris menawarkan Aktifkan, Edit…, dan Hapus.
Tambah KoneksiSebuah menu: OpenAI, Anthropic, OpenRouter, Ollama (komputer ini), LM Studio (komputer ini), atau Kustom….
File yang dikecualikanPola untuk file yang tidak pernah dibagikan. * mewakili karakter apa pun dalam sebuah nama, ** mewakili folder apa pun, dan nama yang diakhiri / mencakup seluruh folder. Defaultnya mencakup *.pem, .env*, *.key, dan secrets/. Tambah pola, Hapus satu, atau Pulihkan Default.
Folder dinonaktifkanMencantumkan folder tempat Anda mematikan asisten, masing-masing dengan Aktifkan. Menampilkan "Tidak ada folder yang dimatikan." bila tidak ada.
PrivasiTautan untuk membaca kebijakan privasi Pilcrow, dan Hapus Semua Data AI…, yang menghapus setiap koneksi dan kunci tersimpan, percakapan, serta pilihan privasi Anda, lalu mematikan asisten. Akan bertanya terlebih dahulu.

Kunci API Anda disimpan di Keychain hanya di perangkat ini.

Formulir koneksi#

Tambah Koneksi dan Edit… membuka sebuah formulir.

IsianFungsinya
NamaLabel untuk koneksi.
FormatKompatibel dengan OpenAI atau Anthropic.
AlamatAlamat web layanan. Gunakan https://, atau http:// hanya untuk komputer ini atau jaringan lokal Anda.
Izinkan koneksi tanpa enkripsi di jaringan lokal sayaMengizinkan alamat http:// di jaringan Anda. Teks dan kunci Anda dikirim tanpa enkripsi, jadi izinkan hanya jika Anda memercayai jaringannya.
ModelModel yang digunakan, dengan Pilih… untuk memilih dari daftar layanan.
Memerlukan kunci API dan Kunci APIApakah layanan memerlukan kunci, dan kuncinya sendiri, yang disimpan di Keychain. Biarkan kosong saat mengedit untuk mempertahankan kunci yang tersimpan.
Uji KoneksiMemeriksa alamat, kunci, dan model. Menampilkan "Menguji…" lalu "Terhubung (N md)."
Batalkan, SimpanMenutup atau mempertahankan koneksi.

Diagnostik#

KontrolFungsinya
Rekam log diagnostikMerekam apa yang dilakukan Pilcrow, sehingga Anda dapat mengirimkannya ke dukungan saat terjadi masalah. Log tetap berada di perangkat sampai Anda membagikannya, dan dirancang untuk tidak menyertakan teks dokumen dan nama file Anda. Saat aktif, tanda merah Merekam log tampil di bar status.
Hentikan perekaman setelah1 jam, 24 jam, atau Jangan.
Apa yang direkamTingkat untuk setiap bagian Pilcrow: Editor teks, Makro, Tema, Parsing dan profil, Perenderan dan diagram, Ekspor dan cetak, File dan pustaka, dan App. Masing-masing adalah Hanya masalah, Normal, Terperinci, atau Semuanya. Masalah dan kesalahan selalu disimpan.
Munculkan masalahMengatur setiap bagian ke Terperinci dan mulai merekam. Buat masalahnya terjadi lagi, lalu selesaikan laporan.
Tambahkan logSaat Anda melaporkan bug: Tanya setiap kali, Selalu tambahkan, atau Jangan pernah tambahkan entri log terbaru ke clipboard Anda untuk ditempelkan ke formulir.
Laporkan Bug…Sama dengan Bantuan ▸ Laporkan Bug….
Sertakan dalam laporanSakelar untuk Informasi perangkat dan sistem, Pengaturan Pilcrow, Struktur dokumen (hanya jumlah), Kecepatan dan memori, Jejak tindakan terbaru, dan Detail crash. Struktur dokumen adalah jumlah judul, tabel, dan sebagainya dalam dokumen, tidak pernah kata-katanya. Tidak ada yang dikirim dari layar ini.
Lihat Log…Membuka penampil log (di bawah).
Hapus Log…Menghapus log yang direkam dari perangkat ini secara permanen, setelah bertanya. Mematikan perekaman mempertahankan apa yang sudah direkam sampai Anda menghapusnya.

Saat Anda merekam log untuk laporan bug, Mereproduksi — Selesaikan Laporan (atau Selesaikan Laporan Bug di menu Bantuan) menghentikan perekaman dan menyelesaikan laporan. Dalam kasus itu, perekaman berhenti sendiri setelah 30 menit.

Penampil log#

Log Diagnostik menampilkan ringkasan (Entri, Sesi, Kesalahan, Peringatan, Laporan crash, dan rentang tanggal), lalu entri, yang terbaru di atas, dengan kolom Cari di log serta filter Bagian dan Tingkat. Filter hanya mengubah apa yang Anda lihat, bukan apa yang dikirim. Laporan berisi setiap entri dalam log ditambah apa yang Anda pilih di bawah Sertakan dalam laporan. Muat Ulang menyegarkannya. Kirim Laporan menawarkan:

ItemFungsinya
Simpan Laporan…Menyimpan file yang dapat Anda kirim sendiri.
Bagikan Laporan…Membuka lembar berbagi (AirDrop, File, dan sebagainya).
Laporkan di GitHub…Membuka isu baru dengan ringkasan singkat. Anda memilih Tambahkan Log ke Deskripsi (entri terbaru, hingga 60.000 karakter, batas maksimal GitHub, disalin ke clipboard Anda untuk ditempel) atau Simpan dan Lampirkan File (seluruh log, dalam file yang Anda tambahkan sendiri). Laporan di GitHub bersifat publik.

Saat Anda memulai laporan tanpa ada yang direkam, Pilcrow bertanya Rekam masalahnya dulu?: Rekam masalah dulu, Laporkan sekarang, atau Batalkan. Saat membuka formulir, Pilcrow bertanya apakah akan Tambahkan Log dan Buka Formulir, Selalu Tambahkan Log, atau Buka Formulir Tanpa Log.

Penyimpanan & Privasi#

Pilcrow menyimpan salinan pemulihan, riwayat, izin akses, dan data dukungan di dalam sandbox-nya. Setiap kategori dapat dihapus secara terpisah. Kontrol ini tidak pernah menghapus dokumen Anda.

BagianKontrol
DokumenTinjau data pemulihan dan Tinjau riwayat versi. Tinjau mencantumkan item yang terpengaruh beserta ukurannya, sehingga Anda dapat melihat ruang yang dipakai sebelum menghapus apa pun. Centang yang ingin dihapus (Pilih semua atau Batalkan semua pilihan) dan pilih Hapus yang dipilih. Data pemulihan tidak dapat ditinjau selama dokumen memiliki perubahan yang belum disimpan: simpan atau tutup dokumen itu terlebih dahulu.
Akses fileHapus akses file terbaru… menghapus daftar file terbaru, folder Simpan Sebagai yang diingat, bookmark sesi, dan pilihan sintaks per file.
Data pribadi & dukunganHapus data & kunci AI… (koneksi, kunci Keychain, percakapan saat ini, dan pilihan privasi AI), Hapus diagnostik… (log yang direkam dan diagnostik crash yang tersimpan), dan Bersihkan cache… (file cache dan respons jaringan yang dapat dibuat ulang).

Setiap penghapusan meminta konfirmasi ("Tindakan ini tidak dapat dibatalkan. Dokumen Anda tidak akan dihapus."). Profil sintaks, tema, makro, panduan gaya, dan latar kustom tidak dihapus di sini; tinjau dan hapus di halaman Pustaka masing-masing.
