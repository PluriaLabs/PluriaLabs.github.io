Bab 79

Format Tema Aplikasi

Tema Aplikasi menata gaya Pilcrow itu sendiri: tampilan terang atau gelapnya, warna aksen, bar samping, bar status dan pemformatan, serta editor. Ini adalah file JSON. Dokumen yang dirender (Pratinjau, HTML, PDF, gambar, cetak, dan Word) ditata secara terpisah oleh Tema Render, yaitu CSS (Chapter 80). Kedua jenis ini dipasang, dipilih, dan dihapus secara terpisah, dan tidak ada yang mengikuti yang lain.

Contoh lengkap#

{
  "pilcrowAppTheme": 1,
  "name": "Nord",
  "appearance": "dark",
  "colors": {
    "accent": "#88C0D0",
    "sidebar": { "background": "#2E3440", "foreground": "#D8DEE9" },
    "bars": { "background": "#3B4252", "foreground": "#D8DEE9" },
    "editor": {
      "background": "#2E3440",
      "foreground": "#ECEFF4",
      "cursor": "#88C0D0",
      "selection": "#434C5E",
      "gutterBackground": "#2E3440",
      "gutterForeground": "#4C566A"
    },
    "syntax": {
      "heading": "#88C0D0",
      "marker": "#EBCB8B",
      "code": "#A3BE8C",
      "link": "#81A1C1",
      "muted": "#7B88A1",
      "tokens": { "strong": "#D08770" }
    }
  }
}

Tingkat atas#

KunciWajibNilai
pilcrowAppThemeyaVersi format, 1.
nameya1–200 karakter. Ditampilkan di Pengaturan dan menu Tema.
appearanceya"light", "dark" atau "automatic".
colorstema light dan darkSatu palet (di bawah).
light, darktema automaticDua palet: satu digunakan pada tampilan terang sistem, satu pada tampilan gelap.
idtidakDitulis oleh Pilcrow untuk pustakanya sendiri. Diabaikan saat impor, yang selalu memberikan id baru.

appearance menentukan tampilan setiap jendela: termasuk menu, Pengaturan, sheet, dan pemilih. Tema light atau dark menetapkannya secara tetap; automatic mengikuti sistem.

Tema automatic harus menetapkan setiap warna di light dan dark sekaligus atau di keduanya tidak sama sekali. Warna yang ditetapkan hanya untuk satu tampilan jika tidak akan digambar pada tampilan yang lain.

Palet#

Setiap kunci bersifat opsional. Warna yang dihilangkan mempertahankan tampilan bawaan Pilcrow, sehingga tema bisa sesederhana satu warna aksen.

KunciMenata gaya
accentRona di seluruh aplikasi: tombol, segmen terpilih, sakelar, tautan, cincin fokus, dan baris terpilih di bar samping. Jika tidak ditetapkan, aksen sistem dipertahankan.
sidebar.background, sidebar.foregroundBar samping File, Kerangka, dan Cari. Label sekunder diturunkan dari latar depan.
bars.background, bars.foregroundBar status, bilah alat pemformatan yang disematkan, dan pemberitahuan impor. Label sekunder diturunkan dari latar depan.
editor.background, editor.foregroundKanvas editor dan teks isi.
editor.cursor, editor.selectionTitik sisip dan sorotan pilihan.
editor.gutterBackground, editor.gutterForegroundGutter nomor baris. Latar belakangnya secara default mengikuti latar belakang editor.
editor.currentLineRuleGaris tipis di bawah baris tempat kursor berada, saat Tampilan ▸ Aturan Baris Saat Ini aktif. Secara default berupa warna teks editor dengan kekuatan rendah.
syntax.<group>Warna sintaks langsung menurut grup (di bawah).
syntax.tokens.<raw>Satu token menurut nilai mentahnya, menggantikan grupnya.

Grup sintaks#

GrupMewarnai
headingJudul (penanda dan teks), penanda peringatan, istilah definisi
markerPenekanan, tebal, coretan, dan pembatas inline lainnya; penanda daftar dan tugas
codeKode inline, blok kode berpagar dan berindentasi, matematika, blok HTML
linkLabel dan tujuan tautan dan gambar, tautan otomatis
mutedPenanda kutipan blok, pemisah tematik, baris tabel, komentar, atribut blok
codeKeyword, codeString, codeNumber, codeCommentKode yang disorot di dalam pagar

Grup yang tidak ditetapkan mendapat warna bawaan yang dipilih sesuai latar belakang editor: nada lebih gelap pada kanvas terang, nada lebih terang pada kanvas gelap. Nama token di syntax.tokens menggunakan huruf, angka, _ dan -, dan tidak boleh sama dengan nama grup (syntax.heading sudah mencakup heading).

Warna#

Setiap warna adalah string hex: #RGB, #RGBA, #RRGGBB atau #RRGGBBAA, dalam sRGB. Pilcrow menyimpannya dalam huruf besar.

Validasi#

Pilcrow menolak file daripada mengabaikan sebagian isinya, dan menyebutkan kunci yang bermasalah, misalnya colors.editor.cursor: must be a hex colour. Pilcrow menolak:

  • versi pilcrowAppTheme yang hilang atau berbeda;
  • kunci tak dikenal di tingkat mana pun (biasanya salah ketik);
  • kunci palet yang tidak sesuai dengan tampilan (colors pada tema automatic, light dan dark pada tema light atau dark);
  • warna yang bukan hex;
  • tema automatic yang palet light dan dark-nya menetapkan warna berbeda.

Yang tidak diubah oleh Tema Aplikasi#

Bilah judul dan bilah alat jendela (kaca milik sistem, yang hanya menerima aksen), menu, Pengaturan, sheet, dan pemilih mempertahankan tampilan aslinya selain tampilan dan aksen. Font tidak ditema: font dan ukuran editor diatur di Pengaturan ▸ Tampilan ▸ Ukuran Teks & Font.

Memasang dan membagikan#

  • Impor file .json dari Pengaturan ▸ Pustaka ▸ Tema, File ▸ Impor ▸ Tema di Mac, atau Pengaturan ▸ Pustaka ▸ Impor di iPad. Menjatuhkan file ke Pilcrow juga berfungsi.
  • Paket tema .zip dapat berisi Tema Aplikasi bersama Tema Render (Chapter 80).
  • Tombol bagikan di samping tema menyimpan file .json-nya, atau seluruh paket jika tema berasal dari paket.

Pilcrow menyertakan tiga Tema Aplikasi: Otomatis, Terang, dan Gelap. Ketiganya menetapkan warna editor dan sintaks dan membiarkan chrome dalam tampilan bawaannya.
