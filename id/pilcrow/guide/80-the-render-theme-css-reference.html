Bab 80

Referensi CSS Tema Render

Tema Render adalah CSS. Ia menata gaya keluaran Pratinjau, HTML, PDF, gambar, dan cetak, serta gaya Word yang tercantum di akhir bab ini. Tema Render dapat berupa satu file .css atau bagian dari paket ZIP dengan aset lokal. Profil sintaks menentukan bagaimana teks sumber menjadi dokumen; Tema Render hanya menata hasilnya. CSS tidak pernah menata gaya aplikasi atau editor; itu adalah Tema Aplikasi (Chapter 79).

Cascade#

Pilcrow menerapkan gaya dalam urutan ini:

  1. reset struktural Pilcrow;
  2. CSS tema yang dipilih;
  3. CSS sekali pakai dari panel ekspor (Opsi lanjutan ▸ CSS Kustom);
  4. koreksi cetak dan perenderan yang diperlukan.

Aturan yang lebih akhir menang menurut cascade CSS normal. JavaScript tema, sumber daya jarak jauh, URL file:, dan @import tidak didukung.

Sumber daya#

Pilcrow membaca CSS tema dengan tokenizer CSS standar, sehingga escape didekode sebelum apa pun diperiksa: u\72 l(…) adalah url() dan @im\70 ort adalah @import. Setiap tempat yang akan dimuat oleh browser diperiksa: url(…), url("…"), src("…"), dan string di dalam image-set(). Masing-masing harus berupa salah satu dari:

  • path relatif paket (fonts/Body.woff2, ./paper.png). ?query atau #fragment diperbolehkan dan diabaikan saat file dicari;
  • URL data: bertipe PNG, JPEG, GIF, WebP, SVG (image/svg+xml), TTF, OTF, WOFF atau WOFF2;
  • referensi fragmen seperti url(#shadow), yang menunjuk elemen di halaman.

Apa pun dengan skema selain data: (https:, file:, blob:) atau diawali // ditolak, begitu pula path yang diawali / atau mengandung ...

Paket ZIP#

Paket ZIP dapat berisi Tema Render (.css) dan Tema Aplikasi (.json) sekaligus; masing-masing dicantumkan dengan jenisnya sendiri di Pengaturan. ZIP dengan paling banyak satu file CSS dan paling banyak satu Tema Aplikasi tidak memerlukan manifes. Selebihnya memerlukan pilcrow-theme.json, yang mencantumkan setiap tema di bawah variants[].file. Ekstensi file menentukan jenisnya:

{
  "id": "com.example.paper",
  "name": "Paper",
  "version": "1.0.0",
  "author": "Example Author",
  "license": "MIT",
  "cssAPIVersion": 1,
  "variants": [
    { "id": "app", "name": "Paper", "file": "Paper.json", "appearance": "automatic" },
    { "id": "light", "name": "Paper Light", "file": "Paper-Light.css", "appearance": "light" },
    { "id": "dark", "name": "Paper Dark", "file": "Paper-Dark.css", "appearance": "dark" }
  ]
}

Manifes menjelaskan paket dan temanya. Manifes tidak pernah berisi nilai gaya: nilai tersebut ada di file CSS dan Tema Aplikasi.

  • id paket menamai folder pemasangan. Tidak boleh diawali . atau memiliki spasi di awal atau akhir. Memasang paket yang id-nya sudah terpasang akan menggantikannya.
  • ZIP yang dibuat dengan Kompres Finder berfungsi apa adanya. Pilcrow melewati __MACOSX/, ._*, .DS_Store dan Thumbs.db, dan bila setiap file berada di dalam satu folder tingkat atas, folder itu diperlakukan sebagai akar paket.
  • Menghapus satu tema akan mengeluarkannya dari paket dan mempertahankan yang lain beserta aset bersama. Menghapus tema terakhir akan menghapus paket. Tema terhapus yang sedang dipilih mengembalikan pilihan itu ke default jenisnya: Otomatis untuk Tema Aplikasi, Terang untuk Tema Render.
  • CSS dapat merujuk file PNG, JPEG, GIF, WebP, TTF, OTF, WOFF dan WOFF2 yang dikemas dengan path url(...) relatif. Pilcrow memverifikasi tanda tangannya dan menyematkan aset yang dirujuk sebagai URL data agar perenderan dan HTML yang diekspor tetap offline dan mandiri. Path ZIP tidak boleh keluar dari paket, bertabrakan karena perbedaan huruf besar-kecil, atau menunjuk ke tautan. Ukuran arsip, jumlah entri, ukuran individual, dan rasio kompresi dibatasi.

Word#

Ekspor Word menggunakan nilai :root terang (dasar) dan memetakan properti semantik ini ke gaya Word bernama: --pt-foreground, --pt-background, --pt-accent, --pt-link-color, --pt-code-background, --pt-code-foreground, --pt-body-font-family, --pt-mono-font-family, --pt-base-font-size dan --pt-line-height. Selektor browser dan aturan tata letak tidak memiliki padanan umum di Word. Keluaran Pratinjau, HTML, PDF, dan gambar menggunakan stylesheet lengkap; Word menggunakan subset ini sambil mempertahankan struktur dokumen, diagram, gambar matematika, tautan, dan media. Panel ekspor menampilkan keterbatasan ini setiap kali Word dipilih.

Pilcrow menyertakan dua Tema Render, Terang dan Gelap, yang merupakan titik awal lengkap.
