Bab 60

Bilah samping

Bilah samping memuat lima panel: File, Kerangka, Cari, Proyek dan Asisten. Sakelar di bagian atas bilah samping memilih File, Kerangka, Proyek (muncul saat folder yang terbuka adalah proyek buku) atau Asisten (muncul setelah koneksi disiapkan). Cari memiliki header sendiri dengan judul Cari, tombol Selesai yang kembali ke File, dan kontrol cakupan untuk Dokumen Ini atau Folder; buka lewat Tampilan ▸ Cari (⇧⌘F). Menu Tampilan juga mengganti panel, dan memilih panel yang sedang tampil akan menyembunyikan bilah samping. Seret tepi bilah samping untuk mengubah ukurannya. Di atas pohon file, sebuah menu menawarkan Buka File… dan Buka Folder….

File#

Panel File adalah pohon dari folder yang terbuka.

Jika tidak ada folder yang terbuka, panel ini menampilkan "Choose a folder to browse its files." dan menawarkan Buka Folder dan Buka File. Anda juga bisa menjatuhkan folder ke dalamnya. Saat Anda membuka satu file yang foldernya tidak dapat dilihat Pilcrow, panel ini menawarkan "Browse folder to see the files beside this document", dengan Telusuri Folder Penampung….

Klik file untuk membukanya. Folder dapat dibuka dan ditutup. Klik kanan sebuah baris, atau tekan dan tahan di iPad, untuk melihat menunya:

ItemFungsinya
File BaruMembuat file di dalam folder (atau di samping file yang Anda klik).
Folder BaruMembuat folder di sana.
Ganti Nama…Mengganti nama file atau folder.
Pindahkan ke SampahMemindahkannya ke Sampah setelah Anda mengonfirmasi. Anda dapat mengembalikannya dari sana.
Tampilkan di FinderMenampilkannya di Finder (Mac).

Jika sistem tidak memiliki Sampah untuk suatu lokasi, Pilcrow menyimpan item yang dihapus di bagian Baru Saja Dihapus di bagian bawah panel. Setiap item di sana menawarkan Kembalikan dan Hapus Permanen, dan Kosongkan Baru Saja Dihapus menghapus seluruh item di bagian itu untuk selamanya. Penghapusan permanen tidak dapat dibatalkan, jadi Pilcrow bertanya dulu. Item yang Anda hapus dari tempat lain tidak terpengaruh.

File dan folder tersembunyi ditampilkan atau disembunyikan lewat Pengaturan ▸ File ▸ Tampilkan folder dan file tersembunyi.

Kerangka#

Kerangka mencantumkan judul dari dokumen aktif, dengan indentasi sesuai tingkatnya. Klik sebuah judul untuk melompat ke sana. Tanda panah di samping judul menutup atau membuka judul-judul yang bersarang di bawahnya. Ini tidak mengubah dokumen, dan keadaan tertutup tidak disimpan.

Keadaan yang mungkin Anda lihat:

PesanArtinya
Tidak ada judulProfil aktif tidak menemukan judul.
Indexing outline… N%Dokumen besar masih dipindai.
Outline indexing failed. The listing may be incomplete.Pemindaian mengalami masalah.
N headings near your position — scroll to see others.Dokumen yang sangat besar menampilkan sebagian kerangka di sekitar kursor.

Di bawah kerangka, bagian Isian muncul saat dokumen memiliki isian yang harus diisi (Chapter 24). Bagian ini mencantumkannya, beserta jumlahnya; klik salah satu untuk menggulir ke sana dan memilihnya. Untuk isian dalam jumlah sangat banyak, tertulis "Only the first fields are listed."

Cari#

Panel Cari mencari di setiap file dalam folder yang terbuka. Tanpa folder, panel ini menampilkan "Open a folder to search it." dengan tombol Buka Folder….

KontrolFungsinya
Isian Cari di FolderKetik untuk mencari seiring Anda mengetik. Tombol clear mengosongkannya.
AaCocokkan huruf besar/kecil.
abSeluruh kata.
.\*Ekspresi reguler. Pola yang salah dilaporkan di bawah isian.
Baris statusMenampilkan "Searching…" dengan tombol Batalkan, lalu "Matches: N". Pencarian berhenti pada 500 kecocokan dan menampilkan "Showing the first 500 matches." Setelah dibatalkan, tersedia Cari Lagi.
Ganti…Muncul saat pencarian menemukan kecocokan. Membuka Ganti di Folder (Chapter 63).
HasilSetiap hasil menyebut file dan menampilkan barisnya. Klik salah satu untuk membuka file pada baris itu.

Proyek#

Panel Proyek ditujukan untuk proyek buku. Lihat Chapter 34, Chapter 35 dan acuan panel Proyek di bawah.

Detail untuk sebuah item memiliki Jenis (Bagian awal, Bagian, Bab, Adegan, Bagian akhir), Status, Sudut pandang, Lokasi, Target jumlah kata, dan Sinopsis. File proyek yang berubah di disk menampilkan "The project file changed on disk, so your last change was not applied. Try it again." dengan Abaikan.

Pengaturan proyek memiliki Judul, Penulis, Target jumlah kata buku, Berkas baru ditulis dalam (sintaks untuk bab dan adegan baru; file yang sudah ada tetap memakai sintaksnya), Variabel (nama dan nilai, ditulis sebagai {{name}} dalam teks Anda; {{title}} dan {{author}} selalu berfungsi), dan Apa yang dihitung sebagai kata: Hitung judul, Hitung bagian awal, Hitung blok kode. Pilih Simpan atau Batalkan.
