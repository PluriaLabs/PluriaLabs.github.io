Розділ 80

Довідник CSS теми відображення

Тема відображення — це CSS. Вона стилізує Перегляд, HTML, PDF, зображення й друк, а також стилі Word, перелічені в кінці цього розділу. Тема відображення може бути одним файлом .css або частиною пакета ZIP з локальними ресурсами. Профілі синтаксису визначають, як вихідний текст стає документом; теми відображення лише стилізують результат. CSS ніколи не стилізує програму чи редактор; це робить тема програми (розділ 79).

Каскад#

Pilcrow застосовує стилі в такому порядку:

  1. структурне скидання Pilcrow;
  2. CSS вибраної теми;
  3. разовий CSS з панелі експорту (Додаткові параметри ▸ Власний CSS);
  4. необхідні виправлення для друку й відображення.

Пізніші правила перемагають за звичайним каскадом CSS. JavaScript у темах, віддалені ресурси, URL file: та @import не підтримуються.

Ресурси#

Pilcrow читає CSS теми стандартним токенізатором CSS, тож екранування декодуються до будь-якої перевірки: u\72 l(…) — це url(), а @im\70 ort — це @import. Перевіряється кожне місце, звідки браузер міг би завантажувати: url(…), url("…"), src("…") та рядки всередині image-set(). Кожне має бути одним із таких:

  • шлях відносно пакета (fonts/Body.woff2, ./paper.png). ?query або #fragment дозволені й ігноруються під час пошуку файлу;
  • URL data: типу PNG, JPEG, GIF, WebP, SVG (image/svg+xml), TTF, OTF, WOFF або WOFF2;
  • посилання на фрагмент, як-от url(#shadow), що називає елемент на сторінці.

Усе зі схемою, відмінною від data: (https:, file:, blob:), або що починається з //, відхиляється, так само як і шлях, що починається з / або містить ...

  --pt-border-color: #dadce0;

  --pt-code-foreground: #202124;

Пакети ZIP#

Пакет ZIP може містити разом теми відображення (.css) і теми програми (.json); кожна показується в Параметрах зі своїм видом. ZIP щонайбільше з одним файлом CSS і щонайбільше однією темою програми не потребує маніфесту. Для чогось більшого потрібен pilcrow-theme.json, що перелічує кожну тему в variants[].file. Вид файлу визначає його розширення:

{
  "id": "com.example.paper",
  "name": "Paper",
  "version": "1.0.0",
  "author": "Example Author",
  "license": "MIT",
  "cssAPIVersion": 1,
  "variants": [
    { "id": "app", "name": "Paper", "file": "Paper.json", "appearance": "automatic" },
    { "id": "light", "name": "Paper Light", "file": "Paper-Light.css", "appearance": "light" },
    { "id": "dark", "name": "Paper Dark", "file": "Paper-Dark.css", "appearance": "dark" }
  ]
}

Маніфест описує пакет і його теми. Він ніколи не містить значень стилів: вони містяться у файлах CSS і тем програми.

  • id пакета називає теку встановлення. Він не повинен починатися з . або мати пробіли на початку чи в кінці. Встановлення пакета, id якого вже встановлено, замінює його.
  • ZIP, створений Стиснути у Finder, працює без змін. Pilcrow пропускає __MACOSX/, ._*, .DS_Store і Thumbs.db, а коли всі файли лежать в одній теці верхнього рівня, ця тека вважається коренем пакета.
  • Видалення однієї теми прибирає її з пакета й зберігає решту разом зі спільними ресурсами. Видалення останньої теми прибирає пакет. Видалена вибрана тема повертає вибір до типового для її виду: Автоматично для теми програми, Світла для теми відображення.
  • CSS може посилатися на пакетні файли PNG, JPEG, GIF, WebP, TTF, OTF, WOFF і WOFF2 відносними шляхами url(...). Pilcrow перевіряє їхні сигнатури та вбудовує згадані ресурси як URL даних, щоб відображення й експортований HTML лишалися автономними та працювали офлайн. Шляхи ZIP не можуть виходити за межі пакета, збігатися за регістром чи вказувати на посилання. Розмір архіву, кількість елементів, розмір окремого елемента й коефіцієнт стиснення обмежені.

Word#

Експорт у Word використовує світлі (базові) значення :root і відображає ці семантичні властивості на іменовані стилі Word: --pt-foreground, --pt-background, --pt-accent, --pt-link-color, --pt-code-background, --pt-code-foreground, --pt-body-font-family, --pt-mono-font-family, --pt-base-font-size і --pt-line-height. Селектори браузера й правила розмітки не мають загального відповідника у Word. Перегляд, HTML, PDF і зображення використовують повну таблицю стилів; Word використовує цю підмножину, зберігаючи структуру документа, діаграми, картинки формул, посилання й медіа. Панель експорту показує це обмеження щоразу, коли вибрано Word.

Pilcrow містить дві теми відображення, Світла і Темна, які є повноцінними відправними точками.
