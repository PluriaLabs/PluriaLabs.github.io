Chapter 67

General

Language & Windows#

ControlWhat it does
LanguageChooses Pilcrow's language, independent of the device's. System default follows the device. A language that was translated with AI shows "Machine-translated — may contain errors." The change takes effect the next time you open Pilcrow, with a Quit Now button on Mac.
Show the translation notice when Pilcrow startsTurns the "Translated with AI" notice back on after you chose Don't show this again.
Quit Pilcrow when last window is closed (Mac)Quits the app when you close the last window, instead of leaving it running.

Files#

ControlWhat it does
When startingWhat Pilcrow opens at launch: Open new file, Restore last closed folders, Restore last closed files and folders, or Open custom folder (with a Choose… button). Restoring reopens what was on screen when the app last quit. A file that has since moved or been deleted is skipped.
Save new documents asThe file type, and so the syntax profile, for a new document: each profile with its extension, for example "CommonMark (.md)".
Automatically save changesSaves a document that has a file as you work.
Save without asking when closing a fileSkips the "do you want to save?" question and saves.
Versions to keepHow many saved versions of each file Pilcrow keeps for Version History, from none to 500. The default is 50. "Versions to keep: none" turns history off.
Record recent files and foldersLets Pilcrow remember what you opened, for Open Recent and for restoring at launch.
Show hidden folders and filesShows items whose names start with a dot in the Files panel.
When something is dropped onto the appWhat happens when you drop onto the editor or the sidebar: for a Folder or a Markdown file, Open in editor or Insert link; for an Importable file (a theme, syntax profile or macro collection), Open in editor, Insert link or Import file.

Translation#

Translation needs macOS 15 or iPadOS 18 or later.

ControlWhat it does
Translate intoYour default target language. The first choice is "System language".
SpeedFast, Best quality, or AI assistant. Fast suits long documents and can be about twenty times quicker, with plainer wording; it needs macOS or iPadOS 26.4. AI assistant sends the text to your connection from Settings ▸ Assistant; your service may charge for it and the text leaves the device.
When a file is in another languageDo nothing, Offer to translate, or Translate automatically. Pilcrow works out a file's language when you open it, and nothing leaves the device for that. The offer shows a bar with a choice to translate into your default language.
Offer Again for All FilesClears the files you set to Never for This File.
After translatingOpen in a new tab, Save a copy beside the original (named like the original with the language added, such as Notes_fr.md), or Replace the document (which can be undone).
Languages on This DeviceLists each language with On this device, Download or Not available. Translation uses language packs that stay on the device. Downloading one asks the system for permission; remove one in the system's language settings.

Assistant#

ControlWhat it does
Enable AI assistantAdds the Assistant panel to the sidebar. Nothing is sent until you ask, and only the text you choose to share.
A status lineReady., or the reason it is not: "The active connection's address is not usable.", "The active connection needs an API key.", or "Add a connection below. The Assistant pane appears once one is ready."
ConnectionsThe list of connections, with "No connections yet." when empty. Each shows its name and, for the one in use, Active. A row offers Make Active, Edit… and Remove.
Add ConnectionA menu: OpenAI, Anthropic, OpenRouter, Ollama (this computer), LM Studio (this computer), or Custom….
Excluded filesPatterns for files that are never shared. * stands for any characters in a name, ** for any folders, and a name ending in / covers a whole folder. Defaults include *.pem, .env*, *.key and secrets/. Add a pattern, Remove one, or Restore Defaults.
Folders turned offLists folders where you switched the assistant off, each with Turn On. Shows "No folders are turned off." when none.
PrivacyA link to read Pilcrow's privacy policy, and Delete All AI Data…, which removes every connection and saved key, the conversation and your privacy choices, and turns the assistant off. It asks first.

Your API key is stored in the Keychain on this device only.

The connection form#

Add Connection and Edit… open a form.

FieldWhat it does
NameA label for the connection.
FormatOpenAI-compatible or Anthropic.
AddressThe service's web address. Use https://, or http:// only for this computer or your local network.
Allow an unencrypted connection on my local networkPermits an http:// address on your network. It sends your text and key in the clear, so allow it only if you trust the network.
ModelThe model to use, with Choose… to pick from the service's list.
Needs an API key and API keyWhether the service needs a key, and the key itself, held in the Keychain. Leave it blank when editing to keep the saved key.
Test ConnectionChecks the address, key and model. Shows "Testing…" then "Connected (N ms)."
Cancel, SaveClose or keep the connection.

Diagnostics#

ControlWhat it does
Record diagnostic logRecords what Pilcrow is doing, so you can send it to support when something goes wrong. It stays on the device until you share it, and is built to leave out your document text and file names. While on, a red Recording log mark shows in the status bar.
Stop recording after1 hour, 24 hours, or Never.
What to recordA level for each part of Pilcrow: Text editor, Macros, Themes, Parsing and profiles, Rendering and diagrams, Export and print, Files and library, and App. Each is Problems only, Normal, Detailed or Everything. Problems and errors are always kept.
Reproduce an issueSets every part to Detailed and starts recording. Make the problem happen again, then finish the report.
Add the logWhen you report a bug: Ask each time, Always add, or Never add the newest entries of the log to your clipboard to paste into the form.
Report a Bug…Same as Help ▸ Report a Bug….
Include in a reportSwitches for Device and system information, Pilcrow settings, Document structure (counts only), Speed and memory, Trail of recent actions, and Crash details. Document structure is how many headings, tables and so on the document has, never its words. Nothing is sent from this screen.
View Log…Opens the log viewer (below).
Clear Log…Permanently deletes the recorded log from this device, after asking. Turning recording off keeps what was recorded until you clear it.

While you are recording a log for a bug report, Reproducing — Finish Report (or Finish Bug Report in the Help menu) stops recording and finishes the report. Recording stops by itself after 30 minutes in that case.

The log viewer#

Diagnostic Log shows a summary (Entries, Sessions, Errors, Warnings, Crash reports, and the date range), then the entries, newest first, with a Search the log field and Part and Level filters. Filters change only what you see, not what is sent. A report contains every entry in the log plus what you chose under Include in a report. Reload refreshes it. Send Report offers:

ItemWhat it does
Save Report…Keeps a file you can send yourself.
Share Report…Opens the share sheet (AirDrop, Files and so on).
Report on GitHub…Opens a new issue with a short summary. You choose Add Log to Description (the newest entries, up to 60,000 characters, which is all GitHub allows, copied to your clipboard to paste) or Save and Attach File (the whole log, in a file you add yourself). Reports on GitHub are public.

When you start a report with nothing recorded, Pilcrow asks Record the Problem First?: Record the Problem First, Report Now or Cancel. When it opens the form it asks whether to Add Log and Open Form, Always Add the Log, or Open Form Without Log.

Storage & Privacy#

Pilcrow keeps recovery copies, history, access grants and support data inside its sandbox. Each category can be deleted separately. These controls never delete your documents.

SectionControls
DocumentsReview recovery data and Review version history. Review lists the affected items with their sizes, so you can see the space before deleting anything. Tick the ones to delete (Select All or Select None) and choose Delete Selected. Recovery data cannot be reviewed while a document has unsaved changes: save or close it first.
File AccessClear Recent File Access… removes recent-file lists, remembered Save As folders, session bookmarks and per-file syntax choices.
Private & Support DataDelete AI Data & Keys… (connections, Keychain keys, the current conversation and AI privacy choices), Delete Diagnostics… (recorded logs and saved crash diagnostics), and Clear Caches… (re-creatable cached files and network responses).

Every deletion asks for confirmation ("This cannot be undone. Your documents will not be deleted."). Custom syntax profiles, themes, macros, style guides and backdrops are not removed here; review and delete them on their own Library pages.
