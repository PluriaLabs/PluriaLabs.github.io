Chapter 82

Messages, banners and empty states

This chapter explains the short messages Pilcrow shows, so none of them is a mystery.

In the editor and preview#

MessageWhat it means
Nothing to preview yet. Start writing and it will appear here. (or "Switch to Edit and start writing.")The document is empty, so there is nothing to draw in Preview.
Preview couldn't render: … with Show Source and RetryPreview failed. Show Source switches to Edit. Retry tries again.
A failed equation or diagram, with a Show Source linkOne block could not be drawn. Click Show Source to jump to that block's source and fix it.
Couldn't save with Retry and a dismiss buttonSaving failed. The document stays open and unsaved. Fix the cause (disk space, permissions, a file that moved) and choose Retry.
File Changed on DiskAnother app modified the file. Reload reads the new version; Keep Current Version keeps what you have.
Parsing warningA line where a construct is probably not what you meant (Chapter 68).
Replace Existing File?The name you chose is already in use at that place.
Fill-in fields remainYou are printing or exporting with unfilled fields (Chapter 63).
Pane divider (VoiceOver hint: "Drag to resize the editor and the preview. Double-tap to reset.")The handle between source and preview in Side by Side.
Words: NThe word count in the status bar.

In dialogs and panels#

WhereMessageMeaning
Command paletteType a commandThe field's hint. "No matching commands" appears when nothing fits.
Open QuicklyType a filenameThe field's hint.
Carets in a ColumnLines (for example 3-17), Column (for example 100, or 100-105 to select)Field hints. A single column places carets; a range selects those characters on each line.
Search panelType to search this folder., No matches in this folder., Search cancelled.The state of a folder search.
Files panelYou can also drop a folder here.Drag a folder onto the panel to open it.
Replace in FolderNothing to replace.The search has no matches.
CompareTooltips on the buttons: Accept ("Make this change in the open document"), Reject ("Leave this change out of the open document"), Take Back ("Put the older lines back in the document for this change only").What each does.
TranslateThe translation could not be completed.Try again, or choose another speed.
TranslateEstimated time: less than a minuteAn estimate for the AI assistant speed; the time depends on your AI service. After a translation, Open in New Tab opens the result.
AssistantNo document is open., No document text is sent.The panel has nothing to share, so nothing is sent.
Model chooserLoading models…, No models match.The list is loading, or your search found nothing.
Style reviewNo findings. and The reply could not be read as findings. Try again.The review found nothing, or the AI's reply was not in the expected form.
Style reviewApply All tooltip: "Makes every fix that has one, as a single change you can undo."One Undo reverses them all.
Project panelYour name, Add VariableThe Author field's hint, and the button for a project variable.
Assistant permissionRead Pilcrow's privacy policyOpens the privacy policy.

In Settings#

WhereMessageMeaning
KeyboardPress the new shortcut, then click Save. and Press any key…While recording a shortcut.
Library ▸ LocationLibrary location, Moving your library…The page title, and the progress while a library moves.
Assistant connectionLeave blank to keep the saved key.When editing, a blank key field keeps the key already in the Keychain.
Macro editorTrigger — e.g. /sigThe trigger field's hint.
Profile editorAdvanced profile JSON, Sample and resultsThe JSON editor's title, and the area under Test Sample that shows the nodes a sample produces.
DiagnosticsAll parts (in the log viewer), No entries match.The unfiltered log, and a filter that matches nothing.

Title controlOpen documents and document actionsThe tooltip on the document title.
