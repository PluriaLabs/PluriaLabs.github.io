Chapter 68

Editing

Display & Typing#

Display#

ControlWhat it does
Show line numbersLine numbers in the gutter. Same as View ▸ Line Numbers.
Show current-line ruleA thin rule under the line the caret is on.
Styled SourceDraws headings, bold and italic in a matching face.
Heading FoldsFold chevrons beside headings.
Rendered BlocksDraws tables, equations and diagrams as pictures with an edit button.
Auto-Expand SectionsOpens a folded section or a picture block when the caret arrives in it, and closes it when the caret leaves.
Hide MarkersHides heading, bold and italic marks on every line except the caret's. Needs Styled Source.
Wrap long linesWhen off, long lines scroll sideways instead of wrapping. Preview and exports always wrap. Lines of 20,000 characters or more, and Focus Mode, always wrap.
Short lines in column modeWhat a column does on a line too short to reach it: Use the end of the line, Leave the line out, Soft pad with spaces (adds spaces so typed text lines up on screen), Hard pad with spaces (one space for every missing character, so it lines up by column number), or Stop at the line. Deleting never removes characters from a short line.
Show status barTurns the status bar at the bottom on or off.
Formatting ToolbarShows the optional toolbar under the text.

Typing#

ControlWhat it does
Auto-pair brackets and quotesTyping an opening bracket or quote adds the closing one.
Auto-pair Markdown ( \* \_ ` ~ ) | Does the same for Markdown's marks.
Expand emoji shortcodes (:smile:)Turns a shortcode into the emoji as you type. A file that already contains one is shown as written.
Continue lists and quotes on ReturnReturn starts the next item, Return on an empty item ends the list, and Tab indents an item.
Keep indentation on ReturnA new line starts with the same leading spaces or tabs as the one above.
Insert spaces when pressing TabTab inserts as many spaces as the tab width, up to the next tab stop, instead of a tab character.

Smart punctuation, highlight, subscript and superscript are under Library ▸ CommonMark Options.

Typing sounds#

ControlWhat it does
Play a sound as I typeEach key makes a sound; Space, Return and Delete sound different. Pasting and undoing stay silent. On iPad the silent switch mutes it.
SoundThe pack: Typewriter, Duck, or Kitten.
Volume, PreviewSet the level and hear the pack.
Your own soundsChoose a short clip for any kind of key; the others keep the sound picked above. The kinds are Lowercase letters, Uppercase letters, Numbers, Symbols and punctuation, Space, Tab, Return and Delete. Each has Choose… (or Change…), Play and Remove. Clips can be up to 2 seconds and 3 MB (WAV, AIFF, MP3, M4A or CAF), and are stored in memory so they play with no delay.

Spelling and diagnostics#

Check spelling while typing underlines misspellings. Show parsing warnings marks lines where a construct is probably not what you meant, such as an unclosed code fence or math block, a link with no closing parenthesis, or a table row that does not match its header. The note appears at the end of the line. It changes what is shown, never how a document is parsed or exported.

Images#

These settings decide what happens to an image you insert (Insert ▸ Image…, or by dropping one in).

ControlWhat it does
ActionNo special action, Copy image to current folder (./), Copy image to ./assets, or Copy image to ./\${filename}.assets. Upload image is shown as unavailable: Pilcrow has no image host, so images are inserted where they already are.
Apply to local imagesWhether the action applies to images already on your device.
Apply to online imagesWhether it applies to images that point to a web address.
Load images from the internetOff, pictures that point to a web address are not downloaded for Preview, PDF or image export, so the site hosting them learns nothing. On, they are fetched like in a web browser, and that site can see the request.
Use relative path if possibleWrites a path relative to the document.
Add ./ for relative pathsStarts relative paths with ./.
Auto-escape image URLs on insertEscapes characters in the address that would break the link.
