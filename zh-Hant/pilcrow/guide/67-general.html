一般

語言與視窗#

控制項功能
語言選擇 Pilcrow 的語言，與裝置的語言無關。系統預設會跟隨裝置。以 AI 翻譯的語言會顯示「機器翻譯——可能含有錯誤。」。變更會在下次開啟 Pilcrow 時生效，Mac 上有立即結束按鈕。
Pilcrow 啟動時顯示翻譯通知在你選擇不再顯示此訊息之後，重新開啟「已由 AI 翻譯」通知。
關閉最後一個視窗時結束 Pilcrow（Mac）在你關閉最後一個視窗時結束 App，而不是讓它繼續執行。

檔案#

控制項功能
啟動時Pilcrow 在啟動時開啟的內容：開啟新檔案、還原上次關閉的資料夾、還原上次關閉的檔案與資料夾，或開啟自訂資料夾（附有選擇…按鈕）。還原會重新開啟 App 上次結束時畫面上的內容。之後已移動或已刪除的檔案會被略過。
將新文件儲存為新文件的檔案類型，也就是語法設定檔：每個設定檔連同其副檔名，例如「CommonMark (.md)」。
自動儲存變更在你工作時儲存已有檔案的文件。
關閉檔案時不詢問直接儲存略過「要儲存嗎？」的詢問並直接儲存。
保留的版本數Pilcrow 為「版本記錄」保留每個檔案多少個已儲存版本，從無到 500 個。預設為 50 個。「保留的版本數：無」會關閉記錄。
記錄最近使用的檔案與資料夾讓 Pilcrow 記住你開啟過的內容，供開啟最近項目以及啟動時還原使用。
顯示隱藏的資料夾與檔案在「檔案」面板中顯示名稱以點開頭的項目。
當有項目拖放到 App 上時當你把項目拖放到編輯器或側邊欄時會發生什麼事：對於資料夾或 Markdown 檔案，可選在編輯器中開啟或插入連結；對於可匯入的檔案（佈景主題、語法設定檔或巨集集合），可選在編輯器中開啟、插入連結或匯入檔案。

翻譯#

翻譯需要 macOS 15 或 iPadOS 18 以上版本。

控制項功能
翻譯成你的預設目標語言。第一個選項是「系統語言」。
速度快速、最佳品質或 AI 助理。快速適合長文件，速度可快上約二十倍，但用字較為平實；它需要 macOS 或 iPadOS 26.4。AI 助理會把文字傳送到你在 設定 ▸ 助理 中的連線；你的服務可能會收費，而且文字會離開裝置。
當檔案使用其他語言時不執行任何動作、提供翻譯或自動翻譯。Pilcrow 會在你開啟檔案時判斷其語言，過程中不會有任何內容離開裝置。提供翻譯時會顯示一個橫幅，可選擇翻譯成你的預設語言。
對所有檔案再次提供翻譯清除你設為此檔案永不的檔案。
翻譯之後在新標籤頁中開啟、在原檔旁儲存副本（檔名與原檔相同並加上語言，例如 Notes_fr.md），或取代文件（可以復原）。
此裝置上的語言列出每種語言，並標示在此裝置上、下載或無法使用。翻譯使用留在裝置上的語言套件。下載語言套件時會向系統請求權限；要移除，請在系統的語言設定中進行。

助理#

控制項功能
啟用 AI 助理將助理面板加入側邊欄。在你提問之前不會傳送任何內容，而且只會傳送你選擇分享的文字。
狀態行就緒。，或無法就緒的原因：「使用中連線的位址無法使用。」、「使用中的連線需要 API 金鑰。」，或「請在下方加入連線。連線就緒後會出現助理窗格。」
連線連線清單，空白時顯示「尚無連線。」。每一項會顯示其名稱，正在使用的那一項會標示使用中。每列提供設為使用中、編輯…與移除。
加入連線一個選單：OpenAI、Anthropic、OpenRouter、Ollama（此電腦）、LM Studio（此電腦），或自訂…。
排除的檔案永不分享的檔案模式。* 代表名稱中的任意字元，** 代表任意資料夾，以 / 結尾的名稱則涵蓋整個資料夾。預設包含 *.pem、.env*、*.key 與 secrets/。可加入模式、移除模式，或還原預設值。
已關閉的資料夾列出你關閉助理的資料夾，每個都有開啟。沒有任何資料夾時顯示「沒有已關閉的資料夾。」。
隱私權一個閱讀 Pilcrow 隱私權政策的連結，以及刪除所有 AI 資料…，它會移除所有連線與已儲存的金鑰、對話與你的隱私選擇，並關閉助理。執行前會先詢問。

你的 API 金鑰只儲存在此裝置的鑰匙圈中。

連線表單#

加入連線與編輯…會開啟一份表單。

欄位功能
名稱連線的標籤。
格式OpenAI 相容或 Anthropic。
位址服務的網頁位址。請使用 https://，只有此電腦或你的區域網路才使用 http://。
允許在我的區域網路上使用未加密連線允許你網路上的 http:// 位址。它會以明文傳送你的文字與金鑰，因此只有在你信任該網路時才允許。
模型要使用的模型，可用選擇…從服務的清單中挑選。
需要 API 金鑰與 API 金鑰服務是否需要金鑰，以及金鑰本身，存放在鑰匙圈中。編輯時留空即可保留已儲存的金鑰。
測試連線檢查位址、金鑰與模型。會顯示「測試中…」，然後是「已連線（N 毫秒）。」
取消、儲存關閉或保留此連線。

診斷#

控制項功能
記錄診斷記錄記錄 Pilcrow 正在做的事，以便出問題時傳送給支援團隊。在你分享之前，它會留在裝置上，而且設計上不會包含你的文件文字與檔案名稱。開啟時，狀態列會顯示紅色的正在記錄標記。
在以下時間後停止記錄1 小時、24 小時或永不。
要記錄的內容Pilcrow 每個部分的層級：文字編輯器、巨集、佈景主題、解析與設定檔、渲染與圖解、匯出與列印、檔案與資料庫，以及 App。每個都可選僅問題、一般、詳細或全部。問題與錯誤一律會保留。
重現問題將每個部分都設為詳細並開始記錄。讓問題再次發生，然後完成回報。
加入記錄回報錯誤時：每次詢問、一律加入或永不加入記錄中最新的項目，拷貝到你的剪貼簿以貼到表單中。
回報錯誤…與 說明 ▸ 回報錯誤… 相同。
報告包含內容以下項目的開關：裝置與系統資訊、Pilcrow 設定、文件結構（僅計數）、速度與記憶體、最近操作軌跡與當機詳細資料。文件結構是指文件有多少標題、表格等等，絕不包含其文字。此畫面不會傳送任何內容。
檢視記錄…開啟記錄檢視器（見下文）。
清除記錄…在詢問之後，從此裝置永久刪除已記錄的記錄。關閉記錄功能會保留已記錄的內容，直到你清除為止。

在為錯誤回報記錄日誌的期間，重現中 — 完成回報（或「說明」選單中的完成錯誤回報）會停止記錄並完成回報。在此情況下，記錄會在 30 分鐘後自動停止。

記錄檢視器#

診斷記錄會顯示摘要（項目、工作階段、錯誤、警告、當機報告，以及日期範圍），接著是依新到舊排列的項目，並有搜尋記錄欄位以及部分與層級篩選器。篩選器只會改變你所看到的內容，不會改變所傳送的內容。報告包含記錄中的每一個項目，加上你在「報告包含內容」下所選擇的項目。重新載入會重新整理。傳送報告提供：

項目功能
儲存報告…保留一個可自行傳送的檔案。
分享報告…開啟分享面板（AirDrop、檔案等等）。
在 GitHub 上回報…開啟附有簡短摘要的新議題。你可選擇將記錄加入描述（最新的項目，最多 60,000 個字元，這是 GitHub 所允許的上限，會拷貝到你的剪貼簿供貼上），或儲存並附加檔案（整份記錄，放在你自行加入的檔案中）。在 GitHub 上的回報是公開的。

當你在沒有任何記錄的情況下開始回報時，Pilcrow 會詢問要先記錄問題嗎？：先記錄問題、立即回報或取消。開啟表單時，它會詢問要加入記錄並開啟表單、一律加入記錄，還是不含記錄開啟表單。

儲存空間與隱私#

Pilcrow 會把復原副本、記錄、存取授權與支援資料保存在其沙盒內。每個類別都可以單獨刪除。這些控制項絕不會刪除你的文件。

區段控制項
文件審閱復原資料與審閱版本記錄。審閱會列出受影響的項目及其大小，讓你在刪除前先看到空間用量。勾選要刪除的項目（全選或全不選），然後選擇刪除所選。文件有未儲存的變更時，無法審閱復原資料：請先儲存或關閉它。
檔案存取權限清除最近檔案的存取權限…會移除最近檔案清單、記住的「另存新檔」資料夾、工作階段書籤，以及各檔案的語法選擇。
私人資料與支援資料刪除 AI 資料與金鑰…（連線、鑰匙圈金鑰、目前的對話與 AI 隱私選擇）、刪除診斷資訊…（已記錄的記錄與已儲存的當機診斷資訊），以及清除快取…（可重新建立的快取檔案與網路回應）。

每次刪除都會要求確認（「此操作無法復原。你的文件不會被刪除。」）。自訂的語法設定檔、佈景主題、巨集、風格指南與背景圖不會在此移除；請在它們各自的「資料庫」頁面中審閱並刪除。
