第 80 章

渲染佈景主題 CSS 參考

渲染佈景主題就是 CSS。它用來設定預覽、HTML、PDF、圖片和列印輸出的樣式，以及本章最後列出的 Word 樣式。渲染佈景主題可以是單一 .css 檔案，也可以是附有本機資產的 ZIP 套件的一部分。語法設定檔定義原始文字如何變成文件；渲染佈景主題只為結果設定樣式。CSS 絕不會設定 App 或編輯器的樣式，那是應用程式佈景主題的工作（Chapter 79）。

層疊#

Pilcrow 依下列順序套用樣式：

  1. Pilcrow 的結構重置；
  2. 所選佈景主題的 CSS；
  3. 匯出面板中的一次性 CSS（進階選項 ▸ 自訂 CSS）；
  4. 必要的列印與渲染修正。

依照一般 CSS 層疊規則，後面的規則優先。不支援佈景主題 JavaScript、遠端資源、file: URL 和 @import。

資源#

Pilcrow 以標準的 CSS 詞法分析器讀取佈景主題 CSS，因此跳脫字元會在任何檢查之前先被解碼：u\72 l(…) 就是 url()，@im\70 ort 就是 @import。瀏覽器會從中載入內容的每個位置都會被檢查：url(…)、url("…")、src("…")，以及 image-set() 內的字串。每一個都必須是下列其中之一：

  • 套件內的相對路徑（fonts/Body.woff2、./paper.png）。允許 ?query 或 #fragment，查找檔案時會被忽略；
  • PNG、JPEG、GIF、WebP、SVG（image/svg+xml）、TTF、OTF、WOFF 或 WOFF2 類型的 data: URL；
  • 片段參照，例如 url(#shadow)，它指向頁面中的某個元素。

任何使用 data: 以外的配置（https:、file:、blob:）或以 // 開頭的內容都會被拒絕，以 / 開頭或包含 .. 的路徑也一樣。

ZIP 套件#

ZIP 套件可以同時包含渲染佈景主題（.css）和應用程式佈景主題（.json）；每一個都會在設定中以各自的類型列出。最多只有一個 CSS 檔案和一個應用程式佈景主題的 ZIP 不需要資訊清單。超過的話就需要 pilcrow-theme.json，在 variants[].file 下列出每個佈景主題。檔案的副檔名決定它的類型：

{
  "id": "com.example.paper",
  "name": "Paper",
  "version": "1.0.0",
  "author": "Example Author",
  "license": "MIT",
  "cssAPIVersion": 1,
  "variants": [
    { "id": "app", "name": "Paper", "file": "Paper.json", "appearance": "automatic" },
    { "id": "light", "name": "Paper Light", "file": "Paper-Light.css", "appearance": "light" },
    { "id": "dark", "name": "Paper Dark", "file": "Paper-Dark.css", "appearance": "dark" }
  ]
}

資訊清單描述套件及其中的佈景主題。它絕不包含樣式值：那些都在 CSS 和應用程式佈景主題檔案中。

  • 套件的 id 為安裝資料夾命名。它不能以 . 開頭，也不能有前導或尾隨空格。安裝 id 已經安裝過的套件會取代原有的套件。
  • 以 Finder 的壓縮製作的 ZIP 可直接使用。Pilcrow 會略過 __MACOSX/、._*、.DS_Store 和 Thumbs.db，而當所有檔案都位於同一個頂層資料夾內時，該資料夾會被視為套件根目錄。
  • 刪除單一佈景主題會將它從套件中移除，並保留其他佈景主題與共用資產。刪除最後一個佈景主題則會移除整個套件。若被刪除的佈景主題正被選用，該選擇會回到其類型的預設值：應用程式佈景主題為自動，渲染佈景主題為淺色。
  • CSS 可以用相對的 url(...) 路徑參照套件內的 PNG、JPEG、GIF、WebP、TTF、OTF、WOFF 和 WOFF2 檔案。Pilcrow 會驗證它們的簽章，並將被參照的資產內嵌為 data URL，讓渲染與匯出的 HTML 保持離線且自成一體。ZIP 路徑不能跳出套件、不能因大小寫而衝突，也不能指向連結。封存檔大小、項目數量、單一檔案大小和壓縮比都有上限。

Word#

Word 匯出使用淺色（基底）的 :root 值，並將這些語意屬性對應到具名的 Word 樣式：--pt-foreground、--pt-background、--pt-accent、--pt-link-color、--pt-code-background、--pt-code-foreground、--pt-body-font-family、--pt-mono-font-family、--pt-base-font-size 和 --pt-line-height。瀏覽器選擇器與版面規則在 Word 中沒有通用的對應項目。預覽、HTML、PDF 和圖片輸出使用完整的樣式表；Word 則使用這個子集，同時保留文件結構、圖解、數學式圖片、連結和媒體。選取 Word 時，匯出面板一律會顯示這項限制。

Pilcrow 內含兩個渲染佈景主題：淺色和深色，它們都是完整的起點。
