第 74 章

設定檔編輯器與設定檔構成要素

語法設定檔會告訴 Pilcrow 你的標記代表什麼意思。本章逐一說明設定檔編輯器的各個控制項，然後列出設定檔可以使用的所有構成要素。若想從工作任務的角度入門，請參閱第 37 章至第 39 章。

從 設定 ▸ 資料庫 ▸ 語法設定檔 開啟編輯器：新增 會建立新的設定檔，編輯 會修改自訂設定檔，複製 會複製內建設定檔，讓你修改副本。編輯器的標題是 編輯設定檔，附有 取消、儲存 與 設定檔說明（會開啟這些構成要素的 App 內參考資料）。在窄螢幕上，設定檔段落 切換器可在 概觀、規則 與 測試範例 之間選擇；在寬螢幕上，三者會同時顯示。

擴充 Markdown 會把你的規則加到 Markdown 的規則之上：Markdown 的標題、清單、強調等仍會被讀取，而你的區塊規則與行內規則會再加進去。若某條規則是 CommonMark 設定檔中某條規則的原封不動複本，它所描述的是 Markdown 本來就會做的事，因此交由 Markdown 處理。取代 Markdown 會讓你的規則成為完整的語法，因此 Markdown 的結構將不再被辨識。使用這個選項時，必須有一條規則產生 行尾，否則內容不會分成段落。編輯器會警告「請加入一條輸出節點為 "newline" 的規則，否則內容不會分成段落」，而且在這樣的規則出現之前，設定檔無法儲存。編輯器也會列出設定檔尚未定義的任何輸出類型。

規則#

規則分為三組。

區塊規則#

區塊規則用來辨識整行與區塊。加入規則 會新增一條。每條規則都有 模式、符合 類型、它 產生 的內容，以及 選項。按下規則的 刪除 按鈕即可移除。若沒有任何規則，編輯器會顯示「目前沒有規則。請加入一條來辨識區塊結構。」

行內規則#

行內規則用來辨識一行之中的文字。加入行內規則 會新增一條。行內規則提供四種符合類型（字面前置詞、完全照字面、正規表示式（有界） 與 分隔符號成對）；區塊規則則提供全部七種。

巢狀規則#

巢狀規則規定哪些輸出可以放在哪些輸出之內。每條規則都有 父節點 與 允許的子節點（以逗號分隔）。留空表示不設限：「沒有限制。任何節點類型都可以巢狀置於其他節點類型之內。」加入巢狀規則 會新增一條。

依周圍字元配對的行內標記#

像 Markdown 這樣的語言，以一串字元書寫粗體與斜體，這串字元是開啟還是結束，取決於旁邊的字元；行內程式碼與連結則以括號書寫，因此無法用單一模式涵蓋整個結構。開啟 依標記周圍的字元來讀取標記 即可描述它們。

設定作用
跳脫字元讓下一個字元變成純文字的字元。
行內程式碼字元一串這個字元會開啟一段範圍，由下一串相同長度的字元結束。
連續標記以連續字元配對的標記，以 加入連續標記 新增。每個都有 標記、單一標記繪製為 的內容與 兩個標記繪製為 的內容，以及 可在字詞內開啟或關閉（_ 為關閉）。
成對標記與相同長度的一串字元配對的標記，以 加入成對標記 新增：包含 標記、它 繪製 的內容，以及 僅在此設定開啟時，也就是必須開啟的語法設定，例如醒目標示（或 永遠）。
連結與網址圖片前置詞、單獨書寫的位址會被以下符號包住、開頭為純位址的協定、定義標籤的行具有，以及 註腳標籤開頭為（標籤開頭括號之後使其成為註腳的字元：當某行以 [^note]: 開頭時，[^note] 會被繪製為註腳參照）。

標記是在同一行之內配對。程式碼、跳脫字元，以及連結的位址，對於它們周圍的標記而言都是純文字。

套用樣式的原始碼#

開啟 套用樣式的原始碼 後，編輯器會以語法本身的外觀來繪製文件：較大的標題、粗體與斜體片段、引用線、清單縮排、待辦事項方塊、分隔線、連結與程式碼卡片；並且（開啟 隱藏標記 時）隱藏構成這些樣式的標記，只有插入點所在的那一行例外。編輯器並不認識任何特定語法：規則會透過附帶樣式項目來說明其符合內容是什麼，沒有樣式項目的規則只會被著色，不會重新套用樣式。

每條規則的 選項 都有一個 套用樣式的原始碼 群組：

欄位作用
角色符合內容是什麼，或 未套用樣式。對於一行之內的單一結構：heading、strong、emphasis、code、strike、highlight、underline、link、subscript、superscript。對於整行：rule（分隔線）、list（清單項目的標記，包括其縮排與後面的空格）、task（標記後接核取方塊）與 quote（被引用行的 > 標記）。對於整體辨識的區塊：codeBlock。對於開頭行與結尾行為各自獨立符合的區塊：quoteRegion。對於以圖片方式繪製的表格、方程式或圖解：renderedBlock。
內容群組從 1 起算的擷取群組，包含該結構所要表達的內容：*bold* 裡面的字，或 \section{Title} 中的標題。符合內容中除此之外的部分是該結構自己的標記，由 隱藏標記 隱藏。0 表示整個符合內容都是內容，不會隱藏任何部分，例如網址。若符合內容只有標記，例如標題的 == ，則請省略。
標題層級、層級群組標題的層級，從 1 到 6。若省略，則取規則輸出名稱結尾的數字（heading2），或包含一串 # 的擷取群組之長度。
標記群組用於清單或待辦事項，指擷取群組中包含標記、其縮排與後面空格的部分，適用於符合內容以其他東西開頭的情況，例如被引用項目的 > 。
將樣式套用到行尾從符合處到行尾套用樣式，用於只符合標題標記、而把標題文字留作後面文字的規則。
繪製為對於已呈現的區塊，它是什麼：表格、數學式或圖解，或 不是圖片。
位址群組對於連結，依序嘗試的擷取群組，包含點按或點擊時所開啟的位址；0 是整個符合內容。只有網頁、郵件與電話位址能被開啟。

群組編號從 1 起算模式中的括號；0 是整個符合內容。不取代 Markdown 的設定檔，也會對其規則未宣告的種類保留 Markdown 本身的解讀，例如它的引用線與成對的 **。

文件屬性與條件式段落#

文件屬性 規則以 name 定義一個值，而 屬性參考 規則（含有 name 與 original 兩個部分的行內規則）會以該值取代參考。對於沒有人定義過的屬性，其參考會維持原樣。條件式段落 會依其所指名的屬性是否已設定，保留或捨棄其行與行之間的區塊。屬性從定義處起往後生效。

產生 下一個區塊的設定 的規則，會辨識出為其後的區塊進行設定的整行文字，本身不顯示任何內容。它的部分與固定屬性會交給那個區塊：title、id、nodeType、language 與 hardbreaks 的意義見「部分」之下的說明，其他任何部分則保留在區塊上，由表格、清單或引用讀取。

測試設定檔#

在編輯器底部，測試範例 內有範例文字（一開始是一個標題與一行文字）。選擇 檢查範例，即可看到你的規則製作出的節點，並依巢狀關係縮排。若沒有任何符合內容，它會顯示「沒有辨識出任何區塊。」

基準#

設定檔的 基準 是它的還原點：即你建立、複製或匯入它時的樣子。重置為基準 會在你確認後，捨棄自那時起的所有變更。設為新基準 會儲存設定檔，並讓它目前的狀態成為還原點。

如果設定檔取代了 Markdown 卻沒有行尾規則、模式不安全而可能使編輯器停止回應，或是檔案無法寫入，儲存會被拒絕，並顯示訊息。

輸出#

規則所 產生 的內容：它在選單中的名稱，然後是設定檔檔案所儲存的名稱、區塊規則或行內規則是否能產生它，以及它讀取的部分。規則也可以指名這份清單中沒有的輸出，會保留為 自訂。

部分#

部分是符合內容中具名的片段，供輸出讀取。

部分意義
allOf當所有名稱都需要時，名稱之間的分隔符號，例如 +。
alt圖片的描述，供看不到圖片的讀者使用。
anyOf當任一名稱即可時，名稱之間的分隔符號，例如 ,。
attribution引用的說話者，顯示於引用之下。
citetitle引用所出自的作品，顯示於出處之後。
columns表格的欄清單，例如 1,2,1；其項目數即為欄數。
condition該段落所依據的屬性名稱。
conditionTypedefined 表示在屬性已設定時保留該段落，undefined 表示在未設定時保留。
content文字本身，在它不是整個符合內容時使用。
format圖解的引擎（mermaid 或 vega-lite）；對於表格，則是儲存格所用的分隔格式之一。
hardbreaks若存在，會保留下一個區塊的單一換行。
header任何非 false 的值都會讓表格的第一列成為標頭。
id一個名稱：對於下一個區塊，是交叉參照所指向的 id；對於註腳，則是讓之後沒有自己文字的註腳可以共用其編號的名稱。
keys要按下的按鍵，以逗號分隔。
label參考或錨點所顯示的文字，用來取代目標本身的標題。
language程式碼區塊的程式語言，用於著色。
level標題層級，從 1 到 6。
marker詞彙之後的分隔符號，例如 ::。不同的標記會在描述中巢狀排列一個清單。
name屬性的名稱，用於定義或參考中。
nodeType依檔案中的名稱，將下一個區塊變成另一種輸出。
noHeader若存在，表格沒有標頭列。
notation數學記號：tex（預設）或 latex。
opentrue 會讓可收合段落顯示為展開。
orderedtrue 會讓清單成為編號清單。
original照原樣書寫的參考，在屬性未定義時顯示。
presentation下一個描述清單的顯示方式：sideBySide 會把詞彙與描述放在兩欄；questions 會把每個詞彙編號成一個問題，答案在其下。
primary索引項目。
secondary索引項目之下的子項目。
sectionLabel下一個標題的編號所跟隨的字詞，例如 Appendix：這類標題會單獨計數，如 Appendix A:。
sectionLabelStart這些編號的第一個：字母（A）以字母計數，數字則以數字計數。
src視訊或音訊檔案的位址。
start編號清單起始的數字。
summary可收合段落在收合時顯示的那一行。
targetID參考所指向的 id。
term所描述的詞彙。
tertiary次要項目之下的子項目。
text顯示的文字，在模式擷取的內容多於此時使用。註腳的文字跟隨它所在的段落、表格或清單，並有編號。
title標題：框的標題、圖片或連結的提示文字，或下一個區塊上方的標題說明。
type提示的種類，例如 note、tip 或 warning。
unset若存在，規則會移除屬性而不是定義它。
url連結或圖片所指向的位址。
value屬性的值；其中對較早定義之屬性的參考會被取代。
