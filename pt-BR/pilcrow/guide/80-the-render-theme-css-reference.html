Capítulo 80

A referência de CSS do Tema de renderização

Um Tema de renderização é CSS. Ele define o estilo da pré-visualização e das saídas em HTML, PDF, imagem e impressão, além dos estilos do Word listados no fim deste capítulo. Um Tema de renderização pode ser um único arquivo .css ou parte de um pacote ZIP com recursos locais. Os perfis de sintaxe definem como o texto-fonte se torna o documento; os Temas de renderização apenas estilizam o resultado. O CSS nunca estiliza o app nem o editor; isso cabe ao Tema do app (Capítulo 79).

A cascata#

O Pilcrow aplica os estilos nesta ordem:

  1. a redefinição estrutural do Pilcrow;
  2. o CSS do tema selecionado;
  3. o CSS pontual do painel de exportação (Opções avançadas ▸ CSS personalizado);
  4. as correções necessárias de impressão e renderização.

As regras posteriores prevalecem de acordo com a cascata normal do CSS. JavaScript em temas, recursos remotos, URLs file: e @import não são suportados.

Recursos#

O Pilcrow lê o CSS do tema com um tokenizador de CSS padrão, de modo que os escapes são decodificados antes de qualquer verificação: u\72 l(…) é um url() e @im\70 ort é um @import. Todo lugar de onde um navegador carregaria algo é verificado: url(…), url("…"), src("…") e strings dentro de image-set(). Cada um deve ser:

  • um caminho relativo ao pacote (fonts/Body.woff2, ./paper.png). Um ?query ou #fragment é permitido e ignorado quando o arquivo é procurado;
  • uma URL data: do tipo PNG, JPEG, GIF, WebP, SVG (image/svg+xml), TTF, OTF, WOFF ou WOFF2;
  • uma referência de fragmento como url(#shadow), que nomeia um elemento da página.

Qualquer coisa com um esquema diferente de data: (https:, file:, blob:) ou que comece com // é recusada, assim como um caminho que comece com / ou contenha ...

Pacotes ZIP#

Um pacote ZIP pode conter Temas de renderização (.css) e Temas do app (.json) juntos; cada um é listado com o seu próprio tipo nos Ajustes. Um ZIP com no máximo um arquivo CSS e no máximo um Tema do app não precisa de manifesto. Qualquer coisa além disso precisa de pilcrow-theme.json, que lista todos os temas em variants[].file. A extensão do arquivo decide o seu tipo:

{
  "id": "com.example.paper",
  "name": "Paper",
  "version": "1.0.0",
  "author": "Example Author",
  "license": "MIT",
  "cssAPIVersion": 1,
  "variants": [
    { "id": "app", "name": "Paper", "file": "Paper.json", "appearance": "automatic" },
    { "id": "light", "name": "Paper Light", "file": "Paper-Light.css", "appearance": "light" },
    { "id": "dark", "name": "Paper Dark", "file": "Paper-Dark.css", "appearance": "dark" }
  ]
}

O manifesto descreve o pacote e os seus temas. Ele nunca contém valores de estilo: esses ficam nos arquivos CSS e de Tema do app.

  • O id do pacote dá nome à pasta de instalação. Ele não pode começar com . nem ter espaços no início ou no fim. Instalar um pacote cujo id já está instalado o substitui.
  • Um ZIP criado com Comprimir do Finder funciona como está. O Pilcrow ignora __MACOSX/, ._*, .DS_Store e Thumbs.db, e, quando todos os arquivos estão dentro de uma única pasta de nível superior, essa pasta é tratada como a raiz do pacote.
  • Excluir um tema o remove do pacote e mantém os outros, junto com os recursos compartilhados. Excluir o último tema remove o pacote. Se um tema excluído estava selecionado, a seleção volta ao padrão do seu tipo: Automático para o Tema do app, Claro para o Tema de renderização.
  • O CSS pode referenciar arquivos PNG, JPEG, GIF, WebP, TTF, OTF, WOFF e WOFF2 empacotados com caminhos relativos em url(...). O Pilcrow verifica as assinaturas deles e incorpora os recursos referenciados como URLs de dados, para que a renderização e o HTML exportado continuem offline e autossuficientes. Os caminhos do ZIP não podem escapar do pacote, colidir por diferença de maiúsculas e minúsculas nem apontar para links. O tamanho do arquivo, o número de entradas, o tamanho individual e a taxa de compressão são limitados.

Word#

A exportação para Word usa os valores claros (base) de :root e mapeia estas propriedades semânticas para estilos nomeados do Word: --pt-foreground, --pt-background, --pt-accent, --pt-link-color, --pt-code-background, --pt-code-foreground, --pt-body-font-family, --pt-mono-font-family, --pt-base-font-size e --pt-line-height. Seletores de navegador e regras de layout não têm equivalente geral no Word. A pré-visualização e as saídas em HTML, PDF e imagem usam a folha de estilo completa; o Word usa este subconjunto, preservando a estrutura do documento, os diagramas, as imagens de fórmulas, os links e a mídia. O painel de exportação mostra esta limitação sempre que o Word é selecionado.

O Pilcrow inclui dois Temas de renderização, Claro e Escuro, que são pontos de partida completos.
