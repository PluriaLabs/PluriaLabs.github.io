Capítulo 80

Referencia de CSS de los temas de renderizado

Un tema de renderizado es CSS. Da estilo a la salida de Vista previa, HTML, PDF, imagen e impresión, y a los estilos de Word enumerados al final de este capítulo. Un tema de renderizado puede ser un único archivo .css o parte de un paquete ZIP con recursos locales. Los perfiles de sintaxis definen cómo el texto fuente se convierte en el documento; los temas de renderizado solo dan estilo al resultado. El CSS nunca da estilo a la aplicación ni al editor; eso corresponde al tema de la aplicación (capítulo 79).

La cascada#

Pilcrow aplica los estilos en este orden:

  1. el restablecimiento estructural de Pilcrow;
  2. el CSS del tema seleccionado;
  3. el CSS puntual del panel de exportación (Opciones avanzadas ▸ CSS personalizado);
  4. las correcciones necesarias de impresión y renderizado.

Las reglas posteriores prevalecen según la cascada normal de CSS. No se admiten JavaScript en los temas, recursos remotos, URL file: ni @import.

Recursos#

Pilcrow lee el CSS del tema con un analizador léxico de CSS estándar, de modo que los escapes se decodifican antes de comprobar nada: u\72 l(…) es un url() y @im\70 ort es un @import. Se comprueba cada lugar desde el que un navegador cargaría algo: url(…), url("…"), src("…") y las cadenas dentro de image-set(). Cada uno debe ser de uno de estos tipos:

  • una ruta relativa al paquete (fonts/Body.woff2, ./paper.png). Se permite un ?query o #fragment, que se ignora al buscar el archivo;
  • una URL data: de tipo PNG, JPEG, GIF, WebP, SVG (image/svg+xml), TTF, OTF, WOFF o WOFF2;
  • una referencia de fragmento como url(#shadow), que nombra un elemento de la página.

Se rechaza cualquier cosa con un esquema distinto de data: (https:, file:, blob:) o que empiece por //, así como una ruta que empiece por / o contenga ...

Pilcrow puede añadir clases y atributos en una actualización. Evita los selectores que dependen de una profundidad de envoltorios no documentada, de ID generados o de la ausencia de clases adicionales.

Paquetes ZIP#

Un paquete ZIP puede contener juntos temas de renderizado (.css) y temas de la aplicación (.json); cada uno aparece en Configuración con su propio tipo. Un ZIP con como máximo un archivo CSS y como máximo un tema de la aplicación no necesita manifiesto. Cualquier otro caso necesita pilcrow-theme.json, que enumera todos los temas en variants[].file. La extensión del archivo decide su tipo:

{
  "id": "com.example.paper",
  "name": "Paper",
  "version": "1.0.0",
  "author": "Example Author",
  "license": "MIT",
  "cssAPIVersion": 1,
  "variants": [
    { "id": "app", "name": "Paper", "file": "Paper.json", "appearance": "automatic" },
    { "id": "light", "name": "Paper Light", "file": "Paper-Light.css", "appearance": "light" },
    { "id": "dark", "name": "Paper Dark", "file": "Paper-Dark.css", "appearance": "dark" }
  ]
}

El manifiesto describe el paquete y sus temas. Nunca contiene valores de estilo: esos están en los archivos CSS y de temas de la aplicación.

  • El id del paquete da nombre a la carpeta de instalación. No debe empezar por . ni tener espacios al principio o al final. Instalar un paquete cuyo id ya está instalado lo reemplaza.
  • Un ZIP creado con Comprimir del Finder funciona tal cual. Pilcrow omite __MACOSX/, ._*, .DS_Store y Thumbs.db, y cuando todos los archivos están dentro de una única carpeta de nivel superior, esa carpeta se trata como la raíz del paquete.
  • Eliminar un tema lo quita del paquete y conserva los demás junto con los recursos compartidos. Eliminar el último tema elimina el paquete. Si se elimina un tema que estaba seleccionado, esa selección vuelve al valor predeterminado de su tipo: Automático para el tema de la aplicación, Claro para el tema de renderizado.
  • El CSS puede hacer referencia a archivos PNG, JPEG, GIF, WebP, TTF, OTF, WOFF y WOFF2 empaquetados con rutas relativas en url(...). Pilcrow verifica sus firmas e incrusta los recursos referenciados como URL de datos para que el renderizado y el HTML exportado sigan siendo sin conexión y autónomos. Las rutas del ZIP no pueden salirse del paquete, chocar por mayúsculas y minúsculas ni apuntar a enlaces. El tamaño del archivo, el número de entradas, el tamaño individual y la relación de compresión están acotados.

Word#

La exportación a Word usa los valores :root claros (base) y asigna estas propiedades semánticas a estilos de Word con nombre: --pt-foreground, --pt-background, --pt-accent, --pt-link-color, --pt-code-background, --pt-code-foreground, --pt-body-font-family, --pt-mono-font-family, --pt-base-font-size y --pt-line-height. Los selectores del navegador y las reglas de maquetación no tienen un equivalente general en Word. La salida de Vista previa, HTML, PDF e imagen usa la hoja de estilos completa; Word usa este subconjunto y conserva la estructura del documento, los diagramas, las imágenes de fórmulas, los enlaces y los medios. El panel de exportación muestra esta limitación siempre que se selecciona Word.

Pilcrow incluye dos temas de renderizado, Claro y Oscuro, que son puntos de partida completos.
