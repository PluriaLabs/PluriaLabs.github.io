การแสดงผลและการพิมพ์#

การแสดงผล#

ตัวควบคุมหน้าที่
แสดงหมายเลขบรรทัดหมายเลขบรรทัดในแถบข้าง เหมือน มุมมอง ▸ หมายเลขบรรทัด
แสดงกฎบรรทัดปัจจุบันเส้นบางใต้บรรทัดที่เคอร์เซอร์อยู่
ต้นฉบับที่มีสไตล์วาดหัวเรื่อง ตัวหนา และตัวเอียงด้วยรูปแบบตัวอักษรที่ตรงกัน
การพับหัวเรื่องลูกศรพับข้างหัวเรื่อง
บล็อกที่แสดงผลวาดตาราง สมการ และแผนภาพเป็นรูปภาพพร้อมปุ่มแก้ไข
ขยายส่วนอัตโนมัติเปิดส่วนที่พับไว้หรือบล็อกรูปภาพเมื่อเคอร์เซอร์เข้าไปในนั้น และปิดเมื่อเคอร์เซอร์ออกไป
ซ่อนเครื่องหมายซ่อนเครื่องหมายของหัวเรื่อง ตัวหนา และตัวเอียงในทุกบรรทัดยกเว้นบรรทัดของเคอร์เซอร์ ต้องเปิด ต้นฉบับที่มีสไตล์
ตัดบรรทัดยาวเมื่อปิด บรรทัดยาวจะเลื่อนไปด้านข้างแทนการตัดบรรทัด ตัวอย่างและการส่งออกจะตัดบรรทัดเสมอ บรรทัดที่ยาว 20,000 อักขระขึ้นไป และโหมดโฟกัส จะตัดบรรทัดเสมอ
บรรทัดสั้นในโหมดคอลัมน์สิ่งที่คอลัมน์ทำกับบรรทัดที่สั้นเกินกว่าจะถึงคอลัมน์: ใช้ท้ายบรรทัด, ไม่รวมบรรทัดนี้, เติมช่องว่างแบบยืดหยุ่น (เพิ่มช่องว่างเพื่อให้ข้อความที่พิมพ์เรียงตรงกันบนหน้าจอ), เติมช่องว่างแบบตายตัว (หนึ่งช่องว่างต่อทุกอักขระที่ขาด เพื่อให้เรียงตรงกันตามหมายเลขคอลัมน์) หรือ หยุดที่บรรทัด การลบจะไม่ลบอักขระออกจากบรรทัดสั้น
แสดงแถบสถานะเปิดหรือปิดแถบสถานะที่ด้านล่าง
แถบเครื่องมือจัดรูปแบบแสดงแถบเครื่องมือเสริมใต้ข้อความ

การพิมพ์#

ตัวควบคุมหน้าที่
จับคู่วงเล็บและเครื่องหมายคำพูดอัตโนมัติการพิมพ์วงเล็บเปิดหรือเครื่องหมายคำพูดเปิดจะเพิ่มตัวปิดให้
จับคู่ Markdown อัตโนมัติ ( \* \_ ` ~ ) | ทำเช่นเดียวกันกับเครื่องหมายของ Markdown
ขยายรหัสย่ออีโมจิ (:smile:)เปลี่ยนรหัสย่อเป็นอีโมจิขณะที่คุณพิมพ์ ไฟล์ที่มีรหัสย่ออยู่แล้วจะแสดงตามที่เขียนไว้
ต่อรายการและข้อความอ้างอิงเมื่อกด ReturnReturn เริ่มรายการถัดไป Return บนรายการว่างจะจบรายการ และ Tab จะเยื้องรายการ
คงการเยื้องเมื่อกด Returnบรรทัดใหม่เริ่มต้นด้วยช่องว่างหรือแท็บนำหน้าเหมือนบรรทัดข้างบน
แทรกช่องว่างเมื่อกด TabTab แทรกช่องว่างตามความกว้างแท็บ จนถึงจุดหยุดแท็บถัดไป แทนอักขระแท็บ

เครื่องหมายวรรคตอนอัจฉริยะ ไฮไลต์ ตัวห้อย และตัวยก อยู่ภายใต้ คลัง ▸ ตัวเลือก CommonMark

เสียงการพิมพ์#

ตัวควบคุมหน้าที่
เล่นเสียงขณะพิมพ์ทุกปุ่มมีเสียง Space, Return และ Delete เสียงต่างกัน การวางและการเลิกทำจะเงียบ บน iPad สวิตช์เงียบจะปิดเสียงนี้
เสียงชุดเสียง: เครื่องพิมพ์ดีด, เป็ด หรือ ลูกแมว
ระดับเสียง, ตัวอย่างตั้งระดับและฟังชุดเสียง
เสียงของคุณเองเลือกคลิปสั้นสำหรับปุ่มแต่ละประเภท ประเภทอื่นจะใช้เสียงที่เลือกไว้ด้านบน ประเภทได้แก่ ตัวพิมพ์เล็ก, ตัวพิมพ์ใหญ่, ตัวเลข, สัญลักษณ์และเครื่องหมายวรรคตอน, ช่องว่าง, แท็บ, Return และ ลบ แต่ละประเภทมี เลือก… (หรือ เปลี่ยน…), เล่น และ ลบออก คลิปยาวได้ถึง 2 วินาทีและขนาด 3 MB (WAV, AIFF, MP3, M4A หรือ CAF) และถูกเก็บไว้ในหน่วยความจำเพื่อให้เล่นได้โดยไม่มีหน่วงเวลา

การสะกดและการวินิจฉัย#

ตรวจการสะกดขณะพิมพ์ ขีดเส้นใต้คำที่สะกดผิด แสดงคำเตือนการแยกวิเคราะห์ ทำเครื่องหมายบรรทัดที่โครงสร้างบางอย่างน่าจะไม่ตรงกับที่คุณตั้งใจ เช่น รั้วโค้ดหรือบล็อกสูตรคณิตศาสตร์ที่ไม่ได้ปิด ลิงก์ที่ไม่มีวงเล็บปิด หรือแถวตารางที่ไม่ตรงกับส่วนหัว หมายเหตุจะปรากฏที่ท้ายบรรทัด การตั้งค่านี้เปลี่ยนสิ่งที่แสดง ไม่เคยเปลี่ยนวิธีที่เอกสารถูกแยกวิเคราะห์หรือส่งออก

รูปภาพ#

การตั้งค่าเหล่านี้กำหนดสิ่งที่เกิดขึ้นกับรูปภาพที่คุณแทรก (แทรก ▸ รูปภาพ… หรือโดยการวางลงไป)

ตัวควบคุมหน้าที่
การดำเนินการไม่มีการดำเนินการพิเศษ, คัดลอกรูปภาพไปยังโฟลเดอร์ปัจจุบัน (./), คัดลอกรูปภาพไปที่ ./assets หรือ คัดลอกรูปภาพไปที่ ./\${filename}.assets อัปโหลดรูปภาพ แสดงเป็นไม่พร้อมใช้งาน: Pilcrow ไม่มีโฮสต์รูปภาพ จึงแทรกรูปภาพไว้ตรงที่มันอยู่แล้ว
ใช้กับรูปภาพในเครื่องการดำเนินการใช้กับรูปภาพที่อยู่บนอุปกรณ์ของคุณแล้วหรือไม่
ใช้กับรูปภาพออนไลน์ใช้กับรูปภาพที่ชี้ไปยังที่อยู่เว็บหรือไม่
โหลดรูปภาพจากอินเทอร์เน็ตเมื่อปิด รูปภาพที่ชี้ไปยังที่อยู่เว็บจะไม่ถูกดาวน์โหลดสำหรับตัวอย่าง PDF หรือการส่งออกรูปภาพ ดังนั้นเว็บไซต์ที่โฮสต์รูปภาพจะไม่รู้อะไรเลย เมื่อเปิด รูปภาพจะถูกดึงเหมือนในเว็บเบราว์เซอร์ และเว็บไซต์นั้นเห็นคำขอได้
ใช้พาธสัมพัทธ์หากเป็นไปได้เขียนพาธที่สัมพัทธ์กับเอกสาร
เพิ่ม ./ สำหรับพาธแบบสัมพัทธ์เริ่มพาธสัมพัทธ์ด้วย ./
หลีก URL ของรูปภาพอัตโนมัติเมื่อแทรกหลีกอักขระในที่อยู่ที่จะทำให้ลิงก์เสีย
