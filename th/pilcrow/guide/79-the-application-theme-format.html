บทที่ 79

รูปแบบธีมแอปพลิเคชัน

Application Theme (ธีมแอปพลิเคชัน) กำหนดสไตล์ให้ตัว Pilcrow เอง ได้แก่ รูปลักษณ์แบบสว่างหรือมืด สีเน้น แถบด้านข้าง แถบสถานะและแถบจัดรูปแบบ และตัวแก้ไข เป็นไฟล์ JSON ส่วนเอกสารที่แสดงผล (Preview, HTML, PDF, รูปภาพ, การพิมพ์ และ Word) ถูกกำหนดสไตล์แยกต่างหากด้วย Render Theme (ธีมการแสดงผล) ซึ่งเป็น CSS (บทที่ 80) ธีมทั้งสองประเภทติดตั้ง เลือก และลบแยกกัน และไม่ตามกัน

ตัวอย่างฉบับสมบูรณ์#

{
  "pilcrowAppTheme": 1,
  "name": "Nord",
  "appearance": "dark",
  "colors": {
    "accent": "#88C0D0",
    "sidebar": { "background": "#2E3440", "foreground": "#D8DEE9" },
    "bars": { "background": "#3B4252", "foreground": "#D8DEE9" },
    "editor": {
      "background": "#2E3440",
      "foreground": "#ECEFF4",
      "cursor": "#88C0D0",
      "selection": "#434C5E",
      "gutterBackground": "#2E3440",
      "gutterForeground": "#4C566A"
    },
    "syntax": {
      "heading": "#88C0D0",
      "marker": "#EBCB8B",
      "code": "#A3BE8C",
      "link": "#81A1C1",
      "muted": "#7B88A1",
      "tokens": { "strong": "#D08770" }
    }
  }
}

ระดับบนสุด#

คีย์จำเป็นหรือไม่ค่า
pilcrowAppThemeจำเป็นเวอร์ชันของรูปแบบ คือ 1
nameจำเป็น1–200 ตัวอักษร แสดงใน Settings และเมนูธีม
appearanceจำเป็น"light", "dark" หรือ "automatic"
colorsธีม light และ darkหนึ่งชุดสี (ด้านล่าง)
light, darkธีม automaticสองชุดสี: ชุดหนึ่งใช้ในรูปลักษณ์สว่างของระบบ อีกชุดใช้ในรูปลักษณ์มืด
idไม่จำเป็นPilcrow เขียนให้สำหรับคลังของตัวเอง จะถูกละเว้นเมื่อนำเข้า ซึ่งจะกำหนด id ใหม่เสมอ

appearance กำหนดรูปลักษณ์ของทุกหน้าต่าง รวมถึงเมนู Settings ชีต และตัวเลือก ธีม light หรือ dark กำหนดตายตัว ส่วน automatic ตามระบบ

ธีมแบบ automatic ต้องกำหนดแต่ละสีทั้งใน light และ dark หรือไม่กำหนดเลยทั้งสองอย่าง มิฉะนั้นสีที่กำหนดไว้เพียงรูปลักษณ์เดียวจะถูกวาดในอีกรูปลักษณ์หนึ่งด้วย

ชุดสี#

ทุกคีย์เป็นตัวเลือก สีที่ไม่ได้กำหนดจะใช้หน้าตาในตัวของ Pilcrow ดังนั้นธีมจึงเล็กได้ถึงขนาดมีสีเน้นเพียงสีเดียว

คีย์กำหนดสไตล์ให้
accentสีเน้นทั้งแอป: ปุ่ม ส่วนที่เลือก สวิตช์ ลิงก์ วงโฟกัส และแถวที่เลือกของแถบด้านข้าง หากไม่กำหนดจะใช้สีเน้นของระบบ
sidebar.background, sidebar.foregroundแถบด้านข้างของไฟล์ เค้าร่าง และค้นหา ป้ายรองได้มาจากสีพื้นหน้า
bars.background, bars.foregroundแถบสถานะ แถบเครื่องมือจัดรูปแบบที่ยึดติด และประกาศการนำเข้า ป้ายรองได้มาจากสีพื้นหน้า
editor.background, editor.foregroundพื้นที่ตัวแก้ไขและข้อความเนื้อหา
editor.cursor, editor.selectionจุดแทรกและไฮไลต์ส่วนที่เลือก
editor.gutterBackground, editor.gutterForegroundคอลัมน์หมายเลขบรรทัด พื้นหลังมีค่าเริ่มต้นเป็นพื้นหลังของตัวแก้ไข
editor.currentLineRuleเส้นบางใต้บรรทัดที่เคอร์เซอร์อยู่ เมื่อ View ▸ Current-Line Rule (มุมมอง ▸ กฎบรรทัดปัจจุบัน) เปิดอยู่ ค่าเริ่มต้นคือสีข้อความของตัวแก้ไขที่ความเข้มต่ำ
syntax.<group>สีไวยากรณ์แบบสดตามกลุ่ม (ด้านล่าง)
syntax.tokens.<raw>โทเค็นหนึ่งตัวตามค่าดิบ ซึ่งแทนที่สีของกลุ่ม

กลุ่มไวยากรณ์#

กลุ่มสีที่กำหนด
headingหัวเรื่อง (เครื่องหมายและข้อความ) เครื่องหมายการแจ้งเตือน และคำนิยาม
markerตัวเน้น ตัวหนา ขีดทับ และตัวคั่นในบรรทัดอื่น ๆ เครื่องหมายรายการและงาน
codeโค้ดแบบแทรกในบรรทัด บล็อกโค้ดแบบรั้วและแบบเยื้อง สูตรคณิตศาสตร์ บล็อก HTML
linkป้ายและปลายทางของลิงก์และรูปภาพ ลิงก์อัตโนมัติ
mutedเครื่องหมายข้อความอ้างอิง เส้นคั่นเชิงเนื้อหา แถวของตาราง คอมเมนต์ แอตทริบิวต์ของบล็อก
codeKeyword, codeString, codeNumber, codeCommentโค้ดที่ไฮไลต์ภายในรั้วโค้ด

กลุ่มที่ไม่ได้กำหนดจะใช้สีในตัวที่เลือกให้เข้ากับพื้นหลังของตัวแก้ไข: โทนเข้มกว่าบนพื้นสว่าง โทนสว่างกว่าบนพื้นมืด ชื่อโทเค็นใน syntax.tokens ใช้ตัวอักษร ตัวเลข _ และ - และต้องไม่ซ้ำกับชื่อกลุ่ม (syntax.heading ครอบคลุม heading อยู่แล้ว)

สี#

ทุกสีเป็นสตริงฐานสิบหก: #RGB, #RGBA, #RRGGBB หรือ #RRGGBBAA ใน sRGB Pilcrow เก็บเป็นตัวพิมพ์ใหญ่

การตรวจสอบความถูกต้อง#

Pilcrow ปฏิเสธไฟล์แทนที่จะละเว้นบางส่วน และระบุคีย์ที่ผิด เช่น colors.editor.cursor: must be a hex colour โดยจะปฏิเสธ:

  • เวอร์ชัน pilcrowAppTheme ที่ขาดหายไปหรือต่างออกไป
  • คีย์ที่ไม่รู้จักในระดับใดก็ตาม (มักเป็นการพิมพ์ผิด)
  • คีย์ชุดสีที่ไม่ตรงกับรูปลักษณ์ (colors ในธีม automatic, light และ dark ในธีม light หรือ dark)
  • สีที่ไม่ใช่ฐานสิบหก
  • ธีม automatic ที่ชุดสี light และ dark กำหนดสีต่างกัน

สิ่งที่ธีมแอปพลิเคชันไม่เปลี่ยน#

แถบชื่อหน้าต่างและแถบเครื่องมือ (กระจกของระบบ ซึ่งรับเฉพาะสีเน้น) เมนู Settings ชีต และตัวเลือกยังคงหน้าตาดั้งเดิม นอกจากรูปลักษณ์และสีเน้น ฟอนต์ไม่ถูกกำหนดด้วยธีม: ฟอนต์และขนาดของตัวแก้ไขตั้งใน Settings ▸ Appearance ▸ Text Size & Fonts (การตั้งค่า ▸ รูปลักษณ์ ▸ ขนาดข้อความและฟอนต์)

การติดตั้งและการแชร์#

  • นำเข้าไฟล์ .json จาก Settings ▸ Library ▸ Themes (การตั้งค่า ▸ คลัง ▸ ธีม) File ▸ Import ▸ Theme (ไฟล์ ▸ นำเข้า ▸ ธีม) บน Mac หรือ Settings ▸ Library ▸ Import บน iPad การวางไฟล์ลงบน Pilcrow ก็ใช้ได้เช่นกัน
  • แพ็กเกจธีม .zip อาจมีธีมแอปพลิเคชันควบคู่กับธีมการแสดงผล (บทที่ 80)
  • ปุ่มแชร์ข้างธีมจะบันทึกไฟล์ .json ของธีม หรือทั้งแพ็กเกจหากธีมนั้นมาจากแพ็กเกจ

Pilcrow มีธีมแอปพลิเคชันสามธีม: Automatic (อัตโนมัติ), Light (สว่าง) และ Dark (มืด) ธีมเหล่านี้กำหนดสีของตัวแก้ไขและไวยากรณ์ และปล่อยส่วนโครงหน้าต่างไว้ตามหน้าตาในตัว

ก่อนหน้าการใช้ Pilcrow บน iPad ถัดไปเอกสารอ้างอิง CSS ของธีมการแสดงผล
