บทที่ 74

ตัวแก้ไขโปรไฟล์และส่วนประกอบของโปรไฟล์

โปรไฟล์ไวยากรณ์บอก Pilcrow ว่ามาร์กอัปของคุณมีความหมายอย่างไร บทนี้อธิบายตัวแก้ไขโปรไฟล์ทีละตัวควบคุม แล้วแสดงรายการส่วนประกอบทุกอย่างที่โปรไฟล์ใช้ได้ หากต้องการเริ่มต้นแบบเน้นงานที่ทำ ดูบทที่ 37 ถึงบทที่ 39

เปิดตัวแก้ไขจาก การตั้งค่า ▸ คลัง ▸ โปรไฟล์ไวยากรณ์ โดย ใหม่ เริ่มโปรไฟล์ใหม่ แก้ไข เปลี่ยนโปรไฟล์ที่กำหนดเอง และ ทำสำเนา คัดลอกโปรไฟล์ที่มาพร้อมแอปเพื่อให้คุณแก้ไขสำเนาได้ ชื่อของตัวแก้ไขคือ แก้ไขโปรไฟล์ พร้อม ยกเลิก, บันทึก และ วิธีใช้โปรไฟล์ (ซึ่งเปิดข้อมูลอ้างอิงในแอปสำหรับส่วนประกอบเหล่านี้) บนหน้าจอแคบ สวิตช์ ส่วนของโปรไฟล์ ใช้เลือกระหว่าง ภาพรวม, กฎ และ ตัวอย่างทดสอบ ส่วนบนหน้าจอกว้างจะแสดงทั้งสามพร้อมกัน

ภาพรวม#

ฟิลด์หน้าที่
ชื่อชื่อของโปรไฟล์ แสดงในเมนูแถบสถานะและในการตั้งค่า
คำอธิบายบันทึกเกี่ยวกับโปรไฟล์
นามสกุลไฟล์ (คั่นด้วยจุลภาค)นามสกุลที่ทำให้ไฟล์เลือกใช้โปรไฟล์นี้ โปรไฟล์สองโปรไฟล์ใช้นามสกุลเดียวกันไม่ได้
สืบทอดจากไม่มี หรือโปรไฟล์อื่นที่โปรไฟล์นี้ต่อยอดจากกฎของโปรไฟล์นั้น
ไวยากรณ์ขยาย Markdown หรือ แทนที่ Markdown (ดูด้านล่าง)
ภาพรวมจำนวนของ กฎของบล็อก, กฎแบบอินไลน์ และ กฎการซ้อน
แก้ไข JSON ขั้นสูง…เปิดโปรไฟล์เป็น JSON สำหรับฟิลด์ที่ตัวแก้ไขแบบนำทางไม่แสดง นำไปใช้ จะเก็บการเปลี่ยนแปลง JSON ของคุณ ยกเลิก จะทิ้งการเปลี่ยนแปลง

ขยาย Markdown เพิ่มกฎของคุณเข้ากับกฎของ Markdown โดยหัวเรื่อง รายการ ตัวเน้น และอื่นๆ ของ Markdown ยังคงถูกอ่านตามเดิม และกฎของบล็อกและกฎแบบอินไลน์ของคุณจะเพิ่มเข้าไป กฎที่เป็นสำเนาไม่มีการแก้ไขของกฎใดกฎหนึ่งในโปรไฟล์ CommonMark อธิบายสิ่งที่ Markdown ทำอยู่แล้ว จึงปล่อยให้ Markdown จัดการ แทนที่ Markdown ทำให้กฎของคุณเป็นไวยากรณ์ทั้งหมด ดังนั้นโครงสร้างของ Markdown จะไม่ถูกรู้จักอีกต่อไป เมื่อใช้ตัวเลือกนี้ ต้องมีกฎหนึ่งข้อที่สร้าง ท้ายบรรทัด มิฉะนั้นจะไม่มีสิ่งใดแบ่งเป็นย่อหน้า ตัวแก้ไขจะเตือนว่า "Add a rule whose output node is "newline", or nothing will separate into paragraphs" และบันทึกโปรไฟล์ไม่ได้จนกว่าจะมีกฎดังกล่าว นอกจากนี้ยังแสดงรายการประเภทเอาต์พุตที่โปรไฟล์ไม่ได้กำหนดไว้

กฎ#

กฎมีสามกลุ่ม

กฎของบล็อก#

กฎของบล็อกรู้จักทั้งบรรทัดและบล็อก เพิ่มกฎ ใช้เพิ่มกฎ แต่ละกฎมี รูปแบบ ประเภท ตรงกัน สิ่งที่ สร้าง และ ตัวเลือก ลบกฎได้ด้วยปุ่ม ลบ ของกฎนั้น เมื่อไม่มีกฎเลย ตัวแก้ไขจะแสดงว่า "No rules yet. Add one to recognize a block construct."

กฎแบบอินไลน์#

กฎแบบอินไลน์รู้จักข้อความภายในบรรทัด เพิ่มกฎแบบอินไลน์ ใช้เพิ่มกฎ กฎแบบอินไลน์มีประเภทการจับคู่สี่แบบ (คำนำหน้าตามตัวอักษร, ตรงตามตัวอักษร, Regex (มีขอบเขต) และ คู่ตัวคั่น) ส่วนกฎของบล็อกมีให้เลือกทั้งเจ็ดแบบ

กฎการซ้อน#

กฎการซ้อนบอกว่าเอาต์พุตใดวางอยู่ภายในเอาต์พุตใดได้ แต่ละกฎมี โหนดแม่ และ องค์ประกอบย่อยที่อนุญาต (คั่นด้วยจุลภาค) ค่าว่างหมายถึงไม่จำกัด: "No restrictions. Every node type may nest inside any other." เพิ่มกฎการซ้อน ใช้เพิ่มกฎ

ประเภทการจับคู่#

ประเภทการจับคู่อ่านรูปแบบเป็นบล็อกอินไลน์
คำนำหน้าตามตัวอักษรข้อความที่โครงสร้างขึ้นต้นด้วยใช่ใช่
ตรงตามตัวอักษรข้อความทั้งหมดของโครงสร้างใช่ใช่
คำนำหน้าต้นบรรทัดข้อความที่ต้นบรรทัด เช่น # ใช่
บล็อกที่เยื้องบรรทัดที่ขึ้นต้นด้วยรูปแบบ เช่น ช่องว่างสี่ช่องหรือแท็บ บรรทัดที่ต่อเนื่องกัน รวมทั้งบรรทัดว่างระหว่างกัน เป็นบล็อกเดียว และแสดงโดยไม่มีการเยื้องใช่
บล็อกที่มีรั้วบรรทัดที่เปิดบล็อก และปิดด้วยบรรทัดที่ตรงกันใช่
Regex (มีขอบเขต)นิพจน์ปรกติ Pilcrow จะเตือนก่อนบันทึกนิพจน์ที่อาจค้าง: "This regex could hang the editor — simplify it."ใช่ใช่
คู่ตัวคั่นเครื่องหมายเดียวกันทั้งสองด้านของข้อความในบรรทัดเดียว เช่น %% ใน %%this%% ไม่มีช่องว่างอยู่ด้านในติดกับเครื่องหมายใช่ใช่

ในนิพจน์ปรกติ (?<name>…) ตั้งชื่อส่วนหนึ่งของสิ่งที่ตรงกัน ดู ส่วนที่ตั้งชื่อ ด้านล่าง

แอตทริบิวต์คงที่ส่วนที่มีค่าเหมือนเดิมทุกครั้ง เพิ่มด้วย เพิ่มแอตทริบิวต์ (ชื่อ และ ค่า) ค่าอาจมีส่วนที่ตั้งชื่อ เขียนเป็น {name} เช่น กฎอีเมลที่รูปแบบตั้งชื่อ address ไว้ สามารถให้ลิงก์ของตนมี url เป็น mailto:{address}
แทรกข้อความสิ่งที่เมนู แทรก เขียนให้กฎนี้ ตรงตามที่ควรปรากฏ โดยใช้ $0 ตรงตำแหน่งที่เคอร์เซอร์ควรอยู่ กฎที่จับคู่ด้วยนิพจน์ปรกติ บล็อก หรือการเยื้อง ต้องมีตัวเลือกนี้ ไม่เช่นนั้นเมนูแทรกจะไม่แสดงกฎนั้น
เฉพาะหลังบรรทัดว่างสำหรับบล็อกที่เยื้อง: บรรทัดที่เยื้องซึ่งอยู่ถัดจากข้อความทันทีจะยังเป็นส่วนหนึ่งของข้อความนั้น เช่น บรรทัดถัดไปของรายการ
หลังกด Return ที่ท้ายบรรทัดสำหรับรายการและข้อความอ้างอิง: อัตโนมัติ (ทำซ้ำสัญลักษณ์แสดงหัวข้อย่อยและเครื่องหมายอ้างอิง นับขึ้นสำหรับรายการลำดับเลข และเริ่มรายการงานแบบไม่ได้ทำเครื่องหมาย), ทำซ้ำเครื่องหมาย, นับขึ้น, เริ่มใหม่จากเครื่องหมาย หรือ ไม่เพิ่มอะไร

บล็อกที่มีรั้วและบล็อกที่มีตัวคั่น#

สำหรับกฎ บล็อกที่มีรั้ว บล็อกประกอบด้วย บอกว่าข้างในมีอะไร

ตัวเลือกความหมาย
ยังไม่มีอะไรยังไม่ได้ตั้งค่า
ข้อความ แสดงตามที่เขียนโค้ดหรือข้อความที่จัดรูปแบบไว้ล่วงหน้า
ไม่มี — ซ่อนอยู่ความคิดเห็น ซึ่งถูกละไว้จากเอกสาร
บล็อกอื่นๆ ในกล่องข้อความอ้างอิง แถบด้านข้าง หรือกล่องข้อความเตือนที่มีย่อหน้า รายการ และอื่นๆ
บล็อกอื่นๆ ไม่มีกล่องบล็อกรวมเข้ากับข้อความรอบข้าง บรรทัดเหล่านี้เพียงจัดกลุ่มบล็อกไว้
ตารางดู ตาราง ด้านล่าง
ตารางที่วาดด้วยข้อความตารางเส้นหรือคอลัมน์ที่จัดแนวด้วยข้อความ ซึ่งต่อเนื่องจากบรรทัดเปิดไปจนถึงบรรทัดว่างถัดไป เช่นของ reStructuredText
ข้อความที่เยื้องใต้บรรทัดที่ลงท้ายด้วยเครื่องหมายบรรทัดเปิดเป็นร้อยแก้วที่ลงท้ายด้วยเครื่องหมาย เหมือน :: ของ reStructuredText ร้อยแก้วนั้นยังเป็นย่อหน้า ส่วนข้อความที่เยื้องอยู่ใต้มันหลังบรรทัดว่างจะแสดงตามที่เขียน
ข้อความที่เยื้องใต้บรรทัดเปิดไดเรกทีฟ เช่น .. code-block:: ซึ่งรวบรวมบรรทัดที่เยื้องใต้มัน และไม่มีบรรทัดปิด

บรรทัดปิด คือบรรทัดที่จบบล็อก ค่าว่างหมายถึงเหมือนบรรทัดเปิด ("Same as the opening line") ตัวคั่นที่ไม่ใช่นิพจน์ปรกติ เช่น +++ จะถูกจับคู่เป็นข้อความธรรมดา บรรทัดปิดซ้ำเครื่องหมายเปิด อย่างน้อยเท่าจำนวนเดิม ใช้กับรั้วแบบ Markdown: บรรทัดปิดคืออักขระตัวแรกของบรรทัดเปิดที่ซ้ำอย่างน้อยเท่าจำนวนเดิม ดังนั้นรั้วที่ยาวกว่าจึงครอบรั้วที่สั้นกว่าเป็นข้อความ ภาษาของบล็อกข้อความ เมื่อบรรทัดเปิดระบุภาษาที่รู้จัก จะถูกระบายสีในตัวแก้ไข

ตาราง#

ตัวเลือกของบล็อกตาราง

ตัวเลือกหน้าที่
เลย์เอาต์ตารางที่มีเส้นตาราง (เซลล์อยู่ระหว่าง | โดยมีเส้นกำกับคั่นระหว่างแถว) หรือ คอลัมน์ที่จัดแนว (คอลัมน์เรียงแนวใต้เส้นกำกับบรรทัดแรก)
ตัวคั่นเซลล์ข้อความที่เริ่มแต่ละเซลล์
รูปแบบเส้นกำกับ, รูปแบบเส้นกำกับส่วนหัวบรรทัดที่วาดเพียงเส้นกำกับ และบรรทัดที่จบส่วนหัว
แถวลงท้ายด้วยเครื่องหมายที่จบแต่ละแถว เหมือนที่ tabular ของ LaTeX ทำ
รูปแบบเซลล์ที่ครอบคลุมหลายช่องเซลล์ที่ครอบคลุมหลายคอลัมน์
รูปแบบตัวเลือกเซลล์นิพจน์ปรกติสำหรับสิ่งที่อาจอยู่ก่อนตัวคั่นของเซลล์ทันที ส่วนที่ชื่อ colspan ทำให้เซลล์ครอบคลุมคอลัมน์ตามจำนวนนั้น
ตัวคั่นรายการคอลัมน์, ทำซ้ำเครื่องหมายวิธีเขียนรายการ columns: ด้วย , และ * โดย 3* นับเป็นสามคอลัมน์
บรรทัดแรกก่อนบรรทัดว่างคือส่วนหัวแถวส่วนหัวถูกกำหนดโดยนัยจากเลย์เอาต์
รูปแบบวิธีเขียนเซลล์แบบอื่น แต่ละแบบมีชื่อและตัวคั่น (เช่น csv และ ,) เพิ่มด้วย เพิ่มรูปแบบ และเลือกด้วยส่วน format ของตาราง

การตั้งค่าทั่วทั้งโปรไฟล์#

การตั้งค่าหน้าที่
ซ้อนรายการตามเครื่องหมายเครื่องหมายใหม่แต่ละตัว เช่น ** หลัง * เริ่มระดับที่ลึกขึ้น ไม่ว่าจะเยื้องอย่างไร
บรรทัดต่อของรายการบรรทัดที่อยู่ลำพังหลังรายการ ซึ่งผูกบล็อกถัดไปเข้ากับรายการนั้น
คงการขึ้นบรรทัดใหม่เดี่ยวการขึ้นบรรทัดใหม่ภายในย่อหน้ายังคงเป็นการขึ้นบรรทัดใหม่
กำหนด id ให้หัวเรื่องหัวเรื่องที่ไม่มี id ของตัวเองจะได้ id จากชื่อ: ตัวพิมพ์เล็ก คำเชื่อมด้วย ตัวคั่นคำ ต่อจาก คำนำหน้า (คำนำหน้า id ของหัวเรื่อง, ตัวคั่นคำใน id ของหัวเรื่อง) เมื่อใช้ _ และ _ "Getting Started" จะเป็น _getting_started ดังนั้นการอ้างอิงโยงไปยังหัวเรื่องนั้นจะแสดงชื่อเรื่อง ชื่อที่ซ้ำจะเพิ่มตัวคั่นและตัวเลข
ใส่หมายเลขหัวเรื่องเมื่อเอกสารกำหนดแอตทริบิวต์ที่ระบุใน เมื่อเอกสารกำหนด เช่น :sectnums: ของ AsciiDoc หัวเรื่องตั้งแต่ จากระดับหัวเรื่อง ลงไปจะมีหมายเลข: 1., 1.1., 2. หัวเรื่องก่อนการกำหนดจะไม่มีหมายเลข
คำบรรยายที่มีหมายเลขบล็อกที่มีชื่อเรื่องและเป็นเอาต์พุตที่อยู่ในรายการนี้ เช่น image, table หรือ example จะได้ ป้ายกำกับ และหมายเลขของตัวเองก่อนชื่อเรื่อง (เช่น "Figure 1.") ที่ ตำแหน่งคำบรรยาย คือ ด้านบน หรือ ด้านล่าง ของบล็อก เพิ่มด้วย เพิ่มคำบรรยาย

เครื่องหมายแบบอินไลน์ที่จับคู่ตามสิ่งที่อยู่รอบๆ#

ภาษาอย่าง Markdown เขียนตัวหนาและตัวเอียงด้วยชุดอักขระที่เปิดหรือปิดตามอักขระที่อยู่ข้างๆ และเขียนโค้ดแบบแทรกในบรรทัดหรือลิงก์ด้วยวงเล็บ ดังนั้นรูปแบบเดียวสำหรับทั้งโครงสร้างจึงหาสิ่งเหล่านี้ไม่พบ เปิด อ่านเครื่องหมายตามสิ่งที่อยู่รอบๆ เพื่ออธิบายสิ่งเหล่านี้

การตั้งค่าหน้าที่
อักขระหลีกอักขระที่ทำให้ตัวถัดไปเป็นอักขระธรรมดา
อักขระโค้ดแบบแทรกในบรรทัดชุดของอักขระนี้เปิดช่วงที่ปิดด้วยชุดถัดไปที่มีความยาวเท่ากัน
เครื่องหมายแบบชุดเครื่องหมายที่จับคู่เป็นชุด เพิ่มด้วย เพิ่มเครื่องหมายแบบชุด แต่ละอันมี เครื่องหมาย สิ่งที่ เครื่องหมายหนึ่งตัววาด และสิ่งที่ เครื่องหมายสองตัววาด และ อาจเปิดหรือปิดภายในคำ (ปิดสำหรับ _)
เครื่องหมายแบบคู่เครื่องหมายที่จับคู่กับชุดที่มีความยาวเท่ากัน เพิ่มด้วย เพิ่มเครื่องหมายแบบคู่: เครื่องหมาย สิ่งที่มัน วาด และ เฉพาะเมื่อเปิดการตั้งค่านี้ ซึ่งเป็นการตั้งค่าไวยากรณ์ เช่น ไฮไลต์ ที่ต้องเปิดอยู่ (หรือ เสมอ)
ลิงก์และที่อยู่เว็บคำนำหน้ารูปภาพ, ที่อยู่ที่เขียนเดี่ยวๆ ถูกล้อมด้วย, รูปแบบที่ขึ้นต้นที่อยู่เปล่า, บรรทัดที่กำหนดป้ายกำกับมี และ ป้ายเชิงอรรถขึ้นต้นด้วย (อักขระหลังวงเล็บเปิดของป้ายที่ทำให้เป็นเชิงอรรถ: [^note] จะถูกวาดเป็นการอ้างอิงเชิงอรรถเมื่อมีบรรทัดขึ้นต้นด้วย [^note]:)

เครื่องหมายจับคู่กันภายในบรรทัด โค้ด อักขระที่ถูกหลีก และที่อยู่ของลิงก์ เป็นข้อความธรรมดาสำหรับเครื่องหมายที่อยู่รอบๆ

ต้นฉบับที่มีสไตล์#

เมื่อเปิด ต้นฉบับที่มีสไตล์ ตัวแก้ไขจะวาดเอกสารในรูปลักษณ์ของไวยากรณ์ของมัน: หัวเรื่องที่ใหญ่ขึ้น ช่วงตัวหนาและตัวเอียง แถบข้อความอ้างอิง การเยื้องรายการ กล่องงาน เส้นคั่น ลิงก์ และการ์ดโค้ด และซ่อนเครื่องหมายที่สร้างสิ่งเหล่านั้น (เมื่อเปิด ซ่อนเครื่องหมาย) ยกเว้นบนบรรทัดที่เคอร์เซอร์อยู่ ตัวแก้ไขไม่รู้จักไวยากรณ์ใดโดยเฉพาะ: กฎบอกว่าสิ่งที่จับคู่ได้คืออะไรโดยมีรายการสไตล์ติดไปด้วย และกฎที่ไม่มีจะถูกระบายสีแต่ไม่ถูกปรับสไตล์ใหม่

ตัวเลือก ของทุกกฎมีกลุ่ม ต้นฉบับที่มีสไตล์

ฟิลด์หน้าที่
บทบาทสิ่งที่การจับคู่เป็น หรือ ไม่มีสไตล์ สำหรับโครงสร้างหนึ่งภายในบรรทัด: heading, strong, emphasis, code, strike, highlight, underline, link, subscript, superscript สำหรับทั้งบรรทัด: rule (เส้นคั่นเชิงเนื้อหา), list (เครื่องหมายของรายการ รวมทั้งการเยื้องและช่องว่างหลังเครื่องหมาย), task (เครื่องหมายตามด้วยช่องทำเครื่องหมาย) และ quote (เครื่องหมาย > ของบรรทัดอ้างอิง) สำหรับบล็อกที่รู้จักทั้งก้อน: codeBlock สำหรับบล็อกที่บรรทัดเปิดและบรรทัดปิดเป็นการจับคู่แยกกัน: quoteRegion สำหรับตาราง สมการ หรือแผนภาพที่วาดเป็นรูปภาพ: renderedBlock
กลุ่มเนื้อหากลุ่มการจับ นับจาก 1 ที่เก็บสิ่งที่โครงสร้างนั้นพูดถึง: คำใน *bold* ชื่อเรื่องใน \section{Title} ส่วนที่เหลือของการจับคู่คือเครื่องหมายของโครงสร้างนั้นเอง ซึ่ง ซ่อนเครื่องหมาย จะซ่อน 0 หมายถึงการจับคู่ทั้งหมดเป็นเนื้อหาและไม่มีสิ่งใดถูกซ่อน เช่นที่อยู่เว็บ ละไว้เมื่อการจับคู่เป็นเพียงเครื่องหมาย เช่น == ของหัวเรื่อง
ระดับหัวเรื่อง, กลุ่มระดับระดับของหัวเรื่อง 1 ถึง 6 หากละไว้ จะเป็นตัวเลขท้ายชื่อเอาต์พุตของกฎ (heading2) หรือความยาวของกลุ่มการจับที่เก็บชุดของ #
กลุ่มเครื่องหมายสำหรับรายการหรืองาน กลุ่มการจับที่เป็นเครื่องหมายพร้อมการเยื้องและช่องว่างหลังมัน เมื่อการจับคู่ขึ้นต้นด้วยสิ่งอื่น เช่น > ของรายการที่อ้างอิง
สไตล์จนถึงท้ายบรรทัดใช้สไตล์จากตำแหน่งที่จับคู่ไปจนถึงท้ายบรรทัด สำหรับกฎที่จับคู่เฉพาะเครื่องหมายของหัวเรื่องและปล่อยชื่อเรื่องเป็นข้อความที่ตามมา
วาดเป็นสำหรับบล็อกที่ถูกวาด ว่ามันคืออะไร: ตาราง สูตรคณิตศาสตร์ หรือแผนภาพ หรือ ไม่ใช่รูปภาพ
กลุ่มที่อยู่สำหรับลิงก์ กลุ่มการจับที่ลองตามลำดับ ซึ่งเก็บที่อยู่ที่ลิงก์เปิดเมื่อคลิกหรือแตะ; 0 คือการจับคู่ทั้งหมด เปิดได้เฉพาะที่อยู่เว็บ อีเมล และโทรศัพท์

หมายเลขกลุ่มนับวงเล็บของรูปแบบจาก 1; 0 คือการจับคู่ทั้งหมด โปรไฟล์ที่ไม่แทนที่ Markdown ยังคงใช้การอ่านของ Markdown เองกับชนิดที่กฎของมันไม่ได้ประกาศไว้ เช่น แถบข้อความอ้างอิงและคู่ของ **

แอตทริบิวต์ของเอกสารและส่วนแบบมีเงื่อนไข#

กฎ แอตทริบิวต์ของเอกสาร กำหนดค่าด้วย name และกฎ ข้อมูลอ้างอิงแอตทริบิวต์ (กฎแบบอินไลน์ที่มีส่วน name และ original) แทนที่การอ้างอิงด้วยค่านั้น การอ้างอิงถึงแอตทริบิวต์ที่ยังไม่มีใครกำหนดจะคงไว้ตามที่เขียน ส่วนแบบมีเงื่อนไข เก็บไว้หรือทิ้งบล็อกระหว่างบรรทัดของมัน ขึ้นอยู่กับว่าแอตทริบิวต์ที่มันระบุถูกตั้งไว้หรือไม่ แอตทริบิวต์มีผลตั้งแต่ตำแหน่งที่กำหนดเป็นต้นไป

กฎที่สร้าง การตั้งค่าสำหรับบล็อกถัดไป รู้จักทั้งบรรทัดที่กำหนดค่าบล็อกที่ตามมา และไม่แสดงสิ่งใดด้วยตัวเอง ส่วนและแอตทริบิวต์คงที่ของมันจะถูกมอบให้บล็อกนั้น: title, id, nodeType, language และ hardbreaks มีความหมายตามที่ระบุไว้ใต้ ส่วนต่างๆ และส่วนอื่นๆ จะถูกเก็บไว้ที่บล็อก ซึ่งตาราง รายการ หรือข้อความอ้างอิงจะอ่านค่า

การทดสอบโปรไฟล์#

ที่ด้านล่างของตัวแก้ไข ตัวอย่างทดสอบ เก็บข้อความตัวอย่าง (เริ่มต้นเป็นหัวเรื่องและหนึ่งบรรทัดข้อความ) เลือก ตัวอย่างการตรวจสอบ เพื่อดูโหนดที่กฎของคุณสร้าง เยื้องตามการซ้อน หากไม่มีสิ่งใดตรงกัน จะแสดงว่า "No blocks recognized."

ค่าพื้นฐาน#

ค่าพื้นฐาน ของโปรไฟล์คือจุดกู้คืน: สภาพของโปรไฟล์ตอนที่คุณสร้าง ทำสำเนา หรือนำเข้า รีเซ็ตเป็นค่าพื้นฐาน ทิ้งทุกการเปลี่ยนแปลงตั้งแต่นั้น หลังจากที่คุณยืนยัน ตั้งเป็นค่าพื้นฐานใหม่ บันทึกโปรไฟล์และทำให้สถานะปัจจุบันเป็นจุดกู้คืน

การบันทึกจะถูกปฏิเสธพร้อมข้อความ หากโปรไฟล์แทนที่ Markdown แต่ไม่มีกฎท้ายบรรทัด หากรูปแบบไม่ปลอดภัยและอาจทำให้ตัวแก้ไขค้าง หรือหากเขียนไฟล์ไม่ได้

เอาต์พุต#

สิ่งที่กฎ สร้าง: ชื่อในเมนู แล้วชื่อที่ไฟล์โปรไฟล์เก็บ ว่ากฎของบล็อกหรือกฎแบบอินไลน์สร้างได้หรือไม่ และส่วนที่มันอ่าน กฎอาจระบุเอาต์พุตที่ไม่มีในรายการนี้ก็ได้ ซึ่งจะถูกเก็บเป็น กำหนดเอง

#### โครงสร้างข้อความ

เอาต์พุตเก็บเป็นประเภทอ่าน
หัวเรื่อง 1heading1บล็อก
หัวเรื่อง 2heading2บล็อก
หัวเรื่อง 3heading3บล็อก
หัวเรื่อง 4heading4บล็อก
หัวเรื่อง 5heading5บล็อก
หัวเรื่อง 6heading6บล็อก
ย่อหน้าparagraphบล็อก
เส้นคั่นแนวนอนthematicBreak หรือ thematic_breakบล็อก
ท้ายบรรทัดnewlineบล็อกและอินไลน์
หัวเรื่อง (ระดับตามกฎ)headingบล็อกlevel

#### รายการ

เอาต์พุตเก็บเป็นประเภทอ่าน
รายการlistบล็อกordered, start
รายการสัญลักษณ์แสดงหัวข้อย่อยlistItemUnorderedบล็อก
รายการลำดับเลขlistItemOrderedบล็อก
รายการเช็กลิสต์taskListMarkerบล็อก
ศัพท์ในรายการคำอธิบายdefinition_termบล็อกterm, marker

#### บล็อก

เอาต์พุตเก็บเป็นประเภทอ่าน
บล็อกโค้ดcode_block หรือ codeBlock หรือ fencedCodeบล็อกlanguage, content
ข้อความที่จัดรูปแบบไว้ล่วงหน้าliteral_blockบล็อก
HTML ดิบhtml_blockบล็อก
สมการmath_block หรือ mathBlockบล็อกnotation, content
แผนภาพdiagramบล็อกformat, content
ตารางtableบล็อกcolumns, header, noHeader, format
เส้นของแถวตารางtableRowบล็อก

#### กล่องและข้อความอ้างอิง

เอาต์พุตเก็บเป็นประเภทอ่าน
ข้อความอ้างอิงblockquoteบล็อกattribution, citetitle
เครื่องหมายบรรทัดอ้างอิงblockquoteMarkerบล็อก
บรรทัดข้อความเตือนalertMarkerบล็อกtype
กล่องข้อความเตือนadmonitionบล็อกtype, title
แถบด้านข้างsidebarบล็อกtitle
กล่องตัวอย่างexampleบล็อกtitle
ส่วนที่ยุบได้detailsบล็อกsummary, open
กลุ่ม (ไม่มีกล่อง)open_blockบล็อก

#### ซ่อนอยู่และการตั้งค่า

เอาต์พุตเก็บเป็นประเภทอ่าน
ความคิดเห็น (ซ่อนอยู่)commentบล็อก
การตั้งค่าสำหรับบล็อกถัดไปblock_attributesบล็อกnodeType, title, id, language, hardbreaks, sectionLabel, sectionLabelStart, presentation
แอตทริบิวต์ของเอกสารattribute_definitionบล็อกname, value, unset
ส่วนแบบมีเงื่อนไขconditionalบล็อกcondition, conditionType, anyOf, allOf

#### การจัดรูปแบบ

เอาต์พุตเก็บเป็นประเภทอ่าน
ตัวหนาstrongอินไลน์
ตัวเอียงemphasisอินไลน์
ไฮไลต์markอินไลน์
ขีดเส้นใต้underlineอินไลน์
ขีดทับstrikethroughอินไลน์
ตัวยกsuperscriptอินไลน์
ตัวห้อยsubscriptอินไลน์
โค้ดแบบแทรกในบรรทัดcodeSpan หรือ codeอินไลน์
แป้นกดบนแป้นพิมพ์keyboardอินไลน์keys
การขึ้นบรรทัดใหม่line_breakอินไลน์
ข้อความแทนที่textอินไลน์content
HTML ดิบ (อินไลน์)html_inlineอินไลน์content

#### ลิงก์และการอ้างอิง

เอาต์พุตเก็บเป็นประเภทอ่าน
ลิงก์linkอินไลน์url, title, text
ที่อยู่เว็บautolinkอินไลน์
การอ้างอิงโยงcross_referenceอินไลน์targetID, label
จุดยึดanchorอินไลน์id, label
ข้อมูลอ้างอิงแอตทริบิวต์substitutionอินไลน์name, original
เชิงอรรถfootnote_definitionอินไลน์id, text
คำดัชนีindex_termอินไลน์primary, secondary, tertiary

#### สื่อและคณิตศาสตร์

เอาต์พุตเก็บเป็นประเภทอ่าน
รูปภาพimageบล็อกและอินไลน์url, alt, title
วิดีโอvideoบล็อกsrc
เสียงaudioบล็อกsrc
สมการแบบอินไลน์math_inline หรือ inlineMathอินไลน์notation, content

ส่วนต่างๆ#

ส่วนต่างๆ คือชิ้นส่วนที่ตั้งชื่อของการจับคู่ซึ่งเอาต์พุตอ่านค่า

ส่วนความหมาย
allOfตัวคั่นระหว่างชื่อเมื่อต้องการครบทุกชื่อ เช่น +
altคำอธิบายรูปภาพ สำหรับผู้อ่านที่มองไม่เห็นรูป
anyOfตัวคั่นระหว่างชื่อเมื่อชื่อใดชื่อหนึ่งก็พอ เช่น ,
attributionผู้กล่าวข้อความอ้างอิง แสดงใต้ข้อความนั้น
citetitleผลงานที่ข้อความอ้างอิงมาจาก แสดงหลังผู้กล่าว
columnsรายการคอลัมน์ของตาราง เช่น 1,2,1 จำนวนรายการคือจำนวนคอลัมน์
conditionชื่อแอตทริบิวต์ที่ส่วนนั้นขึ้นอยู่กับ
conditionTypedefined เก็บส่วนไว้เมื่อตั้งแอตทริบิวต์ไว้ undefined เมื่อไม่ได้ตั้ง
contentตัวข้อความ เมื่อไม่ใช่การจับคู่ทั้งหมด
formatเอนจินของแผนภาพ (mermaid หรือ vega-lite) สำหรับตาราง คือรูปแบบที่คั่นด้วยตัวคั่นที่เซลล์ใช้
hardbreaksเมื่อมีอยู่ จะคงการขึ้นบรรทัดใหม่เดี่ยวของบล็อกถัดไป
headerค่าใดก็ตามที่ไม่ใช่ false ทำให้แถวแรกของตารางเป็นส่วนหัว
idชื่อ: สำหรับบล็อกถัดไป คือ id ที่การอ้างอิงโยงชี้ไป สำหรับเชิงอรรถ คือชื่อที่ให้เชิงอรรถหลังๆ ที่ไม่มีข้อความของตัวเองใช้หมายเลขร่วมกัน
keysแป้นที่ต้องกด คั่นด้วยจุลภาค
labelข้อความที่แสดงสำหรับการอ้างอิงหรือจุดยึด แทนชื่อเรื่องของเป้าหมายเอง
languageภาษาโปรแกรมของบล็อกโค้ด ใช้สำหรับการระบายสี
levelระดับหัวเรื่อง ตั้งแต่ 1 ถึง 6
markerตัวคั่นหลังศัพท์ เช่น :: เครื่องหมายที่ต่างออกไปจะซ้อนรายการไว้ภายในคำอธิบาย
nameชื่อของแอตทริบิวต์ ในการกำหนดหรือการอ้างอิง
nodeTypeทำให้บล็อกถัดไปเป็นเอาต์พุตอื่น ตามชื่อของมันในไฟล์
noHeaderเมื่อมีอยู่ ตารางไม่มีแถวส่วนหัว
notationสัญกรณ์คณิตศาสตร์: tex (ค่าเริ่มต้น) หรือ latex
opentrue แสดงส่วนที่ยุบได้ในสถานะเปิด
orderedtrue ทำให้รายการเป็นแบบมีหมายเลข
originalการอ้างอิงตามที่เขียน แสดงเมื่อไม่ได้กำหนดแอตทริบิวต์
presentationวิธีแสดงรายการคำอธิบายถัดไป: sideBySide วางศัพท์และคำอธิบายเป็นสองคอลัมน์ questions ใส่หมายเลขศัพท์แต่ละตัวเป็นคำถาม โดยมีคำตอบอยู่ใต้ศัพท์นั้น
primaryรายการดัชนี
secondaryรายการย่อยใต้รายการดัชนี
sectionLabelคำที่หมายเลขของหัวเรื่องถัดไปตามหลัง เช่น Appendix: หัวเรื่องเช่นนี้ถูกนับแยกต่างหาก Appendix A:
sectionLabelStartหมายเลขแรกของชุดนั้น: ตัวอักษร (A) นับเป็นตัวอักษร ตัวเลขนับเป็นตัวเลข
srcที่อยู่ของไฟล์วิดีโอหรือเสียง
startตัวเลขที่รายการแบบมีหมายเลขเริ่มต้น
summaryบรรทัดที่แสดงบนส่วนที่ยุบได้ขณะที่ปิดอยู่
targetIDid ที่การอ้างอิงชี้ไป
termศัพท์ที่กำลังอธิบาย
tertiaryรายการย่อยใต้รายการย่อยระดับที่สอง
textข้อความที่แสดง เมื่อรูปแบบจับได้มากกว่านั้น ข้อความของเชิงอรรถตามหลังย่อหน้า ตาราง หรือรายการที่มันอยู่ และมีหมายเลข
titleชื่อเรื่อง: หัวข้อของกล่อง คำแนะนำเครื่องมือของรูปภาพหรือลิงก์ หรือคำบรรยายเหนือบล็อกถัดไป
typeชนิดของข้อความเตือน เช่น note, tip หรือ warning
unsetเมื่อมีอยู่ กฎจะลบแอตทริบิวต์แทนที่จะกำหนด
urlที่อยู่ที่ลิงก์หรือรูปภาพชี้ไป
valueค่าของแอตทริบิวต์ การอ้างอิงถึงแอตทริบิวต์ที่กำหนดไว้ก่อนหน้าจะถูกแทนที่ในค่านี้
ก่อนหน้าการสมัครสมาชิกและเครดิต ถัดไปตัวแก้ไขธีม
