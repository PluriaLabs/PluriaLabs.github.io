Chapter 81

Files, encodings and limits

Files Pilcrow opens#

Pilcrow edits plain-text and markup files. The usual extensions are txt, md, markdown, adoc, asciidoc, rst and tex, and any extension a profile you add claims. Pilcrow detects a file's text encoding when it opens it.

ItemType
Syntax profile, macro collection, style guide, Application Theme.json
Render Theme.css
Theme package.zip
Book project manifestmanifest.pilcrow
BackdropHEIC, PNG, JPEG, SVG, MP4, MOV, M4V
Typing sound clipWAV, AIFF, MP3, M4A, CAF

Text encodings#

Pilcrow reads UTF-8, UTF-16, UTF-32 and ISO 8859-1 (Latin-1) text. You can convert a document with Document Information ▸ Encoding ▸ Convert To… to any of the following; the file is converted when it is next saved:

UTF-8, UTF-8 (BOM), UTF-16 LE, UTF-16 LE (BOM), UTF-16 BE, UTF-16 BE (BOM), UTF-32 LE, UTF-32 LE (BOM), UTF-32 BE, UTF-32 BE (BOM).

A Latin-1 file can be converted to any of these without loss. Converting to Latin-1 is not offered, because it can destroy content.

Limits and numbers#

Where Pilcrow stops, or where a choice has a range:

WhereLimit
Search panelStops at 500 matches.
Preview findCounts up to 2,000 matches.
Replace in FolderChanges at most 2,000 files at a time.
Check LinksChecks up to 50,000 links.
CompareShows up to 5,000 changed lines.
Versions to keepNone to 500 (default 50).
Long linesLines of 20,000 characters or more always wrap.
Font size9 to 32 points.
Tab width2 to 8 spaces.
Text width50% to 100%.
Zoom50% to 200%, in ten steps.
Reading speed60 to 2,000 words per minute.
Navigator width180 to 420 points.
Typing sound clipAt most 2 seconds and 3 MB.
Diagnostic report log textThe newest entries, up to 60,000 characters, when added to a GitHub issue description.
Very large filesOpen and edit without being read into memory whole. Line and word counts, and the outline, are completed in the background and may be partial until then. PDF export of a very large document needs much more memory than editing or HTML and Word export; PDF Archive splits it into bounded parts.

Where Pilcrow keeps things#

WhatWhere
Your documentsWherever you saved them.
Library (themes, profiles, macros, style guides, backdrops)In the app's private storage, or in a folder named "Pilcrow Library" inside a folder you choose (Settings ▸ Library ▸ Location).
Preferences, API keys, recovery copies, version historyOn the device, in the app's private storage and Keychain. Review and delete them in Settings ▸ General ▸ Storage & Privacy.
Diagnostic logOn the device, until you clear it.
