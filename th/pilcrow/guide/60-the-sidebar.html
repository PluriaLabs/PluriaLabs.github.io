บทที่ 60

แถบด้านข้าง

แถบด้านข้างมีห้าแผง ได้แก่ Files, Outline, Search, Project และ Assistant สวิตช์ที่ด้านบนของแถบด้านข้างใช้เลือก Files, Outline, Project (แสดงเมื่อโฟลเดอร์ที่เปิดอยู่เป็นโปรเจกต์หนังสือ) หรือ Assistant (แสดงเมื่อตั้งค่าการเชื่อมต่อแล้ว) ส่วน Search มีส่วนหัวของตัวเองที่มีชื่อว่า Find, ปุ่ม Done ที่พาคุณกลับไปยัง Files และตัวควบคุมขอบเขตสำหรับ This Document หรือ Folder เข้าถึงได้จาก View ▸ Search (⇧⌘F) เมนู View ยังใช้สลับแผงได้ด้วย และการเลือกแผงที่แสดงอยู่แล้วจะซ่อนแถบด้านข้าง ลากขอบของแถบด้านข้างเพื่อปรับขนาด เหนือแผนผังไฟล์มีเมนูที่ให้เลือก Open File… และ Open Folder…

Files#

แผง Files คือแผนผังของโฟลเดอร์ที่เปิดอยู่

เมื่อไม่มีโฟลเดอร์เปิดอยู่ แผงจะแสดงข้อความ "Choose a folder to browse its files." และมี Open Folder กับ Open File ให้เลือก คุณยังลากโฟลเดอร์มาวางบนแผงได้ด้วย เมื่อคุณเปิดไฟล์เดียวที่ Pilcrow มองไม่เห็นโฟลเดอร์ของไฟล์นั้น แผงจะแสดง "Browse folder to see the files beside this document" พร้อม Browse Enclosing Folder…

คลิกไฟล์เพื่อเปิด โฟลเดอร์ขยายและยุบได้ คลิกขวาที่แถว หรือกดค้างบน iPad เพื่อเปิดเมนูของแถวนั้น:

ItemWhat it does
New Fileสร้างไฟล์ในโฟลเดอร์ (หรือข้างไฟล์ที่คุณคลิก)
New Folderสร้างโฟลเดอร์ที่นั่น
Rename…เปลี่ยนชื่อไฟล์หรือโฟลเดอร์
Move to Trashย้ายไปที่ถังขยะหลังจากที่คุณยืนยัน คุณนำกลับมาจากที่นั่นได้
Reveal in Finderแสดงใน Finder (Mac)

ในตำแหน่งที่ระบบไม่มีถังขยะ Pilcrow จะเก็บรายการที่ลบไว้ในส่วน Recently Deleted ที่ด้านล่างของแผง แต่ละรายการในนั้นมี Put Back และ Delete Permanently และ Empty Recently Deleted จะลบรายการทั้งหมดในส่วนนั้นอย่างถาวร การลบอย่างถาวรเลิกทำไม่ได้ Pilcrow จึงถามก่อน รายการที่คุณลบจากที่อื่นจะไม่ได้รับผลกระทบ

การแสดงหรือซ่อนไฟล์และโฟลเดอร์ที่ซ่อนอยู่ทำได้ที่ Settings ▸ Files ▸ Show hidden folders and files

Outline#

Outline แสดงรายการหัวเรื่องของเอกสารที่ใช้งานอยู่ โดยเยื้องตามระดับ คลิกหัวเรื่องเพื่อข้ามไปที่นั่น เครื่องหมายลูกศรทางด้านข้างหัวเรื่องใช้ยุบหรือขยายหัวเรื่องที่อยู่ภายใต้ สิ่งนี้ไม่เปลี่ยนเอกสาร และสถานะที่ยุบไม่ถูกบันทึก

สถานะที่คุณอาจเห็น:

MessageMeaning
No headingsโปรไฟล์ที่ใช้งานอยู่ไม่พบหัวเรื่อง
Indexing outline… N%เอกสารขนาดใหญ่ยังอยู่ระหว่างการสแกน
Outline indexing failed. The listing may be incomplete.การสแกนพบปัญหา
N headings near your position — scroll to see others.เอกสารที่ใหญ่มากจะแสดงเค้าร่างเป็นช่วงรอบตำแหน่งเคอร์เซอร์

ใต้เค้าร่างจะมีส่วน Fields ปรากฏขึ้นเมื่อเอกสารมีฟิลด์ให้กรอก (Chapter 24) ส่วนนี้แสดงรายการฟิลด์พร้อมจำนวน คลิกฟิลด์เพื่อเลื่อนไปที่ฟิลด์นั้นและเลือกมัน หากมีฟิลด์จำนวนมาก แผงจะแสดงว่า "Only the first fields are listed."
