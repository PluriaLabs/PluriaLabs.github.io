Chapter 53

The File menu

On Mac these items are in the File menu. On iPad they are in Menu ▸ File in the header, or in the menu bar that appears when you hold ⌘ or move the pointer to the top of the screen. Items marked "Mac only" do not exist on iPad.

ItemShortcutWhat it does
New (iPad: New Document)⌘NCreates an untitled document. It joins the open documents.
Open… (iPad: Open File…)⌘OOpens a text or markup file from disk.
Open Recent (Mac only)Lists recently opened files. Clear Menu empties the list. Shows "No Recent Documents" when the list is empty.
Open Quickly… (Mac only)⇧⌘OSearches the filenames in the open folder. Greyed out while no folder is open.
Open Folder… (iPad header menu and More)Opens a folder in the sidebar. On Mac, use the sidebar's own Open Folder button.
Browse Enclosing Folder…Asks permission to browse the folder that contains the open file. Pilcrow's sandbox opens a file alone; this adds its folder. Greyed out when the folder is already open or the document has no file.
New Book…Creates a book project folder with its manifest (Chapter 34).
Make Folder a Book ProjectWrites a manifest.pilcrow into the open folder and shows the Project panel (Chapter 34). Greyed out when no folder is open or the folder already has a manifest.
Close Document (iPad: Close)⌘WCloses the active document, asking first if it has unsaved changes. When Settings is in front, ⌘W closes Settings instead.
Close All (iPad)⇧⌘WCloses every document, asking about each unsaved one. On Mac, the title menu has Close All Documents.
Save⌘SSaves the document. A new document asks where to save it.
Save All (Mac only)⌥⌘SSaves every document with unsaved changes. Greyed out when there are none.
Duplicate (Mac only)⇧⌘SMakes a copy and opens it beside the original, which stays unchanged.
Save As…⌥⇧⌘SSaves to a new name or place, or in another encoding. Afterwards the document is the new file.
Move To… (Mac only)Moves or renames the file on disk through a save panel (the button reads Move), keeping the document open.
Version History…Opens the document's saved versions (Chapter 17 and Chapter 63).
Compare with File…Compares the document with another file and lets you accept or reject each change (Chapter 18).
Reload from Disk (Mac only)Re-reads the file from disk, for use when another app changed it. If you have unsaved changes it asks first: Save, Then Reload, Reload Without Saving, or Cancel. Greyed out for a document with no file.
Show in Finder (Mac only)Reveals the file in Finder.
Import (Mac only)A submenu: Theme…, Syntax Profile…, Macro Collection…, Style Guide…. Each adds a file to your library (Chapter 43). On iPad, import is under Settings ▸ Library ▸ Import.
Export…⇧⌘EOpens the export panel (Chapter 64).
Share…Shares the document's file.
Compile Manuscript…Compiles a book project (Chapter 36). Greyed out until a book project is loaded.
Page Setup… (Mac only)Sets paper, orientation and margins, the same settings PDF export uses.
Print…⌘PPrints the rendered document. If the document has unfilled fill-in fields, Pilcrow warns you first.
