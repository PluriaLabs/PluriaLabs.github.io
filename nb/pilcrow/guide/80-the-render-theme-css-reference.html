Kapittel 80

CSS-referansen for gjengivelsestemaer

Et Gjengivelsestema er CSS. Det styler utdata for forhåndsvisning, HTML, PDF, bilde og utskrift, samt Word-stilene som er listet opp på slutten av dette kapittelet. Et gjengivelsestema kan være én enkelt .css-fil eller en del av en ZIP-pakke med lokale ressurser. Syntaksprofiler definerer hvordan kildetekst blir til dokumentet; gjengivelsestemaer styler bare resultatet. CSS styler aldri appen eller redigeringsvinduet; det er apptemaets oppgave (kapittel 79).

Kaskaden#

Pilcrow bruker stiler i denne rekkefølgen:

  1. Pilcrows strukturelle tilbakestilling;
  2. CSS-en i det valgte temaet;
  3. engangs-CSS fra eksportpanelet (Avanserte valg ▸ Egendefinert CSS);
  4. nødvendige utskrifts- og gjengivelsesrettinger.

Senere regler vinner etter den vanlige CSS-kaskaden. Tema-JavaScript, eksterne ressurser, file:-URL-er og @import støttes ikke.

Ressurser#

Pilcrow leser tema-CSS med en standard CSS-tokenizer, så escape-sekvenser dekodes før noe kontrolleres: u\72 l(…) er en url() og @im\70 ort er en @import. Alle steder en nettleser ville lastet fra, kontrolleres: url(…), url("…"), src("…") og strenger inni image-set(). Hver må være én av disse:

  • en pakkerelativ sti (fonts/Body.woff2, ./paper.png). En ?query eller #fragment er tillatt og ignoreres når filen slås opp;
  • en data:-URL av typen PNG, JPEG, GIF, WebP, SVG (image/svg+xml), TTF, OTF, WOFF eller WOFF2;
  • en fragmentreferanse som url(#shadow), som navngir et element på siden.

Alt med et annet skjema enn data: (https:, file:, blob:) eller som begynner med //, avvises, det samme gjelder en sti som begynner med / eller inneholder ...

Offentlige modifikatorer omfatter pt-heading-1 til og med pt-heading-6, pt-list--ordered, pt-list--unordered, pt-definition-list--side-by-side, pt-code-block--wrap, pt-code-block--numbered, de fem standardverdiene pt-admonition--*, og parameteriserte klasser for språk, råformat, matematikknotasjon, diagramformat, tabellseksjonstype, betingelsestype og makronavn. Parameteriserte suffikser kommer fra den aktive syntaksprofilen eller dokumentet og må CSS-escapes når de inneholder tegnsetting.

Pilcrow kan legge til klasser og attributter i en oppdatering. Unngå selektorer som avhenger av udokumentert innpakningsdybde, genererte ID-er eller fravær av ekstra klasser.

  --pt-accent: #0b57d0;

.pt-document { max-width: 72ch; }
.pt-heading-1 { letter-spacing: -0.025em; }

ZIP-pakker#

En ZIP-pakke kan inneholde gjengivelsestemaer (.css) og apptemaer (.json) sammen; hvert vises med sin egen type i Innstillinger. En ZIP med høyst én CSS-fil og høyst ett apptema trenger ikke manifest. Alt utover det krever pilcrow-theme.json, som lister hvert tema under variants[].file. Filens filtype avgjør typen:

{
  "id": "com.example.paper",
  "name": "Paper",
  "version": "1.0.0",
  "author": "Example Author",
  "license": "MIT",
  "cssAPIVersion": 1,
  "variants": [
    { "id": "app", "name": "Paper", "file": "Paper.json", "appearance": "automatic" },
    { "id": "light", "name": "Paper Light", "file": "Paper-Light.css", "appearance": "light" },
    { "id": "dark", "name": "Paper Dark", "file": "Paper-Dark.css", "appearance": "dark" }
  ]
}

Manifestet beskriver pakken og temaene i den. Det inneholder aldri stilverdier: de ligger i CSS- og apptemafilene.

  • Pakkens id navngir installasjonsmappen. Den må ikke begynne med . eller ha innledende eller etterfølgende mellomrom. Å installere en pakke hvis id allerede er installert, erstatter den.
  • En ZIP laget med Finders Komprimer fungerer som den er. Pilcrow hopper over __MACOSX/, ._*, .DS_Store og Thumbs.db, og når alle filer ligger inni én toppnivåmappe, behandles den mappen som pakkens rot.
  • Å slette ett tema fjerner det fra pakken og beholder de andre sammen med de delte ressursene. Å slette det siste temaet fjerner pakken. Et slettet tema som var valgt, setter valget tilbake til standarden for sin type: Automatisk for apptemaet, Lys for gjengivelsestemaet.
  • CSS kan referere til pakkede PNG-, JPEG-, GIF-, WebP-, TTF-, OTF-, WOFF- og WOFF2-filer med relative url(...)-stier. Pilcrow verifiserer signaturene deres og bygger inn refererte ressurser som data-URL-er, slik at gjengivelse og eksportert HTML forblir frakoblet og selvstendig. ZIP-stier kan ikke bryte ut av pakken, kollidere på store og små bokstaver eller peke til lenker. Arkivstørrelse, antall oppføringer, enkeltstørrelse og komprimeringsforhold er begrenset.

Word#

Word-eksport bruker de lyse (grunn-) :root-verdiene og tilordner disse semantiske egenskapene til navngitte Word-stiler: --pt-foreground, --pt-background, --pt-accent, --pt-link-color, --pt-code-background, --pt-code-foreground, --pt-body-font-family, --pt-mono-font-family, --pt-base-font-size og --pt-line-height. Nettleserselektorer og layoutregler har ingen generell Word-ekvivalent. Utdata for forhåndsvisning, HTML, PDF og bilde bruker hele stilarket; Word bruker denne delmengden og bevarer samtidig dokumentstruktur, diagrammer, matematikkbilder, lenker og medier. Eksportpanelet viser denne begrensningen hver gang Word er valgt.

Pilcrow inneholder to gjengivelsestemaer, Lys og Mørk, som er fullstendige utgangspunkter.
