제79장

앱 테마 형식

앱 테마는 Pilcrow 자체의 모양, 즉 라이트 또는 다크 화면 모드, 강조색, 사이드바, 상태 및 서식 막대, 편집기의 스타일을 지정합니다. JSON 파일입니다. 렌더링된 문서(미리보기, HTML, PDF, 이미지, 프린트, Word)는 CSS로 된 렌더링 테마가 따로 스타일을 지정합니다(Chapter 80). 두 종류는 각각 따로 설치, 선택, 삭제되며 서로 영향을 주지 않습니다.

전체 예시#

{
  "pilcrowAppTheme": 1,
  "name": "Nord",
  "appearance": "dark",
  "colors": {
    "accent": "#88C0D0",
    "sidebar": { "background": "#2E3440", "foreground": "#D8DEE9" },
    "bars": { "background": "#3B4252", "foreground": "#D8DEE9" },
    "editor": {
      "background": "#2E3440",
      "foreground": "#ECEFF4",
      "cursor": "#88C0D0",
      "selection": "#434C5E",
      "gutterBackground": "#2E3440",
      "gutterForeground": "#4C566A"
    },
    "syntax": {
      "heading": "#88C0D0",
      "marker": "#EBCB8B",
      "code": "#A3BE8C",
      "link": "#81A1C1",
      "muted": "#7B88A1",
      "tokens": { "strong": "#D08770" }
    }
  }
}

최상위 수준#

키필수 여부값
pilcrowAppTheme예형식 버전, 1.
name예1~200자. 설정과 테마 메뉴에 표시됩니다.
appearance예"light", "dark" 또는 "automatic".
colorslight 및 dark 테마팔레트 하나(아래 참고).
light, darkautomatic 테마팔레트 두 개: 하나는 시스템이 라이트 모드일 때, 하나는 다크 모드일 때 사용합니다.
id아니요Pilcrow가 자체 라이브러리용으로 기록합니다. 가져올 때는 무시되며 항상 새 id가 지정됩니다.

appearance는 메뉴, 설정, 시트, 선택기를 포함한 모든 창의 화면 모드를 결정합니다. light 또는 dark 테마는 화면 모드를 고정하고, automatic은 시스템을 따릅니다.

automatic 테마는 각 색상을 light와 dark 모두에서 지정하거나 둘 다 지정하지 않아야 합니다. 한쪽 화면 모드에만 지정한 색상은 다른 쪽에도 그대로 그려지기 때문입니다.

팔레트#

모든 키는 선택 사항입니다. 생략한 색상은 Pilcrow의 기본 모양을 유지하므로 테마는 강조색 하나만으로도 만들 수 있습니다.

키스타일 대상
accent앱 전체의 색조: 버튼, 선택된 세그먼트, 토글, 링크, 포커스 링, 사이드바의 선택된 행. 지정하지 않으면 시스템 강조색을 사용합니다.
sidebar.background, sidebar.foreground파일, 개요, 찾기 사이드바. 보조 레이블은 전경색에서 파생됩니다.
bars.background, bars.foreground상태 막대, 고정된 서식 도구 막대, 가져오기 알림. 보조 레이블은 전경색에서 파생됩니다.
editor.background, editor.foreground편집기 캔버스와 본문 텍스트.
editor.cursor, editor.selection삽입 지점과 선택 영역 강조 표시.
editor.gutterBackground, editor.gutterForeground줄 번호 거터. 배경의 기본값은 편집기 배경입니다.
editor.currentLineRule보기 ▸ 현재 줄 밑줄이 켜져 있을 때 캐럿이 있는 줄 아래의 가는 선. 기본값은 약한 강도의 편집기 텍스트 색상입니다.
syntax.<group>그룹별 실시간 구문 색상(아래 참고).
syntax.tokens.<raw>원시 값으로 지정하는 토큰 하나. 해당 그룹의 색상보다 우선합니다.

구문 그룹#

그룹색상 대상
heading제목(마커와 텍스트), 알림 마커, 정의 용어
marker강조, 굵게, 취소선 및 기타 인라인 구분 기호, 목록 및 작업 마커
code인라인 코드, 펜스 및 들여쓰기 코드 블록, 수식, HTML 블록
link링크와 이미지의 레이블 및 대상, 자동 링크
muted인용 마커, 주제 구분선, 표 행, 주석, 블록 속성
codeKeyword, codeString, codeNumber, codeComment펜스 안의 강조된 코드

지정하지 않은 그룹은 편집기 배경에 맞춰 선택된 기본 제공 색상을 사용합니다. 밝은 캔버스에서는 더 어두운 톤, 어두운 캔버스에서는 더 밝은 톤입니다. syntax.tokens의 토큰 이름에는 영문자, 숫자, _, -를 사용할 수 있으며 그룹 이름과 같을 수 없습니다(syntax.heading이 이미 heading을 포함합니다).

색상#

모든 색상은 sRGB의 16진수 문자열(#RGB, #RGBA, #RRGGBB 또는 #RRGGBBAA)입니다. Pilcrow는 이를 대문자로 저장합니다.

유효성 검사#

Pilcrow는 파일의 일부를 무시하는 대신 파일 전체를 거부하며, 문제가 있는 키를 알려 줍니다. 예: colors.editor.cursor: must be a hex colour. 다음의 경우 거부합니다.

  • pilcrowAppTheme 버전이 없거나 다른 경우
  • 어느 수준에서든 알 수 없는 키가 있는 경우(대개 오타)
  • 화면 모드와 맞지 않는 팔레트 키(automatic 테마의 colors, light 또는 dark 테마의 light와 dark)
  • 16진수가 아닌 색상
  • light와 dark 팔레트가 서로 다른 색상을 지정한 automatic 테마

앱 테마가 바꾸지 않는 것#

창 제목 막대와 도구 막대(강조색만 적용되는 시스템 글라스), 메뉴, 설정, 시트, 선택기는 화면 모드와 강조색을 제외하면 기본 모양을 유지합니다. 서체는 테마로 지정하지 않으며, 편집기 글꼴과 크기는 설정 ▸ 화면 모드 ▸ 텍스트 크기 및 글꼴에서 정합니다.

설치와 공유#

  • .json 파일은 설정 ▸ 라이브러리 ▸ 테마에서 가져오기하거나, Mac에서는 파일 ▸ 가져오기 ▸ 테마, iPad에서는 설정 ▸ 라이브러리 ▸ 가져오기를 사용합니다. 파일을 Pilcrow 위로 끌어다 놓아도 됩니다.
  • .zip 테마 패키지에는 렌더링 테마와 함께 앱 테마를 담을 수 있습니다(Chapter 80).
  • 테마 옆의 공유 버튼은 해당 테마의 .json 파일을 저장하며, 패키지에서 온 테마라면 패키지 전체를 저장합니다.

Pilcrow에는 자동, 라이트, 다크의 앱 테마 세 가지가 포함되어 있습니다. 이 테마들은 편집기와 구문 색상을 지정하고 크롬은 기본 모양 그대로 둡니다.
