제80장

렌더링 테마 CSS 참조

렌더링 테마는 CSS입니다. 미리보기, HTML, PDF, 이미지, 프린트 출력과 이 장 끝에 나열된 Word 스타일의 모양을 지정합니다. 렌더링 테마는 .css 파일 하나일 수도 있고 로컬 에셋이 들어 있는 ZIP 패키지의 일부일 수도 있습니다. 구문 프로필은 소스 텍스트가 문서가 되는 방식을 정의하고, 렌더링 테마는 그 결과의 스타일만 지정합니다. CSS는 앱이나 편집기의 스타일을 지정하지 않으며, 그것은 앱 테마의 역할입니다(Chapter 79).

캐스케이드#

Pilcrow는 다음 순서로 스타일을 적용합니다.

  1. Pilcrow의 구조 재설정
  2. 선택한 테마 CSS
  3. 내보내기 패널의 일회성 CSS(고급 옵션 ▸ 사용자 CSS)
  4. 필수 프린트 및 렌더링 보정

나중 규칙이 일반적인 CSS 캐스케이드에 따라 우선합니다. 테마 JavaScript, 원격 리소스, file: URL, @import는 지원되지 않습니다.

리소스#

Pilcrow는 표준 CSS 토크나이저로 테마 CSS를 읽으므로, 검사하기 전에 이스케이프가 먼저 해석됩니다. u\72 l(…)은 url()이고 @im\70 ort는 @import입니다. 브라우저가 무언가를 불러오는 모든 위치(url(…), url("…"), src("…"), image-set() 안의 문자열)를 검사하며, 각각은 다음 중 하나여야 합니다.

  • 패키지 기준 상대 경로(fonts/Body.woff2, ./paper.png). ?query나 #fragment는 허용되며 파일을 찾을 때는 무시됩니다.
  • PNG, JPEG, GIF, WebP, SVG(image/svg+xml), TTF, OTF, WOFF, WOFF2 형식의 data: URL
  • url(#shadow)처럼 페이지 안의 요소를 가리키는 프래그먼트 참조

data:가 아닌 스킴(https:, file:, blob:)이 붙은 것이나 //로 시작하는 것, /로 시작하거나 ..를 포함하는 경로는 거부됩니다.

공개 수식 클래스에는 pt-heading-1부터 pt-heading-6까지, pt-list--ordered, pt-list--unordered, pt-definition-list--side-by-side, pt-code-block--wrap, pt-code-block--numbered, 표준 pt-admonition--* 값 다섯 가지, 그리고 언어, 원시 형식, 수식 표기법, 다이어그램 형식, 표 섹션 유형, 조건 유형, 매크로 이름에 따른 매개변수화된 클래스가 있습니다. 매개변수화된 접미사는 활성 구문 프로필이나 문서에서 오며, 문장 부호가 들어 있으면 CSS 이스케이프해야 합니다.

Pilcrow는 업데이트에서 클래스와 속성을 추가할 수 있습니다. 문서화되지 않은 래퍼 깊이, 생성된 ID, 추가 클래스가 없다는 가정에 의존하는 선택자는 피하세요.

ZIP 패키지#

ZIP 패키지에는 렌더링 테마(.css)와 앱 테마(.json)를 함께 담을 수 있으며, 각각 설정에서 자신의 종류와 함께 표시됩니다. CSS 파일이 최대 하나이고 앱 테마가 최대 하나인 ZIP에는 매니페스트가 필요 없습니다. 그보다 많으면 모든 테마를 variants[].file 아래에 나열하는 pilcrow-theme.json이 필요합니다. 파일의 확장자가 종류를 결정합니다.

{
  "id": "com.example.paper",
  "name": "Paper",
  "version": "1.0.0",
  "author": "Example Author",
  "license": "MIT",
  "cssAPIVersion": 1,
  "variants": [
    { "id": "app", "name": "Paper", "file": "Paper.json", "appearance": "automatic" },
    { "id": "light", "name": "Paper Light", "file": "Paper-Light.css", "appearance": "light" },
    { "id": "dark", "name": "Paper Dark", "file": "Paper-Dark.css", "appearance": "dark" }
  ]
}

매니페스트는 패키지와 그 테마를 설명하며 스타일 값은 절대 담지 않습니다. 스타일 값은 CSS와 앱 테마 파일에 있습니다.

  • 패키지 id는 설치 폴더의 이름이 됩니다. .으로 시작하거나 앞뒤에 공백이 있으면 안 됩니다. 이미 설치된 id의 패키지를 설치하면 기존 패키지를 대체합니다.
  • Finder의 압축으로 만든 ZIP은 그대로 사용할 수 있습니다. Pilcrow는 __MACOSX/, ._*, .DS_Store, Thumbs.db를 건너뛰며, 모든 파일이 최상위 폴더 하나 안에 있으면 그 폴더를 패키지 루트로 취급합니다.
  • 테마 하나를 삭제하면 패키지에서 그 테마만 제거되고 나머지 테마와 공유 에셋은 유지됩니다. 마지막 테마를 삭제하면 패키지가 제거됩니다. 선택되어 있던 테마를 삭제하면 해당 종류의 기본값으로 선택이 돌아갑니다. 앱 테마는 자동, 렌더링 테마는 라이트입니다.
  • CSS는 상대 url(...) 경로로 패키지 안의 PNG, JPEG, GIF, WebP, TTF, OTF, WOFF, WOFF2 파일을 참조할 수 있습니다. Pilcrow는 파일 시그니처를 확인하고, 참조된 에셋을 데이터 URL로 내장하여 렌더링과 내보낸 HTML이 오프라인에서 독립적으로 유지되게 합니다. ZIP 경로는 패키지를 벗어나거나, 대소문자로 충돌하거나, 링크를 가리킬 수 없습니다. 아카이브 크기, 항목 수, 개별 크기, 압축률에는 제한이 있습니다.

Word#

Word 내보내기는 라이트(기본) :root 값을 사용하며, 다음 의미 속성을 이름이 있는 Word 스타일에 대응시킵니다. --pt-foreground, --pt-background, --pt-accent, --pt-link-color, --pt-code-background, --pt-code-foreground, --pt-body-font-family, --pt-mono-font-family, --pt-base-font-size, --pt-line-height입니다. 브라우저 선택자와 레이아웃 규칙은 Word에 일반적으로 대응하는 것이 없습니다. 미리보기, HTML, PDF, 이미지 출력은 전체 스타일시트를 사용하고, Word는 문서 구조, 다이어그램, 수식 그림, 링크, 미디어를 보존하면서 이 부분 집합을 사용합니다. 내보내기 패널은 Word를 선택할 때마다 이 제한을 표시합니다.

Pilcrow에는 완전한 출발점이 되는 렌더링 테마 두 가지, 라이트와 다크가 포함되어 있습니다.
