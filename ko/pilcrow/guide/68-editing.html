제68장

편집

화면 및 입력#

화면#

컨트롤기능
줄 번호 표시여백에 줄 번호를 표시합니다. 보기 ▸ 줄 번호와 같습니다.
현재 줄 아래에 밑줄 표시캐럿이 있는 줄 아래에 가는 선을 표시합니다.
스타일 적용 소스제목, 굵게, 기울임을 그에 맞는 서체로 그립니다.
제목 접기제목 옆에 접기 화살표를 표시합니다.
렌더링된 블록표, 수식, 다이어그램을 편집 버튼이 있는 그림으로 그립니다.
섹션 자동 펼치기캐럿이 들어오면 접힌 섹션이나 그림 블록을 열고, 캐럿이 나가면 닫습니다.
표식 숨기기캐럿이 있는 줄을 제외한 모든 줄에서 제목, 굵게, 기울임 표시를 숨깁니다. 스타일 적용 소스가 필요합니다.
긴 줄 바꿈끄면 긴 줄이 줄 바꿈 대신 옆으로 스크롤됩니다. 미리보기와 내보내기는 항상 줄 바꿈됩니다. 20,000자 이상의 줄과 집중 모드는 항상 줄 바꿈됩니다.
열 모드에서 짧은 줄열에 닿기에 너무 짧은 줄에서 열이 하는 동작: 줄 끝 사용, 그 줄 제외, 공백으로 부드럽게 채우기(입력한 텍스트가 화면에서 정렬되도록 공백 추가), 공백으로 엄격하게 채우기(부족한 글자마다 공백 하나씩 추가하여 열 번호로 정렬), 또는 그 줄에서 멈추기. 삭제는 짧은 줄에서 글자를 지우지 않습니다.
상태 표시줄 표시하단의 상태 표시줄을 켜거나 끕니다.
서식 도구 막대텍스트 아래에 선택 사항인 도구 막대를 표시합니다.

입력#

컨트롤기능
괄호와 따옴표 자동 짝 맞춤여는 괄호나 따옴표를 입력하면 닫는 것이 추가됩니다.
Markdown 자동 짝 맞춤 ( \* \_ ` ~ ) | Markdown 기호에도 같은 기능을 적용합니다.
이모지 단축 코드 확장(:smile:)입력하는 동안 단축 코드를 이모지로 바꿉니다. 이미 단축 코드가 들어 있는 파일은 작성된 그대로 표시됩니다.
Return 키로 목록과 인용 이어가기Return은 다음 항목을 시작하고, 빈 항목에서 Return을 누르면 목록이 끝나며, Tab은 항목을 들여씁니다.
Return 키로 들여쓰기 유지새 줄이 위 줄과 같은 앞쪽 공백이나 탭으로 시작합니다.
Tab 키로 공백 삽입Tab이 탭 문자 대신 다음 탭 정지 위치까지 탭 너비만큼의 공백을 삽입합니다.

스마트 문장 부호, 강조 표시, 아래 첨자, 위 첨자는 라이브러리 ▸ CommonMark 옵션에 있습니다.

입력 소리#

컨트롤기능
입력할 때 소리 재생키를 누를 때마다 소리가 나며, 스페이스, Return, Delete는 다른 소리가 납니다. 붙여넣기와 실행 취소는 소리가 나지 않습니다. iPad에서는 무음 스위치가 소리를 끕니다.
소리소리 팩: 타자기, 오리, 또는 새끼 고양이.
음량, 미리보기음량을 설정하고 소리 팩을 들어 봅니다.
내 소리원하는 키 종류에 짧은 클립을 선택합니다. 나머지는 위에서 고른 소리를 유지합니다. 종류는 소문자, 대문자, 숫자, 기호 및 구두점, 스페이스, 탭, Return, 삭제입니다. 각각 선택…(또는 변경…), 재생, 제거가 있습니다. 클립은 최대 2초, 3MB(WAV, AIFF, MP3, M4A 또는 CAF)까지 가능하며, 지연 없이 재생되도록 메모리에 저장됩니다.

맞춤법 및 진단#

입력하는 동안 맞춤법 검사는 틀린 철자에 밑줄을 긋습니다. 구문 분석 경고 표시는 닫히지 않은 코드 펜스나 수식 블록, 닫는 괄호가 없는 링크, 머리글과 맞지 않는 표 행처럼 의도와 다를 가능성이 있는 구문이 있는 줄을 표시합니다. 안내는 줄 끝에 나타납니다. 표시되는 내용만 바꾸며 문서를 구문 분석하거나 내보내는 방식은 바꾸지 않습니다.

이미지#

이 설정은 삽입하는 이미지(삽입 ▸ 이미지… 또는 끌어다 놓기)를 어떻게 처리할지 정합니다.

컨트롤기능
동작특별한 동작 없음, 이미지를 현재 폴더로 복사 (./), 이미지를 ./assets로 복사, 또는 이미지를 ./\${filename}.assets로 복사. 이미지 업로드는 사용할 수 없는 항목으로 표시됩니다. Pilcrow에는 이미지 호스트가 없으므로 이미지는 원래 있던 위치 그대로 삽입됩니다.
로컬 이미지에 적용이미 기기에 있는 이미지에 동작을 적용할지 여부입니다.
온라인 이미지에 적용웹 주소를 가리키는 이미지에 적용할지 여부입니다.
인터넷에서 이미지 불러오기끄면 웹 주소를 가리키는 그림이 미리보기, PDF, 이미지 내보내기를 위해 다운로드되지 않으므로 그림을 호스팅하는 사이트가 아무것도 알 수 없습니다. 켜면 웹 브라우저처럼 가져오며 해당 사이트가 요청을 볼 수 있습니다.
가능하면 상대 경로 사용문서를 기준으로 한 상대 경로를 씁니다.
상대 경로에 ./ 추가상대 경로를 ./로 시작합니다.
삽입 시 이미지 URL 이스케이프링크를 깨뜨릴 수 있는 주소의 문자를 이스케이프합니다.
