# Part XVI — Window and menu reference

# Chapter 52: The window at a glance

This chapter names every control in Pilcrow's window, from left to right, on Mac and on iPad. The chapters that follow in this part describe each menu item, and Part XVII describes each panel and dialog.

## The header bar

The header runs across the top of the window. Its controls, in order:

| Control | Where | What it does |
| --- | --- | --- |
| **Navigator** (sidebar icon) | Mac and iPad | Shows or hides the sidebar. Its tooltip reads "Show or hide navigator". Same as **View ▸ Toggle Sidebar**. |
| **Document title** | Mac and iPad | Shows the active document's name, with a dot that tells you whether it is saved. Click it to open the document switcher and the document actions (Chapter 59). |
| **Menu button** or menu strip | iPad only | The Mac's menus, inside the header, for an iPad with no keyboard or mouse (Chapter 58). |
| **Document Mode** (Edit, Preview, Split) | Mac and iPad | Switches between source, rendered page, and both side by side. "Split" is **Side by Side**. |
| **Find** (magnifying glass) | Mac and iPad | Opens the find bar (Chapter 62). |
| **Export** (share icon) | Mac and iPad | Opens the export panel (Chapter 64). |
| **Settings** (gear) | iPad only | Opens Settings in a sheet. On the Mac, Settings is in the **Pilcrow** menu (**⌘,**). |
| **More** (three dots) | Mac and iPad | Holds the actions that do not fit on the bar. See below. |

Find, Export and the mode control appear only while a document is open.

### How the header adapts to width

The header is built to stay usable in a narrow window, such as a Mac window tiled beside another app or an iPad in Split View. As the window gets narrower, controls move into the **More** menu in this order:

| Window width | What you see |
| --- | --- |
| 720 points or wider | Edit/Preview/Split control, **Find**, **Export**, and **More**. |
| 600 to 719 | **Find** moves into **More**. |
| 500 to 599 | **Export** moves into **More** as well. |
| Under 500 | The mode control becomes a single button whose icon shows the current mode (pencil, eye, or two panes). Click it to choose. |

On iPad the mode control becomes the compact button below 580 points. The title always shrinks first, between 140 and 520 points wide, so the buttons stay in place. With larger accessibility text sizes, the window widths above are divided by 1.3 first, so controls move into **More** while the window is still wider.

### The More menu

What **More** offers depends on the mode and the platform. Items that are shown only when the source is visible (Edit or Side by Side) are marked below.

| Item | When it appears | What it does |
| --- | --- | --- |
| **Find…** | Only when the bar has no Find button | Opens the find bar. |
| **Replace…** | Source visible | Opens find with the replace field. |
| **Go to Line…** | Source visible | Jumps to a line, or line and column. |
| **Carets in a Column…** | iPad, source visible | Places carets down a column by number (Chapter 63). |
| **Column Selection** | iPad, source visible | A switch. While on, a one-finger drag selects a rectangle of text. |
| **Share…** | A document is open | Shares the document's file through the system share sheet. |
| **Export…** | Only when the bar has no Export button | Opens the export panel. |
| **Focus** | Always | A switch for Focus Mode (below). |
| **Heading Folds**, **Rendered Blocks**, **Auto-Expand Sections**, **Hide Markers**, **Styled Source**, **Formatting Toolbar** | Source visible | The same display switches as in the View menu (Chapter 55). **Hide Markers** is greyed unless **Styled Source** is on. |
| **Open File…**, **Open Folder…** | iPad | Open a file or a folder when the sidebar is closed. |
| **Print…** | iPad | Prints the rendered document. |
| **Settings…**, **Help** | iPad | Open Settings or the in-app Help. |

## The working area

Under the header is the editor, the preview, or both. Below the editor, when switched on, are the **formatting toolbar** and the **status bar** (Chapter 61). A **backdrop** picture or video can sit behind the editor and the sidebar (Chapter 69).

In **Side by Side**, the source sits beside the preview and scrolls with it. The pane divider can be dragged, and the position is remembered. When the window is narrower than 520 points the two panes stack one above the other instead. When opening the sidebar would leave less than 640 points for the document, the sidebar covers the document rather than squeezing it.

## The sidebar (navigator)

The sidebar can show **Files**, **Outline**, **Search**, **Project** and **Assistant** (Chapter 60). Drag its edge to resize it, between 180 and 420 points wide. In a window narrower than 500 points it fills the whole width, and a **Done** button closes it.

## Focus Mode

**Focus Mode** hides everything but the text. Turn it on from **View ▸ Focus Mode**, from **More ▸ Focus**, or from the command palette. While it is on, an **Exit Focus** button appears so you can leave without a keyboard. Focus Mode always wraps long lines and has its own text column, separate from the one in Settings. It has no default shortcut; assign one in **Settings ▸ Keyboard**.

## When there is no document

With nothing open, the window offers **New Document** and **Open File…** under the heading "Start a document". On iPad, **Open Folder…** is in **More**.

When Pilcrow starts and finds unsaved work from an earlier session, it shows a **Recover Documents** list instead. See Chapter 17 for how recovery works. The list offers **Recover** and **Delete** for each item, and **Recover All** and **Delete All** for the whole list. A document that was never saved cannot be brought back once deleted, so **Delete All** asks first. A **Dismiss** button on the single-document banner declines recovery for that item.

While a large file opens, the window shows "Opening *name*…" with a progress indication.

# Chapter 53: The File menu

On Mac these items are in the **File** menu. On iPad they are in **Menu ▸ File** in the header, or in the menu bar that appears when you hold **⌘** or move the pointer to the top of the screen. Items marked "Mac only" do not exist on iPad.

| Item | Shortcut | What it does |
| --- | --- | --- |
| **New** (iPad: **New Document**) | `⌘N` | Creates an untitled document. It joins the open documents. |
| **Open…** (iPad: **Open File…**) | `⌘O` | Opens a text or markup file from disk. |
| **Open Recent** (Mac only) | | Lists recently opened files. **Clear Menu** empties the list. Shows "No Recent Documents" when the list is empty. |
| **Open Quickly…** (Mac only) | `⇧⌘O` | Searches the filenames in the open folder. Greyed out while no folder is open. |
| **Open Folder…** (iPad header menu and More) | | Opens a folder in the sidebar. On Mac, use the sidebar's own **Open Folder** button. |
| **Browse Enclosing Folder…** | | Asks permission to browse the folder that contains the open file. Pilcrow's sandbox opens a file alone; this adds its folder. Greyed out when the folder is already open or the document has no file. |
| **New Book…** | | Creates a book project folder with its manifest (Chapter 34). |
| **Make Folder a Book Project** | | Writes a `manifest.pilcrow` into the open folder and shows the Project panel (Chapter 34). Greyed out when no folder is open or the folder already has a manifest. |
| **Close Document** (iPad: **Close**) | `⌘W` | Closes the active document, asking first if it has unsaved changes. When Settings is in front, `⌘W` closes Settings instead. |
| **Close All** (iPad) | `⇧⌘W` | Closes every document, asking about each unsaved one. On Mac, the title menu has **Close All Documents**. |
| **Save** | `⌘S` | Saves the document. A new document asks where to save it. |
| **Save All** (Mac only) | `⌥⌘S` | Saves every document with unsaved changes. Greyed out when there are none. |
| **Duplicate** (Mac only) | `⇧⌘S` | Makes a copy and opens it beside the original, which stays unchanged. |
| **Save As…** | `⌥⇧⌘S` | Saves to a new name or place, or in another encoding. Afterwards the document is the new file. |
| **Move To…** (Mac only) | | Moves or renames the file on disk through a save panel (the button reads **Move**), keeping the document open. |
| **Version History…** | | Opens the document's saved versions (Chapter 17 and Chapter 63). |
| **Compare with File…** | | Compares the document with another file and lets you accept or reject each change (Chapter 18). |
| **Reload from Disk** (Mac only) | | Re-reads the file from disk, for use when another app changed it. If you have unsaved changes it asks first: **Save, Then Reload**, **Reload Without Saving**, or **Cancel**. Greyed out for a document with no file. |
| **Show in Finder** (Mac only) | | Reveals the file in Finder. |
| **Import** (Mac only) | | A submenu: **Theme…**, **Syntax Profile…**, **Macro Collection…**, **Style Guide…**. Each adds a file to your library (Chapter 43). On iPad, import is under **Settings ▸ Library ▸ Import**. |
| **Export…** | `⇧⌘E` | Opens the export panel (Chapter 64). |
| **Share…** | | Shares the document's file. |
| **Compile Manuscript…** | | Compiles a book project (Chapter 36). Greyed out until a book project is loaded. |
| **Page Setup…** (Mac only) | | Sets paper, orientation and margins, the same settings PDF export uses. |
| **Print…** | `⌘P` | Prints the rendered document. If the document has unfilled fill-in fields, Pilcrow warns you first. |

# Chapter 54: The Edit menu

The Edit menu holds the system's standard commands and many of Pilcrow's own. Menu items for selection, lines and carets work on the source, so they are greyed out in Preview.

## Undo, clipboard and paste

| Item | Shortcut | What it does |
| --- | --- | --- |
| **Undo**, **Redo** | `⌘Z`, `⇧⌘Z` | Steps back and forward through your edits. |
| **Cut**, **Copy**, **Paste**, **Delete**, **Select All** | | The system's commands. |
| **Copy as Markdown** | `⇧⌘C` | Copies the selection as Markdown source. |
| **Copy as Plain Text** | | Copies the selection with structural markup removed where possible. |
| **Copy as HTML Code** | | Copies the selection's rendered HTML as text. |
| **Paste as Plain Text** | `⇧⌘V` | Pastes without any formatting from the clipboard. |

## Find

**Find** is a submenu.

| Item | Shortcut |
| --- | --- |
| **Find…** | `⌘F` |
| **Replace…** | `⌘R` |
| **Find Next** | `⌘G` |
| **Find Previous** | `⇧⌘G` |

## Spelling and Grammar

On iPad this submenu holds only **Check Spelling While Typing**, the same switch as in Settings. The other two items are Mac only, because an iPad text view has no spelling panel.

| Item | Shortcut | What it does |
| --- | --- | --- |
| **Show Spelling and Grammar** | `⌘:` | Opens the system spelling panel. |
| **Check Document Now** | `⌘;` | Checks the whole document. |
| **Check Spelling While Typing** | | Underlines misspellings as you type. The same switch is in Settings. |

## Transformations and Speech

| Item | What it does |
| --- | --- |
| **Make Upper Case**, **Make Lower Case**, **Capitalize** | Changes the case of the selection, or of the word at the caret. |
| **Start Speaking**, **Stop Speaking** | Reads the selection aloud, or the whole document when nothing is selected. |

## Selection

A submenu of ways to select and move.

| Item | Shortcut | What it does |
| --- | --- | --- |
| **Select Word** | `⌘D` | Selects the word at the caret. |
| **Select Line** | `⌘L` | Selects the whole file line, not the wrapped screen line. |
| **Select Paragraph** | `⌥⌘P` | Selects the paragraph. |
| **Jump to Top**, **Jump to Bottom** | `⌘↑`, `⌘↓` | Moves the caret to the start or end of the document. |
| **Jump to Line Start**, **Jump to Line End** | `⌃A`, `⌃E` | Moves to either end of the line. |
| **Add Caret Above**, **Add Caret Below** | `⌃⇧↑`, `⌃⇧↓` | Adds another caret on the line above or below (Chapter 7). |
| **Select Next Occurrence** | `⌃⌥D` | Adds the next match of the selected text. |
| **Select All Occurrences** | `⌃⌥⇧D` | Selects every match at once. |
| **Next Field**, **Previous Field** | `⌥Tab`, `⌥⇧Tab` | Jumps between fill-in fields a macro left (Chapter 24). Settings has a choice of key pairs for this, called Super Tab keys. |
| **Carets in a Column…** | `⌃⇧G` | Opens a sheet to place carets down a column by number. |

The shortcuts for carets, occurrences, fields and the command palette can be changed in **Settings ▸ Keyboard**.

## Lines

| Item | What it does |
| --- | --- |
| **Sort Lines Ascending**, **Sort Lines Descending** | Sorts the selected lines. |
| **Reverse Lines** | Reverses their order. |
| **Remove Duplicate Lines** | Keeps the first of each repeated line. |
| **Remove Blank Lines** | Deletes empty lines in the selection. |
| **Trim Trailing Whitespace** | Removes spaces and tabs at the ends of lines. |
| **Join Lines** | Joins the selected lines into one. |

## Delete Range

| Item | Shortcut |
| --- | --- |
| **Delete Word** | `⇧⌘D` |
| **Delete Line** | `⌥⇧⌘L` |
| **Delete Paragraph** | `⌥⇧⌘P` |

## Move, translate, navigate

| Item | Shortcut | What it does |
| --- | --- | --- |
| **Move Row Up**, **Move Row Down** | `⌥⌘↑`, `⌥⌘↓` | Moves the current line or selected lines up or down. |
| **Translate ▸ Document**, **Translate ▸ Selection** | | Opens the translate sheet (Chapter 63). |
| **Go to Line…** | `⌃G` | Jumps to a line number, or line and column. |
| **Check Links…** | | Checks the document's links and images (Chapter 19). |
| **Command Palette…** | `⌃⇧P` | Opens the command palette (Chapter 62). |
| **Go Back**, **Go Forward** | `⌃⌘←`, `⌃⌘→` | Retraces the places you jumped between. |

At the bottom, the system adds **Writing Tools**, **AutoFill**, **Start Dictation…** and **Emoji & Symbols**.
