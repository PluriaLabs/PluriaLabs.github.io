# Chapter 72: Tastiera

**Impostazioni ▸ Tastiera ▸ Abbreviazioni** elenca ogni comando di cui puoi cambiare l’abbreviazione, con il tasto attuale.

| Controllo | Cosa fa |
| --- | --- |
| La riga di un comando | Fai clic su di essa, premi la nuova abbreviazione, poi scegli **Salva**. **Rimuovi associazione** elimina l’abbreviazione. **Annulla** mantiene quella precedente. Se l’abbreviazione era già usata da un altro comando, quel comando viene svuotato e la pagina ti dice quale. |
| **Tasti Super Tab** | I tasti per **Campo successivo** e **Campo precedente**, che saltano tra gli spazi vuoti lasciati da una macro: `⌥Tab` e `⌥⇧Tab`, oppure `⌃⌘]` e `⌃⌘[`, oppure **Personalizzato**. |
| **Ripristina tutte le abbreviazioni** | Ripristina tutte le impostazioni predefinite. |

I comandi che puoi cambiare, con le impostazioni predefinite, sono:

| Comando | Predefinito |
| --- | --- |
| Grassetto | `⌘B` |
| Enfasi | `⌘I` |
| Codice in linea | `⌃`` ` `` |
| Formula in linea | `⌃M` |
| Barrato | `⌃⇧`` ` `` |
| Collegamento | `⌘K` |
| Cancella formattazione | `⌘\` |
| Mostra/nascondi barra laterale | `⇧⌘L` |
| Riquadro laterale: Struttura | `⌃⌘1` |
| Documenti aperti | `⌃⌘2` |
| Riquadro laterale: Albero dei file | `⌃⌘3` |
| Riquadro laterale: Cerca | `⇧⌘F` |
| Riquadro laterale: Assistente | `⌃⌘4` |
| Aggiungi cursore sopra | `⌃⇧↑` |
| Aggiungi cursore sotto | `⌃⇧↓` |
| Cursori in una colonna… | `⌃⇧G` |
| Indietro | `⌃⌘←` |
| Avanti | `⌃⌘→` |
| Seleziona l’occorrenza successiva | `⌃⌥D` |
| Seleziona tutte le occorrenze | `⌃⌥⇧D` |
| Campo successivo | `⌥Tab` |
| Campo precedente | `⌥⇧Tab` |
| Riquadro comandi… | `⌃⇧P` |
| Modalità concentrazione | nessuna |

I comandi che non sono in questo elenco, come Salva, Trova e le voci Paragrafo, hanno abbreviazioni fisse. Il Chapter 77 elenca tutte le abbreviazioni.

# Chapter 73: Abbonamento e crediti

Ogni funzione di Pilcrow è gratuita. Sostenere Pilcrow è facoltativo: aiuta a finanziare lo sviluppo e ti dà dei voti su ciò che verrà realizzato dopo. I voti orientano l’ordine del lavoro, ma non garantiscono alcuna funzione.

La pagina **Sostieni Pilcrow** contiene:

| Parte | Cosa mostra o fa |
| --- | --- |
| **I tuoi voti** | **Dal tuo abbonamento** (i voti del mese pagato in corso, con la loro scadenza) e **Acquistati** (voti che non scadono mai). I voti dell’abbonamento vengono usati per primi e scadono alla fine del mese pagato. |
| **Ottieni voti** | L’abbonamento e i voti singoli che puoi acquistare. Pilcrow Supporter si rinnova ogni mese finché non lo annulli nelle impostazioni del tuo Apple Account. Ogni mese pagato ti dà dei voti. |
| **Ripristina acquisti** | Recupera gli acquisti effettuati su un altro dispositivo. |
| **Termini di utilizzo**, **Informativa sulla privacy** | Link. |
| **Icona dell’app** | Una scelta di icone dell’app per gli abbonati. Le icone di un turno di votazione si ottengono abbonandosi durante quel turno e si conservano. Su Mac l’icona cambia nel Dock mentre Pilcrow è aperto. |
| **Roadmap** | Il turno attuale di funzioni aperte al voto, con i conteggi «Voti» e «I tuoi» e un pulsante **Vota** per ciascuna. Ogni voto usa uno dei tuoi voti e non può essere ritirato. Tra un turno e l’altro indica quando si aprirà il prossimo. |

Se le opzioni di sostegno non sono disponibili in una particolare build, la pagina lo dice.
