# Chapter 81: File, codifiche e limiti

## I file che Pilcrow apre

Pilcrow modifica file di testo semplice e di markup. Le estensioni più comuni sono `txt`, `md`, `markdown`, `adoc`, `asciidoc`, `rst` e `tex`, più qualsiasi estensione rivendicata da un profilo che aggiungi. Pilcrow rileva la codifica del testo di un file quando lo apre.

| Elemento | Tipo |
| --- | --- |
| Profilo di sintassi, raccolta di macro, guida di stile, Tema dell’app | `.json` |
| Tema di rendering | `.css` |
| Pacchetto di temi | `.zip` |
| Manifesto del progetto di libro | `manifest.pilcrow` |
| Sfondo | HEIC, PNG, JPEG, SVG, MP4, MOV, M4V |
| Clip dei suoni di digitazione | WAV, AIFF, MP3, M4A, CAF |

## Codifiche del testo

Pilcrow legge testo in UTF-8, UTF-16, UTF-32 e ISO 8859-1 (Latin-1). Puoi convertire un documento con **Informazioni sul documento ▸ Codifica ▸ Converti in…** in una qualsiasi delle seguenti; il file viene convertito al successivo salvataggio:

UTF-8, UTF-8 (BOM), UTF-16 LE, UTF-16 LE (BOM), UTF-16 BE, UTF-16 BE (BOM), UTF-32 LE, UTF-32 LE (BOM), UTF-32 BE, UTF-32 BE (BOM).

Un file Latin-1 può essere convertito in una qualsiasi di queste senza perdite. La conversione in Latin-1 non è offerta, perché può distruggere contenuto.

## Formati di esportazione

| Formato | Estensione |
| --- | --- |
| HTML, HTML (senza stili) | `.html` |
| PDF | `.pdf` |
| Word (.docx) | `.docx` |
| Immagine | `.png` |
| Archivio PDF | `.zip` |

## Limiti e numeri

Dove Pilcrow si ferma, o dove una scelta ha un intervallo:

| Dove | Limite |
| --- | --- |
| Pannello di ricerca | Si ferma a 500 corrispondenze. |
| Trova nell’anteprima | Conta fino a 2.000 corrispondenze. |
| Sostituisci nella cartella | Modifica al massimo 2.000 file alla volta. |
| Controlla i collegamenti | Controlla fino a 50.000 link. |
| Confronta | Mostra fino a 5.000 righe modificate. |
| Versioni da conservare | Da nessuna a 500 (predefinito 50). |
| Righe lunghe | Le righe di 20.000 caratteri o più vanno sempre a capo. |
| Dimensione carattere | Da 9 a 32 punti. |
| Larghezza tabulazione | Da 2 a 8 spazi. |
| Larghezza del testo | Dal 50% al 100%. |
| Zoom | Dal 50% al 200%, in dieci passi. |
| Velocità di lettura | Da 60 a 2.000 parole al minuto. |
| Larghezza del navigatore | Da 180 a 420 punti. |
| Clip dei suoni di digitazione | Al massimo 2 secondi e 3 MB. |
| Testo del log del rapporto diagnostico | Le voci più recenti, fino a 60.000 caratteri, quando viene aggiunto alla descrizione di una segnalazione su GitHub. |
| File molto grandi | Si aprono e si modificano senza essere letti per intero in memoria. I conteggi di righe e parole e la struttura vengono completati in background e fino ad allora possono essere parziali. L’esportazione PDF di un documento molto grande richiede molta più memoria della modifica o dell’esportazione in HTML e Word; Archivio PDF lo suddivide in parti limitate. |

## Dove Pilcrow conserva i dati

| Che cosa | Dove |
| --- | --- |
| I tuoi documenti | Dove li hai salvati. |
| Libreria (temi, profili, macro, guide di stile, sfondi) | Nell’archivio privato dell’app, oppure in una cartella chiamata “Pilcrow Library” all’interno di una cartella che scegli (**Impostazioni ▸ Libreria ▸ Posizione**). |
| Preferenze, chiavi API, copie di recupero, cronologia delle versioni | Sul dispositivo, nell’archivio privato dell’app e nel Portachiavi. Controllale ed eliminale in **Impostazioni ▸ Generali ▸ Archiviazione e privacy**. |
| Log diagnostico | Sul dispositivo, finché non lo cancelli. |

# Chapter 82: Messaggi, banner e stati vuoti

Questo capitolo spiega i brevi messaggi che Pilcrow mostra, così nessuno di essi resta un mistero.

## Nell’editor e nell’anteprima

| Messaggio | Che cosa significa |
| --- | --- |
| **Ancora niente da mostrare nell’anteprima. Inizia a scrivere e apparirà qui.** (oppure “Passa a Modifica e inizia a scrivere.”) | Il documento è vuoto, quindi non c’è nulla da disegnare nell’Anteprima. |
| **L’anteprima non è riuscita a eseguire il rendering: …** con **Mostra sorgente** e **Riprova** | L’anteprima non è riuscita. **Mostra sorgente** passa a Modifica. **Riprova** ritenta. |
| Un’equazione o un diagramma non riusciti, con un link **Mostra sorgente** | Un blocco non ha potuto essere disegnato. Fai clic su **Mostra sorgente** per passare al sorgente di quel blocco e correggerlo. |
| **Impossibile salvare** con **Riprova** e un pulsante per chiudere | Il salvataggio non è riuscito. Il documento resta aperto e non salvato. Risolvi la causa (spazio su disco, permessi, un file spostato) e scegli **Riprova**. |
| **File modificato sul disco** | Un’altra app ha modificato il file. **Ricarica** legge la nuova versione; **Mantieni la versione attuale** conserva ciò che hai. |
| **Avviso di analisi** | Una riga in cui un costrutto probabilmente non è ciò che intendevi (Chapter 68). |
| **Sostituire il file esistente?** | Il nome che hai scelto è già in uso in quel punto. |
| **Restano campi da compilare** | Stai stampando o esportando con campi non compilati (Chapter 63). |
| **Divisore dei pannelli** (suggerimento VoiceOver: “Trascina per ridimensionare l’editor e l’anteprima. Tocca due volte per ripristinare.”) | La maniglia tra sorgente e anteprima in Affiancato. |
| **Parole: N** | Il conteggio parole nella barra di stato. |

## Nelle finestre di dialogo e nei pannelli

| Dove | Messaggio | Significato |
| --- | --- | --- |
| Palette dei comandi | **Digita un comando** | Il suggerimento del campo. “Nessun comando corrispondente” appare quando nulla corrisponde. |
| Apri rapidamente | **Digita un nome file** | Il suggerimento del campo. |
| Cursori in una colonna | **Righe (per esempio 3-17)**, **Colonna (per esempio 100, oppure 100-105 per selezionare)** | Suggerimenti dei campi. Una singola colonna posiziona i cursori; un intervallo seleziona quei caratteri su ogni riga. |
| Pannello di ricerca | **Digita per cercare in questa cartella.**, **Nessuna corrispondenza in questa cartella.**, **Ricerca annullata.** | Lo stato di una ricerca nella cartella. |
| Pannello File | **Puoi anche trascinare qui una cartella.** | Trascina una cartella sul pannello per aprirla. |
| Sostituisci nella cartella | **Niente da sostituire.** | La ricerca non ha corrispondenze. |
| Confronta | Descrizioni sui pulsanti: **Accetta** (“Applica questa modifica al documento aperto”), **Rifiuta** (“Lascia fuori questa modifica dal documento aperto”), **Rimetti** (“Rimette nel documento le righe precedenti solo per questa modifica”). | Che cosa fa ciascuno. |
| Traduci | **Non è stato possibile completare la traduzione.** | Riprova, oppure scegli un’altra velocità. |
| Traduci | **Tempo stimato: meno di un minuto** | Una stima per la velocità dell’assistente IA; il tempo dipende dal tuo servizio IA. Dopo una traduzione, **Apri in una nuova scheda** apre il risultato. |
| Assistente | **Nessun documento aperto.**, **Nessun testo del documento viene inviato.** | Il pannello non ha nulla da condividere, quindi non viene inviato nulla. |
| Selettore del modello | **Caricamento dei modelli…**, **Nessun modello corrisponde.** | L’elenco è in caricamento, oppure la tua ricerca non ha trovato nulla. |
| Revisione dello stile | **Nessun rilievo.** e **Non è stato possibile leggere la risposta come rilievi. Riprova.** | La revisione non ha trovato nulla, oppure la risposta dell’IA non era nella forma prevista. |
| Revisione dello stile | Descrizione di **Applica tutto**: “Applica ogni correzione che ne ha una, come un’unica modifica che puoi annullare.” | Un solo Annulla le ripristina tutte. |
| Pannello Progetto | **Il tuo nome**, **Aggiungi variabile** | Il suggerimento del campo Autore e il pulsante per una variabile di progetto. |
| Autorizzazione dell’assistente | **Leggi l’informativa sulla privacy di Pilcrow** | Apre l’informativa sulla privacy. |
