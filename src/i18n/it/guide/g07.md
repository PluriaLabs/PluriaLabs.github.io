# Chapter 60: La barra laterale

La barra laterale contiene cinque pannelli: **File**, **Struttura**, **Cerca**, **Progetto** e **Assistente**. Un selettore in cima alla barra laterale sceglie **File**, **Struttura**, **Progetto** (mostrato quando la cartella aperta è un progetto di libro) o **Assistente** (mostrato quando è stata configurata una connessione). **Cerca** ha una propria intestazione con il titolo **Trova**, un pulsante **Fine** che riporta a File e un controllo dell'ambito per **Questo documento** o **Cartella**; si raggiunge da **Vista ▸ Cerca** (`⇧⌘F`). Anche il menu **Vista** cambia pannello, e scegliere il pannello già visibile nasconde la barra laterale. Trascina il bordo della barra laterale per ridimensionarla. Sopra l'albero dei file, un menu offre **Apri file…** e **Apri cartella…**.

## File

Il pannello File è un albero della cartella aperta.

Senza una cartella aperta, mostra «Scegli una cartella per esplorarne i file.» e offre **Apri cartella** e **Apri file**. Puoi anche trascinarvi sopra una cartella. Quando hai aperto un singolo file la cui cartella Pilcrow non può vedere, offre «Esplora *cartella* per vedere i file accanto a questo documento», con **Esplora la cartella contenitore…**.

Fai clic su un file per aprirlo. Le cartelle si espandono e si comprimono. Fai clic con il tasto destro su una riga, oppure tieni premuto su iPad, per aprirne il menu:

| Voce | Cosa fa |
| --- | --- |
| **Nuovo file** | Crea un file nella cartella (o accanto al file su cui hai fatto clic). |
| **Nuova cartella** | Crea lì una cartella. |
| **Rinomina…** | Rinomina il file o la cartella. |
| **Sposta nel Cestino** | Lo sposta nel Cestino dopo la tua conferma. Da lì puoi rimetterlo a posto. |
| **Mostra nel Finder** | Lo mostra nel Finder (Mac). |

Dove il sistema non ha un Cestino per una posizione, Pilcrow conserva gli elementi eliminati in una sezione **Eliminati di recente** in fondo al pannello. Ogni elemento lì offre **Ripristina** ed **Elimina definitivamente**, e **Svuota Eliminati di recente** rimuove per sempre tutti gli elementi della sezione. L'eliminazione definitiva non si può annullare, quindi Pilcrow chiede prima conferma. Gli elementi che hai eliminato da altre posizioni non sono interessati.

Le cartelle e i file nascosti si mostrano o si nascondono con **Impostazioni ▸ File ▸ Mostra cartelle e file nascosti**.

## Struttura

La Struttura elenca i titoli del documento attivo, con rientro in base al livello. Fai clic su un titolo per saltarvi. Una freccia accanto a un titolo comprime o espande i titoli annidati sotto di esso. Questo non modifica il documento, e lo stato di compressione non viene salvato.

Stati che puoi incontrare:

| Messaggio | Significato |
| --- | --- |
| **Nessun titolo** | Il profilo attivo non ha trovato titoli. |
| **Indicizzazione della struttura… N%** | Un documento grande è ancora in fase di scansione. |
| **Indicizzazione della struttura non riuscita. L'elenco potrebbe essere incompleto.** | La scansione ha incontrato un problema. |
| **N titoli vicino alla tua posizione — scorri per vedere gli altri.** | Un documento molto grande mostra una finestra della sua struttura attorno al cursore. |

Sotto la struttura compare una sezione **Campi** quando il documento ha campi da compilare (Chapter 24). Li elenca, con un conteggio; fai clic su uno per scorrere fino a esso e selezionarlo. Se i campi sono moltissimi, dice «Sono elencati solo i primi campi.»

## Cerca

Il pannello Cerca cerca in tutti i file della cartella aperta. Senza una cartella dice «Apri una cartella per cercarvi.» con un pulsante **Apri cartella…**.

| Controllo | Cosa fa |
| --- | --- |
| Campo **Cerca nella cartella** | Scrivi per cercare mentre digiti. Un pulsante **cancella** lo svuota. |
| **Aa** | **Maiuscole/minuscole.** |
| **ab** | **Parola intera.** |
| **.\*** | **Espressione regolare.** Un modello errato viene segnalato sotto il campo. |
| Riga di stato | Mostra «Ricerca in corso…» con un pulsante **Annulla**, poi «Risultati: N». La ricerca si ferma a 500 risultati e dice «Mostro i primi 500 risultati.» Dopo un annullamento offre **Cerca di nuovo**. |
| **Sostituisci…** | Compare quando la ricerca trova risultati. Apre Sostituisci nella cartella (Chapter 63). |
| Risultati | Ogni risultato indica il file e mostra la riga. Fai clic su uno per aprire il file a quella riga. |

## Progetto

Il pannello Progetto è per i progetti di libro. Vedi Chapter 34, Chapter 35 e il riferimento del pannello Progetto qui sotto.

### Riferimento del pannello Progetto

| Parte | Cosa fa |
| --- | --- |
| **Questa cartella non è un progetto di libro.** con **Rendila un progetto** | Mostrato quando la cartella aperta non ha un manifesto. |
| **Riprova** | Mostrato se non è stato possibile leggere il progetto. |
| **Vista** | Sceglie **Elenco**, **Sinossi** o **Schede**. |
| Titolo, totali di parole | Il nome del progetto e «N parole», oppure «N di obiettivo» quando è impostato un obiettivo di parole del libro. |
| Filtro **Stato** | Filtra per un solo stato, oppure **Tutti gli stati**. Un riepilogo elenca ogni stato con il numero di file e di parole. Il riordino è disponibile solo quando nessun filtro è attivo. |
| **Impostazioni del progetto** (ingranaggio) | Apre il pannello delle impostazioni descritto sotto. |
| **Compila…** | Apre il pannello di compilazione (Chapter 64). |
| **Riordina** e **Fine** | Su iPad, trascina i capitoli in un nuovo ordine, poi scegli **Fine**. |
| **Nuovo file** (più) | Offre **Nuovo capitolo**, **Nuova scena**, **Nuove parti iniziali**, **Nuove parti finali**. |
| **Non nel manoscritto** con **Aggiungi** e **Aggiungi tutto** | Elenca i file nella cartella che il manifesto non include. |
| La freccia di una riga | **Mostra scene** o **Nascondi scene** sotto un capitolo. |
| Etichette **Mancante** ed **Escluso** | Un file che non si trova, oppure che hai escluso dal manoscritto. |
| Il menu di una riga | **Dettagli…**, **Nuovo file sotto**, **Sposta il capitolo in alto**, **Sposta il capitolo in basso**, **Includi nel manoscritto**, **Escludi dal manoscritto**. |
| **Obiettivo di parole** per elemento | Ogni elemento mostra le sue parole e l'eventuale obiettivo. |

**Dettagli** di un elemento comprende **Tipo** (Parti iniziali, Parte, Capitolo, Scena, Parti finali), **Stato**, **Punto di vista**, **Posizione**, **Obiettivo di parole** e **Sinossi**. Un file di progetto modificato sul disco mostra «Il file del progetto è cambiato sul disco, quindi la tua ultima modifica non è stata applicata. Riprova.» con **Ignora**.

**Impostazioni del progetto** comprende **Titolo**, **Autore**, **Obiettivo di parole del libro**, **I nuovi file sono scritti in** (la sintassi per i nuovi capitoli e scene; i file esistenti mantengono la propria), **Variabili** (un nome e un valore, scritti come `{{name}}` nel testo; `{{title}}` e `{{author}}` funzionano sempre) e **Cosa conta come parola**: **Conta i titoli**, **Conta le parti iniziali**, **Conta i blocchi di codice**. Scegli **Salva** o **Annulla**.

## Assistente

Il pannello Assistente compare quando è stata configurata una connessione (Chapter 65).

# Chapter 61: La barra di formattazione e la barra di stato

## La barra di formattazione

La barra di formattazione è una riga facoltativa sotto il testo. Mostrala o nascondila con **Vista ▸ Barra di formattazione**, **Altro ▸ Barra di formattazione**, **Impostazioni ▸ Modifica ▸ Barra di formattazione**, oppure con la voce **Nascondi barra strumenti** della barra stessa. Agisce tramite il profilo attivo, quindi un pulsante che il profilo non sa esprimere è disattivato.

| Controllo | Cosa fa |
| --- | --- |
| Menu **Tipo di paragrafo** (per esempio «Paragrafo» o «Titolo 1») | Mostra il tipo della riga corrente e lo cambia: **Paragrafo**, **Titolo 1** fino a **6**, **Citazione**, **Elenco puntato**, **Elenco numerato**, **Elenco attività**, **Blocco di codice**. |
| **Grassetto** (`⌘B`) | Strong. |
| **Corsivo** (`⌘I`) | Enfasi. |
| **Codice in linea** | Codice. |
| **Inserisci link** (`⌘K`) | Crea un link. |
| **Citazione** | Attiva o disattiva una citazione. |
| **Elenco puntato** | Attiva o disattiva un elenco puntato. |
| **Altra formattazione** (**⋯**) | I comandi meno usati: **Barrato**, **Inserisci formula in linea**, **Inserisci elenco attività**, **Attiva/disattiva stato attività**, **Aumenta rientro**, **Riduci rientro**, **Aumenta livello titolo**, **Diminuisci livello titolo**, **Inserisci tabella…**, **Inserisci immagine…**, **Inserisci diagramma**, **Inserisci grafico**, **Inserisci formula in evidenza**, **Inserisci blocco di codice**, **Inserisci avviso**, **Inserisci linea orizzontale**, **Inserisci riferimento link**, **Inserisci nota a piè di pagina**, **Inserisci indice**, **Inserisci front matter YAML** e **Nascondi barra strumenti**. |

## La barra di stato

La barra di stato corre lungo il fondo. Attivala o disattivala con **Impostazioni ▸ Modifica ▸ Mostra barra di stato**.

| Parte | Cosa mostra o fa |
| --- | --- |
| **Parole**, **Rg**, **Col** | Il conteggio delle parole, e la riga e la colonna del cursore. Con una selezione aggiunge «Sel: N rg · N car» per le righe e i caratteri selezionati. |
| Menu **Sintassi** (per esempio «CommonMark») | Il profilo di questo documento. Fai clic per sceglierne un altro, oppure **Nessuna sintassi** per il testo semplice. |
| **Campi rimasti: N** | Mostrato quando una macro ha lasciato campi da compilare. Fai clic per saltare al campo successivo. |
| Avanzamento e stato | **Indicizzazione N%**, **Analisi lessicale N%** mentre un file grande viene analizzato, e **Traduzione N%** con **Circa N rimanenti** e un pulsante **Annulla traduzione** mentre è in corso una traduzione. |
| **Non sincronizzato** | Un avviso che l'editor e il registro delle modifiche del documento sono divergenti. Il salvataggio lascia il file contrassegnato come non salvato, così non si perde nulla: copia il testo in un posto sicuro, poi chiudi e riapri il documento. |
| Informazioni sul documento | Fai clic sui conteggi, o sul suggerimento «Mostra informazioni sul documento», per aprire **Informazioni sul documento**. |

**Informazioni sul documento** elenca **Parole**, **Caratteri**, **Righe**, **Tempo di lettura** (basato sulla tua velocità di lettura in Impostazioni), **Cursore**, **Selezione**, **Codifica** e **Sintassi**. In un file molto grande i conteggi riguardano la parte caricata finché l'indicizzazione non termina, e il tempo di lettura è stimato per l'intero file. **Converti in…** sotto **Codifica** sceglie un'altra codifica del testo; il file viene convertito al successivo salvataggio.


# Chapter 62: Trova, sostituisci, Vai alla riga, Apertura rapida e riquadro comandi

## La barra di ricerca

Aprila con **Trova…** (`⌘F`), il pulsante **Trova**, oppure **Sostituisci…** (`⌘R`). Si trova in cima al documento.

| Controllo | Cosa fa |
| --- | --- |
| Campo **Trova nel documento** | Scrivi il testo da trovare. I risultati vengono evidenziati mentre digiti. |
| **Aa**, **ab**, **.\*** | **Maiuscole/minuscole**, **Parola intera**, **Espressione regolare**. |
| **Risultato precedente**, **Risultato successivo** | Scorrono i risultati (`⇧⌘G`, `⌘G`). |
| **Mostra sostituzione** / **Nascondi sostituzione** (freccia) | Mostra il campo **Sostituisci con**. |
| **Sostituisci**, **Sostituisci tutto** | Sostituisce il risultato corrente, oppure tutti. Disattivati finché non c'è un risultato. |
| **Cerca in** (un selettore all'estremità sinistra della barra) | **Questo documento**, oppure **Cartella** per cercare invece in tutta la cartella aperta. |
| **Chiudi barra di ricerca** | La chiude. |

Quando ci sono più risultati di quanti Pilcrow ne conti, la barra dice «Ci sono altri risultati». In **Anteprima**, Trova cerca tra le parole renderizzate e le evidenzia, fino a 2.000 risultati. Un modello che non si può usare dice «Modello non valido». Sostituisci è disponibile solo in Modifica: in Anteprima la barra dice «Sostituisci funziona in Modifica. Passa a Modifica per cambiare il testo.» In **Affiancato**, Trova cerca nel sorgente ed evidenzia le parole corrispondenti nell'anteprima.

## Vai alla riga

**Vai alla riga…** (`⌃G`) apre un piccolo pannello con un solo campo, «Numero di riga, o riga:colonna». Scrivi `120` o `120:8` e scegli **Vai**, oppure **Annulla**. Un numero oltre la fine porta all'ultima riga. Per qualsiasi altra cosa Pilcrow dice «Inserisci un numero di riga, come 120 o 120:8.» In un file molto grande di cui le righe sono ancora in conteggio, ti chiede di riprovare tra un momento.

## Apertura rapida

**Apertura rapida…** (`⇧⌘O`) è una ricerca di nomi di file nella cartella aperta. Scrivi una parte del nome, e l'elenco si restringe e mostra «N risultati». Scegli un risultato e **Apri**, oppure **Annulla**. È disattivata senza una cartella aperta.

## Il riquadro comandi

**Riquadro comandi…** (`⌃⇧P`) elenca i comandi di Pilcrow per nome, con le loro scorciatoie, così puoi eseguirne uno senza cercare il suo menu. Scrivi per restringere l'elenco, scegli un comando e **Esegui**, oppure **Annulla**. Mostra «Nessun comando corrispondente» quando nulla corrisponde. Un comando che al momento non può essere eseguito, come una modifica al sorgente mentre sei in Anteprima, appare disattivato. L'elenco comprende i comandi di formattazione e di inserimento, i comandi di Modifica per selezione, righe e maiuscole/minuscole, la sintesi vocale, i selettori di Vista, lo zoom e i pannelli della barra laterale, e le azioni sui file e di esportazione. La scorciatoia per aprire il riquadro si può cambiare in **Impostazioni ▸ Tastiera**.
