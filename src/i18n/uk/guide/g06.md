# Chapter 55: Меню «Вигляд» і «Вікно»

Меню «Вигляд» керує панелями, режимом, розміром і відображенням редактора. Його скорочення можна змінити в **Параметри ▸ Клавіатура**, окрім зазначених випадків.

## Панелі та режим

| Пункт | Скорочення | Що він робить |
| --- | --- | --- |
| **Панель форматування** | | Показує або ховає необов’язковий рядок кнопок форматування під текстом. Неактивний у режимі «Перегляд». |
| **Показати або сховати бічну панель** | `⇧⌘L` | Показує або ховає всю бічну панель. |
| **Структура** | `⌃⌘1` | Показує панель «Структура». Повторний вибір ховає бічну панель. |
| **Файли** | `⌃⌘3` | Показує панель «Файли» (дерево файлів). |
| **Пошук** | `⇧⌘F` | Показує панель пошуку в папці. |
| **Асистент** | `⌃⌘4` | Показує панель «Асистент». З’являється лише після налаштування підключення асистента. |
| **Перегляд** | `⇧⌘P` | Перемикає на відображену сторінку. |
| **Поруч** | `⌃⌘P` | Показує джерело й перегляд разом. |
| **Режим фокусу** | немає | Ховає все, крім тексту. |

## Розмір

| Пункт | Скорочення |
| --- | --- |
| **Фактичний розмір** | `⇧⌘0` |
| **Збільшити** | `⇧⌘=` |
| **Зменшити** | `⇧⌘-` |

Масштаб змінюється за наперед заданими рівнями й запам’ятовується. Він масштабує редактор і перегляд.

## Відображення редактора

Кожен із цих пунктів — перемикач. Ті самі перемикачі є в **Параметри ▸ Редагування** (Chapter 68).

| Пункт | Скорочення | Що він робить |
| --- | --- | --- |
| **Номери рядків** | `⌥⌘L` | Показує номери рядків на полі. |
| **Лінія поточного рядка** | | Малює тонку лінію під рядком, у якому розташований курсор. Колір лінії береться з теми програми. |
| **Переносити рядки** | | Переносить довгі рядки на краю вікна. Коли вимкнено, вони прокручуються вбік. Дуже довгі рядки та режим фокусу переносяться незалежно від цього. |
| **Джерело зі стилями** | | Малює заголовки, напівжирний і курсивний текст відповідним накресленням, у вигляді синтаксису, замість звичайного джерела. |
| **Сховати маркери** | | Коли ввімкнено «Джерело зі стилями», ховає позначки заголовків, напівжирного та курсиву (`#`, `**`) в усіх рядках, окрім того, де розташований курсор. Неактивний, коли «Джерело зі стилями» вимкнено. |
| **Відображені блоки** | | Малює таблиці, рівняння та діаграми як картинки замість їхнього джерела, кожну з кнопкою редагування. |
| **Згортання заголовків** | | Додає шеврон згортання на полі поруч із кожним заголовком, щоб його розділ можна було згорнути, у будь-якому профілі синтаксису. |
| **Згорнути все**, **Розгорнути все** | | Згортає або розгортає розділ кожного заголовка. Неактивний, доки не ввімкнено «Згортання заголовків». |
| **Автоматично розгортати розділи** | | Відкриває згорнутий розділ або блок, намальований як картинка, коли курсор у нього потрапляє, і закриває його знову, коли курсор іде. Коли вимкнено, стрілки вгору й вниз переступають через нього, а він лишається як є. |

## Тема

**Вигляд ▸ Тема** вибирає **Тему програми** (Автоматично, Світла, Темна) і **Тему відображення** (Світла, Темна) із позначкою. Теми, які ви додаєте, теж з’являються тут. Див. Chapter 40.

Система також додає **Увійти в повноекранний режим**.

## Меню «Вікно»

| Пункт | Скорочення | Що він робить |
| --- | --- | --- |
| **Відкриті документи** | `⌃⌘2` | Відкриває перемикач документів. |
| **Наступний документ**, **Попередній документ** | `⌃Tab`, `⌃⇧Tab` | Перебирає відкриті документи по колу. Неактивний, коли відкрито менше двох. |

Меню «Вікно» також містить системні команди вікон і перелічує кожен відкритий документ за назвою. На iPad ці три пункти розташовані в кінці меню «Вигляд».

# Chapter 56: Меню «Вставити»

Усе в меню «Вставити» вставляє в документ біля курсора джерело, записане власною нотацією активного профілю синтаксису. Пункти, які профіль не може виразити, неактивні, а в режимі «Перегляд» вимкнено кожен пункт.

| Пункт | Що він робить |
| --- | --- |
| **Таблиця…** | Відкриває діалог «Вставити таблицю» (Chapter 63). Скорочення `⌥⌘T`. |
| **Зображення…** | Вибирає зображення й вставляє його, застосовуючи налаштування зображень (Chapter 68). Скорочення `⇧⌘I`. |
| **Діаграми** | Підменю готових діаграм Mermaid (нижче). |
| **Графіки** | Підменю готових графіків Vega-Lite (нижче). |
| **Рівняння** | Підменю готових рівнянь (нижче). |
| **Огородження коду** | Вставляє блок коду в огородженні. |
| **Сповіщення** | Підменю: **Примітка**, **Порада**, **Важливо**, **Попередження**, **Обережно**. |
| **Горизонтальна лінія** | Вставляє тематичний розрив. |
| **Довідкове посилання** | Вставляє посилання довідкового стилю та його визначення. |
| **Виноска** | Вставляє позначку виноски та її визначення. |
| **Зміст** | Вставляє рядок `[TOC]`, який стає згенерованим списком змісту. |
| **Вступ YAML** | Вставляє блок вступу на початку файлу. |
| **Поле** | Вставляє порожнє місце для заповнення для Super Tab, виділене, щоб ви могли його назвати (Chapter 24). |

Нижче розташований роздільник, а за ним — **власні конструкції активного профілю**, наприклад застереження або власний блок, який визначає профіль. Якщо профіль не вибрано, меню повідомляє «Виберіть профіль синтаксису, щоб вставляти конструкції».

## Шаблони діаграм

## Шаблони графіків

Стовпчастий графік, Лінійний графік, Графік із областями, Діаграма розсіювання, Кругова діаграма, Складений стовпчастий графік, Гістограма, Теплова карта та Діаграма «ящик із вусами».

# Chapter 57: Меню «Формат»

Меню «Формат» застосовує стилі до виділеного або до рядка, у якому розташований курсор, через активний профіль синтаксису. Якщо в профілі немає способу записати стиль, пункт неактивний разом зі своїм скороченням, тож команда ніколи не вставляє синтаксис, якого профіль не прочитає назад. У режимі «Перегляд» кожен пункт вимкнено.

## Смуга меню iPad

iPad має власний рядок меню, який показується, коли ви утримуєте **⌘** або підводите вказівник до верху екрана. Він містить ті самі команди, що й меню Mac, з тих самих визначень, з тими самими змінюваними скороченнями. Відрізняється лише **Файл**, бо меню «Файл» на Mac використовує панелі AppKit.

Для iPad без клавіатури чи миші Pilcrow може показувати ті самі меню у своєму заголовку. **Параметри ▸ Вигляд ▸ Меню в заголовку** пропонує вибір:

| Вибір | Наслідок |
| --- | --- |
| **Автоматично** | Показує меню, якщо не підключено клавіатуру чи мишу. |
| **Завжди** | Завжди показує їх. |
| **Ніколи** | Ніколи не показує їх. |

У вікні завширшки 1100 пунктів або більше шість меню розташовані поруч: **Файл**, **Редагувати**, **Вставити**, **Формат**, **Вигляд** і **Довідка**. У вужчому вікні вони згортаються в одну кнопку **Меню**. Смуга — полегшена версія рядка меню:

- **Файл** додає **Відкрити папку…**, **Експортувати…** і **Друк…** до звичайних пунктів.
- **Редагувати** містить **Скасувати**, **Повторити**, команди копіювання, **Знайти**, **Правопис і граматика**, **Виділення**, **Перекласти**, **Перейти до рядка…**, **Перевірити посилання…**, **Палітра команд…**, **Назад** і **Уперед**.
- **Формат** містить вбудовані стилі, підменю **Абзац**, **Вставити таблицю…** і **Вставити зображення…**.
- **Вигляд** містить **Панель форматування**, **Показати або сховати бічну панель**, **Структура**, **Файли**, **Пошук**, режим документа, **Фокус**, **Номери рядків**, **Лінія поточного рядка**, **Джерело зі стилями**, **Згортання заголовків** і **Відкриті документи**. Для решти перемикачів відображення скористайтеся **Більше** або «Параметрами».
- **Довідка** містить **Довідка Pilcrow**, **Повідомити про помилку…** і **Завершити звіт про помилку**.

# Part XVII — Панелі, рядки й діалоги

# Chapter 59: Назва документа та перемикач документів

Назва документа розташована в заголовку з малою кольоровою крапкою та стрілкою вниз. Клацніть її або виберіть **Вигляд ▸ Відкриті документи** (`⌃⌘2`), щоб відкрити список **Відкриті документи**. На малому екрані він відкривається як аркуш із кнопкою **Готово**.

## Крапка збереження

Крапка поруч із назвою з першого погляду повідомляє стан документа. Стан також озвучує VoiceOver.

| Крапка | Значення |
| --- | --- |
| Зелена | **Збережено.** Файл на диску збігається з тим, що ви бачите. |
| Бурштинова | **Змінено.** У вас є зміни, які ще не збережено. |
| Червона | **Не вдалося зберегти.** Pilcrow спробував зберегти й не зміг. Над редактором з’являється банер **Не вдалося зберегти** із кнопкою **Повторити**. |
| Синя | **Змінено іншою програмою.** Файл на диску змінено ззовні Pilcrow. |

Документ, який ніколи не зберігали, показує «Ще не збережено» і число в списку, бо в нього немає папки, яку можна показати. Документ із незбереженими змінами також має в кінці свого рядка слово **Змінено**.

## Список «Відкриті документи»

| Частина | Що вона робить |
| --- | --- |
| **Шукати у відкритих документах** | З’являється, коли відкрито сім або більше документів. Введіть частину назви чи папки; кожне слово має збігатися десь у назві або в папці, без урахування регістру й наголосів. Return відкриває перший збіг. Коли нічого не збігається, показує «Немає відкритих документів, що збігаються.» |
| Рядок для кожного документа | Показує назву, його крапку збереження та папку, у якій він розташований. Позначка-галочка вказує активний документ. Клацніть рядок, щоб перейти до нього. |
| **Закрити** (**x** у кінці рядка) | Закриває цей документ, спершу питаючи, якщо в ньому є незбережені зміни. |
| **Новий документ** | Створює документ без назви. |
| **Зберегти** | Зберігає активний документ. |
| **Зберегти як…** | Зберігає під новою назвою чи в нове місце. |
| **Перейменувати…** | Відкриває форму перейменування (нижче). |
| **Закрити всі документи** | Закриває кожен документ, питаючи про кожен незбережений. |

Скористайтеся `⌃Tab` і `⌃⇧Tab`, щоб перейти до наступного чи попереднього документа без відкриття списку.

## Перейменування

**Перейменувати…** показує поточну **Назву** та **Де** розташований файл, із кнопками **Скасувати** й **Перейменувати**. Перейменування змінює файл на диску й залишає документ відкритим. Якщо нову назву не можна використати, повідомлення **Не вдалося перейменувати документ** пояснює причину.
