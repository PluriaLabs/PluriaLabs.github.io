# Part XIX — Редактори елементів бібліотеки

# Chapter 74: Редактор профілю та будівельні блоки профілю

Профіль синтаксису повідомляє Pilcrow, що означає ваша розмітка. Цей розділ описує редактор профілю елемент за елементом, а потім перелічує всі будівельні блоки, які може використовувати профіль. Вступ, побудований на завданнях, дивіться в Chapter 37 — Chapter 39.

Відкрийте редактор через **Параметри ▸ Бібліотека ▸ Профілі синтаксису**: **Новий** створює профіль, **Редагувати** змінює власний, а **Дублювати** копіює вбудований профіль, щоб ви могли змінити копію. Редактор має назву **Редагувати профіль**, а в ньому кнопки **Скасувати**, **Зберегти** та **Довідка про профілі** (вона відкриває вбудований довідник із цими будівельними блоками). На вузькому екрані перемикач **Розділ профілю** вибирає між **Огляд**, **Правила** і **Тестовий зразок**; на широкому всі три видно одночасно.

## Огляд

| Поле | Що воно робить |
| --- | --- |
| **Назва** | Назва профілю, що показується в меню рядка стану та в параметрах. |
| **Опис** | Примітка про профіль. |
| **Розширення файлів (через кому)** | Розширення, за якими цей профіль обирається для файлу. Два профілі не можуть мати спільне розширення. |
| **Успадковує** | **Немає** або інший профіль, на правилах якого будується цей. |
| **Синтаксис** | **Розширює Markdown** або **Замінює Markdown** (нижче). |
| **Коротко** | Кількість **Блокові правила**, **Рядкові правила** та **Правила вкладеності**. |
| **Редагувати додатковий JSON…** | Відкриває профіль як JSON для полів, яких не показує покроковий редактор. **Застосувати** зберігає ваші зміни в JSON; **Скасувати** відкидає їх. |

**Розширює Markdown** додає ваші правила до правил Markdown: його заголовки, списки, курсив та решта, як і раніше, читаються, а ваші блокові й рядкові правила їх доповнюють. Правило, що є незміненою копією одного з правил профілю CommonMark, описує те, що Markdown уже робить, і залишається йому. **Замінює Markdown** робить ваші правила всім синтаксисом, тож конструкції Markdown перестають розпізнаватися. З ним одне правило має створювати **Кінець рядка**, інакше абзаци не розділятимуться. Редактор попереджає «Add a rule whose output node is "newline", or nothing will separate into paragraphs», і профіль не можна зберегти, доки такого правила немає. Він також перелічує всі типи виводу, яких профіль не визначає.

## Правила

Правила поділяються на три групи.

### Блокові правила

Блокове правило розпізнає цілі рядки та блоки. **Додати правило** додає одне. Кожне правило має **Шаблон**, тип **Збіг**, те, що воно **Створює**, і **Параметри**. Правило видаляється кнопкою **Видалити**. Якщо правил немає, редактор пише «No rules yet. Add one to recognize a block construct.»

### Рядкові правила

Рядкове правило розпізнає текст усередині рядка. **Додати рядкове правило** додає одне. Рядкові правила пропонують чотири типи збігу (**Буквальний префікс**, **Буквально точно**, **Regex (з обмеженням)** і **Пара роздільників**); блокові правила пропонують усі сім.

### Правила вкладеності

Правила вкладеності визначають, які результати можуть бути всередині яких. Кожне має **Батьківський вузол** і **Дозволені дочірні елементи (через кому)**. Порожнє означає без обмежень: «No restrictions. Every node type may nest inside any other.» **Додати правило вкладеності** додає одне.

### Типи збігу

| Тип збігу | Читає шаблон як | Блок | Рядок |
| --- | --- | --- | --- |
| **Буквальний префікс** | Текст, з якого починається конструкція. | так | так |
| **Буквально точно** | Весь текст конструкції. | так | так |
| **Префікс початку рядка** | Текст на початку рядка, наприклад `# `. | так | |
| **Блок із відступом** | Рядки, що починаються із шаблону, наприклад чотирьох пробілів або табуляції. Послідовні рядки та порожні рядки між ними становлять один блок, який показується без відступу. | так | |
| **Огороджений блок** | Рядок, що відкриває блок, який закривається відповідним рядком. | так | |
| **Regex (з обмеженням)** | Регулярний вираз. Pilcrow попереджає перед збереженням виразу, який може зависнути: «This regex could hang the editor — simplify it.» | так | так |
| **Пара роздільників** | Та сама позначка з обох боків тексту в одному рядку, наприклад `%%` у `%%this%%`. Одразу всередині позначок немає пробілу. | так | так |

У регулярному виразі `(?<name>…)` називає частину збігу. Дивіться Іменовані частини нижче.

## Параметри правила

**Параметри** кожного правила пропонують:

| Параметр | Що він робить |
| --- | --- |
| **Пріоритет** | Правила з вищим пріоритетом перевіряються першими. |
| **Лише на початку рядка** | Не дає правилу збігатися всередині рядка. |
| **Іменовані частини стають атрибутами** | Кожна іменована частина регулярного виразу стає атрибутом результату. Редактор перелічує «Parts in this pattern» і «Parts this output reads». Для результату, що містить текст, як-от напівжирний або посилання, показується частина з іменем `text`, якщо вона є, інакше остання частина, що збіглася. |
| **Створює** | Що створює правило: результат зі списків нижче або **Власний** варіант назви. |
| **Власна назва вузла** | Назва для результату **Власний**. |
| **Незмінні атрибути** | Частини, що щоразу мають те саме значення, додаються через **Додати атрибут** (**Назва** і **Значення**). Значення може містити іменовану частину, записану як `{name}`: правило для e-mail, у шаблоні якого названо `address`, може дати своєму посиланню `url` `mailto:{address}`. |
| **Вставити текст** | Що меню **Вставити** записує для цього правила, саме так, як воно має виглядати, з `$0` там, де має стояти курсор. Правилу, що збігається за регулярним виразом, блоком чи відступом, це потрібно, інакше меню «Вставити» його пропускає. |
| **Лише після порожнього рядка** | Для блока із відступом: рядок із відступом одразу після тексту залишається частиною цього тексту, наприклад наступний рядок елемента списку. |
| **Після Return в кінці рядка** | Для списків і цитат: **Автоматично** (повторює марковані позначки й цитати, рахує вгору нумеровані елементи та починає елементи завдань непоміченими), **Повторити позначку**, **Рахувати вгору**, **Починати спочатку від позначки** або **Нічого не додавати**. |

### Огороджені та розмежовані блоки

Для правила **Огороджений блок** **Блок містить** вказує, що всередині:

| Вибір | Значення |
| --- | --- |
| **Поки нічого** | Не задано. |
| **Текст, як написано** | Код або попередньо відформатований текст. |
| **Нічого — приховано** | Коментар, виключений із документа. |
| **Інші блоки в рамці** | Цитата, бічний блок або застереження, що містить абзаци, списки та інше. |
| **Інші блоки без рамки** | Блоки приєднуються до навколишнього тексту; рядки лише групують їх. |
| **Таблиця** | Дивіться Таблиці нижче. |
| **Таблиця, намальована текстом** | Сітка або вирівняні стовпці тексту, що тягнеться від початкового рядка до наступного порожнього, наприклад як у reStructuredText. |
| **Текст із відступом під рядком, що закінчується позначкою** | Початковий рядок — це проза, що закінчується позначкою, як у `::` в reStructuredText; проза залишається абзацом, а текст із відступом під нею після порожнього рядка показується як написано. |
| **Текст із відступом під початковим рядком** | Директива на кшталт `.. code-block::`, яка містить рядки з відступом під собою й не має завершального рядка. |

**Завершальний рядок** — це рядок, що закінчує блок; порожнє значення означає той самий рядок, що й початковий («Same as the opening line»). Роздільник, що не є регулярним виразом, наприклад `+++`, зіставляється як звичайний текст. **Завершальний рядок повторює початкову позначку, не рідше ніж вона** призначений для огорож у стилі Markdown: завершальний рядок — це перший символ початкового рядка, повторений не менше разів, тож довша огорожа містить коротшу як текст. Мова текстового блока, якщо початковий рядок називає відому, підсвічується в редакторі кольором.

### Таблиці

Параметри табличного блока:

| Параметр | Що він робить |
| --- | --- |
| **Макет** | **Сітка з лініями** (клітинки між `|` з лінією між рядками) або **Вирівняні стовпці** (стовпці вирівняно під першою лінією). |
| **Роздільник клітинок** | Текст, що починає кожну клітинку. |
| **Шаблон лінії правила**, **Шаблон лінії верхнього колонтитула** | Рядки, що малюють лише лінію, і та, що завершує заголовок. |
| **Рядок закінчується на** | Позначка, що завершує кожен рядок, як у LaTeX `tabular`. |
| **Шаблон об’єднаної клітинки** | Клітинка, що охоплює кілька стовпців. |
| **Шаблон параметрів клітинки** | Регулярний вираз для того, що може стояти безпосередньо перед роздільником клітинки; частина з іменем `colspan` змушує клітинку охоплювати стільки стовпців. |
| **Роздільник списку стовпців**, **Повторювана позначка** | Як записується список `columns`: з `,` і `*`, `3*` означає три стовпці. |
| **Перший рядок перед порожнім рядком — заголовок** | Рядок заголовка визначається макетом. |
| **Формати** | Інші способи запису клітинок, кожен — назва й роздільник (наприклад `csv` і `,`), додаються через **Додати формат** і вибираються частиною `format` таблиці. |

## Параметри всього профілю

| Параметр | Що він робить |
| --- | --- |
| **Вкладати списки за позначкою** | Кожна нова позначка, наприклад `**` після `*`, починає глибший рівень незалежно від відступу. |
| **Продовження рядка списку** | Рядок, сам по собі після елемента списку, що прикріплює наступний блок до елемента. |
| **Зберігати одинарні розриви рядків** | Розрив рядка всередині абзацу залишається розривом рядка. |
| **Надавати заголовкам ідентифікатори** | Заголовок без власного ідентифікатора отримує його зі свого тексту: малими літерами, слова з’єднано **роздільником слів** після **префікса** (**Префікс ідентифікатора заголовка**, **Роздільник слів в ідентифікаторі заголовка**). З `_` і `_` «Getting Started» стає `_getting_started`, тож перехресне посилання на нього показує назву. Повторена назва додає роздільник і число. |
| **Нумерувати заголовки** | Щойно документ визначає атрибут, названий у **Коли документ визначає**, наприклад `:sectnums:` в AsciiDoc, заголовки від **З рівня заголовка** і нижче нумеруються: `1.`, `1.1.`, `2.`. Заголовки перед визначенням — ні. |
| **Нумеровані підписи** | Блок із назвою одного з наведених тут результатів, наприклад `image`, `table` чи `example`, отримує **Мітка** і власний номер перед назвою (наприклад «Figure 1.») у місці **Розташування підпису**, **Вище** або **Нижче** блока. Додається через **Додати підпис**. |

## Рядкові позначки, що парують за оточенням

Мова на кшталт Markdown записує напівжирний і курсив серією символів, яка відкривається чи закривається залежно від символів поруч, а фрагмент коду чи посилання — дужками, тож один шаблон для всієї конструкції не може їх знайти. Увімкніть **Читати позначки за оточенням**, щоб їх описати.

| Параметр | Що він робить |
| --- | --- |
| **Символ екранування** | Символ, що робить наступний звичайним. |
| **Символ фрагмента коду** | Серія цього символу відкриває фрагмент, який закриває наступна серія такої ж довжини. |
| **Позначки серій** | Позначки, що парують як серії, додаються через **Додати позначку серії**. Кожна має **Позначка**, що **Одна позначка малює** і що **Дві позначки малюють**, та **Може відкриватися чи закриватися всередині слова** (вимкнено для `_`). |
| **Парні позначки** | Позначки, що парують із серією такої ж довжини, додаються через **Додати парну позначку**: **Позначка**, що вона **Малює**, та **Лише коли цей параметр увімкнено** — параметр синтаксису, наприклад виділення, який має бути ввімкнено (або **Завжди**). |
| **Посилання та вебадреси** | **Префікс зображення**, **Адреса, написана окремо, береться в**, **Схеми, з яких починається проста адреса**, **Рядок, що визначає мітку, має** і **Мітка виноски починається з** (символ після відкривальної дужки мітки, що робить її виноскою: `[^note]` малюється як посилання на виноску, коли рядок починається з `[^note]:`). |

Позначки парують у межах рядка. Код, екрановані символи та адреса посилання є для навколишніх позначок звичайним текстом.

## Джерело зі стилями

З увімкненим **Джерело зі стилями** редактор малює документ у вигляді його синтаксису: більші заголовки, напівжирні та курсивні серії, смуги цитат, відступи списків, прапорці завдань, лінії, посилання та картки коду, і ховає позначки, що їх створюють (з увімкненим **Сховати маркери**), крім рядка, де стоїть курсор. Редактор нічого не знає про жоден окремий синтаксис: правило повідомляє, чим є його збіг, несучи запис стилізації, а правило без нього розфарбовується, але не змінює вигляду.

**Параметри** кожного правила мають групу **Джерело зі стилями**:

| Поле | Що воно робить |
| --- | --- |
| **Роль** | Чим є збіг, або **Без стилю**. Для однієї конструкції всередині рядка: heading, strong, emphasis, code, strike, highlight, underline, link, subscript, superscript. Для цілого рядка: rule (тематичний розрив), list (позначка елемента списку разом з відступом і пробілом після неї), task (позначка з прапорцем) і quote (позначки `>` цитованого рядка). Для блока, розпізнаного цілком: codeBlock. Для блока, початковий і завершальний рядки якого — окремі збіги: quoteRegion. Для таблиці, рівняння чи діаграми, намальованих як зображення: renderedBlock. |
| **Група вмісту** | Група захоплення, рахуючи від 1, що містить те, про що конструкція: слово всередині `*bold*`, назва в `\section{Title}`. Те, що збіг має крім цього, — власні позначки конструкції, які ховає «Сховати маркери». `0` означає, що весь збіг — вміст і нічого не ховається, як для вебадреси. Пропустіть, якщо збіг — лише позначки, наприклад `== ` заголовка. |
| **Рівень заголовка**, **Група рівнів** | Рівень заголовка, від 1 до 6. Якщо пропущено, це число в кінці назви результату правила (`heading2`) або довжина групи захоплення, що містить серію `#`. |
| **Група позначок** | Для списку чи завдання — група захоплення, що є позначкою з відступом і пробілами після неї, коли збіг починається з чогось іншого, наприклад `> ` цитованого елемента. |
| **Стилі до кінця рядка** | Стилі від збігу до кінця рядка, для правила, що збігається лише з позначкою заголовка й залишає його назву як текст, що йде далі. |
| **Малюється як** | Для відтвореного блока — чим він є: таблицею, формулою чи діаграмою, або **Не зображення**. |
| **Групи адреси** | Для посилання — групи захоплення, що перевіряються по черзі й містять адресу, яку воно відкриває після клацання чи дотику; `0` — весь збіг. Відкриваються лише веб-, поштові й телефонні адреси. |

Номери груп рахують дужки шаблону від 1; 0 — весь збіг. Профіль, що не замінює Markdown, також зберігає власне читання Markdown для тих видів, яких його правила не оголошують, як-от смуги цитат і пари `**`.

## Атрибути документа та умовні розділи

Правило **Атрибут документа** визначає значення за `name`, а правило **Довідник атрибутів** (рядкове правило з частинами `name` і `original`) замінює посилання на нього. Посилання на атрибут, якого ніхто не визначив, залишається як написано. **Умовний розділ** зберігає або відкидає блоки між його рядками залежно від того, чи задано названі в ньому атрибути. Атрибути діють від місця визначення й далі.

Правило, що створює **Параметри для наступного блока**, розпізнає цілий рядок, який налаштовує блок після нього, і саме нічого не показує. Його частини та незмінні атрибути передаються цьому блоку: `title`, `id`, `nodeType`, `language` і `hardbreaks` мають значення, наведені в розділі Частини, а будь-яка інша частина зберігається в блоці, де її читає таблиця, список чи цитата.

## Перевірка профілю

Унизу редактора **Тестовий зразок** містить зразок тексту (спочатку це заголовок і рядок тексту). Виберіть **Перевірити зразок**, щоб побачити вузли, які створюють ваші правила, з відступами за вкладеністю. Якщо нічого не збігається, пишеться «No blocks recognized.»

## Базові значення

**Базові значення** профілю — це його точка відновлення: яким він був, коли ви його створили, продублювали чи імпортували. **Скинути до базових значень** відкидає всі зміни від того часу, після підтвердження. **Задати як нові базові значення** зберігає профіль і робить його поточний стан точкою відновлення.

Збереження відхиляється з повідомленням, якщо профіль замінює Markdown, але не має правила кінця рядка, якщо шаблон небезпечний і може зависнути редактор, або якщо файл неможливо записати.

## Частини

Частини — це іменовані фрагменти збігу, які читає результат.

| Частина | Значення |
| --- | --- |
| `allOf` | Роздільник між назвами, коли потрібні всі, наприклад `+`. |
| `alt` | Опис зображення для читачів, які його не бачать. |
| `anyOf` | Роздільник між назвами, коли достатньо будь-якої, наприклад `,`. |
| `attribution` | Хто сказав цитату, показується під нею. |
| `citetitle` | Твір, з якого походить цитата, показується після авторства. |
| `columns` | Список стовпців таблиці, наприклад `1,2,1`; кількість елементів — кількість стовпців. |
| `condition` | Назви атрибутів, від яких залежить розділ. |
| `conditionType` | `defined` зберігає розділ, коли атрибути задано, `undefined` — коли ні. |
| `content` | Сам текст, коли він не є всім збігом. |
| `format` | Рушій діаграми (`mermaid` або `vega-lite`); для таблиці — який із її розмежованих форматів використовують клітинки. |
| `hardbreaks` | Якщо присутня, зберігає одинарні розриви рядків наступного блока. |
| `header` | Будь-яке значення, крім `false`, робить перший рядок таблиці її заголовком. |
| `id` | Назва: для наступного блока — ідентифікатор, на який вказують перехресні посилання; для виноски — назва, що дозволяє наступним виноскам без власного тексту ділити її номер. |
| `keys` | Клавіші, які слід натиснути, розділені комами. |
| `label` | Текст, що показується для посилання чи якоря замість власної назви цілі. |
| `language` | Мова програмування блока коду, використовується для його розфарбовування. |
| `level` | Рівень заголовка, від 1 до 6. |
| `marker` | Роздільник після терміна, наприклад `::`. Інша позначка вкладає список усередину опису. |
| `name` | Назва атрибута у визначенні чи посиланні. |
| `nodeType` | Перетворює наступний блок на інший результат за його назвою у файлі. |
| `noHeader` | Якщо присутня, таблиця не має рядка заголовка. |
| `notation` | Математична нотація: `tex` (типово) або `latex`. |
| `open` | `true` показує розділ, що згортається, відкритим. |
| `ordered` | `true` робить список нумерованим. |
| `original` | Посилання як написано, показується, коли атрибут не визначено. |
| `presentation` | Як показується наступний список описів: `sideBySide` ставить терміни й описи у два стовпці; `questions` нумерує кожен термін як запитання з відповіддю під ним. |
| `primary` | Запис покажчика. |
| `secondary` | Підзапис під записом покажчика. |
| `sectionLabel` | Слово, за яким іде номер наступного заголовка, наприклад `Appendix`: такі заголовки рахуються окремо, `Appendix A:`. |
| `sectionLabelStart` | Перший із цих номерів: літера (`A`) рахує літерами, число — числами. |
| `src` | Адреса відео- або аудіофайла. |
| `start` | Число, з якого починається нумерований список. |
| `summary` | Рядок, що показується на розділі, який згортається, поки він закритий. |
| `targetID` | Ідентифікатор, на який вказує посилання. |
| `term` | Термін, що описується. |
| `tertiary` | Підзапис під вторинним. |
| `text` | Текст, що показується, коли шаблон захоплює більше. Текст виноски йде після абзацу, таблиці чи списку, в якому вона стоїть, пронумерований. |
| `title` | Назва: заголовок рамки, підказка зображення чи посилання або підпис над наступним блоком. |
| `type` | Вид застереження, наприклад `note`, `tip` або `warning`. |
| `unset` | Якщо присутня, правило прибирає атрибут замість його визначення. |
| `url` | Адреса, на яку вказує посилання чи зображення. |
| `value` | Значення атрибута; посилання на раніше визначені атрибути в ньому замінюються. |
