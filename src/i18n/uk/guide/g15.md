# Chapter 81: Файли, кодування та обмеження

## Файли, які відкриває Pilcrow

Pilcrow редагує файли простого тексту й розмітки. Поширені розширення: `txt`, `md`, `markdown`, `adoc`, `asciidoc`, `rst` і `tex`, а також будь-яке розширення, яке вказує додатковий профіль. Pilcrow визначає кодування тексту файлу, коли відкриває його.

| Елемент | Тип |
| --- | --- |
| Профіль синтаксису, збірка макросів, стильовий посібник, тема програми | `.json` |
| Тема відображення | `.css` |
| Пакет теми | `.zip` |
| Маніфест проєкту книги | `manifest.pilcrow` |
| Тло | HEIC, PNG, JPEG, SVG, MP4, MOV, M4V |
| Звуковий кліп набору | WAV, AIFF, MP3, M4A, CAF |

## Кодування тексту

Pilcrow читає текст у кодуваннях UTF-8, UTF-16, UTF-32 та ISO 8859-1 (Latin-1). Документ можна перетворити за допомогою **Відомості про документ ▸ Кодування ▸ Перетворити на…** на будь-яке з наведених нижче; файл буде перетворено під час наступного збереження:

UTF-8, UTF-8 (BOM), UTF-16 LE, UTF-16 LE (BOM), UTF-16 BE, UTF-16 BE (BOM), UTF-32 LE, UTF-32 LE (BOM), UTF-32 BE, UTF-32 BE (BOM).

Файл у Latin-1 можна перетворити на будь-яке з них без втрат. Перетворення на Latin-1 не пропонується, бо воно може знищити вміст.

## Формати експорту

| Формат | Розширення |
| --- | --- |
| HTML, HTML (без стилів) | `.html` |
| PDF | `.pdf` |
| Word (.docx) | `.docx` |
| Зображення | `.png` |
| Архів PDF | `.zip` |

## Обмеження та числа

Де Pilcrow зупиняється або де вибір має діапазон:

| Де | Обмеження |
| --- | --- |
| Панель пошуку | Зупиняється на 500 збігах. |
| Пошук у перегляді | Рахує до 2 000 збігів. |
| Заміна в папці | Змінює щонайбільше 2 000 файлів за раз. |
| Перевірити посилання | Перевіряє до 50 000 посилань. |
| Порівняння | Показує до 5 000 змінених рядків. |
| Версій для збереження | Від немає до 500 (типово 50). |
| Довгі рядки | Рядки від 20 000 символів завжди переносяться. |
| Розмір шрифту | Від 9 до 32 пунктів. |
| Ширина табуляції | Від 2 до 8 пробілів. |
| Ширина тексту | Від 50% до 100%. |
| Масштаб | Від 50% до 200%, за десять кроків. |
| Швидкість читання | Від 60 до 2 000 слів на хвилину. |
| Ширина навігатора | Від 180 до 420 пунктів. |
| Звуковий кліп набору | Щонайбільше 2 секунди й 3 МБ. |
| Текст журналу діагностичного звіту | Найновіші записи, до 60 000 символів, коли його додають до опису проблеми на GitHub. |
| Дуже великі файли | Відкриваються й редагуються без повного читання в пам’ять. Підрахунок рядків і слів та структура завершуються у фоновому режимі й до того можуть бути неповними. Експорт у PDF дуже великого документа потребує набагато більше пам’яті, ніж редагування чи експорт у HTML і Word; Архів PDF ділить його на обмежені частини. |

## Де Pilcrow зберігає дані

| Що | Де |
| --- | --- |
| Ваші документи | Там, куди ви їх зберегли. |
| Бібліотека (теми, профілі, макроси, стильові посібники, тла) | У приватному сховищі програми або в папці з назвою «Pilcrow Library» усередині вибраної вами папки (**Параметри ▸ Бібліотека ▸ Розташування**). |
| Налаштування, ключі API, копії для відновлення, історія версій | На пристрої, у приватному сховищі програми та в Keychain. Переглядайте й видаляйте їх у **Параметри ▸ Загальні ▸ Сховище та конфіденційність**. |
| Діагностичний журнал | На пристрої, доки ви його не очистите. |

# Chapter 82: Повідомлення, банери та порожні стани

Цей розділ пояснює короткі повідомлення, які показує Pilcrow, щоб жодне з них не лишалося загадкою.

## У редакторі та перегляді

| Повідомлення | Що воно означає |
| --- | --- |
| **Поки нічого переглядати. Почніть писати, і воно з’явиться тут.** (або «Перейдіть до редагування й почніть писати.») | Документ порожній, тож у перегляді нічого малювати. |
| **Не вдалося відтворити перегляд: …** з **Показати джерело** і **Повторити** | Перегляд не вдався. **Показати джерело** перемикає на редагування. **Повторити** пробує ще раз. |
| Невдале рівняння чи діаграма з посиланням **Показати джерело** | Один блок не вдалося намалювати. Клацніть **Показати джерело**, щоб перейти до джерела цього блока й виправити його. |
| **Не вдалося зберегти** з **Повторити** і кнопкою закриття | Збереження не вдалося. Документ лишається відкритим і незбереженим. Усуньте причину (місце на диску, дозволи, файл, який перемістили) і оберіть **Повторити**. |
| **Файл змінено на диску** | Інша програма змінила файл. **Перезавантажити** читає нову версію; **Залишити поточну версію** зберігає те, що у вас є. |
| **Попередження розбору** | Рядок, де конструкція, імовірно, не те, що ви мали на увазі (Chapter 68). |
| **Замінити наявний файл?** | Назву, яку ви вибрали, уже використано в цьому місці. |
| **Лишилися поля для заповнення** | Ви друкуєте чи експортуєте з незаповненими полями (Chapter 63). |
| **Роздільник панелей** (підказка VoiceOver: «Перетягніть, щоб змінити розмір редактора й перегляду. Двічі торкніться, щоб скинути.») | Ручка між джерелом і переглядом у режимі «Поруч». |
| **Слова: N** | Кількість слів у рядку стану. |

## У діалогах і панелях

| Де | Повідомлення | Значення |
| --- | --- | --- |
| Палітра команд | **Введіть команду** | Підказка поля. Коли нічого не підходить, з’являється «Немає відповідних команд». |
| Швидке відкриття | **Введіть назву файлу** | Підказка поля. |
| Курсори в стовпці | **Рядки (наприклад, 3-17)**, **Стовпець (наприклад 100 або 100-105 для вибору діапазону)** | Підказки полів. Один стовпець розміщує курсори; діапазон вибирає ці символи в кожному рядку. |
| Панель пошуку | **Введіть текст, щоб шукати в цій папці.**, **У цій папці немає збігів.**, **Пошук скасовано.** | Стан пошуку в папці. |
| Панель файлів | **Папку також можна скинути сюди.** | Перетягніть папку на панель, щоб відкрити її. |
| Заміна в папці | **Нема що замінювати.** | Пошук не має збігів. |
| Порівняння | Підказки кнопок: **Прийняти** («Внести цю зміну у відкритий документ»), **Відхилити** («Не вносити цю зміну у відкритий документ»), **Забрати назад** («Повернути старіші рядки в документ лише для цієї зміни»). | Що робить кожна. |
| Переклад | **Не вдалося завершити переклад.** | Спробуйте ще раз або виберіть іншу швидкість. |
| Переклад | **Орієнтовний час: менше хвилини** | Оцінка для швидкості асистента ШІ; час залежить від вашого сервісу ШІ. Після перекладу **Відкрити в новій вкладці** відкриває результат. |
| Асистент | **Жоден документ не відкрито.**, **Текст документа не надсилається.** | Панелі нема чим ділитися, тож нічого не надсилається. |
| Вибір моделі | **Завантаження моделей…**, **Немає відповідних моделей.** | Список завантажується або пошук нічого не знайшов. |
| Перевірка стилю | **Зауважень немає.** і **Відповідь не вдалося прочитати як зауваження. Спробуйте ще раз.** | Перевірка нічого не знайшла, або відповідь ШІ була не в очікуваній формі. |
| Перевірка стилю | Підказка **Застосувати всі**: «Вносить кожне виправлення, яке є, як одну зміну, яку можна скасувати.» | Одне скасування відміняє їх усі. |
| Панель проєкту | **Ваше ім’я**, **Додати змінну** | Підказка поля «Автор» і кнопка для змінної проєкту. |
| Дозвіл асистента | **Прочитати політику конфіденційності Pilcrow** | Відкриває політику конфіденційності. |

## У параметрах

| Де | Повідомлення | Значення |
| --- | --- | --- |
| Клавіатура | **Натисніть нову комбінацію клавіш, потім клацніть Зберегти.** і **Натисніть будь-яку клавішу…** | Під час запису комбінації клавіш. |
| Бібліотека ▸ Розташування | **Розташування бібліотеки**, **Переміщення вашої бібліотеки…** | Назва сторінки та перебіг, поки бібліотеку переміщують. |
| Підключення асистента | **Залиште порожнім, щоб зберегти наявний ключ.** | Під час редагування порожнє поле ключа зберігає ключ, що вже є в Keychain. |
| Редактор макросів | **Тригер — наприклад, /sig** | Підказка поля тригера. |
| Редактор профілю | **Додатковий JSON профілю**, **Зразок і результати** | Назва редактора JSON і область під «Перевірити зразок», що показує вузли, які дає зразок. |
| Діагностика | **Усі частини** (у засобі перегляду журналу), **Немає відповідних записів.** | Журнал без фільтра та фільтр, що нічого не знаходить. |
| Рядок стану | Червона позначка **Запис журналу**; її підказка **Показати параметри діагностики** | Журнал записується. Клацніть її, щоб відкрити сторінку «Діагностика». **Зупинити запис і завершити звіт про помилку** — це підказка до **Відтворення — завершити звіт**. |
| Рядок стану | **Виберіть профіль синтаксису для цього документа** | Підказка до меню синтаксису. |
| Елемент назви | **Відкриті документи й дії з документами** | Підказка до назви документа. |
