# Part XXI — Формати файлів і обмеження

# Chapter 79: Формат теми програми

**Тема програми** задає стиль самого Pilcrow: його світлий або темний вигляд, акцентний колір, бічну панель, рядки стану й форматування та редактор. Це файл JSON. Відображені документи (Перегляд, HTML, PDF, зображення, друк і Word) стилізуються окремо за допомогою **теми відображення**, яка є CSS (розділ 80). Ці два види тем встановлюються, вибираються й видаляються окремо, і жодна не залежить від іншої.

## Повний приклад

```json
{
  "pilcrowAppTheme": 1,
  "name": "Nord",
  "appearance": "dark",
  "colors": {
    "accent": "#88C0D0",
    "sidebar": { "background": "#2E3440", "foreground": "#D8DEE9" },
    "bars": { "background": "#3B4252", "foreground": "#D8DEE9" },
    "editor": {
      "background": "#2E3440",
      "foreground": "#ECEFF4",
      "cursor": "#88C0D0",
      "selection": "#434C5E",
      "gutterBackground": "#2E3440",
      "gutterForeground": "#4C566A"
    },
    "syntax": {
      "heading": "#88C0D0",
      "marker": "#EBCB8B",
      "code": "#A3BE8C",
      "link": "#81A1C1",
      "muted": "#7B88A1",
      "tokens": { "strong": "#D08770" }
    }
  }
}
```

## Верхній рівень

| Ключ | Обов'язковий | Значення |
| --- | --- | --- |
| `pilcrowAppTheme` | так | Версія формату, `1`. |
| `name` | так | 1–200 символів. Показується в Параметрах і меню «Теми». |
| `appearance` | так | `"light"`, `"dark"` або `"automatic"`. |
| `colors` | теми `light` і `dark` | Одна палітра (нижче). |
| `light`, `dark` | теми `automatic` | Дві палітри: одна для світлого вигляду системи, інша для темного. |
| `id` | ні | Записується Pilcrow для власної бібліотеки. Під час імпорту ігнорується, бо завжди призначається новий id. |

`appearance` визначає вигляд **кожного** вікна, зокрема меню, Параметрів, аркушів і засобів вибору. Тема `light` або `dark` фіксує його; `automatic` слідує за системою.

Автоматична тема має задавати кожен колір і в `light`, і в `dark`, або в жодній. Колір, заданий лише для одного вигляду, інакше був би намальований в іншому.

## Палітра

Кожен ключ необов'язковий. Пропущений колір залишає вбудований вигляд Pilcrow, тож тема може бути настільки малою, як один акцентний колір.

| Ключ | Що стилізує |
| --- | --- |
| `accent` | Загальний відтінок програми: кнопки, вибрані сегменти, перемикачі, посилання, кільця фокусу та вибраний рядок бічної панелі. Незадане значення залишає системний акцент. |
| `sidebar.background`, `sidebar.foreground` | Бічна панель «Файли», «Структура» й «Пошук». Другорядні підписи виводяться з переднього плану. |
| `bars.background`, `bars.foreground` | Рядок стану, закріплена панель форматування та повідомлення про імпорт. Другорядні підписи виводяться з переднього плану. |
| `editor.background`, `editor.foreground` | Полотно редактора й основний текст. |
| `editor.cursor`, `editor.selection` | Точка вставлення й підсвічування виділення. |
| `editor.gutterBackground`, `editor.gutterForeground` | Поле з номерами рядків. Тло типово збігається з тлом редактора. |
| `editor.currentLineRule` | Тонка лінія під рядком, де стоїть курсор, коли ввімкнено **Вигляд ▸ Лінія поточного рядка**. Типово — колір тексту редактора з малою інтенсивністю. |
| `syntax.<group>` | Кольори живого синтаксису за групами (нижче). |
| `syntax.tokens.<raw>` | Один токен за його сирим значенням, що перевизначає його групу. |

### Групи синтаксису

| Група | Кольори |
| --- | --- |
| `heading` | Заголовки (маркери й текст), маркери сповіщень, терміни означень |
| `marker` | Курсив, напівжирний, закреслений та інші рядкові роздільники; маркери списків і завдань |
| `code` | Рядковий код, огороджені та відступні блоки коду, формули, блоки HTML |
| `link` | Підписи й адреси посилань та зображень, автопосилання |
| `muted` | Маркери цитат, тематичні розриви, рядки таблиць, коментарі, атрибути блоків |
| `codeKeyword`, `codeString`, `codeNumber`, `codeComment` | Підсвічений код усередині огородження |

Група, яку не задано, отримує вбудований колір, підібраний до тла редактора: темніші тони на світлому полотні, світліші на темному. Назви токенів у `syntax.tokens` використовують літери, цифри, `_` і `-` та не можуть повторювати назву групи (`syntax.heading` уже охоплює `heading`).

## Кольори

Кожен колір — це шістнадцятковий рядок: `#RGB`, `#RGBA`, `#RRGGBB` або `#RRGGBBAA`, в sRGB. Pilcrow зберігає їх у верхньому регістрі.

## Перевірка

Pilcrow відхиляє файл, а не ігнорує його частину, і називає ключ із помилкою, наприклад `colors.editor.cursor: must be a hex colour`. Він відхиляє:

- відсутню або іншу версію `pilcrowAppTheme`;
- невідомий ключ на будь-якому рівні (зазвичай це описка);
- ключ палітри, що не відповідає вигляду (`colors` в автоматичній темі, `light` і `dark` у світлій чи темній);
- колір, що не є шістнадцятковим;
- автоматичну тему, у якій палітри `light` і `dark` задають різні кольори.

## Що тема програми не змінює

Рядок заголовка вікна й панель інструментів (системне скло, що сприймає лише акцент), меню, Параметри, аркуші та засоби вибору зберігають рідний вигляд, окрім вигляду й акценту. Шрифти не входять до тем: шрифт і розмір редактора задаються в **Параметри ▸ Вигляд ▸ Розмір тексту й шрифти**.

## Встановлення та спільний доступ

- **Імпортуйте** файл `.json` через **Параметри ▸ Бібліотека ▸ Теми**, **Файл ▸ Імпорт ▸ Тема** на Mac або **Параметри ▸ Бібліотека ▸ Імпорт** на iPad. Перетягування файлу на Pilcrow теж працює.
- Пакет теми `.zip` може містити теми програми поряд із темами відображення (розділ 80).
- Кнопка поширення поруч із темою зберігає її файл `.json` або весь пакет, якщо тема походить із нього.

Pilcrow містить три теми програми: **Автоматично**, **Світла** і **Темна**. Вони задають кольори редактора й синтаксису, а оформлення вікна залишають вбудованим.

# Chapter 80: Довідник CSS теми відображення

**Тема відображення** — це CSS. Вона стилізує Перегляд, HTML, PDF, зображення й друк, а також стилі Word, перелічені в кінці цього розділу. Тема відображення може бути одним файлом `.css` або частиною пакета ZIP з локальними ресурсами. Профілі синтаксису визначають, як вихідний текст стає документом; теми відображення лише стилізують результат. CSS ніколи не стилізує програму чи редактор; це робить тема програми (розділ 79).

## Каскад

Pilcrow застосовує стилі в такому порядку:

1. структурне скидання Pilcrow;
2. CSS вибраної теми;
3. разовий CSS з панелі експорту (**Додаткові параметри ▸ Власний CSS**);
4. необхідні виправлення для друку й відображення.

Пізніші правила перемагають за звичайним каскадом CSS. JavaScript у темах, віддалені ресурси, URL `file:` та `@import` не підтримуються.

## Ресурси

Pilcrow читає CSS теми стандартним токенізатором CSS, тож екранування декодуються до будь-якої перевірки: `u\72 l(…)` — це `url()`, а `@im\70 ort` — це `@import`. Перевіряється кожне місце, звідки браузер міг би завантажувати: `url(…)`, `url("…")`, `src("…")` та рядки всередині `image-set()`. Кожне має бути одним із таких:

- шлях відносно пакета (`fonts/Body.woff2`, `./paper.png`). `?query` або `#fragment` дозволені й ігноруються під час пошуку файлу;
- URL `data:` типу PNG, JPEG, GIF, WebP, SVG (`image/svg+xml`), TTF, OTF, WOFF або WOFF2;
- посилання на фрагмент, як-от `url(#shadow)`, що називає елемент на сторінці.

Усе зі схемою, відмінною від `data:` (`https:`, `file:`, `blob:`), або що починається з `//`, відхиляється, так само як і шлях, що починається з `/` або містить `..`.

## Властивості відображення

Вбудоване скидання читає ці властивості та надає запасні значення:

| Група | Властивості |
| --- | --- |
| Колір | `--pt-background`, `--pt-foreground`, `--pt-secondary-background`, `--pt-secondary-foreground`, `--pt-accent`, `--pt-link-color`, `--pt-border-color` |
| Код | `--pt-code-background`, `--pt-code-foreground`, `--pt-code-keyword`, `--pt-code-string`, `--pt-code-number`, `--pt-code-comment` |
| Шрифт | `--pt-body-font-family`, `--pt-mono-font-family`, `--pt-base-font-size`, `--pt-line-height` |
| Відстані | `--pt-paragraph-spacing`, `--pt-blockquote-indent`, `--pt-list-indent`, `--pt-code-padding`, `--pt-heading-top`, `--pt-heading-bottom` |
| Таблиці | `--pt-table-header-background`, `--pt-table-stripe-background` |
| Сповіщення | `--pt-admonition-note-color`, `--pt-admonition-tip-color`, `--pt-admonition-important-color`, `--pt-admonition-warning-color`, `--pt-admonition-caution-color` |

Pilcrow може додавати класи й атрибути в оновленні. Уникайте селекторів, що залежать від недокументованої глибини обгорток, згенерованих ID або відсутності додаткових класів.

## Мінімальна тема

```css
:root {
  color-scheme: light;
  --pt-background: #ffffff;
  --pt-foreground: #202124;
  --pt-secondary-background: #f5f6f7;
  --pt-secondary-foreground: #5f6368;
  --pt-accent: #0b57d0;
  --pt-link-color: var(--pt-accent);
  --pt-border-color: #dadce0;
  --pt-code-background: #f1f3f4;
  --pt-code-foreground: #202124;
  --pt-body-font-family: system-ui, -apple-system, sans-serif;
  --pt-mono-font-family: ui-monospace, "SF Mono", monospace;
  --pt-base-font-size: 16px;
  --pt-line-height: 1.6;
}

.pt-document { max-width: 72ch; }
.pt-heading-1 { letter-spacing: -0.025em; }
```

## Пакети ZIP

Пакет ZIP може містити разом теми відображення (`.css`) і теми програми (`.json`); кожна показується в Параметрах зі своїм видом. ZIP щонайбільше з одним файлом CSS і щонайбільше однією темою програми не потребує маніфесту. Для чогось більшого потрібен `pilcrow-theme.json`, що перелічує кожну тему в `variants[].file`. Вид файлу визначає його розширення:

```json
{
  "id": "com.example.paper",
  "name": "Paper",
  "version": "1.0.0",
  "author": "Example Author",
  "license": "MIT",
  "cssAPIVersion": 1,
  "variants": [
    { "id": "app", "name": "Paper", "file": "Paper.json", "appearance": "automatic" },
    { "id": "light", "name": "Paper Light", "file": "Paper-Light.css", "appearance": "light" },
    { "id": "dark", "name": "Paper Dark", "file": "Paper-Dark.css", "appearance": "dark" }
  ]
}
```

Маніфест описує пакет і його теми. Він ніколи не містить значень стилів: вони містяться у файлах CSS і тем програми.

- `id` пакета називає теку встановлення. Він не повинен починатися з `.` або мати пробіли на початку чи в кінці. Встановлення пакета, `id` якого вже встановлено, замінює його.
- ZIP, створений **Стиснути** у Finder, працює без змін. Pilcrow пропускає `__MACOSX/`, `._*`, `.DS_Store` і `Thumbs.db`, а коли всі файли лежать в одній теці верхнього рівня, ця тека вважається коренем пакета.
- Видалення однієї теми прибирає її з пакета й зберігає решту разом зі спільними ресурсами. Видалення останньої теми прибирає пакет. Видалена вибрана тема повертає вибір до типового для її виду: Автоматично для теми програми, Світла для теми відображення.
- CSS може посилатися на пакетні файли PNG, JPEG, GIF, WebP, TTF, OTF, WOFF і WOFF2 відносними шляхами `url(...)`. Pilcrow перевіряє їхні сигнатури та вбудовує згадані ресурси як URL даних, щоб відображення й експортований HTML лишалися автономними та працювали офлайн. Шляхи ZIP не можуть виходити за межі пакета, збігатися за регістром чи вказувати на посилання. Розмір архіву, кількість елементів, розмір окремого елемента й коефіцієнт стиснення обмежені.

## Word

Експорт у Word використовує світлі (базові) значення `:root` і відображає ці семантичні властивості на іменовані стилі Word: `--pt-foreground`, `--pt-background`, `--pt-accent`, `--pt-link-color`, `--pt-code-background`, `--pt-code-foreground`, `--pt-body-font-family`, `--pt-mono-font-family`, `--pt-base-font-size` і `--pt-line-height`. Селектори браузера й правила розмітки не мають загального відповідника у Word. Перегляд, HTML, PDF і зображення використовують повну таблицю стилів; Word використовує цю підмножину, зберігаючи структуру документа, діаграми, картинки формул, посилання й медіа. Панель експорту показує це обмеження щоразу, коли вибрано Word.

Pilcrow містить дві теми відображення, **Світла** і **Темна**, які є повноцінними відправними точками.
