# Chapter 72: Tastatur

**Innstillinger ▸ Tastatur ▸ Snarveier** viser alle kommandoer du kan endre snarveien til, med gjeldende tast.

| Kontroll | Hva den gjør |
| --- | --- |
| En kommandos rad | Klikk på den, trykk den nye snarveien, og velg deretter **Arkiver**. **Fjern binding** fjerner snarveien. **Avbryt** beholder den gamle. Hvis snarveien var i bruk av en annen kommando, blir den kommandoen tømt, og siden forteller deg hvilken. |
| **Super-Tab-taster** | Tastene for **Neste felt** og **Forrige felt**, som hopper mellom de tomme feltene en makro etterlater: `⌥Tab` og `⌥⇧Tab`, eller `⌃⌘]` og `⌃⌘[`, eller **Egendefinert**. |
| **Tilbakestill alle snarveier** | Gjenoppretter alle standardverdier. |

Kommandoene du kan endre, med standardverdiene, er:

| Kommando | Standard |
| --- | --- |
| Sterk | `⌘B` |
| Utheving | `⌘I` |
| Innebygd kode | `⌃`` ` `` |
| Innebygd matematikk | `⌃M` |
| Gjennomstreking | `⌃⇧`` ` `` |
| Hyperlenke | `⌘K` |
| Fjern formatering | `⌘\` |
| Vis/skjul sidepanel | `⇧⌘L` |
| Sidepanel: Disposisjon | `⌃⌘1` |
| Åpne dokumenter | `⌃⌘2` |
| Sidepanel: Filtre | `⌃⌘3` |
| Sidepanel: Søk | `⇧⌘F` |
| Sidepanel: Assistent | `⌃⌘4` |
| Legg til markør over | `⌃⇧↑` |
| Legg til markør under | `⌃⇧↓` |
| Markører i en kolonne… | `⌃⇧G` |
| Gå tilbake | `⌃⌘←` |
| Gå fremover | `⌃⌘→` |
| Marker neste forekomst | `⌃⌥D` |
| Marker alle forekomster | `⌃⌥⇧D` |
| Neste felt | `⌥Tab` |
| Forrige felt | `⌥⇧Tab` |
| Kommandopalett… | `⌃⇧P` |
| Fokusmodus | ingen |

Kommandoer som ikke står på denne listen, for eksempel Arkiver, Søk og elementene under Avsnitt, har faste snarveier. Chapter 77 viser alle snarveier.

# Chapter 73: Abonnement og kreditter

Alle funksjoner i Pilcrow er gratis. Å støtte Pilcrow er frivillig: det er med på å betale for utviklingen, og det gir deg stemmer over hva som bygges neste gang. Stemmene styrer rekkefølgen på arbeidet, men lover ingen funksjon.

Siden **Støtt Pilcrow** har:

| Del | Hva den viser eller gjør |
| --- | --- |
| **Stemmene dine** | **Fra abonnementet ditt** (stemmene for denne betalte måneden, med utløpsdato) og **Kjøpt** (stemmer som aldri utløper). Abonnementsstemmer brukes først og utløper når den betalte måneden er slutt. |
| **Få stemmer** | Abonnementet og enkeltstemmene du kan kjøpe. Pilcrow Supporter fornyes hver måned til du sier det opp i Apple-konto-innstillingene dine. Hver betalte måned gir deg stemmer. |
| **Gjenopprett kjøp** | Henter tilbake kjøp gjort på en annen enhet. |
| **Bruksvilkår**, **Personvernerklæring** | Lenker. |
| **Appikon** | Et utvalg appikoner for abonnenter. Ikoner for en stemmerunde opptjenes ved å abonnere under den runden, og beholdes. På Mac endres ikonet i Dock mens Pilcrow er åpen. |
| **Veikart** | Den gjeldende runden med funksjoner som er åpne for avstemning, med tellerne «Stemmer» og «Dine» og en **Stem**-knapp for hver. Hver stemme bruker én av stemmene dine og kan ikke trekkes tilbake. Mellom rundene står det når den neste åpner. |

Hvis støttealternativer ikke er tilgjengelige i en bestemt versjon, sier siden fra om det.
