# Chapter 81: Filer, tegnkodinger og grenser

## Filer Pilcrow åpner

Pilcrow redigerer filer med ren tekst og markering. De vanlige filendelsene er `txt`, `md`, `markdown`, `adoc`, `asciidoc`, `rst` og `tex`, pluss alle filendelser som en profil du legger til, gjør krav på. Pilcrow oppdager tekstkodingen til en fil når den åpnes.

| Element | Type |
| --- | --- |
| Syntaksprofil, makrosamling, stilguide, Apptema | `.json` |
| Gjengivelsestema | `.css` |
| Temapakke | `.zip` |
| Manifest for bokprosjekt | `manifest.pilcrow` |
| Bakgrunn | HEIC, PNG, JPEG, SVG, MP4, MOV, M4V |
| Skrivelydklipp | WAV, AIFF, MP3, M4A, CAF |

## Tegnkodinger

Pilcrow leser tekst i UTF-8, UTF-16, UTF-32 og ISO 8859-1 (Latin-1). Du kan konvertere et dokument med **Dokumentinformasjon ▸ Tegnkoding ▸ Konverter til…** til hvilken som helst av følgende; filen konverteres neste gang den arkiveres:

UTF-8, UTF-8 (BOM), UTF-16 LE, UTF-16 LE (BOM), UTF-16 BE, UTF-16 BE (BOM), UTF-32 LE, UTF-32 LE (BOM), UTF-32 BE, UTF-32 BE (BOM).

En Latin-1-fil kan konverteres til alle disse uten tap. Konvertering til Latin-1 tilbys ikke, fordi det kan ødelegge innhold.

## Eksportformater

| Format | Filendelse |
| --- | --- |
| HTML, HTML (uten stiler) | `.html` |
| PDF | `.pdf` |
| Word (.docx) | `.docx` |
| Bilde | `.png` |
| PDF-arkiv | `.zip` |

## Grenser og tall

Der Pilcrow stopper, eller der et valg har et område:

| Hvor | Grense |
| --- | --- |
| Søkepanel | Stopper ved 500 treff. |
| Søk i forhåndsvisning | Teller opptil 2 000 treff. |
| Erstatt i mappe | Endrer høyst 2 000 filer om gangen. |
| Kontroller lenker | Kontrollerer opptil 50 000 lenker. |
| Sammenlign | Viser opptil 5 000 endrede linjer. |
| Versjoner å beholde | Ingen til 500 (standard 50). |
| Lange linjer | Linjer på 20 000 tegn eller mer brytes alltid. |
| Skriftstørrelse | 9 til 32 punkter. |
| Tabulatorbredde | 2 til 8 mellomrom. |
| Tekstbredde | 50 % til 100 %. |
| Zoom | 50 % til 200 %, i ti trinn. |
| Lesehastighet | 60 til 2 000 ord per minutt. |
| Navigatorbredde | 180 til 420 punkter. |
| Skrivelydklipp | Høyst 2 sekunder og 3 MB. |
| Loggtekst i diagnoserapport | De nyeste oppføringene, opptil 60 000 tegn, når den legges til i beskrivelsen av en GitHub-sak. |
| Veldig store filer | Åpnes og redigeres uten å leses inn i minnet i sin helhet. Linje- og ordtelling og disposisjonen fullføres i bakgrunnen og kan være ufullstendige inntil da. PDF-eksport av et veldig stort dokument krever mye mer minne enn redigering eller HTML- og Word-eksport; PDF-arkiv deler det opp i avgrensede deler. |

## Der Pilcrow lagrer ting

| Hva | Hvor |
| --- | --- |
| Dokumentene dine | Der du arkiverte dem. |
| Bibliotek (temaer, profiler, makroer, stilguider, bakgrunner) | I appens private lagring, eller i en mappe som heter «Pilcrow Library» inne i en mappe du velger (**Innstillinger ▸ Bibliotek ▸ Plassering**). |
| Innstillinger, API-nøkler, gjenopprettingskopier, versjonslogg | På enheten, i appens private lagring og i Nøkkelringen. Se gjennom og slett dem i **Innstillinger ▸ Generelt ▸ Lagring og personvern**. |
| Diagnoselogg | På enheten, helt til du tømmer den. |

# Chapter 82: Meldinger, bannere og tomme tilstander

Dette kapittelet forklarer de korte meldingene Pilcrow viser, slik at ingen av dem er et mysterium.

## I redigeringen og forhåndsvisningen

| Melding | Hva den betyr |
| --- | --- |
| **Nothing to preview yet. Start writing and it will appear here.** (eller «Switch to Edit and start writing.») | Dokumentet er tomt, så det er ingenting å tegne i forhåndsvisningen. |
| **Preview couldn't render: …** med **Vis kilde** og **Prøv igjen** | Forhåndsvisningen mislyktes. **Vis kilde** bytter til Rediger. **Prøv igjen** prøver på nytt. |
| En mislykket ligning eller et mislykket diagram, med en **Vis kilde**-lenke | Én blokk kunne ikke tegnes. Klikk **Vis kilde** for å hoppe til kilden til blokken og rette den. |
| **Couldn't save** med **Prøv igjen** og en lukkeknapp | Arkiveringen mislyktes. Dokumentet forblir åpent og ikke arkivert. Rett årsaken (diskplass, tillatelser, en fil som er flyttet) og velg **Prøv igjen**. |
| **Filen er endret på disken** | En annen app endret filen. **Last inn på nytt** leser den nye versjonen; **Behold gjeldende versjon** beholder det du har. |
| **Tolkingsadvarsel** | En linje der en konstruksjon sannsynligvis ikke er det du mente (kapittel 68). |
| **Erstatte eksisterende fil?** | Navnet du valgte, er allerede i bruk på det stedet. |
| **Utfyllingsfelt gjenstår** | Du skriver ut eller eksporterer med ufylte felt (kapittel 63). |
| **Panelskille** (VoiceOver-hint: «Drag to resize the editor and the preview. Double-tap to reset.») | Håndtaket mellom kilde og forhåndsvisning i Side ved side. |
| **Ord: N** | Ordtellingen i statuslinjen. |

## I dialoger og paneler

| Hvor | Melding | Betydning |
| --- | --- | --- |
| Kommandopalett | **Skriv en kommando** | Hintet i feltet. «No matching commands» vises når ingenting passer. |
| Åpne raskt | **Skriv et filnavn** | Hintet i feltet. |
| Markører i en kolonne | **Linjer (for eksempel 3-17)**, **Kolonne (for eksempel 100, eller 100-105 for å markere)** | Hint i feltene. En enkelt kolonne plasserer markører; et område markerer disse tegnene på hver linje. |
| Søkepanel | **Type to search this folder.**, **No matches in this folder.**, **Search cancelled.** | Tilstanden til et mappesøk. |
| Filpanel | **You can also drop a folder here.** | Dra en mappe til panelet for å åpne den. |
| Erstatt i mappe | **Nothing to replace.** | Søket har ingen treff. |
| Sammenlign | Verktøytips på knappene: **Godta** («Make this change in the open document»), **Avvis** («Leave this change out of the open document»), **Ta tilbake** («Put the older lines back in the document for this change only»). | Hva hver av dem gjør. |
| Oversett | **The translation could not be completed.** | Prøv igjen, eller velg en annen hastighet. |
| Oversett | **Anslått tid: under ett minutt** | Et anslag for AI-assistentens hastighet; tiden avhenger av AI-tjenesten din. Etter en oversettelse åpner **Åpne i ny fane** resultatet. |
| Assistent | **No document is open.**, **No document text is sent.** | Panelet har ingenting å dele, så ingenting sendes. |
| Modellvelger | **Laster inn modeller…**, **No models match.** | Listen lastes, eller søket ditt ga ingen treff. |
| Stilgjennomgang | **No findings.** og **The reply could not be read as findings. Try again.** | Gjennomgangen fant ingenting, eller AI-ens svar var ikke i det forventede formatet. |
| Stilgjennomgang | Verktøytipset til **Bruk alle**: «Makes every fix that has one, as a single change you can undo.» | Én Angre reverserer dem alle. |
| Prosjektpanel | **Navnet ditt**, **Legg til variabel** | Hintet i Forfatter-feltet, og knappen for en prosjektvariabel. |
| Assistenttillatelse | **Read Pilcrow's privacy policy** | Åpner personvernerklæringen. |
