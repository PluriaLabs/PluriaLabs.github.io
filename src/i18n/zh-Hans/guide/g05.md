# Part XVI — 窗口与菜单参考

# Chapter 52: 窗口总览

本章按从左到右的顺序，列出 Pilcrow 窗口中的每一个控件，Mac 和 iPad 均适用。本部分接下来的各章介绍每个菜单项，第 XVII 部分介绍每个面板和对话框。

## 标题栏

标题栏横跨窗口顶部。其中的控件依次如下：

| 控件 | 位置 | 作用 |
| --- | --- | --- |
| **导航器**（侧栏图标） | Mac 和 iPad | 显示或隐藏侧栏。其提示文字为“显示或隐藏导航器”。与 **视图 ▸ 显示或隐藏边栏** 相同。 |
| **文稿标题** | Mac 和 iPad | 显示当前文稿的名称，并带有一个表示是否已存储的圆点。点按它可打开文稿切换器和文稿操作（第 59 章）。 |
| **菜单按钮**或菜单条 | 仅限 iPad | 把 Mac 的菜单放进标题栏，供没有键盘或鼠标的 iPad 使用（第 58 章）。 |
| **文稿模式**（编辑、预览、拆分） | Mac 和 iPad | 在源码、渲染页面以及二者并排之间切换。“拆分”即**并排**。 |
| **查找**（放大镜） | Mac 和 iPad | 打开查找栏（第 62 章）。 |
| **导出**（共享图标） | Mac 和 iPad | 打开导出面板（第 64 章）。 |
| **设置**（齿轮） | 仅限 iPad | 在弹出面板中打开设置。在 Mac 上，设置位于 **Pilcrow** 菜单（**⌘,**）。 |
| **更多**（三个点） | Mac 和 iPad | 收纳标题栏放不下的操作。见下文。 |

查找、导出和模式控件仅在打开文稿时出现。

### 标题栏如何适应宽度

标题栏的设计目标是在窄窗口中仍然好用，例如与其他 App 并排平铺的 Mac 窗口，或处于分屏浏览的 iPad。窗口越窄，控件就越会按以下顺序移入**更多**菜单：

| 窗口宽度 | 你看到的内容 |
| --- | --- |
| 720 点或更宽 | 编辑/预览/拆分控件、**查找**、**导出**和**更多**。 |
| 600 至 719 | **查找**移入**更多**。 |
| 500 至 599 | **导出**也移入**更多**。 |
| 小于 500 | 模式控件变为单个按钮，其图标显示当前模式（铅笔、眼睛或两个窗格）。点按它即可选择。 |

在 iPad 上，宽度低于 580 点时模式控件变为紧凑按钮。标题总是最先缩小，宽度在 140 至 520 点之间，因此按钮的位置保持不变。使用较大的辅助功能文字大小时，上述窗口宽度会先除以 1.3，所以窗口仍然较宽时控件就会移入**更多**。

### 更多菜单

**更多**提供哪些项目取决于模式和平台。仅在源码可见（编辑或并排）时才显示的项目在下面已标出。

| 项目 | 出现时机 | 作用 |
| --- | --- | --- |
| **查找…** | 仅当标题栏没有查找按钮时 | 打开查找栏。 |
| **替换…** | 源码可见 | 打开带替换字段的查找。 |
| **前往行…** | 源码可见 | 跳转到某一行，或某行某列。 |
| **在某一列放置光标…** | iPad，源码可见 | 按编号沿某一列放置光标（第 63 章）。 |
| **列选择** | iPad，源码可见 | 一个开关。开启时，单指拖移可选择一个矩形区域的文本。 |
| **共享…** | 已打开文稿 | 通过系统共享面板共享文稿的文件。 |
| **导出…** | 仅当标题栏没有导出按钮时 | 打开导出面板。 |
| **专注** | 始终 | 专注模式的开关（见下文）。 |
| **标题折叠**、**渲染块**、**自动展开章节**、**隐藏标记**、**样式化源码**、**格式工具栏** | 源码可见 | 与视图菜单中的显示开关相同（第 55 章）。除非开启**样式化源码**，否则**隐藏标记**为灰色。 |
| **打开文件…**、**打开文件夹…** | iPad | 在侧栏关闭时打开文件或文件夹。 |
| **打印…** | iPad | 打印渲染后的文稿。 |
| **设置…**、**帮助** | iPad | 打开设置或 App 内的帮助。 |

## 工作区

标题栏下方是编辑器、预览，或两者同时显示。开启后，编辑器下方是**格式工具栏**和**状态栏**（第 61 章）。编辑器和侧栏后面可以放一张**背景**图片或视频（第 69 章）。

在**并排**模式下，源码位于预览旁边，并与预览一起滚动。窗格分隔线可以拖移，其位置会被记住。窗口窄于 520 点时，两个窗格改为上下堆叠。如果打开侧栏会使文稿的可用空间少于 640 点，侧栏就会覆盖在文稿之上，而不是挤压文稿。

## 侧栏（导航器）

侧栏可以显示**文件**、**大纲**、**搜索**、**项目**和**助手**（第 60 章）。拖移其边缘可调整大小，宽度在 180 至 420 点之间。在窄于 500 点的窗口中，侧栏占满整个宽度，并由**完成**按钮关闭它。

## 专注模式

**专注模式**会隐藏文本以外的一切。可通过 **视图 ▸ 专注模式**、**更多 ▸ 专注**或命令面板开启。开启期间会出现**退出专注**按钮，这样不用键盘也能退出。专注模式始终自动换行长行，并且有自己的文本栏，与设置中的文本栏相互独立。它没有默认快捷键；可在 **设置 ▸ 键盘** 中指定一个。

## 没有文稿时

没有打开任何文稿时，窗口会在标题“Start a document”下提供**新建文稿**和**打开文件…**。在 iPad 上，**打开文件夹…**位于**更多**中。

当 Pilcrow 启动时发现上一次会话留下了未存储的内容，会改为显示**恢复文稿**列表。恢复的原理见第 17 章。列表中的每一项都有**恢复**和**删除**，整个列表则有**全部恢复**和**全部删除**。从未存储过的文稿一旦删除就无法找回，因此**全部删除**会先询问。单文稿横幅上的**关闭**按钮表示拒绝恢复该项。

打开大文件时，窗口会显示“Opening *name*…”并带有进度指示。

# Chapter 53: 文件菜单

在 Mac 上，这些项目位于**文件**菜单。在 iPad 上，它们位于标题栏中的 **菜单 ▸ 文件**，或在按住 **⌘** 或将指针移到屏幕顶部时出现的菜单栏中。标有“仅限 Mac”的项目在 iPad 上不存在。

| 项目 | 快捷键 | 作用 |
| --- | --- | --- |
| **新建**（iPad：**新建文稿**） | `⌘N` | 创建一个未命名文稿，并加入已打开的文稿。 |
| **打开…**（iPad：**打开文件…**） | `⌘O` | 从磁盘打开文本或标记文件。 |
| **最近打开**（仅限 Mac） | | 列出最近打开的文件。**清除菜单**会清空该列表。列表为空时显示“No Recent Documents”。 |
| **快速打开…**（仅限 Mac） | `⇧⌘O` | 在已打开的文件夹中搜索文件名。没有打开文件夹时为灰色。 |
| **打开文件夹…**（iPad 标题栏菜单和更多） | | 在侧栏中打开一个文件夹。在 Mac 上，请使用侧栏自带的**打开文件夹**按钮。 |
| **浏览所在文件夹…** | | 请求权限以浏览包含当前文件的文件夹。Pilcrow 的沙盒只会单独打开一个文件；此项会把它所在的文件夹也加进来。文件夹已经打开或文稿没有文件时为灰色。 |
| **新建书籍…** | | 创建一个带清单的书籍项目文件夹（第 34 章）。 |
| **将文件夹设为书籍项目** | | 在已打开的文件夹中写入 `manifest.pilcrow`，并显示项目面板（第 34 章）。没有打开文件夹或文件夹已有清单时为灰色。 |
| **关闭文稿**（iPad：**关闭**） | `⌘W` | 关闭当前文稿；如有未存储的更改，会先询问。当设置位于最前时，`⌘W` 改为关闭设置。 |
| **全部关闭**（iPad） | `⇧⌘W` | 关闭所有文稿，并对每个未存储的文稿逐一询问。在 Mac 上，标题菜单中有**关闭所有文稿**。 |
| **保存** | `⌘S` | 存储文稿。新文稿会询问存放位置。 |
| **全部保存**（仅限 Mac） | `⌥⌘S` | 存储所有有未存储更改的文稿。没有这类文稿时为灰色。 |
| **复制**（仅限 Mac） | `⇧⌘S` | 制作一个副本并在原文稿旁打开，原文稿保持不变。 |
| **存储为…** | `⌥⇧⌘S` | 以新名称或在新位置存储，或使用另一种编码。之后该文稿就是新文件。 |
| **移到…**（仅限 Mac） | | 通过存储面板移动文件或为其重新命名（按钮显示为**移动**），文稿保持打开。 |
| **版本历史…** | | 打开文稿的已存储版本（第 17 章和第 63 章）。 |
| **与文件比较…** | | 将文稿与另一个文件比较，并让你逐项接受或拒绝每处更改（第 18 章）。 |
| **从磁盘重新载入**（仅限 Mac） | | 从磁盘重新读取文件，用于其他 App 更改了文件的情况。如果有未存储的更改，会先询问：**保存后重新载入**、**不保存并重新载入**或**取消**。没有文件的文稿为灰色。 |
| **在“访达”中显示**（仅限 Mac） | | 在“访达”中显示该文件。 |
| **导入**（仅限 Mac） | | 一个子菜单：**主题…**、**语法配置…**、**宏集合…**、**风格指南…**。每一项都会把一个文件添加到你的资源库（第 43 章）。在 iPad 上，导入位于 **设置 ▸ 资源库 ▸ 导入**。 |
| **导出…** | `⇧⌘E` | 打开导出面板（第 64 章）。 |
| **共享…** | | 共享文稿的文件。 |
| **编译书稿…** | | 编译书籍项目（第 36 章）。加载书籍项目之前为灰色。 |
| **页面设置…**（仅限 Mac） | | 设置纸张、方向和页边距，与 PDF 导出使用的设置相同。 |
| **打印…** | `⌘P` | 打印渲染后的文稿。如果文稿中有未填写的填空字段，Pilcrow 会先发出警告。 |

# Chapter 54: 编辑菜单

编辑菜单包含系统的标准命令和许多 Pilcrow 自己的命令。用于选择、行和光标的菜单项作用于源码，因此在预览中为灰色。

## 撤销、剪贴板与粘贴

| 项目 | 快捷键 | 作用 |
| --- | --- | --- |
| **撤销**、**重做** | `⌘Z`、`⇧⌘Z` | 在你的编辑记录中后退和前进。 |
| **剪切**、**拷贝**、**粘贴**、**删除**、**全选** | | 系统命令。 |
| **拷贝为 Markdown** | `⇧⌘C` | 将所选内容拷贝为 Markdown 源码。 |
| **拷贝为纯文本** | | 拷贝所选内容，并尽可能去掉结构标记。 |
| **拷贝为 HTML 代码** | | 将所选内容渲染后的 HTML 作为文本拷贝。 |
| **粘贴为纯文本** | `⇧⌘V` | 粘贴时不带剪贴板中的任何格式。 |

## 查找

**查找**是一个子菜单。

| 项目 | 快捷键 |
| --- | --- |
| **查找…** | `⌘F` |
| **替换…** | `⌘R` |
| **查找下一个** | `⌘G` |
| **查找上一个** | `⇧⌘G` |

## 拼写和语法

在 iPad 上，此子菜单只有**键入时检查拼写**，与设置中的开关相同。另外两项仅限 Mac，因为 iPad 的文本视图没有拼写面板。

| 项目 | 快捷键 | 作用 |
| --- | --- | --- |
| **显示拼写和语法** | `⌘:` | 打开系统拼写面板。 |
| **立即检查文稿** | `⌘;` | 检查整个文稿。 |
| **键入时检查拼写** | | 在你键入时为拼写错误加下划线。设置中有同样的开关。 |

## 转换与语音

| 项目 | 作用 |
| --- | --- |
| **变为大写**、**变为小写**、**首字母大写** | 更改所选内容或光标所在单词的大小写。 |
| **开始朗读**、**停止朗读** | 朗读所选内容；没有选择时朗读整个文稿。 |

## 选择

一个用于选择和移动的子菜单。

| 项目 | 快捷键 | 作用 |
| --- | --- | --- |
| **选择单词** | `⌘D` | 选择光标所在的单词。 |
| **选择行** | `⌘L` | 选择整行文件内容，而不是自动换行后的屏幕行。 |
| **选择段落** | `⌥⌘P` | 选择该段落。 |
| **跳到顶部**、**跳到底部** | `⌘↑`、`⌘↓` | 将光标移到文稿的开头或末尾。 |
| **跳到行首**、**跳到行尾** | `⌃A`、`⌃E` | 移到行的任一端。 |
| **在上方添加光标**、**在下方添加光标** | `⌃⇧↑`、`⌃⇧↓` | 在上一行或下一行再添加一个光标（第 7 章）。 |
| **选择下一个匹配项** | `⌃⌥D` | 添加所选文本的下一个匹配项。 |
| **选择所有匹配项** | `⌃⌥⇧D` | 一次选中所有匹配项。 |
| **下一个字段**、**上一个字段** | `⌥Tab`、`⌥⇧Tab` | 在宏留下的填空字段之间跳转（第 24 章）。设置中提供多组按键供选择，称为 Super Tab 按键。 |
| **在某一列放置光标…** | `⌃⇧G` | 打开一个面板，按编号沿某一列放置光标。 |

光标、匹配项、字段和命令面板的快捷键可以在 **设置 ▸ 键盘** 中更改。

## 行

| 项目 | 作用 |
| --- | --- |
| **按升序排序行**、**按降序排序行** | 对所选行排序。 |
| **反转行顺序** | 颠倒它们的顺序。 |
| **删除重复行** | 对每条重复的行只保留第一条。 |
| **删除空行** | 删除所选内容中的空行。 |
| **删除行尾空白** | 去掉行尾的空格和制表符。 |
| **合并行** | 将所选的行合并为一行。 |

## 删除范围

| 项目 | 快捷键 |
| --- | --- |
| **删除单词** | `⇧⌘D` |
| **删除行** | `⌥⇧⌘L` |
| **删除段落** | `⌥⇧⌘P` |

## 移动、翻译、导航

| 项目 | 快捷键 | 作用 |
| --- | --- | --- |
| **上移一行**、**下移一行** | `⌥⌘↑`、`⌥⌘↓` | 将当前行或所选行上移或下移。 |
| **翻译 ▸ 文稿**、**翻译 ▸ 选择** | | 打开翻译面板（第 63 章）。 |
| **前往行…** | `⌃G` | 跳转到某个行号，或某行某列。 |
| **检查链接…** | | 检查文稿中的链接和图像（第 19 章）。 |
| **命令面板…** | `⌃⇧P` | 打开命令面板（第 62 章）。 |
| **后退**、**前进** | `⌃⌘←`、`⌃⌘→` | 沿着你之前跳转过的位置回溯。 |

在底部，系统会添加**写作工具**、**自动填充**、**开始听写…**和**表情与符号**。
