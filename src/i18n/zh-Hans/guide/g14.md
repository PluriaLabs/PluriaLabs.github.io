# Part XXI — 文件格式与限制

# Chapter 79: 应用主题格式

**应用主题** 用来设定 Pilcrow 本身的样式：它的浅色或深色外观、强调色、侧栏、状态栏和格式栏，以及编辑器。它是一个 JSON 文件。渲染后的文稿（预览、HTML、PDF、图像、打印和 Word）由 **渲染主题** 单独设定样式，后者是 CSS（Chapter 80）。这两种主题分别安装、选择和删除，互不跟随。

## 一个完整的示例

```json
{
  "pilcrowAppTheme": 1,
  "name": "Nord",
  "appearance": "dark",
  "colors": {
    "accent": "#88C0D0",
    "sidebar": { "background": "#2E3440", "foreground": "#D8DEE9" },
    "bars": { "background": "#3B4252", "foreground": "#D8DEE9" },
    "editor": {
      "background": "#2E3440",
      "foreground": "#ECEFF4",
      "cursor": "#88C0D0",
      "selection": "#434C5E",
      "gutterBackground": "#2E3440",
      "gutterForeground": "#4C566A"
    },
    "syntax": {
      "heading": "#88C0D0",
      "marker": "#EBCB8B",
      "code": "#A3BE8C",
      "link": "#81A1C1",
      "muted": "#7B88A1",
      "tokens": { "strong": "#D08770" }
    }
  }
}
```

## 顶层

| 键 | 是否必需 | 值 |
| --- | --- | --- |
| `pilcrowAppTheme` | 是 | 格式版本，`1`。 |
| `name` | 是 | 1–200 个字符。显示在设置和“主题”菜单中。 |
| `appearance` | 是 | `"light"`、`"dark"` 或 `"automatic"`。 |
| `colors` | `light` 和 `dark` 主题 | 一套配色（见下文）。 |
| `light`、`dark` | `automatic` 主题 | 两套配色：一套用于系统的浅色外观，一套用于深色外观。 |
| `id` | 否 | 由 Pilcrow 为其自己的资源库写入。导入时会被忽略，导入总会分配一个新的 id。 |

`appearance` 决定 **每一个** 窗口的外观，包括菜单、设置、面板和选取器。`light` 或 `dark` 主题会固定外观；`automatic` 则跟随系统。

自动主题必须在 `light` 和 `dark` 中同时设定每种颜色，或者都不设定。只为其中一种外观设定的颜色，否则会在另一种外观中被绘制出来。

## 配色

每个键都是可选的。省略的颜色会保留 Pilcrow 的内置外观，因此一个主题可以小到只有一种强调色。

| 键 | 设定样式的对象 |
| --- | --- |
| `accent` | 整个应用的色调：按钮、选中的分段、开关、链接、焦点环，以及侧栏中选中的行。未设定则保留系统强调色。 |
| `sidebar.background`、`sidebar.foreground` | “文件”、“大纲”和“查找”侧栏。次要标签由前景色派生。 |
| `bars.background`、`bars.foreground` | 状态栏、停靠的格式工具栏和导入通知。次要标签由前景色派生。 |
| `editor.background`、`editor.foreground` | 编辑器画布和正文文本。 |
| `editor.cursor`、`editor.selection` | 插入点和选择高亮。 |
| `editor.gutterBackground`、`editor.gutterForeground` | 行号栏。背景默认为编辑器背景。 |
| `editor.currentLineRule` | 当 **视图 ▸ 当前行下划线** 开启时，光标所在行下方的细线。默认为较低强度的编辑器文本颜色。 |
| `syntax.<group>` | 按组划分的实时语法颜色（见下文）。 |
| `syntax.tokens.<raw>` | 按原始值指定的单个标记，会覆盖其所属组。 |

### 语法组

| 组 | 着色对象 |
| --- | --- |
| `heading` | 标题（标记和文本）、提醒标记、定义术语 |
| `marker` | 强调、加粗、删除线和其他行内分隔符；列表和任务标记 |
| `code` | 行内代码、围栏和缩进代码块、公式、HTML 块 |
| `link` | 链接和图像的标签与目标、自动链接 |
| `muted` | 引用标记、分隔线、表格行、注释、块属性 |
| `codeKeyword`、`codeString`、`codeNumber`、`codeComment` | 围栏内高亮显示的代码 |

未设定的组会采用根据编辑器背景选择的内置颜色：浅色画布用较深的色调，深色画布用较浅的色调。`syntax.tokens` 中的标记名称使用字母、数字、`_` 和 `-`，并且不能与组名重复（`syntax.heading` 已经涵盖 `heading`）。

## 颜色

每种颜色都是十六进制字符串：`#RGB`、`#RGBA`、`#RRGGBB` 或 `#RRGGBBAA`，使用 sRGB。Pilcrow 以大写形式存储它们。

## 验证

Pilcrow 会拒绝整个文件，而不是忽略其中一部分，并指出出错的键，例如 `colors.editor.cursor: must be a hex colour`。它会拒绝：

- 缺失或不同的 `pilcrowAppTheme` 版本；
- 任何层级上的未知键（通常是拼写错误）；
- 与外观不匹配的配色键（自动主题中出现 `colors`，或浅色、深色主题中出现 `light` 和 `dark`）；
- 不是十六进制的颜色；
- `light` 和 `dark` 配色设定了不同颜色的自动主题。

## 应用主题不会更改的内容

窗口标题栏和工具栏（系统的玻璃效果，只采用强调色）、菜单、设置、面板和选取器，除外观和强调色外，保持其原生样式。字体不受主题影响：编辑器的字体和大小在 **设置 ▸ 外观 ▸ 文字大小和字体** 中设定。

## 安装和分享

- 从 **设置 ▸ 资源库 ▸ 主题**、Mac 上的 **文件 ▸ 导入 ▸ 主题**，或 iPad 上的 **设置 ▸ 资源库 ▸ 导入**，**导入** 一个 `.json` 文件。把文件拖放到 Pilcrow 上也可以。
- `.zip` 主题包可以同时包含应用主题和渲染主题（Chapter 80）。
- 主题旁边的分享按钮会保存它的 `.json` 文件；如果该主题来自某个主题包，则保存整个主题包。

Pilcrow 内置三个应用主题：**自动**、**浅色** 和 **深色**。它们设定编辑器和语法的颜色，而让界面外框保持其内置外观。

# Chapter 80: 渲染主题 CSS 参考

**渲染主题** 就是 CSS。它为预览、HTML、PDF、图像和打印输出设定样式，也为本章末尾列出的 Word 样式设定样式。渲染主题可以是单个 `.css` 文件，也可以是带有本地资源的 ZIP 包的一部分。语法配置定义源文本如何变成文稿；渲染主题只为结果设定样式。CSS 从不影响应用或编辑器的样式；那是应用主题的职责（Chapter 79）。

## 层叠

Pilcrow 按以下顺序应用样式：

1. Pilcrow 的结构重置；
2. 所选主题的 CSS；
3. 导出面板中的一次性 CSS（**高级选项 ▸ 自定 CSS**）；
4. 必需的打印和渲染修正。

后面的规则按照正常的 CSS 层叠取胜。不支持主题 JavaScript、远程资源、`file:` URL 和 `@import`。

## 资源

Pilcrow 用标准的 CSS 词法分析器读取主题 CSS，因此转义会在检查之前先被解码：`u\72 l(…)` 就是 `url()`，`@im\70 ort` 就是 `@import`。浏览器会从中加载内容的每个位置都会被检查：`url(…)`、`url("…")`、`src("…")`，以及 `image-set()` 内的字符串。每一个都必须是以下之一：

- 相对于主题包的路径（`fonts/Body.woff2`、`./paper.png`）。允许带 `?query` 或 `#fragment`，查找文件时会忽略它们；
- 类型为 PNG、JPEG、GIF、WebP、SVG（`image/svg+xml`）、TTF、OTF、WOFF 或 WOFF2 的 `data:` URL；
- 片段引用，例如 `url(#shadow)`，它指向页面中的某个元素。

任何带有 `data:` 以外协议（`https:`、`file:`、`blob:`）或以 `//` 开头的内容都会被拒绝，以 `/` 开头或包含 `..` 的路径也一样。

## 渲染属性

内置的重置会读取这些属性，并提供备用值：

| 组 | 属性 |
| --- | --- |
| 颜色 | `--pt-background`、`--pt-foreground`、`--pt-secondary-background`、`--pt-secondary-foreground`、`--pt-accent`、`--pt-link-color`、`--pt-border-color` |
| 代码 | `--pt-code-background`、`--pt-code-foreground`、`--pt-code-keyword`、`--pt-code-string`、`--pt-code-number`、`--pt-code-comment` |
| 字体 | `--pt-body-font-family`、`--pt-mono-font-family`、`--pt-base-font-size`、`--pt-line-height` |
| 间距 | `--pt-paragraph-spacing`、`--pt-blockquote-indent`、`--pt-list-indent`、`--pt-code-padding`、`--pt-heading-top`、`--pt-heading-bottom` |
| 表格 | `--pt-table-header-background`、`--pt-table-stripe-background` |
| 提醒 | `--pt-admonition-note-color`、`--pt-admonition-tip-color`、`--pt-admonition-important-color`、`--pt-admonition-warning-color`、`--pt-admonition-caution-color` |

## ZIP 包

ZIP 包可以同时包含渲染主题（`.css`）和应用主题（`.json`）；每个主题在设置中都按其自己的类别列出。最多包含一个 CSS 文件和一个应用主题的 ZIP 不需要清单。超过这个数量就需要 `pilcrow-theme.json`，它在 `variants[].file` 下列出每个主题。文件的扩展名决定其类别：

```json
{
  "id": "com.example.paper",
  "name": "Paper",
  "version": "1.0.0",
  "author": "Example Author",
  "license": "MIT",
  "cssAPIVersion": 1,
  "variants": [
    { "id": "app", "name": "Paper", "file": "Paper.json", "appearance": "automatic" },
    { "id": "light", "name": "Paper Light", "file": "Paper-Light.css", "appearance": "light" },
    { "id": "dark", "name": "Paper Dark", "file": "Paper-Dark.css", "appearance": "dark" }
  ]
}
```

清单描述主题包及其中的主题。它从不包含样式值：这些值在 CSS 和应用主题文件中。

- 主题包的 `id` 用作安装文件夹的名称。它不能以 `.` 开头，也不能有前导或尾随空格。安装一个 `id` 已被安装的主题包会替换原来的那个。
- 用“访达”的 **压缩** 制作的 ZIP 可直接使用。Pilcrow 会跳过 `__MACOSX/`、`._*`、`.DS_Store` 和 `Thumbs.db`；当所有文件都位于同一个顶层文件夹内时，该文件夹会被视为主题包的根目录。
- 删除一个主题会把它从主题包中移除，并保留其他主题以及共享的资源。删除最后一个主题会移除整个主题包。如果被删除的主题正被选中，则选择会回到其类别的默认值：应用主题为“自动”，渲染主题为“浅色”。
- CSS 可以用相对的 `url(...)` 路径引用主题包内的 PNG、JPEG、GIF、WebP、TTF、OTF、WOFF 和 WOFF2 文件。Pilcrow 会校验它们的签名，并把被引用的资源嵌入为 data URL，使渲染和导出的 HTML 保持离线且自包含。ZIP 路径不能逃出主题包、不能因大小写而冲突，也不能指向链接。压缩包大小、条目数量、单个文件大小和压缩比都有上限。

## Word

Word 导出使用浅色（基础）`:root` 的值，并把这些语义属性映射到命名的 Word 样式中：`--pt-foreground`、`--pt-background`、`--pt-accent`、`--pt-link-color`、`--pt-code-background`、`--pt-code-foreground`、`--pt-body-font-family`、`--pt-mono-font-family`、`--pt-base-font-size` 和 `--pt-line-height`。浏览器选择器和布局规则在 Word 中没有通用的对应项。预览、HTML、PDF 和图像输出使用完整的样式表；Word 使用这个子集，同时保留文稿结构、图表、公式图片、链接和媒体。每当选择 Word 时，导出面板都会显示这一限制。

Pilcrow 内置两个渲染主题，**浅色** 和 **深色**，它们都是完整的起点。
