# Chapter 68: 编辑

## 显示与输入

### 显示

| 控件 | 作用 |
| --- | --- |
| **显示行号** | 在边栏中显示行号。与 **视图 ▸ 行号** 相同。 |
| **在当前行下方显示横线** | 在光标所在行下方显示一条细线。 |
| **样式化源码** | 用相应的字体样式绘制标题、粗体和斜体。 |
| **标题折叠** | 在标题旁显示折叠箭头。 |
| **渲染块** | 将表格、公式和图表绘制为图片，并带有编辑按钮。 |
| **自动展开章节** | 当光标进入折叠的章节或图片块时将其展开，光标离开时再将其关闭。 |
| **隐藏标记** | 隐藏除光标所在行以外每一行的标题、粗体和斜体标记。需要启用“样式化源码”。 |
| **长行自动换行** | 关闭时，长行会横向滚动而不是换行。预览和导出始终会换行。20,000 个字符或更长的行，以及专注模式，始终会换行。 |
| **列模式中的短行** | 当某行太短而无法到达所选列时，列模式的行为：**使用行尾**、**跳过该行**、**用空格软补齐**（添加空格，使键入的文本在屏幕上对齐）、**用空格硬补齐**（为每个缺少的字符补一个空格，使其按列号对齐）或 **在该行处停止**。删除操作绝不会从短行中移除字符。 |
| **显示状态栏** | 开启或关闭底部的状态栏。 |
| **格式工具栏** | 在文本下方显示可选的工具栏。 |

### 输入

| 控件 | 作用 |
| --- | --- |
| **自动配对括号和引号** | 输入左括号或左引号时会自动添加右括号或右引号。 |
| **自动配对 Markdown ( \* \_ ` ~ )** | 对 Markdown 的标记执行同样的操作。 |
| **展开表情符号短代码（:smile:）** | 在你输入时将短代码转换为表情符号。已经包含短代码的文件会按原样显示。 |
| **按回车键延续列表和引用** | 按回车键开始下一项，在空项上按回车键结束列表，按 Tab 键缩进项目。 |
| **按回车键保持缩进** | 新的一行以与上一行相同的前导空格或制表符开头。 |
| **按 Tab 键时插入空格** | Tab 键会插入与制表符宽度相同数量的空格，直到下一个制表位，而不是插入制表符字符。 |

智能标点、高亮、下标和上标位于 **资源库 ▸ CommonMark 选项** 中。

### 键入声音

| 控件 | 作用 |
| --- | --- |
| **输入时播放声音** | 每个按键都会发出声音；空格、回车和删除的声音各不相同。粘贴和撤销时保持静音。在 iPad 上，静音开关会将其静音。 |
| **声音** | 声音包：**打字机**、**鸭子** 或 **小猫**。 |
| **音量**、**预览** | 设置音量并试听声音包。 |
| **自定声音** | 为任意一类按键选择一段短音频；其他按键仍使用上面选定的声音。类别有 **小写字母**、**大写字母**、**数字**、**符号和标点**、**空格**、**制表符**、**换行** 和 **删除**。每一类都有 **选择…**（或 **更改…**）、**播放** 和 **移除**。音频片段最长 2 秒、最大 3 MB（WAV、AIFF、MP3、M4A 或 CAF），并存放在内存中，因此播放时没有延迟。 |

### 拼写与诊断

**键入时检查拼写** 会在拼写错误处加下划线。**显示解析警告** 会标出那些很可能不是你本意的结构所在的行，例如未闭合的代码围栏或公式块、缺少右括号的链接，或与表头不匹配的表格行。提示显示在该行末尾。它只改变显示的内容，绝不改变文档的解析或导出方式。

## 图像

这些设置决定了你插入图像（**插入 ▸ 图像…**，或通过拖放）时会发生什么。

| 控件 | 作用 |
| --- | --- |
| **操作** | **无特殊操作**、**将图像复制到当前文件夹 (./)**、**将图像复制到 ./assets** 或 **Copy image to ./\${filename}.assets**。**上传图像** 显示为不可用：Pilcrow 没有图像托管服务，因此图像会按其原有位置插入。 |
| **应用于本地图像** | 该操作是否适用于已在你设备上的图像。 |
| **应用于在线图像** | 是否适用于指向网址的图像。 |
| **从互联网加载图像** | 关闭时，指向网址的图片不会为预览、PDF 或图像导出而下载，因此托管它们的网站不会获知任何信息。开启时，它们会像在网页浏览器中一样被获取，该网站可以看到这次请求。 |
| **尽可能使用相对路径** | 写入相对于文档的路径。 |
| **为相对路径添加 ./** | 让相对路径以 `./` 开头。 |
| **插入时转义图像 URL** | 转义地址中会破坏链接的字符。 |

# Chapter 69: 外观

## 主题与背景

| 控件 | 作用 |
| --- | --- |
| **应用主题** | App 和编辑器的外观：**自动**、**浅色**、**深色**，或你添加的任何主题。它决定浅色或深色、强调色、侧栏和各种栏，以及编辑器。自动跟随系统。渲染模式和导出使用渲染主题，在“导出”下选择。 |
| **界面大小**（iPad） | 菜单、栏、侧栏和对话框的大小：**系统大小**（跟随 iPad 的“文字大小”）、**小一级**、**小两级**、**小三级**。编辑器的文字有它自己的大小。 |
| **标题栏中的菜单**（iPad） | **自动**（连接键盘或鼠标时隐藏 Pilcrow 自己的菜单）、**始终** 或 **从不**。 |
| **缩放** | 编辑器和预览的大小：50%、67%、80%、90%、100%、110%、125%、150%、175% 或 200%。与 **视图 ▸ 放大** 和 **缩小** 相同。 |
| **阅读速度** | 每分钟字数，从 60 到 2,000，用于估算阅读时间。 |

## 编辑器背景（背景图）

编辑器、侧栏和状态栏的后面可以放一张图片或一段视频。

| 控件 | 作用 |
| --- | --- |
| **媒体** | **选择…** HEIC、PNG、JPEG 或 SVG 图片，或 MP4、MOV 或 M4V 视频。**移除** 会将其清除。 |
| **布局** | **填充**、**适应** 或 **拼贴**。 |
| **文本区域后面**、**侧栏后面** | 各自有独立的 **淡化** 和 **模糊**。**淡化** 会用主题的背景色覆盖图片，使文字保持易读；**模糊** 会使其变柔和。状态栏会将其模糊。 |
| **使用电池时也播放** | 允许视频在电池供电时播放。视频在低电量模式下会暂停，开启“减弱动态效果”时会保持静止。 |
| **声音**、**音量** | 视频默认静音播放，除非你开启它的声音。 |

背景图绝不会出现在预览或导出中，并且“降低透明度”会将其隐藏。

## 文字大小和字体

| 控件 | 作用 |
| --- | --- |
| **字体大小** | 编辑器的字体大小，9 到 32 点。编辑器字体、适配各种文字的字体和行节奏会一同调整大小，并立即生效。 |
| **行距** | 行与行之间的间距，以字体大小的倍数表示，步长为 0.1。 |
| **制表符宽度** | 一个制表符绘制的宽度，为 2 到 8 个编辑器字体的空格宽度。 |
| **文本宽度** | 文本占编辑器宽度的比例，从 50% 到 100%，居中。专注模式有它自己的栏宽。 |
| **编辑器字体**、**边栏字体** | 用于文本的字体和用于行号的字体。筛选器（**全部**、**等宽**、**无衬线**、**衬线**）会缩小列表范围，但不会更改你的选择。默认值为 **系统默认** 和 **系统等宽**。 |

# Chapter 70: 目录与导出默认设置

## 目录与标签

这些设置适用于所有导出格式：PDF、Word、HTML 等。

| 控件 | 作用 |
| --- | --- |
| **为每次导出添加目录** | 在每份导出内容的顶部放置一个目录列表。 |
| **用列表替换 [TOC] 行** | 仅含 `[TOC]` 的一行会在预览和每种导出中变成标题列表。 |
| **为标题编号（1.、1.1.）** | 在输出中为标题编号。下面的标题标签会取代普通编号。 |
| **标题** | 列表的名称，例如“目录”或“说明”。留空则使用“目录”。 |
| **列出标题的最大级别** | 深度，1 到 6。级别 1 只列出顶级标题；级别 6 列出全部标题。 |
| **缩进** | 每一级的缩进，以点为单位。 |
| **让每个标题链接回其目录条目** | 添加从标题到其条目的返回链接。 |
| **只列出 [TOC] 行下方的标题** | 省略 `[TOC]` 行上方的标题。 |

### 标题标签

**为标题添加标签** 会给每一级设置各自的标签，例如“Part I -”或“Chapter 3:”。每一级都有一个模板。在模板中，`#` 表示下一个数字，`@` 表示下一个大写字母；一个标签可以使用其中一个，但不能两者都用。写作 `\#` 或 `\@`，则每当出现更浅一级的标题时重新开始计数；不加反斜杠时，会在整个文档中持续计数。**字母** 和 **数字 0 到 9** 设置用于字母编号和数字编号的字符。在最后一个字母之后，字母会翻倍：Y、Z、AA、AB。

| 控件 | 作用 |

| **页面** | 用于打印以及每次 PDF、PDF 存档和 Word 导出的纸张大小、方向和页边距（第 64 章）。 |
| **页眉模板**、**页脚模板** | 每页顶部和底部的文字。变量：`${title}`、`${author}`、`${pageNo}`、`${pageCount}` 和 `${today}`。例如页脚 `Page ${pageNo}`。 |
| **作者** | `${author}` 以及文档元数据中使用的作者名称。 |
| **在顶级标题之间分页** | 让每个顶级标题从新的一页开始。 |

# Chapter 71: 资源库

资源库是你添加的主题、语法配置、宏、风格指南和背景。内置项目是只读的；如需更改，请先复制一份。

## 语法配置

将每个配置列为 **内置** 或 **自定**。

| 控件 | 作用 |
| --- | --- |
| **导入…** | 添加别人分享的配置 `.json` 文件。 |
| **新建** | 从头开始创建配置。 |
| **编辑**、**复制**、删除 | 针对每个配置。内置配置可以复制，但不能编辑或删除。 |
| **未加载** | 无法加载的配置会连同原因列在此处：它使用了其他配置已有的文件扩展名、不是此版本能读取的配置，或包含可能使编辑器停止响应的模式。它仍在你的配置文件夹中。 |

配置的编辑见第 74 章。

## CommonMark 选项

可选 CommonMark 语法的开关。只启用你的源文件用到的内容。

| 部分 | 控件 |
| --- | --- |
| **语法支持** | **高亮（==key==）**、**下标（H~2~O）**、**上标（X^2^）**、**行内公式（$…$）**。 |
| **其他语法** | **自动链接（纯 URL）**、**GitHub 样式提醒**、**YAML 前置元数据**（位于最顶部的由 `---` 行围成的块会被淡化，并从预览和每种导出中省略）、**图表与统计图（Mermaid、Vega-Lite）**。 |
| **智能标点** | **转换**：**输入时转换**、**渲染时转换** 或 **关闭**。然后是 **智能引号**、**智能破折号**、**智能省略号**。 |
| **围栏代码块** | **显示行号**、**长行自动换行** 和 **缩进大小**（以空格计）。 |

在对应选项开启之前，格式 ▸ 高亮、下标、上标和行内公式会显示为灰色。

## 主题

“主题”页面列出 **应用主题**（JSON：App 的浅色或深色外观、强调色、侧栏、栏和编辑器）和 **渲染主题**（CSS：预览、HTML、PDF、图像和打印输出，以及 Word 样式）。每个都标有 **内置** 或 **自定**，以及 **浅色**、**深色** 或 **自动**。

| 控件 | 作用 |
| --- | --- |
| **新建** | 创建任一种主题。 |
| **导入主题…** | 添加 `.json` 应用主题、`.css` 渲染主题，或包含其中一种或两种的 `.zip` 包。 |
| **打开主题文件夹** | 显示存放你的主题的文件夹。 |
| **编辑**、**复制**、**导出**、删除 | 针对每个主题。内置主题是只读的。 |

主题的编辑见第 75 章。

## 宏

列出宏集合。内置集合是只读的。

| 控件 | 作用 |
| --- | --- |
| **新建合集**、**导入宏…** | 开始一个集合，或导入 `.json` 集合。 |
| 集合的菜单 | **重命名…**、**复制合集**、**导出合集…**、**删除合集**。 |
| **新建**、**编辑**、**复制**、删除 | 针对每个宏。 |

宏的编辑见第 76 章。带有不安全触发器的导入集合会被拒绝。

## 风格指南

列出风格指南，每份都带有其规则数量和范围。

| 控件 | 作用 |
| --- | --- |
| **导入风格指南…** | 添加指南 `.json` 文件。 |
| 指南的菜单 | **复制风格指南**、**导出风格指南…**、**删除风格指南…**。删除会在你确认后将其从此设备移除，因此如果想保留副本，请先导出。 |
| “基于 …” | 一份指南可以基于另一份。如果那份指南缺失，则无法使用。 |

风格指南是一个包含命名规则的 `.json` 文件。你也可以请助手撰写一份（**助手 ▸ 帮助 ▸ 风格指南**），**帮助 ▸ 风格指南** 会说明其格式。

## 渲染库

公式、图示和统计图由内置的库在此设备上绘制。此页面列出每个库及其版本；选择其中一个即可阅读其随附的声明。

## 位置

你的资源库位于你所选文件夹内一个名为“Pilcrow Library”的文件夹中。iCloud 云盘中的文件夹会让它在你的各台设备之间保持同步。偏好设置、API 密钥和崩溃恢复副本始终保留在此设备上。

| 控件 | 作用 |
| --- | --- |
| **保存位置** | 资源库当前所在的位置：“在此设备上”或“在文件夹 *名称* 中”。 |
| **选择文件夹…** | 将资源库移到某个文件夹。如果该文件夹中已有 Pilcrow 资源库，Pilcrow 不会合并两者：你可以 **使用现有内容**。否则选择 **将我的资源库移到此处**（检查每个文件，然后移除旧副本）或 **将我的资源库拷贝到此处**（保留旧副本）。 |
| **使用此设备** | 将资源库带回此设备。 |

如果无法访问所选文件夹，Pilcrow 会暂时使用此设备上的资源库，不更改也不删除任何内容，并在该文件夹可用时再次使用它。

## 导入（iPad）

在 iPad 上，**导入** 会将项目添加到资源库：**导入主题…**、**导入语法描述文件…**、**导入宏集合…**、**导入风格指南…**。在 Mac 上，请使用 **文件 ▸ 导入**（第 53 章）。
