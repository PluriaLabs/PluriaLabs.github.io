# Chapter 65: 助手面板与风格审阅

在 **设置 ▸ 助手** 中设置好连接后，助手面板才会出现（第 67 章）。在没有可用连接时，“视图”菜单中不会显示 **助手** 项。

## 面板

| 控件 | 作用 |
| --- | --- |
| **助手模式** | **对话**、**风格审阅** 或 **帮助**。 |
| **选择模型…** | 打开模型选择器（见下文）。当模型不再可用或已被弃用时会显示警告，并注明停用日期。 |
| **清除对话** | 清空对话。对话不会被保存；App 退出时会被丢弃。 |
| **要分享的内容** | 选择随提问一起发送的内容：**不分享文档内容**、**选择**、**分区**、**光标附近**、**整个文档**、**大纲** 或 **配置**。无法适用的选项会说明原因（“请先选择一些文本。”“此文档没有标题。”“太大，无法整份发送。”“没有语法配置。”）。提问框上方有一行文字，说明将发送多少内容、发往哪个主机。你的选择会被记住。 |
| **预览**（以及 **发送的内容**） | 精确显示将要发送的内容。 |
| **向助手提问…** / **描述你想写的内容** | 提问框。在 **帮助** 模式下，**编写内容** 可选择 **语法描述文件**、**宏** 或 **风格指南**。 |
| **发送** 和 **停止** | 发送请求，或停止正在进行的回复。 |
| **隐私** | 显示助手在此文件夹中是否已开启。**为此文件夹关闭** 和 **为此文件夹开启** 可切换。对于符合排除规则的文件，会显示“此文件已被排除在助手之外。” |
| 每条回复 | **拷贝**、**在光标处插入**、**重试**，对于风格或宏的回复，还有 **添加到资源库…**。出错的回复会提供 **请求修正**。被截断的回复会有说明。 |

## 选择模型

**选择模型…** 会列出该连接提供的模型，并提供 **搜索模型**。**显示所有模型** 会包括较不常用的模型。已弃用的模型会标明其停用日期。如果没有列出任何模型，请直接输入模型名称。**重试** 会重新加载列表。

## 风格审阅

在 **风格审阅** 模式下，面板会用风格指南检查你的文字。

| 控件 | 作用 |
| --- | --- |
| **风格指南**、**变体** | 选择一份指南及其中的一个变体。 |
| **审阅范围** | **选择** 或 **文稿**。太大而无法整份审阅的文档会显示“太大，无法整份审阅。请改为审阅某个分区。” |
| **范围** | 选择要检查哪些范围，或选择 **所有范围**。 |
| **审阅** | 将文本和规则发送到你的 AI 连接。在审阅整个文档之前，会弹出提示，说明将发送多少个请求、大约多少文本，并询问 **审阅** 还是 **取消**。 |
| **在此检查** | 在此设备上运行该指南自带的检查。不会发送任何内容。 |
| **检查交叉引用** | 发送标题、引用行和参考文献列表，以检查那些需要将文档的某一部分与另一部分进行比较的规则。 |
| **停止** | 停止正在进行的审阅。**审阅其余部分** 会在停止或失败后继续。 |

审阅结果会显示在列表中。每条结果都包含引文、说明，以及（如果有的话）建议的修正。

| 按钮 | 作用 |
| --- | --- |
| **跳转到** | 移到文档中的该条结果处。若引文出现多次，会显示“第 N 处，共 N 处”。 |
| **应用** | 执行建议的修正。仅当文本与发现时完全一致时才会应用。否则会显示“文本已更改。”或“在文本中未找到。” |
| **忽略** | 移除该条结果。 |
| **全部应用** | 执行每一条带有修正的结果，执行前会有确认提示，说明修正的数量，并作为一次更改，可一步撤销。它还会说明有多少修正来自 AI。 |
| **忽略所有建议**、**清除** | 清空列表。 |

面板还会报告“有 N 条规则只能通过审阅来判断”“有 N 条规则在 100 条结果后停止”，以及“某项建议的更改已被省略，因为它添加了文本中没有的事实。”

# Chapter 66: 设置的组织方式

从 Mac 上的 **Pilcrow ▸ 设置…**（`⌘,`）打开设置，在 iPad 上则从标题栏中的齿轮图标打开，它会以带有 **完成** 按钮的面板形式出现。窗口左侧有一个 **搜索设置** 框和一列 **类别**。每个类别有一个或多个 **页面**，以一排按钮的形式显示在顶部。

| 类别 | 页面 |
| --- | --- |
| **通用** | 语言与窗口（iPad：**语言**）、文件、翻译、助手、诊断、存储与隐私 |
| **编辑** | 显示与输入、图像 |
| **外观** | 主题与背景、文字大小和字体 |
| **目录** | 目录与标签 |
| **导出** | 导出默认设置 |
| **资源库** | 语法配置、CommonMark 选项、主题、宏、风格指南、渲染库、位置（iPad 还有 **导入**） |
| **键盘** | 快捷输入 |
| **订阅与积分** | 支持 Pilcrow |

**搜索设置** 按名称查找控件。输入标签的一部分，例如“行距”或“版本”，结果会显示该控件、所在页面及其类别。选择其中一项即可直接前往。更改会立即生效；除主题、配置、宏和键盘快捷键的编辑器外，没有“存储”按钮。

仅影响某一台 Mac 或某一台 iPad 的设置会保留在该设备上。你的资源库（主题、配置、宏、风格指南和背景）可以移到你选择的文件夹中，包括 iCloud 云盘中的文件夹（第 71 章）。

# Chapter 67: 通用

## 语言与窗口

| 控件 | 作用 |
| --- | --- |
| **语言** | 选择 Pilcrow 的语言，与设备的语言无关。**系统默认** 跟随设备。使用 AI 翻译的语言会显示“机器翻译，可能包含错误。”更改会在你下次打开 Pilcrow 时生效，在 Mac 上有 **立即退出** 按钮。 |
| **启动 Pilcrow 时显示翻译提示** | 在你选择了 **不再显示** 之后，重新开启“由 AI 翻译”的提示。 |
| **关闭最后一个窗口时退出 Pilcrow**（Mac） | 在你关闭最后一个窗口时退出 App，而不是让它继续运行。 |

## 文件

| 控件 | 作用 |
| --- | --- |
| **启动时** | Pilcrow 启动时打开的内容：**打开新文件**、**恢复上次关闭的文件夹**、**恢复上次关闭的文件和文件夹** 或 **打开自定文件夹**（带有 **选择…** 按钮）。恢复会重新打开 App 上次退出时屏幕上的内容。之后已被移动或删除的文件会被跳过。 |
| **新文稿存储为** | 新文档的文件类型，也就是语法配置：每个配置连同其扩展名，例如“CommonMark (.md)”。 |
| **自动保存更改** | 在你工作时存储已有文件的文档。 |
| **关闭文件时不询问直接保存** | 跳过“是否要存储？”的提问并直接存储。 |
| **保留的版本数** | Pilcrow 为“版本历史”保留每个文件多少个已存储的版本，从无到 500 个。默认为 50。“保留的版本数：无”会关闭历史记录。 |
| **记录最近使用的文件和文件夹** | 让 Pilcrow 记住你打开过的内容，用于 **最近打开** 以及启动时的恢复。 |
| **显示隐藏的文件夹和文件** | 在“文件”面板中显示名称以点开头的项目。 |
| **当有项目拖放到 App 上时** | 当你把项目拖放到编辑器或侧栏上时的行为：对于 **文件夹** 或 **Markdown 文件**，为 **在编辑器中打开** 或 **插入链接**；对于 **可导入的文件**（主题、语法配置或宏集合），为 **在编辑器中打开**、**插入链接** 或 **导入文件**。 |

## 翻译

翻译需要 macOS 15 或 iPadOS 18 或更高版本。

| 控件 | 作用 |
| --- | --- |
| **翻译为** | 你的默认目标语言。第一个选项是“系统语言”。 |
| **速度** | **快速**、**最佳质量** 或 **AI 助手**。快速适合长文档，速度可快约二十倍，但措辞较为平实；它需要 macOS 或 iPadOS 26.4。**AI 助手** 会把文本发送到你在 **设置 ▸ 助手** 中设置的连接；你的服务可能会对此收费，且文本会离开设备。 |
| **当文件使用其他语言时** | **不执行任何操作**、**提示翻译** 或 **自动翻译**。Pilcrow 会在你打开文件时判断其语言，此过程不会有任何内容离开设备。提示会显示一个栏，可选择翻译为你的默认语言。 |
| **对所有文件再次提示** | 清除你设为 **不再对此文件提示** 的文件。 |
| **翻译后** | **在新标签页中打开**、**在原文件旁保存副本**（文件名为原文件名加上语言，例如 `Notes_fr.md`），或 **替换文稿**（可以撤销）。 |
| **此设备上的语言** | 列出每种语言及其状态：**在此设备上**、**下载** 或 **不可用**。翻译使用保留在设备上的语言包。下载语言包时会向系统请求权限；若要移除，请在系统的语言设置中操作。 |

## 助手

| 控件 | 作用 |
| --- | --- |
| **启用 AI 助手** | 将助手面板添加到侧栏。在你提问之前不会发送任何内容，并且只发送你选择分享的文本。 |
| 状态行 | **就绪。**，或未就绪的原因：“当前连接的地址不可用。”“当前连接需要 API 密钥。”或“请在下方添加连接。连接就绪后会出现助手窗格。” |
| **连接** | 连接列表，为空时显示“尚无连接。”每一项会显示其名称，正在使用的那个会显示 **当前**。每行提供 **设为当前**、**编辑…** 和 **移除**。 |
| **添加连接** | 一个菜单：**OpenAI**、**Anthropic**、**OpenRouter**、**Ollama（此电脑）**、**LM Studio（此电脑）** 或 **自定义…**。 |
| **已排除的文件** | 永不分享的文件的匹配模式。`*` 代表名称中的任意字符，`**` 代表任意文件夹，以 `/` 结尾的名称涵盖整个文件夹。默认包括 `*.pem`、`.env*`、`*.key` 和 `secrets/`。可以 **添加** 一个模式、**移除** 一个模式，或 **还原默认设置**。 |
| **已关闭的文件夹** | 列出你已关闭助手的文件夹，每个都带有 **开启**。没有时显示“没有已关闭的文件夹。” |
| **隐私** | 一个用于阅读 Pilcrow 隐私政策的链接，以及 **删除所有 AI 数据…**，它会移除所有连接和已存储的密钥、对话以及你的隐私选择，并关闭助手。操作前会先询问。 |

你的 API 密钥只存储在此设备的钥匙串中。

### 连接表单

**添加连接** 和 **编辑…** 会打开一个表单。

| 字段 | 作用 |
| --- | --- |
| **名称** | 连接的标签。 |
| **格式** | **兼容 OpenAI** 或 **Anthropic**。 |
| **地址** | 服务的网址。请使用 `https://`，仅在连接本机或本地网络时才使用 `http://`。 |
| **允许在我的本地网络中使用未加密的连接** | 允许在你的网络中使用 `http://` 地址。这会以明文发送你的文本和密钥，因此只有在你信任该网络时才允许。 |
| **模型** | 要使用的模型，可通过 **选择…** 从服务的列表中挑选。 |
| **需要 API 密钥** 和 **API 密钥** | 服务是否需要密钥，以及密钥本身，存放在钥匙串中。编辑时留空则保留已存储的密钥。 |
| **测试连接** | 检查地址、密钥和模型。先显示“正在测试…”，然后显示“已连接（N 毫秒）。” |
| **取消**、**存储** | 关闭或保留该连接。 |

## 诊断

| 控件 | 作用 |
| --- | --- |
| **记录诊断日志** | 记录 Pilcrow 正在做什么，以便在出问题时发送给支持人员。在你分享之前，它会一直保留在设备上，并且设计为不包含你的文档文本和文件名。开启期间，状态栏中会显示红色的 **正在记录日志** 标记。 |
| **记录停止时间** | **1 小时**、**24 小时** 或 **从不**。 |
| **记录内容** | Pilcrow 每个部分的级别：**文本编辑器**、**宏**、**主题**、**解析与描述文件**、**渲染与图表**、**导出与打印**、**文件与资源库** 以及 **App**。每一项可设为 **仅问题**、**常规**、**详细** 或 **全部**。问题和错误始终会被保留。 |
| **重现问题** | 将每个部分都设为“详细”并开始记录。让问题再次出现，然后完成报告。 |
| **添加日志** | 报告错误时：**每次询问**、**始终添加** 或 **从不添加** 日志的最新条目到你的剪贴板，以便粘贴到表单中。 |
| **报告错误…** | 与 **帮助 ▸ 报告错误…** 相同。 |
| **包含在报告中** | 以下各项的开关：**设备与系统信息**、**Pilcrow 设置**、**文档结构（仅计数）**、**速度与内存**、**近期操作轨迹** 和 **崩溃详情**。文档结构是指文档有多少个标题、表格等，绝不包含其中的文字。此屏幕不会发送任何内容。 |
| **查看日志…** | 打开日志查看器（见下文）。 |
| **清除日志…** | 在询问后，从此设备永久删除已记录的日志。关闭记录会保留已记录的内容，直到你清除为止。 |

在你为错误报告记录日志时，**重现中 — 完成报告**（或“帮助”菜单中的 **完成错误报告**）会停止记录并完成报告。在这种情况下，记录会在 30 分钟后自动停止。

### 日志查看器

**诊断日志** 会显示摘要（**条目**、**会话**、**错误**、**警告**、**崩溃报告** 以及日期范围），然后是条目列表（最新的在前），带有 **搜索日志** 字段以及 **部分** 和 **级别** 筛选。筛选只改变你看到的内容，不改变发送的内容。报告包含日志中的每个条目，加上你在“包含在报告中”下选择的内容。**重新加载** 会刷新。**发送报告** 提供：

| 项目 | 作用 |
| --- | --- |
| **存储报告…** | 保留一个文件，供你自行发送。 |
| **共享报告…** | 打开共享面板（AirDrop、“文件”等）。 |
| **在 GitHub 上报告…** | 打开一个带有简短摘要的新 issue。你可以选择 **将日志添加到描述**（最新的条目，最多 60,000 个字符，这是 GitHub 允许的上限，会拷贝到你的剪贴板以便粘贴）或 **存储并附加文件**（完整日志，放在一个由你自己添加的文件中）。在 GitHub 上的报告是公开的。 |

当你在没有任何记录的情况下开始报告时，Pilcrow 会询问 **先记录问题吗？**：**先记录问题**、**立即报告** 或 **取消**。当它打开表单时，会询问是否 **添加日志并打开表单**、**始终添加日志**，或 **不带日志打开表单**。

## 存储与隐私

Pilcrow 在其沙盒内保存恢复副本、历史记录、访问授权和支持数据。每个类别都可以单独删除。这些控件绝不会删除你的文档。

| 部分 | 控件 |
| --- | --- |
| **文稿** | **查看恢复数据** 和 **查看版本历史**。查看会列出受影响的项目及其大小，让你在删除任何内容之前就能看到占用的空间。勾选要删除的项目（**全选** 或 **全不选**），然后选择 **删除所选**。当文档有未存储的更改时，无法查看恢复数据：请先存储或关闭它。 |
| **文件访问** | **清除最近文件的访问权限…** 会移除最近文件列表、记住的“存储为”文件夹、会话书签以及每个文件的语法选择。 |
| **私有数据与支持数据** | **删除 AI 数据和密钥…**（连接、钥匙串密钥、当前对话和 AI 隐私选择）、**删除诊断信息…**（已记录的日志和已存储的崩溃诊断）以及 **清除缓存…**（可重新生成的缓存文件和网络响应）。 |

每次删除都会要求确认（“此操作无法撤销。你的文档不会被删除。”）。自定义的语法配置、主题、宏、风格指南和背景不会在此处移除；请在它们各自的“资源库”页面中查看和删除。
