# Chapter 75: 主题编辑器

主题分为两种，各有各的编辑器。两者都可从 **设置 ▸ 资源库 ▸ 主题** 打开：**新建** 用来创建主题，**编辑** 用来修改自定主题，**复制** 用来拷贝内置主题，以便修改副本。内置主题无法编辑。

## 渲染主题编辑器

**编辑渲染主题** 用来设定预览、HTML、PDF、图像和打印输出的样式。其中的 Pilcrow 自定义属性也会设定 Word 样式。渲染主题不会影响应用或编辑器的样式。

| 部分 | 作用 |
| --- | --- |
| **名称** | 主题的名称。 |
| **外观** | **自动**、**浅色** 或 **深色**。 |
| **CSS** | 样式表，在代码编辑器中编写。属性和类请参见 Chapter 80。 |
| **渲染后的预览** | 一份示例文稿，会在你输入时用你的 CSS 绘制，让你看到效果。 |
| **CSS 诊断** | Pilcrow 在 CSS 中发现的问题，例如不被允许的远程资源。 |
| **取消**、**保存** | 关闭或保留主题。有更改时关闭，会询问 **要放弃主题的更改吗？**，可选 **放弃更改** 或 **继续编辑**。 |
| **基线** | **重置为基线** 会（在你确认后）放弃自主题创建、复制或导入以来的所有更改。**设为新基线** 会保存主题，并把它的当前状态设为还原点。 |

## 应用主题编辑器

**编辑应用主题** 用来设定 Pilcrow 本身的样式：外观、强调色、侧栏、各种栏和编辑器。

| 部分 | 作用 |
| --- | --- |
| **名称** | 主题的名称。 |
| **外观** | **自动**、**浅色** 或 **深色**。自动主题有两套配色。 |
| **正在编辑颜色：** | 对于自动主题，可选 **浅色** 或 **深色**：表示你正在编辑它两套配色中的哪一套。 |
| 颜色，分五组 | **应用**（强调色）、**侧栏**（背景和前景）、**状态栏和格式栏**（背景和前景）、**编辑器**（背景、前景、光标、选择、行号栏背景、行号栏前景、当前行下划线），以及 **语法**（标题、标记、代码、链接、弱化，以及代码的关键字、字符串、数字和注释）。每种颜色在你设定之前都显示 **默认**，并有一个 **重置** 按钮可将其还原。 |
| **预览** | Pilcrow 的缩略图，包含侧栏、编辑器和状态栏，以你所选的颜色显示，可切换浅色或深色。 |
| **取消**、**保存**、**基线** | 同上。 |

主题还可以为个别语法标记设定颜色。这些颜色会被保留，但需要在主题的 JSON 文件（`syntax.tokens`）中编辑；请参见 Chapter 79。

# Chapter 76: 宏编辑器

从 **设置 ▸ 资源库 ▸ 宏** 打开宏编辑器：在某个集合中点按 **新建**，或在某个宏上点按 **编辑**。其标题为 **新建宏** 或 **编辑宏**。

| 字段 | 作用 |
| --- | --- |
| **名称** | 宏的标签。 |
| **触发词**（例如 `/sig`） | 启动宏的文本。输入触发词后接空格、制表符或回车，宏就会展开。 |
| **匹配** | 触发词的解读方式：**精确文本**、**前缀** 或 **正则表达式**。可能导致编辑器卡死的正则表达式会被拒绝：“That regular expression could hang the editor. Simplify it.” |
| **替换** | 展开后的文本。 |
| **插入日期/时间** | 一个菜单，用来向替换文本中添加日期或时间标记。 |
| **已启用** | 开启或关闭宏，而不必删除它。 |
| **不在代码中展开** | 阻止宏在行内代码和代码块中触发。 |
| **取消**、**保存** | 关闭或保留宏。如果无法保存，消息会说明原因。 |

在替换文本中，`$1`、`$2` 等是制表位，`$0` 是光标最终停留的位置。宏展开后，按 Tab（或 **下一个字段**）可在各制表位之间跳转。日期和时间使用标记：`{{date:yyyy-MM-dd}}`、`{{time:HH:mm:ss}}` 和 `{{datetime:MM/dd/yyyy h:mm a}}`，以及命名格式 `iso8601`、`rfc2822`、`unix`、`short`、`medium`、`long` 和 `full`。字段下方的 **Now:** 一行会显示此刻替换文本将生成的内容。

# Chapter 78: 在 iPad 上使用 Pilcrow

Pilcrow 可在 iPadOS 17 或更高版本上运行。它既可仅用触控操作，也可配合外接键盘，以及触控板或鼠标使用。

## 触控

- **窗格分隔条。** 在并排模式下，拖移源码与预览之间的分隔条即可调整它们的大小。双击分隔条可重置。
- **导航器。** 拖移侧栏的边缘可调整其大小。在窄窗口中，侧栏会覆盖文稿，点按 **完成** 按钮即可关闭它。
- **列选择。** 开启 **更多 ▸ 列选择**，然后用一根手指拖移，即可选择一个矩形区域的文本。两根手指仍然用于滚动。开启时会显示 **列选择** 徽标，并带有一个关闭它的按钮。也可以使用 **更多 ▸ 在某一列放置光标…**，按数字放置光标。
- **上下文菜单。** 在文本中按住不放，即可打开编辑器的菜单（见下文）。
- **文件。** 在“文件”面板中按住某个文件不放，即可打开它的菜单（Chapter 60）。

## 使用外接键盘

Chapter 77 中的每个快捷键都可使用。按住 **⌘** 可查看 iPad 的菜单栏，也可以把指针移到屏幕顶部。连接键盘或鼠标时，Pilcrow 可以隐藏它自己的标题栏菜单；请参见 **设置 ▸ 外观 ▸ 标题栏中的菜单**。

## 使用触控板或鼠标

右键点按会打开编辑器的上下文菜单。拖移时按住 **Option**，即可选择一个矩形区域的文本。

## 编辑器的上下文菜单

在文本中，Mac 上右键点按，iPad 上按住不放。当前语法配置无法表达的项目会显示为灰色，系统还会添加它自己的项目（剪切、拷贝、粘贴、拼写建议、查询等）。

在 **Mac** 上：

| 项目 | 作用 |
| --- | --- |
| **拷贝 / 粘贴为…** | **拷贝为 Markdown**、**拷贝为纯文本**、**拷贝为 HTML 代码**、**粘贴为纯文本**。 |
| **段落** | **段落**、**标题 1** 至 **6**、**引用**、**项目符号列表**、**编号列表**、**任务列表**、**代码块**。 |
| **格式** | **加粗**、**强调**、**代码**、**删除线**、**行内公式**、**行间公式**、**图表**、**统计图**、**超链接**。 |
| **选择** | **选择单词**、**选择行**、**选择段落**。 |

在 **iPad** 上，系统的项目旁边有三个子菜单：

| 项目 | 作用 |
| --- | --- |
| **格式** | 行内样式：加粗、强调、代码等。 |
| **段落** | 段落类型：标题、引用、列表、代码块。 |
| **插入** | 与格式栏的 **更多** 菜单相同的插入项，包括 **插入提醒**、**插入图像…** 和 **插入表格…**，以及在 **语法** 下当前配置自己的结构。 |

## 与 Mac 的区别

| 在 iPad 上 | 在 Mac 上 |
| --- | --- |
| 设置从标题栏中的齿轮打开，显示在面板中。 | **Pilcrow ▸ 设置…** (`⌘,`)。 |
| 标题栏可以显示 Pilcrow 自己的菜单（**标题栏中的菜单**）。 | 菜单栏是系统的。 |
| **界面大小** 设定菜单、栏和对话框的大小。 | 不可用。 |
| 导入在 **设置 ▸ 资源库 ▸ 导入** 中。 | **文件 ▸ 导入**。 |
| 没有全部保存、复制、移到、从磁盘重新载入、在“访达”中显示或页面设置。 | 这些都在“文件”菜单中。 |
| **编辑 ▸ 拼写和语法** 只有一个项目：**键入时检查拼写**。 | **编辑 ▸ 拼写和语法** 还有 **显示拼写和语法** 和 **立即检查文稿**。 |
| 键入声音会被 iPad 的静音开关静音。 | 不适用。 |
