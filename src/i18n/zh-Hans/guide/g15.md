# Chapter 81: 文件、编码和限制

## Pilcrow 能打开的文件

Pilcrow 编辑纯文本和标记文件。常用的扩展名有 `txt`、`md`、`markdown`、`adoc`、`asciidoc`、`rst` 和 `tex`，以及你添加的配置所声明的任何扩展名。Pilcrow 会在打开文件时检测其文本编码。

| 项目 | 类型 |
| --- | --- |
| 语法配置、宏集合、风格指南、应用主题 | `.json` |
| 渲染主题 | `.css` |
| 主题包 | `.zip` |
| 书籍项目清单 | `manifest.pilcrow` |
| 背景 | HEIC、PNG、JPEG、SVG、MP4、MOV、M4V |
| 键入声音片段 | WAV、AIFF、MP3、M4A、CAF |

## 文本编码

Pilcrow 可读取 UTF-8、UTF-16、UTF-32 和 ISO 8859-1 (Latin-1) 文本。你可以通过 **文稿信息 ▸ 编码 ▸ 转换为…** 将文稿转换为以下任一编码；文件会在下次存储时完成转换：

UTF-8, UTF-8 (BOM), UTF-16 LE, UTF-16 LE (BOM), UTF-16 BE, UTF-16 BE (BOM), UTF-32 LE, UTF-32 LE (BOM), UTF-32 BE, UTF-32 BE (BOM).

Latin-1 文件可以无损转换为上述任一编码。不提供转换为 Latin-1 的选项，因为这可能会破坏内容。

## 导出格式

| 格式 | 扩展名 |
| --- | --- |
| HTML、HTML（无样式） | `.html` |
| PDF | `.pdf` |
| Word (.docx) | `.docx` |
| 图像 | `.png` |
| PDF Archive | `.zip` |

## 限制和数值

Pilcrow 的上限所在，或某项选择的取值范围：

| 位置 | 限制 |
| --- | --- |
| 搜索面板 | 达到 500 个匹配项时停止。 |
| 预览中查找 | 最多统计 2,000 个匹配项。 |
| 在文件夹中替换 | 一次最多更改 2,000 个文件。 |
| 检查链接 | 最多检查 50,000 个链接。 |
| 比较 | 最多显示 5,000 行更改。 |
| 保留的版本数 | 无到 500（默认 50）。 |
| 长行 | 20,000 个字符或更长的行始终自动换行。 |
| 字体大小 | 9 至 32 磅。 |
| 制表符宽度 | 2 至 8 个空格。 |
| 文本宽度 | 50% 至 100%。 |
| 缩放 | 50% 至 200%，分十档。 |
| 阅读速度 | 每分钟 60 至 2,000 字。 |
| 导航器宽度 | 180 至 420 点。 |
| 键入声音片段 | 最长 2 秒，最大 3 MB。 |
| 诊断报告的日志文本 | 添加到 GitHub 问题描述时，最新的条目，最多 60,000 个字符。 |
| 超大文件 | 打开和编辑时不会被整个读入内存。行数和字数以及大纲会在后台完成计算，在此之前可能不完整。超大文稿的 PDF 导出所需内存远多于编辑，也多于 HTML 和 Word 导出；PDF Archive 会将其拆分为有界的若干部分。 |

## Pilcrow 把东西保存在哪里

| 内容 | 位置 |
| --- | --- |
| 你的文稿 | 就在你保存它们的地方。 |
| 资源库（主题、配置、宏、风格指南、背景） | 在应用的私有存储中，或在你所选文件夹内名为“Pilcrow Library”的文件夹中（**设置 ▸ 资源库 ▸ 位置**）。 |
| 偏好设置、API 密钥、恢复副本、版本历史 | 在设备上，位于应用的私有存储和钥匙串中。可在 **设置 ▸ 通用 ▸ 存储与隐私** 中查看和删除。 |
| 诊断日志 | 在设备上，直到你清除它。 |

# Chapter 82: 消息、横幅和空状态

本章解释 Pilcrow 显示的各种简短消息，让它们不再神秘。

## 在编辑器和预览中

| 消息 | 含义 |
| --- | --- |
| **暂无可预览的内容。开始写作，内容就会显示在这里。**（或“切换到编辑并开始写作。”） | 文稿为空，所以预览中没有可绘制的内容。 |
| **预览无法渲染：…**，附带 **显示源文件** 和 **重试** | 预览失败。**显示源文件** 会切换到编辑。**重试** 会再试一次。 |
| 公式或图表失败，附带 **显示源文件** 链接 | 有一个块无法绘制。点按 **显示源文件** 即可跳到该块的源文件并修正。 |
| **无法存储**，附带 **重试** 和关闭按钮 | 存储失败。文稿保持打开且未存储。请排除原因（磁盘空间、权限、文件已被移动），然后选择 **重试**。 |
| **磁盘上的文件已更改** | 另一个 App 修改了该文件。**重新加载** 会读取新版本；**保留当前版本** 会保留你现有的内容。 |
| **解析警告** | 某一行中的结构可能并非你的本意（第 68 章）。 |
| **要替换现有文件吗？** | 你选择的名称在该位置已被占用。 |
| **仍有未填写的字段** | 你正在打印或导出，但仍有未填写的字段（第 63 章）。 |
| **窗格分隔条**（旁白提示：“拖移以调整编辑器和预览的大小。轻点两下可重置。”） | 并排显示中，位于源文件与预览之间的拖移把手。 |
| **字数：N** | 状态栏中的字数统计。 |

## 在对话框和面板中

| 位置 | 消息 | 含义 |
| --- | --- | --- |
| 命令面板 | **输入命令** | 该字段的提示。没有匹配项时会显示“没有匹配的命令”。 |
| 快速打开 | **输入文件名** | 该字段的提示。 |
| 在某一列放置光标 | **行（例如 3-17）**、**列（例如 100，或用 100-105 来选择）** | 字段提示。单个列号会放置光标；范围则会选中每一行中的这些字符。 |
| 搜索面板 | **输入内容以搜索此文件夹。**、**此文件夹中没有匹配项。**、**搜索已取消。** | 文件夹搜索的状态。 |
| 文件面板 | **你也可以把文件夹拖放到这里。** | 将文件夹拖到面板上即可打开它。 |
| 在文件夹中替换 | **没有可替换的内容。** | 搜索没有匹配项。 |
| 比较 | 按钮上的工具提示：**接受**（“在打开的文稿中进行此更改”）、**拒绝**（“不在打开的文稿中进行此更改”）、**撤回**（“仅针对此更改，把较旧的行放回文稿中”）。 | 各按钮的作用。 |
| 翻译 | **无法完成翻译。** | 请重试，或选择其他速度。 |
| 翻译 | **预计用时：不到一分钟** | 针对 AI 助手速度的估计；具体时间取决于你的 AI 服务。翻译完成后，**在新标签页中打开** 会打开结果。 |
| 助手 | **没有打开的文稿。**、**不会发送任何文稿文本。** | 面板没有可共享的内容，因此不会发送任何内容。 |
| 模型选择器 | **正在加载模型…**、**没有匹配的模型。** | 列表正在加载，或你的搜索没有结果。 |
| 风格审阅 | **没有发现。** 和 **无法将回复解析为审阅结果。请重试。** | 审阅没有发现问题，或 AI 的回复不是预期的形式。 |
| 风格审阅 | **全部应用** 的工具提示：“将所有可修复的问题一次性修复，作为一次可撤销的更改。” | 一次撤销即可还原全部更改。 |
| 项目面板 | **你的姓名**、**添加变量** | “作者”字段的提示，以及用于添加项目变量的按钮。 |
| 助手权限 | **阅读 Pilcrow 的隐私政策** | 打开隐私政策。 |
