# Chapter 72: 键盘

**设置 ▸ 键盘 ▸ 快捷输入** 列出了所有可以更改快捷键的命令，并显示各自当前的按键。

| 控件 | 作用 |
| --- | --- |
| 命令所在的行 | 点按该行，按下新的快捷键，然后选择**保存**。**取消绑定**会移除快捷键。**取消**保留原来的快捷键。如果该快捷键已被其他命令使用，那个命令的快捷键会被清除，页面会告诉你是哪一个。 |
| **Super Tab 按键** | **下一个字段**和**上一个字段**所用的按键，用于在宏留下的空白处之间跳转：`⌥Tab` 和 `⌥⇧Tab`，或 `⌃⌘]` 和 `⌃⌘[`，或**自定**。 |
| **重置所有快捷键** | 恢复所有默认设置。 |

# Chapter 73: 订阅与积分

Pilcrow 的所有功能都是免费的。支持 Pilcrow 是可选的：它有助于支付开发成本，并让你对接下来要开发的内容投票。投票会影响开发的先后顺序，但不保证任何功能一定会实现。

**支持 Pilcrow** 页面包含：

| 部分 | 显示内容或作用 |
| --- | --- |
| **你的投票数** | **来自订阅**（本付费月的投票数及其到期时间）和**已购买**（永不过期的投票数）。订阅投票数优先使用，并在付费月结束时过期。 |
| **获取投票数** | 订阅，以及可以购买的单次投票。Pilcrow Supporter 每月自动续订，直到你在 Apple 账户设置中取消。每个付费月都会给你投票数。 |
| **恢复购买项目** | 找回在其他设备上完成的购买。 |
| **使用条款**、**隐私政策** | 链接。 |
| **App 图标** | 供订阅者选择的 App 图标。某一轮投票的图标需在该轮期间订阅才能获得，获得后会一直保留。在 Mac 上，Pilcrow 打开期间，Dock 中的图标会随之更改。 |
| **路线图** | 当前开放投票的功能轮次，显示“投票数”和“你的”计数，每项都有一个**投票**按钮。每次投票会用掉你的一票，且无法收回。两轮之间，页面会说明下一轮何时开始。 |

如果某个版本不提供支持选项，页面会予以说明。
