# Chapter 60: 边栏

边栏包含五个面板：**文件**、**大纲**、**搜索**、**项目**和**助手**。边栏顶部的切换控件可选择**文件**、**大纲**、**项目**（当打开的文件夹是书籍项目时显示）或**助手**（设置好连接后显示）。**搜索**有自己的标题栏，标题为**查找**，其中有返回“文件”的**完成**按钮，以及用于选择**此文稿**或**文件夹**范围的控件；可通过 **视图 ▸ 搜索**（`⇧⌘F`）打开。**视图**菜单也可以切换面板，选择已经显示的面板会隐藏边栏。拖动边栏的边缘可调整其大小。文件树上方的菜单提供**打开文件…**和**打开文件夹…**。

## 文件

“文件”面板是所打开文件夹的树状结构。

未打开文件夹时，它会显示“选择一个文件夹以浏览其中的文件。”，并提供**打开文件夹**和**打开文件**。你也可以把文件夹拖到面板上。如果你打开的单个文件所在的文件夹 Pilcrow 无法访问，它会提供“浏览*文件夹*以查看此文稿旁的文件”，并附有**浏览所在文件夹…**。

点按文件即可打开。文件夹可以展开和折叠。右键点按某一行（在 iPad 上则按住不放）可打开它的菜单：

| 项目 | 作用 |
| --- | --- |
| **新建文件** | 在该文件夹中（或在你点按的文件旁边）创建文件。 |
| **新建文件夹** | 在该处创建文件夹。 |
| **重命名…** | 重命名文件或文件夹。 |
| **移到废纸篓** | 经你确认后移到废纸篓。你可以从废纸篓中放回。 |
| **在“访达”中显示** | 在“访达”中显示（Mac）。 |

如果系统对某个位置没有废纸篓，Pilcrow 会把删除的项目保存在面板底部的**最近删除**区域。那里的每个项目都提供**放回原处**和**永久删除**，而**清空“最近删除”**会永久移除该区域中的所有项目。永久删除无法撤销，因此 Pilcrow 会先询问。你从其他位置删除的项目不受影响。

隐藏的文件和文件夹由 **设置 ▸ 文件 ▸ 显示隐藏的文件夹和文件**控制显示或隐藏。

## 大纲

“大纲”按级别缩进，列出当前文稿的标题。点按标题即可跳转到该处。标题旁的箭头可折叠或展开其下嵌套的标题。这不会更改文稿，折叠状态也不会被保存。

你可能会看到的状态：

| 消息 | 含义 |
| --- | --- |
| **无标题** | 当前配置未找到任何标题。 |
| **正在为大纲建立索引… N%** | 仍在扫描较大的文稿。 |
| **大纲索引失败。列表可能不完整。** | 扫描时遇到问题。 |
| **光标附近有 N 个标题 — 滚动可查看其他标题。** | 非常大的文稿只显示光标周围一段范围的大纲。 |

在大纲下方，当文稿包含需要填写的字段时，会出现**字段**区域（第 24 章）。它列出这些字段并显示数量；点按其中一个即可滚动到该字段并选中它。如果字段数量非常多，它会显示“仅列出前面的字段。”

## 搜索

“搜索”面板会搜索所打开文件夹中的每个文件。未打开文件夹时，它会显示“打开一个文件夹以进行搜索。”，并附有**打开文件夹…**按钮。

| 控件 | 作用 |
| --- | --- |
| **搜索文件夹**字段 | 输入时即时搜索。**清除**按钮可清空内容。 |
| **Aa** | **区分大小写。** |
| **ab** | **全字匹配。** |
| **.\*** | **正则表达式。** 无效的模式会在字段下方报告。 |
| 状态行 | 显示“正在搜索…”和**取消**按钮，然后显示“匹配项：N”。搜索在 500 个匹配项时停止，并显示“显示前 500 个匹配项。”。取消后会提供**再次搜索**。 |
| **替换…** | 搜索到匹配项时出现。打开“在文件夹中替换”（第 63 章）。 |
| 结果 | 每个结果会给出文件名并显示该行。点按其中一个即可在该行打开文件。 |

## 项目

“项目”面板用于书籍项目。请参阅第 34 章、第 35 章以及下面的“项目面板参考”。

### 项目面板参考

| 部分 | 作用 |
| --- | --- |
| **此文件夹不是书籍项目。** 及**设为项目** | 当打开的文件夹没有清单文件时显示。 |
| **重试** | 项目无法读取时显示。 |
| **视图** | 选择**列表**、**概要**或**卡片**。 |
| 标题、字数合计 | 项目名称和“N 词”；设置了全书字数目标时显示“N / 目标”。 |
| **状态**筛选 | 仅筛选某一状态，或选择**所有状态**。统计会列出每个状态及其文件数和字数。只有在未启用筛选时才能重新排序。 |
| **项目设置**（齿轮） | 打开下面的设置面板。 |
| **编译…** | 打开编译面板（第 64 章）。 |
| **重新排序**和**完成** | 在 iPad 上，拖动章节调整顺序，然后选择**完成**。 |
| **新建文件**（加号） | 提供**新建章节**、**新建场景**、**新建前置内容**、**新建附录**。 |
| **不在书稿中**及**添加**和**全部添加** | 列出文件夹中清单文件未包含的文件。 |
| 某一行的箭头 | 在章节下**显示场景**或**隐藏场景**。 |
| **缺失**和**已排除**标记 | 找不到的文件，或你已从书稿中排除的文件。 |
| 某一行的菜单 | **详细信息…**、**在下方新建文件**、**上移章节**、**下移章节**、**纳入书稿**、**从书稿中排除**。 |
| 每个项目的**字数目标** | 每个项目显示其字数和字数目标（如有）。 |

某个项目的**详细信息**包含**种类**（前置内容、部分、章节、场景、附录）、**状态**、**视角**、**位置**、**字数目标**和**概要**。如果项目文件在磁盘上发生了更改，会显示“项目文件在磁盘上已更改，因此你的上一次更改未被应用。请重试。”以及**关闭**。

**项目设置**包含**标题**、**作者**、**全书字数目标**、**新文件使用的格式**（新章节和新场景使用的语法；已有文件保持其原有语法）、**变量**（名称和值，在文中写作 `{{name}}`；`{{title}}` 和 `{{author}}` 始终可用），以及**哪些内容算作词**：**统计标题**、**统计前置内容**、**统计代码块**。选择**保存**或**取消**。

设置好连接后会出现“助手”面板（第 65 章）。

# Chapter 61: 格式工具栏和状态栏

## 格式工具栏

格式工具栏是文本下方的一行可选工具栏。可通过 **视图 ▸ 格式工具栏**、**更多 ▸ 格式工具栏**、**设置 ▸ 编辑 ▸ 格式工具栏**或工具栏自己的**隐藏工具栏**项来显示或隐藏。它通过当前配置执行操作，因此配置无法表达的按钮会显示为灰色。

| 控件 | 作用 |
| --- | --- |
| **段落类型**菜单（例如“段落”或“标题 1”） | 显示当前行的类型并可更改：**段落**、**标题 1** 至 **6**、**引用**、**项目符号列表**、**编号列表**、**任务列表**、**代码块**。 |
| **粗体**（`⌘B`） | 加粗。 |
| **斜体**（`⌘I`） | 强调。 |
| **行内代码** | 代码。 |
| **插入链接**（`⌘K`） | 创建链接。 |
| **引用** | 切换引用。 |
| **项目符号列表** | 切换项目符号列表。 |
| **更多格式**（**⋯**） | 较少用的命令：**删除线**、**插入行内公式**、**插入任务列表**、**切换任务状态**、**增加缩进**、**减少缩进**、**提高标题级别**、**降低标题级别**、**插入表格…**、**插入图像…**、**插入图表**、**插入统计图**、**插入行间公式**、**插入代码块**、**插入提醒**、**插入水平线**、**插入链接引用**、**插入脚注**、**插入目录**、**插入 YAML 前言**，以及**隐藏工具栏**。 |

## 状态栏

状态栏位于底部。可通过 **设置 ▸ 编辑 ▸ 显示状态栏**将其打开或关闭。

| 部分 | 显示内容或作用 |
| --- | --- |
| **字数**、**行**、**列** | 字数，以及光标所在的行和列。有选区时，还会为所选的行和字符添加“选区：N 行 · N 字符”。 |
| **语法**菜单（例如“CommonMark”） | 此文稿使用的配置。点按可选择其他配置，或选择**无语法**以使用纯文本。 |
| **剩余字段：N** | 当宏留下了需要填写的字段时显示。点按它可跳到下一个字段。 |
| 进度和状态 | 分析大文件时显示 **正在建立索引 N%**、**正在词法分析 N%**；翻译进行时显示 **正在翻译 N%**、**约剩 N** 以及**取消翻译**按钮。 |
| **不同步** | 警告编辑器与文稿的更改日志已不一致。存储时文件仍会标记为未存储，以确保不会丢失任何内容：请把文本拷贝到安全的地方，然后关闭并重新打开文稿。 |
| 文稿信息 | 点按计数，或提示“显示文稿信息”，即可打开**文稿信息**。 |

**文稿信息**列出**字数**、**字符**、**行**、**阅读时间**（基于“设置”中你的阅读速度）、**光标**、**选择**、**编码**和**语法**。在非常大的文件中，索引完成之前计数仅针对已载入的部分，而阅读时间是按整个文件估算的。**编码**下的**转换为…**可选择另一种文本编码；文件会在下次存储时进行转换。


# Chapter 62: 查找、替换、前往行、快速打开和命令面板

## 查找栏

可通过**查找…**（`⌘F`）、**查找**按钮或**替换…**（`⌘R`）打开。它位于文稿顶部。

| 控件 | 作用 |
| --- | --- |
| **在文稿中查找**字段 | 输入要查找的文本。输入时匹配项会高亮显示。 |
| **Aa**、**ab**、**.\*** | **区分大小写**、**全字匹配**、**正则表达式**。 |
| **上一个匹配项**、**下一个匹配项** | 逐个浏览匹配项（`⇧⌘G`、`⌘G`）。 |
| **显示替换** / **隐藏替换**（箭头） | 显示**替换为**字段。 |
| **替换**、**全部替换** | 替换当前匹配项，或替换所有匹配项。在有匹配项之前显示为灰色。 |
| **查找范围**（栏左端的切换控件） | **此文稿**，或选择**文件夹**以改为搜索整个打开的文件夹。 |
| **关闭查找栏** | 关闭它。 |

当匹配项多于 Pilcrow 所统计的数量时，栏中会显示“仍有更多匹配项”。在**预览**中，“查找”会在渲染后的文字中搜索并高亮显示，最多 2,000 个匹配项。无法使用的模式会显示“模式无效”。替换仅在“编辑”中可用：在“预览”中，栏中会显示“替换仅在编辑中可用。请切换到编辑以更改文本。”。在**并排**中，“查找”会搜索源文本，并在预览中高亮显示匹配的文字。

## 前往行

**前往行…**（`⌃G`）会打开一个只有一个字段的小面板，字段为“行号，或 行:列”。输入 `120` 或 `120:8`，然后选择**前往**或**取消**。超出末尾的数字会跳到最后一行。输入其他内容时，Pilcrow 会显示“请输入行号，例如 120 或 120:8。”。在仍在统计行数的非常大的文件中，它会请你稍后再试。

## 快速打开

**快速打开…**（`⇧⌘O`）是在打开的文件夹中按文件名搜索。输入名称的一部分，列表会随之缩小，并显示“N 个匹配项”。选择一个结果并选择**打开**，或选择**取消**。没有打开的文件夹时它显示为灰色。

## 命令面板

**命令面板…**（`⌃⇧P`）按名称列出 Pilcrow 的命令及其快捷键，这样你无需查找菜单就能运行命令。输入内容可缩小列表范围，选择一个命令并选择**运行**，或选择**取消**。没有匹配项时它会显示“没有匹配的命令”。当前无法运行的命令（例如在“预览”中进行源文本编辑）会显示为灰色。列表包括格式和插入命令、用于选择、行和大小写的“编辑”命令、朗读、视图切换、缩放和边栏面板，以及文件和导出操作。打开命令面板的快捷键可在 **设置 ▸ 键盘**中更改。
