# Part XIX — 资源库项目的编辑器

# Chapter 74: 配置编辑器与配置构建块

语法描述文件告诉 Pilcrow 你的标记是什么意思。本章逐项介绍配置编辑器的各个控件，然后列出配置可以使用的所有构建块。若想先看按任务讲解的入门内容，请参阅第 37 章至第 39 章。

从 **设置 ▸ 资源库 ▸ 语法配置** 打开编辑器：**新建**用于创建配置，**编辑**用于修改自定义配置，**复制**用于复制内置配置，以便你修改副本。编辑器的标题是**编辑配置**，带有**取消**、**保存**和**配置帮助**（打开这些构建块的应用内参考）。在窄屏上，**配置分区**开关可在**概览**、**规则**和**测试示例**之间切换；在宽屏上，三者同时显示。

## 概览

| 字段 | 作用 |
| --- | --- |
| **名称** | 配置的名称，显示在状态栏菜单和设置中。 |
| **说明** | 关于该配置的备注。 |
| **文件扩展名(以逗号分隔)** | 用于为文件选定此配置的扩展名。两个配置不能共用同一个扩展名。 |
| **继承** | **无**，或另一个配置，本配置在其规则的基础上构建。 |
| **语法** | **扩展 Markdown** 或 **替换 Markdown**（见下文）。 |
| **概览** | **块规则**、**行内规则**和**嵌套规则**的数量。 |
| **编辑高级 JSON…** | 以 JSON 形式打开配置，用于引导式编辑器未提供的字段。**应用**保留你对 JSON 的更改；**取消**放弃这些更改。 |

**扩展 Markdown** 会把你的规则添加到 Markdown 的规则之上：Markdown 的标题、列表、强调等仍会被识别，你的块规则和行内规则是在它们之外的补充。如果某条规则是 CommonMark 配置中某条规则的原样副本，它描述的是 Markdown 本来就会做的事，会交由 Markdown 处理。**替换 Markdown** 则让你的规则成为全部语法，Markdown 的构造不再被识别。使用它时，必须有一条规则生成**行尾**，否则无法把内容分成段落。编辑器会警告“Add a rule whose output node is "newline", or nothing will separate into paragraphs”，在存在这样的规则之前，配置无法保存。它还会列出配置尚未定义的任何输出类型。

## 规则

规则分为三组。

### 块规则

块规则识别整行和整个块。**添加规则**可添加一条。每条规则都有**模式**、**匹配**类型、**生成**的内容以及**选项**。用该规则的**删除**按钮即可移除它。没有规则时，编辑器会显示“No rules yet. Add one to recognize a block construct.”

### 行内规则

行内规则识别一行之内的文本。**添加行内规则**可添加一条。行内规则提供四种匹配类型（**字面前缀**、**字面精确**、**正则(有界)**和**分隔符对**）；块规则则提供全部七种。

### 嵌套规则

嵌套规则说明哪些输出可以放在哪些输出之内。每条规则都有**父节点**和**允许的子节点（以逗号分隔）**。留空表示不受限制：“No restrictions. Every node type may nest inside any other.”**添加嵌套规则**可添加一条。

### 匹配类型

| 匹配类型 | 把模式理解为 | 块 | 行内 |
| --- | --- | --- | --- |
| **字面前缀** | 该构造开头的文本。 | 是 | 是 |
| **字面精确** | 该构造的全部文本。 | 是 | 是 |
| **行首前缀** | 一行开头的文本，例如 `# `。 | 是 | |
| **缩进块** | 以该模式开头的行，例如四个空格或一个制表符。连续的行以及它们之间的空行属于同一个块，显示时不带缩进。 | 是 | |
| **围栏块** | 开启一个块的行，由与之匹配的行结束。 | 是 | |
| **正则(有界)** | 正则表达式。保存可能卡住的表达式前，Pilcrow 会发出警告：“This regex could hang the editor — simplify it.” | 是 | 是 |
| **分隔符对** | 同一行文本两侧的相同标记，例如 `%%this%%` 中的 `%%`。标记内侧没有空格。 | 是 | 是 |

在正则表达式中，`(?<name>…)` 为匹配的一部分命名。参见下文的“部分”。

## 规则选项

每条规则的**选项**分组提供：

| 选项 | 作用 |
| --- | --- |
| **优先级** | 优先级较高的规则先被尝试。 |
| **仅在行首** | 防止规则在行中间匹配。 |
| **命名部分成为属性** | 正则表达式中每个命名的部分都成为输出的一个属性。编辑器会列出“Parts in this pattern”和“Parts this output reads”。对于包含文本的输出，例如粗体或链接，显示的文本是名为 `text` 的部分（若有），否则是最后一个匹配的部分。 |
| **生成** | 规则生成的内容：下方列表中的某个输出，或**自定义**名称。 |
| **自定义节点名称** | **自定义**输出的名称。 |
| **固定属性** | 每次值都相同的部分，通过**添加属性**添加（一个**名称**和一个**值**）。值可以包含命名部分，写作 `{name}`：模式中命名了 `address` 的电子邮件规则，可以让它的链接的 `url` 为 `mailto:{address}`。 |
| **插入文本** | **插入**菜单为此规则写入的内容，与应当出现的样子完全一致，用 `$0` 表示光标应处的位置。由正则表达式、块或缩进匹配的规则需要这一项，否则“插入”菜单会略去它。 |
| **仅在空行之后** | 用于缩进块：紧跟在文本之后的缩进行仍属于该文本，例如列表项的下一行。 |
| **在行尾按回车后** | 用于列表和引用：**自动**（重复项目符号和引用标记，为编号项递增编号，并让任务项以未勾选状态开始）、**重复标记**、**递增**、**从标记重新开始**，或**不添加任何内容**。 |

### 围栏块和分隔块

对于**围栏块**规则，**块包含**说明其中的内容：

| 选项 | 含义 |
| --- | --- |
| **暂无** | 未设置。 |
| **文本，按原样显示** | 代码或预格式化文本。 |
| **无——隐藏** | 注释，不出现在文稿中。 |
| **其他块，带框** | 包含段落、列表等内容的引用、侧栏或提示框。 |
| **其他块，不带框** | 这些块并入周围的文本；这些行只起分组作用。 |
| **表格** | 见下文“表格”。 |
| **用文本绘制的表格** | 从开头行到下一个空行的文本网格或对齐的列，例如 reStructuredText 的表格。 |
| **以标记结尾的行下方的缩进文本** | 开头行是以该标记结尾的正文，如 reStructuredText 的 `::`；该正文仍是一个段落，空行之后缩进在其下的文本按原样显示。 |
| **开头行下方的缩进文本** | 指令，例如 `.. code-block::`，它包含其下的缩进行，没有结束行。 |

**结束行**是结束该块的行；留空表示与开头行相同（“Same as the opening line”）。不是正则表达式的分隔符，例如 `+++`，按纯文本匹配。**结束行重复开头的标记，次数不少于开头行**适用于 Markdown 风格的围栏：结束行是开头行的第一个字符重复至少同样多的次数，因此较长的围栏可以把较短的围栏当作文本包含在内。当开头行指明了已知语言时，文本块的语言会在编辑器中着色。

### 表格

表格块的选项：

| 选项 | 作用 |
| --- | --- |
| **布局** | **带分隔线的网格**（单元格位于 `|` 之间，行与行之间有分隔线）或**对齐的列**（各列在第一条分隔线下对齐）。 |
| **单元格分隔符** | 开启每个单元格的文本。 |
| **分隔线模式**、**表头分隔线模式** | 仅绘制分隔线的行，以及结束表头的那一行。 |
| **行以此结尾** | 结束每一行的标记，如 LaTeX 的 `tabular`。 |
| **合并单元格模式** | 跨列的单元格。 |
| **单元格选项模式** | 一个正则表达式，匹配可以紧邻单元格分隔符之前的内容；名为 `colspan` 的部分会让该单元格跨越相应数量的列。 |
| **列列表分隔符**、**重复标记** | `columns` 列表的写法：用 `,` 和 `*`，`3*` 表示三列。 |
| **空行前的第一行为表头** | 表头行由布局隐含。 |
| **格式** | 书写单元格的其他方式，每种包含一个名称和一个分隔符（例如 `csv` 和 `,`），用**添加格式**添加，并通过表格的 `format` 部分选择。 |

## 配置范围的设置

| 设置 | 作用 |
| --- | --- |
| **按标记嵌套列表** | 每出现一个新标记，例如 `**` 出现在 `*` 之后，就开始更深一级，无论缩进如何。 |
| **列表续行** | 单独跟在列表项之后的一行，把下一个块附加到该列表项。 |
| **保留单个换行** | 段落内的换行仍然是换行。 |
| **为标题生成 ID** | 没有自己 ID 的标题会根据标题文字生成一个：小写，单词以**单词分隔符**连接，位于**前缀**之后（**ID 前缀**、**ID 单词分隔符**）。前缀为 `_`、分隔符为 `_` 时，“Getting Started”变为 `_getting_started`，因此指向它的交叉引用会显示标题。重复的标题会再加上分隔符和一个数字。 |
| **为标题编号** | 一旦文稿定义了**当文档定义**中指定的属性，例如 AsciiDoc 的 `:sectnums:`，从**从标题级别**往下的标题就会编号：`1.`、`1.1.`、`2.`。定义之前的标题不编号。 |
| **编号题注** | 此处列出的输出所对应的带标题的块，例如 `image`、`table` 或 `example`，会在标题前得到**标签**和它自己的编号（例如“Figure 1.”），位于**题注位置**，即块的**上方**或**下方**。用**添加题注**添加。 |

## 按周围字符配对的行内标记

像 Markdown 这样的语言，用一串字符书写粗体和斜体，这串字符是开启还是关闭取决于它旁边的字符；行内代码或链接则用括号书写，因此无法用一个模式涵盖整个构造。开启**按周围字符判定标记**即可描述它们。

| 设置 | 作用 |
| --- | --- |
| **转义字符** | 使下一个字符变成普通字符的字符。 |
| **行内代码字符** | 一串该字符开启一个范围，下一串同样长度的该字符将其关闭。 |
| **连续标记** | 按连续字符配对的标记，用**添加连续标记**添加。每个都有一个**标记**、**一个标记绘制为**什么，以及**两个标记绘制为**什么，还有**可在单词内部开始或结束**（`_` 为关闭）。 |
| **成对标记** | 与同样长度的一串字符配对的标记，用**添加成对标记**添加：**标记**、它**绘制为**什么，以及**仅当此设置开启时**，即某个必须开启的语法设置，例如高亮（或**始终**）。 |
| **链接和网址** | **图片前缀**、**单独书写的地址由以下字符包围**、**裸地址的起始协议**、**定义标签的行带有**，以及**脚注标签以此开头**（标签开括号之后、使其成为脚注的那个字符：当某行以 `[^note]:` 开头时，`[^note]` 会被绘制为脚注引用）。 |

标记在一行之内配对。代码、转义字符和链接的地址，对其周围的标记而言都是纯文本。

## 样式化源码

开启**样式化源码**后，编辑器会按语法的外观绘制文稿：更大的标题、粗体和斜体、引用竖线、列表缩进、任务框、分隔线、链接和代码卡片，并隐藏生成这些效果的标记（开启**隐藏标记**时），光标所在的行除外。编辑器并不了解任何一种具体语法：规则通过携带一个样式条目来说明其匹配内容是什么，没有样式条目的规则只会着色，不会重新设置样式。

每条规则的**选项**中都有一个**带样式的源文本**分组：

| 字段 | 作用 |
| --- | --- |
| **角色** | 匹配内容是什么，或**无样式**。对于一行之内的某个构造：heading、strong、emphasis、code、strike、highlight、underline、link、subscript、superscript。对于整行：rule（主题分隔线）、list（列表项的标记，包括其缩进及其后的空格）、task（后面跟着复选框的标记）和 quote（引用行的 `>` 标记）。对于整体识别的块：codeBlock。对于开头行和结束行是各自独立匹配的块：quoteRegion。对于绘制成图片的表格、公式或图表：renderedBlock。 |
| **内容分组** | 从 1 开始计数的捕获组，其中包含该构造所关于的内容：`*bold*` 中的单词，`\section{Title}` 中的标题。匹配内容中除此之外的部分是该构造自己的标记，由“隐藏标记”隐藏。`0` 表示整个匹配都是内容，不隐藏任何东西，如网址那样。如果匹配内容只有标记，例如标题的 `== `，则留空。 |
| **标题级别**、**级别分组** | 标题的级别，1 到 6。若省略，则取规则输出名称末尾的数字（`heading2`），或包含一串 `#` 的捕获组的长度。 |
| **标记分组** | 对于列表或任务，指包含标记及其缩进和后面空格的捕获组，适用于匹配内容以其他内容开头的情况，例如引用项的 `> `。 |
| **样式延续到行尾** | 从匹配处到行尾都应用样式，适用于只匹配标题标记、而把标题文字留作其后文本的规则。 |
| **绘制为** | 对于渲染块，它是什么：表格、数学公式或图表，或**不是图片**。 |
| **地址分组** | 对于链接，按顺序尝试的捕获组，其中包含点按或点击时打开的地址；`0` 为整个匹配。只有网页、邮件和电话地址会被打开。 |

组号从 1 起计算模式中的括号；0 是整个匹配。不替换 Markdown 的配置，对其规则没有声明的种类，也仍保留 Markdown 自己的解读，例如它的引用竖线和成对的 `**`。

## 文稿属性与条件部分

**文稿属性**规则通过 `name` 定义一个值，**属性引用**规则（带有 `name` 和 `original` 两个部分的行内规则）用该值替换引用。对无人定义的属性的引用保持原样。**条件部分**根据它所指名的属性是否已设置，保留或舍弃其各行之间的块。属性从定义处起向后生效。

生成**下一个块的设置**的规则，识别用来配置其后一个块的整行内容，自身不显示任何东西。它的部分和固定属性会交给那个块：`title`、`id`、`nodeType`、`language` 和 `hardbreaks` 的含义见“部分”下的说明，其他任何部分都保留在该块上，由表格、列表或引用读取。

## 测试配置

在编辑器底部，**测试示例**存放示例文本（一开始是一个标题和一行文字）。选择**检查示例**，可以看到你的规则生成的节点，按嵌套关系缩进显示。没有任何匹配时，它会显示“No blocks recognized.”

## 基线

配置的**基线**是它的还原点：即你创建、复制或导入它时的样子。**重置为基线**会在你确认后放弃此后的所有更改。**设为新基线**会存储该配置，并把它当前的状态作为还原点。

如果配置替换了 Markdown 却没有行尾规则、模式不安全可能卡住编辑器，或文件无法写入，则会拒绝保存，并给出提示。

## 部分

部分是匹配内容中被命名的片段，由输出读取。

| 部分 | 含义 |
| --- | --- |
| `allOf` | 需要全部名称时，名称之间的分隔符，例如 `+`。 |
| `alt` | 图像的说明，供看不到图像的读者使用。 |
| `anyOf` | 只需其中任一名称时，名称之间的分隔符，例如 `,`。 |
| `attribution` | 引用的说话人，显示在引用下方。 |
| `citetitle` | 引用出自的作品，显示在出处署名之后。 |
| `columns` | 表格的列列表，例如 `1,2,1`；其条目数即列数。 |
| `condition` | 该部分所依赖的属性名称。 |
| `conditionType` | `defined` 表示属性已设置时保留该部分，`undefined` 表示属性未设置时保留。 |
| `content` | 文本本身，当它不是整个匹配时。 |
| `format` | 图表的引擎（`mermaid` 或 `vega-lite`）；对表格，则是单元格使用的某种分隔格式。 |
| `hardbreaks` | 存在时，保留下一个块中的单个换行。 |
| `header` | 除 `false` 之外的任何值都会让表格的第一行成为表头。 |
| `id` | 一个名称：对下一个块，是交叉引用所指向的 ID；对脚注，是让之后没有自己文本的脚注共用其编号的名称。 |
| `keys` | 要按下的按键，以逗号分隔。 |
| `label` | 引用或锚点显示的文本，取代目标自己的标题。 |
| `language` | 代码块的编程语言，用于着色。 |
| `level` | 标题级别，从 1 到 6。 |
| `marker` | 术语之后的分隔符，例如 `::`。不同的标记会在描述之内嵌套一个列表。 |
| `name` | 属性的名称，用于定义或引用中。 |
| `nodeType` | 按文件中的名称，把下一个块变成另一种输出。 |
| `noHeader` | 存在时，表格没有表头行。 |
| `notation` | 数学记法：`tex`（默认）或 `latex`。 |
| `open` | `true` 表示可折叠部分以展开状态显示。 |
| `ordered` | `true` 表示列表带编号。 |
| `original` | 按书写原样的引用，在属性未定义时显示。 |
| `presentation` | 下一个描述列表的显示方式：`sideBySide` 把术语和描述放在两列；`questions` 把每个术语编号为问题，答案在其下方。 |
| `primary` | 索引条目。 |
| `secondary` | 索引条目之下的子条目。 |
| `sectionLabel` | 下一个标题的编号所跟随的词，例如 `Appendix`：这类标题单独计数，如 `Appendix A:`。 |
| `sectionLabelStart` | 这些编号中的第一个：字母（`A`）按字母计数，数字按数字计数。 |
| `src` | 视频或音频文件的地址。 |
| `start` | 编号列表的起始数字。 |
| `summary` | 可折叠部分在关闭时显示的那一行。 |
| `targetID` | 引用所指向的 ID。 |
| `term` | 被描述的术语。 |
| `tertiary` | 次级条目之下的子条目。 |
| `text` | 显示的文本，当模式捕获的内容多于此时。脚注的文本跟在它所在的段落、表格或列表之后，并带编号。 |
| `title` | 标题：框的标题、图像或链接的提示文字，或下一个块上方的题注。 |
| `type` | 提示的种类，例如 `note`、`tip` 或 `warning`。 |
| `unset` | 存在时，规则会移除该属性而不是定义它。 |
| `url` | 链接或图像所指向的地址。 |
| `value` | 属性的值；其中对先前已定义属性的引用会被替换。 |
