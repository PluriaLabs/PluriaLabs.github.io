# Chapter 63: 对话框和提示

本章介绍你工作时出现的面板和提醒。

## 插入表格

**格式 ▸ 段落 ▸ 表格 ▸ 插入表格…**（`⌥⌘T`）或**插入 ▸ 表格…**会询问**列**和**行**。选择**好**或**取消**。表格使用当前配置的表格语法写成。

## 在某一列放置光标

**编辑 ▸ 选择 ▸ 在某一列放置光标…**（`⌃⇧G`）可通过数字放置光标，适用于没有键盘的 iPad。输入**行**（例如 `3-17`）和**列**（例如 `100`，或用 `100-105` 选择每行中的这些字符），然后选择**放置**。之后即可输入、删除、拷贝或粘贴。某一行太短而到不了该列时，按 **设置 ▸ 编辑 ▸ 列模式中的短行**处理。列选择处于活动状态时，会出现**列选择**标记，并带有**关闭列选择**按钮。

## 编辑块

开启**渲染块**后，每个以图片形式绘制的表格、公式或图表都有一个编辑按钮。它会打开**编辑块**，这是一个显示该块源文本的面板。选择**应用**可将你的更改放回，或选择**取消**。

## 检查链接

**编辑 ▸ 检查链接…**会检查文稿中的每个链接和图像。必须先存储文稿，才能检查其指向其他文件的链接：“请先存储文稿，以检查其指向其他文件的链接。”面板会显示“正在检查链接…”，然后是问题列表（每项附带行号），或显示“所有链接均可用。”摘要为“已检查的链接：N。未访问的网址：N。”Pilcrow 不会访问网址。它最多检查 50,000 个链接。选择**重新检查**或**完成**。

## 在文件夹中替换

搜索面板中的**替换…**会在改动任何文件之前，先预览每一处更改。

- **替换为**字段存放替换内容。面板会列出每个将被更改的文件，其中包含数量，以及每个匹配项更改前后的示例，还有一个复选框，方便你排除某个文件。
- **在 M 个文件中替换 N 个匹配项**会执行更改。**取消**则停止。
- **已跳过**列表会列出 Pilcrow 不会更改的文件及原因：“已在编辑器中打开。请在那里替换，或先将其关闭。”、“不是纯 UTF-8 文本。”、“单个文件中的匹配项过多。”、“某一行对于此模式来说太长。”或“无法读取。”
- 一次替换最多更改 2,000 个文件。超出后会显示“匹配的文件多于一次替换所能更改的数量。请先替换这些文件，然后再次搜索。”
- 自预览以来已更改的文件保持不变。
- 完成时显示：“已在 M 个文件中替换 N 个匹配项。”并带有**撤销**和**完成**。**撤销**会从备份还原这些文件。此后被编辑过或已不存在的文件保持原样，并会被列出。下次打开该面板时，它会提供撤销上一次替换的选项。

## 版本历史

**文件 ▸ 版本历史…**会列出文稿已存储的版本。每次存储都会保留一个版本，最多保留 **设置 ▸ 文件 ▸ 保留的版本数**中设置的数量。对于未存储的文稿，它显示“请先存储文稿，以开始保留版本。”；该设置为无时显示“版本历史已关闭。”；首次存储之前显示“尚无版本。”

选择一个版本，然后：

| 按钮 | 作用 |
| --- | --- |
| **打开副本** | 将旧版本作为单独的文稿打开。 |
| **比较…** | 打开与该版本的比较面板。 |
| **还原…** | 经你确认后，将文稿恢复为当时的样子。当前文本会保留为一个版本，因此你可以返回。还原需要先存储或还原你的更改。 |
| **完成** | 关闭面板。 |

## 比较版本

**文件 ▸ 与文件比较…**，或版本历史中的**比较…**，会打开**比较版本**。

- 两个选取器**较旧**和**较新**用于选择要比较的内容。**与文件比较…**用于选择一个文件。
- **忽略行尾空白**会隐藏仅由行尾空格造成的差异。
- 摘要为“新增：N。移除：N。”，并列出更改的行，最多 5,000 行。
- 对于每处更改：**接受**会在打开的文稿中进行该更改，**拒绝**则不采用，**重新考虑**会撤销你的选择，而**撤回**（当较旧版本位于旧的一侧时）只为该处更改放回较旧版本的行。**接受其余全部**会接受剩下的全部更改。
- 只有当文本仍然匹配时才会应用更改。否则会显示“未做任何更改：自比较以来，文稿的该部分已发生变化。”
- 消息：“两者相同。”、“无法比较这些内容。”，以及差异过多时的“它们的差异行数过多，无法逐行比较。请打开该版本的副本，并与文稿并排阅读。”

## 翻译

**编辑 ▸ 翻译 ▸ 文稿**或**所选内容**会打开**翻译文稿**或**翻译所选内容**。

| 控件 | 作用 |
| --- | --- |
| **检测到的语言** | Pilcrow 在文本中发现的语言。 |
| **翻译为** | 目标语言。 |
| **速度** | **快速**（大约快二十倍，措辞较为平实，长文稿需要选此项）、**最佳质量**（适用于你要细读的文本）或 **AI 助手**（你在“设置 ▸ 助手”中设置的自有 AI 连接；文本会发送到该连接所指向的地方）。**最佳质量**适用于 macOS 和 iPadOS 26.4 及更高版本；更早的系统只有一种速度。 |
| **完成后** | 对于文稿：**在新标签页中打开**（新文稿的名称与原文稿相似，并在括号中注明语言）、**在原文件旁保存副本**或**替换文稿**。对于所选内容，**替换所选内容**会就地放入译文。 |
| **翻译**或**发送并翻译** | 开始翻译。当 AI 助手会发送你的文本时，会显示“发送并翻译”；它会指明提供方，并提醒你的服务可能会为此收费。 |
| **预计时间** | 一个估计值：“不到一分钟”或“约 N”。时间取决于你的 AI 服务。 |

翻译在后台运行，进度显示在状态栏中。第一次翻译成某种语言时会下载语言包。如果两种语言之间没有直接翻译，Pilcrow 会询问是否通过英语进行翻译（**是**或**否**）。代码、链接和数学内容保持原样。翻译需要 macOS 15 或 iPadOS 18 及更高版本。如果已对该文件或文件夹关闭助手，则不会使用助手。

当你打开以另一种语言写成的文件时，可能会出现一个栏，询问“这看起来是*语言*。要将其翻译为*语言*吗？”，并带有**翻译**、**暂不**和**不再对此文件提示**。设置 ▸ 通用 ▸ 翻译对此进行控制（第 67 章）。

## 存储和关闭

- **是否保留此文稿？** 关闭新文稿时，Pilcrow 会询问“要保留这个新文稿吗？”对于已有文稿，则询问“要存储你所做的更改吗？”选项为**存储**、**取消**和**删除**（或“不存储”）。对于新文稿，表单中有**存储为：**（名称）、**标签：**和**位置：**（可用**其他…**或**选择…**指定其他文件夹）。你无法撤销“删除”。
- **存储文稿**是首次存储时的表单，包含**名称**和**位置**（**选择其他位置…**）。如果已存在同名文件，它会询问**要替换现有文件吗？**。
- 当另一个 App 修改了打开的文件时，会出现**磁盘上的文件已更改**：选择**重新加载**或**保留当前版本**。
- **要从磁盘重新载入吗？**（文件 ▸ 从磁盘重新载入）提供**先存储，再重新载入**、**不存储直接重新载入**和**取消**。
- 当你在字段仍未填写时打印或导出，会出现**仍有未填写的字段**。它提供**转到下一个字段**、**仍然继续**（这些字段会按原样写入输出）和**取消**。
- **解析警告**、**无法共享**、**无法存储文稿**和**文件操作失败**会显示一条消息，并带有**好**。
- 如果 Pilcrow 上次意外退出，会有横幅提示，并提供**打开诊断**或**暂不**。
- 导入资源库项目后，会有一个小提示予以确认，并带有用于关闭它的按钮。
- 当 App 语言为翻译版本时，首次启动会显示**由 AI 翻译**，说明该翻译尚未经母语人士审阅，并带有**不再显示**和**好**。

## 助手的权限面板

在首次把内容发送到在线服务之前，**要发送到 *service* 吗？**会说明将发送的内容（你的请求、问题框上方计入的文稿文本，或依据风格指南规则审阅的文本、模型名称，以及你的密钥）、接收方，以及如何撤回。这台电脑上的程序绝不会离开这台电脑；你网络中的另一台电脑除非地址以 https 开头，否则不会加密；在线服务可能会按其自身条款保留文本。面板中有指向该服务隐私政策和 Pilcrow 隐私政策的链接。选择**发送**或**取消**。在你选择“发送”之前不会发送任何内容。

# Chapter 64: 导出和编译

## 导出面板

可通过**文件 ▸ 导出…**（`⇧⌘E`）、**导出**按钮或**更多 ▸ 导出…**打开。左侧是格式列表，右侧是选项，底部是按钮。

### 格式

| 格式 | 文件 | 说明 |
| --- | --- | --- |
| **HTML** | `.html` | 独立的带样式页面。 |
| **HTML（无样式）** | `.html` | 干净的结构，不含主题 CSS。 |
| **PDF** | `.pdf` | 分页。 |
| **Word (.docx)** | `.docx` | 真正的 Word 文件包。它使用主题的颜色、字体、大小和行距；浏览器布局选择器在 Word 中没有对应项。公式、图表和统计图会变成图片。 |
| **图像** | `.png` | 渲染后文稿的一张图像。 |
| **PDF 归档 (.zip)** | `.zip` | 按顺序排列的 PDF 分段加一份清单，适用于非常大的文稿。 |

### 选项

| 部分 | 控件 |
| --- | --- |
| **样式** | **主题**用于选择渲染主题。主题控制导出文稿的排版和颜色。 |
| **页面**（PDF、PDF 归档和 Word） | **纸张大小**（A3、A4、A5、Letter、Legal、Tabloid，或自定义**宽度**和**高度**）、**方向**（**纵向**或**横向**），以及**上边距**、**下边距**、**左边距**和**右边距**，单位均为毫米（起初为 25.4 毫米，即一英寸）。**将这些页面设置用作默认设置**会为之后的导出保存这些设置；在你更改某项之前显示为灰色。否则它们仅适用于本次导出。 |
| **高级选项** | **自定 CSS**，仅对本次导出在主题之后应用。 |

面板会显示“存储为 *name*”及其将使用的文件名，以及“这些选择仅适用于本次导出。”选择某种格式后，左下角的一行会显示它生成的内容：例如 HTML 显示“带有所选样式的独立网页。”，PDF 显示“一个分页的 PDF 文稿。”

### 按钮

**取消**会关闭面板。**共享…**会把生成的文件直接发送到系统共享面板。**导出**会询问存储位置。处理过程中，面板会显示“正在渲染…”。如果出了问题，它会显示“导出失败。”如果仍有未填写的字段，Pilcrow 会先询问（第 63 章）。

适用于所有导出的页面设置、页眉和页脚模板、目录和编号选项，位于 **设置 ▸ 目录与标签**和 **设置 ▸ 导出**中（第 70 章）。

## 编译面板

**文件 ▸ 编译书稿…**（或项目面板中的**编译…**）会按清单顺序合并书籍项目的文件。载入项目后即可使用。

| 部分 | 控件 |
| --- | --- |
| **书稿** | 摘要：“N 个文件”、“N 个已排除”，以及任何“找不到”的路径，这些路径必须在编译前修复。**顺序**列表显示最终顺序。 |
| **输出** | **格式**，然后是**从新页开始**：**前置内容**、**部分**、**章节**、**附录**。**场景之间**设置分隔符（“无”或一个标记）。**目录**、**为标题编号**，以及**先保留每个文件的一个版本**（为每个包含的文件在版本历史中存储一条记录）。 |
| **预设** | **已存储**的预设。**存储为预设**，包含**预设名称**和**存储**。**删除预设**会移除所选的预设。 |

选择**编译…**以选取存储位置，或选择**取消**。运行时会显示“正在读取 N / N…”然后是“正在编译…”，并带有**停止**。没有值的变量会被列出（“这些 {{variables}} 没有值，已按原样保留”），并保持明显不变。如果无法创建文件，它会显示“无法在该处创建书籍。”

### 新建书籍

**文件 ▸ 新建书籍…**会询问**标题**、**作者**、**写作格式**（章节使用的语法）和**保存位置**（一个文件夹，带有**选择…**）。选择**创建**。Pilcrow 会创建包含清单和第一章的文件夹。如果无法在该处创建书籍，它会说明。
