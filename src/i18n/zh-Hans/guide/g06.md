## 编辑器显示

下面每一项都是一个开关。**设置 ▸ 编辑** 中有同样的开关（第 68 章）。

| 项目 | 快捷键 | 作用 |
| --- | --- | --- |
| **行号** | `⌥⌘L` | 在边栏中显示行号。 |

| **自动换行** | | 在窗口边缘折行显示长行。关闭时，长行可横向滚动。超长行和专注模式无论如何都会折行。 |
| **样式化源码** | | 以与语法外观相匹配的字体绘制标题、粗体和斜体文本，而不是纯源码。 |
| **隐藏标记** | | 开启样式化源码后，隐藏除光标所在行以外各行的标题、粗体和斜体标记（`#`、`**`）。样式化源码关闭时为灰色。 |

| **自动展开章节** | | 光标进入时打开已折叠的分区或绘制为图片的块，光标离开时再次关闭。关闭时，上下箭头会跳过它，它保持原样。 |

# Chapter 56: 插入菜单

插入菜单中的所有项目都会在光标处向文稿中放入源码，并采用当前语法配置自己的写法。该配置无法表达的项目为灰色，在预览中所有项目都不可用。

| 项目 | 作用 |
| --- | --- |
| **表格…** | 打开“插入表格”对话框（第 63 章）。快捷键 `⌥⌘T`。 |
| **图像…** | 选取一张图像并插入，同时应用图像设置（第 68 章）。快捷键 `⇧⌘I`。 |
| **图示** | 现成 Mermaid 图示的子菜单（见下文）。 |
| **图表** | 现成 Vega-Lite 图表的子菜单（见下文）。 |
| **公式** | 现成公式的子菜单（见下文）。 |
| **围栏代码块** | 插入一个围栏代码块。 |
| **提醒** | 一个子菜单：**备注**、**提示**、**重要**、**警告**、**注意**。 |
| **水平线** | 插入一条分隔线。 |
| **链接引用** | 插入引用式链接及其定义。 |
| **脚注** | 插入脚注标记及其定义。 |
| **目录** | 插入一行 `[TOC]`，它会变成自动生成的目录列表。 |
| **YAML 前言** | 在文件顶部插入一个前言块。 |
| **字段** | 插入一个供 Super Tab 使用的填空，并将其选中，方便你为它命名（第 24 章）。 |

这些项目下方是一条分隔线，其后是**当前配置自己的构造**，例如配置定义的警示块或自定义块。如果没有选择配置，菜单会显示“Select a syntax profile to insert constructs”。

## 图示模板

插入 ▸ 图示提供 17 个起点。每一个都会插入一个可供编辑的有效示例。

流程图（Flowchart）、时序图（Sequence Diagram）、类图（Class Diagram）、状态图（State Diagram）、实体关系图（Entity Relationship Diagram）、甘特图（Gantt Chart）、饼图（Pie）、用户旅程图（User Journey）、Git 图（Git Graph）、思维导图（Mind Map）、时间线（Timeline）、象限图（Quadrant Chart）、桑基图（Sankey Diagram）、XY 图（XY Chart）、框图（Block Diagram）、数据包图（Packet Diagram）和看板（Kanban Board）。

## 图表模板

条形图（Bar Chart）、折线图（Line Chart）、面积图（Area Chart）、散点图（Scatter Plot）、饼图（Pie Chart）、堆叠条形图（Stacked Bar Chart）、直方图（Histogram）、热力图（Heatmap）和箱线图（Box Plot）。

## 公式模板

分数（Fraction）、平方根（Square Root）、求和（Summation）、积分（Integral）、极限（Limit）、二次公式（Quadratic Formula）、矩阵（Matrix）、分段函数（Piecewise Function）、对齐公式（Aligned Equations）、二项式系数（Binomial Coefficient）、贝叶斯定理（Bayes' Theorem）和欧拉恒等式（Euler's Identity）。

在 iPad 上，名称同样出现在“段落”子菜单中的插入项（提醒、水平线、链接引用、脚注、目录、YAML 前言）会显示为“插入提醒”等，因为 iPad 会合并同名的菜单项。

# Part XVII — 面板、栏和对话框

# Chapter 59: 文稿标题与文稿切换器

文稿的名称位于标题栏中，旁边有一个彩色小圆点和一个向下箭头。点按它，或选取 **视图 ▸ 打开的文稿**（`⌃⌘2`），即可打开**打开的文稿**列表。在小屏幕上，它会以带有**完成**按钮的面板形式打开。

## 存储圆点

名称旁的圆点让你一眼看出文稿的状态。VoiceOver 也会朗读该状态。

| 圆点 | 含义 |
| --- | --- |
| 绿色 | **已存储。**磁盘上的文件与你所见的一致。 |
| 琥珀色 | **已编辑。**你有尚未存储的更改。 |
| 红色 | **保存失败。**Pilcrow 尝试存储但未能成功。编辑器上方会出现带有**重试**按钮的“Couldn't save”横幅。 |
| 蓝色 | **已被其他 App 更改。**磁盘上的文件在 Pilcrow 之外被更改。 |

从未存储过的文稿会显示“Not yet saved”和一个编号，因为它没有可显示的文件夹。有未存储更改的文稿，其行末还会显示**已编辑**。

## 打开的文稿列表

| 部分 | 作用 |
| --- | --- |
| **搜索打开的文稿** | 打开了七个或更多文稿时出现。键入名称或文件夹的一部分；每个词都必须在名称或文件夹的某处匹配，忽略大小写和重音。按下**换行**键会打开第一个匹配项。没有匹配时显示“No open documents match.” |
| 每个文稿一行 | 显示名称、其存储圆点以及它所在的文件夹。对勾标记当前文稿。点按一行即可切换到它。 |
| **关闭**（行末的 **x**） | 关闭该文稿；如有未存储的更改，会先询问。 |
| **新建文稿** | 创建一个未命名文稿。 |
| **保存** | 存储当前文稿。 |
| **存储为…** | 以新名称或在新位置存储。 |
| **重命名…** | 打开重命名表单（见下文）。 |
| **关闭所有文稿** | 关闭所有文稿，并对每个未存储的文稿逐一询问。 |

使用 `⌃Tab` 和 `⌃⇧Tab` 可以移到下一个或上一个文稿，而无需打开列表。

## 重命名

**重命名…**会显示当前的**名称**和文件所在的**位置**，并带有**取消**和**重命名**按钮。重命名会更改磁盘上的文件，并保持文稿打开。如果新名称无法使用，会有“**无法重新命名文稿**”消息说明原因。
