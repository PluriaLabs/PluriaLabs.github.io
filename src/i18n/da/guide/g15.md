# Chapter 81: Filer, kodninger og grænser

## Filer, som Pilcrow åbner

Pilcrow redigerer filer med almindelig tekst og markup. De sædvanlige filtypenavne er `txt`, `md`, `markdown`, `adoc`, `asciidoc`, `rst` og `tex` samt ethvert filtypenavn, som en profil, du tilføjer, gør krav på. Pilcrow registrerer en fils tekstkodning, når den åbnes.

| Element | Type |
| --- | --- |
| Syntaksprofil, makrosamling, stilguide, programtema | `.json` |
| Gengivelsestema | `.css` |
| Temapakke | `.zip` |
| Bogprojektets manifest | `manifest.pilcrow` |
| Baggrund | HEIC, PNG, JPEG, SVG, MP4, MOV, M4V |
| Skrivelydklip | WAV, AIFF, MP3, M4A, CAF |

## Tekstkodninger

Pilcrow læser tekst i UTF-8, UTF-16, UTF-32 og ISO 8859-1 (Latin-1). Du kan konvertere et dokument med **Dokumentoplysninger ▸ Kodning ▸ Konvertér til…** til en af følgende; filen konverteres, næste gang den gemmes:

UTF-8, UTF-8 (BOM), UTF-16 LE, UTF-16 LE (BOM), UTF-16 BE, UTF-16 BE (BOM), UTF-32 LE, UTF-32 LE (BOM), UTF-32 BE, UTF-32 BE (BOM).

En Latin-1-fil kan konverteres til alle disse uden tab. Konvertering til Latin-1 tilbydes ikke, fordi det kan ødelægge indhold.

| Format | Filtypenavn |

| PDF | `.pdf` |

## Grænser og tal

Hvor Pilcrow stopper, eller hvor et valg har et interval:

| Hvor | Grænse |
| --- | --- |
| Søgepanel | Stopper ved 500 resultater. |
| Søgning i forhåndsvisning | Tæller op til 2.000 resultater. |
| Erstat i mappe | Ændrer højst 2.000 filer ad gangen. |
| Kontrollér links | Kontrollerer op til 50.000 links. |
| Sammenlign | Viser op til 5.000 ændrede linjer. |
| Versioner, der skal beholdes | Ingen til 500 (standard 50). |
| Lange linjer | Linjer på 20.000 tegn eller mere ombrydes altid. |
| Skriftstørrelse | 9 til 32 punkter. |
| Tabulatorbredde | 2 til 8 mellemrum. |
| Tekstbredde | 50 % til 100 %. |
| Zoom | 50 % til 200 % i ti trin. |
| Læsehastighed | 60 til 2.000 ord i minuttet. |
| Navigatorbredde | 180 til 420 punkter. |
| Skrivelydklip | Højst 2 sekunder og 3 MB. |
| Logtekst i diagnoserapport | De nyeste poster, op til 60.000 tegn, når den føjes til beskrivelsen af en GitHub-sag. |
| Meget store filer | Åbnes og redigeres uden at blive læst ind i hukommelsen på én gang. Linje- og ordtælling samt oversigten fuldføres i baggrunden og kan være ufuldstændige indtil da. PDF-eksport af et meget stort dokument kræver langt mere hukommelse end redigering og eksport til HTML og Word; PDF-arkiv deler det op i afgrænsede dele. |

## Hvor Pilcrow gemmer ting

| Hvad | Hvor |
| --- | --- |
| Dine dokumenter | Der, hvor du gemte dem. |
| Bibliotek (temaer, profiler, makroer, stilguides, baggrunde) | I programmets private lager eller i en mappe med navnet "Pilcrow Library" inde i en mappe, du vælger (**Indstillinger ▸ Bibliotek ▸ Placering**). |
| Indstillinger, API-nøgler, gendannelseskopier, versionshistorik | På enheden, i programmets private lager og nøgleringen. Gennemse og slet dem i **Indstillinger ▸ Generelt ▸ Lager og privatliv**. |
| Diagnostisk log | På enheden, indtil du rydder den. |

# Chapter 82: Meddelelser, bannere og tomme tilstande

Dette kapitel forklarer de korte meddelelser, Pilcrow viser, så ingen af dem er en gåde.

## I editoren og forhåndsvisningen

| Meddelelse | Hvad den betyder |
| --- | --- |
| **Nothing to preview yet. Start writing and it will appear here.** (eller "Switch to Edit and start writing.") | Dokumentet er tomt, så der er intet at tegne i forhåndsvisningen. |
| **Preview couldn't render: …** med **Vis kilde** og **Prøv igen** | Forhåndsvisningen mislykkedes. **Vis kilde** skifter til redigering. **Prøv igen** forsøger igen. |
| En mislykket ligning eller et mislykket diagram med et **Vis kilde**-link | Én blok kunne ikke tegnes. Klik på **Vis kilde** for at springe til den bloks kildetekst og rette den. |
| **Couldn't save** med **Prøv igen** og en knap til at afvise | Det lykkedes ikke at gemme. Dokumentet forbliver åbent og ugemt. Ret årsagen (diskplads, rettigheder, en fil, der er flyttet), og vælg **Prøv igen**. |
| **Filen er ændret på disken** | Et andet program har ændret filen. **Indlæs igen** læser den nye version; **Behold nuværende version** beholder det, du har. |
| **Fortolkningsadvarsel** | En linje, hvor en konstruktion sandsynligvis ikke er det, du mente (Chapter 68). |
| **Vil du erstatte den eksisterende fil?** | Det navn, du valgte, er allerede i brug det pågældende sted. |
| **Der er stadig felter, der skal udfyldes** | Du udskriver eller eksporterer med felter, der ikke er udfyldt (Chapter 63). |
| **Rudeskiller** (VoiceOver-hint: "Drag to resize the editor and the preview. Double-tap to reset.") | Håndtaget mellem kilde og forhåndsvisning i Side om side. |
| **Ord: N** | Ordtællingen i statuslinjen. |

## I dialoger og paneler

| Hvor | Meddelelse | Betydning |
| --- | --- | --- |
| Kommandopalet | **Skriv en kommando** | Feltets hint. "No matching commands" vises, når intet passer. |
| Åbn hurtigt | **Skriv et filnavn** | Feltets hint. |
| Markører i en kolonne | **Linjer (f.eks. 3-17)**, **Kolonne (f.eks. 100 eller 100-105 for at markere)** | Feltets hint. En enkelt kolonne placerer markører; et interval markerer disse tegn på hver linje. |
| Søgepanel | **Type to search this folder.**, **No matches in this folder.**, **Search cancelled.** | Tilstanden for en mappesøgning. |
| Filpanel | **You can also drop a folder here.** | Træk en mappe hen på panelet for at åbne den. |
| Erstat i mappe | **Nothing to replace.** | Søgningen har ingen resultater. |
| Sammenlign | Værktøjstip på knapperne: **Acceptér** ("Make this change in the open document"), **Afvis** ("Leave this change out of the open document"), **Tag tilbage** ("Put the older lines back in the document for this change only"). | Hvad hver af dem gør. |
| Oversæt | **The translation could not be completed.** | Prøv igen, eller vælg en anden hastighed. |
| Oversæt | **Anslået tid: under et minut** | Et skøn for AI-assistentens hastighed; tiden afhænger af din AI-tjeneste. Efter en oversættelse åbner **Åbn i ny fane** resultatet. |
| Assistent | **No document is open.**, **No document text is sent.** | Panelet har intet at dele, så der sendes intet. |
| Modelvælger | **Indlæser modeller…**, **No models match.** | Listen indlæses, eller din søgning fandt intet. |
| Stilgennemgang | **No findings.** og **The reply could not be read as findings. Try again.** | Gennemgangen fandt intet, eller AI'ens svar havde ikke det forventede format. |
| Stilgennemgang | Værktøjstip for **Anvend alle**: "Makes every fix that has one, as a single change you can undo." | Én Fortryd tilbagefører dem alle. |
| Projektpanel | **Dit navn**, **Tilføj variabel** | Hintet i feltet Forfatter og knappen til en projektvariabel. |
| Assistenttilladelse | **Read Pilcrow's privacy policy** | Åbner privatlivspolitikken. |
