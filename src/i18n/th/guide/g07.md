# Chapter 60: แถบด้านข้าง

แถบด้านข้างมีห้าแผง ได้แก่ **Files**, **Outline**, **Search**, **Project** และ **Assistant** สวิตช์ที่ด้านบนของแถบด้านข้างใช้เลือก **Files**, **Outline**, **Project** (แสดงเมื่อโฟลเดอร์ที่เปิดอยู่เป็นโปรเจกต์หนังสือ) หรือ **Assistant** (แสดงเมื่อตั้งค่าการเชื่อมต่อแล้ว) ส่วน **Search** มีส่วนหัวของตัวเองที่มีชื่อว่า **Find**, ปุ่ม **Done** ที่พาคุณกลับไปยัง Files และตัวควบคุมขอบเขตสำหรับ **This Document** หรือ **Folder** เข้าถึงได้จาก **View ▸ Search** (`⇧⌘F`) เมนู **View** ยังใช้สลับแผงได้ด้วย และการเลือกแผงที่แสดงอยู่แล้วจะซ่อนแถบด้านข้าง ลากขอบของแถบด้านข้างเพื่อปรับขนาด เหนือแผนผังไฟล์มีเมนูที่ให้เลือก **Open File…** และ **Open Folder…**

## Files

แผง Files คือแผนผังของโฟลเดอร์ที่เปิดอยู่

เมื่อไม่มีโฟลเดอร์เปิดอยู่ แผงจะแสดงข้อความ "Choose a folder to browse its files." และมี **Open Folder** กับ **Open File** ให้เลือก คุณยังลากโฟลเดอร์มาวางบนแผงได้ด้วย เมื่อคุณเปิดไฟล์เดียวที่ Pilcrow มองไม่เห็นโฟลเดอร์ของไฟล์นั้น แผงจะแสดง "Browse *folder* to see the files beside this document" พร้อม **Browse Enclosing Folder…**

คลิกไฟล์เพื่อเปิด โฟลเดอร์ขยายและยุบได้ คลิกขวาที่แถว หรือกดค้างบน iPad เพื่อเปิดเมนูของแถวนั้น:

| Item | What it does |
| --- | --- |
| **New File** | สร้างไฟล์ในโฟลเดอร์ (หรือข้างไฟล์ที่คุณคลิก) |
| **New Folder** | สร้างโฟลเดอร์ที่นั่น |
| **Rename…** | เปลี่ยนชื่อไฟล์หรือโฟลเดอร์ |
| **Move to Trash** | ย้ายไปที่ถังขยะหลังจากที่คุณยืนยัน คุณนำกลับมาจากที่นั่นได้ |
| **Reveal in Finder** | แสดงใน Finder (Mac) |

ในตำแหน่งที่ระบบไม่มีถังขยะ Pilcrow จะเก็บรายการที่ลบไว้ในส่วน **Recently Deleted** ที่ด้านล่างของแผง แต่ละรายการในนั้นมี **Put Back** และ **Delete Permanently** และ **Empty Recently Deleted** จะลบรายการทั้งหมดในส่วนนั้นอย่างถาวร การลบอย่างถาวรเลิกทำไม่ได้ Pilcrow จึงถามก่อน รายการที่คุณลบจากที่อื่นจะไม่ได้รับผลกระทบ

การแสดงหรือซ่อนไฟล์และโฟลเดอร์ที่ซ่อนอยู่ทำได้ที่ **Settings ▸ Files ▸ Show hidden folders and files**

## Outline

Outline แสดงรายการหัวเรื่องของเอกสารที่ใช้งานอยู่ โดยเยื้องตามระดับ คลิกหัวเรื่องเพื่อข้ามไปที่นั่น เครื่องหมายลูกศรทางด้านข้างหัวเรื่องใช้ยุบหรือขยายหัวเรื่องที่อยู่ภายใต้ สิ่งนี้ไม่เปลี่ยนเอกสาร และสถานะที่ยุบไม่ถูกบันทึก

สถานะที่คุณอาจเห็น:

| Message | Meaning |
| --- | --- |
| **No headings** | โปรไฟล์ที่ใช้งานอยู่ไม่พบหัวเรื่อง |
| **Indexing outline… N%** | เอกสารขนาดใหญ่ยังอยู่ระหว่างการสแกน |
| **Outline indexing failed. The listing may be incomplete.** | การสแกนพบปัญหา |
| **N headings near your position — scroll to see others.** | เอกสารที่ใหญ่มากจะแสดงเค้าร่างเป็นช่วงรอบตำแหน่งเคอร์เซอร์ |

ใต้เค้าร่างจะมีส่วน **Fields** ปรากฏขึ้นเมื่อเอกสารมีฟิลด์ให้กรอก (Chapter 24) ส่วนนี้แสดงรายการฟิลด์พร้อมจำนวน คลิกฟิลด์เพื่อเลื่อนไปที่ฟิลด์นั้นและเลือกมัน หากมีฟิลด์จำนวนมาก แผงจะแสดงว่า "Only the first fields are listed."

## Search

แผง Search ค้นหาในทุกไฟล์ของโฟลเดอร์ที่เปิดอยู่ หากไม่มีโฟลเดอร์ แผงจะแสดง "Open a folder to search it." พร้อมปุ่ม **Open Folder…**

| Control | What it does |
| --- | --- |
| ช่อง **Search Folder** | พิมพ์เพื่อค้นหาไปเรื่อยๆ ปุ่ม **clear** จะล้างช่อง |
| **Aa** | **Match case** |
| **ab** | **Whole word** |
| **.\*** | **Regular expression** รูปแบบที่ไม่ถูกต้องจะแสดงข้อความใต้ช่อง |
| บรรทัดสถานะ | แสดง "Searching…" พร้อมปุ่ม **Cancel** จากนั้นแสดง "Matches: N" การค้นหาจะหยุดที่ 500 รายการที่ตรงกันและแสดง "Showing the first 500 matches." หลังจากยกเลิก จะมี **Search Again** ให้เลือก |
| **Replace…** | ปรากฏเมื่อการค้นหาพบรายการที่ตรงกัน เปิด Replace in Folder (Chapter 63) |
| ผลลัพธ์ | แต่ละผลลัพธ์ระบุชื่อไฟล์และแสดงบรรทัด คลิกผลลัพธ์เพื่อเปิดไฟล์ที่บรรทัดนั้น |

## Project

แผง Project มีไว้สำหรับโปรเจกต์หนังสือ ดู Chapter 34, Chapter 35 และคู่มืออ้างอิงแผง Project ด้านล่าง

### Project panel reference

| Part | What it does |
| --- | --- |
| **This folder is not a book project.** พร้อม **Make It a Project** | แสดงเมื่อโฟลเดอร์ที่เปิดอยู่ไม่มี manifest |
| **Try Again** | แสดงหากอ่านโปรเจกต์ไม่ได้ |
| **View** | เลือก **List**, **Synopses** หรือ **Cards** |
| ชื่อเรื่อง ยอดรวมจำนวนคำ | ชื่อโปรเจกต์และ "N words" หรือ "N of target" เมื่อตั้งเป้าหมายจำนวนคำของหนังสือไว้ |
| ตัวกรอง **Status** | กรองให้เหลือหนึ่งสถานะ หรือ **All statuses** ตารางสรุปแสดงแต่ละสถานะพร้อมจำนวนไฟล์และจำนวนคำ การจัดลำดับใหม่ทำได้เฉพาะเมื่อไม่มีตัวกรองใช้งานอยู่ |
| **Project Settings** (เฟือง) | เปิดชีตการตั้งค่าด้านล่าง |
| **Compile…** | เปิดชีตคอมไพล์ (Chapter 64) |
| **Reorder** และ **Done** | บน iPad ลากบทเพื่อจัดลำดับใหม่ แล้วเลือก **Done** |
| **New File** (เครื่องหมายบวก) | มี **New Chapter**, **New Scene**, **New Front Matter**, **New Back Matter** ให้เลือก |
| **Not in the manuscript** พร้อม **Add** และ **Add All** | แสดงไฟล์ในโฟลเดอร์ที่ manifest ไม่ได้รวมไว้ |
| เครื่องหมายลูกศรของแถว | **Show Scenes** หรือ **Hide Scenes** ใต้บท |
| แท็ก **Missing** และ **Left out** | ไฟล์ที่หาไม่พบ หรือไฟล์ที่คุณละไว้จากต้นฉบับ |
| เมนูของแถว | **Details…**, **New File Below**, **Move Chapter Up**, **Move Chapter Down**, **Include in Manuscript**, **Leave Out of Manuscript** |
| **Word target** ของแต่ละรายการ | แต่ละรายการแสดงจำนวนคำและเป้าหมาย (ถ้ามี) |

**Details** ของรายการมี **Kind** (Front matter, Part, Chapter, Scene, Back matter), **Status**, **Point of view**, **Location**, **Word target** และ **Synopsis** หากไฟล์โปรเจกต์เปลี่ยนแปลงบนดิสก์ จะแสดง "The project file changed on disk, so your last change was not applied. Try it again." พร้อม **Dismiss**

**Project Settings** มี **Title**, **Author**, **Book word target**, **New files are written in** (ไวยากรณ์สำหรับบทและฉากใหม่ ไฟล์ที่มีอยู่แล้วยังคงของเดิม), **Variables** (ชื่อและค่า เขียนเป็น `{{name}}` ในข้อความของคุณ `{{title}}` และ `{{author}}` ใช้ได้เสมอ) และ **What counts as a word**: **Count headings**, **Count front matter**, **Count code blocks** เลือก **Save** หรือ **Cancel**

# Chapter 61: แถบเครื่องมือจัดรูปแบบและแถบสถานะ

## แถบเครื่องมือจัดรูปแบบ

แถบเครื่องมือจัดรูปแบบเป็นแถวเสริมใต้ข้อความ แสดงหรือซ่อนได้ด้วย **View ▸ Formatting Toolbar**, **More ▸ Formatting Toolbar**, **Settings ▸ Editing ▸ Formatting Toolbar** หรือรายการ **Hide Toolbar** ของแถบเครื่องมือเอง แถบนี้ทำงานผ่านโปรไฟล์ที่ใช้งานอยู่ ปุ่มที่โปรไฟล์ไม่รองรับจึงเป็นสีเทา

| Control | What it does |
| --- | --- |
| เมนู **Paragraph type** (เช่น "Paragraph" หรือ "Heading 1") | แสดงประเภทของบรรทัดปัจจุบันและเปลี่ยนได้: **Paragraph**, **Heading 1** ถึง **6**, **Blockquote**, **Bulleted List**, **Numbered List**, **Task List**, **Code Fence** |
| **Bold** (`⌘B`) | ตัวหนา |
| **Italic** (`⌘I`) | ตัวเน้น |
| **Inline code** | โค้ด |
| **Insert link** (`⌘K`) | สร้างลิงก์ |
| **Blockquote** | สลับการอ้างอิง |
| **Bulleted list** | สลับรายการสัญลักษณ์แสดงหัวข้อย่อย |
| **More formatting** (**⋯**) | คำสั่งที่ใช้น้อยกว่า: **Strikethrough**, **Insert Inline Math**, **Insert Task List**, **Toggle Task Status**, **Indent**, **Outdent**, **Increase Heading Level**, **Decrease Heading Level**, **Insert Table…**, **Insert Image…**, **Insert Diagram**, **Insert Chart**, **Insert Display Math**, **Insert Code Fence**, **Insert Alert**, **Insert Horizontal Line**, **Insert Link Reference**, **Insert Footnote**, **Insert Table of Contents**, **Insert YAML Front Matter** และ **Hide Toolbar** |

## แถบสถานะ

แถบสถานะอยู่ตามแนวด้านล่าง เปิดหรือปิดได้ที่ **Settings ▸ Editing ▸ Show status bar**

| Part | What it shows or does |
| --- | --- |
| **Words**, **Ln**, **Col** | จำนวนคำ และบรรทัดกับคอลัมน์ของเคอร์เซอร์ เมื่อมีส่วนที่เลือก จะเพิ่ม "Sel: N ln · N ch" สำหรับจำนวนบรรทัดและอักขระที่เลือก |
| เมนู **Syntax** (เช่น "CommonMark") | โปรไฟล์ของเอกสารนี้ คลิกเพื่อเลือกอย่างอื่น หรือ **No Syntax** สำหรับข้อความธรรมดา |
| **Fields left: N** | แสดงเมื่อมาโครทิ้งฟิลด์ให้กรอกไว้ คลิกเพื่อข้ามไปยังฟิลด์ถัดไป |
| ความคืบหน้าและสถานะ | **Indexing N%**, **Lexing N%** ขณะวิเคราะห์ไฟล์ขนาดใหญ่ และ **Translating N%** พร้อม **About N left** และปุ่ม **Cancel translation** ขณะที่การแปลกำลังทำงาน |
| **Out of sync** | คำเตือนว่าตัวแก้ไขกับบันทึกการเปลี่ยนแปลงของเอกสารไม่ตรงกัน การบันทึกจะคงไฟล์ไว้ในสถานะยังไม่ได้บันทึกเพื่อไม่ให้สูญเสียสิ่งใด: คัดลอกข้อความของคุณไปเก็บในที่ปลอดภัย แล้วปิดและเปิดเอกสารใหม่ |
| ข้อมูลเอกสาร | คลิกตัวเลขจำนวน หรือคำแนะนำ "Show document information" เพื่อเปิด **Document Information** |

**Document Information** แสดง **Words**, **Characters**, **Lines**, **Reading time** (อิงจากความเร็วในการอ่านของคุณใน Settings), **Cursor**, **Selection**, **Encoding** และ **Syntax** ในไฟล์ขนาดใหญ่มาก ตัวเลขจะนับเฉพาะส่วนที่โหลดแล้วจนกว่าการทำดัชนีจะเสร็จ และเวลาอ่านจะประมาณจากทั้งไฟล์ **Convert To…** ใต้ **Encoding** ใช้เลือกการเข้ารหัสข้อความอื่น ไฟล์จะถูกแปลงเมื่อบันทึกครั้งถัดไป


# Chapter 62: Find, replace, Go to Line, Open Quickly และคำสั่งด่วน

## แถบค้นหา

เปิดด้วย **Find…** (`⌘F`), ปุ่ม **Find** หรือ **Replace…** (`⌘R`) แถบนี้อยู่ที่ด้านบนของเอกสาร

| Control | What it does |
| --- | --- |
| ช่อง **Find in document** | พิมพ์ข้อความที่ต้องการค้นหา รายการที่ตรงกันจะถูกไฮไลต์ขณะที่คุณพิมพ์ |
| **Aa**, **ab**, **.\*** | **Match case**, **Whole word**, **Regular expression** |
| **Previous match**, **Next match** | ไล่ดูรายการที่ตรงกัน (`⇧⌘G`, `⌘G`) |
| **Show replace** / **Hide replace** (เครื่องหมายลูกศร) | แสดงช่อง **Replace with** |
| **Replace**, **Replace All** | แทนที่รายการที่ตรงกันปัจจุบัน หรือทุกรายการ เป็นสีเทาจนกว่าจะมีรายการที่ตรงกัน |
| **Find In** (สวิตช์ที่ปลายซ้ายของแถบ) | **This Document** หรือ **Folder** เพื่อค้นหาในทั้งโฟลเดอร์ที่เปิดอยู่แทน |
| **Close find bar** | ปิดแถบ |

เมื่อมีรายการที่ตรงกันมากกว่าที่ Pilcrow นับ แถบจะแสดง "More matches remain" ใน **Preview** Find จะค้นผ่านคำที่แสดงผลแล้วและไฮไลต์คำเหล่านั้น สูงสุด 2,000 รายการ รูปแบบที่ใช้ไม่ได้จะแสดง "Invalid pattern" Replace ใช้ได้เฉพาะใน Edit: ใน Preview แถบจะแสดง "Replace works in Edit. Switch to Edit to change the text." ใน **Side by Side** Find ค้นหาในซอร์สและไฮไลต์คำที่ตรงกันในตัวอย่าง

## Go to Line

**Go to Line…** (`⌃G`) เปิดชีตเล็กๆ ที่มีช่องเดียว คือ "Line number, or line:column" พิมพ์ `120` หรือ `120:8` แล้วเลือก **Go** หรือ **Cancel** หมายเลขที่เกินท้ายเอกสารจะไปที่บรรทัดสุดท้าย สำหรับสิ่งอื่น Pilcrow จะแสดง "Enter a line number, such as 120 or 120:8." ในไฟล์ขนาดใหญ่มากที่ยังนับบรรทัดไม่เสร็จ แอปจะขอให้ลองอีกครั้งในอีกสักครู่

## Open Quickly

**Open Quickly…** (`⇧⌘O`) คือการค้นหาชื่อไฟล์ในทั้งโฟลเดอร์ที่เปิดอยู่ พิมพ์บางส่วนของชื่อ รายการจะแคบลงและแสดง "N matches" เลือกผลลัพธ์แล้วเลือก **Open** หรือ **Cancel** จะเป็นสีเทาหากไม่มีโฟลเดอร์ที่เปิดอยู่

## คำสั่งด่วน

**Command Palette…** (`⌃⇧P`) แสดงรายการคำสั่งของ Pilcrow ตามชื่อพร้อมทางลัด เพื่อให้คุณเรียกใช้คำสั่งได้โดยไม่ต้องหาเมนู พิมพ์เพื่อให้รายการแคบลง เลือกคำสั่งแล้วเลือก **Run** หรือ **Cancel** แอปแสดง "No matching commands" เมื่อไม่มีสิ่งใดตรง คำสั่งที่ใช้งานไม่ได้ในขณะนี้ เช่น การแก้ไขซอร์สขณะอยู่ใน Preview จะแสดงเป็นสีเทา รายการนี้รวมคำสั่งจัดรูปแบบและแทรก คำสั่ง Edit สำหรับการเลือก บรรทัด และตัวพิมพ์ การอ่านออกเสียง สวิตช์ของ View การซูม แผงของแถบด้านข้าง และการดำเนินการกับไฟล์และการส่งออก ทางลัดสำหรับเปิดคำสั่งด่วนเปลี่ยนได้ที่ **Settings ▸ Keyboard**
