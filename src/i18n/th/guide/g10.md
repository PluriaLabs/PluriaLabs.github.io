# Chapter 68: การแก้ไข

## การแสดงผลและการพิมพ์

### การแสดงผล

| ตัวควบคุม | หน้าที่ |
| --- | --- |
| **แสดงหมายเลขบรรทัด** | หมายเลขบรรทัดในแถบข้าง เหมือน **มุมมอง ▸ หมายเลขบรรทัด** |
| **แสดงกฎบรรทัดปัจจุบัน** | เส้นบางใต้บรรทัดที่เคอร์เซอร์อยู่ |
| **ต้นฉบับที่มีสไตล์** | วาดหัวเรื่อง ตัวหนา และตัวเอียงด้วยรูปแบบตัวอักษรที่ตรงกัน |
| **การพับหัวเรื่อง** | ลูกศรพับข้างหัวเรื่อง |
| **บล็อกที่แสดงผล** | วาดตาราง สมการ และแผนภาพเป็นรูปภาพพร้อมปุ่มแก้ไข |
| **ขยายส่วนอัตโนมัติ** | เปิดส่วนที่พับไว้หรือบล็อกรูปภาพเมื่อเคอร์เซอร์เข้าไปในนั้น และปิดเมื่อเคอร์เซอร์ออกไป |
| **ซ่อนเครื่องหมาย** | ซ่อนเครื่องหมายของหัวเรื่อง ตัวหนา และตัวเอียงในทุกบรรทัดยกเว้นบรรทัดของเคอร์เซอร์ ต้องเปิด ต้นฉบับที่มีสไตล์ |
| **ตัดบรรทัดยาว** | เมื่อปิด บรรทัดยาวจะเลื่อนไปด้านข้างแทนการตัดบรรทัด ตัวอย่างและการส่งออกจะตัดบรรทัดเสมอ บรรทัดที่ยาว 20,000 อักขระขึ้นไป และโหมดโฟกัส จะตัดบรรทัดเสมอ |
| **บรรทัดสั้นในโหมดคอลัมน์** | สิ่งที่คอลัมน์ทำกับบรรทัดที่สั้นเกินกว่าจะถึงคอลัมน์: **ใช้ท้ายบรรทัด**, **ไม่รวมบรรทัดนี้**, **เติมช่องว่างแบบยืดหยุ่น** (เพิ่มช่องว่างเพื่อให้ข้อความที่พิมพ์เรียงตรงกันบนหน้าจอ), **เติมช่องว่างแบบตายตัว** (หนึ่งช่องว่างต่อทุกอักขระที่ขาด เพื่อให้เรียงตรงกันตามหมายเลขคอลัมน์) หรือ **หยุดที่บรรทัด** การลบจะไม่ลบอักขระออกจากบรรทัดสั้น |
| **แสดงแถบสถานะ** | เปิดหรือปิดแถบสถานะที่ด้านล่าง |
| **แถบเครื่องมือจัดรูปแบบ** | แสดงแถบเครื่องมือเสริมใต้ข้อความ |

### การพิมพ์

| ตัวควบคุม | หน้าที่ |
| --- | --- |
| **จับคู่วงเล็บและเครื่องหมายคำพูดอัตโนมัติ** | การพิมพ์วงเล็บเปิดหรือเครื่องหมายคำพูดเปิดจะเพิ่มตัวปิดให้ |
| **จับคู่ Markdown อัตโนมัติ ( \* \_ ` ~ )** | ทำเช่นเดียวกันกับเครื่องหมายของ Markdown |
| **ขยายรหัสย่ออีโมจิ (:smile:)** | เปลี่ยนรหัสย่อเป็นอีโมจิขณะที่คุณพิมพ์ ไฟล์ที่มีรหัสย่ออยู่แล้วจะแสดงตามที่เขียนไว้ |
| **ต่อรายการและข้อความอ้างอิงเมื่อกด Return** | Return เริ่มรายการถัดไป Return บนรายการว่างจะจบรายการ และ Tab จะเยื้องรายการ |
| **คงการเยื้องเมื่อกด Return** | บรรทัดใหม่เริ่มต้นด้วยช่องว่างหรือแท็บนำหน้าเหมือนบรรทัดข้างบน |
| **แทรกช่องว่างเมื่อกด Tab** | Tab แทรกช่องว่างตามความกว้างแท็บ จนถึงจุดหยุดแท็บถัดไป แทนอักขระแท็บ |

เครื่องหมายวรรคตอนอัจฉริยะ ไฮไลต์ ตัวห้อย และตัวยก อยู่ภายใต้ **คลัง ▸ ตัวเลือก CommonMark**

### เสียงการพิมพ์

| ตัวควบคุม | หน้าที่ |
| --- | --- |
| **เล่นเสียงขณะพิมพ์** | ทุกปุ่มมีเสียง Space, Return และ Delete เสียงต่างกัน การวางและการเลิกทำจะเงียบ บน iPad สวิตช์เงียบจะปิดเสียงนี้ |
| **เสียง** | ชุดเสียง: **เครื่องพิมพ์ดีด**, **เป็ด** หรือ **ลูกแมว** |
| **ระดับเสียง**, **ตัวอย่าง** | ตั้งระดับและฟังชุดเสียง |
| **เสียงของคุณเอง** | เลือกคลิปสั้นสำหรับปุ่มแต่ละประเภท ประเภทอื่นจะใช้เสียงที่เลือกไว้ด้านบน ประเภทได้แก่ **ตัวพิมพ์เล็ก**, **ตัวพิมพ์ใหญ่**, **ตัวเลข**, **สัญลักษณ์และเครื่องหมายวรรคตอน**, **ช่องว่าง**, **แท็บ**, **Return** และ **ลบ** แต่ละประเภทมี **เลือก…** (หรือ **เปลี่ยน…**), **เล่น** และ **ลบออก** คลิปยาวได้ถึง 2 วินาทีและขนาด 3 MB (WAV, AIFF, MP3, M4A หรือ CAF) และถูกเก็บไว้ในหน่วยความจำเพื่อให้เล่นได้โดยไม่มีหน่วงเวลา |

### การสะกดและการวินิจฉัย

**ตรวจการสะกดขณะพิมพ์** ขีดเส้นใต้คำที่สะกดผิด **แสดงคำเตือนการแยกวิเคราะห์** ทำเครื่องหมายบรรทัดที่โครงสร้างบางอย่างน่าจะไม่ตรงกับที่คุณตั้งใจ เช่น รั้วโค้ดหรือบล็อกสูตรคณิตศาสตร์ที่ไม่ได้ปิด ลิงก์ที่ไม่มีวงเล็บปิด หรือแถวตารางที่ไม่ตรงกับส่วนหัว หมายเหตุจะปรากฏที่ท้ายบรรทัด การตั้งค่านี้เปลี่ยนสิ่งที่แสดง ไม่เคยเปลี่ยนวิธีที่เอกสารถูกแยกวิเคราะห์หรือส่งออก

## รูปภาพ

การตั้งค่าเหล่านี้กำหนดสิ่งที่เกิดขึ้นกับรูปภาพที่คุณแทรก (**แทรก ▸ รูปภาพ…** หรือโดยการวางลงไป)

| ตัวควบคุม | หน้าที่ |
| --- | --- |
| **การดำเนินการ** | **ไม่มีการดำเนินการพิเศษ**, **คัดลอกรูปภาพไปยังโฟลเดอร์ปัจจุบัน (./)**, **คัดลอกรูปภาพไปที่ ./assets** หรือ **คัดลอกรูปภาพไปที่ ./\${filename}.assets** **อัปโหลดรูปภาพ** แสดงเป็นไม่พร้อมใช้งาน: Pilcrow ไม่มีโฮสต์รูปภาพ จึงแทรกรูปภาพไว้ตรงที่มันอยู่แล้ว |
| **ใช้กับรูปภาพในเครื่อง** | การดำเนินการใช้กับรูปภาพที่อยู่บนอุปกรณ์ของคุณแล้วหรือไม่ |
| **ใช้กับรูปภาพออนไลน์** | ใช้กับรูปภาพที่ชี้ไปยังที่อยู่เว็บหรือไม่ |
| **โหลดรูปภาพจากอินเทอร์เน็ต** | เมื่อปิด รูปภาพที่ชี้ไปยังที่อยู่เว็บจะไม่ถูกดาวน์โหลดสำหรับตัวอย่าง PDF หรือการส่งออกรูปภาพ ดังนั้นเว็บไซต์ที่โฮสต์รูปภาพจะไม่รู้อะไรเลย เมื่อเปิด รูปภาพจะถูกดึงเหมือนในเว็บเบราว์เซอร์ และเว็บไซต์นั้นเห็นคำขอได้ |
| **ใช้พาธสัมพัทธ์หากเป็นไปได้** | เขียนพาธที่สัมพัทธ์กับเอกสาร |
| **เพิ่ม ./ สำหรับพาธแบบสัมพัทธ์** | เริ่มพาธสัมพัทธ์ด้วย `./` |
| **หลีก URL ของรูปภาพอัตโนมัติเมื่อแทรก** | หลีกอักขระในที่อยู่ที่จะทำให้ลิงก์เสีย |

## พื้นหลังตัวแก้ไข (ฉากหลัง)

รูปภาพหรือวิดีโอวางอยู่ด้านหลังตัวแก้ไข แถบด้านข้าง และแถบสถานะได้

| ตัวควบคุม | หน้าที่ |
| --- | --- |
| **สื่อ** | **เลือก…** รูปภาพ HEIC, PNG, JPEG หรือ SVG หรือวิดีโอ MP4, MOV หรือ M4V **ลบออก** จะล้างสื่อ |
| **เลย์เอาต์** | **เติม**, **พอดี** หรือ **เรียงต่อ** |
| **ด้านหลังพื้นที่ข้อความ**, **ด้านหลังแถบด้านข้าง** | แต่ละรายการมี **หรี่** และ **เบลอ** ของตัวเอง **หรี่** ปิดรูปภาพด้วยสีพื้นหลังของธีมเพื่อให้ข้อความอ่านได้ **เบลอ** ทำให้รูปภาพนุ่มลง แถบสถานะจะเบลอรูปภาพ |
| **เล่นขณะใช้แบตเตอรี่** | ให้วิดีโอเล่นขณะใช้พลังงานจากแบตเตอรี่ วิดีโอจะหยุดชั่วคราวในโหมดประหยัดพลังงานและอยู่นิ่งเมื่อเปิดลดการเคลื่อนไหว |
| **เสียง**, **ระดับเสียง** | วิดีโอเล่นแบบไม่มีเสียงเว้นแต่คุณเปิดเสียงของมัน |

ฉากหลังจะไม่ปรากฏในตัวอย่างหรือในการส่งออก และลดความโปร่งใสจะซ่อนฉากหลัง

# Chapter 70: สารบัญและค่าเริ่มต้นการส่งออก

## สารบัญและป้ายกำกับ

การตั้งค่าเหล่านี้ใช้กับทุกรูปแบบการส่งออก: PDF, Word, HTML และอื่นๆ

| ตัวควบคุม | หน้าที่ |
| --- | --- |
| **เพิ่มสารบัญในทุกการส่งออก** | ใส่รายการสารบัญไว้ที่ด้านบนของแต่ละการส่งออก |
| **แทนที่บรรทัด [TOC] ด้วยรายการ** | บรรทัดที่มีเพียง `[TOC]` จะกลายเป็นรายการหัวเรื่องในตัวอย่างและทุกการส่งออก |
| **ใส่หมายเลขหัวเรื่อง (1., 1.1.)** | ใส่หมายเลขหัวเรื่องในผลลัพธ์ ป้ายกำกับหัวเรื่องด้านล่างจะมาแทนที่การใส่หมายเลขธรรมดา |
| **ชื่อเรื่อง** | ชื่อที่เรียกรายการ เช่น "สารบัญ" หรือ "คำแนะนำ" หากเว้นว่างจะใช้ "สารบัญ" |
| **แสดงหัวเรื่องลงไปถึงระดับ** | ความลึก 1 ถึง 6 ระดับ 1 แสดงเฉพาะหัวเรื่องบนสุด ระดับ 6 แสดงทั้งหมด |
| **การย่อหน้า** | การเยื้องเป็นพอยต์สำหรับแต่ละระดับ |
| **ลิงก์แต่ละหัวเรื่องกลับไปยังรายการในสารบัญ** | เพิ่มลิงก์กลับจากหัวเรื่องไปยังรายการของมัน |
| **แสดงเฉพาะหัวเรื่องที่อยู่ต่ำกว่าบรรทัด [TOC]** | ไม่รวมหัวเรื่องที่อยู่เหนือบรรทัด `[TOC]` |

### ป้ายกำกับหัวเรื่อง

**ใส่ป้ายกำกับให้หัวเรื่อง** ให้ป้ายกำกับของตัวเองแก่แต่ละระดับ เช่น "ส่วน I -" หรือ "บทที่ 3:" แต่ละระดับมีแม่แบบ ในแม่แบบ `#` คือหมายเลขถัดไป และ `@` คือตัวอักษรพิมพ์ใหญ่ตัวถัดไป ป้ายกำกับใช้ได้อย่างใดอย่างหนึ่ง ไม่ใช่ทั้งสอง เขียน `\#` หรือ `\@` เพื่อเริ่มนับใหม่ทุกครั้งที่มีหัวเรื่องระดับตื้นกว่าปรากฏ หากเขียนเปล่าจะนับต่อไปทั้งเอกสาร **ตัวอักษร** และ **ตัวเลข 0 ถึง 9** กำหนดอักขระที่ใช้ในการใส่ตัวอักษรและหมายเลข หลังตัวอักษรสุดท้าย ตัวอักษรจะเพิ่มเป็นสองตัว: Y, Z, AA, AB

## ค่าเริ่มต้นการส่งออก

| ตัวควบคุม | หน้าที่ |
| --- | --- |
| **ธีมการแสดงผล** | ธีมเริ่มต้นสำหรับตัวอย่างและการส่งออก |
| **รูปแบบ**, **นามสกุลไฟล์**, **ตัวแปลง** | ข้อมูลเกี่ยวกับแต่ละรูปแบบการส่งออก ทั้งหมดสร้างโดยตัวแปลงในตัว |
| **หน้า** | ขนาดกระดาษ การวางแนว และระยะขอบที่ใช้สำหรับการพิมพ์และทุกการส่งออก PDF, PDF Archive และ Word (บทที่ 64) |
| **แม่แบบส่วนหัวกระดาษ**, **แม่แบบท้ายกระดาษ** | ข้อความสำหรับด้านบนและด้านล่างของแต่ละหน้า ตัวแปร: `${title}`, `${author}`, `${pageNo}`, `${pageCount}` และ `${today}` ตัวอย่างเช่น ท้ายกระดาษ `Page ${pageNo}` |
| **ผู้เขียน** | ชื่อผู้เขียนที่ใช้โดย `${author}` และในข้อมูลเมทาของเอกสาร |
| **ตัดหน้าระหว่างหัวเรื่องระดับบนสุด** | เริ่มหัวเรื่องระดับบนสุดแต่ละรายการในหน้าใหม่ |

# Chapter 71: คลัง

คลังคือธีม โปรไฟล์ไวยากรณ์ มาโคร คู่มือสไตล์ และฉากหลังที่คุณเพิ่ม รายการในตัวเป็นแบบอ่านอย่างเดียว ให้ทำสำเนารายการหนึ่งเพื่อแก้ไข

## โปรไฟล์ไวยากรณ์

แสดงแต่ละโปรไฟล์เป็น **ในตัว** หรือ **กำหนดเอง**

| ตัวควบคุม | หน้าที่ |
| --- | --- |
| **นำเข้า…** | เพิ่มไฟล์ `.json` ของโปรไฟล์ที่มีคนแชร์ให้ |
| **ใหม่** | เริ่มโปรไฟล์ตั้งแต่ต้น |
| **แก้ไข**, **ทำสำเนา**, ลบ | ต่อโปรไฟล์ โปรไฟล์ในตัวทำสำเนาได้แต่แก้ไขหรือลบไม่ได้ |
| **ยังไม่ได้โหลด** | โปรไฟล์ที่โหลดไม่ได้จะแสดงที่นี่พร้อมเหตุผล: ใช้นามสกุลไฟล์ที่โปรไฟล์อื่นมีอยู่แล้ว ไม่ใช่โปรไฟล์ที่เวอร์ชันนี้อ่านได้ หรือมีรูปแบบที่อาจทำให้ตัวแก้ไขหยุดตอบสนอง โปรไฟล์นั้นยังอยู่ในโฟลเดอร์โปรไฟล์ของคุณ |

การแก้ไขโปรไฟล์อยู่ในบทที่ 74

## ตัวเลือก CommonMark

สวิตช์สำหรับไวยากรณ์ CommonMark เสริม เปิดเฉพาะสิ่งที่ต้นฉบับของคุณใช้

| ส่วน | ตัวควบคุม |
| --- | --- |
| **การรองรับไวยากรณ์** | **ไฮไลต์ (==key==)**, **ตัวห้อย (H~2~O)**, **ตัวยก (X^2^)**, **สูตรคณิตศาสตร์แบบอินไลน์ ($…$)** |
| **ไวยากรณ์เพิ่มเติม** | **ลิงก์อัตโนมัติ (URL เปล่า)**, **การแจ้งเตือนแบบ GitHub**, **YAML front matter** (บล็อกของบรรทัด `---` ที่ด้านบนสุดจะถูกหรี่และไม่รวมในตัวอย่างและทุกการส่งออก), **แผนภาพและแผนภูมิ (Mermaid, Vega-Lite)** |
| **เครื่องหมายวรรคตอนอัจฉริยะ** | **แปลง**: **แปลงเมื่อป้อน**, **แปลงเมื่อแสดงผล** หรือ **ปิด** จากนั้น **เครื่องหมายคำพูดอัจฉริยะ**, **ขีดกลางอัจฉริยะ**, **จุดไข่ปลาอัจฉริยะ** |
| **รั้วโค้ด** | **แสดงหมายเลขบรรทัด**, **ตัดบรรทัดยาวอัตโนมัติ** และ **ขนาดการเยื้อง** (เป็นช่องว่าง) |

รูปแบบ ▸ ไฮไลต์ ตัวห้อย ตัวยก และสูตรคณิตศาสตร์แบบอินไลน์ จะเป็นสีเทาจนกว่าจะเปิดตัวเลือกของมัน

## ธีม

หน้าธีมแสดง **ธีมแอปพลิเคชัน** (JSON: รูปลักษณ์สว่างหรือมืดของแอป สีเน้น แถบด้านข้าง แถบต่างๆ และตัวแก้ไข) และ **ธีมการแสดงผล** (CSS: ตัวอย่าง HTML, PDF, รูปภาพ ผลลัพธ์สำหรับพิมพ์ และสไตล์ของ Word) แต่ละรายการมีป้าย **ในตัว** หรือ **กำหนดเอง** พร้อม **สว่าง**, **มืด** หรือ **อัตโนมัติ**

| ตัวควบคุม | หน้าที่ |
| --- | --- |
| **ใหม่** | สร้างธีมได้ทั้งสองชนิด |
| **นำเข้าธีม…** | เพิ่มธีมแอปพลิเคชัน `.json` ธีมการแสดงผล `.css` หรือแพ็กเกจ `.zip` ที่มีชนิดใดชนิดหนึ่งหรือทั้งสอง |
| **เปิดโฟลเดอร์ธีม** | แสดงโฟลเดอร์ที่เก็บธีมของคุณ |
| **แก้ไข**, **ทำสำเนา**, **ส่งออก**, ลบ | ต่อธีม ธีมในตัวเป็นแบบอ่านอย่างเดียว |

การแก้ไขธีมอยู่ในบทที่ 75

## มาโคร

แสดงคอลเลกชันมาโคร คอลเลกชันในตัวเป็นแบบอ่านอย่างเดียว

| ตัวควบคุม | หน้าที่ |
| --- | --- |
| **คอลเลกชันใหม่**, **นำเข้ามาโคร…** | เริ่มคอลเลกชันหรือนำเข้าคอลเลกชัน `.json` |
| เมนูของคอลเลกชัน | **เปลี่ยนชื่อ…**, **ทำสำเนาคอลเลกชัน**, **ส่งออกคอลเลกชัน…**, **ลบคอลเลกชัน** |
| **ใหม่**, **แก้ไข**, **ทำสำเนา**, ลบ | ต่อมาโคร |

การแก้ไขมาโครอยู่ในบทที่ 76 คอลเลกชันที่นำเข้าซึ่งมีตัวกระตุ้นที่ไม่ปลอดภัยจะถูกปฏิเสธ

## คู่มือสไตล์

แสดงคู่มือสไตล์ พร้อมจำนวนกฎและพื้นที่ของแต่ละคู่มือ

| ตัวควบคุม | หน้าที่ |
| --- | --- |
| **นำเข้าคู่มือสไตล์…** | เพิ่มไฟล์ `.json` ของคู่มือ |
| เมนูของคู่มือ | **ทำสำเนาคู่มือสไตล์**, **ส่งออกคู่มือสไตล์…**, **ลบคู่มือสไตล์…** การลบจะนำคู่มือออกจากอุปกรณ์นี้ หลังจากที่คุณยืนยัน ดังนั้นให้ส่งออกก่อนหากต้องการสำเนา |
| "สร้างต่อจาก …" | คู่มือหนึ่งสร้างต่อจากอีกคู่มือหนึ่งได้ หากคู่มือนั้นหายไป จะใช้คู่มือนี้ไม่ได้ |

คู่มือสไตล์คือไฟล์ `.json` ของกฎที่มีชื่อ คุณยังขอให้ผู้ช่วยเขียนให้ได้ด้วย (**ผู้ช่วย ▸ วิธีใช้ ▸ คู่มือสไตล์**) และ **วิธีใช้ ▸ คู่มือสไตล์** อธิบายรูปแบบ

## ไลบรารีการแสดงผล

สูตรคณิตศาสตร์ แผนภาพ และแผนภูมิถูกวาดบนอุปกรณ์นี้โดยไลบรารีที่รวมมาให้ หน้านี้แสดงแต่ละไลบรารีและเวอร์ชัน เลือกหนึ่งรายการเพื่ออ่านประกาศที่รวมมาให้

## ตำแหน่ง

คลังของคุณอยู่ในโฟลเดอร์ชื่อ "Pilcrow Library" ภายในโฟลเดอร์ที่คุณเลือก โฟลเดอร์ใน iCloud Drive ช่วยซิงก์คลังระหว่างอุปกรณ์ของคุณ การตั้งค่าส่วนตัว คีย์ API และสำเนากู้คืนการขัดข้องจะอยู่บนอุปกรณ์นี้เสมอ

| ตัวควบคุม | หน้าที่ |
| --- | --- |
| **เก็บไว้** | ตำแหน่งปัจจุบันของคลัง: "บนอุปกรณ์นี้" หรือ "ในโฟลเดอร์ *ชื่อ*" |
| **เลือกโฟลเดอร์…** | ย้ายคลังไปยังโฟลเดอร์ หากโฟลเดอร์มีคลัง Pilcrow อยู่แล้ว Pilcrow จะไม่รวมสองคลังเข้าด้วยกัน: คุณเลือก **ใช้ที่มีอยู่** ได้ มิฉะนั้นเลือก **ย้ายคลังของฉันมาที่นี่** (ตรวจทุกไฟล์ แล้วลบสำเนาเก่า) หรือ **คัดลอกคลังของฉันมาที่นี่** (เก็บสำเนาเก่าไว้) |
| **ใช้อุปกรณ์นี้** | นำคลังกลับมายังอุปกรณ์นี้ |

หากเข้าถึงโฟลเดอร์ที่เลือกไม่ได้ Pilcrow จะใช้คลังบนอุปกรณ์นี้ไปก่อนโดยไม่เปลี่ยนแปลงหรือลบสิ่งใด และจะกลับมาใช้โฟลเดอร์อีกครั้งเมื่อพร้อม
