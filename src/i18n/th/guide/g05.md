# Part XVI — ข้อมูลอ้างอิงหน้าต่างและเมนู

# Chapter 52: ภาพรวมของหน้าต่าง

บทนี้บอกชื่อทุกตัวควบคุมในหน้าต่างของ Pilcrow เรียงจากซ้ายไปขวา ทั้งบน Mac และบน iPad บทถัดไปในส่วนนี้จะอธิบายแต่ละรายการเมนู และ Part XVII จะอธิบายแต่ละแผงและกล่องโต้ตอบ

## แถบส่วนหัว

ส่วนหัวพาดอยู่ด้านบนของหน้าต่าง ตัวควบคุมเรียงตามลำดับดังนี้

| ตัวควบคุม | อยู่ที่ | ทำอะไร |
| --- | --- | --- |
| **ตัวนำทาง** (ไอคอนแถบด้านข้าง) | Mac และ iPad | แสดงหรือซ่อนแถบด้านข้าง คำอธิบายเครื่องมือระบุว่า "Show or hide navigator" เหมือนกับ **มุมมอง ▸ เปิด/ปิดแถบด้านข้าง** |
| **ชื่อเอกสาร** | Mac และ iPad | แสดงชื่อเอกสารที่ใช้งานอยู่ พร้อมจุดที่บอกว่าบันทึกแล้วหรือยัง คลิกเพื่อเปิดตัวสลับเอกสารและการดำเนินการกับเอกสาร (Chapter 59) |
| **ปุ่มเมนู** หรือแถบเมนู | เฉพาะ iPad | เมนูของ Mac ที่อยู่ในส่วนหัว สำหรับ iPad ที่ไม่มีแป้นพิมพ์หรือเมาส์ (Chapter 58) |
| **โหมดเอกสาร** (แก้ไข ตัวอย่าง แยก) | Mac และ iPad | สลับระหว่างต้นฉบับ หน้าที่แสดงผล และทั้งสองแบบเคียงข้างกัน "แยก" คือ **เคียงข้างกัน** |
| **ค้นหา** (แว่นขยาย) | Mac และ iPad | เปิดแถบค้นหา (Chapter 62) |
| **ส่งออก** (ไอคอนแชร์) | Mac และ iPad | เปิดแผงส่งออก (Chapter 64) |
| **การตั้งค่า** (เฟือง) | เฉพาะ iPad | เปิดการตั้งค่าในชีต บน Mac การตั้งค่าอยู่ในเมนู **Pilcrow** (**⌘,**) |
| **เพิ่มเติม** (จุดสามจุด) | Mac และ iPad | รวมการดำเนินการที่ไม่พอดีกับแถบ ดูด้านล่าง |

ค้นหา ส่งออก และตัวควบคุมโหมดจะปรากฏเฉพาะเมื่อมีเอกสารเปิดอยู่

### ส่วนหัวปรับตามความกว้างอย่างไร

ส่วนหัวถูกสร้างให้ใช้งานได้ในหน้าต่างแคบ เช่น หน้าต่าง Mac ที่จัดเรียงเคียงกับแอปอื่น หรือ iPad ในโหมด Split View เมื่อหน้าต่างแคบลง ตัวควบคุมจะย้ายเข้าไปในเมนู **เพิ่มเติม** ตามลำดับนี้

| ความกว้างหน้าต่าง | สิ่งที่คุณเห็น |
| --- | --- |
| 720 พอยต์ขึ้นไป | ตัวควบคุมแก้ไข/ตัวอย่าง/แยก **ค้นหา** **ส่งออก** และ **เพิ่มเติม** |
| 600 ถึง 719 | **ค้นหา** ย้ายเข้าไปใน **เพิ่มเติม** |
| 500 ถึง 599 | **ส่งออก** ย้ายเข้าไปใน **เพิ่มเติม** ด้วย |
| ต่ำกว่า 500 | ตัวควบคุมโหมดกลายเป็นปุ่มเดียวที่ไอคอนแสดงโหมดปัจจุบัน (ดินสอ ตา หรือสองบานหน้าต่าง) คลิกเพื่อเลือก |

บน iPad ตัวควบคุมโหมดจะกลายเป็นปุ่มขนาดกะทัดรัดเมื่อต่ำกว่า 580 พอยต์ ชื่อเรื่องจะหดก่อนเสมอ ระหว่างความกว้าง 140 ถึง 520 พอยต์ เพื่อให้ปุ่มอยู่ที่เดิม เมื่อใช้ขนาดข้อความการช่วยการเข้าถึงที่ใหญ่ขึ้น ความกว้างหน้าต่างข้างต้นจะถูกหารด้วย 1.3 ก่อน ตัวควบคุมจึงย้ายเข้าไปใน **เพิ่มเติม** ทั้งที่หน้าต่างยังกว้างกว่า

### เมนูเพิ่มเติม

สิ่งที่ **เพิ่มเติม** มีให้ขึ้นอยู่กับโหมดและแพลตฟอร์ม รายการที่แสดงเฉพาะเมื่อมองเห็นต้นฉบับ (แก้ไข หรือ เคียงข้างกัน) มีเครื่องหมายไว้ด้านล่าง

| รายการ | ปรากฏเมื่อ | ทำอะไร |
| --- | --- | --- |
| **ค้นหา…** | เฉพาะเมื่อแถบไม่มีปุ่มค้นหา | เปิดแถบค้นหา |
| **แทนที่…** | มองเห็นต้นฉบับ | เปิดการค้นหาพร้อมช่องแทนที่ |
| **ไปที่บรรทัด…** | มองเห็นต้นฉบับ | ข้ามไปยังบรรทัด หรือบรรทัดและคอลัมน์ |
| **เคอร์เซอร์ในคอลัมน์…** | iPad มองเห็นต้นฉบับ | วางเคอร์เซอร์เรียงลงตามคอลัมน์ตามจำนวนที่ระบุ (Chapter 63) |
| **การเลือกคอลัมน์** | iPad มองเห็นต้นฉบับ | สวิตช์ เมื่อเปิดอยู่ การลากนิ้วเดียวจะเลือกข้อความเป็นสี่เหลี่ยม |
| **แชร์…** | มีเอกสารเปิดอยู่ | แชร์ไฟล์ของเอกสารผ่านชีตแชร์ของระบบ |
| **ส่งออก…** | เฉพาะเมื่อแถบไม่มีปุ่มส่งออก | เปิดแผงส่งออก |
| **โฟกัส** | เสมอ | สวิตช์สำหรับโหมดโฟกัส (ด้านล่าง) |
| **การพับหัวเรื่อง** **บล็อกที่แสดงผล** **ขยายส่วนอัตโนมัติ** **ซ่อนเครื่องหมาย** **ต้นฉบับที่มีสไตล์** **แถบเครื่องมือจัดรูปแบบ** | มองเห็นต้นฉบับ | สวิตช์การแสดงผลชุดเดียวกับในเมนูมุมมอง (Chapter 55) **ซ่อนเครื่องหมาย** เป็นสีเทาเว้นแต่ **ต้นฉบับที่มีสไตล์** จะเปิดอยู่ |
| **เปิดไฟล์…** **เปิดโฟลเดอร์…** | iPad | เปิดไฟล์หรือโฟลเดอร์เมื่อแถบด้านข้างปิดอยู่ |
| **พิมพ์…** | iPad | พิมพ์เอกสารที่แสดงผล |
| **การตั้งค่า…** **วิธีใช้** | iPad | เปิดการตั้งค่าหรือวิธีใช้ในแอป |

## พื้นที่ทำงาน

ใต้ส่วนหัวคือตัวแก้ไข ตัวอย่าง หรือทั้งสองอย่าง ใต้ตัวแก้ไข เมื่อเปิดใช้ จะมี **แถบเครื่องมือจัดรูปแบบ** และ **แถบสถานะ** (Chapter 61) **ภาพพื้นหลัง** หรือวิดีโออาจอยู่หลังตัวแก้ไขและแถบด้านข้าง (Chapter 69)

ใน **เคียงข้างกัน** ต้นฉบับอยู่ข้างตัวอย่างและเลื่อนไปพร้อมกัน ลากตัวแบ่งบานหน้าต่างได้ และตำแหน่งจะถูกจดจำไว้ เมื่อหน้าต่างแคบกว่า 520 พอยต์ ทั้งสองบานหน้าต่างจะซ้อนกันบนล่างแทน เมื่อการเปิดแถบด้านข้างจะเหลือพื้นที่ให้เอกสารน้อยกว่า 640 พอยต์ แถบด้านข้างจะคลุมเอกสารแทนที่จะบีบเอกสาร

## แถบด้านข้าง (ตัวนำทาง)

แถบด้านข้างแสดงได้ทั้ง **ไฟล์** **เค้าร่าง** **ค้นหา** **โปรเจกต์** และ **ผู้ช่วย** (Chapter 60) ลากขอบเพื่อปรับขนาด กว้าง 180 ถึง 420 พอยต์ ในหน้าต่างที่แคบกว่า 500 พอยต์ แถบจะเต็มความกว้าง และปุ่ม **เสร็จสิ้น** ปิดแถบนั้น

## โหมดโฟกัส

**โหมดโฟกัส** ซ่อนทุกอย่างยกเว้นข้อความ เปิดจาก **มุมมอง ▸ โหมดโฟกัส** จาก **เพิ่มเติม ▸ โฟกัส** หรือจากคำสั่งด่วน ขณะเปิดอยู่ ปุ่ม **ออกจากโฟกัส** จะปรากฏเพื่อให้ออกได้โดยไม่ต้องใช้แป้นพิมพ์ โหมดโฟกัสตัดบรรทัดยาวเสมอและมีคอลัมน์ข้อความของตัวเอง แยกจากที่อยู่ในการตั้งค่า โหมดนี้ไม่มีทางลัดเริ่มต้น ให้กำหนดเองใน **การตั้งค่า ▸ แป้นพิมพ์**

## เมื่อไม่มีเอกสาร

เมื่อไม่มีอะไรเปิดอยู่ หน้าต่างจะเสนอ **เอกสารใหม่** และ **เปิดไฟล์…** ใต้หัวเรื่อง "Start a document" บน iPad **เปิดโฟลเดอร์…** อยู่ใน **เพิ่มเติม**

เมื่อ Pilcrow เริ่มทำงานและพบงานที่ยังไม่ได้บันทึกจากเซสชันก่อนหน้า จะแสดงรายการ **กู้คืนเอกสาร** แทน ดู Chapter 17 สำหรับวิธีการกู้คืน รายการนี้มี **กู้คืน** และ **ลบ** สำหรับแต่ละรายการ และ **กู้คืนทั้งหมด** กับ **ลบทั้งหมด** สำหรับทั้งรายการ เอกสารที่ไม่เคยบันทึกจะนำกลับมาไม่ได้เมื่อลบไปแล้ว ดังนั้น **ลบทั้งหมด** จะถามก่อน ปุ่ม **ปิดทิ้ง** บนแบนเนอร์เอกสารเดี่ยวคือการปฏิเสธการกู้คืนรายการนั้น

ขณะเปิดไฟล์ขนาดใหญ่ หน้าต่างจะแสดง "Opening *name*…" พร้อมตัวบอกความคืบหน้า

# Chapter 53: เมนูไฟล์

บน Mac รายการเหล่านี้อยู่ในเมนู **ไฟล์** บน iPad อยู่ใน **เมนู ▸ ไฟล์** ในส่วนหัว หรือในแถบเมนูที่ปรากฏเมื่อคุณกด **⌘** ค้างไว้หรือเลื่อนตัวชี้ไปที่ด้านบนของหน้าจอ รายการที่มีเครื่องหมาย "Mac only" ไม่มีบน iPad

| รายการ | ทางลัด | ทำอะไร |
| --- | --- | --- |
| **ใหม่** (iPad: **เอกสารใหม่**) | `⌘N` | สร้างเอกสารที่ยังไม่มีชื่อ เอกสารจะรวมอยู่ในเอกสารที่เปิดอยู่ |
| **เปิด…** (iPad: **เปิดไฟล์…**) | `⌘O` | เปิดไฟล์ข้อความหรือมาร์กอัปจากดิสก์ |
| **เปิดล่าสุด** (Mac only) | | แสดงรายการไฟล์ที่เปิดล่าสุด **ล้างเมนู** ล้างรายการ แสดง "No Recent Documents" เมื่อรายการว่าง |
| **เปิดด่วน…** (Mac only) | `⇧⌘O` | ค้นหาชื่อไฟล์ในโฟลเดอร์ที่เปิดอยู่ เป็นสีเทาเมื่อไม่มีโฟลเดอร์เปิดอยู่ |
| **เปิดโฟลเดอร์…** (เมนูส่วนหัวของ iPad และเพิ่มเติม) | | เปิดโฟลเดอร์ในแถบด้านข้าง บน Mac ให้ใช้ปุ่ม **เปิดโฟลเดอร์** ของแถบด้านข้างเอง |
| **เรียกดูโฟลเดอร์ที่บรรจุ…** | | ขอสิทธิ์เรียกดูโฟลเดอร์ที่บรรจุไฟล์ที่เปิดอยู่ แซนด์บ็อกซ์ของ Pilcrow เปิดไฟล์เดี่ยวๆ เท่านั้น รายการนี้เพิ่มโฟลเดอร์ของไฟล์เข้ามา เป็นสีเทาเมื่อโฟลเดอร์นั้นเปิดอยู่แล้วหรือเอกสารไม่มีไฟล์ |
| **หนังสือใหม่…** | | สร้างโฟลเดอร์โปรเจกต์หนังสือพร้อมไฟล์ manifest (Chapter 34) |
| **ทำให้โฟลเดอร์เป็นโปรเจกต์หนังสือ** | | เขียน `manifest.pilcrow` ลงในโฟลเดอร์ที่เปิดอยู่และแสดงแผงโปรเจกต์ (Chapter 34) เป็นสีเทาเมื่อไม่มีโฟลเดอร์เปิดอยู่หรือโฟลเดอร์มี manifest อยู่แล้ว |
| **ปิดเอกสาร** (iPad: **ปิด**) | `⌘W` | ปิดเอกสารที่ใช้งานอยู่ โดยถามก่อนหากมีการเปลี่ยนแปลงที่ยังไม่ได้บันทึก เมื่อการตั้งค่าอยู่ด้านหน้า `⌘W` จะปิดการตั้งค่าแทน |
| **ปิดทั้งหมด** (iPad) | `⇧⌘W` | ปิดทุกเอกสาร โดยถามทีละเอกสารที่ยังไม่ได้บันทึก บน Mac เมนูชื่อเรื่องมี **ปิดเอกสารทั้งหมด** |
| **บันทึก** | `⌘S` | บันทึกเอกสาร เอกสารใหม่จะถามว่าจะบันทึกที่ไหน |
| **บันทึกทั้งหมด** (Mac only) | `⌥⌘S` | บันทึกทุกเอกสารที่มีการเปลี่ยนแปลงที่ยังไม่ได้บันทึก เป็นสีเทาเมื่อไม่มี |
| **ทำสำเนา** (Mac only) | `⇧⌘S` | สร้างสำเนาและเปิดไว้ข้างต้นฉบับ ซึ่งยังคงไม่เปลี่ยนแปลง |
