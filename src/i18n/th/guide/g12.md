# Part XIX — ตัวแก้ไขสำหรับรายการในคลัง

# Chapter 74: ตัวแก้ไขโปรไฟล์และส่วนประกอบของโปรไฟล์

โปรไฟล์ไวยากรณ์บอก Pilcrow ว่ามาร์กอัปของคุณมีความหมายอย่างไร บทนี้อธิบายตัวแก้ไขโปรไฟล์ทีละตัวควบคุม แล้วแสดงรายการส่วนประกอบทุกอย่างที่โปรไฟล์ใช้ได้ หากต้องการเริ่มต้นแบบเน้นงานที่ทำ ดูบทที่ 37 ถึงบทที่ 39

เปิดตัวแก้ไขจาก **การตั้งค่า ▸ คลัง ▸ โปรไฟล์ไวยากรณ์** โดย **ใหม่** เริ่มโปรไฟล์ใหม่ **แก้ไข** เปลี่ยนโปรไฟล์ที่กำหนดเอง และ **ทำสำเนา** คัดลอกโปรไฟล์ที่มาพร้อมแอปเพื่อให้คุณแก้ไขสำเนาได้ ชื่อของตัวแก้ไขคือ **แก้ไขโปรไฟล์** พร้อม **ยกเลิก**, **บันทึก** และ **วิธีใช้โปรไฟล์** (ซึ่งเปิดข้อมูลอ้างอิงในแอปสำหรับส่วนประกอบเหล่านี้) บนหน้าจอแคบ สวิตช์ **ส่วนของโปรไฟล์** ใช้เลือกระหว่าง **ภาพรวม**, **กฎ** และ **ตัวอย่างทดสอบ** ส่วนบนหน้าจอกว้างจะแสดงทั้งสามพร้อมกัน

## ภาพรวม

| ฟิลด์ | หน้าที่ |
| --- | --- |
| **ชื่อ** | ชื่อของโปรไฟล์ แสดงในเมนูแถบสถานะและในการตั้งค่า |
| **คำอธิบาย** | บันทึกเกี่ยวกับโปรไฟล์ |
| **นามสกุลไฟล์ (คั่นด้วยจุลภาค)** | นามสกุลที่ทำให้ไฟล์เลือกใช้โปรไฟล์นี้ โปรไฟล์สองโปรไฟล์ใช้นามสกุลเดียวกันไม่ได้ |
| **สืบทอดจาก** | **ไม่มี** หรือโปรไฟล์อื่นที่โปรไฟล์นี้ต่อยอดจากกฎของโปรไฟล์นั้น |
| **ไวยากรณ์** | **ขยาย Markdown** หรือ **แทนที่ Markdown** (ดูด้านล่าง) |
| **ภาพรวม** | จำนวนของ **กฎของบล็อก**, **กฎแบบอินไลน์** และ **กฎการซ้อน** |
| **แก้ไข JSON ขั้นสูง…** | เปิดโปรไฟล์เป็น JSON สำหรับฟิลด์ที่ตัวแก้ไขแบบนำทางไม่แสดง **นำไปใช้** จะเก็บการเปลี่ยนแปลง JSON ของคุณ **ยกเลิก** จะทิ้งการเปลี่ยนแปลง |

**ขยาย Markdown** เพิ่มกฎของคุณเข้ากับกฎของ Markdown โดยหัวเรื่อง รายการ ตัวเน้น และอื่นๆ ของ Markdown ยังคงถูกอ่านตามเดิม และกฎของบล็อกและกฎแบบอินไลน์ของคุณจะเพิ่มเข้าไป กฎที่เป็นสำเนาไม่มีการแก้ไขของกฎใดกฎหนึ่งในโปรไฟล์ CommonMark อธิบายสิ่งที่ Markdown ทำอยู่แล้ว จึงปล่อยให้ Markdown จัดการ **แทนที่ Markdown** ทำให้กฎของคุณเป็นไวยากรณ์ทั้งหมด ดังนั้นโครงสร้างของ Markdown จะไม่ถูกรู้จักอีกต่อไป เมื่อใช้ตัวเลือกนี้ ต้องมีกฎหนึ่งข้อที่สร้าง **ท้ายบรรทัด** มิฉะนั้นจะไม่มีสิ่งใดแบ่งเป็นย่อหน้า ตัวแก้ไขจะเตือนว่า "Add a rule whose output node is "newline", or nothing will separate into paragraphs" และบันทึกโปรไฟล์ไม่ได้จนกว่าจะมีกฎดังกล่าว นอกจากนี้ยังแสดงรายการประเภทเอาต์พุตที่โปรไฟล์ไม่ได้กำหนดไว้

## กฎ

กฎมีสามกลุ่ม

### กฎของบล็อก

กฎของบล็อกรู้จักทั้งบรรทัดและบล็อก **เพิ่มกฎ** ใช้เพิ่มกฎ แต่ละกฎมี **รูปแบบ** ประเภท **ตรงกัน** สิ่งที่ **สร้าง** และ **ตัวเลือก** ลบกฎได้ด้วยปุ่ม **ลบ** ของกฎนั้น เมื่อไม่มีกฎเลย ตัวแก้ไขจะแสดงว่า "No rules yet. Add one to recognize a block construct."

### กฎแบบอินไลน์

กฎแบบอินไลน์รู้จักข้อความภายในบรรทัด **เพิ่มกฎแบบอินไลน์** ใช้เพิ่มกฎ กฎแบบอินไลน์มีประเภทการจับคู่สี่แบบ (**คำนำหน้าตามตัวอักษร**, **ตรงตามตัวอักษร**, **Regex (มีขอบเขต)** และ **คู่ตัวคั่น**) ส่วนกฎของบล็อกมีให้เลือกทั้งเจ็ดแบบ

### กฎการซ้อน

กฎการซ้อนบอกว่าเอาต์พุตใดวางอยู่ภายในเอาต์พุตใดได้ แต่ละกฎมี **โหนดแม่** และ **องค์ประกอบย่อยที่อนุญาต (คั่นด้วยจุลภาค)** ค่าว่างหมายถึงไม่จำกัด: "No restrictions. Every node type may nest inside any other." **เพิ่มกฎการซ้อน** ใช้เพิ่มกฎ

| --- | --- | --- | --- |
| **คำนำหน้าตามตัวอักษร** | ข้อความที่โครงสร้างขึ้นต้นด้วย | ใช่ | ใช่ |
| **ตรงตามตัวอักษร** | ข้อความทั้งหมดของโครงสร้าง | ใช่ | ใช่ |
| **คำนำหน้าต้นบรรทัด** | ข้อความที่ต้นบรรทัด เช่น `# ` | ใช่ | |
| **บล็อกที่เยื้อง** | บรรทัดที่ขึ้นต้นด้วยรูปแบบ เช่น ช่องว่างสี่ช่องหรือแท็บ บรรทัดที่ต่อเนื่องกัน รวมทั้งบรรทัดว่างระหว่างกัน เป็นบล็อกเดียว และแสดงโดยไม่มีการเยื้อง | ใช่ | |
| **บล็อกที่มีรั้ว** | บรรทัดที่เปิดบล็อก และปิดด้วยบรรทัดที่ตรงกัน | ใช่ | |
| **Regex (มีขอบเขต)** | นิพจน์ปรกติ Pilcrow จะเตือนก่อนบันทึกนิพจน์ที่อาจค้าง: "This regex could hang the editor — simplify it." | ใช่ | ใช่ |
| **คู่ตัวคั่น** | เครื่องหมายเดียวกันทั้งสองด้านของข้อความในบรรทัดเดียว เช่น `%%` ใน `%%this%%` ไม่มีช่องว่างอยู่ด้านในติดกับเครื่องหมาย | ใช่ | ใช่ |

ในนิพจน์ปรกติ `(?<name>…)` ตั้งชื่อส่วนหนึ่งของสิ่งที่ตรงกัน ดู ส่วนที่ตั้งชื่อ ด้านล่าง

## ตัวเลือกของกฎ

กลุ่ม **ตัวเลือก** ของแต่ละกฎมี

| ตัวเลือก | หน้าที่ |
| --- | --- |
| **ลำดับความสำคัญ** | กฎที่มีลำดับความสำคัญสูงกว่าจะถูกลองก่อน |
| **เฉพาะที่ต้นบรรทัด** | ไม่ให้กฎจับคู่กลางบรรทัด |
| **ส่วนที่ตั้งชื่อจะกลายเป็นแอตทริบิวต์** | แต่ละส่วนที่ตั้งชื่อของนิพจน์ปรกติจะกลายเป็นแอตทริบิวต์ของเอาต์พุต ตัวแก้ไขแสดง "Parts in this pattern" และ "Parts this output reads" สำหรับเอาต์พุตที่มีข้อความ เช่น ตัวหนาหรือลิงก์ ข้อความที่แสดงคือส่วนที่ชื่อ `text` หากมี มิฉะนั้นคือส่วนสุดท้ายที่ตรงกัน |
| **สร้าง** | สิ่งที่กฎสร้าง: เอาต์พุตจากรายการด้านล่าง หรือชื่อ **กำหนดเอง** |
| **ชื่อโหนดที่กำหนดเอง** | ชื่อสำหรับเอาต์พุตแบบ **กำหนดเอง** |
| **แอตทริบิวต์คงที่** | ส่วนที่มีค่าเหมือนเดิมทุกครั้ง เพิ่มด้วย **เพิ่มแอตทริบิวต์** (**ชื่อ** และ **ค่า**) ค่าอาจมีส่วนที่ตั้งชื่อ เขียนเป็น `{name}` เช่น กฎอีเมลที่รูปแบบตั้งชื่อ `address` ไว้ สามารถให้ลิงก์ของตนมี `url` เป็น `mailto:{address}` |
| **แทรกข้อความ** | สิ่งที่เมนู **แทรก** เขียนให้กฎนี้ ตรงตามที่ควรปรากฏ โดยใช้ `$0` ตรงตำแหน่งที่เคอร์เซอร์ควรอยู่ กฎที่จับคู่ด้วยนิพจน์ปรกติ บล็อก หรือการเยื้อง ต้องมีตัวเลือกนี้ ไม่เช่นนั้นเมนูแทรกจะไม่แสดงกฎนั้น |
| **เฉพาะหลังบรรทัดว่าง** | สำหรับบล็อกที่เยื้อง: บรรทัดที่เยื้องซึ่งอยู่ถัดจากข้อความทันทีจะยังเป็นส่วนหนึ่งของข้อความนั้น เช่น บรรทัดถัดไปของรายการ |
| **หลังกด Return ที่ท้ายบรรทัด** | สำหรับรายการและข้อความอ้างอิง: **อัตโนมัติ** (ทำซ้ำสัญลักษณ์แสดงหัวข้อย่อยและเครื่องหมายอ้างอิง นับขึ้นสำหรับรายการลำดับเลข และเริ่มรายการงานแบบไม่ได้ทำเครื่องหมาย), **ทำซ้ำเครื่องหมาย**, **นับขึ้น**, **เริ่มใหม่จากเครื่องหมาย** หรือ **ไม่เพิ่มอะไร** |

### บล็อกที่มีรั้วและบล็อกที่มีตัวคั่น

สำหรับกฎ **บล็อกที่มีรั้ว** **บล็อกประกอบด้วย** บอกว่าข้างในมีอะไร

| ตัวเลือก | ความหมาย |
| --- | --- |
| **ยังไม่มีอะไร** | ยังไม่ได้ตั้งค่า |
| **ข้อความ แสดงตามที่เขียน** | โค้ดหรือข้อความที่จัดรูปแบบไว้ล่วงหน้า |
| **ไม่มี — ซ่อนอยู่** | ความคิดเห็น ซึ่งถูกละไว้จากเอกสาร |
| **บล็อกอื่นๆ ในกล่อง** | ข้อความอ้างอิง แถบด้านข้าง หรือกล่องข้อความเตือนที่มีย่อหน้า รายการ และอื่นๆ |
| **บล็อกอื่นๆ ไม่มีกล่อง** | บล็อกรวมเข้ากับข้อความรอบข้าง บรรทัดเหล่านี้เพียงจัดกลุ่มบล็อกไว้ |
| **ตาราง** | ดู ตาราง ด้านล่าง |
| **ตารางที่วาดด้วยข้อความ** | ตารางเส้นหรือคอลัมน์ที่จัดแนวด้วยข้อความ ซึ่งต่อเนื่องจากบรรทัดเปิดไปจนถึงบรรทัดว่างถัดไป เช่นของ reStructuredText |
| **ข้อความที่เยื้องใต้บรรทัดที่ลงท้ายด้วยเครื่องหมาย** | บรรทัดเปิดเป็นร้อยแก้วที่ลงท้ายด้วยเครื่องหมาย เหมือน `::` ของ reStructuredText ร้อยแก้วนั้นยังเป็นย่อหน้า ส่วนข้อความที่เยื้องอยู่ใต้มันหลังบรรทัดว่างจะแสดงตามที่เขียน |
| **ข้อความที่เยื้องใต้บรรทัดเปิด** | ไดเรกทีฟ เช่น `.. code-block::` ซึ่งรวบรวมบรรทัดที่เยื้องใต้มัน และไม่มีบรรทัดปิด |

**บรรทัดปิด** คือบรรทัดที่จบบล็อก ค่าว่างหมายถึงเหมือนบรรทัดเปิด ("Same as the opening line") ตัวคั่นที่ไม่ใช่นิพจน์ปรกติ เช่น `+++` จะถูกจับคู่เป็นข้อความธรรมดา **บรรทัดปิดซ้ำเครื่องหมายเปิด อย่างน้อยเท่าจำนวนเดิม** ใช้กับรั้วแบบ Markdown: บรรทัดปิดคืออักขระตัวแรกของบรรทัดเปิดที่ซ้ำอย่างน้อยเท่าจำนวนเดิม ดังนั้นรั้วที่ยาวกว่าจึงครอบรั้วที่สั้นกว่าเป็นข้อความ ภาษาของบล็อกข้อความ เมื่อบรรทัดเปิดระบุภาษาที่รู้จัก จะถูกระบายสีในตัวแก้ไข

### ตาราง

ตัวเลือกของบล็อกตาราง

| ตัวเลือก | หน้าที่ |
| --- | --- |
| **เลย์เอาต์** | **ตารางที่มีเส้นตาราง** (เซลล์อยู่ระหว่าง `|` โดยมีเส้นกำกับคั่นระหว่างแถว) หรือ **คอลัมน์ที่จัดแนว** (คอลัมน์เรียงแนวใต้เส้นกำกับบรรทัดแรก) |
| **ตัวคั่นเซลล์** | ข้อความที่เริ่มแต่ละเซลล์ |
| **รูปแบบเส้นกำกับ**, **รูปแบบเส้นกำกับส่วนหัว** | บรรทัดที่วาดเพียงเส้นกำกับ และบรรทัดที่จบส่วนหัว |
| **แถวลงท้ายด้วย** | เครื่องหมายที่จบแต่ละแถว เหมือนที่ `tabular` ของ LaTeX ทำ |
| **รูปแบบเซลล์ที่ครอบคลุมหลายช่อง** | เซลล์ที่ครอบคลุมหลายคอลัมน์ |
| **รูปแบบตัวเลือกเซลล์** | นิพจน์ปรกติสำหรับสิ่งที่อาจอยู่ก่อนตัวคั่นของเซลล์ทันที ส่วนที่ชื่อ `colspan` ทำให้เซลล์ครอบคลุมคอลัมน์ตามจำนวนนั้น |
| **ตัวคั่นรายการคอลัมน์**, **ทำซ้ำเครื่องหมาย** | วิธีเขียนรายการ `columns`: ด้วย `,` และ `*` โดย `3*` นับเป็นสามคอลัมน์ |
| **บรรทัดแรกก่อนบรรทัดว่างคือส่วนหัว** | แถวส่วนหัวถูกกำหนดโดยนัยจากเลย์เอาต์ |
| **รูปแบบ** | วิธีเขียนเซลล์แบบอื่น แต่ละแบบมีชื่อและตัวคั่น (เช่น `csv` และ `,`) เพิ่มด้วย **เพิ่มรูปแบบ** และเลือกด้วยส่วน `format` ของตาราง |

| การตั้งค่า | หน้าที่ |

| **ซ้อนรายการตามเครื่องหมาย** | เครื่องหมายใหม่แต่ละตัว เช่น `**` หลัง `*` เริ่มระดับที่ลึกขึ้น ไม่ว่าจะเยื้องอย่างไร |
| **บรรทัดต่อของรายการ** | บรรทัดที่อยู่ลำพังหลังรายการ ซึ่งผูกบล็อกถัดไปเข้ากับรายการนั้น |
| **คงการขึ้นบรรทัดใหม่เดี่ยว** | การขึ้นบรรทัดใหม่ภายในย่อหน้ายังคงเป็นการขึ้นบรรทัดใหม่ |
| **กำหนด id ให้หัวเรื่อง** | หัวเรื่องที่ไม่มี id ของตัวเองจะได้ id จากชื่อ: ตัวพิมพ์เล็ก คำเชื่อมด้วย **ตัวคั่นคำ** ต่อจาก **คำนำหน้า** (**คำนำหน้า id ของหัวเรื่อง**, **ตัวคั่นคำใน id ของหัวเรื่อง**) เมื่อใช้ `_` และ `_` "Getting Started" จะเป็น `_getting_started` ดังนั้นการอ้างอิงโยงไปยังหัวเรื่องนั้นจะแสดงชื่อเรื่อง ชื่อที่ซ้ำจะเพิ่มตัวคั่นและตัวเลข |
| **ใส่หมายเลขหัวเรื่อง** | เมื่อเอกสารกำหนดแอตทริบิวต์ที่ระบุใน **เมื่อเอกสารกำหนด** เช่น `:sectnums:` ของ AsciiDoc หัวเรื่องตั้งแต่ **จากระดับหัวเรื่อง** ลงไปจะมีหมายเลข: `1.`, `1.1.`, `2.` หัวเรื่องก่อนการกำหนดจะไม่มีหมายเลข |
| **คำบรรยายที่มีหมายเลข** | บล็อกที่มีชื่อเรื่องและเป็นเอาต์พุตที่อยู่ในรายการนี้ เช่น `image`, `table` หรือ `example` จะได้ **ป้ายกำกับ** และหมายเลขของตัวเองก่อนชื่อเรื่อง (เช่น "Figure 1.") ที่ **ตำแหน่งคำบรรยาย** คือ **ด้านบน** หรือ **ด้านล่าง** ของบล็อก เพิ่มด้วย **เพิ่มคำบรรยาย** |

## เครื่องหมายแบบอินไลน์ที่จับคู่ตามสิ่งที่อยู่รอบๆ

ภาษาอย่าง Markdown เขียนตัวหนาและตัวเอียงด้วยชุดอักขระที่เปิดหรือปิดตามอักขระที่อยู่ข้างๆ และเขียนโค้ดแบบแทรกในบรรทัดหรือลิงก์ด้วยวงเล็บ ดังนั้นรูปแบบเดียวสำหรับทั้งโครงสร้างจึงหาสิ่งเหล่านี้ไม่พบ เปิด **อ่านเครื่องหมายตามสิ่งที่อยู่รอบๆ** เพื่ออธิบายสิ่งเหล่านี้

| การตั้งค่า | หน้าที่ |
| --- | --- |
| **อักขระหลีก** | อักขระที่ทำให้ตัวถัดไปเป็นอักขระธรรมดา |
| **อักขระโค้ดแบบแทรกในบรรทัด** | ชุดของอักขระนี้เปิดช่วงที่ปิดด้วยชุดถัดไปที่มีความยาวเท่ากัน |
| **เครื่องหมายแบบชุด** | เครื่องหมายที่จับคู่เป็นชุด เพิ่มด้วย **เพิ่มเครื่องหมายแบบชุด** แต่ละอันมี **เครื่องหมาย** สิ่งที่ **เครื่องหมายหนึ่งตัววาด** และสิ่งที่ **เครื่องหมายสองตัววาด** และ **อาจเปิดหรือปิดภายในคำ** (ปิดสำหรับ `_`) |
| **เครื่องหมายแบบคู่** | เครื่องหมายที่จับคู่กับชุดที่มีความยาวเท่ากัน เพิ่มด้วย **เพิ่มเครื่องหมายแบบคู่**: **เครื่องหมาย** สิ่งที่มัน **วาด** และ **เฉพาะเมื่อเปิดการตั้งค่านี้** ซึ่งเป็นการตั้งค่าไวยากรณ์ เช่น ไฮไลต์ ที่ต้องเปิดอยู่ (หรือ **เสมอ**) |
| **ลิงก์และที่อยู่เว็บ** | **คำนำหน้ารูปภาพ**, **ที่อยู่ที่เขียนเดี่ยวๆ ถูกล้อมด้วย**, **รูปแบบที่ขึ้นต้นที่อยู่เปล่า**, **บรรทัดที่กำหนดป้ายกำกับมี** และ **ป้ายเชิงอรรถขึ้นต้นด้วย** (อักขระหลังวงเล็บเปิดของป้ายที่ทำให้เป็นเชิงอรรถ: `[^note]` จะถูกวาดเป็นการอ้างอิงเชิงอรรถเมื่อมีบรรทัดขึ้นต้นด้วย `[^note]:`) |

เครื่องหมายจับคู่กันภายในบรรทัด โค้ด อักขระที่ถูกหลีก และที่อยู่ของลิงก์ เป็นข้อความธรรมดาสำหรับเครื่องหมายที่อยู่รอบๆ

## ต้นฉบับที่มีสไตล์

เมื่อเปิด **ต้นฉบับที่มีสไตล์** ตัวแก้ไขจะวาดเอกสารในรูปลักษณ์ของไวยากรณ์ของมัน: หัวเรื่องที่ใหญ่ขึ้น ช่วงตัวหนาและตัวเอียง แถบข้อความอ้างอิง การเยื้องรายการ กล่องงาน เส้นคั่น ลิงก์ และการ์ดโค้ด และซ่อนเครื่องหมายที่สร้างสิ่งเหล่านั้น (เมื่อเปิด **ซ่อนเครื่องหมาย**) ยกเว้นบนบรรทัดที่เคอร์เซอร์อยู่ ตัวแก้ไขไม่รู้จักไวยากรณ์ใดโดยเฉพาะ: กฎบอกว่าสิ่งที่จับคู่ได้คืออะไรโดยมีรายการสไตล์ติดไปด้วย และกฎที่ไม่มีจะถูกระบายสีแต่ไม่ถูกปรับสไตล์ใหม่

**ตัวเลือก** ของทุกกฎมีกลุ่ม **ต้นฉบับที่มีสไตล์**

| ฟิลด์ | หน้าที่ |
| --- | --- |
| **บทบาท** | สิ่งที่การจับคู่เป็น หรือ **ไม่มีสไตล์** สำหรับโครงสร้างหนึ่งภายในบรรทัด: heading, strong, emphasis, code, strike, highlight, underline, link, subscript, superscript สำหรับทั้งบรรทัด: rule (เส้นคั่นเชิงเนื้อหา), list (เครื่องหมายของรายการ รวมทั้งการเยื้องและช่องว่างหลังเครื่องหมาย), task (เครื่องหมายตามด้วยช่องทำเครื่องหมาย) และ quote (เครื่องหมาย `>` ของบรรทัดอ้างอิง) สำหรับบล็อกที่รู้จักทั้งก้อน: codeBlock สำหรับบล็อกที่บรรทัดเปิดและบรรทัดปิดเป็นการจับคู่แยกกัน: quoteRegion สำหรับตาราง สมการ หรือแผนภาพที่วาดเป็นรูปภาพ: renderedBlock |
| **กลุ่มเนื้อหา** | กลุ่มการจับ นับจาก 1 ที่เก็บสิ่งที่โครงสร้างนั้นพูดถึง: คำใน `*bold*` ชื่อเรื่องใน `\section{Title}` ส่วนที่เหลือของการจับคู่คือเครื่องหมายของโครงสร้างนั้นเอง ซึ่ง ซ่อนเครื่องหมาย จะซ่อน `0` หมายถึงการจับคู่ทั้งหมดเป็นเนื้อหาและไม่มีสิ่งใดถูกซ่อน เช่นที่อยู่เว็บ ละไว้เมื่อการจับคู่เป็นเพียงเครื่องหมาย เช่น `== ` ของหัวเรื่อง |
| **ระดับหัวเรื่อง**, **กลุ่มระดับ** | ระดับของหัวเรื่อง 1 ถึง 6 หากละไว้ จะเป็นตัวเลขท้ายชื่อเอาต์พุตของกฎ (`heading2`) หรือความยาวของกลุ่มการจับที่เก็บชุดของ `#` |
| **กลุ่มเครื่องหมาย** | สำหรับรายการหรืองาน กลุ่มการจับที่เป็นเครื่องหมายพร้อมการเยื้องและช่องว่างหลังมัน เมื่อการจับคู่ขึ้นต้นด้วยสิ่งอื่น เช่น `> ` ของรายการที่อ้างอิง |
| **สไตล์จนถึงท้ายบรรทัด** | ใช้สไตล์จากตำแหน่งที่จับคู่ไปจนถึงท้ายบรรทัด สำหรับกฎที่จับคู่เฉพาะเครื่องหมายของหัวเรื่องและปล่อยชื่อเรื่องเป็นข้อความที่ตามมา |
| **วาดเป็น** | สำหรับบล็อกที่ถูกวาด ว่ามันคืออะไร: ตาราง สูตรคณิตศาสตร์ หรือแผนภาพ หรือ **ไม่ใช่รูปภาพ** |
| **กลุ่มที่อยู่** | สำหรับลิงก์ กลุ่มการจับที่ลองตามลำดับ ซึ่งเก็บที่อยู่ที่ลิงก์เปิดเมื่อคลิกหรือแตะ; `0` คือการจับคู่ทั้งหมด เปิดได้เฉพาะที่อยู่เว็บ อีเมล และโทรศัพท์ |

หมายเลขกลุ่มนับวงเล็บของรูปแบบจาก 1; 0 คือการจับคู่ทั้งหมด โปรไฟล์ที่ไม่แทนที่ Markdown ยังคงใช้การอ่านของ Markdown เองกับชนิดที่กฎของมันไม่ได้ประกาศไว้ เช่น แถบข้อความอ้างอิงและคู่ของ `**`

## แอตทริบิวต์ของเอกสารและส่วนแบบมีเงื่อนไข

กฎ **แอตทริบิวต์ของเอกสาร** กำหนดค่าด้วย `name` และกฎ **ข้อมูลอ้างอิงแอตทริบิวต์** (กฎแบบอินไลน์ที่มีส่วน `name` และ `original`) แทนที่การอ้างอิงด้วยค่านั้น การอ้างอิงถึงแอตทริบิวต์ที่ยังไม่มีใครกำหนดจะคงไว้ตามที่เขียน **ส่วนแบบมีเงื่อนไข** เก็บไว้หรือทิ้งบล็อกระหว่างบรรทัดของมัน ขึ้นอยู่กับว่าแอตทริบิวต์ที่มันระบุถูกตั้งไว้หรือไม่ แอตทริบิวต์มีผลตั้งแต่ตำแหน่งที่กำหนดเป็นต้นไป

กฎที่สร้าง **การตั้งค่าสำหรับบล็อกถัดไป** รู้จักทั้งบรรทัดที่กำหนดค่าบล็อกที่ตามมา และไม่แสดงสิ่งใดด้วยตัวเอง ส่วนและแอตทริบิวต์คงที่ของมันจะถูกมอบให้บล็อกนั้น: `title`, `id`, `nodeType`, `language` และ `hardbreaks` มีความหมายตามที่ระบุไว้ใต้ ส่วนต่างๆ และส่วนอื่นๆ จะถูกเก็บไว้ที่บล็อก ซึ่งตาราง รายการ หรือข้อความอ้างอิงจะอ่านค่า

## การทดสอบโปรไฟล์

ที่ด้านล่างของตัวแก้ไข **ตัวอย่างทดสอบ** เก็บข้อความตัวอย่าง (เริ่มต้นเป็นหัวเรื่องและหนึ่งบรรทัดข้อความ) เลือก **ตัวอย่างการตรวจสอบ** เพื่อดูโหนดที่กฎของคุณสร้าง เยื้องตามการซ้อน หากไม่มีสิ่งใดตรงกัน จะแสดงว่า "No blocks recognized."

## ค่าพื้นฐาน

**ค่าพื้นฐาน** ของโปรไฟล์คือจุดกู้คืน: สภาพของโปรไฟล์ตอนที่คุณสร้าง ทำสำเนา หรือนำเข้า **รีเซ็ตเป็นค่าพื้นฐาน** ทิ้งทุกการเปลี่ยนแปลงตั้งแต่นั้น หลังจากที่คุณยืนยัน **ตั้งเป็นค่าพื้นฐานใหม่** บันทึกโปรไฟล์และทำให้สถานะปัจจุบันเป็นจุดกู้คืน

การบันทึกจะถูกปฏิเสธพร้อมข้อความ หากโปรไฟล์แทนที่ Markdown แต่ไม่มีกฎท้ายบรรทัด หากรูปแบบไม่ปลอดภัยและอาจทำให้ตัวแก้ไขค้าง หรือหากเขียนไฟล์ไม่ได้

## ส่วนต่างๆ

ส่วนต่างๆ คือชิ้นส่วนที่ตั้งชื่อของการจับคู่ซึ่งเอาต์พุตอ่านค่า

| ส่วน | ความหมาย |
| --- | --- |
| `allOf` | ตัวคั่นระหว่างชื่อเมื่อต้องการครบทุกชื่อ เช่น `+` |
| `alt` | คำอธิบายรูปภาพ สำหรับผู้อ่านที่มองไม่เห็นรูป |
| `anyOf` | ตัวคั่นระหว่างชื่อเมื่อชื่อใดชื่อหนึ่งก็พอ เช่น `,` |
| `attribution` | ผู้กล่าวข้อความอ้างอิง แสดงใต้ข้อความนั้น |
| `citetitle` | ผลงานที่ข้อความอ้างอิงมาจาก แสดงหลังผู้กล่าว |
| `columns` | รายการคอลัมน์ของตาราง เช่น `1,2,1` จำนวนรายการคือจำนวนคอลัมน์ |
| `condition` | ชื่อแอตทริบิวต์ที่ส่วนนั้นขึ้นอยู่กับ |
| `conditionType` | `defined` เก็บส่วนไว้เมื่อตั้งแอตทริบิวต์ไว้ `undefined` เมื่อไม่ได้ตั้ง |
| `content` | ตัวข้อความ เมื่อไม่ใช่การจับคู่ทั้งหมด |
| `format` | เอนจินของแผนภาพ (`mermaid` หรือ `vega-lite`) สำหรับตาราง คือรูปแบบที่คั่นด้วยตัวคั่นที่เซลล์ใช้ |
| `hardbreaks` | เมื่อมีอยู่ จะคงการขึ้นบรรทัดใหม่เดี่ยวของบล็อกถัดไป |
| `header` | ค่าใดก็ตามที่ไม่ใช่ `false` ทำให้แถวแรกของตารางเป็นส่วนหัว |
| `id` | ชื่อ: สำหรับบล็อกถัดไป คือ id ที่การอ้างอิงโยงชี้ไป สำหรับเชิงอรรถ คือชื่อที่ให้เชิงอรรถหลังๆ ที่ไม่มีข้อความของตัวเองใช้หมายเลขร่วมกัน |
| `keys` | แป้นที่ต้องกด คั่นด้วยจุลภาค |
| `label` | ข้อความที่แสดงสำหรับการอ้างอิงหรือจุดยึด แทนชื่อเรื่องของเป้าหมายเอง |
| `language` | ภาษาโปรแกรมของบล็อกโค้ด ใช้สำหรับการระบายสี |
| `level` | ระดับหัวเรื่อง ตั้งแต่ 1 ถึง 6 |
| `marker` | ตัวคั่นหลังศัพท์ เช่น `::` เครื่องหมายที่ต่างออกไปจะซ้อนรายการไว้ภายในคำอธิบาย |
| `name` | ชื่อของแอตทริบิวต์ ในการกำหนดหรือการอ้างอิง |
| `nodeType` | ทำให้บล็อกถัดไปเป็นเอาต์พุตอื่น ตามชื่อของมันในไฟล์ |
| `noHeader` | เมื่อมีอยู่ ตารางไม่มีแถวส่วนหัว |
| `notation` | สัญกรณ์คณิตศาสตร์: `tex` (ค่าเริ่มต้น) หรือ `latex` |
| `open` | `true` แสดงส่วนที่ยุบได้ในสถานะเปิด |
| `ordered` | `true` ทำให้รายการเป็นแบบมีหมายเลข |
| `original` | การอ้างอิงตามที่เขียน แสดงเมื่อไม่ได้กำหนดแอตทริบิวต์ |
| `presentation` | วิธีแสดงรายการคำอธิบายถัดไป: `sideBySide` วางศัพท์และคำอธิบายเป็นสองคอลัมน์ `questions` ใส่หมายเลขศัพท์แต่ละตัวเป็นคำถาม โดยมีคำตอบอยู่ใต้ศัพท์นั้น |
| `primary` | รายการดัชนี |
| `secondary` | รายการย่อยใต้รายการดัชนี |
| `sectionLabel` | คำที่หมายเลขของหัวเรื่องถัดไปตามหลัง เช่น `Appendix`: หัวเรื่องเช่นนี้ถูกนับแยกต่างหาก `Appendix A:` |
| `sectionLabelStart` | หมายเลขแรกของชุดนั้น: ตัวอักษร (`A`) นับเป็นตัวอักษร ตัวเลขนับเป็นตัวเลข |
| `src` | ที่อยู่ของไฟล์วิดีโอหรือเสียง |
| `start` | ตัวเลขที่รายการแบบมีหมายเลขเริ่มต้น |
| `summary` | บรรทัดที่แสดงบนส่วนที่ยุบได้ขณะที่ปิดอยู่ |
| `targetID` | id ที่การอ้างอิงชี้ไป |
| `term` | ศัพท์ที่กำลังอธิบาย |
| `tertiary` | รายการย่อยใต้รายการย่อยระดับที่สอง |
| `text` | ข้อความที่แสดง เมื่อรูปแบบจับได้มากกว่านั้น ข้อความของเชิงอรรถตามหลังย่อหน้า ตาราง หรือรายการที่มันอยู่ และมีหมายเลข |
| `title` | ชื่อเรื่อง: หัวข้อของกล่อง คำแนะนำเครื่องมือของรูปภาพหรือลิงก์ หรือคำบรรยายเหนือบล็อกถัดไป |
| `type` | ชนิดของข้อความเตือน เช่น `note`, `tip` หรือ `warning` |
| `unset` | เมื่อมีอยู่ กฎจะลบแอตทริบิวต์แทนที่จะกำหนด |
| `url` | ที่อยู่ที่ลิงก์หรือรูปภาพชี้ไป |
| `value` | ค่าของแอตทริบิวต์ การอ้างอิงถึงแอตทริบิวต์ที่กำหนดไว้ก่อนหน้าจะถูกแทนที่ในค่านี้ |
