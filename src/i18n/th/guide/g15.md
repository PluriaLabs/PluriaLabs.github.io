# Chapter 81: ไฟล์ การเข้ารหัส และขีดจำกัด

## ไฟล์ที่ Pilcrow เปิดได้

Pilcrow แก้ไขไฟล์ข้อความธรรมดาและไฟล์มาร์กอัป นามสกุลที่ใช้บ่อยคือ `txt`, `md`, `markdown`, `adoc`, `asciidoc`, `rst` และ `tex` รวมถึงนามสกุลใดก็ตามที่โปรไฟล์ซึ่งคุณเพิ่มระบุไว้ Pilcrow ตรวจหาการเข้ารหัสข้อความของไฟล์เมื่อเปิดไฟล์

| รายการ | ประเภท |
| --- | --- |
| โปรไฟล์ไวยากรณ์ ชุดมาโคร คู่มือสไตล์ ธีมแอปพลิเคชัน | `.json` |
| ธีมการแสดงผล | `.css` |
| แพ็กเกจธีม | `.zip` |
| ไฟล์ระบุโปรเจกต์หนังสือ | `manifest.pilcrow` |
| ฉากหลัง | HEIC, PNG, JPEG, SVG, MP4, MOV, M4V |
| คลิปเสียงการพิมพ์ | WAV, AIFF, MP3, M4A, CAF |

## การเข้ารหัสข้อความ

Pilcrow อ่านข้อความที่เข้ารหัสแบบ UTF-8, UTF-16, UTF-32 และ ISO 8859-1 (Latin-1) คุณแปลงเอกสารได้ด้วย **ข้อมูลเอกสาร ▸ การเข้ารหัส ▸ แปลงเป็น…** เป็นรูปแบบใดก็ได้ต่อไปนี้ ไฟล์จะถูกแปลงเมื่อบันทึกครั้งถัดไป:

UTF-8, UTF-8 (BOM), UTF-16 LE, UTF-16 LE (BOM), UTF-16 BE, UTF-16 BE (BOM), UTF-32 LE, UTF-32 LE (BOM), UTF-32 BE, UTF-32 BE (BOM)

ไฟล์ Latin-1 แปลงเป็นรูปแบบเหล่านี้ได้ทุกแบบโดยไม่สูญเสียข้อมูล ไม่มีตัวเลือกให้แปลงเป็น Latin-1 เพราะอาจทำให้เนื้อหาเสียหาย

## รูปแบบการส่งออก

| รูปแบบ | นามสกุล |
| --- | --- |
| HTML, HTML (ไม่มีสไตล์) | `.html` |
| PDF | `.pdf` |
| Word (.docx) | `.docx` |
| รูปภาพ | `.png` |
| PDF Archive | `.zip` |

จุดที่ Pilcrow หยุด หรือที่ตัวเลือกมีช่วงค่า:

| เปรียบเทียบ | แสดงบรรทัดที่เปลี่ยนแปลงได้ถึง 5,000 บรรทัด |
| เวอร์ชันที่จะเก็บ | ตั้งแต่ไม่มีไปจนถึง 500 (ค่าเริ่มต้น 50) |
| บรรทัดยาว | บรรทัดที่ยาว 20,000 อักขระขึ้นไปจะตัดบรรทัดเสมอ |
| ขนาดฟอนต์ | 9 ถึง 32 พอยต์ |
| ความกว้างแท็บ | 2 ถึง 8 ช่องว่าง |
| ความกว้างข้อความ | 50% ถึง 100% |
| ซูม | 50% ถึง 200% ในสิบขั้น |

| ความกว้างตัวนำทาง | 180 ถึง 420 พอยต์ |
| คลิปเสียงการพิมพ์ | ไม่เกิน 2 วินาทีและ 3 MB |
| ข้อความบันทึกของรายงานการวินิจฉัย | รายการล่าสุด สูงสุด 60,000 อักขระ เมื่อเพิ่มลงในคำอธิบาย issue บน GitHub |
| ไฟล์ขนาดใหญ่มาก | เปิดและแก้ไขได้โดยไม่ต้องอ่านทั้งไฟล์เข้าหน่วยความจำ จำนวนบรรทัดและจำนวนคำ รวมถึงเค้าโครง จะทำให้เสร็จในเบื้องหลัง และอาจยังไม่ครบถ้วนจนกว่าจะเสร็จ การส่งออก PDF ของเอกสารขนาดใหญ่มากต้องใช้หน่วยความจำมากกว่าการแก้ไขหรือการส่งออก HTML และ Word มาก PDF Archive จะแบ่งเอกสารเป็นส่วน ๆ ที่มีขนาดจำกัด |

## Pilcrow เก็บสิ่งต่าง ๆ ไว้ที่ไหน

| อะไร | ที่ไหน |
| --- | --- |
| เอกสารของคุณ | ที่ที่คุณบันทึกไว้ |
| คลัง (ธีม โปรไฟล์ มาโคร คู่มือสไตล์ ฉากหลัง) | ในพื้นที่จัดเก็บส่วนตัวของแอป หรือในโฟลเดอร์ชื่อ "Pilcrow Library" ภายในโฟลเดอร์ที่คุณเลือก (**การตั้งค่า ▸ คลัง ▸ ตำแหน่ง**) |
| ค่ากำหนด คีย์ API สำเนากู้คืน ประวัติเวอร์ชัน | บนอุปกรณ์ ในพื้นที่จัดเก็บส่วนตัวของแอปและพวงกุญแจ ตรวจสอบและลบได้ใน **การตั้งค่า ▸ ทั่วไป ▸ พื้นที่จัดเก็บและความเป็นส่วนตัว** |
| บันทึกการวินิจฉัย | บนอุปกรณ์ จนกว่าคุณจะล้าง |

# Chapter 82: ข้อความ แบนเนอร์ และสถานะว่าง

บทนี้อธิบายข้อความสั้น ๆ ที่ Pilcrow แสดง เพื่อให้ไม่มีข้อความใดที่เป็นปริศนา

## ในตัวแก้ไขและตัวอย่าง

| ข้อความ | ความหมาย |
| --- | --- |
| **ยังไม่มีอะไรให้แสดงตัวอย่าง เริ่มเขียนแล้วจะปรากฏที่นี่** (หรือ "สลับไปที่แก้ไขแล้วเริ่มเขียน") | เอกสารว่างเปล่า จึงไม่มีอะไรให้วาดในตัวอย่าง |
| **ตัวอย่างแสดงผลไม่ได้: …** พร้อม **แสดงต้นฉบับ** และ **ลองอีกครั้ง** | ตัวอย่างล้มเหลว **แสดงต้นฉบับ** สลับไปที่โหมดแก้ไข **ลองอีกครั้ง** คือลองใหม่ |
| สมการหรือแผนภาพที่ล้มเหลว พร้อมลิงก์ **แสดงต้นฉบับ** | วาดบล็อกหนึ่งไม่ได้ คลิก **แสดงต้นฉบับ** เพื่อข้ามไปยังต้นฉบับของบล็อกนั้นแล้วแก้ไข |
| **บันทึกไม่ได้** พร้อม **ลองอีกครั้ง** และปุ่มปิด | การบันทึกล้มเหลว เอกสารยังเปิดอยู่และยังไม่ได้บันทึก แก้ที่สาเหตุ (พื้นที่ดิสก์ สิทธิ์ หรือไฟล์ที่ถูกย้าย) แล้วเลือก **ลองอีกครั้ง** |
| **ไฟล์มีการเปลี่ยนแปลงบนดิสก์** | แอปอื่นแก้ไขไฟล์ **โหลดซ้ำ** อ่านเวอร์ชันใหม่ ส่วน **เก็บเวอร์ชันปัจจุบันไว้** เก็บสิ่งที่คุณมีอยู่ |
| **คำเตือนการแยกวิเคราะห์** | บรรทัดที่โครงสร้างบางอย่างอาจไม่ใช่สิ่งที่คุณตั้งใจ (Chapter 68) |
| **แทนที่ไฟล์ที่มีอยู่หรือไม่** | ชื่อที่คุณเลือกมีการใช้อยู่แล้วในตำแหน่งนั้น |
| **ยังมีฟิลด์ให้กรอกเหลืออยู่** | คุณกำลังพิมพ์หรือส่งออกโดยที่ยังมีฟิลด์ที่ไม่ได้กรอก (Chapter 63) |
| **ตัวแบ่งบานหน้าต่าง** (คำแนะนำ VoiceOver: "ลากเพื่อปรับขนาดตัวแก้ไขและตัวอย่าง แตะสองครั้งเพื่อรีเซ็ต") | ที่จับระหว่างต้นฉบับและตัวอย่างในโหมดเคียงข้างกัน |
| **คำ: N** | จำนวนคำในแถบสถานะ |

## ในกล่องโต้ตอบและแผง

| ที่ไหน | ข้อความ | ความหมาย |
| --- | --- | --- |
| พาเลตคำสั่ง | **พิมพ์คำสั่ง** | คำใบ้ของช่อง "ไม่มีคำสั่งที่ตรงกัน" จะปรากฏเมื่อไม่มีอะไรตรงกัน |
| เปิดด่วน | **พิมพ์ชื่อไฟล์** | คำใบ้ของช่อง |
| เคอร์เซอร์ในคอลัมน์ | **บรรทัด (เช่น 3-17)**, **คอลัมน์ (เช่น 100 หรือ 100-105 เพื่อเลือก)** | คำใบ้ของช่อง คอลัมน์เดียวจะวางเคอร์เซอร์ ส่วนช่วงจะเลือกอักขระเหล่านั้นในแต่ละบรรทัด |
| แผงค้นหา | **พิมพ์เพื่อค้นหาในโฟลเดอร์นี้** **ไม่พบรายการที่ตรงกันในโฟลเดอร์นี้** **ยกเลิกการค้นหาแล้ว** | สถานะของการค้นหาในโฟลเดอร์ |
| แผงไฟล์ | **คุณวางโฟลเดอร์ลงที่นี่ได้ด้วย** | ลากโฟลเดอร์มาวางบนแผงเพื่อเปิด |
| แทนที่ในโฟลเดอร์ | **ไม่มีอะไรให้แทนที่** | การค้นหาไม่มีรายการที่ตรงกัน |
| เปรียบเทียบ | คำอธิบายบนปุ่ม: **ยอมรับ** ("ทำการเปลี่ยนแปลงนี้ในเอกสารที่เปิดอยู่"), **ปฏิเสธ** ("ไม่รวมการเปลี่ยนแปลงนี้ในเอกสารที่เปิดอยู่"), **นำกลับ** ("ใส่บรรทัดเดิมกลับเข้าไปในเอกสารสำหรับการเปลี่ยนแปลงนี้เท่านั้น") | แต่ละปุ่มทำอะไร |
| แปล | **การแปลทำไม่สำเร็จ** | ลองอีกครั้ง หรือเลือกความเร็วอื่น |
| แปล | **เวลาโดยประมาณ: ไม่ถึงหนึ่งนาที** | ค่าประมาณสำหรับความเร็วของผู้ช่วย AI เวลาขึ้นอยู่กับบริการ AI ของคุณ หลังการแปล **เปิดในแท็บใหม่** จะเปิดผลลัพธ์ |
| ผู้ช่วย | **ไม่มีเอกสารที่เปิดอยู่** **ไม่มีการส่งข้อความเอกสาร** | แผงไม่มีอะไรให้แชร์ จึงไม่มีอะไรถูกส่ง |
| ตัวเลือกโมเดล | **กำลังโหลดโมเดล…** **ไม่มีโมเดลที่ตรงกัน** | รายการกำลังโหลด หรือการค้นหาของคุณไม่พบอะไร |
| ตรวจทานสไตล์ | **ไม่พบประเด็น** และ **อ่านคำตอบเป็นประเด็นที่พบไม่ได้ ลองอีกครั้ง** | การตรวจทานไม่พบอะไร หรือคำตอบของ AI ไม่ได้อยู่ในรูปแบบที่คาดไว้ |
| ตรวจทานสไตล์ | คำอธิบาย **ใช้ทั้งหมด**: "แก้ทุกจุดที่มีการแก้ไขให้ในครั้งเดียว ซึ่งเลิกทำได้" | เลิกทำครั้งเดียวย้อนกลับได้ทั้งหมด |
| แผงโปรเจกต์ | **ชื่อของคุณ**, **เพิ่มตัวแปร** | คำใบ้ของช่องผู้เขียน และปุ่มสำหรับตัวแปรของโปรเจกต์ |
| สิทธิ์ของผู้ช่วย | **อ่านนโยบายความเป็นส่วนตัวของ Pilcrow** | เปิดนโยบายความเป็นส่วนตัว |

## ในการตั้งค่า

| ที่ไหน | ข้อความ | ความหมาย |
| --- | --- | --- |
| แป้นพิมพ์ | **กดแป้นพิมพ์ลัดใหม่ แล้วคลิกบันทึก** และ **กดแป้นใดก็ได้…** | ขณะบันทึกแป้นพิมพ์ลัด |
| คลัง ▸ ตำแหน่ง | **ตำแหน่งคลัง**, **กำลังย้ายคลังของคุณ…** | ชื่อหน้า และความคืบหน้าขณะย้ายคลัง |
| การเชื่อมต่อผู้ช่วย | **เว้นว่างไว้เพื่อเก็บคีย์ที่บันทึกไว้** | ขณะแก้ไข ช่องคีย์ที่ว่างจะเก็บคีย์ที่อยู่ในพวงกุญแจอยู่แล้ว |
| ตัวแก้ไขมาโคร | **ทริกเกอร์ — เช่น /sig** | คำใบ้ของช่องทริกเกอร์ |
| ตัวแก้ไขโปรไฟล์ | **JSON ของโปรไฟล์ขั้นสูง**, **ตัวอย่างและผลลัพธ์** | ชื่อของตัวแก้ไข JSON และพื้นที่ใต้ตัวอย่างทดสอบที่แสดงโหนดที่ตัวอย่างสร้างขึ้น |
| การวินิจฉัย | **ทุกส่วน** (ในตัวดูบันทึก), **ไม่มีรายการที่ตรงกัน** | บันทึกที่ไม่ได้กรอง และตัวกรองที่ไม่ตรงกับอะไรเลย |
| แถบสถานะ | เครื่องหมายสีแดง **กำลังบันทึกข้อมูล** พร้อมคำอธิบาย **แสดงการตั้งค่าการวินิจฉัย** | กำลังบันทึกข้อมูลอยู่ คลิกเพื่อไปยังหน้าการวินิจฉัย **หยุดบันทึกและเสร็จสิ้นรายงานข้อบกพร่อง** คือคำอธิบายบน **กำลังทำซ้ำ — เสร็จสิ้นรายงาน** |
| แถบสถานะ | **เลือกโปรไฟล์ไวยากรณ์สำหรับเอกสารนี้** | คำอธิบายบนเมนูไวยากรณ์ |
| ตัวควบคุมชื่อเรื่อง | **เอกสารที่เปิดอยู่และการดำเนินการกับเอกสาร** | คำอธิบายบนชื่อเอกสาร |
