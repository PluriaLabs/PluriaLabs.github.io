| **พับทั้งหมด** **ขยายทั้งหมด** | | ยุบหรือขยายส่วนของทุกหัวเรื่อง เป็นสีเทาเว้นแต่ การพับหัวเรื่อง จะเปิดอยู่ |

# Chapter 56: เมนูแทรก

ทุกอย่างในเมนูแทรกจะใส่ต้นฉบับลงในเอกสารที่ตำแหน่งเคอร์เซอร์ เขียนด้วยสัญกรณ์ของโปรไฟล์ไวยากรณ์ที่ใช้งานอยู่ รายการที่โปรไฟล์ไม่สามารถแสดงได้จะเป็นสีเทา และทุกรายการจะปิดอยู่ในโหมดตัวอย่าง

| รายการ | ทำอะไร |
| --- | --- |
| **ตาราง…** | เปิดกล่องโต้ตอบแทรกตาราง (Chapter 63) ทางลัด `⌥⌘T` |
| **รูปภาพ…** | เลือกรูปภาพและแทรก โดยใช้การตั้งค่ารูปภาพ (Chapter 68) ทางลัด `⇧⌘I` |
| **แผนภาพ** | เมนูย่อยของแผนภาพ Mermaid สำเร็จรูป (ด้านล่าง) |
| **แผนภูมิ** | เมนูย่อยของแผนภูมิ Vega-Lite สำเร็จรูป (ด้านล่าง) |
| **สมการ** | เมนูย่อยของสมการสำเร็จรูป (ด้านล่าง) |
| **รั้วโค้ด** | แทรกบล็อกโค้ดแบบมีรั้ว |
| **การแจ้งเตือน** | เมนูย่อย: **หมายเหตุ** **เคล็ดลับ** **สำคัญ** **คำเตือน** **ข้อควรระวัง** |
| **เส้นแนวนอน** | แทรกตัวแบ่งเชิงเนื้อหา |
| **การอ้างอิงลิงก์** | แทรกลิงก์แบบอ้างอิงและคำนิยามของลิงก์ |
| **เชิงอรรถ** | แทรกเครื่องหมายเชิงอรรถและคำนิยามของเชิงอรรถ |
| **สารบัญ** | แทรกบรรทัด `[TOC]` ซึ่งจะกลายเป็นรายการสารบัญที่สร้างขึ้น |
| **YAML Front Matter** | แทรกบล็อก front matter ที่ด้านบนของไฟล์ |
| **ฟิลด์** | แทรกช่องว่างให้กรอกสำหรับแป้น Tab อัจฉริยะ โดยเลือกไว้เพื่อให้คุณตั้งชื่อได้ (Chapter 24) |

ใต้รายการเหล่านี้ ตัวแบ่งตามด้วย **โครงสร้างเฉพาะของโปรไฟล์ที่ใช้งานอยู่** เช่น admonition หรือบล็อกแบบกำหนดเองที่โปรไฟล์นิยามไว้ หากยังไม่ได้เลือกโปรไฟล์ เมนูจะแสดง "Select a syntax profile to insert constructs"

## แม่แบบแผนภาพ

แทรก ▸ แผนภาพ มีจุดเริ่มต้น 17 แบบ แต่ละแบบแทรกตัวอย่างที่ใช้งานได้ให้คุณแก้ไข

Flowchart, Sequence Diagram, Class Diagram, State Diagram, Entity Relationship Diagram, Gantt Chart, Pie, User Journey, Git Graph, Mind Map, Timeline, Quadrant Chart, Sankey Diagram, XY Chart, Block Diagram, Packet Diagram และ Kanban Board

## แม่แบบแผนภูมิ

Bar Chart, Line Chart, Area Chart, Scatter Plot, Pie Chart, Stacked Bar Chart, Histogram, Heatmap และ Box Plot

## แม่แบบสมการ

Fraction, Square Root, Summation, Integral, Limit, Quadratic Formula, Matrix, Piecewise Function, Aligned Equations, Binomial Coefficient, Bayes' Theorem และ Euler's Identity

บน iPad รายการแทรกที่มีชื่อซ้ำกับเมนูย่อยย่อหน้า (การแจ้งเตือน เส้นแนวนอน การอ้างอิงลิงก์ เชิงอรรถ สารบัญ YAML Front Matter) จะแสดงเป็น "แทรกการแจ้งเตือน" เป็นต้น เพราะ iPad รวมรายการเมนูที่ใช้ชื่อเดียวกัน

## แถบเมนูของ iPad

iPad มีแถบเมนูของตัวเอง แสดงเมื่อคุณกด **⌘** ค้างไว้หรือเลื่อนตัวชี้ไปที่ด้านบนของหน้าจอ มีคำสั่งเดียวกับเมนูของ Mac จากคำนิยามเดียวกัน พร้อมทางลัดที่กำหนดใหม่ได้เหมือนกัน มีเพียง **ไฟล์** ที่ต่างออกไป เพราะเมนูไฟล์ของ Mac ใช้แผงของ AppKit

สำหรับ iPad ที่ไม่มีแป้นพิมพ์หรือเมาส์ Pilcrow แสดงเมนูชุดเดียวกันในส่วนหัวได้ **การตั้งค่า ▸ รูปลักษณ์ ▸ เมนูในส่วนหัว** เลือกได้ดังนี้

| ตัวเลือก | ผล |
| --- | --- |
| **อัตโนมัติ** | แสดงเมนู เว้นแต่จะเชื่อมต่อแป้นพิมพ์หรือเมาส์ |
| **เสมอ** | แสดงเสมอ |
| **ไม่เลย** | ไม่แสดงเลย |

- **ไฟล์** เพิ่ม **เปิดโฟลเดอร์…** **ส่งออก…** และ **พิมพ์…** จากรายการปกติ
- **แก้ไข** มี **เลิกทำ** **ทำซ้ำ** คำสั่งคัดลอก **ค้นหา** **การสะกดและไวยากรณ์** **ส่วนที่เลือก** **แปล** **ไปที่บรรทัด…** **ตรวจสอบลิงก์…** **คำสั่งด่วน…** **ย้อนกลับ** และ **ไปข้างหน้า**
- **รูปแบบ** มีสไตล์แบบแทรกในบรรทัด เมนูย่อย **ย่อหน้า** **แทรกตาราง…** และ **แทรกรูปภาพ…**
- **มุมมอง** มี **แถบเครื่องมือจัดรูปแบบ** **เปิด/ปิดแถบด้านข้าง** **เค้าร่าง** **ไฟล์** **ค้นหา** โหมดเอกสาร **โฟกัส** **หมายเลขบรรทัด** **กฎบรรทัดปัจจุบัน** **ต้นฉบับที่มีสไตล์** **การพับหัวเรื่อง** และ **เอกสารที่เปิดอยู่** สำหรับสวิตช์การแสดงผลอื่นๆ ให้ใช้ **เพิ่มเติม** หรือการตั้งค่า
- **วิธีใช้** มี **วิธีใช้ Pilcrow** **รายงานข้อบกพร่อง…** และ **เสร็จสิ้นรายงานข้อบกพร่อง**

# Part XVII — แผง แถบ และกล่องโต้ตอบ

# Chapter 59: ชื่อเอกสารและตัวสลับเอกสาร

ชื่อของเอกสารอยู่ในส่วนหัวพร้อมจุดสีเล็กๆ และลูกศรลง คลิกที่ชื่อ หรือเลือก **มุมมอง ▸ เอกสารที่เปิดอยู่** (`⌃⌘2`) เพื่อเปิดรายการ **เอกสารที่เปิดอยู่** บนหน้าจอขนาดเล็กจะเปิดเป็นชีตพร้อมปุ่ม **เสร็จสิ้น**

## จุดบอกการบันทึก

จุดข้างชื่อบอกสถานะของเอกสารได้ในพริบตา VoiceOver ก็อ่านสถานะนี้ออกเสียงด้วย

| จุด | ความหมาย |
| --- | --- |
| เขียว | **บันทึกแล้ว** ไฟล์บนดิสก์ตรงกับที่คุณเห็น |
| เหลืองอำพัน | **แก้ไขแล้ว** คุณมีการเปลี่ยนแปลงที่ยังไม่ได้บันทึก |
| แดง | **บันทึกไม่สำเร็จ** Pilcrow พยายามบันทึกแต่ทำไม่ได้ แบนเนอร์ **Couldn't save** พร้อมปุ่ม **ลองอีกครั้ง** จะปรากฏเหนือตัวแก้ไข |
| น้ำเงิน | **ถูกเปลี่ยนโดยแอปอื่น** ไฟล์บนดิสก์ถูกเปลี่ยนจากภายนอก Pilcrow |

เอกสารที่ไม่เคยบันทึกจะแสดง "Not yet saved" และตัวเลขในรายการ เพราะไม่มีโฟลเดอร์ให้แสดง เอกสารที่มีการเปลี่ยนแปลงที่ยังไม่ได้บันทึกจะบอกว่า **แก้ไขแล้ว** ที่ท้ายแถวด้วย

## รายการเอกสารที่เปิดอยู่

| ส่วน | ทำอะไร |
| --- | --- |
| **ค้นหาในเอกสารที่เปิดอยู่** | ปรากฏเมื่อเปิดเอกสารตั้งแต่เจ็ดเอกสารขึ้นไป พิมพ์บางส่วนของชื่อหรือโฟลเดอร์ แต่ละคำต้องตรงกันที่ใดที่หนึ่งในชื่อหรือโฟลเดอร์ โดยไม่สนใจตัวพิมพ์และเครื่องหมายกำกับเสียง Return เปิดรายการแรกที่ตรง เมื่อไม่มีรายการตรง จะแสดง "No open documents match." |
| แถวสำหรับแต่ละเอกสาร | แสดงชื่อ จุดบอกการบันทึก และโฟลเดอร์ที่เอกสารอยู่ เครื่องหมายถูกระบุเอกสารที่ใช้งานอยู่ คลิกแถวเพื่อสลับไปที่เอกสารนั้น |
| **ปิด** (เครื่องหมาย **x** ที่ท้ายแถว) | ปิดเอกสารนั้น โดยถามก่อนหากมีการเปลี่ยนแปลงที่ยังไม่ได้บันทึก |
| **เอกสารใหม่** | สร้างเอกสารที่ยังไม่มีชื่อ |
| **บันทึก** | บันทึกเอกสารที่ใช้งานอยู่ |
| **บันทึกเป็น…** | บันทึกเป็นชื่อหรือตำแหน่งใหม่ |
| **เปลี่ยนชื่อ…** | เปิดแบบฟอร์มเปลี่ยนชื่อ (ด้านล่าง) |
| **ปิดเอกสารทั้งหมด** | ปิดทุกเอกสาร โดยถามทีละเอกสารที่ยังไม่ได้บันทึก |

ใช้ `⌃Tab` และ `⌃⇧Tab` เพื่อไปยังเอกสารถัดไปหรือก่อนหน้าโดยไม่ต้องเปิดรายการ

## เปลี่ยนชื่อ

**เปลี่ยนชื่อ…** แสดง **ชื่อ** ปัจจุบันและ **ที่ไหน** ที่ไฟล์อยู่ พร้อมปุ่ม **ยกเลิก** และ **เปลี่ยนชื่อ** การเปลี่ยนชื่อจะเปลี่ยนไฟล์บนดิสก์และเก็บเอกสารไว้เปิดอยู่ หากใช้ชื่อใหม่ไม่ได้ ข้อความ **ไม่สามารถเปลี่ยนชื่อเอกสารได้** จะอธิบายเหตุผล
