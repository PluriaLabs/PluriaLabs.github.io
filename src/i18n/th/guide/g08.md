# Chapter 63: กล่องโต้ตอบและข้อความแจ้ง

บทนี้อธิบายชีตและการแจ้งเตือนที่ปรากฏขึ้นขณะที่คุณทำงาน

## Insert Table

**Format ▸ Paragraph ▸ Table ▸ Insert Table…** (`⌥⌘T`) หรือ **Insert ▸ Table…** จะถามหา **Columns** และ **Rows** เลือก **OK** หรือ **Cancel** ตารางจะถูกเขียนด้วยไวยากรณ์ตารางของโปรไฟล์ที่ใช้งานอยู่

## Carets in a Column

**Edit ▸ Selection ▸ Carets in a Column…** (`⌃⇧G`) วางเคอร์เซอร์ตามตัวเลข สำหรับ iPad ที่ไม่มีแป้นพิมพ์ ป้อน **Lines** (เช่น `3-17`) และ **Column** (เช่น `100` หรือ `100-105` เพื่อเลือกอักขระเหล่านั้นในแต่ละบรรทัด) แล้วเลือก **Place** จากนั้นพิมพ์ ลบ คัดลอก หรือวางได้ บรรทัดที่สั้นเกินกว่าจะถึงคอลัมน์จะเป็นไปตาม **Settings ▸ Editing ▸ Short lines in column mode** ขณะที่การเลือกคอลัมน์ใช้งานอยู่ จะมีป้าย **Column Selection** ปรากฏขึ้น พร้อมปุ่ม **Turn off Column Selection**

## Edit Block

เมื่อเปิด **Rendered Blocks** ตาราง สมการ หรือแผนภาพที่วาดเป็นรูปภาพทุกรายการจะมีปุ่มแก้ไข ปุ่มนี้เปิด **Edit Block** ซึ่งเป็นชีตที่แสดงซอร์สของบล็อก เลือก **Apply** เพื่อนำการเปลี่ยนแปลงของคุณกลับไปใส่ หรือ **Cancel**

## Check Links

**Edit ▸ Check Links…** ตรวจสอบทุกลิงก์และรูปภาพในเอกสาร ต้องบันทึกเอกสารก่อนจึงจะตรวจสอบลิงก์ไปยังไฟล์อื่นได้: "Save the document to check its links to other files." ชีตจะแสดง "Checking links…" จากนั้นเป็นรายการปัญหา แต่ละรายการมีหมายเลขบรรทัด หรือ "All links work." สรุปจะอ่านว่า "Links checked: N. Web addresses not contacted: N." Pilcrow ไม่ติดต่อที่อยู่เว็บ แอปตรวจสอบได้สูงสุด 50,000 ลิงก์ เลือก **Check Again** หรือ **Done**

## Replace in Folder

**Replace…** ในแผง Search เปิดตัวอย่างของทุกการเปลี่ยนแปลงก่อนที่จะแตะต้องไฟล์ใดๆ

- ช่อง **Replace with** ใช้ใส่ข้อความที่จะแทนที่ ชีตแสดงไฟล์ที่จะเปลี่ยนแปลงทั้งหมด พร้อมจำนวน และตัวอย่างก่อนและหลังของแต่ละรายการที่ตรงกัน และช่องกาเครื่องหมายเพื่อให้คุณละไฟล์นั้นไว้ได้
- **Replace N matches in M files** ทำการเปลี่ยนแปลง **Cancel** หยุด
- รายการ **Skipped** ระบุไฟล์ที่ Pilcrow จะไม่เปลี่ยนแปลง พร้อมเหตุผล: "Open in an editor. Replace there, or close it first.", "Not plain UTF-8 text.", "Too many matches in one file.", "A line is too long for this pattern." หรือ "Could not be read."
- การแทนที่หนึ่งครั้งเปลี่ยนได้มากที่สุด 2,000 ไฟล์ เกินจากนั้นจะแสดง "More files match than one replace changes. Replace these first, then search again."
- ไฟล์ที่เปลี่ยนแปลงหลังจากดูตัวอย่างจะไม่ถูกแก้ไข
- เมื่อเสร็จสิ้น: "Replaced N matches in M files." พร้อม **Undo** และ **Done** **Undo** กู้คืนไฟล์จากข้อมูลสำรอง ไฟล์ที่ถูกแก้ไขหลังจากนั้นหรือหายไปจะถูกปล่อยไว้ตามเดิมและแสดงรายการไว้ ครั้งถัดไปที่คุณเปิดชีต จะมีตัวเลือกให้เลิกทำการแทนที่ครั้งล่าสุด

## Version History

**File ▸ Version History…** แสดงรายการเวอร์ชันที่บันทึกไว้ของเอกสาร เวอร์ชันจะถูกเก็บทุกครั้งที่คุณบันทึก ได้สูงสุดตามจำนวนที่ตั้งไว้ใน **Settings ▸ Files ▸ Versions to keep** แอปแสดง "Save the document to start keeping versions." สำหรับเอกสารที่ยังไม่ได้บันทึก "Version history is off." เมื่อการตั้งค่านั้นเป็นไม่มี และ "No versions yet." ก่อนการบันทึกครั้งแรก

เลือกเวอร์ชันหนึ่ง แล้ว:

| Button | What it does |
| --- | --- |
| **Open Copy** | เปิดเวอร์ชันเก่าเป็นเอกสารแยกต่างหาก |
| **Compare…** | เปิดชีตเปรียบเทียบกับเวอร์ชันนั้น |
| **Restore…** | นำเอกสารกลับไปเป็นอย่างที่เคยเป็นในตอนนั้น หลังจากที่คุณยืนยัน ข้อความปัจจุบันจะถูกเก็บไว้เป็นเวอร์ชัน คุณจึงย้อนกลับได้ การกู้คืนต้องบันทึกหรือยกเลิกการเปลี่ยนแปลงของคุณก่อน |
| **Done** | ปิดชีต |

## Compare Versions

**File ▸ Compare with File…** หรือ **Compare…** ใน Version History เปิด **Compare Versions**

- ตัวเลือกสองตัว คือ **Older** และ **Newer** ใช้เลือกสิ่งที่จะเปรียบเทียบ **Compare with File…** ใช้เลือกไฟล์
- **Ignore trailing whitespace** ซ่อนความแตกต่างที่เป็นเพียงช่องว่างท้ายบรรทัด
- สรุปจะอ่านว่า "Added: N. Removed: N." และแสดงรายการบรรทัดที่เปลี่ยนแปลง สูงสุด 5,000 บรรทัด
- สำหรับแต่ละการเปลี่ยนแปลง: **Accept** ทำการเปลี่ยนแปลงในเอกสารที่เปิดอยู่ **Reject** ละไว้ **Reconsider** เลิกทำการเลือกของคุณ และ **Take Back** (เมื่อเวอร์ชันเก่าอยู่ด้านเก่า) นำบรรทัดเก่ากลับมาเฉพาะการเปลี่ยนแปลงนั้น **Accept All Remaining** ยอมรับทุกอย่างที่เหลือ
- การเปลี่ยนแปลงจะถูกนำไปใช้ก็ต่อเมื่อข้อความของมันยังตรงกัน มิฉะนั้นจะแสดง "Nothing was changed: that part of the document has changed since the comparison."
- ข้อความ: "The two are the same.", "Could not compare these." และเมื่อมีความแตกต่างมากเกินไป "They differ in too many lines to compare line by line. Open a copy of the version and read it beside the document."

## Translate

**Edit ▸ Translate ▸ Document** หรือ **Selection** เปิด **Translate Document** หรือ **Translate Selection**

| Control | What it does |
| --- | --- |
| **Detected language** | ภาษาที่ Pilcrow พบในข้อความ |
| **Translate to** | ภาษาปลายทาง |
| **Speed** | **Fast** (เร็วกว่าประมาณยี่สิบเท่า ใช้ถ้อยคำเรียบง่ายกว่า และเป็นสิ่งที่เอกสารยาวต้องใช้), **Best quality** (สำหรับข้อความที่คุณจะอ่านอย่างละเอียด) หรือ **AI assistant** (การเชื่อมต่อ AI ของคุณเองจาก Settings ▸ Assistant ข้อความจะถูกส่งไปยังที่ที่การเชื่อมต่อนั้นชี้ไป) **Best quality** ใช้ได้ตั้งแต่ macOS และ iPadOS 26.4 ระบบรุ่นก่อนหน้ามีความเร็วเดียว |
| **When finished** | สำหรับเอกสาร: **Open in a new tab** (เอกสารใหม่ที่ตั้งชื่อเหมือนต้นฉบับโดยมีภาษาอยู่ในวงเล็บ), **Save a copy beside the original** หรือ **Replace the document** สำหรับส่วนที่เลือก **Replace Selection** จะนำคำแปลไปใส่แทนที่ |
| **Translate** หรือ **Send and Translate** | เริ่มการแปล Send and Translate ปรากฏเมื่อผู้ช่วย AI จะส่งข้อความของคุณ โดยจะระบุผู้ให้บริการและเตือนว่าบริการของคุณอาจคิดค่าใช้จ่าย |
| **Estimated time** | ค่าประมาณ: "less than a minute" หรือ "about N" เวลาขึ้นอยู่กับบริการ AI ของคุณ |

การแปลทำงานอยู่เบื้องหลัง โดยแสดงความคืบหน้าในแถบสถานะ ชุดภาษาจะดาวน์โหลดเมื่อคุณแปลเป็นภาษานั้นเป็นครั้งแรก หากไม่มีการแปลโดยตรงระหว่างสองภาษา Pilcrow จะถามว่าจะแปลผ่านภาษาอังกฤษหรือไม่ (**Yes** หรือ **No**) โค้ด ลิงก์ และสูตรคณิตศาสตร์จะถูกปล่อยไว้ตามเดิม การแปลต้องใช้ macOS 15 หรือ iPadOS 18 ขึ้นไป จะไม่ใช้ผู้ช่วยหากปิดไว้สำหรับไฟล์หรือโฟลเดอร์นั้น

เมื่อคุณเปิดไฟล์ที่เขียนด้วยภาษาอื่น อาจมีแถบถามว่า "This looks like *Language*. Translate it into *Language*?" พร้อม **Translate**, **Not Now** และ **Never for This File** Settings ▸ General ▸ Translation ควบคุมสิ่งนี้ (Chapter 67)

## Saving and closing

- **Keep this document?** เมื่อคุณปิดเอกสารใหม่ Pilcrow จะถามว่า "Do you want to keep this new document?" สำหรับเอกสารที่มีอยู่แล้ว จะถามว่า "Do you want to save the changes you made?" ตัวเลือกคือ **Save**, **Cancel** และ **Delete** (หรือ **Don't Save**) สำหรับเอกสารใหม่ ฟอร์มมี **Save As:** (ชื่อ), **Tags:** และ **Where:** (พร้อม **Other…** หรือ **Choose…** สำหรับโฟลเดอร์อื่น) คุณเลิกทำ Delete ไม่ได้
- **Save Document** คือฟอร์มสำหรับการบันทึกครั้งแรก พร้อม **Name** และ **Location** (**Choose Another Location…**) หากมีไฟล์ชื่อนั้นอยู่แล้ว จะถาม **Replace Existing File?**
- **File Changed on Disk** ปรากฏเมื่อแอปอื่นแก้ไขไฟล์ที่เปิดอยู่: เลือก **Reload** หรือ **Keep Current Version**
- **Reload from Disk?** (File ▸ Reload from Disk) มี **Save, Then Reload**, **Reload Without Saving** และ **Cancel**
- **Fill-in fields remain** ปรากฏเมื่อคุณพิมพ์หรือส่งออกขณะที่ยังมีฟิลด์ที่ไม่ได้กรอก มี **Go to Next Field**, **Continue Anyway** (ฟิลด์จะปรากฏในผลลัพธ์ตามที่เขียนไว้) และ **Cancel**
- **Parsing warning**, **Could Not Share**, **Could Not Save Document** และ **File Operation Failed** แสดงข้อความพร้อม **OK**
- หาก Pilcrow ปิดตัวลงโดยไม่คาดคิดในครั้งก่อน แบนเนอร์จะแจ้งเรื่องนี้และมี **Open Diagnostics** หรือ **Not Now** ให้เลือก
- หลังจากนำเข้ารายการจากไลบรารี จะมีข้อความเล็กๆ ยืนยัน พร้อมปุ่มสำหรับปิดข้อความนั้น
- เมื่อใช้ภาษาของแอปที่แปลแล้ว การเปิดครั้งแรกจะแสดง **Translated with AI** อธิบายว่าคำแปลยังไม่ได้รับการตรวจสอบโดยเจ้าของภาษา พร้อม **Don't show this again** และ **OK**

## The assistant's permission sheet

ก่อนที่เนื้อหาชิ้นแรกจะถูกส่งไปยังบริการออนไลน์ **Send to *service*?** จะอธิบายสิ่งที่ถูกส่ง (คำขอของคุณ ข้อความของเอกสารที่นับไว้เหนือช่องคำถาม หรือข้อความที่กำลังตรวจทานด้วยกฎของคู่มือสไตล์ ชื่อของโมเดล และคีย์ของคุณ) ใครเป็นผู้รับ และวิธีเรียกคืน โปรแกรมบนคอมพิวเตอร์เครื่องนี้จะไม่ออกจากคอมพิวเตอร์ คอมพิวเตอร์เครื่องอื่นในเครือข่ายของคุณจะไม่ถูกเข้ารหัสเว้นแต่ที่อยู่ขึ้นต้นด้วย https บริการออนไลน์อาจเก็บข้อความไว้ตามข้อกำหนดของตนเอง มีลิงก์ไปยังนโยบายความเป็นส่วนตัวของบริการและของ Pilcrow เลือก **Send** หรือ **Cancel** จะไม่มีการส่งสิ่งใดจนกว่าคุณจะเลือก Send

# Chapter 64: Export and Compile

## แผงส่งออก

เปิดด้วย **File ▸ Export…** (`⇧⌘E`), ปุ่ม **Export** หรือ **More ▸ Export…** แผงมีรายการรูปแบบทางซ้าย ตัวเลือกทางขวา และปุ่มตามแนวด้านล่าง

### รูปแบบ

| Format | File | Notes |
| --- | --- | --- |
| **HTML** | `.html` | หน้าเว็บแบบสแตนด์อโลนที่มีสไตล์ |
| **HTML (without Styles)** | `.html` | โครงสร้างสะอาดโดยไม่มี CSS ของธีม |
| **PDF** | `.pdf` | แบ่งหน้า |
| **Word (.docx)** | `.docx` | แพ็กเกจ Word จริง ใช้สี ฟอนต์ ขนาด และระยะห่างบรรทัดของธีม ตัวเลือกเลย์เอาต์ของเบราว์เซอร์ไม่มีสิ่งที่เทียบเท่าใน Word สมการ แผนภาพ และแผนภูมิจะกลายเป็นรูปภาพ |
| **Image** | `.png` | รูปภาพเดียวของเอกสารที่แสดงผล |
| **PDF Archive (.zip)** | `.zip` | ส่วน PDF ที่เรียงลำดับพร้อม manifest สำหรับเอกสารที่ใหญ่มาก |

### ตัวเลือก

| Section | Controls |
| --- | --- |
| **Style** | **Theme** เลือก Render Theme ธีมควบคุมตัวอักษรและสีของเอกสารที่ส่งออก |
| **Page** (PDF, PDF Archive และ Word) | **Paper size** (A3, A4, A5, Letter, Legal, Tabloid หรือ **Width** และ **Height** ที่กำหนดเอง), **Orientation** (**Portrait** หรือ **Landscape**) และ **Top margin**, **Bottom margin**, **Left margin** และ **Right margin** ทั้งหมดเป็นมิลลิเมตร (เริ่มต้นที่ 25.4 มม. หรือหนึ่งนิ้ว) **Use these page settings as default** บันทึกค่าเหล่านี้สำหรับการส่งออกครั้งต่อไป เป็นสีเทาจนกว่าคุณจะเปลี่ยนบางอย่าง มิฉะนั้นจะใช้กับการส่งออกครั้งนี้เท่านั้น |
| **Advanced options** | **Custom CSS** ใช้หลังธีม สำหรับการส่งออกครั้งนี้เท่านั้น |

แผงแสดง "Save as *name*" พร้อมชื่อไฟล์ที่จะใช้ และ "These choices apply to this export only." การเลือกรูปแบบจะแสดงสิ่งที่มันสร้างในบรรทัดที่ด้านล่างซ้าย เช่น "A standalone web page with the selected style." สำหรับ HTML หรือ "One paginated PDF document." สำหรับ PDF

### ปุ่ม

**Cancel** ปิดแผง **Share…** ส่งไฟล์ที่สร้างขึ้นตรงไปยังชีตแชร์ของระบบ **Export** ถามว่าจะบันทึกที่ไหน ขณะทำงาน แผงจะแสดง "Rendering…" หากเกิดข้อผิดพลาด จะแสดง "Export failed." หากยังมีฟิลด์ให้กรอกเหลืออยู่ Pilcrow จะถามก่อน (Chapter 63)

การตั้งค่าหน้า เทมเพลตส่วนหัวและส่วนท้าย สารบัญ และตัวเลือกการใส่หมายเลขที่ใช้กับทุกการส่งออกอยู่ใน **Settings ▸ Contents & Labels** และ **Settings ▸ Export** (Chapter 70)

**File ▸ Compile Manuscript…** (หรือ **Compile…** ในแผง Project) รวมไฟล์ของโปรเจกต์หนังสือตามลำดับใน manifest ใช้ได้เมื่อโหลดโปรเจกต์แล้ว

| Section | Controls |
| --- | --- |
| **Manuscript** | สรุป: "N files", "N left out" และพาธ "Cannot be found" ใดๆ ซึ่งต้องแก้ไขก่อนคอมไพล์ รายการ **Order** แสดงลำดับสุดท้าย |
| **Output** | **Format** จากนั้น **Start on a new page**: **Front matter**, **Parts**, **Chapters**, **Back matter** **Between scenes** กำหนดตัวคั่น ("None" หรือเครื่องหมาย) **Table of contents**, **Number headings** และ **Keep a version of each file first** (บันทึกรายการ Version History สำหรับทุกไฟล์ที่รวมไว้) |
| **Preset** | ค่าที่ตั้งไว้ล่วงหน้าที่ **Saved** ไว้ **Save as preset** พร้อม **Preset name** และ **Save** **Delete Preset** ลบรายการที่เลือก |

เลือก **Compile…** เพื่อเลือกที่บันทึก หรือ **Cancel** ขณะทำงานจะแสดง "Reading N of N…" แล้ว "Compiling…" พร้อม **Stop** ตัวแปรที่ไม่มีค่าจะถูกแสดงรายการไว้ ("These {{variables}} have no value and were left as written") และถูกปล่อยไว้โดยไม่เปลี่ยนแปลงให้เห็นชัด หากสร้างไฟล์ไม่ได้ จะแสดง "The book could not be created there."

### New Book

**File ▸ New Book…** ถามหา **Title**, **Author**, **Write in** (ไวยากรณ์สำหรับบท) และ **Keep it in** (โฟลเดอร์ พร้อม **Choose…**) เลือก **Create** Pilcrow จะสร้างโฟลเดอร์พร้อม manifest และบทแรก หากสร้างหนังสือที่นั่นไม่ได้ แอปจะแจ้งไว้
