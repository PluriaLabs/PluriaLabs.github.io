# Chapter 72: แป้นพิมพ์

**การตั้งค่า ▸ แป้นพิมพ์ ▸ คำสั่งลัด** แสดงรายการทุกคำสั่งที่คุณเปลี่ยนคำสั่งลัดได้ พร้อมแป้นปัจจุบัน

| ตัวควบคุม | หน้าที่ |
| --- | --- |
| แถวของคำสั่ง | คลิกที่แถว กดคำสั่งลัดใหม่ แล้วเลือก **บันทึก** **ยกเลิกการผูก** จะลบคำสั่งลัดออก **ยกเลิก** จะคงอันเดิมไว้ หากคำสั่งลัดนั้นถูกใช้โดยคำสั่งอื่นอยู่ คำสั่งนั้นจะถูกล้าง และหน้านี้จะบอกคุณว่าเป็นคำสั่งใด |
| **แป้น Tab อัจฉริยะ** | แป้นสำหรับ **ฟิลด์ถัดไป** และ **ฟิลด์ก่อนหน้า** ซึ่งใช้กระโดดไปมาระหว่างช่องว่างที่มาโครทิ้งไว้ ได้แก่ `⌥Tab` และ `⌥⇧Tab` หรือ `⌃⌘]` และ `⌃⌘[` หรือ **กำหนดเอง** |
| **รีเซ็ตแป้นพิมพ์ลัดทั้งหมด** | คืนค่าเริ่มต้นทั้งหมด |

คำสั่งที่คุณเปลี่ยนได้ พร้อมค่าเริ่มต้น มีดังนี้

| คำสั่ง | ค่าเริ่มต้น |
| --- | --- |
| ตัวหนา | `⌘B` |
| ตัวเน้น | `⌘I` |
| โค้ดแบบแทรกในบรรทัด | `⌃`` ` `` |
| สูตรคณิตศาสตร์แบบอินไลน์ | `⌃M` |
| ขีดทับ | `⌃⇧`` ` `` |
| ไฮเปอร์ลิงก์ | `⌘K` |
| ล้างการจัดรูปแบบ | `⌘\` |
| เปิด/ปิดแถบด้านข้าง | `⇧⌘L` |
| แถบด้านข้าง: เค้าร่าง | `⌃⌘1` |
| เอกสารที่เปิดอยู่ | `⌃⌘2` |
| แถบด้านข้าง: แผนผังไฟล์ | `⌃⌘3` |
| แถบด้านข้าง: ค้นหา | `⇧⌘F` |
| แถบด้านข้าง: ผู้ช่วย | `⌃⌘4` |
| เพิ่มเคอร์เซอร์ด้านบน | `⌃⇧↑` |
| เพิ่มเคอร์เซอร์ด้านล่าง | `⌃⇧↓` |
| เคอร์เซอร์ในคอลัมน์… | `⌃⇧G` |
| ย้อนกลับ | `⌃⌘←` |
| ไปข้างหน้า | `⌃⌘→` |
| เลือกตำแหน่งที่พบถัดไป | `⌃⌥D` |
| เลือกทุกตำแหน่งที่พบ | `⌃⌥⇧D` |
| ฟิลด์ถัดไป | `⌥Tab` |
| ฟิลด์ก่อนหน้า | `⌥⇧Tab` |
| คำสั่งด่วน… | `⌃⇧P` |
| โหมดโฟกัส | ไม่มี |

คำสั่งที่ไม่อยู่ในรายการนี้ เช่น บันทึก ค้นหา และรายการภายใต้ย่อหน้า มีคำสั่งลัดแบบตายตัว บทที่ 77 รวบรวมคำสั่งลัดทั้งหมดไว้

# Chapter 73: การสมัครสมาชิกและเครดิต

ทุกฟีเจอร์ใน Pilcrow ใช้ได้ฟรี การสนับสนุน Pilcrow เป็นทางเลือก ช่วยสมทบค่าพัฒนา และให้คะแนนโหวตแก่คุณเพื่อเลือกสิ่งที่จะสร้างต่อไป คะแนนโหวตช่วยกำหนดลำดับงาน แต่ไม่ได้รับประกันว่าจะมีฟีเจอร์ใดเกิดขึ้น

หน้า **สนับสนุน Pilcrow** มีดังนี้

| ส่วน | แสดงหรือทำอะไร |
| --- | --- |
| **คะแนนโหวตของคุณ** | **จากการสมัครสมาชิกของคุณ** (คะแนนโหวตของเดือนที่ชำระเงินนี้ พร้อมวันหมดอายุ) และ **ที่ซื้อ** (คะแนนโหวตที่ไม่มีวันหมดอายุ) ระบบใช้คะแนนโหวตจากการสมัครสมาชิกก่อน และจะหมดอายุเมื่อสิ้นสุดเดือนที่ชำระเงิน |
| **รับคะแนนโหวต** | การสมัครสมาชิกและคะแนนโหวตเดี่ยวที่คุณซื้อได้ Pilcrow Supporter ต่ออายุทุกเดือนจนกว่าคุณจะยกเลิกในการตั้งค่า Apple Account ของคุณ ทุกเดือนที่ชำระเงินจะได้รับคะแนนโหวต |
| **กู้คืนการซื้อ** | นำการซื้อที่ทำไว้บนอุปกรณ์เครื่องอื่นกลับมา |
| **ข้อกำหนดการใช้งาน**, **นโยบายความเป็นส่วนตัว** | ลิงก์ |
| **ไอคอนแอป** | ตัวเลือกไอคอนแอปสำหรับผู้สมัครสมาชิก ไอคอนของรอบโหวตจะได้รับโดยการสมัครสมาชิกในช่วงรอบนั้น และเก็บไว้ได้ตลอด บน Mac ไอคอนใน Dock จะเปลี่ยนขณะที่ Pilcrow เปิดอยู่ |
| **แผนงาน** | รอบปัจจุบันของฟีเจอร์ที่เปิดให้โหวต พร้อมจำนวน “คะแนนโหวต” และ “ของคุณ” และปุ่ม **โหวต** ของแต่ละรายการ การโหวตแต่ละครั้งใช้คะแนนโหวตของคุณหนึ่งคะแนนและเรียกคืนไม่ได้ ระหว่างรอบ หน้านี้จะบอกว่ารอบถัดไปจะเปิดเมื่อใด |

หากตัวเลือกการสนับสนุนไม่พร้อมใช้งานในบิลด์ใดบิลด์หนึ่ง หน้านี้จะแจ้งไว้
