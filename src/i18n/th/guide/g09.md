# Chapter 65: แผงผู้ช่วยและการตรวจทานสไตล์

แผงผู้ช่วยจะปรากฏหลังจากตั้งค่าการเชื่อมต่อใน **การตั้งค่า ▸ ผู้ช่วย** (บทที่ 67) ขณะที่ยังไม่มีการเชื่อมต่อที่พร้อมใช้งาน รายการ **ผู้ช่วย** จะไม่อยู่ในเมนูมุมมอง

## แผง

| ตัวควบคุม | หน้าที่ |
| --- | --- |
| **โหมดผู้ช่วย** | **สนทนา**, **ตรวจทานสไตล์** หรือ **วิธีใช้** |
| **เลือกโมเดล…** | เปิดตัวเลือกโมเดล (ด้านล่าง) แสดงคำเตือนเมื่อโมเดลไม่พร้อมใช้งานอีกต่อไปหรือเลิกใช้แล้ว พร้อมวันที่ยุติการให้บริการ |
| **ล้างการสนทนา** | ล้างการสนทนาให้ว่าง การสนทนาจะไม่ถูกบันทึก และจะถูกทิ้งเมื่อออกจากแอป |
| **สิ่งที่จะแชร์** | เลือกสิ่งที่จะส่งไปพร้อมกับคำถามของคุณ: **ไม่มีอะไรจากเอกสาร**, **ส่วนที่เลือก**, **ส่วน**, **รอบเคอร์เซอร์**, **ทั้งเอกสาร**, **เค้าร่าง** หรือ **โปรไฟล์** ตัวเลือกที่ใช้ไม่ได้จะบอกเหตุผล ("เลือกข้อความก่อน", "เอกสารนี้ไม่มีหัวเรื่อง", "ใหญ่เกินกว่าจะส่งทั้งหมด", "ไม่มีโปรไฟล์ไวยากรณ์") บรรทัดเหนือช่องคำถามบอกว่าจะส่งข้อมูลเท่าใดและไปยังโฮสต์ใด ตัวเลือกของคุณจะถูกจดจำไว้ |
| **ตัวอย่าง** (และ **สิ่งที่ส่ง**) | แสดงสิ่งที่จะถูกส่งอย่างแน่ชัด |
| **ถามผู้ช่วย…** / **อธิบายสิ่งที่คุณต้องการเขียน** | ช่องคำถาม ในโหมด **วิธีใช้** นั้น **สิ่งที่จะเขียน** ให้เลือก **โปรไฟล์ไวยากรณ์**, **มาโคร** หรือ **คู่มือสไตล์** |
| **ส่ง** และ **หยุด** | ส่งคำขอ หรือหยุดคำตอบที่กำลังแสดงอยู่ |
| **ความเป็นส่วนตัว** | แสดงว่าผู้ช่วยเปิดอยู่สำหรับโฟลเดอร์นี้หรือไม่ **ปิดสำหรับโฟลเดอร์นี้** และ **เปิดสำหรับโฟลเดอร์นี้** ใช้สลับสถานะ ข้อความ "ไฟล์นี้ถูกยกเว้นจากผู้ช่วย" จะปรากฏกับไฟล์ที่ตรงกับรายการยกเว้น |
| คำตอบแต่ละรายการ | **คัดลอก**, **แทรกที่เคอร์เซอร์**, **ลองอีกครั้ง** และสำหรับคำตอบที่เป็นสไตล์หรือมาโครมี **เพิ่มลงในคลัง…** คำตอบที่มีข้อผิดพลาดจะมี **ขอให้แก้ไข** คำตอบที่ถูกตัดสั้นจะบอกไว้ |

## เลือกโมเดล

**เลือกโมเดล…** แสดงรายการโมเดลที่การเชื่อมต่อมีให้ พร้อม **ค้นหาโมเดล** **แสดงโมเดลทั้งหมด** จะรวมโมเดลที่พบน้อยกว่าด้วย โมเดลที่เลิกใช้แล้วจะมีเครื่องหมายพร้อมวันที่ยุติการให้บริการ หากไม่มีรายการใดเลย ให้พิมพ์ชื่อโมเดลแทน **ลองอีกครั้ง** จะโหลดรายการซ้ำ

## ตรวจทานสไตล์

ในโหมด **ตรวจทานสไตล์** แผงจะใช้คู่มือสไตล์ตรวจงานเขียนของคุณ

| ตัวควบคุม | หน้าที่ |
| --- | --- |
| **คู่มือสไตล์**, **ตัวแปร** | เลือกคู่มือและหนึ่งในตัวแปรของคู่มือนั้น |
| **สิ่งที่จะตรวจทาน** | **ส่วนที่เลือก** หรือ **เอกสาร** เอกสารที่ใหญ่เกินกว่าจะตรวจทานทั้งหมดจะแสดงว่า "ใหญ่เกินกว่าจะตรวจทานทั้งหมด ให้ตรวจทานทีละส่วนแทน" |
| **พื้นที่** | เลือกพื้นที่ที่จะตรวจ หรือ **ทุกพื้นที่** |
| **ตรวจทาน** | ส่งข้อความและกฎไปยังการเชื่อมต่อ AI ของคุณ ก่อนการตรวจทานทั้งเอกสาร การแจ้งเตือนจะบอกว่าจะส่งกี่คำขอและข้อความประมาณเท่าใด แล้วถามว่า **ตรวจทาน** หรือ **ยกเลิก** |
| **ตรวจที่นี่** | เรียกใช้การตรวจสอบของคู่มือเองบนอุปกรณ์นี้ ไม่มีการส่งข้อมูลใดออกไป |
| **ตรวจสอบการอ้างอิงโยง** | ส่งหัวเรื่อง บรรทัดที่อ้างถึง และรายการอ้างอิง เพื่อตรวจกฎที่เปรียบเทียบส่วนหนึ่งของเอกสารกับอีกส่วนหนึ่ง |
| **หยุด** | หยุดการตรวจทานที่กำลังทำอยู่ **ตรวจทานส่วนที่เหลือ** จะทำต่อหลังจากหยุดหรือล้มเหลว |

ผลการตรวจพบจะแสดงเป็นรายการ แต่ละรายการแสดงข้อความที่ยกมา คำอธิบาย และวิธีแก้ที่แนะนำ (ถ้ามี)

| ปุ่ม | หน้าที่ |
| --- | --- |
| **ข้ามไปที่** | ไปยังจุดที่พบในเอกสาร ข้อความที่ยกมาซึ่งปรากฏมากกว่าหนึ่งครั้งจะแสดง "ตรงกัน N จาก N" |
| **นำไปใช้** | ทำตามวิธีแก้ที่แนะนำ จะใช้ได้ก็ต่อเมื่อข้อความยังเหมือนตอนที่พบทุกประการ มิฉะนั้นจะแสดงว่า "ข้อความมีการเปลี่ยนแปลง" หรือ "ไม่พบในข้อความ" |
| **ปิดทิ้ง** | ลบรายการที่พบนั้นออก |
| **ใช้ทั้งหมด** | ทำตามวิธีแก้ทุกรายการที่มี หลังการยืนยันที่บอกจำนวน โดยเป็นการเปลี่ยนแปลงครั้งเดียวที่ย้อนกลับได้ในขั้นตอนเดียว และบอกด้วยว่ามีกี่วิธีแก้ที่มาจาก AI |
| **ปิดทิ้งข้อเสนอแนะทั้งหมด**, **ล้าง** | ล้างรายการ |

แผงยังรายงานว่า "N กฎที่ตัดสินได้ด้วยการตรวจทานเท่านั้น", "N กฎหยุดหลังพบ 100 รายการ" และ "ข้อเสนอแนะการเปลี่ยนแปลงหนึ่งรายการถูกตัดออก เพราะเพิ่มข้อเท็จจริงที่ข้อความไม่มี"

# Part XVIII — ข้อมูลอ้างอิงการตั้งค่า

# Chapter 66: การจัดระเบียบการตั้งค่า

เปิดการตั้งค่าจาก **Pilcrow ▸ การตั้งค่า…** (`⌘,`) บน Mac หรือจากไอคอนเฟืองในส่วนหัวบน iPad ซึ่งจะเปิดเป็นชีตพร้อมปุ่ม **เสร็จสิ้น** หน้าต่างมีช่อง **ค้นหาการตั้งค่า** และรายการ **หมวดหมู่** ทางซ้าย แต่ละหมวดหมู่มีหนึ่งหน้าหรือมากกว่า แสดงเป็นแถบปุ่มด้านบน

| หมวดหมู่ | หน้า |
| --- | --- |
| **ทั่วไป** | ภาษาและหน้าต่าง (iPad: **ภาษา**), ไฟล์, การแปล, ผู้ช่วย, การวินิจฉัย, พื้นที่จัดเก็บและความเป็นส่วนตัว |
| **การแก้ไข** | การแสดงผลและการพิมพ์, รูปภาพ |
| **รูปลักษณ์** | ธีมและฉากหลัง, ขนาดข้อความและฟอนต์ |
| **สารบัญ** | สารบัญและป้ายกำกับ |
| **ส่งออก** | ค่าเริ่มต้นการส่งออก |
| **คลัง** | โปรไฟล์ไวยากรณ์, ตัวเลือก CommonMark, ธีม, มาโคร, คู่มือสไตล์, ไลบรารีการแสดงผล, ตำแหน่ง (iPad มี **นำเข้า** ด้วย) |
| **แป้นพิมพ์** | คำสั่งลัด |
| **การสมัครสมาชิกและเครดิต** | สนับสนุน Pilcrow |

**ค้นหาการตั้งค่า** ค้นหาตัวควบคุมตามชื่อ พิมพ์บางส่วนของป้ายกำกับ เช่น "ระยะห่างบรรทัด" หรือ "เวอร์ชัน" ผลลัพธ์จะแสดงตัวควบคุม หน้า และหมวดหมู่ของมัน เลือกรายการหนึ่งเพื่อไปที่นั่นทันที การเปลี่ยนแปลงมีผลทันที ไม่มีปุ่มบันทึก ยกเว้นในตัวแก้ไขของธีม โปรไฟล์ มาโคร และคำสั่งลัด

การตั้งค่าที่มีผลกับ Mac เครื่องเดียวหรือ iPad เครื่องเดียวจะอยู่บนอุปกรณ์นั้น คลังของคุณ (ธีม โปรไฟล์ มาโคร คู่มือสไตล์ และฉากหลัง) ย้ายไปยังโฟลเดอร์ที่คุณเลือกได้ รวมถึงโฟลเดอร์ใน iCloud Drive (บทที่ 71)

# Chapter 67: ทั่วไป

## ภาษาและหน้าต่าง

| ตัวควบคุม | หน้าที่ |
| --- | --- |
| **ภาษา** | เลือกภาษาของ Pilcrow โดยไม่ขึ้นกับภาษาของอุปกรณ์ **ค่าเริ่มต้นของระบบ** จะตามอุปกรณ์ ภาษาที่แปลด้วย AI จะแสดง "แปลด้วยเครื่อง — อาจมีข้อผิดพลาด" การเปลี่ยนแปลงจะมีผลเมื่อเปิด Pilcrow ครั้งถัดไป โดยบน Mac มีปุ่ม **ออกตอนนี้** |
| **แสดงประกาศการแปลเมื่อ Pilcrow เริ่มทำงาน** | เปิดประกาศ "แปลด้วย AI" อีกครั้งหลังจากที่คุณเลือก **ไม่ต้องแสดงอีก** |
| **ออกจาก Pilcrow เมื่อปิดหน้าต่างสุดท้าย** (Mac) | ออกจากแอปเมื่อคุณปิดหน้าต่างสุดท้าย แทนที่จะปล่อยให้ทำงานต่อ |

## ไฟล์

| ตัวควบคุม | หน้าที่ |
| --- | --- |
| **เมื่อเริ่มต้น** | สิ่งที่ Pilcrow เปิดเมื่อเริ่มทำงาน: **เปิดไฟล์ใหม่**, **กู้คืนโฟลเดอร์ที่ปิดล่าสุด**, **กู้คืนไฟล์และโฟลเดอร์ที่ปิดล่าสุด** หรือ **เปิดโฟลเดอร์ที่กำหนดเอง** (พร้อมปุ่ม **เลือก…**) การกู้คืนจะเปิดสิ่งที่อยู่บนหน้าจอเมื่อออกจากแอปครั้งล่าสุดอีกครั้ง ไฟล์ที่ถูกย้ายหรือลบไปแล้วจะถูกข้าม |
| **บันทึกเอกสารใหม่เป็น** | ประเภทไฟล์ และด้วยเหตุนี้คือโปรไฟล์ไวยากรณ์ ของเอกสารใหม่: แต่ละโปรไฟล์พร้อมนามสกุล เช่น "CommonMark (.md)" |
| **บันทึกการเปลี่ยนแปลงโดยอัตโนมัติ** | บันทึกเอกสารที่มีไฟล์ระหว่างที่คุณทำงาน |
| **บันทึกโดยไม่ถามเมื่อปิดไฟล์** | ข้ามคำถาม "ต้องการบันทึกหรือไม่" และบันทึกเลย |
| **เวอร์ชันที่จะเก็บ** | จำนวนเวอร์ชันที่บันทึกของแต่ละไฟล์ที่ Pilcrow เก็บไว้สำหรับประวัติเวอร์ชัน ตั้งแต่ไม่เก็บเลยถึง 500 ค่าเริ่มต้นคือ 50 "เวอร์ชันที่จะเก็บ: ไม่มี" จะปิดประวัติ |
| **บันทึกไฟล์และโฟลเดอร์ล่าสุด** | ให้ Pilcrow จดจำสิ่งที่คุณเปิด สำหรับ **เปิดล่าสุด** และสำหรับการกู้คืนเมื่อเริ่มทำงาน |
| **แสดงโฟลเดอร์และไฟล์ที่ซ่อนอยู่** | แสดงรายการที่ชื่อขึ้นต้นด้วยจุดในแผงไฟล์ |
| **เมื่อมีการวางบางสิ่งลงบนแอป** | สิ่งที่เกิดขึ้นเมื่อคุณวางลงบนตัวแก้ไขหรือแถบด้านข้าง: สำหรับ **โฟลเดอร์** หรือ **ไฟล์ Markdown** คือ **เปิดในตัวแก้ไข** หรือ **แทรกลิงก์** สำหรับ **ไฟล์ที่นำเข้าได้** (ธีม โปรไฟล์ไวยากรณ์ หรือคอลเลกชันมาโคร) คือ **เปิดในตัวแก้ไข**, **แทรกลิงก์** หรือ **ไฟล์ที่นำเข้า** |

## การแปล

การแปลต้องใช้ macOS 15 หรือ iPadOS 18 ขึ้นไป

| ตัวควบคุม | หน้าที่ |
| --- | --- |
| **แปลเป็น** | ภาษาเป้าหมายเริ่มต้นของคุณ ตัวเลือกแรกคือ "ภาษาของระบบ" |
| **ความเร็ว** | **เร็ว**, **คุณภาพดีที่สุด** หรือ **ผู้ช่วย AI** โหมดเร็วเหมาะกับเอกสารยาวและเร็วกว่าได้ประมาณยี่สิบเท่า แต่ถ้อยคำจะเรียบง่ายกว่า ต้องใช้ macOS หรือ iPadOS 26.4 ส่วน **ผู้ช่วย AI** จะส่งข้อความไปยังการเชื่อมต่อของคุณจาก **การตั้งค่า ▸ ผู้ช่วย** ผู้ให้บริการอาจคิดค่าใช้จ่าย และข้อความจะออกจากอุปกรณ์ |
| **เมื่อไฟล์เป็นภาษาอื่น** | **ไม่ทำอะไร**, **เสนอให้แปล** หรือ **แปลอัตโนมัติ** Pilcrow ตรวจภาษาของไฟล์เมื่อคุณเปิด และไม่มีสิ่งใดออกจากอุปกรณ์เพื่อการนี้ ข้อเสนอจะแสดงแถบที่มีตัวเลือกให้แปลเป็นภาษาเริ่มต้นของคุณ |
| **เสนออีกครั้งสำหรับทุกไฟล์** | ล้างไฟล์ที่คุณตั้งเป็น **ไม่ใช้กับไฟล์นี้** |
| **หลังการแปล** | **เปิดในแท็บใหม่**, **บันทึกสำเนาไว้ข้างต้นฉบับ** (ตั้งชื่อเหมือนต้นฉบับโดยเติมภาษาต่อท้าย เช่น `Notes_fr.md`) หรือ **แทนที่เอกสาร** (ย้อนกลับได้) |
| **ภาษาบนอุปกรณ์นี้** | แสดงแต่ละภาษาพร้อม **บนอุปกรณ์นี้**, **ดาวน์โหลด** หรือ **ไม่พร้อมใช้งาน** การแปลใช้ชุดภาษาที่อยู่บนอุปกรณ์ การดาวน์โหลดจะขออนุญาตจากระบบ ส่วนการลบทำได้ในการตั้งค่าภาษาของระบบ |

## ผู้ช่วย

| ตัวควบคุม | หน้าที่ |
| --- | --- |
| **เปิดใช้ผู้ช่วย AI** | เพิ่มแผงผู้ช่วยในแถบด้านข้าง จะไม่มีสิ่งใดถูกส่งจนกว่าคุณจะถาม และส่งเฉพาะข้อความที่คุณเลือกแชร์ |
| บรรทัดสถานะ | **พร้อมแล้ว** หรือเหตุผลที่ยังไม่พร้อม: "ที่อยู่ของการเชื่อมต่อที่ใช้งานอยู่ใช้ไม่ได้", "การเชื่อมต่อที่ใช้งานอยู่ต้องใช้คีย์ API" หรือ "เพิ่มการเชื่อมต่อด้านล่าง แผงผู้ช่วยจะปรากฏเมื่อมีการเชื่อมต่อที่พร้อมใช้งาน" |
| **การเชื่อมต่อ** | รายการการเชื่อมต่อ โดยแสดง "ยังไม่มีการเชื่อมต่อ" เมื่อว่าง แต่ละรายการแสดงชื่อ และสำหรับรายการที่ใช้อยู่จะแสดง **ใช้งานอยู่** แถวหนึ่งมี **ตั้งเป็นที่ใช้งาน**, **แก้ไข…** และ **ลบออก** |
| **เพิ่มการเชื่อมต่อ** | เมนู: **OpenAI**, **Anthropic**, **OpenRouter**, **Ollama (คอมพิวเตอร์เครื่องนี้)**, **LM Studio (คอมพิวเตอร์เครื่องนี้)** หรือ **กำหนดเอง…** |
| **ไฟล์ที่ยกเว้น** | รูปแบบของไฟล์ที่จะไม่ถูกแชร์เลย `*` แทนอักขระใดก็ได้ในชื่อ `**` แทนโฟลเดอร์ใดก็ได้ และชื่อที่ลงท้ายด้วย `/` ครอบคลุมทั้งโฟลเดอร์ ค่าเริ่มต้นรวมถึง `*.pem`, `.env*`, `*.key` และ `secrets/` **เพิ่ม** รูปแบบ, **ลบออก** รูปแบบ หรือ **คืนค่าเริ่มต้น** |
| **ปิดโฟลเดอร์แล้ว** | แสดงโฟลเดอร์ที่คุณปิดผู้ช่วย แต่ละรายการมี **เปิด** แสดง "ไม่มีโฟลเดอร์ที่ปิดอยู่" เมื่อไม่มี |
| **ความเป็นส่วนตัว** | ลิงก์สำหรับอ่านนโยบายความเป็นส่วนตัวของ Pilcrow และ **ลบข้อมูล AI ทั้งหมด…** ซึ่งลบทุกการเชื่อมต่อและคีย์ที่บันทึกไว้ การสนทนา และตัวเลือกความเป็นส่วนตัวของคุณ แล้วปิดผู้ช่วย โดยจะถามก่อน |

คีย์ API ของคุณถูกเก็บไว้ใน Keychain บนอุปกรณ์นี้เท่านั้น

**เพิ่มการเชื่อมต่อ** และ **แก้ไข…** เปิดแบบฟอร์ม

| ฟิลด์ | หน้าที่ |
| --- | --- |

| **อนุญาตการเชื่อมต่อที่ไม่เข้ารหัสบนเครือข่ายภายในของฉัน** | อนุญาตที่อยู่ `http://` บนเครือข่ายของคุณ ข้อความและคีย์ของคุณจะถูกส่งแบบไม่เข้ารหัส จึงควรอนุญาตเฉพาะเมื่อคุณไว้ใจเครือข่าย |

| **ทดสอบการเชื่อมต่อ** | ตรวจสอบที่อยู่ คีย์ และโมเดล แสดง "กำลังทดสอบ…" แล้วจึง "เชื่อมต่อแล้ว (N ms)" |
| **ยกเลิก**, **บันทึก** | ปิดหรือเก็บการเชื่อมต่อ |

## การวินิจฉัย

| ตัวควบคุม | หน้าที่ |
| --- | --- |
| **บันทึกการวินิจฉัย** | บันทึกสิ่งที่ Pilcrow กำลังทำ เพื่อให้คุณส่งให้ฝ่ายสนับสนุนเมื่อมีสิ่งผิดปกติ ข้อมูลจะอยู่บนอุปกรณ์จนกว่าคุณจะแชร์ และออกแบบมาให้ไม่รวมข้อความในเอกสารและชื่อไฟล์ของคุณ ขณะเปิดอยู่ เครื่องหมายสีแดง **กำลังบันทึกข้อมูล** จะแสดงในแถบสถานะ |
| **หยุดบันทึกหลังจาก** | **1 ชั่วโมง**, **24 ชั่วโมง** หรือ **ไม่เลย** |
| **สิ่งที่จะบันทึก** | ระดับสำหรับแต่ละส่วนของ Pilcrow: **ตัวแก้ไขข้อความ**, **มาโคร**, **ธีม**, **การแยกวิเคราะห์และโปรไฟล์**, **การแสดงผลและแผนภาพ**, **ส่งออกและพิมพ์**, **ไฟล์และคลัง** และ **แอป** แต่ละส่วนเป็น **เฉพาะปัญหา**, **ปกติ**, **ละเอียด** หรือ **ทุกอย่าง** ปัญหาและข้อผิดพลาดจะถูกเก็บไว้เสมอ |
| **สร้างปัญหาซ้ำ** | ตั้งทุกส่วนเป็นละเอียดและเริ่มบันทึก ทำให้ปัญหาเกิดขึ้นอีกครั้ง แล้วจึงสรุปรายงานให้เสร็จ |
| **เพิ่มบันทึก** | เมื่อคุณรายงานข้อบกพร่อง: **ถามทุกครั้ง**, **เพิ่มทุกครั้ง** หรือ **ไม่เพิ่มเลย** รายการล่าสุดของบันทึกไปยังคลิปบอร์ดของคุณเพื่อวางลงในแบบฟอร์ม |
| **รายงานข้อบกพร่อง…** | เหมือน **วิธีใช้ ▸ รายงานข้อบกพร่อง…** |
| **รวมในรายงาน** | สวิตช์สำหรับ **ข้อมูลอุปกรณ์และระบบ**, **การตั้งค่า Pilcrow**, **โครงสร้างเอกสาร (เฉพาะจำนวน)**, **ความเร็วและหน่วยความจำ**, **ร่องรอยการดำเนินการล่าสุด** และ **รายละเอียดการขัดข้อง** โครงสร้างเอกสารคือจำนวนหัวเรื่อง ตาราง และอื่นๆ ที่เอกสารมี โดยไม่รวมถ้อยคำของเอกสารเลย จะไม่มีสิ่งใดถูกส่งจากหน้าจอนี้ |

ขณะที่คุณกำลังบันทึกบันทึกสำหรับรายงานข้อบกพร่อง **กำลังทำซ้ำ — เสร็จสิ้นรายงาน** (หรือ **เสร็จสิ้นรายงานข้อบกพร่อง** ในเมนูวิธีใช้) จะหยุดการบันทึกและสรุปรายงาน ในกรณีนั้นการบันทึกจะหยุดเองหลัง 30 นาที

### ตัวดูบันทึก

**บันทึกการวินิจฉัย** แสดงสรุป (**รายการ**, **เซสชัน**, **ข้อผิดพลาด**, **คำเตือน**, **รายงานการขัดข้อง** และช่วงวันที่) จากนั้นเป็นรายการ โดยล่าสุดอยู่บนสุด พร้อมช่อง **ค้นหาในบันทึก** และตัวกรอง **ส่วน** และ **ระดับ** ตัวกรองเปลี่ยนเฉพาะสิ่งที่คุณเห็น ไม่ใช่สิ่งที่ส่ง รายงานมีทุกรายการในบันทึกบวกสิ่งที่คุณเลือกไว้ใน รวมในรายงาน **โหลดซ้ำ** จะรีเฟรช **ส่งรายงาน** มีให้เลือก:

| รายการ | หน้าที่ |
| --- | --- |
| **บันทึกรายงาน…** | เก็บไฟล์ที่คุณส่งเองได้ |
| **แชร์รายงาน…** | เปิดชีตการแชร์ (AirDrop, ไฟล์ และอื่นๆ) |
| **รายงานบน GitHub…** | เปิด issue ใหม่พร้อมสรุปสั้นๆ คุณเลือก **เพิ่มบันทึกลงในคำอธิบาย** (รายการล่าสุด สูงสุด 60,000 อักขระ ซึ่งเป็นขีดจำกัดของ GitHub คัดลอกไปยังคลิปบอร์ดของคุณเพื่อวาง) หรือ **บันทึกและแนบไฟล์** (บันทึกทั้งหมด ในไฟล์ที่คุณเพิ่มเอง) รายงานบน GitHub เป็นสาธารณะ |

เมื่อคุณเริ่มรายงานโดยยังไม่มีสิ่งใดถูกบันทึก Pilcrow จะถาม **บันทึกปัญหาก่อนหรือไม่**: **บันทึกปัญหาก่อน**, **รายงานทันที** หรือ **ยกเลิก** เมื่อเปิดแบบฟอร์ม จะถามว่าจะ **เพิ่มบันทึกและเปิดแบบฟอร์ม**, **เพิ่มบันทึกทุกครั้ง** หรือ **เปิดแบบฟอร์มโดยไม่มีบันทึก**

## พื้นที่จัดเก็บและความเป็นส่วนตัว

Pilcrow เก็บสำเนากู้คืน ประวัติ สิทธิ์เข้าถึง และข้อมูลการสนับสนุนไว้ในแซนด์บอกซ์ของตัวเอง แต่ละหมวดลบแยกกันได้ ตัวควบคุมเหล่านี้จะไม่ลบเอกสารของคุณ

| ส่วน | ตัวควบคุม |
| --- | --- |
| **เอกสาร** | **ตรวจดูข้อมูลกู้คืน** และ **ตรวจดูประวัติเวอร์ชัน** การตรวจดูจะแสดงรายการที่เกี่ยวข้องพร้อมขนาด เพื่อให้คุณเห็นพื้นที่ก่อนลบสิ่งใด ทำเครื่องหมายรายการที่จะลบ (**เลือกทั้งหมด** หรือ **ไม่เลือกเลย**) แล้วเลือก **ลบรายการที่เลือก** ไม่สามารถตรวจดูข้อมูลกู้คืนได้ขณะที่เอกสารมีการเปลี่ยนแปลงที่ยังไม่ได้บันทึก: ให้บันทึกหรือปิดเอกสารก่อน |
| **การเข้าถึงไฟล์** | **ล้างสิทธิ์เข้าถึงไฟล์ล่าสุด…** ลบรายการไฟล์ล่าสุด โฟลเดอร์บันทึกเป็นที่จดจำไว้ บุ๊กมาร์กของเซสชัน และตัวเลือกไวยากรณ์รายไฟล์ |
| **ข้อมูลส่วนตัวและข้อมูลการสนับสนุน** | **ลบข้อมูลและคีย์ AI…** (การเชื่อมต่อ คีย์ใน Keychain การสนทนาปัจจุบัน และตัวเลือกความเป็นส่วนตัวของ AI), **ลบข้อมูลวินิจฉัย…** (บันทึกที่บันทึกไว้และข้อมูลวินิจฉัยการขัดข้องที่บันทึกไว้) และ **ล้างแคช…** (ไฟล์แคชและการตอบสนองของเครือข่ายที่สร้างใหม่ได้) |

ทุกการลบจะถามยืนยัน ("ไม่สามารถย้อนกลับได้ เอกสารของคุณจะไม่ถูกลบ") โปรไฟล์ไวยากรณ์ ธีม มาโคร คู่มือสไตล์ และฉากหลังที่กำหนดเองจะไม่ถูกลบที่นี่ ให้ตรวจดูและลบในหน้าคลังของแต่ละรายการ
