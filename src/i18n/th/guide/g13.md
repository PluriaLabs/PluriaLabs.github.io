# Chapter 75: ตัวแก้ไขธีม

ธีมมีสองประเภท และแต่ละประเภทมีตัวแก้ไขของตัวเอง เปิดได้จาก **Settings ▸ Library ▸ Themes** (**การตั้งค่า ▸ คลัง ▸ ธีม**): **New** (**ใหม่**) สร้างธีม **Edit** (**แก้ไข**) เปลี่ยนธีมที่กำหนดเอง และ **Duplicate** (**ทำสำเนา**) คัดลอกธีมในตัวเพื่อให้คุณแก้ไขสำเนานั้นได้ ธีมในตัวไม่สามารถแก้ไขได้

## ตัวแก้ไขธีมการแสดงผล

**Edit Render Theme** (**แก้ไขธีมการแสดงผล**) กำหนดสไตล์ให้กับผลลัพธ์แบบ Preview, HTML, PDF, รูปภาพ และการพิมพ์ คุณสมบัติแบบกำหนดเองของ Pilcrow ยังใช้กำหนดสไตล์ของ Word ด้วย ธีมการแสดงผลไม่ได้กำหนดสไตล์ของแอปหรือตัวแก้ไข

| ส่วน | ทำอะไร |
| --- | --- |
| **Name** (**ชื่อ**) | ชื่อของธีม |
| **Appearance** (**รูปลักษณ์**) | **Automatic** (**อัตโนมัติ**), **Light** (**สว่าง**) หรือ **Dark** (**มืด**) |
| **CSS** | สไตล์ชีต ในตัวแก้ไขโค้ด ดูคุณสมบัติและคลาสในบทที่ 80 |
| **Rendered preview** (**ตัวอย่างที่แสดงผล**) | เอกสารตัวอย่างที่วาดด้วย CSS ของคุณขณะที่คุณพิมพ์ เพื่อให้เห็นผลทันที |
| **CSS diagnostics** (**การวินิจฉัย CSS**) | ปัญหาที่ Pilcrow พบใน CSS เช่น ทรัพยากรระยะไกลที่ไม่ได้รับอนุญาต |
| **Cancel** (**ยกเลิก**), **Save** (**บันทึก**) | ปิดหรือเก็บธีมไว้ การปิดทั้งที่มีการเปลี่ยนแปลงจะถามว่า **Discard theme changes?** (**ละทิ้งการเปลี่ยนแปลงธีมหรือไม่**) พร้อมตัวเลือก **Discard Changes** (**ละทิ้งการเปลี่ยนแปลง**) หรือ **Keep Editing** (**แก้ไขต่อ**) |
| **Baseline** (**เส้นฐาน**) | **Reset to Baseline** (**รีเซ็ตเป็นค่าพื้นฐาน**) ละทิ้งทุกการเปลี่ยนแปลงตั้งแต่สร้าง ทำสำเนา หรือนำเข้าธีม (หลังจากที่คุณยืนยัน) ส่วน **Set as New Baseline** (**ตั้งเป็นค่าพื้นฐานใหม่**) จะบันทึกธีมและทำให้สถานะปัจจุบันเป็นจุดกู้คืน |

## ตัวแก้ไขธีมแอปพลิเคชัน

**Edit Application Theme** (**แก้ไขธีมแอปพลิเคชัน**) กำหนดสไตล์ให้ตัว Pilcrow เอง ได้แก่ รูปลักษณ์ สีเน้น แถบด้านข้าง แถบต่าง ๆ และตัวแก้ไข

| ส่วน | ทำอะไร |
| --- | --- |
| **Name** (**ชื่อ**) | ชื่อของธีม |
| **Appearance** (**รูปลักษณ์**) | **Automatic** (**อัตโนมัติ**), **Light** (**สว่าง**) หรือ **Dark** (**มืด**) ธีมแบบอัตโนมัติมีสองชุดสี |
| **Editing colours for** (**กำลังแก้ไขสีสำหรับ**) | สำหรับธีมแบบอัตโนมัติ คือ **Light** (**สว่าง**) หรือ **Dark** (**มืด**): ชุดสีใดในสองชุดที่คุณกำลังแก้ไข |
| สี แบ่งเป็นห้ากลุ่ม | **App** (**แอป**) (สีเน้น), **Sidebar** (**แถบด้านข้าง**) (พื้นหลังและพื้นหน้า), **Status and formatting bars** (**แถบสถานะและแถบจัดรูปแบบ**) (พื้นหลังและพื้นหน้า), **Editor** (**ตัวแก้ไข**) (พื้นหลัง พื้นหน้า เคอร์เซอร์ ส่วนที่เลือก พื้นหลังของคอลัมน์หมายเลขบรรทัด พื้นหน้าของคอลัมน์หมายเลขบรรทัด **Current-Line Rule** (**กฎบรรทัดปัจจุบัน**)) และ **Syntax** (**ไวยากรณ์**) (หัวเรื่อง เครื่องหมาย โค้ด ลิงก์ สีจาง และคีย์เวิร์ด สตริง ตัวเลข และคอมเมนต์ของโค้ด) แต่ละสีจะแสดง **Default** (**ค่าเริ่มต้น**) จนกว่าคุณจะตั้งค่า และปุ่ม **Reset** (**รีเซ็ต**) จะคืนสีนั้นกลับ |
| **Preview** (**ตัวอย่าง**) | Pilcrow ขนาดย่อ ประกอบด้วยแถบด้านข้าง ตัวแก้ไข และแถบสถานะ ในสีที่คุณเลือก ทั้งแบบสว่างหรือมืด |
| **Cancel** (**ยกเลิก**), **Save** (**บันทึก**), **Baseline** (**เส้นฐาน**) | เหมือนข้างต้น |

ธีมอาจกำหนดสีให้กับโทเค็นไวยากรณ์แต่ละตัวได้ด้วย สีเหล่านั้นจะถูกเก็บไว้ แต่แก้ไขได้ในไฟล์ JSON ของธีม (`syntax.tokens`) ดูบทที่ 79

# Chapter 76: ตัวแก้ไขมาโคร

เปิดตัวแก้ไขมาโครจาก **Settings ▸ Library ▸ Macros** (**การตั้งค่า ▸ คลัง ▸ มาโคร**): **New** (**ใหม่**) ภายในคอลเลกชัน หรือ **Edit** (**แก้ไข**) บนมาโคร ชื่อหน้าต่างคือ **New Macro** (**มาโครใหม่**) หรือ **Edit Macro** (**แก้ไขมาโคร**)

| ฟิลด์ | ทำอะไร |
| --- | --- |
| **Name** (**ชื่อ**) | ป้ายชื่อของมาโคร |
| **Trigger** (**ทริกเกอร์**) (เช่น `/sig`) | ข้อความที่เริ่มมาโคร มาโครจะขยายเมื่อคุณพิมพ์ทริกเกอร์ตามด้วยช่องว่าง แท็บ หรือ return |
| **Match** (**ตรงกัน**) | วิธีอ่านทริกเกอร์: **Exact text** (**ข้อความที่ตรงกันทุกตัวอักษร**), **Prefix** (**คำนำหน้า**) หรือ **Regular expression** (**นิพจน์ทั่วไป**) นิพจน์ทั่วไปที่อาจทำให้ตัวแก้ไขค้างจะถูกปฏิเสธ: "นิพจน์ทั่วไปนี้อาจทำให้ตัวแก้ไขค้าง โปรดทำให้ง่ายขึ้น" |
| **Replacement** (**ข้อความแทนที่**) | ข้อความที่มาโครขยายออกมา |
| **Insert Date/Time** (**แทรกวันที่/เวลา**) | เมนูที่เพิ่มโทเค็นวันที่หรือเวลาลงในข้อความแทนที่ |
| **Enabled** (**เปิดใช้งาน**) | เปิดหรือปิดมาโครโดยไม่ต้องลบ |
| **Don't expand inside code** (**ไม่ขยายภายในโค้ด**) | หยุดมาโครไม่ให้ทำงานภายในโค้ดแบบแทรกในบรรทัดและบล็อกโค้ด |
| **Cancel** (**ยกเลิก**), **Save** (**บันทึก**) | ปิดหรือเก็บมาโครไว้ ถ้าบันทึกไม่ได้ ข้อความจะบอกเหตุผล |

ในข้อความแทนที่ `$1`, `$2` และต่อ ๆ ไปคือจุดหยุดด้วยแท็บ และ `$0` คือตำแหน่งที่เคอร์เซอร์จะไปอยู่ หลังจากมาโครขยายแล้ว Tab (หรือ **Next Field** (**ฟิลด์ถัดไป**)) จะข้ามจากจุดหยุดหนึ่งไปอีกจุดหนึ่ง วันที่และเวลาใช้โทเค็น: `{{date:yyyy-MM-dd}}`, `{{time:HH:mm:ss}}` และ `{{datetime:MM/dd/yyyy h:mm a}}` และรูปแบบที่มีชื่อ `iso8601`, `rfc2822`, `unix`, `short`, `medium`, `long` และ `full` บรรทัด **Now:** ใต้ฟิลด์จะแสดงสิ่งที่ข้อความแทนที่จะสร้างขึ้น ณ ขณะนี้

# Chapter 78: การใช้ Pilcrow บน iPad

Pilcrow ทำงานบน iPadOS 17 ขึ้นไป ใช้ได้ทั้งแบบสัมผัสอย่างเดียว กับแป้นพิมพ์ฮาร์ดแวร์ และกับแทร็กแพดหรือเมาส์

## การสัมผัส

- **Pane divider** (**ตัวแบ่งบานหน้าต่าง**) ในโหมด Side by Side (เคียงข้างกัน) ลากตัวแบ่งระหว่างต้นฉบับกับตัวอย่างเพื่อปรับขนาด แตะสองครั้งเพื่อรีเซ็ต
- **Navigator** (**ตัวนำทาง**) ลากขอบของแถบด้านข้างเพื่อปรับขนาด ในหน้าต่างแคบ แถบด้านข้างจะทับเอกสาร และปุ่ม **Done** (**เสร็จสิ้น**) จะปิดแถบนั้น
- **Column selection** (**การเลือกคอลัมน์**) เปิด **More ▸ Column Selection** (**เพิ่มเติม ▸ การเลือกคอลัมน์**) แล้วลากด้วยนิ้วเดียวเพื่อเลือกข้อความเป็นสี่เหลี่ยมผืนผ้า สองนิ้วยังคงเลื่อนหน้าได้ ป้าย **Column Selection** จะแสดงขณะที่เปิดอยู่ พร้อมปุ่มปิด หรือใช้ **More ▸ Carets in a Column…** (**เพิ่มเติม ▸ เคอร์เซอร์ในคอลัมน์…**) เพื่อวางเคอร์เซอร์ตามจำนวน
- **เมนูบริบท** กดค้างในข้อความเพื่อเรียกเมนูของตัวแก้ไข (ด้านล่าง)
- **ไฟล์** กดไฟล์ค้างในแผงไฟล์เพื่อเรียกเมนูของไฟล์ (บทที่ 60)

## เมื่อใช้แป้นพิมพ์ฮาร์ดแวร์

คำสั่งลัดทุกรายการในบทที่ 77 ใช้ได้ กด **⌘** ค้างไว้เพื่อดูแถบเมนูของ iPad หรือเลื่อนตัวชี้ไปที่ด้านบนของหน้าจอ Pilcrow ซ่อนเมนูส่วนหัวของตัวเองได้เมื่อเชื่อมต่อแป้นพิมพ์หรือเมาส์ ดู **Settings ▸ Appearance ▸ Menus in the Header** (**การตั้งค่า ▸ รูปลักษณ์ ▸ เมนูในส่วนหัว**)

## เมื่อใช้แทร็กแพดหรือเมาส์

คลิกขวาเพื่อเปิดเมนูบริบทของตัวแก้ไข กด **Option** ค้างไว้ขณะลากเพื่อเลือกข้อความเป็นสี่เหลี่ยมผืนผ้า

## เมนูบริบทของตัวแก้ไข

คลิกขวาบน Mac หรือกดค้างบน iPad ในข้อความ รายการที่โปรไฟล์ไวยากรณ์ที่ใช้งานอยู่ไม่รองรับจะเป็นสีเทา และระบบจะเพิ่มรายการของตัวเอง (ตัดออก คัดลอก วาง คำแนะนำการสะกด ค้นหา และอื่น ๆ)

บน **Mac**:

| รายการ | ทำอะไร |
| --- | --- |
| **Copy / Paste As…** | **Copy as Markdown** (**คัดลอกเป็น Markdown**), **Copy as Plain Text** (**คัดลอกเป็นข้อความธรรมดา**), **Copy as HTML Code** (**คัดลอกเป็นโค้ด HTML**), **Paste as Plain Text** (**วางเป็นข้อความธรรมดา**) |
| **Paragraph** (**ย่อหน้า**) | **Paragraph** (**ย่อหน้า**), **Heading 1** (**หัวเรื่อง 1**) ถึง **6**, **Blockquote** (**ข้อความอ้างอิง**), **Bulleted List** (**รายการสัญลักษณ์แสดงหัวข้อย่อย**), **Numbered List** (**รายการลำดับเลข**), **Task List** (**รายการงาน**), **Code Fence** (**รั้วโค้ด**) |
| **Format** (**รูปแบบ**) | **Strong** (**ตัวหนา**), **Emphasis** (**ตัวเน้น**), **Code** (**โค้ด**), **Strikethrough** (**ขีดทับ**), **Inline Math** (**สูตรคณิตศาสตร์แบบอินไลน์**), **Display Math** (**สมการแบบบล็อก**), **Diagram** (**แผนภาพ**), **Chart** (**แผนภูมิ**), **Hyperlink** (**ไฮเปอร์ลิงก์**) |
| **Selection** (**ส่วนที่เลือก**) | **Select Word** (**เลือกคำ**), **Select Line** (**เลือกบรรทัด**), **Select Paragraph** (**เลือกย่อหน้า**) |

บน **iPad** มีเมนูย่อยสามเมนูอยู่ร่วมกับรายการของระบบ:

| รายการ | ทำอะไร |
| --- | --- |
| **Format** (**รูปแบบ**) | สไตล์ในบรรทัด: ตัวหนา ตัวเน้น โค้ด และอื่น ๆ |
| **Paragraph** (**ย่อหน้า**) | ประเภทของย่อหน้า: หัวเรื่อง ข้อความอ้างอิง รายการ รั้วโค้ด |
| **Insert** (**แทรก**) | การแทรกชุดเดียวกับเมนู **More** (**เพิ่มเติม**) ของแถบเครื่องมือจัดรูปแบบ รวมถึง **Insert Alert** (**แทรกการแจ้งเตือน**), **Insert Image…** (**แทรกรูปภาพ…**) และ **Insert Table…** (**แทรกตาราง…**) และภายใต้ **Syntax** (**ไวยากรณ์**) คือโครงสร้างเฉพาะของโปรไฟล์ที่ใช้งานอยู่ |

## ความแตกต่างจาก Mac

| บน iPad | บน Mac |
| --- | --- |
| การตั้งค่าเปิดจากเฟืองในส่วนหัว ในชีต | **Pilcrow ▸ Settings…** (**การตั้งค่า…**) (`⌘,`) |
| ส่วนหัวแสดงเมนูของ Pilcrow เองได้ (**Menus in the Header**) | แถบเมนูเป็นของระบบ |
| **Interface Size** (**ขนาดส่วนติดต่อ**) กำหนดขนาดของเมนู แถบ และกล่องโต้ตอบ | **Not available** (**ไม่พร้อมใช้งาน**) |
| นำเข้าอยู่ใน **Settings ▸ Library ▸ Import** | **File ▸ Import** (**ไฟล์ ▸ นำเข้า**) |
| ไม่มี Save All, Duplicate, Move To, Reload from Disk, Show in Finder หรือ Page Setup | รายการเหล่านี้อยู่ในเมนู File |
| **Edit ▸ Spelling and Grammar** (**แก้ไข ▸ การสะกดและไวยากรณ์**) มีหนึ่งรายการ คือ **Check Spelling While Typing** (**ตรวจการสะกดขณะพิมพ์**) | **Edit ▸ Spelling and Grammar** มี **Show Spelling and Grammar** (**แสดงการสะกดและไวยากรณ์**) และ **Check Document Now** (**ตรวจสอบเอกสารตอนนี้**) ด้วย |
| เสียงการพิมพ์ถูกปิดโดยสวิตช์เงียบของ iPad | ไม่เกี่ยวข้อง |
