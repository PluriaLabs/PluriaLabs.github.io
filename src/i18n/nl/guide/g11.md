# Chapter 72: Toetsenbord

**Instellingen ▸ Toetsenbord ▸ Afkortingen** toont elke opdracht waarvan je de toetscombinatie kunt wijzigen, met de huidige toets.

| Bediening | Wat het doet |
| --- | --- |
| De rij van een opdracht | Klik erop, druk op de nieuwe toetscombinatie en kies dan **Bewaren**. **Ontkoppel** verwijdert de toetscombinatie. **Annuleer** behoudt de oude. Als de toetscombinatie al door een andere opdracht werd gebruikt, wordt die opdracht leeggemaakt en vertelt de pagina je welke. |
| **Super Tab-toetsen** | De toetsen voor **Volgend veld** en **Vorig veld**, waarmee je springt tussen de lege plekken die een macro achterlaat: `⌥Tab` en `⌥⇧Tab`, of `⌃⌘]` en `⌃⌘[`, of **Aangepast**. |
| **Alle toetscombinaties herstellen** | Herstelt alle standaardwaarden. |

De opdrachten die je kunt wijzigen, met hun standaardwaarden, zijn:

| Opdracht | Standaard |
| --- | --- |
| Vet | `⌘B` |
| Nadruk | `⌘I` |
| Inline code | `⌃`` ` `` |
| Inline-formule | `⌃M` |
| Doorhalen | `⌃⇧`` ` `` |
| Hyperlink | `⌘K` |
| Opmaak wissen | `⌘\` |
| Navigatiekolom tonen/verbergen | `⇧⌘L` |
| Zijbalk: Overzicht | `⌃⌘1` |
| Geopende documenten | `⌃⌘2` |
| Zijbalk: Bestandsboom | `⌃⌘3` |
| Zijbalk: Zoek | `⇧⌘F` |
| Zijbalk: Assistent | `⌃⌘4` |
| Cursor erboven toevoegen | `⌃⇧↑` |
| Cursor eronder toevoegen | `⌃⇧↓` |
| Cursors in een kolom… | `⌃⇧G` |
| Terug | `⌃⌘←` |
| Vooruit | `⌃⌘→` |
| Volgende voorkomen selecteren | `⌃⌥D` |
| Alle voorkomens selecteren | `⌃⌥⇧D` |
| Volgend veld | `⌥Tab` |
| Vorig veld | `⌥⇧Tab` |
| Opdrachtenpalet… | `⌃⇧P` |
| Focusmodus | geen |

Opdrachten die niet in deze lijst staan, zoals Bewaren, Zoek en de onderdelen van Alinea, hebben vaste toetscombinaties. Hoofdstuk 77 geeft een overzicht van alle toetscombinaties.

# Chapter 73: Abonnement en tegoed

Elke functie in Pilcrow is gratis. Pilcrow steunen is optioneel: het helpt de ontwikkeling te betalen en geeft je stemmen over wat er daarna wordt gebouwd. Stemmen bepalen de volgorde van het werk, maar beloven geen enkele functie.

De pagina **Steun Pilcrow** bevat:

| Onderdeel | Wat het toont of doet |
| --- | --- |
| **Je stemmen** | **Uit je abonnement** (de stemmen voor deze betaalde maand, met de datum waarop ze vervallen) en **Gekocht** (stemmen die nooit vervallen). Abonnementsstemmen worden het eerst gebruikt en vervallen aan het einde van de betaalde maand. |
| **Stemmen krijgen** | Het abonnement en de losse stemmen die je kunt kopen. Pilcrow Supporter wordt elke maand verlengd totdat je het opzegt in de instellingen van je Apple Account. Elke betaalde maand geeft je stemmen. |
| **Aankopen herstellen** | Haalt aankopen terug die op een ander apparaat zijn gedaan. |
| **Gebruiksvoorwaarden**, **Privacybeleid** | Koppelingen. |
| **Appicoon** | Een keuze uit appicoontjes voor abonnees. Icoontjes voor een stemronde verdien je door je tijdens die ronde te abonneren, en je houdt ze. Op de Mac verandert het icoon in het Dock terwijl Pilcrow geopend is. |
| **Roadmap** | De huidige ronde functies waarop gestemd kan worden, met de tellers “Stemmen” en “Van jou” en bij elke functie een knop **Stem**. Elke stem gebruikt een van je stemmen en kan niet worden teruggenomen. Tussen twee rondes staat er wanneer de volgende opent. |

Als ondersteuningsopties in een bepaalde versie niet beschikbaar zijn, staat dat op de pagina.
