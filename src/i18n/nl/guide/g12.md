# Part XIX — Editors voor bibliotheekitems

# Chapter 74: De profieleditor en de bouwstenen van een profiel

Een syntaxisprofiel vertelt Pilcrow wat jouw opmaak betekent. Dit hoofdstuk beschrijft de profieleditor bediening voor bediening en geeft daarna een overzicht van elke bouwsteen die een profiel kan gebruiken. Voor een inleiding aan de hand van taken, zie Hoofdstuk 37 tot en met Hoofdstuk 39.

Open de editor via **Instellingen ▸ Bibliotheek ▸ Syntaxisprofielen**: **Nieuw** begint een profiel, **Bewerk** wijzigt een aangepast profiel en **Dupliceer** kopieert een ingebouwd profiel zodat je de kopie kunt wijzigen. De titel van de editor is **Profiel bewerken**, met **Annuleer**, **Bewaren** en **Profielhulp** (die de naslag in de app over deze bouwstenen opent). Op een smal scherm kies je met een schakelaar **Profielsectie** tussen **Overzicht**, **Regels** en **Voorbeeldtekst**; op een breed scherm zie je alle drie tegelijk.

## Overzicht

| Veld | Wat het doet |
| --- | --- |
| **Naam** | De naam van het profiel, getoond in het menu van de statusbalk en in Instellingen. |
| **Beschrijving** | Een notitie over het profiel. |
| **Bestandsextensies (kommagescheiden)** | De extensies waarmee dit profiel voor een bestand wordt gekozen. Twee profielen kunnen geen extensie delen. |
| **Erft van** | **Geen**, of een ander profiel waarop de regels van dit profiel voortbouwen. |
| **Syntaxis** | **Breidt Markdown uit** of **Vervangt Markdown** (hieronder). |
| **In één oogopslag** | Aantallen **Blokregels**, **Inline-regels** en **Nestingsregels**. |
| **Geavanceerde JSON bewerken…** | Opent het profiel als JSON voor velden die de begeleide editor niet toont. **Pas toe** behoudt je JSON-wijzigingen; **Annuleer** gooit ze weg. |

**Breidt Markdown uit** voegt jouw regels toe aan die van Markdown: de koppen, lijsten, nadruk en de rest worden nog steeds gelezen, en jouw blok- en inline-regels komen erbij. Een regel die een ongewijzigde kopie is van een regel uit het CommonMark-profiel, beschrijft wat Markdown al doet en wordt aan Markdown overgelaten. **Vervangt Markdown** maakt jouw regels tot de hele syntaxis, zodat Markdown-constructies niet meer worden herkend. Daarbij moet één regel **Regeleinde** opleveren, anders worden alinea’s niet gescheiden. De editor waarschuwt “Voeg een regel toe waarvan het uitvoerknooppunt “newline” is, anders worden alinea’s niet gescheiden”, en het profiel kan pas worden bewaard als die er is. Ook staan er alle uitvoertypen in die het profiel niet definieert.

## Regels

Regels zijn er in drie groepen.

### Blokregels

Een blokregel herkent hele regels en blokken. **Regel toevoegen** voegt er een toe. Elke regel heeft een **Patroon**, een type **Overeenkomst**, wat hij **Levert**, en **Opties**. Een regel verwijder je met de knop **Verwijder**. Zonder regels staat er in de editor “Nog geen regels. Voeg er een toe om een blokconstructie te herkennen.”

### Inline-regels

Een inline-regel herkent tekst binnen een regel. **Inline-regel toevoegen** voegt er een toe. Inline-regels bieden vier typen overeenkomst (**Letterlijke prefix**, **Letterlijk exact**, **Regex (begrensd)** en **Scheidingstekenpaar**); blokregels bieden alle zeven.

### Nestingsregels

Nestingsregels bepalen welke uitvoer binnen welke andere mag staan. Elke regel heeft een **Bovenliggend knooppunt** en **Toegestane onderliggende knooppunten (gescheiden door komma’s)**. Leeg betekent onbeperkt: “Geen beperkingen. Elk knooppunttype mag binnen elk ander worden genest.” **Nestingsregel toevoegen** voegt er een toe.

### Typen overeenkomst

| Type overeenkomst | Leest het patroon als | Blok | Inline |
| --- | --- | --- | --- |
| **Letterlijke prefix** | Tekst waarmee de constructie begint. | ja | ja |
| **Letterlijk exact** | De volledige tekst van de constructie. | ja | ja |
| **Prefix aan regelbegin** | Tekst aan het begin van een regel, zoals `# `. | ja | |
| **Ingesprongen blok** | Regels die met het patroon beginnen, zoals vier spaties of een tab. Opeenvolgende regels, en lege regels ertussen, vormen één blok, getoond zonder de inspringing. | ja | |
| **Afgebakend blok** | Een regel die een blok opent, afgesloten door een bijpassende regel. | ja | |
| **Regex (begrensd)** | Een reguliere expressie. Pilcrow waarschuwt voordat je er een bewaart die kan vastlopen: “Deze regex kan de editor laten vastlopen — vereenvoudig hem.” | ja | ja |
| **Scheidingstekenpaar** | Dezelfde markering aan beide kanten van tekst op één regel, zoals `%%` in `%%this%%`. Direct binnen de markeringen staat geen spatie. | ja | ja |

In een reguliere expressie geeft `(?<name>…)` een deel van de overeenkomst een naam. Zie Benoemde delen hieronder.

## Regelopties

De groep **Opties** van elke regel biedt:

| Optie | Wat het doet |
| --- | --- |
| **Prioriteit** | Regels met een hogere prioriteit worden het eerst geprobeerd. |
| **Alleen aan het begin van een regel** | Voorkomt dat een regel midden in een regel overeenkomt. |
| **Benoemde delen worden attributen** | Elk benoemd deel van een reguliere expressie wordt een attribuut van de uitvoer. De editor toont “Delen in dit patroon” en “Delen die deze uitvoer leest”. Bij een uitvoer die tekst bevat, zoals vet of een link, is de getoonde tekst het deel met de naam `text` als dat er is, anders het laatste deel dat overeenkwam. |
| **Levert** | Wat de regel maakt: een uitvoer uit de onderstaande lijsten, of een **Aangepast** naam. |
| **Aangepaste knooppuntnaam** | De naam voor een **Aangepast** uitvoer. |
| **Vaste attributen** | Delen die elke keer dezelfde waarde hebben, toegevoegd met **Attribuut toevoegen** (een **Naam** en een **Waarde**). Een waarde mag een benoemd deel bevatten, geschreven als `{name}`: een e-mailregel waarvan het patroon `address` noemt, kan zijn link de `url` `mailto:{address}` geven. |
| **Invoegtekst** | Wat het menu **Invoegen** voor deze regel schrijft, precies zoals het eruit moet zien, met `$0` op de plek waar de cursor moet komen. Een regel die door een reguliere expressie, een blok of inspringing wordt herkend, heeft dit nodig, anders laat het menu Invoegen hem weg. |
| **Alleen na een lege regel** | Voor een ingesprongen blok: een ingesprongen regel direct na tekst blijft deel van die tekst, zoals de volgende regel van een lijstitem. |
| **Na Return aan het einde van een regel** | Voor lijsten en citaten: **Automatisch** (herhaalt opsommingstekens en citaatmarkeringen, telt genummerde items op en begint taakitems niet aangevinkt), **Herhalingsteken**, **Optellen**, **Opnieuw beginnen vanaf de markering**, of **Niets toevoegen**. |

### Afgebakende blokken en blokken met scheidingstekens

Bij een regel met **Afgebakend blok** zegt **Het blok bevat** wat erin staat:

| Keuze | Betekenis |
| --- | --- |
| **Nog niets** | Niet ingesteld. |
| **Tekst, getoond zoals geschreven** | Code of voorgeformatteerde tekst. |
| **Niets — verborgen** | Een opmerking, weggelaten uit het document. |
| **Andere blokken, in een kader** | Een citaat, zijbalk of waarschuwing met alinea’s, lijsten en meer. |
| **Andere blokken, zonder kader** | De blokken voegen zich bij de omringende tekst; de regels groeperen ze alleen. |
| **Een tabel** | Zie Tabellen, hieronder. |
| **Een tabel getekend in tekst** | Een raster of uitgelijnde kolommen van tekst die van de openingsregel tot de volgende lege regel loopt, zoals bij reStructuredText. |
| **Ingesprongen tekst onder een regel die op een markering eindigt** | De openingsregel is proza dat op de markering eindigt, zoals bij `::` in reStructuredText; het proza blijft een alinea, en de tekst die er na een lege regel onder is ingesprongen, wordt getoond zoals geschreven. |
| **Ingesprongen tekst onder een openingsregel** | Een directive zoals `.. code-block::`, die de ingesprongen regels eronder bevat en geen sluitregel heeft. |

De **Afsluitende regel** is de regel die het blok beëindigt; leeg betekent dezelfde regel als de openingsregel (“Hetzelfde als de openingsregel”). Een scheidingsteken dat geen reguliere expressie is, zoals `+++`, wordt als gewone tekst vergeleken. **De sluitregel herhaalt het openingsteken minstens even vaak** is voor afbakeningen in Markdown-stijl: de sluitregel is het eerste teken van de openingsregel, minstens zo vaak herhaald, zodat een langere afbakening een kortere als tekst bevat. De taal van een tekstblok, wanneer de openingsregel een bekende taal noemt, wordt in de editor gekleurd.

| **Rij eindigt met** | Een markering die elke rij beëindigt, zoals bij een LaTeX-`tabular`. |
| **Patroon voor samengevoegde cellen** | Een cel die meerdere kolommen beslaat. |
| **Patroon voor celopties** | Een reguliere expressie voor wat direct vóór het scheidingsteken van een cel mag staan; een deel met de naam `colspan` laat de cel dat aantal kolommen beslaan. |
| **Scheidingsteken kolomlijst**, **Herhalingsteken** | Hoe een `columns`-lijst wordt geschreven: met `,` en `*`, waarbij `3*` drie kolommen telt. |

| **Formaten** | Andere manieren om de cellen te schrijven, elk een naam en een scheidingsteken (zoals `csv` en `,`), toegevoegd met **Formaat toevoegen** en gekozen met het deel `format` van de tabel. |

## Inline-markeringen die paren vormen op basis van wat eromheen staat

Een taal als Markdown schrijft vet en cursief met een reeks tekens die opent of sluit afhankelijk van de tekens ernaast, en een codefragment of link met haakjes, zodat één patroon voor de hele constructie ze niet kan vinden. Zet **Tekens lezen op basis van wat eromheen staat** aan om ze te beschrijven.

| Instelling | Wat het doet |
| --- | --- |
| **Escapeteken** | Een teken dat het volgende teken gewoon maakt. |
| **Teken voor codefragmenten** | Een reeks van dit teken opent een fragment dat door de volgende reeks van dezelfde lengte wordt gesloten. |
| **Reeksmarkeringen** | Markeringen die als reeksen paren vormen, toegevoegd met **Reeksmarkering toevoegen**. Elk heeft een **Markering**, wat **Eén markering tekent** en wat **Twee markeringen tekenen**, en **Mag binnen een woord openen of sluiten** (uit voor `_`). |
| **Paarmarkeringen** | Markeringen die een paar vormen met een reeks van dezelfde lengte, toegevoegd met **Paarmarkering toevoegen**: de **Markering**, wat hij **Tekent**, en **Alleen als deze instelling aan staat**, een syntaxisinstelling zoals markeren die aan moet staan (of **Altijd**). |
| **Links en webadressen** | **Afbeeldingsprefix**, **Een los geschreven adres staat tussen**, **Schema’s waarmee een kaal adres begint**, **Een regel die een label definieert heeft** en **Het label van een voetnoot begint met** (het teken na het openingshaakje van een label dat er een voetnoot van maakt: `[^note]` wordt als voetnootverwijzing getekend wanneer een regel met `[^note]:` begint). |

Markeringen vormen paren binnen een regel. Code, geëscapete tekens en het adres van een link zijn gewone tekst voor de markeringen eromheen.

## Gestileerde bron

Met **Opgemaakte bron** aan tekent de editor een document in de stijl van zijn syntaxis: grotere koppen, vette en cursieve reeksen, citaatbalken, lijstinspringingen, taakvakjes, lijnen, links en codekaarten, en verbergt hij de tekens die ze vormen (met **Markeringen verbergen** aan), behalve op de regel waar de cursor staat. De editor kent geen enkele syntaxis: een regel zegt wat zijn overeenkomst is door een stijlinvoer te dragen, en een regel zonder wordt gekleurd maar niet opnieuw opgemaakt.

De groep **Opties** van elke regel heeft een groep **Gestileerde bron**:

| Veld | Wat het doet |
| --- | --- |
| **Rol** | Wat de overeenkomst is, of **Zonder stijl**. Voor één constructie binnen een regel: heading, strong, emphasis, code, strike, highlight, underline, link, subscript, superscript. Voor een hele regel: rule (een thematische scheiding), list (de markering van een lijstitem, inclusief inspringing en de spatie erna), task (een markering gevolgd door een selectievakje) en quote (de `>`-tekens van een geciteerde regel). Voor een blok dat als geheel wordt herkend: codeBlock. Voor een blok waarvan de open- en sluitregel aparte overeenkomsten zijn: quoteRegion. Voor een tabel, vergelijking of diagram getekend als afbeelding: renderedBlock. |
| **Groep van de inhoud** | De capture-groep, geteld vanaf 1, die bevat waar de constructie over gaat: het woord binnen `*bold*`, de titel in `\section{Title}`. Wat de overeenkomst verder heeft, zijn de eigen markeringen van de constructie, die Markeringen verbergen verbergt. `0` betekent dat de hele overeenkomst inhoud is en niets wordt verborgen, zoals bij een webadres. Laat het weg wanneer de overeenkomst alleen uit markeringen bestaat, zoals de `== ` van een kop. |
| **Niveau van de kop**, **Groep van het niveau** | Het niveau van een kop, 1 tot 6. Weggelaten is het het getal aan het einde van de uitvoernaam van de regel (`heading2`), of de lengte van de capture-groep die een reeks `#` bevat. |
| **Groep van de markering** | Voor een lijst of taak, de capture-groep die de markering is met zijn inspringing en de spaties erna, wanneer de overeenkomst met iets anders begint, zoals de `> ` van een geciteerd item. |
| **Past de stijl toe tot het einde van de regel** | Past de stijl toe van de overeenkomst tot het einde van de regel, voor een regel die alleen de markering van een kop vindt en de titel laat als de tekst die volgt. |
| **Wordt getekend als** | Voor een weergegeven blok, wat het is: een tabel, formule of diagram, of **Geen afbeelding**. |
| **Groepen van het adres** | Voor een link, de capture-groepen, in volgorde geprobeerd, die het adres bevatten dat hij opent bij klikken of tikken; `0` is de hele overeenkomst. Alleen web-, e-mail- en telefoonadressen openen. |

De groepsnummers tellen de haakjes van het patroon vanaf 1; 0 is de hele overeenkomst. Een profiel dat Markdown niet vervangt, behoudt ook Markdowns eigen lezing van de soorten die zijn regels niet declareren, zoals de citaatbalken en de paren `**`.

## Documentattributen en voorwaardelijke secties

Een regel **Documentattribuut** definieert een waarde met `name`, en een regel **Attribuutverwijzing** (een inline-regel met de delen `name` en `original`) vervangt een verwijzing daardoor. Een verwijzing naar een attribuut dat niemand heeft gedefinieerd, blijft staan zoals geschreven. Een **Voorwaardelijke sectie** behoudt of verwijdert de blokken tussen zijn regels, afhankelijk van of de attributen die hij noemt zijn ingesteld. Attributen gelden vanaf de plek waar ze zijn gedefinieerd.

Een regel die **Instellingen voor het volgende blok** levert, herkent een hele regel die het blok erna configureert en toont zelf niets. Zijn delen en vaste attributen worden aan dat blok gegeven: `title`, `id`, `nodeType`, `language` en `hardbreaks` hebben de betekenissen die onder Delen staan, en elk ander deel blijft op het blok bewaard, waar een tabel, lijst of citaat het leest.

## Een profiel testen

Onderaan de editor bevat **Voorbeeldtekst** een voorbeeldtekst (die begint als een kop en een regel tekst). Kies **Voorbeeld controleren** om de knooppunten te zien die jouw regels maken, ingesprongen zoals ze nesten. Er staat “Geen blokken herkend.” wanneer niets overeenkomt.

## Basislijn

De **basislijn** van een profiel is zijn herstelpunt: hoe het was toen je het maakte, dupliceerde of importeerde. **Terugzetten naar basislijn** gooit elke wijziging sindsdien weg, nadat je het hebt bevestigd. **Instellen als nieuwe basislijn** bewaart het profiel en maakt de huidige staat het herstelpunt.

Bewaren wordt geweigerd, met een bericht, als het profiel Markdown vervangt maar geen regel voor regeleinde heeft, als een patroon onveilig is en de editor kan laten vastlopen, of als het bestand niet kan worden geschreven.

## Delen

Delen zijn de benoemde stukken van een overeenkomst die een uitvoer leest.

| Deel | Betekenis |
| --- | --- |
| `allOf` | Het scheidingsteken tussen namen wanneer alle nodig zijn, zoals `+`. |
| `alt` | De beschrijving van een afbeelding, voor lezers die haar niet kunnen zien. |
| `anyOf` | Het scheidingsteken tussen namen wanneer één ervan genoeg is, zoals `,`. |
| `attribution` | Wie een citaat heeft uitgesproken, eronder getoond. |
| `citetitle` | Het werk waaruit een citaat komt, getoond na de bronvermelding. |
| `columns` | De kolomlijst van een tabel, zoals `1,2,1`; de items tellen de kolommen. |
| `condition` | De attribuutnamen waarvan de sectie afhangt. |
| `conditionType` | `defined` behoudt de sectie wanneer de attributen zijn ingesteld, `undefined` wanneer ze dat niet zijn. |
| `content` | De tekst zelf, wanneer die niet de hele overeenkomst is. |
| `format` | De engine van een diagram (`mermaid` of `vega-lite`); bij een tabel, welk van zijn formaten met scheidingstekens de cellen gebruiken. |
| `hardbreaks` | Wanneer aanwezig, behoudt de enkele regeleinden van het volgende blok. |
| `header` | Elke waarde behalve `false` maakt de eerste rij van een tabel tot zijn koprij. |
| `id` | Een naam: voor het volgende blok de id waarnaar kruisverwijzingen wijzen; voor een voetnoot een naam waarmee latere voetnoten zonder eigen tekst zijn nummer delen. |
| `keys` | De toetsen om in te drukken, gescheiden door komma’s. |
| `label` | De tekst die voor een verwijzing of anker wordt getoond, in plaats van de eigen titel van het doel. |
| `language` | De programmeertaal van een codeblok, gebruikt voor de kleuring. |
| `level` | Het kopniveau, van 1 tot 6. |
| `marker` | Het scheidingsteken na de term, zoals `::`. Een andere markering nest een lijst binnen de beschrijving. |
| `name` | De naam van het attribuut, in een definitie of een verwijzing. |
| `nodeType` | Maakt van het volgende blok een andere uitvoer, met zijn naam in het bestand. |
| `noHeader` | Wanneer aanwezig, heeft een tabel geen koprij. |
| `notation` | De wiskundige notatie: `tex` (de standaard) of `latex`. |
| `open` | `true` toont een inklapbare sectie geopend. |
| `ordered` | `true` maakt de lijst genummerd. |
| `original` | De verwijzing zoals geschreven, getoond wanneer het attribuut niet is gedefinieerd. |
| `presentation` | Hoe de volgende beschrijvingslijst wordt getoond: `sideBySide` zet termen en beschrijvingen in twee kolommen; `questions` nummert elke term als een vraag, met het antwoord eronder. |
| `primary` | Het indexitem. |
| `secondary` | Een subitem onder het indexitem. |
| `sectionLabel` | Een woord waar het nummer van de volgende kop op volgt, zoals `Appendix`: zulke koppen worden apart geteld, `Appendix A:`. |
| `sectionLabelStart` | Het eerste van die nummers: een letter (`A`) telt in letters, een getal in getallen. |
| `src` | Het adres van het video- of audiobestand. |
| `start` | Het getal waarmee een genummerde lijst begint. |
| `summary` | De regel die bij een inklapbare sectie wordt getoond zolang hij gesloten is. |
| `targetID` | De id waarnaar de verwijzing wijst. |
| `term` | De term die wordt beschreven. |
| `tertiary` | Een subitem onder het secundaire. |
| `text` | De getoonde tekst, wanneer het patroon meer vastlegt dan dat. De tekst van een voetnoot volgt op de alinea, tabel of lijst waarin hij staat, genummerd. |
| `title` | Een titel: de kop van een kader, de tooltip van een afbeelding of link, of een bijschrift boven het volgende blok. |
| `type` | Het soort waarschuwing, zoals `note`, `tip` of `warning`. |
| `unset` | Wanneer aanwezig, verwijdert de regel het attribuut in plaats van het te definiëren. |
| `url` | Het adres waarnaar een link of afbeelding wijst. |
| `value` | De waarde van het attribuut; verwijzingen naar eerder gedefinieerde attributen worden erin vervangen. |
