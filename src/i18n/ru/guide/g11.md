# Chapter 72: Клавиатура

В разделе **Настройки ▸ Клавиатура ▸ Сокращения** перечислены все команды, сочетание клавиш для которых можно изменить, с текущей клавишей.

| Элемент | Что делает |
| --- | --- |
| Строка команды | Нажмите на неё, введите новое сочетание клавиш, затем выберите **Сохранить**. **Отвязать** удаляет сочетание. **Отменить** оставляет прежнее. Если сочетание уже использовалось другой командой, у той команды оно сбрасывается, и страница сообщает, у какой именно. |
| **Клавиши Super Tab** | Клавиши для **Следующее поле** и **Предыдущее поле**, которые переходят между пропусками, оставленными макросом: `⌥Tab` и `⌥⇧Tab`, либо `⌃⌘]` и `⌃⌘[`, либо **Пользовательский**. |
| **Сбросить все сочетания клавиш** | Восстанавливает все значения по умолчанию. |

| --- | --- |

| Курсив | `⌘I` |

| Строчная формула | `⌃M` |
| Зачёркнутый | `⌃⇧`` ` `` |
| Гиперссылка | `⌘K` |

| Показать/скрыть боковую панель | `⇧⌘L` |
| Боковая панель: Структура | `⌃⌘1` |

| Боковая панель: Дерево файлов | `⌃⌘3` |
| Боковая панель: Поиск | `⇧⌘F` |

# Chapter 73: Подписка и кредиты

Все функции Pilcrow бесплатны. Поддержка Pilcrow необязательна: она помогает оплачивать разработку и даёт вам голоса за то, что будет создано дальше. Голоса определяют порядок работы, но не гарантируют появления какой-либо функции.

На странице **Поддержать Pilcrow** есть:

| Часть | Что показывает или делает |
| --- | --- |
| **Ваши голоса** | **По подписке** (голоса за этот оплаченный месяц с указанием, когда они истекают) и **Купленные** (голоса, которые не истекают). Сначала расходуются голоса по подписке, и они истекают в конце оплаченного месяца. |
| **Получить голоса** | Подписка и отдельные голоса, которые можно купить. Pilcrow Supporter продлевается каждый месяц, пока вы не отмените его в настройках вашей учётной записи Apple. Каждый оплаченный месяц даёт вам голоса. |
| **Восстановить покупки** | Возвращает покупки, сделанные на другом устройстве. |
| **Условия использования**, **Политика конфиденциальности** | Ссылки. |
| **Значок приложения** | Выбор значков приложения для подписчиков. Значки для раунда голосования зарабатываются подпиской в течение этого раунда и остаются у вас. На Mac значок меняется в Dock, пока Pilcrow открыт. |
| **Дорожная карта** | Текущий раунд функций, открытых для голосования, со счётчиками «Голоса» и «Ваши» и кнопкой **Голосовать** для каждой. Каждый голос тратит один из ваших голосов и не может быть возвращён. Между раундами указано, когда откроется следующий. |

Если в конкретной сборке возможности поддержки недоступны, страница сообщает об этом.
