# Part XIX — Редакторы элементов библиотеки

# Chapter 74: Редактор профилей и строительные блоки профиля

Синтаксический профиль сообщает Pilcrow, что означает ваша разметка. В этой главе редактор профилей описан элемент за элементом, а затем перечислены все строительные блоки, которые может использовать профиль. Вводное описание по задачам см. в Chapter 37 — Chapter 39.

Откройте редактор через **Настройки ▸ Библиотека ▸ Синтаксические профили**: **Создать** начинает новый профиль, **Изменить** меняет пользовательский, а **Дублировать** копирует встроенный профиль, чтобы вы могли изменить копию. Заголовок редактора — **Изменить профиль**, с кнопками **Отменить**, **Сохранить** и **Справка по профилям** (она открывает встроенную справку по этим строительным блокам). На узком экране переключатель **Раздел профиля** выбирает между **Обзор**, **Правила** и **Тестовый образец**; на широком все три показаны одновременно.

## Обзор

| Поле | Что делает |
| --- | --- |
| **Имя** | Имя профиля, показываемое в меню строки состояния и в настройках. |
| **Описание** | Заметка о профиле. |
| **Расширения файлов (через запятую)** | Расширения, по которым для файла выбирается этот профиль. Два профиля не могут иметь одно расширение. |
| **Наследует** | **Нет** или другой профиль, на правилах которого строится этот. |
| **Синтаксис** | **Расширяет Markdown** или **Заменяет Markdown** (см. ниже). |
| **Кратко** | Количество **Правила блоков**, **Внутристрочные правила** и **Правила вложенности**. |
| **Изменить расширенный JSON…** | Открывает профиль как JSON для полей, которые пошаговый редактор не показывает. **Применить** сохраняет ваши изменения JSON; **Отменить** отбрасывает их. |

**Расширяет Markdown** добавляет ваши правила к правилам Markdown: его заголовки, списки, курсив и остальное по-прежнему читаются, а ваши блочные и внутристрочные правила дополняют их. Правило, которое является неизменённой копией одного из правил профиля CommonMark, описывает то, что Markdown уже умеет, и остаётся на его усмотрение. **Заменяет Markdown** делает ваши правила всем синтаксисом, поэтому конструкции Markdown перестают распознаваться. В этом случае одно правило должно создавать **Конец строки**, иначе ничто не разделит текст на абзацы. Редактор предупреждает: «Add a rule whose output node is "newline", or nothing will separate into paragraphs», и профиль нельзя сохранить, пока такого правила нет. Он также перечисляет все типы вывода, которые профиль не определяет.

## Правила

Правила делятся на три группы.

### Правила блоков

Правило блока распознаёт целые строки и блоки. **Добавить правило** добавляет одно. У каждого правила есть **Шаблон**, тип **Совпадение**, то, что оно **Создаёт**, и **Параметры**. Правило удаляется кнопкой **Удалить**. Если правил нет, редактор сообщает: «No rules yet. Add one to recognize a block construct.»

### Внутристрочные правила

Внутристрочное правило распознаёт текст внутри строки. **Добавить внутристрочное правило** добавляет одно. Для внутристрочных правил доступны четыре типа совпадения (**Буквальный префикс**, **Точное совпадение**, **Regex (ограниченная)** и **Пара разделителей**); для правил блоков — все семь.

### Правила вложенности

Правила вложенности говорят, какие выводы могут находиться внутри каких. У каждого есть **Родительский узел** и **Допустимые дочерние узлы (через запятую)**. Пусто означает отсутствие ограничений: «No restrictions. Every node type may nest inside any other.» **Добавить правило вложенности** добавляет одно.

### Типы совпадения

| Тип совпадения | Как читает шаблон | Блок | В строке |
| --- | --- | --- | --- |
| **Буквальный префикс** | Текст, которым начинается конструкция. | да | да |
| **Точное совпадение** | Весь текст конструкции. | да | да |
| **Префикс в начале строки** | Текст в начале строки, например `# `. | да | |
| **Блок с отступом** | Строки, начинающиеся с шаблона, например четырёх пробелов или табуляции. Идущие подряд строки и пустые строки между ними образуют один блок, показываемый без отступа. | да | |
| **Огражденный блок** | Строка, открывающая блок, который закрывается соответствующей строкой. | да | |
| **Regex (ограниченная)** | Регулярное выражение. Pilcrow предупреждает перед сохранением выражения, которое может зависнуть: «This regex could hang the editor — simplify it.» | да | да |
| **Пара разделителей** | Одна и та же метка с обеих сторон текста в одной строке, например `%%` в `%%this%%`. Сразу внутри меток нет пробела. | да | да |

В регулярном выражении `(?<name>…)` называет часть совпадения. См. раздел «Именованные части» ниже.

## Параметры правила

В группе **Параметры** каждого правила есть:

| Параметр | Что делает |
| --- | --- |
| **Приоритет** | Правила с более высоким приоритетом проверяются первыми. |
| **Только в начале строки** | Не позволяет правилу срабатывать посреди строки. |
| **Именованные части становятся атрибутами** | Каждая именованная часть регулярного выражения становится атрибутом вывода. Редактор перечисляет «Parts in this pattern» и «Parts this output reads». Для вывода, содержащего текст, например жирного шрифта или ссылки, показывается часть с именем `text`, если она есть, иначе последняя совпавшая часть. |
| **Создаёт** | Что создаёт правило: вывод из списков ниже или имя **Пользовательский**. |
| **Своё имя узла** | Имя для вывода **Пользовательский**. |
| **Постоянные атрибуты** | Части, которые каждый раз имеют одно и то же значение; добавляются через **Добавить атрибут** (**Имя** и **Значение**). Значение может включать именованную часть, записываемую как `{name}`: правило для e-mail, шаблон которого называет часть `address`, может задать своей ссылке `url` со значением `mailto:{address}`. |
| **Текст вставки** | Что меню **Вставка** записывает для этого правила, в точности так, как это должно выглядеть, с `$0` в том месте, где должен встать курсор. Правилу, которое срабатывает по регулярному выражению, блоку или отступу, это нужно, иначе меню «Вставка» его пропустит. |
| **Только после пустой строки** | Для блока с отступом: строка с отступом сразу после текста остаётся частью этого текста, например следующая строка элемента списка. |
| **После Return в конце строки** | Для списков и цитат: **Автоматически** (повторяет маркеры и знаки цитаты, увеличивает номера нумерованных элементов и начинает пункты задач неотмеченными), **Повторить маркер**, **Увеличить номер**, **Начать заново с маркера** или **Ничего не добавлять**. |

### Огражденные и ограниченные разделителями блоки

Для правила **Огражденный блок** параметр **Блок содержит** указывает, что находится внутри:

| Выбор | Значение |
| --- | --- |
| **Пока ничего** | Не задано. |
| **Текст, как написан** | Код или форматированный текст. |
| **Ничего — скрыто** | Комментарий, исключённый из документа. |
| **Другие блоки, в рамке** | Цитата, врезка или примечание, содержащие абзацы, списки и прочее. |
| **Другие блоки, без рамки** | Блоки объединяются с окружающим текстом; строки лишь группируют их. |
| **Таблица** | См. раздел «Таблицы» ниже. |
| **Таблица, нарисованная текстом** | Сетка или выровненные столбцы текста, идущие от открывающей строки до следующей пустой строки, как в reStructuredText. |
| **Текст с отступом под строкой, оканчивающейся маркером** | Открывающая строка — это проза, заканчивающаяся маркером, как `::` в reStructuredText; проза остаётся абзацем, а текст с отступом под ней после пустой строки показывается как написан. |
| **Текст с отступом под открывающей строкой** | Директива, такая как `.. code-block::`, которая содержит строки с отступом под собой и не имеет закрывающей строки. |

**Закрывающая строка** — это строка, которая завершает блок; пусто означает ту же строку, что и открывающая («Same as the opening line»). Разделитель, не являющийся регулярным выражением, например `+++`, сопоставляется как обычный текст. **Закрывающая строка повторяет открывающий знак не меньше раз** предназначено для ограждений в стиле Markdown: закрывающая строка — это первый символ открывающей строки, повторённый не меньше раз, поэтому более длинное ограждение содержит более короткое как текст. Язык текстового блока, если открывающая строка называет известный язык, подсвечивается в редакторе цветом.

### Таблицы

Параметры блока таблицы:

| Параметр | Что делает |
| --- | --- |
| **Расположение** | **Сетка с разделительными линиями** (ячейки между `|` с разделительной линией между строками) или **Выровненные столбцы** (столбцы, выровненные под первой разделительной линией). |
| **Разделитель ячеек** | Текст, с которого начинается каждая ячейка. |
| **Шаблон разделительной строки**, **Шаблон разделительной строки заголовка** | Строки, рисующие только линию, и строка, завершающая заголовок. |
| **Строка заканчивается на** | Знак, завершающий каждую строку, как в `tabular` из LaTeX. |
| **Шаблон объединённой ячейки** | Ячейка, объединяющая столбцы. |
| **Шаблон параметров ячейки** | Регулярное выражение для того, что может стоять прямо перед разделителем ячейки; часть с именем `colspan` заставляет ячейку занимать столько столбцов. |
| **Разделитель списка столбцов**, **Знак повтора** | Как записывается список `columns`: с `,` и `*`, `3*` означает три столбца. |
| **Первая строка перед пустой строкой — заголовок** | Строка заголовка определяется расположением. |
| **Форматы** | Другие способы записи ячеек, каждый — имя и разделитель (например `csv` и `,`); добавляются через **Добавить формат** и выбираются частью `format` таблицы. |

## Настройки всего профиля

| Настройка | Что делает |
| --- | --- |
| **Вкладывать списки по маркеру** | Каждый новый маркер, например `**` после `*`, начинает более глубокий уровень независимо от отступа. |
| **Строка продолжения списка** | Строка, стоящая отдельно после элемента списка, которая присоединяет следующий блок к этому элементу. |
| **Сохранять одиночные переводы строк** | Перевод строки внутри абзаца остаётся переводом строки. |
| **Присваивать заголовкам идентификаторы** | Заголовок без собственного идентификатора получает его из названия: строчными буквами, слова соединены **разделителем слов** после **префикса** (**Префикс идентификатора**, **Разделитель слов в идентификаторе**). При `_` и `_` «Getting Started» превращается в `_getting_started`, так что перекрёстная ссылка на него показывает название. Повторяющееся название добавляет разделитель и число. |
| **Нумеровать заголовки** | Как только документ определяет атрибут, названный в **Когда документ определяет**, например `:sectnums:` в AsciiDoc, заголовки начиная с **С уровня заголовка** нумеруются: `1.`, `1.1.`, `2.`. Заголовки до определения не нумеруются. |
| **Нумерованные подписи** | Блок с названием из перечисленных здесь выводов, например `image`, `table` или `example`, получает **Метка** и собственный номер перед названием (например, «Рисунок 1.») в положении **Положение подписи**, **Сверху** или **Снизу** от блока. Добавляется через **Добавить подпись**. |

## Внутристрочные метки, парные по своему окружению

Язык вроде Markdown записывает полужирный и курсив серией символов, которая открывает или закрывает выделение в зависимости от соседних символов, а фрагмент кода или ссылку — скобками, поэтому один шаблон на всю конструкцию их найти не может. Включите **Читать метки по их окружению**, чтобы описать их.

| Настройка | Что делает |
| --- | --- |
| **Символ экранирования** | Символ, делающий следующий за ним обычным. |
| **Символ фрагмента кода** | Серия этого символа открывает фрагмент, который закрывает следующая серия той же длины. |
| **Метки-серии** | Метки, образующие пары как серии; добавляются через **Добавить метку-серию**. У каждой есть **Метка**, что **Одна метка рисует**, что **Две метки рисуют** и **Может открываться и закрываться внутри слова** (выключено для `_`). |
| **Парные метки** | Метки, образующие пару с серией той же длины; добавляются через **Добавить парную метку**: **Метка**, что она **Рисует**, и **Только если включён этот параметр** — настройка синтаксиса, например выделения, которая должна быть включена (или **Всегда**). |
| **Ссылки и веб-адреса** | **Префикс изображения**, **Адрес сам по себе заключается в**, **Схемы, с которых начинается простой адрес**, **Строка, определяющая метку, содержит** и **Метка сноски начинается с** (символ после открывающей скобки метки, который делает её сноской: `[^note]` рисуется как ссылка на сноску, когда строка начинается с `[^note]:`). |

Метки образуют пары в пределах строки. Код, экранированные символы и адрес ссылки для окружающих их меток — обычный текст.

## Стилизованный исходник

При включённом **Стилизованный исходник** редактор рисует документ в виде его синтаксиса: более крупные заголовки, полужирные и курсивные фрагменты, полосы цитат, отступы списков, флажки задач, линии, ссылки и карточки кода, и скрывает создающие их метки (при включённом **Скрыть разметку**), кроме строки, на которой стоит курсор. Редактор ничего не знает ни об одном отдельном синтаксисе: правило говорит, чем является его совпадение, через запись стилизации, а правило без неё раскрашивается, но не переоформляется.

В **Параметры** каждого правила есть группа **Оформленный исходный текст**:

| Поле | Что делает |
| --- | --- |
| **Роль** | Чем является совпадение, или **Без оформления**. Для одной конструкции внутри строки: heading, strong, emphasis, code, strike, highlight, underline, link, subscript, superscript. Для целой строки: rule (тематический разрыв), list (маркер элемента списка, включая его отступ и пробел после него), task (маркер с флажком) и quote (знаки `>` цитируемой строки). Для блока, распознаваемого целиком: codeBlock. Для блока, открывающая и закрывающая строки которого — отдельные совпадения: quoteRegion. Для таблицы, формулы или диаграммы, нарисованных как картинка: renderedBlock. |
| **Группа содержимого** | Группа захвата, считая с 1, которая содержит то, о чём конструкция: слово внутри `*bold*`, название в `\section{Title}`. Всё остальное в совпадении — собственные метки конструкции, которые скрывает «Скрыть разметку». `0` означает, что всё совпадение — содержимое и ничего не скрывается, как для веб-адреса. Не указывайте, если совпадение состоит только из меток, например `== ` заголовка. |
| **Уровень заголовка**, **Группа уровня** | Уровень заголовка от 1 до 6. Если не указан, это число в конце имени вывода правила (`heading2`) или длина группы захвата, содержащей серию `#`. |
| **Группа маркера** | Для списка или задачи — группа захвата, являющаяся маркером с его отступом и пробелами после него, когда совпадение начинается с чего-то другого, например с `> ` цитируемого элемента. |
| **Оформляет до конца строки** | Оформляет от совпадения до конца строки, для правила, которое совпадает только с маркером заголовка и оставляет его название как следующий за ним текст. |
| **Отображается как** | Для отрисованного блока — чем он является: таблицей, формулой или диаграммой, или **Не изображение**. |
| **Группы адреса** | Для ссылки — группы захвата, проверяемые по порядку, которые содержат адрес, открываемый по щелчку или касанию; `0` — всё совпадение. Открываются только веб-адреса, адреса почты и телефона. |

Номера групп считают скобки шаблона с 1; 0 — всё совпадение. Профиль, который не заменяет Markdown, также сохраняет собственное чтение Markdown для видов, которые его правила не объявляют, например его полосы цитат и пары `**`.

## Атрибуты документа и условные разделы

Правило **Атрибут документа** определяет значение по `name`, а правило **Ссылка на атрибут** (внутристрочное правило с частями `name` и `original`) заменяет ссылку этим значением. Ссылка на атрибут, который никто не определил, остаётся как написана. **Условный раздел** сохраняет или отбрасывает блоки между своими строками в зависимости от того, заданы ли названные в нём атрибуты. Атрибуты действуют с того места, где они определены, и далее.

Правило, создающее **Настройки следующего блока**, распознаёт целую строку, которая настраивает следующий за ней блок и сама ничего не показывает. Её части и постоянные атрибуты передаются этому блоку: `title`, `id`, `nodeType`, `language` и `hardbreaks` имеют значения, перечисленные в разделе «Части», а любая другая часть сохраняется в блоке, где её читает таблица, список или цитата.

## Проверка профиля

Внизу редактора в **Тестовый образец** находится образец текста (сначала это заголовок и строка текста). Выберите **Проверить образец**, чтобы увидеть узлы, которые создают ваши правила, с отступами по вложенности. Если ничего не совпало, выводится «No blocks recognized.»

## Исходная версия

**Исходная версия** профиля — это его точка восстановления: каким он был, когда вы его создали, продублировали или импортировали. **Вернуть к исходной версии** отбрасывает все изменения с тех пор после вашего подтверждения. **Сделать новой исходной версией** сохраняет профиль и делает его текущее состояние точкой восстановления.

Сохранение отклоняется с сообщением, если профиль заменяет Markdown, но не имеет правила конца строки, если шаблон небезопасен и может зависнуть в редакторе или если файл не удаётся записать.

## Части

Части — это именованные фрагменты совпадения, которые читает вывод.

| Часть | Значение |
| --- | --- |
| `allOf` | Разделитель между именами, когда нужны все, например `+`. |
| `alt` | Описание изображения для читателей, которые его не видят. |
| `anyOf` | Разделитель между именами, когда достаточно любого одного, например `,`. |
| `attribution` | Кто произнёс цитату; показывается под ней. |
| `citetitle` | Произведение, из которого взята цитата; показывается после автора. |
| `columns` | Список столбцов таблицы, например `1,2,1`; его элементы считают столбцы. |
| `condition` | Имена атрибутов, от которых зависит раздел. |
| `conditionType` | `defined` сохраняет раздел, когда атрибуты заданы, `undefined` — когда не заданы. |
| `content` | Сам текст, когда это не всё совпадение. |
| `format` | Движок диаграммы (`mermaid` или `vega-lite`); для таблицы — какой из её форматов с разделителями используют ячейки. |
| `hardbreaks` | Если присутствует, сохраняет одиночные переводы строк следующего блока. |
| `header` | Любое значение, кроме `false`, делает первую строку таблицы её заголовком. |
| `id` | Имя: для следующего блока — идентификатор, на который указывают перекрёстные ссылки; для сноски — имя, позволяющее последующим сноскам без собственного текста делить её номер. |
| `keys` | Клавиши, которые нужно нажать, через запятую. |
| `label` | Текст, показываемый для ссылки или якоря вместо собственного названия цели. |
| `language` | Язык программирования блока кода, используемый для его подсветки. |
| `level` | Уровень заголовка от 1 до 6. |
| `marker` | Разделитель после термина, например `::`. Другой маркер вкладывает список внутрь описания. |
| `name` | Имя атрибута в определении или ссылке. |
| `nodeType` | Превращает следующий блок в другой вывод по его имени в файле. |
| `noHeader` | Если присутствует, у таблицы нет строки заголовка. |
| `notation` | Нотация формул: `tex` (по умолчанию) или `latex`. |
| `open` | `true` показывает сворачиваемый раздел раскрытым. |
| `ordered` | `true` делает список нумерованным. |
| `original` | Ссылка в том виде, как написана; показывается, когда атрибут не определён. |
| `presentation` | Как показывается следующий список определений: `sideBySide` помещает термины и описания в два столбца; `questions` нумерует каждый термин как вопрос, с ответом под ним. |
| `primary` | Запись указателя. |
| `secondary` | Подзапись под записью указателя. |
| `sectionLabel` | Слово, за которым следует номер следующего заголовка, например `Appendix`: такие заголовки считаются отдельно, `Appendix A:`. |
| `sectionLabelStart` | Первый из этих номеров: буква (`A`) считает буквами, число — числами. |
| `src` | Адрес видео- или аудиофайла. |
| `start` | Число, с которого начинается нумерованный список. |
| `summary` | Строка, показываемая на сворачиваемом разделе, пока он закрыт. |
| `targetID` | Идентификатор, на который указывает ссылка. |
| `term` | Описываемый термин. |
| `tertiary` | Подзапись под вторичной. |
| `text` | Показываемый текст, когда шаблон захватывает больше. Текст сноски следует за абзацем, таблицей или списком, в которых она находится, с нумерацией. |
| `title` | Название: заголовок рамки, подсказка изображения или ссылки либо подпись над следующим блоком. |
| `type` | Вид примечания, например `note`, `tip` или `warning`. |
| `unset` | Если присутствует, правило удаляет атрибут вместо его определения. |
| `url` | Адрес, на который указывает ссылка или изображение. |
| `value` | Значение атрибута; ссылки на ранее определённые атрибуты в нём заменяются. |
