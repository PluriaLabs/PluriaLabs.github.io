# Chapter 81: Файлы, кодировки и ограничения

## Файлы, которые открывает Pilcrow

Pilcrow редактирует файлы с обычным текстом и разметкой. Обычные расширения — `txt`, `md`, `markdown`, `adoc`, `asciidoc`, `rst` и `tex`, а также любое расширение, которое заявляет добавленный вами профиль. Pilcrow определяет кодировку текста файла при его открытии.

| Элемент | Тип |
| --- | --- |
| Профиль синтаксиса, набор макросов, руководство по стилю, тема приложения | `.json` |
| Тема отображения | `.css` |
| Пакет темы | `.zip` |
| Манифест проекта книги | `manifest.pilcrow` |
| Фон | HEIC, PNG, JPEG, SVG, MP4, MOV, M4V |
| Звуковой клип набора | WAV, AIFF, MP3, M4A, CAF |

## Кодировки текста

Pilcrow читает текст в UTF-8, UTF-16, UTF-32 и ISO 8859-1 (Latin-1). Документ можно преобразовать с помощью **Сведения о документе ▸ Кодировка ▸ Преобразовать в…** в любую из следующих кодировок; файл будет преобразован при следующем сохранении:

UTF-8, UTF-8 (BOM), UTF-16 LE, UTF-16 LE (BOM), UTF-16 BE, UTF-16 BE (BOM), UTF-32 LE, UTF-32 LE (BOM), UTF-32 BE, UTF-32 BE (BOM).

Файл в Latin-1 можно преобразовать в любую из них без потерь. Преобразование в Latin-1 не предлагается, потому что оно может уничтожить содержимое.

## Форматы экспорта

| Формат | Расширение |
| --- | --- |
| HTML, HTML (без стилей) | `.html` |
| PDF | `.pdf` |
| Word (.docx) | `.docx` |
| Изображение | `.png` |
| Архив PDF | `.zip` |

## Ограничения и числа

Где Pilcrow останавливается или где у выбора есть диапазон:

| Где | Ограничение |
| --- | --- |
| Панель поиска | Останавливается на 500 совпадениях. |
| Поиск в предпросмотре | Считает до 2 000 совпадений. |
| Замена в папке | Изменяет не более 2 000 файлов за раз. |
| Проверить ссылки | Проверяет до 50 000 ссылок. |
| Сравнить | Показывает до 5 000 изменённых строк. |
| Хранить версий | От нуля до 500 (по умолчанию 50). |
| Длинные строки | Строки в 20 000 символов и более всегда переносятся. |
| Размер шрифта | От 9 до 32 пунктов. |
| Ширина табуляции | От 2 до 8 пробелов. |
| Ширина текста | От 50 % до 100 %. |
| Масштаб | От 50 % до 200 %, десятью шагами. |
| Скорость чтения | От 60 до 2 000 слов в минуту. |
| Ширина навигатора | От 180 до 420 пунктов. |
| Звуковой клип набора | Не более 2 секунд и 3 МБ. |
| Текст журнала в диагностическом отчёте | Самые новые записи, до 60 000 символов, при добавлении в описание обращения на GitHub. |
| Очень большие файлы | Открываются и редактируются без чтения в память целиком. Подсчёт строк и слов, а также структура документа завершаются в фоновом режиме и до этого могут быть неполными. Для экспорта очень большого документа в PDF нужно гораздо больше памяти, чем для редактирования или экспорта в HTML и Word; Архив PDF разбивает его на части ограниченного размера. |

## Где Pilcrow хранит данные

| Что | Где |
| --- | --- |
| Ваши документы | Там, куда вы их сохранили. |
| Библиотека (темы, профили, макросы, руководства по стилю, фоны) | В закрытом хранилище приложения или в папке «Pilcrow Library» внутри выбранной вами папки (**Настройки ▸ Библиотека ▸ Расположение**). |
| Предпочтения, ключи API, резервные копии, история версий | На устройстве, в закрытом хранилище приложения и в связке ключей. Просматривайте и удаляйте их в **Настройки ▸ Основные ▸ Хранилище и конфиденциальность**. |
| Диагностический журнал | На устройстве, пока вы его не очистите. |

# Chapter 82: Сообщения, баннеры и пустые состояния

В этой главе объясняются короткие сообщения, которые показывает Pilcrow, чтобы ни одно из них не было загадкой.

## В редакторе и предпросмотре

| Сообщение | Что оно означает |
| --- | --- |
| **Пока нечего показывать. Начните писать, и текст появится здесь.** (или «Перейдите в режим правки и начните писать.») | Документ пуст, поэтому в предпросмотре нечего отображать. |
| **Не удалось построить предпросмотр: …** с кнопками **Показать исходный текст** и **Повторить** | Предпросмотр не удался. **Показать исходный текст** переключает в режим правки. **Повторить** пробует снова. |
| Неудавшаяся формула или диаграмма со ссылкой **Показать исходный текст** | Один блок не удалось отобразить. Нажмите **Показать исходный текст**, чтобы перейти к исходному тексту этого блока и исправить его. |
| **Не удалось сохранить** с кнопкой **Повторить** и кнопкой закрытия | Сохранение не удалось. Документ остаётся открытым и несохранённым. Устраните причину (место на диске, права доступа, перемещённый файл) и выберите **Повторить**. |
| **Файл изменён на диске** | Другое приложение изменило файл. **Обновить** читает новую версию; **Оставить текущую версию** сохраняет то, что есть у вас. |
| **Предупреждение разбора** | Строка, где конструкция, вероятно, не соответствует вашему замыслу (глава 68). |
| **Заменить существующий файл?** | Выбранное вами имя уже занято в этом месте. |
| **Остались незаполненные поля** | Вы печатаете или экспортируете документ с незаполненными полями (глава 63). |
| **Разделитель панелей** (подсказка VoiceOver: «Перетащите, чтобы изменить размер редактора и предпросмотра. Дважды коснитесь, чтобы сбросить.») | Ползунок между исходным текстом и предпросмотром в режиме «Рядом». |
| **Слова: N** | Число слов в строке состояния. |

## В диалогах и панелях

| Где | Сообщение | Значение |
| --- | --- | --- |
| Палитра команд | **Введите команду** | Подсказка в поле. Когда ничего не подходит, появляется «Нет подходящих команд». |
| Быстрое открытие | **Введите имя файла** | Подсказка в поле. |
| Курсоры в столбце | **Строки (например, 3-17)**, **Столбец (например, 100 или 100-105 для выделения)** | Подсказки в полях. Один столбец ставит курсоры; диапазон выделяет эти символы в каждой строке. |
| Панель поиска | **Введите запрос для поиска в этой папке.**, **В этой папке нет совпадений.**, **Поиск отменён.** | Состояние поиска по папке. |
| Панель файлов | **Папку можно также перетащить сюда.** | Перетащите папку на панель, чтобы открыть её. |
| Замена в папке | **Нечего заменять.** | У поиска нет совпадений. |
| Сравнить | Подсказки на кнопках: **Принять** («Внести это изменение в открытый документ»), **Отклонить** («Не вносить это изменение в открытый документ»), **Вернуть** («Вернуть в документ прежние строки только для этого изменения»). | Что делает каждая из них. |
| Перевести | **Не удалось завершить перевод.** | Повторите попытку или выберите другую скорость. |
| Перевести | **Примерное время: меньше минуты** | Оценка для скорости ИИ-ассистента; время зависит от вашего ИИ-сервиса. После перевода **Открыть в новой вкладке** открывает результат. |
| Ассистент | **Нет открытого документа.**, **Текст документа не отправляется.** | Панели нечем делиться, поэтому ничего не отправляется. |
| Выбор модели | **Загрузка моделей…**, **Подходящих моделей нет.** | Список загружается или по вашему запросу ничего не найдено. |
| Проверка стиля | **Замечаний нет.** и **Не удалось разобрать ответ как замечания. Повторите попытку.** | Проверка ничего не нашла или ответ ИИ был не в ожидаемой форме. |
| Проверка стиля | Подсказка **Применить все**: «Вносит все исправления, у которых они есть, одним изменением, которое можно отменить.» | Одна отмена возвращает всё. |
| Панель проекта | **Ваше имя**, **Добавить переменную** | Подсказка поля «Автор» и кнопка для переменной проекта. |
| Разрешение для ассистента | **Прочитать политику конфиденциальности Pilcrow** | Открывает политику конфиденциальности. |

## В настройках

| Где | Сообщение | Значение |
| --- | --- | --- |
| Клавиатура | **Нажмите новое сочетание клавиш, затем нажмите «Сохранить».** и **Нажмите любую клавишу…** | Во время записи сочетания клавиш. |
| Библиотека ▸ Расположение | **Расположение библиотеки**, **Перемещение библиотеки…** | Название страницы и ход выполнения при перемещении библиотеки. |
| Подключение ассистента | **Оставьте пустым, чтобы сохранить сохранённый ключ.** | При редактировании пустое поле ключа сохраняет ключ, уже находящийся в связке ключей. |
| Редактор макросов | **Триггер — например /sig** | Подсказка поля триггера. |
| Редактор профиля | **Расширенный JSON профиля**, **Образец и результаты** | Название редактора JSON и область под тестовым образцом, где показаны узлы, которые порождает образец. |
| Диагностика | **Все части** (в просмотре журнала), **Нет подходящих записей.** | Журнал без фильтра и фильтр, которому ничего не соответствует. |
| Строка состояния | Красная метка **Запись журнала**; её подсказка **Показать настройки диагностики** | Журнал записывается. Нажмите её, чтобы открыть страницу «Диагностика». **Остановить запись и завершить отчёт об ошибке** — подсказка на **Воспроизведение — завершить отчёт**. |
| Строка состояния | **Выберите синтаксический профиль для этого документа** | Подсказка в меню синтаксиса. |
| Элемент названия | **Открытые документы и действия с документом** | Подсказка на названии документа. |
