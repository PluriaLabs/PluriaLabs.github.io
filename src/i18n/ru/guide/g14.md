# Part XXI — Форматы файлов и ограничения

# Chapter 79: Формат темы приложения

**Тема приложения** задаёт оформление самого Pilcrow: светлый или тёмный вид, акцентный цвет, боковую панель, строки состояния и форматирования и редактор. Это JSON-файл. Отрисованные документы (предпросмотр, HTML, PDF, изображение, печать и Word) оформляются отдельно **темой отображения**, которая представляет собой CSS (глава 80). Эти два вида тем устанавливаются, выбираются и удаляются независимо, и ни одна не следует за другой.

## Полный пример

```json
{
  "pilcrowAppTheme": 1,
  "name": "Nord",
  "appearance": "dark",
  "colors": {
    "accent": "#88C0D0",
    "sidebar": { "background": "#2E3440", "foreground": "#D8DEE9" },
    "bars": { "background": "#3B4252", "foreground": "#D8DEE9" },
    "editor": {
      "background": "#2E3440",
      "foreground": "#ECEFF4",
      "cursor": "#88C0D0",
      "selection": "#434C5E",
      "gutterBackground": "#2E3440",
      "gutterForeground": "#4C566A"
    },
    "syntax": {
      "heading": "#88C0D0",
      "marker": "#EBCB8B",
      "code": "#A3BE8C",
      "link": "#81A1C1",
      "muted": "#7B88A1",
      "tokens": { "strong": "#D08770" }
    }
  }
}
```

## Верхний уровень

| Ключ | Обязателен | Значение |
| --- | --- | --- |
| `pilcrowAppTheme` | да | Версия формата, `1`. |
| `name` | да | От 1 до 200 символов. Показывается в настройках и в меню тем. |
| `appearance` | да | `"light"`, `"dark"` или `"automatic"`. |
| `colors` | темы `light` и `dark` | Одна палитра (см. ниже). |
| `light`, `dark` | темы `automatic` | Две палитры: одна используется при светлом оформлении системы, другая при тёмном. |
| `id` | нет | Записывается Pilcrow для собственной библиотеки. При импорте игнорируется: всегда назначается новый id. |

`appearance` определяет оформление **каждого** окна, включая меню, настройки, листы и средства выбора. Тема `light` или `dark` задаёт его жёстко; `automatic` следует за системой.

В автоматической теме каждый цвет нужно задать и в `light`, и в `dark`, либо ни там ни там. Цвет, заданный только для одного оформления, иначе был бы показан и в другом.

## Палитра

Все ключи необязательны. Пропущенный цвет сохраняет встроенный вид Pilcrow, поэтому тема может состоять всего из одного акцентного цвета.

| Ключ | Что оформляет |
| --- | --- |
| `accent` | Оттенок всего приложения: кнопки, выбранные сегменты, переключатели, ссылки, рамки фокуса и выбранная строка боковой панели. Если не задан, остаётся системный акцент. |
| `sidebar.background`, `sidebar.foreground` | Боковая панель «Файлы», «Структура» и «Поиск». Вторичные подписи вычисляются из переднего плана. |
| `bars.background`, `bars.foreground` | Строка состояния, закреплённая панель форматирования и уведомления об импорте. Вторичные подписи вычисляются из переднего плана. |
| `editor.background`, `editor.foreground` | Полотно редактора и основной текст. |
| `editor.cursor`, `editor.selection` | Точка вставки и выделение. |
| `editor.gutterBackground`, `editor.gutterForeground` | Поле номеров строк. Фон по умолчанию совпадает с фоном редактора. |
| `editor.currentLineRule` | Тонкая линия под строкой, в которой находится курсор, когда включено **Вид ▸ Линия под текущей строкой**. По умолчанию это цвет текста редактора с малой интенсивностью. |
| `syntax.<group>` | Цвета живой подсветки синтаксиса по группам (см. ниже). |
| `syntax.tokens.<raw>` | Один токен по его исходному значению, переопределяющий цвет его группы. |

### Группы синтаксиса

| Группа | Что окрашивает |
| --- | --- |
| `heading` | Заголовки (маркеры и текст), маркеры предупреждений, термины определений |
| `marker` | Курсив, полужирный, зачёркивание и другие строчные разделители; маркеры списков и задач |
| `code` | Встроенный код, огороженные блоки кода и блоки с отступом, формулы, HTML-блоки |
| `link` | Подписи и адреса ссылок и изображений, автоссылки |
| `muted` | Маркеры цитат, тематические разрывы, строки таблиц, комментарии, атрибуты блоков |
| `codeKeyword`, `codeString`, `codeNumber`, `codeComment` | Подсвеченный код внутри ограждения |

Если цвет группы не задан, берётся встроенный цвет, подобранный к фону редактора: более тёмные тона на светлом полотне и более светлые на тёмном. Имена токенов в `syntax.tokens` состоят из букв, цифр, `_` и `-` и не могут повторять имя группы (`syntax.heading` уже охватывает `heading`).

## Цвета

Каждый цвет — это шестнадцатеричная строка: `#RGB`, `#RGBA`, `#RRGGBB` или `#RRGGBBAA`, в sRGB. Pilcrow хранит их в верхнем регистре.

## Проверка

Pilcrow отклоняет файл целиком, а не игнорирует его часть, и называет проблемный ключ, например `colors.editor.cursor: must be a hex colour`. Он отклоняет:

- отсутствующую или другую версию `pilcrowAppTheme`;
- неизвестный ключ на любом уровне (обычно это опечатка);
- ключ палитры, не соответствующий оформлению (`colors` в автоматической теме, `light` и `dark` в светлой или тёмной);
- цвет не в шестнадцатеричной записи;
- автоматическую тему, у которой палитры `light` и `dark` задают разные наборы цветов.

## Что тема приложения не меняет

Заголовок окна и панель инструментов (системное «стекло», которое принимает только акцент), меню, настройки, листы и средства выбора сохраняют родной вид, кроме оформления и акцента. Шрифты темами не задаются: шрифт и размер редактора устанавливаются в **Настройки ▸ Оформление ▸ Размер текста и шрифты**.

## Установка и обмен

- **Импортируйте** файл `.json` через **Настройки ▸ Библиотека ▸ Темы**, **Файл ▸ Импорт ▸ Тема** на Mac или **Настройки ▸ Библиотека ▸ Импорт** на iPad. Можно также перетащить файл на Pilcrow.
- Пакет темы `.zip` может содержать темы приложения вместе с темами отображения (глава 80).
- Кнопка «Поделиться» рядом с темой сохраняет её файл `.json` или весь пакет, если тема пришла из пакета.

В Pilcrow входят три темы приложения: **Автоматически**, **Светлая** и **Тёмная**. Они задают цвета редактора и синтаксиса, а внешний вид окна оставляют встроенным.

# Chapter 80: Справочник по CSS темы отображения

**Тема отображения** — это CSS. Она оформляет предпросмотр, а также вывод в HTML, PDF, изображение и на печать, и стили Word, перечисленные в конце главы. Тема отображения может быть одним файлом `.css` или частью ZIP-пакета с локальными ресурсами. Профили синтаксиса определяют, как исходный текст становится документом; темы отображения лишь оформляют результат. CSS никогда не оформляет приложение или редактор: этим занимается тема приложения (глава 79).

## Каскад

Pilcrow применяет стили в таком порядке:

1. структурный сброс Pilcrow;
2. CSS выбранной темы;
3. разовый CSS из панели экспорта (**Дополнительные параметры ▸ Свой CSS**);
4. обязательные поправки для печати и отображения.

Более поздние правила побеждают по обычным правилам каскада CSS. JavaScript в темах, удалённые ресурсы, URL `file:` и `@import` не поддерживаются.

## Ресурсы

Pilcrow читает CSS темы стандартным токенизатором CSS, поэтому экранирование раскрывается до любых проверок: `u\72 l(…)` — это `url()`, а `@im\70 ort` — это `@import`. Проверяется каждое место, откуда браузер мог бы загружать данные: `url(…)`, `url("…")`, `src("…")` и строки внутри `image-set()`. Каждое из них должно быть одним из следующего:

- путь относительно пакета (`fonts/Body.woff2`, `./paper.png`). `?query` или `#fragment` допускаются и игнорируются при поиске файла;
- URL `data:` типа PNG, JPEG, GIF, WebP, SVG (`image/svg+xml`), TTF, OTF, WOFF или WOFF2;
- ссылка на фрагмент, например `url(#shadow)`, указывающая на элемент страницы.

Всё, что имеет схему, отличную от `data:` (`https:`, `file:`, `blob:`), или начинается с `//`, отклоняется, как и путь, начинающийся с `/` или содержащий `..`.

## Свойства отображения

Встроенный сброс читает эти свойства и подставляет значения по умолчанию:

| Группа | Свойства |
| --- | --- |
| Цвет | `--pt-background`, `--pt-foreground`, `--pt-secondary-background`, `--pt-secondary-foreground`, `--pt-accent`, `--pt-link-color`, `--pt-border-color` |
| Код | `--pt-code-background`, `--pt-code-foreground`, `--pt-code-keyword`, `--pt-code-string`, `--pt-code-number`, `--pt-code-comment` |
| Шрифт | `--pt-body-font-family`, `--pt-mono-font-family`, `--pt-base-font-size`, `--pt-line-height` |
| Отступы | `--pt-paragraph-spacing`, `--pt-blockquote-indent`, `--pt-list-indent`, `--pt-code-padding`, `--pt-heading-top`, `--pt-heading-bottom` |
| Таблицы | `--pt-table-header-background`, `--pt-table-stripe-background` |
| Предупреждения | `--pt-admonition-note-color`, `--pt-admonition-tip-color`, `--pt-admonition-important-color`, `--pt-admonition-warning-color`, `--pt-admonition-caution-color` |

## ZIP-пакеты

ZIP-пакет может содержать вместе темы отображения (`.css`) и темы приложения (`.json`); в настройках каждая указана со своим видом. ZIP, в котором не больше одного файла CSS и не больше одной темы приложения, манифеста не требует. В остальных случаях нужен `pilcrow-theme.json`, который перечисляет каждую тему в `variants[].file`. Вид файла определяется его расширением:

```json
{
  "id": "com.example.paper",
  "name": "Paper",
  "version": "1.0.0",
  "author": "Example Author",
  "license": "MIT",
  "cssAPIVersion": 1,
  "variants": [
    { "id": "app", "name": "Paper", "file": "Paper.json", "appearance": "automatic" },
    { "id": "light", "name": "Paper Light", "file": "Paper-Light.css", "appearance": "light" },
    { "id": "dark", "name": "Paper Dark", "file": "Paper-Dark.css", "appearance": "dark" }
  ]
}
```

Манифест описывает пакет и его темы. Значений стиля в нём никогда нет: они находятся в файлах CSS и тем приложения.

- `id` пакета задаёт имя папки установки. Он не должен начинаться с `.` или иметь пробелы в начале или в конце. Установка пакета, `id` которого уже установлен, заменяет его.
- ZIP, созданный командой Finder **Сжать**, работает как есть. Pilcrow пропускает `__MACOSX/`, `._*`, `.DS_Store` и `Thumbs.db`, а если все файлы лежат в одной папке верхнего уровня, эта папка считается корнем пакета.
- Удаление одной темы убирает её из пакета, а остальные вместе с общими ресурсами остаются. Удаление последней темы убирает пакет. Если удалённая тема была выбрана, выбор для её вида возвращается к значению по умолчанию: «Автоматически» для темы приложения, «Светлая» для темы отображения.
- CSS может ссылаться на упакованные файлы PNG, JPEG, GIF, WebP, TTF, OTF, WOFF и WOFF2 относительными путями `url(...)`. Pilcrow проверяет их сигнатуры и встраивает используемые ресурсы как data-URL, чтобы отображение и экспортированный HTML оставались автономными и работали офлайн. Пути в ZIP не могут выходить за пределы пакета, различаться только регистром или указывать на ссылки. Размер архива, число записей, размер отдельных файлов и степень сжатия ограничены.

## Word

Экспорт в Word использует значения светлого (базового) `:root` и сопоставляет эти семантические свойства с именованными стилями Word: `--pt-foreground`, `--pt-background`, `--pt-accent`, `--pt-link-color`, `--pt-code-background`, `--pt-code-foreground`, `--pt-body-font-family`, `--pt-mono-font-family`, `--pt-base-font-size` и `--pt-line-height`. У селекторов браузера и правил вёрстки нет общего соответствия в Word. Предпросмотр, HTML, PDF и изображение используют таблицу стилей целиком; Word использует это подмножество, сохраняя структуру документа, диаграммы, формулы в виде картинок, ссылки и медиа. Панель экспорта показывает это ограничение, когда выбран Word.

В Pilcrow входят две темы отображения, **Светлая** и **Тёмная**, которые являются полноценными отправными точками.
