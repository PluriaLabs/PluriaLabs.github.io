# Chapter 60: Боковая панель

В боковой панели пять разделов: **Файлы**, **Структура**, **Поиск**, **Проект** и **Ассистент**. Переключатель вверху боковой панели выбирает **Файлы**, **Структура**, **Проект** (он виден, когда открытая папка является книжным проектом) или **Ассистент** (он виден после настройки подключения). У раздела **Поиск** собственный заголовок с названием **Найти**, кнопка **Готово**, которая возвращает к файлам, и переключатель области поиска: **Этот документ** или **Папка**; открыть его можно через **Вид ▸ Поиск** (`⇧⌘F`). Разделы также переключаются в меню **Вид**, а выбор уже открытого раздела скрывает боковую панель. Чтобы изменить ширину боковой панели, перетащите её край. Над деревом файлов меню предлагает **Открыть файл…** и **Открыть папку…**.

## Файлы

Раздел «Файлы» показывает дерево открытой папки.

Если папка не открыта, в нём написано «Choose a folder to browse its files.» и предлагаются **Открыть папку** и **Открыть файл**. Папку можно и перетащить на панель. Если вы открыли отдельный файл, а его папка недоступна Pilcrow, предлагается «Browse *папка* to see the files beside this document» с кнопкой **Просмотреть папку с файлом…**.

Нажмите на файл, чтобы открыть его. Папки раскрываются и сворачиваются. Щёлкните строку правой кнопкой (на iPad нажмите и удерживайте), чтобы открыть её меню:

| Пункт | Что делает |
| --- | --- |
| **Новый файл** | Создаёт файл в папке (или рядом с файлом, на который вы нажали). |
| **Новая папка** | Создаёт там папку. |
| **Переименовать…** | Переименовывает файл или папку. |
| **Переместить в Корзину** | Перемещает в Корзину после подтверждения. Оттуда его можно вернуть. |
| **Показать в Finder** | Показывает его в Finder (Mac). |

Если для какого-то места в системе нет Корзины, Pilcrow хранит удалённые объекты в разделе **Недавно удалённые** внизу панели. Для каждого объекта там доступны **Вернуть** и **Удалить навсегда**, а **Очистить «Недавно удалённые»** безвозвратно удаляет все объекты раздела. Удаление навсегда отменить нельзя, поэтому Pilcrow сначала спрашивает. Объекты, которые вы удалили в других местах, не затрагиваются.

Скрытые файлы и папки показываются или скрываются параметром **Настройки ▸ Файлы ▸ Показывать скрытые папки и файлы**.

## Структура

Структура перечисляет заголовки активного документа с отступами по уровням. Нажмите на заголовок, чтобы перейти к нему. Стрелка рядом с заголовком сворачивает или разворачивает вложенные под ним заголовки. Документ при этом не меняется, а свёрнутое состояние не сохраняется.

Какие сообщения вы можете увидеть:

| Сообщение | Значение |
| --- | --- |
| **Нет заголовков** | Активный профиль не нашёл заголовков. |
| **Indexing outline… N%** | Большой документ ещё сканируется. |
| **Outline indexing failed. The listing may be incomplete.** | При сканировании возникла проблема. |
| **N headings near your position — scroll to see others.** | В очень большом документе показано окно структуры вокруг курсора. |

Под структурой появляется раздел **Поля**, если в документе есть поля для заполнения (глава 24). Он перечисляет их с общим числом; нажмите на поле, чтобы прокрутить к нему и выделить его. Если полей очень много, написано «Only the first fields are listed.»

## Поиск

Раздел «Поиск» ищет по всем файлам открытой папки. Если папки нет, в нём написано «Open a folder to search it.» и есть кнопка **Открыть папку…**.

| Элемент | Что делает |
| --- | --- |
| Поле **Поиск в папке** | Вводите текст, и поиск идёт по мере набора. Кнопка **очистить** опустошает поле. |
| **Aa** | **Учитывать регистр.** |
| **ab** | **Слово целиком.** |
| **.\*** | **Регулярное выражение.** О неверном шаблоне сообщается под полем. |
| Строка состояния | Показывает «Searching…» с кнопкой **Отменить**, затем «Matches: N». Поиск останавливается на 500 совпадениях и пишет «Showing the first 500 matches.» После отмены предлагается **Искать снова**. |
| **Заменить…** | Появляется, когда поиск нашёл совпадения. Открывает замену в папке (глава 63). |
| Результаты | Для каждого результата указан файл и показана строка. Нажмите на результат, чтобы открыть файл на этой строке. |

## Проект

Раздел «Проект» предназначен для книжных проектов. См. главы 34 и 35 и справочник по разделу «Проект» ниже.

### Справочник по разделу «Проект»

| Элемент | Что делает |
| --- | --- |
| **This folder is not a book project.** с кнопкой **Сделать проектом** | Показывается, когда в открытой папке нет манифеста. |
| **Повторить** | Показывается, если проект не удалось прочитать. |
| **Вид** | Выбирает **Список**, **Аннотации** или **Карточки**. |
| Название, итоги по словам | Название проекта и «N words», либо «N of target», если задана цель по числу слов в книге. |
| Фильтр **Статус** | Оставляет один статус или **Все статусы**. Сводка перечисляет каждый статус с числом файлов и слов. Менять порядок можно только при выключенном фильтре. |
| **Настройки проекта** (шестерёнка) | Открывает окно настроек, описанное ниже. |
| **Скомпилировать…** | Открывает окно компиляции (глава 64). |
| **Изменить порядок** и **Готово** | На iPad перетащите главы в новом порядке, затем выберите **Готово**. |
| **Новый файл** (плюс) | Предлагает **Новая глава**, **Новая сцена**, **Новая вводная часть**, **Новые приложения**. |
| **Не в рукописи** с кнопками **Добавить** и **Добавить все** | Перечисляет файлы папки, которых нет в манифесте. |
| Стрелка в строке | **Показать сцены** или **Скрыть сцены** под главой. |
| Метки **Отсутствует** и **Исключено** | Файл, который не удалось найти, или который вы исключили из рукописи. |
| Меню строки | **Подробности…**, **Новый файл ниже**, **Переместить главу вверх**, **Переместить главу вниз**, **Включить в рукопись**, **Исключить из рукописи**. |
| **Цель по числу слов** для каждого элемента | У каждого элемента показано число слов и цель, если она задана. |

В **Подробностях** элемента есть **Тип** (Вводная часть, Часть, Глава, Сцена, Приложения), **Статус**, **Точка зрения**, **Расположение**, **Цель по числу слов** и **Аннотация**. Если файл проекта изменился на диске, появляется «The project file changed on disk, so your last change was not applied. Try it again.» с кнопкой **Закрыть**.

В **Настройках проекта** есть **Название**, **Автор**, **Цель по числу слов в книге**, **Новые файлы создаются в формате** (синтаксис для новых глав и сцен; существующие файлы сохраняют свой), **Переменные** (имя и значение, которые записываются в тексте как `{{name}}`; `{{title}}` и `{{author}}` работают всегда) и **Что считается словом**: **Учитывать заголовки**, **Учитывать вводную часть**, **Учитывать блоки кода**. Выберите **Сохранить** или **Отменить**.

# Chapter 61: Панель форматирования и строка состояния

## Панель форматирования

Панель форматирования — необязательная строка под текстом. Показать или скрыть её можно через **Вид ▸ Панель форматирования**, **Ещё ▸ Панель форматирования**, **Настройки ▸ Редактирование ▸ Панель форматирования** или пункт **Скрыть панель инструментов** на самой панели. Она работает через активный профиль, поэтому кнопка, которую профиль выразить не может, неактивна.

| Элемент | Что делает |
| --- | --- |
| Меню **Тип абзаца** (например «Абзац» или «Заголовок 1») | Показывает тип текущей строки и меняет его: **Абзац**, **Заголовок 1** — **6**, **Цитата**, **Маркированный список**, **Нумерованный список**, **Список задач**, **Блок кода**. |
| **Жирный** (`⌘B`) | Полужирный. |
| **Курсив** (`⌘I`) | Курсив. |
| **Встроенный код** | Код. |
| **Вставить ссылку** (`⌘K`) | Создаёт ссылку. |
| **Цитата** | Включает или выключает цитату. |
| **Маркированный список** | Включает или выключает маркированный список. |
| **Больше форматирования** (**⋯**) | Более редкие команды: **Зачёркнутый**, **Вставить строчную формулу**, **Вставить список задач**, **Переключить статус задачи**, **Увеличить отступ**, **Уменьшить отступ**, **Повысить уровень заголовка**, **Понизить уровень заголовка**, **Вставить таблицу…**, **Вставить изображение…**, **Вставить диаграмму**, **Вставить график**, **Вставить выключную формулу**, **Вставить блок кода**, **Вставить предупреждение**, **Вставить горизонтальную линию**, **Вставить ссылку-сноску**, **Вставить сноску**, **Вставить оглавление**, **Вставить YAML-заголовок** и **Скрыть панель инструментов**. |

## Строка состояния

Строка состояния проходит вдоль нижнего края. Включить или выключить её можно параметром **Настройки ▸ Редактирование ▸ Показывать строку состояния**.

| Элемент | Что показывает или делает |
| --- | --- |
| **Слова**, **Стр**, **Ст** | Число слов, а также строка и столбец курсора. При выделении добавляется «Sel: N ln · N ch» — число выделенных строк и символов. |
| Меню **Синтаксис** (например «CommonMark») | Профиль этого документа. Нажмите, чтобы выбрать другой, или **Без синтаксиса** для простого текста. |
| **Fields left: N** | Показывается, когда макрос оставил поля для заполнения. Нажмите, чтобы перейти к следующему полю. |
| Ход выполнения и состояние | **Indexing N%**, **Lexing N%** во время анализа большого файла, а также **Translating N%** с надписью **About N left** и кнопкой **Отменить перевод**, пока идёт перевод. |
| **Рассинхронизировано** | Предупреждение о том, что редактор и журнал изменений документа разошлись. При сохранении файл остаётся помеченным как несохранённый, чтобы ничего не потерялось: скопируйте текст в надёжное место, затем закройте и снова откройте документ. |
| Сведения о документе | Нажмите на счётчики или на подсказку «Show document information», чтобы открыть **Сведения о документе**. |

В **Сведениях о документе** перечислены **Слова**, **Символы**, **Строки**, **Время чтения** (по вашей скорости чтения из настроек), **Курсор**, **Выделение**, **Кодировка** и **Синтаксис**. В очень большом файле счётчики относятся к загруженной части, пока не завершится индексация, а время чтения оценивается для всего файла. **Преобразовать в…** под **Кодировкой** выбирает другую кодировку текста; файл будет преобразован при следующем сохранении.


# Chapter 62: Поиск, замена, переход к строке, быстрое открытие и палитра команд

## Панель поиска

Откройте её через **Найти…** (`⌘F`), кнопку **Найти** или **Заменить…** (`⌘R`). Она находится вверху документа.

| Элемент | Что делает |
| --- | --- |
| Поле **Найти в документе** | Введите искомый текст. Совпадения подсвечиваются по мере набора. |
| **Aa**, **ab**, **.\*** | **Учитывать регистр**, **Слово целиком**, **Регулярное выражение**. |
| **Предыдущее совпадение**, **Следующее совпадение** | Переход по совпадениям (`⇧⌘G`, `⌘G`). |
| **Показать замену** / **Скрыть замену** (стрелка) | Показывает поле **Заменить на**. |
| **Заменить**, **Заменить все** | Заменяет текущее совпадение или все совпадения. Неактивны, пока нет совпадения. |
| **Искать в** (переключатель в левом конце панели) | **Этот документ** или **Папка**, чтобы искать по всей открытой папке. |
| **Закрыть панель поиска** | Закрывает её. |

Когда совпадений больше, чем подсчитывает Pilcrow, на панели написано «More matches remain». В режиме **Предпросмотр** поиск идёт по отрисованным словам и подсвечивает их, до 2 000 совпадений. Если шаблон использовать нельзя, написано «Invalid pattern». Замена доступна только в режиме «Изменить»: в режиме предпросмотра на панели написано «Replace works in Edit. Switch to Edit to change the text.» В режиме **Рядом** поиск идёт по исходному тексту и подсвечивает найденные слова в предпросмотре.

## Перейти к строке

**Перейти к строке…** (`⌃G`) открывает небольшое окно с одним полем: «Line number, or line:column». Введите `120` или `120:8` и выберите **Перейти** или **Отменить**. Номер за концом документа ведёт к последней строке. На любой другой ввод Pilcrow отвечает «Enter a line number, such as 120 or 120:8.» В очень большом файле, где строки ещё подсчитываются, он просит повторить попытку через мгновение.

## Быстрое открытие

**Быстрое открытие…** (`⇧⌘O`) — это поиск по именам файлов в открытой папке. Введите часть имени, и список сузится, а внизу появится «N matches». Выберите результат и **Открыть** или **Отменить**. Без открытой папки пункт неактивен.

## Палитра команд

**Палитра команд…** (`⌃⇧P`) перечисляет команды Pilcrow по названиям, вместе с их сочетаниями клавиш, чтобы выполнить команду, не разыскивая её меню. Вводите текст, чтобы сузить список, выберите команду и **Выполнить** или **Отменить**. Если ничего не подходит, показывается «No matching commands». Команда, которую сейчас выполнить нельзя, например правка исходного текста в режиме предпросмотра, показана неактивной. В список входят команды форматирования и вставки, команды меню «Изменить» для выделения, строк и регистра, озвучивания, переключатели меню «Вид», масштаб, разделы боковой панели, а также действия с файлами и экспортом. Сочетание клавиш для открытия палитры можно изменить в **Настройки ▸ Клавиатура**.
