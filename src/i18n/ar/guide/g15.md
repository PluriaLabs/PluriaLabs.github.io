# Chapter 81: الملفات والترميزات والحدود

## الملفات التي يفتحها Pilcrow

يحرّر Pilcrow ملفات النص العادي وملفات الترميز. الامتدادات المعتادة هي `txt` و`md` و`markdown` و`adoc` و`asciidoc` و`rst` و`tex`، وأي امتداد يطالب به ملف تعريف تضيفه. يكتشف Pilcrow ترميز نص الملف عند فتحه.

| العنصر | النوع |
| --- | --- |
| ملف تعريف الصياغة، ومجموعة الماكرو، ودليل الأسلوب، وسمة التطبيق | `.json` |
| سمة العرض | `.css` |
| حزمة السمة | `.zip` |
| بيان مشروع الكتاب | `manifest.pilcrow` |
| الخلفية | HEIC وPNG وJPEG وSVG وMP4 وMOV وM4V |
| مقطع صوت الكتابة | WAV وAIFF وMP3 وM4A وCAF |

## ترميزات النص

يقرأ Pilcrow نصوص UTF-8 وUTF-16 وUTF-32 وISO 8859-1 (Latin-1). يمكنك تحويل مستند باستخدام **معلومات المستند ▸ الترميز ▸ تحويل إلى…** إلى أي مما يلي؛ ويُحوَّل الملف عند حفظه في المرة التالية:

UTF-8، UTF-8 (BOM)، UTF-16 LE، UTF-16 LE (BOM)، UTF-16 BE، UTF-16 BE (BOM)، UTF-32 LE، UTF-32 LE (BOM)، UTF-32 BE، UTF-32 BE (BOM).

يمكن تحويل ملف Latin-1 إلى أي من هذه من دون فقدان. أما التحويل إلى Latin-1 فلا يُعرض، لأنه قد يُتلف المحتوى.

## صيغ التصدير

| الصيغة | الامتداد |
| --- | --- |
| HTML، HTML (بدون أنماط) | `.html` |
| PDF | `.pdf` |
| Word (‎.docx) | `.docx` |
| صورة | `.png` |
| أرشيف PDF | `.zip` |

## الحدود والأرقام

أين يتوقف Pilcrow، أو أين يكون للخيار نطاق:

| أين | الحد |
| --- | --- |
| لوحة البحث | تتوقف عند 500 نتيجة. |
| البحث في المعاينة | يعدّ حتى 2,000 نتيجة. |
| الاستبدال في المجلد | يغيّر 2,000 ملف على الأكثر في كل مرة. |
| فحص الروابط | يفحص حتى 50,000 رابط. |
| المقارنة | تعرض حتى 5,000 سطر متغيّر. |
| الإصدارات المحتفَظ بها | من بلا إلى 500 (الافتراضي 50). |
| الأسطر الطويلة | الأسطر التي تبلغ 20,000 حرف أو أكثر تلتف دائمًا. |
| حجم الخط | من 9 إلى 32 نقطة. |
| عرض Tab | من 2 إلى 8 مسافات. |
| عرض النص | من 50% إلى 100%. |
| تكبير/تصغير | من 50% إلى 200%، في عشر خطوات. |
| سرعة القراءة | من 60 إلى 2,000 كلمة في الدقيقة. |
| عرض المستعرض | من 180 إلى 420 نقطة. |
| مقطع صوت الكتابة | ثانيتان و3 ميغابايت على الأكثر. |
| نص سجل تقرير التشخيص | أحدث الإدخالات، حتى 60,000 حرف، عند إضافته إلى وصف مشكلة على GitHub. |
| الملفات الكبيرة جدًا | تُفتح وتُحرَّر من دون قراءتها في الذاكرة كاملة. تكتمل أعداد الأسطر والكلمات والمخطط في الخلفية وقد تكون جزئية إلى حين ذلك. يحتاج تصدير PDF لمستند كبير جدًا إلى ذاكرة أكبر بكثير من التحرير أو تصدير HTML وWord؛ أما أرشيف PDF فيقسّمه إلى أجزاء محدودة. |

## أين يحتفظ Pilcrow بالأشياء

| ماذا | أين |
| --- | --- |
| مستنداتك | حيثما حفظتها. |
| المكتبة (السمات وملفات التعريف والماكرو وأدلة الأسلوب والخلفيات) | في التخزين الخاص بالتطبيق، أو في مجلد باسم "Pilcrow Library" داخل مجلد تختاره (**الإعدادات ▸ المكتبة ▸ الموقع**). |
| التفضيلات ومفاتيح API ونسخ الاسترداد وسجل الإصدارات | على الجهاز، في التخزين الخاص بالتطبيق وسلسلة المفاتيح. راجعها واحذفها في **الإعدادات ▸ عام ▸ التخزين والخصوصية**. |
| سجل التشخيص | على الجهاز، إلى أن تمسحه. |

# Chapter 82: الرسائل واللافتات والحالات الفارغة

يشرح هذا الفصل الرسائل القصيرة التي يعرضها Pilcrow، فلا تبقى أي منها لغزًا.

## في المحرر والمعاينة

| الرسالة | ماذا تعني |
| --- | --- |
| **لا شيء لمعاينته بعد. ابدأ الكتابة وسيظهر هنا.** (أو "انتقل إلى التحرير وابدأ الكتابة.") | المستند فارغ، فلا يوجد ما يُرسم في المعاينة. |
| **تعذّر عرض المعاينة: …** مع **إظهار المصدر** و**إعادة المحاولة** | فشلت المعاينة. **إظهار المصدر** ينتقل إلى التحرير. **إعادة المحاولة** تحاول مجددًا. |
| معادلة أو مخطط فاشل، مع رابط **إظهار المصدر** | تعذّر رسم كتلة واحدة. انقر **إظهار المصدر** للانتقال إلى مصدر تلك الكتلة وإصلاحه. |
| **تعذّر الحفظ** مع **إعادة المحاولة** وزر إغلاق | فشل الحفظ. يبقى المستند مفتوحًا وغير محفوظ. أصلح السبب (مساحة القرص أو الأذونات أو ملف نُقل) واختر **إعادة المحاولة**. |
| **تغيّر الملف على القرص** | عدّل تطبيق آخر الملف. **إعادة التحميل** تقرأ الإصدار الجديد؛ و**الإبقاء على الإصدار الحالي** يُبقي ما لديك. |
| **تحذير التحليل** | سطر يُحتمل أن يكون فيه تركيب لا تقصده (الفصل 68). |
| **هل تريد استبدال الملف الموجود؟** | الاسم الذي اخترته مستخدم بالفعل في ذلك المكان. |
| **لا تزال هناك حقول للملء** | أنت تطبع أو تصدّر وبعض الحقول غير معبّأة (الفصل 63). |
| **فاصل الألواح** (تلميح VoiceOver: "اسحب لتغيير حجم المحرر والمعاينة. انقر نقرًا مزدوجًا لإعادة الضبط.") | المقبض بين المصدر والمعاينة في جنبًا إلى جنب. |
| **الكلمات: N** | عدد الكلمات في شريط الحالة. |

## في مربعات الحوار واللوحات

| أين | الرسالة | المعنى |
| --- | --- | --- |
| لوحة الأوامر | **اكتب أمرًا** | تلميح الحقل. تظهر "لا توجد أوامر مطابقة" حين لا يناسب شيء. |
| الفتح السريع | **اكتب اسم ملف** | تلميح الحقل. |
| مؤشرات إدخال في عمود | **الأسطر (مثل 3-17)**، **العمود (مثل 100، أو 100-105 للتحديد)** | تلميحات الحقول. عمود واحد يضع مؤشرات إدخال؛ ونطاق يحدّد تلك الأحرف في كل سطر. |
| لوحة البحث | **اكتب للبحث في هذا المجلد.**، **لا توجد نتائج في هذا المجلد.**، **أُلغي البحث.** | حالة البحث في المجلد. |
| لوحة الملفات | **يمكنك أيضًا إسقاط مجلد هنا.** | اسحب مجلدًا إلى اللوحة لفتحه. |
| الاستبدال في المجلد | **لا شيء للاستبدال.** | لا توجد نتائج للبحث. |
| المقارنة | تلميحات الأزرار: **قبول** ("إجراء هذا التغيير في المستند المفتوح")، **رفض** ("ترك هذا التغيير خارج المستند المفتوح")، **سحب** ("إعادة الأسطر الأقدم إلى المستند لهذا التغيير فقط"). | ما يفعله كل منها. |
| ترجمة | **تعذّر إكمال الترجمة.** | حاول مجددًا، أو اختر سرعة أخرى. |
| ترجمة | **الوقت المقدَّر: أقل من دقيقة** | تقدير لسرعة مساعد الذكاء الاصطناعي؛ ويعتمد الوقت على خدمة الذكاء الاصطناعي لديك. بعد الترجمة، **فتح في علامة تبويب جديدة** يفتح النتيجة. |
| المساعد | **لا يوجد مستند مفتوح.**، **لا يُرسَل أي نص من المستند.** | ليس في اللوحة ما يُشارَك، فلا يُرسَل شيء. |
| منتقي النموذج | **جارٍ تحميل النماذج…**، **لا توجد نماذج مطابقة.** | القائمة قيد التحميل، أو لم يجد بحثك شيئًا. |
| مراجعة الأسلوب | **لا توجد ملاحظات.** و**تعذّرت قراءة الرد كملاحظات. حاول مجددًا.** | لم تجد المراجعة شيئًا، أو لم يكن رد الذكاء الاصطناعي بالشكل المتوقع. |
| مراجعة الأسلوب | تلميح **تطبيق الكل**: "يجري كل إصلاح له إصلاح، كتغيير واحد يمكنك التراجع عنه." | تراجع واحد يعكسها كلها. |
| لوحة المشروع | **اسمك**، **إضافة متغيّر** | تلميح حقل المؤلف، وزر متغيّر المشروع. |
| إذن المساعد | **اقرأ سياسة الخصوصية في Pilcrow** | يفتح سياسة الخصوصية. |

## في الإعدادات

| أين | الرسالة | المعنى |
| --- | --- | --- |
| لوحة المفاتيح | **اضغط الاختصار الجديد، ثم انقر حفظ.** و**اضغط أي مفتاح…** | أثناء تسجيل اختصار. |
| المكتبة ▸ الموقع | **موقع المكتبة**، **جارٍ نقل مكتبتك…** | عنوان الصفحة، والتقدم أثناء نقل المكتبة. |
| اتصال المساعد | **اتركه فارغًا للإبقاء على المفتاح المحفوظ.** | عند التحرير، يُبقي حقل المفتاح الفارغ المفتاح الموجود أصلًا في سلسلة المفاتيح. |
| محرر الماكرو | **المشغّل — مثل /sig** | تلميح حقل المشغّل. |
| محرر ملف التعريف | **JSON متقدم للملف التعريفي**، **العيّنة والنتائج** | عنوان محرر JSON، والمنطقة تحت اختبار العيّنة التي تعرض العقد التي تنتجها العيّنة. |
| التشخيصات | **كل الأجزاء** (في عارض السجل)، **لا توجد إدخالات مطابقة.** | السجل غير المصفّى، ومرشّح لا يطابق شيئًا. |
| شريط الحالة | علامة حمراء **جارٍ تسجيل السجل**؛ وتلميحها **إظهار إعدادات التشخيص** | يجري تسجيل سجل. انقر عليها لفتح صفحة التشخيصات. **أوقف التسجيل وأنهِ تقرير الخطأ** هو التلميح على **إعادة إنتاج — إنهاء التقرير**. |
| شريط الحالة | **اختر ملف تعريف الصياغة لهذا المستند** | التلميح على قائمة الصياغة. |
| عنصر العنوان | **المستندات المفتوحة وإجراءات المستند** | التلميح على عنوان المستند. |
