# Chapter 75: محررا السمات

هناك نوعان من السمات، ولكل نوع محرره الخاص. افتح أيًّا منهما من **الإعدادات ▸ المكتبة ▸ السمات**: يُنشئ **جديد** سمة، ويغيّر **تحرير** سمة مخصصة، وينسخ **تكرار** سمة مدمجة لكي تغيّر النسخة. لا يمكن تحرير السمات المدمجة.

## محرر سمة العرض

يضبط **تحرير سمة العرض** نمط المعاينة وHTML وPDF والصور ومخرجات الطباعة. وتحدد خصائص Pilcrow المخصصة فيه أنماط Word أيضًا. لا تضبط سمة العرض نمط التطبيق ولا المحرر.

| الجزء | وظيفته |
| --- | --- |
| **الاسم** | اسم السمة. |
| **المظهر** | **تلقائي** أو **فاتح** أو **داكن**. |
| **CSS** | ورقة الأنماط، في محرر شيفرة. راجع Chapter 80 للاطلاع على الخصائص والفئات. |
| **المعاينة المعروضة** | مستند نموذجي يُرسم بشيفرة CSS الخاصة بك أثناء الكتابة، لترى التأثير. |
| **تشخيصات CSS** | المشكلات التي وجدها Pilcrow في CSS، مثل مورد بعيد غير مسموح به. |
| **إلغاء**، **حفظ** | إغلاق السمة أو الاحتفاظ بها. عند الإغلاق مع وجود تغييرات يظهر السؤال **هل تريد تجاهل تغييرات السمة؟** مع **تجاهل التغييرات** أو **متابعة التحرير**. |
| **خط الأساس** | يتجاهل **إعادة الضبط إلى خط الأساس** كل تغيير منذ إنشاء السمة أو تكرارها أو استيرادها (بعد أن تؤكد). ويحفظ **تعيين كخط أساس جديد** السمة ويجعل حالتها الحالية نقطة الاستعادة. |

## محرر سمة التطبيق

يضبط **تحرير سمة التطبيق** نمط Pilcrow نفسه: مظهره ولون التمييز والشريط الجانبي والأشرطة والمحرر.

| الجزء | وظيفته |
| --- | --- |
| **الاسم** | اسم السمة. |
| **المظهر** | **تلقائي** أو **فاتح** أو **داكن**. للسمة التلقائية لوحتا ألوان. |
| **تحرير الألوان لـ** | في السمة التلقائية، **فاتح** أو **داكن**: أي اللوحتين تحرّر. |
| الألوان، في خمس مجموعات | **التطبيق** (لون التمييز)، و**الشريط الجانبي** (الخلفية والمقدمة)، و**أشرطة الحالة والتنسيق** (الخلفية والمقدمة)، و**المحرر** (الخلفية والمقدمة والمؤشر والتحديد وخلفية الهامش ومقدمة الهامش وقاعدة السطر الحالي)، و**الصياغة** (العنوان والعلامة والشيفرة والرابط والخافت، وكلمة مفتاحية وسلسلة نصية ورقم وتعليق في الشيفرة). يعرض كل لون **افتراضي** إلى أن تحدد لونًا، ويعيده زر **إعادة ضبط** إلى حاله. |
| **معاينة** | نسخة مصغرة من Pilcrow، بشريط جانبي ومحرر وشريط حالة، بالألوان التي اخترتها، فاتحة أو داكنة. |
| **إلغاء**، **حفظ**، **خط الأساس** | كما سبق. |

يمكن للسمة أيضًا تلوين رموز صياغة فردية. تُحفظ هذه الألوان، لكنها تُحرَّر في ملف JSON الخاص بالسمة (`syntax.tokens`)؛ راجع Chapter 79.

# Chapter 76: محرر الماكرو

افتح محرر الماكرو من **الإعدادات ▸ المكتبة ▸ الماكرو**: **جديد** داخل مجموعة، أو **تحرير** على ماكرو. عنوانه **ماكرو جديد** أو **تحرير الماكرو**.

| الحقل | وظيفته |
| --- | --- |
| **الاسم** | تسمية للماكرو. |
| **المشغّل** (مثل `/sig`) | النص الذي يبدأه. يتوسع الماكرو عندما تكتب المشغّل متبوعًا بمسافة أو علامة جدولة أو Return. |
| **تطابق** | كيفية قراءة المشغّل: **النص المطابق تمامًا** أو **البادئة** أو **تعبير نمطي**. يُرفض التعبير النمطي الذي قد يعلّق المحرر: "That regular expression could hang the editor. Simplify it." |
| **الاستبدال** | النص الذي يتوسع إليه. |
| **إدراج التاريخ/الوقت** | قائمة تضيف رمز تاريخ أو وقت إلى الاستبدال. |
| **مفعَّل** | يشغّل الماكرو أو يوقفه دون حذفه. |
| **عدم التوسيع داخل الشيفرة** | يمنع الماكرو من العمل داخل مقاطع الشيفرة وكتل الشيفرة. |
| **إلغاء**، **حفظ** | إغلاق الماكرو أو الاحتفاظ به. إن تعذّر الحفظ فإن الرسالة توضح السبب. |

في الاستبدال، تمثل `$1` و`$2` وهكذا محطات توقف بعلامة الجدولة، وتمثل `$0` الموضع الذي يستقر فيه المؤشر. بعد توسع الماكرو، ينتقل Tab (أو **الحقل التالي**) من محطة إلى أخرى. تستخدم التواريخ والأوقات رموزًا: `{{date:yyyy-MM-dd}}` و`{{time:HH:mm:ss}}` و`{{datetime:MM/dd/yyyy h:mm a}}`، وصيغًا مسماة هي `iso8601` و`rfc2822` و`unix` و`short` و`medium` و`long` و`full`. يعرض سطر **Now:** أسفل الحقل ما سينتجه الاستبدال في هذه اللحظة.

# Chapter 78: استخدام Pilcrow على iPad

يعمل Pilcrow على iPadOS 17 أو أحدث. ويعمل باللمس وحده، ومع لوحة مفاتيح خارجية، ومع لوحة تتبع أو فأرة.

## اللمس

- **فاصل الألواح.** في **جنبًا إلى جنب**، اسحب الفاصل بين المصدر والمعاينة لتغيير حجمهما. انقر عليه مرتين لإعادة الضبط.
- **المستعرض.** اسحب حافة الشريط الجانبي لتغيير حجمه. في النافذة الضيقة يغطي الشريط الجانبي المستند، ويغلقه زر **تم**.
- **تحديد الأعمدة.** فعّل **المزيد ▸ تحديد الأعمدة**، ثم اسحب بإصبع واحد لتحديد مستطيل من النص. ما زال الإصبعان يمرّران الصفحة. تظهر شارة **تحديد الأعمدة** أثناء التفعيل، مع زر لإيقافه. أو استخدم **المزيد ▸ مؤشرات إدخال في عمود…** لوضع مؤشرات الإدخال بحسب العدد.
- **قائمة السياق.** اضغط مطولًا في النص لتظهر قائمة المحرر (أدناه).
- **الملفات.** اضغط مطولًا على ملف في لوحة الملفات لتظهر قائمته (Chapter 60).

## مع لوحة مفاتيح خارجية

تعمل كل اختصارات Chapter 77. اضغط باستمرار على **⌘** لرؤية شريط قوائم iPad، أو حرّك المؤشر إلى أعلى الشاشة. يمكن لـ Pilcrow إخفاء قوائمه في الترويسة عند توصيل لوحة مفاتيح أو فأرة؛ راجع **الإعدادات ▸ المظهر ▸ القوائم في الترويسة**.

## مع لوحة تتبع أو فأرة

تفتح النقرة بزر الفأرة الأيمن قائمة سياق المحرر. اضغط باستمرار على **Option** أثناء السحب لتحديد مستطيل من النص.

## قائمة سياق المحرر

انقر بالزر الأيمن على Mac، أو اضغط مطولًا على iPad، في النص. تظهر العناصر التي لا يستطيع ملف الصياغة النشط التعبير عنها باهتة، ويضيف النظام عناصره الخاصة (قص ونسخ ولصق واقتراحات الإملاء والبحث وغيرها).

على **Mac**:

| العنصر | وظيفته |
| --- | --- |
| **نسخ / لصق كـ…** | **نسخ كـ Markdown** و**نسخ كنص عادي** و**نسخ كشيفرة HTML** و**لصق كنص عادي**. |
| **فقرة** | **فقرة** و**العنوان 1** إلى **6** و**اقتباس** و**قائمة نقطية** و**قائمة مرقمة** و**قائمة المهام** و**سياج شيفرة**. |
| **تنسيق** | **غامق** و**تأكيد** و**شيفرة** و**يتوسطه خط** و**رياضيات ضمن السطر** و**معادلة معروضة** و**مخطط توضيحي** و**مخطط** و**رابط تشعبي**. |
| **التحديد** | **تحديد الكلمة** و**تحديد السطر** و**تحديد الفقرة**. |

على **iPad**، توجد ثلاث قوائم فرعية مع عناصر النظام:

| العنصر | وظيفته |
| --- | --- |
| **تنسيق** | الأنماط ضمن السطر: الغامق والتأكيد والشيفرة وغيرها. |
| **فقرة** | أنواع الفقرات: العناوين والاقتباس والقوائم وسياج الشيفرة. |
| **إدراج** | عمليات الإدراج نفسها في قائمة **المزيد** بشريط التنسيق، ومنها **إدراج تنبيه** و**إدراج صورة…** و**إدراج جدول…**، وتحت **الصياغة** بنى ملف الصياغة النشط الخاصة. |
