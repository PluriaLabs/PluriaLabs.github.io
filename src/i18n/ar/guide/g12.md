# Part XIX — محررات عناصر المكتبة

# Chapter 74: محرر الملف التعريفي ولبنات بناء الملفات التعريفية

يخبر ملف تعريف الصياغة Pilcrow بمعنى علامات الصياغة التي تكتبها. يصف هذا الفصل محرر الملف التعريفي عنصرًا عنصرًا، ثم يسرد كل لبنة بناء يمكن لملف تعريفي استخدامها. للتعرف على الموضوع بحسب المهام، راجع الفصل 37 إلى الفصل 39.

افتح المحرر من **الإعدادات ▸ المكتبة ▸ ملفات تعريف الصياغة**: يبدأ **جديد** ملفًا تعريفيًا، ويغيّر **تحرير** ملفًا مخصصًا، وينسخ **تكرار** ملفًا تعريفيًا مدمجًا لتتمكن من تغيير النسخة. عنوان المحرر هو **تحرير الملف التعريفي**، وفيه **إلغاء** و**حفظ** و**تعليمات الملف التعريفي** (الذي يفتح المرجع المدمج في التطبيق لهذه اللبنات). على الشاشة الضيقة، يختار مفتاح **قسم الملف التعريفي** بين **نظرة عامة** و**القواعد** و**عيّنة الاختبار**؛ وعلى الشاشة العريضة تظهر الثلاثة معًا.

## نظرة عامة

| الحقل | ما يفعله |
| --- | --- |
| **الاسم** | اسم الملف التعريفي، ويظهر في قائمة شريط الحالة وفي الإعدادات. |
| **الوصف** | ملاحظة عن الملف التعريفي. |
| **امتدادات الملفات (مفصولة بفواصل)** | الامتدادات التي تختار هذا الملف التعريفي لملف ما. لا يمكن لملفين تعريفيين مشاركة امتداد واحد. |
| **يرث** | **بلا**، أو ملف تعريفي آخر يبني هذا الملف على قواعده. |
| **الصياغة** | **يمدّد Markdown** أو **يستبدل Markdown** (أدناه). |
| **لمحة سريعة** | أعداد **قواعد الكتل** و**القواعد ضمن السطر** و**قواعد التداخل**. |
| **تحرير JSON المتقدم…** | يفتح الملف التعريفي بصيغة JSON للحقول التي لا يعرضها المحرر الموجَّه. يحتفظ **تطبيق** بتغييرات JSON التي أجريتها؛ ويتجاهلها **إلغاء**. |

يضيف **يمدّد Markdown** قواعدك إلى قواعد Markdown: تظل عناوينه وقوائمه وتأكيده وغيرها مقروءة، وتُضاف قواعد الكتل والقواعد ضمن السطر لديك إليها. القاعدة التي هي نسخة غير معدّلة من إحدى قواعد ملف CommonMark التعريفي تصف ما يفعله Markdown أصلًا، وتُترك له. يجعل **يستبدل Markdown** قواعدك هي الصياغة كلها، فتتوقف تراكيب Markdown عن أن تُعرَف. ومعه، يجب أن تنتج قاعدة واحدة **نهاية السطر**، وإلا لن يوجد ما يفصل الفقرات. يحذّر المحرر "Add a rule whose output node is "newline", or nothing will separate into paragraphs"، ولا يمكن حفظ الملف التعريفي حتى توجد قاعدة كهذه. ويسرد أيضًا أي أنواع مخرجات لا يعرّفها الملف التعريفي.

## القواعد

تأتي القواعد في ثلاث مجموعات.

### قواعد الكتل

تتعرف قاعدة الكتلة على أسطر وكتل كاملة. يضيف **إضافة قاعدة** قاعدة. لكل قاعدة **نمط** ونوع **تطابق** وما **ينتج** عنها و**الخيارات**. تُزال القاعدة بزر **حذف** الخاص بها. وعند عدم وجود أي قاعدة، يقول المحرر "No rules yet. Add one to recognize a block construct."

### القواعد ضمن السطر

تتعرف القاعدة ضمن السطر على نص داخل سطر. يضيف **إضافة قاعدة ضمن السطر** قاعدة. تقدّم القواعد ضمن السطر أربعة أنواع تطابق (**بادئة حرفية** و**حرفي مطابق تمامًا** و**تعبير نمطي (محدود)** و**زوج محدِّدات**)؛ أما قواعد الكتل فتقدّم الأنواع السبعة كلها.

### قواعد التداخل

تحدد قواعد التداخل أي المخرجات يجوز أن تقع داخل أيها. لكل قاعدة **العقدة الأصل** و**العناصر الفرعية المسموح بها (مفصولة بفواصل)**. الفراغ يعني بلا قيود: "No restrictions. Every node type may nest inside any other." يضيف **إضافة قاعدة تداخل** قاعدة.

### أنواع التطابق

| نوع التطابق | يقرأ النمط على أنه | كتلة | ضمن السطر |
| --- | --- | --- | --- |
| **بادئة حرفية** | نص يبدأ به التركيب. | نعم | نعم |
| **حرفي مطابق تمامًا** | النص الكامل للتركيب. | نعم | نعم |
| **بادئة بداية السطر** | نص في بداية السطر، مثل `# `. | نعم | |
| **كتلة مُزاحة** | أسطر تبدأ بالنمط، مثل أربع مسافات أو علامة جدولة. المتتالية منها، والأسطر الفارغة بينها، كتلة واحدة، وتُعرض بلا الإزاحة. | نعم | |
| **كتلة مسيَّجة** | سطر يفتح كتلة، وتُغلق بسطر مطابق. | نعم | |
| **تعبير نمطي (محدود)** | تعبير نمطي. يحذّر Pilcrow قبل حفظ تعبير قد يتعطل: "This regex could hang the editor — simplify it." | نعم | نعم |
| **زوج محدِّدات** | العلامة نفسها على جانبي نص في سطر واحد، مثل `%%` في `%%this%%`. لا توجد مسافة مباشرة داخل العلامتين. | نعم | نعم |

في التعبير النمطي، يسمّي `(?<name>…)` جزءًا من التطابق. انظر الأجزاء المسماة أدناه.

## خيارات القاعدة

تقدّم مجموعة **الخيارات** في كل قاعدة ما يلي:

| الخيار | ما يفعله |
| --- | --- |
| **الأولوية** | تُجرَّب القواعد ذات الأولوية الأعلى أولًا. |
| **فقط في بداية السطر** | يمنع القاعدة من التطابق في منتصف السطر. |
| **الأجزاء المسماة تصبح خصائص** | يصبح كل جزء مسمى في التعبير النمطي خاصية للمخرج. يسرد المحرر "Parts in this pattern" و"Parts this output reads". بالنسبة إلى مخرج يحمل نصًا، مثل الغامق أو الرابط، يكون النص المعروض هو الجزء المسمى `text` إن وجد، وإلا فآخر جزء تطابق. |
| **ينتج** | ما تصنعه القاعدة: مخرج من القوائم أدناه، أو اسم **مخصص**. |
| **اسم عقدة مخصص** | الاسم الخاص بمخرج **مخصص**. |
| **خصائص ثابتة** | أجزاء لها القيمة نفسها في كل مرة، تُضاف بـ **إضافة خاصية** (**الاسم** و**القيمة**). قد تتضمن القيمة جزءًا مسمى، يُكتب `{name}`: قاعدة بريد إلكتروني يسمّي نمطها `address` يمكنها أن تمنح رابطها `url` بالقيمة `mailto:{address}`. |
| **إدراج نص** | ما تكتبه قائمة **إدراج** لهذه القاعدة، تمامًا كما ينبغي أن يظهر، مع `$0` حيث يجب أن يوضع مؤشر الإدخال. القاعدة التي يطابقها تعبير نمطي أو كتلة أو إزاحة تحتاج إلى هذا، وإلا حذفتها قائمة إدراج. |
| **فقط بعد سطر فارغ** | بالنسبة إلى كتلة مُزاحة: يظل السطر المُزاح الذي يلي نصًا مباشرة جزءًا من ذلك النص، مثل السطر التالي لعنصر قائمة. |
| **بعد الضغط على Return في نهاية سطر** | بالنسبة إلى القوائم والاقتباسات: **تلقائي** (يكرر النقاط والاقتباسات، ويعدّ العناصر المرقمة تصاعديًا، ويبدأ عناصر المهام غير محددة)، أو **كرّر العلامة**، أو **عدّ تصاعدي**، أو **البدء من جديد من العلامة**، أو **عدم إضافة شيء**. |

### الكتل المسيَّجة والمحدَّدة

بالنسبة إلى قاعدة **كتلة مسيَّجة**، يحدد **تحتوي الكتلة على** ما بداخلها:

| الاختيار | المعنى |
| --- | --- |
| **لا شيء بعد** | غير محدد. |
| **نص يُعرَض كما كُتب** | شيفرة أو نص مُنسَّق مسبقًا. |
| **لا شيء — مخفي** | تعليق، يُستبعد من المستند. |
| **كتل أخرى، في مربع** | اقتباس أو شريط جانبي أو تنبيه يحتوي على فقرات وقوائم وغيرها. |
| **كتل أخرى، بلا مربع** | تنضم الكتل إلى النص المحيط؛ وتكتفي الأسطر بتجميعها. |
| **جدول** | انظر الجداول أدناه. |
| **جدول مرسوم بالنص** | شبكة أو أعمدة محاذاة من النص تمتد من سطرها الافتتاحي إلى السطر الفارغ التالي، مثل جداول reStructuredText. |
| **نص مُزاح تحت سطر ينتهي بعلامة** | السطر الافتتاحي نثر ينتهي بالعلامة، كما يفعل `::` في reStructuredText؛ يبقى النثر فقرة، ويُعرض النص المُزاح تحته بعد سطر فارغ كما كُتب. |
| **نص مُزاح تحت سطر افتتاحي** | توجيه مثل `.. code-block::`، يحتوي على الأسطر المُزاحة تحته وليس له سطر إغلاق. |

**سطر الإغلاق** هو السطر الذي ينهي الكتلة؛ والفراغ يعني السطر نفسه الخاص بالافتتاح ("Same as the opening line"). المحدِّد الذي ليس تعبيرًا نمطيًا، مثل `+++`، يُطابَق كنص عادي. **يكرر سطر الإغلاق علامة الفتح، وبعدد مرات لا يقل عنها** مخصص للأسيجة على نمط Markdown: سطر الإغلاق هو الحرف الأول من سطر الفتح مكررًا بعدد مرات لا يقل عن عدده، فيحتوي سياج أطول سياجًا أقصر كنص. تُلوَّن لغة كتلة النص في المحرر عندما يسمّي سطر الافتتاح لغة معروفة.

### الجداول

خيارات كتلة الجدول:

| الخيار | ما يفعله |
| --- | --- |
| **التخطيط** | **شبكة بخطوط فاصلة** (خلايا بين `|` مع خط فاصل بين الصفوف) أو **أعمدة محاذاة** (أعمدة متراصة تحت أول خط فاصل). |
| **فاصل الخلايا** | النص الذي تبدأ به كل خلية. |
| **نمط الخط الفاصل**، **نمط سطر فاصل الرأس** | أسطر ترسم خطًا فاصلًا فقط، والسطر الذي ينهي الرأس. |
| **ينتهي الصف بـ** | علامة تنهي كل صف، كما يفعل `tabular` في LaTeX. |
| **نمط الخلية الممتدة** | خلية تمتد على عدة أعمدة. |
| **نمط خيارات الخلية** | تعبير نمطي لما قد يأتي قبل فاصل الخلية مباشرة؛ والجزء المسمى `colspan` يجعل الخلية تمتد على هذا العدد من الأعمدة. |
| **فاصل قائمة الأعمدة**، **تكرار العلامة** | كيفية كتابة قائمة `columns`: بـ `,` و`*`، فتعني `3*` ثلاثة أعمدة. |
| **السطر الأول قبل سطر فارغ هو الرأس** | صف الرأس يُستدل عليه من التخطيط. |
| **التنسيقات** | طرق أخرى لكتابة الخلايا، لكل منها اسم وفاصل (مثل `csv` و`,`)، تُضاف بـ **إضافة تنسيق** وتُختار بالجزء `format` في الجدول. |

## إعدادات على مستوى الملف التعريفي

| الإعداد | ما يفعله |
| --- | --- |
| **تداخل القوائم بحسب العلامة** | كل علامة جديدة، مثل `**` بعد `*`، تبدأ مستوى أعمق، مهما كانت الإزاحة. |
| **سطر متابعة القائمة** | سطر منفرد بعد عنصر قائمة يربط الكتلة التالية بالعنصر. |
| **الحفاظ على فواصل الأسطر المفردة** | يبقى فاصل السطر داخل الفقرة فاصل سطر. |
| **إعطاء العناوين معرّفات** | العنوان الذي ليس له معرّف خاص يحصل على واحد من عنوانه: بأحرف صغيرة، وكلمات يربطها **فاصل الكلمات**، بعد **البادئة** (**بادئة معرّف العنوان**، **فاصل كلمات معرّف العنوان**). مع `_` و`_`، يصبح "Getting Started" هو `_getting_started`، فتعرض الإحالة المرجعية إليه العنوان. العنوان المكرر يضيف الفاصل ورقمًا. |
| **ترقيم العناوين** | بمجرد أن يعرّف المستند الخاصية المسماة في **عندما يعرّف المستند**، مثل `:sectnums:` في AsciiDoc، تُرقَّم العناوين من **من مستوى العنوان** فنازلًا: `1.` و`1.1.` و`2.`. أما العناوين التي تسبق التعريف فلا تُرقَّم. |
| **تعليقات توضيحية مرقمة** | الكتلة ذات العنوان من مخرج مدرج هنا، مثل `image` أو `table` أو `example`، تحصل على **التسمية** ورقمها الخاص قبل عنوانها (مثل "Figure 1.")، في **موضع التعليق التوضيحي**، **أعلى** الكتلة أو **أدناه**. تُضاف بـ **إضافة تعليق توضيحي**. |

## علامات ضمن السطر تتزاوج بحسب ما يحيط بها

تكتب لغة مثل Markdown الغامق والمائل بسلسلة أحرف تفتح أو تغلق بحسب الأحرف المجاورة لها، وتكتب مقطع الشيفرة أو الرابط بأقواس، فلا يستطيع نمط واحد للتركيب كله العثور عليها. فعّل **قراءة العلامات بحسب ما يحيط بها** لوصفها.

| الإعداد | ما يفعله |
| --- | --- |
| **حرف الإفلات** | حرف يجعل الحرف التالي عاديًا. |
| **حرف مقطع الشيفرة** | سلسلة من هذا الحرف تفتح مقطعًا تغلقه السلسلة التالية بالطول نفسه. |
| **علامات التشغيل** | علامات تتزاوج كسلاسل، تُضاف بـ **إضافة علامة تشغيل**. لكل منها **علامة**، وما **علامة واحدة ترسم**، وما **علامتان ترسمان**، و**قد يُفتح أو يُغلق داخل كلمة** (معطّل مع `_`). |
| **علامات الأزواج** | علامات تتزاوج مع سلسلة بالطول نفسه، تُضاف بـ **إضافة علامة زوج**: **العلامة**، وما **يرسم**، و**فقط عندما يكون هذا الإعداد مفعّلًا**، وهو إعداد صياغة مثل التمييز يجب أن يكون مفعّلًا (أو **دائمًا**). |
| **الروابط وعناوين الويب** | **بادئة الصورة**، و**العنوان المكتوب بمفرده محاط بـ**، و**المخططات التي يبدأ بها العنوان المجرّد**، و**السطر الذي يعرّف تسمية يحتوي على**، و**تبدأ تسمية الحاشية بـ** (الحرف الذي يلي قوس فتح التسمية ويجعلها حاشية: يُرسَم `[^note]` كمرجع حاشية عندما يبدأ سطر بـ `[^note]:`). |

تتزاوج العلامات داخل السطر. الشيفرة والأحرف المُفلَتة وعنوان الرابط نص عادي بالنسبة إلى العلامات المحيطة بها.

## مصدر منسَّق

عند تفعيل **مصدر منسَّق**، يرسم المحرر المستند بمظهر صياغته: عناوين أكبر، ومقاطع غامقة ومائلة، وأشرطة اقتباس، وإزاحات قوائم، ومربعات مهام، وخطوطًا فاصلة، وروابط، وبطاقات شيفرة، ويخفي العلامات التي تصنعها (عند تفعيل **إخفاء العلامات**) ما عدا في السطر الذي يوجد فيه مؤشر الإدخال. لا يعرف المحرر شيئًا عن أي صياغة بعينها: تقول القاعدة ما هو تطابقها بحمل بند تنسيق، والقاعدة التي لا تحمله تُلوَّن ولا يُعاد تنسيقها.

لكل قاعدة في **الخيارات** مجموعة **مصدر منسَّق**:

| الحقل | ما يفعله |
| --- | --- |
| **الدور** | ما هو التطابق، أو **بلا تنسيق**. بالنسبة إلى تركيب واحد داخل سطر: heading وstrong وemphasis وcode وstrike وhighlight وunderline وlink وsubscript وsuperscript. بالنسبة إلى سطر كامل: rule (فاصل موضوعي) وlist (علامة عنصر قائمة، بما فيها إزاحتها والمسافة بعدها) وtask (علامة يتبعها مربع اختيار) وquote (علامات `>` في سطر مقتبس). بالنسبة إلى كتلة يُتعرف عليها كاملة: codeBlock. بالنسبة إلى كتلة سطرا افتتاحها وإغلاقها تطابقان منفصلان: quoteRegion. بالنسبة إلى جدول أو معادلة أو مخطط يُرسم كصورة: renderedBlock. |
| **مجموعة المحتوى** | مجموعة الالتقاط، بدءًا من 1، التي تحمل ما يدور حوله التركيب: الكلمة داخل `*bold*`، والعنوان في `\section{Title}`. وما يملكه التطابق عداها هو علامات التركيب نفسه، التي يخفيها **إخفاء العلامات**. يعني `0` أن التطابق كله محتوى ولا شيء يُخفى، كما في عنوان الويب. اتركه فارغًا عندما يكون التطابق علامات فقط، مثل `== ` في العنوان. |
| **مستوى العنوان**، **مجموعة المستوى** | مستوى العنوان، من 1 إلى 6. عند تركه فارغًا، يكون الرقم في نهاية اسم مخرج القاعدة (`heading2`)، أو طول مجموعة الالتقاط التي تحمل سلسلة من `#`. |
| **مجموعة العلامة** | بالنسبة إلى قائمة أو مهمة، مجموعة الالتقاط التي هي العلامة مع إزاحتها والمسافات بعدها، عندما يبدأ التطابق بشيء آخر، مثل `> ` في عنصر مقتبس. |
| **أنماط حتى نهاية السطر** | تنسّق من التطابق حتى نهاية السطر، لقاعدة تطابق علامة العنوان فقط وتترك عنوانه كالنص الذي يليها. |
| **يُرسَم كـ** | بالنسبة إلى كتلة مرسومة، ما هي: جدول أو رياضيات أو مخطط توضيحي، أو **ليست صورة**. |
| **مجموعات العناوين** | بالنسبة إلى رابط، مجموعات الالتقاط، المجرَّبة بالترتيب، التي تحمل العنوان الذي يفتحه عند النقر أو اللمس؛ و`0` هو التطابق كله. لا تُفتح إلا عناوين الويب والبريد والهاتف. |

تُعدّ أرقام المجموعات أقواس النمط من 1؛ و0 هو التطابق كله. الملف التعريفي الذي لا يستبدل Markdown يحتفظ أيضًا بقراءة Markdown الخاصة للأنواع التي لا تصرّح بها قواعده، مثل أشرطة الاقتباس وأزواج `**`.

## خصائص المستند والأقسام الشرطية

تعرّف قاعدة **خاصية المستند** قيمة باسم `name`، وتستبدل قاعدة **مرجع الخصائص** (قاعدة ضمن السطر لها الجزآن `name` و`original`) المرجع بها. المرجع إلى خاصية لم يعرّفها أحد يبقى كما كُتب. يحتفظ **قسم شرطي** بالكتل بين سطريه أو يسقطها، بحسب ما إذا كانت الخصائص التي يسمّيها مضبوطة. تسري الخصائص من حيث تُعرَّف فصاعدًا.

القاعدة التي تنتج **إعدادات الكتلة التالية** تتعرف على سطر كامل يهيّئ الكتلة التي بعده ولا يعرض شيئًا بنفسه. تُعطى أجزاؤه وخصائصه الثابتة لتلك الكتلة: لـ `title` و`id` و`nodeType` و`language` و`hardbreaks` المعاني المسرودة تحت الأجزاء، وأي جزء آخر يبقى على الكتلة، حيث يقرؤه جدول أو قائمة أو اقتباس.

## اختبار ملف تعريفي

في أسفل المحرر، تحتوي **عيّنة الاختبار** على نص تجريبي (يبدأ كعنوان وسطر نص). اختر **فحص العيّنة** لترى العقد التي تصنعها قواعدك، مُزاحةً بحسب تداخلها. تقول "No blocks recognized." عندما لا يتطابق شيء.

## خط الأساس

**خط الأساس** للملف التعريفي هو نقطة استعادته: كما كان عندما أنشأته أو كررته أو استوردته. يتجاهل **إعادة الضبط إلى خط الأساس** كل تغيير منذ ذلك الحين، بعد أن تؤكد. يحفظ **تعيين كخط أساس جديد** الملف التعريفي ويجعل حالته الحالية نقطة الاستعادة.

يُرفض الحفظ، مع رسالة، إذا كان الملف التعريفي يستبدل Markdown ولا توجد فيه قاعدة نهاية سطر، أو إذا كان نمط غير آمن وقد يعطّل المحرر، أو إذا تعذرت كتابة الملف.

## الأجزاء

الأجزاء هي القطع المسماة من التطابق التي يقرؤها المخرج.

| الجزء | المعنى |
| --- | --- |
| `allOf` | الفاصل بين الأسماء عندما تلزم كلها، مثل `+`. |
| `alt` | وصف الصورة، للقراء الذين لا يستطيعون رؤيتها. |
| `anyOf` | الفاصل بين الأسماء عندما يكفي أي واحد منها، مثل `,`. |
| `attribution` | من قال الاقتباس، ويظهر تحته. |
| `citetitle` | العمل الذي جاء منه الاقتباس، ويظهر بعد الإسناد. |
| `columns` | قائمة أعمدة الجدول، مثل `1,2,1`؛ وعدد عناصرها هو عدد الأعمدة. |
| `condition` | أسماء الخصائص التي يعتمد عليها القسم. |
| `conditionType` | `defined` يُبقي القسم عندما تكون الخصائص مضبوطة، و`undefined` عندما لا تكون. |
| `content` | النص نفسه، عندما لا يكون التطابق كله. |
| `format` | محرك المخطط التوضيحي (`mermaid` أو `vega-lite`)؛ وبالنسبة إلى الجدول، أي من تنسيقاته المحدَّدة تستخدمها الخلايا. |
| `hardbreaks` | عند وجوده، يحافظ على فواصل الأسطر المفردة في الكتلة التالية. |
| `header` | أي قيمة غير `false` تجعل الصف الأول من الجدول رأسه. |
| `id` | اسم: بالنسبة إلى الكتلة التالية، المعرّف الذي تشير إليه الإحالات المرجعية؛ وبالنسبة إلى حاشية، اسم يتيح للحواشي اللاحقة التي لا نص لها مشاركة رقمها. |
| `keys` | المفاتيح المراد ضغطها، مفصولة بفواصل. |
| `label` | النص المعروض لمرجع أو مرساة، بدلًا من عنوان الهدف نفسه. |
| `language` | لغة البرمجة لكتلة شيفرة، تُستخدم في تلوينها. |
| `level` | مستوى العنوان، من 1 إلى 6. |
| `marker` | الفاصل بعد المصطلح، مثل `::`. العلامة المختلفة تُدخل قائمة داخل الوصف. |
| `name` | اسم الخاصية، في تعريف أو مرجع. |
| `nodeType` | يجعل الكتلة التالية مخرجًا آخر، باسمه في الملف. |
| `noHeader` | عند وجوده، لا يكون للجدول صف رأس. |
| `notation` | صيغة الرياضيات: `tex` (الافتراضية) أو `latex`. |
| `open` | `true` يعرض القسم القابل للطيّ مفتوحًا. |
| `ordered` | `true` يجعل القائمة مرقمة. |
| `original` | المرجع كما كُتب، ويظهر عندما لا تكون الخاصية معرّفة. |
| `presentation` | كيفية عرض قائمة الأوصاف التالية: `sideBySide` يضع المصطلحات والأوصاف في عمودين؛ و`questions` يرقّم كل مصطلح كسؤال، وجوابه تحته. |
| `primary` | مدخل الفهرس. |
| `secondary` | مدخل فرعي تحت مدخل الفهرس. |
| `sectionLabel` | كلمة يتبعها رقم العنوان التالي، مثل `Appendix`: تُعدّ هذه العناوين على حدة، `Appendix A:`. |
| `sectionLabelStart` | أول هذه الأرقام: الحرف (`A`) يعدّ بالحروف، والرقم يعدّ بالأرقام. |
| `src` | عنوان ملف الفيديو أو الصوت. |
| `start` | الرقم الذي تبدأ به القائمة المرقمة. |
| `summary` | السطر المعروض على قسم قابل للطيّ وهو مغلق. |
| `targetID` | المعرّف الذي يشير إليه المرجع. |
| `term` | المصطلح الذي يجري وصفه. |
| `tertiary` | مدخل فرعي تحت المدخل الثانوي. |
| `text` | النص المعروض، عندما يلتقط النمط أكثر منه. يتبع نص الحاشية الفقرة أو الجدول أو القائمة التي هي فيها، مرقّمًا. |
| `title` | عنوان: عنوان مربع، أو تلميح صورة أو رابط، أو تعليق توضيحي فوق الكتلة التالية. |
| `type` | نوع التنبيه، مثل `note` أو `tip` أو `warning`. |
| `unset` | عند وجوده، تزيل القاعدة الخاصية بدلًا من تعريفها. |
| `url` | العنوان الذي يشير إليه رابط أو صورة. |
| `value` | قيمة الخاصية؛ وتُستبدل فيها المراجع إلى خصائص عُرِّفت سابقًا. |
