# Part XXI — تنسيقات الملفات والحدود

# Chapter 79: تنسيق سمة التطبيق

تضبط **سمة التطبيق** نمط Pilcrow نفسه: مظهره الفاتح أو الداكن، ولون التمييز، والشريط الجانبي، وأشرطة الحالة والتنسيق، والمحرر. وهي ملف JSON. أما المستندات المعروضة (المعاينة وHTML وPDF والصور والطباعة وWord) فيُضبط نمطها بشكل منفصل بواسطة **سمة العرض**، وهي CSS (Chapter 80). يُثبَّت النوعان ويُختاران ويُحذفان كلٌّ على حدة، ولا يتبع أحدهما الآخر.

## مثال كامل

```json
{
  "pilcrowAppTheme": 1,
  "name": "Nord",
  "appearance": "dark",
  "colors": {
    "accent": "#88C0D0",
    "sidebar": { "background": "#2E3440", "foreground": "#D8DEE9" },
    "bars": { "background": "#3B4252", "foreground": "#D8DEE9" },
    "editor": {
      "background": "#2E3440",
      "foreground": "#ECEFF4",
      "cursor": "#88C0D0",
      "selection": "#434C5E",
      "gutterBackground": "#2E3440",
      "gutterForeground": "#4C566A"
    },
    "syntax": {
      "heading": "#88C0D0",
      "marker": "#EBCB8B",
      "code": "#A3BE8C",
      "link": "#81A1C1",
      "muted": "#7B88A1",
      "tokens": { "strong": "#D08770" }
    }
  }
}
```

## المستوى الأعلى

| المفتاح | مطلوب | القيمة |
| --- | --- | --- |
| `pilcrowAppTheme` | نعم | إصدار التنسيق، `1`. |
| `name` | نعم | من 1 إلى 200 حرف. يظهر في الإعدادات وقائمة السمات. |
| `appearance` | نعم | `"light"` أو `"dark"` أو `"automatic"`. |
| `colors` | السمات `light` و`dark` | لوحة ألوان واحدة (أدناه). |
| `light`، `dark` | السمات `automatic` | لوحتان: إحداهما تُستخدم في المظهر الفاتح للنظام والأخرى في المظهر الداكن. |
| `id` | لا | يكتبه Pilcrow لمكتبته الخاصة. يُتجاهل عند الاستيراد، الذي يعيّن دائمًا معرّفًا جديدًا. |

يحدد `appearance` مظهر **كل** نافذة: بما في ذلك القوائم والإعدادات والأوراق والمنتقيات. تثبّته السمة `light` أو `dark`، وتتبع `automatic` النظام.

يجب أن تضبط السمة التلقائية كل لون في `light` و`dark` معًا أو في أيٍّ منهما على الإطلاق. فاللون المضبوط لمظهر واحد فقط كان سيُرسم في المظهر الآخر.

## لوحة الألوان

كل مفتاح اختياري. اللون المتروك يحتفظ بمظهر Pilcrow المدمج، لذا يمكن أن تكون السمة صغيرة بقدر لون تمييز واحد.

| المفتاح | ما يضبط نمطه |
| --- | --- |
| `accent` | التلوين على مستوى التطبيق: الأزرار والمقاطع المحددة ومفاتيح التبديل والروابط وحلقات التركيز والصف المحدد في الشريط الجانبي. تركه دون ضبط يُبقي لون تمييز النظام. |
| `sidebar.background`، `sidebar.foreground` | الشريط الجانبي للملفات والمخطط التفصيلي والبحث. تُشتق التسميات الثانوية من المقدمة. |
| `bars.background`، `bars.foreground` | شريط الحالة وشريط التنسيق المثبّت وإشعارات الاستيراد. تُشتق التسميات الثانوية من المقدمة. |
| `editor.background`، `editor.foreground` | لوحة المحرر ونص المتن. |
| `editor.cursor`، `editor.selection` | نقطة الإدخال وتمييز التحديد. |
| `editor.gutterBackground`، `editor.gutterForeground` | هامش أرقام الأسطر. الخلفية افتراضيًا هي خلفية المحرر. |
| `editor.currentLineRule` | الخط الرفيع أسفل السطر الذي يوجد عليه مؤشر الإدخال، عند تفعيل **عرض ▸ قاعدة السطر الحالي**. افتراضيًا هو لون نص المحرر بقوة منخفضة. |
| `syntax.<group>` | ألوان الصياغة الحية بحسب المجموعة (أدناه). |
| `syntax.tokens.<raw>` | رمز واحد بحسب قيمته الخام، يتجاوز مجموعته. |

### مجموعات الصياغة

| المجموعة | ما تلوّنه |
| --- | --- |
| `heading` | العناوين (العلامات والنص)، وعلامات التنبيهات، ومصطلحات التعريف |
| `marker` | التأكيد والغامق والتوسط بخط وفواصل أخرى ضمن السطر؛ وعلامات القوائم والمهام |
| `code` | الشيفرة ضمن السطر، وكتل الشيفرة المسيّجة والمزاحة، والرياضيات، وكتل HTML |
| `link` | تسميات الروابط والصور ووجهاتها، والروابط التلقائية |
| `muted` | علامات الاقتباس، والفواصل الموضوعية، وصفوف الجداول، والتعليقات، وسمات الكتل |
| `codeKeyword`، `codeString`، `codeNumber`، `codeComment` | الشيفرة المميّزة داخل السياج |

تأخذ المجموعة غير المضبوطة لونًا مدمجًا يُختار لخلفية المحرر: درجات أغمق على لوحة فاتحة، وأفتح على لوحة داكنة. تستخدم أسماء الرموز في `syntax.tokens` الحروف والأرقام و`_` و`-`، ولا يمكنها تكرار اسم مجموعة (فـ `syntax.heading` يغطي `heading` بالفعل).

## الألوان

كل لون سلسلة سداسية عشرية: `#RGB` أو `#RGBA` أو `#RRGGBB` أو `#RRGGBBAA`، في sRGB. يخزّنها Pilcrow بأحرف كبيرة.

## التحقق

يرفض Pilcrow الملف بدلًا من تجاهل جزء منه، ويسمّي المفتاح المعيب، مثل `colors.editor.cursor: must be a hex colour`. وهو يرفض:

- إصدار `pilcrowAppTheme` مفقودًا أو مختلفًا؛
- مفتاحًا غير معروف في أي مستوى (وغالبًا يكون خطأ إملائيًا)؛
- مفتاح لوحة لا يطابق المظهر (`colors` في سمة تلقائية، و`light` و`dark` في سمة فاتحة أو داكنة)؛
- لونًا ليس سداسيًا عشريًا؛
- سمة تلقائية تضبط لوحتاها `light` و`dark` ألوانًا مختلفة.

## ما لا تغيّره سمة التطبيق

شريط عنوان النافذة وشريط الأدوات (زجاج النظام، الذي يأخذ لون التمييز فقط) والقوائم والإعدادات والأوراق والمنتقيات تحتفظ بمظهرها الأصلي عدا المظهر ولون التمييز. الخطوط لا تخضع للسمات: يُضبط خط المحرر وحجمه في **الإعدادات ▸ المظهر ▸ حجم النص والخطوط**.

## التثبيت والمشاركة

- **استيراد** ملف `.json` من **الإعدادات ▸ المكتبة ▸ السمات**، أو **ملف ▸ استيراد ▸ سمة** على Mac، أو **الإعدادات ▸ المكتبة ▸ استيراد** على iPad. ويصلح أيضًا إسقاط الملف على Pilcrow.
- قد تضم حزمة سمات `.zip` سمات تطبيق إلى جانب سمات العرض (Chapter 80).
- يحفظ زر المشاركة بجوار السمة ملف `.json` الخاص بها، أو الحزمة كاملة إن كانت السمة قد جاءت من حزمة.

يتضمن Pilcrow ثلاث سمات تطبيق: **تلقائي** و**فاتح** و**داكن**. وهي تضبط ألوان المحرر والصياغة وتترك الإطار بمظهره المدمج.

# Chapter 80: مرجع CSS لسمة العرض

**سمة العرض** هي CSS. تضبط نمط المعاينة وHTML وPDF والصور ومخرجات الطباعة، وأنماط Word المذكورة في نهاية هذا الفصل. قد تكون سمة العرض ملف `.css` واحدًا أو جزءًا من حزمة ZIP مع موارد محلية. تحدد ملفات الصياغة كيف يصبح النص المصدر مستندًا؛ أما سمات العرض فتضبط نمط الناتج فقط. لا تضبط CSS أبدًا نمط التطبيق أو المحرر؛ فذلك من شأن سمة التطبيق (Chapter 79).

## التتالي

يطبّق Pilcrow الأنماط بهذا الترتيب:

1. إعادة الضبط البنيوية الخاصة بـ Pilcrow؛
2. شيفرة CSS للسمة المختارة؛
3. شيفرة CSS لمرة واحدة من لوحة التصدير (**خيارات متقدمة ▸ CSS مخصص**)؛
4. تصحيحات الطباعة والعرض المطلوبة.

تفوز القواعد اللاحقة بحسب تتالي CSS المعتاد. لا يُدعم JavaScript في السمات ولا الموارد البعيدة ولا عناوين `file:` ولا `@import`.

## الموارد

يقرأ Pilcrow شيفرة CSS للسمة بمحلل رموز CSS قياسي، فتُفكّ الرموز المهرّبة قبل فحص أي شيء: `u\72 l(…)` هي `url()` و`@im\70 ort` هي `@import`. يُفحص كل موضع قد يحمّل منه المتصفح: `url(…)` و`url("…")` و`src("…")` والسلاسل داخل `image-set()`. ويجب أن يكون كلٌّ منها واحدًا مما يلي:

- مسارًا نسبيًا إلى الحزمة (`fonts/Body.woff2`، `./paper.png`). يُسمح بـ `?query` أو `#fragment` ويُتجاهلان عند البحث عن الملف؛
- عنوان `data:` من نوع PNG أو JPEG أو GIF أو WebP أو SVG (`image/svg+xml`) أو TTF أو OTF أو WOFF أو WOFF2؛
- مرجع جزء مثل `url(#shadow)`، يسمّي عنصرًا في الصفحة.

يُرفض أي شيء بمخطط غير `data:` (`https:` أو `file:` أو `blob:`) أو يبدأ بـ `//`، وكذلك أي مسار يبدأ بـ `/` أو يحتوي على `..`.

## خصائص العرض

تقرأ إعادة الضبط المدمجة هذه الخصائص وتوفّر قيمًا احتياطية:

| المجموعة | الخصائص |
| --- | --- |
| اللون | `--pt-background`, `--pt-foreground`, `--pt-secondary-background`, `--pt-secondary-foreground`, `--pt-accent`, `--pt-link-color`, `--pt-border-color` |
| الشيفرة | `--pt-code-background`, `--pt-code-foreground`, `--pt-code-keyword`, `--pt-code-string`, `--pt-code-number`, `--pt-code-comment` |
| الخط | `--pt-body-font-family`, `--pt-mono-font-family`, `--pt-base-font-size`, `--pt-line-height` |
| التباعد | `--pt-paragraph-spacing`, `--pt-blockquote-indent`, `--pt-list-indent`, `--pt-code-padding`, `--pt-heading-top`, `--pt-heading-bottom` |
| الجداول | `--pt-table-header-background`, `--pt-table-stripe-background` |
| التنبيهات | `--pt-admonition-note-color`, `--pt-admonition-tip-color`, `--pt-admonition-important-color`, `--pt-admonition-warning-color`, `--pt-admonition-caution-color` |

## حزم ZIP

يمكن لحزمة ZIP أن تضم سمات العرض (`.css`) وسمات التطبيق (`.json`) معًا؛ وتُدرج كلٌّ منها بنوعها في الإعدادات. لا تحتاج حزمة ZIP التي تضم ملف CSS واحدًا على الأكثر وسمة تطبيق واحدة على الأكثر إلى بيان. أما أي شيء أكثر فيحتاج `pilcrow-theme.json`، الذي يسرد كل سمة تحت `variants[].file`. يحدد امتداد الملف نوعه:

```json
{
  "id": "com.example.paper",
  "name": "Paper",
  "version": "1.0.0",
  "author": "Example Author",
  "license": "MIT",
  "cssAPIVersion": 1,
  "variants": [
    { "id": "app", "name": "Paper", "file": "Paper.json", "appearance": "automatic" },
    { "id": "light", "name": "Paper Light", "file": "Paper-Light.css", "appearance": "light" },
    { "id": "dark", "name": "Paper Dark", "file": "Paper-Dark.css", "appearance": "dark" }
  ]
}
```

يصف البيان الحزمة وسماتها. ولا يحتوي أبدًا على قيم أنماط: فهذه في ملفات CSS وسمات التطبيق.

- يسمّي `id` الحزمة مجلد التثبيت. ويجب ألا يبدأ بـ `.` أو تكون فيه مسافات في أوله أو آخره. تثبيت حزمة يكون `id` الخاص بها مثبّتًا بالفعل يستبدلها.
- تعمل حزمة ZIP المصنوعة بـ **ضغط** في Finder كما هي. يتخطى Pilcrow `__MACOSX/` و`._*` و`.DS_Store` و`Thumbs.db`، وعندما تكون كل الملفات داخل مجلد واحد من المستوى الأعلى يُعامل ذلك المجلد على أنه جذر الحزمة.
- يؤدي حذف سمة واحدة إلى إزالتها من الحزمة مع الإبقاء على البقية والموارد المشتركة. وحذف السمة الأخيرة يزيل الحزمة. وإذا كانت السمة المحذوفة هي المختارة فإن الاختيار يعود إلى الافتراضي لنوعها: تلقائي لسمة التطبيق، وفاتح لسمة العرض.
- يمكن لـ CSS الإشارة إلى ملفات PNG وJPEG وGIF وWebP وTTF وOTF وWOFF وWOFF2 المضمّنة في الحزمة بمسارات `url(...)` نسبية. يتحقق Pilcrow من توقيعاتها ويضمّن الموارد المشار إليها كعناوين data بحيث يبقى العرض وHTML المصدَّر دون اتصال ومكتفيين بذاتهما. لا يمكن لمسارات ZIP أن تخرج من الحزمة أو تتصادم بحسب حالة الأحرف أو تشير إلى روابط. وحجم الأرشيف وعدد العناصر والحجم الفردي ونسبة الضغط كلها محدودة.

## Word

يستخدم تصدير Word قيم `:root` الفاتحة (الأساسية) ويحوّل هذه الخصائص الدلالية إلى أنماط Word مسمّاة: `--pt-foreground` و`--pt-background` و`--pt-accent` و`--pt-link-color` و`--pt-code-background` و`--pt-code-foreground` و`--pt-body-font-family` و`--pt-mono-font-family` و`--pt-base-font-size` و`--pt-line-height`. ليس لمحددات المتصفح وقواعد التخطيط مكافئ عام في Word. تستخدم مخرجات المعاينة وHTML وPDF والصور ورقة الأنماط كاملة؛ أما Word فيستخدم هذه المجموعة الفرعية مع الحفاظ على بنية المستند والمخططات التوضيحية وصور الرياضيات والروابط والوسائط. تعرض لوحة التصدير هذا القيد كلما اختير Word.

يتضمن Pilcrow سمتي عرض هما **فاتح** و**داكن**، وهما نقطتا بداية كاملتان.
