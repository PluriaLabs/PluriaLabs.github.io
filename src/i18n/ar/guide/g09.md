# Chapter 65: لوحة المساعد ومراجعة الأسلوب

تظهر لوحة المساعد بعد إعداد اتصال في **الإعدادات ▸ المساعد** (الفصل 67). وما دام لا يوجد اتصال جاهز، لا يظهر عنصر **المساعد** في قائمة «عرض».

## اللوحة

| عنصر التحكم | ما يفعله |
| --- | --- |
| **وضع المساعد** | **حواري** أو **مراجعة الأسلوب** أو **مساعدة**. |
| **اختيار نموذج…** | يفتح أداة اختيار النموذج (أدناه). ويعرض تحذيرات عندما يصبح النموذج غير متاح أو يُعلَن إيقافه، مع تاريخ التقاعد. |
| **مسح المحادثة** | يُفرغ المحادثة. لا تُحفظ المحادثات؛ بل تُتجاهل عند إنهاء التطبيق. |
| **ما يُشارَك** | يحدد ما يُرسَل مع سؤالك: **لا شيء من المستند** أو **التحديد** أو **القسم** أو **حول المؤشر** أو **المستند بأكمله** أو **المخطط التفصيلي** أو **ملف تعريف**. وإذا تعذّر تطبيق خيار ما فإنه يذكر السبب («حدّد بعض النص أولًا.» و«لا يحتوي هذا المستند على عناوين.» و«كبير جدًا لإرساله كاملًا.» و«لا يوجد ملف تعريف للصياغة.»). ويوضّح سطر فوق مربع السؤال كمية ما سيُرسَل وإلى أي مضيف. ويُحفَظ اختيارك. |
| **معاينة** (و**ما يُرسَل**) | يعرض بالضبط ما سيُرسَل. |
| **اسأل المساعد…** / **صِف ما تريد كتابته** | مربع السؤال. في وضع **مساعدة**، يحدد **ما تكتبه** إحدى الخيارات: **ملف تعريف للصياغة** أو **ماكرو** أو **دليل أسلوب**. |
| **إرسال** و**إيقاف** | يرسل الطلب، أو يوقف ردًّا جاريًا. |
| **الخصوصية** | يعرض ما إذا كان المساعد مفعّلًا لهذا المجلد. ويبدّل بين الحالتين **إيقاف لهذا المجلد** و**تشغيل لهذا المجلد**. وتظهر عبارة «هذا الملف مستبعد من المساعد.» لملف يطابق أحد الاستثناءات. |
| كل رد | **نسخ** و**إدراج عند المؤشر** و**إعادة المحاولة**، وعند الرد الذي يتضمن أسلوبًا أو ماكرو: **إضافة إلى المكتبة…**. والرد الذي يحتوي على خطأ يقدّم **اطلب الإصلاح**. والرد المقطوع يذكر ذلك. |

## اختيار نموذج

يسرد **اختيار نموذج…** النماذج التي يتيحها الاتصال، مع **البحث في النماذج**. ويضم **إظهار كل النماذج** النماذج الأقل شيوعًا. ويُوسَم النموذج المُعلَن إيقافه بتاريخ تقاعده. وإذا لم يُسرَد أي نموذج، فاكتب اسم النموذج بنفسك. ويعيد **إعادة المحاولة** تحميل القائمة.

## مراجعة الأسلوب

في وضع **مراجعة الأسلوب**، تطبّق اللوحة دليل أسلوب على كتابتك.

| عنصر التحكم | ما يفعله |
| --- | --- |
| **دليل الأسلوب**، **المتغير** | اختر دليلًا وأحد متغيراته. |
| **ما يُراجَع** | **التحديد** أو **المستند**. والمستند الكبير جدًا بحيث لا يمكن مراجعته كاملًا يعرض «كبير جدًا لمراجعته كاملًا. راجع قسمًا بدلًا من ذلك.» |
| **مناطق** | اختر المناطق المراد فحصها، أو **كل المناطق**. |
| **مراجعة** | يرسل النص والقواعد إلى اتصال الذكاء الاصطناعي لديك. وقبل مراجعة المستند بأكمله، ينبّه تنبيه إلى عدد الطلبات التي سترسَل وتقدير حجم النص، ويسأل: **مراجعة** أم **إلغاء**. |
| **فحص هنا** | يشغّل فحوصات الدليل الخاصة به على هذا الجهاز. ولا يُرسَل شيء. |
| **فحص الإحالات المرجعية** | يرسل العناوين والأسطر المستشهِدة وقوائم المراجع لفحص القواعد التي تقارن جزءًا من المستند بجزء آخر. |
| **إيقاف** | يوقف مراجعة جارية. ويتابع **مراجعة المتبقي** بعد إيقاف أو إخفاق. |

تظهر النتائج في قائمة. وتعرض كل نتيجة الاقتباس وشرحًا، وإصلاحًا مقترحًا عند وجوده.

| الزر | ما يفعله |
| --- | --- |
| **انتقال إلى** | ينتقل إلى النتيجة في المستند. والاقتباس الذي يتكرر أكثر من مرة يعرض «تطابق N من N». |
| **تطبيق** | ينفّذ الإصلاح المقترح. ولا يُطبَّق إلا إذا ظل النص كما وُجد تمامًا. وإلا يعرض «تغيّر النص.» أو «لم يُعثر عليه في النص.» |
| **تجاهل** | يزيل النتيجة. |
| **تطبيق الكل** | ينفّذ كل إصلاح له إصلاح، بعد تأكيد يذكر عددها، كتغيير واحد يمكنك التراجع عنه بخطوة واحدة. ويذكر أيضًا كم إصلاحًا جاء من الذكاء الاصطناعي. |
| **تجاهل كل الاقتراحات**، **مسح** | يمسحان القائمة. |

وتبلّغ اللوحة أيضًا بعبارات «N من القواعد لا يمكن الحكم عليها إلا بمراجعة» و«توقفت N من القواعد بعد 100 نتيجة» و«حُذف تغيير مقترح لأنه أضاف وقائع لا يتضمنها النص.»

# Chapter 66: كيف تُنظَّم الإعدادات

افتح الإعدادات من **Pilcrow ▸ الإعدادات…** (`⌘,`) على Mac، أو من رمز الترس في الترويسة على iPad، حيث تُفتح كورقة مع زر **تم**. تضم النافذة مربع **البحث في الإعدادات** وقائمة **فئات** على اليسار. ولكل فئة صفحة أو أكثر، تظهر كشريط أزرار في الأعلى.

| الفئة | الصفحات |
| --- | --- |
| **عام** | اللغة والنوافذ (على iPad: **اللغة**)، الملفات، الترجمة، المساعد، التشخيصات، التخزين والخصوصية |
| **التحرير** | العرض والكتابة، الصور |
| **المظهر** | السمة والخلفية، حجم النص والخطوط |
| **جدول المحتويات** | المحتويات والتسميات |
| **تصدير** | الإعدادات الافتراضية للتصدير |
| **المكتبة** | ملفات تعريف الصياغة، خيارات CommonMark، السمات، الماكرو، أدلة الأسلوب، مكتبات العرض، الموقع (ولدى iPad أيضًا **استيراد**) |
| **لوحة المفاتيح** | الاختصارات |
| **الاشتراك والرصيد** | ادعم Pilcrow |

يبحث **البحث في الإعدادات** عن عنصر تحكم بالاسم. اكتب جزءًا من تسمية، مثل «تباعد الأسطر» أو «الإصدارات»، فتعرض النتائج عنصر التحكم وصفحته وفئته. اختر إحداها للانتقال إليها مباشرة. تسري التغييرات فورًا؛ ولا يوجد زر حفظ إلا في محررات السمات وملفات التعريف والماكرو واختصارات لوحة المفاتيح.

تبقى الإعدادات التي تخص جهاز Mac واحدًا أو iPad واحدًا على ذلك الجهاز. أما مكتبتك (السمات وملفات التعريف والماكرو وأدلة الأسلوب والخلفيات) فيمكن نقلها إلى مجلد تختاره، بما في ذلك مجلد في iCloud Drive (الفصل 71).

## الترجمة

تتطلب الترجمة macOS 15 أو iPadOS 18 أو أحدث.

| عنصر التحكم | ما يفعله |
| --- | --- |
| **الترجمة إلى** | لغتك الهدف الافتراضية. والخيار الأول هو «لغة النظام». |
| **السرعة** | **سريع** أو **أفضل جودة** أو **مساعد الذكاء الاصطناعي**. يناسب **سريع** المستندات الطويلة وقد يكون أسرع بنحو عشرين ضعفًا، بصياغة أبسط؛ ويتطلب macOS أو iPadOS 26.4. ويرسل **مساعد الذكاء الاصطناعي** النص إلى اتصالك من **الإعدادات ▸ المساعد**؛ وقد تتقاضى خدمتك رسومًا على ذلك، ويغادر النص الجهاز. |
| **عندما يكون الملف بلغة أخرى** | **عدم فعل شيء** أو **اقتراح الترجمة** أو **الترجمة تلقائيًا**. يحدد Pilcrow لغة الملف عند فتحه، ولا يغادر شيء الجهاز لهذا الغرض. ويعرض الاقتراح شريطًا فيه خيار الترجمة إلى لغتك الافتراضية. |
| **الاقتراح مجددًا لكل الملفات** | يمسح الملفات التي عيّنتها على **أبدًا لهذا الملف**. |
| **بعد الترجمة** | **فتح في علامة تبويب جديدة** أو **حفظ نسخة بجوار الأصل** (باسم مثل الأصل مع إضافة اللغة، مثل `Notes_fr.md`) أو **استبدال المستند** (ويمكن التراجع عنه). |
| **اللغات على هذا الجهاز** | يسرد كل لغة مع **على هذا الجهاز** أو **تنزيل** أو **غير متاح**. تستخدم الترجمة حزم لغات تبقى على الجهاز. ويطلب التنزيل إذنًا من النظام؛ ولإزالة حزمة افتح إعدادات اللغة في النظام. |

## المساعد

| عنصر التحكم | ما يفعله |
| --- | --- |
| **تفعيل مساعد الذكاء الاصطناعي** | يضيف لوحة المساعد إلى الشريط الجانبي. ولا يُرسَل شيء حتى تسأل، ولا يُرسَل إلا النص الذي تختار مشاركته. |
| سطر الحالة | **جاهز.**، أو سبب عدم الجاهزية: «عنوان الاتصال النشط غير صالح للاستخدام.» أو «الاتصال النشط يحتاج إلى مفتاح API.» أو «أضف اتصالًا أدناه. يظهر جزء المساعد بمجرد أن يصبح أحد الاتصالات جاهزًا.» |
| **الاتصالات** | قائمة الاتصالات، مع «لا توجد اتصالات بعد.» عندما تكون فارغة. ويعرض كل اتصال اسمه، وللاتصال المستخدم **نشط**. ويقدّم الصف **تعيين كنشط** و**تحرير…** و**إزالة**. |
| **إضافة اتصال** | قائمة: **OpenAI** أو **Anthropic** أو **OpenRouter** أو **Ollama (هذا الكمبيوتر)** أو **LM Studio (هذا الكمبيوتر)** أو **مخصص…**. |
| **الملفات المستبعدة** | أنماط للملفات التي لا تُشارَك أبدًا. يمثّل `*` أي أحرف في اسم، و`**` أي مجلدات، والاسم المنتهي بـ `/` يشمل مجلدًا كاملًا. وتتضمن الأنماط الافتراضية `*.pem` و`.env*` و`*.key` و`secrets/`. **إضافة** نمط، أو **إزالة** نمط، أو **استعادة الإعدادات الافتراضية**. |
| **مجلدات متوقفة** | يسرد المجلدات التي أوقفت فيها المساعد، ولكل منها **تشغيل**. ويعرض «لا توجد مجلدات متوقفة.» عند عدم وجودها. |
| **الخصوصية** | رابط لقراءة سياسة خصوصية Pilcrow، و**حذف كل بيانات الذكاء الاصطناعي…** الذي يزيل كل اتصال وكل مفتاح محفوظ والمحادثة وخياراتك في الخصوصية، ويوقف المساعد. ويسأل أولًا. |

يُخزَّن مفتاح API الخاص بك في سلسلة المفاتيح (Keychain) على هذا الجهاز فقط.

### نموذج الاتصال

يفتح **إضافة اتصال** و**تحرير…** نموذجًا.

| الحقل | ما يفعله |
| --- | --- |
| **الاسم** | تسمية للاتصال. |
| **التنسيق** | **متوافق مع OpenAI** أو **Anthropic**. |
| **العنوان** | عنوان الويب للخدمة. استخدم `https://`، أو `http://` لهذا الكمبيوتر أو شبكتك المحلية فقط. |
| **السماح باتصال غير مشفّر على شبكتي المحلية** | يسمح بعنوان `http://` على شبكتك. فهو يرسل نصك ومفتاحك دون تشفير، فلا تسمح به إلا إذا كنت تثق بالشبكة. |
| **النموذج** | النموذج المراد استخدامه، مع **اختيار…** للاختيار من قائمة الخدمة. |
| **يحتاج إلى مفتاح API** و**مفتاح API** | ما إذا كانت الخدمة تحتاج إلى مفتاح، والمفتاح نفسه، محفوظًا في سلسلة المفاتيح. اتركه فارغًا عند التحرير للإبقاء على المفتاح المحفوظ. |
| **اختبار الاتصال** | يفحص العنوان والمفتاح والنموذج. ويعرض «جارٍ الاختبار…» ثم «تم الاتصال (N مللي ثانية).» |
| **إلغاء**، **حفظ** | يغلقان الاتصال أو يحتفظان به. |

## التشخيصات

| عنصر التحكم | ما يفعله |
| --- | --- |
| **تسجيل سجل التشخيص** | يسجّل ما يفعله Pilcrow، لتتمكن من إرساله إلى الدعم عند حدوث خلل. ويبقى على الجهاز حتى تشاركه، وهو مصمَّم لاستبعاد نص مستندك وأسماء ملفاتك. وأثناء التشغيل تظهر علامة حمراء **جارٍ تسجيل السجل** في شريط الحالة. |
| **إيقاف التسجيل بعد** | **ساعة واحدة** أو **24 ساعة** أو **أبدًا**. |
| **ما يُسجَّل** | مستوى لكل جزء من Pilcrow: **محرر النصوص** و**الماكرو** و**السمات** و**التحليل وملفات التعريف** و**العرض والمخططات التوضيحية** و**التصدير والطباعة** و**الملفات والمكتبة** و**التطبيق**. ويكون كل منها **المشكلات فقط** أو **عادي** أو **مفصّل** أو **كل شيء**. وتُحفَظ المشكلات والأخطاء دائمًا. |
| **إعادة إنتاج مشكلة** | يضبط كل جزء على «مفصّل» ويبدأ التسجيل. اجعل المشكلة تحدث مرة أخرى، ثم أنهِ التقرير. |
| **إضافة السجل** | عند الإبلاغ عن خطأ: **اسأل في كل مرة** أو **إضافة دائمًا** أو **عدم الإضافة أبدًا** لأحدث إدخالات السجل إلى الحافظة لتلصقها في النموذج. |
| **الإبلاغ عن خطأ…** | مثل **مساعدة ▸ الإبلاغ عن خطأ…**. |
| **تضمين في التقرير** | مفاتيح لـ **معلومات الجهاز والنظام** و**إعدادات Pilcrow** و**بنية المستند (أعداد فقط)** و**السرعة والذاكرة** و**سجل الإجراءات الأخيرة** و**تفاصيل الأعطال**. وبنية المستند هي عدد العناوين والجداول وما شابه في المستند، ولا تتضمن كلماته أبدًا. ولا يُرسَل شيء من هذه الشاشة. |
| **عرض السجل…** | يفتح عارض السجل (أدناه). |
| **مسح السجل…** | يحذف السجل المسجَّل من هذا الجهاز نهائيًا، بعد السؤال. وإيقاف التسجيل يُبقي ما سُجِّل حتى تمسحه. |

أثناء تسجيل سجل لتقرير خطأ، يوقف **إعادة إنتاج — إنهاء التقرير** (أو **إنهاء تقرير الخطأ** في قائمة المساعدة) التسجيل وينهي التقرير. ويتوقف التسجيل من تلقاء نفسه بعد 30 دقيقة في هذه الحالة.

### عارض السجل

يعرض **سجل التشخيص** ملخصًا (**الإدخالات** و**الجلسات** و**الأخطاء** و**تحذيرات** و**تقارير الأعطال**، والنطاق الزمني)، ثم الإدخالات، الأحدث أولًا، مع حقل **البحث في السجل** ومرشِّحَي **جزء** و**المستوى**. وتغيّر المرشِّحات ما تراه فقط، لا ما يُرسَل. ويحتوي التقرير على كل إدخال في السجل بالإضافة إلى ما اخترته ضمن «تضمين في التقرير». ويحدّثه **إعادة التحميل**. ويقدّم **إرسال التقرير**:

| العنصر | ما يفعله |
| --- | --- |
| **حفظ التقرير…** | يحتفظ بملف يمكنك إرساله بنفسك. |
| **مشاركة التقرير…** | يفتح ورقة المشاركة (AirDrop والملفات وغيرها). |
| **إبلاغ على GitHub…** | يفتح بلاغًا جديدًا بملخص قصير. وتختار **إضافة السجل إلى الوصف** (أحدث الإدخالات، حتى 60,000 حرف، وهو أقصى ما يتيحه GitHub، تُنسخ إلى الحافظة لتلصقها) أو **حفظ وإرفاق ملف** (السجل كاملًا، في ملف تضيفه بنفسك). والبلاغات على GitHub علنية. |

عندما تبدأ تقريرًا ولم يُسجَّل شيء، يسأل Pilcrow **هل تريد تسجيل المشكلة أولًا؟**: **سجّل المشكلة أولًا** أو **أبلغ الآن** أو **إلغاء**. وعندما يفتح النموذج يسأل هل **إضافة السجل وفتح النموذج** أم **إضافة السجل دائمًا** أم **فتح النموذج بدون السجل**.

## التخزين والخصوصية

يحتفظ Pilcrow بنسخ الاسترداد والسجل ومنح الوصول وبيانات الدعم داخل صندوقه المعزول. ويمكن حذف كل فئة على حدة. ولا تحذف عناصر التحكم هذه مستنداتك أبدًا.

| القسم | عناصر التحكم |
| --- | --- |
| **المستندات** | **مراجعة بيانات الاسترداد** و**مراجعة سجل الإصدارات**. تسرد المراجعة العناصر المعنية مع أحجامها، لترى المساحة قبل حذف أي شيء. حدّد ما تريد حذفه (**تحديد الكل** أو **إلغاء تحديد الكل**) واختر **حذف المحدّد**. ولا يمكن مراجعة بيانات الاسترداد ما دام في مستند تغييرات غير محفوظة: احفظه أو أغلقه أولًا. |
| **الوصول إلى الملفات** | يزيل **مسح الوصول إلى الملفات الأخيرة…** قوائم الملفات الأخيرة ومجلدات «حفظ باسم» المتذكَّرة وإشارات الجلسات المرجعية واختيارات الصياغة لكل ملف. |
| **البيانات الخاصة وبيانات الدعم** | **حذف بيانات الذكاء الاصطناعي ومفاتيحه…** (الاتصالات ومفاتيح سلسلة المفاتيح والمحادثة الحالية وخيارات خصوصية الذكاء الاصطناعي)، و**حذف بيانات التشخيص…** (السجلات المسجَّلة وتشخيصات الأعطال المحفوظة)، و**مسح ذاكرات التخزين المؤقت…** (ملفات مخزَّنة مؤقتًا يمكن إعادة إنشائها واستجابات الشبكة). |

يطلب كل حذف تأكيدًا («لا يمكن التراجع عن هذا. لن تُحذف مستنداتك.»). ولا تُزال هنا ملفات تعريف الصياغة المخصصة ولا السمات ولا الماكرو ولا أدلة الأسلوب ولا الخلفيات؛ راجعها واحذفها من صفحات المكتبة الخاصة بها.
