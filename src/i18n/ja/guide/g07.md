# Chapter 60: サイドバー

サイドバーには、**ファイル**、**アウトライン**、**検索**、**プロジェクト**、**アシスタント**の5つのパネルがあります。サイドバー上部のスイッチで、**ファイル**、**アウトライン**、**プロジェクト**（開いているフォルダが本のプロジェクトのときに表示されます）、**アシスタント**（接続を設定すると表示されます）を切り替えます。**検索**には専用のヘッダがあり、タイトル **検索**、ファイルに戻る **完了** ボタン、**この書類**または**フォルダ**を選ぶ範囲コントロールが並びます。**表示 ▸ 検索**（`⇧⌘F`）から開きます。**表示**メニューでもパネルを切り替えられ、すでに表示中のパネルを選ぶとサイドバーが隠れます。サイドバーの端をドラッグするとサイズを変えられます。ファイルツリーの上にあるメニューから、**ファイルを開く…** と **フォルダを開く…** を選べます。

## ファイル

ファイルパネルは、開いているフォルダのツリーです。

フォルダを開いていないときは「フォルダを選んでファイルを表示します。」と表示され、**フォルダを開く**と**ファイルを開く**が用意されます。フォルダをここにドロップすることもできます。Pilcrow がフォルダを参照できない単一のファイルを開いた場合は、「この書類の隣にあるファイルを見るには *フォルダ* を参照してください」と表示され、**このファイルのフォルダを参照…**が使えます。

ファイルをクリックすると開きます。フォルダは展開と折りたたみができます。行を右クリックするか（iPad では長押し）、その行のメニューが開きます。

| 項目 | 動作 |
| --- | --- |
| **新規ファイル** | フォルダ内（またはクリックしたファイルの隣）にファイルを作成します。 |
| **新規フォルダ** | そこにフォルダを作成します。 |
| **名称変更…** | ファイルまたはフォルダの名前を変更します。 |
| **ゴミ箱に入れる** | 確認のあと、ゴミ箱に移動します。そこから戻すことができます。 |
| **Finder で表示** | Finder で表示します（Mac）。 |

場所によってシステムにゴミ箱がない場合、Pilcrow は削除した項目をパネル下部の**最近削除した項目**セクションに保管します。そこにある各項目には**戻す**と**完全に削除**があり、**「最近削除した項目」を空にする**を選ぶと、そのセクションの項目がすべて完全に削除されます。完全な削除は取り消せないため、Pilcrow は先に確認します。ほかの場所から削除した項目には影響しません。

隠しファイルと隠しフォルダは、**設定 ▸ ファイル ▸ 非表示のフォルダとファイルを表示**で表示または非表示にします。

## アウトライン

アウトラインには、アクティブな書類の見出しがレベルごとにインデントされて並びます。見出しをクリックすると、そこへ移動します。見出しの横のシェブロンで、その下にある見出しを折りたたんだり展開したりできます。これは書類を変更せず、折りたたみの状態も保存されません。

表示されることのあるメッセージ：

| メッセージ | 意味 |
| --- | --- |
| **見出しなし** | アクティブなプロファイルでは見出しが見つかりませんでした。 |
| **アウトラインを作成中… N%** | 大きな書類をまだスキャンしています。 |
| **アウトラインの作成に失敗しました。一覧が不完全な可能性があります。** | スキャン中に問題が起きました。 |
| **現在位置の近くに N 個の見出しがあります。ほかを見るにはスクロールしてください。** | 非常に大きな書類では、キャレット周辺のアウトラインの一部が表示されます。 |

アウトラインの下には、書類に未入力のフィールドがあると**フィールド**セクションが表示されます（第24章）。件数とともに一覧が表示され、1つをクリックするとそこへスクロールして選択されます。フィールドが非常に多い場合は「最初のフィールドのみ表示しています。」と表示されます。

## 検索

検索パネルは、開いているフォルダ内のすべてのファイルを検索します。フォルダがない場合は「フォルダを開いて検索してください。」と表示され、**フォルダを開く…** ボタンが出ます。

| コントロール | 動作 |
| --- | --- |
| **フォルダを検索**フィールド | 入力しながら検索します。**消去**ボタンで空にします。 |
| **Aa** | **大文字と小文字を区別**。 |
| **ab** | **単語全体**。 |
| **.\*** | **正規表現**。不正なパターンはフィールドの下に表示されます。 |
| ステータス行 | 「検索中…」と**キャンセル**ボタンが表示され、続いて「一致: N 件」と表示されます。検索は500件で止まり、「最初の500件を表示しています。」と表示されます。キャンセルした後は**再検索**が使えます。 |
| **置換…** | 検索で一致が見つかると表示されます。フォルダ内置換を開きます（第63章）。 |
| 結果 | 各結果にファイル名と該当行が表示されます。クリックすると、その行でファイルが開きます。 |

## プロジェクト

プロジェクトパネルは本のプロジェクト用です。第34章、第35章、および下記のプロジェクトパネルのリファレンスを参照してください。

### プロジェクトパネルのリファレンス

| 部分 | 動作 |
| --- | --- |
| **このフォルダは本のプロジェクトではありません。** と **プロジェクトにする** | 開いているフォルダにマニフェストがないときに表示されます。 |
| **再試行** | プロジェクトを読み込めなかったときに表示されます。 |
| **表示** | **リスト**、**あらすじ**、**カード**を選びます。 |
| タイトル、語数の合計 | プロジェクト名と「N 語」。本の目標語数を設定している場合は「N / 目標」。 |
| **ステータス**フィルタ | 1つのステータス、または**すべてのステータス**で絞り込みます。集計には各ステータスのファイル数と語数が並びます。並べ替えはフィルタが無効のときだけ使えます。 |
| **プロジェクトの設定**（歯車） | 下記の設定シートを開きます。 |
| **コンパイル…** | コンパイルシートを開きます（第64章）。 |
| **並べ替え**と**完了** | iPad では、章をドラッグして順序を変え、**完了**を選びます。 |
| **新規ファイル**（プラス） | **新しい章**、**新しいシーン**、**新しい前付け**、**新しい巻末**を選べます。 |
| **原稿に含まれていません** と **追加**、**すべて追加** | フォルダ内にあってマニフェストに含まれていないファイルを一覧にします。 |
| 行のシェブロン | 章の下の**シーンを表示**または**シーンを隠す**。 |
| **見つかりません** と **除外** のタグ | 見つからないファイル、または原稿から除外したファイル。 |
| 行のメニュー | **詳細…**、**下に新しいファイル**、**章を上へ移動**、**章を下へ移動**、**原稿に含める**、**原稿から除外**。 |
| 項目ごとの**目標語数** | 各項目に語数と、設定されていれば目標が表示されます。 |

項目の**詳細**には、**種類**（前付け、部、章、シーン、巻末）、**ステータス**、**視点**、**場所**、**目標語数**、**あらすじ**があります。プロジェクトファイルがディスク上で変更された場合は、「プロジェクトファイルがディスク上で変更されたため、直前の変更は適用されませんでした。もう一度お試しください。」と **閉じる** が表示されます。

**プロジェクトの設定**には、**タイトル**、**作成者**、**本の目標語数**、**新しいファイルの記述形式**（新しい章とシーンの構文で、既存のファイルは元のままです）、**変数**（名前と値で、本文中では `{{name}}` と書きます。`{{title}}` と `{{author}}` は常に使えます）、**単語として数えるもの**（**見出しを数える**、**前付けを数える**、**コードブロックを数える**）があります。**保存**または**キャンセル**を選びます。

# Chapter 61: フォーマットツールバーとステータスバー

## フォーマットツールバー

フォーマットツールバーは、テキストの下に表示できるオプションの行です。**表示 ▸ フォーマットツールバー**、**その他 ▸ フォーマットツールバー**、**設定 ▸ 編集 ▸ フォーマットツールバー**、またはツールバー自身の**ツールバーを隠す**項目で表示と非表示を切り替えます。アクティブなプロファイルを通して動作するため、プロファイルで表現できないボタンはグレー表示になります。

| コントロール | 動作 |
| --- | --- |
| **段落タイプ**メニュー（例：「段落」や「見出し 1」） | 現在の行のタイプを表示し、変更します：**段落**、**見出し 1** から **6**、**引用**、**箇条書き**、**番号付きリスト**、**タスクリスト**、**コードブロック**。 |
| **太字**（`⌘B`） | 強い強調。 |
| **斜体**（`⌘I`） | 強調。 |
| **インラインコード** | コード。 |
| **リンクを挿入**（`⌘K`） | リンクを作成します。 |
| **引用** | 引用のオン／オフを切り替えます。 |
| **箇条書き** | 箇条書きのオン／オフを切り替えます。 |
| **その他のフォーマット**（**⋯**） | あまり使わないコマンド：**取り消し線**、**インライン数式を挿入**、**タスクリストを挿入**、**タスクの状態を切り替える**、**インデント**、**インデント解除**、**見出しレベルを上げる**、**見出しレベルを下げる**、**表を挿入…**、**イメージを挿入…**、**ダイアグラムを挿入**、**グラフを挿入**、**別行立て数式を挿入**、**コードフェンスを挿入**、**注意を挿入**、**水平線を挿入**、**リンク参照を挿入**、**脚注を挿入**、**目次を挿入**、**YAML フロントマターを挿入**、そして**ツールバーを隠す**。 |

## ステータスバー

ステータスバーは下端に表示されます。**設定 ▸ 編集 ▸ ステータスバーを表示**でオンとオフを切り替えます。

| 部分 | 表示または動作 |
| --- | --- |
| **単語**、**行**、**列** | 単語数と、キャレットの行と列。選択範囲がある場合は、選択した行数と文字数が「Sel: N ln · N ch」として加わります。 |
| **構文**メニュー（例：「CommonMark」） | この書類のプロファイル。クリックして別のものを選ぶか、プレーンテキストにするには**構文なし**を選びます。 |
| **残りのフィールド: N** | マクロが未入力のフィールドを残したときに表示されます。クリックすると次のフィールドへ移動します。 |
| 進行状況とステータス | 大きなファイルを解析している間の **インデックス作成 N%**、**字句解析 N%**、そして翻訳の実行中の **翻訳中 N%**、**残り約 N**、**翻訳を中止**ボタン。 |
| **同期していません** | エディタと書類の変更ログがずれたことを知らせる警告です。保存してもファイルは未保存のままになるので、何も失われません。テキストを安全な場所にコピーしてから、書類を閉じて開き直してください。 |
| 書類の情報 | カウントをクリックするか、ツールチップ「書類の情報を表示」から、**書類の情報**を開きます。 |

**書類の情報**には、**単語**、**文字**、**行**、**読了時間**（設定の読む速度に基づきます）、**カーソル**、**選択**、**エンコーディング**、**構文**が並びます。非常に大きなファイルでは、インデックス作成が終わるまでは読み込み済みの部分のカウントになり、読了時間はファイル全体について推定されます。**エンコーディング**の下の**変換…**で別のテキストエンコーディングを選ぶと、次に保存するときにファイルが変換されます。


# Chapter 62: 検索、置換、行へ移動、クイックオープン、コマンドパレット

## 検索バー

**検索…**（`⌘F`）、**検索**ボタン、または**置換…**（`⌘R`）で開きます。書類の上部に表示されます。

| コントロール | 動作 |
| --- | --- |
| **書類内を検索**フィールド | 探すテキストを入力します。入力に合わせて一致箇所がハイライトされます。 |
| **Aa**、**ab**、**.\*** | **大文字と小文字を区別**、**単語全体**、**正規表現**。 |
| **前の一致**、**次の一致** | 一致箇所を順に移動します（`⇧⌘G`、`⌘G`）。 |
| **置換を表示** / **置換を隠す**（シェブロン） | **置換後**フィールドを表示します。 |
| **置換**、**すべて置換** | 現在の一致、またはすべての一致を置き換えます。一致があるまではグレー表示です。 |
| **検索対象**（バーの左端のスイッチ） | **この書類**、または開いているフォルダ全体を検索する**フォルダ**。 |
| **検索バーを閉じる** | 閉じます。 |

Pilcrow が数える数より一致が多い場合、バーに「さらに一致があります」と表示されます。**プレビュー**では、検索は描画された単語を対象にしてハイライトし、最大2,000件まで扱います。使えないパターンには「無効なパターン」と表示されます。置換は編集でのみ使えます。プレビューでは、バーに「置換は編集で使えます。テキストを変更するには編集に切り替えてください。」と表示されます。**並べて表示**では、検索はソースを対象にし、プレビュー内の一致する単語をハイライトします。

## 行へ移動

**行へ移動…**（`⌃G`）は、「行番号、または 行:桁」というフィールドが1つある小さなシートを開きます。`120` や `120:8` と入力して**移動**を選ぶか、**キャンセル**を選びます。末尾を超える番号は最後の行へ移動します。それ以外の入力には、Pilcrow は「120 や 120:8 のように行番号を入力してください。」と表示します。行数をまだ数えている非常に大きなファイルでは、しばらくしてからもう一度試すよう求められます。

## クイックオープン

**クイックオープン…**（`⇧⌘O`）は、開いているフォルダ全体でファイル名を検索します。名前の一部を入力すると一覧が絞り込まれ、「N 件」と表示されます。結果を選んで**開く**か、**キャンセル**を選びます。フォルダを開いていないときはグレー表示です。

## コマンドパレット

**コマンドパレット…**（`⌃⇧P`）は、Pilcrow のコマンドを名前とショートカットとともに一覧にするので、メニューを探さずに実行できます。入力して一覧を絞り込み、コマンドを選んで**実行**するか、**キャンセル**を選びます。該当がない場合は「一致するコマンドがありません」と表示されます。プレビューにいるときのソース編集のように、今は実行できないコマンドはグレー表示になります。一覧には、フォーマットと挿入のコマンド、選択範囲・行・大文字小文字の編集コマンド、読み上げ、表示の切り替え、ズーム、サイドバーのパネル、ファイルと書き出しの操作が含まれます。パレットを開くショートカットは、**設定 ▸ キーボード**で変更できます。
