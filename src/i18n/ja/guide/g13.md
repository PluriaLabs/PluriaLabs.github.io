# Chapter 75: テーマエディタ

テーマには2つの種類があり、それぞれ専用のエディタがあります。どちらも **設定 ▸ ライブラリ ▸ テーマ** から開きます。**新規** でテーマを作成し、**編集** でカスタムテーマを変更し、**複製** で内蔵テーマのコピーを作って、そのコピーを変更できます。内蔵テーマは編集できません。

## レンダリングテーマエディタ

**レンダリングテーマを編集** では、プレビュー、HTML、PDF、画像、プリントの出力のスタイルを設定します。Pilcrow 独自のカスタムプロパティは、Word のスタイルにも反映されます。レンダリングテーマは、アプリやエディタのスタイルには影響しません。

| 項目 | 内容 |
| --- | --- |
| **名前** | テーマの名前です。 |
| **外観** | **自動**、**ライト**、**ダーク** のいずれかです。 |
| **CSS** | スタイルシートです。コードエディタで編集します。プロパティとクラスについては、Chapter 80 を参照してください。 |
| **レンダリングされたプレビュー** | 入力中の CSS を適用して描画したサンプル書類です。効果をその場で確認できます。 |
| **CSS の診断** | 許可されていないリモートリソースなど、Pilcrow が CSS で見つけた問題です。 |
| **キャンセル**、**保存** | テーマを閉じる、または保持します。変更したまま閉じると **テーマの変更を破棄しますか？** と尋ねられ、**変更を破棄** または **編集を続ける** を選べます。 |
| **ベースライン** | **ベースラインに戻す** は、テーマの作成、複製、読み込み以降のすべての変更を破棄します（確認後）。**新しいベースラインとして設定** は、テーマを保存し、現在の状態を復元ポイントにします。 |

## アプリケーションテーマエディタ

**アプリケーションテーマを編集** では、Pilcrow 自体の外観、アクセント、サイドバー、バー、エディタのスタイルを設定します。

| 項目 | 内容 |
| --- | --- |
| **名前** | テーマの名前です。 |
| **外観** | **自動**、**ライト**、**ダーク** のいずれかです。自動テーマには2つのパレットがあります。 |
| **編集する配色** | 自動テーマの場合、**ライト** または **ダーク** を選び、2つのパレットのどちらを編集するかを指定します。 |
| 5つのグループの配色 | **アプリ**（アクセント）、**サイドバー**（背景と前景）、**ステータスバーと書式バー**（背景と前景）、**エディタ**（背景、前景、カーソル、選択範囲、ガターの背景、ガターの前景、現在の行の罫線）、**構文**（見出し、記号、コード、リンク、控えめな色、およびコードのキーワード、文字列、数値、コメント）。各配色は、設定するまで **デフォルト** と表示され、**リセット** ボタンで元に戻せます。 |
| **プレビュー** | サイドバー、エディタ、ステータスバーを備えた Pilcrow のミニチュアです。選んだ配色で、ライトまたはダークで表示されます。 |
| **キャンセル**、**保存**、**ベースライン** | 上記と同じです。 |

テーマでは、個々の構文トークンに色を付けることもできます。それらの色は保持されますが、テーマの JSON ファイル（`syntax.tokens`）で編集します。Chapter 79 を参照してください。

# Chapter 76: マクロエディタ

マクロエディタは **設定 ▸ ライブラリ ▸ マクロ** から開きます。コレクション内の **新規**、またはマクロの **編集** を使います。タイトルは **新規マクロ** または **マクロを編集** です。

| フィールド | 内容 |
| --- | --- |
| **名前** | マクロのラベルです。 |
| **トリガー**（例：`/sig`） | マクロを起動するテキストです。トリガーの後にスペース、タブ、リターンのいずれかを入力すると、マクロが展開されます。 |
| **一致** | トリガーの解釈方法です。**完全一致テキスト**、**接頭辞**、**正規表現** のいずれかです。エディタが固まるおそれのある正規表現は拒否されます：「That regular expression could hang the editor. Simplify it.」 |
| **置換** | 展開後のテキストです。 |
| **日付/時刻を挿入** | 置換に日付または時刻のトークンを追加するメニューです。 |
| **有効** | マクロを削除せずに、オンまたはオフにします。 |
| **コード内では展開しない** | コードスパンやコードブロックの中でマクロが動作しないようにします。 |
| **キャンセル**、**保存** | マクロを閉じる、または保持します。保存できない場合は、その理由がメッセージで表示されます。 |

置換の中では、`$1`、`$2` などがタブストップで、`$0` はカーソルが置かれる位置です。マクロの展開後は、Tab（または **次のフィールド**）でストップ間を移動できます。日付と時刻にはトークンを使います：`{{date:yyyy-MM-dd}}`、`{{time:HH:mm:ss}}`、`{{datetime:MM/dd/yyyy h:mm a}}`、および名前付きフォーマットの `iso8601`、`rfc2822`、`unix`、`short`、`medium`、`long`、`full` です。フィールドの下の **Now:** 行には、現時点で置換がどのように展開されるかが表示されます。

# Chapter 78: iPad で Pilcrow を使う

Pilcrow は iPadOS 17 以降で動作します。タッチ操作だけでも、ハードウェアキーボードやトラックパッド、マウスとの組み合わせでも使えます。

## タッチ操作

- **ペインの境界。** 並べて表示では、ソースとプレビューの間の境界をドラッグしてサイズを変更します。ダブルタップするとリセットされます。
- **ナビゲータ。** サイドバーの端をドラッグしてサイズを変更します。幅の狭いウインドウでは、サイドバーが書類の上に重なり、**完了** ボタンで閉じられます。
- **列選択。** **その他 ▸ 列選択** をオンにして、指1本でドラッグすると、テキストの矩形範囲を選択できます。指2本では引き続きスクロールします。オンの間は **列選択** のバッジが表示され、オフにするボタンも付いています。または **その他 ▸ 列にカーソルを置く…** を使って、数を指定してカーソルを置くこともできます。
- **コンテキストメニュー。** テキストを長押しすると、エディタのメニューが表示されます（後述）。
- **ファイル。** ファイルパネルでファイルを長押しすると、そのメニューが表示されます（Chapter 60）。

## ハードウェアキーボードを使う場合

Chapter 77 のすべてのショートカットが使えます。**⌘** を押し続けると iPad のメニューバーが表示されます。またはポインタを画面の上端に移動します。キーボードやマウスが接続されているときは、Pilcrow 独自のヘッダメニューを非表示にできます。**設定 ▸ 外観 ▸ ヘッダのメニュー** を参照してください。

## トラックパッドまたはマウスを使う場合

右クリックすると、エディタのコンテキストメニューが開きます。**Option** を押したままドラッグすると、テキストの矩形範囲を選択できます。

## エディタのコンテキストメニュー

テキスト内で、Mac では右クリック、iPad では長押しします。有効な構文プロファイルで表現できない項目はグレーアウトされ、システムの項目（カット、コピー、ペースト、スペルの候補、調べるなど）が追加されます。

**Mac** の場合：

| 項目 | 内容 |
| --- | --- |
| **コピー / ペースト形式…** | **Markdown としてコピー**、**プレーンテキストとしてコピー**、**HTML コードとしてコピー**、**プレーンテキストとしてペースト**。 |
| **段落** | **段落**、**見出し 1** から **6**、**引用**、**箇条書き**、**番号付きリスト**、**タスクリスト**、**コードブロック**。 |
| **フォーマット** | **太字**、**強調**、**コード**、**取り消し線**、**インライン数式**、**別行立て数式**、**ダイアグラム**、**グラフ**、**ハイパーリンク**。 |
| **選択** | **単語を選択**、**行を選択**、**段落を選択**。 |

**iPad** では、システムの項目と並んで3つのサブメニューが表示されます。

| 項目 | 内容 |
| --- | --- |
| **フォーマット** | インラインスタイル：太字、強調、コードなど。 |
| **段落** | 段落の種類：見出し、引用、リスト、コードブロック。 |
| **挿入** | 書式バーの **その他** メニューと同じ挿入項目で、**注意を挿入**、**イメージを挿入…**、**表を挿入…** のほか、**構文** の下に、有効なプロファイル独自の構文要素があります。 |

## Mac との違い

| iPad の場合 | Mac の場合 |
| --- | --- |
| 設定は、ヘッダの歯車からシートで開きます。 | **Pilcrow ▸ 設定…**（`⌘,`）。 |
| ヘッダに Pilcrow 独自のメニューを表示できます（**ヘッダのメニュー**）。 | メニューバーはシステムのものです。 |
| **インターフェースのサイズ** で、メニュー、バー、ダイアログのサイズを設定します。 | 利用できません。 |
| 読み込みは **設定 ▸ ライブラリ ▸ 読み込む** にあります。 | **ファイル ▸ 読み込む**。 |
| すべて保存、複製、移動先、ディスクから再読み込み、Finder で表示、ページ設定はありません。 | これらはファイルメニューにあります。 |
| **編集 ▸ スペルと文法** には **入力中にスペルチェック** の1項目だけがあります。 | **編集 ▸ スペルと文法** には、**スペルと文法を表示** と **今すぐ書類をチェック** もあります。 |
| 入力サウンドは、iPad のサイレントスイッチでミュートされます。 | 該当しません。 |
