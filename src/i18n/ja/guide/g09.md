# Chapter 65: アシスタントパネルとスタイルレビュー

アシスタントパネルは、**設定 ▸ アシスタント**（第67章）で接続を設定すると表示されます。使用できる接続がない間は、表示メニューに**アシスタント**の項目は表示されません。

## パネル

| コントロール | 機能 |
| --- | --- |
| **アシスタントのモード** | **会話**、**スタイルレビュー**、**ヘルプ**のいずれかです。 |
| **モデルを選択…** | モデルの選択画面（下記）を開きます。モデルが利用できなくなった場合や非推奨になった場合は、廃止日とともに警告を表示します。 |

| **アシスタントに質問…** / **書きたいものを説明してください** | 質問ボックスです。**ヘルプ**モードでは、**作成するもの**で**構文プロファイル**、**マクロ**、**スタイルガイド**のいずれかを選びます。 |
| **送信**と**停止** | リクエストを送信するか、実行中の返信を停止します。 |
| **プライバシー** | このフォルダでアシスタントがオンかどうかを表示します。**このフォルダでオフにする**と**このフォルダでオンにする**で切り替えます。除外の条件に一致するファイルでは、「このファイルはアシスタントから除外されています。」と表示されます。 |
| 各返信 | **コピー**、**カーソル位置に挿入**、**再試行**があり、スタイルやマクロの返信には**ライブラリに追加…**もあります。エラーを含む返信には**修正を依頼**が表示されます。途中で切れた返信にはその旨が表示されます。 |

## モデルを選ぶ

**モデルを選択…**には、接続が提供するモデルが一覧表示され、**モデルを検索**で絞り込めます。**すべてのモデルを表示**をオンにすると、あまり使われないモデルも含まれます。非推奨のモデルには廃止日が表示されます。一覧にモデルがない場合は、モデル名を直接入力してください。**再試行**で一覧を再読み込みします。

## スタイルレビュー

**スタイルレビュー**モードでは、パネルがスタイルガイドをあなたの文章に適用します。

| コントロール | 機能 |
| --- | --- |
| **スタイルガイド**、**バリエーション** | ガイドと、そのバリエーションの1つを選びます。 |
| **レビュー対象** | **選択**または**ドキュメント**です。大きすぎて全体をレビューできない書類では、「大きすぎて全体をレビューできません。代わりにセクションをレビューしてください。」と表示されます。 |
| **分野** | チェックする分野を選ぶか、**すべての分野**を選びます。 |
| **レビュー** | テキストとルールをAI接続に送信します。書類全体のレビューの前に、送信されるリクエストの数とおおよそのテキスト量を示すアラートが表示され、**レビュー**または**キャンセル**を選びます。 |
| **ここをチェック** | ガイド独自のチェックをこのデバイス上で実行します。何も送信されません。 |
| **相互参照をチェック** | 書類内のある部分と別の部分を比較するルールを確認するために、見出し、引用している行、参照リストを送信します。 |
| **停止** | 実行中のレビューを停止します。停止または失敗のあとは、**残りをレビュー**で続行できます。 |

検索結果は一覧に表示されます。それぞれに、引用箇所、説明、そして修正案がある場合は修正案が表示されます。

| ボタン | 機能 |
| --- | --- |
| **移動** | 書類内の該当箇所に移動します。同じ引用が複数回出てくる場合は、「N件中N件目」と表示されます。 |
| **適用** | 修正案を反映します。テキストが見つかったときのままである場合にだけ適用されます。そうでない場合は、「テキストが変更されています。」または「テキスト内に見つかりません。」と表示されます。 |
| **閉じる** | 指摘を削除します。 |
| **すべて適用** | 修正案のあるすべての指摘を反映します。件数を示す確認のあとで実行され、1回の操作で取り消せる1つの変更になります。AIによる修正の件数も表示されます。 |
| **すべての提案を無視**、**クリア** | 一覧を空にします。 |

パネルには、「N個のルールはレビューでしか判断できません」「N個のルールは100件の指摘で打ち切られました」「テキストにない事実が加えられていたため、修正案を1件除外しました。」といった報告も表示されます。

### ログビューア

**診断ログ**には、概要（**エントリ**、**セッション**、**エラー**、**警告**、**クラッシュレポート**、日付の範囲）が表示され、その下に新しい順のエントリが並びます。**ログを検索**フィールドと、**項目**および**レベル**のフィルタがあります。フィルタは表示だけを変え、送信される内容は変えません。レポートには、ログのすべてのエントリと、「レポートに含める」で選んだ内容が含まれます。**再読み込み**で更新します。**レポートを送信**には次の項目があります。

| 項目 | 機能 |
| --- | --- |
| **レポートを保存…** | 自分で送れるファイルとして保存します。 |
| **レポートを共有…** | 共有シート（AirDrop、ファイルなど）を開きます。 |
| **GitHubで報告…** | 短い概要付きの新しいissueを開きます。**ログを説明に追加**（最新のエントリで、GitHubが許容する上限の60,000文字までをクリップボードにコピーするので貼り付けます）または**保存してファイルを添付**（ログ全体を、自分で添付するファイルにします）を選びます。GitHubでの報告は公開されます。 |

何も記録されていない状態で報告を始めると、Pilcrowは**先に問題を記録しますか？**と尋ねます。選択肢は**先に問題を記録**、**今すぐ報告**、**キャンセル**です。フォームを開くときには、**ログを追加してフォームを開く**、**常にログを追加**、**ログなしでフォームを開く**のどれにするかを尋ねます。

## ストレージとプライバシー

Pilcrowは、復元用のコピー、履歴、アクセス許可、サポート用データをサンドボックス内に保持します。各カテゴリは個別に削除できます。これらのコントロールが書類を削除することはありません。

| セクション | コントロール |
| --- | --- |
| **書類** | **復元データを確認**と**バージョン履歴を確認**です。確認画面には対象の項目がサイズとともに一覧表示されるので、削除する前に容量を確かめられます。削除するものにチェックを付け（**すべてを選択**または**選択を解除**）、**選択項目を削除**を選びます。書類に未保存の変更がある間は、復元データを確認できません。先に保存するか閉じてください。 |
| **ファイルへのアクセス** | **最近使ったファイルへのアクセスを消去…**は、最近使ったファイルの一覧、記憶された「別名で保存」のフォルダ、セッションのブックマーク、ファイルごとの構文の選択を削除します。 |
| **プライベートデータとサポートデータ** | **AI のデータとキーを削除…**（接続、キーチェーンのキー、現在の会話、AIのプライバシーの選択内容）、**診断情報を削除…**（記録されたログと保存済みのクラッシュ診断）、**キャッシュを消去…**（再作成できるキャッシュファイルとネットワーク応答）があります。 |

削除はすべて確認が表示されます（「この操作は取り消せません。書類は削除されません。」）。カスタムの構文プロファイル、テーマ、マクロ、スタイルガイド、背景はここでは削除されません。それぞれのライブラリのページで確認して削除してください。
