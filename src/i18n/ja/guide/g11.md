# Chapter 72: キーボード

**設定 ▸ キーボード ▸ ショートカット** には、ショートカットを変更できるすべてのコマンドと、現在のキーが一覧表示されます。

| 操作 | できること |
| --- | --- |
| コマンドの行 | 行をクリックし、新しいショートカットを押して、**保存** を選びます。**割り当てを解除** を選ぶとショートカットが解除されます。**キャンセル** を選ぶと元のままになります。ショートカットがほかのコマンドで使われていた場合は、そのコマンドの割り当てが解除され、ページにその旨が表示されます。 |
| **Super Tabのキー** | **次のフィールド** と **前のフィールド** のキーです。マクロが残した空欄の間を移動します。`⌥Tab` と `⌥⇧Tab`、または `⌃⌘]` と `⌃⌘[`、あるいは **カスタム** から選べます。 |
| **すべてのショートカットをリセット** | すべてをデフォルトに戻します。 |

変更できるコマンドとそのデフォルトは次のとおりです。

| コマンド | デフォルト |
| --- | --- |
| 太字 | `⌘B` |
| 強調 | `⌘I` |
| インラインコード | `⌃`` ` `` |
| インライン数式 | `⌃M` |
| 取り消し線 | `⌃⇧`` ` `` |
| ハイパーリンク | `⌘K` |
| フォーマットを消去 | `⌘\` |
| サイドバーの表示/非表示 | `⇧⌘L` |
| サイドバー: アウトライン | `⌃⌘1` |
| 開いている書類 | `⌃⌘2` |
| サイドバー: ファイルツリー | `⌃⌘3` |
| サイドバー: 検索 | `⇧⌘F` |
| サイドバー: アシスタント | `⌃⌘4` |
| 上にカーソルを追加 | `⌃⇧↑` |
| 下にカーソルを追加 | `⌃⇧↓` |
| 列にカーソルを置く… | `⌃⇧G` |
| 戻る | `⌃⌘←` |
| 進む | `⌃⌘→` |
| 次の出現箇所を選択 | `⌃⌥D` |
| すべての出現箇所を選択 | `⌃⌥⇧D` |
| 次のフィールド | `⌥Tab` |
| 前のフィールド | `⌥⇧Tab` |
| コマンドパレット… | `⌃⇧P` |
| 集中モード | なし |

この一覧にないコマンド（保存、検索、段落の項目など）のショートカットは固定です。すべてのショートカットは第77章にまとめてあります。

# Chapter 73: サブスクリプションとクレジット

Pilcrow のすべての機能は無料です。Pilcrow を応援するかどうかは任意です。応援していただくと開発の助けになり、次に何を作るかについての投票権が得られます。投票は作業の順序の参考にしますが、機能の実現をお約束するものではありません。

**Pilcrowを応援** のページには次の項目があります。

| 項目 | 表示される内容・できること |
| --- | --- |
| **あなたの投票数** | **サブスクリプションから**（今回の有料月の投票数と、その有効期限）と **購入分**（期限のない投票数）。サブスクリプションの投票が先に使われ、有料月が終わると失効します。 |
| **投票数を入手** | サブスクリプションと、購入できる単発の投票。Pilcrow Supporter は、Apple アカウントの設定で解約するまで毎月更新されます。有料の月ごとに投票数が付与されます。 |
| **購入を復元** | 別のデバイスで行った購入を復元します。 |
| **利用規約**、**プライバシーポリシー** | リンクです。 |
| **Appアイコン** | 購読者向けの Appアイコンの選択肢です。投票ラウンド用のアイコンは、そのラウンド中に購読すると獲得でき、その後も使い続けられます。Mac では、Pilcrow を開いている間、Dock のアイコンが切り替わります。 |
| **ロードマップ** | 現在投票を受け付けている機能のラウンドです。「Votes」と「Yours」の数と、各機能の **投票** ボタンが表示されます。1回の投票で投票数を1つ使い、取り消すことはできません。ラウンドの合間には、次のラウンドがいつ始まるかが表示されます。 |

お使いのビルドで応援のオプションが利用できない場合は、ページにその旨が表示されます。
