# Part XIX — ライブラリ項目のエディタ

# Chapter 74: プロファイルエディタとプロファイルの構成要素

構文プロファイルは、あなたのマークアップが何を意味するのかを Pilcrow に伝えるものです。この章では、プロファイルエディタをコントロールごとに説明し、続いてプロファイルで使えるすべての構成要素を一覧にします。作業を中心にした入門は、第37章から第39章をご覧ください。

エディタは **設定 ▸ ライブラリ ▸ 構文プロファイル** から開きます。**新規** でプロファイルを作り、**編集** でカスタムプロファイルを変更し、**複製** で組み込みプロファイルをコピーして、コピーのほうを変更できます。エディタのタイトルは **プロファイルを編集** で、**キャンセル**、**保存**、**プロファイルのヘルプ**（これらの構成要素のアプリ内リファレンスを開きます）があります。画面が狭い場合は、**プロファイルのセクション** スイッチで **概要**、**ルール**、**テストサンプル** を切り替えます。広い画面では3つすべてが同時に表示されます。

## 概要

| フィールド | 内容 |
| --- | --- |
| **名前** | プロファイルの名前です。ステータスバーのメニューと設定に表示されます。 |
| **説明** | プロファイルについてのメモです。 |
| **ファイル拡張子（カンマ区切り）** | ファイルに対してこのプロファイルを選ぶ拡張子です。2つのプロファイルで同じ拡張子を共有することはできません。 |
| **継承元** | **なし**、またはこのプロファイルがルールの土台にする別のプロファイルです。 |
| **構文** | **Markdown を拡張** または **Markdown を置き換え**（後述）。 |
| **概要** | **ブロックルール**、**インラインルール**、**入れ子ルール** の数です。 |
| **詳細な JSON を編集…** | ガイド付きエディタでは扱えないフィールドのために、プロファイルを JSON として開きます。**適用** で JSON の変更を保持し、**キャンセル** で破棄します。 |

**Markdown を拡張** は、あなたのルールを Markdown のルールに加えます。見出し、リスト、強調などは引き続き読み取られ、あなたのブロックルールとインラインルールがそれに追加されます。CommonMark プロファイルのルールと変更のないコピーであるルールは、Markdown がすでに行っていることを表すので、Markdown に任せられます。**Markdown を置き換え** は、あなたのルールを構文のすべてにします。そのため Markdown の構造は認識されなくなります。この場合、いずれかのルールが **行末** を生成する必要があります。そうしないと段落が区切られません。エディタは「Add a rule whose output node is "newline", or nothing will separate into paragraphs」（出力ノードが「newline」のルールを追加してください。そうしないと段落が区切られません）と警告し、そのようなルールができるまでプロファイルを保存できません。また、プロファイルが定義していない出力の種類があれば、それも一覧表示します。

## ルール

ルールは3つのグループに分かれます。

### ブロックルール

ブロックルールは、行全体やブロックを認識します。**ルールを追加** で追加します。各ルールには **パターン**、**一致** の種類、何を **生成するもの** か、そして **オプション** があります。ルールは **削除** ボタンで取り除きます。ルールがないときは、エディタに「No rules yet. Add one to recognize a block construct.」（まだルールがありません。ブロックの構造を認識するには、ルールを追加してください。）と表示されます。

### インラインルール

インラインルールは、行の中のテキストを認識します。**インラインルールを追加** で追加します。インラインルールで選べる一致の種類は4つ（**リテラル接頭辞**、**完全一致**、**正規表現（制限付き）**、**区切り文字ペア**）で、ブロックルールでは7つすべてを選べます。

### 入れ子ルール

入れ子ルールは、どの出力がどの出力の中に入れるかを定めます。各ルールには **親ノード** と **許可する子ノード（カンマ区切り）** があります。空の場合は制限なしを意味し、「No restrictions. Every node type may nest inside any other.」（制限なし。どのノードの種類も、ほかのどれの中にも入れ子にできます。）と表示されます。**入れ子ルールを追加** で追加します。

### 一致の種類

| 一致の種類 | パターンの読み方 | ブロック | インライン |
| --- | --- | --- | --- |
| **リテラル接頭辞** | その構造が始まるテキスト。 | はい | はい |
| **完全一致** | その構造のテキスト全体。 | はい | はい |
| **行頭接頭辞** | `# ` のように、行の先頭にあるテキスト。 | はい | |
| **インデントブロック** | 4つのスペースやタブのように、パターンで始まる行。連続する行と、その間の空行は1つのブロックとなり、インデントなしで表示されます。 | はい | |
| **フェンスブロック** | ブロックを開く行。対応する行で閉じられます。 | はい | |
| **正規表現（制限付き）** | 正規表現。止まってしまうおそれのある正規表現は、保存する前に Pilcrow が「This regex could hang the editor — simplify it.」（この正規表現はエディタを停止させるおそれがあります。単純にしてください。）と警告します。 | はい | はい |
| **区切り文字ペア** | `%%this%%` の `%%` のように、1行の中でテキストの両側に付く同じ記号。記号のすぐ内側にスペースは入りません。 | はい | はい |

正規表現では、`(?<name>…)` で一致の一部に名前を付けます。後述の「部分」をご覧ください。

## ルールのオプション

各ルールの **オプション** グループには次のものがあります。

| オプション | 内容 |
| --- | --- |
| **優先度** | 優先度が高いルールが先に試されます。 |
| **行頭のみ** | ルールが行の途中で一致しないようにします。 |
| **名前付きの部分を属性にする** | 正規表現の名前付きの部分が、それぞれ出力の属性になります。エディタには「Parts in this pattern」（このパターンの部分）と「Parts this output reads」（この出力が読む部分）が一覧表示されます。太字やリンクのようにテキストを持つ出力では、表示されるテキストは、`text` という名前の部分があればそれ、なければ最後に一致した部分になります。 |
| **生成するもの** | ルールが作るものです。下の一覧にある出力か、**カスタム** の名前を選びます。 |
| **カスタムノード名** | **カスタム** の出力につける名前です。 |
| **固定属性** | 毎回同じ値になる部分です。**属性を追加** で追加します（**名前** と **値**）。値には、`{name}` と書いて名前付きの部分を含められます。たとえば、パターンで `address` という名前を付けたメールのルールなら、リンクの `url` を `mailto:{address}` にできます。 |
| **挿入テキスト** | このルールのために **挿入** メニューが書き込む内容です。表示されるとおりに書き、カーソルを置きたい場所に `$0` を入れます。正規表現、ブロック、インデントで一致するルールにはこれが必要です。ないと、挿入メニューにそのルールは出ません。 |
| **空行の後だけ** | インデントブロック用です。テキストの直後のインデントされた行は、リスト項目の次の行のように、そのテキストの一部のままになります。 |
| **行末でReturnを押した後** | リストと引用用です。**自動**（箇条書きと引用を繰り返し、番号付きの項目は番号を増やし、タスク項目は未チェックで始めます）、**マーカーを繰り返す**、**番号を増やす**、**マーカーから新しく始める**、**何も追加しない** から選びます。 |

### フェンスブロックと区切りブロック

**フェンスブロック** のルールでは、**ブロックの中身** で中に入るものを指定します。

| 選択肢 | 意味 |
| --- | --- |
| **まだなし** | 未設定です。 |
| **テキスト（書いたまま表示）** | コードや整形済みテキストです。 |
| **なし（非表示）** | コメントです。書類には表示されません。 |
| **ほかのブロック（枠あり）** | 段落やリストなどを含む、引用、サイドバー、注記です。 |
| **ほかのブロック（枠なし）** | ブロックは周囲のテキストにつながり、行はそれらをまとめるだけです。 |
| **表** | 後述の「表」をご覧ください。 |
| **テキストで描いた表** | reStructuredText のように、開始行から次の空行まで続く、テキストのグリッドや揃えた列です。 |
| **マーカーで終わる行の下のインデントされたテキスト** | 開始行は、reStructuredText の `::` のように、マーカーで終わる文章です。その文章は段落のままで、空行をはさんで下にインデントされたテキストは書いたまま表示されます。 |
| **開始行の下のインデントされたテキスト** | `.. code-block::` のようなディレクティブです。その下のインデントされた行を内容とし、終了行はありません。 |

**終了行** はブロックを終わらせる行です。空の場合は開始行と同じ行を意味します（「Same as the opening line」（開始行と同じ））。`+++` のような、正規表現ではない区切りは、そのままのテキストとして一致します。**終了行は開始行の記号を同じ数以上、繰り返す** は Markdown 形式のフェンス用です。終了行は、開始行の最初の文字を同じ数以上繰り返したもので、長いフェンスは短いフェンスをテキストとして含められます。テキストブロックの言語は、開始行が既知の言語を示している場合、エディタ内で色分けされます。

### 表

表ブロックのオプションです。

| オプション | 内容 |
| --- | --- |
| **配置** | **罫線付きのグリッド**（セルは `|` の間に置き、行の間に罫線を引く）または **揃えた列**（最初の罫線行の下に列を揃える）。 |
| **セルの区切り** | 各セルを始めるテキストです。 |
| **罫線行のパターン**、**見出し罫線行のパターン** | 罫線だけを描く行と、見出しを終わらせる行です。 |
| **行の終わり** | LaTeX の `tabular` のように、各行を終わらせる記号です。 |
| **結合セルのパターン** | 複数の列にまたがるセルです。 |
| **セルオプションのパターン** | セルの区切りの直前に置けるものを表す正規表現です。`colspan` という名前の部分があると、そのセルはその数の列にまたがります。 |
| **列リストの区切り**、**繰り返し記号** | `columns` のリストの書き方です。`,` と `*` を使い、`3*` は3列を数えます。 |
| **空行の前の最初の行を見出しにする** | 見出し行を、レイアウトによって暗黙に決めます。 |
| **形式** | セルを書くほかの方法で、それぞれ名前と区切りからなります（`csv` と `,` など）。**形式を追加** で追加し、表の `format` の部分で選びます。 |

## プロファイル全体の設定

| 設定 | 内容 |
| --- | --- |
| **マーカーでリストを入れ子にする** | `*` の後の `**` のように、新しいマーカーが現れるたびに、インデントに関係なく、1段深いレベルが始まります。 |
| **リスト継続行** | リスト項目の後に単独で置かれ、次のブロックをその項目に結び付ける行です。 |
| **単一の改行を保持** | 段落内の改行を、改行のままにします。 |
| **見出しにIDを付ける** | 自分のIDを持たない見出しには、タイトルからIDが付きます。小文字にし、単語を **単語区切り** でつなぎ、**接頭辞** の後ろに置きます（**IDの接頭辞**、**IDの単語区切り**）。`_` と `_` なら、"Getting Started" は `_getting_started` になり、それへの相互参照にはタイトルが表示されます。タイトルが重複すると、区切りと数字が追加されます。 |
| **見出しに番号を付ける** | AsciiDoc の `:sectnums:` のように、**文書が定義したとき** で指定した属性を書類が定義すると、**見出しレベルから** 下の見出しに `1.`、`1.1.`、`2.` と番号が付きます。定義より前の見出しには付きません。 |
| **番号付きキャプション** | ここに挙げた出力（`image`、`table`、`example` など）のタイトル付きブロックには、タイトルの前に **ラベル** と専用の番号が付きます（たとえば「Figure 1.」）。位置は **キャプションの位置** で、ブロックの **上** か **下** です。**キャプションを追加** で追加します。 |

## 周囲の文字で決まるインライン記号

Markdown のような言語では、太字や斜体を、隣の文字によって開いたり閉じたりする文字の連なりで書き、コード片やリンクを括弧で書きます。そのため、構造全体を1つのパターンで見つけることはできません。これらを記述するには、**周囲の文字で決まる記号を読み取る** をオンにします。

| 設定 | 内容 |
| --- | --- |
| **エスケープ文字** | 次の1文字を普通の文字にする文字です。 |
| **コード片の文字** | この文字の連なりでコード片が始まり、同じ長さの次の連なりで閉じます。 |
| **連続記号** | 連なりとして対になる記号です。**連続記号を追加** で追加します。それぞれに **記号**、**1つの記号で描画** するもの、**2つの記号で描画** するもの、そして **単語の途中で開始・終了できる**（`_` ではオフ）があります。 |
| **対になる記号** | 同じ長さの連なりと対になる記号です。**対になる記号を追加** で追加します。**記号**、**描画** するもの、そして **この設定がオンのときのみ**（ハイライトのように、オンになっている必要がある構文設定。または **常に**）を指定します。 |
| **リンクとWebアドレス** | **画像の接頭辞**、**単独のアドレスを囲む文字**、**装飾のないアドレスの先頭になるスキーム**、**ラベルを定義する行に付く文字**、**脚注のラベルの先頭文字**（ラベルの開き括弧の次の文字で、脚注にするもの。`[^note]:` で始まる行があれば、`[^note]` は脚注の参照として描かれます）。 |

記号は1行の中で対になります。コード、エスケープされた文字、リンクのアドレスは、周囲の記号から見ると普通のテキストです。

## スタイル付きソース

**スタイル付きソース** をオンにすると、エディタは書類を、その構文の見た目で描画します。大きな見出し、太字や斜体、引用の縦線、リストのインデント、タスクのボックス、罫線、リンク、コードのカードなどです。そして、カーソルがある行を除いて、それらを作る記号を隠します（**マーカーを隠す** がオンのとき）。エディタは特定の構文を何も知りません。ルールが、スタイルの項目を持つことで一致が何であるかを示し、持たないルールは色が付くだけでスタイルは変わりません。

すべてのルールの **オプション** には **スタイル付きソース** グループがあります。

| フィールド | 内容 |
| --- | --- |
| **役割** | 一致が何であるか、または **スタイルなし**。行の中の1つの構造には、見出し（heading）、太字（strong）、強調（emphasis）、コード（code）、取り消し線（strike）、ハイライト（highlight）、下線（underline）、リンク（link）、下付き（subscript）、上付き（superscript）があります。行全体には、罫線（rule、主題の区切り）、リスト（list、リスト項目のマーカー。インデントとその後のスペースを含む）、タスク（task、チェックボックスが続くマーカー）、引用（quote、引用された行の `>` 記号）があります。全体で認識されるブロックには codeBlock、開始行と終了行が別々の一致であるブロックには quoteRegion、画像として描かれる表、数式、ダイアグラムには renderedBlock があります。 |
| **内容のグループ** | 1から数えて、その構造の内容を保持するキャプチャグループです。`*bold*` の中の単語や、`\section{Title}` のタイトルなどです。一致のそれ以外の部分はその構造自身の記号で、**マーカーを隠す** で隠されます。`0` は一致全体が内容で何も隠さないことを意味し、Web アドレスがそうです。見出しの `== ` のように、一致が記号だけのときは省略します。 |
| **見出しレベル**、**レベルのグループ** | 見出しのレベルで、1から6です。省略した場合は、ルールの出力名の末尾の数字（`heading2`）、または `#` の連なりを保持するキャプチャグループの長さになります。 |
| **マーカーのグループ** | リストまたはタスクで、一致が引用された項目の `> ` のようにほかのもので始まるとき、インデントとその後のスペースを含むマーカーであるキャプチャグループです。 |
| **行末までスタイルを適用** | 一致から行末までスタイルを適用します。見出しのマーカーだけに一致し、タイトルをその後に続くテキストとして残すルール用です。 |
| **描画方法** | 描画されるブロックについて、それが何であるかです。表、数式、ダイアグラム、または **画像にしない**。 |
| **アドレスのグループ** | リンクで、クリックまたはタップしたときに開くアドレスを保持するキャプチャグループを、試す順に指定します。`0` は一致全体です。開くのは Web、メール、電話のアドレスだけです。 |

グループ番号は、パターンの括弧を1から数えたものです。0は一致全体です。Markdown を置き換えないプロファイルは、ルールが宣言していない種類について、引用の縦線や `**` の対のように、Markdown 自身の読み取りも保持します。

## 書類の属性と条件付きセクション

**書類の属性** ルールは、`name` で値を定義します。**属性の参照** ルール（`name` と `original` の部分を持つインラインルール）は、参照をその値に置き換えます。だれも定義していない属性への参照は、書いたままになります。**条件付きセクション** は、指定した属性が設定されているかどうかに応じて、その行の間のブロックを残すか除きます。属性は、定義された場所から先で有効になります。

**次のブロックの設定** を生成するルールは、その後ろのブロックを設定する行全体を認識し、それ自体は何も表示しません。その部分と固定属性は、そのブロックに渡されます。`title`、`id`、`nodeType`、`language`、`hardbreaks` は「部分」の項に挙げた意味を持ち、ほかの部分はブロックに保持されて、表、リスト、引用が読み取ります。

## プロファイルのテスト

エディタの下部にある **テストサンプル** には、サンプルのテキストが入っています（最初は見出しと1行のテキストです）。**サンプルをチェック** を選ぶと、ルールが作るノードが、入れ子の深さに応じたインデントで表示されます。何も一致しないときは「No blocks recognized.」（認識されたブロックはありません。）と表示されます。

## ベースライン

プロファイルの **ベースライン** は、その復元ポイントです。プロファイルを作成、複製、または読み込んだときの状態を指します。**ベースラインに戻す** は、確認の後、それ以降のすべての変更を破棄します。**新しいベースラインとして設定** は、プロファイルを保存し、その現在の状態を復元ポイントにします。

プロファイルが Markdown を置き換えるのに行末のルールがない場合、パターンが安全でなくエディタを止めるおそれがある場合、またはファイルを書き込めない場合は、保存が拒否され、メッセージが表示されます。

## 出力

ルールが **生成するもの** です。メニューでの名前、続いてプロファイルファイルに保存される名前、ブロックルールとインラインルールのどちらが生成できるか、そして読み取る部分を示します。ルールは、この一覧にない出力の名前を指定することもでき、その場合は **カスタム** として保持されます。

## 部分

部分とは、出力が読み取る、一致の名前付きの要素です。

| 部分 | 意味 |
| --- | --- |
| `allOf` | すべてが必要なときの、名前の間の区切りです。`+` など。 |
| `alt` | 画像を見られない読者のための、画像の説明です。 |
| `anyOf` | どれか1つで足りるときの、名前の間の区切りです。`,` など。 |
| `attribution` | 引用を述べた人で、引用の下に表示されます。 |
| `citetitle` | 引用の出典となる作品で、帰属表示の後に表示されます。 |
| `columns` | 表の列リストです。`1,2,1` など。要素の数が列の数になります。 |
| `condition` | セクションが依存する属性の名前です。 |
| `conditionType` | `defined` は属性が設定されているときにセクションを残し、`undefined` は設定されていないときに残します。 |
| `content` | 一致全体ではないときの、テキストそのものです。 |
| `format` | ダイアグラムのエンジン（`mermaid` または `vega-lite`）。表では、セルが使う区切り形式のどれかです。 |
| `hardbreaks` | 指定すると、次のブロックの単一の改行を保持します。 |
| `header` | `false` 以外の値にすると、表の最初の行が見出しになります。 |
| `id` | 名前です。次のブロックでは、相互参照が指すID。脚注では、自分のテキストを持たない後続の脚注が番号を共有できるようにする名前です。 |
| `keys` | 押すキーで、カンマで区切ります。 |
| `label` | 参照やアンカーに、対象自身のタイトルの代わりに表示されるテキストです。 |
| `language` | コードブロックのプログラミング言語で、色分けに使われます。 |
| `level` | 見出しのレベルで、1から6です。 |
| `marker` | 用語の後の区切りです。`::` など。別のマーカーを使うと、説明の中にリストが入れ子になります。 |
| `name` | 定義や参照での、属性の名前です。 |
| `nodeType` | 次のブロックを、ファイル内の名前で指定した別の出力にします。 |
| `noHeader` | 指定すると、表に見出し行がありません。 |
| `notation` | 数式の記法です。`tex`（デフォルト）または `latex`。 |
| `open` | `true` にすると、折りたたみセクションが開いた状態で表示されます。 |
| `ordered` | `true` にすると、リストに番号が付きます。 |
| `original` | 書かれたままの参照で、属性が定義されていないときに表示されます。 |
| `presentation` | 次の説明リストの表示方法です。`sideBySide` は用語と説明を2列に並べ、`questions` は各用語を質問として番号付けし、その下に答えを置きます。 |
| `primary` | 索引の項目です。 |
| `secondary` | 索引の項目の下にある副項目です。 |
| `sectionLabel` | 次の見出しの番号が後に続く語です。`Appendix` など。そのような見出しは単独で数えられ、`Appendix A:` となります。 |
| `sectionLabelStart` | それらの番号の最初です。文字（`A`）なら文字で数え、数字なら数字で数えます。 |
| `src` | ビデオまたはオーディオのファイルのアドレスです。 |
| `start` | 番号付きリストが始まる番号です。 |
| `summary` | 折りたたみセクションが閉じている間に表示される行です。 |
| `targetID` | 参照が指すIDです。 |
| `term` | 説明される用語です。 |
| `tertiary` | 副項目の下にある副項目です。 |
| `text` | パターンがそれ以上を捕捉するときの、表示されるテキストです。脚注のテキストは、それがある段落、表、リストの後に番号付きで続きます。 |
| `title` | タイトルです。ボックスの見出し、画像やリンクのツールチップ、または次のブロックの上のキャプション。 |
| `type` | 注記の種類です。`note`、`tip`、`warning` など。 |
| `unset` | 指定すると、ルールは属性を定義せずに削除します。 |
| `url` | リンクや画像が指すアドレスです。 |
| `value` | 属性の値です。先に定義された属性への参照は、この中で置き換えられます。 |
