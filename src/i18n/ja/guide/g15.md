# Chapter 81: ファイル、エンコーディング、上限

## Pilcrowで開けるファイル

Pilcrowは、プレーンテキストとマークアップのファイルを編集します。通常の拡張子は `txt`、`md`、`markdown`、`adoc`、`asciidoc`、`rst`、`tex` のほか、追加したプロファイルが受け持つ拡張子です。Pilcrowは、ファイルを開くときにテキストのエンコーディングを自動で検出します。

| 項目 | 種類 |
| --- | --- |
| 構文プロファイル、マクロコレクション、スタイルガイド、アプリケーションテーマ | `.json` |
| レンダリングテーマ | `.css` |
| テーマパッケージ | `.zip` |
| ブックプロジェクトのマニフェスト | `manifest.pilcrow` |
| 背景 | HEIC、PNG、JPEG、SVG、MP4、MOV、M4V |
| 入力サウンドのクリップ | WAV、AIFF、MP3、M4A、CAF |

## テキストのエンコーディング

Pilcrowは、UTF-8、UTF-16、UTF-32、ISO 8859-1（Latin-1）のテキストを読み込めます。**書類の情報 ▸ エンコーディング ▸ 変換…** を使うと、書類を次のいずれかに変換できます。ファイルは、次に保存するときに変換されます。

UTF-8、UTF-8 (BOM)、UTF-16 LE、UTF-16 LE (BOM)、UTF-16 BE、UTF-16 BE (BOM)、UTF-32 LE、UTF-32 LE (BOM)、UTF-32 BE、UTF-32 BE (BOM)。

Latin-1のファイルは、どの形式にも欠落なく変換できます。内容が失われるおそれがあるため、Latin-1への変換は用意されていません。

## 書き出しのフォーマット

| フォーマット | 拡張子 |
| --- | --- |
| HTML、HTML（スタイルなし） | `.html` |
| PDF | `.pdf` |
| Word (.docx) | `.docx` |
| 画像 | `.png` |
| PDFアーカイブ | `.zip` |

## 上限と数値

Pilcrowが止まる場所や、選択に範囲がある場所です。

| 場所 | 上限 |
| --- | --- |
| 検索パネル | 500件で止まります。 |
| プレビューの検索 | 2,000件までカウントします。 |
| フォルダ内の置換 | 一度に最大2,000ファイルを変更します。 |
| リンクを確認 | 最大50,000件のリンクを確認します。 |
| 比較 | 変更された行を最大5,000行まで表示します。 |
| 保持するバージョン | なしから500まで（デフォルトは50）。 |
| 長い行 | 20,000文字以上の行は、常に折り返されます。 |
| フォントサイズ | 9〜32ポイント。 |
| タブ幅 | 2〜8スペース。 |
| テキストの幅 | 50%〜100%。 |
| ズーム | 50%〜200%、10段階。 |
| 読む速さ | 1分あたり60〜2,000語。 |
| ナビゲータの幅 | 180〜420ポイント。 |
| 入力サウンドのクリップ | 最大2秒、3 MBまで。 |
| 診断レポートのログテキスト | GitHubのissueの説明に追加するとき、最新のエントリから最大60,000文字。 |
| 非常に大きなファイル | ファイル全体をメモリに読み込まずに開いて編集できます。行数と単語数、およびアウトラインはバックグラウンドで完成させるため、それまでは部分的な場合があります。非常に大きな書類のPDF書き出しは、編集やHTML、Wordへの書き出しよりはるかに多くのメモリを必要とします。PDFアーカイブは、それを上限のあるいくつかの部分に分割します。 |

## Pilcrowがデータを保管する場所

| 内容 | 場所 |
| --- | --- |
| お使いの書類 | 保存した場所。 |
| ライブラリ（テーマ、プロファイル、マクロ、スタイルガイド、背景） | アプリのプライベートストレージ、または選んだフォルダの中の「Pilcrow Library」という名前のフォルダ（**設定 ▸ ライブラリ ▸ 場所**）。 |
| 環境設定、APIキー、復元用コピー、バージョン履歴 | デバイス上の、アプリのプライベートストレージとキーチェーン。確認と削除は **設定 ▸ 一般 ▸ ストレージとプライバシー** で行えます。 |
| 診断ログ | 消去するまで、デバイス上。 |

# Chapter 82: メッセージ、バナー、空の状態

この章では、Pilcrowが表示する短いメッセージを説明します。どれも謎のままにはしません。

## エディタとプレビューで

| メッセージ | 意味 |
| --- | --- |
| **プレビューするものがまだありません。書き始めるとここに表示されます。**（または「編集に切り替えて書き始めてください。」） | 書類が空なので、プレビューに描画するものがありません。 |
| **プレビューを表示できませんでした: …** と **ソースを表示** および **再試行** | プレビューに失敗しました。**ソースを表示** は編集に切り替えます。**再試行** はもう一度試します。 |
| 失敗した数式や図と、**ソースを表示** リンク | 1つのブロックを描画できませんでした。**ソースを表示** をクリックすると、そのブロックのソースへ移動して修正できます。 |
| **保存できませんでした** と **再試行**、閉じるボタン | 保存に失敗しました。書類は開いたまま、未保存の状態です。原因（ディスクの空き容量、権限、移動されたファイル）を直してから、**再試行** を選びます。 |
| **ディスク上でファイルが変更されました** | 別のアプリがファイルを変更しました。**再読み込み** は新しいバージョンを読み込みます。**現在のバージョンを残す** は、今の内容を残します。 |
| **解析の警告** | 構文が意図と違っていそうな行です（第68章）。 |
| **既存のファイルを置き換えますか？** | 選んだ名前は、その場所ですでに使われています。 |
| **未入力のフィールドがあります** | 未入力のフィールドがある状態で、印刷または書き出しをしようとしています（第63章）。 |
| **ペインの境界**（VoiceOverのヒント: 「ドラッグしてエディタとプレビューのサイズを変更します。ダブルタップでリセットします。」） | 並べて表示での、ソースとプレビューの間のハンドルです。 |
| **単語数: N** | ステータスバーの単語数です。 |

## ダイアログとパネルで

| 場所 | メッセージ | 意味 |
| --- | --- | --- |
| コマンドパレット | **コマンドを入力** | フィールドのヒントです。該当するものがないときは「一致するコマンドはありません」と表示されます。 |
| クイックオープン | **ファイル名を入力** | フィールドのヒントです。 |
| 列にカーソルを置く | **行（例：3-17）**、**列（例：100、選択するなら 100-105）** | フィールドのヒントです。列を1つ指定するとカーソルが置かれ、範囲を指定すると各行のその範囲の文字が選択されます。 |
| 検索パネル | **入力してこのフォルダを検索します。**、**このフォルダに一致するものはありません。**、**検索を中止しました。** | フォルダ検索の状態です。 |
| ファイルパネル | **フォルダをここにドロップして開くこともできます。** | フォルダをパネルにドラッグすると開きます。 |
| フォルダ内の置換 | **置換するものはありません。** | 検索に一致するものがありません。 |
| 比較 | ボタンのツールチップ: **受け入れる**（「この変更を開いている書類に反映します」）、**却下**（「この変更を開いている書類に反映しません」）、**旧版に戻す**（「この変更についてのみ、古い行を書類に戻します」）。 | それぞれの働きです。 |
| 翻訳 | **翻訳を完了できませんでした。** | もう一度試すか、別の速度を選んでください。 |
| 翻訳 | **推定所要時間: 1 分未満** | AIアシスタント速度での見積もりです。実際の時間はお使いのAIサービスによって変わります。翻訳後は、**新しいタブで開く** で結果を開けます。 |
| アシスタント | **開いている書類はありません。**、**書類のテキストは送信されません。** | パネルに共有するものがないため、何も送信されません。 |
| モデルの選択 | **モデルを読み込み中…**、**一致するモデルはありません。** | リストを読み込み中か、検索に一致するものがありません。 |
| スタイルレビュー | **指摘はありません。** と **返信を指摘として読み取れませんでした。もう一度お試しください。** | レビューで指摘がなかったか、AIの返信が想定した形式ではありませんでした。 |
| スタイルレビュー | **すべて適用** のツールチップ: 「修正案のあるものをすべて、取り消せる1回の変更として適用します。」 | 取り消しを1回行うと、すべて元に戻ります。 |
| プロジェクトパネル | **お名前**、**変数を追加** | 作成者フィールドのヒントと、プロジェクト変数を追加するボタンです。 |
| アシスタントの許可 | **Pilcrowのプライバシーポリシーを読む** | プライバシーポリシーを開きます。 |

## 設定で

| 場所 | メッセージ | 意味 |
| --- | --- | --- |
| キーボード | **新しいショートカットを押してから、保存をクリックしてください。** と **いずれかのキーを押してください…** | ショートカットの記録中に表示されます。 |
| ライブラリ ▸ 場所 | **ライブラリの場所**、**ライブラリを移動中…** | ページのタイトルと、ライブラリの移動中の進行状況です。 |
| アシスタントの接続 | **保存済みのキーを残すには空欄のままにしてください。** | 編集時に、キーのフィールドを空欄にすると、キーチェーンにあるキーがそのまま残ります。 |
| マクロエディタ | **トリガー — 例: /sig** | トリガーフィールドのヒントです。 |
| プロファイルエディタ | **プロファイルの詳細 JSON**、**サンプルと結果** | JSONエディタのタイトルと、テストサンプルの下にある、サンプルから生成されるノードを表示する領域です。 |
| 診断 | **すべての項目**（ログビューア内）、**一致するエントリはありません。** | 絞り込みなしのログと、何にも一致しない絞り込みです。 |
| ステータスバー | 赤い **ログ記録中** マーク。そのツールチップは **診断の設定を表示** | ログを記録中です。クリックすると診断のページが開きます。**記録を停止してバグ報告を完了** は、**再現中 — 報告を完了** のツールチップです。 |
| ステータスバー | **この書類の構文プロファイルを選択** | 構文メニューのツールチップです。 |
| タイトルコントロール | **開いている書類と書類の操作** | 書類タイトルのツールチップです。 |
