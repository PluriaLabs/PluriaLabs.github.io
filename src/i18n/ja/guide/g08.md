# Chapter 63: ダイアログとプロンプト

この章では、作業中に表示されるシートとアラートについて説明します。

## 表を挿入

**フォーマット ▸ 段落 ▸ 表 ▸ 表を挿入…**（`⌥⌘T`）、または**挿入 ▸ 表…**で、**列**と**行**を尋ねられます。**OK** または**キャンセル**を選びます。表は、アクティブなプロファイルの表の構文で書かれます。

## 列にカーソルを置く

**編集 ▸ 選択 ▸ 列にカーソルを置く…**（`⌃⇧G`）は、キーボードのない iPad のために、番号を指定してキャレットを置きます。**行**（例：`3-17`）と**桁**（例：`100`、または各行のその範囲の文字を選択する `100-105`）を入力し、**配置**を選びます。そのあと、入力、削除、コピー、ペーストができます。列まで届かない短い行は、**設定 ▸ 編集 ▸ 列モードでの短い行**に従います。列選択がアクティブな間は**列選択**バッジが表示され、**列選択をオフにする**ボタンがあります。

## ブロックを編集

**描画ブロック**がオンのとき、画像として描かれた表、数式、ダイアグラムには編集ボタンがあります。これを押すと、ブロックのソースを含むシート**ブロックを編集**が開きます。変更を戻すには**適用**を、やめるには**キャンセル**を選びます。

## リンクを確認

**編集 ▸ リンクを確認…**は、書類内のすべてのリンクと画像を確認します。ほかのファイルへのリンクを確認するには、先に書類を保存する必要があります：「ほかのファイルへのリンクを確認するには、書類を保存してください。」シートには「リンクを確認中…」と表示され、続いて問題の一覧（それぞれに行番号付き）、または「すべてのリンクは有効です。」と表示されます。概要は「確認したリンク: N。接続していない Web アドレス: N。」と表示されます。Pilcrow は Web アドレスには接続しません。最大50,000件のリンクを確認します。**もう一度確認**または**完了**を選びます。

## フォルダ内置換

検索パネルの**置換…**は、ファイルに触れる前に、すべての変更のプレビューを開きます。

- **置換後**フィールドに置換するテキストを入力します。シートには、変更されるファイルが一覧され、一致ごとの件数と変更前後のサンプルが表示され、ファイルを除外するためのチェックボックスがあります。
- **M 個のファイルの N 件を置換**で変更を実行します。**キャンセル**で中止します。
- **スキップ**の一覧には、Pilcrow が変更しないファイルが理由とともに挙げられます：「エディタで開いています。そこで置換するか、先に閉じてください。」、「プレーンな UTF-8 テキストではありません。」、「1つのファイルに一致が多すぎます。」、「このパターンには長すぎる行があります。」、「読み込めませんでした。」
- 1回の置換で変更するファイルは最大2,000個です。それを超えると「一度に置換できる数より多くのファイルが一致しています。これらを先に置換してから、もう一度検索してください。」と表示されます。
- プレビュー以降に変更されたファイルは、変更されません。
- 完了すると、「M 個のファイルの N 件を置換しました。」と**取り消す**と**完了**が表示されます。**取り消す**は、バックアップからファイルを復元します。その後に編集された、または失われたファイルはそのままにされ、一覧に表示されます。次にシートを開いたときに、直前の置換を取り消すことを提案します。

## バージョン履歴

**ファイル ▸ バージョン履歴…**は、書類の保存済みバージョンを一覧にします。バージョンは保存のたびに保持され、**設定 ▸ ファイル ▸ 保持するバージョン**で設定した数までです。未保存の書類では「書類を保存するとバージョンの保持が始まります。」、その設定がなしのときは「バージョン履歴はオフです。」、最初の保存の前は「まだバージョンがありません。」と表示されます。

バージョンを選んでから：

| ボタン | 動作 |
| --- | --- |
| **コピーを開く** | 古いバージョンを別の書類として開きます。 |
| **比較…** | そのバージョンとの比較シートを開きます。 |
| **復元…** | 確認のあと、書類をそのときの状態に戻します。現在のテキストはバージョンとして残るので、元に戻れます。復元するには、変更を先に保存するか破棄しておく必要があります。 |
| **完了** | シートを閉じます。 |

## バージョンを比較

**ファイル ▸ ファイルと比較…**、またはバージョン履歴の**比較…**で、**バージョンを比較**が開きます。

- 2つのピッカー、**古い方**と**新しい方**で、比べる対象を選びます。**ファイルと比較…**ではファイルを選びます。
- **行末の空白を無視**は、行末のスペースだけの違いを隠します。
- 概要は「追加: N。削除: N。」と表示され、変更された行が最大5,000行まで一覧されます。
- 変更ごとに、**受け入れる**は開いている書類にその変更を反映し、**却下**は反映せず、**見直す**は選択を取り消し、**旧版に戻す**（古いバージョンが古い側にあるとき）はその変更だけ古い行を戻します。**残りをすべて受け入れる**は、残りをすべて受け入れます。
- 変更は、そのテキストがまだ一致している場合にのみ適用されます。そうでない場合は「何も変更されませんでした：比較したあとにその部分が変更されています。」と表示されます。
- メッセージ：「2つは同じです。」、「これらを比較できませんでした。」、そして差異が多すぎる場合は「違いのある行が多すぎて、行ごとに比較できません。バージョンのコピーを開いて、書類と並べて読んでください。」

## 翻訳

**編集 ▸ 翻訳 ▸ 書類**または**選択範囲**で、**書類を翻訳**または**選択範囲を翻訳**が開きます。

| コントロール | 動作 |
| --- | --- |
| **検出された言語** | Pilcrow がテキストから見つけた言語。 |
| **翻訳先** | 翻訳先の言語。 |
| **速度** | **高速**（約20倍速く、表現はより平易で、長い書類に必要な方式）、**最高品質**（じっくり読むテキスト向け）、または**AI アシスタント**（設定 ▸ アシスタントにある自分の AI 接続。テキストは接続先に送られます）。**最高品質**は macOS と iPadOS 26.4 以降で使えます。それより前のシステムでは速度は1種類です。 |
| **完了したら** | 書類の場合：**新しいタブで開く**（元の名前に言語をかっこで付けた新しい書類）、**元のファイルの隣にコピーを保存**、または**書類を置き換える**。選択範囲の場合は、**選択範囲を置き換える**で翻訳がその場所に入ります。 |
| **翻訳**または**送信して翻訳** | 開始します。AI アシスタントがテキストを送信する場合は「送信して翻訳」が表示され、プロバイダ名を示し、サービスによっては料金がかかることがあると警告します。 |
| **推定所要時間** | 目安です：「1分未満」または「約 N」。所要時間は AI サービスによって異なります。 |

翻訳はバックグラウンドで実行され、進行状況はステータスバーに表示されます。ある言語への翻訳を初めて行うとき、言語パックがダウンロードされます。2つの言語の間に直接の翻訳がない場合、Pilcrow は英語を経由して翻訳するかどうかを尋ねます（**はい**または**いいえ**）。コード、リンク、数式はそのまま残ります。翻訳には macOS 15 または iPadOS 18 以降が必要です。ファイルまたはフォルダでアシスタントがオフになっている場合、アシスタントは使われません。

別の言語で書かれたファイルを開くと、バーに「これは *言語* のようです。*言語* に翻訳しますか？」と表示され、**翻訳**、**今はしない**、**このファイルでは行わない**が選べます。設定 ▸ 一般 ▸ 翻訳で制御します（第67章）。

## 保存と閉じる

- **この書類を保存しますか？** 新しい書類を閉じるとき、Pilcrow は「この新しい書類を保存しますか？」と尋ねます。既存の書類では「行った変更を保存しますか？」と尋ねます。選択肢は**保存**、**キャンセル**、**削除**（または**保存しない**）です。新しい書類のフォームには、**名前：**（名前）、**タグ：**、**場所：**（別のフォルダには**その他…**または**選択…**）があります。削除は取り消せません。
- **書類を保存**は最初の保存のフォームで、**名前**と**場所**（**別の場所を選択…**）があります。同じ名前のファイルがある場合は、**既存のファイルを置き換えますか？**と尋ねます。
- **ディスク上でファイルが変更されました**は、ほかの App が開いているファイルを変更したときに表示されます：**再読み込み**または**現在のバージョンを残す**を選びます。
- **ディスクから再読み込みしますか？**（ファイル ▸ ディスクから再読み込み）には、**保存してから再読み込み**、**保存せずに再読み込み**、**キャンセル**があります。
- **未入力のフィールドがあります**は、フィールドが未入力のまま印刷または書き出しをするときに表示されます。**次のフィールドへ**、**このまま続ける**（フィールドは書かれたとおりに出力に現れます）、**キャンセル**が選べます。
- **解析の警告**、**共有できませんでした**、**書類を保存できませんでした**、**ファイル操作に失敗しました**は、メッセージと **OK** を表示します。
- 前回 Pilcrow が予期せず終了した場合は、バナーでお知らせし、**診断を開く**または**今はしない**が選べます。
- ライブラリの項目を読み込むと、小さなトーストで知らせ、閉じるためのボタンが付きます。
- アプリの言語が翻訳されている場合、最初の起動時に**AIによる翻訳**が表示され、この翻訳をネイティブスピーカーが確認していないことを説明します。**今後表示しない**と **OK** があります。

## アシスタントの許可シート

最初の内容がオンラインサービスに送られる前に、**「*サービス*」に送信しますか？**が、何が送られるか（あなたのリクエスト、質問ボックスの上に数えられる書類のテキスト、またはスタイルガイドの規則でレビューされるテキスト、モデル名、そしてキー）、誰が受け取るか、どうすれば取り消せるかを説明します。このコンピュータ上のプログラムに送られる内容はコンピュータの外に出ません。ネットワーク上の別のコンピュータへは、アドレスが https で始まらない限り暗号化されません。オンラインサービスは、独自の規約のもとでテキストを保持することがあります。サービスのプライバシーポリシーと Pilcrow のプライバシーポリシーへのリンクがあります。**送信**または**キャンセル**を選びます。送信を選ぶまで、何も送られません。

# Chapter 64: 書き出しとコンパイル

## 書き出しパネル

**ファイル ▸ 書き出す…**（`⇧⌘E`）、**書き出す**ボタン、または**その他 ▸ 書き出す…**で開きます。左に形式の一覧、右にオプション、下にボタンが並びます。

### 形式

| 形式 | ファイル | 備考 |
| --- | --- | --- |
| **HTML** | `.html` | スタイル付きの単独のページ。 |
| **HTML（スタイルなし）** | `.html` | テーマの CSS を含まない、すっきりした構造。 |
| **PDF** | `.pdf` | ページ分割あり。 |
| **Word (.docx)** | `.docx` | 本物の Word パッケージ。テーマの色、フォント、サイズ、行間が使われます。ブラウザのレイアウト用セレクタに相当するものは Word にはありません。数式、ダイアグラム、グラフは画像になります。 |
| **画像** | `.png` | 描画された書類の1枚の画像。 |
| **PDF アーカイブ (.zip)** | `.zip` | 順序付きの PDF の分割ファイルとマニフェスト。非常に大きな書類向け。 |

### オプション

| セクション | コントロール |
| --- | --- |
| **スタイル** | **テーマ**でレンダリングテーマを選びます。テーマは、書き出す書類の書体と色を決めます。 |
| **ページ**（PDF、PDF アーカイブ、Word） | **用紙サイズ**（A3、A4、A5、Letter、Legal、Tabloid、またはカスタムの**幅**と**高さ**）、**方向**（**縦**または**横**）、**上余白**、**下余白**、**左余白**、**右余白**。すべてミリメートル単位です（初期値は25.4 mm、つまり1インチ）。**このページ設定を既定として使用**は、設定を以降の書き出しに保存します。何かを変更するまではグレー表示です。そうでなければ、今回の書き出しにのみ適用されます。 |
| **詳細オプション** | **カスタム CSS**。今回の書き出しだけ、テーマの後に適用されます。 |

パネルには、使用するファイル名とともに「*名前* として保存」と、「この設定は今回の書き出しにのみ適用されます。」と表示されます。形式を選ぶと、何が作られるかが左下の1行に表示されます。たとえば HTML では「選択したスタイルの単独の Web ページ。」、PDF では「ページ分割された1つの PDF 書類。」です。

### ボタン

**キャンセル**はパネルを閉じます。**共有…**は、生成したファイルをそのままシステムの共有シートに送ります。**書き出す**は、保存先を尋ねます。処理中、パネルには「レンダリング中…」と表示されます。問題が起きると「書き出しに失敗しました。」と表示されます。未入力のフィールドが残っている場合、Pilcrow は先に確認します（第63章）。

すべての書き出しに適用されるページ設定、ヘッダとフッタのテンプレート、目次、番号付けのオプションは、**設定 ▸ 目次とラベル**と**設定 ▸ 書き出し**にあります（第70章）。

## コンパイルシート

**ファイル ▸ 原稿をコンパイル…**（またはプロジェクトパネルの**コンパイル…**）は、本のプロジェクトのファイルをマニフェストの順に結合します。プロジェクトを読み込むと使えるようになります。

| セクション | コントロール |
| --- | --- |
| **原稿** | 概要：「N 個のファイル」、「N 個を除外」、そして「見つかりません」と表示されるパス。コンパイルの前に直す必要があります。**順序**の一覧に、最終的な並びが表示されます。 |
| **出力** | **フォーマット**、続いて**新しいページから始める**：**前付け**、**部**、**章**、**巻末**。**シーンの区切り**で区切りを設定します（「なし」または記号）。**目次**、**見出しに番号を付ける**、**最初に各ファイルのバージョンを保存**（含まれるすべてのファイルについてバージョン履歴の項目を保存します）。 |
| **プリセット** | **保存済み**のプリセット。**プリセットとして保存**で**プリセット名**を入力し、**保存**します。**プリセットを削除**で、選んだものを削除します。 |

**コンパイル…**を選んで保存先を指定するか、**キャンセル**を選びます。実行中は「N / N を読み込み中…」に続いて「コンパイル中…」と表示され、**停止**が使えます。値のない変数は一覧に表示され（「これらの {{variables}} には値がなく、書かれたまま残されました」）、見た目にわかるようそのまま残されます。ファイルを作成できない場合は「そこに本を作成できませんでした。」と表示されます。

### 新しい本

**ファイル ▸ 新しい本…**では、**タイトル**、**作成者**、**記述形式**（章の構文）、**保存先**（フォルダで、**選択…**を使います）を尋ねられます。**作成**を選びます。Pilcrow はマニフェストと最初の章を含むフォルダを作ります。そこに本を作成できない場合は、その旨が表示されます。
