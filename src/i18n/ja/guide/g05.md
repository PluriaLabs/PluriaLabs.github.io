# Part XVI — ウインドウとメニューのリファレンス

# Chapter 52: ウインドウの全体像

この章では、Pilcrow のウインドウにあるすべてのコントロールを、MacとiPadの両方について左から右へ順に紹介します。この部に続く各章ではメニュー項目をひとつずつ説明し、Part XVII ではパネルとダイアログを説明します。

## ヘッダバー

ヘッダはウインドウの上端に沿って表示されます。コントロールは次の順に並んでいます。

| コントロール | 場所 | 機能 |
| --- | --- | --- |
| **ナビゲータ**(サイドバーのアイコン) | MacとiPad | サイドバーを表示または非表示にします。ツールチップには「Show or hide navigator」と表示されます。**表示 ▸ サイドバーの表示/非表示** と同じです。 |
| **書類のタイトル** | MacとiPad | 現在の書類の名前を表示し、保存されているかどうかを示すドットが付きます。クリックすると、書類スイッチャと書類のアクションが開きます(Chapter 59)。 |
| **メニュー**ボタンまたはメニューストリップ | iPadのみ | キーボードもマウスもないiPad向けに、Macのメニューをヘッダ内に表示したものです(Chapter 58)。 |
| **書類モード**(編集、プレビュー、分割) | MacとiPad | ソース、レンダリングされたページ、その両方を並べた表示を切り替えます。「分割」は **並べて表示** のことです。 |
| **検索**(虫眼鏡) | MacとiPad | 検索バーを開きます(Chapter 62)。 |
| **書き出す**(共有アイコン) | MacとiPad | 書き出しパネルを開きます(Chapter 64)。 |
| **設定**(歯車) | iPadのみ | 設定をシートで開きます。Macでは、設定は **Pilcrow** メニュー(**⌘,**)にあります。 |
| **その他**(三つの点) | MacとiPad | バーに収まらないアクションをまとめています。以下を参照してください。 |

検索、書き出す、モードのコントロールは、書類を開いているときだけ表示されます。

### ウインドウ幅に応じたヘッダの変化

ヘッダは、他のアプリと並べたMacのウインドウや、Split View 中のiPadのような狭いウインドウでも使いやすいように作られています。ウインドウが狭くなるにつれて、コントロールは次の順で **その他** メニューに移ります。

| ウインドウの幅 | 表示されるもの |
| --- | --- |
| 720ポイント以上 | 編集/プレビュー/分割のコントロール、**検索**、**書き出す**、**その他**。 |
| 600〜719 | **検索** が **その他** に移ります。 |
| 500〜599 | **書き出す** も **その他** に移ります。 |
| 500未満 | モードのコントロールが、現在のモードを示すアイコン(鉛筆、目、または二つのペイン)のボタン1つになります。クリックして選びます。 |

iPadでは、580ポイント未満になるとモードのコントロールがコンパクトなボタンになります。タイトルは常に最初に縮み、幅が140〜520ポイントの間で変化するので、ボタンは位置を保ちます。アクセシビリティ用の大きな文字サイズでは、上記のウインドウ幅をまず1.3で割るため、ウインドウがまだ広いうちにコントロールが **その他** に移ります。

### その他メニュー

**その他** に何が表示されるかは、モードとプラットフォームによって決まります。ソースが見えているとき(編集または並べて表示)にだけ表示される項目には、以下で印を付けています。

| 項目 | 表示される条件 | 機能 |
| --- | --- | --- |
| **検索…** | バーに検索ボタンがないときのみ | 検索バーを開きます。 |
| **置換…** | ソースが見えているとき | 置換フィールド付きで検索を開きます。 |
| **行へ移動…** | ソースが見えているとき | 行、または行と列へジャンプします。 |
| **列にカーソルを置く…** | iPadでソースが見えているとき | 数を指定して、列に沿ってカーソルを置きます(Chapter 63)。 |
| **列選択** | iPadでソースが見えているとき | スイッチです。オンの間は、指1本のドラッグでテキストの矩形範囲を選択します。 |
| **共有…** | 書類を開いているとき | システムの共有シートで書類のファイルを共有します。 |
| **書き出す…** | バーに書き出すボタンがないときのみ | 書き出しパネルを開きます。 |
| **フォーカス** | 常時 | 集中モード(下記)のスイッチです。 |
| **見出しの折りたたみ**、**描画ブロック**、**セクションを自動的に展開**、**マーカーを隠す**、**スタイル付きソース**、**フォーマットツールバー** | ソースが見えているとき | 表示メニューにあるものと同じ表示スイッチです(Chapter 55)。**マーカーを隠す** は、**スタイル付きソース** がオンでないとグレーアウトします。 |
| **ファイルを開く…**、**フォルダを開く…** | iPad | サイドバーが閉じているときに、ファイルまたはフォルダを開きます。 |
| **プリント…** | iPad | レンダリングされた書類をプリントします。 |
| **設定…**、**ヘルプ** | iPad | 設定またはアプリ内ヘルプを開きます。 |

## 作業エリア

ヘッダの下にはエディタ、プレビュー、またはその両方があります。エディタの下には、オンにしていれば **フォーマットツールバー** と **ステータスバー** があります(Chapter 61)。エディタとサイドバーの背後には、**背景** の画像や動画を置くことができます(Chapter 69)。

**並べて表示** では、ソースがプレビューの隣に並び、一緒にスクロールします。ペインの境界線はドラッグでき、位置は記憶されます。ウインドウの幅が520ポイント未満のときは、二つのペインが上下に積み重なります。サイドバーを開くと書類に使える幅が640ポイント未満になる場合は、書類を圧縮せず、サイドバーが書類に重なって表示されます。

## サイドバー(ナビゲータ)

サイドバーには、**ファイル**、**アウトライン**、**検索**、**プロジェクト**、**アシスタント** を表示できます(Chapter 60)。端をドラッグして、幅180〜420ポイントの間でサイズを変えられます。幅500ポイント未満のウインドウでは、サイドバーが全幅を占め、**完了** ボタンで閉じます。

## 集中モード

**集中モード** は、テキスト以外をすべて隠します。**表示 ▸ 集中モード**、**その他 ▸ フォーカス**、またはコマンドパレットからオンにします。オンの間は **フォーカスを終了** ボタンが表示されるので、キーボードがなくても抜けられます。集中モードは常に長い行を折り返し、設定にあるものとは別の独自のテキスト列を持ちます。既定のショートカットはありません。**設定 ▸ キーボード** で割り当ててください。

## 書類がないとき

何も開いていないときは、ウインドウに「Start a document」という見出しの下に **新規書類** と **ファイルを開く…** が表示されます。iPadでは、**フォルダを開く…** は **その他** にあります。

Pilcrow の起動時に、以前のセッションの未保存の作業が見つかると、代わりに **書類を復元** のリストが表示されます。復元のしくみは Chapter 17 を参照してください。リストでは、各項目に **復元** と **削除** が、リスト全体に **すべて復元** と **すべて削除** があります。一度も保存していない書類は、削除すると元に戻せないため、**すべて削除** は先に確認を求めます。単一書類のバナーにある **閉じる** ボタンは、その項目の復元を辞退します。

大きなファイルを開いている間、ウインドウには進行状況とともに「Opening *name*…」と表示されます。

# Chapter 53: ファイルメニュー

Macでは、これらの項目は **ファイル** メニューにあります。iPadでは、ヘッダの **メニュー ▸ ファイル** にあるか、**⌘** を押し続けるかポインタを画面上端に動かすと現れるメニューバーにあります。「Macのみ」と記した項目はiPadにはありません。

| 項目 | ショートカット | 機能 |
| --- | --- | --- |
| **新規**(iPad: **新規書類**) | `⌘N` | 無題の書類を作成します。開いている書類に加わります。 |
| **開く…**(iPad: **ファイルを開く…**) | `⌘O` | ディスクからテキストまたはマークアップのファイルを開きます。 |
| **最近使った項目**(Macのみ) | | 最近開いたファイルを一覧表示します。**メニューを消去** でリストを空にします。リストが空のときは「No Recent Documents」と表示されます。 |
| **クイックオープン…**(Macのみ) | `⇧⌘O` | 開いているフォルダ内のファイル名を検索します。フォルダが開いていない間はグレーアウトします。 |
| **フォルダを開く…**(iPadのヘッダメニューと その他) | | サイドバーでフォルダを開きます。Macでは、サイドバーにある **フォルダを開く** ボタンを使います。 |
| **このファイルのフォルダを参照…** | | 開いているファイルを含むフォルダを参照する許可を求めます。Pilcrow のサンドボックスはファイルを単独で開くため、これでそのフォルダが加わります。フォルダがすでに開いているとき、または書類にファイルがないときはグレーアウトします。 |
| **新しい本…** | | マニフェスト付きの本のプロジェクトフォルダを作成します(Chapter 34)。 |
| **フォルダを書籍プロジェクトにする** | | 開いているフォルダに `manifest.pilcrow` を書き込み、プロジェクトパネルを表示します(Chapter 34)。フォルダが開いていないとき、またはフォルダにすでにマニフェストがあるときはグレーアウトします。 |
| **書類を閉じる**(iPad: **閉じる**) | `⌘W` | 現在の書類を閉じます。未保存の変更がある場合は先に確認します。設定が最前面にあるときは、`⌘W` で代わりに設定が閉じます。 |
| **すべてを閉じる**(iPad) | `⇧⌘W` | すべての書類を閉じ、未保存のものは1つずつ確認します。Macでは、タイトルメニューに **すべての書類を閉じる** があります。 |
| **保存** | `⌘S` | 書類を保存します。新規の書類は保存先を尋ねます。 |
| **すべて保存**(Macのみ) | `⌥⌘S` | 未保存の変更があるすべての書類を保存します。該当がないときはグレーアウトします。 |
| **複製**(Macのみ) | `⇧⌘S` | コピーを作り、元の書類の隣で開きます。元の書類は変わりません。 |
| **別名で保存…** | `⌥⇧⌘S` | 新しい名前や場所、または別のエンコーディングで保存します。その後、書類は新しいファイルになります。 |
| **移動…**(Macのみ) | | 保存パネル(ボタンには **移動** と表示)を通じて、ディスク上のファイルを移動または名称変更します。書類は開いたままです。 |
| **バージョン履歴…** | | 書類の保存済みバージョンを開きます(Chapter 17 と Chapter 63)。 |
| **ファイルと比較…** | | 書類を別のファイルと比較し、変更をひとつずつ受け入れるか却下できます(Chapter 18)。 |
| **ディスクから再読み込み**(Macのみ) | | 別のアプリがファイルを変更したときのために、ディスクからファイルを再読み込みします。未保存の変更がある場合は先に確認します。**Save, Then Reload**、**Reload Without Saving**、**キャンセル** から選びます。ファイルのない書類ではグレーアウトします。 |
| **Finder で表示**(Macのみ) | | ファイルを Finder で表示します。 |
| **読み込む**(Macのみ) | | サブメニューで、**テーマ…**、**構文プロファイル…**、**マクロコレクション…**、**スタイルガイド…** があります。それぞれファイルをライブラリに追加します(Chapter 43)。iPadでは、読み込みは **設定 ▸ ライブラリ ▸ 読み込む** にあります。 |
| **書き出す…** | `⇧⌘E` | 書き出しパネルを開きます(Chapter 64)。 |
| **共有…** | | 書類のファイルを共有します。 |
| **原稿をコンパイル…** | | 本のプロジェクトをコンパイルします(Chapter 36)。本のプロジェクトが読み込まれるまでグレーアウトします。 |
| **ページ設定…**(Macのみ) | | 用紙、向き、余白を設定します。PDF書き出しと同じ設定です。 |
| **プリント…** | `⌘P` | レンダリングされた書類をプリントします。書類に未入力の入力フィールドがある場合、Pilcrow は先に警告します。 |

# Chapter 54: 編集メニュー

編集メニューには、システム標準のコマンドと、Pilcrow 独自のコマンドが数多く入っています。選択、行、カーソルに関する項目はソースに対して働くため、プレビューではグレーアウトします。

## 取り消し、クリップボード、ペースト

| 項目 | ショートカット | 機能 |
| --- | --- | --- |
| **取り消す**、**やり直す** | `⌘Z`、`⇧⌘Z` | 編集を前後にたどります。 |
| **カット**、**コピー**、**ペースト**、**削除**、**すべてを選択** | | システムのコマンドです。 |
| **Markdown としてコピー** | `⇧⌘C` | 選択範囲を Markdown のソースとしてコピーします。 |
| **プレーンテキストとしてコピー** | | 可能な範囲で構造のマークアップを取り除いて、選択範囲をコピーします。 |
| **HTML コードとしてコピー** | | 選択範囲のレンダリングされた HTML をテキストとしてコピーします。 |
| **プレーンテキストとしてペースト** | `⇧⌘V` | クリップボードの書式をすべて除いてペーストします。 |

## 検索

**検索** はサブメニューです。

| 項目 | ショートカット |
| --- | --- |
| **検索…** | `⌘F` |
| **置換…** | `⌘R` |
| **次を検索** | `⌘G` |
| **前を検索** | `⇧⌘G` |

## スペルと文法

iPadでは、このサブメニューには **入力中にスペルチェック** だけがあり、設定にあるものと同じスイッチです。ほかの2項目は、iPadのテキストビューにはスペルのパネルがないため、Macのみです。

| 項目 | ショートカット | 機能 |
| --- | --- | --- |
| **スペルと文法を表示** | `⌘:` | システムのスペルパネルを開きます。 |
| **今すぐ書類をチェック** | `⌘;` | 書類全体をチェックします。 |
| **入力中にスペルチェック** | | 入力中に、綴りの誤りに下線を引きます。設定にあるものと同じスイッチです。 |

## 変換とスピーチ

| 項目 | 機能 |
| --- | --- |
| **大文字にする**、**小文字にする**、**先頭を大文字にする** | 選択範囲、またはカーソル位置の単語の大文字・小文字を変更します。 |
| **読み上げを開始**、**読み上げを停止** | 選択範囲を読み上げます。何も選択していないときは書類全体を読み上げます。 |

## 選択

選択と移動の方法をまとめたサブメニューです。

| 項目 | ショートカット | 機能 |
| --- | --- | --- |
| **単語を選択** | `⌘D` | カーソル位置の単語を選択します。 |
| **行を選択** | `⌘L` | 画面上の折り返された行ではなく、ファイルの1行全体を選択します。 |
| **段落を選択** | `⌥⌘P` | 段落を選択します。 |
| **先頭へ移動**、**末尾へ移動** | `⌘↑`、`⌘↓` | カーソルを書類の先頭または末尾に移動します。 |
| **行頭へ移動**、**行末へ移動** | `⌃A`、`⌃E` | 行のどちらかの端へ移動します。 |
| **上にカーソルを追加**、**下にカーソルを追加** | `⌃⇧↑`、`⌃⇧↓` | 上の行または下の行にカーソルをもう1つ追加します(Chapter 7)。 |
| **次の出現箇所を選択** | `⌃⌥D` | 選択したテキストの次の一致を追加します。 |
| **すべての出現箇所を選択** | `⌃⌥⇧D` | 一致するものをすべて一度に選択します。 |
| **次のフィールド**、**前のフィールド** | `⌥Tab`、`⌥⇧Tab` | マクロが残した入力フィールドの間を移動します(Chapter 24)。設定には、このためのキーの組み合わせを選ぶ項目があり、Super Tabのキーと呼ばれます。 |
| **列にカーソルを置く…** | `⌃⇧G` | 数を指定して列に沿ってカーソルを置くシートを開きます。 |

カーソル、出現箇所、フィールド、コマンドパレットのショートカットは、**設定 ▸ キーボード** で変更できます。

## 行

| 項目 | 機能 |
| --- | --- |
| **行を昇順に並べ替える**、**行を降順に並べ替える** | 選択した行を並べ替えます。 |
| **行の順序を逆にする** | 順序を逆にします。 |
| **重複する行を削除** | 繰り返される行のうち、最初のものを残します。 |
| **空白行を削除** | 選択範囲内の空の行を削除します。 |
| **行末の空白を削除** | 行末のスペースとタブを取り除きます。 |
| **行を結合** | 選択した行を1行に結合します。 |

## 移動、翻訳、ナビゲート

| 項目 | ショートカット | 機能 |
| --- | --- | --- |
| **行を上へ移動**、**行を下へ移動** | `⌥⌘↑`、`⌥⌘↓` | 現在の行、または選択した行を上下に移動します。 |
| **翻訳 ▸ 書類**、**翻訳 ▸ 選択** | | 翻訳シートを開きます(Chapter 63)。 |

最後に、システムが **Writing Tools**、**AutoFill**、**Start Dictation…**、**Emoji & Symbols** を加えます。
