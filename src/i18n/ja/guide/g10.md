# Chapter 68: 編集

## 表示と入力

### 表示

| コントロール | 機能 |
| --- | --- |
| **行番号を表示** | ガターに行番号を表示します。**表示 ▸ 行番号**と同じです。 |
| **現在の行の下に罫線を表示** | キャレットのある行の下に細い罫線を表示します。 |
| **スタイル付きソース** | 見出し、太字、斜体を、それに合った書体で描画します。 |
| **見出しの折りたたみ** | 見出しの横に折りたたみ用のシェブロンを表示します。 |
| **描画ブロック** | 表、数式、ダイアグラムを、編集ボタン付きの画像として描画します。 |
| **セクションを自動的に展開** | キャレットが入ったときに、折りたたまれたセクションや画像ブロックを開き、キャレットが離れると閉じます。 |
| **マーカーを隠す** | キャレットのある行以外のすべての行で、見出し、太字、斜体の記号を隠します。スタイル付きソースが必要です。 |
| **長い行を折り返す** | オフにすると、長い行は折り返されず横にスクロールします。プレビューと書き出しでは常に折り返されます。20,000文字以上の行と集中モードでは、常に折り返されます。 |
| **列モードでの短い行** | 列に届かないほど短い行での、列の動作です。**行末を使う**、**その行を除外する**、**スペースでやわらかく埋める**（入力したテキストが画面上で揃うようにスペースを追加します）、**スペースで厳密に埋める**（足りない文字1つにつきスペース1つを加え、列番号で揃えます）、**その行で止める**から選びます。削除によって短い行から文字が取り除かれることはありません。 |
| **ステータスバーを表示** | 下部のステータスバーのオンとオフを切り替えます。 |
| **フォーマットツールバー** | テキストの下に、オプションのツールバーを表示します。 |

### 入力

| コントロール | 機能 |
| --- | --- |
| **括弧と引用符を自動で対にする** | 開き括弧や開き引用符を入力すると、閉じるほうも追加します。 |
| **Markdownの記号を自動で対にする（ \* \_ ` ~ ）** | Markdownの記号に対して同じ動作をします。 |
| **絵文字ショートコードを展開（:smile:）** | 入力中にショートコードを絵文字に変換します。すでにショートコードを含んでいるファイルは、書かれたまま表示されます。 |
| **Returnキーでリストと引用を続ける** | Returnで次の項目を始め、空の項目でReturnを押すとリストを終了し、Tabで項目をインデントします。 |
| **Returnキーでインデントを保つ** | 新しい行を、上の行と同じ先頭のスペースまたはタブで始めます。 |
| **Tabキーでスペースを挿入** | Tabを押すと、タブ文字ではなく、次のタブ位置までタブ幅の分だけスペースを挿入します。 |

スマート句読点、ハイライト、下付き、上付きは**ライブラリ ▸ CommonMark のオプション**にあります。

### 入力サウンド

| コントロール | 機能 |
| --- | --- |
| **入力中にサウンドを鳴らす** | キーを押すたびに音が鳴ります。スペース、Return、Deleteは別の音になります。ペーストと取り消しでは鳴りません。iPadでは、消音スイッチで鳴らなくなります。 |
| **サウンド** | サウンドパックです。**タイプライター**、**アヒル**、**子猫**から選びます。 |
| **音量**、**プレビュー** | 音量を設定し、パックの音を確認します。 |
| **自分のサウンド** | どの種類のキーにも短いクリップを選べます。それ以外のキーは、上で選んだサウンドのままです。種類は**小文字**、**大文字**、**数字**、**記号と句読点**、**スペース**、**タブ**、**Return**、**削除**です。それぞれに**選択…**（または**変更…**）、**再生**、**削除**があります。クリップは2秒、3 MBまでで（WAV、AIFF、MP3、M4A、CAF）、遅延なく再生できるようメモリに保持されます。 |

### スペルと診断

**入力中にスペルチェック**は、つづりの誤りに下線を引きます。**解析の警告を表示**は、閉じられていないコードフェンスや数式ブロック、閉じ括弧のないリンク、ヘッダと合っていない表の行など、意図と異なる可能性が高い構文のある行に印を付けます。注記は行末に表示されます。表示が変わるだけで、書類の解析や書き出しの方法は変わりません。

## 画像

これらの設定は、挿入した画像（**挿入 ▸ 画像…**、またはドロップ）をどう扱うかを決めます。

| コントロール | 機能 |
| --- | --- |
| **アクション** | **特別な処理なし**、**画像を現在のフォルダにコピー (./)**、**画像を ./assets にコピー**、**画像を ./\${filename}.assets にコピー**から選びます。**画像をアップロード**は利用できない項目として表示されます。Pilcrowには画像ホストがないため、画像は元の場所のまま挿入されます。 |
| **ローカル画像に適用** | デバイス上にすでにある画像にアクションを適用するかどうかです。 |
| **オンライン画像に適用** | Webアドレスを指す画像にアクションを適用するかどうかです。 |
| **インターネットから画像を読み込む** | オフのときは、Webアドレスを指す画像はプレビュー、PDF、画像の書き出しのためにダウンロードされないので、その画像を置いているサイトに何も知られません。オンのときは、Webブラウザと同様に取得され、そのサイトにリクエストが見えます。 |
| **可能なら相対パスを使用** | 書類からの相対パスで書き込みます。 |
| **相対パスに ./ を付ける** | 相対パスを `./` で始めます。 |
| **挿入時に画像 URL をエスケープ** | リンクを壊してしまうアドレス内の文字をエスケープします。 |

# Chapter 69: 外観

## テーマと背景

| コントロール | 機能 |
| --- | --- |
| **アプリケーションテーマ** | アプリとエディタの見た目です。**自動**、**ライト**、**ダーク**、または追加したテーマから選びます。ライトかダークか、アクセントカラー、サイドバーとバー、エディタが決まります。自動はシステムに従います。レンダリングモードと書き出しには、書き出しで選ぶレンダリングテーマが使われます。 |
| **インターフェースのサイズ**（iPad） | メニュー、バー、サイドバー、ダイアログのサイズです。**システムのサイズ**（iPadの文字サイズに従います）、**1段階小さく**、**2段階小さく**、**3段階小さく**から選びます。エディタのテキストには別のサイズがあります。 |
| **ヘッダのメニュー**（iPad） | **自動**（キーボードまたはマウスが接続されている間はPilcrow独自のメニューを隠します）、**常に**、**しない**から選びます。 |
| **ズーム** | エディタとプレビューのサイズです。50%、67%、80%、90%、100%、110%、125%、150%、175%、200%から選びます。**表示 ▸ 拡大**と**縮小**と同じです。 |
| **読む速さ** | 1分あたりの単語数で、60から2,000までです。読む時間の見積もりに使われます。 |

## エディタの背景（バックドロップ）

エディタ、サイドバー、ステータスバーの背後に、画像または動画を置けます。

| コントロール | 機能 |
| --- | --- |
| **メディア** | **選択…**で、HEIC、PNG、JPEG、SVGの画像、またはMP4、MOV、M4Vの動画を選びます。**削除**で解除します。 |
| **配置** | **全体に広げる**、**全体を表示**、**並べる**から選びます。 |
| **テキスト領域の背面**、**サイドバーの背面** | それぞれに**フェード**と**ぼかし**があります。**フェード**は、テキストが読みやすいように画像をテーマの背景色で覆います。**ぼかし**は画像をやわらかくします。ステータスバーでは画像がぼかされます。 |
| **バッテリー駆動時も再生** | バッテリー駆動時にも動画を再生できるようにします。低電力モードでは動画は一時停止し、視差効果を減らす設定がオンのときは静止します。 |
| **サウンド**、**音量** | 動画は、サウンドをオンにしない限りミュートで再生されます。 |

背景がプレビューや書き出しに表示されることはありません。透明度を下げる設定がオンのときは、背景は非表示になります。

| コントロール | 機能 |
| --- | --- |
| **フォントサイズ** | エディタのフォントサイズで、9から32ポイントです。エディタのフォント、各文字体系に対応したフォント、行のリズムはまとめてサイズが調整され、すぐに反映されます。 |
| **行間** | 行と行の間隔です。フォントサイズの倍数で、0.1刻みです。 |

| **テキストの幅** | エディタの幅のうち、テキストが占める割合です。50%から100%で、中央に配置されます。集中モードには専用の幅があります。 |
| **エディタのフォント**、**ガターのフォント** | テキスト用と行番号用のフォントです。フィルタ（**すべて**、**等幅**、**サンセリフ**、**セリフ**）で、選択内容を変えずに一覧を絞り込めます。デフォルトは**システムのデフォルト**と**システム等幅**です。 |

# Chapter 70: 目次と書き出しの既定値

## 目次とラベル

これらの設定は、PDF、Word、HTMLなど、すべての書き出し形式に適用されます。

| コントロール | 機能 |
| --- | --- |
| **すべての書き出しに目次を追加** | 各書き出しの先頭に目次を置きます。 |
| **[TOC] 行を一覧に置き換える** | `[TOC]`だけの行を、プレビューとすべての書き出しで見出しの一覧にします。 |
| **見出しに番号を付ける（1.、1.1.）** | 出力の見出しに番号を付けます。下の見出しラベルは、通常の番号付けに代わるものです。 |
| **タイトル** | 一覧の名前です。たとえば「目次」や「手順」とします。空欄の場合は「目次」が使われます。 |
| **一覧にする見出しのレベル** | 深さで、1から6です。レベル1は最上位の見出しだけ、レベル6はすべてを一覧にします。 |
| **字下げ** | 各レベルのインデントで、単位はポイントです。 |
| **各見出しから目次の項目へのリンクを付ける** | 見出しから対応する項目へ戻るリンクを追加します。 |
| **[TOC] 行より下の見出しだけを一覧にする** | `[TOC]`行より上の見出しを除外します。 |

### 見出しラベル

**見出しにラベルを付ける**と、レベルごとに独自のラベルを付けられます。たとえば「Part I -」や「Chapter 3:」です。各レベルにはテンプレートがあります。テンプレートでは、`#`は次の数字、`@`は次の大文字を表し、1つのラベルにはどちらか一方しか使えません。より浅い見出しが現れるたびに数え直したいときは、`\#`または`\@`と書きます。そのままの場合は、書類全体を通して数え続けます。**文字**と**0 から 9 までの数字**は、文字による番号付けと数字による番号付けに使う文字を設定します。最後の文字のあとは、Y、Z、AA、ABのように桁が増えます。

## 書き出しの既定値

| コントロール | 機能 |
| --- | --- |

| **フォーマット**、**ファイル拡張子**、**コンバータ** | 各書き出し形式についての情報です。すべて内蔵のコンバータで生成されます。 |
| **ページ** | 印刷や、すべてのPDF、PDFアーカイブ、Wordの書き出しで使う用紙サイズ、向き、余白です（第64章）。 |
| **ヘッダのテンプレート**、**フッタのテンプレート** | 各ページの上部と下部のテキストです。変数は `${title}`、`${author}`、`${pageNo}`、`${pageCount}`、`${today}` です。たとえば、フッタを `Page ${pageNo}` にします。 |
| **作成者** | `${author}`と書類のメタデータで使われる作成者名です。 |
| **最上位見出しの間で改ページ** | 最上位の見出しごとに、新しいページから始めます。 |

# Chapter 71: ライブラリ

ライブラリとは、追加したテーマ、構文プロファイル、マクロ、スタイルガイド、背景のことです。内蔵の項目は読み取り専用です。変更するには複製してください。

## 構文プロファイル

各プロファイルを**内蔵**または**カスタム**として一覧表示します。

| コントロール | 機能 |
| --- | --- |
| **読み込む…** | 誰かが共有したプロファイルの `.json` ファイルを追加します。 |
| **新規** | プロファイルを一から作り始めます。 |
| **編集**、**複製**、削除 | プロファイルごとの操作です。内蔵のプロファイルは複製できますが、編集や削除はできません。 |
| **読み込まれていません** | 読み込めなかったプロファイルが、その理由とともにここに表示されます。理由は、別のプロファイルがすでに持っているファイル拡張子を使っている、このバージョンで読めないプロファイルである、エディタが応答しなくなるおそれのあるパターンを含んでいる、のいずれかです。そのプロファイルはプロファイルフォルダに残っています。 |

プロファイルの編集については第74章を参照してください。

## CommonMark のオプション

CommonMarkの任意の構文を切り替えます。ソースで使うものだけを有効にしてください。

| セクション | コントロール |
| --- | --- |
| **構文サポート** | **ハイライト（==key==）**、**下付き（H~2~O）**、**上付き（X^2^）**、**インライン数式（$…$）**。 |
| **追加の構文** | **自動リンク（URL のみ）**、**GitHub 形式の注意**、**YAML フロントマター**（先頭にある`---`行で囲まれたブロックは薄く表示され、プレビューとすべての書き出しから除外されます）、**ダイアグラムとグラフ（Mermaid、Vega-Lite）**。 |
| **スマート句読点** | **変換**：**入力時に変換**、**レンダリング時に変換**、または**オフ**。続いて**スマート引用符**、**スマートダッシュ**、**スマート省略記号**。 |
| **コードフェンス** | **行番号を表示**、**長い行を自動で折り返す**、**インデント幅**（スペースの数）。 |

フォーマット ▸ ハイライト、下付き、上付き、インライン数式は、対応するオプションをオンにするまでグレー表示になります。

## テーマ

テーマのページには、**アプリケーションテーマ**（JSON：アプリのライトまたはダークの外観、アクセント、サイドバー、バー、エディタ）と、**レンダリングテーマ**（CSS：プレビュー、HTML、PDF、画像、印刷の出力、およびWordのスタイル）が一覧表示されます。それぞれに**内蔵**または**カスタム**、そして**ライト**、**ダーク**または**自動**のラベルが付きます。

| コントロール | 機能 |
| --- | --- |
| **新規** | どちらの種類のテーマも作成します。 |
| **テーマを読み込む…** | `.json`のアプリケーションテーマ、`.css`のレンダリングテーマ、またはその一方または両方を含む`.zip`パッケージを追加します。 |
| **テーマフォルダを開く** | テーマを保存しているフォルダを表示します。 |
| **編集**、**複製**、**書き出す**、削除 | テーマごとの操作です。内蔵のテーマは読み取り専用です。 |

テーマの編集については第75章を参照してください。

## マクロ

マクロコレクションを一覧表示します。内蔵のコレクションは読み取り専用です。

| コントロール | 機能 |
| --- | --- |
| **新規コレクション**、**マクロを読み込む…** | コレクションを作り始める、または`.json`のコレクションを読み込みます。 |
| コレクションのメニュー | **名称変更…**、**コレクションを複製**、**コレクションを書き出す…**、**コレクションを削除**。 |
| **新規**、**編集**、**複製**、削除 | マクロごとの操作です。 |

マクロの編集については第76章を参照してください。安全でないトリガを含むコレクションは、読み込みが拒否されます。

## スタイルガイド

スタイルガイドを、ルールの数と分野とともに一覧表示します。

| コントロール | 機能 |
| --- | --- |
| **スタイルガイドを読み込む…** | ガイドの`.json`ファイルを追加します。 |
| ガイドのメニュー | **スタイルガイドを複製**、**スタイルガイドを書き出す…**、**スタイルガイドを削除…**。削除すると、確認のうえ、このデバイスから取り除かれます。コピーが必要な場合は、先に書き出してください。 |

スタイルガイドは、名前付きのルールをまとめた`.json`ファイルです。アシスタントに書いてもらうこともでき（**アシスタント ▸ ヘルプ ▸ スタイルガイド**）、形式については**ヘルプ ▸ スタイルガイド**で説明されています。

## レンダリングライブラリ

数式、ダイアグラム、グラフは、同梱のライブラリによってこのデバイス上で描画されます。このページには各ライブラリとそのバージョンが一覧表示され、選ぶと同梱の通知を読めます。

## 場所

ライブラリは、選んだフォルダの中の「Pilcrow Library」という名前のフォルダにあります。iCloud Drive内のフォルダなら、デバイス間で同期されます。環境設定、APIキー、クラッシュ復元用のコピーは、常にこのデバイスに残ります。

| コントロール | 機能 |
| --- | --- |
| **保存場所** | ライブラリが現在ある場所です。「このデバイス上」または「フォルダ*名前*内」と表示されます。 |
| **フォルダを選択…** | ライブラリをフォルダに移します。そのフォルダにすでにPilcrowのライブラリがある場合、Pilcrowは2つを統合しません。**既存のものを使用**できます。そうでなければ、**ライブラリをここに移動**（すべてのファイルを確認してから古いコピーを削除します）または**ライブラリをここにコピー**（古いほうは残します）を選びます。 |
| **このデバイスを使用** | ライブラリをこのデバイスに戻します。 |

選んだフォルダにアクセスできない場合、Pilcrowは一時的にこのデバイス上のライブラリを使い、何も変更も削除もしません。フォルダが利用可能になると、再びそのフォルダを使います。

## 読み込む（iPad）

iPadでは、**読み込む**でライブラリに項目を追加します。**テーマを読み込む…**、**構文プロファイルを読み込む…**、**マクロコレクションを読み込む…**、**スタイルガイドを読み込む…**です。Macでは、**ファイル ▸ 読み込む**を使います（第53章）。
