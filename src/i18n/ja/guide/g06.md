# Chapter 55: 表示メニューとウインドウメニュー

表示メニューは、パネル、モード、サイズ、エディタの表示を制御します。ショートカットは、特記したものを除き、**設定 ▸ キーボード** で変更できます。

## パネルとモード

| 項目 | ショートカット | 機能 |
| --- | --- | --- |
| **フォーマットツールバー** | | テキストの下にある、フォーマットボタンの行(オプション)を表示または非表示にします。プレビューではグレーアウトします。 |
| **サイドバーの表示/非表示** | `⇧⌘L` | サイドバー全体を表示または非表示にします。 |
| **アウトライン** | `⌃⌘1` | アウトラインパネルを表示します。もう一度選ぶと、サイドバーを隠します。 |
| **ファイル** | `⌃⌘3` | ファイルパネル(ファイルツリー)を表示します。 |
| **検索** | `⇧⌘F` | フォルダの検索パネルを表示します。 |
| **アシスタント** | `⌃⌘4` | アシスタントパネルを表示します。アシスタントの接続を設定した後にのみ表示されます。 |
| **プレビュー** | `⇧⌘P` | レンダリングされたページに切り替えます。 |
| **並べて表示** | `⌃⌘P` | ソースとプレビューを一緒に表示します。 |
| **集中モード** | なし | テキスト以外をすべて隠します。 |

## サイズ

| 項目 | ショートカット |
| --- | --- |
| **実際のサイズ** | `⇧⌘0` |
| **拡大** | `⇧⌘=` |
| **縮小** | `⇧⌘-` |

ズームはあらかじめ決められたレベルを順に切り替え、その設定は記憶されます。エディタとプレビューの両方が拡大縮小されます。

## エディタの表示

これらはそれぞれスイッチです。同じスイッチが **設定 ▸ 編集** にもあります(Chapter 68)。

| 項目 | ショートカット | 機能 |
| --- | --- | --- |
| **行番号** | `⌥⌘L` | ガターに行番号を表示します。 |
| **現在の行の罫線** | | カーソルのある行の下に細い罫線を引きます。罫線の色は、アプリケーションテーマで決まります。 |
| **行を折り返す** | | 長い行をウインドウの端で折り返します。オフにすると、横にスクロールします。非常に長い行と集中モードは、この設定にかかわらず折り返されます。 |
| **スタイル付きソース** | | 見出し、太字、斜体を、プレーンなソースではなく、構文の見た目に合わせた書体で表示します。 |
| **マーカーを隠す** | | スタイル付きソースがオンのとき、カーソルのある行を除くすべての行で、見出し、太字、斜体の記号(`#`、`**`)を隠します。スタイル付きソースがオフのときはグレーアウトします。 |
| **描画ブロック** | | 表、数式、ダイアグラムを、ソースの代わりに画像として表示し、それぞれに編集ボタンを付けます。 |
| **見出しの折りたたみ** | | 各見出しの横のガターに折りたたみのシェブロンを追加し、どの構文プロファイルでも、そのセクションを折りたたんで隠せるようにします。 |
| **すべて折りたたむ**、**すべて展開** | | すべての見出しのセクションを折りたたむ、または展開します。見出しの折りたたみがオンでないとグレーアウトします。 |
| **セクションを自動的に展開** | | カーソルが入ると、折りたたまれたセクションや画像として表示されたブロックを開き、カーソルが出ると再び閉じます。オフの場合、上下の矢印キーはそれを飛び越え、そのままの状態に保たれます。 |

## テーマ

**表示 ▸ テーマ** では、**アプリケーションテーマ**(自動、ライト、ダーク)と **レンダリングテーマ**(ライト、ダーク)をチェックマークで選びます。追加したテーマもここに表示されます。Chapter 40 を参照してください。

システムは **Enter Full Screen** も追加します。

## ウインドウメニュー

| 項目 | ショートカット | 機能 |
| --- | --- | --- |
| **開いている書類** | `⌃⌘2` | 書類スイッチャを開きます。 |
| **次の書類**、**前の書類** | `⌃Tab`、`⌃⇧Tab` | 開いている書類を順に切り替えます。開いている書類が2つ未満のときはグレーアウトします。 |

ウインドウメニューには、システムのウインドウコマンドもあり、開いている各書類が名前で一覧表示されます。iPadでは、これら3つの項目は表示メニューの末尾にあります。

# Chapter 56: 挿入メニュー

挿入メニューのすべての項目は、アクティブな構文プロファイル自身の記法で書いたソースを、カーソル位置の書類に入れます。プロファイルで表現できない項目はグレーアウトし、プレビューではすべての項目がオフになります。

| 項目 | 機能 |
| --- | --- |
| **表…** | 表を挿入ダイアログを開きます(Chapter 63)。ショートカットは `⌥⌘T`。 |
| **画像…** | 画像を選んで挿入し、画像の設定を適用します(Chapter 68)。ショートカットは `⇧⌘I`。 |
| **ダイアグラム** | あらかじめ用意された Mermaid ダイアグラムのサブメニューです(下記)。 |
| **グラフ** | あらかじめ用意された Vega-Lite グラフのサブメニューです(下記)。 |
| **数式** | あらかじめ用意された数式のサブメニューです(下記)。 |
| **コードブロック** | フェンス付きのコードブロックを挿入します。 |
| **注意** | サブメニューで、**注記**、**ヒント**、**重要**、**警告**、**注意** があります。 |
| **水平線** | 主題の区切りを挿入します。 |
| **リンク参照** | 参照形式のリンクとその定義を挿入します。 |
| **脚注** | 脚注の記号とその定義を挿入します。 |
| **目次** | `[TOC]` の行を挿入します。これは自動生成される目次になります。 |
| **YAML フロントマター** | ファイルの先頭にフロントマターのブロックを挿入します。 |
| **フィールド** | Super Tab 用の入力欄を挿入し、名前を付けられるように選択状態にします(Chapter 24)。 |

これらの下には区切り線があり、その後に **アクティブなプロファイル独自の構文要素** が続きます。たとえば、アドモニションや、プロファイルが定義するカスタムブロックなどです。プロファイルが選ばれていない場合、メニューには「Select a syntax profile to insert constructs」と表示されます。

## ダイアグラムのテンプレート

挿入 ▸ ダイアグラムには、17個の出発点があります。それぞれ、編集して使える動作する例を挿入します。

フローチャート、シーケンス図、クラス図、状態図、ER図、ガントチャート、円グラフ、ユーザージャーニー、Git グラフ、マインドマップ、タイムライン、四象限チャート、サンキー図、XY チャート、ブロック図、パケット図、かんばんボード。

## グラフのテンプレート

棒グラフ、折れ線グラフ、面グラフ、散布図、円グラフ、積み上げ棒グラフ、ヒストグラム、ヒートマップ、箱ひげ図。

## 数式のテンプレート

分数、平方根、総和、積分、極限、二次方程式の解の公式、行列、区分関数、整列した数式、二項係数、ベイズの定理、オイラーの等式。

iPadでは、段落サブメニューにも同じ名前がある挿入項目(注意、水平線、リンク参照、脚注、目次、YAML フロントマター)は、iPadが同じ名前のメニュー項目をまとめてしまうため、「Insert Alert」のように表示されます。

## iPad のメニューストリップ

iPadには専用のメニューバーがあり、**⌘** を押し続けるか、ポインタを画面上端に動かすと表示されます。Macのメニューと同じ定義から、同じコマンドが、同じく変更可能なショートカットで用意されています。違うのは **ファイル** だけで、これはMacのファイルメニューが AppKit のパネルを使うためです。

キーボードやマウスのないiPadのために、Pilcrow は同じメニューをヘッダに表示できます。**設定 ▸ 外観 ▸ ヘッダのメニュー** で次から選びます。

| 選択肢 | 効果 |
| --- | --- |
| **自動** | キーボードやマウスが接続されていない限り、メニューを表示します。 |
| **常に** | 常に表示します。 |
| **しない** | 表示しません。 |

幅が1,100ポイント以上のウインドウでは、6つのメニュー **ファイル**、**編集**、**挿入**、**フォーマット**、**表示**、**ヘルプ** が横に並びます。それより狭いウインドウでは、1つの **メニュー** ボタンにまとめられます。このストリップは、メニューバーを軽くしたものです。

- **ファイル** には、通常の項目に加えて **フォルダを開く…**、**書き出す…**、**プリント…** があります。
- **編集** には、**取り消す**、**やり直す**、コピーのコマンド、**検索**、**スペルと文法**、**選択**、**翻訳**、**行へ移動…**、**リンクを確認…**、**コマンドパレット…**、**戻る**、**進む** があります。
- **フォーマット** には、インラインスタイル、**段落** サブメニュー、**表を挿入…**、**イメージを挿入…** があります。
- **表示** には、**フォーマットツールバー**、**サイドバーの表示/非表示**、**アウトライン**、**ファイル**、**検索**、書類モード、**フォーカス**、**行番号**、**現在の行の罫線**、**スタイル付きソース**、**見出しの折りたたみ**、**開いている書類** があります。そのほかの表示スイッチは、**その他** または設定を使ってください。
- **ヘルプ** には、**Pilcrow ヘルプ**、**バグを報告…**、**バグ報告を完了** があります。

# Chapter 59: 書類のタイトルと書類スイッチャ

書類の名前は、小さな色付きのドットと下向きの矢印とともにヘッダに表示されます。これをクリックするか、**表示 ▸ 開いている書類**(`⌃⌘2`)を選ぶと、**開いている書類** のリストが開きます。小さい画面では、**完了** ボタン付きのシートとして開きます。

## 保存ドット

名前の横のドットで、書類の状態がひと目でわかります。状態は VoiceOver でも読み上げられます。

| ドット | 意味 |
| --- | --- |
| 緑 | **保存済み。** ディスク上のファイルは、表示されている内容と一致しています。 |
| 琥珀色 | **編集済み。** まだ保存していない変更があります。 |
| 赤 | **保存に失敗しました。** Pilcrow は保存を試みましたが、できませんでした。エディタの上に、**再試行** ボタン付きの **Couldn't save** バナーが表示されます。 |
| 青 | **他のAppで変更されました。** ディスク上のファイルが Pilcrow の外から変更されました。 |

一度も保存していない書類は、表示するフォルダがないため、リストに「Not yet saved」と番号が表示されます。未保存の変更がある書類は、行の末尾に **編集済み** とも表示されます。

## 開いている書類のリスト

| 部分 | 機能 |
| --- | --- |
| **開いている書類を検索** | 開いている書類が7つ以上のときに表示されます。名前やフォルダの一部を入力します。大文字小文字とアクセントは区別せず、各単語が名前またはフォルダのどこかに一致する必要があります。Return で最初の一致を開きます。一致するものがないときは「No open documents match.」と表示されます。 |
| 各書類の行 | 名前、保存ドット、書類のあるフォルダを表示します。現在の書類にはチェックマークが付きます。行をクリックするとその書類に切り替わります。 |
| **閉じる**(行の末尾の **x**) | その書類を閉じます。未保存の変更がある場合は先に確認します。 |
| **新規書類** | 無題の書類を作成します。 |
| **保存** | 現在の書類を保存します。 |
| **別名で保存…** | 新しい名前や場所で保存します。 |
| **名称変更…** | 名称変更のフォームを開きます(下記)。 |
| **すべての書類を閉じる** | すべての書類を閉じ、未保存のものは1つずつ確認します。 |

リストを開かずに次または前の書類へ移動するには、`⌃Tab` と `⌃⇧Tab` を使います。

## 名称変更

**名称変更…** は、現在の **名前** とファイルのある **場所** を、**キャンセル** と **名称変更** のボタンとともに表示します。名称変更するとディスク上のファイルが変わり、書類は開いたままです。新しい名前が使えない場合は、**書類の名前を変更できませんでした** というメッセージが理由を説明します。
