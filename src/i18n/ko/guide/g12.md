# Part XIX — 라이브러리 항목 편집기

# Chapter 74: 프로파일 편집기와 프로파일 구성 요소

구문 프로파일은 마크업이 무엇을 뜻하는지 Pilcrow에 알려 줍니다. 이 장에서는 프로파일 편집기를 컨트롤별로 설명한 다음, 프로파일에 사용할 수 있는 모든 구성 요소를 나열합니다. 작업 중심의 소개는 Chapter 37부터 Chapter 39까지를 참고하세요.

편집기는 **설정 ▸ 라이브러리 ▸ 구문 프로파일**에서 엽니다. **새로 만들기**는 프로파일을 새로 시작하고, **편집**은 사용자 프로파일을 수정하며, **복제**는 기본 제공 프로파일을 복사해 복사본을 수정할 수 있게 합니다. 편집기의 제목은 **프로파일 편집**이며 **취소**, **저장**, **프로파일 도움말**(이 구성 요소들에 대한 앱 내 참조를 엽니다)이 있습니다. 좁은 화면에서는 **프로파일 섹션** 스위치로 **개요**, **규칙**, **샘플 테스트** 중에서 선택하고, 넓은 화면에서는 세 가지가 한꺼번에 표시됩니다.

## 개요

| 필드 | 기능 |
| --- | --- |
| **이름** | 프로파일의 이름으로, 상태 표시줄 메뉴와 설정에 표시됩니다. |
| **설명** | 프로파일에 대한 메모입니다. |
| **파일 확장자(쉼표로 구분)** | 파일에 이 프로파일을 선택하게 하는 확장자입니다. 두 프로파일이 같은 확장자를 공유할 수 없습니다. |
| **상속** | **없음**, 또는 이 프로파일이 규칙을 이어받는 다른 프로파일입니다. |
| **구문** | **Markdown 확장** 또는 **Markdown 대체**(아래 참고)입니다. |
| **한눈에 보기** | **블록 규칙**, **인라인 규칙**, **중첩 규칙**의 개수입니다. |
| **고급 JSON 편집…** | 안내식 편집기에서 다루지 않는 필드를 위해 프로파일을 JSON으로 엽니다. **적용**은 JSON 변경 사항을 유지하고, **취소**는 버립니다. |

**Markdown 확장**은 Markdown의 규칙에 내 규칙을 더합니다. Markdown의 제목, 목록, 강조 등은 계속 읽히고, 내 블록 규칙과 인라인 규칙이 여기에 추가됩니다. CommonMark 프로파일의 규칙을 그대로 복사한 규칙은 Markdown이 이미 하는 일을 설명하는 것이므로 Markdown에 맡깁니다. **Markdown 대체**는 내 규칙을 구문 전체로 만들어, Markdown 구조는 더 이상 인식되지 않습니다. 이 경우 규칙 하나가 **줄 끝**을 생성해야 하며, 그렇지 않으면 단락이 나뉘지 않습니다. 편집기는 "Add a rule whose output node is "newline", or nothing will separate into paragraphs"라고 경고하며, 그런 규칙이 생길 때까지 프로파일을 저장할 수 없습니다. 프로파일에 정의되지 않은 출력 유형도 함께 표시됩니다.

## 규칙

규칙은 세 그룹으로 나뉩니다.

### 블록 규칙

블록 규칙은 전체 줄과 블록을 인식합니다. **규칙 추가**로 하나를 추가합니다. 각 규칙에는 **패턴**, **일치** 유형, 무엇을 **생성**하는지, 그리고 **옵션**이 있습니다. 규칙은 **삭제** 버튼으로 제거합니다. 규칙이 없으면 편집기에 "No rules yet. Add one to recognize a block construct."라고 표시됩니다.

### 인라인 규칙

인라인 규칙은 한 줄 안의 텍스트를 인식합니다. **인라인 규칙 추가**로 하나를 추가합니다. 인라인 규칙에는 네 가지 일치 유형(**리터럴 접두사**, **리터럴 정확**, **정규식(제한적)**, **구분 기호 쌍**)이 있고, 블록 규칙에는 일곱 가지 모두 있습니다.

### 중첩 규칙

중첩 규칙은 어떤 출력이 어떤 출력 안에 들어갈 수 있는지 정합니다. 각 규칙에는 **부모 노드**와 **허용되는 자식 노드(쉼표로 구분)**가 있습니다. 비어 있으면 제한이 없다는 뜻입니다. "No restrictions. Every node type may nest inside any other." **중첩 규칙 추가**로 하나를 추가합니다.

### 일치 유형

| 일치 유형 | 패턴을 이렇게 읽음 | 블록 | 인라인 |
| --- | --- | --- | --- |
| **리터럴 접두사** | 구조가 시작되는 텍스트입니다. | 예 | 예 |
| **리터럴 정확** | 구조의 전체 텍스트입니다. | 예 | 예 |
| **줄 시작 접두사** | `# `처럼 줄의 시작에 있는 텍스트입니다. | 예 | |
| **들여쓴 블록** | 공백 네 칸이나 탭처럼 패턴으로 시작하는 줄입니다. 연속된 줄과 그 사이의 빈 줄은 하나의 블록이 되며, 들여쓰기 없이 표시됩니다. | 예 | |
| **펜스 블록** | 블록을 여는 줄이며, 짝이 되는 줄로 닫힙니다. | 예 | |
| **정규식(제한적)** | 정규 표현식입니다. 멈춰 버릴 수 있는 식을 저장하기 전에 Pilcrow가 경고합니다. "This regex could hang the editor — simplify it." | 예 | 예 |
| **구분 기호 쌍** | `%%this%%`의 `%%`처럼 한 줄의 텍스트 양쪽에 같은 표시가 있는 경우입니다. 표시 바로 안쪽에는 공백이 없습니다. | 예 | 예 |

정규 표현식에서 `(?<name>…)`은 일치 부분에 이름을 붙입니다. 아래의 이름 붙은 부분(Parts)을 참고하세요.

## 규칙 옵션

각 규칙의 **옵션** 그룹에는 다음이 있습니다.

| 옵션 | 기능 |
| --- | --- |
| **우선순위** | 우선순위가 높은 규칙을 먼저 시도합니다. |
| **줄 시작에서만** | 규칙이 줄 중간에서 일치하지 않게 합니다. |
| **이름 붙은 부분을 속성으로 사용** | 정규 표현식의 이름 붙은 각 부분이 출력의 속성이 됩니다. 편집기에 "Parts in this pattern"과 "Parts this output reads"가 나열됩니다. 굵게나 링크처럼 텍스트를 담는 출력에서는 `text`라는 이름의 부분이 있으면 그것이, 없으면 마지막으로 일치한 부분이 표시되는 텍스트가 됩니다. |
| **생성** | 규칙이 만드는 것입니다. 아래 목록의 출력이거나 **사용자화** 이름입니다. |
| **사용자 지정 노드 이름** | **사용자화** 출력의 이름입니다. |
| **고정 속성** | 매번 같은 값을 갖는 부분으로, **속성 추가**로 추가합니다(**이름**과 **값**). 값에는 `{name}`으로 쓴 이름 붙은 부분을 넣을 수 있습니다. 패턴에서 `address`라는 이름을 붙인 이메일 규칙은 링크의 `url`을 `mailto:{address}`로 지정할 수 있습니다. |
| **삽입 텍스트** | 이 규칙에 대해 **삽입** 메뉴가 쓰는 텍스트로, 나타나야 하는 그대로 쓰며 커서가 놓일 자리에 `$0`을 씁니다. 정규 표현식, 블록 또는 들여쓰기로 일치하는 규칙에는 이것이 필요하며, 없으면 삽입 메뉴에서 빠집니다. |
| **빈 줄 다음에만** | 들여쓴 블록용입니다. 텍스트 바로 다음의 들여쓴 줄은 목록 항목의 다음 줄처럼 그 텍스트의 일부로 남습니다. |
| **줄 끝에서 Return을 누른 후** | 목록과 인용용입니다. **자동**(글머리 기호와 인용을 반복하고, 번호 항목은 번호를 올리고, 작업 항목은 체크 해제 상태로 시작), **표시 반복**, **번호 증가**, **표시에서 새로 시작**, **아무것도 추가 안 함** 중에서 선택합니다. |

### 펜스 블록과 구분 블록

**펜스 블록** 규칙에서는 **블록 내용**이 안에 무엇이 있는지 정합니다.

| 선택 | 의미 |
| --- | --- |
| **아직 없음** | 설정되지 않음. |
| **텍스트(작성한 그대로 표시)** | 코드 또는 서식 지정된 텍스트. |
| **없음 — 숨김** | 주석으로, 문서에서 제외됩니다. |
| **다른 블록, 상자 안** | 단락, 목록 등을 담은 인용, 사이드바 또는 주의 상자. |
| **다른 블록, 상자 없음** | 블록이 주변 텍스트에 합쳐지고, 줄은 그것들을 묶기만 합니다. |
| **표** | 아래 표(Tables)를 참고하세요. |
| **텍스트로 그린 표** | reStructuredText의 표처럼, 여는 줄부터 다음 빈 줄까지 이어지는 텍스트 격자 또는 정렬된 열. |
| **표시로 끝나는 줄 아래의 들여쓴 텍스트** | 여는 줄은 reStructuredText의 `::`처럼 표시로 끝나는 산문이며, 산문은 단락으로 남고 빈 줄 뒤에 들여써 놓은 텍스트는 작성한 그대로 표시됩니다. |
| **시작 줄 아래의 들여쓴 텍스트** | `.. code-block::` 같은 지시문으로, 그 아래의 들여쓴 줄을 담으며 닫는 줄이 없습니다. |

**닫는 줄**은 블록을 끝내는 줄이며, 비어 있으면 여는 줄과 같은 줄을 뜻합니다("Same as the opening line"). `+++`처럼 정규 표현식이 아닌 구분자는 일반 텍스트로 일치합니다. **닫는 줄은 여는 줄의 표시를 같거나 더 많이 반복함**은 Markdown 스타일 펜스용입니다. 닫는 줄은 여는 줄의 첫 문자를 같거나 더 많은 횟수만큼 반복한 것이므로, 더 긴 펜스는 더 짧은 펜스를 텍스트로 담습니다. 여는 줄에 알려진 언어가 지정되어 있으면 텍스트 블록의 언어는 편집기에서 색으로 표시됩니다.

### 표

표 블록의 옵션은 다음과 같습니다.

| 옵션 | 기능 |
| --- | --- |
| **배치** | **구분선이 있는 격자**(`|` 사이의 셀과 행 사이의 구분선) 또는 **정렬된 열**(첫 구분선 아래에 맞춘 열). |
| **셀 구분자** | 각 셀을 시작하는 텍스트입니다. |
| **구분선 패턴**, **머리글 구분선 패턴** | 구분선만 그리는 줄과 머리글을 끝내는 줄입니다. |
| **행의 끝 표시** | LaTeX `tabular`처럼 각 행을 끝내는 표시입니다. |
| **병합 셀 패턴** | 열에 걸치는 셀입니다. |
| **셀 옵션 패턴** | 셀 구분자 바로 앞에 올 수 있는 것에 대한 정규 표현식입니다. `colspan`이라는 이름의 부분은 셀이 그 수만큼의 열에 걸치게 합니다. |
| **열 목록 구분자**, **반복 표시** | `columns` 목록을 쓰는 방식입니다. `,`와 `*`를 쓰면 `3*`는 열 세 개를 뜻합니다. |
| **빈 줄 앞의 첫 줄이 머리글** | 머리글 행이 배치에 의해 정해집니다. |
| **형식** | 셀을 쓰는 다른 방식으로, 각각 이름과 구분자(`csv`와 `,` 등)로 이루어지며 **형식 추가**로 추가하고 표의 `format` 부분으로 선택합니다. |

## 프로파일 전체 설정

| 설정 | 기능 |
| --- | --- |
| **표시 기호로 목록 중첩** | `*` 뒤의 `**`처럼 새 표시가 나올 때마다 들여쓰기와 관계없이 더 깊은 수준이 시작됩니다. |
| **목록 연결 줄** | 목록 항목 뒤에 홀로 놓여 다음 블록을 그 항목에 붙이는 줄입니다. |
| **단일 줄바꿈 유지** | 단락 안의 줄바꿈이 줄바꿈으로 남습니다. |
| **제목에 ID 부여** | 자체 ID가 없는 제목은 제목에서 ID를 얻습니다. 소문자로 바꾸고, 단어를 **단어 구분자**로 이으며, **접두사**(**ID 접두사**, **ID 단어 구분자**)를 앞에 붙입니다. `_`와 `_`로 설정하면 "Getting Started"는 `_getting_started`가 되고, 이에 대한 상호 참조에는 제목이 표시됩니다. 제목이 반복되면 구분자와 번호가 붙습니다. |
| **제목 번호 매기기** | **문서가 정의하면**에 지정한 속성(AsciiDoc의 `:sectnums:` 등)을 문서가 정의하면, **제목 수준부터** 아래의 제목에 `1.`, `1.1.`, `2.`처럼 번호가 매겨집니다. 정의 이전의 제목에는 번호가 없습니다. |
| **번호가 붙은 캡션** | 여기에 나열된 출력(`image`, `table`, `example` 등)의 제목이 있는 블록에는 제목 앞에 **레이블**과 자체 번호(예: "Figure 1.")가 붙으며, 위치는 블록의 **위** 또는 **아래**인 **캡션 위치**를 따릅니다. **캡션 추가**로 추가합니다. |

## 주변 문자에 따라 짝이 정해지는 인라인 표시

Markdown 같은 언어는 굵게와 기울임꼴을 옆 문자에 따라 열리거나 닫히는 문자 연속으로 쓰고, 코드 조각이나 링크는 괄호로 쓰기 때문에, 구조 전체를 하나의 패턴으로 찾을 수 없습니다. 이를 설명하려면 **주변 문자에 따라 정해지는 표시 읽기**를 켭니다.

| 설정 | 기능 |
| --- | --- |
| **이스케이프 문자** | 다음 문자를 일반 문자로 만드는 문자입니다. |
| **코드 조각 문자** | 이 문자의 연속이 조각을 열고, 같은 길이의 다음 연속이 닫습니다. |
| **연속 표시** | 연속으로 짝을 이루는 표시로, **연속 표시 추가**로 추가합니다. 각각 **표시**, **표시 하나로 그리기**, **표시 둘로 그리기**, **단어 안에서 열고 닫을 수 있음**(`_`는 끔)이 있습니다. |
| **짝 표시** | 같은 길이의 연속과 짝을 이루는 표시로, **짝 표시 추가**로 추가합니다. **표시**, 그것이 **그리기**하는 것, 그리고 **이 설정이 켜져 있을 때만**(켜져 있어야 하는 강조 표시 같은 구문 설정, 또는 **항상**)이 있습니다. |
| **링크 및 웹 주소** | **이미지 접두사**, **단독으로 쓴 주소를 감싸는 문자**, **꾸밈없는 주소를 시작하는 스킴**, **레이블을 정의하는 줄에 붙는 문자**, **각주 레이블의 시작 문자**(레이블의 여는 대괄호 뒤에서 각주로 만드는 문자로, 줄이 `[^note]:`로 시작하면 `[^note]`는 각주 참조로 그려집니다)가 있습니다. |

표시는 한 줄 안에서 짝을 이룹니다. 코드, 이스케이프된 문자, 링크 주소는 주변 표시에 대해 일반 텍스트로 취급됩니다.

## 스타일 적용 소스

**스타일 적용 소스**를 켜면 편집기는 문서를 그 구문의 모양으로 그립니다. 더 큰 제목, 굵은 글씨와 기울임 글씨, 인용 막대, 목록 들여쓰기, 작업 상자, 구분선, 링크, 코드 카드로 표시하고, 그것을 만드는 표시는(**표식 숨기기**를 켜 두면) 커서가 있는 줄을 제외하고 숨깁니다. 편집기는 특정 구문에 대해 아무것도 알지 못합니다. 규칙은 스타일 항목을 가짐으로써 자신의 일치가 무엇인지 알리며, 항목이 없는 규칙은 색은 입혀지지만 스타일은 바뀌지 않습니다.

모든 규칙의 **옵션**에는 **스타일이 적용된 소스** 그룹이 있습니다.

| 필드 | 기능 |
| --- | --- |
| **역할** | 일치가 무엇인지, 또는 **스타일 없음**. 한 줄 안의 구조: heading, strong, emphasis, code, strike, highlight, underline, link, subscript, superscript. 전체 줄: rule(구분선), list(들여쓰기와 뒤의 공백을 포함한 목록 항목의 표시), task(체크박스가 뒤따르는 표시), quote(인용된 줄의 `>` 표시). 전체가 한 번에 인식되는 블록: codeBlock. 여는 줄과 닫는 줄이 별도의 일치인 블록: quoteRegion. 그림으로 그려지는 표, 수식, 다이어그램: renderedBlock. |
| **내용 그룹** | 구조의 대상이 되는 내용을 담은 캡처 그룹으로, 1부터 셉니다. `*bold*` 안의 단어, `\section{Title}`의 제목 등입니다. 일치에서 그 밖의 부분은 구조 자체의 표시이며 **표식 숨기기**가 숨깁니다. `0`은 일치 전체가 내용이어서 아무것도 숨기지 않는다는 뜻이며, 웹 주소가 그렇습니다. 일치가 제목의 `== `처럼 표시뿐이면 생략합니다. |
| **제목 수준**, **수준 그룹** | 제목의 수준으로 1에서 6까지입니다. 생략하면 규칙의 출력 이름 끝의 숫자(`heading2`)이거나, `#` 연속을 담은 캡처 그룹의 길이입니다. |
| **표시 그룹** | list나 task에서, 일치가 인용된 항목의 `> `처럼 다른 것으로 시작할 때, 들여쓰기와 뒤의 공백을 포함한 표시인 캡처 그룹입니다. |
| **줄 끝까지 스타일 적용** | 제목의 표시에만 일치하고 제목은 뒤따르는 텍스트로 남기는 규칙에서, 일치부터 줄 끝까지 스타일을 적용합니다. |
| **그려지는 형태** | 렌더링된 블록에서 그것이 무엇인지: 표, 수식, 다이어그램, 또는 **그림이 아님**. |
| **주소 그룹** | 링크에서, 클릭하거나 탭할 때 열리는 주소를 담은 캡처 그룹으로 순서대로 시도됩니다. `0`은 일치 전체입니다. 웹, 메일, 전화 주소만 열립니다. |

그룹 번호는 패턴의 괄호를 1부터 세며, 0은 일치 전체입니다. Markdown을 대체하지 않는 프로파일은 자신의 규칙이 선언하지 않은 종류에 대해 인용 막대나 `**` 쌍처럼 Markdown 자체의 해석도 유지합니다.

## 문서 속성과 조건부 섹션

**문서 속성** 규칙은 `name`으로 값을 정의하고, **속성 참조** 규칙(`name`과 `original` 부분이 있는 인라인 규칙)은 참조를 그 값으로 바꿉니다. 아무도 정의하지 않은 속성에 대한 참조는 작성한 그대로 남습니다. **조건부 섹션**은 이름을 지정한 속성이 설정되어 있는지에 따라 줄 사이의 블록을 유지하거나 버립니다. 속성은 정의된 곳부터 이후에 적용됩니다.

**다음 블록 설정**을 생성하는 규칙은 뒤따르는 블록을 구성하는 한 줄 전체를 인식하며 그 자체는 아무것도 표시하지 않습니다. 이 규칙의 부분과 고정 속성은 그 블록에 전달됩니다. `title`, `id`, `nodeType`, `language`, `hardbreaks`는 이름 붙은 부분(Parts)에 나온 의미를 가지며, 그 밖의 부분은 블록에 보관되어 표, 목록, 인용이 읽습니다.

## 프로파일 테스트

편집기 맨 아래의 **샘플 테스트**에는 샘플 텍스트가 있습니다(처음에는 제목 하나와 텍스트 한 줄). **샘플 검사**를 선택하면 규칙이 만드는 노드가 중첩된 대로 들여쓰기되어 표시됩니다. 일치하는 것이 없으면 "No blocks recognized."라고 표시됩니다.

## 기준본

프로파일의 **기준본**은 복원 지점으로, 프로파일을 만들거나 복제하거나 가져왔을 때의 상태입니다. **기준본으로 되돌리기**는 확인 후 그 이후의 모든 변경을 버립니다. **새 기준본으로 설정**은 프로파일을 저장하고 현재 상태를 복원 지점으로 삼습니다.

프로파일이 Markdown을 대체하는데 줄 끝 규칙이 없거나, 패턴이 안전하지 않아 편집기를 멈추게 할 수 있거나, 파일을 쓸 수 없으면 메시지와 함께 저장이 거부됩니다.

## Parts

이름 붙은 부분(Parts)은 출력이 읽는, 일치의 이름 붙은 조각입니다.

| 부분 | 의미 |
| --- | --- |
| `allOf` | 모든 이름이 필요할 때 이름 사이의 구분자로, `+` 등이 있습니다. |
| `alt` | 이미지를 볼 수 없는 독자를 위한 이미지 설명입니다. |
| `anyOf` | 이름 중 하나만 있어도 될 때 이름 사이의 구분자로, `,` 등이 있습니다. |
| `attribution` | 인용 아래에 표시되는, 인용문을 말한 사람입니다. |
| `citetitle` | 인용문의 출처 작품으로, 출처 표기 뒤에 표시됩니다. |
| `columns` | `1,2,1` 같은 표의 열 목록으로, 항목 수가 열의 수입니다. |
| `condition` | 섹션이 의존하는 속성 이름입니다. |
| `conditionType` | `defined`는 속성이 설정되어 있을 때, `undefined`는 설정되어 있지 않을 때 섹션을 유지합니다. |
| `content` | 일치 전체가 아닐 때의 텍스트 자체입니다. |
| `format` | 다이어그램의 엔진(`mermaid` 또는 `vega-lite`)이며, 표에서는 셀이 사용하는 구분 형식 중 하나입니다. |
| `hardbreaks` | 있으면 다음 블록의 단일 줄바꿈을 유지합니다. |
| `header` | `false`가 아닌 값이면 표의 첫 행이 머리글이 됩니다. |
| `id` | 이름입니다. 다음 블록에서는 상호 참조가 가리키는 ID이고, 각주에서는 자체 텍스트가 없는 이후 각주가 그 번호를 공유하게 하는 이름입니다. |
| `keys` | 누를 키로, 쉼표로 구분합니다. |
| `label` | 참조나 앵커에 대상 자체의 제목 대신 표시되는 텍스트입니다. |
| `language` | 코드 블록의 프로그래밍 언어로, 색 지정에 사용됩니다. |
| `level` | 1에서 6까지의 제목 수준입니다. |
| `marker` | `::`처럼 용어 뒤의 구분자입니다. 다른 표시는 설명 안에 목록을 중첩합니다. |
| `name` | 정의나 참조에서의 속성 이름입니다. |
| `nodeType` | 다음 블록을 파일에서의 이름으로 지정한 다른 출력으로 만듭니다. |
| `noHeader` | 있으면 표에 머리글 행이 없습니다. |
| `notation` | 수식 표기법으로, `tex`(기본값) 또는 `latex`입니다. |
| `open` | `true`이면 접을 수 있는 섹션이 펼쳐진 채 표시됩니다. |
| `ordered` | `true`이면 목록에 번호가 매겨집니다. |
| `original` | 작성한 그대로의 참조로, 속성이 정의되지 않았을 때 표시됩니다. |
| `presentation` | 다음 설명 목록의 표시 방식입니다. `sideBySide`는 용어와 설명을 두 열로 놓고, `questions`는 각 용어를 질문으로 번호를 매겨 그 아래에 답을 놓습니다. |
| `primary` | 색인 항목입니다. |
| `secondary` | 색인 항목 아래의 하위 항목입니다. |
| `sectionLabel` | 다음 제목의 번호 앞에 오는 단어로, `Appendix` 등이 있습니다. 이런 제목은 따로 세어져 `Appendix A:`가 됩니다. |
| `sectionLabelStart` | 그 번호의 첫 값입니다. 문자(`A`)는 문자로, 숫자는 숫자로 셉니다. |
| `src` | 비디오 또는 오디오 파일의 주소입니다. |
| `start` | 번호 목록이 시작하는 번호입니다. |
| `summary` | 접을 수 있는 섹션이 닫혀 있을 때 표시되는 줄입니다. |
| `targetID` | 참조가 가리키는 ID입니다. |
| `term` | 설명하는 대상 용어입니다. |
| `tertiary` | 두 번째 항목 아래의 하위 항목입니다. |
| `text` | 패턴이 그 이상을 캡처할 때 표시되는 텍스트입니다. 각주의 텍스트는 그것이 들어 있는 단락, 표 또는 목록 뒤에 번호가 매겨져 이어집니다. |
| `title` | 제목입니다. 상자의 제목, 이미지나 링크의 툴팁, 또는 다음 블록 위의 캡션입니다. |
| `type` | `note`, `tip`, `warning` 같은 주의의 종류입니다. |
