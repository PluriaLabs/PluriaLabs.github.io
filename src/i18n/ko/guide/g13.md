# Chapter 75: 테마 편집기

테마에는 두 종류가 있으며, 각각 전용 편집기가 있습니다. 두 편집기 모두 **설정 ▸ 라이브러리 ▸ 테마**에서 엽니다. **새로 만들기**는 테마를 만들고, **편집**은 사용자 테마를 수정하며, **복제**는 기본 제공 테마를 복사해 복사본을 수정할 수 있게 합니다. 기본 제공 테마는 편집할 수 없습니다.

## 렌더링 테마 편집기

**렌더링 테마 편집**은 미리보기, HTML, PDF, 이미지, 프린트 출력의 스타일을 지정합니다. 이 편집기의 Pilcrow 사용자 속성은 Word 스타일도 설정합니다. 렌더링 테마는 앱이나 편집기의 스타일은 지정하지 않습니다.

| 항목 | 기능 |
| --- | --- |
| **이름** | 테마의 이름입니다. |
| **화면 모드** | **자동**, **라이트** 또는 **다크**입니다. |
| **CSS** | 코드 편집기에 표시되는 스타일시트입니다. 속성과 클래스는 Chapter 80을 참고하세요. |
| **렌더링된 미리보기** | 입력하는 CSS가 적용된 견본 문서가 실시간으로 그려지므로 효과를 바로 확인할 수 있습니다. |
| **CSS 진단** | 허용되지 않는 원격 리소스처럼 Pilcrow가 CSS에서 찾은 문제입니다. |
| **취소**, **저장** | 테마를 닫거나 저장합니다. 변경 사항이 있는 상태로 닫으면 **테마 변경 사항을 폐기할까요?**라고 묻고 **변경 사항 폐기** 또는 **계속 편집**을 선택할 수 있습니다. |
| **기준본** | **기준본으로 되돌리기**는 테마를 만들거나 복제하거나 가져온 이후의 모든 변경 사항을 (확인 후) 폐기합니다. **새 기준본으로 설정**은 테마를 저장하고 현재 상태를 복원 지점으로 만듭니다. |

## 앱 테마 편집기

**앱 테마 편집**은 Pilcrow 자체의 모양, 즉 화면 모드, 강조색, 사이드바, 막대, 편집기의 스타일을 지정합니다.

| 항목 | 기능 |
| --- | --- |
| **이름** | 테마의 이름입니다. |
| **화면 모드** | **자동**, **라이트** 또는 **다크**입니다. 자동 테마에는 팔레트가 두 개 있습니다. |
| **색상 편집 대상** | 자동 테마에서 **라이트** 또는 **다크**를 선택해, 두 팔레트 중 어느 쪽을 편집할지 정합니다. |
| 색상, 다섯 그룹 | **앱**(강조색), **사이드바**(배경 및 전경), **상태 및 서식 막대**(배경 및 전경), **편집기**(배경, 전경, 커서, 선택, 거터 배경, 거터 전경, 현재 줄 밑줄), **구문**(제목, 마커, 코드, 링크, 흐린 색, 그리고 코드의 키워드, 문자열, 숫자, 주석)입니다. 각 색상은 지정하기 전까지 **기본값**으로 표시되며, **재설정** 버튼으로 되돌릴 수 있습니다. |
| **미리보기** | 선택한 색상으로 사이드바, 편집기, 상태 막대를 갖춘 Pilcrow의 축소판을 라이트 또는 다크로 보여 줍니다. |
| **취소**, **저장**, **기준본** | 위와 같습니다. |

테마는 개별 구문 토큰에도 색을 지정할 수 있습니다. 이 색상은 그대로 유지되지만 테마의 JSON 파일(`syntax.tokens`)에서 편집합니다. Chapter 79를 참고하세요.

# Chapter 76: 매크로 편집기

**설정 ▸ 라이브러리 ▸ 매크로**에서 매크로 편집기를 엽니다. 컬렉션 안에서 **새로 만들기**를 누르거나 매크로에서 **편집**을 누릅니다. 제목은 **새 매크로** 또는 **매크로 편집**입니다.

| 필드 | 기능 |
| --- | --- |
| **이름** | 매크로의 레이블입니다. |
| **트리거** (예: `/sig`) | 매크로를 시작하는 텍스트입니다. 트리거 뒤에 공백, 탭 또는 리턴을 입력하면 매크로가 확장됩니다. |
| **일치** | 트리거를 해석하는 방식으로, **정확한 텍스트**, **접두사**, **정규식** 중에서 고릅니다. 편집기를 멈추게 할 수 있는 정규식은 거부됩니다. "That regular expression could hang the editor. Simplify it." |
| **대체** | 매크로가 확장되어 바뀌는 텍스트입니다. |
| **날짜/시간 삽입** | 대체 텍스트에 날짜 또는 시간 토큰을 추가하는 메뉴입니다. |
| **활성화** | 매크로를 삭제하지 않고 켜거나 끕니다. |
| **코드 안에서는 확장 안 함** | 코드 범위와 코드 블록 안에서는 매크로가 실행되지 않게 합니다. |
| **취소**, **저장** | 매크로를 닫거나 저장합니다. 저장할 수 없으면 그 이유가 메시지로 표시됩니다. |

대체 텍스트에서 `$1`, `$2` 등은 탭 정지 지점이고 `$0`은 커서가 놓이는 위치입니다. 매크로가 확장된 뒤에는 Tab(또는 **다음 필드**)으로 정지 지점 사이를 이동합니다. 날짜와 시간은 토큰으로 지정합니다. `{{date:yyyy-MM-dd}}`, `{{time:HH:mm:ss}}`, `{{datetime:MM/dd/yyyy h:mm a}}`, 그리고 이름이 있는 형식인 `iso8601`, `rfc2822`, `unix`, `short`, `medium`, `long`, `full`을 사용할 수 있습니다. 필드 아래의 **Now:** 줄에는 지금 이 순간 대체 텍스트가 어떻게 만들어지는지 표시됩니다.

# Chapter 78: iPad에서 Pilcrow 사용하기

Pilcrow는 iPadOS 17 이상에서 실행됩니다. 터치만으로, 하드웨어 키보드와 함께, 또는 트랙패드나 마우스와 함께 사용할 수 있습니다.

## 터치

- **창 구분선.** 나란히 보기에서 소스와 미리보기 사이의 구분선을 드래그해 크기를 조절합니다. 두 번 탭하면 원래대로 돌아갑니다.
- **탐색기.** 사이드바의 가장자리를 드래그해 크기를 조절합니다. 창이 좁으면 사이드바가 문서를 덮으며, **완료** 버튼으로 닫을 수 있습니다.
- **열 선택.** **더 보기 ▸ 열 선택**을 켠 다음 한 손가락으로 드래그해 직사각형 모양으로 텍스트를 선택합니다. 두 손가락은 계속 스크롤에 쓰입니다. 켜져 있는 동안에는 **열 선택** 배지가 표시되며, 이 배지의 버튼으로 끌 수 있습니다. 또는 **더 보기 ▸ 열에 커서 놓기…**로 숫자를 지정해 커서를 놓을 수도 있습니다.
- **컨텍스트 메뉴.** 텍스트를 길게 누르면 편집기의 메뉴가 나타납니다(아래 참고).
- **파일.** 파일 패널에서 파일을 길게 누르면 해당 파일의 메뉴가 나타납니다(Chapter 60).

## 하드웨어 키보드 사용 시

Chapter 77의 모든 단축키를 사용할 수 있습니다. **⌘**를 길게 누르면 iPad의 메뉴 막대가 보이고, 포인터를 화면 맨 위로 옮겨도 됩니다. 키보드나 마우스가 연결되어 있으면 Pilcrow가 자체 머리말 메뉴를 숨길 수 있습니다. **설정 ▸ 화면 모드 ▸ 머리말의 메뉴**를 참고하세요.

## 트랙패드나 마우스 사용 시

오른쪽 클릭하면 편집기의 컨텍스트 메뉴가 열립니다. **Option**을 누른 채 드래그하면 직사각형 모양으로 텍스트를 선택합니다.

## 편집기의 컨텍스트 메뉴

텍스트에서 Mac은 오른쪽 클릭, iPad는 길게 누르기로 엽니다. 현재 구문 프로필이 표현할 수 없는 항목은 회색으로 표시되며, 시스템이 자체 항목(잘라내기, 복사, 붙여넣기, 맞춤법 제안, 찾아보기 등)을 추가합니다.

**Mac**에서는 다음과 같습니다.

| 항목 | 기능 |
| --- | --- |
| **복사 / 붙여넣기 방식…** | **Markdown으로 복사**, **일반 텍스트로 복사**, **HTML 코드로 복사**, **일반 텍스트로 붙여넣기**. |
| **단락** | **단락**, **제목 1**부터 **6**까지, **인용**, **글머리 기호 목록**, **번호 매기기 목록**, **작업 목록**, **코드 블록**. |
| **포맷** | **굵게**, **강조**, **코드**, **취소선**, **인라인 수식**, **별행 수식**, **다이어그램**, **차트**, **하이퍼링크**. |

| 항목 | 기능 |
| --- | --- |
| **포맷** | 굵게, 강조, 코드 등의 인라인 스타일입니다. |
| **단락** | 제목, 인용, 목록, 코드 블록 같은 단락 유형입니다. |
| **삽입** | 서식 도구 막대의 **더 보기** 메뉴와 같은 삽입 항목으로, **알림 삽입**, **이미지 삽입…**, **표 삽입…**이 포함되며, **구문** 아래에는 현재 프로필 고유의 구성 요소가 있습니다. |
