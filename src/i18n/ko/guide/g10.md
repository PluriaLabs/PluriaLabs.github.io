# Chapter 68: 편집

## 화면 및 입력

### 화면

| 컨트롤 | 기능 |
| --- | --- |
| **줄 번호 표시** | 여백에 줄 번호를 표시합니다. **보기 ▸ 줄 번호**와 같습니다. |
| **현재 줄 아래에 밑줄 표시** | 캐럿이 있는 줄 아래에 가는 선을 표시합니다. |
| **스타일 적용 소스** | 제목, 굵게, 기울임을 그에 맞는 서체로 그립니다. |
| **제목 접기** | 제목 옆에 접기 화살표를 표시합니다. |
| **렌더링된 블록** | 표, 수식, 다이어그램을 편집 버튼이 있는 그림으로 그립니다. |
| **섹션 자동 펼치기** | 캐럿이 들어오면 접힌 섹션이나 그림 블록을 열고, 캐럿이 나가면 닫습니다. |
| **표식 숨기기** | 캐럿이 있는 줄을 제외한 모든 줄에서 제목, 굵게, 기울임 표시를 숨깁니다. 스타일 적용 소스가 필요합니다. |
| **긴 줄 바꿈** | 끄면 긴 줄이 줄 바꿈 대신 옆으로 스크롤됩니다. 미리보기와 내보내기는 항상 줄 바꿈됩니다. 20,000자 이상의 줄과 집중 모드는 항상 줄 바꿈됩니다. |
| **열 모드에서 짧은 줄** | 열에 닿기에 너무 짧은 줄에서 열이 하는 동작: **줄 끝 사용**, **그 줄 제외**, **공백으로 부드럽게 채우기**(입력한 텍스트가 화면에서 정렬되도록 공백 추가), **공백으로 엄격하게 채우기**(부족한 글자마다 공백 하나씩 추가하여 열 번호로 정렬), 또는 **그 줄에서 멈추기**. 삭제는 짧은 줄에서 글자를 지우지 않습니다. |
| **상태 표시줄 표시** | 하단의 상태 표시줄을 켜거나 끕니다. |
| **서식 도구 막대** | 텍스트 아래에 선택 사항인 도구 막대를 표시합니다. |

### 입력

| 컨트롤 | 기능 |
| --- | --- |
| **괄호와 따옴표 자동 짝 맞춤** | 여는 괄호나 따옴표를 입력하면 닫는 것이 추가됩니다. |
| **Markdown 자동 짝 맞춤 ( \* \_ ` ~ )** | Markdown 기호에도 같은 기능을 적용합니다. |
| **이모지 단축 코드 확장(:smile:)** | 입력하는 동안 단축 코드를 이모지로 바꿉니다. 이미 단축 코드가 들어 있는 파일은 작성된 그대로 표시됩니다. |
| **Return 키로 목록과 인용 이어가기** | Return은 다음 항목을 시작하고, 빈 항목에서 Return을 누르면 목록이 끝나며, Tab은 항목을 들여씁니다. |
| **Return 키로 들여쓰기 유지** | 새 줄이 위 줄과 같은 앞쪽 공백이나 탭으로 시작합니다. |
| **Tab 키로 공백 삽입** | Tab이 탭 문자 대신 다음 탭 정지 위치까지 탭 너비만큼의 공백을 삽입합니다. |

스마트 문장 부호, 강조 표시, 아래 첨자, 위 첨자는 **라이브러리 ▸ CommonMark 옵션**에 있습니다.

### 입력 소리

| 컨트롤 | 기능 |
| --- | --- |
| **입력할 때 소리 재생** | 키를 누를 때마다 소리가 나며, 스페이스, Return, Delete는 다른 소리가 납니다. 붙여넣기와 실행 취소는 소리가 나지 않습니다. iPad에서는 무음 스위치가 소리를 끕니다. |
| **소리** | 소리 팩: **타자기**, **오리**, 또는 **새끼 고양이**. |
| **음량**, **미리보기** | 음량을 설정하고 소리 팩을 들어 봅니다. |
| **내 소리** | 원하는 키 종류에 짧은 클립을 선택합니다. 나머지는 위에서 고른 소리를 유지합니다. 종류는 **소문자**, **대문자**, **숫자**, **기호 및 구두점**, **스페이스**, **탭**, **Return**, **삭제**입니다. 각각 **선택…**(또는 **변경…**), **재생**, **제거**가 있습니다. 클립은 최대 2초, 3MB(WAV, AIFF, MP3, M4A 또는 CAF)까지 가능하며, 지연 없이 재생되도록 메모리에 저장됩니다. |

### 맞춤법 및 진단

**입력하는 동안 맞춤법 검사**는 틀린 철자에 밑줄을 긋습니다. **구문 분석 경고 표시**는 닫히지 않은 코드 펜스나 수식 블록, 닫는 괄호가 없는 링크, 머리글과 맞지 않는 표 행처럼 의도와 다를 가능성이 있는 구문이 있는 줄을 표시합니다. 안내는 줄 끝에 나타납니다. 표시되는 내용만 바꾸며 문서를 구문 분석하거나 내보내는 방식은 바꾸지 않습니다.

## 이미지

이 설정은 삽입하는 이미지(**삽입 ▸ 이미지…** 또는 끌어다 놓기)를 어떻게 처리할지 정합니다.

| 컨트롤 | 기능 |
| --- | --- |
| **동작** | **특별한 동작 없음**, **이미지를 현재 폴더로 복사 (./)**, **이미지를 ./assets로 복사**, 또는 **이미지를 ./\${filename}.assets로 복사**. **이미지 업로드**는 사용할 수 없는 항목으로 표시됩니다. Pilcrow에는 이미지 호스트가 없으므로 이미지는 원래 있던 위치 그대로 삽입됩니다. |
| **로컬 이미지에 적용** | 이미 기기에 있는 이미지에 동작을 적용할지 여부입니다. |
| **온라인 이미지에 적용** | 웹 주소를 가리키는 이미지에 적용할지 여부입니다. |
| **인터넷에서 이미지 불러오기** | 끄면 웹 주소를 가리키는 그림이 미리보기, PDF, 이미지 내보내기를 위해 다운로드되지 않으므로 그림을 호스팅하는 사이트가 아무것도 알 수 없습니다. 켜면 웹 브라우저처럼 가져오며 해당 사이트가 요청을 볼 수 있습니다. |
| **가능하면 상대 경로 사용** | 문서를 기준으로 한 상대 경로를 씁니다. |
| **상대 경로에 ./ 추가** | 상대 경로를 `./`로 시작합니다. |
| **삽입 시 이미지 URL 이스케이프** | 링크를 깨뜨릴 수 있는 주소의 문자를 이스케이프합니다. |

## 테마 및 배경

| 컨트롤 | 기능 |
| --- | --- |
| **앱 테마** | 앱과 편집기의 모양: **자동**, **라이트**, **다크**, 또는 추가한 테마. 라이트 또는 다크, 강조 색상, 사이드바와 막대, 편집기를 설정합니다. 자동은 시스템을 따릅니다. 렌더링 모드와 내보내기는 내보내기에서 선택하는 렌더링 테마를 사용합니다. |
| **인터페이스 크기**(iPad) | 메뉴, 막대, 사이드바, 대화상자의 크기: **시스템 크기**(iPad의 텍스트 크기를 따름), **한 단계 작게**, **두 단계 작게**, **세 단계 작게**. 편집기의 텍스트는 자체 크기가 있습니다. |
| **머리말의 메뉴**(iPad) | **자동**(키보드나 마우스가 연결되어 있으면 Pilcrow 자체 메뉴를 숨김), **항상**, 또는 **안 함**. |
| **확대/축소** | 편집기와 미리보기 크기: 50%, 67%, 80%, 90%, 100%, 110%, 125%, 150%, 175% 또는 200%. **보기 ▸ 확대**와 **축소**와 같습니다. |
| **읽기 속도** | 분당 단어 수로, 60에서 2,000까지이며 읽는 시간 추정에 사용됩니다. |

## 편집기 배경(백드롭)

편집기, 사이드바, 상태 표시줄 뒤에 그림이나 비디오를 둘 수 있습니다.

| 컨트롤 | 기능 |
| --- | --- |
| **미디어** | HEIC, PNG, JPEG 또는 SVG 그림이나 MP4, MOV 또는 M4V 비디오를 **선택…**합니다. **제거**는 지웁니다. |
| **배치** | **채우기**, **맞추기**, 또는 **바둑판식**. |
| **텍스트 영역 뒤**, **사이드바 뒤** | 각각 자체 **옅게**와 **흐림**이 있습니다. **옅게**는 텍스트를 읽기 쉽도록 그림을 테마의 배경색으로 덮고, **흐림**은 부드럽게 만듭니다. 상태 표시줄은 그림을 흐리게 합니다. |
| **배터리 사용 중에도 재생** | 배터리 전원으로도 비디오를 재생합니다. 비디오는 저전력 모드에서 일시 정지되고 동작 줄이기가 켜져 있으면 정지 상태로 유지됩니다. |
| **소리**, **음량** | 비디오는 소리를 켜지 않는 한 음소거로 재생됩니다. |

배경은 미리보기나 내보내기에 나타나지 않으며, 투명도 줄이기가 켜져 있으면 숨겨집니다.

# Chapter 70: 목차와 내보내기 기본값

## 목차 및 레이블

이 설정은 PDF, Word, HTML 등 모든 내보내기 형식에 적용됩니다.

| 컨트롤 | 기능 |
| --- | --- |
| **모든 내보내기에 목차 추가** | 각 내보내기 맨 위에 목차 목록을 넣습니다. |
| **[TOC] 줄을 목록으로 바꾸기** | `[TOC]`만 있는 줄이 미리보기와 모든 내보내기에서 제목 목록이 됩니다. |
| **제목 번호 매기기 (1., 1.1.)** | 출력에서 제목에 번호를 매깁니다. 아래의 제목 레이블은 단순 번호 매기기를 대체합니다. |
| **제목** | 목록의 이름으로, 예를 들어 "목차" 또는 "안내"입니다. 비워 두면 "목차"를 사용합니다. |
| **제목 나열 깊이** | 깊이이며 1에서 6까지입니다. 수준 1은 최상위 제목만 나열하고, 수준 6은 모두 나열합니다. |
| **들여쓰기** | 각 수준의 들여쓰기(포인트 단위)입니다. |
| **각 제목에서 목차 항목으로 돌아가는 링크 추가** | 제목에서 해당 항목으로 돌아가는 링크를 추가합니다. |
| **[TOC] 줄 아래의 제목만 나열** | `[TOC]` 줄 위의 제목은 제외합니다. |

### 제목 레이블

**제목에 레이블 붙이기**는 각 수준에 고유한 레이블을 붙입니다(예: "Part I -" 또는 "Chapter 3:"). 각 수준에는 템플릿이 있습니다. 템플릿에서 `#`는 다음 번호, `@`는 다음 대문자를 뜻하며, 레이블에는 둘 중 하나만 쓸 수 있고 둘 다 쓸 수는 없습니다. 더 얕은 제목이 나타날 때마다 다시 세기 시작하려면 `\#` 또는 `\@`로 쓰고, 그냥 쓰면 문서 전체에서 계속 셉니다. **글자**와 **0부터 9까지의 숫자**는 글자와 번호에 쓸 문자를 설정합니다. 마지막 글자 다음에는 글자가 두 개가 됩니다: Y, Z, AA, AB.

## 내보내기 기본값

| 컨트롤 | 기능 |
| --- | --- |
| **렌더링 테마** | 미리보기와 내보내기의 기본 테마입니다. |
| **포맷**, **파일 확장자**, **변환기** | 각 내보내기 형식에 대한 정보입니다. 모두 기본 제공 변환기로 생성됩니다. |
| **페이지** | 인쇄와 모든 PDF, PDF 보관용, Word 내보내기에 사용되는 용지 크기, 방향, 여백입니다(Chapter 64). |
| **머리글 템플릿**, **바닥글 템플릿** | 각 페이지의 위쪽과 아래쪽에 들어갈 텍스트입니다. 변수: `${title}`, `${author}`, `${pageNo}`, `${pageCount}`, `${today}`. 예를 들어 바닥글 `Page ${pageNo}`. |

# Chapter 71: 라이브러리

라이브러리는 추가한 테마, 구문 프로파일, 매크로, 스타일 가이드, 배경으로 구성됩니다. 기본 제공 항목은 읽기 전용이므로 변경하려면 복제하세요.

## 구문 프로파일

각 프로파일을 **기본 제공** 또는 **사용자화**로 나열합니다.

| 컨트롤 | 기능 |
| --- | --- |
| **가져오기…** | 다른 사람이 공유한 프로파일 `.json` 파일을 추가합니다. |
| **새로 만들기** | 처음부터 프로파일을 만듭니다. |
| **편집**, **복제**, 삭제 | 프로파일별 동작입니다. 기본 제공 프로파일은 복제할 수 있지만 편집하거나 삭제할 수 없습니다. |
| **로드되지 않음** | 로드하지 못한 프로파일이 이유와 함께 여기에 나열됩니다. 다른 프로파일이 이미 가진 파일 확장자를 사용하거나, 이 버전에서 읽을 수 없는 프로파일이거나, 편집기가 응답하지 않게 만들 수 있는 패턴이 들어 있는 경우입니다. 프로파일 폴더에는 그대로 남아 있습니다. |

프로파일 편집은 Chapter 74에 있습니다.

## CommonMark 옵션

선택 사항인 CommonMark 구문의 스위치입니다. 소스에서 사용하는 것만 켜세요.

| 섹션 | 컨트롤 |
| --- | --- |
| **구문 지원** | **강조 표시(==key==)**, **아래 첨자(H~2~O)**, **위 첨자(X^2^)**, **인라인 수식($…$)**. |
| **추가 구문** | **자동 링크(일반 URL)**, **GitHub 스타일 알림**, **YAML 프런트 매터**(맨 위의 `---` 줄 블록은 옅게 표시되며 미리보기와 모든 내보내기에서 제외됨), **다이어그램 및 차트(Mermaid, Vega-Lite)**. |
| **스마트 문장 부호** | **변환**: **입력 시 변환**, **렌더링 시 변환**, 또는 **끔**. 이어서 **스마트 따옴표**, **스마트 대시**, **스마트 말줄임표**. |
| **코드 펜스** | **줄 번호 표시**, **긴 줄 자동 줄 바꿈**, **들여쓰기 크기**(공백 수). |

포맷 ▸ 강조 표시, 아래 첨자, 위 첨자, 인라인 수식은 해당 옵션을 켤 때까지 회색으로 표시됩니다.

## 테마

테마 페이지에는 **앱 테마**(JSON: 앱의 라이트 또는 다크 모양, 강조 색상, 사이드바, 막대, 편집기)와 **렌더링 테마**(CSS: 미리보기, HTML, PDF, 이미지, 인쇄 출력, Word 스타일)가 나열됩니다. 각각 **기본 제공** 또는 **사용자화**로 표시되며 **라이트**, **다크**, 또는 **자동**이 함께 표시됩니다.

| 컨트롤 | 기능 |
| --- | --- |
| **새로 만들기** | 두 종류 중 하나의 테마를 만듭니다. |
| **테마 가져오기…** | `.json` 앱 테마, `.css` 렌더링 테마, 또는 둘 중 하나 또는 둘 다를 담은 `.zip` 패키지를 추가합니다. |
| **테마 폴더 열기** | 테마가 들어 있는 폴더를 표시합니다. |
| **편집**, **복제**, **내보내기**, 삭제 | 테마별 동작입니다. 기본 제공 테마는 읽기 전용입니다. |

테마 편집은 Chapter 75에 있습니다.

## 스타일 가이드

스타일 가이드를 규칙 수와 영역과 함께 나열합니다.

| 컨트롤 | 기능 |
| --- | --- |
| **스타일 가이드 가져오기…** | 가이드 `.json` 파일을 추가합니다. |
| 가이드의 메뉴 | **스타일 가이드 복제**, **스타일 가이드 내보내기…**, **스타일 가이드 삭제…**. 삭제하면 확인 후 이 기기에서 제거되므로 사본이 필요하면 먼저 내보내세요. |
| "다음을 기반으로 함 …" | 가이드는 다른 가이드를 기반으로 할 수 있습니다. 해당 가이드가 없으면 사용할 수 없습니다. |

스타일 가이드는 이름이 붙은 규칙으로 이루어진 `.json` 파일입니다. 어시스턴트에게 작성을 요청할 수도 있으며(**어시스턴트 ▸ 도움말 ▸ 스타일 가이드**), **도움말 ▸ 스타일 가이드**에서 형식을 설명합니다.

## 렌더링 라이브러리

수식, 다이어그램, 차트는 번들된 라이브러리가 이 기기에서 그립니다. 이 페이지는 각 라이브러리와 버전을 나열하며, 하나를 선택하면 번들된 고지 사항을 읽을 수 있습니다.

## 위치

라이브러리는 선택한 폴더 안의 "Pilcrow Library"라는 폴더에 있습니다. iCloud Drive의 폴더를 사용하면 기기 간에 동기화됩니다. 환경설정, API 키, 충돌 복구 사본은 항상 이 기기에 남습니다.

| 컨트롤 | 기능 |
| --- | --- |
| **보관 위치** | 라이브러리의 현재 위치: "이 기기" 또는 "*이름* 폴더". |
| **폴더 선택…** | 라이브러리를 폴더로 옮깁니다. 해당 폴더에 이미 Pilcrow 라이브러리가 있으면 Pilcrow는 둘을 병합하지 않으며, **있는 것 사용**을 선택할 수 있습니다. 그렇지 않으면 **내 라이브러리를 여기로 이동**(모든 파일을 확인한 다음 이전 사본을 제거) 또는 **내 라이브러리를 여기로 복사**(이전 사본을 유지)를 선택합니다. |
| **이 기기 사용** | 라이브러리를 이 기기로 되돌립니다. |

선택한 폴더에 접근할 수 없으면 Pilcrow는 당분간 이 기기의 라이브러리를 사용하며 아무것도 변경하거나 삭제하지 않고, 폴더를 다시 사용할 수 있게 되면 다시 사용합니다.

## 가져오기(iPad)

iPad에서 **가져오기**는 라이브러리에 항목을 추가합니다: **테마 가져오기…**, **구문 프로필 가져오기…**, **매크로 모음 가져오기…**, **스타일 가이드 가져오기…**. Mac에서는 **파일 ▸ 가져오기**를 사용하세요(Chapter 53).
