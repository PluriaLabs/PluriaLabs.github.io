# Chapter 72: 키보드

**설정 ▸ 키보드 ▸ 단축어**에는 단축키를 바꿀 수 있는 모든 명령이 현재 키와 함께 나열됩니다.

| 항목 | 기능 |
| --- | --- |
| 명령의 행 | 행을 클릭하고 새 단축키를 누른 다음 **저장**을 선택합니다. **할당 해제**는 단축키를 제거합니다. **취소**는 이전 단축키를 유지합니다. 단축키를 다른 명령이 사용 중이었다면 그 명령의 단축키는 지워지며, 페이지에 어떤 명령인지 표시됩니다. |
| **Super Tab 키** | 매크로가 남긴 빈칸 사이를 이동하는 **다음 필드**와 **이전 필드**의 키입니다. `⌥Tab`과 `⌥⇧Tab`, 또는 `⌃⌘]`와 `⌃⌘[`, 또는 **사용자화**를 선택할 수 있습니다. |
| **모든 단축키 재설정** | 모든 기본값을 복원합니다. |

변경할 수 있는 명령과 기본값은 다음과 같습니다.

| 명령 | 기본값 |
| --- | --- |
| 굵게 | `⌘B` |
| 강조 | `⌘I` |
| 인라인 코드 | `⌃`` ` `` |
| 인라인 수식 | `⌃M` |
| 취소선 | `⌃⇧`` ` `` |
| 하이퍼링크 | `⌘K` |
| 서식 지우기 | `⌘\` |
| 사이드바 가리기/보기 | `⇧⌘L` |
| 사이드바: 개요 | `⌃⌘1` |
| 열린 문서 | `⌃⌘2` |
| 사이드바: 파일 트리 | `⌃⌘3` |
| 사이드바: 검색 | `⇧⌘F` |
| 사이드바: 어시스턴트 | `⌃⌘4` |
| 위에 커서 추가 | `⌃⇧↑` |
| 아래에 커서 추가 | `⌃⇧↓` |
| 열에 커서 놓기… | `⌃⇧G` |
| 뒤로 가기 | `⌃⌘←` |
| 앞으로 가기 | `⌃⌘→` |
| 다음 항목 선택 | `⌃⌥D` |
| 모든 항목 선택 | `⌃⌥⇧D` |
| 다음 필드 | `⌥Tab` |
| 이전 필드 | `⌥⇧Tab` |
| 명령 팔레트… | `⌃⇧P` |
| 집중 모드 | 없음 |

저장, 찾기, 단락 항목처럼 이 목록에 없는 명령은 단축키가 고정되어 있습니다. 모든 단축키는 Chapter 77에 나와 있습니다.

# Chapter 73: 구독 및 크레딧

Pilcrow의 모든 기능은 무료입니다. Pilcrow 후원은 선택 사항이며, 개발 비용에 보탬이 되고 다음에 무엇을 만들지에 대한 투표권을 드립니다. 투표는 작업 순서를 정하는 데 참고가 되지만 어떤 기능도 약속하지는 않습니다.

**Pilcrow 후원하기** 페이지에는 다음이 있습니다.

| 부분 | 표시하거나 하는 일 |
| --- | --- |
| **내 투표권** | **구독에서**(이번 결제 월의 투표권과 만료 시점)와 **구매함**(만료되지 않는 투표권). 구독 투표권이 먼저 사용되며 결제 월이 끝나면 만료됩니다. |
| **투표권 받기** | 구독과 개별로 구매할 수 있는 투표권입니다. Pilcrow Supporter는 Apple 계정 설정에서 취소할 때까지 매월 갱신됩니다. 결제한 달마다 투표권이 주어집니다. |
| **구매 복원** | 다른 기기에서 한 구매를 되살립니다. |
| **이용 약관**, **개인정보 처리방침** | 링크입니다. |
| **앱 아이콘** | 구독자를 위한 앱 아이콘 선택 항목입니다. 투표 라운드용 아이콘은 그 라운드 중에 구독하면 얻을 수 있으며 계속 유지됩니다. Mac에서는 Pilcrow가 열려 있는 동안 Dock의 아이콘이 바뀝니다. |
| **로드맵** | 투표가 열려 있는 현재 라운드의 기능 목록으로, "투표"와 "내 투표" 수, 그리고 각 기능의 **투표** 버튼이 있습니다. 투표할 때마다 투표권 하나가 사용되며 되돌릴 수 없습니다. 라운드 사이에는 다음 라운드가 열리는 시점이 표시됩니다. |

특정 빌드에서 후원 옵션을 사용할 수 없으면 페이지에 그렇게 표시됩니다.
