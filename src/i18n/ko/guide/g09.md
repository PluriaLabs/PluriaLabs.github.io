# Chapter 65: 어시스턴트 패널과 스타일 검토

어시스턴트 패널은 **설정 ▸ 어시스턴트**에서 연결을 설정하면 나타납니다(Chapter 67). 준비된 연결이 없는 동안에는 보기 메뉴에 **어시스턴트** 항목이 없습니다.

## 패널

| 컨트롤 | 기능 |
| --- | --- |
| **도우미 모드** | **대화**, **스타일 검토**, 또는 **도움말**. |
| **모델 선택…** | 모델 선택기를 엽니다(아래 참조). 모델을 더 이상 사용할 수 없거나 지원이 중단된 경우 경고를 표시하며, 지원 중단일도 함께 표시합니다. |
| **대화 지우기** | 대화를 비웁니다. 대화는 저장되지 않으며 앱을 종료하면 삭제됩니다. |
| **공유할 내용** | 질문과 함께 보낼 내용을 선택합니다. **문서에서 아무것도 보내지 않음**, **선택**, **섹션**, **커서 주변**, **문서 전체**, **개요**, 또는 **프로파일**. 적용할 수 없는 선택 항목에는 이유가 표시됩니다("먼저 텍스트를 선택하세요.", "이 문서에는 제목이 없습니다.", "전체를 보내기에는 너무 큽니다.", "구문 프로파일이 없습니다."). 질문 입력란 위의 한 줄에는 어느 호스트로 얼마나 보내는지 표시됩니다. 선택한 내용은 기억됩니다. |
| **미리보기**(및 **전송되는 내용**) | 보낼 내용을 정확히 보여 줍니다. |
| **어시스턴트에게 질문…** / **작성하려는 내용을 설명하세요** | 질문 입력란입니다. **도움말** 모드에서는 **작성할 대상**에서 **구문 프로필**, **매크로**, 또는 **스타일 가이드**를 선택합니다. |
| **보내기** 및 **중지** | 요청을 보내거나, 진행 중인 답변을 중지합니다. |
| **개인정보 보호** | 이 폴더에서 어시스턴트가 켜져 있는지 표시합니다. **이 폴더에서 끄기**와 **이 폴더에서 켜기**로 전환합니다. 제외 패턴에 해당하는 파일에는 "이 파일은 어시스턴트에서 제외됩니다."라고 표시됩니다. |
| 각 답변 | **복사**, **커서 위치에 삽입**, **다시 시도**, 그리고 스타일 또는 매크로 답변에는 **보관함에 추가…**. 오류가 있는 답변에는 **수정 요청**이 표시됩니다. 중간에 끊긴 답변은 그렇다고 표시됩니다. |

## 모델 선택

**모델 선택…**은 연결에서 제공하는 모델을 **모델 검색**과 함께 나열합니다. **모든 모델 보기**에는 자주 쓰지 않는 모델도 포함됩니다. 지원이 중단된 모델에는 지원 중단일이 표시됩니다. 나열된 모델이 없으면 모델 이름을 직접 입력하세요. **다시 시도**는 목록을 다시 불러옵니다.

## 스타일 검토

**스타일 검토** 모드에서 패널은 작성한 글에 스타일 가이드를 적용합니다.

| 컨트롤 | 기능 |
| --- | --- |
| **스타일 가이드**, **변형** | 가이드와 그 변형 중 하나를 선택합니다. |
| **검토할 대상** | **선택** 또는 **문서**. 문서 전체를 검토하기에는 너무 큰 경우 "전체를 검토하기에는 너무 큽니다. 대신 섹션을 검토하세요."라고 표시됩니다. |
| **영역** | 검사할 영역을 선택하거나 **모든 영역**을 선택합니다. |
| **검토** | 텍스트와 규칙을 AI 연결로 보냅니다. 문서 전체를 검토하기 전에 경고창이 보낼 요청 수와 대략적인 텍스트 분량을 알려 주고 **검토** 또는 **취소**를 묻습니다. |
| **여기서 검사** | 가이드 자체의 검사를 이 기기에서 실행합니다. 아무것도 전송되지 않습니다. |
| **상호 참조 검사** | 문서의 한 부분을 다른 부분과 비교하는 규칙을 검사하기 위해 제목, 인용하는 줄, 참고 목록을 보냅니다. |
| **중지** | 진행 중인 검토를 중지합니다. **나머지 검토**는 중지되거나 실패한 뒤에 이어서 진행합니다. |

검토 결과는 목록으로 나타납니다. 각 항목에는 인용문, 설명, 그리고 있는 경우 수정 제안이 표시됩니다.

| 버튼 | 기능 |
| --- | --- |
| **이동** | 문서에서 해당 검토 결과의 위치로 이동합니다. 인용문이 여러 번 나오면 "N번째 일치 / 전체 N개"라고 표시됩니다. |
| **적용** | 제안된 수정을 적용합니다. 텍스트가 찾았을 때와 똑같은 경우에만 적용됩니다. 그렇지 않으면 "텍스트가 변경되었습니다." 또는 "텍스트에서 찾을 수 없습니다."라고 표시됩니다. |
| **닫기** | 검토 결과를 제거합니다. |
| **모두 적용** | 수정이 있는 모든 항목을 적용하며, 먼저 몇 개인지 알려 주는 확인 창이 나타납니다. 한 번에 실행 취소할 수 있는 하나의 변경으로 처리됩니다. AI에서 나온 수정이 몇 개인지도 알려 줍니다. |
| **모든 제안 무시**, **지우기** | 목록을 비웁니다. |

패널은 "검토를 통해서만 판단할 수 있는 규칙 N개", "검토 결과 100개에서 중단된 규칙 N개", "텍스트에 없는 사실을 추가했기 때문에 제안된 변경 하나를 제외했습니다."도 알려 줍니다.

# Chapter 66: 설정의 구성

설정은 Mac에서는 **Pilcrow ▸ 설정…**(`⌘,`)에서, iPad에서는 헤더의 톱니바퀴에서 엽니다. iPad에서는 **완료** 버튼이 있는 시트로 열립니다. 창에는 **설정 검색** 입력란과 왼쪽의 **카테고리** 목록이 있습니다. 각 카테고리에는 하나 이상의 **페이지**가 있으며, 맨 위에 버튼 막대로 표시됩니다.

| 카테고리 | 페이지 |
| --- | --- |
| **일반** | 언어 및 윈도우(iPad: **언어**), 파일, 번역, 어시스턴트, 진단, 저장 공간 및 개인정보 |
| **편집** | 화면 및 입력, 이미지 |
| **화면 모드** | 테마 및 배경, 텍스트 크기 및 글꼴 |
| **목차** | 목차 및 레이블 |
| **내보내기** | 내보내기 기본값 |
| **라이브러리** | 구문 프로파일, CommonMark 옵션, 테마, 매크로, 스타일 가이드, 렌더링 라이브러리, 위치(iPad에는 **가져오기**도 있음) |
| **키보드** | 단축어 |
| **구독 및 크레딧** | Pilcrow 후원하기 |

**설정 검색**은 이름으로 컨트롤을 찾습니다. "줄 간격"이나 "버전"처럼 레이블의 일부를 입력하면 결과에 컨트롤과 해당 페이지, 카테고리가 표시됩니다. 하나를 선택하면 바로 이동합니다. 변경 사항은 즉시 적용되며, 테마, 프로파일, 매크로, 키보드 단축어 편집기를 제외하면 저장 버튼이 없습니다.

한 대의 Mac 또는 한 대의 iPad에만 영향을 주는 설정은 해당 기기에 남습니다. 라이브러리(테마, 프로파일, 매크로, 스타일 가이드, 배경)는 iCloud Drive의 폴더를 포함해 원하는 폴더로 옮길 수 있습니다(Chapter 71).

## 파일

| 컨트롤 | 기능 |
| --- | --- |
| **시작할 때** | Pilcrow가 실행할 때 여는 항목: **새 파일 열기**, **마지막으로 닫은 폴더 복원**, **마지막으로 닫은 파일 및 폴더 복원**, 또는 **사용자 지정 폴더 열기**(**선택…** 버튼 포함). 복원하면 앱을 마지막으로 종료했을 때 화면에 있던 항목을 다시 엽니다. 이후에 이동했거나 삭제된 파일은 건너뜁니다. |
| **새 문서 저장 형식** | 새 문서의 파일 형식, 즉 구문 프로파일입니다. 각 프로파일이 확장자와 함께 표시됩니다(예: "CommonMark (.md)"). |
| **변경 사항 자동 저장** | 파일이 있는 문서를 작업하는 동안 저장합니다. |
| **파일을 닫을 때 묻지 않고 저장** | "저장하시겠습니까?"라는 질문을 건너뛰고 저장합니다. |
| **보관할 버전** | 버전 기록을 위해 Pilcrow가 파일마다 보관하는 저장 버전의 수로, 없음부터 500개까지입니다. 기본값은 50입니다. "보관할 버전: 없음"은 기록을 끕니다. |
| **최근 파일 및 폴더 기록** | **최근 사용**과 실행 시 복원을 위해 Pilcrow가 연 항목을 기억하게 합니다. |
| **숨겨진 폴더 및 파일 표시** | 이름이 점으로 시작하는 항목을 파일 패널에 표시합니다. |
| **앱에 무언가를 놓았을 때** | 편집기나 사이드바에 항목을 놓았을 때의 동작입니다. **폴더** 또는 **Markdown 파일**의 경우 **편집기에서 열기** 또는 **링크 삽입**, **가져올 수 있는 파일**(테마, 구문 프로필 또는 매크로 모음)의 경우 **편집기에서 열기**, **링크 삽입** 또는 **파일 가져오기**. |

## 번역

번역에는 macOS 15 또는 iPadOS 18 이상이 필요합니다.

| 컨트롤 | 기능 |
| --- | --- |
| **번역할 언어** | 기본 대상 언어입니다. 첫 번째 선택 항목은 "시스템 언어"입니다. |
| **속도** | **빠르게**, **최고 품질**, 또는 **AI 어시스턴트**. 빠르게는 긴 문서에 적합하며 약 스무 배 빠를 수 있지만 표현이 더 단순해집니다. macOS 또는 iPadOS 26.4가 필요합니다. **AI 어시스턴트**는 **설정 ▸ 어시스턴트**의 연결로 텍스트를 보냅니다. 서비스에 따라 요금이 부과될 수 있으며 텍스트가 기기를 벗어납니다. |
| **파일이 다른 언어일 때** | **아무것도 하지 않음**, **번역 제안**, 또는 **자동으로 번역**. Pilcrow는 파일을 열 때 파일의 언어를 판단하며, 이를 위해 기기 밖으로 전송되는 것은 없습니다. 번역 제안은 기본 언어로 번역할 수 있는 선택 항목이 있는 막대를 표시합니다. |
| **모든 파일에 다시 제안** | **이 파일에는 안 함**으로 설정한 파일을 초기화합니다. |
| **번역 후** | **새 탭에서 열기**, **원본 옆에 사본 저장**(원본 이름에 언어를 덧붙인 이름, 예: `Notes_fr.md`), 또는 **문서 바꾸기**(실행 취소 가능). |
| **이 기기의 언어** | 각 언어를 **이 기기**, **다운로드**, 또는 **사용할 수 없음**과 함께 나열합니다. 번역은 기기에 남아 있는 언어 팩을 사용합니다. 다운로드할 때 시스템에 권한을 요청하며, 제거는 시스템의 언어 설정에서 합니다. |

## 어시스턴트

| 컨트롤 | 기능 |
| --- | --- |
| **AI 어시스턴트 켜기** | 사이드바에 어시스턴트 패널을 추가합니다. 묻기 전에는 아무것도 전송되지 않으며, 공유하기로 선택한 텍스트만 전송됩니다. |
| 상태 표시줄 | **준비됨.**, 또는 그렇지 않은 이유: "활성 연결의 주소를 사용할 수 없습니다.", "활성 연결에 API 키가 필요합니다.", 또는 "아래에서 연결을 추가하세요. 연결이 준비되면 어시스턴트 창이 나타납니다." |
| **연결** | 연결 목록이며, 비어 있으면 "아직 연결이 없습니다."라고 표시됩니다. 각 연결에는 이름이 표시되고, 사용 중인 연결에는 **활성**이 표시됩니다. 행에는 **활성으로 설정**, **편집…**, **제거**가 있습니다. |
| **연결 추가** | 메뉴: **OpenAI**, **Anthropic**, **OpenRouter**, **Ollama (이 컴퓨터)**, **LM Studio (이 컴퓨터)**, 또는 **사용자 지정…**. |
| **제외된 파일** | 절대 공유하지 않을 파일의 패턴입니다. `*`는 이름 속 임의의 문자, `**`는 임의의 폴더를 뜻하고, `/`로 끝나는 이름은 폴더 전체를 포함합니다. 기본값에는 `*.pem`, `.env*`, `*.key`, `secrets/`가 있습니다. 패턴을 **추가**하거나, **제거**하거나, **기본값 복원**을 선택할 수 있습니다. |
| **꺼진 폴더** | 어시스턴트를 끈 폴더를 나열하며, 각각 **켜기**가 있습니다. 없으면 "꺼진 폴더가 없습니다."라고 표시됩니다. |
| **개인정보 보호** | Pilcrow의 개인정보 처리방침을 읽는 링크와 **모든 AI 데이터 삭제…**가 있습니다. 후자는 모든 연결과 저장된 키, 대화, 개인정보 보호 선택 사항을 제거하고 어시스턴트를 끕니다. 먼저 확인을 요청합니다. |

API 키는 이 기기의 키체인에만 저장됩니다.

| **형식** | **OpenAI 호환** 또는 **Anthropic**. |
| **주소** | 서비스의 웹 주소입니다. `https://`를 사용하세요. `http://`는 이 컴퓨터나 로컬 네트워크에만 사용합니다. |
| **내 로컬 네트워크에서 암호화되지 않은 연결 허용** | 네트워크의 `http://` 주소를 허용합니다. 텍스트와 키가 암호화되지 않은 채 전송되므로 네트워크를 신뢰할 때만 허용하세요. |
| **모델** | 사용할 모델이며, **선택…**으로 서비스의 목록에서 고를 수 있습니다. |
| **API 키 필요** 및 **API 키** | 서비스에 키가 필요한지 여부와 키 자체이며, 키체인에 보관됩니다. 편집할 때 비워 두면 저장된 키를 유지합니다. |
| **연결 테스트** | 주소, 키, 모델을 확인합니다. "테스트 중…"에 이어 "연결됨(N ms)."이라고 표시됩니다. |
| **취소**, **저장** | 연결을 닫거나 유지합니다. |

## 진단

| 컨트롤 | 기능 |
| --- | --- |
| **진단 로그 기록** | 문제가 생겼을 때 지원팀에 보낼 수 있도록 Pilcrow가 하는 일을 기록합니다. 공유하기 전까지는 기기에 남아 있으며, 문서 텍스트와 파일 이름은 제외하도록 만들어졌습니다. 켜져 있는 동안 상태 표시줄에 빨간 **로그 기록 중** 표시가 나타납니다. |
| **기록 중지 시간** | **1시간**, **24시간**, 또는 **안 함**. |
| **기록할 항목** | Pilcrow의 각 부분별 수준: **텍스트 편집기**, **매크로**, **테마**, **구문 분석 및 프로필**, **렌더링 및 다이어그램**, **내보내기 및 인쇄**, **파일 및 라이브러리**, **앱**. 각각 **문제만**, **보통**, **상세**, 또는 **모두**입니다. 문제와 오류는 항상 보관됩니다. |
| **문제 재현** | 모든 부분을 상세로 설정하고 기록을 시작합니다. 문제를 다시 일으킨 다음 보고를 완료하세요. |
| **로그 추가** | 버그를 보고할 때 로그의 최신 항목을 클립보드에 복사해 양식에 붙여 넣을지 설정합니다. **매번 묻기**, **항상 추가**, 또는 **추가 안 함**. |
| **버그 보고…** | **도움말 ▸ 버그 보고…**와 같습니다. |
| **보고서에 포함** | **기기 및 시스템 정보**, **Pilcrow 설정**, **문서 구조(개수만)**, **속도 및 메모리**, **최근 동작 기록**, **충돌 세부 정보**의 스위치입니다. 문서 구조는 문서에 제목, 표 등이 몇 개 있는지를 뜻하며 문서의 단어는 절대 포함되지 않습니다. 이 화면에서는 아무것도 전송되지 않습니다. |
| **로그 보기…** | 로그 뷰어를 엽니다(아래 참조). |
| **로그 지우기…** | 확인한 뒤 기록된 로그를 이 기기에서 영구적으로 삭제합니다. 기록을 꺼도 지울 때까지는 기록된 내용이 남아 있습니다. |

버그 보고를 위해 로그를 기록하는 동안에는 **재현 중 — 보고 완료**(또는 도움말 메뉴의 **버그 보고 완료**)가 기록을 중지하고 보고를 마칩니다. 이 경우 기록은 30분 후에 자동으로 중지됩니다.

### 로그 뷰어

**진단 로그**는 요약(**항목**, **세션**, **오류**, **경고**, **충돌 보고서**, 날짜 범위)을 표시하고, 이어서 최신순으로 항목을 표시하며 **로그 검색** 입력란과 **부분** 및 **수준** 필터가 있습니다. 필터는 보이는 내용만 바꾸며 전송되는 내용에는 영향이 없습니다. 보고서에는 로그의 모든 항목과 보고서에 포함 아래에서 선택한 내용이 들어갑니다. **다시 불러오기**는 새로 고칩니다. **보고서 보내기**는 다음을 제공합니다.

| 항목 | 기능 |
| --- | --- |
| **보고서 저장…** | 직접 보낼 수 있는 파일을 보관합니다. |
| **보고서 공유…** | 공유 시트(AirDrop, 파일 등)를 엽니다. |
| **GitHub에 보고…** | 짧은 요약이 담긴 새 이슈를 엽니다. **로그를 설명에 추가**(최신 항목을 GitHub가 허용하는 최대치인 60,000자까지 클립보드에 복사하여 붙여 넣음) 또는 **저장하고 파일 첨부**(전체 로그를 파일로 저장하여 직접 첨부)를 선택합니다. GitHub의 보고서는 공개됩니다. |

기록된 내용이 없을 때 보고를 시작하면 Pilcrow가 **먼저 문제를 기록할까요?**라고 묻습니다. **먼저 문제 기록**, **지금 보고**, 또는 **취소**. 양식을 열 때는 **로그 추가 후 양식 열기**, **항상 로그 추가**, 또는 **로그 없이 양식 열기**를 묻습니다.

## 저장 공간 및 개인정보

Pilcrow는 복구 사본, 기록, 접근 권한, 지원 데이터를 샌드박스 안에 보관합니다. 각 카테고리는 별도로 삭제할 수 있습니다. 이 컨트롤은 문서를 삭제하지 않습니다.

| 섹션 | 컨트롤 |
| --- | --- |
| **문서** | **복구 데이터 검토**와 **버전 기록 검토**. 검토는 해당 항목을 크기와 함께 나열하므로 삭제하기 전에 공간을 확인할 수 있습니다. 삭제할 항목을 선택하고(**모두 선택** 또는 **모두 선택 해제**) **선택 항목 삭제**를 선택합니다. 문서에 저장하지 않은 변경 사항이 있는 동안에는 복구 데이터를 검토할 수 없습니다. 먼저 저장하거나 닫으세요. |
| **파일 접근** | **최근 파일 접근 권한 지우기…**는 최근 파일 목록, 기억된 다른 이름으로 저장 폴더, 세션 북마크, 파일별 구문 선택을 제거합니다. |
| **개인 정보 및 지원 데이터** | **AI 데이터 및 키 삭제…**(연결, 키체인 키, 현재 대화, AI 개인정보 보호 선택), **진단 정보 삭제…**(기록된 로그와 저장된 충돌 진단), **캐시 비우기…**(다시 만들 수 있는 캐시 파일과 네트워크 응답). |

모든 삭제는 확인을 요청합니다("이 작업은 실행 취소할 수 없습니다. 문서는 삭제되지 않습니다."). 사용자 지정 구문 프로파일, 테마, 매크로, 스타일 가이드, 배경은 여기서 제거되지 않습니다. 각 라이브러리 페이지에서 검토하고 삭제하세요.
