# Chapter 81: 파일, 인코딩 및 제한

## Pilcrow가 여는 파일

Pilcrow는 일반 텍스트와 마크업 파일을 편집합니다. 일반적인 확장자는 `txt`, `md`, `markdown`, `adoc`, `asciidoc`, `rst`, `tex`이며, 추가한 프로파일이 사용하는 확장자도 포함됩니다. Pilcrow는 파일을 열 때 텍스트 인코딩을 자동으로 감지합니다.

| 항목 | 유형 |
| --- | --- |
| 구문 프로파일, 매크로 컬렉션, 스타일 가이드, 앱 테마 | `.json` |
| 렌더링 테마 | `.css` |
| 테마 패키지 | `.zip` |
| 책 프로젝트 매니페스트 | `manifest.pilcrow` |
| 배경 | HEIC, PNG, JPEG, SVG, MP4, MOV, M4V |
| 입력 소리 클립 | WAV, AIFF, MP3, M4A, CAF |

## 텍스트 인코딩

Pilcrow는 UTF-8, UTF-16, UTF-32, ISO 8859-1(Latin-1) 텍스트를 읽습니다. **문서 정보 ▸ 인코딩 ▸ 변환…**으로 문서를 다음 중 어느 것으로든 변환할 수 있으며, 파일은 다음에 저장할 때 변환됩니다.

UTF-8, UTF-8 (BOM), UTF-16 LE, UTF-16 LE (BOM), UTF-16 BE, UTF-16 BE (BOM), UTF-32 LE, UTF-32 LE (BOM), UTF-32 BE, UTF-32 BE (BOM).

Latin-1 파일은 이 중 어느 것으로든 손실 없이 변환할 수 있습니다. 내용이 손상될 수 있으므로 Latin-1로의 변환은 제공하지 않습니다.

## 내보내기 포맷

| 포맷 | 확장자 |
| --- | --- |
| HTML, HTML(스타일 없음) | `.html` |
| PDF | `.pdf` |
| Word (.docx) | `.docx` |
| 이미지 | `.png` |
| PDF 보관 파일 | `.zip` |

## 제한과 수치

Pilcrow가 멈추는 지점, 또는 선택에 범위가 있는 경우입니다.

| 위치 | 제한 |
| --- | --- |
| 검색 패널 | 일치 항목 500개에서 멈춥니다. |
| 미리보기 찾기 | 일치 항목을 최대 2,000개까지 셉니다. |
| 폴더에서 바꾸기 | 한 번에 최대 2,000개 파일을 변경합니다. |
| 링크 확인 | 최대 50,000개 링크를 확인합니다. |
| 비교 | 변경된 줄을 최대 5,000줄까지 보여 줍니다. |
| 보관할 버전 | 없음에서 500까지(기본값 50). |
| 긴 줄 | 20,000자 이상인 줄은 항상 줄바꿈됩니다. |
| 글꼴 크기 | 9에서 32포인트. |
| 탭 너비 | 공백 2개에서 8개. |
| 텍스트 너비 | 50%에서 100%. |
| 확대/축소 | 50%에서 200%, 10단계. |
| 읽기 속도 | 분당 60에서 2,000단어. |
| 탐색기 너비 | 180에서 420포인트. |
| 입력 소리 클립 | 최대 2초, 3 MB. |
| 진단 보고서 로그 텍스트 | GitHub 이슈 설명에 추가할 때 최신 항목부터 최대 60,000자. |
| 매우 큰 파일 | 메모리에 전체를 읽어 들이지 않고 열고 편집합니다. 줄 수와 단어 수, 개요는 백그라운드에서 완료되며 그때까지는 일부만 표시될 수 있습니다. 매우 큰 문서의 PDF 내보내기는 편집이나 HTML, Word 내보내기보다 훨씬 많은 메모리가 필요합니다. PDF 보관 파일은 이를 제한된 크기의 부분으로 나눕니다. |

## Pilcrow가 보관하는 위치

| 항목 | 위치 |
| --- | --- |
| 내 문서 | 저장한 곳 어디든. |
| 라이브러리(테마, 프로파일, 매크로, 스타일 가이드, 배경) | 앱의 비공개 저장 공간, 또는 선택한 폴더 안의 “Pilcrow Library”라는 폴더(**설정 ▸ 라이브러리 ▸ 위치**). |
| 환경설정, API 키, 복구본, 버전 기록 | 기기의 앱 비공개 저장 공간과 키체인. **설정 ▸ 일반 ▸ 저장 공간 및 개인정보**에서 확인하고 삭제할 수 있습니다. |
| 진단 로그 | 지우기 전까지 기기에 보관됩니다. |

# Chapter 82: 메시지, 배너 및 빈 상태

이 장에서는 Pilcrow가 보여 주는 짧은 메시지를 설명하여, 어느 것도 수수께끼로 남지 않도록 합니다.

## 편집기와 미리보기에서

| 메시지 | 의미 |
| --- | --- |
| **아직 미리 볼 내용이 없습니다. 쓰기 시작하면 여기에 나타납니다.**(또는 “편집으로 전환하여 쓰기를 시작하세요.”) | 문서가 비어 있어 미리보기에 그릴 내용이 없습니다. |
| **미리보기를 렌더링할 수 없습니다: …** — **소스 보기**와 **다시 시도** 포함 | 미리보기에 실패했습니다. **소스 보기**는 편집으로 전환합니다. **다시 시도**는 다시 시도합니다. |
| 실패한 수식이나 다이어그램, 그리고 **소스 보기** 링크 | 블록 하나를 그리지 못했습니다. **소스 보기**를 클릭하면 해당 블록의 소스로 이동하여 고칠 수 있습니다. |
| **저장할 수 없음** — **다시 시도**와 닫기 버튼 포함 | 저장에 실패했습니다. 문서는 저장되지 않은 채 열려 있습니다. 원인(디스크 공간, 권한, 이동된 파일)을 해결한 다음 **다시 시도**를 선택하세요. |
| **디스크에서 파일이 변경됨** | 다른 앱이 파일을 수정했습니다. **다시 불러오기**는 새 버전을 읽고, **현재 버전 유지**는 지금 가진 내용을 유지합니다. |
| **구문 분석 경고** | 의도와 다를 가능성이 큰 구문이 있는 줄입니다(Chapter 68). |
| **기존 파일을 바꿀까요?** | 선택한 이름이 그 위치에서 이미 사용 중입니다. |
| **채워야 할 필드가 남아 있습니다** | 채우지 않은 필드가 있는 상태로 인쇄하거나 내보내려 하고 있습니다(Chapter 63). |
| **창 구분선**(VoiceOver 힌트: “드래그하여 편집기와 미리보기의 크기를 조절합니다. 두 번 탭하면 초기화됩니다.”) | 나란히 보기에서 소스와 미리보기 사이의 핸들입니다. |
| **단어: N** | 상태 막대의 단어 수입니다. |

## 대화상자와 패널에서

| 위치 | 메시지 | 의미 |
| --- | --- | --- |
| 명령 팔레트 | **명령 입력** | 필드의 힌트입니다. 맞는 항목이 없으면 “일치하는 명령 없음”이 나타납니다. |
| 빠른 열기 | **파일 이름 입력** | 필드의 힌트입니다. |
| 열에 커서 놓기 | **줄(예: 3-17)**, **열(예: 100, 선택하려면 100-105)** | 필드 힌트입니다. 열 하나를 지정하면 커서가 놓이고, 범위를 지정하면 각 줄의 해당 문자가 선택됩니다. |
| 검색 패널 | **입력하여 이 폴더를 검색합니다.**, **이 폴더에 일치하는 항목이 없습니다.**, **검색이 취소되었습니다.** | 폴더 검색의 상태입니다. |
| 파일 패널 | **폴더를 여기에 끌어다 놓을 수도 있습니다.** | 폴더를 패널로 끌어다 놓으면 열립니다. |
| 폴더에서 바꾸기 | **바꿀 항목이 없습니다.** | 검색에 일치하는 항목이 없습니다. |
| 비교 | 버튼의 툴팁: **수락**(“이 변경 사항을 열린 문서에 적용합니다”), **거절**(“이 변경 사항을 열린 문서에서 제외합니다”), **되돌리기**(“이 변경 사항에 대해서만 이전 줄을 문서에 되돌려 놓습니다”). | 각 버튼의 동작입니다. |
| 번역 | **번역을 완료하지 못했습니다.** | 다시 시도하거나 다른 속도를 선택하세요. |
| 번역 | **예상 시간: 1분 미만** | AI 어시스턴트 속도에 대한 추정치이며, 실제 시간은 사용하는 AI 서비스에 따라 달라집니다. 번역이 끝나면 **새 탭에서 열기**로 결과를 엽니다. |
| 어시스턴트 | **열린 문서가 없습니다.**, **전송되는 문서 텍스트가 없습니다.** | 패널에 공유할 내용이 없으므로 아무것도 전송되지 않습니다. |
| 모델 선택기 | **모델 불러오는 중…**, **일치하는 모델이 없습니다.** | 목록을 불러오는 중이거나 검색 결과가 없습니다. |
| 스타일 검토 | **발견 사항이 없습니다.** 및 **응답을 발견 사항으로 읽을 수 없습니다. 다시 시도하세요.** | 검토에서 아무것도 발견하지 못했거나, AI의 응답이 예상한 형식이 아니었습니다. |
| 스타일 검토 | **모두 적용** 툴팁: “수정할 수 있는 항목을 모두 하나의 변경으로 적용하며, 실행 취소할 수 있습니다.” | 한 번의 실행 취소로 모두 되돌립니다. |
| 프로젝트 패널 | **이름**, **변수 추가** | 작성자 필드의 힌트, 그리고 프로젝트 변수를 추가하는 버튼입니다. |
| 어시스턴트 권한 | **Pilcrow 개인정보 처리방침 읽기** | 개인정보 처리방침을 엽니다. |

## 설정에서

| 위치 | 메시지 | 의미 |
| --- | --- | --- |
| 키보드 | **새 단축키를 누른 다음 저장을 클릭하세요.** 및 **아무 키나 누르세요…** | 단축키를 기록하는 동안 나타납니다. |
| 라이브러리 ▸ 위치 | **라이브러리 위치**, **라이브러리 이동 중…** | 페이지 제목, 그리고 라이브러리를 옮기는 동안의 진행 상태입니다. |
| 어시스턴트 연결 | **저장된 키를 유지하려면 비워 두세요.** | 편집할 때 키 필드를 비워 두면 키체인에 이미 있는 키가 유지됩니다. |
| 매크로 편집기 | **트리거 — 예: /sig** | 트리거 필드의 힌트입니다. |
| 프로파일 편집기 | **고급 프로파일 JSON**, **샘플 및 결과** | JSON 편집기의 제목, 그리고 샘플 테스트 아래에서 샘플이 만들어 내는 노드를 보여 주는 영역입니다. |
| 진단 | **모든 부분**(로그 뷰어에서), **일치하는 항목이 없습니다.** | 필터링하지 않은 로그, 그리고 아무것도 일치하지 않는 필터입니다. |
| 상태 막대 | 빨간색 **로그 기록 중** 표시와 그 툴팁 **진단 설정 보기** | 로그를 기록하는 중입니다. 클릭하면 진단 페이지로 이동합니다. **기록을 멈추고 버그 보고 완료**는 **재현 중 — 보고 완료**의 툴팁입니다. |
| 상태 막대 | **이 문서의 구문 프로파일 선택** | 구문 메뉴의 툴팁입니다. |
| 제목 컨트롤 | **열린 문서 및 문서 동작** | 문서 제목의 툴팁입니다. |
