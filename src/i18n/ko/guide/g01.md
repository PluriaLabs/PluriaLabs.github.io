# Pilcrow 사용 설명서

## 일반 텍스트를 쓰고, 정리하고, 검토하고, 게시하는 방법을 배우는 튜토리얼 과정

이 문서는 Mac과 iPad용 Pilcrow를 작업 중심으로 설명하는 결정판 안내서입니다. 튜토리얼 장은 버튼 목록이 아닙니다. 각 장은 얻고 싶은 결과에서 출발해 작업 과정을 차례로 따라가며, 왜 그렇게 선택하는지를 설명합니다. 끝부분의 참조 장은 반대로 앱의 모든 컨트롤을 하나씩 나열합니다.

Pilcrow는 프로필로 구문을 제어하는 전문가용 일반 텍스트 편집기입니다. 기본 제공 CommonMark 프로필을 사용할 수도 있고, Pilcrow에 다른 마크업 언어를 가르칠 수도 있으며, 매크로로 반복되는 텍스트를 자동화하고, 하우스 스타일에 맞춰 글을 검토하고, 같은 소스를 HTML, PDF, Word로 게시할 수 있습니다.

참조 장(XVI–XXI부)은 **2026년 11월 24일**의 앱을 기준으로 작성했습니다. 튜토리얼 장(I–XV부)은 2026년 11월 10일에 처음 작성했으며, 컨트롤 이름은 11월 24일에 다시 확인했습니다. 메뉴 이름은 Mac 인터페이스를 기준으로 설명합니다. iPad에서는 같은 명령이 대개 도구 막대나 **더 보기** 메뉴에 있습니다. 외장 키보드를 사용하면 대부분 같은 단축키를 쓸 수 있습니다.

고급이라고 명시한 장이 아니라면 프로그래밍 지식은 필요하지 않습니다.

---

## 이 안내서 사용법

처음이라면 I–III부를 순서대로 따라가세요. 문서를 만들고, 작업 공간을 익히고, 바탕이 되는 텍스트를 놓치지 않고 서식을 지정하고, 결과를 미리 보고, 안전하게 저장하는 방법을 배웁니다. 그다음에는 작업에 맞는 경로를 고르세요.

- 작가와 편집자: IV, V, VI, IX부.
- 연구자와 기술 문서 작성자: IV, VII, VIII부.
- 책 저자: X부.
- 자신만의 구문, 테마, 자동화를 만들려는 사람: XI–XIII부.
- 관리자와 개인정보에 민감한 사용자: XIV–XV부.
- 특정 메뉴 항목, 버튼, 설정, 대화상자를 찾아보려는 사람: 참조 장인 XVI–XXI부. 앱의 모든 컨트롤을 메뉴별, 페이지별로 설명합니다.

안내에서는 메뉴 경로를 **파일 ▸ 저장**처럼, 단축키를 `⌘S`처럼 표기합니다. “소스”는 직접 편집하는 일반 텍스트를 뜻합니다. “미리보기”는 렌더링된 읽기 전용 페이지를 뜻합니다. “라이브러리”는 프로필, 테마, 매크로, 스타일 가이드 및 관련 앱 데이터를 모아 둔 Pilcrow의 컬렉션을 뜻하며, 문서 폴더가 아닙니다.

# Part I — 글쓰기 시작

# Chapter 1: Pilcrow의 네 가지 구성 요소 이해하기

## 튜토리얼: 문장 하나를 소스에서 게시까지 따라가기

빈 문서를 만들고 다음을 입력하세요.

```text
# Field Notes

The river rose overnight.
```

이제 Pilcrow의 네 가지 독립된 부분이 함께 작동합니다.

1. **문서**는 일반 텍스트 파일입니다. 어떤 텍스트 편집기에서도 읽을 수 있습니다.
2. **구문 프로필**은 `# Field Notes`가 제목이라고 알려 줍니다. `.md` 파일에는 보통 CommonMark 프로필을 씁니다.
3. **앱 테마**는 앱과 편집기를 제어합니다. **렌더링 테마**는 미리보기와 내보내기를 제어합니다.
4. **매크로**를 사용한다면 날짜나 서명처럼 반복되는 텍스트를 삽입할 수 있습니다.

**미리보기**로 전환하세요. 맨 앞의 `#`가 진짜 제목이 됩니다. 프로필이 의미를 부여하고 렌더링 테마가 표현을 맡았기 때문입니다. **편집**으로 다시 전환하면 소스는 입력한 그대로입니다.

이러한 분리가 Pilcrow의 핵심입니다. 의미를 바꾸려면 프로필을, 게시되는 모양을 바꾸려면 렌더링 테마를, 글 쓰는 환경을 바꾸려면 앱 테마를 사용하세요. 단지 페이지 레이아웃을 흉내 내려고 소스에 공백이나 마크업을 더하지 마세요. 구조만 표현하고 표현 방식은 테마에 맡기세요.

# Chapter 2: 첫 문서 만들기, 열기, 저장하기

## 만들기와 저장

1. **파일 ▸ 새 문서**(`⌘N`)를 선택합니다.
2. 몇 줄을 입력합니다.
3. **파일 ▸ 저장**(`⌘S`)을 선택합니다.
4. 폴더와 파일 이름을 정합니다. CommonMark라면 `.md`처럼 원하는 구문에 맞는 확장자를 사용하세요.
5. 다시 변경한 뒤 저장해 보세요. 이제 Pilcrow가 위치를 묻지 않고 바로 저장합니다.

처음 저장하면 문서의 정체성, 폴더, 확장자가 정해집니다. 상대 링크와 이미지는 이 폴더를 기준으로 해석되므로 폴더가 중요합니다. 확장자는 Pilcrow가 적절한 구문 프로필을 고르는 데 도움이 됩니다.

## 기존 파일 열기

- Mac에서는 **파일 ▸ 파일 열기…**(`⌘O`)를 선택하거나, Finder에서 지원되는 텍스트 파일을 두 번 클릭하거나, 파일을 Pilcrow로 끌어다 놓으세요.
- iPad에서는 파일 선택기, 파일 앱, 공유 시트를 사용하세요. 제공자가 허용하면 Pilcrow가 선택한 파일을 그 자리에서 편집합니다.
- 관련 파일을 함께 작업하려면 **상위 폴더 탐색…**을 선택하거나 사이드바에서 폴더를 여세요.

Pilcrow는 일반 텍스트와 마크업 파일을 지원하며 텍스트 인코딩을 감지합니다. 다른 앱이나 클라우드 제공자가 넘겨준 파일은 계속 접근해야 할 수 있으므로, 열려 있는 동안에는 파일을 옮기거나 접근 권한을 취소하지 마세요.

## 다른 이름으로 저장과 이름 변경

**파일 ▸ 다른 이름으로 저장…**을 사용하면 다른 위치나 다른 인코딩으로 별도의 사본을 만듭니다. 현재 문서의 정체성은 유지한 채 이름만 바꾸려면 문서 제목 메뉴의 **이름 변경**을 사용하세요. 실험하기 전에는 원본이 그대로 남는 다른 이름으로 저장이 더 안전합니다.

## 안전하게 닫기

활성 문서를 닫으려면 **파일 ▸ 닫기**(`⌘W`)를, 모든 문서를 닫으려면 **모두 닫기**(`⇧⌘W`)를 선택하세요. 저장하지 않은 변경 사항이 있으면 Pilcrow가 저장할지, 버릴지, 취소할지 묻습니다. 열린 문서들의 이름이 비슷할 수 있으니 그 안내창의 파일 이름을 꼭 읽어 보세요.

# Chapter 3: 작업 공간 익히기

문서를 열고 다음 영역을 찾아보세요.

- **사이드바**는 사용할 수 있을 때 개요, 파일, 검색, 프로젝트, 어시스턴트 사이에서 바뀝니다.
- **문서 제목 컨트롤**은 활성 파일을 보여 주고 문서 전환기를 엽니다.
- **모드 컨트롤**은 편집, 미리보기, 나란히 보기 중에서 고릅니다.
- **편집기**는 기본 제공 텍스트 영역입니다. 거터에 줄 번호와 접기 컨트롤이 표시될 수 있습니다.
- 선택 사항인 **서식 도구 막대**는 프로필에 맞는 일반적인 서식 및 삽입 명령을 제공합니다.
- **상태 표시줄**에는 단어 수, 문자 수, 줄 수, 커서 위치, 인코딩, 프로필, 백그라운드 작업, 경고가 표시됩니다.

## 패널 전환 연습

1. **보기 ▸ 개요**를 선택해 활성 프로필의 제목을 확인합니다.
2. 다시 선택하면 그 패널이 숨겨집니다.
3. **보기 ▸ 파일 트리**를 선택해 열려 있는 폴더를 탐색합니다.
4. **보기 ▸ 검색**을 선택해 폴더 전체를 검색합니다.
5. 어시스턴트 연결이 있다면 **보기 ▸ 어시스턴트**를 선택합니다.
6. **보기 ▸ 사이드바 가리기/보기**를 사용해 사이드바 전체를 숨기거나 복원합니다.

같은 명령이 패널을 켜고 끕니다. 이미 표시된 패널을 다시 선택하면 사이드바가 숨겨집니다. 선택한 패널을 잃지 않고도 너비를 빠르게 되찾을 수 있습니다.

## 상태 표시줄 읽기

인코딩을 클릭하면 다음 저장 때 변환됩니다. 프로필 컨트롤을 클릭하거나 사용하면 문서를 해석하는 방식이 바뀝니다. **동기화 안 됨**, 구문 분석 경고, 오래 걸리는 작업 표시는 조치가 필요한 정보로 받아들이세요. 편집 보기와 문서 모델이 일치하지 않는다고 Pilcrow가 알리면, 계속하기 전에 사본을 저장하세요.

# Chapter 4: 여러 문서 함께 작업하기

파일을 둘 이상 여세요. 맨 위의 파일 이름을 클릭해 **열린 문서**를 열고 다른 문서를 선택합니다. 같은 메뉴에서 문서를 만들거나 저장하거나 이름을 바꾸거나 닫을 수도 있습니다.

다음 문서로는 `⌃Tab`을, 이전 문서로는 `⌃⇧Tab`을 사용하세요. 순환하는 대신 검색할 수 있는 목록이나 명시적인 목록이 필요하면 **보기 ▸ 열린 문서**를 선택하세요.

각 문서는 자신만의 커서, 선택 영역, 스크롤 위치, 모드, 프로필 선택, 찾기 상태를 유지합니다. 폴더 검색은 작업 공간 전체에 대한 작업이고, 문서의 찾기는 문서 하나에 속합니다. 탭을 많이 닫기 전에는 자동 저장이 이미 실행되었다고 가정하지 말고, 수정된 문서를 각각 저장하거나 안내창을 따르세요.

# Part II — 효율적으로 쓰기

# Chapter 5: 텍스트 이동, 선택, 편집

Pilcrow는 플랫폼의 텍스트 시스템을 사용하므로 일반적인 커서 이동, 끌어서 선택, 복사, 잘라내기, 붙여넣기, 시스템 입력 방식이 모두 평소처럼 작동합니다.

## 유용한 단위 선택하기

**편집 ▸ 선택**을 사용하면 현재 단어, 줄, 단락을 선택할 수 있습니다. 맨 위, 맨 아래, 줄의 시작, 줄의 끝으로 이동할 수도 있습니다. 화면에서 줄 바꿈된 줄과 실제 파일의 줄이 다를 때 이런 의미 단위 명령이 유용합니다.

기본 단축키로는 단어 선택에 `⌘D`, 줄 선택에 `⌘L`, 단락 선택에 `⌥⌘P`가 있습니다. `⌃A`와 `⌃E`는 줄의 시작과 끝으로 이동합니다.

## 의도에 맞게 복사하고 붙여넣기

- **Markdown으로 복사**는 유용한 소스 마크업을 보존합니다.
- **일반 텍스트로 복사**는 가능한 한 구조 마크업을 제거합니다.
- **HTML 코드로 복사**는 HTML 소스를 클립보드에 넣습니다.
- **일반 텍스트로 붙여넣기**(`⇧⌘V`)는 클립보드의 리치 서식을 버립니다.

붙여넣을 대상에 맞는 형태를 고르세요. 브라우저나 워드 프로세서의 글을 소스로 가져올 때는 일반 텍스트가 가장 안전합니다. 렌더링된 구조를 웹 작업 흐름에 넘길 때는 HTML 코드가 유용합니다.

## 실행 취소와 다시 실행

`⌘Z`와 `⇧⌘Z`를 사용하세요. 선택한 비교 변경, 다중 커서 서식, 번역 대체 같은 복잡한 동작은 한 번의 실행 취소 단계가 되도록 설계되어 있습니다. 큰 작업 후 결과가 잘못되었다면 바로 실행 취소하세요. 관련 없는 편집이 뒤에 쌓일수록 복구가 어려워집니다.

# Chapter 6: 찾기, 바꾸기, 탐색

## 소스에서 찾기

1. **편집 ▸ 찾기 ▸ 찾기…**(`⌘F`)를 선택합니다.
2. 검색어를 입력합니다.
3. 필요하면 대소문자 구분, 단어 단위, 정규식을 켭니다.
4. 다음 일치 항목은 Return 또는 `⌘G`, 이전 일치 항목은 `⇧⌘G`로 이동합니다.
5. 하나 또는 모든 일치 항목을 바꾸려면 편집 모드에서 바꿀 텍스트를 입력합니다.

정규식은 강력하지만 문자 그대로의 검색이 검증하기 더 쉽습니다. 캡처 그룹을 사용할 때는 모두 바꾸기 전에 결과 하나로 먼저 테스트하세요.

## 미리보기에서 찾기

미리보기에서는 찾기가 소스 마크업이 아니라 렌더링된 단어를 검색합니다. 모든 일치 항목이 강조 표시되고 현재 항목은 구별되게 표시됩니다. 미리보기는 편집할 수 없으므로 바꾸기는 할 수 없습니다. 서식으로 나뉜 일치 항목이나 코드, 다이어그램, 수식 안의 텍스트는 나타나지 않을 수 있습니다. 문자 그대로의 소스를 검색하려면 편집으로 전환하세요.

나란히 보기에서는 찾기가 소스를 검색하고 그에 대응하는 렌더링된 일치 항목을 강조 표시합니다.

## 줄과 열로 이동

**편집 ▸ 줄로 이동…**(`⌃G`)을 선택하세요. 120번째 줄은 `120`, 120번째 줄의 8번째 열은 `120:8`로 입력합니다. 문서 범위를 벗어난 값은 마지막 유효한 위치로 조정됩니다. 줄 수는 화면에서 줄 바꿈된 줄이 아니라 파일의 줄을 기준으로 셉니다.

## 뒤로 가기와 앞으로 가기

검색 결과, 링크, 멀리 떨어진 위치를 열었을 때 **뒤로 가기**와 **앞으로 가기**로 이동 경로를 되짚을 수 있습니다. 이것은 실행 취소와 별개입니다. 이동 기록은 어디를 보는지를 바꿀 뿐 문서 내용은 바꾸지 않습니다.

# Chapter 7: 다중 커서와 열 편집 사용하기

## 반복되는 항목 편집

1. 단어를 선택합니다.
2. **다음 항목 선택**을 반복해서 선택해 일치하는 선택 영역을 추가합니다.
3. 한 번만 입력합니다. 선택된 모든 항목이 같은 트랜잭션으로 바뀝니다.
4. 필요하면 한 번 실행 취소합니다.

**모든 항목 선택**은 검색어가 충분히 구체적인지 확인한 뒤에만 사용하세요. 짧은 단어는 의도하지 않은 곳과도 일치할 수 있습니다.

## 세로로 커서 추가

한 줄에 커서를 놓고 **위에 커서 추가** 또는 **아래에 커서 추가**를 선택하세요. 대상 행마다 커서가 생길 때까지 계속합니다. 입력, 삭제, 지원되는 서식은 모든 커서에 적용됩니다.

## 열에 커서 놓기

**열에 커서 놓기…**를 선택하고, 줄 범위와 열을 지정하고, 배치를 미리 본 뒤 확인하세요. 직사각형 모양으로 이어진 여러 줄에 접두사를 추가할 때 이상적입니다. 짧은 줄은 보이지 않게 채워지지 않고 안전하게 조정됩니다.

열 선택은 배지로 표시됩니다. Escape를 누르거나 한 곳을 클릭하면 다중 커서 편집이 끝납니다. 되돌리기 어려운 명령을 실행하기 전에 문서에서 모든 커서를 확인하세요.

커서가 여러 개일 때 Pilcrow는 스마트 쌍, 목록 이어가기, 둥근 따옴표 치환을 의도적으로 끕니다. 키를 한 번 누르면 모든 커서에 문자 하나가 그대로 삽입됩니다. iPad에서는 외장 키보드나 **더 보기 ▸ 열에 커서 놓기…**를 사용하세요. 터치로 열을 끌어 선택하려면 **더 보기 ▸ 열 선택**을 켜고 손가락 하나로 끄세요. 손가락 두 개는 여전히 스크롤합니다. 트랙패드나 마우스에서는 Option을 누른 채 끕니다. 끌기는 현재 편집기에 로드된 줄에만 적용할 수 있습니다.

# Chapter 8: 줄, 대소문자, 삭제 명령 실행하기

원하는 줄을 선택한 다음 줄 작업 명령으로 다음을 할 수 있습니다.

- 오름차순 또는 내림차순 정렬.
- 줄 순서 뒤집기.
- 중복된 줄 제거.
- 빈 줄 제거.
- 줄 끝 공백 제거.
- 줄 합치기.
- 행을 위나 아래로 이동(`⌥⌘↑`와 `⌥⌘↓`).

대문자, 소문자, 첫 글자 대문자로 바꾸려면 대소문자 변환을 사용하세요. 끌어서 선택하는 것보다 의미 단위가 편할 때는 단어 삭제, 줄 삭제, 단락 삭제를 사용하세요.

선택 영역이 범위를 결정합니다. 유용한 선택 영역이 없으면 일부 명령은 현재 줄이나 단락에 적용됩니다. 대규모 정리를 하기 전에는 먼저 저장해서 버전 기록에 이전 상태가 남게 하고, 작업을 하나씩 실행하며 결과를 확인하세요.

# Chapter 9: 명령 팔레트 사용과 단축키 사용자화

편집 또는 탐색 명령에서 **명령 팔레트…**를 여세요. “접기”, “내보내기”, “커서”처럼 동작의 일부를 입력하면 메뉴를 뒤지지 않고 바로 실행할 수 있습니다. 메뉴 깊이와 화면 너비가 제한된 iPad에서 특히 유용합니다.

단축키를 바꾸려면 다음과 같이 하세요.

1. **설정 ▸ 키보드 ▸ 단축어**를 엽니다.
2. 동작을 검색하거나 필터링합니다.
3. 해당 단축키를 선택하고 새 조합을 누릅니다.
4. 충돌이 보고되면 해결한 뒤 저장합니다.
5. 할당하고 싶지 않은 동작에는 **할당 해제**를 사용합니다.

Super Tab에 필드 탐색 방식이 제공되면 하나를 고르세요. 기본값으로 돌아가려면 **모든 단축키 재설정**을 사용하세요. Pilcrow는 지원되는 변경 사항을 즉시 적용하므로 다시 실행할 필요가 없습니다.

생산성 향상이 분명하지 않다면 운영 체제의 관례를 덮어쓰지 마세요. 관련 명령은 체계적으로 유지하세요. 예를 들어 다음과 이전은 보조 키 하나만 다르게 합니다.

# Part III — 구조와 미리보기

# Chapter 10: 활성 프로필로 텍스트 서식 지정하기

서식 명령은 활성 구문 프로필이 정의한 일반 텍스트 표시를 씁니다. 리치 텍스트를 몰래 저장하지 않습니다.

## 튜토리얼: 짧은 메모에 서식 지정하기

1. `.md` 문서에 제목과 단락을 입력합니다.
2. 제목에 커서를 놓고 **포맷**에서 제목 수준을 선택합니다.
3. 구절을 선택하고 **굵게**(`⌘B`) 또는 **강조**(`⌘I`)를 선택합니다.
4. 기술 용어를 선택하고 인라인 코드를 선택합니다.
5. 두 줄을 글머리 기호 목록이나 번호 목록으로 바꿉니다.
6. 미리보기로 전환해 구조를 확인합니다.

명령을 사용할 수 없다면 활성 프로필에 그 구조를 쓰는 방법이 선언되어 있지 않거나 미리보기가 활성 상태인 것입니다. 문서가 실제로 다른 구문을 사용할 때만 프로필을 바꾸세요. 그렇지 않으면 기존 표시가 예기치 않게 다르게 해석될 수 있습니다.

단락 명령에는 프로필이 지원하는 경우 제목, 목록, 인용 블록, 코드 블록, 표, 알림, 가로줄, 링크, 참조, 각주, 목차 마커, YAML 머리말이 포함됩니다. 인라인 명령에는 굵게, 강조, 취소선, 코드, 링크, 이미지, 하이라이트, 아래 첨자, 위 첨자 및 그 밖에 선언된 역할이 포함됩니다.

블록 역할을 제거하려면 **단락**을, 선택한 인라인 내용을 일반 단락 텍스트에 가깝게 되돌리려면 **서식 지우기**를, 프로필의 제목 계층을 오르내리려면 **제목 수준 높이기** 또는 **제목 수준 낮추기**를 사용하세요. 목록은 순서 없는 목록, 순서 있는 목록, 작업 목록 형식을 지원합니다. **작업 상태 전환**은 현재 작업을 체크하거나 해제하고, **들여쓰기**와 **내어쓰기**는 중첩 수준을 바꿉니다. 기본 단락 단축키로는 `⌘0`부터 `⌘6`, 순서 없는 목록 `⌥⌘U`, 순서 있는 목록 `⌥⌘O`, 작업 목록 `⌥⌘X`, 인용 블록 `⌥⌘Q`, 코드 블록 `⌥⌘C`가 있습니다.
