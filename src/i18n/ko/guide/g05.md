# Part XVI — 창과 메뉴 참조

# Chapter 52: 한눈에 보는 창

이 장에서는 Mac과 iPad에서 Pilcrow 창에 있는 모든 컨트롤을 왼쪽에서 오른쪽 순서로 설명합니다. 이 부분의 이어지는 장에서는 각 메뉴 항목을, XVII부에서는 각 패널과 대화상자를 설명합니다.

## 머리말 막대

머리말은 창 맨 위를 가로지릅니다. 컨트롤은 다음 순서로 있습니다.

| 컨트롤 | 위치 | 기능 |
| --- | --- | --- |
| **탐색기** (사이드바 아이콘) | Mac 및 iPad | 사이드바를 보이거나 숨깁니다. 툴팁은 "Show or hide navigator"로 표시됩니다. **보기 ▸ 사이드바 가리기/보기**와 같습니다. |
| **문서 제목** | Mac 및 iPad | 현재 문서의 이름을 표시하며, 저장 여부를 알려 주는 점이 함께 있습니다. 클릭하면 문서 전환기와 문서 동작이 열립니다(59장). |
| **메뉴 버튼** 또는 메뉴 스트립 | iPad 전용 | 키보드나 마우스가 없는 iPad를 위해 머리말 안에 표시되는 Mac의 메뉴입니다(58장). |
| **문서 모드** (편집, 미리보기, 분할) | Mac 및 iPad | 소스, 렌더링된 페이지, 둘을 나란히 보기 사이를 전환합니다. "분할"은 **나란히 보기**입니다. |
| **찾기** (돋보기) | Mac 및 iPad | 찾기 막대를 엽니다(62장). |
| **내보내기** (공유 아이콘) | Mac 및 iPad | 내보내기 패널을 엽니다(64장). |
| **설정** (톱니바퀴) | iPad 전용 | 시트에서 설정을 엽니다. Mac에서는 설정이 **Pilcrow** 메뉴(**⌘,**)에 있습니다. |
| **더 보기** (점 세 개) | Mac 및 iPad | 막대에 다 들어가지 않는 동작이 모여 있습니다. 아래를 참조하세요. |

찾기, 내보내기, 모드 컨트롤은 문서가 열려 있는 동안에만 나타납니다.

### 머리말이 너비에 맞춰 바뀌는 방식

머리말은 다른 앱 옆에 배치한 Mac 창이나 Split View의 iPad처럼 좁은 창에서도 쓸 수 있게 만들어졌습니다. 창이 좁아지면 컨트롤이 다음 순서로 **더 보기** 메뉴로 이동합니다.

| 창 너비 | 보이는 항목 |
| --- | --- |
| 720포인트 이상 | 편집/미리보기/분할 컨트롤, **찾기**, **내보내기**, **더 보기**. |
| 600~719 | **찾기**가 **더 보기**로 이동합니다. |
| 500~599 | **내보내기**도 **더 보기**로 이동합니다. |
| 500 미만 | 모드 컨트롤이 현재 모드를 아이콘으로 보여 주는 단일 버튼(연필, 눈, 또는 두 개의 창)으로 바뀝니다. 클릭하여 선택합니다. |

iPad에서는 580포인트 미만에서 모드 컨트롤이 간단한 버튼으로 바뀝니다. 제목은 항상 가장 먼저 줄어들며 너비 140~520포인트 사이에서 줄어들므로 버튼은 제자리에 있습니다. 접근성 텍스트 크기를 크게 하면 위의 창 너비를 먼저 1.3으로 나누므로, 창이 아직 더 넓은 상태에서도 컨트롤이 **더 보기**로 이동합니다.

### 더 보기 메뉴

**더 보기**에 나타나는 항목은 모드와 플랫폼에 따라 다릅니다. 소스가 보일 때(편집 또는 나란히 보기)만 표시되는 항목은 아래에 표시되어 있습니다.

| 항목 | 나타나는 때 | 기능 |
| --- | --- | --- |
| **찾기…** | 막대에 찾기 버튼이 없을 때만 | 찾기 막대를 엽니다. |
| **바꾸기…** | 소스가 보일 때 | 바꾸기 필드와 함께 찾기를 엽니다. |
| **줄로 이동…** | 소스가 보일 때 | 특정 줄 또는 줄과 열로 이동합니다. |
| **열에 커서 놓기…** | iPad, 소스가 보일 때 | 번호를 지정해 열을 따라 커서를 놓습니다(63장). |
| **열 선택** | iPad, 소스가 보일 때 | 스위치입니다. 켜져 있는 동안 손가락 하나로 드래그하면 텍스트의 사각형 영역이 선택됩니다. |
| **공유…** | 문서가 열려 있을 때 | 시스템 공유 시트를 통해 문서 파일을 공유합니다. |
| **내보내기…** | 막대에 내보내기 버튼이 없을 때만 | 내보내기 패널을 엽니다. |
| **집중 모드** | 항상 | 집중 모드를 켜고 끄는 스위치입니다(아래). |
| **제목 접기**, **렌더링된 블록**, **섹션 자동 펼치기**, **표식 숨기기**, **스타일 적용 소스**, **서식 도구 막대** | 소스가 보일 때 | 보기 메뉴와 같은 화면 표시 스위치입니다(55장). **표식 숨기기**는 **스타일 적용 소스**가 켜져 있지 않으면 회색으로 표시됩니다. |
| **파일 열기…**, **폴더 열기…** | iPad | 사이드바가 닫혀 있을 때 파일이나 폴더를 엽니다. |
| **프린트…** | iPad | 렌더링된 문서를 프린트합니다. |
| **설정…**, **도움말** | iPad | 설정 또는 앱 내 도움말을 엽니다. |

## 작업 영역

머리말 아래에는 편집기, 미리보기 또는 둘 다 있습니다. 편집기 아래에는 켜져 있을 때 **서식 도구 막대**와 **상태 막대**가 있습니다(61장). 편집기와 사이드바 뒤에 **배경** 그림이나 비디오를 둘 수 있습니다(69장).

**나란히 보기**에서는 소스가 미리보기 옆에 놓이며 함께 스크롤됩니다. 창 구분선을 드래그할 수 있고 위치는 기억됩니다. 창 너비가 520포인트보다 좁으면 두 창이 대신 위아래로 쌓입니다. 사이드바를 열면 문서에 남는 공간이 640포인트 미만이 될 때는 사이드바가 문서를 좁히는 대신 문서를 덮습니다.

## 사이드바(탐색기)

사이드바에는 **파일**, **개요**, **검색**, **프로젝트**, **어시스턴트**가 표시될 수 있습니다(60장). 가장자리를 드래그하면 180~420포인트 너비 사이에서 크기를 조절할 수 있습니다. 500포인트보다 좁은 창에서는 사이드바가 전체 너비를 채우며 **완료** 버튼으로 닫습니다.

## 집중 모드

**집중 모드**는 텍스트 외의 모든 것을 숨깁니다. **보기 ▸ 집중 모드**, **더 보기 ▸ 집중 모드** 또는 명령 팔레트에서 켭니다. 켜져 있는 동안 **집중 모드 종료** 버튼이 나타나므로 키보드 없이도 나갈 수 있습니다. 집중 모드는 항상 긴 줄을 줄 바꿈하며, 설정의 텍스트 열과는 별도로 자체 텍스트 열이 있습니다. 기본 단축키는 없으며 **설정 ▸ 키보드**에서 지정합니다.

## 문서가 없을 때

아무것도 열려 있지 않으면 창에 "Start a document"라는 제목 아래 **새 문서**와 **파일 열기…**가 표시됩니다. iPad에서는 **폴더 열기…**가 **더 보기**에 있습니다.

Pilcrow가 시작될 때 이전 세션에서 저장하지 않은 작업을 발견하면 대신 **문서 복구** 목록을 표시합니다. 복구 방식은 17장을 참조하세요. 이 목록에서는 각 항목에 대해 **복구**와 **삭제**를, 목록 전체에 대해 **모두 복구**와 **모두 삭제**를 사용할 수 있습니다. 저장한 적 없는 문서는 삭제하면 되돌릴 수 없으므로 **모두 삭제**는 먼저 확인을 요청합니다. 문서 하나짜리 배너의 **닫기** 버튼은 해당 항목의 복구를 거절합니다.

큰 파일을 여는 동안 창에는 진행 표시와 함께 "Opening *name*…"이 표시됩니다.

# Chapter 53: 파일 메뉴

Mac에서는 이 항목들이 **파일** 메뉴에 있습니다. iPad에서는 머리말의 **메뉴 ▸ 파일**에 있거나, **⌘**를 길게 누르거나 포인터를 화면 위쪽으로 옮기면 나타나는 메뉴 막대에 있습니다. "Mac 전용"으로 표시된 항목은 iPad에는 없습니다.

| 항목 | 단축키 | 기능 |
| --- | --- | --- |
| **새로 만들기** (iPad: **새 문서**) | `⌘N` | 제목 없는 문서를 만듭니다. 열린 문서에 추가됩니다. |
| **열기…** (iPad: **파일 열기…**) | `⌘O` | 디스크에서 텍스트 또는 마크업 파일을 엽니다. |
| **최근 사용** (Mac 전용) | | 최근에 연 파일을 나열합니다. **메뉴 지우기**는 목록을 비웁니다. 목록이 비어 있으면 "No Recent Documents"가 표시됩니다. |
| **빠르게 열기…** (Mac 전용) | `⇧⌘O` | 열려 있는 폴더의 파일 이름을 검색합니다. 폴더가 열려 있지 않으면 회색으로 표시됩니다. |
| **폴더 열기…** (iPad 머리말 메뉴 및 더 보기) | | 사이드바에서 폴더를 엽니다. Mac에서는 사이드바 자체의 **폴더 열기** 버튼을 사용하세요. |
| **상위 폴더 탐색…** | | 열려 있는 파일이 들어 있는 폴더를 탐색할 권한을 요청합니다. Pilcrow의 샌드박스는 파일 하나만 열며, 이 항목은 그 폴더를 추가합니다. 폴더가 이미 열려 있거나 문서에 파일이 없으면 회색으로 표시됩니다. |
| **새 책…** | | 매니페스트가 포함된 책 프로젝트 폴더를 만듭니다(34장). |
| **폴더를 책 프로젝트로 만들기** | | 열려 있는 폴더에 `manifest.pilcrow`를 쓰고 **프로젝트** 패널을 표시합니다(34장). 폴더가 열려 있지 않거나 폴더에 이미 매니페스트가 있으면 회색으로 표시됩니다. |
| **문서 닫기** (iPad: **닫기**) | `⌘W` | 현재 문서를 닫으며, 저장하지 않은 변경 사항이 있으면 먼저 묻습니다. 설정이 맨 앞에 있을 때 `⌘W`는 대신 설정을 닫습니다. |
| **모두 닫기** (iPad) | `⇧⌘W` | 모든 문서를 닫으며, 저장하지 않은 문서마다 묻습니다. Mac에서는 제목 메뉴에 **모든 문서 닫기**가 있습니다. |
| **저장** | `⌘S` | 문서를 저장합니다. 새 문서는 저장할 위치를 묻습니다. |
| **모두 저장** (Mac 전용) | `⌥⌘S` | 저장하지 않은 변경 사항이 있는 모든 문서를 저장합니다. 해당하는 문서가 없으면 회색으로 표시됩니다. |
| **복제** (Mac 전용) | `⇧⌘S` | 사본을 만들어 원본 옆에 엽니다. 원본은 변경되지 않습니다. |
| **다른 이름으로 저장…** | `⌥⇧⌘S` | 새 이름이나 위치로, 또는 다른 인코딩으로 저장합니다. 이후 문서는 새 파일이 됩니다. |
| **이동…** (Mac 전용) | | 저장 패널(버튼 이름은 **이동**)을 통해 디스크의 파일을 이동하거나 이름을 변경하며, 문서는 열린 채로 유지됩니다. |
| **버전 기록…** | | 문서의 저장된 버전을 엽니다(17장 및 63장). |
| **파일과 비교…** | | 문서를 다른 파일과 비교하며, 각 변경 사항을 수락하거나 거부할 수 있습니다(18장). |
| **디스크에서 다시 불러오기** (Mac 전용) | | 다른 앱이 파일을 변경했을 때 사용하며 디스크에서 파일을 다시 읽습니다. 저장하지 않은 변경 사항이 있으면 먼저 묻습니다. **Save, Then Reload**, **Reload Without Saving**, **취소** 중에서 선택합니다. 파일이 없는 문서에서는 회색으로 표시됩니다. |
| **Finder에서 보기** (Mac 전용) | | Finder에서 파일을 표시합니다. |
| **가져오기** (Mac 전용) | | 하위 메뉴: **테마…**, **구문 프로파일…**, **매크로 모음…**, **스타일 가이드…**. 각각 파일을 라이브러리에 추가합니다(43장). iPad에서는 가져오기가 **설정 ▸ 라이브러리 ▸ 가져오기**에 있습니다. |
| **내보내기…** | `⇧⌘E` | 내보내기 패널을 엽니다(64장). |
| **공유…** | | 문서 파일을 공유합니다. |
| **원고 컴파일…** | | 책 프로젝트를 컴파일합니다(36장). 책 프로젝트가 로드될 때까지 회색으로 표시됩니다. |
| **페이지 설정…** (Mac 전용) | | 용지, 방향, 여백을 설정하며, PDF 내보내기와 같은 설정입니다. |
| **프린트…** | `⌘P` | 렌더링된 문서를 프린트합니다. 문서에 채우지 않은 채우기 필드가 있으면 Pilcrow가 먼저 경고합니다. |

# Chapter 54: 편집 메뉴

편집 메뉴에는 시스템의 표준 명령과 Pilcrow 고유의 명령이 많이 들어 있습니다. 선택, 줄, 커서에 관한 메뉴 항목은 소스에서 작동하므로 미리보기에서는 회색으로 표시됩니다.

## 실행 취소, 클립보드, 붙여넣기

| 항목 | 단축키 | 기능 |
| --- | --- | --- |
| **실행 취소**, **다시 실행** | `⌘Z`, `⇧⌘Z` | 편집 내용을 뒤로 또는 앞으로 이동합니다. |
| **잘라내기**, **복사**, **붙여넣기**, **삭제**, **모두 선택** | | 시스템 명령입니다. |
| **Markdown으로 복사** | `⇧⌘C` | 선택 영역을 Markdown 소스로 복사합니다. |
| **일반 텍스트로 복사** | | 가능한 경우 구조 마크업을 제거하고 선택 영역을 복사합니다. |
| **HTML 코드로 복사** | | 선택 영역의 렌더링된 HTML을 텍스트로 복사합니다. |
| **일반 텍스트로 붙여넣기** | `⇧⌘V` | 클립보드의 서식 없이 붙여넣습니다. |

## 찾기

**찾기**는 하위 메뉴입니다.

| 항목 | 단축키 |
| --- | --- |
| **찾기…** | `⌘F` |
| **바꾸기…** | `⌘R` |
| **다음 찾기** | `⌘G` |
| **이전 찾기** | `⇧⌘G` |

## 맞춤법 및 문법

iPad에서는 이 하위 메뉴에 설정과 같은 스위치인 **입력하는 동안 맞춤법 검사**만 있습니다. iPad 텍스트 보기에는 맞춤법 패널이 없으므로 나머지 두 항목은 Mac 전용입니다.

| 항목 | 단축키 | 기능 |
| --- | --- | --- |

## 변환 및 음성

| 항목 | 기능 |
| --- | --- |
| **대문자로 변환**, **소문자로 변환**, **첫 글자 대문자로** | 선택 영역 또는 커서가 있는 단어의 대소문자를 바꿉니다. |

## 선택

선택하고 이동하는 여러 방법이 모인 하위 메뉴입니다.

| 항목 | 단축키 | 기능 |
| --- | --- | --- |
| **단어 선택** | `⌘D` | 커서가 있는 단어를 선택합니다. |
| **줄 선택** | `⌘L` | 화면에서 줄 바꿈된 줄이 아니라 파일의 줄 전체를 선택합니다. |
| **단락 선택** | `⌥⌘P` | 단락을 선택합니다. |
| **맨 위로 이동**, **맨 아래로 이동** | `⌘↑`, `⌘↓` | 커서를 문서의 시작 또는 끝으로 옮깁니다. |
| **줄 시작으로 이동**, **줄 끝으로 이동** | `⌃A`, `⌃E` | 줄의 양쪽 끝 중 하나로 이동합니다. |
| **위에 커서 추가**, **아래에 커서 추가** | `⌃⇧↑`, `⌃⇧↓` | 위 또는 아래 줄에 커서를 하나 더 추가합니다(7장). |
| **다음 항목 선택** | `⌃⌥D` | 선택한 텍스트의 다음 일치 항목을 추가합니다. |
| **모든 항목 선택** | `⌃⌥⇧D` | 일치하는 모든 항목을 한 번에 선택합니다. |
| **다음 필드**, **이전 필드** | `⌥Tab`, `⌥⇧Tab` | 매크로가 남긴 채우기 필드 사이를 이동합니다(24장). 설정에는 이를 위한 키 쌍을 고르는 항목인 Super Tab 키가 있습니다. |
| **열에 커서 놓기…** | `⌃⇧G` | 번호를 지정해 열을 따라 커서를 놓는 시트를 엽니다. |

커서, 일치 항목, 필드, 명령 팔레트의 단축키는 **설정 ▸ 키보드**에서 변경할 수 있습니다.
