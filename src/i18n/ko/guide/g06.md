## iPad 메뉴 스트립

iPad에는 자체 메뉴 막대가 있으며, **⌘**를 길게 누르거나 포인터를 화면 위쪽으로 옮기면 나타납니다. 같은 정의에서 가져온 Mac 메뉴와 같은 명령을 같은 재지정 가능한 단축키와 함께 제공합니다. Mac의 파일 메뉴는 AppKit 패널을 사용하므로 **파일**만 다릅니다.

키보드나 마우스가 없는 iPad에서는 Pilcrow가 같은 메뉴를 머리말에 표시할 수 있습니다. **설정 ▸ 화면 모드 ▸ 머리말의 메뉴**에서 선택합니다.

| 선택 | 효과 |
| --- | --- |
| **자동** | 키보드나 마우스가 연결되어 있지 않으면 메뉴를 표시합니다. |
| **항상** | 항상 표시합니다. |
| **안 함** | 표시하지 않습니다. |

너비가 1,100포인트 이상인 창에서는 여섯 개의 메뉴 **파일**, **편집**, **삽입**, **포맷**, **보기**, **도움말**이 나란히 놓입니다. 더 좁은 창에서는 하나의 **메뉴** 버튼으로 합쳐집니다. 이 스트립은 메뉴 막대의 간략한 버전입니다.

- **파일**은 일반 항목에 **폴더 열기…**, **내보내기…**, **프린트…**를 더합니다.
- **편집**에는 **실행 취소**, **다시 실행**, 복사 명령, **찾기**, **맞춤법 및 문법**, **선택**, **번역**, **줄로 이동…**, **링크 확인…**, **명령 팔레트…**, **뒤로 가기**, **앞으로 가기**가 있습니다.
- **포맷**에는 인라인 스타일, **단락** 하위 메뉴, **표 삽입…**, **이미지 삽입…**이 있습니다.
- **보기**에는 **서식 도구 막대**, **사이드바 가리기/보기**, **개요**, **파일**, **검색**, 문서 모드, **집중 모드**, **줄 번호**, **현재 줄 밑줄**, **스타일 적용 소스**, **제목 접기**, **열린 문서**가 있습니다. 다른 화면 표시 스위치는 **더 보기** 또는 설정을 사용하세요.
- **도움말**에는 **Pilcrow 도움말**, **버그 보고…**, **버그 보고 완료**가 있습니다.

# Chapter 59: 문서 제목과 문서 전환기

## 저장 점

이름 옆의 점은 문서의 상태를 한눈에 알려 줍니다. 이 상태는 VoiceOver도 소리 내어 읽어 줍니다.

| 점 | 의미 |
| --- | --- |
| 초록색 | **저장됨.** 디스크의 파일이 화면에 보이는 내용과 일치합니다. |
| 황색 | **편집됨.** 아직 저장하지 않은 변경 사항이 있습니다. |
| 빨간색 | **저장 실패.** Pilcrow가 저장을 시도했으나 할 수 없었습니다. **Couldn't save** 배너와 **다시 시도** 버튼이 편집기 위에 나타납니다. |
| 파란색 | **다른 앱에서 변경됨.** 디스크의 파일이 Pilcrow 밖에서 변경되었습니다. |

저장한 적 없는 문서는 표시할 폴더가 없으므로 목록에 "Not yet saved"와 번호가 표시됩니다. 저장하지 않은 변경 사항이 있는 문서는 행 끝에 **편집됨**도 표시됩니다.

## 열린 문서 목록

| 부분 | 기능 |
| --- | --- |
| **열린 문서 검색** | 문서가 일곱 개 이상 열려 있을 때 나타납니다. 이름이나 폴더의 일부를 입력하면, 각 단어가 이름이나 폴더 어딘가와 일치해야 하며 대소문자와 악센트는 무시됩니다. Return을 누르면 첫 번째 일치 항목이 열립니다. 일치하는 것이 없으면 "No open documents match."라고 표시됩니다. |
| 문서마다 하나의 행 | 이름, 저장 점, 문서가 있는 폴더를 표시합니다. 체크 표시는 현재 문서를 나타냅니다. 행을 클릭하면 그 문서로 전환합니다. |
| **닫기** (행 끝의 **x**) | 해당 문서를 닫으며, 저장하지 않은 변경 사항이 있으면 먼저 묻습니다. |
| **새 문서** | 제목 없는 문서를 만듭니다. |
| **저장** | 현재 문서를 저장합니다. |
| **다른 이름으로 저장…** | 새 이름이나 위치로 저장합니다. |
| **이름 변경…** | 이름 변경 양식을 엽니다(아래). |
| **모든 문서 닫기** | 모든 문서를 닫으며, 저장하지 않은 문서마다 묻습니다. |

목록을 열지 않고 다음 또는 이전 문서로 이동하려면 `⌃Tab`과 `⌃⇧Tab`을 사용하세요.

## 이름 변경

**이름 변경…**은 현재 **이름**과 파일이 있는 **위치**를 **취소** 및 **이름 변경** 버튼과 함께 표시합니다. 이름을 바꾸면 디스크의 파일이 변경되며 문서는 열린 채로 유지됩니다. 새 이름을 사용할 수 없으면 **문서 이름을 변경할 수 없음** 메시지가 이유를 설명합니다.
