# Chapter 60: 사이드바

사이드바에는 **파일**, **개요**, **검색**, **프로젝트**, **어시스턴트**의 다섯 패널이 있습니다. 사이드바 맨 위의 스위치로 **파일**, **개요**, **프로젝트**(열린 폴더가 책 프로젝트일 때 표시됨), **어시스턴트**(연결을 설정하면 표시됨) 중에서 고릅니다. **검색**에는 별도의 머리글이 있어 제목 **찾기**, 파일로 돌아가는 **완료** 버튼, **이 문서** 또는 **폴더**를 고르는 범위 컨트롤이 보입니다. **보기 ▸ 검색**(`⇧⌘F`)으로 엽니다. **보기** 메뉴에서도 패널을 전환할 수 있으며, 이미 표시 중인 패널을 선택하면 사이드바가 숨겨집니다. 사이드바의 가장자리를 드래그하면 크기를 조절할 수 있습니다. 파일 트리 위의 메뉴에서는 **파일 열기…**와 **폴더 열기…**를 제공합니다.

## 파일

파일 패널은 열린 폴더를 트리로 보여 줍니다.

폴더가 열려 있지 않으면 "폴더를 선택하여 파일을 탐색하세요."라고 표시하고 **폴더 열기**와 **파일 열기**를 제공합니다. 폴더를 이 패널에 끌어다 놓을 수도 있습니다. Pilcrow가 폴더를 볼 수 없는 단일 파일을 열었을 때는 "이 문서 옆의 파일을 보려면 *폴더* 탐색"이라고 표시하며 **상위 폴더 탐색…**을 제공합니다.

파일을 클릭하면 열립니다. 폴더는 펼치거나 접을 수 있습니다. 행을 오른쪽 클릭하거나(iPad에서는 길게 누르기) 메뉴가 나타납니다.

| 항목 | 기능 |
| --- | --- |
| **새 파일** | 폴더에(또는 클릭한 파일 옆에) 파일을 만듭니다. |
| **새 폴더** | 그 위치에 폴더를 만듭니다. |
| **이름 변경…** | 파일이나 폴더의 이름을 바꿉니다. |
| **휴지통으로 이동** | 확인 후 휴지통으로 옮깁니다. 휴지통에서 되돌릴 수 있습니다. |
| **Finder에서 보기** | Finder에서 표시합니다(Mac). |

시스템에 해당 위치의 휴지통이 없는 경우, Pilcrow는 삭제한 항목을 패널 아래쪽의 **최근 삭제된 항목** 섹션에 보관합니다. 그곳의 각 항목에는 **되돌려 놓기**와 **영구적으로 삭제**가 있고, **최근 삭제된 항목 비우기**는 그 섹션의 항목을 모두 완전히 지웁니다. 영구 삭제는 취소할 수 없으므로 Pilcrow가 먼저 확인합니다. 다른 위치에서 삭제한 항목은 영향을 받지 않습니다.

숨겨진 폴더와 파일은 **설정 ▸ 파일 ▸ 숨겨진 폴더 및 파일 표시**로 표시하거나 숨깁니다.

## 개요

개요는 활성 문서의 제목을 수준별로 들여 써서 나열합니다. 제목을 클릭하면 그 위치로 이동합니다. 제목 옆의 쉐브론은 그 아래에 포함된 제목을 접거나 펼칩니다. 이는 문서를 변경하지 않으며, 접힌 상태는 저장되지 않습니다.

볼 수 있는 상태는 다음과 같습니다.

| 메시지 | 의미 |
| --- | --- |
| **제목 없음** | 활성 프로파일에서 제목을 찾지 못했습니다. |
| **개요 색인 생성 중… N%** | 큰 문서를 아직 검사하고 있습니다. |
| **개요 색인 생성에 실패했습니다. 목록이 불완전할 수 있습니다.** | 검사 중 문제가 발생했습니다. |
| **현재 위치 근처의 제목 N개 — 다른 제목을 보려면 스크롤하세요.** | 매우 큰 문서에서는 캐럿 주변의 개요 일부만 표시합니다. |

개요 아래에는 문서에 채워야 할 필드가 있으면 **필드** 섹션이 나타납니다(Chapter 24). 개수와 함께 필드를 나열하며, 하나를 클릭하면 그 위치로 스크롤하여 선택합니다. 필드가 매우 많으면 "처음 일부 필드만 나열됩니다."라고 표시합니다.

## 검색

검색 패널은 열린 폴더의 모든 파일을 검색합니다. 폴더가 없으면 "검색하려면 폴더를 여세요."라고 표시하고 **폴더 열기…** 버튼을 제공합니다.

| 컨트롤 | 기능 |
| --- | --- |
| **폴더 검색** 필드 | 입력하는 동안 검색합니다. **지우기** 버튼으로 비웁니다. |
| **Aa** | **대소문자 구분**. |
| **ab** | **단어 단위**. |
| **.\*** | **정규식**. 잘못된 패턴은 필드 아래에 표시됩니다. |
| 상태 줄 | **취소** 버튼과 함께 "검색 중…"을 표시한 뒤 "일치: N"을 표시합니다. 검색은 500개 일치에서 멈추며 "처음 500개 일치를 표시합니다."라고 알려 줍니다. 취소한 뒤에는 **다시 검색**을 제공합니다. |
| **바꾸기…** | 검색에서 일치 항목을 찾으면 나타납니다. 폴더에서 바꾸기를 엽니다(Chapter 63). |
| 결과 | 각 결과에는 파일 이름과 해당 줄이 표시됩니다. 하나를 클릭하면 그 줄에서 파일이 열립니다. |

## 프로젝트

프로젝트 패널은 책 프로젝트용입니다. Chapter 34, Chapter 35 및 아래의 프로젝트 패널 참조를 보세요.

### 프로젝트 패널 참조

| 부분 | 기능 |
| --- | --- |
| **이 폴더는 책 프로젝트가 아닙니다.**와 **프로젝트로 만들기** | 열린 폴더에 매니페스트가 없을 때 표시됩니다. |
| **다시 시도** | 프로젝트를 읽을 수 없을 때 표시됩니다. |
| **보기** | **목록**, **줄거리**, **카드** 중에서 고릅니다. |
| 제목, 단어 합계 | 프로젝트 이름과 "N 단어", 또는 책 목표 단어 수가 설정된 경우 "N / 목표"입니다. |
| **상태** 필터 | 하나의 상태만 보거나 **모든 상태**를 봅니다. 집계에는 각 상태의 파일 수와 단어 수가 나열됩니다. 순서 변경은 필터가 활성화되지 않은 동안에만 가능합니다. |
| **프로젝트 설정**(톱니바퀴) | 아래의 설정 시트를 엽니다. |
| **컴파일…** | 컴파일 시트를 엽니다(Chapter 64). |
| **순서 변경**과 **완료** | iPad에서 장을 드래그하여 새 순서로 정렬한 뒤 **완료**를 선택합니다. |
| **새 파일**(더하기) | **새 장**, **새 장면**, **새 앞부분**, **새 뒷부분**을 제공합니다. |
| **원고에 없음**과 **추가**, **모두 추가** | 폴더에 있지만 매니페스트에 포함되지 않은 파일을 나열합니다. |
| 행의 쉐브론 | 장 아래의 **장면 보기** 또는 **장면 숨기기**. |
| **없음** 및 **제외됨** 태그 | 찾을 수 없는 파일, 또는 원고에서 제외한 파일입니다. |
| 행의 메뉴 | **세부 정보…**, **아래에 새 파일**, **장 위로 이동**, **장 아래로 이동**, **원고에 포함**, **원고에서 제외**. |
| 항목별 **목표 단어 수** | 각 항목에 단어 수와 설정된 목표가 표시됩니다. |

항목의 **세부 정보**에는 **종류**(앞부분, 부분, 장, 장면, 뒷부분), **상태**, **시점**, **위치**, **목표 단어 수**, **줄거리**가 있습니다. 프로젝트 파일이 디스크에서 변경되면 "프로젝트 파일이 디스크에서 변경되어 마지막 변경 사항이 적용되지 않았습니다. 다시 시도하세요."라고 표시하며 **닫기**를 제공합니다.

**프로젝트 설정**에는 **제목**, **작성자**, **책 목표 단어 수**, **새 파일 작성 형식**(새 장과 장면의 구문이며, 기존 파일은 그대로 유지됨), **변수**(이름과 값이며 본문에 `{{name}}`으로 씁니다. `{{title}}`과 `{{author}}`는 항상 사용할 수 있음), **단어로 세는 항목**(**제목 포함**, **앞부분 포함**, **코드 블록 포함**)이 있습니다. **저장** 또는 **취소**를 선택합니다.

## 어시스턴트

# Chapter 61: 서식 도구 막대와 상태 표시줄

## 서식 도구 막대

서식 도구 막대는 텍스트 아래에 표시되는 선택 사항 행입니다. **보기 ▸ 서식 도구 막대**, **더 보기 ▸ 서식 도구 막대**, **설정 ▸ 편집 ▸ 서식 도구 막대**, 또는 도구 막대 자체의 **도구 막대 가리기** 항목으로 표시하거나 숨깁니다. 활성 프로파일을 통해 동작하므로, 프로파일에서 표현할 수 없는 버튼은 흐리게 표시됩니다.

| 컨트롤 | 기능 |
| --- | --- |
| **단락 유형** 메뉴(예: "단락" 또는 "제목 1") | 현재 줄의 유형을 표시하고 바꿉니다. **단락**, **제목 1**부터 **6**, **인용**, **글머리 기호 목록**, **번호 매기기 목록**, **작업 목록**, **코드 블록**. |
| **굵게**(`⌘B`) | 굵은 글씨. |
| **기울임꼴**(`⌘I`) | 강조. |
| **인라인 코드** | 코드. |
| **링크 삽입**(`⌘K`) | 링크를 만듭니다. |
| **인용** | 인용을 전환합니다. |
| **글머리 기호 목록** | 글머리 기호 목록을 전환합니다. |
| **추가 서식**(**⋯**) | 자주 쓰지 않는 명령: **취소선**, **인라인 수식 삽입**, **작업 목록 삽입**, **작업 상태 전환**, **들여쓰기**, **내어쓰기**, **제목 수준 높이기**, **제목 수준 낮추기**, **표 삽입…**, **이미지 삽입…**, **다이어그램 삽입**, **차트 삽입**, **별행 수식 삽입**, **코드 펜스 삽입**, **알림 삽입**, **가로줄 삽입**, **링크 참조 삽입**, **각주 삽입**, **목차 삽입**, **YAML 머리말 삽입**, 그리고 **도구 막대 가리기**. |

## 상태 표시줄

상태 표시줄은 아래쪽을 따라 표시됩니다. **설정 ▸ 편집 ▸ 상태 표시줄 표시**로 켜거나 끕니다.

| 부분 | 표시하거나 하는 일 |
| --- | --- |
| **단어**, **줄**, **열** | 단어 수와 캐럿의 줄 및 열입니다. 선택 영역이 있으면 선택한 줄과 문자 수를 "Sel: N ln · N ch"로 덧붙입니다. |
| **구문** 메뉴(예: "CommonMark") | 이 문서의 프로파일입니다. 클릭하여 다른 것을 고르거나, 일반 텍스트에는 **구문 없음**을 고릅니다. |
| **남은 필드: N** | 매크로가 채워야 할 필드를 남겼을 때 표시됩니다. 클릭하면 다음 필드로 이동합니다. |
| 진행 및 상태 | 큰 파일을 분석하는 동안의 **색인 생성 N%**, **구문 분석 N%**, 번역이 실행되는 동안의 **번역 중 N%**와 **약 N 남음** 및 **번역 취소** 버튼. |
| **동기화 안 됨** | 편집기와 문서의 변경 로그가 어긋났다는 경고입니다. 저장해도 파일은 저장되지 않은 것으로 표시되어 아무것도 잃지 않습니다. 텍스트를 안전한 곳에 복사한 뒤 문서를 닫았다가 다시 여세요. |
| 문서 정보 | 개수를 클릭하거나 툴팁 "문서 정보 표시"를 클릭하면 **문서 정보**가 열립니다. |

**문서 정보**에는 **단어**, **문자**, **줄**, **읽기 시간**(설정의 읽기 속도 기준), **커서**, **선택**, **인코딩**, **구문**이 나열됩니다. 매우 큰 파일에서는 색인 생성이 끝날 때까지 개수가 불러온 부분에 대한 값이고, 읽기 시간은 파일 전체를 기준으로 추정합니다. **인코딩** 아래의 **변환…**으로 다른 텍스트 인코딩을 고르며, 파일은 다음에 저장할 때 변환됩니다.


# Chapter 62: 찾기, 바꾸기, 줄로 이동, 빠르게 열기, 명령 팔레트

## 찾기 막대

**찾기…**(`⌘F`), **찾기** 버튼, 또는 **바꾸기…**(`⌘R`)로 엽니다. 문서 맨 위에 표시됩니다.

| 컨트롤 | 기능 |
| --- | --- |
| **문서에서 찾기** 필드 | 찾을 텍스트를 입력합니다. 입력하는 동안 일치 항목이 강조 표시됩니다. |
| **Aa**, **ab**, **.\*** | **대소문자 구분**, **단어 단위**, **정규식**. |
| **이전 일치**, **다음 일치** | 일치 항목을 차례로 이동합니다(`⇧⌘G`, `⌘G`). |
| **바꾸기 표시** / **바꾸기 가리기**(쉐브론) | **바꿀 내용** 필드를 표시합니다. |
| **바꾸기**, **모두 바꾸기** | 현재 일치 항목 또는 모든 일치 항목을 바꿉니다. 일치 항목이 생기기 전에는 흐리게 표시됩니다. |
| **검색 범위**(막대 왼쪽 끝의 스위치) | **이 문서**, 또는 열린 폴더 전체를 검색하는 **폴더**. |
| **찾기 막대 닫기** | 막대를 닫습니다. |

Pilcrow가 세는 것보다 일치 항목이 많으면 막대에 "일치 항목이 더 있습니다"라고 표시합니다. **미리보기**에서 찾기는 렌더링된 단어를 훑어 최대 2,000개까지 강조 표시합니다. 사용할 수 없는 패턴에는 "잘못된 패턴"이라고 표시합니다. 바꾸기는 편집에서만 가능합니다. 미리보기에서는 막대에 "바꾸기는 편집에서 작동합니다. 텍스트를 변경하려면 편집으로 전환하세요."라고 표시합니다. **나란히 보기**에서는 찾기가 원본을 검색하고 미리보기에서 일치하는 단어를 강조 표시합니다.

## 줄로 이동

**줄로 이동…**(`⌃G`)은 "줄 번호 또는 줄:열" 필드 하나가 있는 작은 시트를 엽니다. `120` 또는 `120:8`을 입력하고 **이동**을 선택하거나 **취소**를 선택합니다. 끝을 넘는 번호는 마지막 줄로 이동합니다. 그 밖의 입력에는 Pilcrow가 "120 또는 120:8과 같은 줄 번호를 입력하세요."라고 알려 줍니다. 줄 수를 아직 세고 있는 매우 큰 파일에서는 잠시 후 다시 시도하라고 안내합니다.

## 빠르게 열기

**빠르게 열기…**(`⇧⌘O`)는 열린 폴더 전체에서 파일 이름을 검색합니다. 이름의 일부를 입력하면 목록이 좁혀지고 "N개 일치"가 표시됩니다. 결과를 고르고 **열기**를 선택하거나 **취소**를 선택합니다. 열린 폴더가 없으면 흐리게 표시됩니다.

## 명령 팔레트

**명령 팔레트…**(`⌃⇧P`)는 Pilcrow의 명령을 이름과 단축키와 함께 나열하므로, 메뉴를 찾지 않고도 명령을 실행할 수 있습니다. 입력하여 목록을 좁히고, 명령을 고른 뒤 **실행**을 선택하거나 **취소**를 선택합니다. 맞는 것이 없으면 "일치하는 명령 없음"이라고 표시합니다. 미리보기에서의 소스 편집처럼 지금 실행할 수 없는 명령은 흐리게 표시됩니다. 목록에는 서식 및 삽입 명령, 선택·줄·대소문자에 관한 편집 명령, 음성, 보기 전환, 확대/축소, 사이드바 패널, 그리고 파일 및 내보내기 동작이 포함됩니다. 팔레트를 여는 단축키는 **설정 ▸ 키보드**에서 변경할 수 있습니다.
