# Chapter 81: Filer, teckenkodningar och gränser

## Filer som Pilcrow öppnar

Pilcrow redigerar filer med ren text och markering. De vanliga filtilläggen är `txt`, `md`, `markdown`, `adoc`, `asciidoc`, `rst` och `tex`, samt alla tillägg som en profil du lägger till gör anspråk på. Pilcrow identifierar en fils teckenkodning när den öppnas.

| Objekt | Typ |
| --- | --- |
| Syntaxprofil, makrosamling, stilguide, programtema | `.json` |
| Renderingstema | `.css` |
| Temapaket | `.zip` |
| Bokprojektets manifest | `manifest.pilcrow` |
| Bakgrund | HEIC, PNG, JPEG, SVG, MP4, MOV, M4V |
| Skrivljudsklipp | WAV, AIFF, MP3, M4A, CAF |

## Teckenkodningar

Pilcrow läser text i UTF-8, UTF-16, UTF-32 och ISO 8859-1 (Latin-1). Du kan konvertera ett dokument med **Dokumentinformation ▸ Teckenkodning ▸ Konvertera till…** till någon av följande; filen konverteras nästa gång den sparas:

UTF-8, UTF-8 (BOM), UTF-16 LE, UTF-16 LE (BOM), UTF-16 BE, UTF-16 BE (BOM), UTF-32 LE, UTF-32 LE (BOM), UTF-32 BE, UTF-32 BE (BOM).

En Latin-1-fil kan konverteras till vilken som helst av dessa utan förlust. Konvertering till Latin-1 erbjuds inte, eftersom det kan förstöra innehåll.

## Exportformat

| Format | Filtillägg |
| --- | --- |
| HTML, HTML (utan stilar) | `.html` |
| PDF | `.pdf` |
| Word (.docx) | `.docx` |
| Bild | `.png` |
| PDF-arkiv | `.zip` |

## Gränser och siffror

Där Pilcrow slutar, eller där ett val har ett intervall:

| Var | Gräns |
| --- | --- |
| Sökpanelen | Stannar vid 500 träffar. |
| Sökning i förhandsvisningen | Räknar upp till 2 000 träffar. |
| Ersätt i mapp | Ändrar högst 2 000 filer åt gången. |
| Kontrollera länkar | Kontrollerar upp till 50 000 länkar. |
| Jämför | Visar upp till 5 000 ändrade rader. |
| Versioner att behålla | Ingen till 500 (standard 50). |
| Långa rader | Rader på 20 000 tecken eller mer radbryts alltid. |
| Teckenstorlek | 9 till 32 punkter. |
| Tabbredd | 2 till 8 mellanslag. |
| Textbredd | 50 % till 100 %. |
| Zoom | 50 % till 200 %, i tio steg. |
| Läshastighet | 60 till 2 000 ord per minut. |
| Navigatorns bredd | 180 till 420 punkter. |
| Skrivljudsklipp | Högst 2 sekunder och 3 MB. |
| Text i diagnostikrapportens logg | De senaste posterna, upp till 60 000 tecken, när de läggs till i ett GitHub-ärendes beskrivning. |
| Mycket stora filer | Öppnas och redigeras utan att läsas in i minnet i sin helhet. Rad- och ordräkning samt disposition slutförs i bakgrunden och kan vara ofullständiga tills dess. PDF-export av ett mycket stort dokument kräver mycket mer minne än redigering eller export till HTML och Word; PDF-arkiv delar upp det i begränsade delar. |

## Var Pilcrow förvarar saker

| Vad | Var |
| --- | --- |
| Dina dokument | Där du sparade dem. |
| Bibliotek (teman, profiler, makron, stilguider, bakgrunder) | I appens privata lagring, eller i en mapp med namnet ”Pilcrow Library” inuti en mapp du väljer (**Inställningar ▸ Bibliotek ▸ Plats**). |
| Inställningar, API-nycklar, återställningskopior, versionshistorik | På enheten, i appens privata lagring och i nyckelringen. Granska och radera dem i **Inställningar ▸ Allmänt ▸ Lagring och integritet**. |
| Diagnostikslogg | På enheten, tills du rensar den. |

# Chapter 82: Meddelanden, banderoller och tomma lägen

Det här kapitlet förklarar de korta meddelanden som Pilcrow visar, så att inget av dem förblir en gåta.

## I redigeraren och förhandsvisningen

| Meddelande | Vad det betyder |
| --- | --- |
| **Inget att förhandsvisa ännu. Börja skriva så visas det här.** (eller ”Växla till Redigera och börja skriva.”) | Dokumentet är tomt, så det finns inget att rita upp i förhandsvisningen. |
| **Förhandsvisningen kunde inte renderas: …** med **Visa källa** och **Försök igen** | Förhandsvisningen misslyckades. **Visa källa** växlar till redigering. **Försök igen** försöker på nytt. |
| En misslyckad ekvation eller ett misslyckat diagram, med en länk **Visa källa** | Ett block kunde inte ritas upp. Klicka på **Visa källa** för att hoppa till blockets källtext och rätta den. |
| **Kunde inte spara** med **Försök igen** och en stängningsknapp | Det gick inte att spara. Dokumentet förblir öppet och osparat. Åtgärda orsaken (diskutrymme, behörigheter, en fil som flyttats) och välj **Försök igen**. |
| **Filen har ändrats på disken** | En annan app ändrade filen. **Läs in igen** läser den nya versionen; **Behåll aktuell version** behåller det du har. |
| **Tolkningsvarning** | En rad där en konstruktion troligen inte är vad du menade (Chapter 68). |
| **Ersätta befintlig fil?** | Namnet du valde används redan på den platsen. |
| **Ifyllnadsfält återstår** | Du skriver ut eller exporterar med ofyllda fält (Chapter 63). |
| **Panelavdelare** (VoiceOver-tips: ”Dra för att ändra storlek på redigeraren och förhandsvisningen. Dubbeltryck för att återställa.”) | Handtaget mellan källa och förhandsvisning i Sida vid sida. |
| **Ord: N** | Ordräkningen i statusfältet. |

## I dialogrutor och paneler

| Var | Meddelande | Betydelse |
| --- | --- | --- |
| Kommandopaletten | **Skriv ett kommando** | Fältets ledtext. ”Inga matchande kommandon” visas när inget passar. |
| Öppna snabbt | **Skriv ett filnamn** | Fältets ledtext. |
| Markörer i en kolumn | **Rader (till exempel 3-17)**, **Kolumn (till exempel 100, eller 100-105 för att markera)** | Fältens ledtexter. En enskild kolumn placerar markörer; ett intervall markerar de tecknen på varje rad. |
| Sökpanelen | **Skriv för att söka i den här mappen.**, **Inga träffar i den här mappen.**, **Sökningen avbröts.** | Tillståndet för en mappsökning. |
| Filpanelen | **Du kan också släppa en mapp här.** | Dra en mapp till panelen för att öppna den. |
| Ersätt i mapp | **Inget att ersätta.** | Sökningen har inga träffar. |
| Jämför | Verktygstips på knapparna: **Godkänn** (”Gör den här ändringen i det öppna dokumentet”), **Avvisa** (”Lämna den här ändringen utanför det öppna dokumentet”), **Ta tillbaka** (”Sätt tillbaka de äldre raderna i dokumentet för just den här ändringen”). | Vad var och en gör. |
| Översätt | **Översättningen kunde inte slutföras.** | Försök igen, eller välj en annan hastighet. |
| Översätt | **Beräknad tid: mindre än en minut** | En uppskattning för AI-assistentens hastighet; tiden beror på din AI-tjänst. Efter en översättning öppnar **Öppna i ny flik** resultatet. |
| Assistent | **Inget dokument är öppet.**, **Ingen dokumenttext skickas.** | Panelen har inget att dela, så inget skickas. |
| Modellväljare | **Läser in modeller…**, **Inga modeller matchar.** | Listan läses in, eller så gav din sökning inga träffar. |
| Stilgranskning | **Inga fynd.** och **Svaret kunde inte läsas som fynd. Försök igen.** | Granskningen hittade inget, eller AI:ns svar hade inte det förväntade formatet. |
| Stilgranskning | Verktygstipset för **Tillämpa alla**: ”Utför varje åtgärd som har en, som en enda ändring du kan ångra.” | En enda ångra upphäver dem alla. |
| Projektpanelen | **Ditt namn**, **Lägg till variabel** | Ledtexten i fältet Författare och knappen för en projektvariabel. |
| Assistentbehörighet | **Läs Pilcrows integritetspolicy** | Öppnar integritetspolicyn. |
