# Chapter 75: Temaredigerarna

Det finns två slags teman, och vart och ett har sin egen redigerare. Öppna någon av dem från **Inställningar ▸ Bibliotek ▸ Teman**: **Ny** skapar ett tema, **Redigera** ändrar ett eget tema och **Duplicera** kopierar ett inbyggt tema så att du kan ändra kopian. Inbyggda teman kan inte redigeras.

## Redigeraren för renderingstema

**Redigera renderingstema** formaterar förhandsvisning, HTML, PDF, bild och utskrift. Dess anpassade Pilcrow-egenskaper styr också Word-format. Ett renderingstema formaterar inte programmet eller redigeraren.

| Del | Vad den gör |
| --- | --- |
| **Namn** | Temats namn. |
| **Utseende** | **Automatisk**, **Ljus** eller **Mörk**. |
| **CSS** | Formatmallen, i en kodredigerare. Se Chapter 80 för egenskaper och klasser. |
| **Renderad förhandsvisning** | Ett exempeldokument som ritas med din CSS medan du skriver, så att du ser effekten. |
| **CSS-diagnostik** | Problem som Pilcrow hittade i CSS-koden, till exempel en fjärrresurs som inte är tillåten. |
| **Avbryt**, **Spara** | Stäng eller behåll temat. Om du stänger med ändringar frågar programmet **Släng temaändringar?** med **Släng ändringar** eller **Fortsätt redigera**. |
| **Baslinje** | **Återställ till baslinjen** slänger alla ändringar sedan temat skapades, duplicerades eller importerades (efter att du bekräftat). **Ange som ny baslinje** sparar temat och gör dess nuvarande tillstånd till återställningspunkt. |

## Redigeraren för programtema

**Redigera programtema** formaterar Pilcrow självt: dess utseende, accentfärg, sidofält, fält och redigerare.

| Del | Vad den gör |
| --- | --- |
| **Namn** | Temats namn. |
| **Utseende** | **Automatisk**, **Ljus** eller **Mörk**. Ett automatiskt tema har två paletter. |
| **Redigerar färger för** | För ett automatiskt tema, **Ljus** eller **Mörk**: vilken av de två palettena du redigerar. |
| Färger, i fem grupper | **Program** (accentfärgen), **Sidofält** (bakgrund och förgrund), **Status- och formateringsfält** (bakgrund och förgrund), **Redigerare** (bakgrund, förgrund, markör, markering, marginalens bakgrund, marginalens förgrund, regel för aktuell rad) och **Syntax** (rubrik, markör, kod, länk, dämpad samt kodens nyckelord, sträng, tal och kommentar). Varje färg visar **Standard** tills du anger en, och en **Återställ**-knapp sätter tillbaka den. |
| **Förhandsvisning** | En miniatyr av Pilcrow, med sidofält, redigerare och statusfält, i de färger du valt, i ljust eller mörkt. |
| **Avbryt**, **Spara**, **Baslinje** | Som ovan. |

Ett tema kan också färglägga enskilda syntaxtecken. Dessa färger bevaras, men redigeras i temats JSON-fil (`syntax.tokens`); se Chapter 79.

# Chapter 76: Makroredigeraren

Öppna makroredigeraren från **Inställningar ▸ Bibliotek ▸ Makron**: **Ny** inuti en samling, eller **Redigera** på ett makro. Dess rubrik är **Nytt makro** eller **Redigera makro**.

| Fält | Vad det gör |
| --- | --- |
| **Namn** | En etikett för makrot. |
| **Utlösare** (till exempel `/sig`) | Texten som startar det. Ett makro expanderas när du skriver utlösaren följd av ett blanksteg, en tabb eller returtangenten. |
| **Matcha** | Hur utlösaren tolkas: **Exakt text**, **Prefix** eller **Reguljärt uttryck**. Ett reguljärt uttryck som kan få redigeraren att hänga sig avvisas: "That regular expression could hang the editor. Simplify it." |
| **Ersättning** | Texten det expanderas till. |
| **Infoga datum/tid** | En meny som lägger till en datum- eller tidstoken i ersättningen. |
| **Aktiverad** | Slår på eller av makrot utan att radera det. |
| **Expandera inte i kod** | Hindrar makrot från att utlösas inuti kodspann och kodblock. |
| **Avbryt**, **Spara** | Stäng eller behåll makrot. Om det inte kan sparas anger meddelandet varför. |

I ersättningen är `$1`, `$2` och så vidare tabbstopp, och `$0` är där markören hamnar. När ett makro har expanderats hoppar Tabb (eller **Nästa fält**) från stopp till stopp. Datum och tider använder token: `{{date:yyyy-MM-dd}}`, `{{time:HH:mm:ss}}` och `{{datetime:MM/dd/yyyy h:mm a}}`, samt de namngivna formaten `iso8601`, `rfc2822`, `unix`, `short`, `medium`, `long` och `full`. En rad med **Nu:** under fältet visar vad ersättningen skulle ge i detta ögonblick.

# Chapter 78: Använda Pilcrow på iPad

Pilcrow körs på iPadOS 17 eller senare. Det fungerar enbart med touch, med ett externt tangentbord och med styrplatta eller mus.

## Touch

- **Panelavdelare.** I Sida vid sida drar du avdelaren mellan källa och förhandsvisning för att ändra storlek. Dubbeltryck på den för att återställa.
- **Navigator.** Dra i sidofältets kant för att ändra dess storlek. I ett smalt fönster täcker sidofältet dokumentet och en **Klar**-knapp stänger det.
- **Kolumnmarkering.** Slå på **Mer ▸ Kolumnmarkering** och dra sedan med ett finger för att markera en rektangel av text. Två fingrar rullar fortfarande. En **Kolumnmarkering**-bricka visas medan det är på, med en knapp för att stänga av det. Eller använd **Mer ▸ Markörer i en kolumn…** för att placera markörer efter antal.
- **Kontextmenyn.** Tryck och håll i texten för redigerarens meny (nedan).
- **Filer.** Tryck och håll på en fil i filpanelen för dess meny (Chapter 60).

## Med ett externt tangentbord

Alla genvägar i Chapter 77 fungerar. Håll ned **⌘** för att se iPadens menyrad, eller flytta en pekare till skärmens överkant. Pilcrow kan dölja sina egna menyer i rubriken när ett tangentbord eller en mus är ansluten; se **Inställningar ▸ Utseende ▸ Menyer i rubriken**.

## Med styrplatta eller mus

Högerklick öppnar redigerarens kontextmeny. Håll ned **Option** medan du drar för att markera en rektangel av text.

## Redigerarens kontextmeny

Högerklicka på Mac, eller tryck och håll på iPad, i texten. Objekt som den aktiva syntaxprofilen inte kan uttrycka är nedtonade, och systemet lägger till sina egna objekt (Klipp ut, Kopiera, Klistra in, stavningsförslag, Slå upp och så vidare).

På **Mac**:

| Objekt | Vad det gör |
| --- | --- |
| **Kopiera / Klistra in som…** | **Kopiera som Markdown**, **Kopiera som oformaterad text**, **Kopiera som HTML-kod**, **Klistra in som oformaterad text**. |
| **Stycke** | **Stycke**, **Rubrik 1** till **6**, **Blockcitat**, **Punktlista**, **Numrerad lista**, **Uppgiftslista**, **Kodstaket**. |
| **Format** | **Fet**, **Betoning**, **Kod**, **Genomstruket**, **Inline-matematik**, **Visad matematik**, **Diagram**, **Graf**, **Hyperlänk**. |
| **Markering** | **Markera ord**, **Markera rad**, **Markera stycke**. |

På **iPad** finns tre undermenyer bland systemets objekt:

| Objekt | Vad det gör |
| --- | --- |
| **Format** | De inbyggda stilarna: fet, betoning, kod och resten. |
| **Stycke** | Styckestyperna: rubriker, citat, listor, kodstaket. |
| **Infoga** | Samma infogningar som i formateringsverktygsfältets **Mer**-meny, inklusive **Infoga varning**, **Infoga bild…** och **Infoga tabell…**, och, under **Syntax**, den aktiva profilens egna konstruktioner. |
