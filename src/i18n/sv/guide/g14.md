# Part XXI — Filformat och begränsningar

# Chapter 79: Formatet för programteman

Ett **programtema** formaterar Pilcrow självt: dess ljusa eller mörka utseende, accentfärgen, sidofältet, status- och formateringsfälten och redigeraren. Det är en JSON-fil. Renderade dokument (förhandsvisning, HTML, PDF, bild, utskrift och Word) formateras separat av ett **renderingstema**, som är CSS (Chapter 80). De två slagen installeras, väljs och raderas separat, och inget av dem följer det andra.

## Ett fullständigt exempel

```json
{
  "pilcrowAppTheme": 1,
  "name": "Nord",
  "appearance": "dark",
  "colors": {
    "accent": "#88C0D0",
    "sidebar": { "background": "#2E3440", "foreground": "#D8DEE9" },
    "bars": { "background": "#3B4252", "foreground": "#D8DEE9" },
    "editor": {
      "background": "#2E3440",
      "foreground": "#ECEFF4",
      "cursor": "#88C0D0",
      "selection": "#434C5E",
      "gutterBackground": "#2E3440",
      "gutterForeground": "#4C566A"
    },
    "syntax": {
      "heading": "#88C0D0",
      "marker": "#EBCB8B",
      "code": "#A3BE8C",
      "link": "#81A1C1",
      "muted": "#7B88A1",
      "tokens": { "strong": "#D08770" }
    }
  }
}
```

## Översta nivån

| Nyckel | Obligatorisk | Värde |
| --- | --- | --- |
| `pilcrowAppTheme` | ja | Formatversionen, `1`. |
| `name` | ja | 1–200 tecken. Visas i Inställningar och Teman-menyn. |
| `appearance` | ja | `"light"`, `"dark"` eller `"automatic"`. |
| `colors` | `light`- och `dark`-teman | En palett (nedan). |
| `light`, `dark` | `automatic`-teman | Två paletter: en som används i systemets ljusa utseende, en i det mörka. |
| `id` | nej | Skrivs av Pilcrow för dess eget bibliotek. Ignoreras vid import, som alltid tilldelar ett nytt id. |

`appearance` bestämmer utseendet för **varje** fönster: menyer, Inställningar, ark och väljare inkluderade. Ett `light`- eller `dark`-tema låser det; `automatic` följer systemet.

Ett automatiskt tema måste ange varje färg i både `light` och `dark` eller i ingen av dem. En färg som anges för bara ett utseende skulle annars ritas i det andra.

## Palett

Alla nycklar är valfria. En färg som utelämnas behåller Pilcrows inbyggda utseende, så ett tema kan vara så litet som en enda accentfärg.

| Nyckel | Formaterar |
| --- | --- |
| `accent` | Programtäckande färgton: knappar, markerade segment, reglage, länkar, fokusringar och sidofältets markerade rad. Om den inte anges behålls systemets accentfärg. |
| `sidebar.background`, `sidebar.foreground` | Sidofältet Filer, Disposition och Sök. Sekundära etiketter härleds från förgrunden. |
| `bars.background`, `bars.foreground` | Statusfältet, det förankrade formateringsverktygsfältet och importmeddelanden. Sekundära etiketter härleds från förgrunden. |
| `editor.background`, `editor.foreground` | Redigerarens yta och brödtext. |
| `editor.cursor`, `editor.selection` | Insättningspunkten och markeringens markering. |
| `editor.gutterBackground`, `editor.gutterForeground` | Marginalen med radnummer. Bakgrunden är som standard redigerarens bakgrund. |
| `editor.currentLineRule` | Den tunna regeln under raden där markören står, när **Visa ▸ Regel för aktuell rad** är på. Som standard redigerarens textfärg med låg styrka. |
| `syntax.<group>` | Syntaxfärger i realtid per grupp (nedan). |
| `syntax.tokens.<raw>` | Ett enskilt token efter sitt råvärde, som åsidosätter dess grupp. |

### Syntaxgrupper

| Grupp | Färglägger |
| --- | --- |
| `heading` | Rubriker (markörer och text), varningsmarkörer, definitionstermer |
| `marker` | Betoning, fet stil, genomstrykning och andra inline-avgränsare; list- och uppgiftsmarkörer |
| `code` | Inline-kod, kodstaket och indragna kodblock, matematik, HTML-block |
| `link` | Etiketter och mål för länkar och bilder, autolänkar |
| `muted` | Blockcitatmarkörer, tematiska avbrott, tabellrader, kommentarer, blockattribut |
| `codeKeyword`, `codeString`, `codeNumber`, `codeComment` | Markerad kod inuti ett staket |

En grupp som inte anges får en inbyggd färg vald för redigerarens bakgrund: mörkare toner på en ljus yta, ljusare toner på en mörk. Tokennamn i `syntax.tokens` använder bokstäver, siffror, `_` och `-`, och får inte upprepa ett gruppnamn (`syntax.heading` täcker redan `heading`).

## Färger

Varje färg är en hex-sträng: `#RGB`, `#RGBA`, `#RRGGBB` eller `#RRGGBBAA`, i sRGB. Pilcrow lagrar dem med versaler.

## Validering

Pilcrow avvisar en fil i stället för att ignorera en del av den, och anger nyckeln som är fel, till exempel `colors.editor.cursor: must be a hex colour`. Den avvisar:

- en saknad eller annan `pilcrowAppTheme`-version;
- en okänd nyckel på någon nivå (oftast ett stavfel);
- en palettnyckel som inte stämmer med utseendet (`colors` i ett automatiskt tema, `light` och `dark` i ett ljust eller mörkt);
- en färg som inte är hex;
- ett automatiskt tema vars `light`- och `dark`-paletter anger olika färger.

## Vad ett programtema inte ändrar

Fönstrets titelrad och verktygsfält (systemets glas, som bara tar emot accentfärgen), menyer, Inställningar, ark och väljare behåller sitt inbyggda utseende bortsett från utseende och accentfärg. Typsnitt formateras inte av teman: redigerarens typsnitt och storlek anges i **Inställningar ▸ Utseende ▸ Textstorlek och typsnitt**.

## Installera och dela

- **Importera** en `.json`-fil från **Inställningar ▸ Bibliotek ▸ Teman**, **Arkiv ▸ Importera ▸ Tema** på Mac, eller **Inställningar ▸ Bibliotek ▸ Importera** på iPad. Att släppa filen på Pilcrow fungerar också.
- Ett `.zip`-temapaket kan innehålla programteman vid sidan av renderingsteman (Chapter 80).
- Delningsknappen bredvid ett tema sparar dess `.json`-fil, eller hela paketet om temat kom från ett.

Pilcrow innehåller tre programteman: **Automatisk**, **Ljus** och **Mörk**. De anger redigerarens och syntaxens färger och låter ramen behålla sitt inbyggda utseende.

# Chapter 80: CSS-referens för renderingstema

Ett **renderingstema** är CSS. Det formaterar förhandsvisning, HTML, PDF, bild och utskrift, samt de Word-format som listas i slutet av det här kapitlet. Ett renderingstema kan vara en enda `.css`-fil eller en del av ett ZIP-paket med lokala tillgångar. Syntaxprofiler definierar hur källtext blir dokumentet; renderingsteman formaterar bara resultatet. CSS formaterar aldrig programmet eller redigeraren; det görs av programtemat (Chapter 79).

## Kaskaden

Pilcrow tillämpar stilar i denna ordning:

1. Pilcrows strukturella återställning;
2. det valda temats CSS;
3. engångs-CSS från exportpanelen (**Avancerade alternativ ▸ Anpassad CSS**);
4. nödvändiga korrigeringar för utskrift och rendering.

Senare regler vinner enligt den vanliga CSS-kaskaden. Tema-JavaScript, fjärrresurser, `file:`-URL:er och `@import` stöds inte.

## Resurser

Pilcrow läser tema-CSS med en vanlig CSS-tokenizer, så escape-sekvenser avkodas innan något kontrolleras: `u\72 l(…)` är en `url()` och `@im\70 ort` är en `@import`. Varje ställe där en webbläsare skulle läsa in något kontrolleras: `url(…)`, `url("…")`, `src("…")` och strängar inuti `image-set()`. Var och en måste vara något av följande:

- en paketrelativ sökväg (`fonts/Body.woff2`, `./paper.png`). En `?query` eller `#fragment` är tillåten och ignoreras när filen slås upp;
- en `data:`-URL av typen PNG, JPEG, GIF, WebP, SVG (`image/svg+xml`), TTF, OTF, WOFF eller WOFF2;
- en fragmentreferens som `url(#shadow)`, som anger ett element på sidan.

Allt med ett annat schema än `data:` (`https:`, `file:`, `blob:`) eller som börjar med `//` avvisas, liksom en sökväg som börjar med `/` eller innehåller `..`.

## ZIP-paket

Ett ZIP-paket kan innehålla renderingsteman (`.css`) och programteman (`.json`) tillsammans; vart och ett listas med sitt eget slag i Inställningar. Ett ZIP med högst en CSS-fil och högst ett programtema behöver ingen manifestfil. Allt utöver det kräver `pilcrow-theme.json`, som listar varje tema under `variants[].file`. Filens ändelse avgör dess slag:

```json
{
  "id": "com.example.paper",
  "name": "Paper",
  "version": "1.0.0",
  "author": "Example Author",
  "license": "MIT",
  "cssAPIVersion": 1,
  "variants": [
    { "id": "app", "name": "Paper", "file": "Paper.json", "appearance": "automatic" },
    { "id": "light", "name": "Paper Light", "file": "Paper-Light.css", "appearance": "light" },
    { "id": "dark", "name": "Paper Dark", "file": "Paper-Dark.css", "appearance": "dark" }
  ]
}
```

Manifestet beskriver paketet och dess teman. Det innehåller aldrig stilvärden: dessa finns i CSS- och programtemafilerna.

- Paketets `id` namnger installationsmappen. Det får inte börja med `.` eller ha inledande eller avslutande blanksteg. Att installera ett paket vars `id` redan är installerat ersätter det.
- Ett ZIP som skapats med Finders **Komprimera** fungerar som det är. Pilcrow hoppar över `__MACOSX/`, `._*`, `.DS_Store` och `Thumbs.db`, och när alla filer ligger i en enda toppmapp behandlas den mappen som paketets rot.
- Att radera ett tema tar bort det från paketet och behåller de andra tillsammans med de delade tillgångarna. Att radera det sista temat tar bort paketet. Ett raderat tema som var valt återställer valet till sitt slags standard: Automatisk för programtemat, Ljus för renderingstemat.
- CSS kan referera till paketerade PNG-, JPEG-, GIF-, WebP-, TTF-, OTF-, WOFF- och WOFF2-filer med relativa `url(...)`-sökvägar. Pilcrow verifierar deras signaturer och bäddar in refererade tillgångar som data-URL:er så att rendering och exporterad HTML förblir offline och fristående. ZIP-sökvägar får inte lämna paketet, kollidera på grund av versaler och gemener eller peka på länkar. Arkivets storlek, antal poster, enskild storlek och komprimeringsgrad är begränsade.

## Word

Word-export använder de ljusa (bas) `:root`-värdena och mappar dessa semantiska egenskaper till namngivna Word-format: `--pt-foreground`, `--pt-background`, `--pt-accent`, `--pt-link-color`, `--pt-code-background`, `--pt-code-foreground`, `--pt-body-font-family`, `--pt-mono-font-family`, `--pt-base-font-size` och `--pt-line-height`. Webbläsarselektorer och layoutregler har ingen allmän motsvarighet i Word. Förhandsvisning, HTML, PDF och bild använder hela formatmallen; Word använder denna delmängd och bevarar samtidigt dokumentstruktur, diagram, matematikbilder, länkar och media. Exportpanelen visar denna begränsning varje gång Word är valt.

Pilcrow innehåller två renderingsteman, **Ljus** och **Mörk**, som är fullständiga utgångspunkter.
