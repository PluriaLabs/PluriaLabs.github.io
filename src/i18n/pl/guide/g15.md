# Chapter 81: Pliki, kodowania i limity

## Pliki otwierane przez Pilcrow

Pilcrow edytuje pliki zwykłego tekstu i znaczników. Zwykłe rozszerzenia to `txt`, `md`, `markdown`, `adoc`, `asciidoc`, `rst` i `tex` oraz każde rozszerzenie, które zgłasza dodany przez Ciebie profil. Pilcrow wykrywa kodowanie tekstu pliku podczas jego otwierania.

| Element | Typ |
| --- | --- |
| Profil składni, kolekcja makr, przewodnik stylu, motyw aplikacji | `.json` |
| Motyw renderowania | `.css` |
| Pakiet motywu | `.zip` |
| Manifest projektu książki | `manifest.pilcrow` |
| Tło | HEIC, PNG, JPEG, SVG, MP4, MOV, M4V |
| Klip dźwięku pisania | WAV, AIFF, MP3, M4A, CAF |

## Kodowania tekstu

Pilcrow odczytuje tekst w UTF-8, UTF-16, UTF-32 i ISO 8859-1 (Latin-1). Dokument możesz przekonwertować poleceniem **Informacje o dokumencie ▸ Kodowanie ▸ Konwertuj na…** na dowolne z poniższych; plik zostanie przekonwertowany przy następnym zapisie:

UTF-8, UTF-8 (BOM), UTF-16 LE, UTF-16 LE (BOM), UTF-16 BE, UTF-16 BE (BOM), UTF-32 LE, UTF-32 LE (BOM), UTF-32 BE, UTF-32 BE (BOM).

Plik Latin-1 można przekonwertować na dowolne z nich bez strat. Konwersja na Latin-1 nie jest oferowana, ponieważ może zniszczyć zawartość.

## Formaty eksportu

| Format | Rozszerzenie |
| --- | --- |
| HTML, HTML (bez stylów) | `.html` |
| PDF | `.pdf` |
| Word (.docx) | `.docx` |
| Obraz | `.png` |
| Archiwum PDF | `.zip` |

## Limity i liczby

Gdzie Pilcrow się zatrzymuje albo gdzie wybór ma określony zakres:

| Gdzie | Limit |
| --- | --- |
| Panel wyszukiwania | Zatrzymuje się na 500 trafieniach. |
| Znajdowanie w podglądzie | Zlicza do 2000 trafień. |
| Zamień w folderze | Zmienia co najwyżej 2000 plików naraz. |
| Sprawdź łącza | Sprawdza do 50 000 łączy. |
| Porównanie | Pokazuje do 5000 zmienionych wierszy. |
| Wersje do zachowania | Od zera do 500 (domyślnie 50). |
| Długie wiersze | Wiersze o długości 20 000 znaków lub więcej są zawsze zawijane. |
| Rozmiar czcionki | Od 9 do 32 punktów. |
| Szerokość tabulatora | Od 2 do 8 spacji. |
| Szerokość tekstu | Od 50% do 100%. |
| Powiększenie | Od 50% do 200%, w dziesięciu krokach. |
| Szybkość czytania | Od 60 do 2000 słów na minutę. |
| Szerokość nawigatora | Od 180 do 420 punktów. |
| Klip dźwięku pisania | Najwyżej 2 sekundy i 3 MB. |
| Tekst dziennika raportu diagnostycznego | Najnowsze wpisy, do 60 000 znaków, po dodaniu do opisu zgłoszenia na GitHubie. |
| Bardzo duże pliki | Otwierają się i są edytowane bez wczytywania w całości do pamięci. Liczba wierszy i słów oraz konspekt są dokańczane w tle i do tego czasu mogą być niepełne. Eksport do PDF bardzo dużego dokumentu wymaga znacznie więcej pamięci niż edycja albo eksport do HTML i Worda; Archiwum PDF dzieli go na ograniczone części. |

## Gdzie Pilcrow przechowuje dane

| Co | Gdzie |
| --- | --- |
| Twoje dokumenty | Tam, gdzie je zapisano. |
| Biblioteka (motywy, profile, makra, przewodniki stylu, tła) | W prywatnej pamięci aplikacji lub w folderze o nazwie „Pilcrow Library” wewnątrz wybranego przez Ciebie folderu (**Ustawienia ▸ Biblioteka ▸ Lokalizacja**). |
| Preferencje, klucze API, kopie odzyskiwania, historia wersji | Na urządzeniu, w prywatnej pamięci aplikacji i w Pęku kluczy. Przejrzyj je i usuń w **Ustawienia ▸ Ogólne ▸ Pamięć i prywatność**. |
| Dziennik diagnostyczny | Na urządzeniu, dopóki go nie wyczyścisz. |

# Chapter 82: Komunikaty, banery i puste stany

Ten rozdział wyjaśnia krótkie komunikaty, które pokazuje Pilcrow, aby żaden z nich nie był zagadką.

## W edytorze i podglądzie

| Komunikat | Co oznacza |
| --- | --- |
| **Nie ma jeszcze nic do podglądu. Zacznij pisać, a pojawi się tutaj.** (lub „Przełącz na edycję i zacznij pisać.”) | Dokument jest pusty, więc nie ma czego rysować w podglądzie. |
| **Podgląd nie mógł się wyrenderować: …** z **Pokaż źródło** i **Ponów próbę** | Podgląd się nie powiódł. **Pokaż źródło** przełącza na edycję. **Ponów próbę** próbuje ponownie. |
| Nieudane równanie lub diagram, z łączem **Pokaż źródło** | Nie udało się narysować jednego bloku. Kliknij **Pokaż źródło**, aby przejść do źródła tego bloku i go poprawić. |
| **Nie udało się zapisać** z **Ponów próbę** i przyciskiem odrzucenia | Zapis się nie powiódł. Dokument pozostaje otwarty i niezapisany. Usuń przyczynę (miejsce na dysku, uprawnienia, plik, który został przeniesiony) i wybierz **Ponów próbę**. |
| **Plik zmieniony na dysku** | Inna aplikacja zmodyfikowała plik. **Wczytaj ponownie** odczytuje nową wersję; **Zachowaj bieżącą wersję** zachowuje to, co masz. |
| **Ostrzeżenie analizy** | Wiersz, w którym konstrukcja prawdopodobnie nie jest tym, co zamierzałeś (rozdział 68). |
| **Zastąpić istniejący plik?** | Wybrana nazwa jest już zajęta w tym miejscu. |
| **Pozostały pola do wypełnienia** | Drukujesz lub eksportujesz z niewypełnionymi polami (rozdział 63). |
| **Separator paneli** (podpowiedź VoiceOver: „Przeciągnij, aby zmienić rozmiar edytora i podglądu. Dotknij dwukrotnie, aby zresetować.”) | Uchwyt między źródłem a podglądem w widoku Obok siebie. |
| **Słowa: N** | Liczba słów na pasku stanu. |

## W oknach dialogowych i panelach

| Gdzie | Komunikat | Znaczenie |
| --- | --- | --- |
| Paleta poleceń | **Wpisz polecenie** | Podpowiedź w polu. „Brak pasujących poleceń” pojawia się, gdy nic nie pasuje. |
| Open Quickly | **Wpisz nazwę pliku** | Podpowiedź w polu. |
| Kursory w kolumnie | **Wiersze (na przykład 3-17)**, **Kolumna (na przykład 100 lub 100-105, aby zaznaczyć)** | Podpowiedzi w polach. Pojedyncza kolumna umieszcza kursory; zakres zaznacza te znaki w każdym wierszu. |
| Panel wyszukiwania | **Wpisz, aby przeszukać ten folder.**, **Brak trafień w tym folderze.**, **Wyszukiwanie anulowano.** | Stan wyszukiwania w folderze. |
| Panel plików | **Możesz też upuścić tutaj folder.** | Przeciągnij folder na panel, aby go otworzyć. |
| Zamień w folderze | **Nie ma nic do zamiany.** | Wyszukiwanie nie ma trafień. |
| Porównanie | Podpowiedzi na przyciskach: **Zaakceptuj** („Wprowadź tę zmianę w otwartym dokumencie”), **Odrzuć** („Pomiń tę zmianę w otwartym dokumencie”), **Wycofaj** („Przywróć starsze wiersze w dokumencie tylko dla tej zmiany”). | Co robi każdy z nich. |
| Tłumacz | **Nie udało się ukończyć tłumaczenia.** | Spróbuj ponownie lub wybierz inną szybkość. |
| Tłumacz | **Szacowany czas: krócej niż minuta** | Szacunek dla szybkości asystenta AI; czas zależy od Twojej usługi AI. Po tłumaczeniu **Otwórz w nowej karcie** otwiera wynik. |
| Asystent | **Żaden dokument nie jest otwarty.**, **Tekst dokumentu nie jest wysyłany.** | Panel nie ma nic do udostępnienia, więc nic nie jest wysyłane. |
| Wybór modelu | **Wczytywanie modeli…**, **Żaden model nie pasuje.** | Lista się wczytuje albo wyszukiwanie nic nie znalazło. |
| Przegląd stylu | **Brak uwag.** i **Nie udało się odczytać odpowiedzi jako uwag. Spróbuj ponownie.** | Przegląd nic nie znalazł albo odpowiedź AI nie miała oczekiwanej postaci. |
| Przegląd stylu | Podpowiedź **Zastosuj wszystkie**: „Wprowadza każdą poprawkę, która ją ma, jako jedną zmianę, którą można cofnąć.” | Jedno Cofnij odwraca je wszystkie. |
| Panel projektu | **Twoje imię i nazwisko**, **Dodaj zmienną** | Podpowiedź pola Autor i przycisk zmiennej projektu. |
| Uprawnienie asystenta | **Przeczytaj politykę prywatności Pilcrow** | Otwiera politykę prywatności. |
