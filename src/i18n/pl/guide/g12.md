# Part XIX — Edytory elementów biblioteki

# Chapter 74: Edytor profili i elementy składowe profilu

Profil składni mówi Pilcrow, co znaczy Twój zapis. Ten rozdział opisuje edytor profili element po elemencie, a następnie wymienia wszystkie elementy składowe, których może używać profil. Wprowadzenie oparte na zadaniach znajdziesz w rozdziałach od 37 do 39.

Otwórz edytor w **Ustawienia ▸ Biblioteka ▸ Profile składni**: **Nowy** tworzy profil, **Edytuj** zmienia profil własny, a **Duplikuj** kopiuje profil wbudowany, abyś mógł zmienić kopię. Tytuł edytora to **Edytuj profil**, z przyciskami **Anuluj**, **Zapisz** i **Pomoc dotycząca profili** (otwiera zawartą w aplikacji dokumentację tych elementów składowych). Na wąskim ekranie przełącznik **Sekcja profilu** wybiera między **Przegląd**, **Reguły** i **Próbka testowa**; na szerokim widoczne są wszystkie trzy naraz.

## Przegląd

| Pole | Co robi |
| --- | --- |
| **Nazwa** | Nazwa profilu, wyświetlana w menu paska stanu i w Ustawieniach. |
| **Opis** | Notatka o profilu. |
| **Rozszerzenia plików (oddzielone przecinkami)** | Rozszerzenia, według których plik otrzymuje ten profil. Dwa profile nie mogą mieć tego samego rozszerzenia. |
| **Dziedziczy po** | **Brak** albo inny profil, na którego regułach opiera się ten. |
| **Składnia** | **Rozszerza Markdown** lub **Zastępuje Markdown** (poniżej). |
| **W skrócie** | Liczba **Reguły blokowe**, **Reguły śródwierszowe** i **Reguły zagnieżdżania**. |
| **Edytuj zaawansowany JSON…** | Otwiera profil jako JSON, aby edytować pola, których edytor z przewodnikiem nie udostępnia. **Zastosuj** zachowuje zmiany w JSON; **Anuluj** je odrzuca. |

**Rozszerza Markdown** dodaje Twoje reguły do reguł Markdown: jego nagłówki, listy, wyróżnienia i reszta są nadal odczytywane, a Twoje reguły blokowe i śródwierszowe je uzupełniają. Reguła, która jest niezmienioną kopią jednej z reguł profilu CommonMark, opisuje to, co Markdown już robi, i jest mu pozostawiona. **Zastępuje Markdown** sprawia, że Twoje reguły stają się całą składnią, więc konstrukcje Markdown przestają być rozpoznawane. Wtedy jedna reguła musi tworzyć **Koniec wiersza**, inaczej nic nie dzieli tekstu na akapity. Edytor ostrzega „Add a rule whose output node is "newline", or nothing will separate into paragraphs”, a profilu nie można zapisać, dopóki taka reguła nie istnieje. Wyświetla też wszystkie typy wyjścia, których profil nie definiuje.

## Reguły

Reguły występują w trzech grupach.

### Reguły blokowe

Reguła blokowa rozpoznaje całe wiersze i bloki. **Dodaj regułę** dodaje nową. Każda reguła ma **Wzorzec**, typ **Dopasowanie**, to, co **Tworzy**, oraz **Opcje**. Regułę usuwa się jej przyciskiem **Usuń**. Gdy reguł nie ma, edytor pisze „No rules yet. Add one to recognize a block construct.”

### Reguły śródwierszowe

Reguła śródwierszowa rozpoznaje tekst wewnątrz wiersza. **Dodaj regułę śródwierszową** dodaje nową. Reguły śródwierszowe oferują cztery typy dopasowania (**Prefiks dosłowny**, **Dosłownie dokładnie**, **Regex (ograniczony)** i **Para ograniczników**); reguły blokowe oferują wszystkie siedem.

### Reguły zagnieżdżania

Reguły zagnieżdżania mówią, które wyjścia mogą znajdować się wewnątrz których. Każda ma **Węzeł nadrzędny** i **Dozwolone elementy podrzędne (oddzielone przecinkami)**. Puste oznacza brak ograniczeń: „No restrictions. Every node type may nest inside any other.” **Dodaj regułę zagnieżdżania** dodaje nową.

### Typy dopasowania

| Typ dopasowania | Odczytuje wzorzec jako | Blokowa | Śródwierszowa |
| --- | --- | --- | --- |
| **Prefiks dosłowny** | Tekst, od którego zaczyna się konstrukcja. | tak | tak |
| **Dosłownie dokładnie** | Cały tekst konstrukcji. | tak | tak |
| **Prefiks na początku wiersza** | Tekst na początku wiersza, na przykład `# `. | tak | |
| **Blok wcięty** | Wiersze zaczynające się od wzorca, na przykład czterech spacji lub tabulatora. Kolejne wiersze oraz puste wiersze między nimi tworzą jeden blok, pokazany bez wcięcia. | tak | |
| **Blok ogrodzony** | Wiersz otwierający blok, zamykany pasującym wierszem. | tak | |
| **Regex (ograniczony)** | Wyrażenie regularne. Pilcrow ostrzega przed zapisaniem takiego, które mogłoby się zawiesić: „This regex could hang the editor — simplify it.” | tak | tak |
| **Para ograniczników** | Ten sam znacznik po obu stronach tekstu w jednym wierszu, na przykład `%%` w `%%this%%`. Tuż wewnątrz znaczników nie ma spacji. | tak | tak |

W wyrażeniu regularnym `(?<name>…)` nazywa część dopasowania. Zobacz Nazwane części poniżej.

## Opcje reguły

**Opcje** każdej reguły oferują:

| Opcja | Co robi |
| --- | --- |
| **Priorytet** | Reguły o wyższym priorytecie są sprawdzane jako pierwsze. |
| **Tylko na początku wiersza** | Nie pozwala regule dopasowywać w środku wiersza. |
| **Nazwane części stają się atrybutami** | Każda nazwana część wyrażenia regularnego staje się atrybutem wyjścia. Edytor wyświetla „Parts in this pattern” i „Parts this output reads”. Dla wyjścia zawierającego tekst, takiego jak pogrubienie lub łącze, wyświetlany tekst to część o nazwie `text`, jeśli istnieje, a w przeciwnym razie ostatnia dopasowana część. |
| **Tworzy** | To, co reguła wytwarza: wyjście z poniższych list lub nazwa **Własny**. |
| **Własna nazwa węzła** | Nazwa dla wyjścia **Własny**. |
| **Stałe atrybuty** | Części, które za każdym razem mają tę samą wartość, dodawane przez **Dodaj atrybut** (**Nazwa** i **Wartość**). Wartość może zawierać nazwaną część, zapisaną jako `{name}`: reguła adresu e-mail, której wzorzec nazywa część `address`, może nadać swojemu łączu `url` równy `mailto:{address}`. |
| **Wstaw tekst** | To, co menu **Wstaw** zapisuje dla tej reguły, dokładnie tak, jak ma się pojawić, z `$0` w miejscu, gdzie ma trafić kursor. Reguła dopasowywana wyrażeniem regularnym, blokiem lub wcięciem tego potrzebuje, w przeciwnym razie menu Wstaw ją pomija. |
| **Tylko po pustym wierszu** | Dla bloku wciętego: wcięty wiersz tuż po tekście pozostaje częścią tego tekstu, na przykład następny wiersz elementu listy. |
| **Po naciśnięciu Return na końcu wiersza** | Dla list i cytatów: **Automatycznie** (powtarza punktory i cytaty, liczy w górę elementy numerowane i zaczyna elementy zadań jako niezaznaczone), **Powtórz znacznik**, **Liczenie w górę**, **Zacznij od nowa od znacznika** lub **Nic nie dodawaj**. |

### Bloki ogrodzone i ograniczone

Dla reguły **Blok ogrodzony** pole **Blok zawiera** mówi, co jest w środku:

| Wybór | Znaczenie |
| --- | --- |
| **Jeszcze nic** | Nie ustawiono. |
| **Tekst, pokazany tak, jak zapisano** | Kod lub tekst preformatowany. |
| **Nic — ukryte** | Komentarz, pominięty w dokumencie. |
| **Pozostałe bloki, w ramce** | Cytat, pasek boczny lub uwaga zawierające akapity, listy i inne. |
| **Pozostałe bloki, bez ramki** | Bloki łączą się z otaczającym tekstem; wiersze tylko je grupują. |
| **Tabela** | Zobacz Tabele poniżej. |
| **Tabela narysowana tekstem** | Siatka lub wyrównane kolumny tekstu, biegnące od wiersza otwierającego do następnego pustego wiersza, jak w reStructuredText. |
| **Wcięty tekst pod wierszem kończącym się znacznikiem** | Wiersz otwierający to proza kończąca się znacznikiem, jak `::` w reStructuredText; proza pozostaje akapitem, a tekst wcięty pod nią po pustym wierszu jest pokazywany tak, jak zapisano. |
| **Wcięty tekst pod wierszem otwierającym** | Dyrektywa, taka jak `.. code-block::`, która zawiera wcięte wiersze pod sobą i nie ma wiersza zamykającego. |

**Wiersz zamykający** to wiersz kończący blok; puste oznacza ten sam wiersz co otwierający („Same as the opening line”). Ogranicznik, który nie jest wyrażeniem regularnym, taki jak `+++`, jest dopasowywany jako zwykły tekst. **Wiersz zamykający powtarza znacznik otwierający, co najmniej tyle samo razy** jest dla ogrodzeń w stylu Markdown: wiersz zamykający to pierwszy znak wiersza otwierającego powtórzony co najmniej tyle samo razy, więc dłuższe ogrodzenie zawiera krótsze jako tekst. Język bloku tekstowego, gdy wiersz otwierający nazywa znany język, jest w edytorze kolorowany.

| Opcja | Co robi |

| **Separator komórek** | Tekst, od którego zaczyna się każda komórka. |

| **Wiersz kończy się** | Znacznik kończący każdy wiersz, jak w LaTeX-owym `tabular`. |
| **Wzorzec komórki łączonej** | Komórka obejmująca kilka kolumn. |

## Znaczniki śródwierszowe parowane według otoczenia

Język taki jak Markdown zapisuje pogrubienie i kursywę ciągiem znaków, który otwiera się lub zamyka zależnie od znaków obok, a fragment kodu lub łącze nawiasami, więc jeden wzorzec dla całej konstrukcji ich nie znajdzie. Włącz **Odczytuj znaczniki według tego, co je otacza**, aby je opisać.

| Ustawienie | Co robi |
| --- | --- |
| **Znak ucieczki** | Znak, który sprawia, że następny jest zwykły. |
| **Znak fragmentu kodu** | Ciąg tego znaku otwiera fragment, który zamyka następny ciąg tej samej długości. |
| **Znaczniki serii** | Znaczniki parowane jako serie, dodawane przez **Dodaj znacznik serii**. Każdy ma **Znacznik**, to, co **Jeden znacznik rysuje**, i to, co **Dwa znaczniki rysują**, oraz **Może się otwierać lub zamykać wewnątrz słowa** (wyłączone dla `_`). |
| **Znaczniki par** | Znaczniki parowane z ciągiem tej samej długości, dodawane przez **Dodaj znacznik pary**: **Znacznik**, to, co **Rysuje**, oraz **Tylko gdy to ustawienie jest włączone**, czyli ustawienie składni, takie jak wyróżnienie, które musi być włączone (lub **Zawsze**). |
| **Łącza i adresy internetowe** | **Prefiks obrazu**, **Adres zapisany samodzielnie jest ujęty w**, **Schematy, od których zaczyna się goły adres**, **Wiersz definiujący etykietę ma** i **Etykieta przypisu zaczyna się od** (znak po nawiasie otwierającym etykietę, który czyni ją przypisem: `[^note]` jest rysowane jako odwołanie do przypisu, gdy wiersz zaczyna się od `[^note]:`). |

Znaczniki parują się w obrębie wiersza. Kod, znaki z ucieczką i adres łącza są dla otaczających je znaczników zwykłym tekstem.

## Źródło ze stylem

Gdy **Źródło ze stylem** jest włączone, edytor rysuje dokument w wyglądzie jego składni: większe nagłówki, pogrubione i pochylone fragmenty, paski cytatów, wcięcia list, pola zadań, linie, łącza i karty kodu, a znaczniki, które je tworzą, ukrywa (gdy **Ukryj znaczniki** jest włączone), z wyjątkiem wiersza, w którym jest kursor. Edytor nie zna żadnej konkretnej składni: reguła mówi, czym jest jej dopasowanie, niosąc wpis stylu, a reguła bez niego jest kolorowana, ale nie stylizowana na nowo.

**Opcje** każdej reguły zawierają grupę **Źródło ze stylem**:

| Pole | Co robi |
| --- | --- |
| **Rola** | Czym jest dopasowanie, lub **Bez stylu**. Dla jednej konstrukcji wewnątrz wiersza: heading, strong, emphasis, code, strike, highlight, underline, link, subscript, superscript. Dla całego wiersza: rule (przerwa tematyczna), list (znacznik elementu listy wraz z wcięciem i następującą po nim spacją), task (znacznik z polem wyboru) i quote (znaki `>` cytowanego wiersza). Dla bloku rozpoznawanego w całości: codeBlock. Dla bloku, którego wiersze otwierający i zamykający są osobnymi dopasowaniami: quoteRegion. Dla tabeli, równania lub diagramu rysowanych jako obraz: renderedBlock. |
| **Grupa treści** | Grupa przechwytująca, licząc od 1, która zawiera to, o czym jest konstrukcja: słowo wewnątrz `*bold*`, tytuł w `\section{Title}`. To, co dopasowanie zawiera poza nią, to własne znaczniki konstrukcji, które ukrywa Ukryj znaczniki. `0` oznacza, że całe dopasowanie jest treścią i nic się nie ukrywa, jak w adresie internetowym. Pomiń to, gdy dopasowanie to same znaczniki, jak `== ` nagłówka. |
| **Poziom nagłówka**, **Grupa poziomu** | Poziom nagłówka, od 1 do 6. Gdy pominięty, jest to liczba na końcu nazwy wyjścia reguły (`heading2`) lub długość grupy przechwytującej zawierającej ciąg `#`. |
| **Grupa znaczników** | Dla listy lub zadania grupa przechwytująca będąca znacznikiem wraz z wcięciem i spacjami po nim, gdy dopasowanie zaczyna się od czegoś innego, na przykład od `> ` cytowanego elementu. |
| **Style do końca wiersza** | Stylizuje od dopasowania do końca wiersza, dla reguły dopasowującej tylko znacznik nagłówka i pozostawiającej jego tytuł jako tekst, który następuje po nim. |
| **Rysuje jako** | Dla bloku renderowanego, czym jest: tabelą, matematyką lub diagramem, albo **To nie jest obraz**. |
| **Grupy adresów** | Dla łącza grupy przechwytujące, sprawdzane po kolei, które zawierają adres otwierany po kliknięciu lub stuknięciu; `0` to całe dopasowanie. Otwierają się tylko adresy internetowe, pocztowe i telefoniczne. |

Numery grup liczą nawiasy wzorca od 1; 0 to całe dopasowanie. Profil, który nie zastępuje Markdown, zachowuje też własny odczyt Markdown dla rodzajów, których jego reguły nie deklarują, takich jak jego paski cytatów i pary `**`.

## Atrybuty dokumentu i sekcje warunkowe

Reguła **Atrybut dokumentu** definiuje wartość przez `name`, a reguła **Odwołanie do atrybutu** (reguła śródwierszowa z częściami `name` i `original`) zastępuje odwołanie tą wartością. Odwołanie do atrybutu, którego nikt nie zdefiniował, pozostaje tak, jak zapisano. **Sekcja warunkowa** zachowuje lub odrzuca bloki między swoimi wierszami, zależnie od tego, czy wymienione w niej atrybuty są ustawione. Atrybuty obowiązują od miejsca, w którym są zdefiniowane.

Reguła tworząca **Ustawienia następnego bloku** rozpoznaje cały wiersz konfigurujący następujący po nim blok i sama niczego nie pokazuje. Jej części i stałe atrybuty są przekazywane temu blokowi: `title`, `id`, `nodeType`, `language` i `hardbreaks` mają znaczenia wymienione w Częściach, a każda inna część jest zachowana w bloku, gdzie odczytuje ją tabela, lista lub cytat.

## Testowanie profilu

Na dole edytora **Próbka testowa** zawiera przykładowy tekst (na początku jest to nagłówek i wiersz tekstu). Wybierz **Sprawdź przykład**, aby zobaczyć węzły tworzone przez Twoje reguły, wcięte zgodnie z zagnieżdżeniem. Gdy nic nie pasuje, wyświetla „No blocks recognized.”

## Wartość bazowa

**Wartość bazowa** profilu to jego punkt przywracania: stan z chwili, gdy go utworzyłeś, zduplikowałeś lub zaimportowałeś. **Przywróć wartość bazową** odrzuca wszystkie zmiany od tamtej chwili, po potwierdzeniu. **Ustaw jako nową wartość bazową** zapisuje profil i czyni jego bieżący stan punktem przywracania.

Zapis zostaje odrzucony, z komunikatem, jeśli profil zastępuje Markdown, ale nie ma reguły końca wiersza, jeśli wzorzec jest niebezpieczny i mógłby zawiesić edytor, lub jeśli nie można zapisać pliku.

## Części

Części to nazwane fragmenty dopasowania, które odczytuje wyjście.

| Część | Znaczenie |
| --- | --- |
| `allOf` | Separator między nazwami, gdy potrzebne są wszystkie, na przykład `+`. |
| `alt` | Opis obrazu dla czytelników, którzy go nie widzą. |
| `anyOf` | Separator między nazwami, gdy wystarczy którakolwiek, na przykład `,`. |
| `attribution` | Kto wypowiedział cytat, pokazane pod nim. |
| `citetitle` | Dzieło, z którego pochodzi cytat, pokazane po autorze. |
| `columns` | Lista kolumn tabeli, na przykład `1,2,1`; jej wpisy liczą kolumny. |
| `condition` | Nazwy atrybutów, od których zależy sekcja. |
| `conditionType` | `defined` zachowuje sekcję, gdy atrybuty są ustawione, `undefined`, gdy nie są. |
| `content` | Sam tekst, gdy nie jest całym dopasowaniem. |
| `format` | Silnik diagramu (`mermaid` lub `vega-lite`); dla tabeli, którego z jej formatów rozdzielanych używają komórki. |
| `hardbreaks` | Gdy obecna, zachowuje pojedyncze podziały wierszy następnego bloku. |
| `header` | Każda wartość poza `false` czyni pierwszy wiersz tabeli jej nagłówkiem. |
| `id` | Nazwa: dla następnego bloku identyfikator, na który wskazują odwołania krzyżowe; dla przypisu nazwa, która pozwala późniejszym przypisom bez własnego tekstu dzielić jego numer. |
| `keys` | Klawisze do naciśnięcia, oddzielone przecinkami. |
| `label` | Tekst pokazywany dla odwołania lub kotwicy, zamiast własnego tytułu celu. |
| `language` | Język programowania bloku kodu, używany do jego kolorowania. |
| `level` | Poziom nagłówka, od 1 do 6. |
| `marker` | Separator po terminie, na przykład `::`. Inny znacznik zagnieżdża listę wewnątrz opisu. |
| `name` | Nazwa atrybutu, w definicji lub w odwołaniu. |
| `nodeType` | Zamienia następny blok w inne wyjście, według jego nazwy w pliku. |
| `noHeader` | Gdy obecna, tabela nie ma wiersza nagłówka. |
| `notation` | Notacja matematyczna: `tex` (domyślna) lub `latex`. |
| `open` | `true` pokazuje sekcję zwijaną jako otwartą. |
| `ordered` | `true` czyni listę numerowaną. |
| `original` | Odwołanie tak, jak zapisano, pokazywane, gdy atrybut nie jest zdefiniowany. |
| `presentation` | Jak pokazywana jest następna lista opisowa: `sideBySide` umieszcza terminy i opisy w dwóch kolumnach; `questions` numeruje każdy termin jako pytanie, z odpowiedzią pod spodem. |
| `primary` | Hasło indeksu. |
| `secondary` | Podhasło pod hasłem indeksu. |
| `sectionLabel` | Słowo, po którym następuje numer następnego nagłówka, na przykład `Appendix`: takie nagłówki są liczone osobno, `Appendix A:`. |
| `sectionLabelStart` | Pierwszy z tych numerów: litera (`A`) liczy literami, liczba liczbami. |
| `src` | Adres pliku wideo lub dźwiękowego. |
| `start` | Liczba, od której zaczyna się lista numerowana. |
| `summary` | Wiersz pokazywany w sekcji zwijanej, gdy jest zamknięta. |
| `targetID` | Identyfikator, na który wskazuje odwołanie. |
| `term` | Opisywany termin. |
| `tertiary` | Podhasło pod drugim poziomem. |
| `text` | Pokazywany tekst, gdy wzorzec przechwytuje więcej. Tekst przypisu następuje po akapicie, tabeli lub liście, w której się znajduje, numerowany. |
| `title` | Tytuł: nagłówek ramki, podpowiedź obrazu lub łącza albo podpis nad następnym blokiem. |
| `type` | Rodzaj uwagi, na przykład `note`, `tip` lub `warning`. |
| `unset` | Gdy obecna, reguła usuwa atrybut zamiast go definiować. |
| `url` | Adres, na który wskazuje łącze lub obraz. |
| `value` | Wartość atrybutu; odwołania do atrybutów zdefiniowanych wcześniej są w niej zastępowane. |
