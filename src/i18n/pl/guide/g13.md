# Chapter 75: Edytory motywów

Są dwa rodzaje motywów i każdy ma własny edytor. Otwórz dowolny z nich z poziomu **Ustawienia ▸ Biblioteka ▸ Motywy**: **Nowy** tworzy motyw, **Edytuj** zmienia motyw własny, a **Duplikuj** kopiuje motyw wbudowany, aby można było zmienić kopię. Motywów wbudowanych nie można edytować.

## Edytor motywu renderowania

**Edytuj motyw renderowania** stylizuje podgląd oraz wyjście HTML, PDF, obrazu i druku. Jego własne właściwości Pilcrow ustawiają także style Worda. Motyw renderowania nie stylizuje aplikacji ani edytora.

| Element | Do czego służy |
| --- | --- |
| **Nazwa** | Nazwa motywu. |
| **Wygląd** | **Automatycznie**, **Jasny** lub **Ciemny**. |
| **CSS** | Arkusz stylów w edytorze kodu. Właściwości i klasy opisuje rozdział 80. |
| **Wyrenderowany podgląd** | Przykładowy dokument rysowany Twoim CSS na bieżąco podczas pisania, dzięki czemu widać efekt. |
| **Diagnostyka CSS** | Problemy znalezione przez Pilcrow w CSS, na przykład niedozwolony zasób zdalny. |
| **Anuluj**, **Zapisz** | Zamykają lub zachowują motyw. Zamknięcie z niezapisanymi zmianami wyświetla pytanie **Odrzucić zmiany w motywie?** z przyciskami **Odrzuć zmiany** i **Kontynuuj edycję**. |
| **Linia bazowa** | **Przywróć wartość bazową** odrzuca wszystkie zmiany od chwili utworzenia, zduplikowania lub zaimportowania motywu (po potwierdzeniu). **Ustaw jako nową wartość bazową** zapisuje motyw i czyni jego bieżący stan punktem przywracania. |

## Edytor motywu aplikacji

**Edytuj motyw aplikacji** stylizuje samego Pilcrow: jego wygląd, kolor akcentu, pasek boczny, paski i edytor.

| Element | Do czego służy |
| --- | --- |
| **Nazwa** | Nazwa motywu. |
| **Wygląd** | **Automatycznie**, **Jasny** lub **Ciemny**. Motyw automatyczny ma dwie palety. |
| **Edycja kolorów dla** | W motywie automatycznym: **Jasny** lub **Ciemny**, czyli którą z dwóch palet edytujesz. |
| Kolory w pięciu grupach | **Aplikacja** (akcent), **Pasek boczny** (tło i pierwszy plan), **Paski stanu i formatowania** (tło i pierwszy plan), **Edytor** (tło, pierwszy plan, kursor, zaznaczenie, tło marginesu, pierwszy plan marginesu, linia bieżącego wiersza) oraz **Składnia** (nagłówek, znacznik, kod, łącze, wyciszony oraz słowo kluczowe, ciąg znaków, liczba i komentarz w kodzie). Każdy kolor pokazuje **Domyślny**, dopóki go nie ustawisz, a przycisk **Resetuj** przywraca go. |
| **Podgląd** | Miniatura Pilcrow z paskiem bocznym, edytorem i paskiem stanu, w wybranych kolorach, w trybie jasnym lub ciemnym. |
| **Anuluj**, **Zapisz**, **Linia bazowa** | Jak wyżej. |

Motyw może też kolorować pojedyncze tokeny składni. Te kolory są zachowywane, ale edytuje się je w pliku JSON motywu (`syntax.tokens`); zobacz rozdział 79.

# Chapter 76: Edytor makr

Edytor makr otwierasz z **Ustawienia ▸ Biblioteka ▸ Makra**: **Nowy** wewnątrz kolekcji lub **Edytuj** przy makrze. Jego tytuł to **Nowe makro** lub **Edytuj makro**.

| Pole | Do czego służy |
| --- | --- |
| **Nazwa** | Etykieta makra. |
| **Wyzwalacz** (na przykład `/sig`) | Tekst, który je uruchamia. Makro rozwija się, gdy wpiszesz wyzwalacz, a po nim spację, tabulator lub return. |
| **Dopasowanie** | Sposób odczytywania wyzwalacza: **Dokładny tekst**, **Prefiks** lub **Wyrażenie regularne**. Wyrażenie regularne, które mogłoby zawiesić edytor, jest odrzucane: „To wyrażenie regularne mogłoby zawiesić edytor. Uprość je." |
| **Zamiennik** | Tekst, na który makro się rozwija. |
| **Wstaw datę/godzinę** | Menu, które dodaje do zamiennika token daty lub godziny. |
| **Włączone** | Włącza lub wyłącza makro bez jego usuwania. |
| **Nie rozwijaj w kodzie** | Zapobiega uruchamianiu makra wewnątrz fragmentów kodu i bloków kodu. |
| **Anuluj**, **Zapisz** | Zamykają lub zachowują makro. Jeśli nie można go zapisać, komunikat podaje powód. |

W zamienniku `$1`, `$2` itd. to punkty tabulacji, a `$0` to miejsce, w którym ląduje kursor. Po rozwinięciu makra Tab (lub **Następne pole**) przeskakuje od punktu do punktu. Daty i godziny zapisuje się tokenami: `{{date:yyyy-MM-dd}}`, `{{time:HH:mm:ss}}` i `{{datetime:MM/dd/yyyy h:mm a}}` oraz formatami nazwanymi `iso8601`, `rfc2822`, `unix`, `short`, `medium`, `long` i `full`. Wiersz **Teraz:** pod polem pokazuje, co zamiennik wytworzyłby w tej chwili.

# Chapter 78: Używanie Pilcrow na iPadzie

Pilcrow działa na iPadOS 17 lub nowszym. Współpracuje z samym dotykiem, z klawiaturą sprzętową oraz z gładzikiem lub myszą.

## Dotyk

- **Separator paneli.** W widoku Obok siebie przeciągnij separator między źródłem a podglądem, aby zmienić ich rozmiar. Stuknij go dwukrotnie, aby przywrócić domyślny.
- **Nawigator.** Przeciągnij krawędź paska bocznego, aby zmienić jego rozmiar. W wąskim oknie pasek boczny przykrywa dokument, a przycisk **Gotowe** go zamyka.
- **Zaznaczenie kolumnowe.** Włącz **Więcej ▸ Zaznaczenie kolumnowe**, a następnie przeciągnij jednym palcem, aby zaznaczyć prostokąt tekstu. Dwa palce nadal przewijają. Gdy tryb jest włączony, widać plakietkę **Zaznaczenie kolumnowe** z przyciskiem do jego wyłączenia. Możesz też użyć **Więcej ▸ Kursory w kolumnie…**, aby ustawić kursory według liczby.
- **Menu kontekstowe.** Naciśnij i przytrzymaj w tekście, aby otworzyć menu edytora (poniżej).
- **Pliki.** Naciśnij i przytrzymaj plik w panelu Pliki, aby otworzyć jego menu (rozdział 60).

## Z klawiaturą sprzętową

Działa każdy skrót z rozdziału 77. Przytrzymaj **⌘**, aby zobaczyć pasek menu iPada, lub przesuń wskaźnik na górę ekranu. Pilcrow może ukrywać własne menu w nagłówku, gdy podłączona jest klawiatura lub mysz; zobacz **Ustawienia ▸ Wygląd ▸ Menu w nagłówku**.

## Z gładzikiem lub myszą

Kliknięcie prawym przyciskiem otwiera menu kontekstowe edytora. Przytrzymaj **Option** podczas przeciągania, aby zaznaczyć prostokąt tekstu.

## Menu kontekstowe edytora

Kliknij prawym przyciskiem na Macu lub naciśnij i przytrzymaj na iPadzie, w tekście. Pozycje, których aktywny profil składni nie potrafi wyrazić, są wyszarzone, a system dodaje własne pozycje (Wytnij, Kopiuj, Wklej, podpowiedzi pisowni, Wyszukaj i tak dalej).

Na **Macu**:

| Pozycja | Do czego służy |
| --- | --- |
| **Kopiuj / Wklej jako…** | **Kopiuj jako Markdown**, **Kopiuj jako zwykły tekst**, **Kopiuj jako kod HTML**, **Wklej jako zwykły tekst**. |
| **Akapit** | **Akapit**, **Nagłówek 1** do **6**, **Cytat blokowy**, **Lista punktowana**, **Lista numerowana**, **Lista zadań**, **Ogrodzenie kodu**. |
| **Format** | **Pogrubienie**, **Wyróżnienie**, **Kod**, **Przekreślenie**, **Wzór w wierszu**, **Wzór wyświetlany**, **Diagram**, **Wykres**, **Hiperłącze**. |
| **Zaznaczenie** | **Zaznacz słowo**, **Zaznacz wiersz**, **Zaznacz akapit**. |

Na **iPadzie** trzy podmenu znajdują się obok pozycji systemowych:

| Pozycja | Do czego służy |
| --- | --- |
| **Format** | Style śródwierszowe: pogrubienie, wyróżnienie, kod i pozostałe. |
| **Akapit** | Typy akapitów: nagłówki, cytat, listy, ogrodzenie kodu. |
| **Wstaw** | Te same wstawki co w menu **Więcej** paska formatowania, w tym **Wstaw alert**, **Wstaw obraz…** i **Wstaw tabelę…** oraz, w sekcji **Składnia**, własne konstrukcje aktywnego profilu. |
