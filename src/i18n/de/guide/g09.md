# Chapter 65: Das Assistentenfenster und die Stilprüfung

Das Assistentenfenster erscheint, sobald unter **Einstellungen ▸ Assistent** eine Verbindung eingerichtet ist (Chapter 67). Solange keine Verbindung bereit ist, fehlt der Eintrag **Assistent** im Menü Darstellung.

## Das Fenster

| Bedienelement | Was es bewirkt |
| --- | --- |
| **Assistentenmodus** | **Gespräch**, **Stilprüfung** oder **Hilfe**. |
| **Modell auswählen …** | Öffnet die Modellauswahl (siehe unten). Zeigt Warnungen, wenn das Modell nicht mehr verfügbar oder veraltet ist, mit dem Datum der Abschaltung. |
| **Unterhaltung löschen** | Leert die Unterhaltung. Unterhaltungen werden nicht gesichert; sie werden verworfen, wenn die App beendet wird. |
| **Was geteilt wird** | Legt fest, was mit Ihrer Frage mitgeschickt wird: **Nichts aus dem Dokument**, **Auswahl**, **Abschnitt**, **Um den Cursor**, **Ganzes Dokument**, **Gliederung** oder **Profil**. Eine Auswahl, die nicht möglich ist, nennt den Grund („Wählen Sie zuerst Text aus.“, „Dieses Dokument hat keine Überschriften.“, „Zu groß, um es ganz zu senden.“, „Kein Syntaxprofil.“). Eine Zeile über dem Fragefeld zeigt, wie viel an welchen Host gesendet wird. Die Auswahl wird gemerkt. |
| **Vorschau** (und **Was gesendet wird**) | Zeigt genau, was gesendet wird. |
| **Den Assistenten fragen …** / **Beschreiben Sie, was Sie schreiben möchten** | Das Fragefeld. Im Modus **Hilfe** wählen Sie unter **Was geschrieben wird** zwischen **Ein Syntaxprofil**, **Ein Makro** und **Ein Stilleitfaden**. |
| **Senden** und **Stopp** | Sendet die Anfrage oder bricht eine laufende Antwort ab. |
| **Datenschutz** | Zeigt, ob der Assistent für diesen Ordner eingeschaltet ist. **Für diesen Ordner ausschalten** und **Für diesen Ordner einschalten** schalten ihn um. „Diese Datei ist vom Assistenten ausgeschlossen.“ erscheint bei einer Datei, die auf einen Ausschluss passt. |
| Jede Antwort | **Kopieren**, **Am Cursor einfügen**, **Erneut versuchen** und, bei einer Antwort mit Stilleitfaden oder Makro, **Zur Bibliothek hinzufügen …**. Bei einer Antwort mit einem Fehler wird **Korrektur anfordern** angeboten. Eine abgebrochene Antwort weist darauf hin. |

## Ein Modell auswählen

**Modell auswählen …** listet die Modelle auf, die die Verbindung anbietet, mit **Modelle suchen**. **Alle Modelle anzeigen** nimmt auch die weniger gebräuchlichen auf. Ein veraltetes Modell ist mit dem Datum seiner Abschaltung gekennzeichnet. Wenn keine aufgelistet sind, geben Sie stattdessen den Namen des Modells ein. **Erneut versuchen** lädt die Liste neu.

## Stilprüfung

Im Modus **Stilprüfung** wendet das Fenster einen Stilleitfaden auf Ihren Text an.

| Bedienelement | Was es bewirkt |
| --- | --- |
| **Stilleitfaden**, **Variante** | Wählen Sie einen Leitfaden und eine seiner Varianten. |
| **Was geprüft wird** | **Auswahl** oder **Dokument**. Bei einem Dokument, das zu groß ist, um es ganz zu prüfen, steht: „Zu groß, um es ganz zu prüfen. Prüfen Sie stattdessen einen Abschnitt.“ |
| **Bereiche** | Wählen Sie, welche Bereiche geprüft werden, oder **Alle Bereiche**. |
| **Prüfen** | Sendet den Text und die Regeln an Ihre KI-Verbindung. Vor der Prüfung eines ganzen Dokuments nennt ein Hinweis, wie viele Anfragen gesendet werden und etwa wie viel Text, und fragt **Prüfen** oder **Abbrechen**. |
| **Hier prüfen** | Führt die eigenen Prüfungen des Leitfadens auf diesem Gerät aus. Es wird nichts gesendet. |
| **Querverweise prüfen** | Sendet die Überschriften, die zitierenden Zeilen und die Literaturlisten, um Regeln zu prüfen, die einen Teil des Dokuments mit einem anderen vergleichen. |
| **Stopp** | Bricht eine laufende Prüfung ab. **Rest prüfen** setzt nach einem Abbruch oder Fehler fort. |

Die Befunde erscheinen in einer Liste. Jeder zeigt das Zitat, eine Erklärung und, falls vorhanden, einen Korrekturvorschlag.

| Schaltfläche | Was sie bewirkt |
| --- | --- |
| **Gehe zu** | Springt im Dokument zum Befund. Bei einem Zitat, das mehrfach vorkommt, steht „Treffer N von N“. |
| **Anwenden** | Führt den Korrekturvorschlag aus. Das geschieht nur, wenn der Text noch genau so ist, wie er gefunden wurde. Andernfalls steht dort „Der Text hat sich geändert.“ oder „Im Text nicht gefunden.“ |
| **Schließen** | Entfernt den Befund. |
| **Alle anwenden** | Führt jede Korrektur aus, die einen Vorschlag hat, nach einer Bestätigung, die die Anzahl nennt, als eine einzige Änderung, die Sie in einem Schritt rückgängig machen können. Sie nennt auch, wie viele Korrekturen von der KI stammen. |
| **Alle Vorschläge verwerfen**, **Leeren** | Leeren die Liste. |

Das Fenster meldet außerdem „N Regeln können nur durch eine Prüfung beurteilt werden“, „N Regeln wurden nach 100 Befunden gestoppt“ und „Eine vorgeschlagene Änderung wurde weggelassen, weil sie Fakten hinzufügte, die der Text nicht enthält.“

# Part XVIII — Einstellungen im Überblick

# Chapter 66: Wie die Einstellungen aufgebaut sind

Öffnen Sie die Einstellungen über **Pilcrow ▸ Einstellungen …** (`⌘,`) auf dem Mac oder über das Zahnrad in der Kopfzeile auf dem iPad, wo sie sich als Blatt mit der Taste **Fertig** öffnen. Das Fenster hat links ein Feld **Einstellungen durchsuchen** und eine Liste von **Kategorien**. Jede Kategorie hat eine oder mehrere **Seiten**, die als Leiste von Tasten oben angezeigt werden.

| Kategorie | Seiten |
| --- | --- |
| **Allgemein** | Sprache und Fenster (iPad: **Sprache**), Dateien, Übersetzung, Assistent, Diagnose, Speicher und Datenschutz |
| **Bearbeitung** | Anzeige und Eingabe, Bilder |
| **Erscheinungsbild** | Theme und Hintergrund, Textgröße und Schriften |
| **Inhaltsverzeichnis** | Inhalt und Beschriftungen |
| **Exportieren** | Export-Standards |
| **Bibliothek** | Syntaxprofile, CommonMark-Optionen, Themes, Makros, Stilleitfäden, Rendering-Bibliotheken, Ort (auf dem iPad gibt es außerdem **Importieren**) |
| **Tastatur** | Kurzbefehle |
| **Abonnement & Guthaben** | Pilcrow unterstützen |

**Einstellungen durchsuchen** sucht ein Bedienelement nach seinem Namen. Geben Sie einen Teil einer Bezeichnung ein, etwa „Zeilenabstand“ oder „Versionen“, und die Ergebnisse zeigen das Bedienelement, seine Seite und seine Kategorie. Wählen Sie eines aus, um direkt dorthin zu gelangen. Änderungen wirken sofort; es gibt keine Taste „Sichern“, außer in den Editoren für Themes, Profile, Makros und Tastaturkurzbefehle.

Einstellungen, die nur einen Mac oder ein iPad betreffen, bleiben auf diesem Gerät. Ihre Bibliothek (Themes, Profile, Makros, Stilleitfäden und Hintergründe) kann in einen Ordner Ihrer Wahl verschoben werden, auch in einen in iCloud Drive (Chapter 71).

# Chapter 67: Allgemein

## Sprache und Fenster

| Bedienelement | Was es bewirkt |
| --- | --- |
| **Sprache** | Wählt die Sprache von Pilcrow, unabhängig von der des Geräts. **Systemstandard** folgt dem Gerät. Bei einer Sprache, die mit KI übersetzt wurde, steht „Maschinell übersetzt – kann Fehler enthalten.“ Die Änderung wird beim nächsten Öffnen von Pilcrow wirksam; auf dem Mac gibt es dazu die Taste **Jetzt beenden**. |
| **Übersetzungshinweis beim Start von Pilcrow anzeigen** | Schaltet den Hinweis „Mit KI übersetzt“ wieder ein, nachdem Sie **Nicht mehr anzeigen** gewählt haben. |
| **Pilcrow beenden, wenn das letzte Fenster geschlossen wird** (Mac) | Beendet die App, wenn Sie das letzte Fenster schließen, statt sie weiterlaufen zu lassen. |

## Dateien

| Bedienelement | Was es bewirkt |
| --- | --- |
| **Beim Start** | Was Pilcrow beim Start öffnet: **Neue Datei öffnen**, **Zuletzt geschlossene Ordner wiederherstellen**, **Zuletzt geschlossene Dateien und Ordner wiederherstellen** oder **Eigenen Ordner öffnen** (mit einer Taste **Auswählen…**). Beim Wiederherstellen wird geöffnet, was beim letzten Beenden der App auf dem Bildschirm war. Eine Datei, die inzwischen verschoben oder gelöscht wurde, wird übersprungen. |
| **Neue Dokumente sichern als** | Der Dateityp und damit das Syntaxprofil für ein neues Dokument: jedes Profil mit seiner Endung, zum Beispiel „CommonMark (.md)“. |
| **Änderungen automatisch sichern** | Sichert ein Dokument, das eine Datei hat, während Sie arbeiten. |
| **Beim Schließen ohne Nachfrage sichern** | Überspringt die Frage „Möchten Sie sichern?“ und sichert. |
| **Aufzubewahrende Versionen** | Wie viele gesicherte Versionen jeder Datei Pilcrow für den Versionsverlauf aufbewahrt, von keiner bis 500. Der Standard ist 50. „Aufzubewahrende Versionen: keine“ schaltet den Verlauf aus. |
| **Zuletzt benutzte Dateien und Ordner merken** | Lässt Pilcrow sich merken, was Sie geöffnet haben, für **Benutzte Dokumente** und für das Wiederherstellen beim Start. |
| **Ausgeblendete Ordner und Dateien anzeigen** | Zeigt Objekte, deren Namen mit einem Punkt beginnen, im Dateienfenster an. |
| **Wenn etwas auf die App gezogen wird** | Was geschieht, wenn Sie etwas auf den Editor oder die Seitenleiste ziehen: bei einem **Ordner** oder einer **Markdown-Datei** **Im Editor öffnen** oder **Link einfügen**; bei einer **Importierbare Datei** (ein Theme, Syntaxprofil oder eine Makrosammlung) **Im Editor öffnen**, **Link einfügen** oder **Datei importieren**. |

## Übersetzung

Für die Übersetzung ist macOS 15 oder iPadOS 18 oder neuer nötig.

| Bedienelement | Was es bewirkt |
| --- | --- |
| **Übersetzen in** | Ihre Standardzielsprache. Die erste Auswahl ist „Systemsprache“. |
| **Geschwindigkeit** | **Schnell**, **Beste Qualität** oder **KI-Assistent**. Schnell eignet sich für lange Dokumente und kann etwa zwanzigmal schneller sein, mit schlichterer Wortwahl; es braucht macOS oder iPadOS 26.4. **KI-Assistent** sendet den Text an Ihre Verbindung aus **Einstellungen ▸ Assistent**; Ihr Dienst kann dafür Kosten berechnen, und der Text verlässt das Gerät. |
| **Wenn eine Datei in einer anderen Sprache ist** | **Nichts tun**, **Übersetzung anbieten** oder **Automatisch übersetzen**. Pilcrow stellt die Sprache einer Datei beim Öffnen fest, und dafür verlässt nichts das Gerät. Das Angebot zeigt eine Leiste mit der Möglichkeit, in Ihre Standardsprache zu übersetzen. |
| **Für alle Dateien wieder anbieten** | Hebt die Dateien auf, für die Sie **Nie für diese Datei** gewählt haben. |
| **Nach dem Übersetzen** | **In einem neuen Tab öffnen**, **Kopie neben dem Original sichern** (benannt wie das Original, mit angehängter Sprache, etwa `Notes_fr.md`) oder **Dokument ersetzen** (lässt sich rückgängig machen). |
| **Sprachen auf diesem Gerät** | Listet jede Sprache mit **Auf diesem Gerät**, **Laden** oder **Nicht verfügbar**. Die Übersetzung nutzt Sprachpakete, die auf dem Gerät bleiben. Beim Laden eines Pakets wird das System um Erlaubnis gefragt; entfernen können Sie eines in den Spracheinstellungen des Systems. |

## Assistent

| Bedienelement | Was es bewirkt |
| --- | --- |
| **KI-Assistenten aktivieren** | Fügt das Assistentenfenster zur Seitenleiste hinzu. Es wird nichts gesendet, bis Sie fragen, und dann nur der Text, den Sie zum Teilen auswählen. |
| Eine Statuszeile | **Bereit.** oder der Grund, warum nicht: „Die Adresse der aktiven Verbindung ist nicht verwendbar.“, „Die aktive Verbindung benötigt einen API-Schlüssel.“ oder „Fügen Sie unten eine Verbindung hinzu. Der Assistentenbereich erscheint, sobald eine bereit ist.“ |
| **Verbindungen** | Die Liste der Verbindungen, mit „Noch keine Verbindungen.“, wenn sie leer ist. Jede zeigt ihren Namen und, bei der verwendeten, **Aktiv**. Eine Zeile bietet **Aktivieren**, **Bearbeiten …** und **Entfernen**. |
| **Verbindung hinzufügen** | Ein Menü: **OpenAI**, **Anthropic**, **OpenRouter**, **Ollama (dieser Computer)**, **LM Studio (dieser Computer)** oder **Benutzerdefiniert …**. |
| **Ausgeschlossene Dateien** | Muster für Dateien, die nie geteilt werden. `*` steht für beliebige Zeichen in einem Namen, `**` für beliebige Ordner, und ein Name mit `/` am Ende gilt für einen ganzen Ordner. Zu den Standardmustern gehören `*.pem`, `.env*`, `*.key` und `secrets/`. **Hinzufügen** eines Musters, **Entfernen** eines Musters oder **Standards wiederherstellen**. |
| **Ausgeschaltete Ordner** | Listet Ordner auf, in denen Sie den Assistenten ausgeschaltet haben, jeweils mit **Einschalten**. Zeigt „Keine Ordner sind ausgeschaltet.“, wenn es keine gibt. |
| **Datenschutz** | Ein Link zur Datenschutzerklärung von Pilcrow und **Alle KI-Daten löschen …**, was jede Verbindung und jeden gesicherten Schlüssel, die Unterhaltung und Ihre Datenschutzentscheidungen entfernt und den Assistenten ausschaltet. Es fragt vorher nach. |

Ihr API-Schlüssel wird nur auf diesem Gerät im Schlüsselbund gespeichert.

### Das Verbindungsformular

**Verbindung hinzufügen** und **Bearbeiten …** öffnen ein Formular.

| Feld | Was es bewirkt |
| --- | --- |
| **Name** | Eine Bezeichnung für die Verbindung. |
| **Format** | **OpenAI-kompatibel** oder **Anthropic**. |
| **Adresse** | Die Webadresse des Dienstes. Verwenden Sie `https://`, oder `http://` nur für diesen Computer oder Ihr lokales Netzwerk. |
| **Unverschlüsselte Verbindung in meinem lokalen Netzwerk erlauben** | Erlaubt eine `http://`-Adresse in Ihrem Netzwerk. Sie sendet Ihren Text und Ihren Schlüssel unverschlüsselt, erlauben Sie es also nur, wenn Sie dem Netzwerk vertrauen. |
| **Modell** | Das zu verwendende Modell, mit **Auswählen…**, um aus der Liste des Dienstes zu wählen. |
| **Benötigt einen API-Schlüssel** und **API-Schlüssel** | Ob der Dienst einen Schlüssel braucht, und der Schlüssel selbst, der im Schlüsselbund liegt. Lassen Sie das Feld beim Bearbeiten leer, um den gesicherten Schlüssel zu behalten. |
| **Verbindung testen** | Prüft Adresse, Schlüssel und Modell. Zeigt „Wird getestet …“ und dann „Verbunden (N ms).“ |
| **Abbrechen**, **Sichern** | Schließen oder behalten die Verbindung. |

## Diagnose

| Bedienelement | Was es bewirkt |
| --- | --- |
| **Diagnoseprotokoll aufzeichnen** | Zeichnet auf, was Pilcrow tut, damit Sie es an den Support senden können, wenn etwas schiefgeht. Es bleibt auf dem Gerät, bis Sie es teilen, und ist so gebaut, dass Ihr Dokumenttext und Ihre Dateinamen nicht enthalten sind. Solange es läuft, zeigt die Statusleiste eine rote Markierung **Protokoll läuft**. |
| **Aufzeichnung beenden nach** | **1 Stunde**, **24 Stunden** oder **Nie**. |
| **Was aufgezeichnet wird** | Eine Stufe für jeden Teil von Pilcrow: **Texteditor**, **Makros**, **Themes**, **Parsen und Profile**, **Darstellung und Diagramme**, **Exportieren und Drucken**, **Dateien und Bibliothek** und **App**. Jeder ist **Nur Probleme**, **Normal**, **Detailliert** oder **Alles**. Probleme und Fehler werden immer behalten. |
| **Problem reproduzieren** | Stellt jeden Teil auf „Detailliert“ und beginnt die Aufzeichnung. Lassen Sie das Problem erneut auftreten und schließen Sie dann den Bericht ab. |
| **Protokoll hinzufügen** | Wenn Sie einen Fehler melden: **Jedes Mal fragen**, **Immer hinzufügen** oder **Nie hinzufügen** der neuesten Einträge des Protokolls in Ihre Zwischenablage, um sie ins Formular einzufügen. |
| **Fehler melden …** | Dasselbe wie **Hilfe ▸ Fehler melden …**. |
| **In einen Bericht aufnehmen** | Schalter für **Geräte- und Systeminformationen**, **Pilcrow-Einstellungen**, **Dokumentstruktur (nur Anzahlen)**, **Geschwindigkeit und Speicher**, **Spur der letzten Aktionen** und **Absturzdetails**. Die Dokumentstruktur ist, wie viele Überschriften, Tabellen und so weiter das Dokument hat, nie seine Wörter. Von diesem Bildschirm aus wird nichts gesendet. |
| **Protokoll ansehen …** | Öffnet die Protokollansicht (siehe unten). |
| **Protokoll löschen …** | Löscht das aufgezeichnete Protokoll nach Rückfrage dauerhaft von diesem Gerät. Wenn Sie die Aufzeichnung ausschalten, bleibt das Aufgezeichnete erhalten, bis Sie es löschen. |

Während Sie ein Protokoll für einen Fehlerbericht aufzeichnen, beendet **Wird reproduziert — Bericht abschließen** (oder **Fehlerbericht abschließen** im Menü Hilfe) die Aufzeichnung und schließt den Bericht ab. In diesem Fall endet die Aufzeichnung von selbst nach 30 Minuten.

### Die Protokollansicht

**Diagnoseprotokoll** zeigt eine Zusammenfassung (**Einträge**, **Sitzungen**, **Fehler**, **Warnungen**, **Absturzberichte** und den Datumsbereich), danach die Einträge, die neuesten zuerst, mit einem Feld **Im Protokoll suchen** und Filtern für **Bereich** und **Stufe**. Filter ändern nur, was Sie sehen, nicht, was gesendet wird. Ein Bericht enthält jeden Eintrag im Protokoll plus das, was Sie unter „In einen Bericht aufnehmen“ gewählt haben. **Neu laden** aktualisiert die Ansicht. **Bericht senden** bietet:

| Eintrag | Was er bewirkt |
| --- | --- |
| **Bericht sichern …** | Behält eine Datei, die Sie selbst senden können. |
| **Bericht teilen …** | Öffnet das Teilen-Blatt (AirDrop, Dateien und so weiter). |
| **Auf GitHub melden …** | Öffnet ein neues Issue mit einer kurzen Zusammenfassung. Sie wählen **Protokoll zur Beschreibung hinzufügen** (die neuesten Einträge, bis zu 60.000 Zeichen, was alles ist, was GitHub erlaubt, in Ihre Zwischenablage kopiert zum Einfügen) oder **Sichern und Datei anhängen** (das ganze Protokoll, in einer Datei, die Sie selbst hinzufügen). Meldungen auf GitHub sind öffentlich. |

Wenn Sie einen Bericht beginnen, ohne dass etwas aufgezeichnet wurde, fragt Pilcrow **Das Problem zuerst aufzeichnen?**: **Problem zuerst aufzeichnen**, **Jetzt melden** oder **Abbrechen**. Wenn es das Formular öffnet, fragt es, ob **Protokoll hinzufügen und Formular öffnen**, **Protokoll immer hinzufügen** oder **Formular ohne Protokoll öffnen** gewünscht ist.

## Speicher und Datenschutz

Pilcrow hält Wiederherstellungskopien, Verlauf, Zugriffsfreigaben und Supportdaten in seiner Sandbox. Jede Kategorie kann einzeln gelöscht werden. Diese Bedienelemente löschen nie Ihre Dokumente.

| Abschnitt | Bedienelemente |
| --- | --- |
| **Dokumente** | **Wiederherstellungsdaten prüfen** und **Versionsverlauf prüfen**. „Prüfen“ listet die betroffenen Objekte mit ihren Größen auf, sodass Sie den Platz sehen, bevor Sie etwas löschen. Haken Sie die zu löschenden an (**Alles auswählen** oder **Nichts auswählen**) und wählen Sie **Auswahl löschen**. Wiederherstellungsdaten können nicht geprüft werden, solange ein Dokument ungesicherte Änderungen hat: Sichern oder schließen Sie es zuerst. |
| **Dateizugriff** | **Zugriff auf zuletzt geöffnete Dateien löschen …** entfernt Listen zuletzt benutzter Dateien, gemerkte Ordner für „Sichern unter“, Sitzungslesezeichen und Syntaxwahlen pro Datei. |
| **Private Daten und Supportdaten** | **KI-Daten und Schlüssel löschen …** (Verbindungen, Schlüssel im Schlüsselbund, die aktuelle Unterhaltung und KI-Datenschutzentscheidungen), **Diagnosedaten löschen …** (aufgezeichnete Protokolle und gesicherte Absturzdiagnosen) und **Caches leeren …** (wiederherstellbare Cache-Dateien und Netzwerkantworten). |

Jedes Löschen verlangt eine Bestätigung („Dies kann nicht rückgängig gemacht werden. Ihre Dokumente werden nicht gelöscht.“). Eigene Syntaxprofile, Themes, Makros, Stilleitfäden und Hintergründe werden hier nicht entfernt; prüfen und löschen Sie sie auf ihren eigenen Bibliotheksseiten.
