# Chapter 55: Die Menüs „Darstellung“ und „Fenster“

Das Menü „Darstellung“ steuert die Bedienfelder, den Modus, die Größe und die Darstellung des Editors. Seine Kürzel lassen sich unter **Einstellungen ▸ Tastatur** ändern, soweit nicht anders vermerkt.

## Bedienfelder und Modus

| Eintrag | Kürzel | Was er bewirkt |
| --- | --- | --- |
| **Formatierungsleiste** | | Blendet die optionale Reihe mit Formatierungsschaltflächen unter dem Text ein oder aus. In der Vorschau ausgegraut. |
| **Seitenleiste ein-/ausblenden** | `⇧⌘L` | Blendet die gesamte Seitenleiste ein oder aus. |
| **Gliederung** | `⌃⌘1` | Zeigt das Bedienfeld „Gliederung“. Wird er erneut gewählt, blendet er die Seitenleiste aus. |
| **Dateien** | `⌃⌘3` | Zeigt das Bedienfeld „Dateien“ (den Dateibaum). |
| **Suchen** | `⇧⌘F` | Zeigt das Bedienfeld „Suchen“ für den Ordner. |
| **Assistent** | `⌃⌘4` | Zeigt das Bedienfeld „Assistent“. Erscheint erst, nachdem eine Assistentenverbindung eingerichtet wurde. |
| **Vorschau** | `⇧⌘P` | Wechselt zur gerenderten Seite. |
| **Nebeneinander** | `⌃⌘P` | Zeigt Quelltext und Vorschau zusammen. |
| **Fokusmodus** | keines | Blendet alles außer dem Text aus. |

## Größe

| Eintrag | Kürzel |
| --- | --- |
| **Originalgröße** | `⇧⌘0` |
| **Vergrößern** | `⇧⌘=` |
| **Verkleinern** | `⇧⌘-` |

Der Zoom geht durch voreingestellte Stufen und wird gemerkt. Er skaliert den Editor und die Vorschau.

## Darstellung des Editors

Jeder dieser Einträge ist ein Schalter. Dieselben Schalter finden sich unter **Einstellungen ▸ Bearbeitung** (Chapter 68).

| Eintrag | Kürzel | Was er bewirkt |
| --- | --- | --- |
| **Zeilennummern** | `⌥⌘L` | Zeigt Zeilennummern am Rand. |
| **Linie unter der aktuellen Zeile** | | Zeichnet eine dünne Linie unter die Zeile, in der die Einfügemarke steht. Die Farbe der Linie stammt vom App-Theme. |
| **Zeilen umbrechen** | | Umbricht lange Zeilen am Fensterrand. Ist er aus, scrollen sie seitwärts. Sehr lange Zeilen und der Fokusmodus werden unabhängig davon umbrochen. |
| **Formatierter Quelltext** | | Zeichnet Überschriften, fetten und kursiven Text in einer passenden Schrift, im Look der Syntax, statt als reinen Quelltext. |
| **Markierungen ausblenden** | | Blendet bei eingeschaltetem „Formatierter Quelltext“ die Zeichen für Überschriften, Fett und Kursiv (das `#`, das `**`) in jeder Zeile aus, außer in der, in der die Einfügemarke steht. Ausgegraut, wenn „Formatierter Quelltext“ aus ist. |
| **Gerenderte Blöcke** | | Zeichnet Tabellen, Gleichungen und Diagramme als Bilder anstelle ihres Quelltexts, jeweils mit einer Bearbeiten-Schaltfläche. |
| **Überschriften falten** | | Fügt neben jeder Überschrift einen Faltpfeil am Rand hinzu, sodass sich ihr Abschnitt einklappen lässt, in jedem Syntaxprofil. |
| **Alle falten**, **Alle entfalten** | | Klappt den Abschnitt jeder Überschrift ein oder aus. Ausgegraut, solange „Überschriften falten“ nicht an ist. |
| **Abschnitte automatisch aufklappen** | | Öffnet einen gefalteten Abschnitt oder einen als Bild gezeichneten Block, wenn die Einfügemarke dorthin gelangt, und schließt ihn wieder, wenn sie ihn verlässt. Ist er aus, springen die Pfeiltasten nach oben und unten darüber hinweg, und der Abschnitt bleibt, wie er ist. |

## Theme

**Darstellung ▸ Theme** wählt mit einem Häkchen das **App-Theme** (Automatisch, Hell, Dunkel) und das **Render-Theme** (Hell, Dunkel). Themes, die Sie hinzufügen, erscheinen hier ebenfalls. Siehe Chapter 40.

Das System fügt außerdem **Vollbildmodus aktivieren** hinzu.

## Menü „Fenster“

| Eintrag | Kürzel | Was er bewirkt |
| --- | --- | --- |
| **Geöffnete Dokumente** | `⌃⌘2` | Öffnet den Dokumentwechsler. |

# Chapter 56: Das Menü „Einfügen“

Alles unter „Einfügen“ setzt Quelltext an der Einfügemarke in das Dokument, geschrieben in der eigenen Notation des aktiven Syntaxprofils. Einträge, die das Profil nicht ausdrücken kann, sind ausgegraut, und in der Vorschau ist jeder Eintrag aus.

| Eintrag | Was er bewirkt |
| --- | --- |
| **Tabelle…** | Öffnet den Dialog „Tabelle einfügen“ (Chapter 63). Kürzel `⌥⌘T`. |
| **Bild…** | Wählt ein Bild aus und fügt es ein, wobei die Bildeinstellungen angewendet werden (Chapter 68). Kürzel `⇧⌘I`. |
| **Diagramme** | Ein Untermenü mit fertigen Mermaid-Diagrammen (unten). |
| **Datendiagramme** | Ein Untermenü mit fertigen Vega-Lite-Diagrammen (unten). |
| **Gleichungen** | Ein Untermenü mit fertigen Gleichungen (unten). |
| **Codeblock** | Fügt einen umzäunten Codeblock ein. |
| **Hinweis** | Ein Untermenü: **Hinweis**, **Tipp**, **Wichtig**, **Warnung**, **Vorsicht**. |
| **Horizontale Linie** | Fügt einen thematischen Umbruch ein. |
| **Link-Referenz** | Fügt einen Link im Referenzstil und seine Definition ein. |
| **Fußnote** | Fügt eine Fußnotenmarke und ihre Definition ein. |
| **Inhaltsverzeichnis** | Fügt eine `[TOC]`-Zeile ein, die zu einer erzeugten Inhaltsliste wird. |
| **YAML-Front-Matter** | Fügt am Dateianfang einen Front-Matter-Block ein. |
| **Feld** | Fügt für Super Tab eine auszufüllende Lücke ein, ausgewählt, damit Sie sie benennen können (Chapter 24). |

Darunter folgt nach einer Trennlinie die Liste der **eigenen Konstrukte des aktiven Profils**, etwa ein Admonition-Block oder ein benutzerdefinierter Block, den das Profil definiert. Ist kein Profil gewählt, steht im Menü „Syntaxprofil auswählen, um Konstrukte einzufügen“.

## Diagrammvorlagen

Einfügen ▸ Diagramme bietet 17 Ausgangspunkte. Jeder fügt ein funktionierendes Beispiel zum Bearbeiten ein.

Flowchart, Sequence Diagram, Class Diagram, State Diagram, Entity Relationship Diagram, Gantt Chart, Pie, User Journey, Git Graph, Mind Map, Timeline, Quadrant Chart, Sankey Diagram, XY Chart, Block Diagram, Packet Diagram und Kanban Board.

## Diagrammvorlagen für Daten

Bar Chart, Line Chart, Area Chart, Scatter Plot, Pie Chart, Stacked Bar Chart, Histogram, Heatmap und Box Plot.

## Gleichungsvorlagen

Fraction, Square Root, Summation, Integral, Limit, Quadratic Formula, Matrix, Piecewise Function, Aligned Equations, Binomial Coefficient, Bayes' Theorem und Euler's Identity.

Auf dem iPad wird ein Einfügen-Eintrag, dessen Name auch im Untermenü „Absatz“ vorkommt (Hinweis, Horizontale Linie, Link-Referenz, Fußnote, Inhaltsverzeichnis, YAML-Front-Matter), als „Hinweis einfügen“ und so weiter angezeigt, weil das iPad Menüeinträge mit gleichem Namen zusammenführt.

# Chapter 57: Das Menü „Format“

Das Menü „Format“ wendet über das aktive Syntaxprofil Stile auf die Auswahl oder auf die Zeile an, in der die Einfügemarke steht. Hat das Profil keine Möglichkeit, einen Stil zu schreiben, ist der Eintrag samt Kürzel ausgegraut, sodass ein Befehl nie Syntax einfügt, die das Profil nicht wieder einliest. In der Vorschau ist jeder Eintrag aus.

## Zeichenstile

| Eintrag | Kürzel | Was er bewirkt |
| --- | --- | --- |
| **Fett** | `⌘B` | Fett. |
| **Betonung** | `⌘I` | Kursiv. |
| **Durchgestrichen** | `⌃⇧`` ` `` | Durchgestrichener Text. |
| **Code** | `` ⌃` `` | Inline-Code. |
| **Hervorhebung** | keines | Markierter Text. Dafür muss **Bibliothek ▸ CommonMark-Optionen ▸ Hervorhebung** eingeschaltet sein. |

| **Formatierung entfernen** | `⌘\` | Entfernt die Formatierung der Auswahl. |

## Die Menüleiste auf dem iPad

Ein iPad hat eine eigene Menüleiste, die erscheint, wenn Sie **⌘** gedrückt halten oder einen Zeiger an den oberen Bildschirmrand bewegen. Sie enthält dieselben Befehle wie die Menüs des Mac, aus denselben Definitionen, mit denselben änderbaren Kürzeln. Nur **Datei** ist anders, weil das Menü „Datei“ des Mac AppKit-Fenster verwendet.

Für ein iPad ohne Tastatur oder Maus kann Pilcrow dieselben Menüs in seiner Kopfleiste zeigen. **Einstellungen ▸ Erscheinungsbild ▸ Menüs in der Kopfzeile** bietet die Auswahl:

| Auswahl | Wirkung |
| --- | --- |
| **Automatisch** | Zeigt die Menüs, sofern keine Tastatur und keine Maus angeschlossen ist. |
| **Immer** | Zeigt sie immer. |
| **Nie** | Zeigt sie nie. |

In einem Fenster mit 1.100 Punkt Breite oder mehr stehen die sechs Menüs nebeneinander: **Datei**, **Bearbeiten**, **Einfügen**, **Format**, **Darstellung** und **Hilfe**. In einem schmaleren Fenster werden sie zu einer einzigen Schaltfläche **Menü** zusammengefasst. Die Leiste ist eine schlankere Version der Menüleiste:

- **Datei** ergänzt die üblichen Einträge um **Ordner öffnen …**, **Exportieren…** und **Drucken…**.
- **Bearbeiten** enthält **Widerrufen**, **Wiederholen**, die Kopierbefehle, **Suchen**, **Rechtschreibung und Grammatik**, **Auswahl**, **Übersetzen**, **Gehe zu Zeile …**, **Links prüfen …**, **Befehlspalette …**, **Zurück** und **Vorwärts**.
- **Format** enthält die Zeichenstile, das Untermenü **Absatz**, **Tabelle einfügen…** und **Bild einfügen…**.
- **Darstellung** enthält **Formatierungsleiste**, **Seitenleiste ein-/ausblenden**, **Gliederung**, **Dateien**, **Suchen**, den Dokumentmodus, **Fokus**, **Zeilennummern**, **Linie unter der aktuellen Zeile**, **Formatierter Quelltext**, **Überschriften falten** und **Geöffnete Dokumente**. Für die übrigen Darstellungsschalter verwenden Sie **Mehr** oder die Einstellungen.
- **Hilfe** enthält **Pilcrow-Hilfe**, **Fehler melden …** und **Fehlerbericht abschließen**.

# Chapter 59: Der Dokumenttitel und der Dokumentwechsler

Der Name des Dokuments steht in der Kopfleiste mit einem kleinen farbigen Punkt und einem Pfeil nach unten. Klicken Sie darauf oder wählen Sie **Darstellung ▸ Geöffnete Dokumente** (`⌃⌘2`), um die Liste **Geöffnete Dokumente** zu öffnen. Auf einem kleinen Bildschirm öffnet sie sich als Blatt mit einer Schaltfläche **Fertig**.

## Der Sichern-Punkt

Der Punkt neben dem Namen zeigt auf einen Blick den Zustand des Dokuments. VoiceOver liest den Zustand ebenfalls vor.

| Punkt | Bedeutung |
| --- | --- |
| Grün | **Gesichert.** Die Datei auf dem Datenträger stimmt mit dem überein, was Sie sehen. |
| Gelb | **Bearbeitet.** Sie haben Änderungen, die noch nicht gesichert sind. |
| Rot | **Sichern fehlgeschlagen.** Pilcrow hat versucht zu sichern und konnte es nicht. Über dem Editor erscheint ein Hinweis **Sichern nicht möglich** mit einer Schaltfläche **Erneut versuchen**. |
| Blau | **Von einer anderen App geändert.** Die Datei auf dem Datenträger wurde von außerhalb von Pilcrow geändert. |

Ein Dokument, das nie gesichert wurde, zeigt in der Liste „Noch nicht gesichert“ und eine Nummer, da es keinen Ordner anzuzeigen gibt. Ein Dokument mit ungesicherten Änderungen trägt außerdem am Ende seiner Zeile den Vermerk **Bearbeitet**.

## Die Liste „Geöffnete Dokumente“

| Teil | Was er bewirkt |
| --- | --- |
| **Geöffnete Dokumente durchsuchen** | Erscheint, wenn sieben oder mehr Dokumente geöffnet sind. Geben Sie einen Teil eines Namens oder Ordners ein; jedes Wort muss irgendwo im Namen oder im Ordner vorkommen, ohne Beachtung von Groß- und Kleinschreibung und von Akzenten. Mit der Eingabetaste öffnen Sie die erste Übereinstimmung. Wenn nichts passt, steht dort „Keine geöffneten Dokumente passen.“ |
| Eine Zeile für jedes Dokument | Zeigt den Namen, seinen Sichern-Punkt und den Ordner, in dem es liegt. Ein Häkchen markiert das aktive Dokument. Ein Klick auf eine Zeile wechselt zu diesem Dokument. |
| **Schließen** (das **x** am Ende einer Zeile) | Schließt dieses Dokument und fragt vorher nach, falls es ungesicherte Änderungen hat. |
| **Neues Dokument** | Erstellt ein unbenanntes Dokument. |
| **Sichern** | Sichert das aktive Dokument. |
| **Sichern unter…** | Sichert unter einem neuen Namen oder an einem neuen Ort. |
| **Umbenennen…** | Öffnet das Formular zum Umbenennen (unten). |
| **Alle Dokumente schließen** | Schließt jedes Dokument und fragt bei jedem ungesicherten nach. |

Mit `⌃Tab` und `⌃⇧Tab` wechseln Sie zum nächsten oder vorherigen Dokument, ohne die Liste zu öffnen.

## Umbenennen

**Umbenennen…** zeigt den aktuellen **Namen** und den **Ort**, an dem die Datei liegt, mit den Schaltflächen **Abbrechen** und **Umbenennen**. Das Umbenennen ändert die Datei auf dem Datenträger und lässt das Dokument geöffnet. Lässt sich der neue Name nicht verwenden, erklärt die Meldung **Dokument konnte nicht umbenannt werden**, warum.
