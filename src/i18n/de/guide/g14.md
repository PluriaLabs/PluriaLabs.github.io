# Part XXI — Dateiformate und Grenzen

# Chapter 79: Das App-Theme-Format

Ein **App-Theme** gestaltet Pilcrow selbst: das helle oder dunkle Erscheinungsbild, die Akzentfarbe, die Seitenleiste, die Status- und Formatierungsleisten und den Editor. Es ist eine JSON-Datei. Gerenderte Dokumente (Vorschau, HTML, PDF, Bild, Druck und Word) werden getrennt davon durch ein **Render-Theme** gestaltet, das aus CSS besteht (Chapter 80). Die beiden Arten werden getrennt installiert, ausgewählt und gelöscht, und keine folgt der anderen.

## Ein vollständiges Beispiel

```json
{
  "pilcrowAppTheme": 1,
  "name": "Nord",
  "appearance": "dark",
  "colors": {
    "accent": "#88C0D0",
    "sidebar": { "background": "#2E3440", "foreground": "#D8DEE9" },
    "bars": { "background": "#3B4252", "foreground": "#D8DEE9" },
    "editor": {
      "background": "#2E3440",
      "foreground": "#ECEFF4",
      "cursor": "#88C0D0",
      "selection": "#434C5E",
      "gutterBackground": "#2E3440",
      "gutterForeground": "#4C566A"
    },
    "syntax": {
      "heading": "#88C0D0",
      "marker": "#EBCB8B",
      "code": "#A3BE8C",
      "link": "#81A1C1",
      "muted": "#7B88A1",
      "tokens": { "strong": "#D08770" }
    }
  }
}
```

## Oberste Ebene

| Schlüssel | Erforderlich | Wert |
| --- | --- | --- |
| `pilcrowAppTheme` | ja | Die Formatversion, `1`. |
| `name` | ja | 1–200 Zeichen. Wird in den Einstellungen und im Menü „Themes“ angezeigt. |
| `appearance` | ja | `"light"`, `"dark"` oder `"automatic"`. |
| `colors` | Themes `light` und `dark` | Eine Palette (unten). |
| `light`, `dark` | Themes `automatic` | Zwei Paletten: eine für das helle Erscheinungsbild des Systems, eine für das dunkle. |
| `id` | nein | Wird von Pilcrow für die eigene Bibliothek geschrieben. Beim Import ignoriert; es wird immer eine neue ID vergeben. |

`appearance` bestimmt das Erscheinungsbild **jedes** Fensters, einschließlich Menüs, Einstellungen, Blättern und Auswahlfenstern. Ein Theme `light` oder `dark` legt es fest; `automatic` folgt dem System.

Ein automatisches Theme muss jede Farbe in `light` und `dark` setzen oder in keinem von beiden. Eine Farbe, die nur für ein Erscheinungsbild gesetzt ist, würde sonst auch im anderen gezeichnet.

## Palette

Jeder Schlüssel ist optional. Eine weggelassene Farbe behält das integrierte Aussehen von Pilcrow, sodass ein Theme so klein sein kann wie eine einzige Akzentfarbe.

| Schlüssel | Gestaltet |
| --- | --- |
| `accent` | Die Tönung der ganzen App: Schaltflächen, ausgewählte Segmente, Schalter, Links, Fokusringe und die ausgewählte Zeile der Seitenleiste. Ohne Angabe bleibt der Systemakzent. |
| `sidebar.background`, `sidebar.foreground` | Die Seitenleiste mit Dateien, Gliederung und Suche. Sekundäre Beschriftungen werden vom Vordergrund abgeleitet. |
| `bars.background`, `bars.foreground` | Die Statusleiste, die angedockte Formatierungsleiste und Importhinweise. Sekundäre Beschriftungen werden vom Vordergrund abgeleitet. |
| `editor.background`, `editor.foreground` | Die Editorfläche und der Fließtext. |
| `editor.cursor`, `editor.selection` | Die Einfügemarke und die Hervorhebung der Auswahl. |
| `editor.gutterBackground`, `editor.gutterForeground` | Die Spalte mit den Zeilennummern. Der Hintergrund entspricht standardmäßig dem Editorhintergrund. |
| `editor.currentLineRule` | Die dünne Linie unter der Zeile, in der sich die Einfügemarke befindet, wenn **Darstellung ▸ Linie unter der aktuellen Zeile** eingeschaltet ist. Standardmäßig die Textfarbe des Editors in geringer Stärke. |
| `syntax.<group>` | Live-Syntaxfarben nach Gruppe (unten). |
| `syntax.tokens.<raw>` | Ein einzelnes Token über seinen Rohwert, das seine Gruppe überschreibt. |

### Syntaxgruppen

| Gruppe | Färbt |
| --- | --- |
| `heading` | Überschriften (Markierungen und Text), Hinweismarkierungen, Definitionsbegriffe |
| `marker` | Betonung, Fettdruck, Durchstreichung und andere Inline-Begrenzer; Listen- und Aufgabenmarkierungen |
| `code` | Inline-Code, umzäunte und eingerückte Codeblöcke, Formeln, HTML-Blöcke |
| `link` | Beschriftungen und Ziele von Links und Bildern, Autolinks |
| `muted` | Zitatmarkierungen, Trennlinien, Tabellenzeilen, Kommentare, Blockattribute |
| `codeKeyword`, `codeString`, `codeNumber`, `codeComment` | Hervorgehobener Code innerhalb eines Fence |

Eine nicht gesetzte Gruppe erhält eine integrierte Farbe, die passend zum Editorhintergrund gewählt wird: dunklere Töne auf einer hellen Fläche, hellere Töne auf einer dunklen. Tokennamen in `syntax.tokens` bestehen aus Buchstaben, Ziffern, `_` und `-` und dürfen keinen Gruppennamen wiederholen (`syntax.heading` deckt `heading` bereits ab).

## Farben

Jede Farbe ist eine Hex-Zeichenfolge: `#RGB`, `#RGBA`, `#RRGGBB` oder `#RRGGBBAA`, in sRGB. Pilcrow speichert sie in Großbuchstaben.

## Validierung

Pilcrow lehnt eine Datei ab, statt einen Teil davon zu ignorieren, und nennt den fehlerhaften Schlüssel, zum Beispiel `colors.editor.cursor: must be a hex colour`. Abgelehnt wird:

- eine fehlende oder abweichende `pilcrowAppTheme`-Version;
- ein unbekannter Schlüssel auf irgendeiner Ebene (meist ein Tippfehler);
- ein Palettenschlüssel, der nicht zum Erscheinungsbild passt (`colors` in einem automatischen Theme, `light` und `dark` in einem hellen oder dunklen);
- eine Farbe, die kein Hex-Wert ist;
- ein automatisches Theme, dessen Paletten `light` und `dark` unterschiedliche Farben setzen.

## Was ein App-Theme nicht ändert

Die Titelleiste und die Symbolleiste des Fensters (das Glas des Systems, das nur den Akzent übernimmt), Menüs, Einstellungen, Blätter und Auswahlfenster behalten ihr natives Aussehen, abgesehen von Erscheinungsbild und Akzent. Schriften werden nicht über Themes gestaltet: Schrift und Größe des Editors legst du unter **Einstellungen ▸ Erscheinungsbild ▸ Textgröße und Schriften** fest.

## Installieren und Teilen

- **Importiere** eine `.json`-Datei über **Einstellungen ▸ Bibliothek ▸ Themes**, auf dem Mac über **Datei ▸ Importieren ▸ Theme** oder auf dem iPad über **Einstellungen ▸ Bibliothek ▸ Importieren**. Die Datei auf Pilcrow zu ziehen funktioniert ebenfalls.
- Ein `.zip`-Themenpaket kann App-Themes neben Render-Themes enthalten (Chapter 80).
- Die Teilen-Schaltfläche neben einem Theme sichert seine `.json`-Datei oder das ganze Paket, wenn das Theme aus einem stammt.

Pilcrow enthält drei App-Themes: **Automatisch**, **Hell** und **Dunkel**. Sie legen die Farben von Editor und Syntax fest und lassen die Oberfläche beim integrierten Aussehen.

# Chapter 80: Die CSS-Referenz für Render-Themes

Ein **Render-Theme** besteht aus CSS. Es gestaltet die Ausgabe von Vorschau, HTML, PDF, Bild und Druck sowie die Word-Formate, die am Ende dieses Kapitels aufgeführt sind. Ein Render-Theme kann eine einzelne `.css`-Datei oder Teil eines ZIP-Pakets mit lokalen Ressourcen sein. Syntaxprofile legen fest, wie aus Quelltext das Dokument wird; Render-Themes gestalten nur das Ergebnis. CSS gestaltet nie die App oder den Editor; das ist Aufgabe des App-Themes (Chapter 79).

## Die Kaskade

Pilcrow wendet Stile in dieser Reihenfolge an:

1. der strukturelle Reset von Pilcrow;
2. das CSS des gewählten Themes;
3. einmaliges CSS aus dem Exportbereich (**Erweiterte Optionen ▸ Eigenes CSS**);
4. erforderliche Korrekturen für Druck und Darstellung.

Spätere Regeln setzen sich nach der üblichen CSS-Kaskade durch. Theme-JavaScript, entfernte Ressourcen, `file:`-URLs und `@import` werden nicht unterstützt.

## Ressourcen

Pilcrow liest Theme-CSS mit einem Standard-CSS-Tokenizer, sodass Escapes dekodiert werden, bevor irgendetwas geprüft wird: `u\72 l(…)` ist ein `url()` und `@im\70 ort` ist ein `@import`. Jede Stelle, von der ein Browser laden würde, wird geprüft: `url(…)`, `url("…")`, `src("…")` und Zeichenfolgen innerhalb von `image-set()`. Jede muss eine der folgenden sein:

- ein paketrelativer Pfad (`fonts/Body.woff2`, `./paper.png`). Ein `?query` oder `#fragment` ist erlaubt und wird beim Suchen der Datei ignoriert;
- eine `data:`-URL vom Typ PNG, JPEG, GIF, WebP, SVG (`image/svg+xml`), TTF, OTF, WOFF oder WOFF2;
- ein Fragmentverweis wie `url(#shadow)`, der ein Element auf der Seite benennt.

Alles mit einem anderen Schema als `data:` (`https:`, `file:`, `blob:`) oder mit einem Anfang `//` wird abgelehnt, ebenso ein Pfad, der mit `/` beginnt oder `..` enthält.

## Render-Eigenschaften

Der integrierte Reset liest diese Eigenschaften und liefert Ersatzwerte:

| Gruppe | Eigenschaften |
| --- | --- |
| Farbe | `--pt-background`, `--pt-foreground`, `--pt-secondary-background`, `--pt-secondary-foreground`, `--pt-accent`, `--pt-link-color`, `--pt-border-color` |
| Code | `--pt-code-background`, `--pt-code-foreground`, `--pt-code-keyword`, `--pt-code-string`, `--pt-code-number`, `--pt-code-comment` |
| Schrift | `--pt-body-font-family`, `--pt-mono-font-family`, `--pt-base-font-size`, `--pt-line-height` |
| Abstände | `--pt-paragraph-spacing`, `--pt-blockquote-indent`, `--pt-list-indent`, `--pt-code-padding`, `--pt-heading-top`, `--pt-heading-bottom` |
| Tabellen | `--pt-table-header-background`, `--pt-table-stripe-background` |
| Hinweise | `--pt-admonition-note-color`, `--pt-admonition-tip-color`, `--pt-admonition-important-color`, `--pt-admonition-warning-color`, `--pt-admonition-caution-color` |

## ZIP-Pakete

Ein ZIP-Paket kann Render-Themes (`.css`) und App-Themes (`.json`) zusammen enthalten; jedes wird in den Einstellungen mit seiner eigenen Art aufgeführt. Ein ZIP mit höchstens einer CSS-Datei und höchstens einem App-Theme braucht kein Manifest. Alles darüber hinaus braucht `pilcrow-theme.json`, das jedes Theme unter `variants[].file` aufführt. Die Dateiendung bestimmt die Art der Datei:

```json
{
  "id": "com.example.paper",
  "name": "Paper",
  "version": "1.0.0",
  "author": "Example Author",
  "license": "MIT",
  "cssAPIVersion": 1,
  "variants": [
    { "id": "app", "name": "Paper", "file": "Paper.json", "appearance": "automatic" },
    { "id": "light", "name": "Paper Light", "file": "Paper-Light.css", "appearance": "light" },
    { "id": "dark", "name": "Paper Dark", "file": "Paper-Dark.css", "appearance": "dark" }
  ]
}
```

Das Manifest beschreibt das Paket und seine Themes. Es enthält nie Stilwerte: Diese stehen in den CSS- und App-Theme-Dateien.

- Die Paket-`id` benennt den Installationsordner. Sie darf nicht mit `.` beginnen und keine führenden oder nachgestellten Leerzeichen haben. Wird ein Paket installiert, dessen `id` bereits installiert ist, ersetzt es dieses.
- Ein mit **Komprimieren** im Finder erstelltes ZIP funktioniert unverändert. Pilcrow überspringt `__MACOSX/`, `._*`, `.DS_Store` und `Thumbs.db`, und wenn alle Dateien in einem einzigen Ordner der obersten Ebene liegen, wird dieser Ordner als Paketwurzel behandelt.
- Wenn du ein einzelnes Theme löschst, wird es aus dem Paket entfernt, und die anderen bleiben samt den gemeinsamen Ressourcen erhalten. Wenn du das letzte Theme löschst, wird das Paket entfernt. Ein gelöschtes Theme, das ausgewählt war, setzt die Auswahl auf den Standard seiner Art zurück: Automatisch beim App-Theme, Hell beim Render-Theme.
- CSS kann mit relativen `url(...)`-Pfaden auf gepackte PNG-, JPEG-, GIF-, WebP-, TTF-, OTF-, WOFF- und WOFF2-Dateien verweisen. Pilcrow prüft ihre Signaturen und bettet referenzierte Ressourcen als Daten-URLs ein, damit Darstellung und exportiertes HTML offline und in sich geschlossen bleiben. ZIP-Pfade dürfen das Paket nicht verlassen, sich nicht nur in der Groß-/Kleinschreibung unterscheiden und nicht auf Links zeigen. Archivgröße, Anzahl der Einträge, Einzelgröße und Kompressionsverhältnis sind begrenzt.

## Word

Der Word-Export verwendet die hellen (Basis-)Werte von `:root` und bildet diese semantischen Eigenschaften auf benannte Word-Formate ab: `--pt-foreground`, `--pt-background`, `--pt-accent`, `--pt-link-color`, `--pt-code-background`, `--pt-code-foreground`, `--pt-body-font-family`, `--pt-mono-font-family`, `--pt-base-font-size` und `--pt-line-height`. Browser-Selektoren und Layoutregeln haben in Word keine allgemeine Entsprechung. Vorschau, HTML, PDF und Bildausgabe verwenden das vollständige Stylesheet; Word verwendet diese Teilmenge und bewahrt dabei Dokumentstruktur, Diagramme, Formelbilder, Links und Medien. Der Exportbereich zeigt diese Einschränkung, sobald Word ausgewählt ist.

Pilcrow enthält zwei Render-Themes, **Hell** und **Dunkel**, die vollständige Ausgangspunkte sind.
