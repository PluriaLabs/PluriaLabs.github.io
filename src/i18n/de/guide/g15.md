# Chapter 81: Dateien, Codierungen und Grenzen

## Dateien, die Pilcrow öffnet

Pilcrow bearbeitet Reintext- und Auszeichnungsdateien. Die üblichen Erweiterungen sind `txt`, `md`, `markdown`, `adoc`, `asciidoc`, `rst` und `tex` sowie jede Erweiterung, die ein von Ihnen hinzugefügtes Profil beansprucht. Pilcrow erkennt die Textcodierung einer Datei beim Öffnen.

| Element | Typ |
| --- | --- |
| Syntaxprofil, Makrosammlung, Styleguide, App-Theme | `.json` |
| Render-Theme | `.css` |
| Theme-Paket | `.zip` |
| Manifest eines Buchprojekts | `manifest.pilcrow` |
| Hintergrund | HEIC, PNG, JPEG, SVG, MP4, MOV, M4V |
| Tippgeräusch-Clip | WAV, AIFF, MP3, M4A, CAF |

## Textcodierungen

Pilcrow liest Text in UTF-8, UTF-16, UTF-32 und ISO 8859-1 (Latin-1). Mit **Dokumentinformationen ▸ Codierung ▸ Konvertieren in …** können Sie ein Dokument in eine der folgenden Codierungen umwandeln; die Datei wird beim nächsten Sichern konvertiert:

UTF-8, UTF-8 (BOM), UTF-16 LE, UTF-16 LE (BOM), UTF-16 BE, UTF-16 BE (BOM), UTF-32 LE, UTF-32 LE (BOM), UTF-32 BE, UTF-32 BE (BOM).

Eine Latin-1-Datei lässt sich verlustfrei in jede davon konvertieren. Die Konvertierung nach Latin-1 wird nicht angeboten, weil dabei Inhalt verloren gehen kann.

## Exportformate

| Format | Erweiterung |
| --- | --- |
| HTML, HTML (ohne Stile) | `.html` |
| PDF | `.pdf` |
| Word (.docx) | `.docx` |
| Bild | `.png` |
| PDF-Archiv | `.zip` |

## Grenzen und Zahlen

Wo Pilcrow aufhört oder wo eine Einstellung einen Wertebereich hat:

| Wo | Grenze |
| --- | --- |
| Suchbereich | Hört bei 500 Treffern auf. |
| Suche in der Vorschau | Zählt bis zu 2.000 Treffer. |
| In Ordner ersetzen | Ändert höchstens 2.000 Dateien auf einmal. |
| Links prüfen | Prüft bis zu 50.000 Links. |
| Vergleichen | Zeigt bis zu 5.000 geänderte Zeilen. |
| Aufzubewahrende Versionen | Keine bis 500 (Standard 50). |
| Lange Zeilen | Zeilen mit 20.000 Zeichen oder mehr werden immer umbrochen. |
| Schriftgröße | 9 bis 32 Punkt. |
| Tabulatorbreite | 2 bis 8 Leerzeichen. |
| Textbreite | 50 % bis 100 %. |
| Zoom | 50 % bis 200 %, in zehn Stufen. |
| Lesegeschwindigkeit | 60 bis 2.000 Wörter pro Minute. |
| Breite des Navigators | 180 bis 420 Punkt. |
| Tippgeräusch-Clip | Höchstens 2 Sekunden und 3 MB. |
| Text des Diagnoseberichtsprotokolls | Die neuesten Einträge, bis zu 60.000 Zeichen, wenn es zur Beschreibung eines GitHub-Issues hinzugefügt wird. |
| Sehr große Dateien | Werden geöffnet und bearbeitet, ohne komplett in den Speicher gelesen zu werden. Zeilen- und Wortanzahl sowie die Gliederung werden im Hintergrund fertiggestellt und können bis dahin unvollständig sein. Der PDF-Export eines sehr großen Dokuments braucht deutlich mehr Speicher als die Bearbeitung oder der HTML- und Word-Export; das PDF-Archiv teilt es in begrenzte Teile auf. |

## Wo Pilcrow Dinge ablegt

| Was | Wo |
| --- | --- |
| Ihre Dokumente | Dort, wo Sie sie gesichert haben. |
| Bibliothek (Themes, Profile, Makros, Styleguides, Hintergründe) | Im privaten Speicher der App oder in einem Ordner namens „Pilcrow Library“ innerhalb eines Ordners Ihrer Wahl (**Einstellungen ▸ Bibliothek ▸ Ort**). |
| Einstellungen, API-Schlüssel, Wiederherstellungskopien, Versionsverlauf | Auf dem Gerät, im privaten Speicher der App und im Schlüsselbund. Sie können sie unter **Einstellungen ▸ Allgemein ▸ Speicher und Datenschutz** ansehen und löschen. |
| Diagnoseprotokoll | Auf dem Gerät, bis Sie es löschen. |

# Chapter 82: Meldungen, Banner und leere Zustände

Dieses Kapitel erklärt die kurzen Meldungen, die Pilcrow anzeigt, damit keine davon ein Rätsel bleibt.

## Im Editor und in der Vorschau

| Meldung | Bedeutung |
| --- | --- |
| **Noch nichts in der Vorschau. Beginnen Sie zu schreiben, dann erscheint es hier.** (oder „Wechseln Sie zu Bearbeiten und beginnen Sie zu schreiben.“) | Das Dokument ist leer, daher gibt es in der Vorschau nichts darzustellen. |
| **Die Vorschau konnte nicht dargestellt werden: …** mit **Quelle anzeigen** und **Erneut versuchen** | Die Vorschau ist fehlgeschlagen. **Quelle anzeigen** wechselt zu Bearbeiten. **Erneut versuchen** versucht es noch einmal. |
| Eine fehlgeschlagene Formel oder ein fehlgeschlagenes Diagramm, mit einem Link **Quelle anzeigen** | Ein Block konnte nicht gezeichnet werden. Klicken Sie auf **Quelle anzeigen**, um zum Quelltext dieses Blocks zu springen und ihn zu korrigieren. |
| **Sichern nicht möglich** mit **Erneut versuchen** und einer Schaltfläche zum Schließen | Das Sichern ist fehlgeschlagen. Das Dokument bleibt geöffnet und ungesichert. Beheben Sie die Ursache (Speicherplatz, Berechtigungen, eine verschobene Datei) und wählen Sie **Erneut versuchen**. |
| **Datei auf dem Datenträger geändert** | Eine andere App hat die Datei geändert. **Neu laden** liest die neue Version; **Aktuelle Version behalten** behält, was Sie haben. |
| **Analysewarnung** | Eine Zeile, in der ein Konstrukt wahrscheinlich nicht dem entspricht, was Sie meinten (Kapitel 68). |
| **Vorhandene Datei ersetzen?** | Der gewählte Name wird an dieser Stelle bereits verwendet. |
| **Es sind noch Felder auszufüllen** | Sie drucken oder exportieren mit nicht ausgefüllten Feldern (Kapitel 63). |
| **Bereichstrenner** (VoiceOver-Hinweis: „Ziehen, um die Größe von Editor und Vorschau zu ändern. Doppeltippen zum Zurücksetzen.“) | Der Griff zwischen Quelltext und Vorschau bei „Nebeneinander“. |
| **Wörter: N** | Die Wortanzahl in der Statusleiste. |

## In Dialogen und Bereichen

| Wo | Meldung | Bedeutung |
| --- | --- | --- |
| Befehlspalette | **Befehl eingeben** | Der Hinweis im Feld. „Keine passenden Befehle“ erscheint, wenn nichts passt. |
| Schnell öffnen | **Dateinamen eingeben** | Der Hinweis im Feld. |
| Einfügemarken in einer Spalte | **Zeilen (zum Beispiel 3-17)**, **Spalte (zum Beispiel 100, oder 100-105 zum Auswählen)** | Hinweise in den Feldern. Eine einzelne Spalte setzt Einfügemarken; ein Bereich wählt diese Zeichen in jeder Zeile aus. |
| Suchbereich | **Tippen, um diesen Ordner zu durchsuchen.**, **Keine Treffer in diesem Ordner.**, **Suche abgebrochen.** | Der Zustand einer Ordnersuche. |
| Dateibereich | **Sie können auch einen Ordner hierher ziehen.** | Ziehen Sie einen Ordner auf den Bereich, um ihn zu öffnen. |
| In Ordner ersetzen | **Nichts zu ersetzen.** | Die Suche hat keine Treffer. |
| Vergleichen | Kurzinfos zu den Schaltflächen: **Übernehmen** („Diese Änderung im geöffneten Dokument vornehmen“), **Ablehnen** („Diese Änderung im geöffneten Dokument weglassen“), **Zurücknehmen** („Die älteren Zeilen nur für diese Änderung wieder ins Dokument einsetzen“). | Was jede bewirkt. |
| Übersetzen | **Die Übersetzung konnte nicht abgeschlossen werden.** | Versuchen Sie es erneut oder wählen Sie eine andere Geschwindigkeit. |
| Übersetzen | **Geschätzte Dauer: weniger als eine Minute** | Eine Schätzung für die Geschwindigkeit des KI-Assistenten; die Dauer hängt von Ihrem KI-Dienst ab. Nach einer Übersetzung öffnet **In neuem Tab öffnen** das Ergebnis. |
| Assistent | **Kein Dokument ist geöffnet.**, **Es wird kein Dokumenttext gesendet.** | Der Bereich hat nichts zu teilen, also wird nichts gesendet. |
| Modellauswahl | **Modelle werden geladen …**, **Keine passenden Modelle.** | Die Liste wird geladen, oder Ihre Suche hat nichts gefunden. |
| Stilprüfung | **Keine Befunde.** und **Die Antwort konnte nicht als Befunde gelesen werden. Versuchen Sie es erneut.** | Die Prüfung hat nichts gefunden, oder die Antwort der KI hatte nicht die erwartete Form. |
| Stilprüfung | Kurzinfo zu **Alle anwenden**: „Wendet jede Korrektur an, die eine hat, als eine einzige Änderung, die Sie widerrufen können.“ | Ein einziges Widerrufen macht alles rückgängig. |
| Projektbereich | **Dein Name**, **Variable hinzufügen** | Der Hinweis im Feld „Autor“ und die Schaltfläche für eine Projektvariable. |
| Berechtigung des Assistenten | **Datenschutzerklärung von Pilcrow lesen** | Öffnet die Datenschutzerklärung. |

## In den Einstellungen

| Wo | Meldung | Bedeutung |
| --- | --- | --- |
| Tastatur | **Drücken Sie den neuen Kurzbefehl und klicken Sie dann auf „Sichern“.** und **Beliebige Taste drücken …** | Während ein Kurzbefehl aufgezeichnet wird. |
| Bibliothek ▸ Ort | **Speicherort der Bibliothek**, **Ihre Bibliothek wird verschoben …** | Der Seitentitel und der Fortschritt, während eine Bibliothek verschoben wird. |
| Verbindung des Assistenten | **Leer lassen, um den gespeicherten Schlüssel zu behalten.** | Beim Bearbeiten behält ein leeres Schlüsselfeld den Schlüssel, der schon im Schlüsselbund liegt. |
| Makro-Editor | **Auslöser – z. B. /sig** | Der Hinweis im Auslöserfeld. |
| Profil-Editor | **Erweitertes Profil-JSON**, **Beispiel und Ergebnisse** | Der Titel des JSON-Editors und der Bereich unter „Testbeispiel“, der die Knoten zeigt, die ein Beispiel erzeugt. |
| Diagnose | **Alle Bereiche** (im Protokollbetrachter), **Keine passenden Einträge.** | Das ungefilterte Protokoll und ein Filter, der nichts findet. |
| Statusleiste | Eine rote Markierung **Protokoll läuft**; ihre Kurzinfo **Diagnoseeinstellungen anzeigen** | Ein Protokoll wird aufgezeichnet. Klicken Sie darauf, um zur Seite „Diagnose“ zu gelangen. **Aufzeichnung beenden und Fehlerbericht abschließen** ist die Kurzinfo zu **Wird reproduziert — Bericht abschließen**. |
| Statusleiste | **Syntaxprofil für dieses Dokument wählen** | Die Kurzinfo zum Syntaxmenü. |
| Titelsteuerung | **Geöffnete Dokumente und Dokumentaktionen** | Die Kurzinfo zum Dokumenttitel. |
