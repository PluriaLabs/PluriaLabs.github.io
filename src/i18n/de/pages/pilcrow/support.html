Bevor Sie einen Fehler melden

  • Durchsuchen Sie die offenen und geschlossenen Issues. Wenn Ihr Problem schon dort steht, ergänzen Sie, was Sie dazu wissen.
  • Prüfen Sie, ob Sie die neueste Version von Pilcrow verwenden.
  • Wählen Sie in Pilcrow Fehler melden, um einen Bericht zu beginnen. Die Pilcrow-Version wird für Sie eingetragen, und es lässt sich ein Diagnoseprotokoll hinzufügen, das Sie vorher lesen können und bei dem Sie auswählen, was enthalten sein soll.
  • Issues auf GitHub sind öffentlich. Sehen Sie alles durch, was Sie anhängen, und posten Sie niemals ein Passwort, einen Schlüssel oder ein privates Dokument.

Häufige Fragen

Wo werden meine Dokumente gespeichert?

Dort, wo Sie sie gesichert haben. Pilcrow bearbeitet Ihre Dateien direkt an Ort und Stelle, auf Ihrem Gerät oder bei einem Speicheranbieter wie iCloud Drive. Pluria Labs erhält sie nie.

Pilcrow wurde beim Schreiben beendet. Ist meine Arbeit verloren?

Pilcrow legt eine temporäre Wiederherstellungskopie von ungesichertem Text an, damit Sie nach einem Absturz oder einer Unterbrechung weitermachen können, und entfernt sie, sobald das Dokument gesichert oder normal geschlossen wird. Auch der Versionsverlauf kann eine frühere gesicherte Version zurückholen.

Etwas wird in der Vorschau seltsam dargestellt.

Prüfen Sie der Reihe nach, ob das richtige Syntaxprofil aktiv ist, ob Ihre Quelle dafür gültig ist und ob das gewünschte Render-Theme ausgewählt ist. Das Profil bestimmt, was Ihre Auszeichnung bedeutet; das Theme bestimmt, wie sie aussieht.

Wie wird meine Privatsphäre geschützt?

Lesen Sie die Datenschutzerklärung. Kurz gesagt: kein Konto, keine Werbung, keine Analysen, und Ihre Dokumente bleiben bei Ihnen.
