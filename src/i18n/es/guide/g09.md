# Chapter 65: El panel del asistente y la revisión de estilo

El panel del asistente aparece cuando se configura una conexión en **Configuración ▸ Asistente** (capítulo 67). Mientras no haya ninguna conexión lista, el elemento **Asistente** no aparece en el menú Visualización.

## El panel

| Control | Qué hace |
| --- | --- |
| **Modo del asistente** | **Conversación**, **Revisión de estilo** o **Ayuda**. |
| **Elegir modelo…** | Abre el selector de modelos (más abajo). Muestra advertencias cuando el modelo ya no está disponible o está obsoleto, con la fecha de retirada. |
| **Borrar conversación** | Vacía la conversación. Las conversaciones no se guardan; se descartan al salir de la app. |
| **Qué compartir** | Elige qué acompaña a tu pregunta: **Nada del documento**, **Selección**, **Sección**, **Alrededor del cursor**, **Documento completo**, **Esquema** o **Perfil**. Una opción que no se puede aplicar explica por qué («Selecciona primero algo de texto.», «Este documento no tiene encabezados.», «Demasiado grande para enviarlo completo.», «No hay perfil de sintaxis.»). Una línea sobre el cuadro de la pregunta indica cuánto se enviará y a qué host. La elección se recuerda. |
| **Vista previa** (y **Qué se envía**) | Muestra exactamente lo que se va a enviar. |
| **Pregunta al asistente…** / **Describe lo que quieres escribir** | El cuadro de la pregunta. En el modo **Ayuda**, **Qué escribir** permite elegir **Un perfil de sintaxis**, **Una macro** o **Una guía de estilo**. |
| **Enviar** y **Detener** | Envía la petición o detiene una respuesta en curso. |
| **Privacidad** | Muestra si el asistente está activado para esta carpeta. **Desactivar para esta carpeta** y **Activar para esta carpeta** lo cambian. «Este archivo está excluido del asistente.» aparece en un archivo que coincide con una exclusión. |
| Cada respuesta | **Copiar**, **Insertar en el cursor**, **Reintentar** y, en una respuesta de estilo o de macro, **Añadir a la biblioteca…**. Una respuesta con un error ofrece **Pedir que lo corrija**. Una respuesta cortada lo indica. |

## Elegir un modelo

**Elegir modelo…** muestra los modelos que ofrece la conexión, con **Buscar modelos**. **Mostrar todos los modelos** incluye los menos habituales. Un modelo obsoleto aparece marcado con su fecha de retirada. Si no aparece ninguno, escribe el nombre del modelo. **Reintentar** vuelve a cargar la lista.

## Revisión de estilo

En el modo **Revisión de estilo**, el panel aplica una guía de estilo a tu texto.

| Control | Qué hace |
| --- | --- |
| **Guía de estilo**, **Variante** | Elige una guía y una de sus variantes. |
| **Qué revisar** | **Selección** o **Documento**. Un documento demasiado grande para revisarlo completo dice «Demasiado grande para revisarlo completo. Revisa una sección.» |
| **Áreas** | Elige qué áreas comprobar, o **Todas las áreas**. |
| **Revisar** | Envía el texto y las reglas a tu conexión de IA. Antes de revisar un documento completo, un aviso indica cuántas peticiones se enviarán y aproximadamente cuánto texto, y pregunta **Revisar** o **Cancelar**. |
| **Comprobar aquí** | Ejecuta las comprobaciones propias de la guía en este dispositivo. No se envía nada. |
| **Comprobar referencias cruzadas** | Envía los encabezados, las líneas con citas y las listas de referencias para comprobar reglas que comparan una parte del documento con otra. |
| **Detener** | Detiene una revisión en curso. **Revisar el resto** continúa después de una detención o un fallo. |

Los resultados aparecen en una lista. Cada uno muestra la cita, una explicación y, cuando la hay, una corrección sugerida.

| Botón | Qué hace |
| --- | --- |
| **Ir a** | Va al resultado en el documento. Una cita que aparece más de una vez dice «Coincidencia N de N». |
| **Aplicar** | Hace la corrección sugerida. Solo se aplica si el texto sigue exactamente como se encontró. Si no, dice «El texto ha cambiado.» o «No se encuentra en el texto.» |
| **Descartar** | Quita el resultado. |
| **Aplicar todo** | Hace todas las correcciones que tengan una, tras una confirmación que indica cuántas son, como un único cambio que puedes deshacer de una vez. También indica cuántas correcciones proceden de la IA. |
| **Descartar todas las sugerencias**, **Borrar** | Vacían la lista. |

El panel también informa de «N reglas solo se pueden juzgar con una revisión», «N reglas se detuvieron tras 100 resultados» y «Se omitió un cambio sugerido porque añadía hechos que el texto no contiene.»

# Part XVIII — Referencia de la configuración

# Chapter 66: Cómo está organizada la configuración

Abre la configuración desde **Pilcrow ▸ Ajustes…** (`⌘,`) en Mac, o desde el engranaje del encabezado en iPad, donde se abre como una hoja con un botón **Listo**. La ventana tiene un cuadro **Buscar en ajustes** y una lista de **categorías** a la izquierda. Cada categoría tiene una o más **páginas**, mostradas como una barra de botones en la parte superior.

| Categoría | Páginas |
| --- | --- |
| **General** | Idioma y ventanas (iPad: **Idioma**), Archivos, Traducción, Asistente, Diagnósticos, Almacenamiento y privacidad |
| **Edición** | Pantalla y escritura, Imágenes |
| **Apariencia** | Tema y fondo, Tamaño del texto y tipos de letra |
| **Tabla de contenido** | Contenido y etiquetas |
| **Exportar** | Valores de exportación predeterminados |
| **Biblioteca** | Perfiles de sintaxis, Opciones de CommonMark, Temas, Macros, Guías de estilo, Bibliotecas de renderizado, Ubicación (iPad también tiene **Importar**) |
| **Teclado** | Atajos |
| **Suscripción y créditos** | Apoyar a Pilcrow |

**Buscar en ajustes** busca un control por su nombre. Escribe parte de una etiqueta, como «interlineado» o «versiones», y los resultados muestran el control, su página y su categoría. Elige uno para ir directamente allí. Los cambios se aplican al instante; no hay botón de guardar, salvo en los editores de temas, perfiles, macros y atajos de teclado.

Los ajustes que afectan solo a un Mac o a un iPad se quedan en ese dispositivo. Tu biblioteca (temas, perfiles, macros, guías de estilo y fondos) se puede mover a una carpeta que elijas, incluida una de iCloud Drive (capítulo 71).

# Chapter 67: General

## Idioma y ventanas

| Control | Qué hace |
| --- | --- |
| **Idioma** | Elige el idioma de Pilcrow, independiente del del dispositivo. **Predeterminado del sistema** sigue al dispositivo. Un idioma que se tradujo con IA muestra «Traducción automática: puede contener errores.» El cambio se aplica la próxima vez que abras Pilcrow, con un botón **Salir ahora** en Mac. |
| **Mostrar el aviso de traducción al iniciar Pilcrow** | Vuelve a activar el aviso «Traducido con IA» después de haber elegido **No volver a mostrar**. |
| **Salir de Pilcrow al cerrar la última ventana** (Mac) | Cierra la app al cerrar la última ventana, en lugar de dejarla en ejecución. |

## Archivos

| Control | Qué hace |
| --- | --- |
| **Al iniciar** | Qué abre Pilcrow al arrancar: **Abrir un archivo nuevo**, **Restaurar las últimas carpetas cerradas**, **Restaurar los últimos archivos y carpetas cerrados** o **Abrir carpeta personalizada** (con un botón **Elegir…**). Restaurar vuelve a abrir lo que había en pantalla cuando la app se cerró por última vez. Un archivo que se ha movido o eliminado desde entonces se omite. |
| **Guardar documentos nuevos como** | El tipo de archivo, y por tanto el perfil de sintaxis, de un documento nuevo: cada perfil con su extensión, por ejemplo «CommonMark (.md)». |
| **Guardar cambios automáticamente** | Guarda un documento que tiene archivo mientras trabajas. |
| **Guardar sin preguntar al cerrar un archivo** | Omite la pregunta «¿quieres guardar?» y guarda. |
| **Versiones que conservar** | Cuántas versiones guardadas de cada archivo conserva Pilcrow para el Historial de versiones, de ninguna a 500. El valor predeterminado es 50. «Versiones que conservar: ninguna» desactiva el historial. |
| **Registrar archivos y carpetas recientes** | Permite que Pilcrow recuerde lo que abriste, para **Abrir reciente** y para restaurarlo al iniciar. |
| **Mostrar carpetas y archivos ocultos** | Muestra en el panel Archivos los elementos cuyo nombre empieza por un punto. |
| **Al soltar algo sobre la app** | Qué ocurre al soltar algo sobre el editor o la barra lateral: con una **Carpeta** o un **Archivo Markdown**, **Abrir en el editor** o **Insertar enlace**; con un **Archivo importable** (un tema, un perfil de sintaxis o una colección de macros), **Abrir en el editor**, **Insertar enlace** o **Importar archivo**. |

## Traducción

La traducción requiere macOS 15 o iPadOS 18 o posterior.

| Control | Qué hace |
| --- | --- |
| **Traducir a** | Tu idioma de destino predeterminado. La primera opción es «Idioma del sistema». |
| **Velocidad** | **Rápida**, **Mejor calidad** o **Asistente de IA**. La rápida es adecuada para documentos largos y puede ser unas veinte veces más veloz, con una redacción más sencilla; requiere macOS o iPadOS 26.4. **Asistente de IA** envía el texto a tu conexión de **Configuración ▸ Asistente**; tu servicio puede cobrar por ello y el texto sale del dispositivo. |
| **Cuando un archivo está en otro idioma** | **No hacer nada**, **Ofrecer traducir** o **Traducir automáticamente**. Pilcrow averigua el idioma de un archivo al abrirlo, y para ello no sale nada del dispositivo. La oferta muestra una barra con la opción de traducir a tu idioma predeterminado. |
| **Ofrecer de nuevo para todos los archivos** | Borra los archivos que marcaste como **Nunca para este archivo**. |
| **Después de traducir** | **Abrir en una pestaña nueva**, **Guardar una copia junto al original** (con el nombre del original más el idioma, como `Notes_fr.md`) o **Reemplazar el documento** (que se puede deshacer). |
| **Idiomas en este dispositivo** | Lista cada idioma con **En este dispositivo**, **Descargar** o **No disponible**. La traducción usa paquetes de idioma que permanecen en el dispositivo. Descargar uno pide permiso al sistema; quita uno en los ajustes de idioma del sistema. |

## Asistente

| Control | Qué hace |
| --- | --- |
| **Activar el asistente de IA** | Añade el panel Asistente a la barra lateral. No se envía nada hasta que preguntas, y solo el texto que eliges compartir. |
| Una línea de estado | **Listo.**, o el motivo por el que no lo está: «La dirección de la conexión activa no es utilizable.», «La conexión activa necesita una clave de API.» o «Añade una conexión abajo. El panel Asistente aparece cuando hay una lista.» |
| **Conexiones** | La lista de conexiones, con «Aún no hay conexiones.» cuando está vacía. Cada una muestra su nombre y, la que está en uso, **Activa**. Una fila ofrece **Activar**, **Editar…** y **Quitar**. |
| **Añadir conexión** | Un menú: **OpenAI**, **Anthropic**, **OpenRouter**, **Ollama (este ordenador)**, **LM Studio (este ordenador)** o **Personalizada…**. |
| **Archivos excluidos** | Patrones de archivos que nunca se comparten. `*` representa cualquier carácter de un nombre, `**` cualquier carpeta, y un nombre que termina en `/` abarca una carpeta entera. Los valores predeterminados incluyen `*.pem`, `.env*`, `*.key` y `secrets/`. **Añadir** un patrón, **Quitar** uno o **Restaurar valores predeterminados**. |
| **Carpetas desactivadas** | Lista las carpetas en las que desactivaste el asistente, cada una con **Activar**. Muestra «Ninguna carpeta está desactivada.» cuando no hay ninguna. |
| **Privacidad** | Un enlace para leer la política de privacidad de Pilcrow y **Eliminar todos los datos de IA…**, que elimina todas las conexiones y claves guardadas, la conversación y tus decisiones de privacidad, y desactiva el asistente. Pregunta antes. |

Tu clave de API se guarda en el llavero solo en este dispositivo.

### El formulario de conexión

**Añadir conexión** y **Editar…** abren un formulario.

| Campo | Qué hace |
| --- | --- |
| **Nombre** | Una etiqueta para la conexión. |
| **Formato** | **Compatible con OpenAI** o **Anthropic**. |
| **Dirección** | La dirección web del servicio. Usa `https://`, o `http://` solo para este ordenador o tu red local. |
| **Permitir una conexión sin cifrar en mi red local** | Permite una dirección `http://` en tu red. Envía tu texto y tu clave sin cifrar, así que permítelo solo si confías en la red. |
| **Modelo** | El modelo que se usará, con **Elegir…** para escoger de la lista del servicio. |
| **Necesita una clave de API** y **Clave de API** | Si el servicio necesita una clave, y la propia clave, guardada en el llavero. Déjala en blanco al editar para conservar la clave guardada. |
| **Probar conexión** | Comprueba la dirección, la clave y el modelo. Muestra «Probando…» y luego «Conectado (N ms).» |
| **Cancelar**, **Guardar** | Cierran o conservan la conexión. |

## Diagnósticos

| Control | Qué hace |
| --- | --- |
| **Registrar el registro de diagnóstico** | Registra lo que está haciendo Pilcrow, para que puedas enviarlo al servicio de asistencia cuando algo falle. Permanece en el dispositivo hasta que lo compartes, y está diseñado para omitir el texto y los nombres de archivo de tus documentos. Mientras está activado, aparece una marca roja **Registrando** en la barra de estado. |
| **Dejar de registrar tras** | **1 hora**, **24 horas** o **Nunca**. |
| **Qué registrar** | Un nivel para cada parte de Pilcrow: **Editor de texto**, **Macros**, **Temas**, **Análisis y perfiles**, **Renderizado y diagramas**, **Exportar e imprimir**, **Archivos y biblioteca** y **App**. Cada una es **Solo problemas**, **Normal**, **Detallado** o **Todo**. Los problemas y los errores siempre se conservan. |
| **Reproducir un problema** | Pone todas las partes en Detallado y empieza a registrar. Haz que el problema ocurra de nuevo y luego finaliza el informe. |
| **Añadir el registro** | Al informar de un error: **Preguntar cada vez**, **Añadir siempre** o **No añadir nunca** las entradas más recientes del registro al portapapeles para pegarlas en el formulario. |
| **Informar de un error…** | Igual que **Ayuda ▸ Informar de un error…**. |
| **Incluir en un informe** | Interruptores para **Información del dispositivo y del sistema**, **Ajustes de Pilcrow**, **Estructura del documento (solo recuentos)**, **Velocidad y memoria**, **Rastro de acciones recientes** y **Detalles de fallos**. La estructura del documento es cuántos encabezados, tablas, etc. tiene el documento, nunca sus palabras. Desde esta pantalla no se envía nada. |
| **Ver registro…** | Abre el visor del registro (más abajo). |
| **Borrar registro…** | Elimina de forma permanente el registro grabado en este dispositivo, tras preguntar. Desactivar el registro conserva lo grabado hasta que lo borres. |

Mientras grabas un registro para un informe de error, **Reproduciendo — Finalizar informe** (o **Finalizar informe de error** en el menú Ayuda) detiene la grabación y finaliza el informe. En ese caso la grabación se detiene sola a los 30 minutos.

### El visor del registro

**Registro de diagnóstico** muestra un resumen (**Entradas**, **Sesiones**, **Errores**, **Advertencias**, **Informes de fallos** y el intervalo de fechas) y después las entradas, las más recientes primero, con un campo **Buscar en el registro** y filtros de **Parte** y **Nivel**. Los filtros solo cambian lo que ves, no lo que se envía. Un informe contiene todas las entradas del registro más lo que elegiste en Incluir en un informe. **Recargar** lo actualiza. **Enviar informe** ofrece:

| Elemento | Qué hace |
| --- | --- |
| **Guardar informe…** | Guarda un archivo que puedes enviar tú mismo. |
| **Compartir informe…** | Abre la hoja de compartir (AirDrop, Archivos, etc.). |
| **Informar en GitHub…** | Abre una incidencia nueva con un resumen breve. Eliges **Añadir el registro a la descripción** (las entradas más recientes, hasta 60 000 caracteres, que es todo lo que permite GitHub, copiadas al portapapeles para pegarlas) o **Guardar y adjuntar archivo** (el registro completo, en un archivo que adjuntas tú). Los informes en GitHub son públicos. |

Cuando empiezas un informe sin nada grabado, Pilcrow pregunta **¿Grabar el problema primero?**: **Grabar el problema primero**, **Informar ahora** o **Cancelar**. Al abrir el formulario pregunta si quieres **Añadir registro y abrir formulario**, **Añadir siempre el registro** o **Abrir formulario sin registro**.

## Almacenamiento y privacidad

Pilcrow guarda copias de recuperación, historial, permisos de acceso y datos de asistencia dentro de su entorno aislado. Cada categoría se puede eliminar por separado. Estos controles nunca eliminan tus documentos.

| Sección | Controles |
| --- | --- |
| **Documentos** | **Revisar datos de recuperación** y **Revisar historial de versiones**. Revisar muestra los elementos afectados con sus tamaños, para que veas el espacio antes de eliminar nada. Marca los que quieras eliminar (**Seleccionar todo** o **No seleccionar nada**) y elige **Eliminar selección**. Los datos de recuperación no se pueden revisar mientras un documento tiene cambios sin guardar: guárdalo o ciérralo primero. |
| **Acceso a archivos** | **Borrar el acceso a archivos recientes…** quita las listas de archivos recientes, las carpetas recordadas de Guardar como, los marcadores de sesión y las opciones de sintaxis por archivo. |
| **Datos privados y de asistencia** | **Eliminar datos y claves de IA…** (conexiones, claves del llavero, la conversación actual y las decisiones de privacidad de la IA), **Eliminar diagnósticos…** (registros grabados y diagnósticos de fallos guardados) y **Vaciar cachés…** (archivos en caché y respuestas de red que se pueden volver a crear). |

Cada eliminación pide confirmación («Esta acción no se puede deshacer. Tus documentos no se eliminarán.»). Los perfiles de sintaxis, temas, macros, guías de estilo y fondos personalizados no se quitan aquí; revísalos y elimínalos en sus propias páginas de la Biblioteca.
