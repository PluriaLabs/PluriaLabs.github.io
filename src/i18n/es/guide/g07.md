# Chapter 60: La barra lateral

La barra lateral contiene cinco paneles: **Archivos**, **Esquema**, **Buscar**, **Proyecto** y **Asistente**. Un selector en la parte superior de la barra lateral elige **Archivos**, **Esquema**, **Proyecto** (se muestra cuando la carpeta abierta es un proyecto de libro) o **Asistente** (se muestra una vez configurada una conexión). **Buscar** tiene su propio encabezado con el título **Buscar**, un botón **Listo** que vuelve a Archivos y un control de ámbito para **Este documento** o **Carpeta**; se accede desde **Visualización ▸ Buscar** (`⇧⌘F`). El menú **Visualización** también cambia de panel, y si eliges el panel que ya se está mostrando, la barra lateral se oculta. Arrastra el borde de la barra lateral para cambiar su tamaño. Encima del árbol de archivos, un menú ofrece **Abrir archivo…** y **Abrir carpeta…**.

## Archivos

El panel Archivos es un árbol de la carpeta abierta.

Sin ninguna carpeta abierta, dice «Elige una carpeta para explorar sus archivos.» y ofrece **Abrir carpeta** y **Abrir archivo**. También puedes soltar una carpeta sobre él. Cuando abriste un solo archivo cuya carpeta Pilcrow no puede ver, ofrece «Explora *carpeta* para ver los archivos junto a este documento», con **Explorar la carpeta contenedora…**.

Haz clic en un archivo para abrirlo. Las carpetas se expanden y se contraen. Haz clic con el botón derecho en una fila, o mantén pulsado en el iPad, para ver su menú:

| Elemento | Qué hace |
| --- | --- |
| **Archivo nuevo** | Crea un archivo en la carpeta (o junto al archivo en el que hiciste clic). |
| **Carpeta nueva** | Crea allí una carpeta. |
| **Renombrar…** | Renombra el archivo o la carpeta. |
| **Mover a la papelera** | Lo mueve a la papelera después de que lo confirmes. Puedes devolverlo desde allí. |
| **Mostrar en el Finder** | Lo muestra en el Finder (Mac). |

Cuando el sistema no tiene papelera para una ubicación, Pilcrow guarda los elementos eliminados en una sección **Eliminados recientemente** al final del panel. Cada elemento de ahí ofrece **Devolver** y **Eliminar permanentemente**, y **Vaciar Eliminados recientemente** elimina definitivamente todos los elementos de la sección. Eliminar permanentemente no se puede deshacer, así que Pilcrow pregunta antes. Los elementos que eliminaste desde otros lugares no se ven afectados.

Las carpetas y los archivos ocultos se muestran u ocultan con **Configuración ▸ Archivos ▸ Mostrar carpetas y archivos ocultos**.

## Esquema

El esquema enumera los encabezados del documento activo, con sangría según el nivel. Haz clic en un encabezado para ir a él. Una flecha junto a un encabezado contrae o expande los encabezados anidados bajo él. Esto no cambia el documento, y el estado de contracción no se guarda.

Estados que puedes ver:

| Mensaje | Significado |
| --- | --- |
| **Sin encabezados** | El perfil activo no encontró ningún encabezado. |
| **Indexando esquema… N%** | Un documento grande todavía se está analizando. |
| **Falló la indexación del esquema. Es posible que la lista esté incompleta.** | El análisis encontró un problema. |
| **N encabezados cerca de tu posición: desplázate para ver los demás.** | Un documento muy grande muestra una ventana de su esquema alrededor del cursor. |

Bajo el esquema aparece una sección **Campos** cuando el documento tiene campos por rellenar (capítulo 24). Los enumera, con un recuento; haz clic en uno para desplazarte hasta él y seleccionarlo. Si hay muchísimos campos, dice «Solo se muestran los primeros campos.»

## Buscar

El panel Buscar busca en todos los archivos de la carpeta abierta. Sin una carpeta, dice «Abre una carpeta para buscar en ella.» con un botón **Abrir carpeta…**.

| Control | Qué hace |
| --- | --- |
| Campo **Buscar en la carpeta** | Escribe para buscar sobre la marcha. Un botón **borrar** lo vacía. |
| **Aa** | **Distinguir mayúsculas.** |
| **ab** | **Palabra completa.** |
| **.\*** | **Expresión regular.** Un patrón incorrecto se indica bajo el campo. |
| Línea de estado | Muestra «Buscando…» con un botón **Cancelar**, y luego «Coincidencias: N». Una búsqueda se detiene a las 500 coincidencias y dice «Se muestran las primeras 500 coincidencias.» Tras cancelar, ofrece **Buscar de nuevo**. |
| **Reemplazar…** | Aparece cuando la búsqueda encuentra coincidencias. Abre Reemplazar en la carpeta (capítulo 63). |
| Resultados | Cada resultado indica el archivo y muestra la línea. Haz clic en uno para abrir el archivo en esa línea. |

## Proyecto

El panel Proyecto es para proyectos de libro. Consulta el capítulo 34, el capítulo 35 y la referencia del panel Proyecto más abajo.

### Referencia del panel Proyecto

| Parte | Qué hace |
| --- | --- |
| **Esta carpeta no es un proyecto de libro.** con **Convertir en proyecto** | Se muestra cuando la carpeta abierta no tiene manifiesto. |
| **Reintentar** | Se muestra si no se pudo leer el proyecto. |
| **Visualización** | Elige **Lista**, **Sinopsis** o **Tarjetas**. |
| Título, totales de palabras | El nombre del proyecto y «N palabras», o «N de objetivo» cuando se ha fijado un objetivo de palabras del libro. |
| Filtro de **Estado** | Filtra por un solo estado, o **Todos los estados**. Un recuento enumera cada estado con sus cifras de archivos y palabras. Solo se puede reordenar mientras no haya ningún filtro activo. |
| **Ajustes del proyecto** (engranaje) | Abre la hoja de ajustes que se describe más abajo. |
| **Compilar…** | Abre la hoja de compilación (capítulo 64). |
| **Reordenar** y **Listo** | En el iPad, arrastra los capítulos a un nuevo orden y luego elige **Listo**. |
| **Archivo nuevo** (más) | Ofrece **Nuevo capítulo**, **Nueva escena**, **Nuevo material inicial**, **Nuevo material final**. |
| **No está en el manuscrito** con **Añadir** y **Añadir todo** | Enumera los archivos de la carpeta que el manifiesto no incluye. |
| La flecha de una fila | **Mostrar escenas** u **Ocultar escenas** bajo un capítulo. |
| Etiquetas **Falta** y **Excluido** | Un archivo que no se encuentra, o que has excluido del manuscrito. |
| El menú de una fila | **Detalles…**, **Nuevo archivo debajo**, **Subir el capítulo**, **Bajar el capítulo**, **Incluir en el manuscrito**, **Excluir del manuscrito**. |
| **Objetivo de palabras** por elemento | Cada elemento muestra sus palabras y su objetivo, si lo tiene. |

Los **Detalles** de un elemento incluyen **Tipo** (Material inicial, Parte, Capítulo, Escena, Material final), **Estado**, **Punto de vista**, **Ubicación**, **Objetivo de palabras** y **Sinopsis**. Si un archivo de proyecto cambió en el disco, aparece «El archivo del proyecto cambió en el disco, por lo que tu último cambio no se aplicó. Inténtalo de nuevo.» con **Descartar**.

Los **Ajustes del proyecto** incluyen **Título**, **Autor**, **Objetivo de palabras del libro**, **Los archivos nuevos se escriben en** (la sintaxis de los capítulos y escenas nuevos; los archivos existentes conservan la suya), **Variables** (un nombre y un valor, que se escriben como `{{name}}` en tu texto; `{{title}}` y `{{author}}` siempre funcionan) y **Qué cuenta como palabra**: **Contar los encabezados**, **Contar el material inicial**, **Contar bloques de código**. Elige **Guardar** o **Cancelar**.

## Asistente

El panel Asistente aparece una vez configurada una conexión (capítulo 65).

# Chapter 61: La barra de formato y la barra de estado

## La barra de formato

La barra de formato es una fila opcional bajo el texto. Muéstrala u ocúltala con **Visualización ▸ Barra de formato**, **Más ▸ Barra de formato**, **Configuración ▸ Edición ▸ Barra de formato**, o con el propio elemento **Ocultar barra de herramientas** de la barra. Actúa a través del perfil activo, así que un botón que el perfil no puede expresar aparece atenuado.

| Control | Qué hace |
| --- | --- |
| Menú **Tipo de párrafo** (por ejemplo «Párrafo» o «Encabezado 1») | Muestra el tipo de la línea actual y lo cambia: **Párrafo**, **Encabezado 1** a **6**, **Cita**, **Lista con viñetas**, **Lista numerada**, **Lista de tareas**, **Bloque de código**. |
| **Negrita** (`⌘B`) | Negrita. |
| **Cursiva** (`⌘I`) | Énfasis. |
| **Código en línea** | Código. |
| **Insertar enlace** (`⌘K`) | Crea un enlace. |
| **Cita** | Activa o desactiva una cita. |
| **Lista con viñetas** | Activa o desactiva una lista con viñetas. |
| **Más formato** (**⋯**) | Los comandos menos frecuentes: **Tachado**, **Insertar fórmula en línea**, **Insertar lista de tareas**, **Alternar estado de tarea**, **Sangrar**, **Anular sangría**, **Aumentar nivel de encabezado**, **Reducir nivel de encabezado**, **Insertar tabla…**, **Insertar imagen…**, **Insertar diagrama**, **Insertar gráfico**, **Insertar fórmula destacada**, **Insertar bloque de código**, **Insertar aviso**, **Insertar línea horizontal**, **Insertar referencia de enlace**, **Insertar nota al pie**, **Insertar tabla de contenido**, **Insertar metadatos YAML** y **Ocultar barra de herramientas**. |

## La barra de estado

La barra de estado recorre la parte inferior. Actívala o desactívala con **Configuración ▸ Edición ▸ Mostrar barra de estado**.

| Parte | Qué muestra o qué hace |
| --- | --- |
| **Palabras**, **Lín**, **Col** | El recuento de palabras, y la línea y la columna del cursor. Con una selección, añade «Sel: N lín · N car» para las líneas y los caracteres seleccionados. |
| Menú **Sintaxis** (por ejemplo «CommonMark») | El perfil de este documento. Haz clic para elegir otro, o **Sin sintaxis** para texto sin formato. |
| **Campos pendientes: N** | Se muestra cuando una macro dejó campos por rellenar. Haz clic para ir al siguiente campo. |
| Progreso y estado | **Indexando N%**, **Analizando N%** mientras se analiza un archivo grande, y **Traduciendo N%** con **Faltan unos N** y un botón **Cancelar traducción** mientras se ejecuta una traducción. |
| **Desincronizado** | Una advertencia de que el editor y el registro de cambios del documento han divergido. Al guardar, el archivo sigue marcado como sin guardar para que no se pierda nada: copia tu texto en un lugar seguro y luego cierra y vuelve a abrir el documento. |
| Información del documento | Haz clic en los recuentos, o en la ayuda emergente «Mostrar información del documento», para abrir **Información del documento**. |

**Información del documento** enumera **Palabras**, **Caracteres**, **Líneas**, **Tiempo de lectura** (según tu velocidad de lectura en Configuración), **Cursor**, **Selección**, **Codificación** y **Sintaxis**. En un archivo muy grande, los recuentos corresponden a la parte cargada hasta que termina la indexación, y el tiempo de lectura se estima para todo el archivo. **Convertir a…** bajo **Codificación** elige otra codificación de texto; el archivo se convierte la próxima vez que se guarde.


# Chapter 62: Buscar, reemplazar, Ir a la línea, Apertura rápida y la paleta de comandos

## La barra de búsqueda

Ábrela con **Buscar…** (`⌘F`), el botón **Buscar** o **Reemplazar…** (`⌘R`). Está en la parte superior del documento.

| Control | Qué hace |
| --- | --- |
| Campo **Buscar en el documento** | Escribe el texto que quieres buscar. Las coincidencias se resaltan mientras escribes. |
| **Aa**, **ab**, **.\*** | **Distinguir mayúsculas**, **Palabra completa**, **Expresión regular**. |
| **Coincidencia anterior**, **Coincidencia siguiente** | Recorren las coincidencias (`⇧⌘G`, `⌘G`). |
| **Mostrar reemplazar** / **Ocultar reemplazar** (flecha) | Muestra el campo **Reemplazar con**. |
| **Reemplazar**, **Reemplazar todo** | Reemplaza la coincidencia actual, o todas las coincidencias. Atenuados hasta que haya una coincidencia. |
| **Buscar en** (un selector en el extremo izquierdo de la barra) | **Este documento**, o **Carpeta** para buscar en toda la carpeta abierta. |
| **Cerrar barra de búsqueda** | La cierra. |

Cuando hay más coincidencias de las que Pilcrow cuenta, la barra dice «Quedan más coincidencias». En **Vista previa**, Buscar recorre las palabras ya renderizadas y las resalta, hasta 2000 coincidencias. Un patrón que no se puede usar dice «Patrón no válido». Reemplazar solo está disponible en Editar: en Vista previa la barra dice «Reemplazar funciona en Editar. Cambia a Editar para modificar el texto.» En **En paralelo**, Buscar busca en el código fuente y resalta las palabras coincidentes en la vista previa.

## Ir a la línea

**Ir a la línea…** (`⌃G`) abre una pequeña hoja con un campo, «Número de línea, o línea:columna». Escribe `120` o `120:8` y elige **Ir**, o **Cancelar**. Un número que pase del final va a la última línea. Pilcrow dice «Introduce un número de línea, como 120 o 120:8.» para cualquier otra cosa. En un archivo muy grande cuyas líneas todavía se están contando, te pide que lo intentes de nuevo en un momento.

## Apertura rápida

**Apertura rápida…** (`⇧⌘O`) es una búsqueda por nombre de archivo en toda la carpeta abierta. Escribe parte de un nombre, y la lista se reduce y muestra «N coincidencias». Elige un resultado y **Abrir**, o **Cancelar**. Aparece atenuada si no hay ninguna carpeta abierta.

## La paleta de comandos

**Paleta de comandos…** (`⌃⇧P`) enumera los comandos de Pilcrow por nombre, con sus atajos, para que puedas ejecutar uno sin buscar su menú. Escribe para reducir la lista, elige un comando y **Ejecutar**, o **Cancelar**. Muestra «Ningún comando coincide» cuando nada encaja. Un comando que no se puede ejecutar en este momento, como una edición del código fuente mientras estás en Vista previa, aparece atenuado. La lista incluye los comandos de formato y de inserción, los comandos de Editar para selección, líneas y mayúsculas y minúsculas, voz, los cambios de Visualización, el zoom y los paneles de la barra lateral, y las acciones de archivo y de exportación. El atajo para abrir la paleta se puede cambiar en **Configuración ▸ Teclado**.
