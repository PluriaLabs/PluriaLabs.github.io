# Chapter 68: Edición

## Pantalla y escritura

### Pantalla

| Control | Qué hace |
| --- | --- |
| **Mostrar números de línea** | Números de línea en el margen. Igual que **Visualización ▸ Números de línea**. |
| **Mostrar un subrayado bajo la línea actual** | Una línea fina bajo la línea donde está el cursor. |
| **Código con estilo** | Dibuja los encabezados, la negrita y la cursiva con un tipo de letra acorde. |
| **Plegado de títulos** | Flechas de plegado junto a los encabezados. |
| **Bloques renderizados** | Dibuja tablas, ecuaciones y diagramas como imágenes con un botón de edición. |
| **Expandir secciones automáticamente** | Abre una sección plegada o un bloque de imagen cuando el cursor llega a él, y lo cierra cuando el cursor se va. |
| **Ocultar marcadores** | Oculta las marcas de encabezado, negrita y cursiva en todas las líneas excepto en la del cursor. Requiere Código con estilo. |
| **Ajustar las líneas largas** | Si está desactivado, las líneas largas se desplazan hacia los lados en lugar de ajustarse. La vista previa y las exportaciones siempre ajustan. Las líneas de 20 000 caracteres o más, y el modo concentración, siempre se ajustan. |
| **Líneas cortas en el modo columna** | Qué hace una columna en una línea demasiado corta para alcanzarla: **Usar el final de la línea**, **Omitir la línea**, **Relleno suave con espacios** (añade espacios para que el texto escrito quede alineado en pantalla), **Relleno estricto con espacios** (un espacio por cada carácter que falta, para que quede alineado por número de columna) o **Detenerse en la línea**. Eliminar nunca quita caracteres de una línea corta. |
| **Mostrar barra de estado** | Activa o desactiva la barra de estado de la parte inferior. |
| **Barra de formato** | Muestra la barra opcional bajo el texto. |

### Escritura

| Control | Qué hace |
| --- | --- |
| **Emparejar paréntesis y comillas automáticamente** | Al escribir un paréntesis o una comilla de apertura, se añade el de cierre. |
| **Auto-pair Markdown ( \* \_ ` ~ )** | Hace lo mismo con las marcas de Markdown. |
| **Expandir códigos cortos de emoji (:smile:)** | Convierte un código corto en el emoji mientras escribes. Un archivo que ya contiene uno se muestra tal como está escrito. |
| **Continuar listas y citas con Intro** | Intro inicia el elemento siguiente, Intro en un elemento vacío termina la lista y Tab sangra un elemento. |
| **Mantener la sangría con Intro** | Una línea nueva empieza con los mismos espacios o tabuladores iniciales que la de arriba. |
| **Insertar espacios al pulsar Tab** | Tab inserta tantos espacios como el ancho del tabulador, hasta la siguiente tabulación, en lugar de un carácter de tabulación. |

La puntuación inteligente, el resaltado, el subíndice y el superíndice están en **Biblioteca ▸ Opciones de CommonMark**.

### Sonidos al escribir

| Control | Qué hace |
| --- | --- |
| **Reproducir un sonido al escribir** | Cada tecla produce un sonido; Espacio, Intro y Suprimir suenan distinto. Pegar y deshacer permanecen en silencio. En iPad, el interruptor de silencio lo desactiva. |
| **Sonido** | El paquete: **Máquina de escribir**, **Pato** o **Gatito**. |
| **Volumen**, **Vista previa** | Ajustan el nivel y permiten oír el paquete. |
| **Tus propios sonidos** | Elige un clip corto para cualquier tipo de tecla; las demás conservan el sonido elegido arriba. Los tipos son **Letras minúsculas**, **Letras mayúsculas**, **Números**, **Símbolos y puntuación**, **Espacio**, **Tabulador**, **Retorno** y **Eliminar**. Cada uno tiene **Elegir…** (o **Cambiar…**), **Reproducir** y **Quitar**. Los clips pueden durar hasta 2 segundos y pesar hasta 3 MB (WAV, AIFF, MP3, M4A o CAF), y se guardan en memoria para que suenen sin retraso. |

### Ortografía y diagnósticos

**Revisar ortografía mientras escribes** subraya las faltas de ortografía. **Mostrar advertencias de análisis** marca las líneas donde una construcción probablemente no es lo que querías, como un bloque de código o de fórmulas sin cerrar, un enlace sin paréntesis de cierre o una fila de tabla que no coincide con su encabezado. La nota aparece al final de la línea. Cambia lo que se muestra, nunca cómo se analiza o se exporta un documento.

## Imágenes

Estos ajustes deciden qué ocurre con una imagen que insertas (**Insertar ▸ Imagen…**, o soltándola en el documento).

| Control | Qué hace |
| --- | --- |

| **Aplicar a imágenes locales** | Si la acción se aplica a las imágenes que ya están en tu dispositivo. |
| **Aplicar a imágenes en línea** | Si se aplica a las imágenes que apuntan a una dirección web. |
| **Cargar imágenes de internet** | Desactivado, las imágenes que apuntan a una dirección web no se descargan para la vista previa, el PDF o la exportación de imagen, de modo que el sitio que las aloja no se entera de nada. Activado, se obtienen como en un navegador web, y ese sitio puede ver la petición. |
| **Usar ruta relativa si es posible** | Escribe una ruta relativa al documento. |
| **Añadir ./ a las rutas relativas** | Hace que las rutas relativas empiecen por `./`. |
| **Escapar URL de imagen al insertar** | Escapa los caracteres de la dirección que romperían el enlace. |

# Chapter 70: Tabla de contenido y valores de exportación predeterminados

## Contenido y etiquetas

Estos ajustes se aplican a todos los formatos de exportación: PDF, Word, HTML y el resto.

| Control | Qué hace |
| --- | --- |
| **Añadir una tabla de contenido a cada exportación** | Pone una lista de contenido al principio de cada exportación. |
| **Sustituir una línea [TOC] por la lista** | Una línea que contiene solo `[TOC]` se convierte en la lista de encabezados en la vista previa y en todas las exportaciones. |
| **Numerar encabezados (1., 1.1.)** | Numera los encabezados en el resultado. Las etiquetas de encabezado, más abajo, sustituyen a la numeración simple. |
| **Título** | Cómo se llama la lista, por ejemplo «Contenido» o «Instrucciones». Vacío usa «Tabla de contenido». |
| **Mostrar encabezados hasta el nivel** | Profundidad, de 1 a 6. El nivel 1 lista solo los encabezados principales; el nivel 6 los lista todos. |
| **Sangría** | La sangría en puntos de cada nivel. |
| **Enlazar cada encabezado con su entrada en la tabla de contenido** | Añade enlaces de vuelta desde los encabezados a sus entradas. |
| **Mostrar solo los encabezados debajo de la línea [TOC]** | Omite los encabezados que están encima de la línea `[TOC]`. |

### Etiquetas de encabezado

**Etiquetar encabezados** da a cada nivel su propia etiqueta, por ejemplo «Parte I -» o «Capítulo 3:». Cada nivel tiene una plantilla. En una plantilla, `#` es el número siguiente y `@` la letra mayúscula siguiente; una etiqueta puede usar una de las dos, no ambas. Escribe `\#` o `\@` para volver a empezar a contar cada vez que aparece un encabezado de nivel superior; sin la barra, sigue contando a lo largo del documento. **Letras** y **Dígitos del 0 al 9** definen los caracteres que se usan para las letras y la numeración. Después de la última letra, las letras se duplican: Y, Z, AA, AB.

| **Página** | El tamaño de papel, la orientación y los márgenes que se usan para imprimir y para cada exportación a PDF, PDF de archivo y Word (capítulo 64). |
| **Plantilla de encabezado**, **Plantilla de pie de página** | Texto para la parte superior e inferior de cada página. Variables: `${title}`, `${author}`, `${pageNo}`, `${pageCount}` y `${today}`. Por ejemplo, el pie `Page ${pageNo}`. |

## Bibliotecas de renderizado

Las fórmulas, los diagramas y los gráficos se dibujan en este dispositivo con bibliotecas incluidas. Esta página lista cada biblioteca y su versión; elige una para leer sus avisos incluidos.

## Ubicación

Tu biblioteca está en una carpeta llamada «Pilcrow Library» dentro de la carpeta que elijas. Una carpeta de iCloud Drive la mantiene sincronizada entre tus dispositivos. Las preferencias, las claves de API y las copias de recuperación ante fallos siempre permanecen en este dispositivo.

| Control | Qué hace |
| --- | --- |
| **Ubicación** | Dónde está la biblioteca ahora: «En este dispositivo» o «En la carpeta *nombre*». |
| **Elegir carpeta…** | Mueve la biblioteca a una carpeta. Si la carpeta ya contiene una biblioteca de Pilcrow, Pilcrow no combinará dos: puedes **Usar lo que hay**. Si no, **Mover mi biblioteca aquí** (comprueba todos los archivos y luego quita la copia antigua) o **Copiar mi biblioteca aquí** (conserva la antigua). |
| **Usar este dispositivo** | Devuelve la biblioteca a este dispositivo. |

Si no se puede acceder a la carpeta elegida, Pilcrow usa por ahora la biblioteca de este dispositivo, sin cambiar ni eliminar nada, y vuelve a usar la carpeta cuando esté disponible.

## Importar (iPad)

En iPad, **Importar** añade elementos a la biblioteca: **Importar tema…**, **Importar perfil de sintaxis…**, **Importar colección de macros…**, **Importar guía de estilo…**. En Mac, usa **Archivo ▸ Importar** (capítulo 53).
