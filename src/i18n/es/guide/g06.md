# Chapter 55: Los menús Visualización y Ventana

El menú Visualización controla los paneles, el modo, el tamaño y la presentación del editor. Sus atajos se pueden cambiar en **Configuración ▸ Teclado**, salvo donde se indique.

## Paneles y modo

| Elemento | Atajo | Qué hace |
| --- | --- | --- |
| **Barra de formato** | | Muestra u oculta la fila opcional de botones de formato bajo el texto. Atenuado en la Vista previa. |
| **Mostrar u ocultar barra lateral** | `⇧⌘L` | Muestra u oculta toda la barra lateral. |
| **Esquema** | `⌃⌘1` | Muestra el panel Esquema. Si vuelves a elegirlo, oculta la barra lateral. |
| **Archivos** | `⌃⌘3` | Muestra el panel Archivos (el árbol de archivos). |
| **Buscar** | `⇧⌘F` | Muestra el panel de búsqueda en carpeta. |

| **En paralelo** | `⌃⌘P` | Muestra el código fuente y la vista previa juntos. |

| Elemento | Atajo |
| --- | --- |

| **Acercar** | `⇧⌘=` |

## Presentación del editor

Cada uno de estos elementos es un interruptor. Los mismos interruptores están en **Configuración ▸ Edición** (Capítulo 68).

| Elemento | Atajo | Qué hace |
| --- | --- | --- |
| **Números de línea** | `⌥⌘L` | Muestra los números de línea en el margen. |
| **Subrayado de la línea actual** | | Dibuja una fina línea bajo la línea en la que está el cursor. El color de la línea procede del Tema de la aplicación. |
| **Ajustar líneas** | | Ajusta las líneas largas al borde de la ventana. Desactivado, se desplazan hacia los lados. Las líneas muy largas y el Modo concentración se ajustan de todos modos. |
| **Código con estilo** | | Dibuja los títulos, la negrita y la cursiva con un tipo de letra equivalente, con el aspecto de la sintaxis, en lugar de código fuente sin formato. |
| **Ocultar marcadores** | | Con Código con estilo activado, oculta las marcas de título, negrita y cursiva (el `#`, el `**`) en todas las líneas salvo en aquella en la que está el cursor. Atenuado cuando Código con estilo está desactivado. |
| **Bloques renderizados** | | Dibuja las tablas, ecuaciones y diagramas como imágenes en lugar de su código fuente, cada uno con un botón de edición. |
| **Plegado de títulos** | | Añade una flecha de plegado en el margen junto a cada título, de modo que su sección se pueda plegar, en cualquier perfil de sintaxis. |
| **Plegar todo**, **Desplegar todo** | | Contrae o expande la sección de cada título. Atenuado a menos que Plegado de títulos esté activado. |
| **Expandir secciones automáticamente** | | Abre una sección plegada, o un bloque dibujado como imagen, cuando el cursor llega a ella, y la vuelve a cerrar cuando el cursor se va. Desactivado, las flechas arriba y abajo la saltan y se queda como está. |

## Tema

**Visualización ▸ Tema** elige el **Tema de la aplicación** (Automático, Claro, Oscuro) y el **Tema de renderizado** (Claro, Oscuro) con una marca de verificación. Los temas que añadas también aparecen aquí. Consulta el Capítulo 40.

El sistema añade además **Entrar en pantalla completa**.

## Menú Ventana

| Elemento | Atajo | Qué hace |
| --- | --- | --- |
| **Documentos abiertos** | `⌃⌘2` | Abre el selector de documentos. |
| **Documento siguiente**, **Documento anterior** | `⌃Tab`, `⌃⇧Tab` | Recorre los documentos abiertos. Atenuado con menos de dos abiertos. |

El menú Ventana también contiene los comandos de ventana del sistema y lista cada documento abierto por su nombre. En iPad, estos tres elementos están al final del menú Visualización.

# Chapter 56: El menú Insertar

Todo lo que hay en Insertar coloca código fuente en el documento en la posición del cursor, escrito con la notación propia del perfil de sintaxis activo. Los elementos que el perfil no puede expresar aparecen atenuados, y todos están desactivados en la Vista previa.

| Elemento | Qué hace |
| --- | --- |
| **Tabla…** | Abre el cuadro de diálogo Insertar tabla (Capítulo 63). Atajo `⌥⌘T`. |
| **Imagen…** | Elige una imagen y la inserta, aplicando los ajustes de imagen (Capítulo 68). Atajo `⇧⌘I`. |
| **Diagramas** | Un submenú de diagramas Mermaid prediseñados (más abajo). |
| **Gráficos** | Un submenú de gráficos Vega-Lite prediseñados (más abajo). |
| **Ecuaciones** | Un submenú de ecuaciones prediseñadas (más abajo). |
| **Bloque de código** | Inserta un bloque de código delimitado. |
| **Aviso** | Un submenú: **Nota**, **Consejo**, **Importante**, **Advertencia**, **Precaución**. |
| **Línea horizontal** | Inserta un salto temático. |
| **Referencia de enlace** | Inserta un enlace de estilo referencia y su definición. |
| **Nota al pie** | Inserta una marca de nota al pie y su definición. |
| **Tabla de contenido** | Inserta una línea `[TOC]`, que se convierte en una lista de contenido generada. |
| **Metadatos YAML** | Inserta un bloque de metadatos al principio del archivo. |
| **Campo** | Inserta un espacio por rellenar para Super Tab, seleccionado para que puedas darle nombre (Capítulo 24). |

Debajo de estos, tras un separador, vienen las **construcciones propias del perfil activo**, como una admonición o un bloque personalizado que define el perfil. Si no se ha elegido ningún perfil, el menú dice «Selecciona un perfil de sintaxis para insertar construcciones».

## Plantillas de diagramas

Insertar ▸ Diagramas ofrece 17 puntos de partida. Cada uno inserta un ejemplo funcional para editar.

Diagrama de flujo, Diagrama de secuencia, Diagrama de clases, Diagrama de estados, Diagrama entidad-relación, Diagrama de Gantt, Circular, Recorrido del usuario, Gráfico de Git, Mapa mental, Línea de tiempo, Gráfico de cuadrantes, Diagrama de Sankey, Gráfico XY, Diagrama de bloques, Diagrama de paquetes y Tablero Kanban.

## Plantillas de gráficos

Gráfico de barras, Gráfico de líneas, Gráfico de áreas, Diagrama de dispersión, Gráfico circular, Gráfico de barras apiladas, Histograma, Mapa de calor y Diagrama de caja.

## Plantillas de ecuaciones

Fracción, Raíz cuadrada, Sumatorio, Integral, Límite, Fórmula cuadrática, Matriz, Función a trozos, Ecuaciones alineadas, Coeficiente binomial, Teorema de Bayes e Identidad de Euler.

En iPad, un elemento de Insertar cuyo nombre también existe en el submenú Párrafo (Aviso, Línea horizontal, Referencia de enlace, Nota al pie, Tabla de contenido, Metadatos YAML) se muestra como «Insertar aviso» y así sucesivamente, porque el iPad fusiona los elementos de menú que comparten nombre.

# Chapter 57: El menú Formato

El menú Formato aplica estilos a la selección, o a la línea en la que está el cursor, mediante el perfil de sintaxis activo. Si el perfil no tiene forma de escribir un estilo, el elemento aparece atenuado junto con su atajo, de modo que un comando nunca inserta una sintaxis que el perfil no vaya a leer de vuelta. Todos los elementos están desactivados en la Vista previa.

## La tira de menús del iPad

Un iPad tiene su propia barra de menús, que se muestra al mantener pulsado **⌘** o al mover un puntero a la parte superior de la pantalla. Contiene los mismos comandos que los menús del Mac, a partir de las mismas definiciones, con los mismos atajos reasignables. Solo **Archivo** es diferente, porque el menú Archivo del Mac usa paneles de AppKit.

Para un iPad sin teclado ni ratón, Pilcrow puede mostrar los mismos menús en su encabezado. **Configuración ▸ Apariencia ▸ Menús en el encabezado** permite elegir:

| Opción | Efecto |
| --- | --- |
| **Automático** | Muestra los menús a menos que haya un teclado o un ratón conectado. |
| **Siempre** | Los muestra siempre. |
| **Nunca** | No los muestra nunca. |

En una ventana de 1.100 puntos de ancho o más, los seis menús aparecen uno junto a otro: **Archivo**, **Editar**, **Insertar**, **Formato**, **Visualización** y **Ayuda**. En una ventana más estrecha se contraen en un único botón **Menú**. La tira es una versión más ligera de la barra de menús:

- **Archivo** añade **Abrir carpeta…**, **Exportar…** e **Imprimir…** a los elementos habituales.
- **Editar** tiene **Deshacer**, **Rehacer**, los comandos de copia, **Buscar**, **Ortografía y gramática**, **Selección**, **Traducir**, **Ir a la línea…**, **Comprobar enlaces…**, **Paleta de comandos…**, **Ir atrás** e **Ir adelante**.
- **Formato** tiene los estilos en línea, el submenú **Párrafo**, **Insertar tabla…** e **Insertar imagen…**.
- **Visualización** tiene **Barra de formato**, **Mostrar u ocultar barra lateral**, **Esquema**, **Archivos**, **Buscar**, el modo del documento, **Enfoque**, **Números de línea**, **Subrayado de la línea actual**, **Código con estilo**, **Plegado de títulos** y **Documentos abiertos**. Para los demás interruptores de visualización, usa **Más** o Configuración.
- **Ayuda** tiene **Ayuda de Pilcrow**, **Informar de un error…** y **Finalizar informe de error**.

# Chapter 59: El título del documento y el selector de documentos

El nombre del documento está en el encabezado, con un pequeño punto de color y una flecha hacia abajo. Haz clic en él, o elige **Visualización ▸ Documentos abiertos** (`⌃⌘2`), para abrir la lista **Documentos abiertos**. En una pantalla pequeña se abre como una hoja con un botón **Listo**.

## El punto de guardado

El punto junto al nombre te indica de un vistazo el estado del documento. VoiceOver también lo lee en voz alta.

| Punto | Significado |
| --- | --- |
| Verde | **Guardado.** El archivo del disco coincide con lo que ves. |
| Ámbar | **Editado.** Tienes cambios que aún no están guardados. |
| Rojo | **Error al guardar.** Pilcrow intentó guardar y no pudo. Aparece sobre el editor un aviso **No se pudo guardar** con un botón **Reintentar**. |
| Azul | **Modificado por otra app.** El archivo del disco se modificó desde fuera de Pilcrow. |

Un documento que nunca se ha guardado muestra «Aún sin guardar» y un número en la lista, ya que no tiene carpeta que mostrar. Un documento con cambios sin guardar también dice **Editado** al final de su fila.

## La lista Documentos abiertos

| Parte | Qué hace |
| --- | --- |
| **Buscar en documentos abiertos** | Aparece cuando hay siete o más documentos abiertos. Escribe parte de un nombre o de una carpeta; cada palabra debe coincidir en algún lugar del nombre o de la carpeta, sin distinguir mayúsculas ni acentos. Retorno abre la primera coincidencia. Cuando nada coincide, dice «Ningún documento abierto coincide.» |
| Una fila por documento | Muestra el nombre, su punto de guardado y la carpeta en la que está. Una marca de verificación indica el documento activo. Haz clic en una fila para cambiar a ese documento. |
| **Cerrar** (la **x** al final de una fila) | Cierra ese documento, preguntando antes si tiene cambios sin guardar. |
| **Nuevo documento** | Crea un documento sin título. |
| **Guardar** | Guarda el documento activo. |
| **Guardar como…** | Guarda con un nombre o en un lugar nuevos. |
| **Renombrar…** | Abre el formulario de cambio de nombre (más abajo). |
| **Cerrar todos los documentos** | Cierra todos los documentos, preguntando por cada uno sin guardar. |

Usa `⌃Tab` y `⌃⇧Tab` para pasar al documento siguiente o anterior sin abrir la lista.

## Renombrar

**Renombrar…** muestra el **Nombre** actual y **Ubicación** del archivo, con los botones **Cancelar** y **Renombrar**. Renombrar cambia el archivo en el disco y mantiene el documento abierto. Si el nuevo nombre no se puede usar, un mensaje **No se pudo cambiar el nombre del documento** explica el motivo.
