# Chapter 11: Inserta tablas, imágenes, campos y bloques especiales

El menú **Insertar** combina herramientas compartidas con construcciones que aporta el perfil activo.

## Inserta una tabla

1. Elige **Insertar ▸ Tabla…** o **Formato ▸ Párrafo ▸ Tabla ▸ Insertar tabla…** (`⌥⌘T`).
2. Elige filas, columnas, alineación y comportamiento del encabezado según lo que se ofrezca.
3. Confirma y luego sustituye las celdas de ejemplo.

Una tabla en el código fuente es lo mejor para relaciones tabulares reales. No la uses solo para alinear prosa no relacionada; eso genera una salida poco accesible.

Con el cursor en una tabla, usa **Formato ▸ Párrafo ▸ Tabla** para añadir una fila encima o debajo, eliminar la fila actual, añadir una columna antes o después, o eliminar la columna actual. Pilcrow reescribe la tabla del código fuente como una sola edición que se puede deshacer. Revisa los marcadores de alineación tras los cambios estructurales cuando el perfil los use.

## Inserta una imagen

Elige **Insertar ▸ Imagen…** o `⇧⌘I`, selecciona el archivo y escribe un texto alternativo útil. Pilcrow sigue las preferencias de imagen descritas en el Chapter 26: puede copiar o mover el archivo, dejarlo donde está y escribir una referencia relativa o absoluta.

## Inserta bloques prediseñados

Usa **Diagramas**, **Gráficos** o **Ecuaciones** para obtener una plantilla editable. Usa **Bloque de código**, **Aviso**, **Línea horizontal**, **Referencia de enlace**, **Nota al pie**, **Tabla de contenido** o **Metadatos YAML** cuando se admitan. Las plantillas son código fuente de partida, no widgets bloqueados; edítalas directamente.

## Inserta un campo

Elige **Insertar ▸ Campo** para colocar un campo de relleno con nombre para Super Tab. El campo usa las marcas del perfil activo. Escribe su nombre mientras está seleccionado y luego úsalo en una macro reutilizable o en una plantilla de documento.

# Chapter 12: Usa Editar, Vista previa y En paralelo

## Editar

Editar muestra el código fuente y acepta cambios. Úsalo para escribir, buscar literalmente, reemplazar e inspeccionar a nivel de código fuente.

## Vista previa

Elige **Visualización ▸ Vista previa** (`⇧⌘P`) o el control de modo. La Vista previa compila la estructura del perfil activo con el Tema de renderizado elegido. Es de solo lectura a propósito. Úsala para evaluar la jerarquía, el espaciado, los enlaces, las ecuaciones, los diagramas, los gráficos y el aspecto de la exportación.

## En paralelo

Elige **Visualización ▸ En paralelo** (`⌃⌘P`). El código fuente aparece junto a la Vista previa y se actualiza mientras escribes. El desplazamiento se sincroniza por títulos siempre que es posible, con un respaldo proporcional. Buscar en el código fuente resalta el texto relacionado de la Vista previa. Ir a la línea mueve el editor y la Vista previa lo sigue.

Oculta la barra lateral cuando ambos paneles te parezcan estrechos. En una ventana estrecha puede ser mejor alternar entre Editar y Vista previa.

## Diagnostica una vista previa inesperada

Comprueba esto en orden:

1. ¿Está activo el perfil de sintaxis previsto?
2. ¿Es el código fuente estructuralmente válido para ese perfil?
3. ¿Está seleccionado el Tema de renderizado previsto?
4. ¿Están activadas las funciones opcionales de CommonMark?
5. ¿Está etiquetado un bloque complementario con un lenguaje admitido?

Este orden separa los problemas de significado de los problemas de estilo.

# Chapter 13: Controla la vista de lectura y de edición

Usa el menú Visualización y los ajustes de Edición o Apariencia para controlar:

- **Barra de formato**: muestra u oculta la fila de formato rápido.
- **Modo concentración**: elimina las distracciones alrededor del documento.
- **Tamaño real, Acercar, Alejar**: cambian la escala de visualización sin cambiar la tipografía de la exportación.
- **Números de línea**: muestra en el margen los números de línea del archivo.
- **Subrayado de la línea actual**: resalta la línea activa.
- **Ajustar líneas**: ajusta las líneas largas al ancho de la vista. Al desactivarlo, se pueden leer horizontalmente registros largos.
- **Código con estilo**: colorea y da estilo a los roles reconocidos del código fuente.
- **Ocultar marcadores**: reduce el marcado visible mientras Código con estilo está activo.
- **Bloques renderizados**: renderiza los bloques admisibles dentro de la experiencia de edición.
- **Plegado de títulos**: contrae las secciones situadas bajo los títulos.
- **Plegar todo / Desplegar todo**: cambian todos los plegados de títulos.
- **Expandir secciones automáticamente**: muestra una sección plegada cuando navegas hasta ella.

Código con estilo no cambia el archivo. Ocultar marcadores puede facilitar la lectura del marcado, pero puede ocultar los caracteres literales que estás editando; desactívalo al diagnosticar la sintaxis. El plegado oculta texto, no lo elimina. Usa Desplegar todo antes de una revisión visual de todo el documento.

Cuando un bloque renderizado ofrezca edición, actívalo para abrir **Editar bloque**. Cambia el código fuente en fuente monoespaciada y luego elige **Aplicar** para reemplazar ese bloque o **Cancelar** para dejarlo intacto. La hoja rechaza un bloque vacío. Así se mantiene la cómoda vista renderizada sin ocultar el código fuente que se guardará.

# Part IV — Archivos, carpetas y documentos grandes

# Chapter 14: Explora una carpeta de trabajo

Abre una carpeta o elige **Explorar la carpeta contenedora…** para el documento activo. La barra lateral Archivos muestra el árbol sin importar ni mover archivos. Selecciona un archivo de texto para abrirlo. Usa la carpeta como ámbito compartido para Buscar, los proyectos de libros y los enlaces relativos.

Para abrir desde el teclado, elige **Archivo ▸ Apertura rápida…** (`⇧⌘O`) una vez abierta una carpeta. Escribe cualquier parte ordenada de un nombre de archivo, usa Arriba y Abajo para elegir un resultado y pulsa Retorno. Pilcrow muestra rutas relativas a la carpeta abreviadas para poder distinguir archivos con nombres idénticos. Apertura rápida no aparece o está desactivada cuando no existe una carpeta de espacio de trabajo.

La barra lateral representa archivos reales. Renombrar, mover o eliminar un archivo puede romper enlaces en otros documentos, así que ejecuta Comprobar enlaces tras los cambios estructurales. Las carpetas en la nube pueden notificar los cambios de forma asíncrona; espera a la sincronización antes de suponer que un conflicto es un error de Pilcrow.

Usa los ajustes de inicio para elegir si Pilcrow restaura la última sesión, abre una carpeta concreta o empieza en otro lugar. Usa las preferencias del árbol de archivos para ajustar lo que muestra la biblioteca y cómo se gestionan los elementos soltados.

# Chapter 15: Busca y reemplaza en una carpeta

## Buscar

1. Abre la carpeta.
2. Elige la barra lateral Buscar (`⇧⌘F` de forma predeterminada).
3. Elige el ámbito **Carpeta**.
4. Introduce el término de búsqueda y, si quieres, los controles Coincidir mayúsculas, Palabra completa o Expresión regular.
5. Abre un resultado para inspeccionarlo en contexto.

## Reemplazar de forma transaccional

1. Elige **Reemplazar…** junto al recuento de resultados.
2. Introduce el reemplazo.
3. Revisa cada archivo afectado, el número de coincidencias y una muestra de antes y después.
4. Deselecciona los archivos que deban permanecer sin cambios.
5. Confirma el número final de coincidencias y de archivos.

Pilcrow omite los archivos abiertos, el texto que no es UTF-8 y los archivos modificados después de la vista previa. Así se evita que una operación en carpeta sobrescriba en silencio un trabajo más reciente. Un reemplazo afecta como máximo a 2000 archivos a la vez.

Después, usa el aviso **Deshacer** de la ventana de reemplazo para restaurar el último lote. Un archivo editado desde el reemplazo se deja como está. Solo el reemplazo en carpeta más reciente tiene esta copia de seguridad especial, así que valida antes de empezar otro.

# Chapter 16: Trabaja con seguridad con archivos muy grandes

Pilcrow no carga un documento enorme en una única cadena gigante. Mantiene el archivo original respaldado en el almacenamiento y materializa una ventana alrededor de lo que ves. Por eso pueden abrirse rápidamente archivos de varios gigabytes.

Para obtener los mejores resultados:

- Espera al recuento de líneas antes de fiarte de la navegación a líneas lejanas.
- Espera un breve refresco cuando saltes lejos de la zona visible actual.
- Guarda antes de transformaciones de todo el archivo.
- Prefiere la búsqueda en carpeta o un Buscar específico a seleccionar un archivo enorme entero.
- Recuerda que la creación de PDF usa un modelo de página renderizada completo y puede requerir mucha más memoria que la edición o que la exportación a HTML/Word por flujo continuo.
- Mantén disponible el archivo de origen mientras esté abierto. Un truncamiento o sustitución externos pueden invalidar el original mapeado.

La barra de estado puede mostrar análisis léxico o sintáctico en segundo plano. Normalmente puedes seguir escribiendo. Si una función te pide guardar un documento por superar un límite indicado de uso compartido o de revisión, guárdalo en lugar de forzar una copia temporal en memoria.

# Chapter 17: Usa codificaciones, guardado automático, recuperación y versiones

## Convertir la codificación

Pilcrow detecta y conserva la codificación de un archivo. Haz clic en la codificación de la barra de estado y elige otra; el siguiente guardado realiza la conversión. Si el texto se ve ilegible, no lo edites mucho: prueba antes con la codificación correcta.

## Configura el guardado automático y la recuperación

En **Configuración ▸ General ▸ Archivos**, elige si los cambios se guardan automáticamente y configura el comportamiento de recuperación. El guardado automático reduce el riesgo, pero no sustituye a los puntos de control intencionados antes de ediciones masivas.

Tras una salida inesperada, Pilcrow ofrece copias de recuperación del trabajo sin guardar. Revisa el nombre del documento y recupera o descarta con intención. La recuperación puede reproducir las ediciones sin guardar cuando la identidad del archivo original sigue coincidiendo; los originales obsoletos o reemplazados pueden recurrir a la versión segura disponible en el disco.

## Usa el Historial de versiones

1. Guarda el documento.
2. Haz un cambio significativo y guarda de nuevo.
3. Elige **Archivo ▸ Historial de versiones…**.
4. Selecciona una versión.
5. Usa **Abrir copia** para inspeccionarla, **Comparar…** para ver los cambios de línea o **Restaurar…** para volver a ella.

Restaurar requiere que no haya cambios sin guardar y primero conserva el estado actual, de modo que una restauración puede revertirse a través del historial. Los guardados sin cambios no crean versiones duplicadas. Los archivos de más de 256 MB no se copian al historial. Define el número que se conserva —de ninguna a 500— en los ajustes de Archivos.

# Chapter 18: Compara documentos y acepta cambios seleccionados

## Recupera un cambio histórico

Abre el Historial de versiones, elige una versión anterior y compárala con el documento actual. Cada cambio ofrece **Recuperar** cuando la versión anterior está en el lado antiguo. Úsalo para restaurar solo ese grupo de líneas. Deshacer revierte la acción.

## Revisa el archivo de un colega

1. Abre tu documento de trabajo.
2. Elige **Archivo ▸ Comparar con archivo…**.
3. Selecciona la copia de tu colega.
4. Revisa las líneas añadidas y eliminadas.
5. Elige **Aceptar** para los cambios que quieras y **Rechazar** para los que no.
6. Usa **Reconsiderar** para restaurar una opción rechazada o **Aceptar el resto** tras la revisión.

Pilcrow aplica un cambio solo si el texto de destino sigue coincidiendo con la base de la comparación. Si editaste esa región entretanto, se omite. Los cambios son grupos de líneas; acepta y luego edita cuando solo quieras una parte de una línea. Los cambios individuales muy grandes se dejan para copiarlos manualmente.

# Part V — Calidad e idioma

# Chapter 19: Comprueba los enlaces antes de publicar

Elige **Editar ▸ Comprobar enlaces…**. Pilcrow comprueba archivos relativos, imágenes, fragmentos de títulos, fragmentos entre archivos y definiciones de referencia. Omite el código y no visita URL web.

Haz clic en un problema para saltar a su línea de código fuente. Corrige el destino, guarda si el documento necesita el contexto de una carpeta y elige **Comprobar de nuevo**.

Ejecuta este tutorial después de renombrar archivos de un proyecto:

1. Renombra un archivo enlazado.
2. Comprueba los enlaces en el documento que lo referencia.
3. Abre el resultado de archivo ausente.
4. Actualiza la ruta.
5. Comprueba de nuevo hasta que no queden problemas locales.

Una comprobación local limpia no demuestra que un sitio web externo esté accesible; Pilcrow evita deliberadamente las solicitudes de red no solicitadas.

# Chapter 20: Traduce un documento o una selección

La traducción usa los modelos de lenguaje en el dispositivo de Apple y requiere macOS 15 o iOS 18 o posterior.

1. Elige **Editar ▸ Traducir ▸ Documento** o **Selección**.
2. Confirma el idioma de origen detectado.
3. Elige el idioma de destino.
4. Elige si el resultado se abre en una pestaña nueva, se guarda junto al original o reemplaza el código fuente cuando esa opción está disponible.
5. Inicia la traducción y sigue el progreso en la barra de estado.

Pilcrow conserva los marcadores estructurales, el código, los enlaces y los metadatos. Traduce las partes en lenguaje humano seleccionadas de los bloques de matemáticas, diagramas y gráficos cuando se admite. Reemplazar una selección es un solo paso de deshacer; la traducción de un documento completo normalmente protege el original mediante la opción de salida configurada.

En **Configuración ▸ General ▸ Traducción**, define un idioma predeterminado, elige si se ofrece o se traduce automáticamente los archivos en otro idioma y elige qué ocurre después. Usa **Nunca para este archivo** en una barra de oferta para suprimir ese documento sin desactivar la traducción globalmente.

# Chapter 21: Revisa la escritura con una guía de estilo

## Instala o elige una guía

Abre **Configuración ▸ Biblioteca ▸ Guías de estilo**. Importa una guía o usa el estilo de la casa de ejemplo. Una guía puede contener variantes y áreas de revisión como terminología, mecánica, voz o accesibilidad.

## Ejecuta una revisión

1. Abre la barra lateral Asistente y elige **Revisión de estilo**.
2. Elige una guía de estilo y una variante.
3. Elige las áreas de revisión.
4. Elige el ámbito Selección o Documento.
5. Revisa la información sobre qué se enviará y adónde.
6. Inicia la revisión.
7. Inspecciona cada hallazgo, su evidencia, su explicación y la corrección sugerida.
8. Aplica solo los hallazgos con los que estés de acuerdo.

Las comprobaciones locales deterministas pueden identificar reglas exactas sin enviar texto. Las comprobaciones asistidas por modelo requieren el proveedor activo y pueden dividir un documento largo en varias solicitudes. Pilcrow te indica el número de solicitudes y el tamaño compartido aproximado antes de una revisión de todo el documento.

Trata los hallazgos como evidencia revisable, no como órdenes. Una regla de estilo puede ser inadecuada en un diálogo, una cita, código o una prosa intencionadamente inusual. Aplica las correcciones una a una cuando importe el significado y usa Deshacer de inmediato si una corrección cambia la intención.

## Escribe una guía de estilo

Crea o duplica una guía en los ajustes de Guías de estilo. Da a cada regla un nombre claro, una justificación, ejemplos, ámbito y gravedad. Prefiere una regla precisa que pueda explicarse a sí misma antes que una instrucción vaga como «escribe mejor». Pruébala con un documento breve que contenga tanto infracciones como excepciones legítimas.

# Chapter 22: Usa la lectura en voz alta, la ortografía y las estadísticas de escritura

Usa **Editar ▸ Voz ▸ Empezar a hablar** para oír el texto seleccionado o el texto del documento que corresponda, y **Dejar de hablar** para terminar la reproducción. Escuchar revela palabras repetidas y puntuación ausente que la revisión visual puede pasar por alto.

Activa **Revisar ortografía mientras escribes** en los ajustes de Edición para usar el servicio de ortografía de la plataforma. La ortografía es una ayuda para escribir, no un validador de sintaxis; los identificadores y los términos inventados pueden marcarse aunque sean correctos.

La barra de estado informa de palabras, caracteres y líneas. Los ajustes también incluyen la velocidad de lectura y el comportamiento del recuento de palabras del editor. Pilcrow registra las sesiones de escritura para estadísticas agregadas mientras los documentos están abiertos y se editan. Estos recuentos son útiles para ver tendencias, no como recuentos contractuales de publicación: los perfiles y las reglas de exportación pueden interpretar las palabras de forma distinta.

# Part VI — Macros y campos de relleno

# Chapter 23: Usa y crea macros

## Usa una macro

Activa una colección en **Configuración ▸ Biblioteca ▸ Macros**, vuelve a Editar y escribe el activador de una macro. Según su tipo de coincidencia, se expande después del activador, en un prefijo, alrededor de una selección o cuando coincide un patrón.

## Crea una

1. Abre los ajustes de Macros.
2. Crea o elige una colección.
3. Elige **Nueva macro**.
4. Dale un nombre, un activador, un tipo de coincidencia y una expansión.
5. Actívala y decide si debe evitar el código.
6. Guárdala y pruébala en un documento desechable.

Una expansión puede incluir variables para fecha, hora, UUID, portapapeles, selección, contador, nombre de archivo, ruta de archivo y valores personalizados. Usa variables cuando la estructura se repite pero un valor cambia.

Las colecciones pueden duplicarse, renombrarse, exportarse, importarse, activarse, desactivarse y eliminarse. Los elementos integrados pueden convertirse en copias de usuario editables. Si una macro se dispara de forma inesperada, desactiva su colección, restringe su activador o activa **No expandir dentro del código**.
