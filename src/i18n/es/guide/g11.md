# Chapter 72: Teclado

**Configuración ▸ Teclado ▸ Atajos** muestra todos los comandos cuyo atajo puedes cambiar, con su tecla actual.

| Control | Qué hace |
| --- | --- |
| La fila de un comando | Haz clic en ella, pulsa el nuevo atajo y elige **Guardar**. **Desasignar** quita el atajo. **Cancelar** conserva el anterior. Si otro comando usaba ese atajo, se le quita y la página te dice cuál. |
| **Teclas de Super Tab** | Las teclas de **Campo siguiente** y **Campo anterior**, que saltan entre los huecos que deja una macro: `⌥Tab` y `⌥⇧Tab`, o `⌃⌘]` y `⌃⌘[`, o **Personalizado**. |
| **Restablecer todos los atajos** | Restaura todos los valores predeterminados. |

Los comandos que puedes cambiar, con sus valores predeterminados, son:

| Comando | Predeterminado |
| --- | --- |
| Negrita | `⌘B` |
| Énfasis | `⌘I` |
| Código en línea | `⌃`` ` `` |
| Fórmula en línea | `⌃M` |
| Tachado | `⌃⇧`` ` `` |
| Hipervínculo | `⌘K` |
| Borrar formato | `⌘\` |
| Mostrar u ocultar barra lateral | `⇧⌘L` |
| Barra lateral: Esquema | `⌃⌘1` |
| Documentos abiertos | `⌃⌘2` |
| Barra lateral: Árbol de archivos | `⌃⌘3` |
| Barra lateral: Buscar | `⇧⌘F` |
| Barra lateral: Asistente | `⌃⌘4` |
| Añadir cursor arriba | `⌃⇧↑` |
| Añadir cursor abajo | `⌃⇧↓` |
| Cursores en una columna… | `⌃⇧G` |
| Ir atrás | `⌃⌘←` |
| Ir adelante | `⌃⌘→` |
| Seleccionar la siguiente aparición | `⌃⌥D` |
| Seleccionar todas las apariciones | `⌃⌥⇧D` |
| Campo siguiente | `⌥Tab` |
| Campo anterior | `⌥⇧Tab` |
| Paleta de comandos… | `⌃⇧P` |
| Modo concentración | ninguno |

Los comandos que no están en esta lista, como Guardar, Buscar y los elementos de Párrafo, tienen atajos fijos. El Capítulo 77 enumera todos los atajos.

# Chapter 73: Suscripción y créditos

Todas las funciones de Pilcrow son gratuitas. Apoyar a Pilcrow es opcional: ayuda a costear el desarrollo y te da votos sobre lo que se construirá a continuación. Los votos orientan el orden del trabajo, pero no garantizan ninguna función.

La página **Apoyar a Pilcrow** tiene:

| Parte | Qué muestra o hace |
| --- | --- |
| **Tus votos** | **De tu suscripción** (los votos de este mes pagado, con la fecha en que caducan) y **Comprados** (votos que nunca caducan). Los votos de la suscripción se usan primero y caducan cuando termina el mes pagado. |
| **Obtener votos** | La suscripción y los votos sueltos que puedes comprar. Pilcrow Supporter se renueva cada mes hasta que la canceles en los ajustes de tu cuenta de Apple. Cada mes pagado te da votos. |
| **Restaurar compras** | Recupera las compras hechas en otro dispositivo. |
| **Condiciones de uso**, **Política de privacidad** | Enlaces. |
| **Icono de la app** | Una selección de iconos de la app para suscriptores. Los iconos de una ronda de votación se consiguen suscribiéndote durante esa ronda, y se conservan. En el Mac, el icono cambia en el Dock mientras Pilcrow está abierto. |
| **Hoja de ruta** | La ronda actual de funciones abiertas a votación, con los recuentos «Votos» y «Tuyos» y un botón **Votar** para cada una. Cada voto usa uno de tus votos y no se puede retirar. Entre rondas indica cuándo se abre la siguiente. |

Si las opciones de apoyo no están disponibles en una compilación concreta, la página lo indica.
