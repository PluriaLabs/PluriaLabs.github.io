# Chapter 75: Los editores de temas

Hay dos tipos de tema, y cada uno tiene su propio editor. Abre cualquiera desde **Configuración ▸ Biblioteca ▸ Temas**: **Nuevo** crea un tema, **Editar** modifica uno personalizado y **Duplicar** copia un tema integrado para que puedas cambiar la copia. Los temas integrados no se pueden editar.

## El editor de temas de renderizado

**Editar tema de renderizado** da estilo a la salida de Vista previa, HTML, PDF, imagen e impresión. Sus propiedades personalizadas de Pilcrow también definen los estilos de Word. Un tema de renderizado no da estilo a la aplicación ni al editor.

| Parte | Qué hace |
| --- | --- |
| **Nombre** | El nombre del tema. |
| **Apariencia** | **Automático**, **Claro** u **Oscuro**. |
| **CSS** | La hoja de estilos, en un editor de código. Consulta el capítulo 80 para ver las propiedades y las clases. |
| **Vista previa renderizada** | Un documento de muestra dibujado con tu CSS mientras escribes, para que veas el efecto. |
| **Diagnósticos de CSS** | Problemas que Pilcrow encontró en el CSS, como un recurso remoto que no está permitido. |
| **Cancelar**, **Guardar** | Cierran o conservan el tema. Al cerrar con cambios aparece **¿Descartar los cambios del tema?** con **Descartar cambios** o **Seguir editando**. |
| **Línea base** | **Restablecer a la línea base** descarta todos los cambios desde que el tema se creó, duplicó o importó (tras confirmarlo). **Establecer como nueva línea base** guarda el tema y convierte su estado actual en el punto de restauración. |

## El editor de temas de la aplicación

**Editar tema de la aplicación** da estilo a la propia Pilcrow: su apariencia, el color de énfasis, la barra lateral, las barras y el editor.

| Parte | Qué hace |
| --- | --- |
| **Nombre** | El nombre del tema. |
| **Apariencia** | **Automático**, **Claro** u **Oscuro**. Un tema Automático tiene dos paletas. |
| **Editando colores para** | En un tema Automático, **Claro** u **Oscuro**: cuál de sus dos paletas estás editando. |
| Colores, en cinco grupos | **App** (el color de énfasis), **Barra lateral** (fondo y primer plano), **Barras de estado y de formato** (fondo y primer plano), **Editor** (fondo, primer plano, cursor, selección, fondo del margen, primer plano del margen, subrayado de la línea actual) y **Sintaxis** (encabezado, marcador, código, enlace, atenuado, y palabra clave, cadena, número y comentario del código). Cada color muestra **Predeterminado** hasta que eliges uno, y un botón **Restablecer** lo devuelve a ese estado. |
| **Vista previa** | Una miniatura de Pilcrow, con una barra lateral, un editor y una barra de estado, en los colores que elegiste, en claro u oscuro. |
| **Cancelar**, **Guardar**, **Línea base** | Como arriba. |

Un tema también puede colorear tokens de sintaxis individuales. Esos colores se conservan, pero se editan en el archivo JSON del tema (`syntax.tokens`); consulta el capítulo 79.

# Chapter 76: El editor de macros

Abre el editor de macros desde **Configuración ▸ Biblioteca ▸ Macros**: **Nuevo** dentro de una colección, o **Editar** en una macro. Su título es **Nueva macro** o **Editar macro**.

| Campo | Qué hace |
| --- | --- |
| **Nombre** | Una etiqueta para la macro. |
| **Disparador** (por ejemplo `/sig`) | El texto que la activa. Una macro se expande cuando escribes el disparador seguido de un espacio, un tabulador o la tecla Retorno. |
| **Coincidencia** | Cómo se interpreta el disparador: **Texto exacto**, **Prefijo** o **Expresión regular**. Se rechaza una expresión regular que podría bloquear el editor: «Esa expresión regular podría bloquear el editor. Simplifícala.» |
| **Reemplazo** | El texto en el que se expande. |
| **Insertar fecha/hora** | Un menú que añade al reemplazo un token de fecha u hora. |
| **Activado** | Activa o desactiva la macro sin eliminarla. |
| **No expandir dentro de código** | Evita que la macro se dispare dentro de fragmentos de código y bloques de código. |
| **Cancelar**, **Guardar** | Cierran o conservan la macro. Si no se puede guardar, el mensaje explica por qué. |

En el reemplazo, `$1`, `$2` y así sucesivamente son puntos de tabulación, y `$0` es donde queda el cursor. Después de que una macro se expande, Tab (o **Campo siguiente**) salta de un punto al siguiente. Las fechas y horas usan tokens: `{{date:yyyy-MM-dd}}`, `{{time:HH:mm:ss}}` y `{{datetime:MM/dd/yyyy h:mm a}}`, y los formatos con nombre `iso8601`, `rfc2822`, `unix`, `short`, `medium`, `long` y `full`. Una línea **Ahora:** bajo el campo muestra lo que produciría el reemplazo en este momento.

# Chapter 78: Usar Pilcrow en el iPad

Pilcrow funciona en iPadOS 17 o posterior. Se puede usar solo con el tacto, con un teclado físico y con un trackpad o un ratón.

## Tacto

- **Divisor de paneles.** En En paralelo, arrastra el divisor entre el código fuente y la vista previa para cambiar su tamaño. Tócalo dos veces para restablecerlo.
- **Navegador.** Arrastra el borde de la barra lateral para cambiar su tamaño. En una ventana estrecha, la barra lateral cubre el documento y un botón **Listo** la cierra.
- **Selección en columna.** Activa **Más ▸ Selección en columna** y arrastra un dedo para seleccionar un rectángulo de texto. Dos dedos siguen desplazando. Mientras está activa se muestra una insignia **Selección en columna**, con un botón para desactivarla. O usa **Más ▸ Cursores en una columna…** para colocar los cursores por número.
- **El menú contextual.** Mantén pulsado en el texto para ver el menú del editor (abajo).
- **Archivos.** Mantén pulsado un archivo en el panel Archivos para ver su menú (capítulo 60).

## Con un teclado físico

Funcionan todos los atajos del capítulo 77. Mantén pulsada **⌘** para ver la barra de menús del iPad, o mueve un puntero a la parte superior de la pantalla. Pilcrow puede ocultar sus propios menús del encabezado cuando hay un teclado o un ratón conectado; consulta **Configuración ▸ Apariencia ▸ Menús en el encabezado**.

## Con un trackpad o un ratón

El clic derecho abre el menú contextual del editor. Mantén pulsada **Opción** mientras arrastras para seleccionar un rectángulo de texto.

## El menú contextual del editor

Clic derecho en el Mac, o mantener pulsado en el iPad, sobre el texto. Los elementos que el perfil de sintaxis activo no puede expresar aparecen atenuados, y el sistema añade los suyos (Cortar, Copiar, Pegar, sugerencias ortográficas, Buscar y así sucesivamente).

En el **Mac**:

| Elemento | Qué hace |
| --- | --- |
| **Copiar / Pegar como…** | **Copiar como Markdown**, **Copiar como texto sin formato**, **Copiar como código HTML**, **Pegar como texto sin formato**. |
| **Párrafo** | **Párrafo**, **Encabezado 1** a **6**, **Cita**, **Lista con viñetas**, **Lista numerada**, **Lista de tareas**, **Bloque de código**. |
| **Formato** | **Negrita**, **Énfasis**, **Código**, **Tachado**, **Fórmula en línea**, **Fórmula destacada**, **Diagrama**, **Gráfico**, **Hipervínculo**. |
| **Selección** | **Seleccionar palabra**, **Seleccionar línea**, **Seleccionar párrafo**. |

En el **iPad**, tres submenús acompañan a los elementos del sistema:

| Elemento | Qué hace |
| --- | --- |
| **Formato** | Los estilos en línea: negrita, énfasis, código y los demás. |
| **Párrafo** | Los tipos de párrafo: encabezados, cita, listas, bloque de código. |
| **Insertar** | Las mismas inserciones que el menú **Más** de la barra de formato, incluidas **Insertar aviso**, **Insertar imagen…** e **Insertar tabla…**, y, en **Sintaxis**, las construcciones propias del perfil activo. |

## Diferencias con el Mac

| En el iPad | En el Mac |
| --- | --- |
| Configuración se abre desde el engranaje del encabezado, en una hoja. | **Pilcrow ▸ Ajustes…** (`⌘,`). |
| El encabezado puede mostrar los menús propios de Pilcrow (**Menús en el encabezado**). | La barra de menús es la del sistema. |
| **Tamaño de la interfaz** define el tamaño de los menús, las barras y los diálogos. | No disponible. |
| Importar está en **Configuración ▸ Biblioteca ▸ Importar**. | **Archivo ▸ Importar**. |
| No hay Guardar todo, Duplicar, Mover a, Recargar desde el disco, Mostrar en el Finder ni Configurar página. | Están en el menú Archivo. |
| **Editar ▸ Ortografía y gramática** tiene un solo elemento, **Revisar ortografía mientras se escribe**. | **Editar ▸ Ortografía y gramática** también tiene **Mostrar ortografía y gramática** y **Revisar documento ahora**. |
| El interruptor de silencio del iPad silencia los sonidos al escribir. | No se aplica. |
