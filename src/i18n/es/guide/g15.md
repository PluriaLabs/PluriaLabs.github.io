# Chapter 81: Archivos, codificaciones y límites

## Archivos que abre Pilcrow

Pilcrow edita archivos de texto sin formato y de marcado. Las extensiones habituales son `txt`, `md`, `markdown`, `adoc`, `asciidoc`, `rst` y `tex`, y cualquier extensión que reclame un perfil que añadas. Pilcrow detecta la codificación de texto de un archivo cuando lo abre.

| Elemento | Tipo |
| --- | --- |
| Perfil de sintaxis, colección de macros, guía de estilo, Tema de la aplicación | `.json` |
| Tema de renderizado | `.css` |
| Paquete de tema | `.zip` |
| Manifiesto de proyecto de libro | `manifest.pilcrow` |
| Fondo | HEIC, PNG, JPEG, SVG, MP4, MOV, M4V |
| Clip de sonido al escribir | WAV, AIFF, MP3, M4A, CAF |

## Codificaciones de texto

Pilcrow lee texto en UTF-8, UTF-16, UTF-32 e ISO 8859-1 (Latin-1). Puedes convertir un documento con **Información del documento ▸ Codificación ▸ Convertir a…** a cualquiera de las siguientes; el archivo se convierte la próxima vez que se guarde:

UTF-8, UTF-8 (BOM), UTF-16 LE, UTF-16 LE (BOM), UTF-16 BE, UTF-16 BE (BOM), UTF-32 LE, UTF-32 LE (BOM), UTF-32 BE, UTF-32 BE (BOM).

Un archivo Latin-1 se puede convertir a cualquiera de ellas sin pérdida. No se ofrece convertir a Latin-1, porque puede destruir contenido.

## Formatos de exportación

| Formato | Extensión |
| --- | --- |
| HTML, HTML (sin estilos) | `.html` |
| PDF | `.pdf` |
| Word (.docx) | `.docx` |
| Imagen | `.png` |
| Archivo PDF | `.zip` |

## Límites y cifras

Dónde se detiene Pilcrow, o dónde una opción tiene un intervalo:

| Dónde | Límite |
| --- | --- |
| Panel de búsqueda | Se detiene en 500 coincidencias. |
| Búsqueda en la vista previa | Cuenta hasta 2000 coincidencias. |
| Reemplazar en la carpeta | Cambia como máximo 2000 archivos a la vez. |
| Comprobar enlaces | Comprueba hasta 50 000 enlaces. |
| Comparar | Muestra hasta 5000 líneas modificadas. |
| Versiones que conservar | De ninguna a 500 (predeterminado: 50). |
| Líneas largas | Las líneas de 20 000 caracteres o más siempre se ajustan. |
| Tamaño de fuente | De 9 a 32 puntos. |
| Ancho del tabulador | De 2 a 8 espacios. |
| Ancho del texto | Del 50 % al 100 %. |
| Zoom | Del 50 % al 200 %, en diez pasos. |
| Velocidad de lectura | De 60 a 2000 palabras por minuto. |
| Ancho del navegador | De 180 a 420 puntos. |
| Clip de sonido al escribir | Como máximo 2 segundos y 3 MB. |
| Texto del registro del informe de diagnóstico | Las entradas más recientes, hasta 60 000 caracteres, cuando se añade a la descripción de una incidencia de GitHub. |
| Archivos muy grandes | Se abren y editan sin leerse enteros en la memoria. El recuento de líneas y palabras, y el esquema, se completan en segundo plano y pueden ser parciales hasta entonces. La exportación a PDF de un documento muy grande necesita mucha más memoria que editar o exportar a HTML y Word; el Archivo PDF lo divide en partes acotadas. |

## Dónde guarda Pilcrow las cosas

| Qué | Dónde |
| --- | --- |
| Tus documentos | Donde los hayas guardado. |
| Biblioteca (temas, perfiles, macros, guías de estilo, fondos) | En el almacenamiento privado de la app, o en una carpeta llamada «Pilcrow Library» dentro de una carpeta que elijas (**Configuración ▸ Biblioteca ▸ Ubicación**). |
| Preferencias, claves de API, copias de recuperación, historial de versiones | En el dispositivo, en el almacenamiento privado de la app y en el llavero. Revísalos y elimínalos en **Configuración ▸ General ▸ Almacenamiento y privacidad**. |
| Registro de diagnóstico | En el dispositivo, hasta que lo borres. |

# Chapter 82: Mensajes, avisos y estados vacíos

Este capítulo explica los mensajes breves que muestra Pilcrow, para que ninguno sea un misterio.

## En el editor y la vista previa

| Mensaje | Qué significa |
| --- | --- |
| **Nothing to preview yet. Start writing and it will appear here.** (o «Switch to Edit and start writing.») | El documento está vacío, así que no hay nada que dibujar en la vista previa. |
| **Preview couldn't render: …** con **Mostrar origen** y **Reintentar** | La vista previa falló. **Mostrar origen** cambia a Editar. **Reintentar** lo intenta de nuevo. |
| Una ecuación o un diagrama fallido, con un enlace **Mostrar origen** | No se pudo dibujar un bloque. Haz clic en **Mostrar origen** para ir al código de ese bloque y corregirlo. |
| **Couldn't save** con **Reintentar** y un botón para descartar | Falló el guardado. El documento sigue abierto y sin guardar. Corrige la causa (espacio en disco, permisos, un archivo que se movió) y elige **Reintentar**. |
| **El archivo cambió en el disco** | Otra app modificó el archivo. **Recargar** lee la versión nueva; **Mantener la versión actual** conserva lo que tienes. |
| **Advertencia de análisis** | Una línea en la que una construcción probablemente no es lo que querías (Capítulo 68). |
| **¿Reemplazar el archivo existente?** | El nombre que elegiste ya está en uso en ese lugar. |
| **Quedan campos por rellenar** | Vas a imprimir o exportar con campos sin rellenar (Capítulo 63). |
| **Divisor de paneles** (pista de VoiceOver: «Drag to resize the editor and the preview. Double-tap to reset.») | El tirador entre el código fuente y la vista previa en En paralelo. |
| **Palabras: N** | El recuento de palabras en la barra de estado. |

## En diálogos y paneles

| Dónde | Mensaje | Significado |
| --- | --- | --- |
| Paleta de comandos | **Escribe un comando** | La pista del campo. Aparece «No matching commands» cuando nada coincide. |
| Abrir rápidamente | **Escribe un nombre de archivo** | La pista del campo. |
| Cursores en una columna | **Líneas (por ejemplo 3-17)**, **Columna (por ejemplo 100, o 100-105 para seleccionar)** | Pistas de los campos. Una sola columna coloca cursores; un intervalo selecciona esos caracteres en cada línea. |
| Panel de búsqueda | **Type to search this folder.**, **No matches in this folder.**, **Search cancelled.** | El estado de una búsqueda en una carpeta. |
| Panel Archivos | **You can also drop a folder here.** | Arrastra una carpeta al panel para abrirla. |
| Reemplazar en la carpeta | **Nothing to replace.** | La búsqueda no tiene coincidencias. |
| Comparar | Descripciones emergentes de los botones: **Aceptar** («Make this change in the open document»), **Rechazar** («Leave this change out of the open document»), **Recuperar** («Put the older lines back in the document for this change only»). | Qué hace cada uno. |
| Traducir | **The translation could not be completed.** | Inténtalo de nuevo o elige otra velocidad. |
| Traducir | **Tiempo estimado: menos de un minuto** | Una estimación para la velocidad del asistente de IA; el tiempo depende de tu servicio de IA. Tras una traducción, **Abrir en una pestaña nueva** abre el resultado. |
| Asistente | **No document is open.**, **No document text is sent.** | El panel no tiene nada que compartir, así que no se envía nada. |
| Selector de modelo | **Cargando modelos…**, **No models match.** | La lista se está cargando, o tu búsqueda no encontró nada. |
| Revisión de estilo | **No findings.** y **The reply could not be read as findings. Try again.** | La revisión no encontró nada, o la respuesta de la IA no tenía la forma esperada. |
| Revisión de estilo | Descripción emergente de **Aplicar todo**: «Makes every fix that has one, as a single change you can undo.» | Un solo Deshacer los revierte todos. |
| Panel Proyecto | **Tu nombre**, **Añadir variable** | La pista del campo Autor y el botón para una variable de proyecto. |
| Permiso del asistente | **Read Pilcrow's privacy policy** | Abre la política de privacidad. |
