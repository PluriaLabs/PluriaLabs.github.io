# Chapter 81: Arquivos, codificações e limites

## Arquivos que o Pilcrow abre

O Pilcrow edita arquivos de texto simples e de marcação. As extensões usuais são `txt`, `md`, `markdown`, `adoc`, `asciidoc`, `rst` e `tex`, além de qualquer extensão reivindicada por um perfil que você adicionar. O Pilcrow detecta a codificação de texto de um arquivo ao abri-lo.

| Item | Tipo |
| --- | --- |
| Perfil de sintaxe, coleção de macros, guia de estilo, Tema do app | `.json` |
| Tema de renderização | `.css` |
| Pacote de tema | `.zip` |
| Manifesto de projeto de livro | `manifest.pilcrow` |
| Plano de fundo | HEIC, PNG, JPEG, SVG, MP4, MOV, M4V |
| Clipe de som de digitação | WAV, AIFF, MP3, M4A, CAF |

## Codificações de texto

O Pilcrow lê texto em UTF-8, UTF-16, UTF-32 e ISO 8859-1 (Latin-1). Você pode converter um documento com **Informações do documento ▸ Codificação ▸ Converter para…** para qualquer uma das seguintes; o arquivo é convertido na próxima vez que for salvo:

UTF-8, UTF-8 (BOM), UTF-16 LE, UTF-16 LE (BOM), UTF-16 BE, UTF-16 BE (BOM), UTF-32 LE, UTF-32 LE (BOM), UTF-32 BE, UTF-32 BE (BOM).

Um arquivo Latin-1 pode ser convertido para qualquer uma delas sem perdas. A conversão para Latin-1 não é oferecida, porque pode destruir conteúdo.

## Formatos de exportação

| Formato | Extensão |
| --- | --- |
| HTML, HTML (sem estilos) | `.html` |
| PDF | `.pdf` |
| Word (.docx) | `.docx` |
| Imagem | `.png` |
| Arquivo PDF | `.zip` |

## Limites e números

Onde o Pilcrow para, ou onde uma escolha tem um intervalo:

| Onde | Limite |
| --- | --- |
| Painel de busca | Para em 500 resultados. |
| Localizar na pré-visualização | Conta até 2.000 resultados. |
| Substituir na pasta | Altera no máximo 2.000 arquivos por vez. |
| Verificar links | Verifica até 50.000 links. |
| Comparar | Mostra até 5.000 linhas alteradas. |
| Versões a manter | De nenhuma a 500 (padrão 50). |
| Linhas longas | Linhas de 20.000 caracteres ou mais sempre quebram. |
| Tamanho da fonte | 9 a 32 pontos. |
| Largura da tabulação | 2 a 8 espaços. |
| Largura do texto | 50% a 100%. |
| Zoom | 50% a 200%, em dez etapas. |
| Velocidade de leitura | 60 a 2.000 palavras por minuto. |
| Largura do navegador | 180 a 420 pontos. |
| Clipe de som de digitação | No máximo 2 segundos e 3 MB. |
| Texto do registro do relatório de diagnóstico | As entradas mais recentes, até 60.000 caracteres, quando adicionado à descrição de um problema no GitHub. |
| Arquivos muito grandes | Abrem e são editados sem serem lidos inteiros para a memória. As contagens de linhas e palavras e a estrutura de tópicos são concluídas em segundo plano e podem ficar parciais até lá. A exportação em PDF de um documento muito grande exige muito mais memória do que a edição ou a exportação em HTML e Word; o Arquivo PDF o divide em partes limitadas. |

## Onde o Pilcrow guarda as coisas

| O quê | Onde |
| --- | --- |
| Seus documentos | Onde você os salvou. |
| Biblioteca (temas, perfis, macros, guias de estilo, planos de fundo) | No armazenamento privado do app, ou em uma pasta chamada "Pilcrow Library" dentro de uma pasta que você escolher (**Ajustes ▸ Biblioteca ▸ Local**). |
| Preferências, chaves de API, cópias de recuperação, histórico de versões | No dispositivo, no armazenamento privado do app e no Keychain. Revise e exclua em **Ajustes ▸ Geral ▸ Armazenamento e privacidade**. |
| Registro de diagnóstico | No dispositivo, até você limpá-lo. |

# Chapter 82: Mensagens, avisos e estados vazios

Este capítulo explica as mensagens curtas que o Pilcrow mostra, para que nenhuma delas seja um mistério.

## No editor e na pré-visualização

| Mensagem | O que significa |
| --- | --- |
| **Nada para pré-visualizar ainda. Comece a escrever e o conteúdo aparecerá aqui.** (ou "Mude para Editar e comece a escrever.") | O documento está vazio, então não há nada para desenhar na Pré-visualização. |
| **Não foi possível renderizar a pré-visualização: …** com **Mostrar fonte** e **Tentar novamente** | A pré-visualização falhou. **Mostrar fonte** muda para Editar. **Tentar novamente** tenta de novo. |
| Uma equação ou um diagrama com falha, com um link **Mostrar fonte** | Um bloco não pôde ser desenhado. Clique em **Mostrar fonte** para ir à fonte desse bloco e corrigi-la. |
| **Não foi possível salvar** com **Tentar novamente** e um botão de dispensar | O salvamento falhou. O documento continua aberto e não salvo. Corrija a causa (espaço em disco, permissões, um arquivo que mudou de lugar) e escolha **Tentar novamente**. |
| **Arquivo alterado no disco** | Outro app modificou o arquivo. **Recarregar** lê a nova versão; **Manter versão atual** mantém o que você tem. |
| **Aviso de análise** | Uma linha em que uma construção provavelmente não é o que você pretendia (Chapter 68). |
| **Substituir o arquivo existente?** | O nome que você escolheu já está em uso nesse local. |
| **Ainda há campos a preencher** | Você está imprimindo ou exportando com campos não preenchidos (Chapter 63). |
| **Divisor de painéis** (dica do VoiceOver: "Arraste para redimensionar o editor e a pré-visualização. Toque duas vezes para redefinir.") | A alça entre a fonte e a pré-visualização em Lado a lado. |
| **Palavras: N** | A contagem de palavras na barra de status. |

## Em caixas de diálogo e painéis

| Onde | Mensagem | Significado |
| --- | --- | --- |
| Paleta de comandos | **Digite um comando** | A dica do campo. "Nenhum comando correspondente" aparece quando nada se encaixa. |
| Abrir rapidamente | **Digite um nome de arquivo** | A dica do campo. |
| Cursores em uma coluna | **Linhas (por exemplo 3-17)**, **Coluna (por exemplo 100, ou 100-105 para selecionar)** | Dicas dos campos. Uma única coluna posiciona cursores; um intervalo seleciona esses caracteres em cada linha. |
| Painel de busca | **Digite para buscar nesta pasta.**, **Nenhum resultado nesta pasta.**, **Busca cancelada.** | O estado de uma busca em pasta. |
| Painel de arquivos | **Você também pode soltar uma pasta aqui.** | Arraste uma pasta para o painel para abri-la. |
| Substituir na pasta | **Nada a substituir.** | A busca não tem resultados. |
| Comparar | Dicas nos botões: **Aceitar** ("Fazer esta alteração no documento aberto"), **Rejeitar** ("Deixar esta alteração fora do documento aberto"), **Recolocar** ("Colocar de volta no documento as linhas mais antigas, apenas para esta alteração"). | O que cada um faz. |
| Traduzir | **Não foi possível concluir a tradução.** | Tente de novo ou escolha outra velocidade. |
| Traduzir | **Tempo estimado: menos de um minuto** | Uma estimativa para a velocidade do assistente de IA; o tempo depende do seu serviço de IA. Depois de uma tradução, **Abrir em uma nova aba** abre o resultado. |
| Assistente | **Nenhum documento está aberto.**, **Nenhum texto de documento é enviado.** | O painel não tem nada para compartilhar, então nada é enviado. |
| Seletor de modelo | **Carregando modelos…**, **Nenhum modelo corresponde.** | A lista está carregando, ou sua busca não encontrou nada. |
| Revisão de estilo | **Nenhuma constatação.** e **Não foi possível ler a resposta como constatações. Tente novamente.** | A revisão não encontrou nada, ou a resposta da IA não estava na forma esperada. |
| Revisão de estilo | Dica de **Aplicar tudo**: "Faz todas as correções que tiverem uma, como uma única alteração que você pode desfazer." | Um único Desfazer reverte todas. |
| Painel do projeto | **Seu nome**, **Adicionar variável** | A dica do campo Autor e o botão para uma variável de projeto. |
| Permissão do assistente | **Leia a política de privacidade do Pilcrow** | Abre a política de privacidade. |
