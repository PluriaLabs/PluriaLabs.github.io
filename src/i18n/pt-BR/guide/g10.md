# Chapter 68: Edição

## Tela e digitação

### Tela

| Controle | O que faz |
| --- | --- |
| **Mostrar números de linha** | Números de linha na margem. O mesmo que **Visualização ▸ Números de linha**. |
| **Mostrar uma linha sob a linha atual** | Uma linha fina sob a linha em que o cursor está. |
| **Código com estilo** | Desenha títulos, negrito e itálico em uma fonte correspondente. |
| **Recolher títulos** | Setas de recolhimento ao lado dos títulos. |
| **Blocos renderizados** | Desenha tabelas, equações e diagramas como imagens, com um botão de edição. |

| **Quebrar linhas longas** | Quando desativado, as linhas longas rolam para o lado em vez de quebrar. A pré-visualização e as exportações sempre quebram. Linhas de 20.000 caracteres ou mais e o Modo foco sempre quebram. |
| **Linhas curtas no modo coluna** | O que uma coluna faz em uma linha curta demais para alcançá-la: **Usar o fim da linha**, **Omitir a linha**, **Preenchimento suave com espaços** (acrescenta espaços para que o texto digitado se alinhe na tela), **Preenchimento rígido com espaços** (um espaço para cada caractere que falta, para que se alinhe pelo número da coluna) ou **Parar na linha**. Excluir nunca remove caracteres de uma linha curta. |
| **Mostrar barra de status** | Ativa ou desativa a barra de status na parte inferior. |
| **Barra de formatação** | Mostra a barra opcional sob o texto. |

### Digitação

| Controle | O que faz |
| --- | --- |
| **Emparelhar parênteses e aspas automaticamente** | Ao digitar um parêntese ou uma aspa de abertura, o de fechamento é adicionado. |
| **Auto-pair Markdown ( \* \_ ` ~ )** | Faz o mesmo para as marcas do Markdown. |
| **Expandir códigos curtos de emoji (:smile:)** | Transforma um código curto no emoji enquanto você digita. Um arquivo que já contém um é mostrado como foi escrito. |
| **Continuar listas e citações com Return** | Return inicia o próximo item, Return em um item vazio encerra a lista e Tab recua um item. |
| **Manter o recuo com Return** | Uma nova linha começa com os mesmos espaços ou tabulações iniciais da linha acima. |
| **Inserir espaços ao pressionar Tab** | Tab insere tantos espaços quanto a largura da tabulação, até a próxima parada de tabulação, em vez de um caractere de tabulação. |

A pontuação inteligente, o destaque, o subscrito e o sobrescrito ficam em **Biblioteca ▸ Opções do CommonMark**.

### Sons de digitação

| Controle | O que faz |
| --- | --- |
| **Tocar um som enquanto eu digito** | Cada tecla faz um som; Espaço, Return e Delete soam diferentes. Colar e desfazer ficam em silêncio. No iPad, o interruptor de silêncio o desativa. |
| **Som** | O pacote: **Máquina de escrever**, **Pato** ou **Gatinho**. |
| **Volume**, **Pré-visualização** | Definem o nível e permitem ouvir o pacote. |
| **Seus próprios sons** | Escolha um clipe curto para qualquer tipo de tecla; as outras mantêm o som escolhido acima. Os tipos são **Letras minúsculas**, **Letras maiúsculas**, **Números**, **Símbolos e pontuação**, **Espaço**, **Tab**, **Return** e **Delete**. Cada um tem **Escolher…** (ou **Alterar…**), **Reproduzir** e **Remover**. Os clipes podem ter até 2 segundos e 3 MB (WAV, AIFF, MP3, M4A ou CAF) e ficam armazenados na memória para tocar sem atraso. |

### Ortografia e diagnósticos

**Verificar ortografia ao digitar** sublinha os erros de ortografia. **Mostrar avisos de análise** marca as linhas em que uma construção provavelmente não é o que você pretendia, como um bloco de código ou de matemática não fechado, um link sem o parêntese de fechamento ou uma linha de tabela que não corresponde ao seu cabeçalho. A nota aparece no fim da linha. Ela muda o que é mostrado, nunca como um documento é analisado ou exportado.

## Fundo do editor (o plano de fundo)

Uma imagem ou um vídeo pode ficar atrás do editor, da barra lateral e da barra de status.

| Controle | O que faz |
| --- | --- |
| **Mídia** | **Escolher…** uma imagem HEIC, PNG, JPEG ou SVG, ou um vídeo MP4, MOV ou M4V. **Remover** a limpa. |

| **Atrás da área de texto**, **Atrás da barra lateral** | Cada um tem o seu próprio **Atenuação** e **Desfoque**. A **Atenuação** cobre a imagem com a cor de fundo do tema para que o texto continue legível; o **Desfoque** a suaviza. A barra de status a desfoca. |

## Tamanho do texto e fontes

| Controle | O que faz |
| --- | --- |
| **Tamanho da fonte** | O tamanho da fonte do editor, de 9 a 32 pontos. A fonte do editor, as fontes específicas de cada escrita e o ritmo das linhas são dimensionados juntos, e a alteração é aplicada imediatamente. |
| **Espaçamento entre linhas** | O espaço entre as linhas, como um múltiplo do tamanho da fonte, em passos de 0,1. |

# Chapter 70: Sumário e padrões de exportação

## Sumário e rótulos

Estes ajustes se aplicam a todos os formatos de exportação: PDF, Word, HTML e os demais.

| Controle | O que faz |
| --- | --- |
| **Adicionar um sumário a cada exportação** | Coloca uma lista de conteúdo no início de cada exportação. |
| **Substituir uma linha [TOC] pela lista** | Uma linha que contém apenas `[TOC]` vira a lista de títulos na Pré-visualização e em todas as exportações. |
| **Numerar títulos (1., 1.1.)** | Numera os títulos na saída. Os rótulos de título, abaixo, substituem a numeração simples. |
| **Título** | Como a lista se chama, por exemplo "Conteúdo" ou "Instruções". Vazio usa "Sumário". |
| **Listar títulos até o nível** | Profundidade, de 1 a 6. O nível 1 lista apenas os títulos principais; o nível 6 lista todos. |
| **Recuo** | O recuo em pontos para cada nível. |
| **Vincular cada título à sua entrada no sumário** | Adiciona links de volta dos títulos para as suas entradas. |
| **Listar só os títulos abaixo da linha [TOC]** | Deixa de fora os títulos acima da linha `[TOC]`. |

### Rótulos de título

**Rotular títulos** dá a cada nível o seu próprio rótulo, por exemplo "Parte I -" ou "Capítulo 3:". Cada nível tem um modelo. Em um modelo, `#` é o próximo número e `@` a próxima letra maiúscula; um rótulo pode usar um deles, não os dois. Escreva `\#` ou `\@` para recomeçar a contagem sempre que aparecer um título de nível mais alto; sem a barra, a contagem continua ao longo do documento. **Letras** e **Dígitos de 0 a 9** definem os caracteres usados para a ordenação por letras e por números. Depois da última letra, as letras se duplicam: Y, Z, AA, AB.

## Padrões de exportação

| Controle | O que faz |
| --- | --- |
| **Tema de renderização** | O tema padrão para a Pré-visualização e as exportações. |
| **Formato**, **Extensão de arquivo**, **Conversor** | Informações sobre cada formato de exportação. Todos são produzidos por um conversor integrado. |
| **Página** | O tamanho do papel, a orientação e as margens usados para imprimir e para toda exportação de PDF, PDF Archive e Word (Chapter 64). |
| **Modelo de cabeçalho**, **Modelo de rodapé** | Texto para a parte superior e inferior de cada página. Variáveis: `${title}`, `${author}`, `${pageNo}`, `${pageCount}` e `${today}`. Por exemplo, o rodapé `Page ${pageNo}`. |
| **Autor** | O nome do autor usado por `${author}` e nos metadados do documento. |
| **Quebra de página entre títulos de nível superior** | Começa cada título de nível superior em uma nova página. |

## Bibliotecas de renderização

Fórmulas, diagramas e gráficos são desenhados neste dispositivo por bibliotecas integradas ao app. Esta página lista cada biblioteca e a sua versão; escolha uma para ler os avisos que a acompanham.

## Local

A sua biblioteca fica em uma pasta chamada "Pilcrow Library" dentro da pasta que você escolher. Uma pasta no iCloud Drive a mantém sincronizada entre os seus dispositivos. As preferências, as chaves de API e as cópias de recuperação após falhas sempre ficam neste dispositivo.

| Controle | O que faz |
| --- | --- |
| **Mantida** | Onde a biblioteca está agora: "Neste dispositivo" ou "Na pasta *nome*". |
| **Escolher pasta…** | Move a biblioteca para uma pasta. Se a pasta já contiver uma biblioteca do Pilcrow, o Pilcrow não mescla duas: você pode **Usar o que está lá**. Caso contrário, **Mover minha biblioteca para cá** (verifica cada arquivo e depois remove a cópia antiga) ou **Copiar minha biblioteca para cá** (mantém a antiga). |
| **Usar este dispositivo** | Traz a biblioteca de volta para este dispositivo. |

Se a pasta escolhida não puder ser acessada, o Pilcrow usa por enquanto a biblioteca deste dispositivo, sem alterar nem excluir nada, e volta a usar a pasta quando ela estiver disponível.

## Importar (iPad)

No iPad, **Importar** adiciona itens à biblioteca: **Importar tema…**, **Importar perfil de sintaxe…**, **Importar coleção de macros…**, **Importar guia de estilo…**. No Mac, use **Arquivo ▸ Importar** (Chapter 53).
