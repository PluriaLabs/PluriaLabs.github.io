# Chapter 65: O painel Assistente e a revisão de estilo

O painel Assistente aparece depois que uma conexão é configurada em **Ajustes ▸ Assistente** (Chapter 67). Enquanto nenhuma conexão estiver pronta, o item **Assistente** não aparece no menu Visualização.

## O painel

| Controle | O que faz |
| --- | --- |
| **Modo do assistente** | **Conversa**, **Revisão de estilo** ou **Ajuda**. |
| **Escolher modelo…** | Abre o seletor de modelos (abaixo). Mostra avisos quando o modelo deixou de estar disponível ou foi descontinuado, com a data de desativação. |
| **Limpar conversa** | Esvazia a conversa. As conversas não são salvas; elas são descartadas quando o app é encerrado. |
| **O que compartilhar** | Escolhe o que acompanha a sua pergunta: **Nada do documento**, **Seleção**, **Seção**, **Ao redor do cursor**, **Documento inteiro**, **Estrutura** ou **Perfil**. Uma escolha que não pode ser aplicada explica o motivo ("Selecione algum texto primeiro.", "Este documento não tem títulos.", "Grande demais para enviar inteiro.", "Nenhum perfil de sintaxe."). Uma linha acima da caixa de pergunta mostra quanto será enviado e para qual host. A escolha é lembrada. |
| **Pré-visualização** (e **O que é enviado**) | Mostra exatamente o que será enviado. |
| **Pergunte ao assistente…** / **Descreva o que você quer escrever** | A caixa de pergunta. No modo **Ajuda**, **O que escrever** permite escolher **Um perfil de sintaxe**, **Uma macro** ou **Um guia de estilo**. |
| **Enviar** e **Parar** | Envia o pedido ou interrompe uma resposta em andamento. |
| **Privacidade** | Mostra se o assistente está ativado para esta pasta. **Desativar para esta pasta** e **Ativar para esta pasta** alternam essa opção. "Este arquivo está excluído do assistente." aparece para um arquivo que corresponde a uma exclusão. |
| Cada resposta | **Copiar**, **Inserir no cursor**, **Tentar novamente** e, para uma resposta de estilo ou de macro, **Adicionar à biblioteca…**. Uma resposta com erro oferece **Pedir correção**. Uma resposta interrompida avisa que foi cortada. |

## Escolher um modelo

**Escolher modelo…** lista os modelos que a conexão oferece, com **Buscar modelos**. **Mostrar todos os modelos** inclui os menos comuns. Um modelo descontinuado é marcado com a data de desativação. Se nenhum for listado, digite o nome do modelo. **Tentar novamente** recarrega a lista.

## Revisão de estilo

No modo **Revisão de estilo**, o painel aplica um guia de estilo ao seu texto.

| Controle | O que faz |
| --- | --- |
| **Guia de estilo**, **Variante** | Escolha um guia e uma de suas variantes. |
| **O que revisar** | **Seleção** ou **Documento**. Um documento grande demais para ser revisado inteiro mostra "Grande demais para revisar inteiro. Revise uma seção." |
| **Áreas** | Escolha quais áreas verificar, ou **Todas as áreas**. |
| **Revisar** | Envia o texto e as regras para a sua conexão de IA. Antes de uma revisão do documento inteiro, um alerta informa quantos pedidos serão enviados e aproximadamente quanto texto, e pergunta **Revisar** ou **Cancelar**. |
| **Verificar aqui** | Executa as verificações do próprio guia neste dispositivo. Nada é enviado. |
| **Verificar referências cruzadas** | Envia os títulos, as linhas de citação e as listas de referências para verificar regras que comparam uma parte do documento com outra. |
| **Parar** | Interrompe uma revisão em andamento. **Revisar o restante** continua depois de uma parada ou falha. |

Os resultados aparecem em uma lista. Cada um mostra a citação, uma explicação e, quando houver, uma correção sugerida.

| Botão | O que faz |
| --- | --- |
| **Ir para** | Vai até o resultado no documento. Uma citação que ocorre mais de uma vez mostra "Correspondência N de N". |
| **Aplicar** | Faz a correção sugerida. Ela só é aplicada se o texto ainda estiver exatamente como foi encontrado. Caso contrário, aparece "O texto foi alterado." ou "Não encontrado no texto." |
| **Dispensar** | Remove o resultado. |
| **Aplicar tudo** | Faz todas as correções que tiverem uma, após uma confirmação que informa quantas são, como uma única alteração que você pode desfazer de uma só vez. Também informa quantas correções vieram da IA. |
| **Dispensar todas as sugestões**, **Limpar** | Limpam a lista. |

O painel também informa "N regras só podem ser avaliadas por uma revisão", "N regras pararam após 100 resultados" e "Uma alteração sugerida foi omitida porque acrescentava fatos que o texto não tem."

# Part XVIII — Referência dos ajustes

# Chapter 66: Como os Ajustes são organizados

Abra os Ajustes em **Pilcrow ▸ Ajustes…** (`⌘,`) no Mac, ou pela engrenagem no cabeçalho no iPad, onde eles abrem como uma folha com um botão **Concluído**. A janela tem uma caixa **Buscar nos ajustes** e uma lista de **categorias** à esquerda. Cada categoria tem uma ou mais **páginas**, exibidas como uma barra de botões na parte superior.

| Categoria | Páginas |
| --- | --- |
| **Geral** | Idioma e janelas (iPad: **Idioma**), Arquivos, Tradução, Assistente, Diagnósticos, Armazenamento e privacidade |
| **Edição** | Tela e digitação, Imagens |
| **Aparência** | Tema e plano de fundo, Tamanho do texto e fontes |
| **Sumário** | Sumário e rótulos |
| **Exportar** | Padrões de exportação |
| **Biblioteca** | Perfis de sintaxe, Opções do CommonMark, Temas, Macros, Guias de estilo, Bibliotecas de renderização, Local (o iPad também tem **Importar**) |
| **Teclado** | Atalhos |
| **Assinatura e créditos** | Apoie o Pilcrow |

**Buscar nos ajustes** procura um controle pelo nome. Digite parte de um rótulo, como "espaçamento entre linhas" ou "versões", e os resultados mostram o controle, a página e a categoria. Escolha um para ir direto até ele. As alterações entram em vigor imediatamente; não há botão Salvar, exceto nos editores de temas, perfis, macros e atalhos de teclado.

Os ajustes que afetam apenas um Mac ou um iPad ficam naquele dispositivo. A sua biblioteca (temas, perfis, macros, guias de estilo e planos de fundo) pode ser movida para uma pasta que você escolher, inclusive uma no iCloud Drive (Chapter 71).

# Chapter 67: Geral

## Idioma e janelas

| Controle | O que faz |
| --- | --- |
| **Idioma** | Escolhe o idioma do Pilcrow, independente do idioma do dispositivo. **Padrão do sistema** acompanha o dispositivo. Um idioma que foi traduzido com IA mostra "Tradução automática — pode conter erros." A alteração entra em vigor na próxima vez que você abrir o Pilcrow, com um botão **Sair agora** no Mac. |
| **Mostrar o aviso de tradução ao iniciar o Pilcrow** | Reativa o aviso "Traduzido com IA" depois de você ter escolhido **Não mostrar novamente**. |
| **Encerrar o Pilcrow ao fechar a última janela** (Mac) | Encerra o app quando você fecha a última janela, em vez de deixá-lo em execução. |

## Arquivos

| Controle | O que faz |
| --- | --- |
| **Ao iniciar** | O que o Pilcrow abre ao iniciar: **Abrir um novo arquivo**, **Restaurar as últimas pastas fechadas**, **Restaurar os últimos arquivos e pastas fechados** ou **Abrir pasta personalizada** (com um botão **Escolher…**). Restaurar reabre o que estava na tela quando o app foi encerrado pela última vez. Um arquivo que foi movido ou excluído desde então é ignorado. |
| **Salvar novos documentos como** | O tipo de arquivo, e portanto o perfil de sintaxe, de um novo documento: cada perfil com a sua extensão, por exemplo "CommonMark (.md)". |
| **Salvar alterações automaticamente** | Salva um documento que tem um arquivo enquanto você trabalha. |
| **Salvar sem perguntar ao fechar um arquivo** | Pula a pergunta "deseja salvar?" e salva. |
| **Versões a manter** | Quantas versões salvas de cada arquivo o Pilcrow mantém para o Histórico de versões, de nenhuma a 500. O padrão é 50. "Versões a manter: nenhuma" desativa o histórico. |
| **Registrar arquivos e pastas recentes** | Permite que o Pilcrow se lembre do que você abriu, para **Abrir recente** e para restaurar ao iniciar. |
| **Mostrar pastas e arquivos ocultos** | Mostra no painel Arquivos os itens cujos nomes começam com um ponto. |
| **Quando algo é solto sobre o app** | O que acontece quando você solta algo sobre o editor ou a barra lateral: para uma **Pasta** ou um **Arquivo Markdown**, **Abrir no editor** ou **Inserir link**; para um **Arquivo importável** (um tema, perfil de sintaxe ou coleção de macros), **Abrir no editor**, **Inserir link** ou **Importar arquivo**. |

## Tradução

A tradução requer macOS 15 ou iPadOS 18 ou posterior.

| Controle | O que faz |
| --- | --- |
| **Traduzir para** | O seu idioma de destino padrão. A primeira opção é "Idioma do sistema". |
| **Velocidade** | **Rápida**, **Melhor qualidade** ou **Assistente de IA**. A opção rápida é adequada para documentos longos e pode ser cerca de vinte vezes mais veloz, com um texto mais simples; requer macOS ou iPadOS 26.4. **Assistente de IA** envia o texto para a sua conexão de **Ajustes ▸ Assistente**; o seu serviço pode cobrar por isso e o texto sai do dispositivo. |
| **Quando um arquivo está em outro idioma** | **Não fazer nada**, **Oferecer tradução** ou **Traduzir automaticamente**. O Pilcrow descobre o idioma de um arquivo quando você o abre, e nada sai do dispositivo para isso. A oferta mostra uma barra com a opção de traduzir para o seu idioma padrão. |
| **Oferecer novamente para todos os arquivos** | Limpa os arquivos que você definiu como **Nunca para este arquivo**. |
| **Depois de traduzir** | **Abrir em uma nova aba**, **Salvar uma cópia ao lado do original** (com o nome do original acrescido do idioma, como `Notes_fr.md`) ou **Substituir o documento** (o que pode ser desfeito). |
| **Idiomas neste dispositivo** | Lista cada idioma com **Neste dispositivo**, **Baixar** ou **Indisponível**. A tradução usa pacotes de idioma que ficam no dispositivo. Baixar um deles pede permissão ao sistema; para remover um, use os ajustes de idioma do sistema. |

## Assistente

| Controle | O que faz |
| --- | --- |
| **Ativar o assistente de IA** | Adiciona o painel Assistente à barra lateral. Nada é enviado até você pedir, e apenas o texto que você escolher compartilhar. |
| Uma linha de status | **Pronto.**, ou o motivo de não estar: "O endereço da conexão ativa não é utilizável.", "A conexão ativa precisa de uma chave de API." ou "Adicione uma conexão abaixo. O painel Assistente aparece quando uma estiver pronta." |
| **Conexões** | A lista de conexões, com "Nenhuma conexão ainda." quando está vazia. Cada uma mostra o seu nome e, para a que está em uso, **Ativa**. Uma linha oferece **Tornar ativa**, **Editar…** e **Remover**. |
| **Adicionar conexão** | Um menu: **OpenAI**, **Anthropic**, **OpenRouter**, **Ollama (este computador)**, **LM Studio (este computador)** ou **Personalizada…**. |
| **Arquivos excluídos** | Padrões de arquivos que nunca são compartilhados. `*` representa quaisquer caracteres em um nome, `**` quaisquer pastas, e um nome terminado em `/` abrange uma pasta inteira. Os padrões incluem `*.pem`, `.env*`, `*.key` e `secrets/`. **Adicionar** um padrão, **Remover** um ou **Restaurar padrões**. |
| **Pastas desativadas** | Lista as pastas em que você desativou o assistente, cada uma com **Ativar**. Mostra "Nenhuma pasta está desativada." quando não há nenhuma. |
| **Privacidade** | Um link para ler a política de privacidade do Pilcrow e **Excluir todos os dados de IA…**, que remove todas as conexões e chaves salvas, a conversa e as suas escolhas de privacidade, e desativa o assistente. Ele pergunta antes. |

A sua chave de API é armazenada no Keychain somente neste dispositivo.

### O formulário de conexão

**Adicionar conexão** e **Editar…** abrem um formulário.

| Campo | O que faz |
| --- | --- |
| **Nome** | Um rótulo para a conexão. |
| **Formato** | **Compatível com OpenAI** ou **Anthropic**. |
| **Endereço** | O endereço web do serviço. Use `https://`, ou `http://` apenas para este computador ou para a sua rede local. |
| **Permitir uma conexão sem criptografia na minha rede local** | Permite um endereço `http://` na sua rede. Ele envia o seu texto e a sua chave em texto aberto, então permita apenas se você confiar na rede. |
| **Modelo** | O modelo a usar, com **Escolher…** para selecionar na lista do serviço. |
| **Precisa de uma chave de API** e **Chave de API** | Se o serviço precisa de uma chave e a própria chave, guardada no Keychain. Deixe em branco ao editar para manter a chave salva. |
| **Testar conexão** | Verifica o endereço, a chave e o modelo. Mostra "Testando…" e depois "Conectado (N ms)." |
| **Cancelar**, **Salvar** | Fecham ou mantêm a conexão. |

## Diagnósticos

| Controle | O que faz |
| --- | --- |
| **Gravar o registro de diagnóstico** | Registra o que o Pilcrow está fazendo, para que você possa enviá-lo ao suporte quando algo der errado. Ele fica no dispositivo até você compartilhá-lo e é feito para deixar de fora o texto dos seus documentos e os nomes dos arquivos. Enquanto está ativado, uma marca vermelha **Gravando registro** aparece na barra de status. |
| **Parar de gravar após** | **1 hora**, **24 horas** ou **Nunca**. |
| **O que gravar** | Um nível para cada parte do Pilcrow: **Editor de texto**, **Macros**, **Temas**, **Análise e perfis**, **Renderização e diagramas**, **Exportar e imprimir**, **Arquivos e biblioteca** e **App**. Cada uma é **Somente problemas**, **Normal**, **Detalhado** ou **Tudo**. Problemas e erros são sempre mantidos. |
| **Reproduzir um problema** | Define todas as partes como Detalhado e começa a gravar. Faça o problema acontecer de novo e depois conclua o relatório. |
| **Adicionar o registro** | Ao relatar um bug: **Perguntar sempre**, **Sempre adicionar** ou **Nunca adicionar** as entradas mais recentes do registro à sua área de transferência para colar no formulário. |
| **Relatar um bug…** | O mesmo que **Ajuda ▸ Relatar um bug…**. |
| **Incluir em um relatório** | Chaves para **Informações do dispositivo e do sistema**, **Ajustes do Pilcrow**, **Estrutura do documento (apenas contagens)**, **Velocidade e memória**, **Trilha das ações recentes** e **Detalhes de falhas**. A estrutura do documento é quantos títulos, tabelas e assim por diante o documento tem, nunca as suas palavras. Nada é enviado a partir desta tela. |
| **Ver registro…** | Abre o visualizador de registro (abaixo). |
| **Limpar registro…** | Exclui permanentemente o registro gravado deste dispositivo, após perguntar. Desativar a gravação mantém o que foi gravado até você limpá-lo. |

Enquanto você grava um registro para um relatório de bug, **Reproduzindo — Concluir relatório** (ou **Concluir relatório de bug** no menu Ajuda) interrompe a gravação e conclui o relatório. Nesse caso, a gravação para sozinha após 30 minutos.

### O visualizador de registro

**Registro de diagnóstico** mostra um resumo (**Entradas**, **Sessões**, **Erros**, **Avisos**, **Relatórios de falha** e o intervalo de datas) e depois as entradas, das mais recentes para as mais antigas, com um campo **Pesquisar no registro** e filtros de **Parte** e **Nível**. Os filtros mudam apenas o que você vê, não o que é enviado. Um relatório contém todas as entradas do registro mais o que você escolheu em Incluir em um relatório. **Recarregar** o atualiza. **Enviar relatório** oferece:

| Item | O que faz |
| --- | --- |
| **Salvar relatório…** | Guarda um arquivo que você mesmo pode enviar. |
| **Compartilhar relatório…** | Abre a folha de compartilhamento (AirDrop, Arquivos e assim por diante). |
| **Relatar no GitHub…** | Abre uma nova issue com um resumo curto. Você escolhe **Adicionar o registro à descrição** (as entradas mais recentes, até 60.000 caracteres, que é o máximo que o GitHub permite, copiadas para a sua área de transferência para colar) ou **Salvar e anexar arquivo** (o registro inteiro, em um arquivo que você mesmo anexa). Os relatórios no GitHub são públicos. |

Quando você inicia um relatório sem nada gravado, o Pilcrow pergunta **Gravar o problema primeiro?**: **Gravar o problema primeiro**, **Relatar agora** ou **Cancelar**. Ao abrir o formulário, ele pergunta se deve **Adicionar o registro e abrir o formulário**, **Sempre adicionar o registro** ou **Abrir o formulário sem o registro**.

## Armazenamento e privacidade

O Pilcrow mantém cópias de recuperação, histórico, permissões de acesso e dados de suporte dentro da sua sandbox. Cada categoria pode ser excluída separadamente. Estes controles nunca excluem os seus documentos.

| Seção | Controles |
| --- | --- |
| **Documentos** | **Revisar dados de recuperação** e **Revisar histórico de versões**. Revisar lista os itens afetados com os seus tamanhos, para que você veja o espaço antes de excluir qualquer coisa. Marque os que serão excluídos (**Selecionar tudo** ou **Não selecionar nada**) e escolha **Excluir seleção**. Os dados de recuperação não podem ser revisados enquanto um documento tiver alterações não salvas: salve ou feche-o primeiro. |
| **Acesso a arquivos** | **Limpar o acesso a arquivos recentes…** remove as listas de arquivos recentes, as pastas lembradas do Salvar como, os marcadores de sessão e as escolhas de sintaxe por arquivo. |
| **Dados privados e de suporte** | **Excluir dados e chaves de IA…** (conexões, chaves do Keychain, a conversa atual e as escolhas de privacidade de IA), **Excluir diagnósticos…** (registros gravados e diagnósticos de falhas salvos) e **Limpar caches…** (arquivos em cache e respostas de rede que podem ser recriados). |

Toda exclusão pede confirmação ("Isto não pode ser desfeito. Os seus documentos não serão excluídos."). Perfis de sintaxe, temas, macros, guias de estilo e planos de fundo personalizados não são removidos aqui; revise-os e exclua-os nas suas próprias páginas da Biblioteca.
