# Chapter 55: Os menus Visualização e Janela

O menu Visualização controla os painéis, o modo, o tamanho e a exibição do editor. Seus atalhos podem ser alterados em **Ajustes ▸ Teclado**, exceto onde indicado.

## Painéis e modo

| Item | Atalho | O que faz |
| --- | --- | --- |
| **Barra de formatação** | | Mostra ou oculta a linha opcional de botões de formatação sob o texto. Esmaecido na Pré-visualização. |

## Exibição do editor

Cada um destes é um interruptor. Os mesmos interruptores estão em **Ajustes ▸ Edição** (Chapter 68).

| Item | Atalho | O que faz |
| --- | --- | --- |
| **Números de linha** | `⌥⌘L` | Mostra os números de linha na margem. |
| **Linha sob a linha atual** | | Desenha uma linha fina sob a linha em que está o cursor. A cor da linha vem do Tema do app. |
| **Quebrar linhas** | | Quebra as linhas longas na borda da janela. Desativado, elas rolam para o lado. Linhas muito longas e o Modo foco quebram de qualquer forma. |
| **Código com estilo** | | Desenha títulos, negrito e itálico em uma fonte correspondente, no visual da sintaxe, em vez do código-fonte simples. |
| **Ocultar marcadores** | | Com Código com estilo ativado, oculta as marcas de título, negrito e itálico (o `#`, o `**`) em todas as linhas, exceto na linha em que está o cursor. Esmaecido quando Código com estilo está desativado. |
| **Blocos renderizados** | | Desenha tabelas, equações e diagramas como imagens no lugar do código-fonte deles, cada um com um botão de edição. |
| **Recolher títulos** | | Adiciona uma seta de recolhimento na margem ao lado de cada título, para que a seção dele possa ser recolhida, em qualquer perfil de sintaxe. |
| **Recolher tudo**, **Expandir tudo** | | Recolhe ou expande a seção de todos os títulos. Esmaecido, a menos que Recolher títulos esteja ativado. |
| **Expandir seções automaticamente** | | Abre uma seção recolhida, ou um bloco desenhado como imagem, quando o cursor chega a ele, e o fecha de novo quando o cursor sai. Desativado, as setas para cima e para baixo passam por cima dele e ele permanece como está. |

**Visualização ▸ Tema** escolhe o **Tema do app** (Automático, Claro, Escuro) e o **Tema de renderização** (Claro, Escuro) com uma marca de seleção. Os temas que você adiciona também aparecem aqui. Veja o Chapter 40.

O sistema também adiciona **Entrar em tela inteira**.

# Chapter 56: O menu Inserir

Tudo em Inserir coloca código-fonte no documento, no cursor, escrito na notação própria do perfil de sintaxe ativo. Os itens que o perfil não consegue expressar ficam esmaecidos, e todos os itens ficam desativados na Pré-visualização.

| **Diagramas** | Um submenu de diagramas Mermaid prontos (abaixo). |
| **Gráficos** | Um submenu de gráficos Vega-Lite prontos (abaixo). |
| **Equações** | Um submenu de equações prontas (abaixo). |
| **Bloco de código** | Insere um bloco de código delimitado. |

| **Linha horizontal** | Insere uma quebra temática. |

| **Nota de rodapé** | Insere uma marca de nota de rodapé e sua definição. |

Abaixo destes, um divisor é seguido pelas **construções do próprio perfil ativo**, como uma advertência ou um bloco personalizado que o perfil define. Se nenhum perfil estiver escolhido, o menu diz "Selecione um perfil de sintaxe para inserir construções".

## A faixa de menus do iPad

Um iPad tem sua própria barra de menus, exibida quando você mantém **⌘** pressionado ou move um ponteiro para o topo da tela. Ela traz os mesmos comandos dos menus do Mac, das mesmas definições, com os mesmos atalhos reconfiguráveis. Somente **Arquivo** é diferente, porque o menu Arquivo do Mac usa painéis do AppKit.

Para um iPad sem teclado nem mouse, o Pilcrow pode mostrar os mesmos menus no cabeçalho. **Ajustes ▸ Aparência ▸ Menus no cabeçalho** escolhe:

| Escolha | Efeito |
| --- | --- |
| **Automático** | Mostra os menus, a menos que um teclado ou mouse esteja conectado. |
| **Sempre** | Sempre os mostra. |
| **Nunca** | Nunca os mostra. |

Em uma janela com 1.100 pontos de largura ou mais, os seis menus ficam lado a lado: **Arquivo**, **Editar**, **Inserir**, **Formato**, **Visualização** e **Ajuda**. Em uma janela mais estreita, eles se recolhem em um único botão **Menu**. A faixa é uma versão mais leve da barra de menus:

- **Arquivo** acrescenta **Abrir pasta…**, **Exportar…** e **Imprimir…** aos itens habituais.
- **Editar** tem **Desfazer**, **Refazer**, os comandos de cópia, **Localizar**, **Ortografia e Gramática**, **Seleção**, **Traduzir**, **Ir para a linha…**, **Verificar links…**, **Paleta de comandos…**, **Voltar** e **Avançar**.
- **Formato** tem os estilos em linha, o submenu **Parágrafo**, **Inserir tabela…** e **Inserir imagem…**.
- **Visualização** tem **Barra de formatação**, **Mostrar/ocultar barra lateral**, **Estrutura**, **Arquivos**, **Buscar**, o modo do documento, **Foco**, **Números de linha**, **Linha sob a linha atual**, **Código com estilo**, **Recolher títulos** e **Documentos abertos**. Para os outros interruptores de exibição, use **Mais** ou os Ajustes.
- **Ajuda** tem **Ajuda do Pilcrow**, **Relatar um bug…** e **Concluir relatório de bug**.

# Chapter 59: O título do documento e o alternador de documentos

O nome do documento fica no cabeçalho, com um pequeno ponto colorido e uma seta para baixo. Clique nele, ou escolha **Visualização ▸ Documentos abertos** (`⌃⌘2`), para abrir a lista **Documentos abertos**. Em uma tela pequena, ela abre como uma folha com um botão **Concluído**.

## O ponto de salvamento

O ponto ao lado do nome mostra, num relance, o estado do documento. O estado também é lido em voz alta pelo VoiceOver.

| Ponto | Significado |
| --- | --- |
| Verde | **Salvo.** O arquivo no disco corresponde ao que você vê. |
| Âmbar | **Editado.** Você tem alterações que ainda não foram salvas. |
| Vermelho | **Falha ao salvar.** O Pilcrow tentou salvar e não conseguiu. Um aviso **Não foi possível salvar** com um botão **Tentar novamente** aparece sobre o editor. |
| Azul | **Alterado por outro app.** O arquivo no disco foi alterado fora do Pilcrow. |

Um documento que nunca foi salvo mostra "Ainda não salvo" e um número na lista, já que não tem pasta para exibir. Um documento com alterações não salvas também diz **Editado** no fim da sua linha.

## A lista Documentos abertos

| Parte | O que faz |
| --- | --- |
| **Buscar nos documentos abertos** | Aparece quando sete ou mais documentos estão abertos. Digite parte de um nome ou de uma pasta; cada palavra deve corresponder em algum ponto do nome ou da pasta, sem diferenciar maiúsculas e acentos. Return abre a primeira correspondência. Quando nada corresponde, diz "Nenhum documento aberto corresponde." |
| Uma linha para cada documento | Mostra o nome, o ponto de salvamento e a pasta em que ele está. Uma marca de seleção indica o documento ativo. Clique em uma linha para mudar para ele. |
| **Fechar** (o **x** no fim de uma linha) | Fecha aquele documento, perguntando antes se ele tem alterações não salvas. |
| **Novo documento** | Cria um documento sem título. |
| **Salvar** | Salva o documento ativo. |
| **Salvar como…** | Salva com um novo nome ou em um novo local. |
| **Renomear…** | Abre o formulário de renomeação (abaixo). |
| **Fechar todos os documentos** | Fecha todos os documentos, perguntando sobre cada um não salvo. |

Use `⌃Tab` e `⌃⇧Tab` para ir ao documento seguinte ou anterior sem abrir a lista.

## Renomear

**Renomear…** mostra o **Nome** atual e **Onde** o arquivo está, com os botões **Cancelar** e **Renomear**. Renomear altera o arquivo no disco e mantém o documento aberto. Se o novo nome não puder ser usado, uma mensagem **Não foi possível renomear o documento** explica o motivo.
