# Chapter 72: Teclado

**Ajustes ▸ Teclado ▸ Atalhos** lista todos os comandos cujo atalho você pode alterar, com a tecla atual.

| Controle | O que faz |
| --- | --- |
| A linha de um comando | Clique nela, pressione o novo atalho e escolha **Salvar**. **Desvincular** remove o atalho. **Cancelar** mantém o antigo. Se o atalho estava em uso por outro comando, esse comando é limpo e a página informa qual. |
| **Teclas do Super Tab** | As teclas de **Próximo campo** e **Campo anterior**, que saltam entre os espaços em branco que uma macro deixa: `⌥Tab` e `⌥⇧Tab`, ou `⌃⌘]` e `⌃⌘[`, ou **Personalizado**. |
| **Redefinir todos os atalhos** | Restaura todos os padrões. |

Os comandos que você pode alterar, com seus padrões, são:

| Comando | Padrão |
| --- | --- |
| Negrito | `⌘B` |
| Ênfase | `⌘I` |
| Código embutido | `⌃`` ` `` |
| Fórmula em linha | `⌃M` |
| Tachado | `⌃⇧`` ` `` |
| Hiperlink | `⌘K` |
| Limpar formatação | `⌘\` |
| Mostrar/ocultar barra lateral | `⇧⌘L` |
| Barra lateral: Estrutura | `⌃⌘1` |
| Documentos abertos | `⌃⌘2` |
| Barra lateral: Árvore de arquivos | `⌃⌘3` |
| Barra lateral: Buscar | `⇧⌘F` |
| Barra lateral: Assistente | `⌃⌘4` |
| Adicionar cursor acima | `⌃⇧↑` |

| Cursores em uma coluna… | `⌃⇧G` |

| Selecionar todas as ocorrências | `⌃⌥⇧D` |
| Próximo campo | `⌥Tab` |
| Campo anterior | `⌥⇧Tab` |
| Paleta de comandos… | `⌃⇧P` |
| Modo foco | nenhum |

Os comandos que não estão nesta lista, como Salvar, Localizar e os itens de Parágrafo, têm atalhos fixos. O Chapter 77 lista todos os atalhos.

# Chapter 73: Assinatura e créditos

Todos os recursos do Pilcrow são gratuitos. Apoiar o Pilcrow é opcional: isso ajuda a pagar o desenvolvimento e dá a você votos sobre o que será criado em seguida. Os votos orientam a ordem do trabalho, mas não prometem nenhum recurso.

A página **Apoie o Pilcrow** tem:

| Parte | O que mostra ou faz |
| --- | --- |
| **Seus votos** | **Da sua assinatura** (os votos do mês pago atual, com a data em que expiram) e **Comprados** (votos que nunca expiram). Os votos da assinatura são usados primeiro e expiram quando o mês pago termina. |
| **Obter votos** | A assinatura e os votos avulsos que você pode comprar. O Pilcrow Supporter é renovado todo mês até você cancelá-lo nos ajustes da sua Conta Apple. Cada mês pago dá a você votos. |
| **Restaurar compras** | Recupera compras feitas em outro dispositivo. |
| **Termos de uso**, **Política de privacidade** | Links. |
| **Ícone do app** | Uma escolha de ícones do app para assinantes. Os ícones de uma rodada de votação são conquistados ao assinar durante essa rodada e são mantidos. No Mac, o ícone muda no Dock enquanto o Pilcrow está aberto. |
| **Roteiro** | A rodada atual de recursos abertos para votação, com as contagens “Votos” e “Seus” e um botão **Votar** para cada um. Cada voto usa um dos seus votos e não pode ser desfeito. Entre as rodadas, informa quando a próxima abre. |

Se as opções de apoio não estiverem disponíveis em uma versão específica, a página informa isso.
