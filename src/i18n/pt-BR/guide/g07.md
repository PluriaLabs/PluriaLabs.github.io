# Chapter 60: A barra lateral

A barra lateral tem cinco painéis: **Arquivos**, **Estrutura**, **Buscar**, **Projeto** e **Assistente**. Um seletor no alto da barra lateral escolhe **Arquivos**, **Estrutura**, **Projeto** (exibido quando a pasta aberta é um projeto de livro) ou **Assistente** (exibido depois que uma conexão é configurada). **Buscar** tem um cabeçalho próprio, com o título **Localizar**, um botão **Concluído** que volta para Arquivos e um controle de escopo para **Este documento** ou **Pasta**; acesse-o por **Visualização ▸ Buscar** (`⇧⌘F`). O menu **Visualização** também alterna os painéis, e escolher o painel que já está à mostra oculta a barra lateral. Arraste a borda da barra lateral para redimensioná-la. Acima da árvore de arquivos, um menu oferece **Abrir arquivo…** e **Abrir pasta…**.

## Arquivos

O painel Arquivos é uma árvore da pasta aberta.

Sem nenhuma pasta aberta, ele diz “Escolha uma pasta para explorar os arquivos dela.” e oferece **Abrir pasta** e **Abrir arquivo**. Você também pode soltar uma pasta sobre ele. Quando você abriu um único arquivo cuja pasta o Pilcrow não consegue ver, ele oferece “Explorar *pasta* para ver os arquivos ao lado deste documento”, com **Explorar a pasta que contém o arquivo…**.

Clique em um arquivo para abri-lo. As pastas se expandem e se recolhem. Clique com o botão direito em uma linha, ou toque e segure no iPad, para ver o menu dela:

| Item | O que faz |
| --- | --- |
| **Novo arquivo** | Cria um arquivo na pasta (ou ao lado do arquivo em que você clicou). |
| **Nova pasta** | Cria uma pasta ali. |
| **Renomear…** | Renomeia o arquivo ou a pasta. |
| **Mover para o Lixo** | Move o item para o Lixo depois que você confirma. De lá, você pode colocá-lo de volta. |
| **Mostrar no Finder** | Mostra o item no Finder (Mac). |

Quando o sistema não tem Lixo para um local, o Pilcrow guarda os itens excluídos em uma seção **Apagados recentemente** no fim do painel. Cada item ali oferece **Colocar de volta** e **Excluir permanentemente**, e **Esvaziar Apagados recentemente** remove de vez todos os itens da seção. A exclusão permanente não pode ser desfeita, por isso o Pilcrow pergunta antes. Os itens que você excluiu de outros locais não são afetados.

Os arquivos e as pastas ocultos são mostrados ou ocultados em **Ajustes ▸ Arquivos ▸ Mostrar pastas e arquivos ocultos**.

## Estrutura

A Estrutura lista os títulos do documento ativo, recuados conforme o nível. Clique em um título para ir até ele. Uma seta ao lado de um título recolhe ou expande os títulos aninhados abaixo dele. Isso não altera o documento, e o estado de recolhimento não é salvo.

Estados que você pode ver:

| Mensagem | Significado |
| --- | --- |
| **Nenhum título** | O perfil ativo não encontrou títulos. |
| **Indexando a estrutura… N%** | Um documento grande ainda está sendo examinado. |
| **Falha na indexação da estrutura. A lista pode estar incompleta.** | A análise encontrou um problema. |
| **N títulos perto da sua posição — role para ver os outros.** | Um documento muito grande mostra uma janela da estrutura ao redor do cursor. |

Sob a estrutura, uma seção **Campos** aparece quando o documento tem campos a preencher (Chapter 24). Ela os lista, com a contagem; clique em um para rolar até ele e selecioná-lo. Quando há uma quantidade muito grande de campos, ela diz “Só os primeiros campos estão listados.”

## Buscar

O painel Buscar pesquisa todos os arquivos da pasta aberta. Sem uma pasta, ele diz “Abra uma pasta para buscar nela.” com um botão **Abrir pasta…**.

| Controle | O que faz |
| --- | --- |
| Campo **Buscar na pasta** | Digite para buscar enquanto escreve. Um botão **limpar** esvazia o campo. |
| **Aa** | **Diferenciar maiúsculas.** |
| **ab** | **Palavra inteira.** |
| **.\*** | **Expressão regular.** Um padrão inválido é indicado abaixo do campo. |
| Linha de status | Mostra “Buscando…” com um botão **Cancelar** e depois “Ocorrências: N”. A busca para em 500 ocorrências e diz “Mostrando as primeiras 500 ocorrências.” Depois de um cancelamento, oferece **Buscar novamente**. |
| **Substituir…** | Aparece quando a busca encontra ocorrências. Abre Substituir na pasta (Chapter 63). |
| Resultados | Cada resultado indica o arquivo e mostra a linha. Clique em um para abrir o arquivo nessa linha. |

## Projeto

O painel Projeto é para projetos de livro. Veja o Chapter 34, o Chapter 35 e a referência do painel Projeto abaixo.

### Referência do painel Projeto

| Parte | O que faz |
| --- | --- |
| **Esta pasta não é um projeto de livro.** com **Transformar em projeto** | Exibido quando a pasta aberta não tem manifesto. |
| **Tentar novamente** | Exibido se o projeto não pôde ser lido. |
| **Visualização** | Escolhe **Lista**, **Sinopses** ou **Cartões**. |
| Título, totais de palavras | O nome do projeto e “N palavras”, ou “N de meta” quando há uma meta de palavras do livro. |
| Filtro **Status** | Filtra por um único status, ou **Todos os status**. Uma contagem lista cada status com o número de arquivos e de palavras. A reordenação só está disponível enquanto nenhum filtro estiver ativo. |
| **Ajustes do projeto** (engrenagem) | Abre a folha de ajustes abaixo. |
| **Compilar…** | Abre a folha de compilação (Chapter 64). |
| **Reordenar** e **Concluído** | No iPad, arraste os capítulos para uma nova ordem e depois escolha **Concluído**. |
| **Novo arquivo** (mais) | Oferece **Novo capítulo**, **Nova cena**, **Novos elementos pré-textuais**, **Novos elementos pós-textuais**. |
| **Fora do manuscrito** com **Adicionar** e **Adicionar tudo** | Lista os arquivos da pasta que o manifesto não inclui. |
| A seta de uma linha | **Mostrar cenas** ou **Ocultar cenas** sob um capítulo. |
| Etiquetas **Ausente** e **Excluído** | Um arquivo que não foi encontrado, ou que você excluiu do manuscrito. |
| O menu de uma linha | **Detalhes…**, **Novo arquivo abaixo**, **Mover o capítulo para cima**, **Mover o capítulo para baixo**, **Incluir no manuscrito**, **Excluir do manuscrito**. |
| **Meta de palavras** por item | Cada item mostra suas palavras e a meta, se houver. |

**Detalhes** de um item tem **Tipo** (Elementos pré-textuais, Parte, Capítulo, Cena, Elementos pós-textuais), **Status**, **Ponto de vista**, **Local** e **Meta de palavras**, além de **Sinopse**. Um arquivo de projeto alterado no disco mostra “O arquivo do projeto foi alterado no disco, então sua última alteração não foi aplicada. Tente de novo.” com **Dispensar**.

**Ajustes do projeto** tem **Título**, **Autor**, **Meta de palavras do livro**, **Os novos arquivos são escritos em** (a sintaxe dos novos capítulos e cenas; os arquivos existentes mantêm a sua), **Variáveis** (um nome e um valor, escritos como `{{name}}` no seu texto; `{{title}}` e `{{author}}` sempre funcionam) e **O que conta como palavra**: **Contar títulos**, **Contar elementos pré-textuais**, **Contar blocos de código**. Escolha **Salvar** ou **Cancelar**.

## Assistente

O painel Assistente aparece depois que uma conexão é configurada (Chapter 65).

# Chapter 61: A barra de formatação e a barra de status

## A barra de formatação

A barra de formatação é uma linha opcional abaixo do texto. Mostre-a ou oculte-a com **Visualização ▸ Barra de formatação**, **Mais ▸ Barra de formatação**, **Ajustes ▸ Edição ▸ Barra de formatação** ou o próprio item **Ocultar barra de ferramentas** da barra. Ela age por meio do perfil ativo, então um botão que o perfil não consegue expressar fica esmaecido.

| Controle | O que faz |
| --- | --- |
| Menu **Tipo de parágrafo** (por exemplo “Parágrafo” ou “Título 1”) | Mostra o tipo da linha atual e o altera: **Parágrafo**, **Título 1** a **6**, **Citação**, **Lista com marcadores**, **Lista numerada**, **Lista de tarefas**, **Bloco de código**. |
| **Negrito** (`⌘B`) | Negrito. |
| **Itálico** (`⌘I`) | Ênfase. |
| **Código embutido** | Código. |
| **Inserir link** (`⌘K`) | Cria um link. |
| **Citação** | Alterna uma citação. |
| **Lista com marcadores** | Alterna uma lista com marcadores. |
| **Mais formatação** (**⋯**) | Os comandos menos usados: **Tachado**, **Inserir fórmula em linha**, **Inserir lista de tarefas**, **Alternar estado da tarefa**, **Recuar**, **Diminuir recuo**, **Aumentar nível do título**, **Diminuir nível do título**, **Inserir tabela…**, **Inserir imagem…**, **Inserir diagrama**, **Inserir gráfico**, **Inserir fórmula destacada**, **Inserir bloco de código**, **Inserir alerta**, **Inserir linha horizontal**, **Inserir referência de link**, **Inserir nota de rodapé**, **Inserir sumário**, **Inserir front matter YAML** e **Ocultar barra de ferramentas**. |

## A barra de status

A barra de status corre ao longo da parte inferior. Ative-a ou desative-a em **Ajustes ▸ Edição ▸ Mostrar barra de status**.

| Parte | O que mostra ou faz |
| --- | --- |
| **Palavras**, **Lin**, **Col** | A contagem de palavras e a linha e a coluna do cursor. Com uma seleção, acrescenta “Sel: N lin · N car” para as linhas e os caracteres selecionados. |
| Menu **Sintaxe** (por exemplo “CommonMark”) | O perfil deste documento. Clique para escolher outro, ou **Sem sintaxe** para texto simples. |
| **Campos restantes: N** | Exibido quando uma macro deixou campos a preencher. Clique para ir ao próximo campo. |
| Progresso e status | **Indexando N%**, **Análise léxica N%** enquanto um arquivo grande é analisado, e **Traduzindo N%** com **Faltam cerca de N** e um botão **Cancelar tradução** enquanto uma tradução está em andamento. |
| **Fora de sincronia** | Um aviso de que o editor e o registro de alterações do documento divergiram. Ao salvar, o arquivo continua marcado como não salvo para que nada se perca: copie seu texto para um lugar seguro e depois feche e reabra o documento. |
| Informações do documento | Clique nas contagens, ou na dica “Mostrar informações do documento”, para abrir **Informações do documento**. |

**Informações do documento** lista **Palavras**, **Caracteres**, **Linhas**, **Tempo de leitura** (com base na sua velocidade de leitura em Ajustes), **Cursor**, **Seleção**, **Codificação** e **Sintaxe**. Em um arquivo muito grande, as contagens se referem à parte carregada até que a indexação termine, e o tempo de leitura é estimado para o arquivo inteiro. **Converter para…** sob **Codificação** escolhe outra codificação de texto; o arquivo é convertido na próxima vez que for salvo.


# Chapter 62: Localizar, substituir, Ir para a linha, Abrir rapidamente e a paleta de comandos

## A barra de busca

Abra-a com **Localizar…** (`⌘F`), o botão **Localizar** ou **Substituir…** (`⌘R`). Ela fica no alto do documento.

| Controle | O que faz |
| --- | --- |
| Campo **Localizar no documento** | Digite o texto a localizar. As ocorrências são destacadas enquanto você digita. |
| **Aa**, **ab**, **.\*** | **Diferenciar maiúsculas**, **Palavra inteira**, **Expressão regular**. |
| **Ocorrência anterior**, **Próxima ocorrência** | Percorrem as ocorrências (`⇧⌘G`, `⌘G`). |
| **Mostrar substituição** / **Ocultar substituição** (seta) | Mostra o campo **Substituir por**. |
| **Substituir**, **Substituir tudo** | Substitui a ocorrência atual, ou todas as ocorrências. Fica esmaecido até haver uma ocorrência. |
| **Buscar em** (um seletor na extremidade esquerda da barra) | **Este documento**, ou **Pasta** para buscar em toda a pasta aberta. |
| **Fechar barra de busca** | Fecha a barra. |

Quando há mais ocorrências do que o Pilcrow conta, a barra diz “Há mais ocorrências”. Em **Pré-visualização**, Localizar examina as palavras renderizadas e as destaca, até 2.000 ocorrências. Um padrão que não pode ser usado diz “Padrão inválido”. Substituir só está disponível em Editar: na Pré-visualização, a barra diz “Substituir funciona em Editar. Mude para Editar para alterar o texto.” Em **Lado a lado**, Localizar busca no código-fonte e destaca as palavras correspondentes na pré-visualização.

## Ir para a linha

**Ir para a linha…** (`⌃G`) abre uma pequena folha com um campo, “Número da linha, ou linha:coluna”. Digite `120` ou `120:8` e escolha **Ir**, ou **Cancelar**. Um número além do fim leva à última linha. O Pilcrow diz “Digite um número de linha, como 120 ou 120:8.” para qualquer outra entrada. Em um arquivo muito grande cujas linhas ainda estão sendo contadas, ele pede que você tente de novo em instantes.

## Abrir rapidamente

**Abrir rapidamente…** (`⇧⌘O`) é uma busca por nome de arquivo em toda a pasta aberta. Digite parte de um nome, e a lista se estreita e mostra “N ocorrências”. Escolha um resultado e **Abrir**, ou **Cancelar**. Fica esmaecido sem uma pasta aberta.

## A paleta de comandos

**Paleta de comandos…** (`⌃⇧P`) lista os comandos do Pilcrow pelo nome, com seus atalhos, para que você execute um sem procurar o menu dele. Digite para estreitar a lista, escolha um comando e **Executar**, ou **Cancelar**. Mostra “Nenhum comando correspondente” quando nada se encaixa. Um comando que não pode ser executado agora, como uma edição de código-fonte enquanto você está na Pré-visualização, aparece esmaecido. A lista inclui os comandos de formatação e de inserção, os comandos de Editar para seleção, linhas e capitalização, fala, as opções de Visualização, zoom e os painéis da barra lateral, e as ações de arquivo e de exportação. O atalho para abrir a paleta pode ser alterado em **Ajustes ▸ Teclado**.
