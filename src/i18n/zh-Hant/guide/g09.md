# Chapter 65: 助理面板與風格審閱

在 **設定 ▸ 助理**（第 67 章）中設定好連線後，就會出現助理面板。在沒有可用連線時，「檢視」選單中不會有 **助理** 項目。

## 面板

| 控制項 | 功能 |
| --- | --- |
| **助理模式** | **對話式**、**風格審閱**或**說明**。 |
| **選擇模型…** | 開啟模型選擇器（見下文）。當模型已無法使用或已被棄用時會顯示警告，並附上停用日期。 |
| **清除對話** | 清空對話。對話不會被儲存；App 結束時就會被捨棄。 |
| **傳送內容** | 選擇隨問題一併傳送的內容：**不含文件的任何內容**、**選取範圍**、**段落**、**游標周圍**、**整份文件**、**大綱**或**設定檔**。無法套用的選項會說明原因（「請先選取一些文字。」、「此文件沒有標題。」、「太大，無法整份傳送。」、「沒有語法設定檔。」）。問題輸入框上方的一行文字會說明將傳送多少內容、傳送到哪個主機。此選擇會被記住。 |
| **預覽**（以及 **傳送內容**） | 顯示確切將要傳送的內容。 |
| **詢問助理…** / **描述你想撰寫的內容** | 問題輸入框。在**說明**模式中，**要撰寫的內容**可選擇**語法設定檔**、**巨集**或**風格指南**。 |
| **傳送**與**停止** | 傳送請求，或停止正在進行的回覆。 |
| **隱私權** | 顯示此資料夾是否已啟用助理。**對此資料夾關閉**與**對此資料夾開啟**可切換。符合排除規則的檔案會顯示「此檔案已從助理中排除。」。 |
| 每則回覆 | **拷貝**、**插入到游標處**、**重試**，風格或巨集的回覆還有 **加入資料庫…**。含有錯誤的回覆會提供**請求修正**。被截斷的回覆會註明這一點。 |

## 選擇模型

**選擇模型…** 會列出連線所提供的模型，並附有**搜尋模型**。**顯示所有模型**會包含較不常見的模型。已棄用的模型會標示其停用日期。如果沒有列出任何模型，請改為輸入模型名稱。**重試**會重新載入清單。

## 風格審閱

在**風格審閱**模式中，面板會用風格指南檢查你的文章。

| 控制項 | 功能 |
| --- | --- |
| **風格指南**、**變體** | 選擇一份指南及其中一個變體。 |
| **要審閱的內容** | **選取範圍**或**文件**。文件太大而無法整份審閱時會顯示「太大，無法整份審閱。請改為審閱一個段落。」 |
| **區域** | 選擇要檢查的區域，或選擇**所有區域**。 |
| **審閱** | 將文字與規則傳送到你的 AI 連線。在整份文件審閱之前，會有提示說明將傳送多少個請求、大約多少文字，並詢問**審閱**或**取消**。 |
| **在此檢查** | 在此裝置上執行指南自己的檢查。不會傳送任何內容。 |
| **檢查交叉參照** | 傳送標題、引用行與參考清單，以檢查需要比對文件不同部分的規則。 |
| **停止** | 停止進行中的審閱。**審閱其餘部分**會在停止或失敗後繼續。 |

發現的問題會以清單呈現。每一項會顯示引文、說明，以及（若有的話）建議的修正。

| 按鈕 | 功能 |
| --- | --- |
| **跳至** | 移到文件中該項發現的位置。出現多次的引文會顯示「第 N 筆，共 N 筆」。 |
| **套用** | 執行建議的修正。只有在文字仍與發現時完全一致時才會套用。否則會顯示「文字已變更。」或「在文字中找不到。」 |
| **忽略** | 移除該項發現。 |
| **全部套用** | 在確認（會說明有多少項）之後，執行每一項有修正的建議，並作為一次變更，可一步復原。同時也會說明有多少項修正來自 AI。 |
| **忽略所有建議**、**清除** | 清除清單。 |

面板也會回報「有 N 條規則只能透過審閱來判斷」、「有 N 條規則在 100 項發現後停止」，以及「有一項建議的變更被略去，因為它加入了文字中沒有的事實。」

# Chapter 66: 設定的組織方式

從 **Pilcrow ▸ 設定…**（`⌘,`）開啟設定（Mac），或從 iPad 上標頭中的齒輪開啟，在 iPad 上它會以附有**完成**按鈕的面板顯示。視窗左側有**搜尋設定**輸入框與**類別**清單。每個類別有一個或多個**頁面**，以一排按鈕顯示在上方。

| 類別 | 頁面 |
| --- | --- |
| **一般** | 語言與視窗（iPad：**語言**）、檔案、翻譯、助理、診斷、儲存空間與隱私 |
| **編輯** | 顯示與輸入、圖片 |
| **外觀** | 佈景主題與背景圖、文字大小與字體 |
| **目錄** | 目錄與標籤 |
| **匯出** | 匯出預設值 |
| **資料庫** | 語法設定檔、CommonMark 選項、佈景主題、巨集、風格指南、渲染程式庫、位置（iPad 另有**匯入**） |
| **鍵盤** | 快速鍵 |
| **訂閱與點數** | 支持 Pilcrow |

**搜尋設定**可依名稱尋找控制項。輸入標籤的一部分，例如「行距」或「版本」，結果就會顯示該控制項、所在頁面與類別。選擇其中一項即可直接前往。變更會立即生效；除了佈景主題、設定檔、巨集與鍵盤快速鍵的編輯器之外，沒有儲存按鈕。

只影響單一 Mac 或單一 iPad 的設定會留在該裝置上。你的資料庫（佈景主題、設定檔、巨集、風格指南與背景圖）可以移到你選擇的資料夾，包括 iCloud Drive 中的資料夾（第 71 章）。

### 記錄檢視器

| 項目 | 功能 |
| --- | --- |
| **儲存報告…** | 保留一個可自行傳送的檔案。 |
| **分享報告…** | 開啟分享面板（AirDrop、檔案等等）。 |

## 儲存空間與隱私

Pilcrow 會把復原副本、記錄、存取授權與支援資料保存在其沙盒內。每個類別都可以單獨刪除。這些控制項絕不會刪除你的文件。

| 區段 | 控制項 |
| --- | --- |
| **文件** | **審閱復原資料**與**審閱版本記錄**。審閱會列出受影響的項目及其大小，讓你在刪除前先看到空間用量。勾選要刪除的項目（**全選**或**全不選**），然後選擇**刪除所選**。文件有未儲存的變更時，無法審閱復原資料：請先儲存或關閉它。 |
| **檔案存取權限** | **清除最近檔案的存取權限…**會移除最近檔案清單、記住的「另存新檔」資料夾、工作階段書籤，以及各檔案的語法選擇。 |
| **私人資料與支援資料** | **刪除 AI 資料與金鑰…**（連線、鑰匙圈金鑰、目前的對話與 AI 隱私選擇）、**刪除診斷資訊…**（已記錄的記錄與已儲存的當機診斷資訊），以及**清除快取…**（可重新建立的快取檔案與網路回應）。 |

每次刪除都會要求確認（「此操作無法復原。你的文件不會被刪除。」）。自訂的語法設定檔、佈景主題、巨集、風格指南與背景圖不會在此移除；請在它們各自的「資料庫」頁面中審閱並刪除。
