# Chapter 60: 側邊欄

側邊欄包含五個面板：**檔案**、**大綱**、**搜尋**、**專案**與**助理**。側邊欄頂端的切換開關可選擇**檔案**、**大綱**、**專案**（開啟的資料夾是書籍專案時才會顯示）或**助理**（設定好連線後才會顯示）。**搜尋**有自己的標頭，標題為**尋找**，並有一個可回到「檔案」的**完成**按鈕，以及選擇**此文件**或**資料夾**範圍的控制項；請由 **檢視 ▸ 搜尋**（`⇧⌘F`）開啟。**檢視**選單也能切換面板，若選擇的是目前已顯示的面板，則會隱藏側邊欄。拖移側邊欄的邊緣即可調整大小。在檔案樹上方，有一個選單提供**開啟檔案…**與**開啟資料夾…**。

## 檔案

「檔案」面板是已開啟資料夾的樹狀結構。

若沒有開啟任何資料夾，面板會顯示「選擇資料夾以瀏覽其中的檔案。」，並提供**開啟資料夾**與**開啟檔案**。您也可以把資料夾拖放到面板上。若您開啟的是單一檔案，而 Pilcrow 看不到該檔案所在的資料夾，面板會提供「瀏覽 *資料夾* 以查看此文件旁的檔案」，並附上**瀏覽所在資料夾…**。

按一下檔案即可開啟。資料夾可展開與收合。在某一列上按右鍵（在 iPad 上則按住不放），即可開啟它的選單：

| 項目 | 功能 |
| --- | --- |
| **新增檔案** | 在資料夾中（或在您點選的檔案旁）建立檔案。 |
| **新增資料夾** | 在該處建立資料夾。 |
| **重新命名…** | 重新命名檔案或資料夾。 |
| **移到垃圾桶** | 經您確認後，將它移到垃圾桶。您可以從那裡放回。 |
| **在 Finder 中顯示** | 在 Finder 中顯示它（Mac）。 |

若系統在某個位置沒有垃圾桶，Pilcrow 會把刪除的項目保存在面板底部的**最近刪除**區段。該處每個項目都提供**放回**與**永久刪除**，而**清空「最近刪除」**會永久移除整個區段中的項目。永久刪除無法復原，因此 Pilcrow 會先詢問。您從其他位置刪除的項目不受影響。

隱藏的檔案與資料夾是否顯示，由 **設定 ▸ 檔案 ▸ 顯示隱藏的資料夾與檔案**控制。

## 大綱

「大綱」會依層級縮排，列出使用中文件的標題。按一下標題即可跳到該處。標題旁的箭頭可收合或展開其下的巢狀標題。這不會更動文件，收合的狀態也不會被儲存。

您可能看到的狀態：

| 訊息 | 意義 |
| --- | --- |
| **沒有標題** | 使用中的設定檔找不到任何標題。 |
| **正在為大綱建立索引… N%** | 大型文件仍在掃描中。 |
| **大綱索引失敗。清單可能不完整。** | 掃描時發生問題。 |
| **您的位置附近有 N 個標題 — 捲動即可查看其他標題。** | 非常大的文件只會顯示插入點附近的一段大綱。 |

在大綱下方，當文件含有待填寫的欄位時，會出現**欄位**區段（第 24 章）。它會列出這些欄位並顯示數量；按一下其中一個即可捲動到該處並選取它。若欄位數量非常多，會顯示「只列出前幾個欄位。」

## 搜尋

「搜尋」面板會搜尋已開啟資料夾中的每個檔案。若沒有開啟資料夾，會顯示「開啟資料夾即可搜尋。」以及**開啟資料夾…**按鈕。

| 控制項 | 功能 |
| --- | --- |
| **搜尋資料夾**欄位 | 輸入時即時搜尋。**清除**按鈕可清空欄位。 |
| **Aa** | **區分大小寫。** |
| **ab** | **全字拼寫相符。** |
| **.\*** | **正規表示式。**無效的模式會在欄位下方回報。 |
| 狀態列 | 顯示「正在搜尋…」與**取消**按鈕，然後顯示「符合項目：N」。搜尋在 500 筆符合項目時停止，並顯示「顯示前 500 筆符合項目。」取消後會提供**再次搜尋**。 |
| **取代…** | 搜尋到符合項目時出現。開啟「在資料夾中取代」（第 63 章）。 |
| 結果 | 每筆結果會列出檔案名稱並顯示該行內容。按一下即可在該行開啟檔案。 |

## 專案

「專案」面板用於書籍專案。請參閱第 34 章、第 35 章，以及下方的「專案面板參考」。

### 專案面板參考

| 部分 | 功能 |
| --- | --- |
| **此資料夾不是書籍專案。**與**設為專案** | 開啟的資料夾沒有資訊清單時顯示。 |
| **重試** | 無法讀取專案時顯示。 |
| **檢視** | 選擇**清單**、**概要**或**卡片**。 |
| 標題、字數總計 | 專案名稱與「N 字」，若設定了全書字數目標，則顯示「N／目標」。 |
| **狀態**篩選 | 篩選為單一狀態，或**所有狀態**。統計會列出每個狀態及其檔案數與字數。只有在沒有啟用任何篩選時才能重新排序。 |
| **專案設定**（齒輪） | 開啟下方的設定面板。 |
| **編譯…** | 開啟編譯面板（第 64 章）。 |
| **重新排序**與**完成** | 在 iPad 上，拖移章節以調整順序，然後選擇**完成**。 |
| **新增檔案**（加號） | 提供**新增章節**、**新增場景**、**新增前置內容**、**新增附錄**。 |
| **不在書稿中**，附有**加入**與**全部加入** | 列出資料夾中資訊清單未包含的檔案。 |
| 某一列的箭頭 | 在章節下**顯示場景**或**隱藏場景**。 |
| **遺失**與**已排除**標記 | 表示找不到的檔案，或您已從書稿中排除的檔案。 |
| 某一列的選單 | **詳細資訊…**、**在下方新增檔案**、**上移章節**、**下移章節**、**納入書稿**、**從書稿中排除**。 |
| 每個項目的**字數目標** | 每個項目會顯示其字數與任何目標。 |

項目的**詳細資訊**包含**種類**（前置內容、部、章節、場景、附錄）、**狀態**、**視角**、**位置**、**字數目標**與**概要**。若專案檔案在磁碟上有變更，會顯示「專案檔案已在磁碟上變更，因此您最近的更動未被套用。請再試一次。」並附有**忽略**。

**專案設定**包含**標題**、**作者**、**全書字數目標**、**新檔案使用的格式**（新章節與場景的語法；既有檔案維持原樣）、**變數**（名稱與值，在文字中寫成 `{{name}}`；`{{title}}` 與 `{{author}}` 一律可用），以及**哪些內容算作詞**：**計入標題**、**計入前置內容**、**計入程式碼區塊**。請選擇**儲存**或**取消**。

# Chapter 61: 格式工具列與狀態列

## 格式工具列

格式工具列是文字下方的選用列。可透過 **檢視 ▸ 格式工具列**、**更多 ▸ 格式工具列**、**設定 ▸ 編輯中 ▸ 格式工具列**，或工具列本身的**隱藏工具列**項目來顯示或隱藏。它透過使用中的設定檔運作，因此設定檔無法表達的按鈕會呈現灰色。

| 控制項 | 功能 |
| --- | --- |
| **段落類型**選單（例如「段落」或「標題 1」） | 顯示目前這一行的類型並可變更：**段落**、**標題 1**至 **6**、**引用區塊**、**項目符號清單**、**編號清單**、**待辦事項清單**、**程式碼圍欄**。 |
| **粗體**（`⌘B`） | 粗體。 |
| **斜體**（`⌘I`） | 強調。 |
| **行內程式碼** | 程式碼。 |
| **插入連結**（`⌘K`） | 建立連結。 |
| **引用區塊** | 切換引用。 |
| **項目符號清單** | 切換項目符號清單。 |
| **更多格式**（**⋯**） | 較少用的指令：**刪除線**、**插入行內數學式**、**插入待辦事項清單**、**切換待辦事項狀態**、**增加縮排**、**減少縮排**、**提高標題層級**、**降低標題層級**、**插入表格…**、**插入圖片…**、**插入圖解**、**插入圖表**、**插入顯示數學式**、**插入程式碼圍欄**、**插入提醒**、**插入水平線**、**插入連結參照**、**插入註腳**、**插入目錄**、**插入 YAML 前置資料**，以及**隱藏工具列**。 |

## 狀態列

狀態列位於底部。可透過 **設定 ▸ 編輯中 ▸ 顯示狀態列**開啟或關閉。

| 部分 | 顯示內容或功能 |
| --- | --- |
| **字數**、**行**、**欄** | 字數，以及插入點所在的行與欄。有選取內容時，會加上「選取：N 行 · N 字元」，表示所選取的行數與字元數。 |
| **語法**選單（例如「CommonMark」） | 此文件的設定檔。按一下可選擇其他設定檔，或選擇**無語法**以使用純文字。 |
| **剩餘欄位：N** | 巨集留下待填寫的欄位時顯示。按一下即可跳到下一個欄位。 |
| 進度與狀態 | 分析大型檔案時顯示**正在建立索引 N%**、**正在詞法分析 N%**；翻譯進行時顯示**正在翻譯 N%**、**約剩 N** 以及**取消翻譯**按鈕。 |
| **不同步** | 警告編輯器與文件的變更記錄已不一致。儲存時檔案會保持未儲存的標記，以免遺失任何內容：請把文字複製到安全的地方，然後關閉並重新開啟文件。 |
| 文件資訊 | 按一下各項計數，或提示文字「顯示文件資訊」，即可開啟**文件資訊**。 |

**文件資訊**列出**字數**、**字元**、**行**、**閱讀時間**（依據「設定」中的閱讀速度）、**游標**、**選取範圍**、**編碼**與**語法**。在非常大的檔案中，索引完成前的計數僅涵蓋已載入的部分，而閱讀時間則是估算整個檔案。**編碼**下的**轉換為…**可選擇另一種文字編碼；檔案會在下次儲存時轉換。


# Chapter 62: 尋找、取代、前往行、快速開啟與指令面板

## 尋找列

可透過**尋找…**（`⌘F`）、**尋找**按鈕或**取代…**（`⌘R`）開啟。它位於文件頂端。

| 控制項 | 功能 |
| --- | --- |
| **在文件中尋找**欄位 | 輸入要尋找的文字。輸入時會即時醒目標示符合項目。 |
| **Aa**、**ab**、**.\*** | **區分大小寫**、**全字拼寫相符**、**正規表示式**。 |
| **上一個符合項目**、**下一個符合項目** | 逐一瀏覽符合項目（`⇧⌘G`、`⌘G`）。 |
| **顯示取代** / **隱藏取代**（箭頭） | 顯示**取代為**欄位。 |
| **取代**、**全部取代** | 取代目前的符合項目，或所有符合項目。在有符合項目之前呈現灰色。 |
| **尋找範圍**（列左端的切換開關） | **此文件**，或選擇**資料夾**改為搜尋整個已開啟的資料夾。 |
| **關閉尋找列** | 關閉尋找列。 |

當符合項目多於 Pilcrow 所計算的數量時，尋找列會顯示「仍有更多符合項目」。在**預覽**中，尋找會搜尋已渲染的文字並醒目標示，最多 2,000 筆符合項目。無法使用的模式會顯示「模式無效」。取代僅能在「編輯」中使用：在「預覽」中，尋找列會顯示「取代僅能在「編輯」中使用。請切換到「編輯」以更改文字。」在**並排**中，尋找會搜尋原始碼，並在預覽中醒目標示相符的文字。

## 前往行

**前往行…**（`⌃G`）會開啟一個只有一個欄位的小面板，欄位提示為「行號，或 行:欄」。輸入 `120` 或 `120:8`，然後選擇**前往**或**取消**。超過檔案結尾的數字會前往最後一行。輸入其他內容時，Pilcrow 會顯示「請輸入行號，例如 120 或 120:8。」在仍在計算行數的非常大檔案中，它會請您稍候再試。

## 快速開啟

**快速開啟…**（`⇧⌘O`）是在已開啟資料夾中搜尋檔名。輸入名稱的一部分，清單就會縮小並顯示「N 個符合項目」。選擇一個結果並按**開啟**，或按**取消**。沒有已開啟的資料夾時呈現灰色。

## 指令面板

**指令面板…**（`⌃⇧P`）會依名稱列出 Pilcrow 的指令及其快速鍵，讓您不必找到選單就能執行指令。輸入文字可縮小清單，選擇一個指令並按**執行**，或按**取消**。沒有符合項目時會顯示「沒有符合的指令」。目前無法執行的指令（例如在「預覽」中進行原始碼編輯）會呈現灰色。清單包含格式與插入指令、用於選取範圍、行與大小寫的「編輯」指令、語音、「檢視」切換、縮放、側邊欄面板，以及檔案與匯出動作。開啟指令面板的快速鍵可在 **設定 ▸ 鍵盤**中更改。
