# Chapter 81: 檔案、編碼與限制

## Pilcrow 能開啟的檔案

Pilcrow 編輯純文字與標記檔案。常見的副檔名有 `txt`、`md`、`markdown`、`adoc`、`asciidoc`、`rst` 和 `tex`，以及你加入的設定檔所宣告的任何副檔名。Pilcrow 在開啟檔案時會偵測其文字編碼。

| 項目 | 類型 |
| --- | --- |
| 語法設定檔、巨集集合、風格指南、應用程式佈景主題 | `.json` |
| 渲染佈景主題 | `.css` |
| 佈景主題套件 | `.zip` |
| 書籍專案資訊清單 | `manifest.pilcrow` |
| 背景圖 | HEIC、PNG、JPEG、SVG、MP4、MOV、M4V |
| 鍵入聲音片段 | WAV、AIFF、MP3、M4A、CAF |

## 文字編碼

Pilcrow 可讀取 UTF-8、UTF-16、UTF-32 和 ISO 8859-1（Latin-1）文字。你可以使用 **文件資訊 ▸ 編碼 ▸ 轉換為…** 將文件轉換為下列任一種編碼；檔案會在下次儲存時完成轉換：

UTF-8、UTF-8 (BOM)、UTF-16 LE、UTF-16 LE (BOM)、UTF-16 BE、UTF-16 BE (BOM)、UTF-32 LE、UTF-32 LE (BOM)、UTF-32 BE、UTF-32 BE (BOM)。

Latin-1 檔案可以無損轉換為上述任何一種編碼。不提供轉換為 Latin-1 的選項，因為這可能會破壞內容。

## 匯出格式

| 格式 | 副檔名 |
| --- | --- |
| HTML、HTML（不含樣式） | `.html` |
| PDF | `.pdf` |
| Word (.docx) | `.docx` |
| 圖片 | `.png` |
| PDF 封存檔 | `.zip` |

## 限制與數值

Pilcrow 的上限所在，或某項選擇的範圍：

| 位置 | 限制 |
| --- | --- |
| 搜尋面板 | 達 500 筆符合項目時停止。 |
| 預覽中尋找 | 最多計算 2,000 筆符合項目。 |
| 在資料夾中取代 | 一次最多變更 2,000 個檔案。 |
| 檢查連結 | 最多檢查 50,000 個連結。 |
| 比較 | 最多顯示 5,000 行變更。 |
| 保留的版本數 | 從無到 500（預設為 50）。 |
| 長行 | 達 20,000 個字元以上的行一律自動換行。 |
| 字體大小 | 9 至 32 點。 |
| Tab 寬度 | 2 至 8 個空格。 |
| 文字寬度 | 50% 至 100%。 |
| 縮放 | 50% 至 200%，分十個級距。 |
| 閱讀速度 | 每分鐘 60 至 2,000 字。 |
| 導覽器寬度 | 180 至 420 點。 |
| 鍵入聲音片段 | 最長 2 秒、最大 3 MB。 |
| 診斷報告的記錄文字 | 加入 GitHub 議題說明時，為最新的項目，最多 60,000 個字元。 |
| 超大型檔案 | 開啟與編輯時不會整個讀入記憶體。行數與字數統計以及大綱會在背景完成，在此之前可能不完整。超大型文件的 PDF 匯出所需的記憶體遠多於編輯或匯出 HTML 與 Word；PDF 封存檔會將其分割為有界的部分。 |

## Pilcrow 把東西存放在哪裡

| 內容 | 位置 |
| --- | --- |
| 你的文件 | 你儲存的任何位置。 |
| 資料庫（佈景主題、設定檔、巨集、風格指南、背景圖） | 在 App 的私人儲存空間中，或位於你所選資料夾內名為「Pilcrow Library」的資料夾中（**設定 ▸ 資料庫 ▸ 位置**）。 |
| 偏好設定、API 金鑰、復原副本、版本記錄 | 在裝置上，位於 App 的私人儲存空間與鑰匙圈中。可在 **設定 ▸ 一般 ▸ 儲存空間與隱私** 中檢視與刪除。 |
| 診斷記錄 | 在裝置上，直到你清除為止。 |

# Chapter 82: 訊息、橫幅與空白狀態

本章說明 Pilcrow 顯示的簡短訊息，讓每一則訊息都不再神祕。

## 在編輯器與預覽中

| 訊息 | 意義 |
| --- | --- |
| **目前沒有可預覽的內容。開始寫作後，內容就會顯示在這裡。**（或「請切換到編輯並開始寫作。」） | 文件是空的，所以預覽中沒有可繪製的內容。 |
| **預覽無法渲染：…**，附有 **顯示原始碼** 和 **重試** | 預覽失敗。**顯示原始碼** 會切換到編輯。**重試** 會再試一次。 |
| 失敗的方程式或圖表，附有 **顯示原始碼** 連結 | 有一個區塊無法繪製。按一下 **顯示原始碼** 即可跳到該區塊的原始碼並加以修正。 |
| **無法儲存**，附有 **重試** 和關閉按鈕 | 儲存失敗。文件仍保持開啟且未儲存。請排除原因（磁碟空間、權限、檔案已移動），然後選擇 **重試**。 |
| **磁碟上的檔案已變更** | 另一個 App 修改了該檔案。**重新載入** 會讀取新版本；**保留目前版本** 則保留你目前的內容。 |
| **解析警告** | 某一行中的結構可能不是你的本意（第 68 章）。 |
| **要取代現有檔案嗎？** | 你選擇的名稱在該位置已被使用。 |
| **仍有待填寫的欄位** | 你正在列印或匯出，但仍有未填寫的欄位（第 63 章）。 |
| **窗格分隔線**（VoiceOver 提示：「拖移以調整編輯器與預覽的大小。連按兩下以重設。」） | 並排檢視中原始碼與預覽之間的把手。 |
| **字數：N** | 狀態列中的字數統計。 |

## 在對話框與面板中

| 位置 | 訊息 | 意義 |
| --- | --- | --- |
| 指令面板 | **輸入指令** | 欄位的提示。沒有符合項目時會顯示「沒有符合的指令」。 |
| 快速開啟 | **輸入檔名** | 欄位的提示。 |
| 單欄多插入點 | **行（例如 3-17）**、**欄（例如 100，或 100-105 表示選取範圍）** | 欄位提示。單一欄位數會放置插入點；範圍則會選取每一行中的這些字元。 |
| 搜尋面板 | **輸入文字以搜尋此資料夾。**、**此資料夾中沒有符合項目。**、**搜尋已取消。** | 資料夾搜尋的狀態。 |
| 檔案面板 | **你也可以將資料夾拖放到這裡。** | 將資料夾拖到面板上即可開啟。 |
| 在資料夾中取代 | **沒有可取代的項目。** | 搜尋沒有符合項目。 |
| 比較 | 按鈕上的工具提示：**接受**（「在開啟的文件中進行此變更」）、**拒絕**（「不將此變更套用到開啟的文件」）、**取回**（「僅針對此項變更，將較舊的行放回文件中」）。 | 各按鈕的作用。 |
| 翻譯 | **無法完成翻譯。** | 請重試，或選擇其他速度。 |
| 翻譯 | **預估時間：不到一分鐘** | AI 助理速度的預估值；實際時間取決於你的 AI 服務。翻譯完成後，**在新標籤頁中開啟** 會開啟結果。 |
| 助理 | **沒有開啟的文件。**、**不會傳送任何文件文字。** | 面板沒有可分享的內容，因此不會傳送任何東西。 |
| 模型選擇器 | **正在載入模型…**、**沒有符合的模型。** | 清單正在載入，或你的搜尋沒有結果。 |
| 風格審閱 | **沒有發現。** 和 **無法將回覆解讀為審閱發現。請再試一次。** | 審閱沒有發現任何問題，或 AI 的回覆不是預期的格式。 |
| 風格審閱 | **全部套用** 工具提示：「將每一項有修正建議的修正一次完成，成為一個可復原的單一變更。」 | 一次復原即可還原全部。 |
| 專案面板 | **你的姓名**、**新增變數** | 作者欄位的提示，以及用於專案變數的按鈕。 |
| 助理權限 | **閱讀 Pilcrow 的隱私權政策** | 開啟隱私權政策。 |
