# Chapter 68: 編輯

## 顯示與輸入

### 顯示

| 控制項 | 功能 |
| --- | --- |
| **顯示行號** | 在行號欄中顯示行號。與 **檢視 ▸ 行號** 相同。 |
| **顯示目前行標線** | 在游標所在行下方顯示一條細線。 |
| **套用樣式的原始碼** | 以相符的字樣繪製標題、粗體與斜體。 |
| **標題摺疊** | 在標題旁顯示摺疊箭頭。 |
| **渲染區塊** | 將表格、方程式與圖解繪製為圖片，並附有編輯按鈕。 |
| **自動展開段落** | 當游標進入已摺疊的段落或圖片區塊時將其開啟，游標離開時再關閉。 |
| **隱藏標記** | 隱藏除游標所在行以外每一行的標題、粗體與斜體標記。需要套用樣式的原始碼。 |
| **長行自動換行** | 關閉時，長行會橫向捲動而不是換行。預覽與匯出一律會換行。20,000 個字元以上的行，以及專注模式，一律會換行。 |
| **單欄模式中的短行** | 當某一行太短而無法到達該欄時，欄的處理方式：**使用行尾**、**略過此行**、**以空格柔性填補**（加入空格，讓輸入的文字在畫面上對齊）、**以空格強制填補**（每缺少一個字元就補一個空格，讓它依欄號對齊），或**在該行停止**。刪除絕不會移除短行中的字元。 |
| **顯示狀態列** | 開啟或關閉底部的狀態列。 |
| **格式工具列** | 在文字下方顯示選用的工具列。 |

### 輸入

| 控制項 | 功能 |
| --- | --- |
| **自動配對括號與引號** | 輸入左括號或左引號時會加入對應的右括號或右引號。 |
| **自動配對 Markdown ( \* \_ ` ~ )** | 對 Markdown 的標記執行相同的處理。 |
| **展開表情符號簡碼 (:smile:)** | 在你輸入時將簡碼轉換為表情符號。已含有簡碼的檔案會照原樣顯示。 |
| **按下 Return 時延續清單與引用** | Return 會開始下一個項目，在空白項目上按 Return 會結束清單，Tab 會縮排項目。 |
| **按下 Return 時保留縮排** | 新的一行會以與上一行相同的前置空格或 Tab 開頭。 |
| **按下 Tab 時插入空格** | Tab 會插入與 Tab 寬度相同數量的空格，直到下一個定位點，而不是插入 Tab 字元。 |

智慧型標點符號、醒目標示、下標與上標位於 **資料庫 ▸ CommonMark 選項**。

### 鍵入聲音

| 控制項 | 功能 |
| --- | --- |
| **輸入時播放聲音** | 每個按鍵都會發出聲音；Space、Return 與 Delete 的聲音不同。貼上與復原時不會發出聲音。在 iPad 上，靜音開關會使其靜音。 |
| **聲音** | 音效組合：**打字機**、**鴨子**或**小貓**。 |
| **音量**、**預覽** | 設定音量並試聽音效組合。 |
| **自訂聲音** | 為任何一種按鍵選擇一段短音訊；其他按鍵維持上方所選的聲音。種類有**小寫字母**、**大寫字母**、**數字**、**符號和標點**、**間距**、**定位字元**、**換行**與**刪除**。每一種都有**選擇…**（或**更改…**）、**播放**與**移除**。音訊最長 2 秒、最大 3 MB（WAV、AIFF、MP3、M4A 或 CAF），並存放在記憶體中，因此播放時沒有延遲。 |

### 拼字與診斷

**輸入時檢查拼字**會在拼錯的字下方加底線。**顯示解析警告**會標記可能不是你本意的語法結構所在的行，例如未關閉的程式碼圍欄或數學區塊、沒有右括號的連結，或與標題列不相符的表格列。提示會顯示在該行的結尾。它只會改變顯示的內容，絕不會改變文件的解析或匯出方式。

## 圖片

這些設定決定你插入的圖片（**插入 ▸ 圖片…**，或拖放進來）會如何處理。

| 控制項 | 功能 |
| --- | --- |
| **動作** | **無特殊動作**、**將圖片拷貝到目前資料夾 (./)**、**將圖片拷貝到 ./assets**，或**將圖片拷貝到 ./\${filename}.assets**。**上傳圖片**顯示為無法使用：Pilcrow 沒有圖片主機，因此圖片會插入在它們原本所在的位置。 |
| **套用於本機圖片** | 此動作是否套用於已在你裝置上的圖片。 |
| **套用於線上圖片** | 是否套用於指向網頁位址的圖片。 |
| **從網際網路載入圖片** | 關閉時，預覽、PDF 或圖片匯出不會下載指向網頁位址的圖片，因此代管它們的網站不會得知任何資訊。開啟時，它們會像在網頁瀏覽器中一樣被擷取，而該網站可以看到這個請求。 |
| **可能時使用相對路徑** | 寫入相對於文件的路徑。 |
| **為相對路徑加上 ./** | 讓相對路徑以 `./` 開頭。 |
| **插入時自動跳脫圖片網址** | 跳脫位址中會破壞連結的字元。 |

# Chapter 69: 外觀

## 佈景主題與背景圖

| 控制項 | 功能 |
| --- | --- |
| **應用程式佈景主題** | App 與編輯器的外觀：**自動**、**淺色**、**深色**，或任何你加入的佈景主題。它會設定淺色或深色、強調色、側邊欄與列，以及編輯器。自動會跟隨系統。渲染模式與匯出使用渲染佈景主題，在「匯出」下選擇。 |
| **介面大小**（iPad） | 選單、列、側邊欄與對話框的大小：**系統大小**（跟隨 iPad 的文字大小）、**小一級**、**小兩級**、**小三級**。編輯器的文字有它自己的大小。 |
| **標頭中的選單**（iPad） | **自動**（連接鍵盤或滑鼠時會隱藏 Pilcrow 自己的選單）、**永遠**或**永不**。 |
| **縮放** | 編輯器與預覽的大小：50%、67%、80%、90%、100%、110%、125%、150%、175% 或 200%。與 **檢視 ▸ 放大**和**縮小**相同。 |
| **閱讀速度** | 每分鐘字數，從 60 到 2,000，用於估算閱讀時間。 |

## 編輯器背景（背景圖）

圖片或影片可以放在編輯器、側邊欄與狀態列後方。

| 控制項 | 功能 |
| --- | --- |
| **媒體** | **選擇…** HEIC、PNG、JPEG 或 SVG 圖片，或 MP4、MOV 或 M4V 影片。**移除**會清除它。 |
| **版面配置** | **填滿**、**符合**或**並排顯示**。 |
| **在文字區域後方**、**在側邊欄後方** | 各自有自己的**調暗**與**模糊**。**調暗**會以佈景主題的背景色覆蓋圖片，讓文字保持易讀；**模糊**會使其變柔和。狀態列會將其模糊。 |
| **使用電池時播放** | 允許影片在電池供電時播放。在低耗電模式下影片會暫停，開啟「減少動態效果」時則保持靜止。 |
| **聲音**、**音量** | 除非你開啟影片的聲音，否則影片會靜音播放。 |

背景圖絕不會出現在預覽或匯出中，而「降低透明度」會將其隱藏。

# Chapter 70: 目錄與匯出預設值

## 目錄與標籤

這些設定適用於每種匯出格式：PDF、Word、HTML 等等。

| 控制項 | 功能 |
| --- | --- |
| **為每次匯出加入目錄** | 在每次匯出的頂端放上目錄清單。 |
| **以清單取代 [TOC] 行** | 只有 `[TOC]` 的一行會在預覽與每種匯出中變成標題清單。 |
| **為標題編號（1.、1.1.）** | 在輸出中為標題編號。下方的標題標籤會取代單純的編號。 |
| **標題** | 清單的名稱，例如「內容」或「說明」。留空則使用「目錄」。 |
| **列出標題至層級** | 深度，1 到 6。層級 1 只列出最上層的標題；層級 6 則全部列出。 |
| **縮排** | 每個層級的縮排，單位為點。 |
| **讓每個標題連結回其目錄項目** | 加入從標題連回其項目的反向連結。 |
| **只列出 [TOC] 行下方的標題** | 略過 `[TOC]` 行上方的標題。 |

### 標題標籤

**為標題加上標籤**會為每個層級提供各自的標籤，例如「Part I -」或「Chapter 3:」。每個層級都有一個範本。在範本中，`#` 是下一個數字，`@` 是下一個大寫字母；一個標籤可以使用其中一種，但不能兩者並用。寫成 `\#` 或 `\@` 時，每當出現較淺層的標題就會重新開始計數；不加反斜線則會在整份文件中持續計數。**字母**與**數字 0 到 9**設定用於字母編號與數字編號的字元。字母用完最後一個之後會加倍：Y、Z、AA、AB。

| **渲染佈景主題** | 預覽與匯出的預設佈景主題。 |

| **頁面** | 列印以及每次 PDF、PDF 封存與 Word 匯出所用的紙張大小、方向與邊界（第 64 章）。 |
| **頁首範本**、**頁尾範本** | 每頁頂端與底端的文字。變數：`${title}`、`${author}`、`${pageNo}`、`${pageCount}` 與 `${today}`。例如頁尾 `Page ${pageNo}`。 |
| **作者** | `${author}` 以及文件中繼資料所使用的作者名稱。 |
| **在頂層標題之間分頁** | 讓每個頂層標題從新的一頁開始。 |

| 控制項 | 功能 |
| --- | --- |
| **匯入…** | 加入別人分享的設定檔 `.json` 檔案。 |
| **新增** | 從頭開始建立設定檔。 |
| **編輯**、**複製**、刪除 | 針對每個設定檔。內建設定檔可以複製，但不能編輯或刪除。 |
| **未載入** | 無法載入的設定檔會與原因一起列在此處：它使用了其他設定檔已有的副檔名、它不是此版本能讀取的設定檔，或它含有可能讓編輯器停止回應的模式。它仍在你的設定檔資料夾中。 |

| 區段 | 控制項 |

## 位置

你的資料庫位於你所選資料夾內名為「Pilcrow Library」的資料夾中。iCloud Drive 中的資料夾可讓它在你的裝置之間保持同步。偏好設定、API 金鑰與當機復原副本一律留在此裝置上。

| 控制項 | 功能 |
| --- | --- |
| **已保留** | 資料庫目前所在的位置：「在此裝置上」或「在資料夾 *名稱* 中」。 |
| **選擇資料夾…** | 將資料庫移到某個資料夾。如果該資料夾已有 Pilcrow 資料庫，Pilcrow 不會合併兩者：你可以**使用現有的**。否則可選**將我的資料庫移到此處**（檢查每個檔案，然後移除舊的副本）或**將我的資料庫拷貝到此處**（保留舊的）。 |
| **使用此裝置** | 將資料庫帶回此裝置。 |

如果無法連到所選的資料夾，Pilcrow 會暫時使用此裝置上的資料庫，不變更也不刪除任何內容，並在該資料夾可用時再次使用它。
