# Part XVI — 視窗與選單參考

# Chapter 52: 視窗一覽

本章由左至右列出 Pilcrow 視窗中的每個控制項，涵蓋 Mac 與 iPad。本部分後續各章說明每個選單項目，第 XVII 部分則說明各個面板與對話框。

## 標頭列

標頭橫跨視窗頂端。其控制項依序如下：

| 控制項 | 位置 | 功能 |
| --- | --- | --- |
| **導覽器**（側邊欄圖示） | Mac 與 iPad | 顯示或隱藏側邊欄。其工具提示為「顯示或隱藏導覽器」。與 **檢視 ▸ 切換側邊欄** 相同。 |
| **文件標題** | Mac 與 iPad | 顯示使用中文件的名稱，並以一個圓點告知是否已儲存。點按即可開啟文件切換器與文件動作（第 59 章）。 |
| **選單按鈕**或選單列 | 僅限 iPad | 將 Mac 的選單放進標頭內，供沒有鍵盤或滑鼠的 iPad 使用（第 58 章）。 |
| **文件模式**（編輯、預覽、分割） | Mac 與 iPad | 在原始碼、渲染頁面，以及兩者並排之間切換。「分割」即 **並排**。 |
| **尋找**（放大鏡） | Mac 與 iPad | 開啟尋找列（第 62 章）。 |
| **匯出**（分享圖示） | Mac 與 iPad | 開啟匯出面板（第 64 章）。 |
| **設定**（齒輪） | 僅限 iPad | 在面板中開啟設定。在 Mac 上，設定位於 **Pilcrow** 選單（**⌘,**）。 |
| **更多**（三個點） | Mac 與 iPad | 收納列上放不下的動作。見下文。 |

尋找、匯出與模式控制項僅在開啟文件時出現。

### 標頭如何隨寬度調整

標頭的設計讓它在窄視窗中仍然好用，例如與另一個 App 並排的 Mac 視窗，或分割檢視中的 iPad。視窗愈窄，控制項就依下列順序移入 **更多** 選單：

| 視窗寬度 | 你會看到 |
| --- | --- |
| 720 點或更寬 | 編輯／預覽／分割控制項、**尋找**、**匯出**與 **更多**。 |
| 600 至 719 | **尋找** 移入 **更多**。 |
| 500 至 599 | **匯出** 也移入 **更多**。 |
| 小於 500 | 模式控制項變成單一按鈕，其圖示顯示目前的模式（鉛筆、眼睛或兩個窗格）。點按即可選擇。 |

在 iPad 上，寬度小於 580 點時，模式控制項會變成精簡按鈕。標題一律最先縮小，寬度介於 140 至 520 點之間，因此按鈕會維持原位。使用較大的輔助使用文字大小時，上述視窗寬度會先除以 1.3，因此視窗仍然較寬時，控制項就會移入 **更多**。

### 「更多」選單

**更多** 提供的內容取決於模式與平台。僅在原始碼可見時（編輯或並排）才顯示的項目，會在下方標明。

| 項目 | 出現時機 | 功能 |
| --- | --- | --- |
| **尋找…** | 僅在列上沒有「尋找」按鈕時 | 開啟尋找列。 |
| **取代…** | 原始碼可見 | 開啟附有取代欄位的尋找。 |
| **前往行…** | 原始碼可見 | 跳到某一行，或某行某欄。 |
| **單欄多插入點…** | iPad，原始碼可見 | 依數字在一欄中放置多個插入點（第 63 章）。 |
| **欄選取** | iPad，原始碼可見 | 一個開關。開啟時，單指拖移會選取一個矩形範圍的文字。 |
| **分享…** | 已開啟文件 | 透過系統分享面板分享文件的檔案。 |
| **匯出…** | 僅在列上沒有「匯出」按鈕時 | 開啟匯出面板。 |
| **專注** | 一律 | 專注模式的開關（見下文）。 |
| **標題摺疊**、**渲染區塊**、**自動展開段落**、**隱藏標記**、**套用樣式的原始碼**、**格式工具列** | 原始碼可見 | 與「檢視」選單中相同的顯示開關（第 55 章）。除非 **套用樣式的原始碼** 已開啟，否則 **隱藏標記** 會呈灰色。 |
| **開啟檔案…**、**開啟資料夾…** | iPad | 側邊欄關閉時開啟檔案或資料夾。 |
| **列印…** | iPad | 列印渲染後的文件。 |
| **設定…**、**說明** | iPad | 開啟設定或 App 內的說明。 |

## 工作區

標頭下方是編輯器、預覽，或兩者並列。編輯器下方在開啟時會出現 **格式工具列** 與 **狀態列**（第 61 章）。編輯器與側邊欄後方可放置 **背景** 圖片或影片（第 69 章）。

在 **並排** 中，原始碼位於預覽旁邊，並隨預覽一起捲動。窗格分隔線可以拖移，位置會被記住。視窗窄於 520 點時，兩個窗格會改為上下堆疊。若開啟側邊欄會讓文件的空間少於 640 點，側邊欄就會覆蓋在文件上，而不是擠壓文件。

## 側邊欄（導覽器）

側邊欄可顯示 **檔案**、**大綱**、**搜尋**、**專案**與**助理**（第 60 章）。拖移其邊緣即可調整大小，寬度介於 180 至 420 點之間。在窄於 500 點的視窗中，它會填滿整個寬度，並由 **完成** 按鈕將它關閉。

## 專注模式

**專注模式** 會隱藏文字以外的一切。可從 **檢視 ▸ 專注模式**、**更多 ▸ 專注**或指令面板開啟。開啟期間會出現 **結束專注** 按鈕，讓你不用鍵盤也能離開。專注模式一律會換行顯示長行，並且有自己的文字欄，與設定中的文字欄各自獨立。它沒有預設快速鍵，請在 **設定 ▸ 鍵盤** 中指定。

## 沒有文件時

沒有開啟任何文件時，視窗會在「開始一份文件」標題下提供 **新增文件** 與 **開啟檔案…**。在 iPad 上，**開啟資料夾…** 位於 **更多** 中。

Pilcrow 啟動時若發現先前工作階段留下未儲存的內容，會改為顯示 **復原文件** 清單。復原的運作方式請見第 17 章。清單為每個項目提供 **復原** 與 **刪除**，並為整份清單提供 **全部復原** 與 **全部刪除**。從未儲存過的文件一經刪除就無法找回，因此 **全部刪除** 會先詢問。單一文件橫幅上的 **忽略** 按鈕，表示不復原該項目。

開啟大型檔案時，視窗會顯示「正在開啟 *名稱*…」並附上進度指示。

# Chapter 53: 檔案選單

在 Mac 上，這些項目位於 **檔案** 選單。在 iPad 上，它們位於標頭中的 **選單 ▸ 檔案**，或按住 **⌘**、或將指標移到螢幕頂端時出現的選單列。標示「僅限 Mac」的項目在 iPad 上不存在。

| 項目 | 快速鍵 | 功能 |
| --- | --- | --- |
| **新增**（iPad：**新增文件**） | `⌘N` | 建立一份未命名的文件，並加入開啟的文件。 |
| **開啟…**（iPad：**開啟檔案…**） | `⌘O` | 從磁碟開啟文字或標記檔案。 |
| **開啟最近項目**（僅限 Mac） | | 列出最近開啟的檔案。**清除選單** 會清空清單。清單為空時顯示「沒有最近的文件」。 |
| **快速開啟…**（僅限 Mac） | `⇧⌘O` | 搜尋已開啟資料夾中的檔名。未開啟資料夾時呈灰色。 |
| **開啟資料夾…**（iPad 標頭選單與「更多」） | | 在側邊欄中開啟資料夾。在 Mac 上，請使用側邊欄本身的 **開啟資料夾** 按鈕。 |
| **瀏覽所在資料夾…** | | 請求權限以瀏覽包含已開啟檔案的資料夾。Pilcrow 的沙箱只會單獨開啟檔案，此項目會加入其資料夾。資料夾已開啟或文件沒有檔案時呈灰色。 |
| **新增書籍…** | | 建立書籍專案資料夾及其資訊清單（第 34 章）。 |
| **將資料夾設為書籍專案** | | 在已開啟的資料夾中寫入 `manifest.pilcrow`，並顯示「專案」面板（第 34 章）。未開啟資料夾或該資料夾已有資訊清單時呈灰色。 |
| **關閉文件**（iPad：**關閉**） | `⌘W` | 關閉使用中的文件，若有未儲存的變更會先詢問。設定位於最前方時，`⌘W` 會改為關閉設定。 |
| **全部關閉**（iPad） | `⇧⌘W` | 關閉所有文件，並逐一詢問每份未儲存的文件。在 Mac 上，標題選單中有 **關閉所有文件**。 |
| **儲存** | `⌘S` | 儲存文件。新文件會詢問儲存位置。 |
| **全部儲存**（僅限 Mac） | `⌥⌘S` | 儲存所有有未儲存變更的文件。沒有任何此類文件時呈灰色。 |
| **複製**（僅限 Mac） | `⇧⌘S` | 製作副本並在原文件旁開啟，原文件維持不變。 |
| **另存新檔…** | `⌥⇧⌘S` | 以新名稱或在新位置儲存，或使用其他編碼。之後該文件就是這個新檔案。 |
| **移到…**（僅限 Mac） | | 透過儲存面板移動磁碟上的檔案或重新命名（按鈕顯示為 **移動**），並保持文件開啟。 |
| **版本記錄…** | | 開啟文件已儲存的各個版本（第 17 章與第 63 章）。 |
| **與檔案比較…** | | 將文件與另一個檔案比較，並讓你接受或拒絕每一項變更（第 18 章）。 |
| **從磁碟重新載入**（僅限 Mac） | | 從磁碟重新讀取檔案，適用於其他 App 變更了檔案的情況。若你有未儲存的變更，會先詢問：**儲存後重新載入**、**不儲存直接重新載入**或**取消**。對沒有檔案的文件呈灰色。 |
| **在 Finder 中顯示**（僅限 Mac） | | 在 Finder 中顯示該檔案。 |
| **匯入**（僅限 Mac） | | 子選單：**佈景主題…**、**語法設定檔…**、**巨集集合…**、**風格指南…**。每一項都會將一個檔案加入你的資料庫（第 43 章）。在 iPad 上，匯入位於 **設定 ▸ 資料庫 ▸ 匯入**。 |
| **匯出…** | `⇧⌘E` | 開啟匯出面板（第 64 章）。 |
| **分享…** | | 分享文件的檔案。 |
| **編譯書稿…** | | 編譯書籍專案（第 36 章）。載入書籍專案之前呈灰色。 |
| **頁面設定…**（僅限 Mac） | | 設定紙張、方向與邊界，與 PDF 匯出使用的設定相同。 |
| **列印…** | `⌘P` | 列印渲染後的文件。若文件含有尚未填寫的填空欄位，Pilcrow 會先提醒你。 |

# Chapter 54: 編輯選單

「編輯」選單包含系統的標準指令與許多 Pilcrow 自己的指令。選取、行與插入點相關的選單項目作用於原始碼，因此在預覽中呈灰色。

## 復原、剪貼簿與貼上

| 項目 | 快速鍵 | 功能 |
| --- | --- | --- |
| **復原**、**重做** | `⌘Z`、`⇧⌘Z` | 在你的編輯記錄中向後與向前步進。 |
| **剪下**、**拷貝**、**貼上**、**刪除**、**全選** | | 系統的指令。 |
| **拷貝為 Markdown** | `⇧⌘C` | 將所選內容以 Markdown 原始碼拷貝。 |
| **拷貝為純文字** | | 拷貝所選內容，並盡可能移除結構性標記。 |
| **拷貝為 HTML 程式碼** | | 將所選內容渲染後的 HTML 以文字形式拷貝。 |
| **以純文字貼上** | `⇧⌘V` | 貼上時不帶剪貼簿中的任何格式。 |

## 尋找

**尋找** 是一個子選單。

| 項目 | 快速鍵 |
| --- | --- |
| **尋找…** | `⌘F` |
| **取代…** | `⌘R` |
| **尋找下一個** | `⌘G` |
| **尋找上一個** | `⇧⌘G` |

## 拼字與文法

在 iPad 上，此子選單只有 **輸入時檢查拼字**，與設定中的開關相同。另外兩個項目僅限 Mac，因為 iPad 的文字檢視沒有拼字面板。

| 項目 | 快速鍵 | 功能 |
| --- | --- | --- |
| **顯示拼字與文法** | `⌘:` | 開啟系統的拼字面板。 |
| **立即檢查文件** | `⌘;` | 檢查整份文件。 |
| **輸入時檢查拼字** | | 在你輸入時為拼錯的字加上底線。設定中有相同的開關。 |

## 轉換與語音

| 項目 | 功能 |
| --- | --- |
| **轉為大寫**、**轉為小寫**、**首字母大寫** | 變更所選內容或插入點所在字詞的大小寫。 |
| **開始朗讀**、**停止朗讀** | 朗讀所選內容；未選取任何內容時朗讀整份文件。 |

## 選取範圍

這是一個選取與移動方式的子選單。

| 項目 | 快速鍵 | 功能 |
| --- | --- | --- |
| **選取字詞** | `⌘D` | 選取插入點所在的字詞。 |
| **選取行** | `⌘L` | 選取整個檔案行，而不是自動換行後的螢幕行。 |
| **選取段落** | `⌥⌘P` | 選取該段落。 |
| **跳到頂端**、**跳到底部** | `⌘↑`、`⌘↓` | 將插入點移到文件的開頭或結尾。 |
| **跳到行首**、**跳到行尾** | `⌃A`、`⌃E` | 移到該行的任一端。 |
| **在上方加入插入點**、**在下方加入插入點** | `⌃⇧↑`、`⌃⇧↓` | 在上一行或下一行加入另一個插入點（第 7 章）。 |
| **選取下一個出現處** | `⌃⌥D` | 加入所選文字的下一個相符項目。 |
| **選取所有出現處** | `⌃⌥⇧D` | 一次選取所有相符項目。 |
| **下一個欄位**、**上一個欄位** | `⌥Tab`、`⌥⇧Tab` | 在巨集留下的填空欄位之間跳轉（第 24 章）。設定中可為此選擇不同的按鍵組合，稱為 Super Tab 按鍵。 |
| **單欄多插入點…** | `⌃⇧G` | 開啟面板，依數字在一欄中放置多個插入點。 |

插入點、出現處、欄位與指令面板的快速鍵，可以在 **設定 ▸ 鍵盤** 中變更。

## 行

| 項目 | 功能 |
| --- | --- |
| **行遞增排序**、**行遞減排序** | 為所選的行排序。 |
| **反轉行順序** | 反轉它們的順序。 |
| **移除重複行** | 每組重複的行只保留第一行。 |
| **移除空白行** | 刪除所選範圍中的空行。 |
| **修剪行尾空白** | 移除行尾的空格與定位字元。 |
| **合併行** | 將所選的行合併為一行。 |

## 刪除範圍

| 項目 | 快速鍵 |
| --- | --- |
| **刪除字詞** | `⇧⌘D` |
| **刪除行** | `⌥⇧⌘L` |
| **刪除段落** | `⌥⇧⌘P` |

## 移動、翻譯、導覽

| 項目 | 快速鍵 | 功能 |
| --- | --- | --- |
| **上移列**、**下移列** | `⌥⌘↑`、`⌥⌘↓` | 將目前的行或所選的行向上或向下移動。 |
| **翻譯 ▸ 文件**、**翻譯 ▸ 選取範圍** | | 開啟翻譯面板（第 63 章）。 |
| **前往行…** | `⌃G` | 跳到某個行號，或某行某欄。 |
| **檢查連結…** | | 檢查文件中的連結與圖片（第 19 章）。 |
| **指令面板…** | `⌃⇧P` | 開啟指令面板（第 62 章）。 |
| **返回**、**前進** | `⌃⌘←`、`⌃⌘→` | 沿著你跳轉過的位置往回或往前走。 |
