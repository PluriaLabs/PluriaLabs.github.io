# Part XVII — 面板、列與對話框

# Chapter 59: 文件標題與文件切換器

文件的名稱位於標頭中，旁邊有一個小小的彩色圓點與一個向下箭頭。點按它，或選擇 **檢視 ▸ 開啟的文件**（`⌃⌘2`），即可開啟 **開啟的文件** 清單。在小螢幕上，它會以附有 **完成** 按鈕的面板開啟。

## 儲存圓點

名稱旁的圓點讓你一眼看出文件的狀態。VoiceOver 也會朗讀此狀態。

| 圓點 | 意義 |
| --- | --- |
| 綠色 | **已儲存。** 磁碟上的檔案與你所見相符。 |
| 琥珀色 | **已編輯。** 你有尚未儲存的變更。 |
| 紅色 | **儲存失敗。** Pilcrow 嘗試儲存但無法完成。編輯器上方會出現附有 **重試** 按鈕的「無法儲存」橫幅。 |
| 藍色 | **已被其他 App 變更。** 磁碟上的檔案在 Pilcrow 之外被變更。 |

從未儲存過的文件會在清單中顯示「尚未儲存」與一個數字，因為它沒有資料夾可顯示。有未儲存變更的文件，其列尾也會註明 **已編輯**。

## 「開啟的文件」清單

| 部分 | 功能 |
| --- | --- |
| **搜尋開啟的文件** | 開啟七份或更多文件時出現。輸入名稱或資料夾的一部分；每個字詞都必須在名稱或資料夾中的某處相符，且不分大小寫與重音符號。按下換行鍵會開啟第一個相符項目。沒有相符項目時會顯示「沒有相符的開啟文件。」 |
| 每份文件一列 | 顯示名稱、其儲存圓點，以及它所在的資料夾。勾號標示使用中的文件。點按某一列即可切換到該文件。 |
| **關閉**（列尾的 **x**） | 關閉該文件，若有未儲存的變更會先詢問。 |
| **新增文件** | 建立一份未命名的文件。 |
| **儲存** | 儲存使用中的文件。 |
| **另存新檔…** | 以新名稱或在新位置儲存。 |
| **重新命名…** | 開啟重新命名表單（見下文）。 |
| **關閉所有文件** | 關閉所有文件，並逐一詢問每份未儲存的文件。 |

使用 `⌃Tab` 與 `⌃⇧Tab` 即可移到下一份或上一份文件，不必開啟清單。

## 重新命名

**重新命名…** 會顯示目前的 **名稱** 與檔案所在的 **位置**，並附有 **取消** 與 **重新命名** 按鈕。重新命名會變更磁碟上的檔案，並保持文件開啟。如果新名稱無法使用，會有 **無法重新命名文件** 的訊息說明原因。
