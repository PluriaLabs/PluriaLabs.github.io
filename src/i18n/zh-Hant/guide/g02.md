# Chapter 11: 插入表格、圖片、欄位與特殊區塊

**插入** 選單結合了共用工具與由作用中設定檔提供的結構。

## 插入表格

1. 選擇 **插入 ▸ 表格…** 或 **格式 ▸ 段落 ▸ 表格 ▸ 插入表格…**（`⌥⌘T`）。
2. 視提供的選項，選擇列數、欄數、對齊方式與標題列行為。
3. 確認後，替換預留位置的儲存格。

原始碼表格最適合用於真正的表格關係。不要只為了對齊不相關的文字而使用它，那會產生不佳的無障礙輸出。

當插入點位於表格中時，使用 **格式 ▸ 段落 ▸ 表格** 可在上方或下方加入一列、刪除目前的列、在前方或後方加入一欄，或刪除目前的欄。Pilcrow 會以單一可復原的編輯重寫原始碼表格。若設定檔使用對齊標記，請在結構變更後檢查這些標記。

## 插入圖片

選擇 **插入 ▸ 圖片…** 或按 `⇧⌘I`，選取檔案，並提供有用的替代文字。Pilcrow 會遵循第 26 章所述的圖片偏好設定：它可能拷貝或移動檔案，或將檔案留在原處，並寫入相對或絕對的參照。

## 插入現成區塊

使用 **圖解**、**圖表** 或 **方程式** 取得可編輯的範本。在支援時，使用 **程式碼圍欄**、**提醒**、**水平線**、**連結參照**、**註腳**、**目錄** 或 **YAML 前置資料**。範本只是起始的原始碼，而不是鎖定的元件；你可以直接編輯。

## 插入欄位

選擇 **插入 ▸ 欄位**，放置一個供 Super Tab 使用的具名填空欄位。欄位使用作用中設定檔的標記。選取它時輸入其名稱，然後在可重複使用的巨集或文件範本中使用。

# Chapter 12: 使用編輯、預覽與並排

## 編輯

編輯模式顯示原始碼並接受變更。請用它來寫作、字面搜尋、取代，以及檢查原始碼。

## 預覽

選擇 **檢視 ▸ 預覽**（`⇧⌘P`）或使用模式控制項。預覽會以所選的渲染佈景主題編譯作用中設定檔的結構。它刻意設計為唯讀。請用它來評估階層、間距、連結、方程式、圖解、圖表與匯出後的外觀。

## 並排

選擇 **檢視 ▸ 並排**（`⌃⌘P`）。原始碼會顯示在預覽旁邊，並隨著你輸入而更新。捲動會盡可能依標題同步，必要時改以比例同步。在原始碼中尋找會醒目標示相關的預覽文字。前往行會移動編輯器，預覽也會跟著移動。

當兩個窗格都顯得太窄時，請隱藏側邊欄。視窗很窄時，在編輯與預覽之間切換可能更合適。

## 診斷非預期的預覽

請依序檢查下列各項：

1. 預期的語法設定檔是否已啟用？
2. 原始碼對該設定檔而言結構是否有效？
3. 是否已選取預期的渲染佈景主題？
4. 是否已啟用選用的 CommonMark 功能？
5. 補充區塊是否標示了支援的語言？

這個順序能把意義上的問題與樣式上的問題區分開來。

# Chapter 13: 控制閱讀與編輯檢視

使用檢視選單以及編輯或外觀設定來控制：

- **格式工具列**：顯示或隱藏快速格式列。
- **專注模式**：移除文件周圍的干擾。
- **實際大小、放大、縮小**：改變檢視比例，但不改變匯出的字體排印。
- **行號**：在邊欄中顯示檔案的行號。
- **目前行標線**：強調作用中的行。
- **換行**：讓長行依檢視寬度換行。關閉後即可橫向閱讀很長的記錄。
- **套用樣式的原始碼**：為已辨識的原始碼角色上色並套用樣式。
- **隱藏標記**：在「套用樣式的原始碼」啟用時減少可見的標記。
- **渲染區塊**：在編輯體驗中渲染符合條件的區塊。
- **標題摺疊**：收合標題下方的段落。
- **全部摺疊 / 全部展開**：變更所有標題的摺疊狀態。
- **自動展開段落**：當你導覽到已摺疊的段落時將其顯示出來。

「套用樣式的原始碼」不會改變檔案。「隱藏標記」可以讓標記更容易閱讀，但也可能遮蔽你正在編輯的字面字元；診斷語法時請將它關閉。摺疊是隱藏文字而非刪除文字。在整份文件進行視覺審閱之前，請先使用「全部展開」。

當渲染區塊提供編輯功能時，啟用它即可開啟 **編輯區塊**。修改等寬字型的原始碼，然後選擇 **套用** 以取代該區塊，或選擇 **取消** 以保持不變。此面板會拒絕空白區塊。這樣既保有方便的渲染檢視，又不會隱藏將被儲存的原始碼。

# Part IV — 檔案、資料夾與大型文件

# Chapter 14: 瀏覽工作資料夾

開啟資料夾，或對作用中的文件選擇 **瀏覽所在資料夾…**。檔案側邊欄會顯示樹狀結構，而不會匯入或移動檔案。選取文字檔即可開啟。請將該資料夾當作搜尋、書籍專案與相對連結共用的範圍。

若要以鍵盤優先的方式開啟檔案，請在開啟資料夾之後選擇 **檔案 ▸ 快速開啟…**（`⇧⌘O`）。輸入檔名中任何依序出現的部分，使用上下方向鍵選擇結果，然後按換行鍵。Pilcrow 會顯示縮短的資料夾相對路徑，以便區分同名的檔案。若沒有工作區資料夾，「快速開啟」將不會出現或無法使用。

側邊欄代表真實的檔案。重新命名、移動或刪除檔案可能會破壞其他文件中的連結，因此在結構變更之後請執行「檢查連結」。雲端資料夾可能以非同步方式回報變更；在認定衝突是 Pilcrow 的錯誤之前，請等待同步完成。

使用啟動設定來選擇 Pilcrow 要還原上次的工作階段、開啟特定資料夾，還是從其他地方開始。使用檔案樹狀圖偏好設定來調整資料庫顯示的內容，以及如何處理拖放進來的項目。

# Chapter 15: 在整個資料夾中搜尋與取代

## 搜尋

1. 開啟資料夾。
2. 選擇搜尋側邊欄（預設為 `⇧⌘F`）。
3. 選擇 **資料夾** 範圍。
4. 輸入搜尋字詞，以及選用的「區分大小寫」、「全字拼寫」或「正規表示式」控制項。
5. 開啟結果，在上下文中檢視。

## 以交易方式取代

1. 選擇結果數量旁的 **取代…**。
2. 輸入取代內容。
3. 檢視每個受影響的檔案、符合數量，以及取代前後的範例。
4. 取消勾選應維持不變的檔案。
5. 確認最終的符合數量與檔案數量。

Pilcrow 會略過已開啟的檔案、非 UTF-8 文字，以及在預覽之後被更動過的檔案。這能避免資料夾操作在無聲無息中覆寫較新的工作成果。一次取代最多影響 2,000 個檔案。

事後可使用取代視窗中的 **復原** 橫幅來還原最近一批變更。取代之後又被編輯過的檔案不會被更動。只有最近一次的資料夾取代有這種特殊備份，因此在開始下一次之前請先驗證。

# Chapter 16: 安全地處理超大型檔案

Pilcrow 不會把巨大的文件載入成單一的巨型字串。它讓原始檔案由儲存空間支援，只具體化你所見範圍周圍的一個視窗。這就是數 GB 的檔案也能快速開啟的原因。

為了獲得最佳效果：

- 在依賴遠處的行導覽之前，先等待行數統計完成。
- 從目前的可視範圍跳到很遠的位置時，預期會有短暫的重新整理。
- 在轉換整個檔案之前先儲存。
- 優先使用資料夾搜尋或有針對性的「尋找」，而不是選取整個超大檔案。
- 請記住，建立 PDF 會使用整個渲染頁面模型，所需記憶體可能遠多於編輯或串流式的 HTML/Word 匯出。
- 檔案開啟期間，請保持來源檔案可用。外部截斷或取代可能使映射的原始檔案失效。

狀態列可能會顯示背景語彙分析或解析。你通常可以繼續輸入。如果某個功能要求你在超過所述的分享或審閱限制時儲存文件，請直接儲存，不要強行建立暫時的記憶體內副本。

# Chapter 17: 使用編碼、自動儲存、復原與版本

## 轉換編碼

Pilcrow 會偵測並保留檔案的編碼。按一下狀態列中的編碼並選擇另一種編碼；下次儲存時就會執行轉換。如果文字看起來是亂碼，請不要大量編輯，先嘗試正確的編碼。

## 設定自動儲存與復原

在 **設定 ▸ 一般 ▸ 檔案** 中，選擇變更是否自動儲存，並設定復原行為。自動儲存可降低風險，但不能取代在大量編輯之前刻意建立的檢查點。

意外結束之後，Pilcrow 會提供未儲存工作的復原副本。請查看文件名稱，並審慎地選擇復原或捨棄。當原始檔案的身分仍然相符時，復原可以重播未儲存的編輯；若原始檔案已過時或被取代，則可能退回到磁碟上可用的安全版本。

## 使用版本記錄

1. 儲存文件。
2. 做一次有意義的修改並再次儲存。
3. 選擇 **檔案 ▸ 版本記錄…**。
4. 選取一個版本。
5. 使用 **開啟副本** 來檢視它，使用 **比較…** 查看行的變更，或使用 **還原…** 回到該版本。

還原要求目前沒有未儲存的變更，並會先保存目前的狀態，因此還原本身也可以透過記錄再被撤銷。沒有變更的儲存不會建立重複的版本。超過 256 MB 的檔案不會被拷貝到記錄中。可在檔案設定中設定保留的數量，範圍從無到 500。

# Chapter 18: 比較文件並接受選定的變更

## 取回一項歷史變更

開啟版本記錄，選擇較早的版本，並與目前的文件比較。當較早的版本位於舊的一側時，每項變更都會提供 **取回**。使用它即可只還原該行群組。復原可以撤銷該動作。

## 審閱同事的檔案

1. 開啟你的工作文件。
2. 選擇 **檔案 ▸ 與檔案比較…**。
3. 選取同事的副本。
4. 檢視新增與移除的行。
5. 對想要的變更選擇 **接受**，對不想要的選擇 **拒絕**。
6. 使用 **重新考慮** 來還原被拒絕的選項，或在審閱後使用 **接受其餘全部**。

只有在目標文字仍與比較基準相符時，Pilcrow 才會套用變更。如果你在這段期間編輯過該區域，該變更就會被略過。變更是以行群組為單位；若只想要一行中的一部分，請先接受再編輯。非常大的單一變更需要手動拷貝。

# Part V — 品質與語言

# Chapter 19: 發布前檢查連結

選擇 **編輯 ▸ 檢查連結…**。Pilcrow 會檢查相對檔案、圖片、標題片段、跨檔案片段與參照定義。它會略過程式碼，也不會造訪網頁 URL。

按一下問題即可跳到其原始碼行。修正目的地，若文件需要資料夾環境則先儲存，然後選擇 **再次檢查**。

在重新命名專案檔案之後，請依下列教學操作：

1. 重新命名一個被連結的檔案。
2. 在參照它的文件中檢查連結。
3. 開啟遺失檔案的結果。
4. 更新路徑。
5. 重複檢查，直到沒有本機問題為止。

本機檢查通過並不能證明外部網站可以連線；Pilcrow 刻意避免主動發出網路請求。

# Chapter 20: 翻譯文件或選取範圍

翻譯使用 Apple 的裝置端語言模型，需要 macOS 15 或 iOS 18 以上版本。

1. 選擇 **編輯 ▸ 翻譯 ▸ 文件** 或 **選取範圍**。
2. 確認偵測到的來源語言。
3. 選擇目標語言。
4. 選擇結果要在新分頁中開啟、儲存在原始檔案旁，或（在有此選項時）取代原始碼。
5. 開始翻譯，並在狀態列中查看進度。

Pilcrow 會保留結構標記、程式碼、連結與前置資料。在支援的情況下，它會翻譯數學、圖解與圖表區塊中被選取的人類語言部分。取代選取範圍是單一的復原步驟；整份文件的翻譯通常會透過所設定的輸出選項來保護原始檔案。

在 **設定 ▸ 一般 ▸ 翻譯** 中，設定預設語言，選擇是否提示或自動翻譯外語檔案，並選擇之後要執行的動作。在提示列上使用 **此檔案永不**，即可對該文件停止提示，而不必全域停用翻譯。

# Chapter 21: 以風格指南審閱文稿

## 安裝或選擇指南

開啟 **設定 ▸ 資料庫 ▸ 風格指南**。匯入指南，或使用範例機構風格。一份指南可以包含變體，以及術語、格式規範、語氣或無障礙等審閱領域。

## 執行審閱

1. 開啟助理側邊欄並選擇 **風格審閱**。
2. 選擇風格指南與變體。
3. 選擇審閱領域。
4. 選擇選取範圍或文件範圍。
5. 查看將傳送什麼內容以及傳送到哪裡的揭露說明。
6. 開始審閱。
7. 檢視每項發現、其證據、說明與建議的修正。
8. 只套用你同意的發現。

本機的確定性檢查可以在不傳送文字的情況下找出精確的規則。由模型輔助的檢查需要使用中的供應商，並且可能把長文件分成數個請求。在整份文件審閱之前，Pilcrow 會告訴你請求數量與大約的共用大小。

請將發現視為可供審閱的證據，而不是命令。風格規則在對話、引文、程式碼或刻意不尋常的文章中可能並不適用。當語意很重要時，請逐項套用修正；若某項修正改變了原意，請立刻復原。

## 撰寫風格指南

在風格指南設定中建立或複製一份指南。為每條規則提供清楚的名稱、理由、範例、範圍與嚴重程度。請偏好能自我說明的精確規則，而不是「寫得更好」這類含糊的指示。請以同時包含違規與合理例外的短文件進行測試。

# Chapter 22: 使用朗讀、拼字與寫作統計

使用 **編輯 ▸ 語音 ▸ 開始朗讀** 來聆聽所選文字或適當的文件文字，並使用 **停止朗讀** 結束播放。聆聽能發現重複的字詞與缺漏的標點，這些是視覺校對可能漏掉的。

在編輯設定中啟用 **輸入時檢查拼字**，即可使用平台的拼字服務。拼字是寫作輔助工具，不是語法驗證器；識別字與自創詞彙即使正確也可能被標記。

狀態列會顯示字數、字元數與行數。設定中也包含閱讀速度與編輯器字數統計的行為。Pilcrow 會在文件開啟並編輯期間記錄寫作時段，以供彙總統計。這些數字適合用來觀察趨勢，而不是作為合約上的出版字數：設定檔與匯出規則對字詞的詮釋可能不同。

# Part VI — 巨集與填空欄位

# Chapter 23: 使用與建立巨集

## 使用巨集

在 **設定 ▸ 資料庫 ▸ 巨集** 中啟用一個集合，回到編輯模式，然後輸入巨集的觸發字詞。依其符合類型，它會在觸發字詞之後、在前綴處、圍繞選取範圍，或在樣式符合時展開。

## 建立巨集

1. 開啟巨集設定。
2. 建立或選擇一個集合。
3. 選擇 **新增巨集**。
4. 為它設定名稱、觸發字詞、符合類型與展開內容。
5. 啟用它，並決定它是否必須避開程式碼。
6. 儲存，並在用完即棄的文件中測試。

展開內容可以包含日期、時間、UUID、剪貼簿、選取範圍、計數器、檔名、檔案路徑與自訂值的變數。當結構重複但數值會變動時，請使用變數。

集合可以被複製、重新命名、匯出、匯入、啟用、停用與刪除。內建項目可以升級為可編輯的使用者副本。如果巨集意外觸發，請停用其集合、縮小其觸發條件，或開啟 **不要在程式碼內展開**。
