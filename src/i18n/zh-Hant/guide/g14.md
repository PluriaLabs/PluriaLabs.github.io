# Part XXI — 檔案格式與限制

# Chapter 79: 應用程式佈景主題格式

**應用程式佈景主題**用來設定 Pilcrow 本身的樣式：淺色或深色外觀、強調色、側邊欄、狀態列與格式列，以及編輯器。它是一個 JSON 檔案。渲染後的文件（預覽、HTML、PDF、圖片、列印和 Word）則由**渲染佈景主題**另外設定樣式，它是 CSS（Chapter 80）。這兩種佈景主題分別安裝、選擇和刪除，彼此互不跟隨。

## 完整範例

```json
{
  "pilcrowAppTheme": 1,
  "name": "Nord",
  "appearance": "dark",
  "colors": {
    "accent": "#88C0D0",
    "sidebar": { "background": "#2E3440", "foreground": "#D8DEE9" },
    "bars": { "background": "#3B4252", "foreground": "#D8DEE9" },
    "editor": {
      "background": "#2E3440",
      "foreground": "#ECEFF4",
      "cursor": "#88C0D0",
      "selection": "#434C5E",
      "gutterBackground": "#2E3440",
      "gutterForeground": "#4C566A"
    },
    "syntax": {
      "heading": "#88C0D0",
      "marker": "#EBCB8B",
      "code": "#A3BE8C",
      "link": "#81A1C1",
      "muted": "#7B88A1",
      "tokens": { "strong": "#D08770" }
    }
  }
}
```

## 最上層

| 鍵 | 必填 | 值 |
| --- | --- | --- |
| `pilcrowAppTheme` | 是 | 格式版本，`1`。 |
| `name` | 是 | 1–200 個字元。顯示在設定與佈景主題選單中。 |
| `appearance` | 是 | `"light"`、`"dark"` 或 `"automatic"`。 |
| `colors` | `light` 和 `dark` 佈景主題 | 一組調色盤（見下文）。 |
| `light`、`dark` | `automatic` 佈景主題 | 兩組調色盤：一組用於系統的淺色外觀，一組用於深色。 |
| `id` | 否 | 由 Pilcrow 為自己的資料庫寫入。匯入時會被忽略，匯入一律會指派新的 id。 |

`appearance` 決定**每一個**視窗的外觀，包括選單、設定、面板和選擇器。`light` 或 `dark` 佈景主題會固定外觀；`automatic` 則跟隨系統。

自動佈景主題必須在 `light` 和 `dark` 中都設定每一種顏色，或兩者都不設定。只為其中一種外觀設定的顏色，否則會在另一種外觀中被繪製出來。

## 調色盤

每個鍵都是選填的。省略的顏色會維持 Pilcrow 的內建外觀，所以佈景主題可以小到只有一個強調色。

| 鍵 | 設定的樣式 |
| --- | --- |
| `accent` | 整個 App 的色調：按鈕、選取的區段、切換開關、連結、焦點環，以及側邊欄中被選取的列。未設定則沿用系統強調色。 |
| `sidebar.background`、`sidebar.foreground` | 檔案、大綱與尋找側邊欄。次要標籤由前景色衍生。 |
| `bars.background`、`bars.foreground` | 狀態列、固定的格式工具列和匯入通知。次要標籤由前景色衍生。 |
| `editor.background`、`editor.foreground` | 編輯器畫布與內文文字。 |
| `editor.cursor`、`editor.selection` | 插入點與選取範圍的醒目標示。 |
| `editor.gutterBackground`、`editor.gutterForeground` | 行號區。背景預設為編輯器背景。 |
| `editor.currentLineRule` | 開啟 **檢視 ▸ 目前行標線** 時，插入點所在行下方的細標線。預設為低強度的編輯器文字顏色。 |
| `syntax.<group>` | 依群組設定的即時語法顏色（見下文）。 |
| `syntax.tokens.<raw>` | 依原始值指定的單一標記，會覆寫其所屬群組。 |

### 語法群組

| 群組 | 上色對象 |
| --- | --- |
| `heading` | 標題（標記與文字）、提醒標記、定義詞彙 |
| `marker` | 強調、粗體、刪除線與其他行內分隔符號；清單與待辦事項標記 |
| `code` | 行內程式碼、圍欄與縮排的程式碼區塊、數學式、HTML 區塊 |
| `link` | 連結與圖片的標籤和目的地、自動連結 |
| `muted` | 引用區塊標記、分隔線、表格列、註解、區塊屬性 |
| `codeKeyword`、`codeString`、`codeNumber`、`codeComment` | 圍欄內經過醒目標示的程式碼 |

未設定的群組會採用依編輯器背景挑選的內建顏色：淺色畫布上用較深的色調，深色畫布上用較淺的色調。`syntax.tokens` 中的標記名稱使用字母、數字、`_` 和 `-`，且不能與群組名稱重複（`syntax.heading` 已涵蓋 `heading`）。

## 顏色

每個顏色都是十六進位字串：`#RGB`、`#RGBA`、`#RRGGBB` 或 `#RRGGBBAA`，採用 sRGB。Pilcrow 以大寫儲存。

## 驗證

Pilcrow 會拒絕整個檔案，而不是忽略其中一部分，並指出有問題的鍵，例如 `colors.editor.cursor: must be a hex colour`。它會拒絕：

- 缺少或不同的 `pilcrowAppTheme` 版本；
- 任何層級中的未知鍵（通常是打錯字）；
- 與外觀不符的調色盤鍵（自動佈景主題中出現 `colors`，或淺色或深色佈景主題中出現 `light` 和 `dark`）；
- 不是十六進位的顏色；
- `light` 和 `dark` 調色盤設定了不同顏色的自動佈景主題。

## 應用程式佈景主題不會改變的部分

視窗標題列與工具列（系統的玻璃效果，只採用強調色）、選單、設定、面板和選擇器，除了外觀與強調色之外，都維持原生樣式。字體不屬於佈景主題：編輯器的字體與大小在 **設定 ▸ 外觀 ▸ 文字大小與字體** 中設定。

## 安裝與分享

- 從 **設定 ▸ 資料庫 ▸ 佈景主題**、Mac 上的 **檔案 ▸ 匯入 ▸ 佈景主題**，或 iPad 上的 **設定 ▸ 資料庫 ▸ 匯入**，**匯入** `.json` 檔案。把檔案拖放到 Pilcrow 上也可以。
- `.zip` 佈景主題套件可以同時包含應用程式佈景主題與渲染佈景主題（Chapter 80）。
- 佈景主題旁的分享按鈕會儲存它的 `.json` 檔案；如果該佈景主題來自套件，則會儲存整個套件。

Pilcrow 內含三個應用程式佈景主題：**自動**、**淺色**和**深色**。它們設定編輯器與語法顏色，並讓介面外框維持內建外觀。

# Chapter 80: 渲染佈景主題 CSS 參考

**渲染佈景主題**就是 CSS。它用來設定預覽、HTML、PDF、圖片和列印輸出的樣式，以及本章最後列出的 Word 樣式。渲染佈景主題可以是單一 `.css` 檔案，也可以是附有本機資產的 ZIP 套件的一部分。語法設定檔定義原始文字如何變成文件；渲染佈景主題只為結果設定樣式。CSS 絕不會設定 App 或編輯器的樣式，那是應用程式佈景主題的工作（Chapter 79）。

## 層疊

Pilcrow 依下列順序套用樣式：

1. Pilcrow 的結構重置；
2. 所選佈景主題的 CSS；
3. 匯出面板中的一次性 CSS（**進階選項 ▸ 自訂 CSS**）；
4. 必要的列印與渲染修正。

依照一般 CSS 層疊規則，後面的規則優先。不支援佈景主題 JavaScript、遠端資源、`file:` URL 和 `@import`。

## 資源

Pilcrow 以標準的 CSS 詞法分析器讀取佈景主題 CSS，因此跳脫字元會在任何檢查之前先被解碼：`u\72 l(…)` 就是 `url()`，`@im\70 ort` 就是 `@import`。瀏覽器會從中載入內容的每個位置都會被檢查：`url(…)`、`url("…")`、`src("…")`，以及 `image-set()` 內的字串。每一個都必須是下列其中之一：

- 套件內的相對路徑（`fonts/Body.woff2`、`./paper.png`）。允許 `?query` 或 `#fragment`，查找檔案時會被忽略；
- PNG、JPEG、GIF、WebP、SVG（`image/svg+xml`）、TTF、OTF、WOFF 或 WOFF2 類型的 `data:` URL；
- 片段參照，例如 `url(#shadow)`，它指向頁面中的某個元素。

任何使用 `data:` 以外的配置（`https:`、`file:`、`blob:`）或以 `//` 開頭的內容都會被拒絕，以 `/` 開頭或包含 `..` 的路徑也一樣。

## 渲染屬性

內建的重置會讀取這些屬性，並提供備用值：

| 群組 | 屬性 |
| --- | --- |
| 顏色 | `--pt-background`、`--pt-foreground`、`--pt-secondary-background`、`--pt-secondary-foreground`、`--pt-accent`、`--pt-link-color`、`--pt-border-color` |
| 程式碼 | `--pt-code-background`、`--pt-code-foreground`、`--pt-code-keyword`、`--pt-code-string`、`--pt-code-number`、`--pt-code-comment` |
| 字型 | `--pt-body-font-family`、`--pt-mono-font-family`、`--pt-base-font-size`、`--pt-line-height` |
| 間距 | `--pt-paragraph-spacing`、`--pt-blockquote-indent`、`--pt-list-indent`、`--pt-code-padding`、`--pt-heading-top`、`--pt-heading-bottom` |
| 表格 | `--pt-table-header-background`、`--pt-table-stripe-background` |
| 提醒 | `--pt-admonition-note-color`、`--pt-admonition-tip-color`、`--pt-admonition-important-color`、`--pt-admonition-warning-color`、`--pt-admonition-caution-color` |

## ZIP 套件

ZIP 套件可以同時包含渲染佈景主題（`.css`）和應用程式佈景主題（`.json`）；每一個都會在設定中以各自的類型列出。最多只有一個 CSS 檔案和一個應用程式佈景主題的 ZIP 不需要資訊清單。超過的話就需要 `pilcrow-theme.json`，在 `variants[].file` 下列出每個佈景主題。檔案的副檔名決定它的類型：

```json
{
  "id": "com.example.paper",
  "name": "Paper",
  "version": "1.0.0",
  "author": "Example Author",
  "license": "MIT",
  "cssAPIVersion": 1,
  "variants": [
    { "id": "app", "name": "Paper", "file": "Paper.json", "appearance": "automatic" },
    { "id": "light", "name": "Paper Light", "file": "Paper-Light.css", "appearance": "light" },
    { "id": "dark", "name": "Paper Dark", "file": "Paper-Dark.css", "appearance": "dark" }
  ]
}
```

資訊清單描述套件及其中的佈景主題。它絕不包含樣式值：那些都在 CSS 和應用程式佈景主題檔案中。

- 套件的 `id` 為安裝資料夾命名。它不能以 `.` 開頭，也不能有前導或尾隨空格。安裝 `id` 已經安裝過的套件會取代原有的套件。
- 以 Finder 的**壓縮**製作的 ZIP 可直接使用。Pilcrow 會略過 `__MACOSX/`、`._*`、`.DS_Store` 和 `Thumbs.db`，而當所有檔案都位於同一個頂層資料夾內時，該資料夾會被視為套件根目錄。
- 刪除單一佈景主題會將它從套件中移除，並保留其他佈景主題與共用資產。刪除最後一個佈景主題則會移除整個套件。若被刪除的佈景主題正被選用，該選擇會回到其類型的預設值：應用程式佈景主題為自動，渲染佈景主題為淺色。
- CSS 可以用相對的 `url(...)` 路徑參照套件內的 PNG、JPEG、GIF、WebP、TTF、OTF、WOFF 和 WOFF2 檔案。Pilcrow 會驗證它們的簽章，並將被參照的資產內嵌為 data URL，讓渲染與匯出的 HTML 保持離線且自成一體。ZIP 路徑不能跳出套件、不能因大小寫而衝突，也不能指向連結。封存檔大小、項目數量、單一檔案大小和壓縮比都有上限。

## Word

Word 匯出使用淺色（基底）的 `:root` 值，並將這些語意屬性對應到具名的 Word 樣式：`--pt-foreground`、`--pt-background`、`--pt-accent`、`--pt-link-color`、`--pt-code-background`、`--pt-code-foreground`、`--pt-body-font-family`、`--pt-mono-font-family`、`--pt-base-font-size` 和 `--pt-line-height`。瀏覽器選擇器與版面規則在 Word 中沒有通用的對應項目。預覽、HTML、PDF 和圖片輸出使用完整的樣式表；Word 則使用這個子集，同時保留文件結構、圖解、數學式圖片、連結和媒體。選取 Word 時，匯出面板一律會顯示這項限制。

Pilcrow 內含兩個渲染佈景主題：**淺色**和**深色**，它們都是完整的起點。
