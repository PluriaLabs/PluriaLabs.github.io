# Chapter 72: 鍵盤

**設定 ▸ 鍵盤 ▸ 快速鍵** 會列出每個可以變更快速鍵的指令，以及目前的按鍵。

| 控制項 | 作用 |
| --- | --- |
| 指令所在的列 | 點按該列，按下新的快速鍵，然後選擇 **儲存**。**解除綁定** 會移除快速鍵。**取消** 會保留舊的快速鍵。如果該快速鍵原本已被其他指令使用，那個指令會被清除，頁面也會告訴你是哪一個。 |
| **Super Tab 按鍵** | **下一個欄位** 與 **上一個欄位** 使用的按鍵，用來在巨集留下的空白處之間跳轉：`⌥Tab` 與 `⌥⇧Tab`，或 `⌃⌘]` 與 `⌃⌘[`，或 **自訂**。 |
| **重置所有快速鍵** | 還原所有預設值。 |

# Chapter 73: 訂閱與點數

Pilcrow 的每項功能都是免費的。支持 Pilcrow 完全出於自願：它能支應開發費用，也讓你對接下來要開發的項目投票。投票會影響工作的先後順序，但不保證任何功能一定會實現。

**支持 Pilcrow** 頁面包含：

| 項目 | 顯示或執行的內容 |
| --- | --- |
| **你的投票數** | **來自訂閱**（本付費月份的投票數，以及到期時間）與 **已購買**（永不過期的投票數）。訂閱投票會先被使用，並在付費月份結束時到期。 |
| **取得投票數** | 訂閱方案與可購買的單次投票。Pilcrow Supporter 每月自動續訂，直到你在 Apple 帳號設定中取消為止。每個付費月份都會給你投票數。 |
| **回復購買項目** | 找回在其他裝置上完成的購買。 |
| **使用條款**、**隱私權政策** | 連結。 |
| **App 圖示** | 提供訂閱者選擇的 App 圖示。投票回合的圖示須在該回合期間訂閱才能獲得，並且會永久保留。在 Mac 上，Pilcrow 開啟時，Dock 中的圖示會隨之改變。 |
| **路線圖** | 目前開放投票的功能回合，附有「票數」與「你的票數」計數，每個項目都有一個 **投票** 按鈕。每次投票會用掉一票，且無法收回。回合之間會顯示下一個回合何時開放。 |

如果某個版本無法使用支持選項，頁面會說明。
