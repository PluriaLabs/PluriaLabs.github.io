# Chapter 63: 對話框與提示

本章說明工作時會出現的面板與提示視窗。

## 插入表格

**格式 ▸ 段落 ▸ 表格 ▸ 插入表格…**（`⌥⌘T`），或 **插入 ▸ 表格…**，會詢問**欄數**與**列數**。請選擇**好**或**取消**。表格會以使用中設定檔的表格語法寫入。

## 單欄多插入點

**編輯 ▸ 選取範圍 ▸ 單欄多插入點…**（`⌃⇧G`）可用數字放置插入點，適合沒有鍵盤的 iPad。輸入**行**（例如 `3-17`）與**欄**（例如 `100`，或 `100-105` 以選取每一行中的這些字元），然後選擇**位置**。接著即可輸入、刪除、拷貝或貼上。若某一行太短而到不了該欄，則依 **設定 ▸ 編輯中 ▸ 單欄模式中的短行**處理。欄選取啟用時，會出現**欄選取**徽章，並附有**關閉欄選取**按鈕。

## 編輯區塊

開啟**渲染區塊**後，每個以圖片繪製的表格、方程式或圖解都有一個編輯按鈕。它會開啟**編輯區塊**，這是一個顯示該區塊原始碼的面板。選擇**套用**即可放回您的更動，或選擇**取消**。

## 檢查連結

**編輯 ▸ 檢查連結…**會檢查文件中的每個連結與圖片。文件必須先儲存，才能檢查指向其他檔案的連結：「請先儲存文件，才能檢查它指向其他檔案的連結。」面板會顯示「正在檢查連結…」，接著列出問題清單（每個問題都附有行號），或顯示「所有連結都正常。」摘要顯示為「已檢查的連結：N。未連線的網址：N。」Pilcrow 不會連線到網址。它最多檢查 50,000 個連結。請選擇**再次檢查**或**完成**。

## 在資料夾中取代

搜尋面板中的**取代…**會在任何檔案被更動之前，先開啟所有變更的預覽。

- **取代為**欄位存放取代內容。面板會列出每個將會變更的檔案，附有數量，以及每個符合項目的取代前後範例，還有一個核取方塊，讓您排除某個檔案。
- **取代 M 個檔案中的 N 個符合項目**會進行變更。**取消**則停止。
- **已略過**清單會列出 Pilcrow 不會更動的檔案及原因：「已在編輯器中開啟。請在那裡取代，或先將它關閉。」、「不是純 UTF-8 文字。」、「單一檔案中的符合項目過多。」、「有一行對此模式而言太長。」或「無法讀取。」
- 單次取代最多更動 2,000 個檔案。超過時會顯示「符合的檔案多於單次取代能更動的數量。請先取代這些檔案，然後再次搜尋。」
- 自預覽之後已變更的檔案會維持不變。
- 完成時：「已取代 M 個檔案中的 N 個符合項目。」並附有**復原**與**完成**。**復原**會從備份還原檔案。之後已被編輯或已消失的檔案會維持原狀，並被列出。下次開啟此面板時，會提供復原上一次取代的選項。

## 版本記錄

**檔案 ▸ 版本記錄…**會列出文件已儲存的版本。每次儲存時都會保留一個版本，數量上限由 **設定 ▸ 檔案 ▸ 保留的版本數**設定。對於尚未儲存的文件，它會顯示「請先儲存文件，才會開始保留版本。」；該設定為「無」時顯示「版本記錄已關閉。」；第一次儲存之前則顯示「尚無版本。」

選取一個版本，然後：

| 按鈕 | 功能 |
| --- | --- |
| **開啟副本** | 將舊版本開啟為獨立的文件。 |
| **比較…** | 以該版本開啟比較面板。 |
| **還原…** | 經您確認後，讓文件回到當時的樣子。目前的文字會保留為一個版本，所以您可以再回去。還原前需要先儲存或還原您的變更。 |
| **完成** | 關閉面板。 |

## 比較版本

**檔案 ▸ 與檔案比較…**，或版本記錄中的**比較…**，會開啟**比較版本**。

- 兩個選擇器，**較舊**與**較新**，用來選擇要比較的內容。**與檔案比較…**可選擇一個檔案。
- **忽略行尾空白**會隱藏只有行尾空格的差異。
- 摘要顯示為「新增：N。移除：N。」，並列出變更的行，最多 5,000 行。
- 對於每項變更：**接受**會在開啟的文件中進行該變更，**拒絕**會略過它，**重新考慮**會復原您的選擇，而**取回**（當較舊版本位於舊的一側時）只會為該項變更放回較舊的行。**接受其餘全部**會接受所有剩下的變更。
- 只有當變更的文字仍然相符時才會套用。否則會顯示「沒有任何變更：自比較以來，文件的該部分已經改變。」
- 訊息：「兩者相同。」、「無法比較這些內容。」，以及差異過多時顯示的「兩者有太多行不同，無法逐行比較。請開啟該版本的副本，並與文件並排閱讀。」

## 翻譯

**編輯 ▸ 翻譯 ▸ 文件**或**選取範圍**會開啟**翻譯文件**或**翻譯選取內容**。

| 控制項 | 功能 |
| --- | --- |
| **偵測到的語言** | Pilcrow 在文字中找到的語言。 |
| **翻譯為** | 目標語言。 |
| **速度** | **快速**（約快二十倍，用詞較平實，也是長文件所需的選擇）、**最佳品質**（適合您會仔細閱讀的文字），或 **AI 助理**（您在「設定 ▸ 助理」中的自有 AI 連線；文字會傳送到該連線所指向的地方）。**最佳品質**適用於 macOS 與 iPadOS 26.4 以上；較早的系統只有一種速度。 |
| **完成時** | 對於文件：**在新標籤頁中開啟**（新文件，名稱與原文件相同，並在括號中註明語言）、**在原檔旁儲存副本**，或**取代文件**。對於選取內容，**取代選取內容**會就地放入翻譯。 |
| **翻譯**或**傳送並翻譯** | 開始翻譯。當 AI 助理會傳送您的文字時，會出現「傳送並翻譯」；它會註明供應商，並警告您的服務可能會為此收費。 |
| **預估時間** | 預估值：「不到一分鐘」或「約 N」。時間取決於您的 AI 服務。 |

翻譯在背景執行，進度顯示在狀態列中。第一次翻譯成某種語言時，會下載語言套件。如果兩種語言之間沒有直接翻譯，Pilcrow 會詢問是否經由英文翻譯（**是**或**否**）。程式碼、連結與數學式會維持原樣。翻譯需要 macOS 15 或 iPadOS 18 以上。若檔案或資料夾已關閉助理，則不會使用助理。

當您開啟以另一種語言寫成的檔案時，可能會出現一個列，詢問「這看起來是*語言*。要將它翻譯成*語言*嗎？」並附有**翻譯**、**現在不要**與**此檔案永不**。設定 ▸ 一般 ▸ 翻譯可控制此功能（第 67 章）。

## 儲存與關閉

- **要保留這份文件嗎？**關閉新文件時，Pilcrow 會詢問「要保留這份新文件嗎？」對於既有文件，則詢問「要儲存您所做的變更嗎？」選項有**儲存**、**取消**與**刪除**（或**不儲存**）。對於新文件，表單中有**儲存為：**（名稱）、**標籤：**與**位置：**（可用**其他…**或**選擇…**選擇不同的資料夾）。您無法復原「刪除」。
- **儲存文件**是第一次儲存時的表單，包含**名稱**與**位置**（**選擇其他位置…**）。如果已有同名檔案，它會詢問**要取代現有檔案嗎？**
- 當其他 App 修改了開啟中的檔案時，會出現**磁碟上的檔案已變更**：請選擇**重新載入**或**保留目前版本**。
- **要從磁碟重新載入嗎？**（檔案 ▸ 從磁碟重新載入）提供**儲存後重新載入**、**不儲存直接重新載入**與**取消**。
- 當您在仍有欄位未填寫時列印或匯出，會出現**仍有待填寫的欄位**。它提供**前往下一個欄位**、**仍要繼續**（欄位會照原樣寫在輸出中）與**取消**。
- **解析警告**、**無法分享**、**無法儲存文件**與**檔案操作失敗**會顯示一則訊息，並附有**好**。
- 如果 Pilcrow 上次意外結束，會有一個橫幅說明此事，並提供**開啟診斷**或**現在不要**。
- 匯入資料庫項目後，會有一則小提示確認，並附有關閉它的按鈕。
- 當 App 語言是翻譯版本時，第一次啟動會顯示**已由 AI 翻譯**，說明翻譯尚未經母語人士審閱，並附有**不再顯示此訊息**與**好**。

## 助理的權限面板

在第一次將內容傳送到線上服務之前，**要傳送給*服務*嗎？**會說明傳送的內容（您的請求、問題框上方所計入的文件文字，或依風格指南規則審閱的文字、模型名稱，以及您的金鑰）、接收者是誰，以及如何收回。此電腦上的程式不會讓資料離開這部電腦；您網路上的另一部電腦除非位址以 https 開頭，否則不會加密；線上服務可能依其自身條款保留文字。面板中有連到該服務隱私權政策與 Pilcrow 隱私權政策的連結。請選擇**傳送**或**取消**。在您選擇「傳送」之前，不會傳送任何內容。

# Chapter 64: 匯出與編譯

## 匯出面板

可透過 **檔案 ▸ 匯出…**（`⇧⌘E`）、**匯出**按鈕或 **更多 ▸ 匯出…**開啟。左側是格式清單，右側是選項，底部是按鈕。

### 格式

| 格式 | 檔案 | 附註 |
| --- | --- | --- |
| **HTML** | `.html` | 獨立且帶有樣式的頁面。 |
| **HTML（不含樣式）** | `.html` | 乾淨的結構，沒有佈景主題 CSS。 |
| **PDF** | `.pdf` | 分頁。 |
| **Word (.docx)** | `.docx` | 真正的 Word 套件。它使用佈景主題的顏色、字型、大小與行距；瀏覽器版面選擇器在 Word 中沒有對應項目。方程式、圖解與圖表會變成圖片。 |
| **圖片** | `.png` | 渲染後文件的單一圖片。 |
| **PDF 封存檔 (.zip)** | `.zip` | 依序排列的 PDF 區段加上資訊清單，適用於非常大的文件。 |

### 選項

| 區段 | 控制項 |
| --- | --- |
| **樣式** | **佈景主題**用於選擇渲染佈景主題。佈景主題控制匯出文件的字體排印與顏色。 |
| **頁面**（PDF、PDF 封存檔與 Word） | **紙張大小**（A3、A4、A5、Letter、Legal、Tabloid，或自訂**寬度**與**高度**）、**方向**（**直向**或**橫向**），以及**上邊界**、**下邊界**、**左邊界**與**右邊界**，皆以公釐為單位（起始為 25.4 公釐，即一英寸）。**將這些頁面設定作為預設值**會儲存這些設定供之後的匯出使用；在您變更任何內容之前呈現灰色。否則這些設定只適用於此次匯出。 |
| **進階選項** | **自訂 CSS**，只在此次匯出中，於佈景主題之後套用。 |

面板會顯示「儲存為 *名稱*」，並附上將使用的檔名，以及「這些選擇只適用於此次匯出。」選擇某種格式後，左下角的一行文字會顯示它所產生的內容：例如 HTML 顯示「使用所選樣式的獨立網頁。」，PDF 則顯示「單一分頁的 PDF 文件。」

### 按鈕

**取消**會關閉面板。**分享…**會把產生的檔案直接送到系統的分享面板。**匯出**會詢問儲存位置。處理期間，面板會顯示「正在渲染…」。若出現問題，會顯示「匯出失敗。」若仍有待填寫的欄位，Pilcrow 會先詢問（第 63 章）。

適用於每次匯出的頁面設定、頁首與頁尾範本、目錄以及編號選項，位於 **設定 ▸ 目錄與標籤**與 **設定 ▸ 匯出**（第 70 章）。

## 編譯面板

**檔案 ▸ 編譯書稿…**（或專案面板中的**編譯…**）會依資訊清單的順序合併書籍專案的檔案。載入專案後才能使用。

| 區段 | 控制項 |
| --- | --- |
| **書稿** | 摘要：「N 個檔案」、「N 個已排除」，以及任何「找不到」的路徑，這些路徑必須在編譯前修正。**順序**清單會顯示最終的順序。 |
| **輸出** | **格式**，然後是**從新頁開始**：**前置內容**、**部**、**章節**、**附錄**。**場景之間**設定分隔符號（「無」或一個標記）。**目錄**、**為標題編號**，以及**先保留每個檔案的一個版本**（為每個納入的檔案儲存一筆版本記錄項目）。 |
| **預設** | **已儲存**的預設。**儲存為預設**，附有**預設名稱**與**儲存**。**刪除預設**會移除所選的預設。 |

選擇**編譯…**以挑選儲存位置，或選擇**取消**。執行時會顯示「正在讀取 N／N…」然後是「正在編譯…」，並附有**停止**。沒有值的變數會被列出（「這些 {{variables}} 沒有值，已照原樣保留」），並保持明顯未變。如果無法建立檔案，會顯示「無法在該處建立這本書。」

### 新增書籍

**檔案 ▸ 新增書籍…**會詢問**標題**、**作者**、**寫作格式**（章節的語法）與**儲存位置**（一個資料夾，附有**選擇…**）。請選擇**建立**。Pilcrow 會建立含有資訊清單與第一章的資料夾。如果無法在該處建立書籍，它會說明此事。
