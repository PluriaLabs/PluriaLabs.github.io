# Chapter 75: 佈景主題編輯器

佈景主題有兩種，各有自己的編輯器。兩者都可從 **設定 ▸ 資料庫 ▸ 佈景主題** 開啟：**新增**可建立佈景主題，**編輯**可修改自訂的佈景主題，**複製**則會複製內建的佈景主題，讓你修改副本。內建的佈景主題無法編輯。

## 渲染佈景主題編輯器

**編輯渲染佈景主題**用來設定預覽、HTML、PDF、圖片和列印輸出的樣式。它的 Pilcrow 自訂屬性也會設定 Word 樣式。渲染佈景主題不會影響 App 或編輯器的樣式。

| 項目 | 功能 |
| --- | --- |
| **名稱** | 佈景主題的名稱。 |
| **外觀** | **自動**、**淺色**或**深色**。 |
| **CSS** | 樣式表，位於程式碼編輯器中。屬性與類別請參閱 Chapter 80。 |
| **渲染後的預覽** | 一份範例文件，會隨著你輸入的 CSS 即時繪製，讓你看到效果。 |
| **CSS 診斷** | Pilcrow 在 CSS 中發現的問題，例如不允許使用的遠端資源。 |
| **取消**、**儲存** | 關閉或保留佈景主題。若有變更就關閉，會詢問**要捨棄佈景主題的變更嗎？**，可選擇**捨棄變更**或**繼續編輯**。 |
| **基線** | **重置為基準**會捨棄自佈景主題建立、複製或匯入以來的所有變更（經你確認後）。**設為新基準**會儲存佈景主題，並把它目前的狀態當作還原點。 |

## 應用程式佈景主題編輯器

**編輯應用程式佈景主題**用來設定 Pilcrow 本身的樣式：外觀、強調色、側邊欄、列和編輯器。

| 項目 | 功能 |
| --- | --- |
| **名稱** | 佈景主題的名稱。 |
| **外觀** | **自動**、**淺色**或**深色**。自動佈景主題有兩組調色盤。 |
| **正在編輯顏色：** | 對自動佈景主題而言，選擇**淺色**或**深色**：你正在編輯兩組調色盤中的哪一組。 |
| 顏色，分為五組 | **App**（強調色）、**側邊欄**（背景與前景）、**狀態列與格式列**（背景與前景）、**編輯器**（背景、前景、游標、選取範圍、行號區背景、行號區前景、目前行標線），以及**語法**（標題、標記、程式碼、連結、淡化，以及程式碼關鍵字、字串、數字和註解）。每個顏色在你設定之前都顯示**預設**，並有**重置**按鈕可還原。 |
| **預覽** | Pilcrow 的縮圖，包含側邊欄、編輯器和狀態列，以你選擇的顏色呈現，可切換淺色或深色。 |
| **取消**、**儲存**、**基線** | 同上。 |

佈景主題也可以為個別的語法標記上色。這些顏色會被保留，但要在佈景主題的 JSON 檔案中編輯（`syntax.tokens`）；請參閱 Chapter 79。

# Chapter 76: 巨集編輯器

從 **設定 ▸ 資料庫 ▸ 巨集** 開啟巨集編輯器：在某個集合內按**新增**，或對巨集按**編輯**。標題為**新增巨集**或**編輯巨集**。

| 欄位 | 功能 |
| --- | --- |
| **名稱** | 巨集的標籤。 |
| **觸發條件**（例如 `/sig`） | 啟動巨集的文字。輸入觸發文字後接空格、Tab 或換行，巨集就會展開。 |
| **符合** | 觸發條件的解讀方式：**完全相符的文字**、**前置詞**或**正規表示式**。可能讓編輯器當機的正規表示式會被拒絕：「That regular expression could hang the editor. Simplify it.」 |
| **取代內容** | 展開後的文字。 |
| **插入日期／時間** | 一個選單，可在取代內容中加入日期或時間標記。 |
| **已啟用** | 開啟或關閉巨集，而不必刪除它。 |
| **不在程式碼內展開** | 避免巨集在行內程式碼和程式碼區塊中觸發。 |
| **取消**、**儲存** | 關閉或保留巨集。若無法儲存，訊息會說明原因。 |

在取代內容中，`$1`、`$2` 等是定位停駐點，`$0` 是游標最後停留的位置。巨集展開後，Tab（或**下一個欄位**）會在各停駐點之間跳轉。日期和時間使用標記：`{{date:yyyy-MM-dd}}`、`{{time:HH:mm:ss}}` 和 `{{datetime:MM/dd/yyyy h:mm a}}`，以及具名格式 `iso8601`、`rfc2822`、`unix`、`short`、`medium`、`long` 和 `full`。欄位下方的 **Now:** 一行會顯示此刻取代內容會產生的結果。

# Chapter 78: 在 iPad 上使用 Pilcrow

Pilcrow 可在 iPadOS 17 或更新版本上執行。它可以只用觸控操作，也可搭配外接鍵盤，以及觸控式軌跡板或滑鼠。

## 觸控

- **窗格分隔線。** 在並排模式中，拖曳原始碼與預覽之間的分隔線即可調整大小。連按兩下可重置。
- **導覽器。** 拖曳側邊欄的邊緣即可調整大小。在狹窄的視窗中，側邊欄會蓋住文件，按**完成**按鈕即可關閉。
- **欄選取。** 開啟 **更多 ▸ 欄選取**，然後用一指拖曳即可選取一塊矩形文字。兩指仍可捲動。開啟時會顯示**欄選取**標章，並附有關閉的按鈕。或者使用 **更多 ▸ 單欄多插入點…**，以數字放置插入點。
- **快顯選單。** 在文字中長按，即可開啟編輯器的選單（見下文）。
- **檔案。** 在檔案面板中長按某個檔案，即可開啟它的選單（Chapter 60）。

## 搭配外接鍵盤

Chapter 77 中的所有快速鍵都能使用。按住 **⌘** 可看到 iPad 的選單列，或將指標移到螢幕頂端。連接鍵盤或滑鼠時，Pilcrow 可以隱藏自己的標頭選單；請參閱 **設定 ▸ 外觀 ▸ 標頭中的選單**。

## 搭配觸控式軌跡板或滑鼠

按右鍵會開啟編輯器的快顯選單。拖曳時按住 **Option**，即可選取一塊矩形文字。

## 編輯器的快顯選單

在文字中，於 Mac 上按右鍵，或在 iPad 上長按。目前的語法設定檔無法表達的項目會呈現灰色，系統也會加入自己的項目（剪下、拷貝、貼上、拼字建議、查詢等）。

在 **Mac** 上：

| 項目 | 功能 |
| --- | --- |
| **拷貝／貼上為…** | **拷貝為 Markdown**、**拷貝為純文字**、**拷貝為 HTML 程式碼**、**以純文字貼上**。 |
| **段落** | **段落**、**標題 1** 至 **6**、**引用區塊**、**項目符號清單**、**編號清單**、**待辦事項清單**、**程式碼圍欄**。 |
| **格式** | **粗體**、**強調**、**程式碼**、**刪除線**、**行內數學式**、**顯示數學式**、**圖解**、**圖表**、**超連結**。 |
| **選取範圍** | **選取字詞**、**選取行**、**選取段落**。 |

在 **iPad** 上，有三個子選單與系統的項目並列：

| 項目 | 功能 |
| --- | --- |
| **格式** | 行內樣式：粗體、強調、程式碼等。 |
| **段落** | 段落類型：標題、引用、清單、程式碼圍欄。 |
| **插入** | 與格式工具列的**更多**選單相同的插入項目，包括**插入提醒**、**插入圖片…**和**插入表格…**，並在**語法**之下列出目前設定檔自己的結構。 |

## 與 Mac 的差異

| 在 iPad 上 | 在 Mac 上 |
| --- | --- |
| 設定從標頭的齒輪開啟，顯示在面板中。 | **Pilcrow ▸ 設定…**（`⌘,`）。 |
| 標頭可顯示 Pilcrow 自己的選單（**標頭中的選單**）。 | 選單列由系統提供。 |
| **介面大小**可設定選單、列和對話框的大小。 | 無法使用。 |
| 匯入位於 **設定 ▸ 資料庫 ▸ 匯入**。 | **檔案 ▸ 匯入**。 |
| 沒有全部儲存、複製、移至、從磁碟重新載入、在 Finder 中顯示或頁面設定。 | 這些都在檔案選單中。 |
| **編輯 ▸ 拼字與文法**只有一個項目：**輸入時檢查拼字**。 | **編輯 ▸ 拼字與文法**還有**顯示拼字與文法**和**立即檢查文件**。 |
| 鍵入聲音會被 iPad 的靜音開關靜音。 | 不適用。 |
