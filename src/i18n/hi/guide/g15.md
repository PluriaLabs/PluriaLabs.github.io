# Chapter 81: फ़ाइलें, एन्कोडिंग और सीमाएँ

## वे फ़ाइलें जिन्हें Pilcrow खोलता है

Pilcrow सादे टेक्स्ट और मार्कअप फ़ाइलें संपादित करता है। सामान्य एक्सटेंशन `txt`, `md`, `markdown`, `adoc`, `asciidoc`, `rst` और `tex` हैं, और कोई भी एक्सटेंशन जिसे आपकी जोड़ी हुई प्रोफ़ाइल दावा करे। Pilcrow फ़ाइल खोलते समय उसकी टेक्स्ट एन्कोडिंग पहचान लेता है।

| आइटम | प्रकार |
| --- | --- |
| सिंटैक्स प्रोफ़ाइल, मैक्रो संग्रह, शैली मार्गदर्शिका, एप्लिकेशन थीम | `.json` |
| रेंडर थीम | `.css` |
| थीम पैकेज | `.zip` |
| पुस्तक प्रोजेक्ट मैनिफ़ेस्ट | `manifest.pilcrow` |
| पृष्ठभूमि | HEIC, PNG, JPEG, SVG, MP4, MOV, M4V |
| टाइपिंग ध्वनि क्लिप | WAV, AIFF, MP3, M4A, CAF |

## टेक्स्ट एन्कोडिंग

Pilcrow UTF-8, UTF-16, UTF-32 और ISO 8859-1 (Latin-1) टेक्स्ट पढ़ता है। आप **दस्तावेज़ की जानकारी ▸ एन्कोडिंग ▸ इसमें रूपांतरित करें…** से किसी दस्तावेज़ को निम्न में से किसी में रूपांतरित कर सकते हैं; फ़ाइल अगली बार सहेजे जाने पर रूपांतरित होती है:

UTF-8, UTF-8 (BOM), UTF-16 LE, UTF-16 LE (BOM), UTF-16 BE, UTF-16 BE (BOM), UTF-32 LE, UTF-32 LE (BOM), UTF-32 BE, UTF-32 BE (BOM).

Latin-1 फ़ाइल को इनमें से किसी में भी बिना हानि के रूपांतरित किया जा सकता है। Latin-1 में रूपांतरण की पेशकश नहीं की जाती, क्योंकि इससे सामग्री नष्ट हो सकती है।

## निर्यात प्रारूप

| प्रारूप | एक्सटेंशन |
| --- | --- |
| HTML, HTML (शैलियों के बिना) | `.html` |
| PDF | `.pdf` |
| Word (.docx) | `.docx` |
| चित्र | `.png` |
| PDF आर्काइव | `.zip` |

## सीमाएँ और संख्याएँ

जहाँ Pilcrow रुक जाता है, या जहाँ किसी विकल्प की एक सीमा-परास है:

| कहाँ | सीमा |
| --- | --- |
| खोज पैनल | 500 मिलान पर रुक जाता है। |
| पूर्वावलोकन में खोजें | 2,000 मिलान तक गिनता है। |
| फ़ोल्डर में बदलें | एक बार में अधिकतम 2,000 फ़ाइलें बदलता है। |
| लिंक जाँचें | 50,000 लिंक तक जाँचता है। |
| तुलना | अधिकतम 5,000 बदली हुई पंक्तियाँ दिखाता है। |
| रखने के लिए संस्करण | कोई नहीं से 500 तक (डिफ़ॉल्ट 50)। |
| लंबी पंक्तियाँ | 20,000 या अधिक अक्षरों की पंक्तियाँ हमेशा रैप होती हैं। |
| फ़ॉन्ट आकार | 9 से 32 पॉइंट। |
| टैब चौड़ाई | 2 से 8 स्पेस। |
| टेक्स्ट चौड़ाई | 50% से 100%। |
| ज़ूम | 50% से 200%, दस चरणों में। |
| पढ़ने की गति | 60 से 2,000 शब्द प्रति मिनट। |
| नेविगेटर की चौड़ाई | 180 से 420 पॉइंट। |
| टाइपिंग ध्वनि क्लिप | अधिकतम 2 सेकंड और 3 MB। |
| निदान रिपोर्ट का लॉग टेक्स्ट | सबसे नई प्रविष्टियाँ, 60,000 अक्षरों तक, जब GitHub इश्यू विवरण में जोड़ा जाए। |
| बहुत बड़ी फ़ाइलें | पूरी की पूरी मेमोरी में पढ़े बिना खुलती और संपादित होती हैं। पंक्ति और शब्द की गिनती, और रूपरेखा, पृष्ठभूमि में पूरी की जाती हैं और तब तक आंशिक हो सकती हैं। बहुत बड़े दस्तावेज़ के PDF निर्यात को संपादन या HTML और Word निर्यात से कहीं अधिक मेमोरी चाहिए; PDF आर्काइव उसे सीमित भागों में बाँट देता है। |

## Pilcrow चीज़ें कहाँ रखता है

| क्या | कहाँ |
| --- | --- |
| आपके दस्तावेज़ | जहाँ भी आपने उन्हें सहेजा। |
| लाइब्रेरी (थीम, प्रोफ़ाइल, मैक्रो, शैली मार्गदर्शिकाएँ, पृष्ठभूमि) | ऐप के निजी संग्रहण में, या आपके चुने फ़ोल्डर के भीतर "Pilcrow Library" नाम के फ़ोल्डर में (**सेटिंग्ज़ ▸ लाइब्रेरी ▸ स्थान**)। |
| प्राथमिकताएँ, API कुंजियाँ, पुनर्प्राप्ति प्रतियाँ, संस्करण इतिहास | डिवाइस पर, ऐप के निजी संग्रहण और Keychain में। इन्हें **सेटिंग्ज़ ▸ सामान्य ▸ संग्रहण और गोपनीयता** में देखें और हटाएँ। |
| निदान लॉग | डिवाइस पर, जब तक आप उसे साफ़ न करें। |

# Chapter 82: संदेश, बैनर और खाली स्थितियाँ

यह अध्याय Pilcrow के दिखाए छोटे संदेशों को समझाता है, ताकि उनमें से कोई भी पहेली न रहे।

## एडिटर और पूर्वावलोकन में

| संदेश | इसका अर्थ |
| --- | --- |
| **Nothing to preview yet. Start writing and it will appear here.** (या "Switch to Edit and start writing.") | दस्तावेज़ खाली है, इसलिए पूर्वावलोकन में बनाने को कुछ नहीं है। |
| **Preview couldn't render: …** के साथ **स्रोत दिखाएँ** और **फिर कोशिश करें** | पूर्वावलोकन विफल रहा। **स्रोत दिखाएँ** संपादन पर ले जाता है। **फिर कोशिश करें** दोबारा प्रयास करता है। |
| विफल समीकरण या आरेख, एक **स्रोत दिखाएँ** लिंक के साथ | एक ब्लॉक नहीं बनाया जा सका। उस ब्लॉक के स्रोत पर जाकर उसे ठीक करने के लिए **स्रोत दिखाएँ** पर क्लिक करें। |
| **Couldn't save** के साथ **फिर कोशिश करें** और एक खारिज बटन | सहेजना विफल रहा। दस्तावेज़ खुला और असहेजा रहता है। कारण ठीक करें (डिस्क स्थान, अनुमतियाँ, खिसकाई गई फ़ाइल) और **फिर कोशिश करें** चुनें। |
| **डिस्क पर फ़ाइल बदल गई** | किसी दूसरे ऐप ने फ़ाइल बदल दी। **फिर से लोड करें** नया संस्करण पढ़ता है; **वर्तमान संस्करण रखें** आपके पास जो है उसे रखता है। |
| **पार्सिंग चेतावनी** | ऐसी पंक्ति जहाँ कोई रचना संभवतः वह नहीं है जो आपका आशय था (Chapter 68)। |
| **मौजूदा फ़ाइल बदलें?** | आपका चुना नाम उस जगह पहले से उपयोग में है। |
| **भरने वाले फ़ील्ड शेष हैं** | आप बिना भरे फ़ील्ड के साथ प्रिंट या निर्यात कर रहे हैं (Chapter 63)। |
| **पैन विभाजक** (VoiceOver संकेत: "Drag to resize the editor and the preview. Double-tap to reset.") | अगल-बगल में स्रोत और पूर्वावलोकन के बीच का हैंडल। |
| **शब्द: N** | स्टेटस बार में शब्द गिनती। |

## डायलॉग और पैनल में

| कहाँ | संदेश | अर्थ |
| --- | --- | --- |
| कमांड पैलेट | **कमांड टाइप करें** | फ़ील्ड का संकेत। कुछ भी मेल न खाने पर "No matching commands" दिखता है। |
| तुरंत खोलें | **फ़ाइल नाम टाइप करें** | फ़ील्ड का संकेत। |
| स्तंभ में कर्सर | **पंक्तियाँ (उदाहरण के लिए 3-17)**, **स्तंभ (उदाहरण के लिए 100, या चुनने के लिए 100-105)** | फ़ील्ड के संकेत। एक अकेला स्तंभ कर्सर रखता है; एक सीमा हर पंक्ति के उन अक्षरों को चुनती है। |
| खोज पैनल | **Type to search this folder.**, **No matches in this folder.**, **Search cancelled.** | फ़ोल्डर खोज की स्थिति। |
| फ़ाइलें पैनल | **You can also drop a folder here.** | किसी फ़ोल्डर को खोलने के लिए उसे पैनल पर खींचें। |
| फ़ोल्डर में बदलें | **Nothing to replace.** | खोज में कोई मिलान नहीं है। |
| तुलना | बटनों पर टूलटिप: **स्वीकार करें** ("Make this change in the open document"), **अस्वीकार करें** ("Leave this change out of the open document"), **वापस लें** ("Put the older lines back in the document for this change only")। | हर एक क्या करता है। |
| अनुवाद करें | **The translation could not be completed.** | फिर कोशिश करें, या कोई दूसरी गति चुनें। |
| अनुवाद करें | **अनुमानित समय: एक मिनट से कम** | AI सहायक की गति का अनुमान; समय आपकी AI सेवा पर निर्भर करता है। अनुवाद के बाद, **नए टैब में खोलें** परिणाम खोलता है। |
| सहायक | **No document is open.**, **No document text is sent.** | पैनल के पास साझा करने को कुछ नहीं है, इसलिए कुछ नहीं भेजा जाता। |
| मॉडल चयनकर्ता | **मॉडल लोड हो रहे हैं…**, **No models match.** | सूची लोड हो रही है, या आपकी खोज में कुछ नहीं मिला। |
| शैली समीक्षा | **No findings.** और **The reply could not be read as findings. Try again.** | समीक्षा में कुछ नहीं मिला, या AI का उत्तर अपेक्षित रूप में नहीं था। |
| शैली समीक्षा | **सभी लागू करें** टूलटिप: "Makes every fix that has one, as a single change you can undo." | एक पूर्ववत करें उन सभी को वापस कर देता है। |
| प्रोजेक्ट पैनल | **आपका नाम**, **वेरिएबल जोड़ें** | लेखक फ़ील्ड का संकेत, और प्रोजेक्ट वेरिएबल के लिए बटन। |
| सहायक अनुमति | **Read Pilcrow's privacy policy** | गोपनीयता नीति खोलता है। |
