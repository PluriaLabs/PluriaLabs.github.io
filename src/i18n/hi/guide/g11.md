# Chapter 72: कीबोर्ड

**सेटिंग्ज़ ▸ कीबोर्ड ▸ शॉर्टकट** में वे सभी कमांड सूचीबद्ध हैं जिनका शॉर्टकट आप बदल सकते हैं, साथ में उनकी मौजूदा कुंजी।

| नियंत्रण | यह क्या करता है |
| --- | --- |
| किसी कमांड की पंक्ति | उस पर क्लिक करें, नया शॉर्टकट दबाएँ, फिर **सहेजें** चुनें। **बंधन हटाएँ** शॉर्टकट हटा देता है। **रद्द करें** पुराना शॉर्टकट बनाए रखता है। अगर वह शॉर्टकट किसी दूसरे कमांड के पास था, तो उस कमांड का शॉर्टकट साफ़ हो जाता है और पेज बताता है कि कौन सा। |
| **सुपर Tab कुंजियाँ** | **अगला फ़ील्ड** और **पिछला फ़ील्ड** की कुंजियाँ, जो मैक्रो द्वारा छोड़े गए खाली स्थानों के बीच कूदती हैं: `⌥Tab` और `⌥⇧Tab`, या `⌃⌘]` और `⌃⌘[`, या **कस्टम**। |
| **सभी शॉर्टकट रीसेट करें** | हर डिफ़ॉल्ट को वापस लाता है। |

जिन कमांड को आप बदल सकते हैं, उनके डिफ़ॉल्ट के साथ, ये हैं:

| कमांड | डिफ़ॉल्ट |
| --- | --- |
| प्रबल | `⌘B` |
| ज़ोर | `⌘I` |
| इनलाइन कोड | `⌃`` ` `` |
| इनलाइन गणित | `⌃M` |
| स्ट्राइकथ्रू | `⌃⇧`` ` `` |
| हाइपरलिंक | `⌘K` |
| प्रारूप साफ़ करें | `⌘\` |
| साइडबार टॉगल करें | `⇧⌘L` |
| साइडबार: रूपरेखा | `⌃⌘1` |
| खुले दस्तावेज़ | `⌃⌘2` |
| साइडबार: फ़ाइल ट्री | `⌃⌘3` |
| साइडबार: खोजें | `⇧⌘F` |
| साइडबार: सहायक | `⌃⌘4` |
| ऊपर कर्सर जोड़ें | `⌃⇧↑` |
| नीचे कर्सर जोड़ें | `⌃⇧↓` |
| स्तंभ में कर्सर… | `⌃⇧G` |
| वापस जाएँ | `⌃⌘←` |
| आगे जाएँ | `⌃⌘→` |
| अगली घटना चुनें | `⌃⌥D` |
| सभी घटनाएँ चुनें | `⌃⌥⇧D` |
| अगला फ़ील्ड | `⌥Tab` |
| पिछला फ़ील्ड | `⌥⇧Tab` |
| कमांड पैलेट… | `⌃⇧P` |
| फ़ोकस मोड | कोई नहीं |

इस सूची में न आने वाले कमांड, जैसे सहेजें, खोजें और अनुच्छेद के आइटम, के शॉर्टकट निश्चित हैं। Chapter 77 में सभी शॉर्टकट दिए गए हैं।

# Chapter 73: सदस्यता और क्रेडिट

Pilcrow की हर सुविधा मुफ़्त है। Pilcrow को सहयोग देना वैकल्पिक है: इससे विकास का खर्च चलता है, और आपको यह तय करने के लिए वोट मिलते हैं कि आगे क्या बनाया जाए। वोट काम का क्रम तय करने में मदद करते हैं, लेकिन किसी सुविधा का वादा नहीं करते।

**Pilcrow को सहयोग दें** पेज में ये हैं:

| भाग | यह क्या दिखाता या करता है |
| --- | --- |
| **आपके वोट** | **आपकी सदस्यता से** (इस भुगतान वाले महीने के वोट, उनकी समाप्ति की तारीख के साथ) और **खरीदे हुए** (वे वोट जो कभी समाप्त नहीं होते)। सदस्यता के वोट पहले इस्तेमाल होते हैं और भुगतान वाला महीना खत्म होने पर समाप्त हो जाते हैं। |
| **वोट पाएँ** | सदस्यता और वे अलग-अलग वोट जो आप खरीद सकते हैं। Pilcrow Supporter हर महीने नवीनीकृत होती है, जब तक आप उसे अपनी Apple Account सेटिंग्ज़ में रद्द न करें। हर भुगतान वाला महीना आपको वोट देता है। |
| **खरीदारियाँ पुनर्स्थापित करें** | किसी दूसरे डिवाइस पर की गई खरीदारियाँ वापस लाता है। |
| **उपयोग की शर्तें**, **गोपनीयता नीति** | लिंक। |
| **ऐप आइकन** | सदस्यों के लिए ऐप आइकनों का विकल्प। किसी वोटिंग दौर के आइकन उसी दौर में सदस्यता लेने पर मिलते हैं, और हमेशा आपके पास रहते हैं। Mac पर Pilcrow खुला रहने के दौरान आइकन Dock में बदल जाता है। |
| **रोडमैप** | वोटिंग के लिए खुली सुविधाओं का मौजूदा दौर, "Votes" और "Yours" की गिनती के साथ और हर सुविधा के लिए एक **वोट करें** बटन। हर वोट आपके वोटों में से एक इस्तेमाल करता है और वापस नहीं लिया जा सकता। दो दौरों के बीच यह बताता है कि अगला कब खुलेगा। |

अगर किसी विशेष बिल्ड में सहयोग के विकल्प उपलब्ध नहीं हैं, तो पेज यह बता देता है।
