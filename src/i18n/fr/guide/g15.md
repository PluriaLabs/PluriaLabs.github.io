# Chapter 81: Fichiers, encodages et limites

## Les fichiers que Pilcrow ouvre

Pilcrow modifie des fichiers de texte brut et de balisage. Les extensions habituelles sont `txt`, `md`, `markdown`, `adoc`, `asciidoc`, `rst` et `tex`, ainsi que toute extension revendiquée par un profil que vous ajoutez. Pilcrow détecte l’encodage du texte d’un fichier à son ouverture.

| Élément | Type |
| --- | --- |
| Profil de syntaxe, collection de macros, guide de style, thème de l’application | `.json` |
| Thème de rendu | `.css` |
| Paquet de thème | `.zip` |
| Manifeste de projet de livre | `manifest.pilcrow` |
| Arrière-plan | HEIC, PNG, JPEG, SVG, MP4, MOV, M4V |
| Clip de son de frappe | WAV, AIFF, MP3, M4A, CAF |

## Encodages de texte

Pilcrow lit le texte en UTF-8, UTF-16, UTF-32 et ISO 8859-1 (Latin-1). Vous pouvez convertir un document avec **Informations sur le document ▸ Encodage ▸ Convertir en…** vers l’un des encodages suivants ; le fichier est converti à son prochain enregistrement :

UTF-8, UTF-8 (BOM), UTF-16 LE, UTF-16 LE (BOM), UTF-16 BE, UTF-16 BE (BOM), UTF-32 LE, UTF-32 LE (BOM), UTF-32 BE, UTF-32 BE (BOM).

Un fichier Latin-1 peut être converti vers n’importe lequel de ces encodages sans perte. La conversion vers Latin-1 n’est pas proposée, car elle peut détruire du contenu.

## Formats d’exportation

| Format | Extension |
| --- | --- |
| HTML, HTML (sans styles) | `.html` |
| PDF | `.pdf` |
| Word (.docx) | `.docx` |
| Image | `.png` |
| Archive PDF | `.zip` |

## Limites et chiffres

Là où Pilcrow s’arrête, ou là où un réglage a une plage de valeurs :

| Où | Limite |
| --- | --- |
| Panneau de recherche | S’arrête à 500 résultats. |
| Recherche dans l’aperçu | Compte jusqu’à 2 000 résultats. |
| Remplacer dans le dossier | Modifie au plus 2 000 fichiers à la fois. |
| Vérifier les liens | Vérifie jusqu’à 50 000 liens. |
| Comparer | Affiche jusqu’à 5 000 lignes modifiées. |
| Versions à conserver | De aucune à 500 (50 par défaut). |
| Lignes longues | Les lignes de 20 000 caractères ou plus passent toujours à la ligne. |
| Taille de police | De 9 à 32 points. |
| Largeur de tabulation | De 2 à 8 espaces. |
| Largeur du texte | De 50 % à 100 %. |
| Zoom | De 50 % à 200 %, en dix paliers. |
| Vitesse de lecture | De 60 à 2 000 mots par minute. |
| Largeur du navigateur | De 180 à 420 points. |
| Clip de son de frappe | Au plus 2 secondes et 3 Mo. |
| Texte du journal du rapport de diagnostic | Les entrées les plus récentes, jusqu’à 60 000 caractères, lorsqu’il est ajouté à la description d’un ticket GitHub. |
| Très gros fichiers | S’ouvrent et se modifient sans être lus entièrement en mémoire. Le nombre de lignes et de mots, ainsi que le plan, sont calculés en arrière-plan et peuvent être partiels d’ici là. L’exportation PDF d’un très gros document demande beaucoup plus de mémoire que la modification ou l’exportation HTML et Word ; l’archive PDF le découpe en parties bornées. |

## Où Pilcrow conserve les choses

| Quoi | Où |
| --- | --- |
| Vos documents | Là où vous les avez enregistrés. |
| Bibliothèque (thèmes, profils, macros, guides de style, arrière-plans) | Dans le stockage privé de l’app, ou dans un dossier nommé « Pilcrow Library » à l’intérieur d’un dossier de votre choix (**Réglages ▸ Bibliothèque ▸ Emplacement**). |
| Préférences, clés API, copies de récupération, historique des versions | Sur l’appareil, dans le stockage privé de l’app et le trousseau. Consultez-les et supprimez-les dans **Réglages ▸ Général ▸ Stockage et confidentialité**. |
| Journal de diagnostic | Sur l’appareil, jusqu’à ce que vous l’effaciez. |

# Chapter 82: Messages, bandeaux et états vides

Ce chapitre explique les courts messages que Pilcrow affiche, afin qu’aucun ne reste un mystère.

## Dans l’éditeur et l’aperçu

| Message | Signification |
| --- | --- |
| **Rien à afficher pour l’instant. Commencez à écrire et le résultat apparaîtra ici.** (ou « Passez à Modifier et commencez à écrire. ») | Le document est vide, il n’y a donc rien à dessiner dans l’aperçu. |
| **L’aperçu n’a pas pu s’afficher : …** avec **Afficher la source** et **Réessayer** | L’aperçu a échoué. **Afficher la source** bascule vers Modifier. **Réessayer** relance l’opération. |
| Une équation ou un diagramme en échec, avec un lien **Afficher la source** | Un bloc n’a pas pu être dessiné. Cliquez sur **Afficher la source** pour aller à la source de ce bloc et la corriger. |
| **Enregistrement impossible** avec **Réessayer** et un bouton de fermeture | L’enregistrement a échoué. Le document reste ouvert et non enregistré. Corrigez la cause (espace disque, autorisations, fichier déplacé) et choisissez **Réessayer**. |
| **Fichier modifié sur le disque** | Une autre app a modifié le fichier. **Recharger** lit la nouvelle version ; **Conserver la version actuelle** garde ce que vous avez. |
| **Avertissement d’analyse** | Une ligne où une construction ne correspond probablement pas à ce que vous vouliez (chapitre 68). |
| **Remplacer le fichier existant ?** | Le nom choisi est déjà utilisé à cet endroit. |
| **Des champs restent à remplir** | Vous imprimez ou exportez avec des champs non remplis (chapitre 63). |
| **Séparateur de volets** (indication VoiceOver : « Faites glisser pour redimensionner l’éditeur et l’aperçu. Touchez deux fois pour réinitialiser. ») | La poignée entre la source et l’aperçu en mode Côte à côte. |
| **Mots : N** | Le nombre de mots dans la barre d’état. |

## Dans les dialogues et les panneaux

| Où | Message | Signification |
| --- | --- | --- |
| Palette de commandes | **Saisissez une commande** | L’indication du champ. « Aucune commande correspondante » apparaît quand rien ne convient. |
| Ouverture rapide | **Saisissez un nom de fichier** | L’indication du champ. |
| Curseurs dans une colonne | **Lignes (par exemple 3-17)**, **Colonne (par exemple 100, ou 100-105 pour sélectionner)** | Indications des champs. Une seule colonne place des curseurs ; une plage sélectionne ces caractères sur chaque ligne. |
| Panneau de recherche | **Saisissez pour rechercher dans ce dossier.**, **Aucun résultat dans ce dossier.**, **Recherche annulée.** | L’état d’une recherche dans un dossier. |
| Panneau Fichiers | **Vous pouvez aussi déposer un dossier ici.** | Faites glisser un dossier sur le panneau pour l’ouvrir. |
| Remplacer dans le dossier | **Rien à remplacer.** | La recherche n’a aucun résultat. |
| Comparer | Info-bulles sur les boutons : **Accepter** (« Appliquer cette modification au document ouvert »), **Rejeter** (« Ne pas appliquer cette modification au document ouvert »), **Reprendre** (« Remettre dans le document les lignes précédentes, pour cette modification seulement »). | Ce que fait chacun. |
| Traduire | **La traduction n’a pas pu être menée à bien.** | Réessayez, ou choisissez une autre vitesse. |
| Traduire | **Durée estimée : moins d’une minute** | Une estimation pour la vitesse de l’assistant IA ; la durée dépend de votre service d’IA. Après une traduction, **Ouvrir dans un nouvel onglet** ouvre le résultat. |
| Assistant | **Aucun document n’est ouvert.**, **Aucun texte de document n’est envoyé.** | Le panneau n’a rien à partager, donc rien n’est envoyé. |
| Sélecteur de modèle | **Chargement des modèles…**, **Aucun modèle ne correspond.** | La liste est en cours de chargement, ou votre recherche n’a rien trouvé. |
| Révision de style | **Aucun constat.** et **La réponse n’a pas pu être lue comme des constats. Réessayez.** | La révision n’a rien trouvé, ou la réponse de l’IA n’avait pas la forme attendue. |
| Révision de style | Info-bulle de **Tout appliquer** : « Applique chaque correction disponible, en une seule modification que vous pouvez annuler. » | Un seul Annuler les inverse toutes. |
| Panneau Projet | **Votre nom**, **Ajouter une variable** | L’indication du champ Auteur, et le bouton d’ajout d’une variable de projet. |
| Autorisation de l’assistant | **Lire la politique de confidentialité de Pilcrow** | Ouvre la politique de confidentialité. |
