# Chapter 55: Les menus Présentation et Fenêtre

Le menu Présentation contrôle les panneaux, le mode, la taille et l’affichage de l’éditeur. Ses raccourcis peuvent être modifiés dans **Réglages ▸ Clavier**, sauf mention contraire.

## Panneaux et mode

| Élément | Raccourci | Ce qu’il fait |
| --- | --- | --- |
| **Barre de mise en forme** | | Affiche ou masque la rangée facultative de boutons de mise en forme sous le texte. Grisé dans l’aperçu. |
| **Afficher/masquer la barre latérale** | `⇧⌘L` | Affiche ou masque tout l’encadré latéral. |
| **Plan** | `⌃⌘1` | Affiche le panneau Plan. Le choisir à nouveau masque l’encadré latéral. |
| **Fichiers** | `⌃⌘3` | Affiche le panneau Fichiers (l’arborescence des fichiers). |
| **Rechercher** | `⇧⌘F` | Affiche le panneau de recherche dans le dossier. |
| **Assistant** | `⌃⌘4` | Affiche le panneau Assistant. N’apparaît qu’une fois la connexion à un assistant configurée. |
| **Aperçu** | `⇧⌘P` | Passe à la page rendue. |
| **Côte à côte** | `⌃⌘P` | Affiche la source et l’aperçu ensemble. |
| **Mode concentration** | aucun | Masque tout sauf le texte. |

## Taille

| Élément | Raccourci |
| --- | --- |
| **Taille réelle** | `⇧⌘0` |
| **Zoom avant** | `⇧⌘=` |
| **Zoom arrière** | `⇧⌘-` |

Le zoom passe par des niveaux prédéfinis et est mémorisé. Il met à l’échelle l’éditeur et l’aperçu.

## Affichage de l’éditeur

Chacun de ces éléments est un interrupteur. Les mêmes interrupteurs se trouvent dans **Réglages ▸ Édition** (chapitre 68).

| Élément | Raccourci | Ce qu’il fait |
| --- | --- | --- |
| **Numéros de ligne** | `⌥⌘L` | Affiche les numéros de ligne dans la gouttière. |
| **Soulignement de la ligne courante** | | Trace un fin trait sous la ligne où se trouve le curseur. La couleur du trait provient du Thème de l’application. |
| **Renvoyer les lignes** | | Renvoie les longues lignes à la ligne au bord de la fenêtre. Désactivé, elles défilent latéralement. Les lignes très longues et le mode concentration sont renvoyés à la ligne dans tous les cas. |
| **Source stylisée** | | Dessine les titres, le gras et l’italique dans une police correspondante, dans l’esprit de la syntaxe, au lieu de la source brute. |
| **Masquer les marqueurs** | | Avec Source stylisée activée, masque les marques de titre, de gras et d’italique (le `#`, le `**`) sur chaque ligne sauf celle où se trouve le curseur. Grisé quand Source stylisée est désactivée. |
| **Blocs rendus** | | Dessine les tableaux, les équations et les diagrammes sous forme d’images à la place de leur source, chacun avec un bouton de modification. |
| **Repli des titres** | | Ajoute un chevron de repli dans la gouttière à côté de chaque titre, afin que sa section puisse être repliée, dans n’importe quel profil de syntaxe. |
| **Tout replier**, **Tout déplier** | | Réduit ou développe la section de chaque titre. Grisé sauf si Repli des titres est activé. |
| **Déplier automatiquement les sections** | | Ouvre une section repliée, ou un bloc dessiné sous forme d’image, quand le curseur y arrive, et la referme quand le curseur la quitte. Désactivé, les flèches haut et bas l’enjambent et elle reste telle quelle. |

## Thème

**Présentation ▸ Thème** choisit le **Thème de l’application** (Automatique, Clair, Sombre) et le **Thème de rendu** (Clair, Sombre) avec une coche. Les thèmes que vous ajoutez apparaissent aussi ici. Voir le chapitre 40.

Le système ajoute aussi **Passer en plein écran**.

## Menu Fenêtre

| Élément | Raccourci | Ce qu’il fait |
| --- | --- | --- |
| **Documents ouverts** | `⌃⌘2` | Ouvre le sélecteur de documents. |
| **Document suivant**, **Document précédent** | `⌃Tab`, `⌃⇧Tab` | Parcourt les documents ouverts. Grisé quand moins de deux sont ouverts. |

Le menu Fenêtre contient aussi les commandes de fenêtre du système, et liste chaque document ouvert par son nom. Sur iPad, ces trois éléments se trouvent à la fin du menu Présentation.

# Chapter 56: Le menu Insérer

Tout ce qui se trouve dans Insérer place du code source dans le document à l’emplacement du curseur, écrit dans la notation propre au profil de syntaxe actif. Les éléments que le profil ne peut pas exprimer sont grisés, et tous les éléments sont désactivés dans l’aperçu.

| Élément | Ce qu’il fait |
| --- | --- |
| **Tableau…** | Ouvre la boîte de dialogue Insérer un tableau (chapitre 63). Raccourci `⌥⌘T`. |
| **Image…** | Choisit une image et l’insère, en appliquant les réglages d’image (chapitre 68). Raccourci `⇧⌘I`. |
| **Diagrammes** | Un sous-menu de diagrammes Mermaid prêts à l’emploi (voir ci-dessous). |
| **Graphiques** | Un sous-menu de graphiques Vega-Lite prêts à l’emploi (voir ci-dessous). |
| **Équations** | Un sous-menu d’équations prêtes à l’emploi (voir ci-dessous). |
| **Bloc de code** | Insère un bloc de code délimité. |
| **Alerte** | Un sous-menu : **Remarque**, **Astuce**, **Important**, **Avertissement**, **Attention**. |
| **Ligne horizontale** | Insère une rupture thématique. |
| **Référence de lien** | Insère un lien de type référence et sa définition. |
| **Note de bas de page** | Insère un appel de note et sa définition. |
| **Table des matières** | Insère une ligne `[TOC]`, qui devient une liste de sommaire générée. |
| **En-tête YAML** | Insère un bloc d’en-tête en haut du fichier. |
| **Champ** | Insère un blanc à remplir pour Super Tab, sélectionné pour que vous puissiez le nommer (chapitre 24). |

En dessous, un séparateur est suivi des **constructions propres au profil actif**, telles qu’une admonition ou un bloc personnalisé que le profil définit. Si aucun profil n’est choisi, le menu indique « Sélectionnez un profil de syntaxe pour insérer des constructions ».

## Modèles de diagrammes

Insérer ▸ Diagrammes propose 17 points de départ. Chacun insère un exemple fonctionnel à modifier.

Flowchart, Sequence Diagram, Class Diagram, State Diagram, Entity Relationship Diagram, Gantt Chart, Pie, User Journey, Git Graph, Mind Map, Timeline, Quadrant Chart, Sankey Diagram, XY Chart, Block Diagram, Packet Diagram et Kanban Board.

## Modèles de graphiques

Bar Chart, Line Chart, Area Chart, Scatter Plot, Pie Chart, Stacked Bar Chart, Histogram, Heatmap et Box Plot.

## Modèles d’équations

Fraction, Square Root, Summation, Integral, Limit, Quadratic Formula, Matrix, Piecewise Function, Aligned Equations, Binomial Coefficient, Bayes' Theorem et Euler's Identity.

Sur iPad, un élément d’Insérer dont le nom existe aussi dans le sous-menu Paragraphe (Alerte, Ligne horizontale, Référence de lien, Note de bas de page, Table des matières, En-tête YAML) s’affiche comme « Insérer une alerte » et ainsi de suite, car l’iPad fusionne les éléments de menu qui portent le même nom.

# Chapter 57: Le menu Format

Le menu Format applique des styles à la sélection, ou à la ligne où se trouve le curseur, via le profil de syntaxe actif. Si le profil n’a aucun moyen d’écrire un style, l’élément est grisé avec son raccourci, de sorte qu’une commande n’insère jamais une syntaxe que le profil ne relira pas. Tous les éléments sont désactivés dans l’aperçu.

## Le bandeau de menus de l’iPad

Un iPad a sa propre barre de menus, affichée quand vous maintenez **⌘** ou déplacez un pointeur en haut de l’écran. Elle propose les mêmes commandes que les menus du Mac, issues des mêmes définitions, avec les mêmes raccourcis remappables. Seul **Fichier** est différent, car le menu Fichier du Mac utilise des panneaux AppKit.

Pour un iPad sans clavier ni souris, Pilcrow peut afficher les mêmes menus dans son en-tête. **Réglages ▸ Apparence ▸ Menus dans l’en-tête** permet de choisir :

| Choix | Effet |
| --- | --- |
| **Automatique** | Affiche les menus sauf si un clavier ou une souris est connecté. |
| **Toujours** | Les affiche toujours. |
| **Jamais** | Ne les affiche jamais. |

Dans une fenêtre de 1 100 points de large ou plus, les six menus se placent côte à côte : **Fichier**, **Modifier**, **Insérer**, **Format**, **Présentation** et **Aide**. Dans une fenêtre plus étroite, ils se regroupent en un seul bouton **Menu**. Le bandeau est une version allégée de la barre de menus :

- **Fichier** ajoute **Ouvrir un dossier…**, **Exporter…** et **Imprimer…** aux éléments habituels.
- **Modifier** comprend **Annuler**, **Rétablir**, les commandes de copie, **Rechercher**, **Orthographe et grammaire**, **Sélection**, **Traduire**, **Aller à la ligne…**, **Vérifier les liens…**, **Palette de commandes…**, **Précédent** et **Suivant**.
- **Format** comprend les styles en ligne, le sous-menu **Paragraphe**, **Insérer un tableau…** et **Insérer une image…**.
- **Présentation** comprend **Barre de mise en forme**, **Afficher/masquer la barre latérale**, **Plan**, **Fichiers**, **Rechercher**, le mode du document, **Concentration**, **Numéros de ligne**, **Soulignement de la ligne courante**, **Source stylisée**, **Repli des titres** et **Documents ouverts**. Pour les autres interrupteurs d’affichage, utilisez **Plus** ou les Réglages.
- **Aide** comprend **Aide Pilcrow**, **Signaler un bug…** et **Terminer le rapport de bug**.

# Part XVII — Panneaux, barres et boîtes de dialogue

# Chapter 59: Le titre du document et le sélecteur de documents

Le nom du document se trouve dans l’en-tête avec un petit point coloré et une flèche vers le bas. Cliquez dessus, ou choisissez **Fenêtre ▸ Documents ouverts** (`⌃⌘2`), pour ouvrir la liste **Documents ouverts**. Sur un petit écran, elle s’ouvre sous forme de feuille avec un bouton **OK**.

## Le point d’enregistrement

Le point à côté du nom vous indique d’un coup d’œil l’état du document. L’état est aussi lu à voix haute par VoiceOver.

| Point | Signification |
| --- | --- |
| Vert | **Enregistré.** Le fichier sur le disque correspond à ce que vous voyez. |
| Orange | **Modifié.** Vous avez des modifications qui ne sont pas encore enregistrées. |
| Rouge | **Échec de l’enregistrement.** Pilcrow a essayé d’enregistrer sans y parvenir. Une bannière **Enregistrement impossible** avec un bouton **Réessayer** apparaît au-dessus de l’éditeur. |
| Bleu | **Modifié par une autre app.** Le fichier sur le disque a été modifié depuis l’extérieur de Pilcrow. |

Un document qui n’a jamais été enregistré affiche « Pas encore enregistré » et un numéro dans la liste, puisqu’il n’a pas de dossier à afficher. Un document avec des modifications non enregistrées indique aussi **Modifié** à la fin de sa ligne.

## La liste Documents ouverts

| Élément | Ce qu’il fait |
| --- | --- |
| **Rechercher dans les documents ouverts** | Apparaît quand sept documents ou plus sont ouverts. Saisissez une partie d’un nom ou d’un dossier ; chaque mot doit correspondre quelque part dans le nom ou le dossier, sans tenir compte de la casse ni des accents. Retour ouvre la première correspondance. Quand rien ne correspond, il affiche « Aucun document ouvert ne correspond. » |
| Une ligne par document | Affiche le nom, son point d’enregistrement et le dossier où il se trouve. Une coche marque le document actif. Cliquez sur une ligne pour y basculer. |
| **Fermer** (le **x** au bout d’une ligne) | Ferme ce document, en demandant d’abord confirmation s’il a des modifications non enregistrées. |
| **Nouveau document** | Crée un document sans titre. |
| **Enregistrer** | Enregistre le document actif. |
| **Enregistrer sous…** | Enregistre sous un nouveau nom ou à un nouvel endroit. |
| **Renommer…** | Ouvre le formulaire de renommage (voir ci-dessous). |
| **Fermer tous les documents** | Ferme tous les documents, en demandant confirmation pour chacun de ceux qui ne sont pas enregistrés. |

Utilisez `⌃Tab` et `⌃⇧Tab` pour passer au document suivant ou précédent sans ouvrir la liste.

## Renommer

**Renommer…** affiche le **Nom** actuel et l’**Emplacement** du fichier, avec les boutons **Annuler** et **Renommer**. Le renommage modifie le fichier sur le disque et garde le document ouvert. Si le nouveau nom est inutilisable, un message **Impossible de renommer le document** en explique la raison.
