# Chapter 72: Clavier

**Réglages ▸ Clavier ▸ Raccourcis** liste toutes les commandes dont vous pouvez modifier le raccourci, avec leur touche actuelle.

| Contrôle | Ce qu’il fait |
| --- | --- |
| La ligne d’une commande | Cliquez dessus, appuyez sur le nouveau raccourci, puis choisissez **Enregistrer**. **Dissocier** supprime le raccourci. **Annuler** conserve l’ancien. Si le raccourci était déjà utilisé par une autre commande, celle-ci est effacée et la page vous indique laquelle. |
| **Touches Super Tab** | Les touches de **Champ suivant** et **Champ précédent**, qui sautent d’un blanc à l’autre laissé par une macro : `⌥Tab` et `⌥⇧Tab`, ou `⌃⌘]` et `⌃⌘[`, ou **Personnalisé**. |
| **Réinitialiser tous les raccourcis** | Rétablit toutes les valeurs par défaut. |

| --- | --- |

| Emphase | `⌘I` |

# Chapter 73: Abonnement et crédits

Toutes les fonctions de Pilcrow sont gratuites. Soutenir Pilcrow est facultatif : cela aide à financer le développement et vous donne des votes sur ce qui sera développé ensuite. Les votes orientent l’ordre du travail, mais ne garantissent aucune fonction.

La page **Soutenir Pilcrow** contient :

| Partie | Ce qu’elle montre ou fait |
| --- | --- |
| **Vos votes** | **Depuis votre abonnement** (les votes de ce mois payé, avec leur date d’expiration) et **Achetés** (des votes qui n’expirent jamais). Les votes de l’abonnement sont utilisés en premier et expirent à la fin du mois payé. |
| **Obtenir des votes** | L’abonnement et les votes à l’unité que vous pouvez acheter. Pilcrow Supporter se renouvelle chaque mois jusqu’à ce que vous le résiliez dans les réglages de votre compte Apple. Chaque mois payé vous donne des votes. |
| **Restaurer les achats** | Rétablit les achats effectués sur un autre appareil. |
| **Conditions d’utilisation**, **Politique de confidentialité** | Des liens. |
| **Icône de l’app** | Un choix d’icônes de l’app pour les abonnés. Les icônes d’un cycle de vote s’obtiennent en s’abonnant pendant ce cycle, et sont conservées. Sur Mac, l’icône change dans le Dock tant que Pilcrow est ouvert. |
| **Feuille de route** | Le cycle de fonctions actuellement ouvert au vote, avec les compteurs « Votes » et « Les vôtres » et un bouton **Voter** pour chacune. Chaque vote utilise un de vos votes et ne peut pas être repris. Entre deux cycles, la page indique quand le suivant ouvre. |

Si les options de soutien ne sont pas disponibles dans une version donnée, la page l’indique.
