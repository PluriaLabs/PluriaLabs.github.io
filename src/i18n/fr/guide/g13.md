# Chapter 75: Les éditeurs de thèmes

Il existe deux sortes de thèmes, et chacune a son propre éditeur. Ouvrez l’un ou l’autre depuis **Réglages ▸ Bibliothèque ▸ Thèmes** : **Nouveau** crée un thème, **Modifier** change un thème personnalisé, et **Dupliquer** copie un thème intégré afin que vous puissiez modifier la copie. Les thèmes intégrés ne peuvent pas être modifiés.

## L’éditeur de thème de rendu

**Modifier le thème de rendu** met en forme l’aperçu et les sorties HTML, PDF, image et impression. Ses propriétés personnalisées Pilcrow définissent aussi les styles Word. Un thème de rendu ne met en forme ni l’application ni l’éditeur.

| Élément | Ce qu’il fait |
| --- | --- |
| **Nom** | Le nom du thème. |
| **Apparence** | **Automatique**, **Clair** ou **Sombre**. |
| **CSS** | La feuille de style, dans un éditeur de code. Voir le chapitre 80 pour les propriétés et les classes. |
| **Aperçu rendu** | Un document modèle dessiné avec votre CSS au fil de la frappe, pour que vous voyiez l’effet. |
| **Diagnostics CSS** | Les problèmes que Pilcrow a trouvés dans le CSS, comme une ressource distante non autorisée. |
| **Annuler**, **Enregistrer** | Ferment ou conservent le thème. Fermer avec des modifications demande **Ignorer les modifications du thème ?** avec **Ignorer les modifications** ou **Continuer la modification**. |
| **Référence** | **Revenir à la référence** annule toutes les modifications faites depuis la création, la duplication ou l’importation du thème (après confirmation). **Définir comme nouvelle référence** enregistre le thème et fait de son état actuel le point de restauration. |

## L’éditeur de thème de l’application

**Modifier le thème de l’application** met en forme Pilcrow lui-même : son apparence, sa couleur d’accent, l’encadré latéral, les barres et l’éditeur.

| Élément | Ce qu’il fait |
| --- | --- |
| **Nom** | Le nom du thème. |
| **Apparence** | **Automatique**, **Clair** ou **Sombre**. Un thème automatique a deux palettes. |
| **Modification des couleurs pour** | Pour un thème automatique, **Clair** ou **Sombre** : laquelle de ses deux palettes vous modifiez. |
| Couleurs, en cinq groupes | **App** (l’accent), **Encadré latéral** (arrière-plan et premier plan), **Barres d’état et de mise en forme** (arrière-plan et premier plan), **Éditeur** (arrière-plan, premier plan, curseur, sélection, arrière-plan de la gouttière, premier plan de la gouttière, soulignement de la ligne courante) et **Syntaxe** (titre, marqueur, code, lien, atténué, ainsi que mot-clé, chaîne, nombre et commentaire du code). Chaque couleur affiche **Par défaut** tant que vous n’en choisissez pas une, et un bouton **Réinitialiser** la remet à sa valeur d’origine. |
| **Aperçu** | Une miniature de Pilcrow, avec une barre latérale, un éditeur et une barre d’état, dans les couleurs que vous avez choisies, en clair ou en sombre. |
| **Annuler**, **Enregistrer**, **Référence** | Comme ci-dessus. |

Un thème peut aussi colorer des jetons de syntaxe individuels. Ces couleurs sont conservées, mais se modifient dans le fichier JSON du thème (`syntax.tokens`) ; voir le chapitre 79.

# Chapter 76: L’éditeur de macros

Ouvrez l’éditeur de macros depuis **Réglages ▸ Bibliothèque ▸ Macros** : **Nouveau** dans une collection, ou **Modifier** sur une macro. Son titre est **Nouvelle macro** ou **Modifier la macro**.

| Champ | Ce qu’il fait |
| --- | --- |
| **Nom** | Un libellé pour la macro. |
| **Déclencheur** (par exemple `/sig`) | Le texte qui la déclenche. Une macro se développe quand vous tapez le déclencheur suivi d’un espace, d’une tabulation ou d’un retour. |
| **Correspondance** | La façon dont le déclencheur est interprété : **Texte exact**, **Préfixe** ou **Expression régulière**. Une expression régulière susceptible de bloquer l’éditeur est refusée : « Cette expression régulière pourrait bloquer l’éditeur. Simplifiez-la. » |
| **Remplacement** | Le texte en lequel elle se développe. |
| **Insérer la date/l’heure** | Un menu qui ajoute au remplacement un jeton de date ou d’heure. |
| **Activé** | Active ou désactive la macro sans la supprimer. |
| **Ne pas développer dans le code** | Empêche la macro de se déclencher dans les portions de code et les blocs de code. |
| **Annuler**, **Enregistrer** | Ferment ou conservent la macro. Si elle ne peut pas être enregistrée, le message en donne la raison. |

Dans le remplacement, `$1`, `$2` et ainsi de suite sont des points de tabulation, et `$0` est l’endroit où le curseur se place. Après le développement d’une macro, Tab (ou **Champ suivant**) passe d’un point à l’autre. Les dates et les heures utilisent des jetons : `{{date:yyyy-MM-dd}}`, `{{time:HH:mm:ss}}` et `{{datetime:MM/dd/yyyy h:mm a}}`, ainsi que les formats nommés `iso8601`, `rfc2822`, `unix`, `short`, `medium`, `long` et `full`. Une ligne **Maintenant :** sous le champ montre ce que produirait le remplacement à cet instant.

# Chapter 78: Utiliser Pilcrow sur iPad

Pilcrow fonctionne sous iPadOS 17 ou version ultérieure. Il se commande au toucher seul, avec un clavier externe, et avec un trackpad ou une souris.

## Toucher

- **Séparateur de volets.** En mode Côte à côte, faites glisser le séparateur entre la source et l’aperçu pour les redimensionner. Touchez-le deux fois pour le réinitialiser.
- **Navigateur.** Faites glisser le bord de la barre latérale pour la redimensionner. Dans une fenêtre étroite, la barre latérale recouvre le document et un bouton **OK** la ferme.
- **Sélection en colonne.** Activez **Plus ▸ Sélection en colonne**, puis faites glisser un doigt pour sélectionner un rectangle de texte. Deux doigts font toujours défiler. Un badge **Sélection en colonne** s’affiche tant que le mode est activé, avec un bouton pour le désactiver. Ou utilisez **Plus ▸ Curseurs dans une colonne…** pour placer les curseurs par nombre.
- **Le menu contextuel.** Maintenez le doigt appuyé dans le texte pour afficher le menu de l’éditeur (ci-dessous).
- **Fichiers.** Maintenez le doigt appuyé sur un fichier dans le panneau Fichiers pour afficher son menu (chapitre 60).

## Avec un clavier externe

Tous les raccourcis du chapitre 77 fonctionnent. Maintenez **⌘** pour voir la barre de menus de l’iPad, ou déplacez un pointeur vers le haut de l’écran. Pilcrow peut masquer ses propres menus d’en-tête lorsqu’un clavier ou une souris est connecté ; voir **Réglages ▸ Apparence ▸ Menus dans l’en-tête**.

## Avec un trackpad ou une souris

Le clic droit ouvre le menu contextuel de l’éditeur. Maintenez **Option** pendant le glissement pour sélectionner un rectangle de texte.

## Le menu contextuel de l’éditeur

Clic droit sur Mac, ou appui prolongé sur iPad, dans le texte. Les éléments que le profil de syntaxe actif ne peut pas exprimer sont grisés, et le système ajoute ses propres éléments (Couper, Copier, Coller, suggestions orthographiques, Recherche et ainsi de suite).

Sur **Mac** :

| Élément | Ce qu’il fait |
| --- | --- |
| **Copier / Coller comme…** | **Copier comme Markdown**, **Copier comme texte brut**, **Copier comme code HTML**, **Coller comme texte brut**. |
| **Paragraphe** | **Paragraphe**, **Titre 1** à **6**, **Citation**, **Liste à puces**, **Liste numérotée**, **Liste de tâches**, **Bloc de code**. |
| **Format** | **Gras**, **Emphase**, **Code**, **Barré**, **Formule en ligne**, **Formule centrée**, **Diagramme**, **Graphique**, **Lien hypertexte**. |
| **Sélection** | **Sélectionner le mot**, **Sélectionner la ligne**, **Sélectionner le paragraphe**. |

Sur **iPad**, trois sous-menus accompagnent les éléments du système :

| Élément | Ce qu’il fait |
| --- | --- |
| **Format** | Les styles en ligne : gras, emphase, code et le reste. |
| **Paragraphe** | Les types de paragraphe : titres, citation, listes, bloc de code. |
| **Insérer** | Les mêmes insertions que le menu **Plus** de la barre d’outils de mise en forme, dont **Insérer une alerte**, **Insérer une image…** et **Insérer un tableau…**, et, sous **Syntaxe**, les constructions propres au profil actif. |

## Différences avec le Mac

| Sur iPad | Sur Mac |
| --- | --- |
| Les réglages s’ouvrent depuis l’engrenage de l’en-tête, dans une feuille. | **Pilcrow ▸ Réglages…** (`⌘,`). |
| L’en-tête peut afficher les menus propres à Pilcrow (**Menus dans l’en-tête**). | La barre de menus est celle du système. |
| **Taille de l’interface** définit la taille des menus, des barres et des dialogues. | Non disponible. |
| L’importation se trouve dans **Réglages ▸ Bibliothèque ▸ Importer**. | **Fichier ▸ Importer**. |
| Pas de Tout enregistrer, Dupliquer, Déplacer vers, Recharger depuis le disque, Afficher dans le Finder ni Mise en page. | Ces éléments se trouvent dans le menu Fichier. |
| **Édition ▸ Orthographe et grammaire** ne comporte qu’un élément, **Vérifier l’orthographe pendant la frappe**. | **Édition ▸ Orthographe et grammaire** comporte aussi **Afficher l’orthographe et la grammaire** et **Vérifier le document maintenant**. |
| Les sons de frappe sont coupés par le commutateur silencieux de l’iPad. | Sans objet. |
