# Chapter 60: La barre latérale

La barre latérale contient cinq panneaux : **Fichiers**, **Plan**, **Rechercher**, **Projet** et **Assistant IA**. Un sélecteur en haut de la barre latérale choisit **Fichiers**, **Plan**, **Projet** (affiché quand le dossier ouvert est un projet de livre) ou **Assistant IA** (affiché dès qu’une connexion est configurée). **Rechercher** a son propre en-tête avec le titre **Rechercher**, un bouton **OK** qui ramène à Fichiers, et un contrôle de portée pour **Ce document** ou **Dossier** ; accédez-y par **Présentation ▸ Rechercher** (`⇧⌘F`). Le menu **Présentation** permet aussi de changer de panneau, et choisir le panneau déjà affiché masque la barre latérale. Faites glisser le bord de la barre latérale pour la redimensionner. Au-dessus de l’arborescence des fichiers, un menu propose **Ouvrir un fichier…** et **Ouvrir un dossier…**.

## Fichiers

Le panneau Fichiers est une arborescence du dossier ouvert.

Quand aucun dossier n’est ouvert, il indique « Choisissez un dossier pour parcourir ses fichiers. » et propose **Ouvrir un dossier** et **Ouvrir un fichier**. Vous pouvez aussi y déposer un dossier. Quand vous avez ouvert un seul fichier dont Pilcrow ne peut pas voir le dossier, il propose « Parcourir *dossier* pour voir les fichiers à côté de ce document », avec **Parcourir le dossier contenant…**.

Cliquez sur un fichier pour l’ouvrir. Les dossiers se déplient et se replient. Faites un clic droit sur une ligne, ou un appui prolongé sur iPad, pour afficher son menu :

| Élément | Ce qu’il fait |
| --- | --- |
| **Nouveau fichier** | Crée un fichier dans le dossier (ou à côté du fichier sur lequel vous avez cliqué). |
| **Nouveau dossier** | Y crée un dossier. |
| **Renommer…** | Renomme le fichier ou le dossier. |
| **Placer dans la corbeille** | Le place dans la corbeille après confirmation. Vous pouvez l’y reprendre. |
| **Afficher dans le Finder** | L’affiche dans le Finder (Mac). |

Lorsque le système n’a pas de corbeille pour un emplacement, Pilcrow conserve les éléments supprimés dans une section **Suppressions récentes** au bas du panneau. Chaque élément y propose **Remettre** et **Supprimer définitivement**, et **Vider Suppressions récentes** supprime pour de bon tous les éléments de la section. La suppression définitive est irréversible, donc Pilcrow demande d’abord confirmation. Les éléments supprimés ailleurs ne sont pas affectés.

Les fichiers et dossiers masqués sont affichés ou masqués par **Réglages ▸ Fichiers ▸ Afficher les dossiers et fichiers masqués**.

## Plan

Le Plan liste les titres du document actif, en retrait selon leur niveau. Cliquez sur un titre pour y aller. Un chevron à côté d’un titre replie ou déplie les titres qui en dépendent. Cela ne modifie pas le document, et l’état replié n’est pas enregistré.

États que vous pouvez voir :

| Message | Signification |
| --- | --- |
| **Aucun titre** | Le profil actif n’a trouvé aucun titre. |
| **Indexation du plan… N %** | Un grand document est encore en cours d’analyse. |
| **L’indexation du plan a échoué. La liste peut être incomplète.** | L’analyse a rencontré un problème. |
| **N titres près de votre position — faites défiler pour voir les autres.** | Un très grand document affiche une fenêtre de son plan autour du curseur. |

Sous le plan, une section **Champs** apparaît quand le document contient des champs à remplir (chapitre 24). Elle les liste, avec leur nombre ; cliquez sur l’un d’eux pour y faire défiler le document et le sélectionner. Quand le nombre de champs est très grand, elle indique « Seuls les premiers champs sont listés. »

## Rechercher

Le panneau Rechercher cherche dans tous les fichiers du dossier ouvert. Sans dossier, il indique « Ouvrez un dossier pour le parcourir. » avec un bouton **Ouvrir un dossier…**.

| Contrôle | Ce qu’il fait |
| --- | --- |
| Champ **Rechercher dans le dossier** | Tapez pour chercher au fur et à mesure. Un bouton **effacer** le vide. |
| **Aa** | **Respecter la casse.** |
| **ab** | **Mot entier.** |
| **.\*** | **Expression régulière.** Un motif incorrect est signalé sous le champ. |
| Ligne d’état | Affiche « Recherche… » avec un bouton **Annuler**, puis « Correspondances : N ». Une recherche s’arrête à 500 correspondances et indique « Affichage des 500 premières correspondances. » Après une annulation, elle propose **Rechercher à nouveau**. |
| **Remplacer…** | Apparaît quand la recherche trouve des correspondances. Ouvre Remplacer dans le dossier (chapitre 63). |
| Résultats | Chaque résultat indique le fichier et affiche la ligne. Cliquez sur l’un d’eux pour ouvrir le fichier à cette ligne. |

## Projet

Le panneau Projet est destiné aux projets de livre. Voir le chapitre 34, le chapitre 35 et la référence du panneau Projet ci-dessous.

### Référence du panneau Projet

| Élément | Ce qu’il fait |
| --- | --- |
| **Ce dossier n’est pas un projet de livre.** avec **En faire un projet** | Affiché quand le dossier ouvert n’a pas de manifeste. |
| **Réessayer** | Affiché si le projet n’a pas pu être lu. |
| **Présentation** | Choisit **Liste**, **Synopsis** ou **Cartes**. |
| Titre, totaux de mots | Le nom du projet et « N mots », ou « N sur l’objectif » quand un objectif de mots du livre est défini. |
| Filtre **Statut** | Filtre sur un seul statut, ou **Tous les statuts**. Un décompte liste chaque statut avec son nombre de fichiers et de mots. La réorganisation n’est possible que lorsqu’aucun filtre n’est actif. |
| **Réglages du projet** (engrenage) | Ouvre la feuille de réglages ci-dessous. |
| **Compiler…** | Ouvre la feuille de compilation (chapitre 64). |
| **Réorganiser** et **OK** | Sur iPad, faites glisser les chapitres dans un nouvel ordre, puis choisissez **OK**. |
| **Nouveau fichier** (plus) | Propose **Nouveau chapitre**, **Nouvelle scène**, **Nouvelles pages liminaires**, **Nouvelles pages finales**. |
| **Pas dans le manuscrit** avec **Ajouter** et **Tout ajouter** | Liste les fichiers du dossier que le manifeste n’inclut pas. |
| Le chevron d’une ligne | **Afficher les scènes** ou **Masquer les scènes** sous un chapitre. |
| Étiquettes **Introuvable** et **Exclu** | Un fichier introuvable, ou que vous avez exclu du manuscrit. |
| Le menu d’une ligne | **Détails…**, **Nouveau fichier en dessous**, **Monter le chapitre**, **Descendre le chapitre**, **Inclure dans le manuscrit**, **Exclure du manuscrit**. |
| **Objectif de mots** par élément | Chaque élément affiche son nombre de mots et son éventuel objectif. |

Les **Détails** d’un élément comprennent **Type** (Pages liminaires, Partie, Chapitre, Scène, Pages finales), **Statut**, **Point de vue**, **Emplacement**, **Objectif de mots** et **Synopsis**. Un fichier de projet modifié sur le disque affiche « Le fichier du projet a changé sur le disque, donc votre dernière modification n’a pas été appliquée. Faites-la de nouveau. » avec **Ignorer**.

Les **Réglages du projet** comprennent **Titre**, **Auteur**, **Objectif de mots du livre**, **Les nouveaux fichiers sont rédigés en** (la syntaxe des nouveaux chapitres et scènes ; les fichiers existants gardent la leur), **Variables** (un nom et une valeur, écrits `{{name}}` dans votre texte ; `{{title}}` et `{{author}}` fonctionnent toujours), et **Ce qui compte comme un mot** : **Compter les titres**, **Compter les pages liminaires**, **Compter les blocs de code**. Choisissez **Enregistrer** ou **Annuler**.

## Assistant IA

Le panneau Assistant IA apparaît dès qu’une connexion est configurée (chapitre 65).

# Chapter 61: La barre de mise en forme et la barre d’état

## La barre de mise en forme

La barre de mise en forme est une rangée facultative sous le texte. Affichez-la ou masquez-la avec **Présentation ▸ Barre de mise en forme**, **Plus ▸ Barre de mise en forme**, **Réglages ▸ Édition ▸ Barre de mise en forme**, ou avec l’élément **Masquer la barre d’outils** de la barre elle-même. Elle agit par le profil actif ; un bouton que le profil ne peut pas exprimer est grisé.

| Contrôle | Ce qu’il fait |
| --- | --- |
| Menu **Type de paragraphe** (par exemple « Paragraphe » ou « Titre 1 ») | Affiche le type de la ligne courante et le modifie : **Paragraphe**, **Titre 1** à **6**, **Citation**, **Liste à puces**, **Liste numérotée**, **Liste de tâches**, **Bloc de code**. |
| **Gras** (`⌘B`) | Gras. |
| **Italique** (`⌘I`) | Emphase. |
| **Code en ligne** | Code. |
| **Insérer un lien** (`⌘K`) | Crée un lien. |
| **Citation** | Active ou désactive une citation. |
| **Liste à puces** | Active ou désactive une liste à puces. |
| **Plus de mise en forme** (**⋯**) | Les commandes plus rares : **Barré**, **Insérer une formule en ligne**, **Insérer une liste de tâches**, **Basculer l’état de la tâche**, **Augmenter le retrait**, **Réduire le retrait**, **Augmenter le niveau de titre**, **Diminuer le niveau de titre**, **Insérer un tableau…**, **Insérer une image…**, **Insérer un diagramme**, **Insérer un graphique**, **Insérer une formule centrée**, **Insérer un bloc de code**, **Insérer une alerte**, **Insérer une ligne horizontale**, **Insérer une référence de lien**, **Insérer une note de bas de page**, **Insérer une table des matières**, **Insérer un en-tête YAML**, et **Masquer la barre d’outils**. |

## La barre d’état

La barre d’état s’étend le long du bas. Activez-la ou désactivez-la avec **Réglages ▸ Édition ▸ Afficher la barre d’état**.

| Élément | Ce qu’il affiche ou fait |
| --- | --- |
| **Mots**, **Lgn**, **Col** | Le nombre de mots, ainsi que la ligne et la colonne du curseur. Avec une sélection, elle ajoute « Sél : N lgn · N car. » pour les lignes et caractères sélectionnés. |
| Menu **Syntaxe** (par exemple « CommonMark ») | Le profil de ce document. Cliquez pour en choisir un autre, ou **Aucune syntaxe** pour du texte brut. |
| **Champs restants : N** | Affiché quand une macro a laissé des champs à remplir. Cliquez dessus pour aller au champ suivant. |
| Progression et état | **Indexation N %**, **Analyse lexicale N %** pendant l’analyse d’un gros fichier, et **Traduction N %** avec **Environ N restantes** et un bouton **Annuler la traduction** pendant qu’une traduction s’exécute. |
| **Désynchronisé** | Un avertissement indiquant que l’éditeur et le journal des modifications du document ont divergé. L’enregistrement laisse le fichier marqué comme non enregistré afin que rien ne soit perdu : copiez votre texte en lieu sûr, puis fermez et rouvrez le document. |
| Informations sur le document | Cliquez sur les totaux, ou sur l’info-bulle « Afficher les informations sur le document », pour ouvrir **Informations sur le document**. |

**Informations sur le document** liste **Mots**, **Caractères**, **Lignes**, **Temps de lecture** (d’après votre vitesse de lecture dans les Réglages), **Curseur**, **Sélection**, **Encodage** et **Syntaxe**. Dans un très gros fichier, les totaux concernent la partie chargée jusqu’à la fin de l’indexation, et le temps de lecture est estimé pour le fichier entier. **Convertir en…** sous **Encodage** choisit un autre encodage de texte ; le fichier est converti à son prochain enregistrement.


# Chapter 62: Rechercher, remplacer, Aller à la ligne, Ouverture rapide et palette de commandes

## La barre de recherche

Ouvrez-la avec **Rechercher…** (`⌘F`), le bouton **Rechercher**, ou **Remplacer…** (`⌘R`). Elle se place en haut du document.

| Contrôle | Ce qu’il fait |
| --- | --- |
| Champ **Rechercher dans le document** | Tapez le texte à trouver. Les correspondances sont surlignées au fur et à mesure de la saisie. |
| **Aa**, **ab**, **.\*** | **Respecter la casse**, **Mot entier**, **Expression régulière**. |
| **Occurrence précédente**, **Occurrence suivante** | Parcourent les correspondances (`⇧⌘G`, `⌘G`). |
| **Afficher le remplacement** / **Masquer le remplacement** (chevron) | Affiche le champ **Remplacer par**. |
| **Remplacer**, **Tout remplacer** | Remplace la correspondance courante, ou toutes les correspondances. Grisé tant qu’il n’y a pas de correspondance. |
| **Rechercher dans** (un sélecteur à l’extrémité gauche de la barre) | **Ce document**, ou **Dossier** pour chercher plutôt dans tout le dossier ouvert. |
| **Fermer la barre de recherche** | La ferme. |

Quand il y a plus de correspondances que Pilcrow n’en compte, la barre indique « D’autres correspondances restent ». Dans **Aperçu**, Rechercher parcourt les mots affichés et les surligne, jusqu’à 2 000 correspondances. Un motif inutilisable indique « Motif non valide ». Le remplacement n’est disponible qu’en mode Modifier : dans l’Aperçu, la barre indique « Le remplacement fonctionne en mode Modifier. Passez en mode Modifier pour changer le texte. » En mode **Côte à côte**, Rechercher parcourt la source et surligne les mots correspondants dans l’aperçu.

## Aller à la ligne

**Aller à la ligne…** (`⌃G`) ouvre une petite feuille avec un seul champ, « Numéro de ligne, ou ligne:colonne ». Tapez `120` ou `120:8` et choisissez **Aller**, ou **Annuler**. Un numéro au-delà de la fin mène à la dernière ligne. Pilcrow indique « Saisissez un numéro de ligne, par exemple 120 ou 120:8. » pour toute autre saisie. Dans un très gros fichier dont les lignes sont encore en cours de comptage, il vous demande de réessayer dans un instant.

## Ouverture rapide

**Ouverture rapide…** (`⇧⌘O`) est une recherche de noms de fichiers dans le dossier ouvert. Tapez une partie d’un nom, et la liste se restreint et affiche « N correspondances ». Choisissez un résultat puis **Ouvrir**, ou **Annuler**. Elle est grisée sans dossier ouvert.

## La palette de commandes

**Palette de commandes…** (`⌃⇧P`) liste les commandes de Pilcrow par nom, avec leurs raccourcis, afin d’en exécuter une sans chercher son menu. Tapez pour restreindre la liste, choisissez une commande puis **Exécuter**, ou **Annuler**. Elle affiche « Aucune commande correspondante » quand rien ne convient. Une commande qui ne peut pas s’exécuter pour le moment, par exemple une modification de la source pendant que vous êtes dans l’Aperçu, apparaît grisée. La liste comprend les commandes de mise en forme et d’insertion, les commandes Modifier pour la sélection, les lignes et la casse, la parole, les commutateurs de Présentation, le zoom et les panneaux de la barre latérale, ainsi que les actions de fichier et d’export. Le raccourci d’ouverture de la palette peut être modifié dans **Réglages ▸ Clavier**.
