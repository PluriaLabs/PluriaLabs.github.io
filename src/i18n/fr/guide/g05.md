# Part XVI — Référence de la fenêtre et des menus

# Chapter 52: La fenêtre en un coup d’œil

Ce chapitre nomme chaque commande de la fenêtre de Pilcrow, de gauche à droite, sur Mac et sur iPad. Les chapitres suivants de cette partie décrivent chaque élément de menu, et la partie XVII décrit chaque panneau et chaque boîte de dialogue.

## La barre d’en-tête

L’en-tête s’étend en haut de la fenêtre. Ses commandes, dans l’ordre :

| Commande | Où | Ce qu’elle fait |
| --- | --- | --- |
| **Navigateur** (icône de la barre latérale) | Mac et iPad | Affiche ou masque l’encadré latéral. Son infobulle indique « Afficher ou masquer le navigateur ». Identique à **Présentation ▸ Afficher/masquer la barre latérale**. |
| **Titre du document** | Mac et iPad | Affiche le nom du document actif, avec un point qui indique s’il est enregistré. Cliquez dessus pour ouvrir le sélecteur de documents et les actions du document (chapitre 59). |
| **Bouton de menu** ou bandeau de menus | iPad uniquement | Les menus du Mac, dans l’en-tête, pour un iPad sans clavier ni souris (chapitre 58). |
| **Mode du document** (Modifier, Aperçu, Côte à côte) | Mac et iPad | Bascule entre la source, la page rendue, et les deux côte à côte. « Split » correspond à **Côte à côte**. |
| **Rechercher** (loupe) | Mac et iPad | Ouvre la barre de recherche (chapitre 62). |
| **Exporter** (icône de partage) | Mac et iPad | Ouvre le panneau d’exportation (chapitre 64). |
| **Réglages** (engrenage) | iPad uniquement | Ouvre les Réglages dans une feuille. Sur Mac, les Réglages se trouvent dans le menu **Pilcrow** (**⌘,**). |
| **Plus** (trois points) | Mac et iPad | Regroupe les actions qui ne tiennent pas dans la barre. Voir ci-dessous. |

Rechercher, Exporter et le contrôle de mode n’apparaissent que lorsqu’un document est ouvert.

### Comment l’en-tête s’adapte à la largeur

L’en-tête est conçu pour rester utilisable dans une fenêtre étroite, comme une fenêtre de Mac placée à côté d’une autre app ou un iPad en Split View. À mesure que la fenêtre se rétrécit, les commandes passent dans le menu **Plus** dans cet ordre :

| Largeur de la fenêtre | Ce que vous voyez |
| --- | --- |
| 720 points ou plus | Le contrôle Modifier/Aperçu/Côte à côte, **Rechercher**, **Exporter** et **Plus**. |
| 600 à 719 | **Rechercher** passe dans **Plus**. |
| 500 à 599 | **Exporter** passe aussi dans **Plus**. |
| Moins de 500 | Le contrôle de mode devient un seul bouton dont l’icône indique le mode actuel (crayon, œil ou deux volets). Cliquez dessus pour choisir. |

Sur iPad, le contrôle de mode devient le bouton compact en dessous de 580 points. Le titre se réduit toujours en premier, entre 140 et 520 points de large, afin que les boutons restent en place. Avec des tailles de texte d’accessibilité plus grandes, les largeurs de fenêtre ci-dessus sont d’abord divisées par 1,3, de sorte que les commandes passent dans **Plus** alors que la fenêtre est encore plus large.

### Le menu Plus

Ce que propose **Plus** dépend du mode et de la plateforme. Les éléments qui ne s’affichent que lorsque la source est visible (Modifier ou Côte à côte) sont signalés ci-dessous.

| Élément | Quand il apparaît | Ce qu’il fait |
| --- | --- | --- |
| **Rechercher…** | Seulement quand la barre n’a pas de bouton Rechercher | Ouvre la barre de recherche. |
| **Remplacer…** | Source visible | Ouvre la recherche avec le champ de remplacement. |
| **Aller à la ligne…** | Source visible | Saute à une ligne, ou à une ligne et une colonne. |
| **Curseurs dans une colonne…** | iPad, source visible | Place des curseurs en colonne selon un nombre (chapitre 63). |
| **Sélection en colonne** | iPad, source visible | Un interrupteur. Tant qu’il est activé, un glissement à un doigt sélectionne un rectangle de texte. |
| **Partager…** | Un document est ouvert | Partage le fichier du document via la feuille de partage du système. |
| **Exporter…** | Seulement quand la barre n’a pas de bouton Exporter | Ouvre le panneau d’exportation. |
| **Concentration** | Toujours | Un interrupteur pour le mode concentration (voir plus bas). |
| **Repli des titres**, **Blocs rendus**, **Déplier automatiquement les sections**, **Masquer les marqueurs**, **Source stylisée**, **Barre de mise en forme** | Source visible | Les mêmes interrupteurs d’affichage que dans le menu Présentation (chapitre 55). **Masquer les marqueurs** est grisé sauf si **Source stylisée** est activé. |
| **Ouvrir un fichier…**, **Ouvrir un dossier…** | iPad | Ouvrent un fichier ou un dossier quand la barre latérale est fermée. |
| **Imprimer…** | iPad | Imprime le document rendu. |
| **Réglages…**, **Aide** | iPad | Ouvrent les Réglages ou l’aide intégrée. |

## La zone de travail

Sous l’en-tête se trouvent l’éditeur, l’aperçu, ou les deux. Sous l’éditeur, lorsqu’elles sont activées, se trouvent la **barre de mise en forme** et la **barre d’état** (chapitre 61). Une image ou une vidéo d’**arrière-plan** peut se placer derrière l’éditeur et l’encadré latéral (chapitre 69).

En **Côte à côte**, la source se place à côté de l’aperçu et défile avec lui. Le séparateur des volets peut être déplacé, et sa position est mémorisée. Quand la fenêtre fait moins de 520 points de large, les deux volets s’empilent l’un au-dessus de l’autre. Quand l’ouverture de l’encadré latéral laisserait moins de 640 points au document, l’encadré recouvre le document au lieu de le comprimer.

## L’encadré latéral (navigateur)

L’encadré latéral peut afficher **Fichiers**, **Plan**, **Rechercher**, **Projet** et **Assistant** (chapitre 60). Faites glisser son bord pour le redimensionner, entre 180 et 420 points de large. Dans une fenêtre de moins de 500 points, il occupe toute la largeur, et un bouton **OK** le ferme.

## Le mode concentration

Le **mode concentration** masque tout sauf le texte. Activez-le depuis **Présentation ▸ Mode concentration**, depuis **Plus ▸ Concentration**, ou depuis la palette de commandes. Tant qu’il est actif, un bouton **Quitter le mode concentration** apparaît pour que vous puissiez en sortir sans clavier. Le mode concentration renvoie toujours les longues lignes à la ligne et a sa propre colonne de texte, distincte de celle des Réglages. Il n’a pas de raccourci par défaut ; attribuez-en un dans **Réglages ▸ Clavier**.

## Quand il n’y a pas de document

Quand rien n’est ouvert, la fenêtre propose **Nouveau document** et **Ouvrir un fichier…** sous le titre « Commencer un document ». Sur iPad, **Ouvrir un dossier…** se trouve dans **Plus**.

Quand Pilcrow démarre et trouve du travail non enregistré d’une session précédente, il affiche à la place une liste **Récupérer des documents**. Voir le chapitre 17 pour le fonctionnement de la récupération. La liste propose **Récupérer** et **Supprimer** pour chaque élément, et **Tout récupérer** et **Tout supprimer** pour l’ensemble de la liste. Un document qui n’a jamais été enregistré ne peut plus être récupéré une fois supprimé ; **Tout supprimer** demande donc une confirmation. Un bouton **Ignorer** sur la bannière d’un document unique refuse la récupération de cet élément.

Pendant l’ouverture d’un gros fichier, la fenêtre affiche « Ouverture de *nom*… » avec un indicateur de progression.

# Chapter 53: Le menu Fichier

Sur Mac, ces éléments se trouvent dans le menu **Fichier**. Sur iPad, ils se trouvent dans **Menu ▸ Fichier** dans l’en-tête, ou dans la barre de menus qui apparaît quand vous maintenez **⌘** ou déplacez le pointeur en haut de l’écran. Les éléments marqués « Mac uniquement » n’existent pas sur iPad.

| Élément | Raccourci | Ce qu’il fait |
| --- | --- | --- |
| **Nouveau** (iPad : **Nouveau document**) | `⌘N` | Crée un document sans titre. Il rejoint les documents ouverts. |
| **Ouvrir…** (iPad : **Ouvrir un fichier…**) | `⌘O` | Ouvre un fichier texte ou de balisage depuis le disque. |
| **Ouvrir récent** (Mac uniquement) | | Liste les fichiers ouverts récemment. **Effacer le menu** vide la liste. Affiche « Aucun document récent » quand la liste est vide. |
| **Ouverture rapide…** (Mac uniquement) | `⇧⌘O` | Recherche parmi les noms de fichiers du dossier ouvert. Grisé tant qu’aucun dossier n’est ouvert. |
| **Ouvrir un dossier…** (menu d’en-tête de l’iPad et Plus) | | Ouvre un dossier dans l’encadré latéral. Sur Mac, utilisez le bouton **Ouvrir un dossier** de l’encadré latéral. |
| **Parcourir le dossier contenant…** | | Demande l’autorisation de parcourir le dossier qui contient le fichier ouvert. Le bac à sable de Pilcrow ouvre un fichier seul ; ceci ajoute son dossier. Grisé quand le dossier est déjà ouvert ou que le document n’a pas de fichier. |
| **Nouveau livre…** | | Crée un dossier de projet de livre avec son manifeste (chapitre 34). |
| **Faire du dossier un projet de livre** | | Écrit un fichier `manifest.pilcrow` dans le dossier ouvert et affiche le panneau Projet (chapitre 34). Grisé quand aucun dossier n’est ouvert ou que le dossier a déjà un manifeste. |
| **Fermer le document** (iPad : **Fermer**) | `⌘W` | Ferme le document actif, en demandant d’abord confirmation s’il a des modifications non enregistrées. Quand les Réglages sont au premier plan, `⌘W` ferme les Réglages à la place. |
| **Tout fermer** (iPad) | `⇧⌘W` | Ferme tous les documents, en demandant confirmation pour chacun de ceux qui ne sont pas enregistrés. Sur Mac, le menu du titre propose **Fermer tous les documents**. |
| **Enregistrer** | `⌘S` | Enregistre le document. Un nouveau document demande où l’enregistrer. |
| **Tout enregistrer** (Mac uniquement) | `⌥⌘S` | Enregistre tous les documents ayant des modifications non enregistrées. Grisé quand il n’y en a aucun. |
| **Dupliquer** (Mac uniquement) | `⇧⌘S` | Fait une copie et l’ouvre à côté de l’original, qui reste inchangé. |
| **Enregistrer sous…** | `⌥⇧⌘S` | Enregistre sous un nouveau nom ou à un nouvel endroit, ou dans un autre encodage. Ensuite, le document devient le nouveau fichier. |
| **Déplacer vers…** (Mac uniquement) | | Déplace ou renomme le fichier sur le disque via un panneau d’enregistrement (le bouton indique **Déplacer**), en gardant le document ouvert. |
| **Historique des versions…** | | Ouvre les versions enregistrées du document (chapitre 17 et chapitre 63). |
| **Comparer avec un fichier…** | | Compare le document avec un autre fichier et vous laisse accepter ou rejeter chaque modification (chapitre 18). |
| **Recharger depuis le disque** (Mac uniquement) | | Relit le fichier depuis le disque, à utiliser quand une autre app l’a modifié. Si vous avez des modifications non enregistrées, il demande d’abord : **Enregistrer, puis recharger**, **Recharger sans enregistrer** ou **Annuler**. Grisé pour un document sans fichier. |
| **Afficher dans le Finder** (Mac uniquement) | | Révèle le fichier dans le Finder. |
| **Importer** (Mac uniquement) | | Un sous-menu : **Thème…**, **Profil de syntaxe…**, **Collection de macros…**, **Guide de style…**. Chacun ajoute un fichier à votre bibliothèque (chapitre 43). Sur iPad, l’importation se trouve sous **Réglages ▸ Bibliothèque ▸ Importer**. |
| **Exporter…** | `⇧⌘E` | Ouvre le panneau d’exportation (chapitre 64). |
| **Partager…** | | Partage le fichier du document. |
| **Compiler le manuscrit…** | | Compile un projet de livre (chapitre 36). Grisé tant qu’aucun projet de livre n’est chargé. |
| **Format d’impression…** (Mac uniquement) | | Définit le papier, l’orientation et les marges, les mêmes réglages que ceux de l’export PDF. |
| **Imprimer…** | `⌘P` | Imprime le document rendu. Si le document contient des champs à remplir non remplis, Pilcrow vous prévient d’abord. |

# Chapter 54: Le menu Modifier

Le menu Modifier contient les commandes standard du système et beaucoup de celles de Pilcrow. Les éléments de menu pour la sélection, les lignes et les curseurs agissent sur la source ; ils sont donc grisés dans l’aperçu.

## Annuler, presse-papiers et coller

| Élément | Raccourci | Ce qu’il fait |
| --- | --- | --- |
| **Annuler**, **Rétablir** | `⌘Z`, `⇧⌘Z` | Revient en arrière et en avant dans vos modifications. |
| **Couper**, **Copier**, **Coller**, **Supprimer**, **Tout sélectionner** | | Les commandes du système. |
| **Copier comme Markdown** | `⇧⌘C` | Copie la sélection comme source Markdown. |
| **Copier comme texte brut** | | Copie la sélection en retirant autant que possible le balisage structurel. |
| **Copier comme code HTML** | | Copie en texte le HTML rendu de la sélection. |
| **Coller comme texte brut** | `⇧⌘V` | Colle sans aucune mise en forme du presse-papiers. |

## Rechercher

**Rechercher** est un sous-menu.

| Élément | Raccourci |
| --- | --- |
| **Rechercher…** | `⌘F` |
| **Remplacer…** | `⌘R` |
| **Rechercher le suivant** | `⌘G` |
| **Rechercher le précédent** | `⇧⌘G` |

## Orthographe et grammaire

Sur iPad, ce sous-menu ne contient que **Vérifier l’orthographe pendant la frappe**, le même interrupteur que dans les Réglages. Les deux autres éléments sont réservés au Mac, car une vue de texte d’iPad n’a pas de panneau d’orthographe.

| Élément | Raccourci | Ce qu’il fait |
| --- | --- | --- |
| **Afficher l’orthographe et la grammaire** | `⌘:` | Ouvre le panneau d’orthographe du système. |
| **Vérifier le document maintenant** | `⌘;` | Vérifie tout le document. |
| **Vérifier l’orthographe pendant la frappe** | | Souligne les fautes d’orthographe pendant la saisie. Le même interrupteur se trouve dans les Réglages. |

## Transformations et parole

| Élément | Ce qu’il fait |
| --- | --- |
| **Mettre en majuscules**, **Mettre en minuscules**, **Initiales en majuscules** | Change la casse de la sélection, ou du mot sous le curseur. |
| **Commencer la lecture**, **Arrêter la lecture** | Lit la sélection à voix haute, ou tout le document quand rien n’est sélectionné. |

## Sélection

Un sous-menu de moyens de sélectionner et de se déplacer.

| Élément | Raccourci | Ce qu’il fait |
| --- | --- | --- |
| **Sélectionner le mot** | `⌘D` | Sélectionne le mot sous le curseur. |
| **Sélectionner la ligne** | `⌘L` | Sélectionne toute la ligne du fichier, et non la ligne affichée à l’écran après renvoi. |
| **Sélectionner le paragraphe** | `⌥⌘P` | Sélectionne le paragraphe. |
| **Aller en haut**, **Aller en bas** | `⌘↑`, `⌘↓` | Déplace le curseur au début ou à la fin du document. |
| **Aller en début de ligne**, **Aller en fin de ligne** | `⌃A`, `⌃E` | Se déplace à l’une ou l’autre extrémité de la ligne. |
| **Ajouter un curseur au-dessus**, **Ajouter un curseur en dessous** | `⌃⇧↑`, `⌃⇧↓` | Ajoute un autre curseur sur la ligne du dessus ou du dessous (chapitre 7). |
| **Sélectionner l’occurrence suivante** | `⌃⌥D` | Ajoute la correspondance suivante du texte sélectionné. |
| **Sélectionner toutes les occurrences** | `⌃⌥⇧D` | Sélectionne toutes les correspondances à la fois. |
| **Champ suivant**, **Champ précédent** | `⌥Tab`, `⌥⇧Tab` | Saute entre les champs à remplir laissés par une macro (chapitre 24). Les Réglages offrent un choix de paires de touches pour cela, appelées Touches Super Tab. |
| **Curseurs dans une colonne…** | `⌃⇧G` | Ouvre une feuille pour placer des curseurs en colonne selon un nombre. |

Les raccourcis pour les curseurs, les occurrences, les champs et la palette de commandes peuvent être modifiés dans **Réglages ▸ Clavier**.

## Lignes

| Élément | Ce qu’il fait |
| --- | --- |
| **Trier les lignes par ordre croissant**, **Trier les lignes par ordre décroissant** | Trie les lignes sélectionnées. |
| **Inverser les lignes** | Inverse leur ordre. |
| **Supprimer les lignes en double** | Conserve la première de chaque ligne répétée. |
| **Supprimer les lignes vides** | Supprime les lignes vides dans la sélection. |
| **Supprimer les espaces en fin de ligne** | Retire les espaces et les tabulations à la fin des lignes. |
| **Joindre les lignes** | Réunit les lignes sélectionnées en une seule. |

## Supprimer une portion

| Élément | Raccourci |
| --- | --- |
| **Supprimer le mot** | `⇧⌘D` |
| **Supprimer la ligne** | `⌥⇧⌘L` |
| **Supprimer le paragraphe** | `⌥⇧⌘P` |

## Déplacer, traduire, naviguer

| Élément | Raccourci | Ce qu’il fait |
| --- | --- | --- |
| **Déplacer la ligne vers le haut**, **Déplacer la ligne vers le bas** | `⌥⌘↑`, `⌥⌘↓` | Déplace vers le haut ou vers le bas la ligne courante ou les lignes sélectionnées. |
| **Traduire ▸ Document**, **Traduire ▸ Sélection** | | Ouvre la feuille de traduction (chapitre 63). |
| **Aller à la ligne…** | `⌃G` | Saute à un numéro de ligne, ou à une ligne et une colonne. |
| **Vérifier les liens…** | | Vérifie les liens et les images du document (chapitre 19). |
| **Palette de commandes…** | `⌃⇧P` | Ouvre la palette de commandes (chapitre 62). |
| **Précédent**, **Suivant** | `⌃⌘←`, `⌃⌘→` | Retrace les endroits entre lesquels vous avez sauté. |

En bas, le système ajoute **Outils d’écriture**, **Remplissage automatique**, **Commencer la dictée…** et **Émoji et symboles**.
