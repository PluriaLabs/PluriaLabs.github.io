# Chapter 81: File, enkode, dan batas

## File yang dibuka Pilcrow

Pilcrow mengedit file teks biasa dan file markup. Ekstensi yang umum adalah `txt`, `md`, `markdown`, `adoc`, `asciidoc`, `rst`, dan `tex`, serta ekstensi apa pun yang diklaim oleh profil yang Anda tambahkan. Pilcrow mendeteksi enkode teks sebuah file saat membukanya.

| Item | Jenis |
| --- | --- |
| Profil sintaks, koleksi makro, panduan gaya, Tema Aplikasi | `.json` |
| Tema Render | `.css` |
| Paket tema | `.zip` |
| Manifes proyek buku | `manifest.pilcrow` |
| Latar | HEIC, PNG, JPEG, SVG, MP4, MOV, M4V |
| Klip suara pengetikan | WAV, AIFF, MP3, M4A, CAF |

## Enkode teks

Pilcrow membaca teks UTF-8, UTF-16, UTF-32, dan ISO 8859-1 (Latin-1). Anda dapat mengonversi dokumen dengan **Informasi Dokumen ▸ Enkode ▸ Konversi Ke…** ke salah satu dari berikut; file dikonversi saat disimpan berikutnya:

UTF-8, UTF-8 (BOM), UTF-16 LE, UTF-16 LE (BOM), UTF-16 BE, UTF-16 BE (BOM), UTF-32 LE, UTF-32 LE (BOM), UTF-32 BE, UTF-32 BE (BOM).

File Latin-1 dapat dikonversi ke semua enkode ini tanpa kehilangan data. Konversi ke Latin-1 tidak ditawarkan, karena dapat merusak konten.

## Format ekspor

| Format | Ekstensi |
| --- | --- |
| HTML, HTML (tanpa Gaya) | `.html` |
| PDF | `.pdf` |
| Word (.docx) | `.docx` |
| Gambar | `.png` |
| Arsip PDF | `.zip` |

## Batas dan angka

Di mana Pilcrow berhenti, atau di mana sebuah pilihan memiliki rentang:

| Di mana | Batas |
| --- | --- |
| Panel pencarian | Berhenti pada 500 kecocokan. |
| Cari di Pratinjau | Menghitung hingga 2.000 kecocokan. |
| Ganti di Folder | Mengubah paling banyak 2.000 file sekaligus. |
| Periksa Tautan | Memeriksa hingga 50.000 tautan. |
| Bandingkan | Menampilkan hingga 5.000 baris yang berubah. |
| Versi yang disimpan | Tidak ada hingga 500 (default 50). |
| Baris panjang | Baris dengan 20.000 karakter atau lebih selalu dibungkus. |
| Ukuran font | 9 hingga 32 poin. |
| Lebar tab | 2 hingga 8 spasi. |
| Lebar teks | 50% hingga 100%. |
| Zoom | 50% hingga 200%, dalam sepuluh langkah. |
| Kecepatan membaca | 60 hingga 2.000 kata per menit. |
| Lebar navigator | 180 hingga 420 poin. |
| Klip suara pengetikan | Paling lama 2 detik dan 3 MB. |
| Teks log laporan diagnostik | Entri terbaru, hingga 60.000 karakter, saat ditambahkan ke deskripsi issue GitHub. |
| File yang sangat besar | Dibuka dan diedit tanpa dibaca ke memori sekaligus. Jumlah baris dan kata, serta kerangka, diselesaikan di latar belakang dan mungkin belum lengkap sampai saat itu. Ekspor PDF dokumen yang sangat besar membutuhkan memori jauh lebih banyak daripada pengeditan atau ekspor HTML dan Word; Arsip PDF membaginya menjadi bagian-bagian terbatas. |

## Tempat Pilcrow menyimpan data

| Apa | Di mana |
| --- | --- |
| Dokumen Anda | Di mana pun Anda menyimpannya. |
| Pustaka (tema, profil, makro, panduan gaya, latar) | Di penyimpanan pribadi app, atau di folder bernama "Pilcrow Library" di dalam folder yang Anda pilih (**Pengaturan ▸ Pustaka ▸ Lokasi**). |
| Preferensi, kunci API, salinan pemulihan, riwayat versi | Di perangkat, di penyimpanan pribadi app dan Keychain. Tinjau dan hapus di **Pengaturan ▸ Umum ▸ Penyimpanan & Privasi**. |
| Log diagnostik | Di perangkat, sampai Anda menghapusnya. |

# Chapter 82: Pesan, banner, dan keadaan kosong

Bab ini menjelaskan pesan singkat yang ditampilkan Pilcrow, agar tidak ada yang menjadi misteri.

## Di editor dan pratinjau

| Pesan | Artinya |
| --- | --- |
| **Belum ada yang dipratinjau. Mulailah menulis dan hasilnya akan muncul di sini.** (atau "Beralih ke Edit dan mulailah menulis.") | Dokumen kosong, jadi tidak ada yang bisa digambar di Pratinjau. |
| **Pratinjau tidak dapat dirender: …** dengan **Tampilkan Sumber** dan **Coba Lagi** | Pratinjau gagal. **Tampilkan Sumber** beralih ke Edit. **Coba Lagi** mencoba kembali. |
| Persamaan atau diagram yang gagal, dengan tautan **Tampilkan Sumber** | Satu blok tidak dapat digambar. Klik **Tampilkan Sumber** untuk melompat ke sumber blok itu dan memperbaikinya. |
| **Tidak dapat menyimpan** dengan **Coba Lagi** dan tombol tutup | Penyimpanan gagal. Dokumen tetap terbuka dan belum tersimpan. Perbaiki penyebabnya (ruang disk, izin, file yang dipindahkan) dan pilih **Coba Lagi**. |
| **File Berubah di Disk** | App lain mengubah file. **Muat Ulang** membaca versi baru; **Pertahankan Versi Saat Ini** mempertahankan yang Anda miliki. |
| **Peringatan parsing** | Baris yang konstruksinya mungkin bukan yang Anda maksud (Bab 68). |
| **Ganti File yang Ada?** | Nama yang Anda pilih sudah dipakai di tempat itu. |
| **Isian yang belum diisi masih ada** | Anda mencetak atau mengekspor dengan isian yang belum diisi (Bab 63). |
| **Pembagi panel** (petunjuk VoiceOver: "Seret untuk mengubah ukuran editor dan pratinjau. Ketuk dua kali untuk mengatur ulang.") | Gagang di antara sumber dan pratinjau pada Berdampingan. |
| **Kata: N** | Jumlah kata di bilah status. |

## Di dialog dan panel

| Di mana | Pesan | Artinya |
| --- | --- | --- |
| Palet perintah | **Ketik perintah** | Petunjuk isian. "Tidak ada perintah yang cocok" muncul saat tidak ada yang sesuai. |
| Buka Cepat | **Ketik nama file** | Petunjuk isian. |
| Kursor dalam Kolom | **Baris (misalnya 3-17)**, **Kolom (misalnya 100, atau 100-105 untuk memilih)** | Petunjuk isian. Satu kolom menempatkan kursor; rentang memilih karakter-karakter itu di setiap baris. |
| Panel pencarian | **Ketik untuk mencari di folder ini.**, **Tidak ada kecocokan di folder ini.**, **Pencarian dibatalkan.** | Status pencarian folder. |
| Panel file | **Anda juga dapat menjatuhkan folder di sini.** | Seret folder ke panel untuk membukanya. |
| Ganti di Folder | **Tidak ada yang diganti.** | Pencarian tidak memiliki kecocokan. |
| Bandingkan | Tooltip pada tombol: **Terima** ("Terapkan perubahan ini pada dokumen yang terbuka"), **Tolak** ("Biarkan perubahan ini di luar dokumen yang terbuka"), **Tarik Kembali** ("Kembalikan baris lama ke dokumen hanya untuk perubahan ini"). | Fungsi masing-masing. |
| Terjemahkan | **Terjemahan tidak dapat diselesaikan.** | Coba lagi, atau pilih kecepatan lain. |
| Terjemahkan | **Perkiraan waktu: kurang dari satu menit** | Perkiraan untuk kecepatan asisten AI; waktunya bergantung pada layanan AI Anda. Setelah terjemahan, **Buka di Tab Baru** membuka hasilnya. |
| Asisten | **Tidak ada dokumen yang terbuka.**, **Tidak ada teks dokumen yang dikirim.** | Panel tidak memiliki apa pun untuk dibagikan, jadi tidak ada yang dikirim. |
| Pemilih model | **Memuat model…**, **Tidak ada model yang cocok.** | Daftar sedang dimuat, atau pencarian Anda tidak menemukan apa pun. |
| Tinjauan gaya | **Tidak ada temuan.** dan **Balasan tidak dapat dibaca sebagai temuan. Coba lagi.** | Tinjauan tidak menemukan apa pun, atau balasan AI tidak dalam bentuk yang diharapkan. |
| Tinjauan gaya | Tooltip **Terapkan Semua**: "Menerapkan setiap perbaikan yang tersedia, sebagai satu perubahan yang dapat Anda batalkan." | Satu kali Batalkan membalikkan semuanya. |
| Panel proyek | **Nama Anda**, **Tambah variabel** | Petunjuk isian Penulis, dan tombol untuk variabel proyek. |
| Izin asisten | **Baca kebijakan privasi Pilcrow** | Membuka kebijakan privasi. |
