# Chapter 75: Editor tema

Ada dua jenis tema, dan masing-masing punya editornya sendiri. Buka keduanya dari **Pengaturan ▸ Pustaka ▸ Tema**: **Baru** membuat tema, **Edit** mengubah tema kustom, dan **Duplikat** menyalin tema bawaan agar Anda dapat mengubah salinannya. Tema bawaan tidak dapat diedit.

## Editor Tema Render

**Edit Tema Render** menata gaya keluaran Pratinjau, HTML, PDF, gambar, dan cetak. Properti kustom Pilcrow-nya juga menetapkan gaya Word. Tema Render tidak menata gaya aplikasi atau editor.

| Bagian | Fungsinya |
| --- | --- |
| **Nama** | Nama tema. |
| **Tampilan** | **Otomatis**, **Terang**, atau **Gelap**. |
| **CSS** | Stylesheet, dalam editor kode. Lihat Chapter 80 untuk properti dan kelasnya. |
| **Pratinjau yang dirender** | Dokumen contoh yang digambar dengan CSS Anda saat Anda mengetik, sehingga Anda dapat melihat efeknya. |
| **Diagnostik CSS** | Masalah yang ditemukan Pilcrow pada CSS, seperti sumber daya jarak jauh yang tidak diizinkan. |
| **Batalkan**, **Simpan** | Menutup atau menyimpan tema. Menutup dengan perubahan akan menampilkan **Buang perubahan tema?** dengan **Buang Perubahan** atau **Lanjutkan Mengedit**. |
| **Garis dasar** | **Setel Ulang ke Baseline** membuang setiap perubahan sejak tema dibuat, diduplikasi, atau diimpor (setelah Anda mengonfirmasi). **Setel sebagai Baseline Baru** menyimpan tema dan menjadikan kondisinya saat ini sebagai titik pemulihan. |

## Editor Tema Aplikasi

**Edit Tema Aplikasi** menata gaya Pilcrow itu sendiri: tampilan, aksen, bar samping, bar, dan editornya.

| Bagian | Fungsinya |
| --- | --- |
| **Nama** | Nama tema. |
| **Tampilan** | **Otomatis**, **Terang**, atau **Gelap**. Tema Otomatis memiliki dua palet. |
| **Mengedit warna untuk** | Untuk tema Otomatis, **Terang** atau **Gelap**: palet mana dari kedua palet yang sedang Anda edit. |
| Warna, dalam lima grup | **Aplikasi** (aksen), **Bar Samping** (latar belakang dan latar depan), **Bar status dan pemformatan** (latar belakang dan latar depan), **Editor** (latar belakang, latar depan, kursor, pilihan, latar belakang gutter, latar depan gutter, aturan baris saat ini), dan **Sintaks** (judul, penanda, kode, tautan, redup, serta kata kunci, string, angka, dan komentar kode). Setiap warna menampilkan **Default** sampai Anda menetapkannya, dan tombol **Setel Ulang** mengembalikannya. |
| **Pratinjau** | Miniatur Pilcrow, dengan bar samping, editor, dan bar status, dalam warna yang Anda pilih, terang atau gelap. |
| **Batalkan**, **Simpan**, **Garis dasar** | Seperti di atas. |

Tema juga dapat mewarnai token sintaks satu per satu. Warna tersebut dipertahankan, tetapi diedit di file JSON tema (`syntax.tokens`); lihat Chapter 79.

# Chapter 76: Editor makro

Buka editor makro dari **Pengaturan ▸ Pustaka ▸ Makro**: **Baru** di dalam koleksi, atau **Edit** pada makro. Judulnya adalah **Makro Baru** atau **Edit Makro**.

| Isian | Fungsinya |
| --- | --- |
| **Nama** | Label untuk makro. |
| **Pemicu** (misalnya `/sig`) | Teks yang memulainya. Makro diperluas saat Anda mengetik pemicu diikuti spasi, tab, atau return. |
| **Cocok** | Cara pemicu dibaca: **Teks persis**, **Prefiks**, atau **Ekspresi reguler**. Ekspresi reguler yang dapat membuat editor hang akan ditolak: "Ekspresi reguler itu dapat membuat editor hang. Sederhanakan." |
| **Pengganti** | Teks hasil perluasannya. |
| **Sisipkan Tanggal/Waktu** | Menu yang menambahkan token tanggal atau waktu ke pengganti. |
| **Aktif** | Menyalakan atau mematikan makro tanpa menghapusnya. |
| **Jangan perluas di dalam kode** | Mencegah makro berjalan di dalam span kode dan blok kode. |
| **Batalkan**, **Simpan** | Menutup atau menyimpan makro. Jika tidak dapat disimpan, pesan akan menjelaskan alasannya. |

Dalam pengganti, `$1`, `$2`, dan seterusnya adalah tab stop, dan `$0` adalah tempat kursor mendarat. Setelah makro diperluas, Tab (atau **Isian Berikutnya**) melompat dari satu titik ke titik berikutnya. Tanggal dan waktu menggunakan token: `{{date:yyyy-MM-dd}}`, `{{time:HH:mm:ss}}` dan `{{datetime:MM/dd/yyyy h:mm a}}`, serta format bernama `iso8601`, `rfc2822`, `unix`, `short`, `medium`, `long` dan `full`. Baris **Sekarang:** di bawah isian menunjukkan hasil pengganti pada saat ini.

# Chapter 78: Menggunakan Pilcrow di iPad

Pilcrow berjalan di iPadOS 17 atau lebih baru. Aplikasi ini dapat digunakan hanya dengan sentuhan, dengan keyboard eksternal, dan dengan trackpad atau mouse.

## Sentuhan

- **Pembagi panel.** Di Berdampingan, seret pembagi antara sumber dan pratinjau untuk mengubah ukurannya. Ketuk dua kali untuk menyetel ulang.
- **Navigator.** Seret tepi bar samping untuk mengubah ukurannya. Di jendela sempit, bar samping menutupi dokumen dan tombol **Selesai** menutupnya.
- **Pilihan kolom.** Nyalakan **Lainnya ▸ Pilihan Kolom**, lalu seret satu jari untuk memilih teks berbentuk persegi panjang. Dua jari tetap menggulir. Lencana **Pilihan Kolom** muncul selama fitur ini aktif, dengan tombol untuk mematikannya. Atau gunakan **Lainnya ▸ Kursor dalam Kolom…** untuk menempatkan kursor berdasarkan jumlah.
- **Menu konteks.** Tekan dan tahan di dalam teks untuk menu editor (di bawah).
- **File.** Tekan dan tahan file di panel File untuk menunya (Chapter 60).

## Dengan keyboard eksternal

Setiap pintasan di Chapter 77 berfungsi. Tahan **⌘** untuk melihat bilah menu iPad, atau gerakkan penunjuk ke bagian atas layar. Pilcrow dapat menyembunyikan menu headernya sendiri saat keyboard atau mouse terhubung; lihat **Pengaturan ▸ Tampilan ▸ Menu di Header**.

## Dengan trackpad atau mouse

Klik kanan membuka menu konteks editor. Tahan **Option** sambil menyeret untuk memilih teks berbentuk persegi panjang.

## Menu konteks editor

Klik kanan di Mac, atau tekan dan tahan di iPad, di dalam teks. Item yang tidak dapat diekspresikan oleh profil sintaks aktif ditampilkan abu-abu, dan sistem menambahkan item miliknya sendiri (Potong, Salin, Tempel, saran ejaan, Cari Tahu, dan seterusnya).

Di **Mac**:

| Item | Fungsinya |
| --- | --- |
| **Salin / Tempel Sebagai…** | **Salin sebagai Markdown**, **Salin sebagai Teks Biasa**, **Salin sebagai Kode HTML**, **Tempel sebagai Teks Biasa**. |
| **Paragraf** | **Paragraf**, **Judul 1** sampai **6**, **Kutipan blok**, **Daftar Berpoin**, **Daftar Bernomor**, **Daftar Tugas**, **Pagar Kode**. |
| **Format** | **Tebal**, **Penekanan**, **Kode**, **Coretan**, **Matematika Inline**, **Matematika Tampilan**, **Diagram**, **Bagan**, **Hyperlink**. |
| **Pilihan** | **Pilih Kata**, **Pilih Baris**, **Pilih Paragraf**. |

Di **iPad**, tiga submenu berada bersama item sistem:

| Item | Fungsinya |
| --- | --- |
| **Format** | Gaya inline: tebal, penekanan, kode, dan lainnya. |
| **Paragraf** | Jenis paragraf: judul, kutipan, daftar, pagar kode. |
| **Sisipkan** | Penyisipan yang sama seperti menu **Lainnya** pada bilah alat pemformatan, termasuk **Sisipkan Peringatan**, **Sisipkan Gambar…** dan **Sisipkan Tabel…**, dan, di bawah **Sintaks**, konstruksi milik profil aktif. |
