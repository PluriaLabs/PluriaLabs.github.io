# Part XXI — Format file dan batasan

# Chapter 79: Format Tema Aplikasi

**Tema Aplikasi** menata gaya Pilcrow itu sendiri: tampilan terang atau gelapnya, warna aksen, bar samping, bar status dan pemformatan, serta editor. Ini adalah file JSON. Dokumen yang dirender (Pratinjau, HTML, PDF, gambar, cetak, dan Word) ditata secara terpisah oleh **Tema Render**, yaitu CSS (Chapter 80). Kedua jenis ini dipasang, dipilih, dan dihapus secara terpisah, dan tidak ada yang mengikuti yang lain.

## Contoh lengkap

```json
{
  "pilcrowAppTheme": 1,
  "name": "Nord",
  "appearance": "dark",
  "colors": {
    "accent": "#88C0D0",
    "sidebar": { "background": "#2E3440", "foreground": "#D8DEE9" },
    "bars": { "background": "#3B4252", "foreground": "#D8DEE9" },
    "editor": {
      "background": "#2E3440",
      "foreground": "#ECEFF4",
      "cursor": "#88C0D0",
      "selection": "#434C5E",
      "gutterBackground": "#2E3440",
      "gutterForeground": "#4C566A"
    },
    "syntax": {
      "heading": "#88C0D0",
      "marker": "#EBCB8B",
      "code": "#A3BE8C",
      "link": "#81A1C1",
      "muted": "#7B88A1",
      "tokens": { "strong": "#D08770" }
    }
  }
}
```

## Tingkat atas

| Kunci | Wajib | Nilai |
| --- | --- | --- |
| `pilcrowAppTheme` | ya | Versi format, `1`. |
| `name` | ya | 1–200 karakter. Ditampilkan di Pengaturan dan menu Tema. |
| `appearance` | ya | `"light"`, `"dark"` atau `"automatic"`. |
| `colors` | tema `light` dan `dark` | Satu palet (di bawah). |
| `light`, `dark` | tema `automatic` | Dua palet: satu digunakan pada tampilan terang sistem, satu pada tampilan gelap. |
| `id` | tidak | Ditulis oleh Pilcrow untuk pustakanya sendiri. Diabaikan saat impor, yang selalu memberikan id baru. |

`appearance` menentukan tampilan **setiap** jendela: termasuk menu, Pengaturan, sheet, dan pemilih. Tema `light` atau `dark` menetapkannya secara tetap; `automatic` mengikuti sistem.

Tema automatic harus menetapkan setiap warna di `light` dan `dark` sekaligus atau di keduanya tidak sama sekali. Warna yang ditetapkan hanya untuk satu tampilan jika tidak akan digambar pada tampilan yang lain.

## Palet

Setiap kunci bersifat opsional. Warna yang dihilangkan mempertahankan tampilan bawaan Pilcrow, sehingga tema bisa sesederhana satu warna aksen.

| Kunci | Menata gaya |
| --- | --- |
| `accent` | Rona di seluruh aplikasi: tombol, segmen terpilih, sakelar, tautan, cincin fokus, dan baris terpilih di bar samping. Jika tidak ditetapkan, aksen sistem dipertahankan. |
| `sidebar.background`, `sidebar.foreground` | Bar samping File, Kerangka, dan Cari. Label sekunder diturunkan dari latar depan. |
| `bars.background`, `bars.foreground` | Bar status, bilah alat pemformatan yang disematkan, dan pemberitahuan impor. Label sekunder diturunkan dari latar depan. |
| `editor.background`, `editor.foreground` | Kanvas editor dan teks isi. |
| `editor.cursor`, `editor.selection` | Titik sisip dan sorotan pilihan. |
| `editor.gutterBackground`, `editor.gutterForeground` | Gutter nomor baris. Latar belakangnya secara default mengikuti latar belakang editor. |
| `editor.currentLineRule` | Garis tipis di bawah baris tempat kursor berada, saat **Tampilan ▸ Aturan Baris Saat Ini** aktif. Secara default berupa warna teks editor dengan kekuatan rendah. |
| `syntax.<group>` | Warna sintaks langsung menurut grup (di bawah). |
| `syntax.tokens.<raw>` | Satu token menurut nilai mentahnya, menggantikan grupnya. |

### Grup sintaks

| Grup | Mewarnai |
| --- | --- |
| `heading` | Judul (penanda dan teks), penanda peringatan, istilah definisi |
| `marker` | Penekanan, tebal, coretan, dan pembatas inline lainnya; penanda daftar dan tugas |
| `code` | Kode inline, blok kode berpagar dan berindentasi, matematika, blok HTML |
| `link` | Label dan tujuan tautan dan gambar, tautan otomatis |
| `muted` | Penanda kutipan blok, pemisah tematik, baris tabel, komentar, atribut blok |
| `codeKeyword`, `codeString`, `codeNumber`, `codeComment` | Kode yang disorot di dalam pagar |

Grup yang tidak ditetapkan mendapat warna bawaan yang dipilih sesuai latar belakang editor: nada lebih gelap pada kanvas terang, nada lebih terang pada kanvas gelap. Nama token di `syntax.tokens` menggunakan huruf, angka, `_` dan `-`, dan tidak boleh sama dengan nama grup (`syntax.heading` sudah mencakup `heading`).

## Warna

Setiap warna adalah string hex: `#RGB`, `#RGBA`, `#RRGGBB` atau `#RRGGBBAA`, dalam sRGB. Pilcrow menyimpannya dalam huruf besar.

## Validasi

Pilcrow menolak file daripada mengabaikan sebagian isinya, dan menyebutkan kunci yang bermasalah, misalnya `colors.editor.cursor: must be a hex colour`. Pilcrow menolak:

- versi `pilcrowAppTheme` yang hilang atau berbeda;
- kunci tak dikenal di tingkat mana pun (biasanya salah ketik);
- kunci palet yang tidak sesuai dengan tampilan (`colors` pada tema automatic, `light` dan `dark` pada tema light atau dark);
- warna yang bukan hex;
- tema automatic yang palet `light` dan `dark`-nya menetapkan warna berbeda.

## Yang tidak diubah oleh Tema Aplikasi

Bilah judul dan bilah alat jendela (kaca milik sistem, yang hanya menerima aksen), menu, Pengaturan, sheet, dan pemilih mempertahankan tampilan aslinya selain tampilan dan aksen. Font tidak ditema: font dan ukuran editor diatur di **Pengaturan ▸ Tampilan ▸ Ukuran Teks & Font**.

## Memasang dan membagikan

- **Impor** file `.json` dari **Pengaturan ▸ Pustaka ▸ Tema**, **File ▸ Impor ▸ Tema** di Mac, atau **Pengaturan ▸ Pustaka ▸ Impor** di iPad. Menjatuhkan file ke Pilcrow juga berfungsi.
- Paket tema `.zip` dapat berisi Tema Aplikasi bersama Tema Render (Chapter 80).
- Tombol bagikan di samping tema menyimpan file `.json`-nya, atau seluruh paket jika tema berasal dari paket.

Pilcrow menyertakan tiga Tema Aplikasi: **Otomatis**, **Terang**, dan **Gelap**. Ketiganya menetapkan warna editor dan sintaks dan membiarkan chrome dalam tampilan bawaannya.

# Chapter 80: Referensi CSS Tema Render

**Tema Render** adalah CSS. Ia menata gaya keluaran Pratinjau, HTML, PDF, gambar, dan cetak, serta gaya Word yang tercantum di akhir bab ini. Tema Render dapat berupa satu file `.css` atau bagian dari paket ZIP dengan aset lokal. Profil sintaks menentukan bagaimana teks sumber menjadi dokumen; Tema Render hanya menata hasilnya. CSS tidak pernah menata gaya aplikasi atau editor; itu adalah Tema Aplikasi (Chapter 79).

## Cascade

Pilcrow menerapkan gaya dalam urutan ini:

1. reset struktural Pilcrow;
2. CSS tema yang dipilih;
3. CSS sekali pakai dari panel ekspor (**Opsi lanjutan ▸ CSS Kustom**);
4. koreksi cetak dan perenderan yang diperlukan.

Aturan yang lebih akhir menang menurut cascade CSS normal. JavaScript tema, sumber daya jarak jauh, URL `file:`, dan `@import` tidak didukung.

## Sumber daya

Pilcrow membaca CSS tema dengan tokenizer CSS standar, sehingga escape didekode sebelum apa pun diperiksa: `u\72 l(…)` adalah `url()` dan `@im\70 ort` adalah `@import`. Setiap tempat yang akan dimuat oleh browser diperiksa: `url(…)`, `url("…")`, `src("…")`, dan string di dalam `image-set()`. Masing-masing harus berupa salah satu dari:

- path relatif paket (`fonts/Body.woff2`, `./paper.png`). `?query` atau `#fragment` diperbolehkan dan diabaikan saat file dicari;
- URL `data:` bertipe PNG, JPEG, GIF, WebP, SVG (`image/svg+xml`), TTF, OTF, WOFF atau WOFF2;
- referensi fragmen seperti `url(#shadow)`, yang menunjuk elemen di halaman.

Apa pun dengan skema selain `data:` (`https:`, `file:`, `blob:`) atau diawali `//` ditolak, begitu pula path yang diawali `/` atau mengandung `..`.

## Properti render

Reset bawaan membaca properti ini, dan menyediakan nilai cadangan:

| Grup | Properti |
| --- | --- |
| Warna | `--pt-background`, `--pt-foreground`, `--pt-secondary-background`, `--pt-secondary-foreground`, `--pt-accent`, `--pt-link-color`, `--pt-border-color` |
| Kode | `--pt-code-background`, `--pt-code-foreground`, `--pt-code-keyword`, `--pt-code-string`, `--pt-code-number`, `--pt-code-comment` |
| Tipe | `--pt-body-font-family`, `--pt-mono-font-family`, `--pt-base-font-size`, `--pt-line-height` |
| Spasi | `--pt-paragraph-spacing`, `--pt-blockquote-indent`, `--pt-list-indent`, `--pt-code-padding`, `--pt-heading-top`, `--pt-heading-bottom` |
| Tabel | `--pt-table-header-background`, `--pt-table-stripe-background` |
| Peringatan | `--pt-admonition-note-color`, `--pt-admonition-tip-color`, `--pt-admonition-important-color`, `--pt-admonition-warning-color`, `--pt-admonition-caution-color` |

## Paket ZIP

Paket ZIP dapat berisi Tema Render (`.css`) dan Tema Aplikasi (`.json`) sekaligus; masing-masing dicantumkan dengan jenisnya sendiri di Pengaturan. ZIP dengan paling banyak satu file CSS dan paling banyak satu Tema Aplikasi tidak memerlukan manifes. Selebihnya memerlukan `pilcrow-theme.json`, yang mencantumkan setiap tema di bawah `variants[].file`. Ekstensi file menentukan jenisnya:

```json
{
  "id": "com.example.paper",
  "name": "Paper",
  "version": "1.0.0",
  "author": "Example Author",
  "license": "MIT",
  "cssAPIVersion": 1,
  "variants": [
    { "id": "app", "name": "Paper", "file": "Paper.json", "appearance": "automatic" },
    { "id": "light", "name": "Paper Light", "file": "Paper-Light.css", "appearance": "light" },
    { "id": "dark", "name": "Paper Dark", "file": "Paper-Dark.css", "appearance": "dark" }
  ]
}
```

Manifes menjelaskan paket dan temanya. Manifes tidak pernah berisi nilai gaya: nilai tersebut ada di file CSS dan Tema Aplikasi.

- `id` paket menamai folder pemasangan. Tidak boleh diawali `.` atau memiliki spasi di awal atau akhir. Memasang paket yang `id`-nya sudah terpasang akan menggantikannya.
- ZIP yang dibuat dengan **Kompres** Finder berfungsi apa adanya. Pilcrow melewati `__MACOSX/`, `._*`, `.DS_Store` dan `Thumbs.db`, dan bila setiap file berada di dalam satu folder tingkat atas, folder itu diperlakukan sebagai akar paket.
- Menghapus satu tema akan mengeluarkannya dari paket dan mempertahankan yang lain beserta aset bersama. Menghapus tema terakhir akan menghapus paket. Tema terhapus yang sedang dipilih mengembalikan pilihan itu ke default jenisnya: Otomatis untuk Tema Aplikasi, Terang untuk Tema Render.
- CSS dapat merujuk file PNG, JPEG, GIF, WebP, TTF, OTF, WOFF dan WOFF2 yang dikemas dengan path `url(...)` relatif. Pilcrow memverifikasi tanda tangannya dan menyematkan aset yang dirujuk sebagai URL data agar perenderan dan HTML yang diekspor tetap offline dan mandiri. Path ZIP tidak boleh keluar dari paket, bertabrakan karena perbedaan huruf besar-kecil, atau menunjuk ke tautan. Ukuran arsip, jumlah entri, ukuran individual, dan rasio kompresi dibatasi.

## Word

Ekspor Word menggunakan nilai `:root` terang (dasar) dan memetakan properti semantik ini ke gaya Word bernama: `--pt-foreground`, `--pt-background`, `--pt-accent`, `--pt-link-color`, `--pt-code-background`, `--pt-code-foreground`, `--pt-body-font-family`, `--pt-mono-font-family`, `--pt-base-font-size` dan `--pt-line-height`. Selektor browser dan aturan tata letak tidak memiliki padanan umum di Word. Keluaran Pratinjau, HTML, PDF, dan gambar menggunakan stylesheet lengkap; Word menggunakan subset ini sambil mempertahankan struktur dokumen, diagram, gambar matematika, tautan, dan media. Panel ekspor menampilkan keterbatasan ini setiap kali Word dipilih.

Pilcrow menyertakan dua Tema Render, **Terang** dan **Gelap**, yang merupakan titik awal lengkap.
