Di bawah ini, sebuah pemisah diikuti oleh **konstruksi milik profil aktif**, seperti admonition atau blok kustom yang didefinisikan profil. Jika tidak ada profil yang dipilih, menu berbunyi "Pilih profil sintaks untuk menyisipkan konstruksi".

## Templat diagram

Insert ▸ Diagram menawarkan 17 titik awal. Masing-masing menyisipkan contoh yang berfungsi untuk diedit.

Flowchart, Sequence Diagram, Class Diagram, State Diagram, Entity Relationship Diagram, Gantt Chart, Pie, User Journey, Git Graph, Mind Map, Timeline, Quadrant Chart, Sankey Diagram, XY Chart, Block Diagram, Packet Diagram, dan Kanban Board.

## Templat bagan

Bar Chart, Line Chart, Area Chart, Scatter Plot, Pie Chart, Stacked Bar Chart, Histogram, Heatmap, dan Box Plot.

## Templat persamaan

Fraction, Square Root, Summation, Integral, Limit, Quadratic Formula, Matrix, Piecewise Function, Aligned Equations, Binomial Coefficient, Bayes' Theorem, dan Euler's Identity.

Di iPad, item Insert yang namanya juga ada di submenu Paragraf (Peringatan, Garis Horizontal, Referensi Tautan, Catatan kaki, Daftar Isi, Front Matter YAML) ditampilkan sebagai "Sisipkan Peringatan" dan seterusnya, karena iPad menggabungkan item menu yang memiliki nama sama.

Untuk iPad tanpa keyboard atau mouse, Pilcrow dapat menampilkan menu yang sama di header-nya. **Settings ▸ Appearance ▸ Menus in the Header** menentukan pilihan:

| Pilihan | Efek |
| --- | --- |

Di jendela selebar 1.100 poin atau lebih, keenam menu berjajar berdampingan: **File**, **Edit**, **Insert**, **Format**, **View**, dan **Help**. Di jendela yang lebih sempit, menu-menu itu menciut menjadi satu tombol **Menu**. Strip ini adalah versi yang lebih ringan dari bilah menu:

- **View** memiliki **Bilah Alat Pemformatan**, **Tampilkan/Sembunyikan Bar Samping**, **Kerangka**, **File**, **Cari**, mode dokumen, **Fokus**, **Nomor Baris**, **Aturan Baris Saat Ini**, **Sumber Bergaya**, **Lipatan Judul**, dan **Dokumen Terbuka**. # Chapter 59: Judul dokumen dan pengalih dokumen

Nama dokumen berada di header bersama titik kecil berwarna dan panah ke bawah. Klik nama itu, atau pilih **View ▸ Open Documents** (`⌃⌘2`), untuk membuka daftar **Dokumen Terbuka**. Di layar kecil, daftar terbuka sebagai sheet dengan tombol **Selesai**.

## Titik simpan

Titik di samping nama memberi tahu Anda keadaan dokumen sekilas. Keadaannya juga dibacakan oleh VoiceOver.

| Titik | Arti |
| --- | --- |
| Hijau | **Tersimpan.** File di disk sama dengan yang Anda lihat. |
| Kuning tua | **Diedit.** Anda punya perubahan yang belum disimpan. |
| Merah | **Penyimpanan gagal.** Pilcrow mencoba menyimpan dan tidak berhasil. Spanduk **Tidak dapat menyimpan** dengan tombol **Coba Lagi** muncul di atas editor. |
| Biru | **Diubah oleh app lain.** File di disk diubah dari luar Pilcrow. |

Dokumen yang belum pernah disimpan menampilkan "Belum disimpan" dan sebuah angka di daftar, karena tidak ada folder yang bisa ditampilkan. Dokumen dengan perubahan yang belum disimpan juga memuat tulisan **Diedit** di ujung barisnya.

## Daftar Dokumen Terbuka

| Bagian | Fungsinya |
| --- | --- |
| **Cari di Dokumen Terbuka** | Muncul saat tujuh dokumen atau lebih terbuka. Ketik sebagian nama atau folder; setiap kata harus cocok di suatu tempat dalam nama atau folder, tanpa membedakan huruf besar/kecil dan aksen. Return membuka kecocokan pertama. Saat tidak ada yang cocok, tertulis "Tidak ada dokumen terbuka yang cocok." |
| Satu baris untuk setiap dokumen | Menampilkan nama, titik simpannya, dan folder tempatnya berada. Tanda centang menandai dokumen aktif. Klik baris untuk beralih ke dokumen itu. |
| **Tutup** (**x** di ujung baris) | Menutup dokumen itu, bertanya dulu jika ada perubahan yang belum disimpan. |
| **Dokumen Baru** | Membuat dokumen tanpa judul. |
| **Simpan** | Menyimpan dokumen aktif. |
| **Simpan Sebagai…** | Menyimpan dengan nama atau tempat baru. |
| **Ganti Nama…** | Membuka formulir ganti nama (di bawah). |
| **Tutup Semua Dokumen** | Menutup setiap dokumen, bertanya tentang setiap dokumen yang belum disimpan. |

Gunakan `⌃Tab` dan `⌃⇧Tab` untuk berpindah ke dokumen berikutnya atau sebelumnya tanpa membuka daftar.

## Ganti nama

**Ganti Nama…** menampilkan **Nama** saat ini dan **Di mana** file berada, dengan tombol **Batalkan** dan **Ganti Nama**. Mengganti nama mengubah file di disk dan membiarkan dokumen tetap terbuka. Jika nama baru tidak dapat dipakai, pesan **Tidak Dapat Mengganti Nama Dokumen** menjelaskan alasannya.
