# Part XIX — Editor untuk item pustaka

# Chapter 74: Editor profil dan blok penyusun profil

Profil sintaks memberi tahu Pilcrow apa arti markup Anda. Bab ini menjelaskan editor profil kontrol demi kontrol, lalu mendaftar setiap blok penyusun yang dapat dipakai sebuah profil. Untuk pengantar berbasis tugas, lihat Chapter 37 sampai Chapter 39.

Buka editor dari **Pengaturan ▸ Pustaka ▸ Profil Sintaks**: **Baru** memulai profil, **Edit** mengubah profil kustom, dan **Duplikat** menyalin profil bawaan agar Anda dapat mengubah salinannya. Judul editor adalah **Edit Profil**, dengan **Batalkan**, **Simpan**, dan **Bantuan Profil** (yang membuka referensi dalam app untuk blok penyusun ini). Pada layar sempit, sakelar **Bagian profil** memilih antara **Overview**, **Rules**, dan **Test Sample**; pada layar lebar ketiganya tampil sekaligus.

## Overview

| Isian | Fungsinya |
| --- | --- |
| **Nama** | Nama profil, ditampilkan di menu bilah status dan Pengaturan. |
| **Deskripsi** | Catatan tentang profil. |
| **Ekstensi file (dipisahkan koma)** | Ekstensi yang memilih profil ini untuk sebuah file. Dua profil tidak dapat memakai ekstensi yang sama. |
| **Mewarisi** | **Tidak ada**, atau profil lain yang aturannya menjadi dasar profil ini. |
| **Sintaks** | **Memperluas Markdown** atau **Menggantikan Markdown** (di bawah). |
| **Sekilas** | Jumlah **Aturan blok**, **Aturan inline**, dan **Aturan penumpukan**. |
| **Edit JSON Lanjutan…** | Membuka profil sebagai JSON untuk isian yang tidak ditampilkan editor terpandu. **Terapkan** mempertahankan perubahan JSON Anda; **Batalkan** membuangnya. |

**Memperluas Markdown** menambahkan aturan Anda ke aturan Markdown: judul, daftar, penekanan, dan lainnya tetap dibaca, dan aturan blok serta inline Anda ditambahkan ke sana. Aturan yang merupakan salinan tak berubah dari salah satu aturan profil CommonMark menjelaskan apa yang sudah dilakukan Markdown, dan diserahkan kepadanya. **Menggantikan Markdown** menjadikan aturan Anda seluruh sintaks, sehingga konstruksi Markdown tidak lagi dikenali. Dengan opsi ini, satu aturan harus menghasilkan **Akhir baris**, jika tidak, tidak ada yang memisahkan paragraf. Editor memperingatkan "Add a rule whose output node is "newline", or nothing will separate into paragraphs", dan profil tidak dapat disimpan sampai aturan seperti itu ada. Editor juga mendaftar tipe keluaran yang tidak didefinisikan profil.

## Rules

Aturan terbagi dalam tiga grup.

### Aturan blok

Aturan blok mengenali seluruh baris dan blok. **Tambah aturan** menambahkan satu. Setiap aturan memiliki **Pola**, tipe **Cocok**, apa yang **Menghasilkan**, dan **Opsi**. Aturan dihapus dengan tombol **Hapus**-nya. Jika tidak ada aturan, editor menyatakan "No rules yet. Add one to recognize a block construct."

### Aturan inline

Aturan inline mengenali teks di dalam sebuah baris. **Tambah aturan inline** menambahkan satu. Aturan inline menawarkan empat tipe pencocokan (**Prefiks harfiah**, **Persis harfiah**, **Regex (terbatas)**, dan **Pasangan pembatas**); aturan blok menawarkan ketujuhnya.

### Aturan penumpukan

Aturan penumpukan menyatakan keluaran mana yang boleh berada di dalam keluaran mana. Masing-masing memiliki **Node induk** dan **Anak yang diizinkan (dipisahkan koma)**. Kosong berarti tanpa batasan: "No restrictions. Every node type may nest inside any other." **Tambah aturan penumpukan** menambahkan satu.

### Tipe pencocokan

| Tipe pencocokan | Membaca pola sebagai | Blok | Inline |
| --- | --- | --- | --- |
| **Prefiks harfiah** | Teks yang menjadi awal konstruksi. | ya | ya |
| **Persis harfiah** | Seluruh teks konstruksi. | ya | ya |
| **Prefiks awal baris** | Teks di awal baris, seperti `# `. | ya | |
| **Blok berindentasi** | Baris yang diawali pola, seperti empat spasi atau satu tab. Baris berurutan, dan baris kosong di antaranya, adalah satu blok, ditampilkan tanpa indentasi. | ya | |
| **Blok berpagar** | Baris yang membuka blok, ditutup oleh baris yang cocok. | ya | |
| **Regex (terbatas)** | Ekspresi reguler. Pilcrow memberi peringatan sebelum menyimpan ekspresi yang bisa macet: "This regex could hang the editor — simplify it." | ya | ya |
| **Pasangan pembatas** | Tanda yang sama di kedua sisi teks pada satu baris, seperti `%%` dalam `%%this%%`. Tidak ada spasi tepat di dalam tanda. | ya | ya |

Dalam ekspresi reguler, `(?<name>…)` memberi nama pada bagian dari kecocokan. Lihat Bagian bernama di bawah.

## Opsi aturan

Grup **Opsi** setiap aturan menawarkan:

| Opsi | Fungsinya |
| --- | --- |
| **Prioritas** | Aturan dengan prioritas lebih tinggi dicoba lebih dulu. |
| **Hanya di awal baris** | Mencegah aturan cocok di tengah baris. |
| **Bagian bernama menjadi atribut** | Setiap bagian bernama dari ekspresi reguler menjadi atribut keluaran. Editor mendaftar "Parts in this pattern" dan "Parts this output reads". Untuk keluaran yang memuat teks, seperti tebal atau tautan, teks yang ditampilkan adalah bagian bernama `text` jika ada, jika tidak bagian terakhir yang cocok. |
| **Menghasilkan** | Apa yang dibuat aturan: keluaran dari daftar di bawah, atau nama **Kustom**. |
| **Nama node kustom** | Nama untuk keluaran **Kustom**. |
| **Atribut tetap** | Bagian yang bernilai sama setiap kali, ditambahkan dengan **Tambah atribut** (**Nama** dan **Nilai**). Nilai dapat menyertakan bagian bernama, ditulis `{name}`: aturan e-mail yang polanya menamai `address` dapat memberi tautannya `url` `mailto:{address}`. |
| **Sisipkan teks** | Apa yang ditulis menu **Sisipkan** untuk aturan ini, persis seperti yang seharusnya tampil, dengan `$0` di tempat kursor harus berada. Aturan yang dicocokkan oleh ekspresi reguler, blok, atau indentasi memerlukan ini, jika tidak menu Sisipkan melewatkannya. |
| **Hanya setelah baris kosong** | Untuk blok berindentasi: baris berindentasi tepat setelah teks tetap menjadi bagian dari teks itu, seperti baris berikutnya dari item daftar. |
| **Setelah Return di akhir baris** | Untuk daftar dan kutipan: **Otomatis** (mengulang poin dan kutipan, menghitung maju item bernomor, dan memulai item tugas tanpa centang), **Ulangi penanda**, **Hitung maju**, **Mulai baru dari penanda**, atau **Tidak menambahkan apa pun**. |

### Blok berpagar dan berpembatas

Untuk aturan **Blok berpagar**, **Blok menampung** menyatakan apa isinya:

| Pilihan | Artinya |
| --- | --- |
| **Belum ada** | Belum diatur. |
| **Teks, ditampilkan apa adanya** | Kode atau teks terformat. |
| **Tidak ada — disembunyikan** | Komentar, dikecualikan dari dokumen. |
| **Blok lain, dalam kotak** | Kutipan, bilah samping, atau peringatan yang memuat paragraf, daftar, dan lainnya. |
| **Blok lain, tanpa kotak** | Blok menyatu dengan teks di sekitarnya; barisnya hanya mengelompokkan. |
| **Tabel** | Lihat Tabel, di bawah. |
| **Tabel yang digambar dengan teks** | Kisi atau kolom sejajar dari teks yang berjalan dari baris pembukanya hingga baris kosong berikutnya, seperti milik reStructuredText. |
| **Teks berindentasi di bawah baris yang diakhiri penanda** | Baris pembuka adalah prosa yang diakhiri penanda, seperti `::` pada reStructuredText; prosa tetap menjadi paragraf, dan teks yang menjorok di bawahnya setelah baris kosong ditampilkan apa adanya. |
| **Teks berindentasi di bawah baris pembuka** | Direktif seperti `.. code-block::`, yang memuat baris berindentasi di bawahnya dan tidak memiliki baris penutup. |

**Baris penutup** adalah baris yang mengakhiri blok; kosong berarti baris yang sama dengan baris pembuka ("Same as the opening line"). Pembatas yang bukan ekspresi reguler, seperti `+++`, dicocokkan sebagai teks biasa. **Baris penutup mengulang tanda pembuka, setidaknya sebanyak itu** untuk pagar gaya Markdown: baris penutup adalah karakter pertama baris pembuka yang diulang setidaknya sebanyak itu, sehingga pagar yang lebih panjang memuat pagar yang lebih pendek sebagai teks. Bahasa blok teks, jika baris pembuka menyebut bahasa yang dikenal, diberi warna di editor.

| Pengaturan | Fungsinya |
| --- | --- |
| **Tumpuk daftar berdasarkan penanda** | Setiap penanda baru, seperti `**` setelah `*`, memulai tingkat yang lebih dalam, apa pun indentasinya. |
| **Baris lanjutan daftar** | Baris yang berdiri sendiri setelah item daftar, yang mengaitkan blok berikutnya ke item itu. |
| **Pertahankan jeda baris tunggal** | Jeda baris di dalam paragraf tetap menjadi jeda baris. |
| **Beri id pada judul** | Judul tanpa id sendiri mendapat id dari judulnya: huruf kecil, kata digabung dengan **pemisah kata**, setelah **prefiks** (**Prefiks id judul**, **Pemisah kata id judul**). Dengan `_` dan `_`, "Getting Started" menjadi `_getting_started`, sehingga referensi silang ke judul itu menampilkan judulnya. Judul yang berulang menambahkan pemisah dan angka. |
| **Beri nomor judul** | Setelah dokumen mendefinisikan atribut yang disebut di **Saat dokumen mendefinisikan**, seperti `:sectnums:` pada AsciiDoc, judul dari **Dari tingkat judul** ke bawah diberi nomor: `1.`, `1.1.`, `2.`. Judul sebelum definisi tidak diberi nomor. |

Ditambahkan dengan **Tambah keterangan**. |

## Tanda inline yang berpasangan menurut apa yang ada di sekitarnya

Bahasa seperti Markdown menulis tebal dan miring dengan rangkaian karakter yang membuka atau menutup tergantung karakter di sebelahnya, serta rentang kode atau tautan dengan tanda kurung, sehingga satu pola untuk seluruh konstruksi tidak dapat menemukannya. Aktifkan **Baca tanda berdasarkan apa yang ada di sekitarnya** untuk menjelaskannya.

| Pengaturan | Fungsinya |
| --- | --- |
| **Karakter escape** | Karakter yang membuat karakter berikutnya menjadi biasa. |
| **Karakter rentang kode** | Rangkaian karakter ini membuka rentang yang ditutup oleh rangkaian berikutnya dengan panjang yang sama. |
| **Tanda urutan** | Tanda yang berpasangan sebagai rangkaian, ditambahkan dengan **Tambah tanda urutan**. Masing-masing memiliki **Tanda**, apa yang digambar **Satu tanda menggambar** dan **Dua tanda menggambar**, serta **Dapat dibuka atau ditutup di dalam kata** (nonaktif untuk `_`). |
| **Tanda pasangan** | Tanda yang berpasangan dengan rangkaian dengan panjang yang sama, ditambahkan dengan **Tambah tanda pasangan**: **Tanda**, apa yang **Menggambar**, dan **Hanya jika pengaturan ini aktif**, pengaturan sintaks seperti sorot yang harus aktif (atau **Selalu**). |
| **Tautan dan alamat web** | **Prefiks gambar**, **Alamat yang ditulis sendiri diapit oleh**, **Skema yang memulai alamat polos**, **Baris yang mendefinisikan label memiliki**, dan **Label catatan kaki diawali dengan** (karakter setelah kurung buka label yang menjadikannya catatan kaki: `[^note]` digambar sebagai referensi catatan kaki ketika sebuah baris diawali `[^note]:`). |

Tanda berpasangan dalam satu baris. Kode, karakter yang di-escape, dan alamat tautan adalah teks biasa bagi tanda di sekitarnya.

## Sumber bergaya

Dengan **Sumber Bergaya** aktif, editor menggambar dokumen dengan tampilan sintaksnya: judul lebih besar, rangkaian tebal dan miring, bilah kutipan, indentasi daftar, kotak tugas, garis, tautan, dan kartu kode, serta menyembunyikan tanda yang membentuknya (dengan **Sembunyikan Penanda** aktif) kecuali pada baris tempat kursor berada. Editor tidak tahu apa pun tentang satu sintaks tertentu: aturan menyatakan apa kecocokannya dengan membawa entri gaya, dan aturan tanpa entri itu diberi warna tetapi tidak diubah gayanya.

Setiap **Opsi** aturan memiliki grup **Sumber bergaya**:

| Isian | Fungsinya |
| --- | --- |
| **Peran** | Apa kecocokan itu, atau **Tanpa gaya**. Untuk satu konstruksi di dalam baris: heading, strong, emphasis, code, strike, highlight, underline, link, subscript, superscript. Untuk seluruh baris: rule (pemisah tematik), list (penanda item daftar, termasuk indentasi dan spasi setelahnya), task (penanda diikuti kotak centang), dan quote (tanda `>` pada baris kutipan). Untuk blok yang dikenali utuh: codeBlock. Untuk blok yang baris pembuka dan penutupnya adalah kecocokan terpisah: quoteRegion. Untuk tabel, persamaan, atau diagram yang digambar sebagai gambar: renderedBlock. |
| **Grup konten** | Grup tangkapan, dihitung dari 1, yang memuat inti konstruksi: kata di dalam `*bold*`, judul dalam `\section{Title}`. Selain itu, kecocokan berisi tanda milik konstruksi itu sendiri, yang disembunyikan Sembunyikan Penanda. `0` berarti seluruh kecocokan adalah konten dan tidak ada yang disembunyikan, seperti pada alamat web. Kosongkan jika kecocokan hanya berupa tanda, seperti `== ` pada judul. |
| **Tingkat judul**, **Grup tingkat** | Tingkat judul, 1 sampai 6. Jika dikosongkan, tingkatnya adalah angka di akhir nama keluaran aturan (`heading2`), atau panjang grup tangkapan yang memuat rangkaian `#`. |
| **Grup penanda** | Untuk daftar atau tugas, grup tangkapan yang merupakan penanda beserta indentasi dan spasi setelahnya, ketika kecocokan diawali sesuatu yang lain, seperti `> ` pada item yang dikutip. |
| **Bergaya hingga akhir baris** | Memberi gaya dari kecocokan hingga akhir baris, untuk aturan yang hanya mencocokkan penanda judul dan membiarkan judulnya sebagai teks yang mengikuti. |
| **Digambar sebagai** | Untuk blok yang dirender, apa itu: tabel, matematika, atau diagram, atau **Bukan gambar**. |
| **Grup alamat** | Untuk tautan, grup tangkapan, dicoba berurutan, yang memuat alamat yang dibuka saat diklik atau diketuk; `0` adalah seluruh kecocokan. Hanya alamat web, surat, dan telepon yang dibuka. |

Nomor grup menghitung tanda kurung pola dari 1; 0 adalah seluruh kecocokan. Profil yang tidak menggantikan Markdown juga mempertahankan pembacaan Markdown sendiri untuk jenis yang tidak dinyatakan aturannya, seperti bilah kutipan dan pasangan `**`.

## Atribut dokumen dan bagian bersyarat

Aturan **Atribut dokumen** mendefinisikan nilai melalui `name`, dan aturan **Referensi atribut** (aturan inline dengan bagian `name` dan `original`) mengganti referensi dengan nilai itu. Referensi ke atribut yang belum didefinisikan tetap seperti yang ditulis. **Bagian bersyarat** mempertahankan atau membuang blok di antara barisnya, tergantung apakah atribut yang disebutnya diatur. Atribut berlaku mulai dari tempat didefinisikan dan seterusnya.

Aturan yang menghasilkan **Pengaturan untuk blok berikutnya** mengenali seluruh baris yang mengonfigurasi blok setelahnya dan tidak menampilkan apa pun sendiri. Bagian dan atribut tetapnya diberikan kepada blok itu: `title`, `id`, `nodeType`, `language`, dan `hardbreaks` memiliki arti yang tercantum di bawah Bagian, dan bagian lain disimpan pada blok, tempat tabel, daftar, atau kutipan membacanya.

## Menguji profil

Di bagian bawah editor, **Test Sample** berisi teks contoh (awalnya berupa judul dan satu baris teks). Pilih **Periksa sampel** untuk melihat node yang dibuat aturan Anda, diindentasi sesuai penumpukannya. Editor menyatakan "No blocks recognized." jika tidak ada yang cocok.

## Baseline

**Baseline** sebuah profil adalah titik pemulihannya: keadaannya saat Anda membuat, menduplikasi, atau mengimpornya. **Setel Ulang ke Baseline** membuang setiap perubahan sejak saat itu, setelah Anda mengonfirmasi. **Setel sebagai Baseline Baru** menyimpan profil dan menjadikan keadaan saat ini sebagai titik pemulihan.

Penyimpanan ditolak, dengan pesan, jika profil menggantikan Markdown tetapi tidak memiliki aturan akhir baris, jika pola tidak aman dan dapat membuat editor macet, atau jika file tidak dapat ditulis.

## Parts

Bagian adalah potongan bernama dari sebuah kecocokan yang dibaca oleh keluaran.

| Bagian | Artinya |
| --- | --- |
| `allOf` | Pemisah antar nama ketika semuanya diperlukan, seperti `+`. |
| `alt` | Deskripsi gambar, untuk pembaca yang tidak dapat melihatnya. |
| `anyOf` | Pemisah antar nama ketika salah satu saja cukup, seperti `,`. |
| `attribution` | Siapa yang mengucapkan kutipan, ditampilkan di bawahnya. |
| `citetitle` | Karya asal kutipan, ditampilkan setelah atribusi. |
| `columns` | Daftar kolom tabel, seperti `1,2,1`; jumlah entrinya menghitung kolom. |
| `condition` | Nama atribut yang menjadi syarat bagian. |
| `conditionType` | `defined` mempertahankan bagian ketika atribut diatur, `undefined` ketika tidak. |
| `content` | Teks itu sendiri, ketika bukan seluruh kecocokan. |
| `format` | Mesin diagram (`mermaid` atau `vega-lite`); untuk tabel, format berpembatas mana yang dipakai selnya. |
| `hardbreaks` | Jika ada, mempertahankan jeda baris tunggal pada blok berikutnya. |
| `header` | Nilai apa pun selain `false` menjadikan baris pertama tabel sebagai headernya. |
| `id` | Sebuah nama: untuk blok berikutnya, id yang dituju referensi silang; untuk catatan kaki, nama yang memungkinkan catatan kaki berikutnya tanpa teks sendiri berbagi nomornya. |
| `keys` | Tombol yang ditekan, dipisahkan koma. |
| `label` | Teks yang ditampilkan untuk referensi atau jangkar, sebagai ganti judul target itu sendiri. |
| `language` | Bahasa pemrograman blok kode, dipakai untuk pewarnaannya. |
| `level` | Tingkat judul, dari 1 sampai 6. |
| `marker` | Pemisah setelah istilah, seperti `::`. Penanda yang berbeda menumpuk daftar di dalam deskripsi. |
| `name` | Nama atribut, dalam definisi atau referensi. |
| `nodeType` | Menjadikan blok berikutnya keluaran lain, menurut namanya di file. |
| `noHeader` | Jika ada, tabel tidak memiliki baris header. |
| `notation` | Notasi matematika: `tex` (bawaan) atau `latex`. |
| `open` | `true` menampilkan bagian yang dapat diciutkan dalam keadaan terbuka. |
| `ordered` | `true` membuat daftar bernomor. |
| `original` | Referensi seperti yang ditulis, ditampilkan ketika atribut tidak didefinisikan. |
| `presentation` | Cara daftar deskripsi berikutnya ditampilkan: `sideBySide` menaruh istilah dan deskripsi dalam dua kolom; `questions` memberi nomor setiap istilah sebagai pertanyaan, dengan jawabannya di bawah. |
| `primary` | Entri indeks. |
| `secondary` | Sub-entri di bawah entri indeks. |
| `sectionLabel` | Kata yang diikuti nomor judul berikutnya, seperti `Appendix`: judul semacam itu dihitung tersendiri, `Appendix A:`. |
| `sectionLabelStart` | Yang pertama dari nomor-nomor itu: huruf (`A`) menghitung dengan huruf, angka dengan angka. |
| `src` | Alamat file video atau audio. |
| `start` | Angka awal daftar bernomor. |
| `summary` | Baris yang ditampilkan pada bagian yang dapat diciutkan saat tertutup. |
| `targetID` | Id yang dituju referensi. |
| `term` | Istilah yang dijelaskan. |
| `tertiary` | Sub-entri di bawah entri sekunder. |
| `text` | Teks yang ditampilkan, ketika pola menangkap lebih dari itu. Teks catatan kaki mengikuti paragraf, tabel, atau daftar tempatnya berada, bernomor. |
| `title` | Judul: heading kotak, tooltip gambar atau tautan, atau keterangan di atas blok berikutnya. |
| `type` | Jenis peringatan, seperti `note`, `tip`, atau `warning`. |
| `unset` | Jika ada, aturan menghapus atribut alih-alih mendefinisikannya. |
| `url` | Alamat yang dituju tautan atau gambar. |
| `value` | Nilai atribut; referensi ke atribut yang didefinisikan lebih awal diganti di dalamnya. |
