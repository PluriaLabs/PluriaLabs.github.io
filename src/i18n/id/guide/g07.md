# Chapter 60: Bilah samping

Bilah samping memuat lima panel: **File**, **Kerangka**, **Cari**, **Proyek** dan **Asisten**. Sakelar di bagian atas bilah samping memilih **File**, **Kerangka**, **Proyek** (muncul saat folder yang terbuka adalah proyek buku) atau **Asisten** (muncul setelah koneksi disiapkan). **Cari** memiliki header sendiri dengan judul **Cari**, tombol **Selesai** yang kembali ke File, dan kontrol cakupan untuk **Dokumen Ini** atau **Folder**; buka lewat **Tampilan ▸ Cari** (`⇧⌘F`). Menu **Tampilan** juga mengganti panel, dan memilih panel yang sedang tampil akan menyembunyikan bilah samping. Seret tepi bilah samping untuk mengubah ukurannya. Di atas pohon file, sebuah menu menawarkan **Buka File…** dan **Buka Folder…**.

## File

Panel File adalah pohon dari folder yang terbuka.

Jika tidak ada folder yang terbuka, panel ini menampilkan "Choose a folder to browse its files." dan menawarkan **Buka Folder** dan **Buka File**. Anda juga bisa menjatuhkan folder ke dalamnya. Saat Anda membuka satu file yang foldernya tidak dapat dilihat Pilcrow, panel ini menawarkan "Browse *folder* to see the files beside this document", dengan **Telusuri Folder Penampung…**.

Klik file untuk membukanya. Folder dapat dibuka dan ditutup. Klik kanan sebuah baris, atau tekan dan tahan di iPad, untuk melihat menunya:

| Item | Fungsinya |
| --- | --- |
| **File Baru** | Membuat file di dalam folder (atau di samping file yang Anda klik). |
| **Folder Baru** | Membuat folder di sana. |
| **Ganti Nama…** | Mengganti nama file atau folder. |
| **Pindahkan ke Sampah** | Memindahkannya ke Sampah setelah Anda mengonfirmasi. Anda dapat mengembalikannya dari sana. |
| **Tampilkan di Finder** | Menampilkannya di Finder (Mac). |

Jika sistem tidak memiliki Sampah untuk suatu lokasi, Pilcrow menyimpan item yang dihapus di bagian **Baru Saja Dihapus** di bagian bawah panel. Setiap item di sana menawarkan **Kembalikan** dan **Hapus Permanen**, dan **Kosongkan Baru Saja Dihapus** menghapus seluruh item di bagian itu untuk selamanya. Penghapusan permanen tidak dapat dibatalkan, jadi Pilcrow bertanya dulu. Item yang Anda hapus dari tempat lain tidak terpengaruh.

File dan folder tersembunyi ditampilkan atau disembunyikan lewat **Pengaturan ▸ File ▸ Tampilkan folder dan file tersembunyi**.

## Kerangka

Kerangka mencantumkan judul dari dokumen aktif, dengan indentasi sesuai tingkatnya. Klik sebuah judul untuk melompat ke sana. Tanda panah di samping judul menutup atau membuka judul-judul yang bersarang di bawahnya. Ini tidak mengubah dokumen, dan keadaan tertutup tidak disimpan.

Keadaan yang mungkin Anda lihat:

| Pesan | Artinya |
| --- | --- |
| **Tidak ada judul** | Profil aktif tidak menemukan judul. |
| **Indexing outline… N%** | Dokumen besar masih dipindai. |
| **Outline indexing failed. The listing may be incomplete.** | Pemindaian mengalami masalah. |
| **N headings near your position — scroll to see others.** | Dokumen yang sangat besar menampilkan sebagian kerangka di sekitar kursor. |

Di bawah kerangka, bagian **Isian** muncul saat dokumen memiliki isian yang harus diisi (Chapter 24). Bagian ini mencantumkannya, beserta jumlahnya; klik salah satu untuk menggulir ke sana dan memilihnya. Untuk isian dalam jumlah sangat banyak, tertulis "Only the first fields are listed."

## Cari

Panel Cari mencari di setiap file dalam folder yang terbuka. Tanpa folder, panel ini menampilkan "Open a folder to search it." dengan tombol **Buka Folder…**.

| Kontrol | Fungsinya |
| --- | --- |
| Isian **Cari di Folder** | Ketik untuk mencari seiring Anda mengetik. Tombol **clear** mengosongkannya. |
| **Aa** | **Cocokkan huruf besar/kecil.** |
| **ab** | **Seluruh kata.** |
| **.\*** | **Ekspresi reguler.** Pola yang salah dilaporkan di bawah isian. |
| Baris status | Menampilkan "Searching…" dengan tombol **Batalkan**, lalu "Matches: N". Pencarian berhenti pada 500 kecocokan dan menampilkan "Showing the first 500 matches." Setelah dibatalkan, tersedia **Cari Lagi**. |
| **Ganti…** | Muncul saat pencarian menemukan kecocokan. Membuka Ganti di Folder (Chapter 63). |
| Hasil | Setiap hasil menyebut file dan menampilkan barisnya. Klik salah satu untuk membuka file pada baris itu. |

## Proyek

Panel Proyek ditujukan untuk proyek buku. Lihat Chapter 34, Chapter 35 dan acuan panel Proyek di bawah.

### Acuan panel Proyek

| Bagian | Fungsinya |
| --- | --- |
| **This folder is not a book project.** dengan **Jadikan proyek** | Muncul saat folder yang terbuka tidak memiliki manifes. |
| **Coba lagi** | Muncul jika proyek tidak dapat dibaca. |
| **Tampilan** | Memilih **Daftar**, **Sinopsis** atau **Kartu**. |
| Judul, total kata | Nama proyek dan "N words", atau "N of target" saat target jumlah kata buku diatur. |
| Filter **Status** | Menyaring ke satu status, atau **Semua status**. Rekapitulasi mencantumkan setiap status beserta jumlah file dan katanya. Pengurutan ulang hanya tersedia selama tidak ada filter yang aktif. |
| **Pengaturan proyek** (roda gigi) | Membuka lembar pengaturan di bawah. |
| **Kompilasi…** | Membuka lembar kompilasi (Chapter 64). |
| **Susun ulang** dan **Selesai** | Di iPad, seret bab ke urutan baru, lalu pilih **Selesai**. |
| **File Baru** (plus) | Menawarkan **Bab baru**, **Adegan baru**, **Bagian awal baru**, **Bagian akhir baru**. |
| **Tidak ada dalam naskah** dengan **Tambah** dan **Tambahkan semua** | Mencantumkan file di folder yang tidak disertakan manifes. |
| Tanda panah pada baris | **Tampilkan adegan** atau **Sembunyikan adegan** di bawah sebuah bab. |
| Tag **Hilang** dan **Dikecualikan** | File yang tidak dapat ditemukan, atau yang Anda kecualikan dari naskah. |
| Menu pada baris | **Detail…**, **Berkas baru di bawah**, **Pindahkan bab ke atas**, **Pindahkan bab ke bawah**, **Sertakan dalam naskah**, **Kecualikan dari naskah**. |
| **Target jumlah kata** per item | Setiap item menampilkan jumlah katanya dan targetnya, jika ada. |

**Detail** untuk sebuah item memiliki **Jenis** (Bagian awal, Bagian, Bab, Adegan, Bagian akhir), **Status**, **Sudut pandang**, **Lokasi**, **Target jumlah kata**, dan **Sinopsis**. File proyek yang berubah di disk menampilkan "The project file changed on disk, so your last change was not applied. Try it again." dengan **Abaikan**.

**Pengaturan proyek** memiliki **Judul**, **Penulis**, **Target jumlah kata buku**, **Berkas baru ditulis dalam** (sintaks untuk bab dan adegan baru; file yang sudah ada tetap memakai sintaksnya), **Variabel** (nama dan nilai, ditulis sebagai `{{name}}` dalam teks Anda; `{{title}}` dan `{{author}}` selalu berfungsi), dan **Apa yang dihitung sebagai kata**: **Hitung judul**, **Hitung bagian awal**, **Hitung blok kode**. Pilih **Simpan** atau **Batalkan**.

## Asisten

Panel Asisten muncul setelah koneksi disiapkan (Chapter 65).

# Chapter 61: Bilah alat pemformatan dan bar status

## Bilah alat pemformatan

Bilah alat pemformatan adalah baris opsional di bawah teks. Tampilkan atau sembunyikan dengan **Tampilan ▸ Bilah Alat Pemformatan**, **Lainnya ▸ Bilah Alat Pemformatan**, **Pengaturan ▸ Pengeditan ▸ Bilah Alat Pemformatan**, atau item **Sembunyikan Bilah Alat** pada bilah alat itu sendiri. Bilah alat bekerja lewat profil aktif, jadi tombol yang tidak dapat diungkapkan oleh profil akan berwarna abu-abu.

| Kontrol | Fungsinya |
| --- | --- |
| Menu **Jenis paragraf** (misalnya "Paragraf" atau "Judul 1") | Menampilkan jenis baris saat ini dan mengubahnya: **Paragraf**, **Judul 1** sampai **6**, **Kutipan blok**, **Daftar Berpoin**, **Daftar Bernomor**, **Daftar Tugas**, **Pagar Kode**. |
| **Tebal** (`⌘B`) | Strong. |
| **Miring** (`⌘I`) | Penekanan. |
| **Kode inline** | Kode. |
| **Sisipkan tautan** (`⌘K`) | Membuat tautan. |
| **Kutipan blok** | Mengaktifkan atau mematikan kutipan. |
| **Daftar berpoin** | Mengaktifkan atau mematikan daftar poin. |
| **Pemformatan lainnya** (**⋯**) | Perintah yang lebih jarang dipakai: **Coretan**, **Sisipkan Matematika Inline**, **Sisipkan Daftar Tugas**, **Ubah Status Tugas**, **Indentasi**, **Kurangi Indentasi**, **Tambah Tingkat Judul**, **Kurangi Tingkat Judul**, **Sisipkan Tabel…**, **Sisipkan Gambar…**, **Sisipkan Diagram**, **Sisipkan Bagan**, **Sisipkan Matematika Tampilan**, **Sisipkan Pagar Kode**, **Sisipkan Peringatan**, **Sisipkan Garis Horizontal**, **Sisipkan Referensi Tautan**, **Sisipkan Catatan Kaki**, **Sisipkan Daftar Isi**, **Sisipkan Front Matter YAML**, dan **Sembunyikan Bilah Alat**. |

## Bar status

Bar status membentang di sepanjang bagian bawah. Aktifkan atau matikan dengan **Pengaturan ▸ Pengeditan ▸ Tampilkan bar status**.

| Bagian | Yang ditampilkan atau fungsinya |
| --- | --- |
| **Kata**, **Br**, **Kol** | Jumlah kata, serta baris dan kolom kursor. Dengan pilihan, ditambahkan "Sel: N ln · N ch" untuk baris dan karakter yang dipilih. |
| Menu **Sintaks** (misalnya "CommonMark") | Profil untuk dokumen ini. Klik untuk memilih yang lain, atau **Tanpa Sintaks** untuk teks biasa. |
| **Fields left: N** | Muncul saat makro meninggalkan isian yang harus diisi. Klik untuk melompat ke isian berikutnya. |
| Kemajuan dan status | **Indexing N%**, **Lexing N%** saat file besar dianalisis, dan **Translating N%** dengan **About N left** serta tombol **Batalkan terjemahan** saat terjemahan berjalan. |
| **Tidak sinkron** | Peringatan bahwa editor dan log perubahan dokumen telah berbeda. Menyimpan membiarkan file tetap bertanda belum tersimpan agar tidak ada yang hilang: salin teks Anda ke tempat aman, lalu tutup dan buka kembali dokumen. |
| Informasi dokumen | Klik jumlahnya, atau tooltip "Show document information", untuk membuka **Informasi Dokumen**. |

**Informasi Dokumen** mencantumkan **Kata**, **Karakter**, **Baris**, **Waktu membaca** (berdasarkan kecepatan membaca Anda di Pengaturan), **Kursor**, **Pilihan**, **Enkode** dan **Sintaks**. Pada file yang sangat besar, jumlahnya untuk bagian yang dimuat sampai pengindeksan selesai, dan waktu membaca diperkirakan untuk seluruh file. **Konversi Ke…** di bawah **Enkode** memilih enkode teks lain; file dikonversi saat disimpan berikutnya.


# Chapter 62: Cari, ganti, Buka Baris, Buka Cepat dan palet perintah

## Bilah cari

Buka dengan **Cari…** (`⌘F`), tombol **Cari**, atau **Ganti…** (`⌘R`). Bilah ini berada di bagian atas dokumen.

| Kontrol | Fungsinya |
| --- | --- |
| Isian **Cari di dokumen** | Ketik teks yang dicari. Kecocokan disorot seiring Anda mengetik. |
| **Aa**, **ab**, **.\*** | **Cocokkan huruf besar/kecil**, **Seluruh kata**, **Ekspresi reguler**. |
| **Kecocokan sebelumnya**, **Kecocokan berikutnya** | Berpindah di antara kecocokan (`⇧⌘G`, `⌘G`). |
| **Tampilkan ganti** / **Sembunyikan ganti** (tanda panah) | Menampilkan isian **Ganti dengan**. |
| **Ganti**, **Ganti Semua** | Mengganti kecocokan saat ini, atau setiap kecocokan. Berwarna abu-abu sampai ada kecocokan. |
| **Cari di** (sakelar di ujung kiri bilah) | **Dokumen Ini**, atau **Folder** untuk mencari di seluruh folder yang terbuka. |
| **Tutup bilah cari** | Menutupnya. |

Saat kecocokan lebih banyak daripada yang dihitung Pilcrow, bilah menampilkan "More matches remain". Di **Pratinjau**, Cari menelusuri kata-kata yang dirender dan menyorotnya, hingga 2.000 kecocokan. Pola yang tidak dapat dipakai menampilkan "Invalid pattern". Ganti hanya tersedia di Edit: di Pratinjau bilah menampilkan "Replace works in Edit. Switch to Edit to change the text." Di **Berdampingan**, Cari mencari di sumber dan menyorot kata yang cocok di pratinjau.

## Buka Baris

**Buka Baris…** (`⌃G`) membuka lembar kecil dengan satu isian, "Line number, or line:column". Ketik `120` atau `120:8` lalu pilih **Buka**, atau **Batalkan**. Nomor yang melewati akhir akan membawa ke baris terakhir. Pilcrow menampilkan "Enter a line number, such as 120 or 120:8." untuk masukan lain. Pada file yang sangat besar yang barisnya masih dihitung, Pilcrow meminta Anda mencoba lagi sebentar lagi.

## Buka Cepat

**Buka Cepat…** (`⇧⌘O`) adalah pencarian nama file di seluruh folder yang terbuka. Ketik sebagian nama, dan daftar menyempit serta menampilkan "N matches". Pilih sebuah hasil lalu **Buka**, atau **Batalkan**. Berwarna abu-abu jika tidak ada folder yang terbuka.

## Palet perintah

**Palet Perintah…** (`⌃⇧P`) mencantumkan perintah Pilcrow berdasarkan nama, beserta pintasannya, sehingga Anda dapat menjalankan salah satunya tanpa mencari menunya. Ketik untuk menyempitkan daftar, pilih perintah lalu **Jalankan**, atau **Batalkan**. Palet menampilkan "No matching commands" saat tidak ada yang cocok. Perintah yang saat ini tidak dapat dijalankan, seperti pengeditan sumber saat Anda berada di Pratinjau, ditampilkan berwarna abu-abu. Daftar mencakup perintah pemformatan dan penyisipan, perintah Edit untuk pilihan, baris dan huruf besar/kecil, ucapan, pengalih Tampilan, zoom, dan panel bilah samping, serta aksi file dan ekspor. Pintasan untuk membuka palet dapat diubah di **Pengaturan ▸ Keyboard**.
