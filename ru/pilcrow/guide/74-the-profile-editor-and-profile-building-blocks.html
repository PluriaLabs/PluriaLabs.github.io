Редактор профилей и строительные блоки профиля

Синтаксический профиль сообщает Pilcrow, что означает ваша разметка. В этой главе редактор профилей описан элемент за элементом, а затем перечислены все строительные блоки, которые может использовать профиль. Вводное описание по задачам см. в Chapter 37 — Chapter 39.

Откройте редактор через Настройки ▸ Библиотека ▸ Синтаксические профили: Создать начинает новый профиль, Изменить меняет пользовательский, а Дублировать копирует встроенный профиль, чтобы вы могли изменить копию. Заголовок редактора — Изменить профиль, с кнопками Отменить, Сохранить и Справка по профилям (она открывает встроенную справку по этим строительным блокам). На узком экране переключатель Раздел профиля выбирает между Обзор, Правила и Тестовый образец; на широком все три показаны одновременно.

Обзор#

ПолеЧто делает
ИмяИмя профиля, показываемое в меню строки состояния и в настройках.
ОписаниеЗаметка о профиле.
Расширения файлов (через запятую)Расширения, по которым для файла выбирается этот профиль. Два профиля не могут иметь одно расширение.
НаследуетНет или другой профиль, на правилах которого строится этот.
СинтаксисРасширяет Markdown или Заменяет Markdown (см. ниже).
КраткоКоличество Правила блоков, Внутристрочные правила и Правила вложенности.
Изменить расширенный JSON…Открывает профиль как JSON для полей, которые пошаговый редактор не показывает. Применить сохраняет ваши изменения JSON; Отменить отбрасывает их.

Расширяет Markdown добавляет ваши правила к правилам Markdown: его заголовки, списки, курсив и остальное по-прежнему читаются, а ваши блочные и внутристрочные правила дополняют их. Правило, которое является неизменённой копией одного из правил профиля CommonMark, описывает то, что Markdown уже умеет, и остаётся на его усмотрение. Заменяет Markdown делает ваши правила всем синтаксисом, поэтому конструкции Markdown перестают распознаваться. В этом случае одно правило должно создавать Конец строки, иначе ничто не разделит текст на абзацы. Редактор предупреждает: «Add a rule whose output node is "newline", or nothing will separate into paragraphs», и профиль нельзя сохранить, пока такого правила нет. Он также перечисляет все типы вывода, которые профиль не определяет.

Правила#

Правила делятся на три группы.

Правила блоков#

Правило блока распознаёт целые строки и блоки. Добавить правило добавляет одно. У каждого правила есть Шаблон, тип Совпадение, то, что оно Создаёт, и Параметры. Правило удаляется кнопкой Удалить. Если правил нет, редактор сообщает: «No rules yet. Add one to recognize a block construct.»

Внутристрочные правила#

Внутристрочное правило распознаёт текст внутри строки. Добавить внутристрочное правило добавляет одно. Для внутристрочных правил доступны четыре типа совпадения (Буквальный префикс, Точное совпадение, Regex (ограниченная) и Пара разделителей); для правил блоков — все семь.

Правила вложенности#

Правила вложенности говорят, какие выводы могут находиться внутри каких. У каждого есть Родительский узел и Допустимые дочерние узлы (через запятую). Пусто означает отсутствие ограничений: «No restrictions. Every node type may nest inside any other.» Добавить правило вложенности добавляет одно.

Типы совпадения#

Тип совпаденияКак читает шаблонБлокВ строке
Буквальный префиксТекст, которым начинается конструкция.дада
Точное совпадениеВесь текст конструкции.дада
Префикс в начале строкиТекст в начале строки, например # .да
Блок с отступомСтроки, начинающиеся с шаблона, например четырёх пробелов или табуляции. Идущие подряд строки и пустые строки между ними образуют один блок, показываемый без отступа.да
Огражденный блокСтрока, открывающая блок, который закрывается соответствующей строкой.да
Regex (ограниченная)Регулярное выражение. Pilcrow предупреждает перед сохранением выражения, которое может зависнуть: «This regex could hang the editor — simplify it.»дада
Пара разделителейОдна и та же метка с обеих сторон текста в одной строке, например %% в %%this%%. Сразу внутри меток нет пробела.дада

В регулярном выражении (?<name>…) называет часть совпадения. См. раздел «Именованные части» ниже.

Параметры правила#

В группе Параметры каждого правила есть:

ПараметрЧто делает
ПриоритетПравила с более высоким приоритетом проверяются первыми.
Только в начале строкиНе позволяет правилу срабатывать посреди строки.
Именованные части становятся атрибутамиКаждая именованная часть регулярного выражения становится атрибутом вывода. Редактор перечисляет «Parts in this pattern» и «Parts this output reads». Для вывода, содержащего текст, например жирного шрифта или ссылки, показывается часть с именем text, если она есть, иначе последняя совпавшая часть.
СоздаётЧто создаёт правило: вывод из списков ниже или имя Пользовательский.
Своё имя узлаИмя для вывода Пользовательский.
Постоянные атрибутыЧасти, которые каждый раз имеют одно и то же значение; добавляются через Добавить атрибут (Имя и Значение). Значение может включать именованную часть, записываемую как {name}: правило для e-mail, шаблон которого называет часть address, может задать своей ссылке url со значением mailto:{address}.
Текст вставкиЧто меню Вставка записывает для этого правила, в точности так, как это должно выглядеть, с $0 в том месте, где должен встать курсор. Правилу, которое срабатывает по регулярному выражению, блоку или отступу, это нужно, иначе меню «Вставка» его пропустит.
Только после пустой строкиДля блока с отступом: строка с отступом сразу после текста остаётся частью этого текста, например следующая строка элемента списка.
После Return в конце строкиДля списков и цитат: Автоматически (повторяет маркеры и знаки цитаты, увеличивает номера нумерованных элементов и начинает пункты задач неотмеченными), Повторить маркер, Увеличить номер, Начать заново с маркера или Ничего не добавлять.

Огражденные и ограниченные разделителями блоки#

Для правила Огражденный блок параметр Блок содержит указывает, что находится внутри:

ВыборЗначение
Пока ничегоНе задано.
Текст, как написанКод или форматированный текст.
Ничего — скрытоКомментарий, исключённый из документа.
Другие блоки, в рамкеЦитата, врезка или примечание, содержащие абзацы, списки и прочее.
Другие блоки, без рамкиБлоки объединяются с окружающим текстом; строки лишь группируют их.
ТаблицаСм. раздел «Таблицы» ниже.
Таблица, нарисованная текстомСетка или выровненные столбцы текста, идущие от открывающей строки до следующей пустой строки, как в reStructuredText.
Текст с отступом под строкой, оканчивающейся маркеромОткрывающая строка — это проза, заканчивающаяся маркером, как :: в reStructuredText; проза остаётся абзацем, а текст с отступом под ней после пустой строки показывается как написан.
Текст с отступом под открывающей строкойДиректива, такая как .. code-block::, которая содержит строки с отступом под собой и не имеет закрывающей строки.

Закрывающая строка — это строка, которая завершает блок; пусто означает ту же строку, что и открывающая («Same as the opening line»). Разделитель, не являющийся регулярным выражением, например +++, сопоставляется как обычный текст. Закрывающая строка повторяет открывающий знак не меньше раз предназначено для ограждений в стиле Markdown: закрывающая строка — это первый символ открывающей строки, повторённый не меньше раз, поэтому более длинное ограждение содержит более короткое как текст. Язык текстового блока, если открывающая строка называет известный язык, подсвечивается в редакторе цветом.

НастройкаЧто делает
Вкладывать списки по маркеруКаждый новый маркер, например ** после *, начинает более глубокий уровень независимо от отступа.
Строка продолжения спискаСтрока, стоящая отдельно после элемента списка, которая присоединяет следующий блок к этому элементу.
Сохранять одиночные переводы строкПеревод строки внутри абзаца остаётся переводом строки.
Присваивать заголовкам идентификаторыЗаголовок без собственного идентификатора получает его из названия: строчными буквами, слова соединены разделителем слов после префикса (Префикс идентификатора, Разделитель слов в идентификаторе). При _ и _ «Getting Started» превращается в _getting_started, так что перекрёстная ссылка на него показывает название. Повторяющееся название добавляет разделитель и число.

Внутристрочные метки, парные по своему окружению#

Язык вроде Markdown записывает полужирный и курсив серией символов, которая открывает или закрывает выделение в зависимости от соседних символов, а фрагмент кода или ссылку — скобками, поэтому один шаблон на всю конструкцию их найти не может. Включите Читать метки по их окружению, чтобы описать их.

НастройкаЧто делает
Символ экранированияСимвол, делающий следующий за ним обычным.
Символ фрагмента кодаСерия этого символа открывает фрагмент, который закрывает следующая серия той же длины.
Метки-серииМетки, образующие пары как серии; добавляются через Добавить метку-серию. У каждой есть Метка, что Одна метка рисует, что Две метки рисуют и Может открываться и закрываться внутри слова (выключено для _).
Парные меткиМетки, образующие пару с серией той же длины; добавляются через Добавить парную метку: Метка, что она Рисует, и Только если включён этот параметр — настройка синтаксиса, например выделения, которая должна быть включена (или Всегда).
Ссылки и веб-адресаПрефикс изображения, Адрес сам по себе заключается в, Схемы, с которых начинается простой адрес, Строка, определяющая метку, содержит и Метка сноски начинается с (символ после открывающей скобки метки, который делает её сноской: [^note] рисуется как ссылка на сноску, когда строка начинается с [^note]:).

Метки образуют пары в пределах строки. Код, экранированные символы и адрес ссылки для окружающих их меток — обычный текст.

Стилизованный исходник#

При включённом Стилизованный исходник редактор рисует документ в виде его синтаксиса: более крупные заголовки, полужирные и курсивные фрагменты, полосы цитат, отступы списков, флажки задач, линии, ссылки и карточки кода, и скрывает создающие их метки (при включённом Скрыть разметку), кроме строки, на которой стоит курсор. Редактор ничего не знает ни об одном отдельном синтаксисе: правило говорит, чем является его совпадение, через запись стилизации, а правило без неё раскрашивается, но не переоформляется.

В Параметры каждого правила есть группа Оформленный исходный текст:

ПолеЧто делает
РольЧем является совпадение, или Без оформления. Для одной конструкции внутри строки: heading, strong, emphasis, code, strike, highlight, underline, link, subscript, superscript. Для целой строки: rule (тематический разрыв), list (маркер элемента списка, включая его отступ и пробел после него), task (маркер с флажком) и quote (знаки > цитируемой строки). Для блока, распознаваемого целиком: codeBlock. Для блока, открывающая и закрывающая строки которого — отдельные совпадения: quoteRegion. Для таблицы, формулы или диаграммы, нарисованных как картинка: renderedBlock.
Группа содержимогоГруппа захвата, считая с 1, которая содержит то, о чём конструкция: слово внутри *bold*, название в \section{Title}. Всё остальное в совпадении — собственные метки конструкции, которые скрывает «Скрыть разметку». 0 означает, что всё совпадение — содержимое и ничего не скрывается, как для веб-адреса. Не указывайте, если совпадение состоит только из меток, например == заголовка.
Уровень заголовка, Группа уровняУровень заголовка от 1 до 6. Если не указан, это число в конце имени вывода правила (heading2) или длина группы захвата, содержащей серию #.
Группа маркераДля списка или задачи — группа захвата, являющаяся маркером с его отступом и пробелами после него, когда совпадение начинается с чего-то другого, например с > цитируемого элемента.
Оформляет до конца строкиОформляет от совпадения до конца строки, для правила, которое совпадает только с маркером заголовка и оставляет его название как следующий за ним текст.
Отображается какДля отрисованного блока — чем он является: таблицей, формулой или диаграммой, или Не изображение.
Группы адресаДля ссылки — группы захвата, проверяемые по порядку, которые содержат адрес, открываемый по щелчку или касанию; 0 — всё совпадение. Открываются только веб-адреса, адреса почты и телефона.

Номера групп считают скобки шаблона с 1; 0 — всё совпадение. Профиль, который не заменяет Markdown, также сохраняет собственное чтение Markdown для видов, которые его правила не объявляют, например его полосы цитат и пары **.

Атрибуты документа и условные разделы#

Правило Атрибут документа определяет значение по name, а правило Ссылка на атрибут (внутристрочное правило с частями name и original) заменяет ссылку этим значением. Ссылка на атрибут, который никто не определил, остаётся как написана. Условный раздел сохраняет или отбрасывает блоки между своими строками в зависимости от того, заданы ли названные в нём атрибуты. Атрибуты действуют с того места, где они определены, и далее.

Правило, создающее Настройки следующего блока, распознаёт целую строку, которая настраивает следующий за ней блок и сама ничего не показывает. Её части и постоянные атрибуты передаются этому блоку: title, id, nodeType, language и hardbreaks имеют значения, перечисленные в разделе «Части», а любая другая часть сохраняется в блоке, где её читает таблица, список или цитата.

Проверка профиля#

Внизу редактора в Тестовый образец находится образец текста (сначала это заголовок и строка текста). Выберите Проверить образец, чтобы увидеть узлы, которые создают ваши правила, с отступами по вложенности. Если ничего не совпало, выводится «No blocks recognized.»

Исходная версия#

Исходная версия профиля — это его точка восстановления: каким он был, когда вы его создали, продублировали или импортировали. Вернуть к исходной версии отбрасывает все изменения с тех пор после вашего подтверждения. Сделать новой исходной версией сохраняет профиль и делает его текущее состояние точкой восстановления.

Сохранение отклоняется с сообщением, если профиль заменяет Markdown, но не имеет правила конца строки, если шаблон небезопасен и может зависнуть в редакторе или если файл не удаётся записать.
