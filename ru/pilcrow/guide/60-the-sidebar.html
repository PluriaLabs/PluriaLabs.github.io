Глава 60

Боковая панель

В боковой панели пять разделов: Файлы, Структура, Поиск, Проект и Ассистент. Переключатель вверху боковой панели выбирает Файлы, Структура, Проект (он виден, когда открытая папка является книжным проектом) или Ассистент (он виден после настройки подключения). У раздела Поиск собственный заголовок с названием Найти, кнопка Готово, которая возвращает к файлам, и переключатель области поиска: Этот документ или Папка; открыть его можно через Вид ▸ Поиск (⇧⌘F). Разделы также переключаются в меню Вид, а выбор уже открытого раздела скрывает боковую панель. Чтобы изменить ширину боковой панели, перетащите её край. Над деревом файлов меню предлагает Открыть файл… и Открыть папку….

Файлы#

Раздел «Файлы» показывает дерево открытой папки.

Если папка не открыта, в нём написано «Choose a folder to browse its files.» и предлагаются Открыть папку и Открыть файл. Папку можно и перетащить на панель. Если вы открыли отдельный файл, а его папка недоступна Pilcrow, предлагается «Browse папка to see the files beside this document» с кнопкой Просмотреть папку с файлом….

Нажмите на файл, чтобы открыть его. Папки раскрываются и сворачиваются. Щёлкните строку правой кнопкой (на iPad нажмите и удерживайте), чтобы открыть её меню:

ПунктЧто делает
Новый файлСоздаёт файл в папке (или рядом с файлом, на который вы нажали).
Новая папкаСоздаёт там папку.
Переименовать…Переименовывает файл или папку.
Переместить в КорзинуПеремещает в Корзину после подтверждения. Оттуда его можно вернуть.
Показать в FinderПоказывает его в Finder (Mac).

Если для какого-то места в системе нет Корзины, Pilcrow хранит удалённые объекты в разделе Недавно удалённые внизу панели. Для каждого объекта там доступны Вернуть и Удалить навсегда, а Очистить «Недавно удалённые» безвозвратно удаляет все объекты раздела. Удаление навсегда отменить нельзя, поэтому Pilcrow сначала спрашивает. Объекты, которые вы удалили в других местах, не затрагиваются.

Скрытые файлы и папки показываются или скрываются параметром Настройки ▸ Файлы ▸ Показывать скрытые папки и файлы.

Структура#

Структура перечисляет заголовки активного документа с отступами по уровням. Нажмите на заголовок, чтобы перейти к нему. Стрелка рядом с заголовком сворачивает или разворачивает вложенные под ним заголовки. Документ при этом не меняется, а свёрнутое состояние не сохраняется.

Какие сообщения вы можете увидеть:

СообщениеЗначение
Нет заголовковАктивный профиль не нашёл заголовков.
Indexing outline… N%Большой документ ещё сканируется.
Outline indexing failed. The listing may be incomplete.При сканировании возникла проблема.
N headings near your position — scroll to see others.В очень большом документе показано окно структуры вокруг курсора.

Под структурой появляется раздел Поля, если в документе есть поля для заполнения (глава 24). Он перечисляет их с общим числом; нажмите на поле, чтобы прокрутить к нему и выделить его. Если полей очень много, написано «Only the first fields are listed.»

Поиск#

Раздел «Поиск» ищет по всем файлам открытой папки. Если папки нет, в нём написано «Open a folder to search it.» и есть кнопка Открыть папку….

ЭлементЧто делает
Поле Поиск в папкеВводите текст, и поиск идёт по мере набора. Кнопка очистить опустошает поле.
AaУчитывать регистр.
abСлово целиком.
.\*Регулярное выражение. О неверном шаблоне сообщается под полем.
Строка состоянияПоказывает «Searching…» с кнопкой Отменить, затем «Matches: N». Поиск останавливается на 500 совпадениях и пишет «Showing the first 500 matches.» После отмены предлагается Искать снова.
Заменить…Появляется, когда поиск нашёл совпадения. Открывает замену в папке (глава 63).
РезультатыДля каждого результата указан файл и показана строка. Нажмите на результат, чтобы открыть файл на этой строке.

Проект#

Раздел «Проект» предназначен для книжных проектов. См. главы 34 и 35 и справочник по разделу «Проект» ниже.

Справочник по разделу «Проект»#

ЭлементЧто делает
This folder is not a book project. с кнопкой Сделать проектомПоказывается, когда в открытой папке нет манифеста.
ПовторитьПоказывается, если проект не удалось прочитать.
ВидВыбирает Список, Аннотации или Карточки.
Название, итоги по словамНазвание проекта и «N words», либо «N of target», если задана цель по числу слов в книге.
Фильтр СтатусОставляет один статус или Все статусы. Сводка перечисляет каждый статус с числом файлов и слов. Менять порядок можно только при выключенном фильтре.
Настройки проекта (шестерёнка)Открывает окно настроек, описанное ниже.
Скомпилировать…Открывает окно компиляции (глава 64).
Изменить порядок и ГотовоНа iPad перетащите главы в новом порядке, затем выберите Готово.
Новый файл (плюс)Предлагает Новая глава, Новая сцена, Новая вводная часть, Новые приложения.
Не в рукописи с кнопками Добавить и Добавить всеПеречисляет файлы папки, которых нет в манифесте.
Стрелка в строкеПоказать сцены или Скрыть сцены под главой.
Метки Отсутствует и ИсключеноФайл, который не удалось найти, или который вы исключили из рукописи.
Меню строкиПодробности…, Новый файл ниже, Переместить главу вверх, Переместить главу вниз, Включить в рукопись, Исключить из рукописи.
Цель по числу слов для каждого элементаУ каждого элемента показано число слов и цель, если она задана.

В Подробностях элемента есть Тип (Вводная часть, Часть, Глава, Сцена, Приложения), Статус, Точка зрения, Расположение, Цель по числу слов и Аннотация. Если файл проекта изменился на диске, появляется «The project file changed on disk, so your last change was not applied. Try it again.» с кнопкой Закрыть.

В Настройках проекта есть Название, Автор, Цель по числу слов в книге, Новые файлы создаются в формате (синтаксис для новых глав и сцен; существующие файлы сохраняют свой), Переменные (имя и значение, которые записываются в тексте как {{name}}; {{title}} и {{author}} работают всегда) и Что считается словом: Учитывать заголовки, Учитывать вводную часть, Учитывать блоки кода. Выберите Сохранить или Отменить.
